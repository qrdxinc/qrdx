`handleImageLoad`는 브라우저에서 이미지 요소의 QR 코드를 디코딩하고 그 텍스트를 반환합니다. 이미지를 어디에도 전송하지 않고 업로드한 파일, 스크린샷, 사진에서 코드를 읽을 때 사용하세요. 바로 쓸 수 있는 드롭 영역이 필요하다면 이 함수를 기반으로 만든 [QR Code Scanner](/docs/components/qr-code-scanner) 컴포넌트를 설치하세요.

| 함수 | 반환값 | 참고 |
| --- | --- | --- |
| `handleImageLoad(img, size, returnFullData?)` | `Promise<string \| QRCode \| "NO_QR">` | 디코딩된 텍스트를 반환하며, `returnFullData`를 지정하면 디코더의 전체 결과를 반환합니다. 아무것도 찾지 못하면 `"NO_QR"`을 반환합니다. 브라우저 전용 |
| `downloadImageWithBoundingBox(img, corners, filename)` | `void` | 찾은 코드에 빨간 윤곽선을 그린 이미지를 PNG로 저장합니다 |
| `getImageScanScore(imageOrBlob, options?)` | `Promise<ImageScanScoreResult>` | 기존 이미지를 디코딩하고 점수를 매깁니다. [스캔이 될까요?](/docs/features/frames#will-it-scan)를 참고하세요 |
| `scanQRPixels(pixels, expected, options?)` | `Promise<PixelScanResult>` | Node에서 RGBA 픽셀이 `expected`로 디코딩되는지 확인합니다 |

## 업로드한 이미지 디코딩 [#decode-an-uploaded-image]

```tsx title="components/qr-reader.tsx"
"use client";

import { handleImageLoad } from "qrdx";
import { useState } from "react";

async function decodeFile(file: File): Promise<string | null> {
  const url = URL.createObjectURL(file);
  try {
    const image = new Image();
    image.src = url;
    await image.decode();
    const result = await handleImageLoad(image, image.naturalWidth);
    return typeof result === "string" && result !== "NO_QR" ? result : null;
  } finally {
    URL.revokeObjectURL(url);
  }
}

export function QrReader() {
  const [result, setResult] = useState("");

  async function onChange(event: React.ChangeEvent<HTMLInputElement>) {
    const file = event.target.files?.[0];
    if (!file) return;
    try {
      setResult((await decodeFile(file)) ?? "No QR code found");
    } catch {
      setResult("Could not read that image");
    }
  }

  return (
    <div>
      <input
        accept="image/*"
        aria-label="Image with a QR code"
        type="file"
        onChange={onChange}
      />
      {result ? <p>{result}</p> : null}
    </div>
  );
}
```

코드가 담긴 스크린샷을 선택하면 입력란 아래에 해당 링크가 나타납니다. `image.decode()`는 파일이 로드될 때까지 기다리고, 이후 `handleImageLoad`가 이미지를 캔버스에 그린 뒤 jsQR을 실행합니다. jsQR은 필요할 때 로드되므로 스캔하지 않는 번들에는 포함되지 않습니다.

## 감지 방식 [#how-detection-works]

`handleImageLoad(img, size, returnFullData)`는 먼저 이미지 전체를 시도한 다음, 이미지의 65% 크기로 자른 네 영역(왼쪽 아래, 오른쪽 아래, 오른쪽 위, 가운데)을 각각 100%에서 10%까지 여섯 가지 배율로 시도합니다. 처음으로 성공한 디코딩 결과를 반환하므로, 스크린샷의 작은 부분만 차지하는 코드도 찾을 수 있습니다. 매우 넓거나 긴 이미지는 먼저 축소합니다.

- `img`는 로드가 끝난 `<img>`여야 합니다. `decode()` 또는 `load` 이벤트를 기다리세요.
- `size`는 이전 릴리스와의 호환성을 위해 남겨 둔 값이며 무시됩니다. 배율은 이미지 자체의 크기에서 정해집니다. 이미지의 너비를 전달하세요.
- `returnFullData`를 지정하면 텍스트 대신 jsQR의 결과 객체를 반환합니다.

흐릿하거나, 가장자리가 잘렸거나, 배경보다 밝은 코드(어두운 바탕에 밝은 모듈)는 `"NO_QR"`로 보고됩니다.

## 위치와 원시 데이터 [#position-and-raw-data]

`returnFullData`를 설정하면 결과는 디코더의 객체 그대로입니다.

```ts title="lib/decode-full.ts"
import { handleImageLoad } from "qrdx";

const found = await handleImageLoad(image, image.naturalWidth, true);
if (found !== "NO_QR") {
  found.data; // "https://example.com"
  found.version; // 1 to 40
  found.binaryData; // the raw bytes, as number[]
  found.chunks; // the encoded segments and their modes
  found.location.topLeftCorner; // { x, y } in the image's pixels, and the other three corners
}
```

`downloadImageWithBoundingBox`는 원본 이미지에 코드의 윤곽선을 그려 저장합니다. 사진이 예상과 다른 값으로 디코딩될 때 도움이 됩니다. 모서리는 왼쪽 위, 오른쪽 위, 왼쪽 아래, 오른쪽 아래 순서로 전달합니다.

```ts title="lib/debug-detection.ts"
import { downloadImageWithBoundingBox, handleImageLoad } from "qrdx";

const found = await handleImageLoad(image, image.naturalWidth, true);
if (found !== "NO_QR") {
  const { topLeftCorner, topRightCorner, bottomLeftCorner, bottomRightCorner } = found.location;
  downloadImageWithBoundingBox(
    image,
    [topLeftCorner, topRightCorner, bottomLeftCorner, bottomRightCorner],
    "found-code.png"
  );
}
```

## 디코딩만 하지 않고 이미지 평가하기 [#score-an-image-instead-of-only-decoding-it]

`getImageScanScore`는 기존 이미지를 디코딩하면서 얼마나 안정적으로 스캔될지도 알려 줍니다. 카메라와 유사한 흐림, 대비, 극성, 여백, 해상도를 적용해 세 가지 크기로 디코딩합니다. `File`, `Blob`, `<img>`를 받을 수 있습니다.

```ts title="lib/score-image.ts"
import { getImageScanScore } from "qrdx";

const { data, score, grade, checks } = await getImageScanScore(file);
// data: "https://example.com" or null
// score: 0 to 100, grade: "great" | "ok" | "risky" | "fails"
```

[스캔 검사기](/tools/scan-checker)가 이 함수를 기반으로 만들어졌습니다. Node에서는 `scanQRPixels(pixels, expected)`로 RGBA 픽셀(`decodePNGPixels` 또는 `sharp().raw()`에서 얻은 값)이 알려진 값으로 디코딩되는지 확인할 수 있습니다.

## 문제가 생겼다면 [#if-something-goes-wrong]

- **모든 이미지가 `"NO_QR"`을 반환해요.** 함수를 호출할 때 이미지가 아직 로드되지 않은 경우입니다. 먼저 `image.decode()`를 기다리세요. 이미 로드되었다면 코드가 너무 작거나, 흐리거나, 잘렸거나, 반전되었을 수 있습니다. 코드 전체와 그 주변 여백이 보이는 더 선명한 이미지를 사용해 보세요.
- **서버에서 `handleImageLoad`를 호출했어요.** 이 함수에는 캔버스가 필요합니다. 클라이언트 컴포넌트나 이벤트 핸들러에서 호출하거나, Node에서는 `scanQRPixels`를 사용하세요.
- **`downloadImageWithBoundingBox`의 윤곽선이 나비넥타이 모양이에요.** 모서리 순서가 잘못되었습니다. 왼쪽 위, 오른쪽 위, 왼쪽 아래, 오른쪽 아래 순서로 전달하세요.
