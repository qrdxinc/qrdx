托管落地页是由 QRdx 为你提供的移动端页面，地址为 `https://qrdx.dev/p/<slug>`（也可使用你的[自定义域名](/docs/custom-domains)）。每个页面都附带一个[动态二维码](/docs/dynamic-qr-codes)，因此二维码印刷之后，你仍然可以继续编辑页面，并查看每一次扫描。当二维码暂时没有可指向的地址，或者手机尺寸的页面比你的网站更合适时，就可以使用它：菜单、名片、链接列表、活动、产品详情等。

<Callout type="info" title="套餐">
  免费版包含 3 个托管页面，页面底部带有“Made with QRdx”页脚。Pro 可去除页脚并取消数量限制；Business 另外提供白标页面和自定义 CSS。每个页面还会占用你套餐中的一个动态二维码名额。参见[套餐与限制](/docs/plans-and-limits)。
</Callout>

时间紧？请看简短的任务页面：[创建移动端页面](/docs/help/pages-and-forms/create-a-page)和[更改已印刷二维码打开的内容](/docs/help/dynamic-codes/change-the-type)。

## 工作原理 [#how-it-works]

<Diagram id="hosted-page-anatomy" />

页面由一组区块堆叠而成：页头、链接、名片、菜单、表单。你在编辑器中排列区块并发布；QRdx 在服务器上渲染页面，因此页面在手机上加载很快，也不需要你自己的网站。二维码的短链接会打开该页面，[二维码控制](/docs/code-controls)中的所有功能同样适用：密码、定时、扫描次数限制。

## 创建页面 [#create-a-page]

1. 在侧边栏中打开 **Pages & forms**，点击 **New page**；或者在二维码列表中点击 **New code**，然后选择页面类型，而不是 **Website link**。
2. 从 {facts.hostedPageTypes} 种[页面类型](#page-types)中选择一种，并从其模板库中选择一个模板。
3. 点击 **Create page**。编辑器会打开并载入模板的区块，页面的二维码也已准备好可供下载。

<Shot id="page-templates" />

已经印刷了打开网站的二维码？打开它并点击 **Change type**，即可在保持短链接不变的情况下把它变成页面。

模板预置了示例名称、价格、数字和照片，方便你了解页面是如何组合的。在首次发布之前，编辑器会提醒你将它们替换为你自己的内容。

## 页面类型 [#page-types]

每种页面类型都只是一个起点：任何区块都可以添加到任何页面，由某一类型创建的页面也可以做成另一种类型的样子。

| 页面类型 | 适用场景 | 初始内容 |
| --- | --- | --- |
| **Link list** | 简介链接、创作者、播客 | 个人资料页头、链接、社交图标 |
| **Social media** | 一个二维码汇总所有账号 | 个人资料页头，每个社交网络一行并带有你的账号 |
| **Business** | 商店、美容美发店、办公室 | 营业时间、地址和地图、联系方式、行动号召 |
| **vCard Plus** | 电子名片 | 带有 **Save contact** 的名片 |
| **Menu** | 咖啡馆、餐厅、酒吧 | 带饮食标签和过敏原的菜单（[详情](/docs/forms-and-pages#menu)） |
| **Coupon** | 折扣和赠品 | 带有优惠码、条形码或兑换按钮的优惠券（[详情](/docs/forms-and-pages#coupon)） |
| **Event** | 派对、会议、网络研讨会、婚礼 | 带有添加到日历功能的活动（[详情](/docs/forms-and-pages#event)） |
| **App download** | 一个二维码对应所有应用商店 | 应用下载（[详情](/docs/forms-and-pages#app-download)） |
| **Feedback & forms** | 评价、NPS 调查、报名 | 表单；反馈模板中还有评价链接（[详情](/docs/forms-and-pages#forms)） |
| **Product** | 包装、标签、吊牌 | 配料、过敏原、营养成分、认证、护理说明、GS1 Digital Link（[详情](/docs/product-pages)） |
| **Appointments** | 美容美发店、诊所、家教 | 服务和价格、预约申请表单、营业时间 |
| **Payments & tips** | 打赏罐、捐款、发票 | 付款链接和可复制的银行信息 |
| **Property listing** | 出售或出租的房屋、开放参观 | 价格和房源信息、照片、经纪人、看房申请或签到表单 |
| **Pet ID tag** | 项圈挂牌、寻宠海报 | 呼叫按钮、宠物信息、“我找到了”表单 |
| **Medical ID** | 挂牌、腕带、过敏卡 | 紧急联系人、病情、过敏史、用药 |
| **PDF** | 宣传册、手册、文档库 | 供阅读或下载的 PDF，或多个文件 |
| **Images** | 图库和作品集 | 照片图库 |
| **MP3 / Audio** | 音乐、播客、语音留言 | 音频播放器 |
| **Video** | 产品视频、短片 | 视频 |
| **Playlist** | 混音合辑、语音导览、有声书 | 依次播放的多个音轨 |
| **Custom page** | 其他任何用途 | 空白页面或公告 |

<IfAvailable feature="fileStorage" unavailable>

此部署未配置文件上传，因此以上传为基础的五种类型（PDF、Images、MP3 / Audio、Video 和 Playlist）不会出现在选择列表中。区块仍然可以链接到托管在其他地方的文件。

**Appointments** 会把预约申请发送到该页面的[回复](/docs/forms-and-pages#responses)和通知中，并且可以链接到你的预约工具。它不会显示空闲时间的实时日历：每个申请都需要你亲自确认。

**Payments & tips** 从不代收付款。每个按钮都会打开对应支付应用自己的页面（PayPal、Venmo、Cash App、Revolut、Wise），银行信息、UPI ID 和钱包地址则带有复制按钮。

任何扫描二维码的人都能看到 **Pet ID tag** 和 **Medical ID** 页面。请只添加对找到你宠物的人或在紧急情况下帮助你的人有用的信息。

## 编辑与发布 [#edit-and-publish]

编辑器有三个标签页和一个实时手机预览。点按预览中的区块，即可跳转到它的设置。

- **Blocks**：用 **Add block** 添加区块，通过拖动（或使用箭头按钮）调整顺序，可隐藏区块而不删除，也可复制或移除区块。每个区块都有自己的表单；存在的问题（例如链接缺少 `https://`）会在区块上标出，必须修复后才能发布。
- **Design**：使用你的某个[已保存二维码主题](/dashboard?to=themes)中的颜色，让页面与印刷的二维码保持一致，也可以选择预设配色，或自行设置每种颜色。可选择字体、圆角半径、纯色、渐变或图片背景，以及可选的徽标。**Match colors** 会根据你的背景色和强调色生成易读的文字和卡片颜色，文字对比度过低时会出现警告。
- **Settings**：分享预览的描述和图片、**Show in search engines**（默认关闭），以及 Business 上的 **Custom CSS**。

<Shot id="page-editor" />

点击 **Publish**（或按 <kbd>⌘</kbd>/<kbd>Ctrl</kbd> + <kbd>S</kbd>）即可让你的更改上线。发布之前，访问者看到的内容不会有任何变化；未发布的编辑内容会保存在你的浏览器中，因此关闭标签页后仍可恢复。每次发布都会保存为一个版本。如果你在编辑时有团队成员发布了同一个页面，QRdx 会要求你重新加载，而不是覆盖对方的更改。

| --- | --- |
| 个人资料头部 | 照片或标志、名称、简介，以及可选的封面图片 |
| 文本 | 一个标题和一段文字（保留换行） |
| 按钮 | 一个行动号召：网页链接、电子邮箱地址或电话号码 |
| 链接列表 | 一组链接按钮，Instagram、YouTube、WhatsApp 等网站带有对应图标 |
| 社交图标 | 以圆形图标、按钮或带用户名的列表形式展示社交主页 |
| 应用下载 | App Store、Google Play 和网站，优先显示访客所用的应用商店（[了解更多](/docs/forms-and-pages#app-download)） |
| 图片 | 一张照片或横幅，可选添加链接 |
| 视频 | YouTube、Vimeo 或 Loom 视频。只有访客点击播放后，才会从视频网站加载 |
| PDF、图库、音频、视频文件、下载 | 你上传或链接的文件（[了解更多](/docs/files)） |
| 联系人名片 | 姓名、职位、电话、电子邮箱、网站、地址、快捷操作（致电、WhatsApp、电子邮件、网站、导航），以及 **保存联系人** 和 **分享** |
| 地址与地图 | 你的地址，附 Google 地图和 Apple 地图导航，还可选嵌入地图 |
| 营业时间 | 按天设置营业时间（支持分段营业和跨午夜营业），并带有 **营业中** 标记，该标记依据你在区块上设置的时区显示 |
| Wi-Fi | 网络名称和密码，带复制按钮（[了解更多](/docs/forms-and-pages#menu)） |
| 详情 | 以列表或磁贴网格展示的标签和值（卧室数量、品种、血型、净重） |
| 活动 | 日期、场地、主办方和添加到日历（[了解更多](/docs/forms-and-pages#event)） |
| 表单、评价链接 | 带回复收件箱的问题，以及评价按钮（[了解更多](/docs/forms-and-pages#forms)） |
| 菜单、优惠券 | 带价格的分区和菜品，以及带条形码的优惠券（[了解更多](/docs/forms-and-pages)） |
| 产品详情 | 认证、成分、过敏原、营养成分表、点击展开的分区，以及 GTIN（[了解更多](/docs/product-pages)） |
| 付款链接 | PayPal、Venmo、Cash App、Revolut、Wise、UPI、银行转账和加密货币钱包。按钮会打开对应的应用；详细信息带有复制按钮。页面本身不会收款 |
| 分隔线、间距 | 布局辅助工具 |

### vCard Plus 与保存联系人 [#vcard-plus-and-save-contact]

**保存联系人** 会下载一个 vCard 3.0 文件（`.vcf`），手机可用通讯录应用打开。文件包含姓名、公司、职位、电话、电子邮箱、网站、地址、简介、页面的社交主页和照片。上传到 QRdx 存储的照片在 1 MB 及以下时会嵌入文件；更大的照片，以及来自其他网站的照片链接，则以链接形式包含，因为 QRdx 从不下载其他网站的图片。**分享** 会打开手机的分享面板，在电脑上则复制页面链接。若还想把名片写入 NFC 卡，请参阅 [NFC 名片](/docs/nfc#nfc-business-cards)。

## 访客体验 [#what-visitors-get]

- 在服务器端渲染、专为手机打造的快速页面。页面上唯一的 QRdx 脚本用于统计浏览和点击，供你的 **页面活动** 卡片使用；没有产品分析，也没有客服小组件。只有当你在代码中添加自己的[跟踪像素](/docs/tracking-and-conversions#tracking-pixels-on-hosted-pages-pro)时，它们才会加载。
- 除非开启 **在搜索引擎中显示**，否则页面会对搜索引擎隐藏。
- 为聊天应用和社交网络提供分享预览（标题、描述、图片）。受密码保护的二维码不会在预览中泄露页面详情。
- 每个页面（包括白标页面）上都有一个小小的 **举报滥用** 链接。

[二维码控制](/docs/code-controls)中的密码保护、开始和结束日期、扫描次数限制以及暂停功能，同样适用于页面及其 **保存联系人** 文件，即使有人直接打开页面链接也一样。

## 限制与套餐 [#limits-and-plans]

| | 免费版 | Pro | Business |
| --- | --- | --- | --- |
| 托管页面 | 3 | 不限 | 不限 |
| “Made with QRdx” 页脚 | 显示 | 移除 | 移除 |
| 白标（以你的标志作为浏览器图标，不显示 QRdx 品牌） | 否 | 否 | 是 |
| 自定义 CSS | 否 | 否 | 是 |

限制只会阻止你创建新页面。你已有的页面在任何套餐下都会继续运行，降级后也一样。从 Business 降级后，页面的自定义 CSS 将不再生效，并且在你于该页面的 **设置** 中移除 CSS 之前，编辑器会拒绝再次发布该页面。

### 自定义 CSS [#custom-css]

在 Business 套餐中，可在 **设置** → **自定义 CSS** 中编写纯 CSS。规则只在你的页面内生效：每个选择器都限定在页面内容范围内，每个区块都可以用 `.lp-block-<type>` 来定位，例如 `.lp-block-links a` 或 `.lp-block-contact h1`。出于安全考虑，CSS 不能加载文件（`url()`、`@import`、`@font-face`），不能使用反斜杠转义，并且只支持 `@media`、`@supports`、`@container` 和 `@keyframes` 这几种 at 规则。

## 面向开发者 [#for-developers]

在 [REST API](/docs/developers/api/update-code) 中，二维码的 `kind` 为 `redirect` 或 `page`，`PATCH /v1/codes/{id}` 可以在两者之间切换，效果与 **更改类型** 相同。页面本身在编辑器中构建，API 不能编辑区块。
