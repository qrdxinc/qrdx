इस पेज के अंत तक आपके पास एक सादे HTML पेज में `<qrdx-code>` एलिमेंट से बना स्टाइल किया हुआ QR कोड होगा, जिसमें object options स्क्रिप्ट से सेट होंगे और PNG में एक्सपोर्ट भी होगा। `qrdx/element`, `qrdx/core` पर बना है, इसलिए यह React के `QRCodeSVG` जैसा ही SVG बनाता है, हर स्टाइल, फ़्रेम, लोगो और एक्सपोर्ट के साथ। इसे किसी फ़्रेमवर्क की ज़रूरत नहीं है, और यह उन फ़्रेमवर्क में भी चलता है जो DOM एलिमेंट रेंडर करते हैं। इसे React 19 और Vue 3 में टेस्ट किया गया है।

<NpmStatus package="qrdx" />

## शुरू करने से पहले [#before-you-start]

- एक ऐसा पेज जिसमें आप `<script type="module">` जोड़ सकें। bundler की ज़रूरत नहीं है; चाहें तो वह भी चलता है।
- bundler वाले तरीके के लिए Node.js 18 या उससे नया वर्शन।

## इसे बनाएँ [#build-it]

### 1. एलिमेंट लोड करें [#1-load-the-element]

<Tabs items={["From a CDN", "With a bundler"]}>
<Tab value="From a CDN">

```html title="index.html"
<script
  type="module"
  src="https://cdn.jsdelivr.net/npm/qrdx/dist/element-define.browser.mjs"
></script>
```

`dist/element-define.browser.mjs` `<qrdx-code>` को रजिस्टर करता है। यह `dist/element.browser.mjs` को लोड करता है, जो एक ES module है और जिसके अंदर इंजन है। वर्शन पिन करने के लिए URL में `qrdx` के बाद `@` और वर्शन जोड़ें। यही पाथ unpkg पर भी काम करते हैं।

</Tab>
<Tab value="With a bundler">

```package-install
qrdx
```

```js title="main.js"
import "qrdx/element/define"; // registers <qrdx-code>
```

सिर्फ़ `qrdx/element` इम्पोर्ट करने से कुछ रजिस्टर नहीं होता। टैग का नाम चुनने के लिए `defineQRdxCode` खुद कॉल करें:

```js title="main.js"
import { defineQRdxCode } from "qrdx/element";

defineQRdxCode(); // <qrdx-code>
defineQRdxCode("brand-qr"); // <brand-qr> as well
```

इसे दोबारा कॉल करना सुरक्षित है, और सर्वर पर यह कुछ नहीं करता। अगर उस नाम पर पहले से कोई दूसरा एलिमेंट है तो यह एरर देता है।

### 2. पेज में एक कोड रखें [#2-put-a-code-in-the-page]

```html title="index.html"
<qrdx-code
  value="https://example.com/menu"
  size="256"
  margin="4"
  body-pattern="rounded"
  label="QR code for the menu"
></qrdx-code>
```

पेज पर गोल मॉड्यूल वाला 256 px का कोड दिखता है। ब्राउज़र के इंस्पेक्टर में कोई attribute बदलें तो कोड दोबारा बन जाता है।

### 3. स्क्रिप्ट से object options सेट करें [#3-set-object-options-from-a-script]

ग्रेडिएंट, फ़्रेम, लोगो और बाकी object options प्रॉपर्टी होते हैं। इन्हें स्क्रिप्ट से सेट करें:

```js title="main.js"
const qr = document.querySelector("qrdx-code");

qr.fgColor = {
  type: "linear",
  angle: 45,
  stops: [
    { color: "#1d4ed8", offset: 0 },
    { color: "#0f172a", offset: 100 },
  ],
};
qr.frame = { style: "banner-bottom", text: "Scan for the menu" };
qr.imageSettings = { src: "/logo.png", width: 40, height: 40, excavate: true };
qr.props = { eyeColor: "#be123c" };
```

कोड एक ही बार दोबारा बनता है, ग्रेडिएंट, बैनर, लोगो और लाल आँखों (eyes) के साथ। स्क्रिप्ट के बिना, object options को `props` attribute में JSON के रूप में रखें:

```html title="index.html"
<qrdx-code
  value="https://example.com"
  props='{"frame": {"style": "banner-bottom", "text": "Scan me"}}'
></qrdx-code>
```

### 4. एक्सपोर्ट करें [#4-export-it]

```js title="main.js"
qr.toSVGString(); // '<svg xmlns="http://www.w3.org/2000/svg" …'
await qr.toDataURL("png", { size: 1024 }); // "data:image/png;base64,…"
await qr.download({ format: "png", size: 1024, filename: "menu.png" });
```

`download`, `menu.png` को 1024 px पर सेव करता है। एक्सपोर्ट कोड को `qr.options` से बनाते हैं, ठीक वैसे ही जैसे `qrdx/core` के `toSVGString` और `downloadQRCode` करते हैं, यानी एलिमेंट के `part`, `role` और `aria-label` के बिना। `toDataURL` और `download` डिफ़ॉल्ट रूप से कोड के `size` पर PNG देते हैं। फ़ॉर्मैट हैं `png`, `jpg`, `webp`, `svg`, `pdf` और `eps`। बिना value के ये एरर देते हैं (`toSVGString`) या reject होते हैं।

PDF के लिए वैकल्पिक `jspdf` पैकेज चाहिए। CDN से इसे मैप करने के लिए, module स्क्रिप्ट से पहले एक import map रखें:

```html title="index.html"
<script type="importmap">
  { "imports": { "jspdf": "https://cdn.jsdelivr.net/npm/jspdf@4/+esm" } }
</script>
```

## Attributes [#attributes]

| Attribute | यह क्या सेट करता है |
| --- | --- |
| `value` | एन्कोड करने के लिए टेक्स्ट या URL। इसके बिना कुछ नहीं बनता |
| `size` | चौड़ाई और ऊँचाई पिक्सल में (फ़्रेम इसमें जुड़ता है) |
| `level` | एरर करेक्शन: `L`, `M`, `Q` या `H` |
| `fg-color`, `bg-color`, `eye-color`, `dot-color` | सॉलिड रंग |
| `body-pattern`, `corner-eye-pattern`, `corner-eye-dot-pattern` | मॉड्यूल, आँखों और आँख के डॉट्स के आकार |
| `margin` | क्वाइट ज़ोन, मॉड्यूल में |
| `template-id` | एक बिल्ट-इन टेम्पलेट |
| `module-scale` | हर मॉड्यूल का आकार, 0.5 से 1 |
| `auto-level` | लोगो को ज़रूरत होने पर एरर करेक्शन को `H` तक बढ़ा देता है |
| `shape` | `square`, `circle` या `heart` |
| `label` | स्क्रीन रीडर क्या बोलते हैं (डिफ़ॉल्ट "QR code") |
| `props` | कोई भी दूसरा option, JSON के रूप में |

जो संख्याएँ और levels पढ़े नहीं जा सकते, उन्हें अनदेखा कर दिया जाता है। [आकार, आँखें और फ़्रेम](/docs/styles) में हर पैटर्न दिखाया गया है।

## Properties [#properties]

हर attribute एक प्रॉपर्टी भी है, option के नाम के साथ: `qr.fgColor`, `qr.bodyPattern`, `qr.templateId`। जो options objects हैं वे सिर्फ़ प्रॉपर्टी हैं: ग्रेडिएंट और इमेज फ़िल, `frame`, `imageSettings`, `eyeColors`, `art`, `customTemplate` और `customProps`। `props` एक साथ सारे options लेता है।

- किसी attribute या नाम वाली प्रॉपर्टी की बात `props` में उसी option से ऊपर मानी जाती है। attribute और उसकी प्रॉपर्टी के बीच, जो बाद में सेट हुआ वह जीतता है। किसी प्रॉपर्टी को हटाने के लिए उसे `undefined` पर सेट करें।
- प्रॉपर्टी वापस attributes नहीं लिखतीं।
- बदलाव एक साथ बैच में होते हैं। आप लगातार कितने भी बदलाव करें, कोड एक ही बार दोबारा बनता है, एक microtask में, और सिर्फ़ तब जब उसका markup बदला हो।
- `qr.options` वह है जिससे कोड बनाया जाता है, और `qr.svg` बना हुआ `<svg>` है।
- एलिमेंट के define होने से पहले सेट की गई प्रॉपर्टी, define होते ही उठा ली जाती हैं।

आधिकारिक फ़्रेम एलिमेंट के बगल वाली फ़ाइल से आता है:

```js title="main.js"
import { getOfficialFrame } from "https://cdn.jsdelivr.net/npm/qrdx/dist/frames-official.mjs";

qr.frame = { style: "custom", spec: getOfficialFrame("wifi-card").spec };
```

## स्टाइलिंग और एक्सेसिबिलिटी [#styling-and-accessibility]

कोड एक open shadow root में बनता है। पेज की CSS उसके paths तक नहीं पहुँच सकती, इसलिए `svg path { fill: red }` या `svg { width: 100% }` जैसा नियम कोड को बिगाड़ नहीं सकता। `<svg>` को बाहर से स्टाइल करने के लिए `::part(svg)` इस्तेमाल करें:

```css title="styles.css"
qrdx-code::part(svg) {
  border-radius: 12px;
}
```

एलिमेंट `inline-block` है। इसका `<svg>` अपना `size` रखता है, लेकिन संकरे कंटेनर में फ़िट होने के लिए छोटा हो जाता है।

`<svg>` में `role="img"` और `label` attribute से `aria-label` होता है, या इसके बिना "QR code"। लेबल कभी value पर वापस नहीं जाता, क्योंकि value में Wi-Fi पासवर्ड या संपर्क जानकारी हो सकती है।

## सर्वर रेंडरिंग [#server-rendering]

`toQRdxCodeHTML(options)` एलिमेंट का markup लौटाता है, जिसमें कोड पहले से declarative shadow root में बना होता है। ब्राउज़र कोई भी स्क्रिप्ट चलने से पहले कोड दिखा देते हैं, और एलिमेंट के define होते ही वह कमान संभाल लेता है। यह Node में चलता है और DOM की ज़रूरत नहीं है।

```js title="server.js"
import { toQRdxCodeHTML } from "qrdx/element";

const html = toQRdxCodeHTML(
  {
    value: "https://example.com",
    size: 256,
    frame: { style: "banner-bottom", text: "Scan me" },
  },
  { label: "Link to example.com" }
);
// <qrdx-code value="https://example.com" size="256" label="Link to example.com"
//   props="{…}"><template shadowrootmode="open">…</template></qrdx-code>
```

सरल options attributes बन जाते हैं और बाकी `props` में JSON के रूप में जाते हैं, ताकि एलिमेंट वही options वापस पढ़े। `customTemplate` को markup के रूप में नहीं लिखा जा सकता: इसे ब्राउज़र में प्रॉपर्टी के रूप में सेट करें। अगर आपने कोई दूसरा नाम रजिस्टर किया है तो `tagName` पास करें।

## React 19 [#react-19]

React 19, एलिमेंट में प्रॉपर्टी होने पर prop को प्रॉपर्टी के रूप में सेट करता है, इसलिए objects को props के रूप में दिया जा सकता है। रेंडर करने से पहले एलिमेंट को एक बार रजिस्टर करें:

```tsx title="components/menu-code.tsx"
import "qrdx/element/define";

export function MenuCode({ url }: { url: string }) {
  return (
    <qrdx-code
      value={url}
      size={256}
      body-pattern="rounded"
      frame={{ style: "banner-bottom", text: "Scan me" }}
      label="Menu"
    />
  );
}
```

TypeScript के लिए, एलिमेंट को `.d.ts` फ़ाइल में JSX में जोड़ें:

```ts title="qrdx-code.d.ts"
import type { QRdxCodeElement, QRdxCodeJSXProps } from "qrdx/element";

declare module "react" {
  namespace JSX {
    interface IntrinsicElements {
      "qrdx-code": React.DetailedHTMLProps<
        React.HTMLAttributes<QRdxCodeElement>,
        QRdxCodeElement
      > &
        QRdxCodeJSXProps;
    }
  }
}
```

`ref` आपको एलिमेंट देता है, `toDataURL` और `download` के लिए।

## Vue [#vue]

Vue के कंपाइलर को बताएँ कि `qrdx-code` एक कस्टम एलिमेंट है:

```js title="vite.config.js"
import vue from "@vitejs/plugin-vue";
import { defineConfig } from "vite";

export default defineConfig({
  plugins: [
    vue({
      template: {
        compilerOptions: { isCustomElement: (tag) => tag === "qrdx-code" },
      },
    }),
  ],
});
```

फिर `main.js` में `qrdx/element/define` को एक बार इम्पोर्ट करें, और templates में options बाइंड करें। एलिमेंट में प्रॉपर्टी होने पर Vue बाइंडिंग को प्रॉपर्टी के रूप में सेट करता है:

```vue title="src/App.vue"
<qrdx-code
  :value="url"
  :size="256"
  body-pattern="rounded"
  :frame="{ style: 'banner-bottom', text: 'Scan me' }"
  label="Menu"
/>
```

## अगर कुछ गड़बड़ हो [#if-something-goes-wrong]

- **कुछ नहीं बनता।** एलिमेंट में `value` नहीं है, या define करने वाली स्क्रिप्ट चली नहीं। attribute जाँचें, और यह भी कि `element-define` module के रूप में लोड हुआ है।
- **`qrdx-error` इवेंट आता है।** कोड नहीं बन सकता, जैसे value QR कोड के लिए बहुत लंबी है, या `props` attribute JSON object नहीं है। एरर `event.detail.error` में होता है। एलिमेंट पुराना कोड हटा देता है और एरर लॉग करता है, जब तक कोई listener `event.preventDefault()` कॉल न करे:

  ```js title="main.js"
  qr.addEventListener("qrdx-error", (event) => {
    event.preventDefault();
    showMessage("That text is too long for a QR code.");
  });
  ```

- **`qrdx: <qrdx-code> is already defined by another element`।** किसी दूसरी स्क्रिप्ट ने वही टैग नाम रजिस्टर कर दिया है। `defineQRdxCode` को कोई दूसरा नाम दें।
- **TypeScript: `Property 'qrdx-code' does not exist on type 'JSX.IntrinsicElements'`।** React 19 सेक्शन की declaration जोड़ें।
