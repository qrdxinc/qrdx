QRdx에는 무료, Pro, Business 세 가지 요금제가 있습니다. Playground와 `qrdx` 라이브러리에서 만드는 정적 QR 코드는 모든 요금제에서 계정 없이 무료로 무제한 사용할 수 있습니다. 요금제에 따라 워크스페이스에서 쓸 수 있는 동적 QR 코드, 페이지, 도메인, 좌석 수가 달라집니다. 한도에 도달하기 전에 확인하고 싶을 때, 그리고 요금제를 바꾸면 정확히 무엇이 달라지는지 볼 때 이 페이지를 활용하세요. 가격은 [요금 페이지](/pricing)에서 비교할 수 있으며, 요청 시 제공되는 [Enterprise](/enterprise) 상품도 있습니다.

급하신가요? 작업별로 짧게 정리한 페이지가 있습니다. [요금제와 포함 내용](/docs/help/account-and-billing/plans), [업그레이드, 다운그레이드 또는 결제 주기 변경](/docs/help/account-and-billing/change-plan), [결제를 중단하면 코드는 어떻게 되나요](/docs/help/account-and-billing/never-hostage)를 참고하세요.

분석 기록 한도는 얼마나 과거까지 볼 수 있는지만 제한합니다. 스캔은 코드가 존재하는 동안 계속 보관되므로, 업그레이드하면 이전 스캔이 다시 표시됩니다.

코드 한도에는 활성 상태의 동적 코드만 포함되며, 보관된 코드는 포함되지 않습니다. 스캔은 어떤 한도에도 포함되지 않고, 트래픽 때문에 코드를 일시 중지하는 요금제도 없습니다. 스캔 상한은 코드에 직접 설정한 것뿐입니다.

API 허용량은 워크스페이스 단위이며 00:00 UTC에 초기화됩니다. 집계되는 요청마다 `X-RateLimit-Limit`, `X-RateLimit-Remaining`, `X-RateLimit-Reset`이 반환되므로 사용량을 확인할 수 있습니다. 분당 한도는 [REST API](/docs/developers/rest-api#rate-limits)를 참고하세요.

## 워크스페이스 [#workspaces]

한도는 [워크스페이스](/docs/teams)마다 따로 적용되며, 워크스페이스는 소유자와 [결제 멤버](/docs/teams#roles) 중 가장 높은 요금제를 사용합니다. 모든 사용자에게는 본인이 소유자로 자동 생성되는 개인 워크스페이스가 있으며, 이 워크스페이스는 본인의 요금제를 따릅니다. 그 외 워크스페이스에서는 소유자 한 명이 Business이면 모든 멤버가 Business 한도를 적용받으며, 멤버가 따로 구독할 필요는 없습니다.

워크스페이스를 더 만들려면 Pro 또는 Business가 필요합니다. 소유자와 결제 멤버가 모두 무료인 워크스페이스는 1좌석(본인만), Pro는 최대 3좌석, Business는 제한이 없습니다. 좌석은 소유자를 포함한 멤버와 대기 중인 초대를 합산하므로, 필요 없는 초대는 취소해서 좌석을 비우세요. 소유자의 요금제가 바뀌어도 현재 멤버는 유지되며, 새 초대만 차단됩니다.

## 한도 초과, 다운그레이드, 해지 [#going-over-a-limit-downgrading-and-canceling]

<Callout type="info" title="한도는 새로 만드는 것만 막습니다">
  기존 코드는 다운그레이드, 결제 실패, 해지 이후에도 모든 요금제에서 계속 리디렉션됩니다. 이것이 [Never-Hostage 보장](/guarantee)입니다.
</Callout>

- **한도 초과:** 한도 아래로 내려갈 때까지 더 만들 수 없습니다. 이미 있는 항목은 계속 수정, 보관, 내보내기할 수 있습니다.
- **일일 API 허용량 초과:** 00:00 UTC까지 API 호출에 `429`가 반환됩니다. 코드는 계속 리디렉션되고 웹사이트도 계속 작동합니다.
- **다운그레이드:** 코드, 랜딩 페이지, 인증된 사용자 지정 도메인은 계속 작동합니다. 분석에는 새 요금제에 포함된 기간의 기록이 표시됩니다.
- **해지:** 결제한 기간이 끝날 때까지 요금제가 유지되고, 이후 계정이 무료로 전환됩니다.
- **결제 실패:** 구독이 만료되면 해지와 같습니다. 일시 중지되는 것은 없습니다.

만료일, 일시 중지, 스캔 한도처럼 직접 정한 이유로 종료된 코드는 스캔한 사람을 대체 URL 또는 중립적인 "This campaign has ended" 페이지로 보내며, QRdx 페이지로는 보내지 않습니다.

## 결제 [#billing]

[요금 페이지](/pricing)에서 업그레이드하세요. 요금제를 변경하거나, 월간과 연간을 전환하거나, 카드를 업데이트하거나, 해지하려면 워크스페이스에서 **Settings** → **Plan & usage**를 열고 **Manage billing**을 클릭하세요. 요금 페이지의 **Manage subscription**도 같은 곳으로 이동합니다. 두 방법 모두 Polar 결제 포털이 열립니다. 구독 하나가 계정 전체에 적용되므로, 구독이 있는 동안에는 새로 결제하지 않고 포털에서 요금제를 변경합니다.

## 셀프 호스팅 [#self-hosting]

[셀프 호스팅](/docs/self-hosting) 인스턴스도 같은 요금제를 사용합니다. 한도는 `apps/app/lib/plans.ts` 파일 한 곳에 정의되어 있으며, 인스턴스에 맞게 변경할 수 있습니다. Polar를 설정하지 않으면 업그레이드를 사용할 수 없고 모든 계정이 무료 한도를 사용합니다. Upstash Redis가 없으면 일일 API 허용량이 집계되지 않고 `X-RateLimit-*` 헤더도 전송되지 않습니다.
