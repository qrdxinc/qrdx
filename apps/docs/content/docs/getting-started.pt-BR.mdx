Ao final desta página, você terá um QR code estilizado renderizado por um componente React e um botão que o salva como SVG. A biblioteca desenha o código sozinha, então você não precisa de conta nem de chave de API.

<NpmStatus package="qrdx" />

## Antes de começar [#before-you-start]

- Um app React na versão 18 ou mais recente. Next.js, Vite, Remix e os demais funcionam.
- Node.js 18 ou mais recente.

Quer ver as opções antes de escrever qualquer código? Estilize um código no [Playground](/playground?open=code&lang=react) e copie como um componente React.

## Passo a passo [#build-it]

### 1. Instale o qrdx [#1-install-qrdx]

```package-install
qrdx
```

`react` e `react-dom` são peer dependencies, então o pacote usa as versões que seu app já tem. Nada mais é instalado: a exportação para PDF precisa do pacote opcional `jspdf`, e só quando você a usa.

### 2. Renderize um código [#2-render-a-code]

```tsx title="components/first-qr-code.tsx"
import { QRCode } from "qrdx";

export function FirstQrCode() {
  return <QRCode value="https://example.com" size={256} />;
}
```

Coloque o componente em uma página. Você verá um código de 256 px no visual padrão da biblioteca: módulos arredondados, olhos dos cantos em forma de engrenagem e preto sobre branco. Aponte a câmera de um celular para a tela e ele abre example.com.

<Shot id="lib-first-code" />

`QRCode` renderiza um `<svg>` e não usa hooks exclusivos do navegador, então funciona em React Server Components e é renderizado no HTML da página antes de qualquer JavaScript rodar. Sozinho, ele não dá nada para leitores de tela: o passo 3 mostra como rotulá-lo.

### 3. Estilize [#3-style-it]

```tsx title="components/styled-qr-code.tsx"
import { QRCode } from "qrdx";

export function StyledQrCode() {
  return (
    <QRCode
      value="https://example.com/menu"
      size={256}
      margin={4}
      fgColor="#1d4ed8"
      bodyPattern="rounded"
      cornerEyePattern="extra-rounded"
      cornerEyeDotPattern="rounded"
      frame={{ style: "banner-bottom", text: "Scan for the menu" }}
    />
  );
}
```

Agora o código está azul, com módulos arredondados, e um banner abaixo dele diz "Scan for the menu". A saída fica maior que 256 px, porque a moldura é adicionada ao redor do código em vez de desenhada sobre ele, então o código continua sendo lido.

<Shot id="lib-styled-code" />

O que cada prop faz:

- `margin` é a zona de silêncio ao redor do código, em módulos. O padrão é 0, que serve para um código dentro de um card com padding próprio. Use 4 em um fundo movimentado ou escuro.
- `fgColor` aceita qualquer cor CSS ou um gradiente. `bgColor`, `eyeColor` e `dotColor` funcionam do mesmo jeito.
- `bodyPattern`, `cornerEyePattern` e `cornerEyeDotPattern` definem a forma dos módulos, dos olhos dos cantos e dos pontos dentro deles. Há {facts.bodyPatterns} padrões de corpo, {facts.eyeShapes} formas de olho e {facts.eyeCentres} centros de olho, todos desenhados ao vivo em [Formas, olhos e molduras](/docs/styles).
- `frame` adiciona uma das {facts.frameStyles} molduras de call to action incluídas, ou uma moldura sua.
- `QRCode` aceita apenas as props do próprio código e `style`. Para dar um nome acessível ou uma classe ao código, envolva-o em um elemento (`<div role="img" aria-label="QR code for the menu">`) ou renderize `QRCodeSVG`, que coloca `aria-label`, `className` e qualquer outro atributo no `<svg>`.

### 4. Salve como arquivo [#4-save-it-as-a-file]

```tsx title="components/download-svg-button.tsx"
"use client";

import { downloadQRCode } from "qrdx";

const menuCode = {
  value: "https://example.com/menu",
  margin: 4,
  fgColor: "#1d4ed8",
  bodyPattern: "rounded",
  frame: { style: "banner-bottom", text: "Scan for the menu" },
} as const;

export function DownloadSvgButton() {
  return (
    <button
      type="button"
      onClick={() =>
        downloadQRCode(menuCode, {
          format: "svg",
          size: { width: 1024, height: 1024 },
          filename: "menu.svg",
        })
      }
    >
      Download SVG
    </button>
  );
}
```

Ao clicar no botão, o arquivo `menu.svg` é salvo: o mesmo código da tela, desenhado em 1024 px e nítido em qualquer tamanho, que é o arquivo que uma gráfica pede. Defina `format` como `png`, `jpg` ou `webp` para uma imagem, `eps` para um arquivo vetorial para ferramentas de design, ou `pdf` (precisa do pacote opcional `jspdf`).

`downloadQRCode` usa o DOM do navegador, então o botão fica em um Client Component. Um Server Component ainda pode renderizá-lo. Mantenha as opções do código em um único objeto, como acima, para que o arquivo seja igual à prévia.

### 5. Confira se ele é lido [#5-check-that-it-scans]

Teste a leitura do código com dois ou três celulares antes de imprimir. Para um design com cores incomuns ou um logo, `getScanScore` executa as mesmas verificações no navegador e retorna uma pontuação, uma nota e o que corrigir:

```tsx title="lib/check-code.ts"
import { getScanScore } from "qrdx";

const { score, grade, checks } = await getScanScore({
  value: "https://example.com/menu",
  fgColor: "#1d4ed8",
  bodyPattern: "rounded",
});
// score: 0 to 100, grade: "great" | "ok" | "risky" | "fails"
// checks: [{ id, passed, message, fix? }]
```

Você também pode enviar uma captura de tela ou uma foto de um código impresso para o [verificador de leitura](/tools/scan-checker).

## Se algo der errado [#if-something-goes-wrong]

- **`Module not found: Can't resolve 'qrdx'`.** Instale o pacote no workspace ou app que o importa e reinicie o servidor de desenvolvimento.
- **O código é renderizado, mas os celulares não o leem.** Adicione `margin={4}`, mantenha módulos escuros sobre fundo claro e renderize com pelo menos 128 px de largura na tela. [O QR code não é lido](/docs/help/troubleshooting/wont-scan) lista as outras causas.
- **`PDF export needs the optional "jspdf" package`.** Execute `npm install jspdf` no mesmo pacote. SVG, PNG, JPG, WebP e EPS não precisam de nada extra.
