`handleImageLoad` ब्राउज़र में किसी इमेज एलिमेंट से QR कोड डिकोड करता है और उसका टेक्स्ट लौटाता है। इसका इस्तेमाल अपलोड, स्क्रीनशॉट या फ़ोटो से कोड पढ़ने के लिए करें, और इमेज को कहीं भेजना नहीं पड़ता। तैयार ड्रॉप ज़ोन के लिए [QR Code Scanner](/docs/components/qr-code-scanner) कॉम्पोनेंट इंस्टॉल करें, जो इसी पर बना है।

| फ़ंक्शन | रिटर्न | नोट्स |
| --- | --- | --- |
| `handleImageLoad(img, size, returnFullData?)` | `Promise<string \| QRCode \| "NO_QR">` | डिकोड किया गया टेक्स्ट, या `returnFullData` देने पर डिकोडर का पूरा नतीजा। कुछ न मिलने पर `"NO_QR"`। सिर्फ़ ब्राउज़र में |
| `downloadImageWithBoundingBox(img, corners, filename)` | `void` | इमेज को PNG के रूप में सेव करता है, जिसमें मिले हुए कोड के चारों ओर लाल आउटलाइन होती है |
| `getImageScanScore(imageOrBlob, options?)` | `Promise<ImageScanScoreResult>` | मौजूदा इमेज को डिकोड करता है और स्कोर देता है। देखें [क्या यह स्कैन होगा?](/docs/features/frames#will-it-scan) |
| `scanQRPixels(pixels, expected, options?)` | `Promise<PixelScanResult>` | जाँचता है कि RGBA पिक्सल `expected` में डिकोड होते हैं या नहीं, Node में |

## अपलोड की गई इमेज डिकोड करें [#decode-an-uploaded-image]

```tsx title="components/qr-reader.tsx"
"use client";

import { handleImageLoad } from "qrdx";
import { useState } from "react";

async function decodeFile(file: File): Promise<string | null> {
  const url = URL.createObjectURL(file);
  try {
    const image = new Image();
    image.src = url;
    await image.decode();
    const result = await handleImageLoad(image, image.naturalWidth);
    return typeof result === "string" && result !== "NO_QR" ? result : null;
  } finally {
    URL.revokeObjectURL(url);
  }
}

export function QrReader() {
  const [result, setResult] = useState("");

  async function onChange(event: React.ChangeEvent<HTMLInputElement>) {
    const file = event.target.files?.[0];
    if (!file) return;
    try {
      setResult((await decodeFile(file)) ?? "No QR code found");
    } catch {
      setResult("Could not read that image");
    }
  }

  return (
    <div>
      <input
        accept="image/*"
        aria-label="Image with a QR code"
        type="file"
        onChange={onChange}
      />
      {result ? <p>{result}</p> : null}
    </div>
  );
}
```

किसी कोड का स्क्रीनशॉट चुनें और उसका लिंक इनपुट के नीचे दिखाई देगा। `image.decode()` फ़ाइल के लोड होने का इंतज़ार करता है; इसके बाद `handleImageLoad` इमेज को कैनवास पर बनाता है और jsQR चलाता है। jsQR ज़रूरत पड़ने पर ही लोड होता है, इसलिए जिन बंडलों में स्कैन नहीं होता, उनमें यह शामिल नहीं होता।

## डिटेक्शन कैसे काम करता है [#how-detection-works]

`handleImageLoad(img, size, returnFullData)` पहले पूरी इमेज आज़माता है, फिर चार क्रॉप (नीचे बाएँ, नीचे दाएँ, ऊपर दाएँ और बीच के हिस्से, इमेज के 65% पर), हर एक को 100% से 10% तक छह स्केल पर। जो भी पहला डिकोड सफल होता है, वही लौटाया जाता है, इसलिए स्क्रीनशॉट के छोटे हिस्से में मौजूद कोड भी मिल जाता है। बहुत चौड़ी या लंबी इमेज को पहले छोटा किया जाता है।

- `img` एक लोड हो चुका `<img>` होना चाहिए। `decode()` या `load` इवेंट का इंतज़ार करें।
- `size` पुराने रिलीज़ के साथ संगतता के लिए रखा गया है और इसे नज़रअंदाज़ किया जाता है: स्केल इमेज के अपने डाइमेंशन से तय होते हैं। इमेज की चौड़ाई दे दें।
- `returnFullData` टेक्स्ट की जगह jsQR का नतीजा ऑब्जेक्ट लौटाता है।

जो कोड धुंधला हो, किनारों पर कटा हो या बैकग्राउंड से हल्का हो (गहरे पर हल्के मॉड्यूल), उसके लिए `"NO_QR"` आता है।

## पोज़िशन और रॉ डेटा [#position-and-raw-data]

`returnFullData` सेट करने पर नतीजा डिकोडर का अपना ऑब्जेक्ट होता है:

```ts title="lib/decode-full.ts"
import { handleImageLoad } from "qrdx";

const found = await handleImageLoad(image, image.naturalWidth, true);
if (found !== "NO_QR") {
  found.data; // "https://example.com"
  found.version; // 1 to 40
  found.binaryData; // the raw bytes, as number[]
  found.chunks; // the encoded segments and their modes
  found.location.topLeftCorner; // { x, y } in the image's pixels, and the other three corners
}
```

`downloadImageWithBoundingBox` मूल इमेज पर कोड की आउटलाइन बनाकर उसे सेव करता है। यह तब काम आता है जब कोई फ़ोटो उम्मीद से अलग कुछ डिकोड करे। कोने इस क्रम में दें: ऊपर बाएँ, ऊपर दाएँ, नीचे बाएँ, नीचे दाएँ:

```ts title="lib/debug-detection.ts"
import { downloadImageWithBoundingBox, handleImageLoad } from "qrdx";

const found = await handleImageLoad(image, image.naturalWidth, true);
if (found !== "NO_QR") {
  const { topLeftCorner, topRightCorner, bottomLeftCorner, bottomRightCorner } = found.location;
  downloadImageWithBoundingBox(
    image,
    [topLeftCorner, topRightCorner, bottomLeftCorner, bottomRightCorner],
    "found-code.png"
  );
}
```

## सिर्फ़ डिकोड करने की जगह इमेज को स्कोर करें [#score-an-image-instead-of-only-decoding-it]

`getImageScanScore` मौजूदा इमेज को डिकोड करता है और यह भी बताता है कि वह कितनी भरोसेमंद तरीके से स्कैन होगी: कैमरे जैसे ब्लर, कंट्रास्ट, पोलैरिटी, क्वाइट ज़ोन और रेज़ोल्यूशन के साथ तीन साइज़ पर डिकोड करके। यह `File`, `Blob` या `<img>` लेता है।

```ts title="lib/score-image.ts"
import { getImageScanScore } from "qrdx";

const { data, score, grade, checks } = await getImageScanScore(file);
// data: "https://example.com" or null
// score: 0 to 100, grade: "great" | "ok" | "risky" | "fails"
```

[स्कैन चेकर](/tools/scan-checker) इसी पर बना है। Node में `scanQRPixels(pixels, expected)` जाँचता है कि RGBA पिक्सल (`decodePNGPixels` या `sharp().raw()` से) किसी तय वैल्यू में डिकोड होते हैं या नहीं।

## अगर कुछ गड़बड़ हो [#if-something-goes-wrong]

- **हर इमेज पर `"NO_QR"` आता है।** फ़ंक्शन कॉल करते समय इमेज लोड नहीं हुई थी। पहले `image.decode()` का इंतज़ार करें। अगर इमेज लोड है, तो हो सकता है कोड बहुत छोटा, धुंधला, कटा हुआ या उलटा हो; ऐसी ज़्यादा साफ़ इमेज आज़माएँ जिसमें पूरा कोड और उसके चारों ओर थोड़ा मार्जिन हो।
- **`handleImageLoad` सर्वर पर कॉल किया गया है।** इसे कैनवास चाहिए। इसे Client Component या इवेंट हैंडलर से कॉल करें, या Node में `scanQRPixels` इस्तेमाल करें।
- **`downloadImageWithBoundingBox` की आउटलाइन बो टाई जैसी बनती है।** कोने गलत क्रम में हैं। ऊपर बाएँ, ऊपर दाएँ, नीचे बाएँ, नीचे दाएँ क्रम में दें।
