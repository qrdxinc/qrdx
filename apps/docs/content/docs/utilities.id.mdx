Helper ini adalah fungsi-fungsi kecil yang dipakai oleh renderer dan skor pemindaian, dan diekspor agar bisa Anda pakai di UI sendiri: memilih warna representatif, memeriksa kontras, memvalidasi ukuran unduhan, dan mendeteksi fitur canvas. Semuanya berjalan di mana saja kecuali bila disebutkan lain.

| Fungsi | Mengembalikan | Catatan |
| --- | --- | --- |
| `getSolidColor(color, fallback?)` | `string` | Satu warna yang mewakili sebuah `ColorConfig`: string itu sendiri, `color` dari warna solid, titik warna pertama dari gradien, `underlay` dari isian gambar, atau `fallback` (`"#000000"`) |
| `getContrastRatio(a, b)` | `number` | Rasio kontras WCAG antara dua warna CSS, dari 1 sampai 21. Warna transparan terlebih dahulu digabungkan di atas warna putih. Mengembalikan 1 jika warna tidak dapat diurai |
| `getContrastLevel(ratio)` | `{ level, warning, message }` | `AAA` mulai dari 7, `AA` mulai dari 4.5, `AA Large` mulai dari 3 (dengan `warning: true`), `Fail` di bawah 3 |
| `getLuminance(r, g, b)` | `number` | Luminansi relatif dari warna sRGB, 0 sampai 1 |
| `hexToRgb(hex)` | `{ r, g, b } \| null` | Membaca hex 3, 4, 6, dan 8 digit, dengan mengabaikan alpha. `null` untuk format lainnya |
| `validateSize(width, height)` | `{ isValid, error? }` | Aturan yang diterapkan setiap unduhan: 50 sampai 5000 px dan berbentuk persegi |
| `SUPPORTS_PATH2D` | `boolean` | Apakah canvas di lingkungan ini mendukung `Path2D` dengan `addPath` |

## Warna [#colors]

```ts title="lib/colors.ts"
import { getSolidColor, hexToRgb } from "qrdx";

getSolidColor({
  type: "linear",
  angle: 45,
  stops: [
    { color: "#ff6b6b", offset: 0 },
    { color: "#4ecdc4", offset: 100 },
  ],
});
// "#ff6b6b": the first stop

getSolidColor({ type: "image", src: photo, underlay: "#111111" }); // "#111111"
getSolidColor(undefined, "#ffffff"); // "#ffffff"

hexToRgb("#ff6b6b"); // { r: 255, g: 107, b: 107 }
hexToRgb("#f00"); // { r: 255, g: 0, b: 0 }
hexToRgb("red"); // null
```

Gunakan `getSolidColor` saat Anda memerlukan satu warna untuk swatch, latar belakang CSS, atau warna cadangan. Renderer memakainya ketika suatu format tidak dapat menggambar gradien, seperti `QRCodeCanvas` dan penggambaran bingkai di Canvas.

## Kontras [#contrast]

```ts title="lib/contrast.ts"
import { getContrastLevel, getContrastRatio, getLuminance } from "qrdx";

getContrastRatio("#000000", "#ffffff"); // 21
getContrastRatio("#1d4ed8", "#f8fafc"); // 6.4
getContrastRatio("rgba(29, 78, 216, 0.5)", "#ffffff"); // the blue over white, so lower

getContrastLevel(4.5);
// { level: "AA", warning: false, message: "Good contrast" }

getContrastLevel(2);
// { level: "Fail", warning: true, message: "Poor contrast - QR code may not scan properly" }

getLuminance(255, 255, 255); // 1
```

Skor pemindaian meloloskan kode pada rasio 4.5 atau lebih (`SCAN_CONTRAST_MIN`), mengurangi poin di bawah angka itu, dan menggagalkannya di bawah 1.5. Gambar membutuhkan lebih banyak: `SCAN_IMAGE_CONTRAST_MIN` adalah 7 untuk isian gambar di dalam modul dan 12 untuk gambar di belakangnya. `getScanContrast(props)` menjalankan pemeriksaan milik skor tersebut pada seluruh desain, termasuk setiap titik warna gradien dan warna mata; lihat [Bingkai, skor pemindaian, dan file cetak](/docs/features/frames#will-it-scan).

Pemeriksa kontras langsung hanya butuh belasan baris:

```tsx title="components/contrast-checker.tsx"
"use client";

import { getContrastLevel, getContrastRatio } from "qrdx";
import { useState } from "react";

export function ContrastChecker() {
  const [fgColor, setFgColor] = useState("#000000");
  const [bgColor, setBgColor] = useState("#ffffff");
  const ratio = getContrastRatio(fgColor, bgColor);
  const level = getContrastLevel(ratio);

  return (
    <div>
      <input
        aria-label="Module color"
        type="color"
        value={fgColor}
        onChange={(event) => setFgColor(event.target.value)}
      />
      <input
        aria-label="Background color"
        type="color"
        value={bgColor}
        onChange={(event) => setBgColor(event.target.value)}
      />
      <p>
        {ratio.toFixed(2)}:1, {level.level}. {level.message}
      </p>
    </div>
  );
}
```

## Validasi [#validation]

```ts title="lib/sizes.ts"
import { validateSize } from "qrdx";

validateSize(1024, 1024); // { isValid: true }
validateSize(40, 40); // { isValid: false, error: "Size must be at least 50x50 pixels" }
validateSize(6000, 6000); // { isValid: false, error: "Size must not exceed 5000x5000 pixels" }
validateSize(400, 300); // { isValid: false, error: "Width and height must be equal for QR codes" }
```

`downloadQRCode`, `getQRCodeDataUrl`, dan `copyQRCodeToClipboard` melempar teks `error` yang sama saat ukuran tidak valid, sehingga formulir dapat memeriksanya lebih dulu.

## Deteksi fitur [#feature-detection]

```ts title="lib/features.ts"
import { SUPPORTS_PATH2D } from "qrdx";

if (SUPPORTS_PATH2D) {
  // draw module paths with Path2D
}
```

`SUPPORTS_PATH2D` dihitung sekali saat modul dimuat, sehingga nilainya `false` di server.

## Helper lainnya [#other-helpers]

- `getColorString(color)` dan `normalizeColorConfig(color)` mengubah bentuk-bentuk `ColorConfig` satu sama lain; `isGradient(color)` dan `isImagePaint(color)` membedakannya.
- `sanitizeFrameText(text)` dan `isLatin1Text(text)` menerapkan aturan label bingkai (24 karakter; Latin-1 untuk PDF dan EPS).
- `decodePNGPixels(bytes)` membaca PNG 8-bit menjadi piksel RGBA tanpa DOM, untuk `createQRArtImage`, `createQRSilhouette`, atau `scanQRPixels` di Node.
- `rgbToCmyk(color)` adalah konversi yang dipakai oleh file cetak CMYK.
