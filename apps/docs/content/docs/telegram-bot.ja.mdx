QRdxボットは、リンクや任意のテキストをTelegram内でQRコードに変換します。無料で、QRdxアカウントも不要です。チャットの相手にすぐコードを届けたいときに便利です。たとえば、ゲストへのWi-Fiのパスワード、グループへのリンク、テーブル用のメニューなどです。

## 仕組み [#how-it-works]

QRdxは作成したコードを保存しません。ボットも、返信のためにだけ各メッセージを読み取ります。コードはすべて、QRdxがリンクから生成する画像です。このリンクには、あなたの内容と選んだデザインが含まれています。そのため、コードのスタイルを変更するときは、そのリンクから両方を読み戻します。リンクは他のリンクと同様にログやキャッシュに残る可能性があります。パスワードなどの機密情報はコードにしないでください。Telegramは、他のメッセージと同じように、チャット内のメッセージを保持します。

## プライベートチャット [#private-chat]

ボットにリンクまたはテキストを送ると、QRコードと4つのボタンが返信されます。

- **PNGをダウンロード** は、保存や共有にそのまま使える画像を開きます。
- **SVGをダウンロード** は、印刷やデザインツール向けのベクター版を開きます。
- **エディタで開く** は、同じデザインでQRdxのエディタを開きます。ウェブアドレスは一緒に引き継がれます。それ以外のテキストは引き継がれないため、エディタに自分で貼り付けてください。
- **スタイル** は、チャット内でコードの見た目を変更します（下記参照）。

コードには、送信した内容がそのまま入ります。改行も含まれます。前後の空白は取り除かれ、`qrdx.dev` のようなドメインだけの入力は `https://qrdx.dev` になります。`/help`（または `/start`）を送ると、ボットの使い方が表示されます。テキストが長すぎて1つのQRコードに収まらない場合は、ボットがその旨を伝えます。全文を載せたページへのリンクにすると、コードが小さくなり、スキャンしやすくなります。

## コードのスタイル設定 [#style-your-code]

コードの下にある **スタイル** をタップすると、ダウンロードボタンの代わりに **デザイン**、**色**、**フレーム**、**ロゴ** が表示され、その下に **PNGをダウンロード** と **完了** が並びます。各グループを開くと選択肢が表示され、現在のコードに適用されているものには ✓ が付きます。**戻る** で前の画面に戻れます。選択肢をタップすると、ボットが画像を描き直します。**完了** をタップすると、ダウンロードボタンが元に戻ります。変更はそのつど、現在のコードに重ねて適用されます。グループでは、コードを依頼した本人だけがスタイルを変更できます。ほかの人がタップした場合は、短いメッセージが表示されます。

デザインは、エディタに組み込まれたデザインのうち、小さいサイズでも読み取りやすいものです。**シンプル** は白地に黒のデザインです。デザインを選ぶと形と色が変わり、選択済みのフレームとロゴはそのまま残ります。色を選ぶと、コード全体がその色になり、背景は白になります。フレームには「Scan me」のラベルが付きます。ロゴメニューには、エディタのクイックアイコンが7つ用意されています。

コードを作成するときに、リンクやテキストの後ろにオプションを加えてスタイルを指定することもできます。オプション名は [QRdx CLI](/docs/developers/cli) と同じです。この方法は、プライベートチャット、グループでの `/qr` の後、そしてインラインモードで使えます。インラインモードでは、変更するメッセージがまだないため、これがスタイルを指定する唯一の方法です。

```text title="Telegram message"
qrdx.dev --look modern --fg 0051ff --frame banner-bottom --frame-text "Scan me"
```

最初のオプションより前の部分が内容になります。まずデザインが適用され、その上に他のオプションが重ねられます。そのため、`--look royal --fg 0051ff` を指定すると、Royalの形を保ったまま青色になります。お使いのスマートフォンが `--` を長いダッシュに変換する場合でも、そのまま使えます。誤ったオプションや値を指定すると、指定できる値の一覧が返信されます。

| オプション | 変更される内容 | 値 |
| --- | --- | --- |
| `--look` | エディタのプリセットから選ぶ、デザイン全体 | `plain`, `classic`, `modern`, `royal`, `folio`, `caffeine`, `retro`, `bordeaux`, `blossom` |
| `--fg`（または `--color`） | ドットの色。目の色を別に指定しない場合は、コーナーの目も同じ色になります | `0051ff` のような16進カラー、または `black`, `blue`, `green`, `red`, `purple`, `orange` |
| `--bg` | 背景 | `--fg` と同じ |
| `--eye-color` | 3つのコーナーの目 | `--fg` と同じ |
| `--dot-color` | コーナーの目の中心 | `--fg` と同じ |
| `--body` | ドットの形 | エディタの{facts.bodyPatterns}種類のドット形状のいずれか（`rounded`、`circle`、`classy` など） |
| `--eye` | コーナーの目の形 | {facts.eyeShapes}種類の目の形のいずれか（`square`、`rounded`、`gear` など） |
| `--dot` | 目の中心の形 | {facts.eyeCentres}種類の中心の形のいずれか（`square`、`rounded`、`circle` など） |
| `--frame` | コードの周りのフレーム | `none`、または組み込みの{facts.frameStyles}種類のフレームのいずれか（`banner-bottom`、`banner-top`、`speech-bubble`、`polaroid` など） |
| `--frame-text` | フレームのラベル（最大24文字） | 任意のテキスト。スペースを含む場合は引用符で囲みます。`--frame` を指定しない場合は、コードの下のバナーに表示されます |
| `--template` | テンプレートとして描画されるフレーム | `Arrow`, `StandardBox`, `SquareBorder`, `StrikedBox`, `DotRing`, `Halloween`, `default`（大文字・小文字は問いません） |
| `--logo` | 中央のアイコン | `link`, `wifi`, `location`, `phone`, `email`, `whatsapp`, `instagram`, `file`, `calendar`, `none` |

スタイルを適用したコードをボットが送信する前に、QRdxはエディタと同じスキャンスコアで確認します。スマートフォンが読み取りにくいデザインの場合、QRdxはデザインを調整し（色を濃くする、形をシンプルにする、誤り訂正を強くするなど）、その内容をキャプションで知らせます。それでも不十分な場合（多くは内容が長いとき）は、白地に黒のコードが、注意書き付きで届きます。

**エディタで開く** は、色、形、フレーム、枠線を含め、同じデザインでエディタを開きます。ロゴのアイコンはリンクに含まれないため、エディタで選び直してください。

## どのチャットでも使えるインラインモード [#inline-mode-in-any-chat]

ボットをチャットに追加しなくても、どのチャットにもコードを送信できます。メッセージ欄に `@`、ボットのユーザー名、スペース、リンクまたはテキストの順に入力します。少し待つと、入力欄の上にコードが表示されます。タップすると送信され、ダウンロード用の2つのボタンとエディタ用のボタン（計3つ）が付きます。メッセージの相手がボットを使う必要はありません。インラインのコードにスタイルを指定するには、テキストに `--options` を追加します。

## グループ [#groups]

ボットをグループに追加し、`/qr` に続けてリンクまたはテキストを送ります。たとえば `/qr https://example.com/menu` です。ボットは、あなたのメッセージへの返信としてコードを送ります。

グループ内のボットは、デフォルトでプライバシーモードがオンになっており、このボットもオンのままにしています。そのため、グループの会話は見えません。Telegramがボットに渡すのは、ボット宛てのコマンドと、ボット自身のメッセージへの返信だけです。ボットが応答するのは `/qr`、`/start`、`/help` で、それ以外はすべて無視します。グループに複数のボットがいる場合や、ボットが `/qr` だけでは応答しない場合は、コマンドにボットのユーザー名を付けてください。`/qr@` にユーザー名、続けてリンクまたはテキストを入力します。

## 制限とプラン [#limits-and-plans]

ボットは無料で、プランはありません。短時間に多くのコードを作成すると、ボットから次のコードまで1分待つよう求められます。スタイルの変更は1回ごとに1つのコードとして数えられます。多くの人が同時に利用すると、混み合っているというメッセージが表示されることがあります。その場合は、1分後にもう一度お試しください。

## ボットを削除する [#remove-the-bot]

プライベートチャットでは、ボットのプロフィールを開いてブロックするか、チャットを削除します。グループでは、管理者がメンバー一覧からボットを削除します。

ボットがすでに送信したコードは、チャットに残ります。**PNGをダウンロード**、**SVGをダウンロード**、**エディタで開く** の各ボタンは、QRdxに直接リンクしているため、引き続き使えます。**スタイル** はボットが必要なので、ボットがいなくなると使えなくなります。

## 開発者向け [#for-developers]

ボットが送信するコードはすべて、[Image API](/docs/developers/image-api) から生成されます。入力するオプションは [CLI](/docs/developers/cli) のものです。自分のスクリプトでコードを作成するには、どちらかを直接ご利用ください。

## セルフホスティング [#self-hosting]

セルフホストしたQRdxサーバーでは、独自のボットを実行できます。[@BotFather](https://t.me/BotFather) でボットを作成し、サーバーに `TELEGRAM_BOT_TOKEN`、`TELEGRAM_WEBHOOK_SECRET`、`TELEGRAM_BOT_USERNAME` を設定して、セットアップスクリプトを実行します。手順は [`plugins/telegram/README.md`](https://github.com/qrdxinc/qrdx/blob/main/plugins/telegram/README.md) に記載されています。3つの変数がすべて設定されるまで、ボットのルートは404を返し、サイトにボットは表示されません。レート制限にはUpstash Redisが必要で、これがない場合は無効になります。[セルフホスティング](/docs/self-hosting#optional-services)をご覧ください。
