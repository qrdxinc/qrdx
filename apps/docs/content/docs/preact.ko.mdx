이 페이지를 마치면 Preact 컴포넌트에 스타일이 적용된 QR 코드와, 이를 PNG로 저장하는 버튼이 생깁니다. `qrdx/preact`에는 React 라이브러리의 SVG 컴포넌트 두 가지인 `QRCodeSVG`와 `QRCode`가 Preact용으로 들어 있습니다. 이 컴포넌트는 Preact 자체의 `h`로 그리므로 `preact/compat`도 `react`도 필요 없으며, React 컴포넌트와 동일한 SVG를 그립니다.

<NpmStatus package="qrdx" />

## 시작하기 전에 [#before-you-start]

- Vite 또는 다른 번들러를 사용하는 Preact 10 이상 프로젝트
- Node.js 18 이상

## 만들어 보기 [#build-it]

### 1. qrdx 설치 [#1-install-qrdx]

```package-install
qrdx
```

`preact`는 `qrdx`의 선택적 피어 의존성입니다. 앱에는 이미 설치되어 있을 것입니다.

### 2. 코드 그리기 [#2-draw-a-code]

```tsx title="src/components/menu-code.tsx"
import { QRCodeSVG } from "qrdx/preact";

export function MenuCode() {
  return (
    <QRCodeSVG
      value="https://example.com/menu"
      size={256}
      margin={4}
      bodyPattern="rounded"
      frame={{ style: "banner-bottom", text: "Scan me" }}
      aria-label="QR code for the menu"
    />
  );
}
```

페이지에 둥근 모듈과 아래에 "Scan me" 배너가 있는 256 px 코드가 표시됩니다.

<Shot id="lib-preact-code" />

`QRCodeSVG`는 React `QRCodeSVG`가 받는 모든 옵션을 받습니다. 패턴, 색상과 그라디언트, 로고(`imageSettings`), 프레임, 도형, 템플릿, 아트가 해당합니다. `class`, `style`, `aria-label` 같은 속성은 `<svg>`에 적용되며, 프레임이 있으면 프레임의 바깥쪽 `<svg>`에 적용됩니다.

`QRCode`는 React `QRCode`의 로고 단축 옵션인 `logo`, `logoOptions`, `hideLogo`, `scale`을 추가로 제공합니다. 코드의 props와 `style`만 받으므로, `class`나 `aria-label`은 코드를 감싸는 요소에 지정하거나 `QRCodeSVG`를 사용하세요.

```tsx title="src/components/logo-code.tsx"
import { QRCode } from "qrdx/preact";

export function LogoCode() {
  return <QRCode value="https://example.com" size={256} logo="/logo.png" level="H" />;
}
```

두 컴포넌트 모두 prop이 바뀌면 다시 그리고, 바뀌지 않으면 작업을 건너뜁니다. React와 마찬가지로 props의 이벤트 핸들러는 `<svg>`에 적용되지 않습니다. 코드를 감싸는 요소에 지정하세요.

### 3. 파일로 저장 [#3-save-it-as-a-file]

컴포넌트는 코드를 그리기만 합니다. 다운로드, `toSVGString`, 스캔 점수 등의 함수는 `qrdx/core`에서 가져옵니다. 컴포넌트가 이미 사용하는 엔진이므로 중복으로 번들되지 않습니다.

```tsx title="src/components/downloadable-code.tsx"
import { downloadQRCode } from "qrdx/core";
import { QRCodeSVG } from "qrdx/preact";

const options = { value: "https://example.com", size: 256, margin: 4 };

export function DownloadableCode() {
  return (
    <>
      <QRCodeSVG {...options} />
      <button
        type="button"
        onClick={() =>
          downloadQRCode(options, {
            format: "png",
            size: { width: 1024, height: 1024 },
            filename: "qr-code.png",
          })
        }
      >
        Download PNG
      </button>
    </>
  );
}
```

버튼을 클릭하면 `qr-code.png`가 1024 px로 저장됩니다. 위 예시처럼 옵션을 하나의 객체로 관리하면 파일이 화면의 코드와 일치합니다. `qrdx/core`는 [Vanilla JavaScript](/docs/vanilla-js)에서 자세히 다룹니다.

## 서버 렌더링 [#server-rendering]

`preact-render-to-string`의 `renderToString`은 `qrdx/core`의 `toSVGString`과 동일한 SVG를 출력합니다. 차이는 이스케이프뿐입니다. 텍스트에서 Preact는 `>`와 `'`를 그대로 두고, core는 `&gt;`와 `&#x27;`로 씁니다. 브라우저는 두 방식을 똑같이 해석합니다.

`hydrate`는 서버의 `<svg>`를 유지하고 다시 그리지 않습니다. 마크업에 임의의 id가 없으므로 서버와 브라우저가 항상 일치합니다.

## preact/compat 사용 시 [#with-preactcompat]

앱에서 이미 `react`를 `preact/compat`으로 별칭 지정했다면 `qrdx`의 React 컴포넌트도 동작합니다. 예: `import { QRCodeSVG } from "qrdx"`. `qrdx/preact`는 별칭 없이 같은 코드를 그리므로, Preact 앱에 `qrdx`를 추가할 때는 이쪽을 권장합니다.

## 문제가 생겼다면 [#if-something-goes-wrong]

- **`Failed to resolve import "react"`.** `preact/compat`이 없는 앱에서 `qrdx/preact`가 아닌 `qrdx`에서 가져왔습니다. import를 변경하세요.
- **컴포넌트의 클릭 핸들러가 동작하지 않습니다.** 핸들러는 `<svg>`에서 제외됩니다. 코드를 `<button>`이나 `<div>`로 감싸고 핸들러를 거기에 지정하세요.
- **`PDF export needs the optional "jspdf" package`.** 앱에서 `npm install jspdf`를 실행하세요.
