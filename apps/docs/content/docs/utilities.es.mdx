Estos helpers son las pequeñas funciones que usan el renderizador y la puntuación de escaneo, exportadas para tu propia interfaz: elegir un color representativo, comprobar el contraste, validar el tamaño de una descarga y detectar funciones de canvas. Se ejecutan en cualquier entorno, salvo donde se indique.

| Función | Devuelve | Notas |
| --- | --- | --- |
| `getSolidColor(color, fallback?)` | `string` | Un color que representa un `ColorConfig`: la cadena, el `color` de un color sólido, la primera parada de un degradado, el `underlay` de un relleno de imagen o, si no, `fallback` (`"#000000"`) |
| `getContrastRatio(a, b)` | `number` | La relación de contraste WCAG entre dos colores CSS, de 1 a 21. Los colores semitransparentes se componen primero sobre blanco. Devuelve 1 cuando no se puede interpretar un color |
| `getContrastLevel(ratio)` | `{ level, warning, message }` | `AAA` desde 7, `AA` desde 4.5, `AA Large` desde 3 (con `warning: true`), `Fail` por debajo de 3 |
| `getLuminance(r, g, b)` | `number` | Luminancia relativa de un color sRGB, de 0 a 1 |
| `hexToRgb(hex)` | `{ r, g, b } \| null` | Lee hexadecimales de 3, 4, 6 y 8 dígitos, descartando el alfa. `null` para cualquier otro formato |
| `validateSize(width, height)` | `{ isValid, error? }` | La regla que aplica cada descarga: de 50 a 5000 px y cuadrado |
| `SUPPORTS_PATH2D` | `boolean` | Indica si el canvas de este entorno admite `Path2D` con `addPath` |

## Colores [#colors]

```ts title="lib/colors.ts"
import { getSolidColor, hexToRgb } from "qrdx";

getSolidColor({
  type: "linear",
  angle: 45,
  stops: [
    { color: "#ff6b6b", offset: 0 },
    { color: "#4ecdc4", offset: 100 },
  ],
});
// "#ff6b6b": the first stop

getSolidColor({ type: "image", src: photo, underlay: "#111111" }); // "#111111"
getSolidColor(undefined, "#ffffff"); // "#ffffff"

hexToRgb("#ff6b6b"); // { r: 255, g: 107, b: 107 }
hexToRgb("#f00"); // { r: 255, g: 0, b: 0 }
hexToRgb("red"); // null
```

Usa `getSolidColor` cuando necesites un solo color para una muestra, un fondo CSS o un valor de reserva. El renderizador lo usa cuando un formato no puede dibujar un degradado, como `QRCodeCanvas` y el dibujo del marco en Canvas.

## Contraste [#contrast]

```ts title="lib/contrast.ts"
import { getContrastLevel, getContrastRatio, getLuminance } from "qrdx";

getContrastRatio("#000000", "#ffffff"); // 21
getContrastRatio("#1d4ed8", "#f8fafc"); // 6.4
getContrastRatio("rgba(29, 78, 216, 0.5)", "#ffffff"); // the blue over white, so lower

getContrastLevel(4.5);
// { level: "AA", warning: false, message: "Good contrast" }

getContrastLevel(2);
// { level: "Fail", warning: true, message: "Poor contrast - QR code may not scan properly" }

getLuminance(255, 255, 255); // 1
```

La puntuación de escaneo aprueba un código con una relación de 4.5 o más (`SCAN_CONTRAST_MIN`), resta puntos por debajo de ese valor y lo suspende por debajo de 1.5. Las imágenes necesitan más: `SCAN_IMAGE_CONTRAST_MIN` es 7 para un relleno de imagen en los módulos y 12 para uno detrás de ellos. `getScanContrast(props)` ejecuta la propia comprobación de la puntuación sobre un diseño completo, incluidas todas las paradas de degradado y los colores de los ojos; consulta [Marcos, puntuación de escaneo y archivos de impresión](/docs/features/frames#will-it-scan).

Un verificador de contraste en vivo cabe en una docena de líneas:

```tsx title="components/contrast-checker.tsx"
"use client";

import { getContrastLevel, getContrastRatio } from "qrdx";
import { useState } from "react";

export function ContrastChecker() {
  const [fgColor, setFgColor] = useState("#000000");
  const [bgColor, setBgColor] = useState("#ffffff");
  const ratio = getContrastRatio(fgColor, bgColor);
  const level = getContrastLevel(ratio);

  return (
    <div>
      <input
        aria-label="Module color"
        type="color"
        value={fgColor}
        onChange={(event) => setFgColor(event.target.value)}
      />
      <input
        aria-label="Background color"
        type="color"
        value={bgColor}
        onChange={(event) => setBgColor(event.target.value)}
      />
      <p>
        {ratio.toFixed(2)}:1, {level.level}. {level.message}
      </p>
    </div>
  );
}
```

## Validación [#validation]

```ts title="lib/sizes.ts"
import { validateSize } from "qrdx";

validateSize(1024, 1024); // { isValid: true }
validateSize(40, 40); // { isValid: false, error: "Size must be at least 50x50 pixels" }
validateSize(6000, 6000); // { isValid: false, error: "Size must not exceed 5000x5000 pixels" }
validateSize(400, 300); // { isValid: false, error: "Width and height must be equal for QR codes" }
```

`downloadQRCode`, `getQRCodeDataUrl` y `copyQRCodeToClipboard` lanzan el mismo texto de `error` cuando un tamaño no es válido, así que un formulario puede comprobarlo antes.

## Detección de funciones [#feature-detection]

```ts title="lib/features.ts"
import { SUPPORTS_PATH2D } from "qrdx";

if (SUPPORTS_PATH2D) {
  // draw module paths with Path2D
}
```

`SUPPORTS_PATH2D` se calcula una sola vez al cargar el módulo, por lo que es `false` en un servidor.

## Otros helpers [#other-helpers]

- `getColorString(color)` y `normalizeColorConfig(color)` convierten entre sí las formas de `ColorConfig`; `isGradient(color)` e `isImagePaint(color)` permiten distinguirlas.
- `sanitizeFrameText(text)` e `isLatin1Text(text)` aplican las reglas de la etiqueta del marco (24 caracteres; Latin-1 para PDF y EPS).
- `decodePNGPixels(bytes)` lee un PNG de 8 bits como píxeles RGBA sin DOM, para `createQRArtImage`, `createQRSilhouette` o `scanQRPixels` en Node.
- `rgbToCmyk(color)` es la conversión que usan los archivos de impresión CMYK.
