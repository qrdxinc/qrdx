Al terminar esta página tendrás un código QR con estilo dibujado en una página HTML simple, actualizado desde tu código y guardado como PNG, con un bundler o con una sola etiqueta script. `qrdx/vanilla` es el mismo motor con el que dibujan los componentes de React, así que dibuja el mismo SVG, con todos los patrones, colores, logos, marcos y exportaciones, y no importa ni `react` ni `react-dom`.

<NpmStatus package="qrdx" />

## Antes de empezar [#before-you-start]

- Una página con un bundler (Vite, webpack, Parcel u otro) para los pasos 1 a 3. Si no usas bundler, salta al [paso 4](#4-use-it-without-a-bundler).
- Node.js 18 o superior para el bundler.

## Constrúyelo [#build-it]

### 1. Instala qrdx [#1-install-qrdx]

```package-install
qrdx
```

`react` y `react-dom` son dependencias peer opcionales. No las necesitas para `qrdx/vanilla` ni para `qrdx/core`.

### 2. Dibuja un código en un elemento [#2-draw-a-code-into-an-element]

```html title="index.html"
<div id="qr"></div>
<script type="module" src="/main.js"></script>
```

```js title="main.js"
import { createQRCode } from "qrdx/vanilla";

const qr = createQRCode("#qr", {
  value: "https://example.com/menu",
  size: 256,
  margin: 4,
  bodyPattern: "rounded",
  frame: { style: "banner-bottom", text: "Scan for the menu" },
  "aria-label": "QR code for the menu",
});
```

Aparece un `<svg>` dentro de `#qr`: un código de 256 px con módulos redondeados y un banner debajo. `createQRCode(element, options)` acepta un elemento o un selector CSS, y todas las opciones que acepta `QRCodeSVG` de React: patrones, colores y degradados, logos (`imageSettings`), marcos, formas, plantillas y arte. Atributos como `className`, `style` o `aria-label` van en el `<svg>`. El elemento se crea con `createElementNS`, así que no se analiza ningún HTML.

### 3. Actualízalo, expórtalo y elimínalo [#3-update-export-and-remove-it]

```js title="main.js"
qr.update({ fgColor: "#1d4ed8" }); // redraws the code in place, now blue

qr.toSVGString(); // '<svg xmlns="http://www.w3.org/2000/svg" …'
await qr.toDataURL("png", { size: 1024 }); // "data:image/png;base64,…"
await qr.download({ format: "png", size: 1024, filename: "menu.png" });

qr.destroy(); // removes the <svg>
```

- `update` combina las opciones nuevas con las actuales y vuelve a dibujar. Pasa `undefined` para quitar una opción. Si el markup no cambia, no se toca la página.
- `toDataURL` y `download` usan por defecto PNG con el `size` del propio código. Los formatos son `png`, `jpg`, `webp`, `svg`, `pdf` y `eps`. Un marco hace que la imagen sea más grande que el código. PDF necesita el paquete opcional `jspdf`.
- `qr.svg` es el elemento `<svg>` y `qr.options` son las opciones actuales.
- `destroy` elimina el `<svg>`. `update` lanza un error después de eso.

### 4. Úsalo sin bundler [#4-use-it-without-a-bundler]

```html title="index.html"
<div id="qr"></div>
<script type="module">
  import { createQRCode } from "https://cdn.jsdelivr.net/npm/qrdx/dist/vanilla.browser.mjs";

  createQRCode("#qr", { value: "https://example.com", size: 256, margin: 4 });
</script>
```

`dist/vanilla.browser.mjs` es la misma API en un solo módulo ES. Añade `@` y una versión después de `qrdx` en la URL para fijar una. La misma ruta funciona en unpkg.

El archivo no incluye los datos de la biblioteca de marcos oficiales, para que las páginas que no la usan no la descarguen. Para usar un marco oficial, impórtalo desde el archivo que está a su lado:

```js title="index.html"
import { getOfficialFrame } from "https://cdn.jsdelivr.net/npm/qrdx/dist/frames-official.mjs";

const wifi = getOfficialFrame("wifi-card");
qr.update({ frame: { style: "custom", spec: wifi.spec } });
```

La exportación a PDF y la puntuación de escaneo cargan `jspdf` y `jsqr` cuando se ejecutan. Una página que las use asigna ambos con un import map, colocado antes del script de módulo:

```html title="index.html"
<script type="importmap">
  {
    "imports": {
      "jspdf": "https://cdn.jsdelivr.net/npm/jspdf@4/+esm",
      "jsqr": "https://cdn.jsdelivr.net/npm/jsqr@1/+esm"
    }
  }
</script>
```

## Markup y nodos del DOM con qrdx/core [#markup-and-dom-nodes-with-qrdxcore]

`qrdx/core` tiene todo lo que tiene la entrada principal `qrdx` excepto los componentes de React. Funciona en Node y en el navegador.

```ts title="code.ts"
import {
  createQRCodeTree,
  renderToDOM,
  renderToString,
  resolveQRCodeProps,
  toSVGElement,
  toSVGString,
} from "qrdx/core";

// What <QRCodeSVG> renders, as a string (no DOM needed)
const svg = toSVGString({ value: "https://example.com", size: 256 });

// The same code as an <svg> element
document.body.append(toSVGElement({ value: "https://example.com" }));

// The code as plain { type, props, key } nodes, then markup or DOM nodes
const tree = createQRCodeTree({ value: "https://example.com" });
renderToString(tree);
renderToDOM(tree);

// <QRCode>'s logo API (logo, logoOptions, hideLogo, scale)
toSVGString(resolveQRCodeProps({ value: "https://example.com", logo: "/logo.png" }));
```

La salida no tiene ids aleatorios, así que el markup renderizado en un servidor coincide con el del navegador. Las descargas, la puntuación de escaneo y el PDF y EPS listos para imprimir salen de las mismas funciones que en la biblioteca de React: `downloadQRCode`, `getQRCodeDataUrl`, `getScanScore`, `downloadPrintPDF` y las demás. Para PNG en un servidor, usa `getQRAsPNG` de `qrdx/node`.

## Plantillas personalizadas sin JSX [#custom-templates-without-jsx]

El `wrapper` de una plantilla recibe el código dibujado y lo devuelve envuelto. `h(type, props, ...children)` permite escribir uno sin JSX:

```js title="labelled-template.js"
import { h, toSVGString } from "qrdx/core";

const Labelled = {
  id: "Labelled",
  name: "Labelled",
  wrapper: (children, props) =>
    h(
      "svg",
      { viewBox: "0 0 300 340", xmlns: "http://www.w3.org/2000/svg" },
      h("g", { transform: "translate(20, 20) scale(0.87)" }, children),
      h("text", { x: "150", y: "325", textAnchor: "middle" }, props?.label)
    ),
};

toSVGString({
  value: "https://example.com",
  customTemplate: Labelled,
  customProps: { label: "Scan me" },
});
```

El mismo wrapper funciona en los componentes de React si importas `h` desde `qrdx`.

## Si algo sale mal [#if-something-goes-wrong]

- **`qrdx: no element matches #qr`.** El script se ejecutó antes de que existiera el elemento. Pon el `<script type="module">` después del elemento, o espera a `DOMContentLoaded`.
- **`qrdx: this QR code was destroyed`.** Llamaste a `update` después de `destroy`. Crea un código nuevo con `createQRCode`.
- **`PDF export needs the optional "jspdf" package`.** Instala `jspdf` junto a `qrdx`, o añádelo al import map en una página sin bundler.
- **El código se dibuja pero un teléfono no lo lee.** Añade `margin: 4`, mantén los módulos oscuros sobre un fondo claro y revisa el diseño con `getScanScore`. Consulta [Un código no se escanea](/docs/help/troubleshooting/wont-scan).
