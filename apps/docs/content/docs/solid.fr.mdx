À la fin de cette page, vous aurez un QR code stylisé dans un composant Solid qui suit un signal, ainsi qu'un bouton qui l'enregistre en PNG. `qrdx/solid` propose les deux composants SVG de la bibliothèque React, `QRCodeSVG` et `QRCode`, conçus pour SolidJS. Ils dessinent le même SVG que les composants React, suivent vos signaux et fonctionnent côté serveur.

<NpmStatus package="qrdx" />

## Avant de commencer [#before-you-start]

- Un projet Solid 1.8 ou plus récent (dans la branche 1.x), avec Vite ou SolidStart.
- Node.js 18 ou plus récent.

## Mise en place [#build-it]

### 1. Installer qrdx [#1-install-qrdx]

```package-install
qrdx
```

`solid-js` est une dépendance peer facultative de `qrdx`. Votre application l'a déjà, et vous n'avez pas besoin de `react`.

### 2. Dessiner un code qui suit un signal [#2-draw-a-code-that-follows-a-signal]

```tsx title="src/components/menu-code.tsx"
import { createSignal } from "solid-js";
import { QRCodeSVG } from "qrdx/solid";

export function MenuCode() {
  const [color, setColor] = createSignal("#0f172a");
  return (
    <>
      <QRCodeSVG
        value="https://example.com/menu"
        size={256}
        margin={4}
        fgColor={color()}
        frame={{ style: "banner-bottom", text: "Scan me" }}
        aria-label="QR code for the menu"
      />
      <button type="button" onClick={() => setColor("#1d4ed8")}>
        Blue
      </button>
    </>
  );
}
```

La page affiche un code sombre avec une bannière « Scan me ». Cliquez sur **Blue** et le code est redessiné en bleu.

<Shot id="lib-solid-signal-code" />

`QRCodeSVG` accepte toutes les options de `QRCodeSVG` côté React : motifs, couleurs et dégradés, logos (`imageSettings`), cadres, formes, modèles et art. Les attributs tels que `class`, `style` ou `aria-label` sont placés sur le `<svg>`, ou sur le `<svg>` extérieur du cadre lorsqu'il y a un cadre.

`QRCode` ajoute le raccourci de logo du `QRCode` React : `logo`, `logoOptions`, `hideLogo` et `scale`. Il n'accepte que les props du code et `style` ; placez `class` ou `aria-label` sur un élément qui l'entoure, ou utilisez `QRCodeSVG`.

```tsx title="src/components/logo-code.tsx"
import { QRCode } from "qrdx/solid";

export function LogoCode() {
  return <QRCode value="https://example.com" size={256} logo="/logo.png" level="H" />;
}
```

Les props sont réactives, comme avec n'importe quel composant Solid. Quand `color()` change, le code est redessiné. Les gestionnaires d'événements passés dans les props ne sont pas placés sur le `<svg>` : mettez-les sur un élément qui entoure le code.

### 3. L'enregistrer dans un fichier [#3-save-it-as-a-file]

Les composants ne font que dessiner le code. Les téléchargements, `toSVGString`, le score de scan et les autres fonctions viennent de `qrdx/core`. C'est le moteur que les composants utilisent déjà, il n'est donc pas inclus deux fois dans le bundle.

```tsx title="src/components/downloadable-code.tsx"
import { downloadQRCode } from "qrdx/core";
import { QRCodeSVG } from "qrdx/solid";

const options = { value: "https://example.com", size: 256, margin: 4 };

export function DownloadableCode() {
  return (
    <>
      <QRCodeSVG {...options} />
      <button
        type="button"
        onClick={() =>
          downloadQRCode(options, {
            format: "png",
            size: { width: 1024, height: 1024 },
            filename: "qr-code.png",
          })
        }
      >
        Download PNG
      </button>
    </>
  );
}
```

Un clic sur le bouton enregistre `qr-code.png` en 1024 px. [JavaScript natif](/docs/vanilla-js) présente `qrdx/core` en détail.

## Comment il dessine [#how-it-draws]

Le package ne contient aucun JSX Solid : il n'a donc pas besoin du compilateur Solid et fonctionne avec n'importe quelle configuration de build.

- Dans le navigateur, un composant renvoie directement l'élément `<svg>`, construit avec `createElementNS` (aucun HTML n'est analysé). Solid l'insère dans la page, le remplace par un nouveau lorsqu'un changement de prop modifie le balisage, et le retire quand le composant est démonté.
- Un changement de prop qui produit le même balisage laisse la page intacte.

## Rendu serveur et hydratation [#server-rendering-and-hydration]

Avec `renderToString` de `solid-js/web`, un composant écrit le même balisage que `toSVGString` de `qrdx/core`, plus la clé d'hydratation `data-hk` de Solid sur l'élément racine. `hydrate` s'appuie sur cette clé pour conserver le `<svg>` du serveur au lieu de le redessiner. Dans `<NoHydration>`, la clé est omise.

Le balisage ne contient aucun identifiant aléatoire, donc le serveur et le navigateur sont toujours d'accord.

## En cas de problème [#if-something-goes-wrong]

- **`Failed to resolve import "react"`.** Vous avez importé depuis `qrdx` au lieu de `qrdx/solid`. L'entrée principale contient les composants React ; changez l'import.
- **Un gestionnaire de clic sur le composant ne fait rien.** Les gestionnaires sont ignorés sur le `<svg>`. Enveloppez le code dans un élément et placez le gestionnaire dessus.
- **`PDF export needs the optional "jspdf" package`.** Exécutez `npm install jspdf` dans l'application.
