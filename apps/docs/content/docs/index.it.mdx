QRdx è una piattaforma open source per QR code: QR code statici gratuiti e senza account, e QR code dinamici che puoi modificare dopo la stampa, con pagine ospitate e analisi delle scansioni. Un QR code dinamico continua a funzionare su ogni piano, anche dopo la disdetta ([la Garanzia Never-Hostage](/guarantee)).
