このページを読み終えると、プレーンなHTMLページにスタイル付きQRコードを描画し、コードから更新して PNG として保存できるようになります。バンドラーを使う方法も、scriptタグ1つだけで済ませる方法も扱います。`qrdx/vanilla` はReactコンポーネントが描画に使うのと同じエンジンなので、パターン、色、ロゴ、フレーム、書き出しのすべてを備えた同じSVGを描画します。`react` も `react-dom` もインポートしません。

## 始める前に [#before-you-start]

- ステップ1〜3には、バンドラー（Vite、webpack、Parcel など）を使うページが必要です。バンドラーを使わない場合は[ステップ4](#4-use-it-without-a-bundler)に進んでください。
- バンドラーには Node.js 18 以降が必要です。

## 作成手順 [#build-it]

### 1. qrdxをインストールする [#1-install-qrdx]

```package-install
qrdx
```

`react` と `react-dom` は任意のピア依存関係です。`qrdx/vanilla` や `qrdx/core` を使うだけなら不要です。

### 2. 要素にQRコードを描画する [#2-draw-a-code-into-an-element]

```html title="index.html"
<div id="qr"></div>
<script type="module" src="/main.js"></script>
```

```js title="main.js"
import { createQRCode } from "qrdx/vanilla";

const qr = createQRCode("#qr", {
  value: "https://example.com/menu",
  size: 256,
  margin: 4,
  bodyPattern: "rounded",
  frame: { style: "banner-bottom", text: "Scan for the menu" },
  "aria-label": "QR code for the menu",
});
```

`#qr` の中に `<svg>` が表示されます。角丸のモジュールで構成された 256 px のコードと、その下のバナーです。`createQRCode(element, options)` は要素またはCSSセレクターを受け取り、ReactのQRCodeコンポーネント `QRCodeSVG` が受け取るすべてのオプションに対応しています。パターン、色とグラデーション、ロゴ（`imageSettings`）、フレーム、シェイプ、テンプレート、アートが指定できます。`className`、`style`、`aria-label` などの属性は `<svg>` に付きます。要素は `createElementNS` で作られるため、HTMLは解析されません。

### 3. 更新、書き出し、削除をする [#3-update-export-and-remove-it]

```js title="main.js"
qr.update({ fgColor: "#1d4ed8" }); // redraws the code in place, now blue

qr.toSVGString(); // '<svg xmlns="http://www.w3.org/2000/svg" …'
await qr.toDataURL("png", { size: 1024 }); // "data:image/png;base64,…"
await qr.download({ format: "png", size: 1024, filename: "menu.png" });

qr.destroy(); // removes the <svg>
```

- `update` は新しいオプションを現在のオプションにマージして再描画します。オプションを外すには `undefined` を渡します。マークアップが変わらない場合、ページには手を加えません。
- `toDataURL` と `download` は、デフォルトでコード自体の `size` の PNG を出力します。形式は `png`、`jpg`、`webp`、`svg`、`pdf`、`eps` です。フレームを付けると、画像はコードより大きくなります。PDF には任意パッケージの `jspdf` が必要です。
- `qr.svg` は `<svg>` 要素、`qr.options` は現在のオプションです。
- `destroy` は `<svg>` を削除します。その後に `update` を呼ぶとエラーになります。

### 4. バンドラーなしで使う [#4-use-it-without-a-bundler]

```html title="index.html"
<div id="qr"></div>
<script type="module">
  import { createQRCode } from "https://cdn.jsdelivr.net/npm/qrdx/dist/vanilla.browser.mjs";

  createQRCode("#qr", { value: "https://example.com", size: 256, margin: 4 });
</script>
```

`dist/vanilla.browser.mjs` は、同じAPIを1つのESモジュールにまとめたものです。URLの `qrdx` の後に `@` とバージョンを付けると、バージョンを固定できます。unpkg でも同じパスで使えます。

このファイルには公式フレームライブラリのデータが含まれていないため、使わないページがそれをダウンロードすることはありません。公式フレームを使うには、隣にあるファイルからインポートします。

```js title="index.html"
import { getOfficialFrame } from "https://cdn.jsdelivr.net/npm/qrdx/dist/frames-official.mjs";

const wifi = getOfficialFrame("wifi-card");
qr.update({ frame: { style: "custom", spec: wifi.spec } });
```

PDFの書き出しとスキャンスコアは、実行時に `jspdf` と `jsqr` を読み込みます。これらを使うページでは、モジュールスクリプトの前に置いたインポートマップで両方をマッピングします。

```html title="index.html"
<script type="importmap">
  {
    "imports": {
      "jspdf": "https://cdn.jsdelivr.net/npm/jspdf@4/+esm",
      "jsqr": "https://cdn.jsdelivr.net/npm/jsqr@1/+esm"
    }
  }
</script>
```

## qrdx/coreでマークアップとDOMノードを扱う [#markup-and-dom-nodes-with-qrdxcore]

`qrdx/core` には、Reactコンポーネントを除き、メインの `qrdx` エントリーにあるものがすべて含まれています。Nodeでもブラウザーでも動作します。

```ts title="code.ts"
import {
  createQRCodeTree,
  renderToDOM,
  renderToString,
  resolveQRCodeProps,
  toSVGElement,
  toSVGString,
} from "qrdx/core";

// What <QRCodeSVG> renders, as a string (no DOM needed)
const svg = toSVGString({ value: "https://example.com", size: 256 });

// The same code as an <svg> element
document.body.append(toSVGElement({ value: "https://example.com" }));

// The code as plain { type, props, key } nodes, then markup or DOM nodes
const tree = createQRCodeTree({ value: "https://example.com" });
renderToString(tree);
renderToDOM(tree);

// <QRCode>'s logo API (logo, logoOptions, hideLogo, scale)
toSVGString(resolveQRCodeProps({ value: "https://example.com", logo: "/logo.png" }));
```

出力にランダムなIDは含まれないため、サーバーでレンダリングしたマークアップはブラウザーのものと一致します。ダウンロード、スキャンスコア、印刷用のPDFとEPSは、Reactライブラリと同じ関数から得られます。`downloadQRCode`、`getQRCodeDataUrl`、`getScanScore`、`downloadPrintPDF` などです。サーバーで PNG を出力するには、`qrdx/node` の `getQRAsPNG` を使います。

## JSXなしのカスタムテンプレート [#custom-templates-without-jsx]

テンプレートの `wrapper` は描画済みのコードを受け取り、それをラップして返します。`h(type, props, ...children)` を使えば、JSXなしで記述できます。

```js title="labelled-template.js"
import { h, toSVGString } from "qrdx/core";

const Labelled = {
  id: "Labelled",
  name: "Labelled",
  wrapper: (children, props) =>
    h(
      "svg",
      { viewBox: "0 0 300 340", xmlns: "http://www.w3.org/2000/svg" },
      h("g", { transform: "translate(20, 20) scale(0.87)" }, children),
      h("text", { x: "150", y: "325", textAnchor: "middle" }, props?.label)
    ),
};

toSVGString({
  value: "https://example.com",
  customTemplate: Labelled,
  customProps: { label: "Scan me" },
});
```

同じwrapperは、代わりに `qrdx` から `h` をインポートすれば、Reactコンポーネントでも使えます。

## うまくいかない場合 [#if-something-goes-wrong]

- **`qrdx: no element matches #qr`。** 要素が存在する前にスクリプトが実行されています。`<script type="module">` を要素の後ろに置くか、`DOMContentLoaded` を待ってください。
- **`qrdx: this QR code was destroyed`。** `destroy` の後に `update` を呼びました。`createQRCode` で新しいコードを作成してください。
- **`PDF export needs the optional "jspdf" package`。** `qrdx` と一緒に `jspdf` をインストールしてください。バンドラーなしのページでは、インポートマップに追加します。
- **コードは描画されるのに、スマートフォンで読み取れない。** `margin: 4` を追加し、明るい背景に暗いモジュールを使い、`getScanScore` でデザインを確認してください。[QRコードがスキャンできない](/docs/help/troubleshooting/wont-scan)を参照してください。
