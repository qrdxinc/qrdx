Ao final desta página, você terá um QR code renderizado por um Server Component sem JavaScript no cliente, um código criado a partir de um parâmetro de rota, um código ao vivo ligado a um campo de entrada, um código com o seu logo e um botão que salva um SVG. `QRCodeSVG` e `QRCode` não usam hooks exclusivos do cliente, então um Server Component renderiza o código direto no HTML da página. Você só precisa de um Client Component quando o valor muda no navegador ou para salvar um arquivo.

<NpmStatus package="qrdx" />

## Antes de começar [#before-you-start]

- Um projeto Next.js com App Router. Os exemplos usam o `params` assíncrono do App Router, como no Next.js 15 e 16.
- React 18 ou mais recente, que o App Router já exige.

## Passo a passo [#build-it]

### 1. Instale o qrdx [#1-install-qrdx]

```package-install
qrdx
```

`react` e `react-dom` são peer dependencies, então as versões do seu próprio app são usadas.

### 2. Renderize um código em um Server Component [#2-render-a-code-in-a-server-component]

```tsx title="app/page.tsx"
import { QRCodeSVG } from "qrdx";

export default function Page() {
  return (
    <QRCodeSVG
      value="https://example.com"
      size={256}
      margin={4}
      role="img"
      aria-label="QR code for example.com"
    />
  );
}
```

Abra a página. O `<svg>` faz parte do HTML que o servidor envia, então aparece antes de qualquer JavaScript carregar, uma página estática o renderiza uma única vez no build, e os leitores de tela recebem o `aria-label`.

<Shot id="lib-nextjs-server-code" />

`margin` é a zona de silêncio ao redor do código, em módulos. O padrão é 0, o que serve para um código dentro de um card com padding próprio. O padrão do QR pede 4, a escolha segura em um fundo carregado ou escuro.

### 3. Monte o valor a partir de um parâmetro de rota [#3-build-the-value-from-a-route-param]

```tsx title="app/tickets/[id]/page.tsx"
import { QRCodeSVG } from "qrdx";

export default async function TicketPage({
  params,
}: {
  params: Promise<{ id: string }>;
}) {
  const { id } = await params;
  const url = `https://example.com/check-in/${encodeURIComponent(id)}`;
  return <QRCodeSVG value={url} size={200} margin={4} level="H" />;
}
```

Acesse `/tickets/A-12` e o código abre `https://example.com/check-in/A-12`. O Next.js passa `params` como uma promise, por isso a página é `async`. Codifique tudo o que vier de um usuário ou de um banco de dados antes de colocar em uma URL. O nível `H` permite que até 30% do código seja danificado, o que ajuda em um crachá que pode ser dobrado ou arranhado.

### 4. Acompanhe um campo de entrada em um Client Component [#4-follow-an-input-in-a-client-component]

```tsx title="components/live-qr-code.tsx"
"use client";

import { QRCodeSVG } from "qrdx";
import { useState } from "react";

export function LiveQrCode() {
  const [value, setValue] = useState("https://example.com");
  return (
    <div>
      <input
        aria-label="Text or link to encode"
        value={value}
        onChange={(event) => setValue(event.target.value)}
      />
      {value ? <QRCodeSVG value={value} size={200} margin={4} /> : null}
    </div>
  );
}
```

O código é redesenhado a cada tecla digitada, e o primeiro valor ainda é renderizado no servidor. Uma página Server Component pode importar este componente do jeito que ele está.

`QRCodeCanvas` também é um Client Component (ele vem com `"use client"`), mas desenha apenas módulos quadrados simples. Use `QRCodeSVG` ou `QRCode` para códigos estilizados.

### 5. Adicione um logo [#5-add-a-logo]

```tsx title="components/logo-qr-code.tsx"
import { QRCode } from "qrdx";

export function LogoQrCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      margin={4}
      level="H"
      logo="/logo.png"
    />
  );
}
```

`/logo.png` é um arquivo na pasta `public` do seu projeto. O logo é desenhado com um quarto da largura do código e os módulos atrás dele são removidos, então o código depende da correção de erros para ser lido: por isso `level` é `H`. O `QRCode` também reduz um logo grande demais para o código conseguir se recuperar.

`logo` aceita um caminho no seu app, uma URL ou uma data URL. Para downloads, uma data URL é a opção mais segura, porque uma imagem remota precisa de headers CORS antes que o navegador possa copiá-la para o arquivo. `logoOptions` define o tamanho, o espaço livre, a posição e o recorte do logo; veja [Adicione um logo no código](/docs/features/logos).

### 6. Baixe como SVG [#6-download-as-svg]

```tsx title="components/download-svg-button.tsx"
"use client";

import { downloadQRCode } from "qrdx";

export function DownloadSvgButton({ value }: { value: string }) {
  return (
    <button
      type="button"
      onClick={() =>
        downloadQRCode(
          { value, level: "Q", margin: 4 },
          {
            format: "svg",
            size: { width: 1024, height: 1024 },
            filename: "qr-code.svg",
          },
        )
      }
    >
      Download SVG
    </button>
  );
}
```

Ao clicar no botão, ele salva `qr-code.svg`, um arquivo vetorial de 1024 px. `downloadQRCode` precisa do DOM do navegador, então o botão é um Client Component. Uma página Server Component ainda pode renderizá-lo e passar o valor como prop. Para outros arquivos, defina `format` como `png`, `jpg`, `webp`, `eps` ou `pdf` (PDF precisa do pacote opcional `jspdf`). [Exportar e baixar](/docs/features/downloads) cobre todas as opções.

## Quando você precisa de uma URL de imagem [#when-you-need-an-image-url]

E-mails, imagens Open Graph, arquivos Markdown e outros lugares que não executam React precisam de uma URL de imagem em vez de um componente. A [API de imagem de QR code](/docs/developers/image-api) retorna uma sem chave:

```html title="email.html"
<img src="https://api.qrdx.dev/v1/qr?data=https://example.com&format=png" width="256" height="256" alt="QR code for example.com" />
```

## Componentes prontos [#ready-made-components]

O [registro do shadcn/ui](/docs/developers/shadcn) instala componentes no seu projeto: um [QR code com botões de download](/docs/components/qr-code), um card, uma caixa de compartilhamento, um gerador, um leitor e códigos de Wi-Fi e de contato.

```bash title="Terminal"
npx shadcn@latest add https://qrdx.dev/r/qr-code.json
```

## Se algo der errado [#if-something-goes-wrong]

- **`useRef only works in Client Components` (ou o mesmo para `useState`).** Você renderizou `QRCodeCanvas`, ou um componente com hooks, a partir de um Server Component. Adicione `"use client"` no topo desse arquivo ou renderize `QRCodeSVG`.
- **O logo aparece na página, mas não no arquivo baixado.** A imagem vem de outra origem sem headers CORS. Sirva-a a partir de `public` ou passe uma data URL.
- **`PDF export needs the optional "jspdf" package`.** Execute `npm install jspdf` no app. Os outros formatos não precisam de nada extra.
