这些辅助函数都是渲染器和扫描评分所使用的小函数，现在也导出给你自己的界面使用：选取代表色、检查对比度、校验下载尺寸，以及检测画布特性。除特别说明外，它们在任何环境中都能运行。

| 函数 | 返回值 | 说明 |
| --- | --- | --- |
| `getSolidColor(color, fallback?)` | `string` | 代表某个 `ColorConfig` 的单一颜色：字符串本身、纯色的 `color`、渐变的第一个色标、图片填充的 `underlay`，否则为 `fallback`（`"#000000"`） |
| `getContrastRatio(a, b)` | `number` | 两个 CSS 颜色之间的 WCAG 对比度，范围 1 到 21。半透明颜色会先叠加在白色上。任一颜色无法解析时返回 1 |
| `getContrastLevel(ratio)` | `{ level, warning, message }` | 从 7 起为 `AAA`，从 4.5 起为 `AA`，从 3 起为 `AA Large`（同时 `warning: true`），低于 3 为 `Fail` |
| `getLuminance(r, g, b)` | `number` | sRGB 颜色的相对亮度，范围 0 到 1 |
| `hexToRgb(hex)` | `{ r, g, b } \| null` | 读取 3、4、6 和 8 位十六进制颜色，并丢弃 alpha。其他输入返回 `null` |
| `validateSize(width, height)` | `{ isValid, error? }` | 所有下载都适用的规则：50 到 5000 px，且为正方形 |
| `SUPPORTS_PATH2D` | `boolean` | 当前环境的画布是否支持带 `addPath` 的 `Path2D` |

## 颜色 [#colors]

```ts title="lib/colors.ts"
import { getSolidColor, hexToRgb } from "qrdx";

getSolidColor({
  type: "linear",
  angle: 45,
  stops: [
    { color: "#ff6b6b", offset: 0 },
    { color: "#4ecdc4", offset: 100 },
  ],
});
// "#ff6b6b": the first stop

getSolidColor({ type: "image", src: photo, underlay: "#111111" }); // "#111111"
getSolidColor(undefined, "#ffffff"); // "#ffffff"

hexToRgb("#ff6b6b"); // { r: 255, g: 107, b: 107 }
hexToRgb("#f00"); // { r: 255, g: 0, b: 0 }
hexToRgb("red"); // null
```

当你需要为色板、CSS 背景或备用色提供单一颜色时，请使用 `getSolidColor`。当某种格式无法绘制渐变时，渲染器也会使用它，例如 `QRCodeCanvas` 和 Canvas 边框绘制。

## 对比度 [#contrast]

```ts title="lib/contrast.ts"
import { getContrastLevel, getContrastRatio, getLuminance } from "qrdx";

getContrastRatio("#000000", "#ffffff"); // 21
getContrastRatio("#1d4ed8", "#f8fafc"); // 6.4
getContrastRatio("rgba(29, 78, 216, 0.5)", "#ffffff"); // the blue over white, so lower

getContrastLevel(4.5);
// { level: "AA", warning: false, message: "Good contrast" }

getContrastLevel(2);
// { level: "Fail", warning: true, message: "Poor contrast - QR code may not scan properly" }

getLuminance(255, 255, 255); // 1
```

扫描评分在对比度达到 4.5 或更高（`SCAN_CONTRAST_MIN`）时判定二维码通过，低于该值会扣分，低于 1.5 则判定为不通过。图片需要更高的对比度：`SCAN_IMAGE_CONTRAST_MIN` 对于码点中的图片填充为 7，对于码点后方的图片填充为 12。`getScanContrast(props)` 会对整个设计运行评分自身的检查，包括每个渐变色标和定位点颜色；参见[边框、扫描评分和印刷文件](/docs/features/frames#will-it-scan)。

实时对比度检查器只需十几行代码：

```tsx title="components/contrast-checker.tsx"
"use client";

import { getContrastLevel, getContrastRatio } from "qrdx";
import { useState } from "react";

export function ContrastChecker() {
  const [fgColor, setFgColor] = useState("#000000");
  const [bgColor, setBgColor] = useState("#ffffff");
  const ratio = getContrastRatio(fgColor, bgColor);
  const level = getContrastLevel(ratio);

  return (
    <div>
      <input
        aria-label="Module color"
        type="color"
        value={fgColor}
        onChange={(event) => setFgColor(event.target.value)}
      />
      <input
        aria-label="Background color"
        type="color"
        value={bgColor}
        onChange={(event) => setBgColor(event.target.value)}
      />
      <p>
        {ratio.toFixed(2)}:1, {level.level}. {level.message}
      </p>
    </div>
  );
}
```

## 校验 [#validation]

```ts title="lib/sizes.ts"
import { validateSize } from "qrdx";

validateSize(1024, 1024); // { isValid: true }
validateSize(40, 40); // { isValid: false, error: "Size must be at least 50x50 pixels" }
validateSize(6000, 6000); // { isValid: false, error: "Size must not exceed 5000x5000 pixels" }
validateSize(400, 300); // { isValid: false, error: "Width and height must be equal for QR codes" }
```

当尺寸不合格时，`downloadQRCode`、`getQRCodeDataUrl` 和 `copyQRCodeToClipboard` 会抛出相同的 `error` 文本，因此表单可以先行检查。

## 特性检测 [#feature-detection]

```ts title="lib/features.ts"
import { SUPPORTS_PATH2D } from "qrdx";

if (SUPPORTS_PATH2D) {
  // draw module paths with Path2D
}
```

`SUPPORTS_PATH2D` 在模块加载时只计算一次，因此在服务器上为 `false`。

## 其他辅助函数 [#other-helpers]

- `getColorString(color)` 和 `normalizeColorConfig(color)` 用于在 `ColorConfig` 的各种形式之间相互转换；`isGradient(color)` 和 `isImagePaint(color)` 用于区分它们。
- `sanitizeFrameText(text)` 和 `isLatin1Text(text)` 应用边框标签规则（24 个字符；PDF 和 EPS 使用 Latin-1）。
- `decodePNGPixels(bytes)` 无需 DOM，即可将 8 位 PNG 读取为 RGBA 像素，供 Node 中的 `createQRArtImage`、`createQRSilhouette` 或 `scanQRPixels` 使用。
- `rgbToCmyk(color)` 是 CMYK 印刷文件所使用的转换函数。
