读完本页，你将在一个普通 HTML 页面中绘制出带样式的二维码，通过代码更新它，并保存为 PNG，打包工具或单个 script 标签均可。`qrdx/vanilla` 与 React 组件使用的是同一个绘制引擎，因此会绘制出相同的 SVG，支持所有图案、颜色、徽标、边框和导出方式，并且不会导入 `react` 或 `react-dom`。

## 开始之前 [#before-you-start]

- 步骤 1 到 3 需要一个使用打包工具的页面（Vite、webpack、Parcel 或其他均可）。如果不用打包工具，请直接跳到[步骤 4](#4-use-it-without-a-bundler)。
- 打包工具需要 Node.js 18 或更高版本。

## 动手实现 [#build-it]

### 1. 安装 qrdx [#1-install-qrdx]

```package-install
qrdx
```

`react` 和 `react-dom` 是可选的对等依赖。使用 `qrdx/vanilla` 或 `qrdx/core` 时不需要它们。

### 2. 在元素中绘制二维码 [#2-draw-a-code-into-an-element]

```html title="index.html"
<div id="qr"></div>
<script type="module" src="/main.js"></script>
```

```js title="main.js"
import { createQRCode } from "qrdx/vanilla";

const qr = createQRCode("#qr", {
  value: "https://example.com/menu",
  size: 256,
  margin: 4,
  bodyPattern: "rounded",
  frame: { style: "banner-bottom", text: "Scan for the menu" },
  "aria-label": "QR code for the menu",
});
```

`#qr` 中会出现一个 `<svg>`：一个 256 px 的二维码，模块为圆角，下方带有横幅。`createQRCode(element, options)` 接受一个元素或 CSS 选择器，并支持 React `QRCodeSVG` 的所有选项：图案、颜色和渐变、徽标（`imageSettings`）、边框、形状、模板和艺术样式。`className`、`style` 或 `aria-label` 等属性会设置在 `<svg>` 上。该元素通过 `createElementNS` 构建，因此不会解析任何 HTML。

### 3. 更新、导出和移除 [#3-update-export-and-remove-it]

```js title="main.js"
qr.update({ fgColor: "#1d4ed8" }); // redraws the code in place, now blue

qr.toSVGString(); // '<svg xmlns="http://www.w3.org/2000/svg" …'
await qr.toDataURL("png", { size: 1024 }); // "data:image/png;base64,…"
await qr.download({ format: "png", size: 1024, filename: "menu.png" });

qr.destroy(); // removes the <svg>
```

- `update` 会把新选项合并到当前选项中并重新绘制。传入 `undefined` 可移除某个选项。如果标记没有变化，页面不会被改动。
- `toDataURL` 和 `download` 默认导出 PNG，尺寸为二维码自身的 `size`。支持的格式有 `png`、`jpg`、`webp`、`svg`、`pdf` 和 `eps`。使用边框时，图片会比二维码本身更大。PDF 需要可选的 `jspdf` 包。
- `qr.svg` 是 `<svg>` 元素，`qr.options` 是当前选项。
- `destroy` 会移除 `<svg>`。调用之后再执行 `update` 会抛出错误。

### 4. 不使用打包工具 [#4-use-it-without-a-bundler]

```html title="index.html"
<div id="qr"></div>
<script type="module">
  import { createQRCode } from "https://cdn.jsdelivr.net/npm/qrdx/dist/vanilla.browser.mjs";

  createQRCode("#qr", { value: "https://example.com", size: 256, margin: 4 });
</script>
```

`dist/vanilla.browser.mjs` 是同一套 API 的单个 ES 模块。在 URL 中的 `qrdx` 后面加上 `@` 和版本号即可固定版本。同样的路径在 unpkg 上也可用。

该文件不包含官方边框库的数据，因此不使用它的页面不会下载这些数据。要使用官方边框，请从它旁边的文件中导入：

```js title="index.html"
import { getOfficialFrame } from "https://cdn.jsdelivr.net/npm/qrdx/dist/frames-official.mjs";

const wifi = getOfficialFrame("wifi-card");
qr.update({ frame: { style: "custom", spec: wifi.spec } });
```

PDF 导出和扫描评分在运行时会加载 `jspdf` 和 `jsqr`。用到它们的页面需要用 import map 映射这两个包，import map 要放在模块脚本之前：

```html title="index.html"
<script type="importmap">
  {
    "imports": {
      "jspdf": "https://cdn.jsdelivr.net/npm/jspdf@4/+esm",
      "jsqr": "https://cdn.jsdelivr.net/npm/jsqr@1/+esm"
    }
  }
</script>
```

## 使用 qrdx/core 生成标记和 DOM 节点 [#markup-and-dom-nodes-with-qrdxcore]

`qrdx/core` 包含 `qrdx` 主入口的全部内容，只是不含 React 组件。它可在 Node 和浏览器中使用。

```ts title="code.ts"
import {
  createQRCodeTree,
  renderToDOM,
  renderToString,
  resolveQRCodeProps,
  toSVGElement,
  toSVGString,
} from "qrdx/core";

// What <QRCodeSVG> renders, as a string (no DOM needed)
const svg = toSVGString({ value: "https://example.com", size: 256 });

// The same code as an <svg> element
document.body.append(toSVGElement({ value: "https://example.com" }));

// The code as plain { type, props, key } nodes, then markup or DOM nodes
const tree = createQRCodeTree({ value: "https://example.com" });
renderToString(tree);
renderToDOM(tree);

// <QRCode>'s logo API (logo, logoOptions, hideLogo, scale)
toSVGString(resolveQRCodeProps({ value: "https://example.com", logo: "/logo.png" }));
```

输出中没有随机 id，因此在服务器上渲染的标记与浏览器中的一致。下载、扫描评分以及可直接印刷的 PDF 和 EPS，都来自与 React 库相同的函数：`downloadQRCode`、`getQRCodeDataUrl`、`getScanScore`、`downloadPrintPDF` 等。需要在服务器上生成 PNG 时，请使用 `qrdx/node` 中的 `getQRAsPNG`。

## 不用 JSX 的自定义模板 [#custom-templates-without-jsx]

模板的 `wrapper` 接收已绘制的二维码，并返回包装后的结果。`h(type, props, ...children)` 可以让你不用 JSX 来编写它：

```js title="labelled-template.js"
import { h, toSVGString } from "qrdx/core";

const Labelled = {
  id: "Labelled",
  name: "Labelled",
  wrapper: (children, props) =>
    h(
      "svg",
      { viewBox: "0 0 300 340", xmlns: "http://www.w3.org/2000/svg" },
      h("g", { transform: "translate(20, 20) scale(0.87)" }, children),
      h("text", { x: "150", y: "325", textAnchor: "middle" }, props?.label)
    ),
};

toSVGString({
  value: "https://example.com",
  customTemplate: Labelled,
  customProps: { label: "Scan me" },
});
```

如果改为从 `qrdx` 导入 `h`，同样的 wrapper 也可以用在 React 组件中。

## 遇到问题时 [#if-something-goes-wrong]

- **`qrdx: no element matches #qr`。** 脚本运行时元素还不存在。请把 `<script type="module">` 放在该元素之后，或等待 `DOMContentLoaded`。
- **`qrdx: this QR code was destroyed`。** 你在 `destroy` 之后调用了 `update`。请用 `createQRCode` 创建一个新的二维码。
- **`PDF export needs the optional "jspdf" package`。** 请在 `qrdx` 旁边安装 `jspdf`；在没有打包工具的页面中，则把它添加到 import map。
- **二维码已绘制出来，但手机无法识别。** 添加 `margin: 4`，保持深色模块配浅色背景，并用 `getScanScore` 检查设计。参见[二维码无法扫描](/docs/help/troubleshooting/wont-scan)。
