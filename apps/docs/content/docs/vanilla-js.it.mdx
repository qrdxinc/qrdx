Alla fine di questa pagina avrai un QR code con stile disegnato in una semplice pagina HTML, aggiornato dal tuo codice e salvato come PNG, con un bundler o con un solo tag script. `qrdx/vanilla` è lo stesso motore con cui disegnano i componenti React, quindi produce lo stesso SVG, con ogni pattern, colore, logo, cornice ed esportazione, e non importa né `react` né `react-dom`.

<NpmStatus package="qrdx" />

## Prima di iniziare [#before-you-start]

- Una pagina con un bundler (Vite, webpack, Parcel o qualsiasi altro) per i passaggi da 1 a 3. Senza bundler, passa al [passaggio 4](#4-use-it-without-a-bundler).
- Node.js 18 o successivo per il bundler.

## Realizzalo [#build-it]

### 1. Installa qrdx [#1-install-qrdx]

```package-install
qrdx
```

`react` e `react-dom` sono peer dependency opzionali. Non ti servono per `qrdx/vanilla` o `qrdx/core`.

### 2. Disegna un codice in un elemento [#2-draw-a-code-into-an-element]

```html title="index.html"
<div id="qr"></div>
<script type="module" src="/main.js"></script>
```

```js title="main.js"
import { createQRCode } from "qrdx/vanilla";

const qr = createQRCode("#qr", {
  value: "https://example.com/menu",
  size: 256,
  margin: 4,
  bodyPattern: "rounded",
  frame: { style: "banner-bottom", text: "Scan for the menu" },
  "aria-label": "QR code for the menu",
});
```

Dentro `#qr` compare un `<svg>`: un codice da 256 px con moduli arrotondati e un banner sotto. `createQRCode(element, options)` accetta un elemento o un selettore CSS, e ogni opzione accettata dal `QRCodeSVG` di React: pattern, colori e gradienti, loghi (`imageSettings`), cornici, forme, template e grafiche. Attributi come `className`, `style` o `aria-label` vanno sull'`<svg>`. L'elemento viene costruito con `createElementNS`, quindi non viene analizzato alcun HTML.

### 3. Aggiornalo, esportalo e rimuovilo [#3-update-export-and-remove-it]

```js title="main.js"
qr.update({ fgColor: "#1d4ed8" }); // redraws the code in place, now blue

qr.toSVGString(); // '<svg xmlns="http://www.w3.org/2000/svg" …'
await qr.toDataURL("png", { size: 1024 }); // "data:image/png;base64,…"
await qr.download({ format: "png", size: 1024, filename: "menu.png" });

qr.destroy(); // removes the <svg>
```

- `update` unisce le nuove opzioni a quelle attuali e ridisegna. Passa `undefined` per eliminare un'opzione. Se il markup non cambia, la pagina non viene toccata.
- `toDataURL` e `download` usano per impostazione predefinita il PNG alla `size` del codice. I formati sono `png`, `jpg`, `webp`, `svg`, `pdf` e `eps`. Una cornice rende l'immagine più grande del codice. Il PDF richiede il pacchetto opzionale `jspdf`.
- `qr.svg` è l'elemento `<svg>` e `qr.options` sono le opzioni attuali.
- `destroy` rimuove l'`<svg>`. Dopo di esso, `update` genera un errore.

### 4. Usalo senza bundler [#4-use-it-without-a-bundler]

```html title="index.html"
<div id="qr"></div>
<script type="module">
  import { createQRCode } from "https://cdn.jsdelivr.net/npm/qrdx/dist/vanilla.browser.mjs";

  createQRCode("#qr", { value: "https://example.com", size: 256, margin: 4 });
</script>
```

`dist/vanilla.browser.mjs` è la stessa API in un unico modulo ES. Aggiungi `@` e una versione dopo `qrdx` nell'URL per bloccarne una. Lo stesso percorso funziona su unpkg.

Il file non include i dati della libreria di cornici ufficiali, così le pagine che non la usano non la scaricano. Per usare una cornice ufficiale, importala dal file accanto:

```js title="index.html"
import { getOfficialFrame } from "https://cdn.jsdelivr.net/npm/qrdx/dist/frames-official.mjs";

const wifi = getOfficialFrame("wifi-card");
qr.update({ frame: { style: "custom", spec: wifi.spec } });
```

L'esportazione PDF e il punteggio di scansione caricano `jspdf` e `jsqr` quando vengono eseguiti. Una pagina che li usa li mappa entrambi con una import map, posta prima dello script del modulo:

```html title="index.html"
<script type="importmap">
  {
    "imports": {
      "jspdf": "https://cdn.jsdelivr.net/npm/jspdf@4/+esm",
      "jsqr": "https://cdn.jsdelivr.net/npm/jsqr@1/+esm"
    }
  }
</script>
```

## Markup e nodi DOM con qrdx/core [#markup-and-dom-nodes-with-qrdxcore]

`qrdx/core` ha tutto ciò che ha l'entry principale `qrdx`, tranne i componenti React. Funziona in Node e nel browser.

```ts title="code.ts"
import {
  createQRCodeTree,
  renderToDOM,
  renderToString,
  resolveQRCodeProps,
  toSVGElement,
  toSVGString,
} from "qrdx/core";

// What <QRCodeSVG> renders, as a string (no DOM needed)
const svg = toSVGString({ value: "https://example.com", size: 256 });

// The same code as an <svg> element
document.body.append(toSVGElement({ value: "https://example.com" }));

// The code as plain { type, props, key } nodes, then markup or DOM nodes
const tree = createQRCodeTree({ value: "https://example.com" });
renderToString(tree);
renderToDOM(tree);

// <QRCode>'s logo API (logo, logoOptions, hideLogo, scale)
toSVGString(resolveQRCodeProps({ value: "https://example.com", logo: "/logo.png" }));
```

L'output non ha id casuali, quindi il markup renderizzato su un server coincide con quello del browser. I download, il punteggio di scansione e i PDF e EPS pronti per la stampa provengono dalle stesse funzioni della libreria React: `downloadQRCode`, `getQRCodeDataUrl`, `getScanScore`, `downloadPrintPDF` e le altre. Per il PNG su un server, usa `getQRAsPNG` da `qrdx/node`.

## Template personalizzati senza JSX [#custom-templates-without-jsx]

Il `wrapper` di un template riceve il codice disegnato e lo restituisce avvolto. `h(type, props, ...children)` ne scrive uno senza JSX:

```js title="labelled-template.js"
import { h, toSVGString } from "qrdx/core";

const Labelled = {
  id: "Labelled",
  name: "Labelled",
  wrapper: (children, props) =>
    h(
      "svg",
      { viewBox: "0 0 300 340", xmlns: "http://www.w3.org/2000/svg" },
      h("g", { transform: "translate(20, 20) scale(0.87)" }, children),
      h("text", { x: "150", y: "325", textAnchor: "middle" }, props?.label)
    ),
};

toSVGString({
  value: "https://example.com",
  customTemplate: Labelled,
  customProps: { label: "Scan me" },
});
```

Lo stesso wrapper funziona nei componenti React se importi `h` da `qrdx`.

## Se qualcosa va storto [#if-something-goes-wrong]

- **`qrdx: no element matches #qr`.** Lo script è stato eseguito prima che l'elemento esistesse. Metti lo `<script type="module">` dopo l'elemento, oppure attendi `DOMContentLoaded`.
- **`qrdx: this QR code was destroyed`.** Hai chiamato `update` dopo `destroy`. Crea un nuovo codice con `createQRCode`.
- **`PDF export needs the optional "jspdf" package`.** Installa `jspdf` accanto a `qrdx`, oppure aggiungilo alla import map in una pagina senza bundler.
- **Il codice viene disegnato ma un telefono non lo legge.** Aggiungi `margin: 4`, mantieni moduli scuri su sfondo chiaro e controlla il design con `getScanScore`. Vedi [Un codice non si scansiona](/docs/help/troubleshooting/wont-scan).
