이 페이지를 끝내면 Angular 컴포넌트 안에 시그널에 바인딩된 스타일 QR 코드가 생기고, 이를 SVG로 저장하는 버튼도 갖게 됩니다. `qrdx/angular`는 독립형 컴포넌트 `<qrdx-qr-code>`이며, React 컴포넌트와 같은 엔진을 기반으로 합니다. React `<QRCode>`의 props를 시그널 입력으로 받고 동일한 SVG를 그립니다. `@angular/ssr`로 서버에서 렌더링되며 오류 없이 하이드레이션됩니다.

<NpmStatus package="qrdx" />

## 시작하기 전에 [#before-you-start]

- Angular CLI로 만든 Angular 20 이상 프로젝트가 필요합니다. 프로덕션 빌드와 `ng serve` 모두 동작합니다.
- Node.js 18 이상이 필요합니다.

## 만들어 보기 [#build-it]

### 1. qrdx 설치 [#1-install-qrdx]

```package-install
qrdx
```

`@angular/core`는 `qrdx`의 선택적 peer dependency입니다. 그래서 설치해도 Angular를 쓰지 않는 앱에는 Angular가 추가되지 않으며, 여러분의 앱에 React가 추가되는 일도 없습니다.

### 2. 코드 그리기 [#2-draw-a-code]

`QRCode`를 가져와 컴포넌트의 `imports`에 추가하세요. NgModule은 필요 없습니다.

```ts title="src/app/app.ts"
import { Component, signal } from "@angular/core";
import { QRCode, type QRCodeProps } from "qrdx/angular";

@Component({
  selector: "app-root",
  imports: [QRCode],
  template: `
    <qrdx-qr-code
      [value]="url()"
      [size]="240"
      [margin]="4"
      level="Q"
      bodyPattern="rounded"
      [fgColor]="fgColor"
      [frame]="{ style: 'banner-bottom', text: 'Scan me' }"
      aria-label="QR code for example.com"
    />
  `,
})
export class App {
  protected readonly url = signal("https://example.com");
  protected readonly fgColor: QRCodeProps["fgColor"] = {
    type: "linear",
    angle: 45,
    stops: [
      { color: "#1d4ed8", offset: 0 },
      { color: "#0f172a", offset: 100 },
    ],
  };
}
```

`ng serve`를 실행하면 둥근 모듈, 파랑에서 남색으로 이어지는 그라데이션, "Scan me" 배너가 있는 240 px 코드가 표시됩니다. `url`을 다른 링크로 바꾸면 코드가 다시 그려집니다. 변경해도 마크업이 같으면 페이지는 건드리지 않습니다.

### 3. 파일로 저장하기 [#3-save-it-as-a-file]

이 컴포넌트는 `qrdx/vanilla`처럼 자신이 그린 코드를 다운로드하고 내보낼 수 있습니다. 템플릿 참조 변수나 `viewChild(QRCode)`로 접근하세요.

```html title="src/app/app.html"
<qrdx-qr-code #qr value="https://example.com" [size]="256" [margin]="4" />
<button type="button" (click)="qr.download({ format: 'svg', filename: 'qr-code.svg' })">
  Download SVG
</button>
```

버튼을 클릭하면 `qr-code.svg`가 저장됩니다.

- `download({ format, size, filename, quality })`는 파일을 저장합니다. 기본값은 PNG이며, `"jpg"`, `"webp"`, `"svg"`, `"pdf"`, `"eps"`도 사용할 수 있습니다. PDF에는 선택 패키지인 `jspdf`가 필요합니다.
- `toDataURL(format, { size, quality })`는 코드를 데이터 URL로 반환합니다.
- `markup()`은 SVG 마크업, `options()`는 코드를 그릴 때 사용한 props, `svg`는 `<svg>` 요소입니다.

`qrdx/core`의 모든 내보내기는 `qrdx/angular`에서도 내보내므로, `toSVGString`, `downloadQRCode`, `getScanScore` 등을 같은 import에서 가져올 수 있습니다.

## 입력 [#inputs]

React `<QRCode>`의 모든 prop은 같은 이름과 타입의 입력으로 제공되며, Angular는 템플릿을 컴파일할 때 바인딩을 이에 맞춰 검사합니다. `value`는 필수입니다.

| 입력 | 기능 |
| --- | --- |
| `value`, `size`, `level`, `margin`, `autoLevel` | 콘텐츠, 픽셀 크기, 오류 정정, 여백(quiet zone), 큰 로고를 위한 레벨 상향 |
| `fgColor`, `bgColor`, `eyeColor`, `dotColor`, `eyeColors` | 색상, 그라데이션, 이미지 채우기 |
| `bodyPattern`, `cornerEyePattern`, `cornerEyeDotPattern`, `moduleScale` | 점과 눈 모양 |
| `logo`, `logoOptions`, `hideLogo`, `scale` | 가운데 로고, `<QRCode>`와 같은 방식으로 배치 |
| `frame`, `shape`, `art` | 행동 유도 문구가 있는 프레임, 원과 하트 윤곽, Logo QR, Image QR |
| `templateId`, `customTemplate`, `customProps` | 템플릿 |
| `frameLabelMarkers`, `partMarkers` | 에디터의 실시간 미리보기용 마커 |
| `svgStyle` | `<svg>`에 적용할 인라인 스타일(`QRCode`의 `style`) |

`style` 대신 `svgStyle`이라는 이름을 쓰는 이유는, `style`이라는 입력이 요소 자체의 `style` 속성을 가로채기 때문입니다. `<qrdx-qr-code>`에 지정한 `class`, `style`, `aria-label` 같은 속성은 그 요소에 그대로 남으며, `<svg>`는 그 안에 있습니다.

컴포넌트의 자체 스타일은 `<svg>`에 적용되지 않습니다. Angular가 스타일을 템플릿 안의 요소로만 한정하기 때문입니다. 코드가 컨테이너를 가득 채우게 하려면 `svgStyle`을 사용하세요.

```html title="src/app/app.html"
<qrdx-qr-code value="https://example.com" [svgStyle]="{ width: '100%', height: 'auto' }" />
```

## 서버 렌더링과 하이드레이션 [#server-rendering-and-hydration]

`@angular/ssr`를 사용하면 서버가 보내는 HTML에 이미 코드가 들어 있어서, 앱이 로드되기 전에도 코드가 표시됩니다. 브라우저에서 Angular가 페이지를 하이드레이션하며 `<qrdx-qr-code>` 요소를 그대로 유지하고, 컴포넌트는 서버와 동일한 코드를 다시 그립니다. `ngSkipHydration`은 필요하지 않습니다.

출력에는 무작위 id가 없으므로 서버와 브라우저가 같은 마크업을 그립니다.

## 문제가 생기면 [#if-something-goes-wrong]

- **`NG8001: 'qrdx-qr-code' is not a known element`.** 컴포넌트의 `imports` 배열에 `QRCode`가 빠져 있습니다. 2단계처럼 추가하세요.
- **컴포넌트의 `svg` CSS 규칙이 적용되지 않습니다.** Angular는 스타일을 사용자 템플릿으로 한정합니다. `svgStyle` 입력을 사용하거나 전역 스타일시트에 규칙을 넣으세요.
- **`PDF export needs the optional "jspdf" package`.** 앱에서 `npm install jspdf`를 실행하세요.
