Halaman ini mencantumkan apa saja yang diekspor oleh `qrdx`, berdasarkan titik masuk dan tugas, lengkap dengan tipe dan nilai default setiap prop. Halaman fitur menjelaskan cara menggunakannya; halaman ini untuk mencari nama tertentu.

## Titik masuk [#entry-points]

| Impor dari | Isinya | Membutuhkan |
| --- | --- | --- |
| `qrdx` | Komponen React (`QRCode`, `QRCodeSVG`, `QRCodeCanvas`, `getQRAsSVG`) beserta semua isi `qrdx/core` | `react`, `react-dom` |
| `qrdx/core` | Seluruh mesin tanpa React: markup, unduhan, file cetak, skor pemindaian, bingkai, templat, seni, dan tipe | Tidak ada |
| `qrdx/vanilla` | `createQRCode`, ditambah `qrdx/core` | DOM |
| `qrdx/element` | Elemen kustom `<qrdx-code>`: `QRdxCodeElement`, `defineQRdxCode`, `toQRdxCodeHTML` | DOM untuk menggambar; tidak perlu apa pun untuk merender markup |
| `qrdx/element/define` | Mendaftarkan `<qrdx-code>` saat diimpor | DOM |
| `qrdx/node` | `getQRAsPNG` | `@resvg/resvg-js` atau `sharp` |
| `qrdx/vue` | `QRCode`, `QRCodeSVG`, `useQRCode`, ditambah `qrdx/core` | `vue` 3.3 atau lebih baru |
| `qrdx/preact` | `QRCode`, `QRCodeSVG` | `preact` 10 atau lebih baru |
| `qrdx/solid` | `QRCode`, `QRCodeSVG` | `solid-js` 1.8 atau lebih baru |
| `qrdx/angular` | Komponen `QRCode` (`<qrdx-qr-code>`), ditambah `qrdx/core` | `@angular/core` 20 atau lebih baru |
| `qrdx/types` | Semua tipe, daftar opsi, dan skema zod, tanpa perender | Tidak ada |

Setiap paket framework adalah peer dependency opsional: memasang `qrdx` tidak pernah menambahkan paket yang tidak Anda gunakan. `jspdf` juga opsional, untuk PDF.

## Komponen [#components]

### QRCode [#qrcode]

Komponen untuk sebagian besar kebutuhan. `QRProps` ditambah API logo sederhana, dirender sebagai `<svg>`. Komponen ini tidak memakai hook khusus browser, sehingga dapat dirender di React Server Components.

```tsx title="components/example.tsx"
import { QRCode } from "qrdx";

<QRCode value="https://example.com" size={256} margin={4} level="H" logo="/logo.png" />;
```

| Prop | Tipe | Default | Fungsinya |
| --- | --- | --- | --- |
| `value` | `string` | wajib | Teks atau URL yang di-encode, persis seperti yang diberikan |
| `size` | `number` | `128` | Lebar dan tinggi dalam piksel. Bingkai menambah ukuran ini; templat muat di dalamnya |
| `scale` | `number` | `1` | Mengalikan `size` |
| `level` | `"L" \| "M" \| "Q" \| "H"` | `"Q"` | Koreksi kesalahan: sekitar 7%, 15%, 25%, atau 30% dari kode boleh rusak |
| `margin` | `number` | `0` | Zona tenang di sekeliling kode, dalam modul. Standar mensyaratkan 4 |
| `fgColor` | `ColorConfig` | `"#000000"` | Warna modul data: warna CSS, gradien, atau isian gambar |
| `bgColor` | `ColorConfig` | `"#FFFFFF"` | Latar belakang. `"transparent"` berarti tanpa latar |
| `eyeColor` | `ColorConfig` | `fgColor` | Warna ketiga mata sudut |
| `dotColor` | `ColorConfig` | `fgColor` | Warna titik di dalam setiap mata |
| `eyeColors` | `EyeColors` | tidak ada | Warna `outer` dan `inner` per mata untuk `topLeft`, `topRight`, dan `bottomLeft`; masing-masing menimpa `eyeColor` dan `dotColor` |
| `bodyPattern` | `BodyPattern` | `"circle"` | Bentuk modul data, salah satu dari {facts.bodyPatterns} |
| `cornerEyePattern` | `CornerEyePattern` | `"gear"` | Bentuk mata sudut, salah satu dari {facts.eyeShapes} |
| `cornerEyeDotPattern` | `CornerEyeDotPattern` | `"circle"` | Bentuk titik mata, salah satu dari {facts.eyeCentres} |
| `moduleScale` | `number` | `1` | Ukuran setiap modul data, 0,5 sampai 1. Setiap pola berhenti pada ukuran terkecil yang masih dapat dipindai (`MODULE_SCALE_FLOOR`) |
| `logo` | `string` | tidak ada | Path, URL, atau data URL yang digambar di tengah, dengan modul di belakangnya dikosongkan. Tanpa prop ini, logo tidak digambar |
| `logoOptions` | `LogoOptions` | tidak ada | `size` logo (0,1 sampai 0,3, default 0,25), `padding` (0 sampai 2 modul), `x` dan `y` (0 sampai 1), `shape`, dan `plate` |
| `hideLogo` | `boolean` | `false` | Menyembunyikan logo meskipun `logo` diatur |
| `autoLevel` | `boolean` | `false` | Menaikkan `level` ke `H` ketika logo menutupi lebih dari 7% kode (`AUTO_LEVEL_LOGO_COVERAGE`) |
| `frame` | `AnyQRFrame` | tidak ada | Bingkai ajakan bertindak: `{ style, text, color, textColor, secondaryText, secondaryColor, fontScale }`, atau `{ style: "custom", spec }`. Ukuran output bertambah agar muat |
| `templateId` | `string` | tidak ada | Templat yang digambar pada `size` dengan kode di dalamnya: `"Arrow"`, `"StandardBox"`, `"SquareBorder"`, `"StrikedBox"`, `"Halloween"`, `"DotRing"`, atau `"default"` |
| `customTemplate` | `TemplateDefinition` | tidak ada | Templat yang Anda gambar lewat kode. Lebih diutamakan daripada `templateId` |
| `customProps` | `Record<string, any>` | tidak ada | Prop untuk `wrapper` templat, seperti `DotRingProps` |
| `shape` | `"square" \| "circle" \| "heart" \| QRSilhouette` | `"square"` | Menempatkan kode di dalam cakram, hati, atau siluet buatan Anda yang diisi modul dekoratif |
| `art` | `QRArt` | tidak ada | Memadukan gambar ke dalam modul: `{ mode, image, intensity, variant, matchEyes }` |
| `style` | `CSSProperties` | tidak ada | Gaya inline untuk `<svg>` |
| `frameLabelMarkers` | `boolean` | `false` | Untuk editor: menandai setiap `<text>` label bingkai dengan `data-qrdx-frame-label`. Hasil ekspor tidak pernah menyertakannya |
| `partMarkers` | `boolean` | `false` | Untuk editor: menandai bagian yang digambar dengan `data-qrdx-part`. Hasil ekspor tidak pernah menyertakannya |
| `isOGContext` | `boolean` | `false` | Menggambar logo sebagai `<img>` berposisi untuk perender gambar Open Graph |

`QRCode` hanya menerima prop ini; prop lainnya akan dibuang. `QRCodeSVG` menempatkan prop lain (`className`, `aria-label`, `role`, `data-*`, …) pada `<svg>`, atau pada `<svg>` terluar bingkai bila ada bingkai. Event handler tidak disertakan dalam markup.

### QRCodeSVG [#qrcodesvg]

`QRProps` ditambah atribut SVG React (`QRPropsSVG`): prop yang sama dengan `QRCode` tanpa `logo`, `logoOptions`, `hideLogo`, dan `scale`. Logo diatur lewat `imageSettings`, dalam piksel:

| Field | Tipe | Default | Fungsinya |
| --- | --- | --- | --- |
| `src` | `string` | wajib | Gambar, berupa URL atau data URL |
| `width`, `height` | `number` | wajib | Ukuran dalam piksel yang sama dengan `size` |
| `excavate` | `boolean` | wajib | Mengosongkan modul di belakang gambar |
| `x`, `y` | `number` | di tengah | Sudut kiri atas gambar |
| `padding` | `number` | `0` | Ruang kosong tambahan di sekeliling gambar, dalam piksel, saat modul dikosongkan |
| `shape` | `"square" \| "rounded" \| "circle"` | `"square"` | Memangkas gambar |
| `plate` | `string` | tidak ada | Pelat solid di belakang gambar, mengikuti bentuknya |

Logo yang lebih besar dari yang dapat dipulihkan kode akan dikecilkan di sekitar titik tengahnya (`capImageSettings`, dengan anggaran yang sama seperti `QRCode`).

### QRCodeCanvas [#qrcodecanvas]

`QRProps` ditambah atribut canvas React (`QRPropsCanvas`), digambar pada `<canvas>` dengan rasio piksel perangkat. Komponen ini menggambar modul persegi polos dengan warna solid: gradien akan kembali ke titik warna pertamanya, dan prop pola, warna mata, `eyeColors`, `moduleScale`, `art`, serta templat diabaikan. Komponen ini dikirim dengan `"use client"`.

### getQRAsSVG [#getqrassvg]

`getQRAsSVG(props: QRPropsSVG): Promise<JSX.Element>` mengembalikan kode sebagai elemen React dengan logo yang disematkan sebagai data URL. Untuk string, gunakan `toSVGString` atau `getSVGString`.

| Fungsi | Mengembalikan | Catatan |
| --- | --- | --- |
| `downloadQRCode(props, { format, size, filename?, quality? })` | `Promise<void>` | Menyimpan file. `size` berkisar 50 hingga 5000 px dan berbentuk persegi; nama file bawaan mencantumkan ukuran piksel untuk format raster |
| `getQRCodeDataUrl(props, format, size, { quality? })` | `Promise<string>` | File yang sama sebagai data URL |
| `getQRAsWebP(props, { quality? })` | `Promise<Blob>` | Lossless kecuali `quality` diatur; melakukan encoding sendiri jika browser tidak mampu |
| `copyQRCodeToClipboard(props, size?)` | `Promise<void>` | PNG di clipboard. Panggil dari gestur pengguna |
| `getSVGString(props)` | `Promise<string>` | Markup SVG dengan logo yang disematkan |
| `toSVGString(props)` | `string` | Markup SVG, sinkron, tanpa penyematan logo. Berjalan di mana saja |
| `toSVGElement(props, document?)` | `SVGSVGElement` | Kode sebagai elemen DOM |
| `getQRAsSVGDataUri(props)` | `Promise<string>` | `data:image/svg+xml,…`, langkah pertama dari setiap ekspor |
| `getQRAsCanvas(props, mimeType, getCanvas?)` | `Promise<string \| HTMLCanvasElement>` | Data URL, atau canvas itu sendiri dengan `getCanvas` |
| `getQRAsPNG(props, { size?, loadExternalLogos? })` | `Promise<Uint8Array>` | Byte PNG di Node, dari `qrdx/node`. Memerlukan `@resvg/resvg-js` atau `sharp` |
| `validateSize(width, height)` | `{ isValid, error? }` | Aturan ukuran yang diterapkan `downloadQRCode` |
| `getDownloadFilename(format, size, frame?)` | `string` | Nama file bawaan |
| `withQRSize(props, size)` | `QRProps` | Props yang digambar pada `size`, dengan logo piksel yang ikut diskalakan |
| `canvasToWebP(canvas, { quality? })`, `blobToDataUrl(blob)`, `encodeWebPLossless(rgba, width, height)` | | Helper WebP |

Konstanta: `DownloadFormat` adalah `"png" \| "jpg" \| "webp" \| "svg" \| "pdf" \| "eps"`; `DOWNLOAD_FORMATS` memetakan masing-masing ke tipe MIME dan ekstensinya; `PRESET_SIZES` berisi `small` (200), `medium` (400), `large` (800), `xlarge` (1200), `2xl` (1600) dan `3xl` (2000); `DEFAULT_SIZE` adalah 128.

## Cetak dan EPS [#print-and-eps]

| Fungsi | Mengembalikan | Catatan |
| --- | --- | --- |
| `getPrintLayout(props, { size, unit?, bleed?, cropMarks?, colorMode? })` | `PrintLayout` | Ukuran fisik dalam mm: `codeWidth`, `trimWidth`, `trimHeight`, `bleed`, `pageWidth`, `pageHeight`, `moduleSize`, `moduleCount`, `maxScanDistance`. `size` berkisar 5 mm hingga 2 m |
| `getQRAsPrintPDF(props, options)` | `Promise<string>` | PDF vektor sebagai data URL. Memerlukan `jspdf` |
| `getQRAsPrintPDFBuffer(props, options)` | `Promise<ArrayBuffer>` | PDF yang sama sebagai byte, untuk Node |
| `getQRAsPrintSVG(props, { size, unit? })` | `Promise<string>` | SVG dengan `width` dan `height` dalam mm atau in |
| `downloadPrintPDF(props, options & { filename? })`, `downloadPrintSVG(props, options & { filename? })` | `Promise<void>` | Unduhan browser untuk keduanya |
| `getQRAsEPS(props, { sizeMm?, bleedMm?, colorMode? })` | `Promise<string>` | Teks EPSF-3.0. Melempar `EPS_IMAGE_FILL_REASON` untuk isian gambar |
| `downloadPrintEPS(props, options & { filename? })` | `Promise<void>` | Unduhan browser |
| `svgToEPS(svg, { width?, colorMode?, bleed?, bleedColor?, title? })` | `Promise<string>` | Mengonversi SVG apa pun yang dirender pustaka |
| `epsToDataUrl(eps)`, `hasImageFill(props)`, `rgbToCmyk(color)`, `getQRModuleCount(props)` | | Helper |

`PrintOptions`: `size` (angka), `unit` (`"mm"` atau `"in"`, bawaan `"mm"`), `bleed` (mm, 0 hingga 20), `cropMarks` (boolean), `colorMode` (`"rgb"` atau `"cmyk"`).

## Skor pemindaian dan deteksi [#scan-score-and-detection]

| Fungsi | Mengembalikan | Catatan |
| --- | --- | --- |
| `getScanScore(props, { sizes?, signal? })` | `Promise<ScanScoreResult>` | `{ score, grade, checks }`. Hanya di browser; memuat jsQR sesuai kebutuhan. Ukuran bawaan 96, 160 dan 320 px (`SCAN_TEST_SIZES`) |
| `getImageScanScore(imageOrBlob, options?)` | `Promise<ImageScanScoreResult>` | Hal yang sama untuk gambar yang sudah ada, ditambah `data` dan `version`. Hanya di browser |
| `getScanScoreFromPixels(pixels, options?)` | `Promise<ImageScanScoreResult>` | Skor gambar pada piksel RGBA, di Node |
| `scanQRPixels(pixels, expected, { sizes? })` | `Promise<PixelScanResult>` | Memeriksa apakah piksel terdekode menjadi `expected`, apa adanya maupun melalui model kamera. Node |
| `getScanContrast(props)` | `{ ratio, required, inverted }` | Pemeriksaan kontras saja |
| `getStylePairRisk(props)` | `StylePairRisk \| null` | Pasangan bentuk yang terlewat oleh sebagian pemindai, dengan `fix` |
| `handleImageLoad(img, size, returnFullData?)` | `Promise<string \| QRCode \| "NO_QR">` | Mendekode kode QR dari `<img>`. Lihat [Deteksi QR](/docs/qr-detection) |
| `downloadImageWithBoundingBox(img, corners, filename)` | `void` | Menyimpan gambar dengan kode yang ditemukan diberi garis tepi |

Grade-nya adalah `"great"`, `"ok"`, `"risky"` dan `"fails"`. Setiap pemeriksaan berbentuk `{ id, passed, message, fix?, skipped? }`. Batas kontras: `SCAN_CONTRAST_MIN` 4.5, `SCAN_CONTRAST_LOW` 3, `SCAN_CONTRAST_FAIL` 1.5, dan `SCAN_IMAGE_CONTRAST_MIN` 7 untuk gambar di dalam kode dan 12 untuk gambar di belakangnya. Pasangan lemah tersedia sebagai `WEAK_BODY_EYES`, `WEAK_DOT_EYES`, `WEAK_SHARP_DOT_EYES`, `SHARP_DOT_EYE_SAFE_BODIES`, `WEAK_EYES` dan `WEAK_DOTS`.

## Tipe dan daftar opsi [#types-and-option-lists]

Tipe di bawah ini berasal dari `qrdx`, `qrdx/core`, dan `qrdx/types`. Daftar opsinya berupa array biasa; skema zod (`qrPropsSchema`, `frameSchema`, `frameSpecSchema`, `colorConfigSchema`, `qrArtSchema`, `logoOptionsSchema`, `imageSettingsSchema`, dan lainnya) dibangun dari daftar tersebut.

| Tipe | Bentuk |
| --- | --- |
| `QRProps` | Tabel props di atas, tanpa API logo |
| `QRCodeProps` | `QRProps` ditambah `logo`, `logoOptions`, `hideLogo`, `scale` |
| `QRSVGOptions` | `QRProps` ditambah atribut root apa pun: yang digambar oleh core |
| `ColorConfig` | `string \| SolidColor \| LinearGradient \| RadialGradient \| AngularGradient \| ImagePaint` |
| `LinearGradient` | `{ type: "linear", stops, angle? }`; `angle` dalam derajat, default 0 |
| `RadialGradient` | `{ type: "radial", stops }` |
| `AngularGradient` | `{ type: "angular", stops, angle? }` |
| `GradientStop` | `{ color, offset }`; `offset` 0 sampai 100 |
| `ImagePaint` | `{ type: "image", src, fit?, scale?, position?, opacity?, underlay? }` |
| `ImageSettings`, `LogoOptions`, `EyeColors` | Seperti pada tabel di atas |
| `QRFrame` | `{ style: FrameStyle, text?, color?, textColor?, secondaryText?, secondaryColor?, fontScale? }` |
| `QRCustomFrame`, `AnyQRFrame`, `FrameSpec` | `{ style: "custom", spec, ...labels and colors }`, tipe union, dan format spec |
| `QRArt`, `QRArtImage` | `{ mode, image, intensity?, variant?, matchEyes? }` dan `{ width, height, data }` |
| `QRCodeShape`, `QRSilhouette` | `"square" \| "circle" \| "heart"` atau `{ type: "silhouette", width, height, cells }` |
| `TemplateDefinition`, `BaseTemplateProps`, `TemplateConfig` | Templat |
| `DownloadFormat`, `DownloadSize`, `DownloadOptions`, `PrintOptions`, `PrintLayout`, `EPSOptions` | Ekspor |
| `ScanScoreResult`, `ImageScanScoreResult`, `ScanCheck`, `ScanGrade`, `StylePairRisk` | Skor pemindaian |
| `BodyPattern`, `CornerEyePattern`, `CornerEyeDotPattern`, `FrameStyle`, `ErrorLevel` | Union opsi |

Daftar opsi: `BODY_PATTERN`, `CORNER_EYE_PATTERNS`, `CORNER_EYE_DOT_PATTERNS`, `FRAME_STYLES`, `QR_SHAPES`, `LOGO_SHAPES`, `EYE_POSITIONS`. Nilai yang sudah dihentikan tetapi masih dirender untuk desain tersimpan: `RETIRED_CORNER_EYE_PATTERNS` (`curly`) dan `RETIRED_CORNER_EYE_DOT_PATTERNS` (`diamond`, `star`, `banner`).

## Tempat fungsi berjalan [#where-things-run]

- **Di mana saja, tanpa DOM:** `toSVGString`, `createQRCodeTree`, `renderToString`, `getQRData`, helper frame dan templat, `createQRArtImage`, `createQRSilhouette`, `getPrintLayout`, `getQRAsEPS`, `getQRAsPrintPDFBuffer`, `scanQRPixels`, `toQRdxCodeHTML`.
- **Browser:** `downloadQRCode` dan unduhan lainnya, `copyQRCodeToClipboard`, `getQRAsCanvas`, `getScanScore`, `getImageScanScore`, `handleImageLoad`, `loadQRArtImage`, `loadQRSilhouette`, `removeLogoBackground`, `createQRCode`, custom element.
- **Hanya Node:** `getQRAsPNG` dari `qrdx/node`.
- **React Server Components:** `QRCode`, `QRCodeSVG`, dan semua yang tidak memerlukan DOM. `QRCodeCanvas` adalah Client Component.
