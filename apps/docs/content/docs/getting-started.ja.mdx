このページを終えると、Reactコンポーネントで表示したスタイル付きQRコードと、それをSVGとして保存するボタンが完成します。コードの描画はライブラリ自身が行うため、アカウントもAPIキーも必要ありません。

<NpmStatus package="qrdx" />

## はじめる前に [#before-you-start]

- React 18以降のReactアプリ。Next.js、Vite、Remixなど、どれでも動作します。
- Node.js 18以降。

コードを書く前にオプションを確認したい場合は、[Playground](/playground?open=code&lang=react)でQRコードをスタイルし、Reactコンポーネントとしてコピーしてください。

## 作成する [#build-it]

### 1. qrdxをインストールする [#1-install-qrdx]

```package-install
qrdx
```

`react`と`react-dom`はピア依存関係のため、パッケージはアプリがすでに使っているバージョンを利用します。ほかには何もインストールされません。PDFエクスポートにはオプションの`jspdf`パッケージが必要ですが、PDFを使う場合のみです。

### 2. コードを表示する [#2-render-a-code]

```tsx title="components/first-qr-code.tsx"
import { QRCode } from "qrdx";

export function FirstQrCode() {
  return <QRCode value="https://example.com" size={256} />;
}
```

コンポーネントをページに配置します。ライブラリのデフォルトの見た目で、256 pxのコードが表示されます。モジュールは丸型、コーナーアイは歯車型、色は白地に黒です。スマートフォンのカメラを画面に向けると、example.comが開きます。

<Shot id="lib-first-code" />

`QRCode`は`<svg>`を描画し、ブラウザ専用のフックを使いません。そのため、React Server Componentsでも動作し、JavaScriptが実行される前のページのHTMLに描画されます。ただし、これだけではスクリーンリーダーには何も伝わりません。ラベルの付け方はステップ3で説明します。

### 3. スタイルを設定する [#3-style-it]

```tsx title="components/styled-qr-code.tsx"
import { QRCode } from "qrdx";

export function StyledQrCode() {
  return (
    <QRCode
      value="https://example.com/menu"
      size={256}
      margin={4}
      fgColor="#1d4ed8"
      bodyPattern="rounded"
      cornerEyePattern="extra-rounded"
      cornerEyeDotPattern="rounded"
      frame={{ style: "banner-bottom", text: "Scan for the menu" }}
    />
  );
}
```

コードは青色で丸型のモジュールになり、その下に「Scan for the menu」というバナーが表示されます。出力が256 pxより大きくなるのは、フレームがコードの上に描画されるのではなくコードの周囲に追加されるためで、コードは問題なくスキャンできます。

<Shot id="lib-styled-code" />

各propの役割は次のとおりです。

- `margin`はコードの周囲のクワイエットゾーンで、モジュール単位で指定します。デフォルトは0で、独自のパディングを持つカード内のコードに適しています。背景が複雑な場合や暗い場合は4を使ってください。
- `fgColor`には、任意のCSSカラーまたはグラデーションを指定できます。`bgColor`、`eyeColor`、`dotColor`も同様です。
- `bodyPattern`、`cornerEyePattern`、`cornerEyeDotPattern`は、モジュール、コーナーアイ、その内側のドットの形を決めます。ボディパターンは{facts.bodyPatterns}種類、アイの形は{facts.eyeShapes}種類、アイの中心は{facts.eyeCentres}種類あり、すべて[形、アイ、フレーム](/docs/styles)でリアルタイムに描画されています。
- `frame`は、組み込みのコールトゥアクションフレーム{facts.frameStyles}種類のいずれか、または独自のフレームを追加します。
- `QRCode`が受け取るのはコード自身のpropsと`style`だけです。コードにアクセシブルな名前やクラスを付けるには、要素で囲む(`<div role="img" aria-label="QR code for the menu">`)か、`<svg>`に`aria-label`、`className`、その他の属性を付けられる`QRCodeSVG`を使ってください。

### 4. ファイルとして保存する [#4-save-it-as-a-file]

```tsx title="components/download-svg-button.tsx"
"use client";

import { downloadQRCode } from "qrdx";

const menuCode = {
  value: "https://example.com/menu",
  margin: 4,
  fgColor: "#1d4ed8",
  bodyPattern: "rounded",
  frame: { style: "banner-bottom", text: "Scan for the menu" },
} as const;

export function DownloadSvgButton() {
  return (
    <button
      type="button"
      onClick={() =>
        downloadQRCode(menuCode, {
          format: "svg",
          size: { width: 1024, height: 1024 },
          filename: "menu.svg",
        })
      }
    >
      Download SVG
    </button>
  );
}
```

ボタンをクリックすると`menu.svg`が保存されます。画面上と同じコードを1024 pxで描画したもので、どんなサイズでも鮮明です。印刷会社から求められるのもこの形式のファイルです。画像にするには`format`を`png`、`jpg`、`webp`に、デザインツール向けのベクターファイルにするには`eps`に、`pdf`にするとPDFになります(オプションの`jspdf`パッケージが必要です)。

`downloadQRCode`はブラウザのDOMを使うため、ボタンはClient Componentに置きます。Server Componentからそれを表示することは可能です。上の例のように、コードのオプションを1つのオブジェクトにまとめておくと、ファイルがプレビューと一致します。

### 5. スキャンできるか確認する [#5-check-that-it-scans]

印刷する前に、2〜3台のスマートフォンでコードをスキャンしてください。珍しい色やロゴを使ったデザインの場合は、`getScanScore`がブラウザ上で同じチェックを実行し、スコア、グレード、修正すべき点を返します。

```tsx title="lib/check-code.ts"
import { getScanScore } from "qrdx";

const { score, grade, checks } = await getScanScore({
  value: "https://example.com/menu",
  fgColor: "#1d4ed8",
  bodyPattern: "rounded",
});
// score: 0 to 100, grade: "great" | "ok" | "risky" | "fails"
// checks: [{ id, passed, message, fix? }]
```

印刷したコードのスクリーンショットや写真を[スキャンチェッカー](/tools/scan-checker)にアップロードすることもできます。

## うまくいかない場合 [#if-something-goes-wrong]

- **`Module not found: Can't resolve 'qrdx'`。** パッケージをインポートしているワークスペースまたはアプリにインストールし、開発サーバーを再起動してください。
- **コードは表示されるのに、スマートフォンで読み取れない。** `margin={4}`を追加し、明るい背景に暗いモジュールを使い、画面上で幅128 px以上で表示してください。そのほかの原因は[QRコードがスキャンできない](/docs/help/troubleshooting/wont-scan)に記載しています。
- **`PDF export needs the optional "jspdf" package`。** 同じパッケージ内で`npm install jspdf`を実行してください。SVG、PNG、JPG、WebP、EPSには追加のものは必要ありません。
