इस पेज के अंत तक आपके पास React कॉम्पोनेंट से रेंडर किया हुआ स्टाइल वाला QR कोड होगा और एक बटन होगा जो उसे SVG के रूप में सेव करता है। लाइब्रेरी कोड खुद ड्रॉ करती है, इसलिए आपको न अकाउंट चाहिए और न API key।

<NpmStatus package="qrdx" />

## शुरू करने से पहले [#before-you-start]

- React 18 या उससे नए वर्शन वाला React ऐप। Next.js, Vite, Remix और बाकी सब काम करते हैं।
- Node.js 18 या उससे नया वर्शन।

कोड लिखने से पहले ऑप्शन देखना चाहते हैं? [playground](/playground?open=code&lang=react) में कोई कोड स्टाइल करें और उसे React कॉम्पोनेंट के रूप में कॉपी करें।

## इसे बनाएँ [#build-it]

### 1. qrdx इंस्टॉल करें [#1-install-qrdx]

```package-install
qrdx
```

`react` और `react-dom` peer dependencies हैं, इसलिए पैकेज वही वर्शन इस्तेमाल करता है जो आपके ऐप में पहले से हैं। और कुछ इंस्टॉल नहीं होता: PDF एक्सपोर्ट के लिए ऑप्शनल `jspdf` पैकेज चाहिए, और वह भी तभी जब आप उसका इस्तेमाल करें।

### 2. कोड रेंडर करें [#2-render-a-code]

```tsx title="components/first-qr-code.tsx"
import { QRCode } from "qrdx";

export function FirstQrCode() {
  return <QRCode value="https://example.com" size={256} />;
}
```

कॉम्पोनेंट को किसी पेज पर रखें। आपको लाइब्रेरी के डिफ़ॉल्ट लुक में 256 px का कोड दिखेगा: गोल मॉड्यूल, गियर के आकार की कॉर्नर आइज़ और सफ़ेद पर काला रंग। फ़ोन का कैमरा स्क्रीन की ओर करें और यह example.com खोल देगा।

<Shot id="lib-first-code" />

`QRCode` एक `<svg>` रेंडर करता है और सिर्फ़ ब्राउज़र में चलने वाले hooks इस्तेमाल नहीं करता, इसलिए यह React Server Components में काम करता है और JavaScript चलने से पहले ही पेज के HTML में रेंडर हो जाता है। स्क्रीन रीडर को यह अपने आप कुछ नहीं बताता: इसे लेबल कैसे करें, यह स्टेप 3 में है।

### 3. स्टाइल करें [#3-style-it]

```tsx title="components/styled-qr-code.tsx"
import { QRCode } from "qrdx";

export function StyledQrCode() {
  return (
    <QRCode
      value="https://example.com/menu"
      size={256}
      margin={4}
      fgColor="#1d4ed8"
      bodyPattern="rounded"
      cornerEyePattern="extra-rounded"
      cornerEyeDotPattern="rounded"
      frame={{ style: "banner-bottom", text: "Scan for the menu" }}
    />
  );
}
```

अब कोड नीले रंग का है और उसके मॉड्यूल गोल हैं, और उसके नीचे एक बैनर पर "Scan for the menu" लिखा है। आउटपुट 256 px से लंबा है, क्योंकि फ़्रेम कोड के ऊपर बनाने के बजाय उसके चारों ओर जोड़ा जाता है, इसलिए कोड फिर भी स्कैन होता है।

<Shot id="lib-styled-code" />

हर prop क्या करता है:

- `margin` कोड के चारों ओर की क्वाइट ज़ोन है, मॉड्यूल में। डिफ़ॉल्ट 0 है, जो अपनी padding वाले कार्ड के अंदर रखे कोड के लिए ठीक है। भीड़-भाड़ वाले या गहरे बैकग्राउंड पर 4 इस्तेमाल करें।
- `fgColor` कोई भी CSS color या ग्रेडिएंट लेता है। `bgColor`, `eyeColor` और `dotColor` भी इसी तरह काम करते हैं।
- `bodyPattern`, `cornerEyePattern` और `cornerEyeDotPattern` मॉड्यूल, कॉर्नर आइज़ और उनके अंदर के डॉट्स का आकार तय करते हैं। {facts.bodyPatterns} बॉडी पैटर्न, {facts.eyeShapes} आई शेप और {facts.eyeCentres} आई सेंटर हैं, जो सब [शेप, आइज़ और फ़्रेम](/docs/styles) में लाइव दिखाए गए हैं।
- `frame` {facts.frameStyles} बिल्ट-इन कॉल-टू-एक्शन फ़्रेम में से एक जोड़ता है, या आपका अपना फ़्रेम।
- `QRCode` सिर्फ़ कोड के अपने props और `style` लेता है, और कुछ नहीं। कोड को accessible नाम या class देने के लिए उसे किसी एलिमेंट में रैप करें (`<div role="img" aria-label="QR code for the menu">`), या `QRCodeSVG` रेंडर करें, जो `aria-label`, `className` और कोई भी दूसरा attribute `<svg>` पर लगा देता है।

### 4. फ़ाइल के रूप में सेव करें [#4-save-it-as-a-file]

```tsx title="components/download-svg-button.tsx"
"use client";

import { downloadQRCode } from "qrdx";

const menuCode = {
  value: "https://example.com/menu",
  margin: 4,
  fgColor: "#1d4ed8",
  bodyPattern: "rounded",
  frame: { style: "banner-bottom", text: "Scan for the menu" },
} as const;

export function DownloadSvgButton() {
  return (
    <button
      type="button"
      onClick={() =>
        downloadQRCode(menuCode, {
          format: "svg",
          size: { width: 1024, height: 1024 },
          filename: "menu.svg",
        })
      }
    >
      Download SVG
    </button>
  );
}
```

बटन क्लिक करने पर `menu.svg` सेव होती है: वही कोड जो स्क्रीन पर है, 1024 px पर बना हुआ और किसी भी साइज़ पर तेज़, और यही वह फ़ाइल है जो प्रिंट शॉप माँगती है। इमेज के लिए `format` को `png`, `jpg` या `webp` पर सेट करें, डिज़ाइन टूल के लिए वेक्टर फ़ाइल चाहिए तो `eps`, या `pdf` (इसके लिए ऑप्शनल `jspdf` पैकेज चाहिए)।

`downloadQRCode` ब्राउज़र के DOM का इस्तेमाल करता है, इसलिए बटन Client Component में रहता है। Server Component फिर भी उसे रेंडर कर सकता है। कोड के ऑप्शन एक ही ऑब्जेक्ट में रखें, जैसा ऊपर है, ताकि फ़ाइल प्रीव्यू से मेल खाए।

### 5. जाँचें कि यह स्कैन होता है [#5-check-that-it-scans]

प्रिंट करने से पहले कोड को दो-तीन फ़ोन से स्कैन करें। अजीब रंगों या लोगो वाले डिज़ाइन के लिए `getScanScore` ब्राउज़र में वही जाँचें चलाता है और स्कोर, ग्रेड और क्या ठीक करना है, यह लौटाता है:

```tsx title="lib/check-code.ts"
import { getScanScore } from "qrdx";

const { score, grade, checks } = await getScanScore({
  value: "https://example.com/menu",
  fgColor: "#1d4ed8",
  bodyPattern: "rounded",
});
// score: 0 to 100, grade: "great" | "ok" | "risky" | "fails"
// checks: [{ id, passed, message, fix? }]
```

आप प्रिंट किए हुए कोड का स्क्रीनशॉट या फ़ोटो भी [स्कैन चेकर](/tools/scan-checker) पर अपलोड कर सकते हैं।

## अगर कुछ गड़बड़ हो जाए [#if-something-goes-wrong]

- **`Module not found: Can't resolve 'qrdx'`।** पैकेज उसी workspace या ऐप में इंस्टॉल करें जो उसे import करता है, फिर dev server दोबारा चालू करें।
- **कोड रेंडर हो जाता है लेकिन फ़ोन उसे नहीं पढ़ते।** `margin={4}` जोड़ें, हल्के बैकग्राउंड पर गहरे मॉड्यूल रखें, और स्क्रीन पर उसे कम से कम 128 px चौड़ा रेंडर करें। बाकी कारण [कोड स्कैन नहीं हो रहा](/docs/help/troubleshooting/wont-scan) में दिए हैं।
- **`PDF export needs the optional "jspdf" package`।** उसी पैकेज में `npm install jspdf` चलाएँ। SVG, PNG, JPG, WebP और EPS के लिए कुछ अतिरिक्त नहीं चाहिए।
