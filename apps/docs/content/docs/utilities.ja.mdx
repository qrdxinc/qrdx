これらのヘルパーは、レンダラーとスキャンスコアが内部で使っている小さな関数です。代表色の選択、コントラストの確認、ダウンロードサイズの検証、キャンバス機能の検出を、独自のUIで使えるようにエクスポートしています。特に記載がない限り、どの環境でも動作します。

| 関数 | 戻り値 | 備考 |
| --- | --- | --- |
| `getSolidColor(color, fallback?)` | `string` | `ColorConfig` を代表する1色を返します。文字列ならその値、単色なら `color`、グラデーションなら最初のストップ、画像塗りなら `underlay`、それ以外は `fallback`(`"#000000"`)です |
| `getContrastRatio(a, b)` | `number` | 2つのCSSカラー間のWCAGコントラスト比で、1〜21の値です。透明を含む色は、先に白の上に合成されます。色を解析できない場合は1を返します |
| `getContrastLevel(ratio)` | `{ level, warning, message }` | 7以上は `AAA`、4.5以上は `AA`、3以上は `AA Large`(`warning: true` 付き)、3未満は `Fail` です |
| `getLuminance(r, g, b)` | `number` | sRGBカラーの相対輝度で、0〜1の値です |
| `hexToRgb(hex)` | `{ r, g, b } \| null` | 3桁、4桁、6桁、8桁の16進数を読み取り、アルファは無視します。それ以外は `null` です |
| `validateSize(width, height)` | `{ isValid, error? }` | すべてのダウンロードに適用されるルールで、50〜5000 pxの正方形です |
| `SUPPORTS_PATH2D` | `boolean` | この環境のキャンバスが `addPath` 付きの `Path2D` に対応しているかどうかを示します |

## 色 [#colors]

```ts title="lib/colors.ts"
import { getSolidColor, hexToRgb } from "qrdx";

getSolidColor({
  type: "linear",
  angle: 45,
  stops: [
    { color: "#ff6b6b", offset: 0 },
    { color: "#4ecdc4", offset: 100 },
  ],
});
// "#ff6b6b": the first stop

getSolidColor({ type: "image", src: photo, underlay: "#111111" }); // "#111111"
getSolidColor(undefined, "#ffffff"); // "#ffffff"

hexToRgb("#ff6b6b"); // { r: 255, g: 107, b: 107 }
hexToRgb("#f00"); // { r: 255, g: 0, b: 0 }
hexToRgb("red"); // null
```

スウォッチ、CSSの背景、フォールバックなど、1色だけが必要な場面では `getSolidColor` を使います。レンダラーも、`QRCodeCanvas` やCanvasのフレーム描画のように、形式がグラデーションを描画できない場面でこの関数を使っています。

## コントラスト [#contrast]

```ts title="lib/contrast.ts"
import { getContrastLevel, getContrastRatio, getLuminance } from "qrdx";

getContrastRatio("#000000", "#ffffff"); // 21
getContrastRatio("#1d4ed8", "#f8fafc"); // 6.4
getContrastRatio("rgba(29, 78, 216, 0.5)", "#ffffff"); // the blue over white, so lower

getContrastLevel(4.5);
// { level: "AA", warning: false, message: "Good contrast" }

getContrastLevel(2);
// { level: "Fail", warning: true, message: "Poor contrast - QR code may not scan properly" }

getLuminance(255, 255, 255); // 1
```

スキャンスコアでは、コントラスト比が4.5以上(`SCAN_CONTRAST_MIN`)であれば合格となり、それを下回ると減点され、1.5を下回ると不合格になります。画像にはより高い値が必要で、`SCAN_IMAGE_CONTRAST_MIN` は、モジュール内の画像塗りでは7、モジュールの背面では12です。`getScanContrast(props)` は、すべてのグラデーションストップとアイカラーを含むデザイン全体に対して、スコア自身のチェックを実行します。詳しくは[フレーム、スキャンスコア、印刷用ファイル](/docs/features/frames#will-it-scan)をご覧ください。

ライブのコントラストチェッカーは、十数行で作れます。

```tsx title="components/contrast-checker.tsx"
"use client";

import { getContrastLevel, getContrastRatio } from "qrdx";
import { useState } from "react";

export function ContrastChecker() {
  const [fgColor, setFgColor] = useState("#000000");
  const [bgColor, setBgColor] = useState("#ffffff");
  const ratio = getContrastRatio(fgColor, bgColor);
  const level = getContrastLevel(ratio);

  return (
    <div>
      <input
        aria-label="Module color"
        type="color"
        value={fgColor}
        onChange={(event) => setFgColor(event.target.value)}
      />
      <input
        aria-label="Background color"
        type="color"
        value={bgColor}
        onChange={(event) => setBgColor(event.target.value)}
      />
      <p>
        {ratio.toFixed(2)}:1, {level.level}. {level.message}
      </p>
    </div>
  );
}
```

## 検証 [#validation]

```ts title="lib/sizes.ts"
import { validateSize } from "qrdx";

validateSize(1024, 1024); // { isValid: true }
validateSize(40, 40); // { isValid: false, error: "Size must be at least 50x50 pixels" }
validateSize(6000, 6000); // { isValid: false, error: "Size must not exceed 5000x5000 pixels" }
validateSize(400, 300); // { isValid: false, error: "Width and height must be equal for QR codes" }
```

`downloadQRCode`、`getQRCodeDataUrl`、`copyQRCodeToClipboard` は、サイズが検証に失敗すると同じ `error` テキストをスローします。そのため、フォーム側で事前にチェックできます。

## 機能検出 [#feature-detection]

```ts title="lib/features.ts"
import { SUPPORTS_PATH2D } from "qrdx";

if (SUPPORTS_PATH2D) {
  // draw module paths with Path2D
}
```

`SUPPORTS_PATH2D` はモジュールの読み込み時に一度だけ計算されるため、サーバー上では `false` になります。

## その他のヘルパー [#other-helpers]

- `getColorString(color)` と `normalizeColorConfig(color)` は、`ColorConfig` のさまざまな形式を相互に変換します。`isGradient(color)` と `isImagePaint(color)` は、それらの形式を判別します。
- `sanitizeFrameText(text)` と `isLatin1Text(text)` は、フレームラベルのルール(24文字、PDFとEPSではLatin-1)を適用します。
- `decodePNGPixels(bytes)` は、8ビットのPNGをDOMなしでRGBAピクセルに読み込みます。Node上で `createQRArtImage`、`createQRSilhouette`、`scanQRPixels` を使う際に利用します。
- `rgbToCmyk(color)` は、CMYK印刷用ファイルで使われる変換です。
