Der QRdx-Bot für Slack erstellt QR-Codes direkt in Slack. Jede Person in einem Slack-Workspace mit dem Bot kann aus einem Link oder einem beliebigen Text einen Code erstellen, ihn über Menüs unter der Nachricht neu stylen und herunterladen. Wer sein QRdx-Konto verknüpft, kann außerdem verfolgte (dynamische) Codes erstellen, die Scans zählen und später auf ein anderes Ziel zeigen können. Nutze ihn, wenn ein Team Links in Slack teilt und einen Code braucht, ohne die Unterhaltung zu verlassen.

## So funktioniert es [#how-it-works]

Der Bot speichert nie Nachrichtentext und lädt nie ein Bild hoch. Jeder Code ist ein QR-Bild, das QRdx über die [Image API](/docs/developers/image-api) aus dem Link in der Nachricht rendert, mit Inhalt und Design in diesem Link. Wenn du einen Code neu gestaltest, liest QRdx beides aus dem Link zurück. Zum Ändern muss also nichts gespeichert werden.

<IfAvailable feature="slackBot" id="add-the-bot-to-slack" title="Bot zu Slack hinzufügen">

1. Öffne in QRdx [Einstellungen → Integrationen → Slack](/settings/integrations/slack) und klicke auf **Bot zu Slack hinzufügen**. Das kann jedes QRdx-Konto tun, in jedem Tarif.
2. Wähle den Slack-Workspace und bestätige. Der Bot bittet darum, seinen Slash-Befehl, Erwähnungen von ihm und seine Direktnachrichten sehen sowie Nachrichten posten zu dürfen.
3. Du kehrst zur Einstellungsseite zurück. Sie listet die Slack-Workspaces auf, zu denen du den Bot hinzugefügt hast.

Dieselbe Slack-App postet auch [Benachrichtigungen](/docs/notifications#slack-and-discord) in einen Kanal. Wenn du den Bot hinzufügst, werden Benachrichtigungen nicht aktiviert, und wenn du Benachrichtigungen hinzufügst, wird der Bot nicht hinzugefügt.

</IfAvailable>

<IfAvailable feature="slackBot" id="make-a-qr-code" title="QR-Code erstellen">

| Wo | Was zu tun ist | Wo der Code erscheint |
| --- | --- | --- |
| In jedem Kanal | `/qr` gefolgt von einem Link oder Text | Im Kanal |
| In einem Kanal, in dem der Bot ist | Erwähne den Bot mit einem Link oder Text | Im Thread |
| In den Direktnachrichten des Bots | Sende einen Link oder Text | In der DM |
| Bei jeder Nachricht | **Weitere Aktionen** → **QR-Code erstellen** | Im Thread der Nachricht |

Jede Antwort ist ein QR-Code-Bild mit dem Inhalt darunter, drei Schaltflächen und den unten beschriebenen Stilmenüs. Die Schaltflächen sind **PNG herunterladen** (1024 Pixel), **SVG herunterladen** und **Im Editor öffnen**, wo du das Design weiter anpassen kannst. Ein Link öffnet den Editor mit eingetragenem Link. Bei Text öffnet sich ein leerer Editor, weil Text nie in einen Link gelangt.

Die Verknüpfung erstellt einen Code aus der ersten Webadresse der Nachricht oder, wenn es keine gibt, aus ihrem gesamten Text. Wenn der Bot nicht in diesem Kanal ist, siehst nur du den Code, mit dem Hinweis „Only you can see this. Add the QRdx app to this channel to reply in threads."

`/qr` allein oder `/qr help` zeigt die Befehle. Bei Inhalten, die für einen QR-Code zu lang sind, erscheint statt eines Bildes eine kurze Erklärung, die nur du siehst.

</IfAvailable>

<IfAvailable feature="slackBot" id="style-your-code" title="Code gestalten">

Unter jedem Code findest du vier Menüs: **Look**, **Farbe**, **Rahmen** und **Logo**. Wähle etwas aus, und der Code ändert sich an Ort und Stelle, mit neuen Download-Links. Jede Auswahl baut auf dem Code in seinem aktuellen Zustand auf. Nur die Person, die den Code erstellt hat, kann ihn neu gestalten. Wenn jemand anderes etwas auswählt, zeigt Slack nur dieser Person einen Hinweis, und der Code bleibt unverändert.

Die Looks sind eine Auswahl der integrierten Designs des Editors, die auch in kleinen Größen gut lesbar sind. **Plain** ist das Design in Schwarz auf Weiß. Ein Look ändert Formen und Farben und behält den gewählten Rahmen und das gewählte Logo. Eine Farbe färbt den ganzen Code in dieser Farbe auf Weiß. Die Rahmen fügen ein „Scan me"-Label hinzu, und das Logo-Menü bietet sieben der Schnellicons des Editors.

Du kannst einen Code auch direkt beim Erstellen gestalten, indem du nach dem Link oder Text Optionen anhängst. Sie heißen genauso wie in der [QRdx CLI](/docs/developers/cli):

```text title="Slack message"
/qr qrdx.dev --look modern --fg 0051ff --frame banner-bottom --frame-text "Scan me"
```

Alles vor der ersten Option ist der Inhalt. Zuerst wird der Look angewendet, die anderen Optionen kommen darüber. So behält `--look royal --fg 0051ff` die Formen von Royal in Blau. Optionen funktionieren auch in Erwähnungen und Direktnachrichten. Wenn eine Option oder ein Wert falsch ist, sagt dir der Bot das privat und listet die Werte auf, die er akzeptiert.

| Option | Was sie ändert | Werte |
| --- | --- | --- |
| `--look` | Das gesamte Design, aus einer der Vorlagen des Editors | `plain`, `classic`, `modern`, `royal`, `folio`, `caffeine`, `retro`, `bordeaux`, `blossom` |
| `--fg` (oder `--color`) | Die Punkte und die Eckaugen, sofern du diese nicht ebenfalls festlegst | Eine Hex-Farbe wie `0051ff` oder `black`, `blue`, `green`, `red`, `purple`, `orange` |
| `--bg` | Der Hintergrund | Wie bei `--fg` |
| `--eye-color` | Die drei Eckaugen | Wie bei `--fg` |
| `--dot-color` | Die Mitten der Eckaugen | Wie bei `--fg` |
| `--body` | Die Form der Punkte | Eine der {facts.bodyPatterns} Punktformen des Editors, etwa `rounded`, `circle` oder `classy` |
| `--eye` | Die Form der Eckaugen | Eine der {facts.eyeShapes} Augenformen, etwa `square`, `rounded` oder `gear` |
| `--dot` | Die Form der Augenmitten | Eine der {facts.eyeCentres} Mittenformen, etwa `square`, `rounded` oder `circle` |
| `--frame` | Ein Rahmen um den Code | `none` oder einer der {facts.frameStyles} integrierten Rahmen, etwa `banner-bottom`, `banner-top`, `speech-bubble` oder `polaroid` |
| `--frame-text` | Das Label des Rahmens, bis zu 24 Zeichen | Beliebiger Text, in Anführungszeichen, wenn er Leerzeichen enthält. Ohne `--frame` steht er auf einem Banner unter dem Code |
| `--template` | Ein als Vorlage gezeichneter Rahmen | `Arrow`, `StandardBox`, `SquareBorder`, `StrikedBox`, `DotRing`, `Halloween` oder `default`, in beliebiger Schreibweise |
| `--logo` | Ein Icon in der Mitte | `link`, `wifi`, `location`, `phone`, `email`, `whatsapp`, `instagram`, `file`, `calendar` oder `none` |

Bevor ein gestalteter Code gepostet wird, prüft QRdx ihn mit demselben Scan-Score wie der Editor. Wenn ein Design für Smartphones schwer lesbar wäre, passt QRdx es an (dunklere Farben, schlichtere Formen oder mehr Fehlerkorrektur) und weist unter dem Code darauf hin. Reicht das nicht aus, meist weil der Inhalt lang ist, erhältst du den Code in Schwarz auf Weiß mit einem Hinweis. Ein gestalteter Code von `/qr` erscheint einen Moment nach dem Senden des Befehls, sobald er geprüft wurde.

**Im Editor öffnen** öffnet den Editor mit demselben Design: Farben, Formen, Rahmen und Rand. Das Logo-Icon wird nicht im Link übertragen, wähle es im Editor also erneut aus.

Codes aus der Verknüpfung, die nur du sehen kannst, haben keine Menüs, und getrackte Codes behalten das schlichte Design.

</IfAvailable>

<IfAvailable feature="slackBot" id="tracked-codes" title="Getrackte Codes">

Ein einfacher Code enthält den Link selbst. Ein getrackter Code enthält einen Kurzlink (`https://qrdx.dev/q/<slug>`), der auf deinen Link weiterleitet. So zählt QRdx seine Scans, und du kannst ändern, wohin er führt. Um sie aus Slack zu erstellen, verknüpfe einmalig dein QRdx-Konto:

1. Führe `/qr link` aus. Eine Schaltfläche **QRdx-Konto verknüpfen**, die nur du siehst, öffnet QRdx. Sie funktioniert 10 Minuten lang.
2. Melde dich bei QRdx an, falls du dazu aufgefordert wirst. Klicke dann auf **Mit Slack anmelden** und melde dich mit demselben Slack-Konto an, das `/qr link` ausgeführt hat. Slack teilt QRdx nur deinen Slack-Benutzer und deinen Workspace mit, und QRdx prüft, ob sie übereinstimmen. Wenn du dich bei Slack als jemand anderes anmeldest, wird nichts verknüpft.
3. Wähle den QRdx-Workspace, in den deine getrackten Codes gehen sollen, und klicke auf **Bestätigen**. QRdx bittet dich zuerst, [zu bestätigen, dass du es bist](/docs/help/privacy-and-security/two-step-verification#confirm-its-you), es sei denn, du hast das kürzlich getan, denn mit der Verknüpfung kann dieses Slack-Konto Codes in deinem Workspace erstellen.
4. Zurück in Slack sendet dir der Bot eine Direktnachricht mit dem Namen des QRdx-Kontos und des Workspace, mit denen du verknüpft hast. Falls du nicht verknüpft hast, führe `/qr unlink` aus.
5. Führe `/qr track` gefolgt von einem Link aus, der mit `https://` oder `http://` beginnt. Du kannst den Bot auch mit `track` und einem Link erwähnen.

Der Code erscheint im Kanal mit seinem Kurzlink und dem Namen des QRdx-Workspace, in dem er liegt. Die Schaltfläche **In QRdx öffnen**, die zum Code in deinem Dashboard führt, kommt in einer separaten Nachricht, die nur du siehst. Der Code ist nach der Website des Links plus „from Slack" benannt, und du findest ihn wie jeden anderen in den Codes des Workspace.

Getrackte Codes folgen denselben Regeln wie im Dashboard erstellte Codes: Deine Rolle muss das Erstellen von Codes erlauben, ein Workspace, der die Bestätigung in zwei Schritten verlangt, braucht sie für dein Konto, und das Limit deines Tarifs für aktive dynamische QR-Codes gilt. Wenn du am Limit bist, sagt der Bot das und verlinkt auf die Tarife. Das wird jedes Mal geprüft. Wenn du einen Workspace verlässt oder den Zugriff verlierst, funktioniert die Verknüpfung dort also nicht mehr.

Jedes Slack-Konto hat pro Slack-Workspace eine Verknüpfung. Wenn du `/qr link` für ein Slack-Konto ausführst, das bereits verknüpft ist, nennt die Seite den QRdx-Workspace, mit dem es verknüpft ist, und ob das in einem anderen QRdx-Konto liegt. Die Schaltfläche heißt dann **Verknüpfung ersetzen**, und nichts ändert sich, bis du darauf klickst. `/qr unlink` entfernt eine Verknüpfung, ebenso **Verknüpfung aufheben** unter **Verknüpfte Slack-Konten** in [Einstellungen → Integrationen → Slack](/settings/integrations/slack).

Inhaber und Admins eines QRdx-Workspace sehen alle damit verknüpften Slack-Konten unter **Slack-Konten** in **Einstellungen** → **API-Schlüssel & Apps**: den Slack-Workspace, die Slack-Benutzer-ID, das Mitglied, als das das Konto handelt, und den Zeitpunkt der Verknüpfung. Mit **Widerrufen** entfernst du dort eine Verknüpfung. Hat der Workspace das [Audit-Protokoll](/docs/help/teams/audit-log), zeigen mit `/qr track` erstellte Codes den Namen des Mitglieds „via Slack", mit den IDs von Slack-Benutzer und Workspace, und auch das Widerrufen einer Verknüpfung wird protokolliert.

</IfAvailable>

## Was der Bot speichert [#what-the-bot-keeps]

Der Bot liest eine Nachricht nur, wenn jemand `/qr` ausführt, den Bot erwähnt, ihm direkt schreibt oder die Shortcut-Aktion auf diese Nachricht nutzt. Er speichert nie den Text von Nachrichten. Die QR-Code-Bilder kommen von der QRdx [Image API](/docs/developers/image-api), die Slack über den Link in der Nachricht lädt. Es wird also nichts hochgeladen.

Für jeden Slack-Workspace speichert QRdx dessen ID und Namen, die Slack-Nutzer-ID des Bots, die vergebenen Scopes, das Token des Bots (verschlüsselt), welcher QRdx-Account ihn hinzugefügt hat und wann. Für jeden verknüpften Slack-Account speichert QRdx die Slack-Nutzer- und Workspace-IDs, deinen QRdx-Account, den ausgewählten Workspace und den Zeitpunkt der Verknüpfung. Die Anmeldung mit Slack zum Verknüpfen fügt dem nichts hinzu: QRdx vergleicht Slack-Nutzer und Workspace und vergisst die Anmeldung dann wieder.<IfAvailable feature="slackBot"> Deine verknüpften Slack-Accounts findest du in deinem [Datenexport](/docs/help/account-and-billing/export-your-data).</IfAvailable>

Damit nicht eine einzelne Person einen Kanal überflutet, zählt der Bot die Codes, die jede Person pro Minute erstellt oder neu gestaltet, sowie die Codes, die ein Slack-Workspace und ganz QRdx zusammen erstellen. Kommen zu viele an, antwortet er: „QRdx is busy right now. Try again in a minute." Keiner der Zähler enthält Inhalte.

<IfAvailable feature="slackBot" id="remove-the-bot" title="Bot entfernen">

Öffne in Slack die Seite der App und wähle **Remove App** (oder bitte einen Slack-Admin darum). QRdx löscht dann das Bot-Token dieses Slack-Workspace und alle dort erstellten Verknüpfungen von Slack-Accounts. Bereits erstellte Codes bleiben in QRdx, und getrackte Codes funktionieren weiter.

</IfAvailable>

## Für Entwickler [#for-developers]

Der Bot ist eine dünne Schicht über zwei öffentlichen Werkzeugen: Die [Image API](/docs/developers/image-api) rendert jeden Code, und getrackte Codes sind gewöhnliche dynamische QR-Codes, die du über die [REST API](/docs/developers/api/list-codes) auslesen kannst. Dieselben Stiloptionen gibt es in der [CLI](/docs/developers/cli).

## Self-Hosting [#self-hosting]

Der Bot nutzt dieselbe Slack-App wie die Benachrichtigungen über „Add to Slack", ergänzt um das Signing Secret. Setze `SLACK_CLIENT_ID`, `SLACK_CLIENT_SECRET` und `SLACK_SIGNING_SECRET` sowie in der Produktion `INTEGRATION_ENCRYPTION_KEY`, der die Bot-Tokens verschlüsselt. Ohne diese Variablen gibt es die Seiten und Endpunkte des Bots nicht. `plugins/slack/manifest.json` im Repository ist das Manifest der App, und `plugins/slack/README.md` führt dich Schritt für Schritt durch das Erstellen der App daraus. Das Manifest enthält den User-Scope `openid` und die Redirect-URL `/api/integrations/slack/link/callback`, die Sign in with Slack braucht, wenn jemand seinen Account verknüpft. Rate Limits brauchen Upstash Redis; ohne es sind sie deaktiviert. Siehe [Self-Hosting](/docs/self-hosting#optional-services).
