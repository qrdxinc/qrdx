Setelah membaca halaman ini, Anda akan memiliki kode QR yang dirender oleh Server Component tanpa JavaScript klien, kode yang dibuat dari parameter rute, kode langsung yang terhubung ke sebuah input, kode dengan logo Anda, dan tombol untuk menyimpan SVG. `QRCodeSVG` dan `QRCode` tidak memakai hook khusus klien, sehingga Server Component merender kode langsung ke dalam HTML halaman. Anda hanya memerlukan Client Component jika nilainya berubah di browser atau untuk menyimpan file.

<NpmStatus package="qrdx" />

## Sebelum memulai [#before-you-start]

- Proyek Next.js dengan App Router. Contoh-contoh memakai `params` asinkron milik App Router, seperti di Next.js 15 dan 16.
- React 18 atau lebih baru, yang memang sudah dibutuhkan oleh App Router.

## Cara membuatnya [#build-it]

### 1. Instal qrdx [#1-install-qrdx]

```package-install
qrdx
```

`react` dan `react-dom` adalah peer dependency, sehingga versi milik aplikasi Anda yang dipakai.

### 2. Render kode di Server Component [#2-render-a-code-in-a-server-component]

```tsx title="app/page.tsx"
import { QRCodeSVG } from "qrdx";

export default function Page() {
  return (
    <QRCodeSVG
      value="https://example.com"
      size={256}
      margin={4}
      role="img"
      aria-label="QR code for example.com"
    />
  );
}
```

Buka halamannya. `<svg>` menjadi bagian dari HTML yang dikirim server, sehingga tampil sebelum JavaScript apa pun dimuat, halaman statis merendernya sekali saat build, dan pembaca layar mendapatkan `aria-label`.

<Shot id="lib-nextjs-server-code" />

`margin` adalah quiet zone di sekeliling kode, dalam satuan modul. Nilai bawaannya 0, cocok untuk kode di dalam kartu yang punya padding sendiri. Standar QR meminta 4, pilihan aman di latar yang ramai atau gelap.

### 3. Bangun nilai dari parameter rute [#3-build-the-value-from-a-route-param]

```tsx title="app/tickets/[id]/page.tsx"
import { QRCodeSVG } from "qrdx";

export default async function TicketPage({
  params,
}: {
  params: Promise<{ id: string }>;
}) {
  const { id } = await params;
  const url = `https://example.com/check-in/${encodeURIComponent(id)}`;
  return <QRCodeSVG value={url} size={200} margin={4} level="H" />;
}
```

Kunjungi `/tickets/A-12` dan kode akan membuka `https://example.com/check-in/A-12`. Next.js meneruskan `params` sebagai promise, jadi halamannya `async`. Lakukan encoding pada apa pun yang berasal dari pengguna atau basis data sebelum dimasukkan ke URL. Level `H` memungkinkan hingga 30% kode rusak, yang membantu pada badge yang terlipat atau tergores.

### 4. Ikuti input di Client Component [#4-follow-an-input-in-a-client-component]

```tsx title="components/live-qr-code.tsx"
"use client";

import { QRCodeSVG } from "qrdx";
import { useState } from "react";

export function LiveQrCode() {
  const [value, setValue] = useState("https://example.com");
  return (
    <div>
      <input
        aria-label="Text or link to encode"
        value={value}
        onChange={(event) => setValue(event.target.value)}
      />
      {value ? <QRCodeSVG value={value} size={200} margin={4} /> : null}
    </div>
  );
}
```

Kode digambar ulang di setiap ketukan tombol, dan nilai pertamanya tetap dirender di server. Halaman Server Component dapat mengimpor komponen ini apa adanya.

`QRCodeCanvas` juga merupakan Client Component (disertai `"use client"`), tetapi hanya menggambar modul persegi polos. Gunakan `QRCodeSVG` atau `QRCode` untuk kode bergaya.

### 5. Tambahkan logo [#5-add-a-logo]

```tsx title="components/logo-qr-code.tsx"
import { QRCode } from "qrdx";

export function LogoQrCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      margin={4}
      level="H"
      logo="/logo.png"
    />
  );
}
```

`/logo.png` adalah file di folder `public` proyek Anda. Logo digambar dengan lebar seperempat lebar kode dan modul di belakangnya dikosongkan, sehingga kode mengandalkan koreksi kesalahan agar bisa dipindai: itulah sebabnya `level` bernilai `H`. `QRCode` juga memperkecil logo yang terlalu besar untuk dapat diperbaiki oleh kode.

`logo` menerima path di aplikasi Anda, URL, atau data URL. Untuk unduhan, data URL paling aman, karena gambar dari sumber jauh memerlukan header CORS sebelum browser boleh menyalinnya ke dalam file. `logoOptions` mengatur ukuran, ruang kosong, posisi, dan pemangkasan logo; lihat [Menambahkan logo lewat kode](/docs/features/logos).

### 6. Unduh sebagai SVG [#6-download-as-svg]

```tsx title="components/download-svg-button.tsx"
"use client";

import { downloadQRCode } from "qrdx";

export function DownloadSvgButton({ value }: { value: string }) {
  return (
    <button
      type="button"
      onClick={() =>
        downloadQRCode(
          { value, level: "Q", margin: 4 },
          {
            format: "svg",
            size: { width: 1024, height: 1024 },
            filename: "qr-code.svg",
          },
        )
      }
    >
      Download SVG
    </button>
  );
}
```

Mengeklik tombol akan menyimpan `qr-code.svg`, file vektor 1024 px. `downloadQRCode` membutuhkan DOM browser, jadi tombolnya adalah Client Component. Halaman Server Component tetap dapat merendernya dan meneruskan nilainya sebagai prop. Untuk file lain, setel `format` ke `png`, `jpg`, `webp`, `eps`, atau `pdf` (PDF memerlukan paket opsional `jspdf`). [Ekspor dan unduh](/docs/features/downloads) membahas setiap opsi.

## Jika Anda memerlukan URL gambar [#when-you-need-an-image-url]

Email, gambar Open Graph, file Markdown, dan tempat lain yang tidak dapat menjalankan React memerlukan URL gambar, bukan komponen. [Image API kode QR](/docs/developers/image-api) mengembalikannya tanpa kunci:

```html title="email.html"
<img src="https://api.qrdx.dev/v1/qr?data=https://example.com&format=png" width="256" height="256" alt="QR code for example.com" />
```

## Komponen siap pakai [#ready-made-components]

[Registry shadcn/ui](/docs/developers/shadcn) memasang komponen ke proyek Anda: [kode QR dengan tombol unduh](/docs/components/qr-code), kartu, dialog berbagi, generator, pemindai, serta kode Wi-Fi dan kontak.

```bash title="Terminal"
npx shadcn@latest add https://qrdx.dev/r/qr-code.json
```

## Jika terjadi masalah [#if-something-goes-wrong]

- **`useRef only works in Client Components` (atau hal yang sama untuk `useState`).** Anda merender `QRCodeCanvas`, atau komponen dengan hook, dari Server Component. Tambahkan `"use client"` di bagian atas file tersebut, atau render `QRCodeSVG`.
- **Logo tampil di halaman tetapi tidak ada di file yang diunduh.** Gambar berasal dari origin lain tanpa header CORS. Sajikan dari `public`, atau berikan data URL.
- **`PDF export needs the optional "jspdf" package`.** Jalankan `npm install jspdf` di aplikasi. Format lain tidak memerlukan tambahan apa pun.
