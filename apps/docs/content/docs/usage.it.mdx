`QRCode` è il componente da usare: accetta tutte le opzioni di stile e una semplice prop `logo`, e viene renderizzato sul server. Questa pagina passa in rassegna le prop che imposti più spesso. Per l'elenco completo delle prop, consulta il [riferimento API della libreria](/docs/api-reference).

## Scegliere un componente [#choose-a-component]

| Componente | Cosa disegna | Quando usarlo |
| --- | --- | --- |
| `QRCode` | Un `<svg>` con tutte le opzioni di stile, più `logo`, `logoOptions`, `hideLogo` e `scale`. Non accetta altri attributi | Quasi sempre |
| `QRCodeSVG` | Lo stesso `<svg>`, con il logo indicato come `imageSettings` grezzo in pixel. Ogni altra prop (`aria-label`, `className`, `role`) viene applicata all'`<svg>` | Ti servono attributi sull'`<svg>`, imposti tu il layout del logo, oppure porti codice da un altro renderer |
| `QRCodeCanvas` | Un `<canvas>` con moduli quadrati semplici e colori pieni | Ti serve un elemento canvas. Pattern, colori degli occhi, gradienti e template vengono ignorati |

`QRCode` e `QRCodeSVG` non usano hook riservati al browser, quindi vengono renderizzati nei React Server Components e in HTML statico. `QRCodeCanvas` include `"use client"`.

```tsx title="components/menu-code.tsx"
import { QRCode } from "qrdx";

export function MenuCode() {
  return (
    <div role="img" aria-label="QR code for the menu">
      <QRCode value="https://example.com/menu" size={256} margin={4} />
    </div>
  );
}
```

`value` viene codificato esattamente come lo passi, quindi funzionano un payload Wi-Fi, una vCard, `mailto:` o testo semplice. `QRCode` accetta solo le prop del codice e `style`: per dargli un nome accessibile, avvolgilo come nell'esempio sopra. `QRCodeSVG` applica `aria-label`, `className`, `role` e ogni altro attributo direttamente all'`<svg>`.

## Dimensione e zona di rispetto [#size-and-quiet-zone]

- `size` è larghezza e altezza in pixel (predefinito 128). Sotto i 128 px circa, un codice denso diventa difficile da scansionare da uno schermo.
- `margin` è la zona di rispetto attorno al codice, in moduli (predefinito 0). Lo standard QR ne richiede 4. Impostalo quando il codice è su una foto, un motivo o una pagina scura; un codice dentro una card bianca con un suo padding può restare a 0.
- `scale` moltiplica `size` su `QRCode`.

Una cornice o un template cambia la dimensione dell'output. Vedi [Cornice o template](#frame-or-template).

## Colori [#colors]

```tsx title="components/brand-code.tsx"
import { QRCode } from "qrdx";

export function BrandCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      fgColor="#1d4ed8"
      bgColor="#f8fafc"
      eyeColor="#0f172a"
      dotColor="#1d4ed8"
    />
  );
}
```

- `fgColor` colora i moduli dei dati, `bgColor` lo sfondo, `eyeColor` i tre occhi agli angoli e `dotColor` il punto dentro ogni occhio. I colori degli occhi usano per impostazione predefinita `fgColor`.
- Ognuno accetta qualsiasi colore CSS (`#1d4ed8`, `rgb(29 78 216)`, un colore con nome) o un oggetto gradiente. [Imposta colori e gradienti](/docs/features/colors-gradients) tratta gradienti, colori trasparenti e riempimenti con immagine.
- Mantieni i moduli più scuri dello sfondo. Gli scanner leggono scuro su chiaro; un codice chiaro su sfondo scuro funziona nella maggior parte delle fotocamere dei telefoni, ma non in alcune app meno recenti.

## Forme [#shapes]

```tsx title="components/rounded-code.tsx"
import { QRCode } from "qrdx";

export function RoundedCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      bodyPattern="rounded"
      cornerEyePattern="extra-rounded"
      cornerEyeDotPattern="rounded"
    />
  );
}
```

- `bodyPattern` dà la forma ai moduli dei dati (predefinito `circle`). Puoi scegliere tra {facts.bodyPatterns}.
- `cornerEyePattern` dà la forma ai tre occhi agli angoli (predefinito `gear`), una tra {facts.eyeShapes}.
- `cornerEyeDotPattern` dà la forma al punto dentro ogni occhio (predefinito `circle`), una tra {facts.eyeCentres}.

[Forme, occhi e cornici](/docs/styles) mostra dal vivo ogni valore. [Scegli le forme di moduli e occhi](/docs/features/patterns) spiega la scala dei moduli, i codici sagomati e le poche combinazioni che si scansionano male.

## Logo [#logo]

```tsx title="components/logo-code.tsx"
import { QRCode } from "qrdx";

export function LogoCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      level="H"
      logo="/logo.png"
      logoOptions={{ size: 0.2, padding: 1 }}
    />
  );
}
```

`logo` accetta un percorso nella tua app, un URL o un data URL. I moduli dietro al logo vengono cancellati, quindi il codice si affida alla correzione degli errori per essere letto: usa `level="H"`. `logoOptions` imposta la larghezza del logo come quota del codice (da 0.1 a 0.3, predefinito 0.25), lo spazio libero attorno in moduli, la posizione e il ritaglio. Il componente non disegna mai un logo più grande di quanto il codice possa recuperare. [Aggiungi un logo nel codice](/docs/features/logos) ha tutti i dettagli.

## Cornice o template [#frame-or-template]

```tsx title="components/framed-code.tsx"
import { QRCode } from "qrdx";

export function FramedCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      frame={{ style: "banner-bottom", text: "Scan me", color: "#0f172a" }}
    />
  );
}
```

- `frame` disegna attorno al codice una cornice con invito all'azione. Il codice resta largo `size` e l'output cresce per contenere la cornice. Ci sono {facts.frameStyles} stili integrati, oltre alla libreria ufficiale di cornici e alle tue specifiche di cornice. Vedi [Cornici, punteggio di scansione e file di stampa](/docs/features/frames).
- `templateId` disegna invece un template come `Arrow` o `StandardBox`. Un template disegna tutta la sua grafica a `size`, con il codice più piccolo al suo interno. Vedi [Usa un template di cornice](/docs/features/templates).

Se li imposti entrambi, la cornice viene disegnata attorno alla grafica del template.

## Correzione degli errori [#error-correction]

| `level` | Danno tollerato | Quando usarlo |
| --- | --- | --- |
| `L` | circa 7% | Schermi puliti, link brevi, il codice più piccolo |
| `M` | circa 15% | Payload lunghi come le vCard, dove conta di più un codice più piccolo |
| `Q` | circa 25% | Il valore predefinito. Uso generico |
| `H` | circa 30% | Loghi, grafica, stampe che possono graffiarsi o piegarsi |

Un livello più alto aggiunge moduli, quindi a parità di dimensione il codice diventa più denso. `autoLevel` porta il livello a `H` da solo quando un logo copre più del 7% del codice; è disattivato per impostazione predefinita, così i codici esistenti mantengono il loro aspetto.
