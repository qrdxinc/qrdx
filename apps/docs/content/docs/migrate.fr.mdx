title: "Passer de Bitly, Rebrandly et autres services à QRdx"

---

QRdx importe d'un seul coup les liens et les codes dynamiques d'autres fournisseurs, ce qui vous permet de migrer sans réimprimer ce qui est déjà en circulation. Chaque import suit les mêmes trois étapes : choisir ce que vous apportez, le prévisualiser, l'importer. Utilisez ce guide si vous avez des codes chez un autre service et que vous voulez pouvoir les modifier et les suivre dans QRdx.

<Callout type="info" title="Offres">
  Les imports fonctionnent avec toutes les offres, dans la limite de codes actifs de votre offre. Conserver les suffixes d'origine nécessite Pro ou Business. Voir [Offres et limites](/docs/plans-and-limits).
</Callout>

Pressé ? Consultez la page de tâche courte : [Importer des codes depuis un autre service](/docs/help/dynamic-codes/import).

## Fonctionnement [#how-it-works]

<Diagram id="import-flow" />

Ouvrez [Codes](/dashboard?to=codes), puis le menu **⋯** → **Importer des codes** → **Depuis Bitly et d'autres applications**. Il existe deux types de sources :

- **Comptes connectés :** Bitly, Rebrandly et Short.io. QRdx liste vos liens via l'API du fournisseur.
- **Fichiers d'export :** QR Code Generator PRO, Uniqode (Beaconstac), Flowcode, QR TIGER, ME-QR, TinyURL, Hovercode, Scanova, ou tout fichier CSV contenant des URL de destination.

Rien ne change dans votre ancien compte pendant l'import lui-même.

### Ce que crée un import [#what-an-import-creates]

Chaque lien ou code devient un [QR code dynamique](/docs/dynamic-qr-codes) avec :

- sa destination et son titre ;
- ses tags (facultatif), et un dossier tel que « Imported from Bitly » (vous pouvez le renommer ou le désactiver) ;
- des notes du type `Imported from Bitly bit.ly/3AbCdEf on 2026-11-01.` ainsi que la date de création d'origine du lien. QRdx attribue sa propre date de création au nouveau code.

La prévisualisation indique combien de codes seront créés, quels tags sont nouveaux et ce qui est ignoré :

- **Déjà importé :** les liens importés auparavant (lors de n'importe quelle exécution précédente) sont toujours ignorés, donc lancer deux fois un import ne crée jamais de doublons.
- **Même destination existante :** les liens dont la destination possède déjà un code QRdx sont ignorés par défaut. Cochez l'option pour les importer malgré tout.
- **Limite de l'offre dépassée :** les liens qui ne tiennent pas dans les codes actifs de votre offre. La prévisualisation propose d'importer les premiers qui rentrent, ou de passer à une offre supérieure.
- **Import impossible :** les destinations manquantes ou invalides, et les liens qui pointent déjà vers un lien court QRdx.

Les imports s'exécutent par lots de 50 avec une barre de progression. Vous pouvez fermer la boîte de dialogue sans risque : rouvrez l'outil d'import et l'import reprend depuis **Imports récents**. Le récapitulatif liste les codes créés, ignorés et en échec, avec les raisons.

## Depuis un compte connecté [#from-a-connected-account]

1. Choisissez le fournisseur. S'il n'est pas encore connecté, connectez-le sur place (connexion, ou collez une clé API ou un jeton). Les jetons sont stockés chiffrés, et vous pouvez vous déconnecter dans [Paramètres → Intégrations](/settings/integrations).
2. Recherchez, filtrez par domaine ou par tag, et sélectionnez des liens. **Sélectionner tous les liens correspondants** prend jusqu'à 1 000 liens par import ; relancez l'import pour le reste.
3. Vérifiez la prévisualisation et cliquez sur **Importer**.

| Fournisseur | Se connecter avec | Lister les liens | Garder les codes imprimés fonctionnels |
| --- | --- | --- | --- |
| Bitly | Connexion, ou un jeton d'accès générique | Oui | Offres Bitly payantes uniquement : 5 redirections de lien par mois avec Core, 20 avec Growth, 110 avec Premium |
| Rebrandly | Clé API | Oui | Dans la limite des modifications de destination mensuelles de Rebrandly : 10 avec Essentials, 50 avec Professional, 150 avec Growth (aucune avec Free) |
| Short.io | Clé API | Oui, un domaine à la fois | Oui, avec toutes les offres |

Les limites des offres sont celles des fournisseurs et évoluent avec le temps. Consultez leurs pages de tarifs.

## Garder les codes imprimés fonctionnels [#keep-printed-codes-working]

Les QR codes que vous avez imprimés avec un autre fournisseur encodent le lien court de ce fournisseur. Après un import depuis un compte connecté, le récapitulatif propose **Garder mes codes imprimés fonctionnels** :

1. Une **simulation** liste chaque ancien lien et le lien QRdx vers lequel il pointerait. Rien ne change encore.
2. Une fois que vous confirmez, QRdx change la destination de chaque ancien lien pour son nouveau code QRdx. Les visiteurs arrivent toujours sur la même page, et chaque scan apparaît désormais dans les statistiques de QRdx. L'ancien fournisseur voit toujours d'abord un clic.
3. **Annuler** rétablit les destinations d'origine, que QRdx a enregistrées lors de l'import.

Si le fournisseur refuse (par exemple une offre Bitly sans redirection de lien restante), QRdx s'arrête, en explique la raison et laisse les liens restants inchangés. Les liens ignorés parce que leur destination avait déjà un code QRdx pointent vers ce code existant.<IfAvailable feature="customDomains"> Les liens dont le suffixe passe avec votre propre domaine (ci-dessous) ne sont pas modifiés : après le changement de DNS, ils sont le lien QRdx.</IfAvailable>

<Callout type="warn" title="Gardez l'ancien compte pour le moment">
  Laissez le fournisseur connecté tant que vous n'êtes pas sûr : l'annulation a besoin de la connexion. L'ancien compte doit aussi rester actif pour que ses liens continuent de rediriger.
</Callout>

## Conserver les suffixes d'origine [#keep-the-original-back-halves]

Avec Pro et Business, cochez **Conserver les suffixes d'origine** dans la prévisualisation de l'import. Chaque code reçoit alors son ancien suffixe au lieu d'un suffixe aléatoire lorsque QRdx peut le conserver, si bien que `bit.ly/spring-menu` devient `qrdx.dev/q/spring-menu` :

- Un suffixe est conservé s'il compte de 3 à 64 lettres, chiffres, `-` ou `_`, ne commence ni ne finit par `-` (voir [suffixes personnalisés](/docs/dynamic-qr-codes#custom-back-halves)), n'est pas réservé, et n'est pas déjà utilisé sur `qrdx.dev` par un code QRdx<IfAvailable feature="customDomains"> (sur votre propre domaine, uniquement par vos codes qui s'y trouvent)</IfAvailable>.
- Sinon, le code reçoit un suffixe généré, et la prévisualisation montre le changement avec la raison, par exemple `spring-menu → Ab3xK9q · Another QRdx code already uses this back-half on qrdx.dev`. L'import utilise exactement le suffixe affiché par la prévisualisation.
- Les suffixes respectent la casse, comme chez Bitly et Short.io.

Les suffixes qui ne peuvent pas être conservés reçoivent un suffixe généré ; ces liens nécessitent une réimpression ou une redirection chez l'ancien fournisseur.

<IfAvailable feature="customDomains" id="your-own-domain-go-yourbrand-com" title="Votre propre domaine (go.yourbrand.com)">

Si vos liens utilisent votre propre domaine, vous pouvez transférer ce domaine vers QRdx et conserver les suffixes, de sorte que `go.yourbrand.com/spring-menu` continue de fonctionner après le changement de DNS.

1. Ajoutez d'abord le domaine dans **Paramètres** → **Domaines**. Il peut rester non vérifié pour l'instant : les suffixes sont alors conservés sur le domaine lui-même, où ils doivent seulement être uniques parmi vos propres codes, et seuls quelques mots techniques sont réservés.
2. Dans la prévisualisation de l'import, cochez **Conserver les suffixes d'origine** et choisissez le domaine sous **Liens sur**. La prévisualisation indique quels suffixes sont conservés.
3. Lancez l'import. Les codes sont placés sur le domaine et réservent leurs suffixes immédiatement.
4. Faites pointer le DNS du domaine vers QRdx et vérifiez-le (voir [Domaines personnalisés](/docs/custom-domains)). Faites-le à un moment calme : les liens du domaine cessent de fonctionner chez l'ancien fournisseur dès que le DNS change, et commencent à fonctionner sur QRdx une fois le domaine vérifié.

Si le domaine n'est pas encore dans QRdx au moment de l'import, ses suffixes sont conservés sur `qrdx.dev` à la place (où ils doivent être libres dans tout QRdx). Une fois le domaine ajouté et vérifié, cliquez sur **Rattacher les codes** dans le récapitulatif de l'import pour y déplacer ces codes.

</IfAvailable>

## À partir d'un fichier d'export [#from-an-export-file]

1. Récupérez le fichier (étapes ci-dessous). QRdx lit les fichiers CSV jusqu'à 2 Mo et 1 000 lignes par import ; pour un fichier Excel, enregistrez-le ou téléchargez-le d'abord au format CSV.
2. Dans l'outil d'import, choisissez le fournisseur et importez le fichier. QRdx reconnaît les colonnes du fournisseur lorsque c'est possible, et vous pouvez modifier la correspondance. Seule la destination est obligatoire ; l'ancien lien court (ou l'ID du code) permet à un nouvel import d'ignorer les codes déjà importés.
3. Prévisualisez et importez, puis utilisez **Copy all new links** ou **Download mapping CSV** (ancien lien → nouveau lien QRdx).

QRdx ne peut pas modifier les codes qui se trouvent sur le domaine du fournisseur. Pour que les codes imprimés continuent de fonctionner, ouvrez chaque ancien QR code dynamique chez l'ancien fournisseur et définissez sa destination sur le nouveau lien QRdx indiqué dans la correspondance. L'ancien compte doit rester actif pour que ces codes redirigent ; réimprimez avec les codes QRdx avant de résilier.<IfAvailable feature="customDomains"> Les codes sur un domaine qui vous appartient peuvent suivre le domaine, sans réimpression : voir [Votre propre domaine](#your-own-domain-go-yourbrand-com) plus haut.</IfAvailable>

### QR Code Generator PRO [#qr-code-generator-pro]

Il n'existe pas d'export documenté de la liste des codes. Créez un tableur avec **Name**, **Short URL** et **Destination URL** pour chaque code. Pour rediriger les codes : ouvrez le code → **Details** → **Edit**, remplacez l'URL et enregistrez. Pour de nombreux codes, sa mise à jour en masse accepte un CSV de nouvelles URL pour 500 codes maximum.

### Uniqode (Beaconstac) [#uniqode-beaconstac]

**QR Codes → Dynamic**, tout sélectionner, **⋯ → Export**, par organisation ou par dossier. Les colonnes de l'export (QR Code Name, QR Code URL, Destination URL, Labels et d'autres) sont reconnues. Pour rediriger : ouvrez le code → **Edit** → nouvelle URL → **Next** → **Save**.

### Flowcode [#flowcode]

Flowcode n'exporte que les codes placés dans un dossier ; commencez donc par ranger vos codes dans des dossiers. Ouvrez ensuite la section **Folder**, cochez les dossiers et cliquez sur **Download URLs**. Les colonnes du CSV (Flowcode Name, Short Links, Scan Destination) sont reconnues, tout comme celles d'une feuille de création en masse (Flowcode Name, Flowcode Scan URL). Pour rediriger : **Assets** → le code → **Overview** → **Destination** → **Save**.

### QR TIGER [#qr-tiger]

**My Account** → choisissez une catégorie (par exemple URL) → **Download QR List**, une fois par catégorie. Pour rediriger : **My Account → Dashboard → URL** → la campagne → **Edit** → **Save**.

### ME-QR [#me-qr]

Il n'y a pas d'export. Notez le nom, le lien du QR code et l'URL de destination de chaque code. Pour rediriger : modifiez le code dans votre liste de codes ME-QR.

### TinyURL [#tinyurl]

TinyURL indique proposer l'export CSV dans ses offres payantes. Exportez vos liens en CSV, ou notez l'alias et l'URL longue. Modifier la destination d'un lien TinyURL nécessite une offre TinyURL payante.

### Hovercode, Scanova et autres [#hovercode-scanova-and-others]

Exportez vos codes en CSV depuis le fournisseur (Hovercode indique proposer les exports CSV dans ses offres Business ; Scanova envoie un lien de téléchargement par e-mail), puis vérifiez la correspondance des colonnes. Tout CSV comportant une colonne de destination fonctionne avec **Another provider (CSV)**.

Les QR codes statiques (issus de goQR.me, QR Code Monkey, Adobe Express et d'outils similaires) encodent la destination elle-même ; ils continuent donc de fonctionner sans l'outil. N'importez leurs destinations depuis un CSV que si vous voulez des codes modifiables et suivis pour de nouvelles impressions.

## À partir d'une bibliothèque de QR codes [#from-a-qr-code-library]

Les bibliothèques génèrent des codes statiques, il n'y a donc rien à migrer : les codes déjà imprimés continuent de fonctionner. Pour changer le rendu dans votre application, installez `qrdx` et remplacez le composant.

### Depuis qrcode.react [#from-qrcode-react]

```tsx title="Before and after"
// Before
import { QRCodeSVG } from "qrcode.react";

<QRCodeSVG value="https://example.com" size={256} fgColor="#111827" />;

// After
import { QRCodeSVG } from "qrdx";

<QRCodeSVG
  value="https://example.com"
  size={256}
  fgColor="#111827"
  bodyPattern="rounded"
/>;
```

`value`, `size`, `level`, `fgColor`, `bgColor`, `marginSize` (sous le nom `margin`) et `imageSettings` sont repris tels quels ; qrdx ajoute des motifs, des dégradés et des modèles. Consultez la [référence de l'API](/docs/api-reference).

### Depuis qr-code-styling [#from-qr-code-styling]

```tsx title="Before and after"
// Before
import QRCodeStyling from "qr-code-styling";

const qr = new QRCodeStyling({
  data: "https://example.com",
  width: 256,
  dotsOptions: { type: "rounded", color: "#111827" },
  image: "/logo.png",
});
qr.append(ref.current);

// After
import { QRCodeSVG } from "qrdx";

<QRCodeSVG
  value="https://example.com"
  size={256}
  bodyPattern="rounded"
  fgColor="#111827"
  imageSettings={{ src: "/logo.png", width: 64, height: 64, excavate: true }}
/>;
```

qrdx est un composant React : il n'y a donc pas d'instance à ajouter au DOM, il suffit de l'afficher comme n'importe quel élément. Les téléchargements utilisent les fonctions utilitaires de la [référence de l'API](/docs/api-reference).

## Pour les développeurs [#for-developers]

Pour déplacer les codes avec un script, créez-les avec l'[API des codes](/docs/developers/api/create-codes) : jusqu'à {facts.apiBatchCodes} par requête avec Pro et Business, avec `slug` pour la fin de lien que vous voulez conserver et un `Idempotency-Key` pour qu'une nouvelle tentative ne duplique jamais un lot.
