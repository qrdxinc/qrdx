Slack용 QRdx 봇은 Slack 안에서 QR 코드를 만들어 줍니다. 봇이 설치된 Slack 워크스페이스의 누구나 링크나 임의의 텍스트로 코드를 만들고, 메시지 아래의 메뉴로 스타일을 바꾸고, 다운로드할 수 있습니다. QRdx 계정을 연결한 사용자는 추적(동적) 코드도 만들 수 있습니다. 추적 코드는 스캔 수를 집계하고, 나중에 다른 곳으로 연결을 바꿀 수 있습니다. 팀이 Slack에서 링크를 공유하면서 대화를 벗어나지 않고 코드를 만들고 싶을 때 사용하세요.

## 작동 방식 [#how-it-works]

봇은 메시지 텍스트를 저장하지 않으며 이미지를 업로드하지도 않습니다. 각 코드는 메시지에 포함된 링크를 바탕으로 QRdx가 [image API](/docs/developers/image-api)를 통해 렌더링하는 QR 이미지이며, 콘텐츠와 디자인 정보는 모두 그 링크에 담겨 있습니다. 코드의 스타일을 바꿀 때도 링크에서 두 정보를 다시 읽어 오므로, 변경하기 위해 따로 저장해 둘 것이 없습니다.

<IfAvailable feature="slackBot" id="add-the-bot-to-slack" title="Slack에 봇 추가하기">

1. QRdx에서 [설정 → 연동 → Slack](/settings/integrations/slack)을 열고 **Add the bot to Slack**을 클릭하세요. 어떤 요금제의 QRdx 계정이든 가능합니다.
2. Slack 워크스페이스를 선택하고 승인하세요. 봇은 슬래시 명령어, 봇을 향한 멘션, 봇에게 보낸 다이렉트 메시지를 볼 수 있는 권한과 메시지를 게시할 권한을 요청합니다.
3. 설정 페이지로 돌아오면 봇을 추가한 Slack 워크스페이스 목록이 표시됩니다.

같은 Slack 앱은 채널에 [알림](/docs/notifications#slack-and-discord)도 게시합니다. 봇을 추가해도 알림이 켜지지 않고, 알림을 추가해도 봇이 추가되지 않습니다.

</IfAvailable>

<IfAvailable feature="slackBot" id="make-a-qr-code" title="QR 코드 만들기">

| 위치 | 방법 | 코드가 표시되는 곳 |
| --- | --- | --- |
| 모든 채널 | `/qr` 뒤에 링크 또는 텍스트 입력 | 채널 |
| 봇이 있는 채널 | 링크 또는 텍스트와 함께 봇을 멘션 | 스레드 |
| 봇과의 다이렉트 메시지 | 링크 또는 텍스트 전송 | DM |
| 모든 메시지 | **More actions** → **Make a QR code** | 해당 메시지의 스레드 |

각 응답은 QR 코드 이미지이며, 그 아래에 콘텐츠, 버튼 세 개, 아래에서 설명하는 스타일 메뉴가 표시됩니다. 버튼은 **Download PNG**(1024픽셀), **Download SVG**, **Open in editor**이며, 편집기에서는 디자인을 더 자세히 바꿀 수 있습니다. 링크를 보내면 해당 링크가 입력된 상태로 편집기가 열리고, 텍스트를 보내면 빈 편집기가 열립니다. 텍스트는 링크에 담기지 않기 때문입니다.

바로가기는 메시지에서 첫 번째 웹 주소로 코드를 만들고, 웹 주소가 없으면 메시지 전체 텍스트로 코드를 만듭니다. 봇이 해당 채널에 없으면 코드는 본인에게만 보이며 "Only you can see this. Add the QRdx app to this channel to reply in threads."라는 안내가 함께 표시됩니다.

`/qr`만 입력하거나 `/qr help`를 입력하면 명령어가 표시됩니다. QR 코드로 만들기에는 콘텐츠가 너무 길면 이미지 대신 짧은 설명이 표시되며, 본인에게만 보입니다.

</IfAvailable>

<IfAvailable feature="slackBot" id="style-your-code" title="코드 스타일 지정하기">

각 코드 아래에는 **Look**, **Color**, **Frame**, **Logo** 메뉴 네 개가 있습니다. 항목을 선택하면 코드가 그 자리에서 바뀌고 새 다운로드 링크가 만들어집니다. 선택한 항목은 현재 코드 상태에 이어서 적용됩니다. 스타일은 코드를 만든 사람만 바꿀 수 있으며, 다른 사람이 선택하면 Slack이 그 사람에게만 보이는 안내를 표시하고 코드는 그대로 유지됩니다.

Look은 편집기의 기본 제공 디자인 중 작은 크기에서도 잘 읽히는 것들입니다. **Plain**은 흰 바탕에 검은색인 디자인입니다. Look을 선택하면 모양과 색상이 바뀌고, 앞서 선택한 프레임과 로고는 유지됩니다. 색상을 선택하면 코드 전체가 흰 바탕 위에 해당 색상으로 바뀝니다. 프레임에는 "Scan me" 라벨이 추가되고, 로고 메뉴에서는 편집기의 빠른 아이콘 일곱 개를 선택할 수 있습니다.

코드를 만들 때 링크나 텍스트 뒤에 옵션을 추가해 스타일을 지정할 수도 있습니다. 옵션 이름은 [QRdx CLI](/docs/developers/cli)와 같습니다.

```text title="Slack message"
/qr qrdx.dev --look modern --fg 0051ff --frame banner-bottom --frame-text "Scan me"
```

첫 번째 옵션 앞의 내용이 모두 콘텐츠입니다. Look이 먼저 적용되고 그 위에 나머지 옵션이 적용되므로, `--look royal --fg 0051ff`는 Royal의 모양을 유지하면서 파란색으로 만듭니다. 옵션은 멘션과 다이렉트 메시지에서도 사용할 수 있습니다. 옵션이나 값이 잘못되면 봇이 본인에게만 알려 주고 사용할 수 있는 값을 나열합니다.

| 옵션 | 바뀌는 항목 | 값 |
| --- | --- | --- |
| `--look` | 편집기 프리셋 중 하나로 디자인 전체 | `plain`, `classic`, `modern`, `royal`, `folio`, `caffeine`, `retro`, `bordeaux`, `blossom` |
| `--fg` (또는 `--color`) | 점, 그리고 따로 지정하지 않은 경우 모서리 눈 | `0051ff` 같은 16진수 색상, 또는 `black`, `blue`, `green`, `red`, `purple`, `orange` |
| `--bg` | 배경 | `--fg`와 같음 |
| `--eye-color` | 모서리 눈 세 개 | `--fg`와 같음 |
| `--dot-color` | 모서리 눈의 중심 | `--fg`와 같음 |
| `--body` | 점의 모양 | 편집기의 {facts.bodyPatterns}가지 점 모양 중 하나(예: `rounded`, `circle`, `classy`) |
| `--eye` | 모서리 눈의 모양 | {facts.eyeShapes}가지 눈 모양 중 하나(예: `square`, `rounded`, `gear`) |
| `--dot` | 눈 중심의 모양 | {facts.eyeCentres}가지 중심 모양 중 하나(예: `square`, `rounded`, `circle`) |
| `--frame` | 코드를 둘러싸는 프레임 | `none` 또는 기본 제공 프레임 {facts.frameStyles}가지 중 하나(예: `banner-bottom`, `banner-top`, `speech-bubble`, `polaroid`) |
| `--frame-text` | 프레임 라벨(최대 24자) | 아무 텍스트(공백이 있으면 따옴표로 묶기). `--frame` 없이 사용하면 코드 아래 배너에 표시됩니다 |
| `--template` | 템플릿으로 그린 프레임 | `Arrow`, `StandardBox`, `SquareBorder`, `StrikedBox`, `DotRing`, `Halloween`, `default`(대소문자 무관) |
| `--logo` | 가운데에 넣는 아이콘 | `link`, `wifi`, `location`, `phone`, `email`, `whatsapp`, `instagram`, `file`, `calendar`, `none` |

스타일을 적용한 코드는 게시하기 전에 편집기와 같은 스캔 점수로 QRdx가 검사합니다. 휴대폰이 읽기 어려운 디자인이면 QRdx가 이를 조정하고(더 어두운 색상, 더 단순한 모양, 더 높은 오류 정정) 코드 아래에 그 사실을 알립니다. 그래도 충분하지 않으면, 대개 콘텐츠가 길 때인데, 흰 바탕에 검은색인 코드와 안내가 표시됩니다. `/qr`로 만든 스타일 코드는 검사를 거치므로 명령어를 보낸 뒤 잠시 후에 표시됩니다.

**Open in editor**를 클릭하면 색상, 모양, 프레임, 테두리가 같은 디자인으로 편집기가 열립니다. 로고 아이콘은 링크에 담기지 않으므로 편집기에서 다시 선택하세요.

본인에게만 보이는 바로가기 코드에는 메뉴가 없으며, 추적 코드는 기본 디자인이 유지됩니다.

</IfAvailable>

<IfAvailable feature="slackBot" id="tracked-codes" title="추적 코드">

일반 코드에는 링크 자체가 담겨 있습니다. 추적 코드에는 사용자의 링크로 리디렉션되는 짧은 링크(`https://qrdx.dev/q/<slug>`)가 담겨 있어, QRdx가 스캔 수를 집계하고 이동할 위치를 바꿀 수 있습니다. Slack에서 추적 코드를 만들려면 QRdx 계정을 한 번 연결하세요.

1. `/qr link`를 실행하세요. 본인에게만 보이는 **Link QRdx account** 버튼이 QRdx를 엽니다. 이 버튼은 10분 동안 유효합니다.
2. 요청하면 QRdx에 로그인하세요. 그런 다음 **Sign in with Slack**을 클릭하고 `/qr link`를 실행한 것과 같은 Slack 계정으로 로그인하세요. Slack은 QRdx에 Slack 사용자와 워크스페이스만 알려 주며, QRdx는 두 정보가 일치하는지 확인합니다. 다른 사람의 Slack 계정으로 로그인하면 아무것도 연결되지 않습니다.
3. 추적 코드를 보낼 QRdx 워크스페이스를 선택하고 **Confirm**을 클릭하세요. 이 링크로 해당 Slack 계정이 사용자의 워크스페이스에서 코드를 만들 수 있게 되므로, 최근에 확인하지 않았다면 QRdx가 먼저 [본인 확인](/docs/help/privacy-and-security/two-step-verification#confirm-its-you)을 요청합니다.
4. Slack으로 돌아오면 봇이 연결된 QRdx 계정과 워크스페이스 이름이 담긴 다이렉트 메시지를 보냅니다. 직접 연결한 적이 없다면 `/qr unlink`를 실행하세요.
5. `/qr track` 뒤에 `https://` 또는 `http://`로 시작하는 링크를 입력해 실행하세요. `track`과 링크를 넣어 봇을 멘션해도 됩니다.

코드는 짧은 링크와 해당 QRdx 워크스페이스 이름과 함께 채널에 표시됩니다. 대시보드의 코드로 이동하는 **Open in QRdx** 버튼은 본인에게만 보이는 별도 메시지로 전송됩니다. 코드 이름은 링크 사이트 이름 뒤에 "from Slack"이 붙은 형태이며, 워크스페이스의 코드 목록에서 다른 코드와 똑같이 찾을 수 있습니다.

추적 코드에는 대시보드에서 만든 코드와 같은 규칙이 적용됩니다. 역할이 코드 생성을 허용해야 하고, 2단계 인증이 필수인 워크스페이스에서는 계정에서 2단계 인증이 켜져 있어야 하며, 요금제의 활성 동적 QR 코드 한도도 적용됩니다. 한도에 도달하면 봇이 이를 알리고 요금제 링크를 제공합니다. 이 조건은 매번 확인하므로 워크스페이스를 떠나거나 접근 권한을 잃으면 해당 워크스페이스에서는 연결이 작동하지 않습니다.

Slack 계정은 Slack 워크스페이스마다 연결을 하나씩 가집니다. 이미 연결된 Slack 계정으로 `/qr link`를 실행하면 페이지에 연결된 QRdx 워크스페이스와 다른 QRdx 계정에 연결되어 있는지가 표시됩니다. 이때 버튼은 **Replace the link**로 바뀌며, 클릭하기 전에는 아무것도 바뀌지 않습니다. `/qr unlink`로 연결을 해제할 수 있으며, [설정 → 연동 → Slack](/settings/integrations/slack)의 **Linked Slack accounts**에서 **Unlink**를 클릭해도 됩니다.

QRdx 워크스페이스의 소유자와 관리자는 **설정** → **API keys & apps**의 **Slack accounts**에서 해당 워크스페이스에 연결된 모든 Slack 계정을 볼 수 있습니다. Slack 워크스페이스, Slack 사용자 ID, 대신 활동하는 멤버, 연결된 시점이 표시됩니다. 여기서 **Revoke**를 클릭하면 연결이 제거됩니다. 워크스페이스에 [감사 로그](/docs/help/teams/audit-log)가 있으면 `/qr track`으로 만든 코드는 멤버 이름 뒤에 "via Slack"이 붙고 Slack 사용자 ID와 워크스페이스 ID와 함께 기록되며, 연결을 해지한 내역도 기록됩니다.

</IfAvailable>

## 봇이 보관하는 정보 [#what-the-bot-keeps]

봇은 누군가 `/qr`을 실행하거나, 봇을 멘션하거나, 봇에게 다이렉트 메시지를 보내거나, 해당 메시지에서 바로가기를 사용할 때만 메시지를 읽습니다. 메시지 텍스트는 저장하지 않습니다. QR 코드 이미지는 QRdx [Image API](/docs/developers/image-api)에서 가져오며, Slack이 메시지 안의 링크로 불러오므로 업로드되는 것은 없습니다.

QRdx는 Slack 워크스페이스마다 워크스페이스 ID와 이름, 봇의 Slack 사용자 ID, 부여된 권한 범위, 봇 토큰(암호화됨), 어떤 QRdx 계정이 언제 추가했는지를 보관합니다. 연결된 Slack 계정마다 Slack 사용자 ID와 워크스페이스 ID, QRdx 계정, 선택한 워크스페이스, 연결한 시점을 보관합니다. 연결하려고 Slack으로 로그인해도 보관하는 정보는 늘어나지 않습니다. QRdx는 Slack 사용자와 워크스페이스를 비교한 뒤 로그인 정보를 삭제합니다.<IfAvailable feature="slackBot"> 연결된 Slack 계정은 [데이터 내보내기](/docs/help/account-and-billing/export-your-data)에 포함됩니다.</IfAvailable>

한 사람이 채널을 도배하지 못하도록, 봇은 사람별로 1분 동안 만들거나 스타일을 바꾼 코드 수와, Slack 워크스페이스 및 QRdx 전체에서 함께 만든 코드 수를 셉니다. 요청이 너무 많이 들어오면 "QRdx is busy right now. Try again in a minute."라고 응답합니다. 두 집계 모두 콘텐츠는 담지 않습니다.

<IfAvailable feature="slackBot" id="remove-the-bot" title="봇 제거하기">

Slack에서 앱 페이지를 열고 **Remove App**을 선택하세요(또는 Slack 관리자에게 요청하세요). 그러면 QRdx가 해당 Slack 워크스페이스의 봇 토큰과 그곳에서 만든 모든 Slack 계정 연결을 삭제합니다. 이미 만든 코드는 QRdx에 남고, 추적 코드는 계속 작동합니다.

</IfAvailable>

## 개발자용 [#for-developers]

봇은 두 가지 공개 도구 위에 얹은 얇은 계층입니다. [Image API](/docs/developers/image-api)가 모든 코드를 렌더링하고, 추적 코드는 [REST API](/docs/developers/api/list-codes)로 읽을 수 있는 일반 동적 QR 코드입니다. 같은 스타일 옵션은 [CLI](/docs/developers/cli)에도 있습니다.

## 셀프 호스팅 [#self-hosting]

봇은 "Add to Slack" 알림과 같은 Slack 앱을 사용하며, 여기에 서명 시크릿을 추가합니다. `SLACK_CLIENT_ID`, `SLACK_CLIENT_SECRET`, `SLACK_SIGNING_SECRET`을 설정하세요. 프로덕션에서는 봇 토큰을 암호화하는 `INTEGRATION_ENCRYPTION_KEY`도 설정해야 합니다. 이 값들이 없으면 봇의 페이지와 엔드포인트는 존재하지 않습니다. 저장소의 `plugins/slack/manifest.json`은 앱의 매니페스트이고, `plugins/slack/README.md`에 이 매니페스트로 앱을 만드는 과정이 안내되어 있습니다. 매니페스트에는 사용자가 계정을 연결할 때 Sign in with Slack에 필요한 `openid` 사용자 스코프와 리디렉션 URL `/api/integrations/slack/link/callback`이 들어 있습니다. 속도 제한에는 Upstash Redis가 필요하며, 없으면 속도 제한이 꺼집니다. [셀프 호스팅](/docs/self-hosting#optional-services)을 참고하세요.
