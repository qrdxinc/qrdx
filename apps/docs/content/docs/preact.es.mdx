Al terminar esta página tendrás un código QR con estilo en un componente de Preact y un botón que lo guarda como PNG. `qrdx/preact` incluye los dos componentes SVG de la biblioteca de React, `QRCodeSVG` y `QRCode`, creados para Preact. Dibujan con el propio `h` de Preact, así que no necesitas `preact/compat` ni `react`, y dibujan el mismo SVG que los componentes de React.

<NpmStatus package="qrdx" />

## Antes de empezar [#before-you-start]

- Un proyecto con Preact 10 o posterior, con Vite o cualquier otro empaquetador.
- Node.js 18 o posterior.

## Constrúyelo [#build-it]

### 1. Instala qrdx [#1-install-qrdx]

```package-install
qrdx
```

`preact` es una dependencia peer opcional de `qrdx`. Tu aplicación ya la tiene.

### 2. Dibuja un código [#2-draw-a-code]

```tsx title="src/components/menu-code.tsx"
import { QRCodeSVG } from "qrdx/preact";

export function MenuCode() {
  return (
    <QRCodeSVG
      value="https://example.com/menu"
      size={256}
      margin={4}
      bodyPattern="rounded"
      frame={{ style: "banner-bottom", text: "Scan me" }}
      aria-label="QR code for the menu"
    />
  );
}
```

La página muestra un código de 256 px con módulos redondeados y un banner "Scan me" debajo.

<Shot id="lib-preact-code" />

`QRCodeSVG` acepta todas las opciones que acepta el `QRCodeSVG` de React: patrones, colores y degradados, logotipos (`imageSettings`), marcos, formas, plantillas y arte. Atributos como `class`, `style` o `aria-label` se aplican al `<svg>`, o al `<svg>` exterior del marco cuando hay un marco.

`QRCode` añade el atajo de logotipo del `QRCode` de React: `logo`, `logoOptions`, `hideLogo` y `scale`. Solo acepta las props del código y `style`; pon `class` o `aria-label` en un elemento que lo envuelva, o usa `QRCodeSVG`.

```tsx title="src/components/logo-code.tsx"
import { QRCode } from "qrdx/preact";

export function LogoCode() {
  return <QRCode value="https://example.com" size={256} logo="/logo.png" level="H" />;
}
```

Ambos componentes se vuelven a dibujar cuando cambia una prop y se saltan el trabajo cuando no cambia ninguna. Los controladores de eventos de las props no se ponen en el `<svg>`, igual que en React. Ponlos en un elemento que envuelva el código.

### 3. Guárdalo como archivo [#3-save-it-as-a-file]

Los componentes solo dibujan el código. Las descargas, `toSVGString`, la puntuación de escaneo y las demás funciones vienen de `qrdx/core`. Ese es el motor que los componentes ya usan, así que no se incluye dos veces.

```tsx title="src/components/downloadable-code.tsx"
import { downloadQRCode } from "qrdx/core";
import { QRCodeSVG } from "qrdx/preact";

const options = { value: "https://example.com", size: 256, margin: 4 };

export function DownloadableCode() {
  return (
    <>
      <QRCodeSVG {...options} />
      <button
        type="button"
        onClick={() =>
          downloadQRCode(options, {
            format: "png",
            size: { width: 1024, height: 1024 },
            filename: "qr-code.png",
          })
        }
      >
        Download PNG
      </button>
    </>
  );
}
```

Al hacer clic en el botón se guarda `qr-code.png` a 1024 px. Mantén las opciones en un solo objeto, como arriba, para que el archivo coincida con el código en pantalla. [JavaScript puro](/docs/vanilla-js) cubre `qrdx/core` por completo.

## Renderizado en el servidor [#server-rendering]

`renderToString` de `preact-render-to-string` escribe el mismo SVG que `toSVGString` de `qrdx/core`. La única diferencia es el escape: Preact deja `>` y `'` tal cual en el texto, mientras que el núcleo escribe `&gt;` y `&#x27;`. Los navegadores leen ambos igual.

`hydrate` conserva el `<svg>` del servidor y no lo dibuja otra vez. El marcado no tiene ids aleatorios, así que el servidor y el navegador siempre coinciden.

## Con preact/compat [#with-preactcompat]

Si tu aplicación ya usa un alias de `react` a `preact/compat`, los componentes de React de `qrdx` también funcionan: `import { QRCodeSVG } from "qrdx"`. `qrdx/preact` dibuja el mismo código sin el alias, así que es preferible cuando añades `qrdx` a una aplicación de Preact.

## Si algo sale mal [#if-something-goes-wrong]

- **`Failed to resolve import "react"`.** Importaste desde `qrdx` en lugar de `qrdx/preact`, en una aplicación sin `preact/compat`. Cambia la importación.
- **Un controlador de clic en el componente no hace nada.** Los controladores se descartan en el `<svg>`. Envuelve el código en un `<button>` o un `<div>` y pon el controlador ahí.
- **`PDF export needs the optional "jspdf" package`.** Ejecuta `npm install jspdf` en la aplicación.
