Al final de esta página tendrás un código QR renderizado por un Server Component sin JavaScript en el cliente, un código creado a partir de un parámetro de ruta, un código en vivo enlazado a un campo de entrada, un código con tu logo y un botón que guarda un SVG. `QRCodeSVG` y `QRCode` no usan hooks exclusivos del cliente, así que un Server Component renderiza el código directamente en el HTML de la página. Solo necesitas un Client Component cuando el valor cambia en el navegador o para guardar un archivo.

<NpmStatus package="qrdx" />

## Antes de empezar [#before-you-start]

- Un proyecto de Next.js con el App Router. Los ejemplos usan el `params` asíncrono del App Router, como en Next.js 15 y 16.
- React 18 o posterior, que el App Router ya exige.

## Constrúyelo [#build-it]

### 1. Instala qrdx [#1-install-qrdx]

```package-install
qrdx
```

`react` y `react-dom` son dependencias entre pares (peer dependencies), así que se usan las versiones de tu propia aplicación.

### 2. Renderiza un código en un Server Component [#2-render-a-code-in-a-server-component]

```tsx title="app/page.tsx"
import { QRCodeSVG } from "qrdx";

export default function Page() {
  return (
    <QRCodeSVG
      value="https://example.com"
      size={256}
      margin={4}
      role="img"
      aria-label="QR code for example.com"
    />
  );
}
```

Abre la página. El `<svg>` forma parte del HTML que envía el servidor, por lo que se muestra antes de que cargue cualquier JavaScript, una página estática lo renderiza una sola vez durante la compilación y los lectores de pantalla reciben el `aria-label`.

<Shot id="lib-nextjs-server-code" />

`margin` es la zona de silencio alrededor del código, en módulos. Por defecto es 0, lo que va bien para un código dentro de una tarjeta con su propio relleno. El estándar QR pide 4, la opción segura sobre un fondo cargado u oscuro.

### 3. Crea el valor a partir de un parámetro de ruta [#3-build-the-value-from-a-route-param]

```tsx title="app/tickets/[id]/page.tsx"
import { QRCodeSVG } from "qrdx";

export default async function TicketPage({
  params,
}: {
  params: Promise<{ id: string }>;
}) {
  const { id } = await params;
  const url = `https://example.com/check-in/${encodeURIComponent(id)}`;
  return <QRCodeSVG value={url} size={200} margin={4} level="H" />;
}
```

Visita `/tickets/A-12` y el código abre `https://example.com/check-in/A-12`. Next.js pasa `params` como una promesa, por eso la página es `async`. Codifica todo lo que venga de un usuario o de una base de datos antes de incluirlo en una URL. El nivel `H` permite que hasta un 30 % del código esté dañado, lo que ayuda en una credencial que se dobla o se rasca.

### 4. Sigue un campo de entrada en un Client Component [#4-follow-an-input-in-a-client-component]

```tsx title="components/live-qr-code.tsx"
"use client";

import { QRCodeSVG } from "qrdx";
import { useState } from "react";

export function LiveQrCode() {
  const [value, setValue] = useState("https://example.com");
  return (
    <div>
      <input
        aria-label="Text or link to encode"
        value={value}
        onChange={(event) => setValue(event.target.value)}
      />
      {value ? <QRCodeSVG value={value} size={200} margin={4} /> : null}
    </div>
  );
}
```

El código se redibuja con cada pulsación de tecla, y el primer valor sigue renderizándose en el servidor. Una página Server Component puede importar este componente tal cual.

`QRCodeCanvas` también es un Client Component (incluye `"use client"`), pero solo dibuja módulos cuadrados simples. Usa `QRCodeSVG` o `QRCode` para códigos con estilo.

### 5. Añade un logo [#5-add-a-logo]

```tsx title="components/logo-qr-code.tsx"
import { QRCode } from "qrdx";

export function LogoQrCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      margin={4}
      level="H"
      logo="/logo.png"
    />
  );
}
```

`/logo.png` es un archivo de la carpeta `public` de tu proyecto. El logo se dibuja a un cuarto del ancho del código y se despejan los módulos que quedan detrás, así que el código depende de la corrección de errores para poder escanearse: por eso `level` es `H`. `QRCode` también reduce un logo demasiado grande para que el código pueda repararlo.

`logo` acepta una ruta de tu aplicación, una URL o una URL de datos. Para las descargas, lo más seguro es una URL de datos, porque una imagen remota necesita encabezados CORS antes de que el navegador pueda copiarla al archivo. `logoOptions` define el tamaño, el espacio libre, la posición y el recorte del logo; consulta [Añadir un logo en código](/docs/features/logos).

### 6. Descarga como SVG [#6-download-as-svg]

```tsx title="components/download-svg-button.tsx"
"use client";

import { downloadQRCode } from "qrdx";

export function DownloadSvgButton({ value }: { value: string }) {
  return (
    <button
      type="button"
      onClick={() =>
        downloadQRCode(
          { value, level: "Q", margin: 4 },
          {
            format: "svg",
            size: { width: 1024, height: 1024 },
            filename: "qr-code.svg",
          },
        )
      }
    >
      Download SVG
    </button>
  );
}
```

Al hacer clic en el botón se guarda `qr-code.svg`, un archivo vectorial de 1024 px. `downloadQRCode` necesita el DOM del navegador, por eso el botón es un Client Component. Una página Server Component puede renderizarlo igualmente y pasarle el valor como prop. Para otros archivos, establece `format` en `png`, `jpg`, `webp`, `eps` o `pdf` (PDF requiere el paquete opcional `jspdf`). [Exportar y descargar](/docs/features/downloads) cubre todas las opciones.

## Cuando necesitas una URL de imagen [#when-you-need-an-image-url]

Los correos electrónicos, las imágenes Open Graph, los archivos Markdown y otros lugares que no pueden ejecutar React necesitan una URL de imagen en lugar de un componente. La [API de imágenes de códigos QR](/docs/developers/image-api) devuelve una sin clave:

```html title="email.html"
<img src="https://api.qrdx.dev/v1/qr?data=https://example.com&format=png" width="256" height="256" alt="QR code for example.com" />
```

```bash title="Terminal"
npx shadcn@latest add https://qrdx.dev/r/qr-code.json
```

## Si algo sale mal [#if-something-goes-wrong]

- **`useRef only works in Client Components` (o lo mismo para `useState`).** Renderizaste `QRCodeCanvas`, o un componente con hooks, desde un Server Component. Añade `"use client"` al principio de ese archivo, o renderiza `QRCodeSVG` en su lugar.
- **El logo se ve en la página pero no en el archivo descargado.** La imagen viene de otro origen sin encabezados CORS. Sírvela desde `public` o pasa una URL de datos.
- **`PDF export needs the optional "jspdf" package`.** Ejecuta `npm install jspdf` en la aplicación. Los demás formatos no necesitan nada adicional.
