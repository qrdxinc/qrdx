---

QRdx 可以一次性导入其他服务商的链接和动态码，让你无需重新印刷已经投放出去的二维码即可完成迁移。每次导入都遵循相同的三个步骤：选择要导入的内容、预览、导入。如果你在其他服务中有二维码，并希望在 QRdx 中编辑和追踪它们，请参阅本指南。

<Callout type="info" title="套餐">
  所有套餐都可以使用导入功能，但受你的套餐有效二维码数量上限限制。保留原有短链后缀需要 Pro 或 Business。参见[套餐与限制](/docs/plans-and-limits)。
</Callout>

时间紧？请看简短的任务页面：[从其他服务导入二维码](/docs/help/dynamic-codes/import)。

## 工作原理 [#how-it-works]

<Diagram id="import-flow" />

打开[二维码](/dashboard?to=codes)，然后点击 **⋯** 菜单 → **导入二维码** → **从 Bitly 和其他应用**。来源分为两类：

- **已连接的账户：**Bitly、Rebrandly 和 Short.io。QRdx 通过服务商的 API 列出你的链接。
- **导出文件：**QR Code Generator PRO、Uniqode (Beaconstac)、Flowcode、QR TIGER、ME-QR、TinyURL、Hovercode、Scanova，或任何包含目标网址的 CSV。

导入过程本身不会改动你的旧账户。

### 导入会创建什么 [#what-an-import-creates]

每个链接或二维码都会成为一个[动态二维码](/docs/dynamic-qr-codes)，包含：

- 目标地址和标题；
- 标签（可选），以及一个类似“Imported from Bitly”的文件夹（你可以重命名或关闭）；
- 类似 `Imported from Bitly bit.ly/3AbCdEf on 2026-11-01.` 的备注，以及该链接的原始创建日期。QRdx 会为新二维码设置自己的创建日期。

预览会显示将创建多少个二维码、哪些标签是新的，以及哪些会被跳过：

- **已导入：**之前（任何一次更早的导入）已导入的链接始终会被跳过，因此重复运行导入不会产生重复项。
- **已存在相同目标地址：**目标地址已有对应 QRdx 二维码的链接默认会被跳过。勾选该选项即可强制导入。
- **超出套餐限制：**超出你套餐有效二维码数量的链接。预览会提供导入能容纳的前若干个链接，或升级套餐的选项。
- **无法导入：**目标地址缺失或无效的链接，以及已指向 QRdx 短链接的链接。

导入以每批 50 个的方式运行，并显示进度条。关闭对话框是安全的：再次打开导入器，导入会从**最近导入**中继续。摘要会列出已创建、已跳过和失败的二维码及原因。

## 从已连接的账户导入 [#from-a-connected-account]

1. 选择服务商。如果尚未连接，可以直接在此连接（登录，或粘贴 API 密钥或令牌）。令牌会加密存储，你可以随时在[设置 → 集成](/settings/integrations)中断开连接。
2. 搜索、按域名或标签筛选，然后选择链接。**选择所有匹配的链接**每次导入最多处理 1,000 个链接；其余的请再次运行导入。
3. 检查预览，然后点击**导入**。

| 服务商 | 连接方式 | 列出链接 | 让已印刷的二维码继续有效 |
| --- | --- | --- | --- |
| Bitly | 登录，或使用通用访问令牌 | 支持 | 仅限 Bitly 付费套餐：Core 每月 5 次链接重定向，Growth 20 次，Premium 110 次 |
| Rebrandly | API 密钥 | 支持 | 受 Rebrandly 每月目标地址修改次数限制：Essentials 10 次，Professional 50 次，Growth 150 次（免费版无） |
| Short.io | API 密钥 | 支持，一次一个域名 | 支持，所有套餐均可 |

套餐限制由各服务商自行制定，并会随时间变化。请查看它们的定价页面。

## 让已印刷的二维码继续有效 [#keep-printed-codes-working]

你用其他服务商印刷的二维码，编码的是该服务商的短链接。通过已连接账户完成导入后，摘要中会提供**让我已印刷的二维码继续有效**：

1. **试运行**会列出每个旧链接，以及它将指向的 QRdx 链接。此时不会有任何改动。
2. 确认后，QRdx 会把每个旧链接的目标地址改为对应的新 QRdx 二维码。访问者仍会到达同一个页面，并且每次扫描现在都会显示在 QRdx 分析中。旧服务商仍会先记录一次点击。
3. **撤销**会恢复原始目标地址，这些地址已由 QRdx 在导入时保存。

如果服务商拒绝修改（例如 Bitly 套餐的链接重定向次数已用完），QRdx 会停止、说明原因，并保持其余链接不变。因目标地址已有 QRdx 二维码而被跳过的链接，会指向那个已有的二维码。<IfAvailable feature="customDomains"> 短链后缀随你的自有域名迁移的链接（见下文）不会被修改：DNS 切换后，它们本身就是 QRdx 链接。</IfAvailable>

<Callout type="warn" title="暂时保留旧账户">
  在确认一切无误之前，请保持与服务商的连接：撤销需要这个连接。旧账户也必须保持有效，其链接才能继续重定向。
</Callout>

## 保留原有短链后缀 [#keep-the-original-back-halves]

在 Pro 和 Business 上，请在导入预览中勾选**保留原有短链后缀**。这样，只要 QRdx 能保留，每个二维码就会使用它原来的短链后缀，而不是随机生成的，例如 `bit.ly/spring-menu` 会变成 `qrdx.dev/q/spring-menu`：

- 短链后缀满足以下条件时会被保留：由 3 到 64 个字母、数字、`-` 或 `_` 组成，不以 `-` 开头或结尾（参见[自定义短链后缀](/docs/dynamic-qr-codes#custom-back-halves)），不是保留字，并且在 `qrdx.dev` 上尚未被任何 QRdx 二维码使用<IfAvailable feature="customDomains">（若使用你自己的域名，则只需不与该域名下你自己的二维码重复）</IfAvailable>。
- 否则，该二维码会使用生成的短链后缀，预览会显示这一变更及原因，例如 `spring-menu → Ab3xK9q · Another QRdx code already uses this back-half on qrdx.dev`。导入时使用的正是预览中显示的短链后缀。
- 短链后缀区分大小写，与 Bitly 和 Short.io 相同。

无法保留的短链后缀会改用生成的后缀；这些链接需要重新印刷，或在旧服务商处设置重定向。

<IfAvailable feature="customDomains" id="your-own-domain-go-yourbrand-com" title="你的自有域名（go.yourbrand.com）">

如果你的链接使用自有域名，你可以把该域名迁移到 QRdx 并保留短链后缀，这样 `go.yourbrand.com/spring-menu` 在 DNS 切换后仍然有效。

1. 先在**设置** → **域名**中添加该域名。此时可以暂不验证：短链后缀会保留在该域名本身之下，只需在你自己的二维码中保持唯一，且只有少数技术词汇是保留字。
2. 在导入预览中，勾选**保留原有短链后缀**，并在**链接位于**下选择该域名。预览会显示哪些短链后缀会被保留。
3. 导入。二维码会放到该域名下，并立即占用各自的短链后缀。
4. 将域名的 DNS 指向 QRdx 并完成验证（参见[自定义域名](/docs/custom-domains)）。请选在访问低峰期进行：DNS 一旦切换，该域名下的链接就会在旧服务商处失效，并在验证通过后于 QRdx 上生效。

如果导入时该域名尚未添加到 QRdx，其短链后缀会改为保留在 `qrdx.dev` 上（在那里它们必须在整个 QRdx 范围内未被占用）。添加并验证域名后，点击导入摘要中的**关联二维码**，即可把这些二维码移到该域名下。

</IfAvailable>

## 从导出文件迁移 [#from-an-export-file]

1. 获取文件（步骤见下文）。QRdx 每次最多读取 2 MB、1,000 行的 CSV；如果是 Excel 文件，请先另存为或下载为 CSV。
2. 在导入工具中选择服务商并上传文件。QRdx 会尽可能识别该服务商的列，你也可以调整列映射。只有目标地址是必填项；旧短链接（或二维码 ID）可让重新上传时跳过已导入的二维码。
3. 预览并导入，然后使用 **Copy all new links** 或 **Download mapping CSV**（旧链接 → 新 QRdx 链接）。

QRdx 无法修改托管在服务商自有域名上的二维码。要让已印刷的二维码继续有效，请在旧服务商中打开每个旧的动态二维码，把它的目标地址设置为映射表中对应的新 QRdx 链接。旧账户必须保持有效，这些二维码才能继续跳转；请在取消旧账户之前，改用 QRdx 二维码重新印刷。<IfAvailable feature="customDomains"> 使用你自己域名的二维码可以随域名一起迁移，无需重新印刷：参见上文的[你自己的域名](#your-own-domain-go-yourbrand-com)。</IfAvailable>

### QR Code Generator PRO [#qr-code-generator-pro]

该服务商没有公开的二维码列表导出功能。请制作一份电子表格，为每个二维码填写 **Name**、**Short URL** 和 **Destination URL**。重新指向的方法：打开二维码 → **Details** → **Edit**，替换 URL 并保存。如果二维码很多，可使用它的批量更新功能，上传包含新 URL 的 CSV，最多支持 500 个二维码。

### Uniqode (Beaconstac) [#uniqode-beaconstac]

**QR Codes → Dynamic**，全选，**⋯ → Export**，按组织或文件夹导出。导出文件中的列（QR Code Name、QR Code URL、Destination URL、Labels 等）都能被识别。重新指向的方法：打开二维码 → **Edit** → 新 URL → **Next** → **Save**。

### Flowcode [#flowcode]

Flowcode 只导出位于文件夹中的二维码，所以请先把二维码移入文件夹。然后打开 **Folder** 部分，勾选文件夹并点击 **Download URLs**。该 CSV 的列（Flowcode Name、Short Links、Scan Destination）可以被识别，批量创建表格的列（Flowcode Name、Flowcode Scan URL）也可以。重新指向的方法：**Assets** → 该二维码 → **Overview** → **Destination** → **Save**。

### QR TIGER [#qr-tiger]

**My Account** → 选择一个类别（例如 URL）→ **Download QR List**，每个类别导出一次。重新指向的方法：**My Account → Dashboard → URL** → 对应的活动 → **Edit** → **Save**。

### ME-QR [#me-qr]

该服务商没有导出功能。请为每个二维码列出名称、二维码链接和目标 URL。重新指向的方法：在 ME-QR 的二维码列表中编辑该二维码。

### TinyURL [#tinyurl]

TinyURL 在其付费套餐中提供 CSV 导出。请将链接导出为 CSV，或列出别名和长 URL。修改 TinyURL 的目标地址需要付费的 TinyURL 套餐。

### Hovercode、Scanova 及其他服务商 [#hovercode-scanova-and-others]

从服务商处将二维码导出为 CSV（Hovercode 在其 Business 套餐中提供 CSV 导出；Scanova 会通过电子邮件发送下载链接），然后检查列映射。任何带有目标地址列的 CSV 都可以通过 **Another provider (CSV)** 导入。

静态二维码（来自 goQR.me、QR Code Monkey、Adobe Express 及类似工具）直接编码了目标内容本身，因此无需原工具也能继续使用。只有当你希望为新的印刷品生成可编辑、可追踪的二维码时，才需要从 CSV 导入它们的目标地址。

## 从二维码库迁移 [#from-a-qr-code-library]

这些库生成的是静态二维码，因此无需迁移：已印刷的二维码仍然有效。要切换应用中的渲染方式，请安装 `qrdx` 并替换组件。

### 从 qrcode.react 迁移 [#from-qrcode-react]

```tsx title="Before and after"
// Before
import { QRCodeSVG } from "qrcode.react";

<QRCodeSVG value="https://example.com" size={256} fgColor="#111827" />;

// After
import { QRCodeSVG } from "qrdx";

<QRCodeSVG
  value="https://example.com"
  size={256}
  fgColor="#111827"
  bodyPattern="rounded"
/>;
```

`value`、`size`、`level`、`fgColor`、`bgColor`、`marginSize`（对应 `margin`）和 `imageSettings` 都可直接沿用；qrdx 另外提供图案、渐变和模板。参见 [API 参考](/docs/api-reference)。

### 从 qr-code-styling 迁移 [#from-qr-code-styling]

```tsx title="Before and after"
// Before
import QRCodeStyling from "qr-code-styling";

const qr = new QRCodeStyling({
  data: "https://example.com",
  width: 256,
  dotsOptions: { type: "rounded", color: "#111827" },
  image: "/logo.png",
});
qr.append(ref.current);

// After
import { QRCodeSVG } from "qrdx";

<QRCodeSVG
  value="https://example.com"
  size={256}
  bodyPattern="rounded"
  fgColor="#111827"
  imageSettings={{ src: "/logo.png", width: 64, height: 64, excavate: true }}
/>;
```

qrdx 是一个 React 组件，所以不需要创建实例再追加到页面：像渲染其他元素一样渲染它即可。下载功能使用 [API 参考](/docs/api-reference)中的辅助函数。

## 面向开发者 [#for-developers]

如果想用脚本迁移二维码，可以通过[二维码 API](/docs/developers/api/create-codes)创建：Pro 和 Business 每次请求最多 {facts.apiBatchCodes} 个，用 `slug` 保留你想沿用的短链后缀，并用 `Idempotency-Key` 确保重试不会产生重复的批次。
