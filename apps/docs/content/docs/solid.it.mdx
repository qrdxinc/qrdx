Alla fine di questa pagina avrai un QR code stilizzato in un componente Solid che segue un signal, e un pulsante che lo salva come PNG. `qrdx/solid` offre i due componenti SVG della libreria React, `QRCodeSVG` e `QRCode`, realizzati per SolidJS. Disegnano lo stesso SVG dei componenti React, seguono i tuoi signal e funzionano anche su un server.

<NpmStatus package="qrdx" />

## Prima di iniziare [#before-you-start]

- Un progetto Solid 1.8 o successivo (nella linea 1.x), con Vite o SolidStart.
- Node.js 18 o successivo.

## Costruiscilo [#build-it]

### 1. Installa qrdx [#1-install-qrdx]

```package-install
qrdx
```

`solid-js` è una peer dependency opzionale di `qrdx`. La tua app ce l'ha già e non ti serve `react`.

### 2. Disegna un codice che segue un signal [#2-draw-a-code-that-follows-a-signal]

```tsx title="src/components/menu-code.tsx"
import { createSignal } from "solid-js";
import { QRCodeSVG } from "qrdx/solid";

export function MenuCode() {
  const [color, setColor] = createSignal("#0f172a");
  return (
    <>
      <QRCodeSVG
        value="https://example.com/menu"
        size={256}
        margin={4}
        fgColor={color()}
        frame={{ style: "banner-bottom", text: "Scan me" }}
        aria-label="QR code for the menu"
      />
      <button type="button" onClick={() => setColor("#1d4ed8")}>
        Blue
      </button>
    </>
  );
}
```

La pagina mostra un codice scuro con un banner "Scan me". Fai clic su **Blue** e il codice viene ridisegnato in blu.

<Shot id="lib-solid-signal-code" />

`QRCodeSVG` accetta tutte le opzioni di `QRCodeSVG` di React: pattern, colori e gradienti, logo (`imageSettings`), cornici, forme, template e art. Attributi come `class`, `style` o `aria-label` vanno sull'`<svg>`, oppure sull'`<svg>` esterno della cornice quando c'è una cornice.

`QRCode` aggiunge la scorciatoia per il logo del `QRCode` di React: `logo`, `logoOptions`, `hideLogo` e `scale`. Accetta solo le props del codice e `style`; metti `class` o `aria-label` su un elemento che lo racchiude, oppure usa `QRCodeSVG`.

```tsx title="src/components/logo-code.tsx"
import { QRCode } from "qrdx/solid";

export function LogoCode() {
  return <QRCode value="https://example.com" size={256} logo="/logo.png" level="H" />;
}
```

Le props sono reattive, come in qualsiasi componente Solid. Quando `color()` cambia, il codice viene ridisegnato. Gli event handler nelle props non vengono applicati all'`<svg>`, quindi mettili su un elemento che racchiude il codice.

### 3. Salvalo come file [#3-save-it-as-a-file]

I componenti si limitano a disegnare il codice. Download, `toSVGString`, il punteggio di scansione e le altre funzioni arrivano da `qrdx/core`. È il motore che i componenti usano già, quindi non viene incluso due volte.

```tsx title="src/components/downloadable-code.tsx"
import { downloadQRCode } from "qrdx/core";
import { QRCodeSVG } from "qrdx/solid";

const options = { value: "https://example.com", size: 256, margin: 4 };

export function DownloadableCode() {
  return (
    <>
      <QRCodeSVG {...options} />
      <button
        type="button"
        onClick={() =>
          downloadQRCode(options, {
            format: "png",
            size: { width: 1024, height: 1024 },
            filename: "qr-code.png",
          })
        }
      >
        Download PNG
      </button>
    </>
  );
}
```

Il clic sul pulsante salva `qr-code.png` a 1024 px. [JavaScript vanilla](/docs/vanilla-js) tratta `qrdx/core` per intero.

## Come disegna [#how-it-draws]

Il pacchetto non contiene JSX di Solid, quindi non richiede il compilatore di Solid e funziona con qualsiasi configurazione di build.

- Nel browser, un componente restituisce direttamente l'elemento `<svg>`, costruito con `createElementNS` (nessun HTML viene analizzato). Solid lo inserisce nella pagina, lo sostituisce con uno nuovo quando la modifica di una prop cambia il markup e lo rimuove quando il componente viene smontato.
- Una modifica di prop che produce lo stesso markup lascia la pagina invariata.

## Rendering lato server e idratazione [#server-rendering-and-hydration]

Con `renderToString` di `solid-js/web`, un componente scrive lo stesso markup di `toSVGString` di `qrdx/core`, più la chiave di idratazione `data-hk` di Solid sull'elemento radice. `hydrate` usa quella chiave per mantenere l'`<svg>` del server invece di disegnarlo di nuovo. All'interno di `<NoHydration>`, la chiave viene omessa.

Il markup non contiene id casuali, quindi server e browser concordano sempre.

## Se qualcosa va storto [#if-something-goes-wrong]

- **`Failed to resolve import "react"`.** Hai importato da `qrdx` invece che da `qrdx/solid`. L'entry principale contiene i componenti React; cambia l'import.
- **Un click handler sul componente non fa nulla.** Gli handler vengono scartati dall'`<svg>`. Racchiudi il codice in un elemento e metti lì l'handler.
- **`PDF export needs the optional "jspdf" package`.** Esegui `npm install jspdf` nella tua app.
