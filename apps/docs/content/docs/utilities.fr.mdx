Ces fonctions utilitaires sont les petites fonctions que le moteur de rendu et le score de scan utilisent, exportées pour votre propre interface : choisir une couleur représentative, vérifier le contraste, valider une taille de téléchargement et détecter les fonctionnalités du canvas. Elles s'exécutent partout, sauf indication contraire.

| Fonction | Retour | Remarques |
| --- | --- | --- |
| `getSolidColor(color, fallback?)` | `string` | Une couleur qui représente un `ColorConfig` : la chaîne, la `color` d'une couleur unie, le premier point d'un dégradé, l'`underlay` d'un remplissage par image, sinon `fallback` (`"#000000"`) |
| `getContrastRatio(a, b)` | `number` | Le rapport de contraste WCAG entre deux couleurs CSS, de 1 à 21. Les couleurs transparentes sont d'abord composées sur du blanc. Renvoie 1 quand une couleur ne peut pas être analysée |
| `getContrastLevel(ratio)` | `{ level, warning, message }` | `AAA` à partir de 7, `AA` à partir de 4.5, `AA Large` à partir de 3 (avec `warning: true`), `Fail` en dessous de 3 |
| `getLuminance(r, g, b)` | `number` | Luminance relative d'une couleur sRGB, de 0 à 1 |
| `hexToRgb(hex)` | `{ r, g, b } \| null` | Lit l'hexadécimal à 3, 4, 6 et 8 chiffres, en ignorant l'alpha. `null` pour tout autre format |
| `validateSize(width, height)` | `{ isValid, error? }` | La règle appliquée par chaque téléchargement : de 50 à 5000 px et carré |
| `SUPPORTS_PATH2D` | `boolean` | Indique si le canvas de cet environnement prend en charge `Path2D` avec `addPath` |

## Couleurs [#colors]

```ts title="lib/colors.ts"
import { getSolidColor, hexToRgb } from "qrdx";

getSolidColor({
  type: "linear",
  angle: 45,
  stops: [
    { color: "#ff6b6b", offset: 0 },
    { color: "#4ecdc4", offset: 100 },
  ],
});
// "#ff6b6b": the first stop

getSolidColor({ type: "image", src: photo, underlay: "#111111" }); // "#111111"
getSolidColor(undefined, "#ffffff"); // "#ffffff"

hexToRgb("#ff6b6b"); // { r: 255, g: 107, b: 107 }
hexToRgb("#f00"); // { r: 255, g: 0, b: 0 }
hexToRgb("red"); // null
```

Utilisez `getSolidColor` quand vous avez besoin d'une seule couleur pour un échantillon, un arrière-plan CSS ou une couleur de repli. Le moteur de rendu l'utilise quand un format ne peut pas dessiner de dégradé, comme `QRCodeCanvas` et le dessin du cadre sur Canvas.

## Contraste [#contrast]

```ts title="lib/contrast.ts"
import { getContrastLevel, getContrastRatio, getLuminance } from "qrdx";

getContrastRatio("#000000", "#ffffff"); // 21
getContrastRatio("#1d4ed8", "#f8fafc"); // 6.4
getContrastRatio("rgba(29, 78, 216, 0.5)", "#ffffff"); // the blue over white, so lower

getContrastLevel(4.5);
// { level: "AA", warning: false, message: "Good contrast" }

getContrastLevel(2);
// { level: "Fail", warning: true, message: "Poor contrast - QR code may not scan properly" }

getLuminance(255, 255, 255); // 1
```

Le score de scan valide un code à partir d'un rapport de 4.5 (`SCAN_CONTRAST_MIN`), retire des points en dessous et le fait échouer sous 1.5. Les images demandent davantage : `SCAN_IMAGE_CONTRAST_MIN` vaut 7 pour un remplissage par image dans les modules et 12 pour une image placée derrière. `getScanContrast(props)` exécute la vérification propre au score sur un design entier, y compris chaque point de dégradé et la couleur des yeux ; voir [Cadres, score de scan et fichiers d'impression](/docs/features/frames#will-it-scan).

Un vérificateur de contraste en direct tient en une douzaine de lignes :

```tsx title="components/contrast-checker.tsx"
"use client";

import { getContrastLevel, getContrastRatio } from "qrdx";
import { useState } from "react";

export function ContrastChecker() {
  const [fgColor, setFgColor] = useState("#000000");
  const [bgColor, setBgColor] = useState("#ffffff");
  const ratio = getContrastRatio(fgColor, bgColor);
  const level = getContrastLevel(ratio);

  return (
    <div>
      <input
        aria-label="Module color"
        type="color"
        value={fgColor}
        onChange={(event) => setFgColor(event.target.value)}
      />
      <input
        aria-label="Background color"
        type="color"
        value={bgColor}
        onChange={(event) => setBgColor(event.target.value)}
      />
      <p>
        {ratio.toFixed(2)}:1, {level.level}. {level.message}
      </p>
    </div>
  );
}
```

## Validation [#validation]

```ts title="lib/sizes.ts"
import { validateSize } from "qrdx";

validateSize(1024, 1024); // { isValid: true }
validateSize(40, 40); // { isValid: false, error: "Size must be at least 50x50 pixels" }
validateSize(6000, 6000); // { isValid: false, error: "Size must not exceed 5000x5000 pixels" }
validateSize(400, 300); // { isValid: false, error: "Width and height must be equal for QR codes" }
```

`downloadQRCode`, `getQRCodeDataUrl` et `copyQRCodeToClipboard` lèvent le même texte `error` quand une taille est refusée, un formulaire peut donc la vérifier au préalable.

## Détection de fonctionnalités [#feature-detection]

```ts title="lib/features.ts"
import { SUPPORTS_PATH2D } from "qrdx";

if (SUPPORTS_PATH2D) {
  // draw module paths with Path2D
}
```

`SUPPORTS_PATH2D` est calculé une seule fois au chargement du module, il vaut donc `false` sur un serveur.

## Autres fonctions utilitaires [#other-helpers]

- `getColorString(color)` et `normalizeColorConfig(color)` convertissent entre elles les formes de `ColorConfig` ; `isGradient(color)` et `isImagePaint(color)` permettent de les distinguer.
- `sanitizeFrameText(text)` et `isLatin1Text(text)` appliquent les règles du libellé de cadre (24 caractères ; Latin-1 pour PDF et EPS).
- `decodePNGPixels(bytes)` lit un PNG 8 bits en pixels RGBA sans DOM, pour `createQRArtImage`, `createQRSilhouette` ou `scanQRPixels` dans Node.
- `rgbToCmyk(color)` est la conversion qu'utilisent les fichiers d'impression CMYK.
