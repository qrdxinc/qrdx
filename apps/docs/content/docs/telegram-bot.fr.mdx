Le bot QRdx transforme un lien ou n'importe quel texte en QR code dans Telegram. Il est gratuit et vous n'avez pas besoin de compte QRdx. Utilisez-le quand un code doit parvenir à quelqu'un dans une conversation tout de suite : un mot de passe Wi-Fi pour un invité, un lien pour un groupe, un menu pour une table.

## Fonctionnement [#how-it-works]

QRdx n'enregistre pas les codes que vous créez, et le bot ne lit chaque message que pour y répondre. Chaque code est une image que QRdx génère à partir d'un lien contenant votre contenu et le design choisi ; modifier le style d'un code relit donc ces informations depuis ce lien. Comme tout lien, il peut se retrouver dans des journaux et des caches : ne créez pas de codes à partir de mots de passe ou d'autres secrets. Telegram conserve les messages dans la conversation, comme pour n'importe quel message.

## Conversation privée [#private-chat]

Envoyez au bot un lien ou du texte, et il répond avec le QR code et quatre boutons :

- **Download PNG** ouvre l'image, prête à être enregistrée ou partagée.
- **Download SVG** ouvre une version vectorielle pour l'impression et les outils de design.
- **Open in editor** ouvre l'éditeur QRdx avec le même design. Une adresse web est transmise avec. Les autres textes ne le sont pas : collez-les vous-même dans l'éditeur.
- **Style** modifie l'apparence du code directement dans la conversation (voir ci-dessous).

Le code contient ce que vous avez envoyé, sauts de ligne compris ; les espaces autour sont supprimés, et un domaine seul comme `qrdx.dev` devient `https://qrdx.dev`. Envoyez `/help` (ou `/start`) pour voir comment utiliser le bot. Si le texte est trop long pour un seul QR code, le bot vous le dit ; un lien vers une page contenant le texte complet donne un code plus petit, plus facile à scanner.

## Personnaliser votre code [#style-your-code]

Touchez **Style** sous un code : les boutons de téléchargement laissent place à **Look**, **Color**, **Frame** et **Logo**, avec **Download PNG** et **Done** en dessous. Chaque groupe ouvre ses options, avec un ✓ à côté de celle que le code utilise actuellement et **Back** pour revenir. Touchez une option et le bot redessine l'image. **Done** rétablit les boutons de téléchargement. Chaque modification s'applique au code dans son état actuel. Dans un groupe, seule la personne qui a demandé le code peut le modifier ; toute autre personne qui touche un bouton reçoit un bref message.

Les looks sont une sélection de designs intégrés à l'éditeur qui restent lisibles en petite taille ; **Plain** est le design noir sur blanc. Choisir un look change les formes et les couleurs, et conserve le cadre et le logo que vous avez choisis. Une couleur applique cette couleur à tout le code, sur fond blanc. Les cadres ajoutent un libellé « Scan me », et le menu du logo propose sept des icônes rapides de l'éditeur.

Vous pouvez aussi personnaliser un code au moment de le créer, en ajoutant des options après le lien ou le texte, avec les mêmes noms que dans la [CLI QRdx](/docs/developers/cli). Cela fonctionne en conversation privée, après `/qr` dans un groupe, et en mode inline, où c'est le seul moyen de personnaliser un code puisqu'il n'y a pas encore de message à modifier :

```text title="Telegram message"
qrdx.dev --look modern --fg 0051ff --frame banner-bottom --frame-text "Scan me"
```

Tout ce qui précède la première option est le contenu. Le look est appliqué en premier, puis les autres options par-dessus, si bien que `--look royal --fg 0051ff` conserve les formes de Royal en bleu. Si votre téléphone transforme `--` en tiret long, cela fonctionne aussi. Une option ou une valeur incorrecte déclenche une réponse listant les valeurs acceptées.

| Option | Ce qu'elle modifie | Valeurs |
| --- | --- | --- |
| `--look` | Le design complet, à partir d'un des préréglages de l'éditeur | `plain`, `classic`, `modern`, `royal`, `folio`, `caffeine`, `retro`, `bordeaux`, `blossom` |
| `--fg` (ou `--color`) | Les points, et les yeux des coins sauf si vous les définissez aussi | Une couleur hexadécimale comme `0051ff`, ou `black`, `blue`, `green`, `red`, `purple`, `orange` |
| `--bg` | L'arrière-plan | Les mêmes que pour `--fg` |
| `--eye-color` | Les trois yeux des coins | Les mêmes que pour `--fg` |
| `--dot-color` | Les centres des yeux des coins | Les mêmes que pour `--fg` |
| `--body` | La forme des points | N'importe laquelle des {facts.bodyPatterns} formes de points de l'éditeur, comme `rounded`, `circle` ou `classy` |
| `--eye` | La forme des yeux des coins | N'importe laquelle des {facts.eyeShapes} formes d'yeux, comme `square`, `rounded` ou `gear` |
| `--dot` | La forme des centres des yeux | N'importe laquelle des {facts.eyeCentres} formes de centres, comme `square`, `rounded` ou `circle` |
| `--frame` | Un cadre autour du code | `none` ou n'importe lequel des {facts.frameStyles} cadres intégrés, comme `banner-bottom`, `banner-top`, `speech-bubble` ou `polaroid` |
| `--frame-text` | Le libellé du cadre, jusqu'à 24 caractères | N'importe quel texte, entre guillemets s'il contient des espaces. Sans `--frame`, il s'affiche sur une bannière sous le code |
| `--template` | Un cadre dessiné comme un modèle | `Arrow`, `StandardBox`, `SquareBorder`, `StrikedBox`, `DotRing`, `Halloween` ou `default`, quelle que soit la casse |
| `--logo` | Une icône au centre | `link`, `wifi`, `location`, `phone`, `email`, `whatsapp`, `instagram`, `file`, `calendar` ou `none` |

Avant que le bot n'envoie un code personnalisé, QRdx le vérifie avec le même score de scan que l'éditeur. Lorsqu'un design serait difficile à lire pour les téléphones, QRdx l'ajuste (couleurs plus sombres, formes plus simples ou correction d'erreur renforcée) et l'indique dans la légende. Si cela ne suffit toujours pas, généralement parce que le contenu est long, vous recevez le code en noir sur blanc avec une note.

**Open in editor** ouvre l'éditeur avec le même design : couleurs, formes, cadre et bordure. L'icône du logo n'est pas transmise dans le lien, choisissez-la à nouveau dans l'éditeur.

## Mode inline dans n'importe quelle conversation [#inline-mode-in-any-chat]

Vous pouvez envoyer un code dans n'importe quelle conversation sans y ajouter le bot. Dans le champ de message, saisissez `@`, le nom d'utilisateur du bot, un espace, puis un lien ou du texte. Le code apparaît au-dessus du champ après un instant. Touchez-le pour l'envoyer, avec les mêmes trois boutons de téléchargement et d'éditeur. Les personnes à qui vous écrivez n'ont pas besoin du bot. Ajoutez `--options` au texte pour personnaliser un code inline.

## Groupes [#groups]

Ajoutez le bot au groupe, puis envoyez `/qr` suivi d'un lien ou d'un texte, par exemple `/qr https://example.com/menu`. Le bot répond à votre message avec le code.

Les bots dans les groupes ont le mode confidentialité activé par défaut, et celui-ci le laisse activé : il ne voit donc pas les conversations du groupe. Telegram ne lui transmet que les commandes qui lui sont destinées et les réponses à ses propres messages. Il répond à `/qr`, `/start` et `/help` et ignore tout le reste. Lorsqu'un groupe compte plusieurs bots, ou que le bot ne répond pas à un simple `/qr`, ajoutez son nom d'utilisateur à la commande : `/qr@` suivi du nom d'utilisateur, puis du lien ou du texte.

## Limites et offres [#limits-and-plans]

Le bot est gratuit et n'est lié à aucune offre. Si vous créez beaucoup de codes en peu de temps, le bot vous demande d'attendre une minute avant le suivant ; chaque modification de style compte comme un code. Quand beaucoup de personnes l'utilisent en même temps, il peut indiquer qu'il est occupé. Réessayez une minute plus tard.

## Supprimer le bot [#remove-the-bot]

Dans une conversation privée, ouvrez le profil du bot et bloquez-le, ou supprimez la conversation. Dans un groupe, un administrateur retire le bot de la liste des membres.

Les codes déjà envoyés par le bot restent dans la conversation. Leurs boutons **Download PNG**, **Download SVG** et **Open in editor** continuent de fonctionner, car ils renvoient directement vers QRdx ; **Style** a besoin du bot et cesse de fonctionner une fois celui-ci retiré.

## Pour les développeurs [#for-developers]

Chaque code envoyé par le bot provient de l'[Image API](/docs/developers/image-api), et les options saisies sont celles de la [CLI](/docs/developers/cli). Pour créer des codes depuis vos propres scripts, utilisez directement l'une ou l'autre.

## Auto-hébergement [#self-hosting]

Un serveur QRdx auto-hébergé peut exécuter son propre bot. Créez-en un avec [@BotFather](https://t.me/BotFather), définissez `TELEGRAM_BOT_TOKEN`, `TELEGRAM_WEBHOOK_SECRET` et `TELEGRAM_BOT_USERNAME` sur le serveur, puis lancez le script d'installation. Les étapes sont décrites dans [`plugins/telegram/README.md`](https://github.com/qrdxinc/qrdx/blob/main/plugins/telegram/README.md). Tant que ces trois variables ne sont pas toutes définies, les routes du bot répondent 404 et votre site ne mentionne pas le bot. Les limites de débit nécessitent Upstash Redis ; sans lui, elles sont désactivées. Voir [Auto-hébergement](/docs/self-hosting#optional-services).
