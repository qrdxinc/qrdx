读完本页后，你将在一个纯 HTML 页面中，用 `<qrdx-code>` 元素绘制出带样式的二维码，通过脚本设置对象选项，并导出为 PNG。`qrdx/element` 基于 `qrdx/core` 构建，因此绘制出的 SVG 与 React 的 `QRCodeSVG` 相同，样式、边框、徽标和导出功能一应俱全。它不需要任何框架，也适用于会渲染 DOM 元素的框架。它已在 React 19 和 Vue 3 中测试过。

<NpmStatus package="qrdx" />

## 开始之前 [#before-you-start]

- 一个可以添加 `<script type="module">` 的页面。无需打包工具，使用打包工具也可以。
- 如果使用打包工具方式，需要 Node.js 18 或更高版本。

## 动手搭建 [#build-it]

### 1. 加载元素 [#1-load-the-element]

<Tabs items={["From a CDN", "With a bundler"]}>
<Tab value="From a CDN">

```html title="index.html"
<script
  type="module"
  src="https://cdn.jsdelivr.net/npm/qrdx/dist/element-define.browser.mjs"
></script>
```

`dist/element-define.browser.mjs` 会注册 `<qrdx-code>`。它会加载 `dist/element.browser.mjs`，这是一个内含引擎的 ES 模块。要固定版本，请在 URL 中 `qrdx` 之后加上 `@` 和版本号。相同的路径在 unpkg 上同样适用。

</Tab>
<Tab value="With a bundler">

```package-install
qrdx
```

```js title="main.js"
import "qrdx/element/define"; // registers <qrdx-code>
```

单独导入 `qrdx/element` 不会注册任何内容。请自行调用 `defineQRdxCode` 来选择标签名：

```js title="main.js"
import { defineQRdxCode } from "qrdx/element";

defineQRdxCode(); // <qrdx-code>
defineQRdxCode("brand-qr"); // <brand-qr> as well
```

重复调用是安全的，在服务端调用则什么也不做。如果该名称已被其他元素占用，则会抛出错误。

</Tab>
</Tabs>

### 2. 在页面中放入二维码 [#2-put-a-code-in-the-page]

```html title="index.html"
<qrdx-code
  value="https://example.com/menu"
  size="256"
  margin="4"
  body-pattern="rounded"
  label="QR code for the menu"
></qrdx-code>
```

页面会显示一个 256 px 的二维码，模块为圆角。在浏览器的检查器中修改任一属性，二维码都会重新绘制。

<Shot id="lib-element-code" />

### 3. 通过脚本设置对象选项 [#3-set-object-options-from-a-script]

渐变、边框、徽标和其他对象选项都是属性（property）。请通过脚本设置：

```js title="main.js"
const qr = document.querySelector("qrdx-code");

qr.fgColor = {
  type: "linear",
  angle: 45,
  stops: [
    { color: "#1d4ed8", offset: 0 },
    { color: "#0f172a", offset: 100 },
  ],
};
qr.frame = { style: "banner-bottom", text: "Scan for the menu" };
qr.imageSettings = { src: "/logo.png", width: 40, height: 40, excavate: true };
qr.props = { eyeColor: "#be123c" };
```

二维码只会重绘一次，呈现渐变、横幅、徽标和红色定位眼。如果不使用脚本，可以把对象选项以 JSON 形式放入 `props` 属性：

```html title="index.html"
<qrdx-code
  value="https://example.com"
  props='{"frame": {"style": "banner-bottom", "text": "Scan me"}}'
></qrdx-code>
```

### 4. 导出 [#4-export-it]

```js title="main.js"
qr.toSVGString(); // '<svg xmlns="http://www.w3.org/2000/svg" …'
await qr.toDataURL("png", { size: 1024 }); // "data:image/png;base64,…"
await qr.download({ format: "png", size: 1024, filename: "menu.png" });
```

`download` 会以 1024 px 保存 `menu.png`。导出内容根据 `qr.options` 绘制，与 `qrdx/core` 中的 `toSVGString` 和 `downloadQRCode` 一致，不包含元素自带的 `part`、`role` 和 `aria-label`。`toDataURL` 和 `download` 默认按二维码的 `size` 导出 PNG。支持的格式有 `png`、`jpg`、`webp`、`svg`、`pdf` 和 `eps`。如果不传值，`toSVGString` 会抛出错误，其余方法则会 reject。

PDF 需要可选的 `jspdf` 包。如果使用 CDN，请在模块脚本之前放置 import map 来映射它：

```html title="index.html"
<script type="importmap">
  { "imports": { "jspdf": "https://cdn.jsdelivr.net/npm/jspdf@4/+esm" } }
</script>
```

## 属性 [#attributes]

| 属性 | 作用 |
| --- | --- |
| `value` | 要编码的文本或 URL。没有它则不会绘制任何内容 |
| `size` | 宽度和高度，单位为像素（边框会在此基础上增加尺寸） |
| `level` | 纠错等级：`L`、`M`、`Q` 或 `H` |
| `fg-color`, `bg-color`, `eye-color`, `dot-color` | 纯色 |
| `body-pattern`, `corner-eye-pattern`, `corner-eye-dot-pattern` | 模块、定位眼和眼点的形状 |
| `margin` | 空白边距，单位为模块 |
| `template-id` | 内置模板 |
| `module-scale` | 每个模块的大小，范围 0.5 到 1 |
| `auto-level` | 当徽标需要时，将纠错等级提高到 `H` |
| `shape` | `square`、`circle` 或 `heart` |
| `label` | 屏幕阅读器播报的内容（默认为 "QR code"） |
| `props` | 其他任何选项，以 JSON 形式提供 |

无法解析的数字和等级会被忽略。[形状、定位眼和边框](/docs/styles)展示了所有图案。

## 属性（Properties） [#properties]

每个属性（attribute）同时也是一个 property，名称与选项名一致：`qr.fgColor`、`qr.bodyPattern`、`qr.templateId`。对象类选项只能作为 property 使用：渐变和图像填充、`frame`、`imageSettings`、`eyeColors`、`art`、`customTemplate` 和 `customProps`。`props` 可一次性接收所有选项。

- 同一选项下，attribute 或具名 property 的优先级高于 `props` 中的值。attribute 与其对应的 property 之间，以最后设置的为准。将 property 设为 `undefined` 即可移除它。
- property 不会回写到 attribute。
- 变更会被批处理。无论连续修改多少次，二维码都只会在一个微任务中重绘一次，并且仅在标记发生变化时才重绘。
- `qr.options` 是绘制二维码所用的选项，`qr.svg` 是已绘制出的 `<svg>`。
- 在元素被定义之前设置的 property，会在元素定义后生效。

官方边框来自元素旁边的文件：

```js title="main.js"
import { getOfficialFrame } from "https://cdn.jsdelivr.net/npm/qrdx/dist/frames-official.mjs";

qr.frame = { style: "custom", spec: getOfficialFrame("wifi-card").spec };
```

## 样式与无障碍 [#styling-and-accessibility]

二维码绘制在一个开放的 shadow root 中。页面的 CSS 无法作用到其中的路径，因此 `svg path { fill: red }` 或 `svg { width: 100% }` 这样的规则不会破坏二维码。如需从外部为 `<svg>` 设置样式，请使用 `::part(svg)`：

```css title="styles.css"
qrdx-code::part(svg) {
  border-radius: 12px;
}
```

该元素为 `inline-block`。其 `<svg>` 保持 `size` 指定的尺寸，但在容器较窄时会缩小以适应。

`<svg>` 带有 `role="img"`，以及来自 `label` 属性的 `aria-label`；未设置时则为 "QR code"。该标签绝不会回退为 value，因为 value 中可能包含 Wi-Fi 密码或联系人信息。

## 服务端渲染 [#server-rendering]

`toQRdxCodeHTML(options)` 返回该元素的标记，其中二维码已绘制在声明式 shadow root 内。浏览器在任何脚本运行之前就能显示二维码，元素定义后再接管。它在 Node 中运行，不需要 DOM。

```js title="server.js"
import { toQRdxCodeHTML } from "qrdx/element";

const html = toQRdxCodeHTML(
  {
    value: "https://example.com",
    size: 256,
    frame: { style: "banner-bottom", text: "Scan me" },
  },
  { label: "Link to example.com" }
);
// <qrdx-code value="https://example.com" size="256" label="Link to example.com"
//   props="{…}"><template shadowrootmode="open">…</template></qrdx-code>
```

简单选项会变成 attribute，其余选项则以 JSON 形式放入 `props`，因此元素读回的选项与原来一致。`customTemplate` 无法写成标记：请在浏览器中将其设为 property。如果你注册了其他名称，请传入 `tagName`。

## React 19 [#react-19]

当元素拥有对应的 property 时，React 19 会把 prop 设置为 property，因此对象可以直接作为 prop 传入。请在渲染之前注册一次该元素：

```tsx title="components/menu-code.tsx"
import "qrdx/element/define";

export function MenuCode({ url }: { url: string }) {
  return (
    <qrdx-code
      value={url}
      size={256}
      body-pattern="rounded"
      frame={{ style: "banner-bottom", text: "Scan me" }}
      label="Menu"
    />
  );
}
```

如果使用 TypeScript，请在 `.d.ts` 文件中把该元素添加到 JSX：

```ts title="qrdx-code.d.ts"
import type { QRdxCodeElement, QRdxCodeJSXProps } from "qrdx/element";

declare module "react" {
  namespace JSX {
    interface IntrinsicElements {
      "qrdx-code": React.DetailedHTMLProps<
        React.HTMLAttributes<QRdxCodeElement>,
        QRdxCodeElement
      > &
        QRdxCodeJSXProps;
    }
  }
}
```

通过 `ref` 可以获取元素，用于调用 `toDataURL` 和 `download`。

## Vue [#vue]

告诉 Vue 的编译器 `qrdx-code` 是自定义元素：

```js title="vite.config.js"
import vue from "@vitejs/plugin-vue";
import { defineConfig } from "vite";

export default defineConfig({
  plugins: [
    vue({
      template: {
        compilerOptions: { isCustomElement: (tag) => tag === "qrdx-code" },
      },
    }),
  ],
});
```

然后在 `main.js` 中导入一次 `qrdx/element/define`，并在模板中绑定选项。当元素拥有对应的 property 时，Vue 会把绑定设置为 property：

```vue title="src/App.vue"
<qrdx-code
  :value="url"
  :size="256"
  body-pattern="rounded"
  :frame="{ style: 'banner-bottom', text: 'Scan me' }"
  label="Menu"
/>
```

## 出现问题时 [#if-something-goes-wrong]

- **没有绘制任何内容。** 元素没有 `value`，或者定义元素的脚本尚未运行。请检查该属性，并确认 `element-define` 是以模块方式加载的。
- **触发了 `qrdx-error` 事件。** 二维码无法绘制，例如 value 对二维码来说太长，或者 `props` 属性不是 JSON 对象。错误信息在 `event.detail.error` 中。除非监听器调用了 `event.preventDefault()`，否则元素会移除旧的二维码并记录该错误：

  ```js title="main.js"
  qr.addEventListener("qrdx-error", (event) => {
    event.preventDefault();
    showMessage("That text is too long for a QR code.");
  });
  ```

- **`qrdx: <qrdx-code> is already defined by another element`。** 其他脚本注册了相同的标签名。请给 `defineQRdxCode` 传入另一个名称。
- **TypeScript：`Property 'qrdx-code' does not exist on type 'JSX.IntrinsicElements'`。** 请添加 React 19 一节中的声明。
