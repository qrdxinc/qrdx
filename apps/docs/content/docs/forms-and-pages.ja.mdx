[ホスト型ページ](/docs/landing-pages)はブロックで構成されます。印刷物向けに特によく使われるのが、メニュー、クーポン、イベント、アプリのダウンロード、フォームの5つです。それぞれ専用のページタイプとテンプレートがあり、ほかのどのページにも追加できます。テーブル、チラシ、招待状、アプリのポスター、フィードバックカードにコードを載せるときに、このガイドを参考にしてください。

<Callout type="info" title="プラン">
  ここで紹介するブロックは、どのプランでも使えます。フォームの回答数にはプランごとに月間上限があります（[下記](#monthly-limits)）。回答の通知は、Proではメール、BusinessではSlack、Discord、Webhookで利用できます。[プランと制限](/docs/plans-and-limits)をご覧ください。
</Callout>

お急ぎの方は、フォームの操作手順をまとめたページ [フォームで回答を集める](/docs/help/pages-and-forms/forms) をご覧ください。

## メニュー [#menu]

**メニュー**ブロックは、セクション（前菜、メインなど）と項目を一覧にします。各項目には、説明、価格、価格の後ろに付ける注記（「グラスあたり」「時価」など）、写真、短いバッジ（「シェフのおすすめ」）のほか、次の情報を設定できます。

- **食事タグ：**ベジタリアン、ビーガン、グルテンフリー、乳製品不使用、ハラール、コーシャ、辛い、オーガニック。
- **アレルゲン：**EUと英国で食品事業者に表示義務がある14品目（グルテン、甲殻類、卵、魚、ピーナッツ、大豆、乳、ナッツ類、セロリ、マスタード、ごま、亜硫酸塩、ルピナス、軟体動物）。「含まれるもの：…」と表示されます。
- **売り切れ：**項目はメニューに残り、薄く表示されて売り切れと明示されます。

1つのメニュー内の価格は、すべて選択した通貨で表示されます。セクションが2つ以上ある場合は、上部のショートカットチップから各セクションへ移動できます。1つのメニューには、最大30セクション、300項目を登録できます。

<Shot id="hosted-menu-page" />

**Wi-Fi**ブロックは、ネットワーク名とパスワードをコピーボタン付きで表示します。スマートフォンはWebページからネットワークに接続できないため、利用者はパスワードをコピーして、Wi-Fiの設定に貼り付けます。ページを開いた人は誰でもパスワードを見られます。

## クーポン [#coupon]

**クーポン**ブロックは、見出し、コピーボタン付きのコード、そして必要に応じてレジで読み取れるバーコードを表示します。

- **Code 128**は、英数字と記号を最大48文字までエンコードします（アクセント付き文字や絵文字は使えません）。
- **EAN-13**は、12桁（QRdxがチェックディジットを追加します）または13桁すべてを受け付けます。20〜29で始まる番号はGS1が店舗内用に予約しているため、クーポンコードに向いています。

デフォルトでは、バーコードにクーポンコードがエンコードされます。ほかの値（POSの番号など）をエンコードしたい場合は、**バーコードの値**を設定してください。

**有効開始日**と**有効期限**は、カレンダー上の日付です。クーポンは、世界のどこかで初日が始まった時点で開始済みとみなされ、世界のすべての地域で最終日が終わってはじめて期限切れとみなされます。このため、タイムゾーンの違いで早く「期限切れ」と表示されることはありません。期限切れのクーポンも表示されたままで、期限切れと明示されます。

**利用ボタン**をオンにすると、利用回数を数えられます。訪問者が**クーポンを利用**をタップし、画面をスタッフに見せて、**今すぐ利用**で確定します。その後、ページにはそのスマートフォンの時刻とともに「利用済み」と表示され、回数はそのページの[回答](#responses)画面に表示されます。同じコードを別のスマートフォンで表示することは防げないため、ロックではなくカウンターとしてお使いください。

## イベント [#event]

**イベント**ブロックは、日時、会場と住所（**マップで開く**リンク付き）、オンラインのリンク、主催者、**チケットを入手**などのボタンを表示します。時刻はイベントのタイムゾーンで入力し、訪問者にも同じタイムゾーンで表示されます（例：「7:00 – 10:00 PM GMT+1」）。終日イベントや複数日にわたるイベントにも対応しています。終了時刻がない場合、イベントの長さは1時間として扱われます。

**カレンダーに追加**では、Googleカレンダー、Appleカレンダー（`.ics`ファイル）、Outlook.com、Yahoo!カレンダーを選べます。`.ics`ファイルはページのアドレスから配信されるため、[カスタムドメイン](/docs/custom-domains)でも動作します。エディターのプレビューでは、ページを公開するまで無効になります。イベントが終了すると、ブロックにその旨が表示され、カレンダーボタンは非表示になります。

## アプリのダウンロード [#app-download]

**アプリのダウンロード**ブロックには、App Storeのリンク（`apps.apple.com`）、Google Playのリンク（`play.google.com`）、ウェブサイトを設定します。訪問者が使っているストアが先頭に表示されます。iPhoneとiPadのユーザーにはApp Storeボタンが、Androidユーザーにended Google Playが、それ以外の人にはウェブサイトが一番上に表示されます。ほかのリンクはその下に残るため、行き場がなくなることはありません。

## フォーム [#forms]

**フォーム**ブロックは回答を集めます。質問には次のタイプがあります。

| タイプ | 訪問者の回答方法 |
| --- | --- |
| テキスト | 短い回答または長い回答（最大文字数を設定できます） |
| メール | メールアドレス |
| 電話 | 電話番号 |
| 星評価 | 3〜10段階の星（自由に選べます。デフォルトは5） |
| NPS（0〜10） | 「どのくらい私たちを薦めたいか」を0〜10で回答 |
| 選択 | 1つの選択肢。**複数回答を許可**をオンにすると複数選択も可能 |
| チェックボックス | チェックを入れる形式（連絡への同意など） |

質問を**必須**にすると、回答が必須になります。エラーは質問の横に表示され、送信後には、あらかじめ書いておいたお礼のメッセージが表示されます。必要な項目だけを尋ね、連絡先をどのように使うかを明記してください。

<Shot id="form-editor" />

スパム対策が組み込まれています。ボットだけが入力する非表示フィールドと、同じ端末からフォームを送信できる頻度の制限です。サーバーに[Cloudflare Turnstile](#cloudflare-turnstile)のキーが設定されている場合は、フォームでTurnstileの非表示チェックも実行されます。

### レビューリンク [#review-links]

**レビューリンク**ブロックは、「Googleでレビューする」（およびTripadvisor、Yelp、Facebook、Trustpilot、その他のサイト）のボタンを表示します。フォームにどう回答したかにかかわらず、すべての訪問者に表示されます。Googleを含むレビューサイトでは、高く評価した人にだけレビューリンクを見せることは認められていないため、QRdxは評価に基づいてリンクを非表示にすることはありません。Googleビジネス プロフィールで**レビューを依頼**を選ぶと、レビューリンクをコピーできます。

## 回答 [#responses]

**ページとフォーム**でページを開き、**回答**を選びます。回答は新しい順に、1画面25件で一覧表示され、時刻（UTC）、訪問者がスキャンしたコード、すべての回答が確認できます。メールアドレスと電話番号はリンクになっています。

<Shot id="form-responses" />

- **1つのページに複数のフォーム：**タブでフォームごとに絞り込めます。
- **CSVをエクスポート：**1回答につき1行、1質問につき1列で出力されます。列は現在の質問の順に並び、その後に、削除済みでも回答が残っている質問が続きます。質問名を変更しても、列はそのまま維持されます。
- **削除：**回答を選択するか、1件ごとのゴミ箱ボタンを使います。削除は元に戻せません。メンバーは自分が作成したページの回答を削除でき、オーナーと管理者はワークスペース内のすべてのページの回答を削除できます。

回答はページに紐づいています。ページを削除すると、そのページの回答も削除されます。

### 月間上限 [#monthly-limits]

| プラン | 月あたりの回答数 |
| --- | --- |
| フリー | 50 |
| Pro | 1,000 |
| Business | 10,000 |

上限は、ワークスペース内のすべてのページが受け取った回答数を暦月（UTC）ごとに数えたもので、毎月1日にリセットされます。回答画面で、使用済みの件数を確認できます。

上限に達すると、フォームには「このフォームは現在回答を受け付けていません。しばらくしてからもう一度お試しください。」と表示され、訪問者が入力した内容は保持されます。すでにある回答は、どのプランでも、ダウングレード後でも、削除されたり非表示になったりすることはありません。

## アクセスルール [#access-rules]

フォームとカレンダーファイルは、ページの[コードコントロール](/docs/code-controls)に従います。コードが一時停止中、後日開始の予定、期限切れ、またはスキャン上限に達している間は、そのフォームは回答を受け付けず、`.ics`ファイルも配信されません。パスワードで保護されたページでは、訪問者がパスワードを入力した後に使えるようになります。

## 通知とWebhook [#notifications-and-webhooks]

回答があるたびに、回答内容を含む`form.submitted`イベントが送信されます。ProとBusinessでは、[メールアラート](/docs/notifications)で各回答が受信箱に届きます。Businessでは、SlackやDiscordのメッセージ、[Webhook](/docs/webhooks)（Zapier、Make、独自のサーバー）にも送られます。

## プライバシー [#privacy]

回答は、ワークスペース内のページとともに保存されます。QRdxは、訪問者のIPアドレスを回答と一緒に保存しません。各回答には、その日のIPアドレスとブラウザーをソルト付きでハッシュ化した値だけが保持され、そこから元のIPアドレスやブラウザーの情報に戻すことはできません。

## セルフホスト [#self-hosting]

### Cloudflare Turnstile [#cloudflare-turnstile]

[Cloudflare Turnstile](https://developers.cloudflare.com/turnstile/)でフォームを保護するには、両方の変数を設定します。

```bash title="apps/app/.env.local"
NEXT_PUBLIC_TURNSTILE_SITE_KEY=0x4AAAAAAA...
TURNSTILE_SECRET_KEY=0x4AAAAAAA...
```

サーバーは、両方のキーが設定されている場合にのみ回答を検証するため、必ず両方を一緒に設定してください。Turnstileのスクリプトは、ページ読み込み時ではなく、訪問者が最初にフォームに触れたときに読み込まれ、Cloudflareが訪問者のクリックを必要としない限り、非表示で実行されます。Cloudflareに接続できない場合でも回答は受け付けられるため、フィードバックを失うことはありません。そのほかのスパム対策は引き続き有効です。

### カスタムドメイン [#custom-domains]

確認済みの[カスタムドメイン](/docs/custom-domains)では、フォームのエンドポイント（`/api/forms/...`）とカレンダーファイル（`/api/calendar/...`）がページと同じ場所から配信されるため、追加の設定なしで、フォームとカレンダーへの追加が動作します。
