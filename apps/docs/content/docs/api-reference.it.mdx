Questa pagina elenca ciò che esporta `qrdx`, per punto di ingresso e per attività, con il tipo e il valore predefinito di ogni prop. Le pagine delle funzionalità spiegano come usarli; questa serve per cercare un nome.

## Punti di ingresso [#entry-points]

| Importa da | Cosa contiene | Richiede |
| --- | --- | --- |
| `qrdx` | I componenti React (`QRCode`, `QRCodeSVG`, `QRCodeCanvas`, `getQRAsSVG`) più tutto ciò che c'è in `qrdx/core` | `react`, `react-dom` |
| `qrdx/core` | L'intero motore senza React: markup, download, file di stampa, il punteggio di scansione, cornici, template, grafica e tipi | Niente |
| `qrdx/vanilla` | `createQRCode`, più `qrdx/core` | Un DOM |
| `qrdx/element` | L'elemento personalizzato `<qrdx-code>`: `QRdxCodeElement`, `defineQRdxCode`, `toQRdxCodeHTML` | Un DOM per disegnare; niente per generare il markup |
| `qrdx/element/define` | Registra `<qrdx-code>` all'importazione | Un DOM |
| `qrdx/node` | `getQRAsPNG` | `@resvg/resvg-js` o `sharp` |
| `qrdx/vue` | `QRCode`, `QRCodeSVG`, `useQRCode`, più `qrdx/core` | `vue` 3.3 o successivo |
| `qrdx/preact` | `QRCode`, `QRCodeSVG` | `preact` 10 o successivo |
| `qrdx/solid` | `QRCode`, `QRCodeSVG` | `solid-js` 1.8 o successivo |
| `qrdx/angular` | Il componente `QRCode` (`<qrdx-qr-code>`), più `qrdx/core` | `@angular/core` 20 o successivo |
| `qrdx/types` | Ogni tipo, elenco di opzioni e schema zod, senza il renderer | Niente |

Ogni pacchetto di framework è una peer dependency opzionale: installare `qrdx` non aggiunge mai un framework che non usi. Anche `jspdf` è opzionale, per il PDF.

## Componenti [#components]

### QRCode [#qrcode]

Il componente per la maggior parte degli usi. `QRProps` più una semplice API per il logo, reso come `<svg>`. Non usa hook solo per browser, quindi viene reso nei React Server Components.

```tsx title="components/example.tsx"
import { QRCode } from "qrdx";

<QRCode value="https://example.com" size={256} margin={4} level="H" logo="/logo.png" />;
```

| Prop | Tipo | Predefinito | Cosa fa |
| --- | --- | --- | --- |
| `value` | `string` | obbligatorio | Il testo o l'URL da codificare, esattamente come lo passi |
| `size` | `number` | `128` | Larghezza e altezza in pixel. Una cornice si aggiunge a questo valore; un template si adatta al suo interno |
| `scale` | `number` | `1` | Moltiplica `size` |
| `level` | `"L" \| "M" \| "Q" \| "H"` | `"Q"` | Correzione degli errori: può essere danneggiato circa il 7%, 15%, 25% o 30% del codice |
| `margin` | `number` | `0` | Zona di rispetto attorno al codice, in moduli. Lo standard ne richiede 4 |
| `fgColor` | `ColorConfig` | `"#000000"` | Colore dei moduli dei dati: un colore CSS, un gradiente o un riempimento con immagine |
| `bgColor` | `ColorConfig` | `"#FFFFFF"` | Sfondo. `"transparent"` non dipinge nulla |
| `eyeColor` | `ColorConfig` | `fgColor` | Colore dei tre occhi agli angoli |
| `dotColor` | `ColorConfig` | `fgColor` | Colore del punto all'interno di ogni occhio |
| `eyeColors` | `EyeColors` | nessuno | Colori `outer` e `inner` per ogni occhio (`topLeft`, `topRight` e `bottomLeft`); ciascuno sostituisce `eyeColor` e `dotColor` |
| `bodyPattern` | `BodyPattern` | `"circle"` | Forma dei moduli dei dati, una tra {facts.bodyPatterns} |
| `cornerEyePattern` | `CornerEyePattern` | `"gear"` | Forma degli occhi agli angoli, una tra {facts.eyeShapes} |
| `cornerEyeDotPattern` | `CornerEyeDotPattern` | `"circle"` | Forma dei punti degli occhi, una tra {facts.eyeCentres} |
| `moduleScale` | `number` | `1` | Dimensione di ogni modulo dei dati, da 0.5 a 1. Ogni motivo si ferma alla dimensione minima che si legge ancora (`MODULE_SCALE_FLOOR`) |
| `logo` | `string` | nessuno | Un percorso, URL o data URL disegnato al centro, con i moduli sottostanti rimossi. Senza questa prop non viene disegnato alcun logo |
| `logoOptions` | `LogoOptions` | nessuno | `size` del logo (da 0.1 a 0.3, predefinito 0.25), `padding` (da 0 a 2 moduli), `x` e `y` (da 0 a 1), `shape` e `plate` |
| `hideLogo` | `boolean` | `false` | Nasconde il logo anche quando `logo` è impostato |
| `autoLevel` | `boolean` | `false` | Porta `level` a `H` quando il logo copre più del 7% del codice (`AUTO_LEVEL_LOGO_COVERAGE`) |
| `frame` | `AnyQRFrame` | nessuno | Una cornice con invito all'azione: `{ style, text, color, textColor, secondaryText, secondaryColor, fontScale }`, oppure `{ style: "custom", spec }`. L'output si ingrandisce per contenerla |
| `templateId` | `string` | nessuno | Un template disegnato a `size` con il codice all'interno: `"Arrow"`, `"StandardBox"`, `"SquareBorder"`, `"StrikedBox"`, `"Halloween"`, `"DotRing"` o `"default"` |
| `customTemplate` | `TemplateDefinition` | nessuno | Un template che disegni nel codice. Ha la precedenza su `templateId` |
| `customProps` | `Record<string, any>` | nessuno | Prop per il `wrapper` del template, come `DotRingProps` |
| `shape` | `"square" \| "circle" \| "heart" \| QRSilhouette` | `"square"` | Inserisce il codice in un disco, in un cuore o in un contorno tuo riempito di moduli decorativi |
| `art` | `QRArt` | nessuno | Fonde un'immagine nei moduli: `{ mode, image, intensity, variant, matchEyes }` |
| `style` | `CSSProperties` | nessuno | Stili inline per l'`<svg>` |
| `frameLabelMarkers` | `boolean` | `false` | Per gli editor: contrassegna ogni `<text>` dell'etichetta della cornice con `data-qrdx-frame-label`. Le esportazioni non lo includono mai |
| `partMarkers` | `boolean` | `false` | Per gli editor: contrassegna le parti disegnate con `data-qrdx-part`. Le esportazioni non lo includono mai |
| `isOGContext` | `boolean` | `false` | Disegna il logo come `<img>` posizionata per i renderer di immagini Open Graph |

`QRCode` accetta solo queste prop; qualsiasi altra prop viene scartata. `QRCodeSVG` applica ogni altra prop (`className`, `aria-label`, `role`, `data-*`, …) all'`<svg>`, oppure all'`<svg>` esterno della cornice quando c'è una cornice. I gestori di eventi vengono esclusi dal markup.

### QRCodeSVG [#qrcodesvg]

`QRProps` più gli attributi SVG di React (`QRPropsSVG`): le stesse prop di `QRCode` senza `logo`, `logoOptions`, `hideLogo` e `scale`. Il logo è `imageSettings`, in pixel:

| Campo | Tipo | Predefinito | Cosa fa |
| --- | --- | --- | --- |
| `src` | `string` | obbligatorio | L'immagine, come URL o data URL |
| `width`, `height` | `number` | obbligatorio | Dimensione negli stessi pixel di `size` |
| `excavate` | `boolean` | obbligatorio | Rimuove i moduli dietro l'immagine |
| `x`, `y` | `number` | centrato | Angolo in alto a sinistra dell'immagine |
| `padding` | `number` | `0` | Spazio libero aggiuntivo attorno all'immagine, in pixel, quando si rimuovono i moduli |
| `shape` | `"square" \| "rounded" \| "circle"` | `"square"` | Ritaglia l'immagine |
| `plate` | `string` | nessuno | Una base piena dietro l'immagine, con la sua stessa forma |

Un logo più grande di quanto il codice possa ripristinare viene ridotto attorno al suo centro (`capImageSettings`, lo stesso limite di `QRCode`).

### QRCodeCanvas [#qrcodecanvas]

`QRProps` più gli attributi canvas di React (`QRPropsCanvas`), disegnato su un `<canvas>` al rapporto di pixel del dispositivo. Disegna semplici moduli quadrati con colori pieni: un gradiente ripiega sul suo primo colore, e le prop di motivo, colore degli occhi, `eyeColors`, `moduleScale`, `art` e template vengono ignorate. Viene distribuito con `"use client"`.

### getQRAsSVG [#getqrassvg]

`getQRAsSVG(props: QRPropsSVG): Promise<JSX.Element>` restituisce il codice come elemento React con il logo incorporato come data URL. Per ottenere una stringa, usa `toSVGString` o `getSVGString`.

## Download ed esportazione [#download-and-export]

| Funzione | Restituisce | Note |
| --- | --- | --- |
| `downloadQRCode(props, { format, size, filename?, quality? })` | `Promise<void>` | Salva un file. `size` va da 50 a 5000 px ed è quadrata; per i formati raster il nome file predefinito indica la dimensione in pixel |
| `getQRCodeDataUrl(props, format, size, { quality? })` | `Promise<string>` | Lo stesso file come data URL |
| `getQRAsWebP(props, { quality? })` | `Promise<Blob>` | Lossless, a meno che `quality` non sia impostato; si codifica da sé dove il browser non può |
| `copyQRCodeToClipboard(props, size?)` | `Promise<void>` | Un PNG negli appunti. Chiamala da un gesto dell'utente |
| `getSVGString(props)` | `Promise<string>` | Markup SVG con il logo incorporato |
| `toSVGString(props)` | `string` | Markup SVG, sincrono, senza logo incorporato. Funziona ovunque |
| `toSVGElement(props, document?)` | `SVGSVGElement` | Il codice come elemento DOM |
| `getQRAsSVGDataUri(props)` | `Promise<string>` | `data:image/svg+xml,…`, il primo passo di ogni esportazione |
| `getQRAsCanvas(props, mimeType, getCanvas?)` | `Promise<string \| HTMLCanvasElement>` | Un data URL, oppure il canvas stesso con `getCanvas` |
| `getQRAsPNG(props, { size?, loadExternalLogos? })` | `Promise<Uint8Array>` | Byte PNG in Node, da `qrdx/node`. Richiede `@resvg/resvg-js` o `sharp` |
| `validateSize(width, height)` | `{ isValid, error? }` | La regola sulla dimensione che applica `downloadQRCode` |
| `getDownloadFilename(format, size, frame?)` | `string` | Il nome file predefinito |
| `withQRSize(props, size)` | `QRProps` | Le props disegnate a `size`, con un logo in pixel scalato di conseguenza |
| `canvasToWebP(canvas, { quality? })`, `blobToDataUrl(blob)`, `encodeWebPLossless(rgba, width, height)` | | Helper WebP |

Costanti: `DownloadFormat` è `"png" \| "jpg" \| "webp" \| "svg" \| "pdf" \| "eps"`; `DOWNLOAD_FORMATS` associa ciascuno al suo tipo MIME e alla sua estensione; `PRESET_SIZES` contiene `small` (200), `medium` (400), `large` (800), `xlarge` (1200), `2xl` (1600) e `3xl` (2000); `DEFAULT_SIZE` è 128.

## Stampa ed EPS [#print-and-eps]

| Funzione | Restituisce | Note |
| --- | --- | --- |
| `getPrintLayout(props, { size, unit?, bleed?, cropMarks?, colorMode? })` | `PrintLayout` | Dimensioni fisiche in mm: `codeWidth`, `trimWidth`, `trimHeight`, `bleed`, `pageWidth`, `pageHeight`, `moduleSize`, `moduleCount`, `maxScanDistance`. `size` va da 5 mm a 2 m |
| `getQRAsPrintPDF(props, options)` | `Promise<string>` | Un PDF vettoriale come data URL. Richiede `jspdf` |
| `getQRAsPrintPDFBuffer(props, options)` | `Promise<ArrayBuffer>` | Lo stesso PDF come byte, per Node |
| `getQRAsPrintSVG(props, { size, unit? })` | `Promise<string>` | SVG con `width` e `height` in mm o in |
| `downloadPrintPDF(props, options & { filename? })`, `downloadPrintSVG(props, options & { filename? })` | `Promise<void>` | Download dei due nel browser |
| `getQRAsEPS(props, { sizeMm?, bleedMm?, colorMode? })` | `Promise<string>` | Testo EPSF-3.0. Lancia `EPS_IMAGE_FILL_REASON` per un riempimento con immagine |
| `downloadPrintEPS(props, options & { filename? })` | `Promise<void>` | Download nel browser |
| `svgToEPS(svg, { width?, colorMode?, bleed?, bleedColor?, title? })` | `Promise<string>` | Converte qualsiasi SVG renderizzato dalla libreria |
| `epsToDataUrl(eps)`, `hasImageFill(props)`, `rgbToCmyk(color)`, `getQRModuleCount(props)` | | Helper |

`PrintOptions`: `size` (numero), `unit` (`"mm"` o `"in"`, predefinito `"mm"`), `bleed` (mm, da 0 a 20), `cropMarks` (booleano), `colorMode` (`"rgb"` o `"cmyk"`).

## Punteggio di scansione e rilevamento [#scan-score-and-detection]

| Funzione | Restituisce | Note |
| --- | --- | --- |
| `getScanScore(props, { sizes?, signal? })` | `Promise<ScanScoreResult>` | `{ score, grade, checks }`. Solo browser; carica jsQR su richiesta. Dimensioni predefinite 96, 160 e 320 px (`SCAN_TEST_SIZES`) |
| `getImageScanScore(imageOrBlob, options?)` | `Promise<ImageScanScoreResult>` | Lo stesso per un'immagine esistente, più `data` e `version`. Solo browser |
| `getScanScoreFromPixels(pixels, options?)` | `Promise<ImageScanScoreResult>` | Il punteggio dell'immagine su pixel RGBA, in Node |
| `scanQRPixels(pixels, expected, { sizes? })` | `Promise<PixelScanResult>` | Verifica che i pixel si decodifichino in `expected`, così come sono e attraverso il modello della fotocamera. Node |
| `getScanContrast(props)` | `{ ratio, required, inverted }` | Il controllo del contrasto da solo |
| `getStylePairRisk(props)` | `StylePairRisk \| null` | Una coppia di forme che alcuni scanner non leggono, con un `fix` |
| `handleImageLoad(img, size, returnFullData?)` | `Promise<string \| QRCode \| "NO_QR">` | Decodifica un QR code da un `<img>`. Vedi [Rilevamento dei QR code](/docs/qr-detection) |
| `downloadImageWithBoundingBox(img, corners, filename)` | `void` | Salva l'immagine con il codice trovato evidenziato da un contorno |

I voti sono `"great"`, `"ok"`, `"risky"` e `"fails"`. Ogni controllo è `{ id, passed, message, fix?, skipped? }`. Soglie di contrasto: `SCAN_CONTRAST_MIN` 4.5, `SCAN_CONTRAST_LOW` 3, `SCAN_CONTRAST_FAIL` 1.5 e `SCAN_IMAGE_CONTRAST_MIN` 7 per un'immagine nel codice e 12 dietro di esso. Le coppie deboli sono incluse come `WEAK_BODY_EYES`, `WEAK_DOT_EYES`, `WEAK_SHARP_DOT_EYES`, `SHARP_DOT_EYE_SAFE_BODIES`, `WEAK_EYES` e `WEAK_DOTS`.

## Template [#templates]

| Export | Cos'è |
| --- | --- |
| `TEMPLATES` | Il registro: `default`, `Arrow`, `StandardBox`, `SquareBorder`, `StrikedBox`, `Halloween`, `DotRing` |

## Tipi ed elenchi di opzioni [#types-and-option-lists]

I tipi seguenti provengono da `qrdx`, `qrdx/core` e `qrdx/types`. Gli elenchi di opzioni sono semplici array; da essi sono costruiti gli schemi zod (`qrPropsSchema`, `frameSchema`, `frameSpecSchema`, `colorConfigSchema`, `qrArtSchema`, `logoOptionsSchema`, `imageSettingsSchema` e gli altri).

| Tipo | Forma |
| --- | --- |
| `QRProps` | La tabella delle prop qui sopra, senza l'API del logo |
| `QRCodeProps` | `QRProps` più `logo`, `logoOptions`, `hideLogo`, `scale` |
| `QRSVGOptions` | `QRProps` più qualsiasi attributo della radice: ciò che disegna il core |
| `ColorConfig` | `string \| SolidColor \| LinearGradient \| RadialGradient \| AngularGradient \| ImagePaint` |
| `LinearGradient` | `{ type: "linear", stops, angle? }`; `angle` in gradi, valore predefinito 0 |
| `RadialGradient` | `{ type: "radial", stops }` |
| `AngularGradient` | `{ type: "angular", stops, angle? }` |
| `GradientStop` | `{ color, offset }`; `offset` da 0 a 100 |
| `ImagePaint` | `{ type: "image", src, fit?, scale?, position?, opacity?, underlay? }` |
| `ImageSettings`, `LogoOptions`, `EyeColors` | Come nelle tabelle qui sopra |
| `QRFrame` | `{ style: FrameStyle, text?, color?, textColor?, secondaryText?, secondaryColor?, fontScale? }` |
| `QRCustomFrame`, `AnyQRFrame`, `FrameSpec` | `{ style: "custom", spec, ...labels and colors }`, l'unione e il formato della specifica |
| `QRArt`, `QRArtImage` | `{ mode, image, intensity?, variant?, matchEyes? }` e `{ width, height, data }` |
| `QRCodeShape`, `QRSilhouette` | `"square" \| "circle" \| "heart"` oppure `{ type: "silhouette", width, height, cells }` |
| `TemplateDefinition`, `BaseTemplateProps`, `TemplateConfig` | Template |
| `DownloadFormat`, `DownloadSize`, `DownloadOptions`, `PrintOptions`, `PrintLayout`, `EPSOptions` | Esportazione |
| `ScanScoreResult`, `ImageScanScoreResult`, `ScanCheck`, `ScanGrade`, `StylePairRisk` | Il punteggio di scansione |
| `BodyPattern`, `CornerEyePattern`, `CornerEyeDotPattern`, `FrameStyle`, `ErrorLevel` | Le unioni delle opzioni |

Elenchi di opzioni: `BODY_PATTERN`, `CORNER_EYE_PATTERNS`, `CORNER_EYE_DOT_PATTERNS`, `FRAME_STYLES`, `QR_SHAPES`, `LOGO_SHAPES`, `EYE_POSITIONS`. Valori ritirati che vengono ancora renderizzati per i design salvati: `RETIRED_CORNER_EYE_PATTERNS` (`curly`) e `RETIRED_CORNER_EYE_DOT_PATTERNS` (`diamond`, `star`, `banner`).

## Dove vengono eseguite le funzioni [#where-things-run]

- **Ovunque, senza DOM:** `toSVGString`, `createQRCodeTree`, `renderToString`, `getQRData`, gli helper per cornici e template, `createQRArtImage`, `createQRSilhouette`, `getPrintLayout`, `getQRAsEPS`, `getQRAsPrintPDFBuffer`, `scanQRPixels`, `toQRdxCodeHTML`.
- **Browser:** `downloadQRCode` e gli altri download, `copyQRCodeToClipboard`, `getQRAsCanvas`, `getScanScore`, `getImageScanScore`, `handleImageLoad`, `loadQRArtImage`, `loadQRSilhouette`, `removeLogoBackground`, `createQRCode`, il custom element.
- **Solo Node:** `getQRAsPNG` da `qrdx/node`.
- **React Server Components:** `QRCode`, `QRCodeSVG` e tutto ciò che non richiede il DOM. `QRCodeCanvas` è un Client Component.
