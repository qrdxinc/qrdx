title: "動的QRコード"
description: "QRコードを一度印刷すれば、あとからリンク先を変更でき、どのくらい、どこでスキャンされたかも確認できます。"
---

動的QRコードには、最終的なURLの代わりに `https://qrdx.dev/q/aB3dE5f` のような短いリンクが埋め込まれています。スキャンすると短いリンクが開き、設定したリンク先にリダイレクトされます。リンク先はいつでも変更できるため、印刷済みのコードが古くなることはなく、すべてのスキャンが集計されます。メニュー、パッケージ、ポスター、名刺など、手軽に刷り直せないものにコードを載せるときに使ってください。

<Callout type="info" title="QRdxアカウントが必要です">
  Playgroundや `qrdx` ライブラリで作成する静的QRコードは、これまでどおり無料で無制限に利用できます。動的QRコードにはアカウントが必要です。フリーでは有効な動的QRコードを10個まで作成でき、ProとBusinessでは制限はありません。[プランと制限](/docs/plans-and-limits)をご覧ください。
</Callout>

お急ぎの方は、手順別の短いページをご覧ください。[動的QRコードを作成する](/docs/help/dynamic-codes/create)、[コードのリンク先を変更する](/docs/help/dynamic-codes/change-the-link)、[スキャンを確認する](/docs/help/dynamic-codes/scans)、[コードのアーカイブ、削除、復元](/docs/help/dynamic-codes/archive-and-delete)。

## 仕組み [#how-it-works]

<Diagram id="dynamic-redirect" />

印刷されたコードは変わらず、短いリンクを保持しています。誰かがスキャンすると、QRdxはコードの設定（一時停止中か、スケジュール設定やパスワード保護があるか、デバイスや場所で振り分けているか）を確認し、Cookieを使わずにスキャンを記録して、リンク先にリダイレクトします。リンク先、デザイン、設定を変更すると、次のスキャンから反映されます。

## コードを作成する [#create-a-code]

**ダッシュボード:** [コード](/dashboard?to=codes)を開き、**New code** をクリックします。**New dynamic QR code** ダイアログで、コードで何を開くかを選びます。**Website link**、または[ホスト型ページ](/docs/landing-pages)のテンプレートのいずれかです。リンクの場合は **Destination URL** と、任意で **Title** を入力してからコードを作成します。コードの **Overview** タブから、PNG、WebP、SVGでダウンロードできます。

<Shot id="new-code-dialog" />

**Playground:** コンテンツタイプで **URL** を選び、リンクを入力して、リンクを **Static** から **Dynamic** に切り替えます。QRコードには短いリンクが埋め込まれ、デザインはそのまま維持されます。そのあとでURLを編集した場合は、**Point it to the new address** をクリックするとリンク先が更新されます。**Save design to code** は、現在のデザインをコードに保存します。静的として作成したコードには、アクションバーの **⋯** メニューにある **Make it dynamic…** を使えます。

<Shot id="playground-content" />

リンク先は `http://` または `https://` のリンクである必要があります。ユーザー名やパスワードを含むリンク、および他のQRdx短縮リンクへのリンクは受け付けられません。すべてのリンク先は[リンクの安全性チェック](/docs/code-controls#safety-checks-on-links)も通ります。

## カスタムバックハーフ [#custom-back-halves]

すべてのコードには、`/q/` に続く部分であるランダムな7文字のバックハーフが割り当てられます。ProとBusinessでは、`https://qrdx.dev/q/spring-menu` のように好きなものを指定できます。コードの作成時または編集時に **Custom back-half** を入力すると、入力中に使えるかどうかがダイアログに表示されます。

- 3〜64文字で、使えるのは英字、数字、`-`、`_` です。先頭と末尾を `-` にすることはできません。
- 自動生成されたものと同様に、バックハーフは大文字と小文字を区別します。`Spring-Menu` と `spring-menu` は別のリンクです。
- `qrdx.dev` では、バックハーフはQRdx全体で一意である必要があります。また、QRdxのページと紛らわしい語（`admin`、`api`、`docs`、`login`、`pricing`、`settings` など）は予約されています。
- ご自身の[カスタムドメイン](/docs/custom-domains)では、そのドメイン内で一意であればよく、予約されているのは一部の技術的な語（`api`、`_next`、`null`、`undefined`）だけなので、`go.yourbrand.com/pricing` も使えます。このようなバックハーフはドメインに属するため、`qrdx.dev/q/` のリンクはありません。

コードのバックハーフを変更するとリンクが変わります。古いバックハーフで印刷したQRコードは使えなくなるため、コードをダウンロードし直してください。

## コードを管理する [#manage-a-code]

[コード](/dashboard?to=codes)からコードを開きます。コードのページには3つのタブがあります。**Overview**（短いリンク、QRコードとそのダウンロード、スキャン合計、**Use with NFC**、各オプションへのショートカット）、**Analytics**、**Settings** です。タブの上には次の項目があります。

- **Edit link** はリンク先またはタイトルを変更します。印刷済みのコードはそのまま使え、次のスキャンから新しいリンク先が開きます。
- **Change type** は、ウェブサイトのリンクを[ホスト型ページ](/docs/landing-pages)に、ページをリンクに、またはページを別の種類のページに変更します。短いリンクとスキャンはそのまま残ります。[印刷済みコードで開く内容を変更する](/docs/help/dynamic-codes/change-the-type)をご覧ください。
- **⋯** メニューには、**Edit design in playground**（コードが短いリンクに紐づいたままエディターが開きます）、**Duplicate**、**Share analytics...**、**Move to folder...**、**Move to workspace...**、**Pause** または **Resume**、**Archive**、**Move to trash** があります。

<Shot id="code-overview" />

**Duplicate** は、新しい短いリンクを持ち、スキャンがゼロの新しいコードを作成します。リンク先、デザイン、フォルダー、タグ、メモ、タイプがコピーされ、ご利用のプランに含まれていれば、コードのコントロール、ルーティング、UTM、ピクセルの設定もコピーされます。

**Archive** はコードを残したまま無効にします。復元するまで、短いリンクには「This QR code is no longer active」ページが表示され、アーカイブしたコードはプランの上限に含まれません。**Move to trash** も同様で、さらに **Trash** からコードを完全に削除できます。完全に削除するとスキャン履歴も消え、短いリンクには「QR code not found」ページが表示されます。

**Settings** タブの下部にある **Version history** には、コードへのすべての変更が記録されます（最大100バージョン）。バージョンを復元する際は、現在の設定が先に保存されるため、復元は元に戻せます。

## コードを整理する [#organize-codes]

- **フォルダー**は最大5階層までネストできます。コードをフォルダーにドラッグするか、**Move to folder...** を使います。フォルダーを削除すると、そのコードとサブフォルダーは1階層上に移動します。
- **タグ**で一覧を絞り込めます。複数選ぶと、そのすべてを持つコードが表示されます。
- **お気に入りとメモ:** コードにスターを付け、非公開のメモを残せます。メモは検索できます。
- **検索**はタイトル、リンク先、メモ、タグ、バックハーフが対象なので、短いリンクを貼り付けるとそのコードが見つかります。
- **一括操作:** コードを選択して、移動、タグ付け、一時停止、アーカイブ、お気に入り登録、ゴミ箱への移動、またはPNG、WebP、SVGファイルのZIPとしてダウンロードできます。
- **CSVインポート:** サイドバーの **Codes** → **Import**（または **New code** → **Import codes** → **From a CSV file**）で、1つのファイルから最大{facts.importRows}個の動的QRコードを作成できます。リンク先、タイトル、フォルダー、タグ、そして `slug` 列に任意のカスタムバックハーフを指定できます。すべてのコードを1つのフォルダーに入れ、まとめてタグを付けることもできます。長いインポートは一時停止でき、再読み込みや接続が切れた場合も、コードを重複して作成することなく途中から再開します。最後に、結果のCSV（各行の短いリンク）と、PNGまたはSVGのコードをまとめたZIPが出力されます。2行以上のインポートとカスタムバックハーフにはProが必要です。

## 権限 [#who-can-do-what]

コードは、作成されたワークスペースに属します。オーナー、管理者、メンバーはコードを作成・編集できます。メンバーは自分のコードを削除でき、オーナーと管理者はどのコードでも削除できます。閲覧者と請求担当メンバーは閲覧のみです。ワークスペースのコードには、オーナーと請求担当メンバーのうち最上位のプランが適用されます。[ワークスペースとチーム](/docs/teams)をご覧ください。

## スキャン分析 [#scan-analytics]

コードの **Analytics** タブには、過去7日、30日、90日、1年、3年、または最初のスキャン以降の全期間について、時間ごとのスキャン数、ユニークビジターの数、QRスキャンとNFCタップ、上位の国と都市、デバイス、OS、ブラウザー、リファラーが表示されます。フリーでは直近{facts.freeScanHistoryYears}年分、ProとBusinessではすべての履歴が表示されます。**Export CSV** は、選択した期間のスキャンをダウンロードします。

<Shot id="code-analytics" />

各スキャンでは、時刻（UTC）、ネットワークから判別した国、地域、市区町村、ユーザーエージェントから判別したデバイスの種類、OS、ブラウザー、そしてリファラーのホスト名が記録されます。IPアドレスの代わりに、アドレス、ユーザーエージェント、日付を組み合わせたソルト付きハッシュを保存します。これにより1日ごとのユニークビジターを集計でき、元のアドレスに戻すことはできません。既知のボット、リンクのプレビュー、ブラウザーのプリフェッチはカウントされません。ProとBusinessでは、コードから[スキャンした人に正確な位置情報を尋ねる](/docs/precise-location)こともできます。全項目の一覧は[スキャン時にQRdxが記録する情報](/docs/help/privacy-and-security/scan-data)をご覧ください。

| スキャン | 無制限 | 無制限 | 無制限 |

<Callout type="info" title="コードは決して使えなくなりません">
  ダウングレードしても、既存のコードが無効になることはありません。上限を超えている間も、コードの編集とアーカイブはできますが、上限を下回るまでは新規作成も復元もできません。[お支払いを停止した場合のコードの扱い](/docs/help/account-and-billing/never-hostage)をご覧ください。
</Callout>

## 開発者向け [#rest-api]

ここまでの機能はすべて、`https://api.qrdx.dev/v1/codes` 以下の REST API から利用できます。[APIキー](/docs/developers/api-keys)、または `codes:read` か `codes:write` スコープを持つ OAuth トークンが必要です。

- コードの[一覧取得](/docs/developers/api/list-codes)、[作成](/docs/developers/api/create-codes)、[取得](/docs/developers/api/get-code)、[更新](/docs/developers/api/update-code)、[削除](/docs/developers/api/delete-code)ができ、[スキャン数などの記録の読み取り](/docs/developers/api/get-code-scans)も可能です。
- Pro と Business では、`POST /v1/codes` で最大 {facts.apiBatchCodes} 件のコードを1回のリクエストでまとめて作成できます。このリクエストは全件成功か全件失敗のどちらかです。`Idempotency-Key` ヘッダーを付けると、再試行しても重複して作成されません。また `Prefer: return=minimal` を指定すると、各コードのデザインがレスポンスから省かれます。詳細は[コードの作成](/docs/developers/api/create-codes)をご覧ください。
- `slug` で後半部分（バックハーフ）を、`domainId` でカスタムドメインを指定します。`kind` でリダイレクトとページを切り替え、`preciseLocation` で位置情報のステップを有効にします。どのコードも `shortLink`、`defaultShortLink`、`nfcLink` が返されます。
- エラーはすべて同じ形式です。詳しくは[エラー](/docs/developers/errors)をご覧ください。

認証とレート制限については [REST API](/docs/developers/rest-api) のページで説明しています。[クイックスタート](/docs/developers/quickstart)では、ターミナルから最初のコードを作成します。

## セルフホスティング [#self-hosting]

動的QRコードは、セルフホストしたインスタンスでも、2つの任意の環境変数で利用できます。`NEXT_PUBLIC_SHORT_LINK_BASE_URL` は短縮リンクのオリジンを設定します（デフォルトはアプリの URL です）。`SCAN_HASH_SALT` は訪問者ハッシュのソルトを設定します（未設定の場合は `BETTER_AUTH_SECRET` から生成されます）。国、地域、市区町村は Vercel の位置情報ヘッダーから取得します。Cloudflare 経由の場合は国のみが読み取られ、それ以外の環境では位置情報は不明と表示されます。[エリアルール](/docs/precise-location#route-scans-by-area)は、スキャンした人が位置情報を共有しなかった場合に Vercel の IP 座標を使います。そのため Vercel 以外では、共有された位置情報にのみ一致します。レート制限は Upstash Redis を設定している場合に適用されます。詳しくは[セルフホスティング](/docs/self-hosting#optional-services)をご覧ください。
