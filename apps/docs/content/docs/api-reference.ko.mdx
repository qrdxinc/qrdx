이 페이지에서는 `qrdx`가 내보내는 항목을 진입점별, 작업별로 나열하고 각 prop의 타입과 기본값을 함께 보여 줍니다. 사용 방법은 기능 페이지에서 설명하고, 이 페이지는 이름을 찾아볼 때 사용합니다.

## 진입점 [#entry-points]

| 가져올 경로 | 포함 항목 | 필요한 것 |
| --- | --- | --- |
| `qrdx` | React 컴포넌트(`QRCode`, `QRCodeSVG`, `QRCodeCanvas`, `getQRAsSVG`)와 `qrdx/core`의 모든 항목 | `react`, `react-dom` |
| `qrdx/core` | React 없는 전체 엔진: 마크업, 다운로드, 인쇄 파일, 스캔 점수, 프레임, 템플릿, 아트, 타입 | 없음 |
| `qrdx/vanilla` | `createQRCode`와 `qrdx/core` | DOM |
| `qrdx/element` | `<qrdx-code>` 커스텀 엘리먼트: `QRdxCodeElement`, `defineQRdxCode`, `toQRdxCodeHTML` | 그리려면 DOM 필요, 마크업 렌더링에는 불필요 |
| `qrdx/element/define` | 가져오면 `<qrdx-code>`를 등록 | DOM |
| `qrdx/node` | `getQRAsPNG` | `@resvg/resvg-js` 또는 `sharp` |
| `qrdx/vue` | `QRCode`, `QRCodeSVG`, `useQRCode`와 `qrdx/core` | `vue` 3.3 이상 |
| `qrdx/preact` | `QRCode`, `QRCodeSVG` | `preact` 10 이상 |
| `qrdx/solid` | `QRCode`, `QRCodeSVG` | `solid-js` 1.8 이상 |
| `qrdx/angular` | `QRCode` 컴포넌트(`<qrdx-qr-code>`)와 `qrdx/core` | `@angular/core` 20 이상 |
| `qrdx/types` | 렌더러 없이 모든 타입, 옵션 목록, zod 스키마 | 없음 |

모든 프레임워크 패키지는 선택적 peer dependency입니다. `qrdx`를 설치해도 사용하지 않는 패키지가 추가되지 않습니다. PDF용 `jspdf`도 선택 사항입니다.

## 컴포넌트 [#components]

### QRCode [#qrcode]

대부분의 경우에 쓰는 컴포넌트입니다. `QRProps`에 간단한 로고 API를 더해 `<svg>`로 렌더링합니다. 브라우저 전용 훅을 쓰지 않아 React Server Components에서도 렌더링됩니다.

```tsx title="components/example.tsx"
import { QRCode } from "qrdx";

<QRCode value="https://example.com" size={256} margin={4} level="H" logo="/logo.png" />;
```

| Prop | 타입 | 기본값 | 설명 |
| --- | --- | --- | --- |
| `value` | `string` | 필수 | 인코딩할 텍스트 또는 URL이며, 입력한 그대로 사용합니다 |
| `size` | `number` | `128` | 너비와 높이(픽셀)입니다. 프레임은 이 크기에 더해지고, 템플릿은 이 크기 안에 맞춰집니다 |
| `scale` | `number` | `1` | `size`에 곱하는 배율입니다 |
| `level` | `"L" \| "M" \| "Q" \| "H"` | `"Q"` | 오류 정정 수준입니다. 코드의 약 7%, 15%, 25%, 30%가 손상되어도 읽을 수 있습니다 |
| `margin` | `number` | `0` | 코드 주변의 여백(콰이어트 존)이며 모듈 단위입니다. 표준에서는 4를 요구합니다 |
| `fgColor` | `ColorConfig` | `"#000000"` | 데이터 모듈의 색입니다. CSS 색상, 그라디언트, 이미지 채우기를 쓸 수 있습니다 |
| `bgColor` | `ColorConfig` | `"#FFFFFF"` | 배경입니다. `"transparent"`는 배경을 칠하지 않습니다 |
| `eyeColor` | `ColorConfig` | `fgColor` | 모서리 세 곳에 있는 눈의 색입니다 |
| `dotColor` | `ColorConfig` | `fgColor` | 각 눈 안쪽 점의 색입니다 |
| `eyeColors` | `EyeColors` | 없음 | `topLeft`, `topRight`, `bottomLeft`별 `outer`, `inner` 색입니다. 각각 `eyeColor`와 `dotColor`보다 우선합니다 |
| `bodyPattern` | `BodyPattern` | `"circle"` | 데이터 모듈의 모양이며 {facts.bodyPatterns} 중 하나입니다 |
| `cornerEyePattern` | `CornerEyePattern` | `"gear"` | 모서리 눈의 모양이며 {facts.eyeShapes} 중 하나입니다 |
| `cornerEyeDotPattern` | `CornerEyeDotPattern` | `"circle"` | 눈 안쪽 점의 모양이며 {facts.eyeCentres} 중 하나입니다 |
| `moduleScale` | `number` | `1` | 각 데이터 모듈의 크기이며 0.5에서 1 사이입니다. 각 패턴은 스캔이 가능한 최소 크기(`MODULE_SCALE_FLOOR`)에서 멈춥니다 |
| `logo` | `string` | 없음 | 가운데에 그릴 경로, URL, 데이터 URL이며 뒤쪽 모듈은 비워 둡니다. 지정하지 않으면 로고를 그리지 않습니다 |
| `logoOptions` | `LogoOptions` | 없음 | 로고의 `size`(0.1~0.3, 기본값 0.25), `padding`(0~2모듈), `x`와 `y`(0~1), `shape`, `plate`입니다 |
| `hideLogo` | `boolean` | `false` | `logo`가 설정되어 있어도 로고를 숨깁니다 |
| `autoLevel` | `boolean` | `false` | 로고가 코드의 7% 넘게 가리면 `level`을 `H`로 올립니다(`AUTO_LEVEL_LOGO_COVERAGE`) |
| `frame` | `AnyQRFrame` | 없음 | 행동 유도 프레임입니다. `{ style, text, color, textColor, secondaryText, secondaryColor, fontScale }` 또는 `{ style: "custom", spec }` 형태이며, 출력 크기가 프레임에 맞게 커집니다 |
| `templateId` | `string` | 없음 | `size`로 그려지고 코드가 안에 들어가는 템플릿입니다. `"Arrow"`, `"StandardBox"`, `"SquareBorder"`, `"StrikedBox"`, `"Halloween"`, `"DotRing"`, `"default"` 중 하나입니다 |
| `customTemplate` | `TemplateDefinition` | 없음 | 코드로 직접 그린 템플릿입니다. `templateId`보다 우선합니다 |
| `customProps` | `Record<string, any>` | 없음 | 템플릿의 `wrapper`에 전달할 prop입니다(예: `DotRingProps`) |
| `shape` | `"square" \| "circle" \| "heart" \| QRSilhouette` | `"square"` | 코드를 원, 하트 또는 직접 만든 윤곽선 안에 넣고 장식용 모듈로 채웁니다 |
| `art` | `QRArt` | 없음 | 그림을 모듈에 섞어 넣습니다. `{ mode, image, intensity, variant, matchEyes }` 형태입니다 |
| `style` | `CSSProperties` | 없음 | `<svg>`에 적용할 인라인 스타일입니다 |
| `frameLabelMarkers` | `boolean` | `false` | 에디터용입니다. 각 프레임 레이블 `<text>`에 `data-qrdx-frame-label`을 표시하며, 내보낸 파일에는 포함되지 않습니다 |
| `partMarkers` | `boolean` | `false` | 에디터용입니다. 그려진 각 부분에 `data-qrdx-part`를 표시하며, 내보낸 파일에는 포함되지 않습니다 |
| `isOGContext` | `boolean` | `false` | Open Graph 이미지 렌더러를 위해 로고를 위치가 지정된 `<img>`로 그립니다 |

`QRCode`는 위 prop만 받으며, 그 밖의 prop은 버려집니다. `QRCodeSVG`는 그 밖의 prop(`className`, `aria-label`, `role`, `data-*` 등)을 `<svg>`에 붙이고, 프레임이 있으면 프레임의 바깥쪽 `<svg>`에 붙입니다. 이벤트 핸들러는 마크업에 포함되지 않습니다.

### QRCodeSVG [#qrcodesvg]

`QRProps`에 React의 SVG 속성(`QRPropsSVG`)을 더한 것입니다. `QRCode`와 같은 prop에서 `logo`, `logoOptions`, `hideLogo`, `scale`을 뺀 구성입니다. 로고는 픽셀 단위의 `imageSettings`로 지정합니다.

| 필드 | 타입 | 기본값 | 설명 |
| --- | --- | --- | --- |
| `src` | `string` | 필수 | 이미지이며 URL 또는 데이터 URL입니다 |
| `width`, `height` | `number` | 필수 | `size`와 같은 픽셀 단위의 크기입니다 |
| `excavate` | `boolean` | 필수 | 이미지 뒤쪽의 모듈을 비웁니다 |
| `x`, `y` | `number` | 가운데 | 이미지의 왼쪽 위 모서리입니다 |
| `padding` | `number` | `0` | 모듈을 비울 때 이미지 주변에 추가로 두는 빈 공간이며 픽셀 단위입니다 |
| `shape` | `"square" \| "rounded" \| "circle"` | `"square"` | 이미지를 잘라 냅니다 |
| `plate` | `string` | 없음 | 이미지 뒤에 이미지 모양대로 놓는 단색 판입니다 |

코드가 복원할 수 있는 범위보다 큰 로고는 가운데를 기준으로 줄어듭니다(`capImageSettings`, `QRCode`와 같은 기준). 

### QRCodeCanvas [#qrcodecanvas]

`QRProps`에 React의 canvas 속성(`QRPropsCanvas`)을 더한 것으로, 기기의 픽셀 비율에 맞춰 `<canvas>`에 그립니다. 단색의 일반 사각형 모듈만 그립니다. 그라디언트는 첫 번째 색으로 대체되고, 패턴, 눈 색상, `eyeColors`, `moduleScale`, `art`, 템플릿 prop은 무시됩니다. `"use client"`가 포함되어 제공됩니다.

### getQRAsSVG [#getqrassvg]

`getQRAsSVG(props: QRPropsSVG): Promise<JSX.Element>`는 로고를 데이터 URL로 포함한 코드를 React 엘리먼트로 반환합니다. 문자열이 필요하면 `toSVGString` 또는 `getSVGString`을 사용하세요.

## 다운로드 및 내보내기 [#download-and-export]

| 함수 | 반환값 | 참고 |
| --- | --- | --- |
| `downloadQRCode(props, { format, size, filename?, quality? })` | `Promise<void>` | 파일을 저장합니다. `size`는 50~5000px이며 정사각형입니다. 래스터 형식의 기본 파일 이름에는 픽셀 크기가 들어갑니다 |
| `getQRCodeDataUrl(props, format, size, { quality? })` | `Promise<string>` | 같은 파일을 데이터 URL로 반환합니다 |
| `getQRAsWebP(props, { quality? })` | `Promise<Blob>` | `quality`를 지정하지 않으면 무손실입니다. 브라우저가 지원하지 않으면 직접 인코딩합니다 |
| `copyQRCodeToClipboard(props, size?)` | `Promise<void>` | PNG를 클립보드에 복사합니다. 사용자 동작에서 호출하세요 |
| `getSVGString(props)` | `Promise<string>` | 로고가 포함된 SVG 마크업입니다 |
| `toSVGString(props)` | `string` | 동기 방식의 SVG 마크업이며 로고는 포함되지 않습니다. 어디서든 실행됩니다 |
| `toSVGElement(props, document?)` | `SVGSVGElement` | QR 코드를 DOM 요소로 반환합니다 |
| `getQRAsSVGDataUri(props)` | `Promise<string>` | `data:image/svg+xml,…`이며 모든 내보내기의 첫 단계입니다 |
| `getQRAsCanvas(props, mimeType, getCanvas?)` | `Promise<string \| HTMLCanvasElement>` | 데이터 URL을 반환하며, `getCanvas`를 쓰면 캔버스 자체를 반환합니다 |
| `getQRAsPNG(props, { size?, loadExternalLogos? })` | `Promise<Uint8Array>` | Node에서 `qrdx/node`로 가져오는 PNG 바이트입니다. `@resvg/resvg-js` 또는 `sharp`가 필요합니다 |
| `validateSize(width, height)` | `{ isValid, error? }` | `downloadQRCode`가 적용하는 크기 규칙입니다 |
| `getDownloadFilename(format, size, frame?)` | `string` | 기본 파일 이름입니다 |
| `withQRSize(props, size)` | `QRProps` | `size`로 그려지는 props이며, 픽셀 로고도 함께 크기가 조정됩니다 |
| `canvasToWebP(canvas, { quality? })`, `blobToDataUrl(blob)`, `encodeWebPLossless(rgba, width, height)` | | WebP 헬퍼입니다 |

상수: `DownloadFormat`은 `"png" \| "jpg" \| "webp" \| "svg" \| "pdf" \| "eps"`입니다. `DOWNLOAD_FORMATS`는 각 형식을 MIME 타입과 확장자에 대응시킵니다. `PRESET_SIZES`에는 `small`(200), `medium`(400), `large`(800), `xlarge`(1200), `2xl`(1600), `3xl`(2000)이 있습니다. `DEFAULT_SIZE`는 128입니다.

## 인쇄 및 EPS [#print-and-eps]

| 함수 | 반환값 | 참고 |
| --- | --- | --- |
| `getPrintLayout(props, { size, unit?, bleed?, cropMarks?, colorMode? })` | `PrintLayout` | mm 단위의 실제 크기: `codeWidth`, `trimWidth`, `trimHeight`, `bleed`, `pageWidth`, `pageHeight`, `moduleSize`, `moduleCount`, `maxScanDistance`. `size`는 5mm~2m입니다 |
| `getQRAsPrintPDF(props, options)` | `Promise<string>` | 벡터 PDF를 데이터 URL로 반환합니다. `jspdf`가 필요합니다 |
| `getQRAsPrintPDFBuffer(props, options)` | `Promise<ArrayBuffer>` | 같은 PDF를 바이트로 반환하며 Node용입니다 |
| `getQRAsPrintSVG(props, { size, unit? })` | `Promise<string>` | `width`와 `height`가 mm 또는 in인 SVG입니다 |
| `downloadPrintPDF(props, options & { filename? })`, `downloadPrintSVG(props, options & { filename? })` | `Promise<void>` | 두 형식의 브라우저 다운로드입니다 |
| `getQRAsEPS(props, { sizeMm?, bleedMm?, colorMode? })` | `Promise<string>` | EPSF-3.0 텍스트입니다. 이미지 채우기이면 `EPS_IMAGE_FILL_REASON` 오류를 던집니다 |
| `downloadPrintEPS(props, options & { filename? })` | `Promise<void>` | 브라우저 다운로드입니다 |
| `svgToEPS(svg, { width?, colorMode?, bleed?, bleedColor?, title? })` | `Promise<string>` | 라이브러리가 렌더링하는 모든 SVG를 변환합니다 |
| `epsToDataUrl(eps)`, `hasImageFill(props)`, `rgbToCmyk(color)`, `getQRModuleCount(props)` | | 헬퍼입니다 |

`PrintOptions`: `size`(숫자), `unit`(`"mm"` 또는 `"in"`, 기본값 `"mm"`), `bleed`(mm, 0~20), `cropMarks`(불리언), `colorMode`(`"rgb"` 또는 `"cmyk"`).

## 스캔 점수 및 감지 [#scan-score-and-detection]

| 함수 | 반환값 | 참고 |
| --- | --- | --- |
| `getScanScore(props, { sizes?, signal? })` | `Promise<ScanScoreResult>` | `{ score, grade, checks }`. 브라우저 전용이며 jsQR을 필요할 때 불러옵니다. 기본 크기는 96, 160, 320px(`SCAN_TEST_SIZES`)입니다 |
| `getImageScanScore(imageOrBlob, options?)` | `Promise<ImageScanScoreResult>` | 기존 이미지에 대한 같은 기능이며 `data`와 `version`이 추가됩니다. 브라우저 전용 |
| `getScanScoreFromPixels(pixels, options?)` | `Promise<ImageScanScoreResult>` | Node에서 RGBA 픽셀에 대한 이미지 점수입니다 |
| `scanQRPixels(pixels, expected, { sizes? })` | `Promise<PixelScanResult>` | 픽셀이 원본 그대로, 그리고 카메라 모델을 거쳐서도 `expected`로 디코딩되는지 확인합니다. Node |
| `getScanContrast(props)` | `{ ratio, required, inverted }` | 대비 검사만 단독으로 실행합니다 |
| `getStylePairRisk(props)` | `StylePairRisk \| null` | 일부 스캐너가 인식하지 못하는 모양 조합이며 `fix`가 함께 제공됩니다 |
| `handleImageLoad(img, size, returnFullData?)` | `Promise<string \| QRCode \| "NO_QR">` | `<img>`에서 QR 코드를 디코딩합니다. [QR 감지](/docs/qr-detection)를 참고하세요 |
| `downloadImageWithBoundingBox(img, corners, filename)` | `void` | 찾은 코드에 윤곽선을 그린 이미지를 저장합니다 |

등급은 `"great"`, `"ok"`, `"risky"`, `"fails"`입니다. 각 검사는 `{ id, passed, message, fix?, skipped? }`입니다. 대비 기준: `SCAN_CONTRAST_MIN` 4.5, `SCAN_CONTRAST_LOW` 3, `SCAN_CONTRAST_FAIL` 1.5, 그리고 코드 안의 그림은 `SCAN_IMAGE_CONTRAST_MIN` 7, 코드 뒤의 그림은 12입니다. 취약한 조합은 `WEAK_BODY_EYES`, `WEAK_DOT_EYES`, `WEAK_SHARP_DOT_EYES`, `SHARP_DOT_EYE_SAFE_BODIES`, `WEAK_EYES`, `WEAK_DOTS`로 제공됩니다.

## 로고 [#logos]

| 함수 | 반환값 | 참고 |
| --- | --- | --- |
| `getQRData(props)` | `imageSettings`가 포함된 props | 1024px 코드 기준으로 `logo`와 `logoOptions`를 배치하며, 오류 정정 예산을 넘지 않도록 제한합니다 |
| `resolveQRCodeProps(props)` | `QRSVGOptions` | `QRCode`의 props를 렌더러가 그리는 형태로 변환하며 `scale`이 적용됩니다 |
| `getLogoSizeLimit({ value, level, margin, shape, autoLevel, logoOptions })` | `number` | 들어갈 수 있는 가장 큰 `logoOptions.size`이며, 없으면 0입니다 |
| `getLogoBlockDamage(...)`, `logoFitsBudget(...)`, `getCodewordMap(...)`, `damagedCodewords(...)` | | 예산을 구성하는 부분들입니다. `LOGO_EC_SAFETY`는 0.6입니다 |
| `removeLogoBackground(src)` | `Promise<string \| null>` | 단색 배경을 제거한 로고를 PNG 데이터 URL로 반환합니다. 브라우저 |
| `removeLogoBackdrop(pixels)` | `LogoPixels \| null` | RGBA 픽셀에 대한 같은 기능이며 어디서든 실행됩니다 |

제한값: `LOGO_SIZE_MIN` 0.1, `LOGO_SIZE_MAX` 0.3, `LOGO_SIZE_DEFAULT` 0.25, `LOGO_PADDING_MAX` 2, `LOGO_SHAPES`(`square`, `rounded`, `circle`).

## 프레임 [#frames]

| 내보내기 | 설명 |
| --- | --- |
| `BUILT_IN_FRAMES` | 모든 기본 제공 프레임: `{ style, name, tags, labelOn, spec }`이며 선택기 순서와 같습니다 |
| `BUILT_IN_FRAME_SPECS`, `getBuiltInFrame(style)` | 스타일별 사양입니다 |
| `frameSpecOf(frame)` | 프레임이 그리는 사양이며, 없으면 `null`입니다 |
| `getFrameColors(frame)` | 옵션 또는 사양의 기본값에서 가져온 `{ frame, text, accent }`입니다 |
| `getFrameDimensions(size, frame)` | `size`px 코드에 대한 출력 `{ width, height }`입니다 |
| `getFrameLayout(size, frame)`, `getFrameText(frame)`, `getFrameSecondaryText(frame)`, `frameLabels(layout)`, `isFrameActive(frame)` | 레이아웃 헬퍼입니다 |
| `OFFICIAL_FRAMES`, `OFFICIAL_FRAME_INDEX`, `getOfficialFrame(id)`, `OFFICIAL_FRAME_COLLECTIONS`, `OFFICIAL_FRAME_COUNT` | 공식 프레임 라이브러리입니다. 프레임은 별도 모듈로 빌드되므로 사용하지 않으면 비용이 들지 않습니다 |
| `resolveFrameSpec(spec)`, `getFrameSpecIssues(spec)`, `frameSpecSchema` | 사양을 검사합니다. `resolveFrameSpec`은 `FrameSpecError`를 던집니다 |
| `importFrameSvg(svg, options)` | SVG 그림을 프레임 사양으로 변환하며 경고를 함께 제공합니다(`FRAME_IMPORT_LIMITS`) |
| `frameSpecHash(spec)` | 사양의 안정적인 해시입니다 |

상수: `FRAME_STYLES`({facts.frameStyles}가지 기본 스타일과 `none`), `DEFAULT_FRAME_TEXT`(`"Scan me"`), `FRAME_TEXT_MAX_LENGTH`(24), `FRAME_FONT_SCALE_MIN`(0.5), `FRAME_FONT_SCALE_MAX`(1.5), `CUSTOM_FRAME_STYLE`(`"custom"`), `GRADIENT_FRAME_DEFAULTS`.

## 타입과 옵션 목록 [#types-and-option-lists]

아래 타입은 `qrdx`, `qrdx/core`, `qrdx/types`에서 가져옵니다. 옵션 목록은 일반 배열이며, zod 스키마(`qrPropsSchema`, `frameSchema`, `frameSpecSchema`, `colorConfigSchema`, `qrArtSchema`, `logoOptionsSchema`, `imageSettingsSchema` 등)는 이 배열을 바탕으로 만들어집니다.

| 타입 | 형태 |
| --- | --- |
| `QRProps` | 위의 props 표에서 로고 API를 뺀 것 |
| `QRCodeProps` | `QRProps`에 `logo`, `logoOptions`, `hideLogo`, `scale`을 더한 것 |
| `QRSVGOptions` | `QRProps`에 루트 속성을 더한 것: 코어가 그리는 내용 |
| `ColorConfig` | `string \| SolidColor \| LinearGradient \| RadialGradient \| AngularGradient \| ImagePaint` |
| `LinearGradient` | `{ type: "linear", stops, angle? }`, `angle`은 도 단위이며 기본값은 0 |
| `RadialGradient` | `{ type: "radial", stops }` |
| `AngularGradient` | `{ type: "angular", stops, angle? }` |
| `GradientStop` | `{ color, offset }`, `offset`은 0에서 100 |
| `ImagePaint` | `{ type: "image", src, fit?, scale?, position?, opacity?, underlay? }` |
| `ImageSettings`, `LogoOptions`, `EyeColors` | 위의 표와 같음 |
| `QRFrame` | `{ style: FrameStyle, text?, color?, textColor?, secondaryText?, secondaryColor?, fontScale? }` |
| `QRCustomFrame`, `AnyQRFrame`, `FrameSpec` | `{ style: "custom", spec, ...labels and colors }`, 유니온 타입, 그리고 스펙 형식 |
| `QRArt`, `QRArtImage` | `{ mode, image, intensity?, variant?, matchEyes? }` 및 `{ width, height, data }` |
| `QRCodeShape`, `QRSilhouette` | `"square" \| "circle" \| "heart"` 또는 `{ type: "silhouette", width, height, cells }` |
| `TemplateDefinition`, `BaseTemplateProps`, `TemplateConfig` | 템플릿 |
| `DownloadFormat`, `DownloadSize`, `DownloadOptions`, `PrintOptions`, `PrintLayout`, `EPSOptions` | 내보내기 |
| `ScanScoreResult`, `ImageScanScoreResult`, `ScanCheck`, `ScanGrade`, `StylePairRisk` | 스캔 점수 |
| `BodyPattern`, `CornerEyePattern`, `CornerEyeDotPattern`, `FrameStyle`, `ErrorLevel` | 옵션 유니온 타입 |

옵션 목록: `BODY_PATTERN`, `CORNER_EYE_PATTERNS`, `CORNER_EYE_DOT_PATTERNS`, `FRAME_STYLES`, `QR_SHAPES`, `LOGO_SHAPES`, `EYE_POSITIONS`. 저장된 디자인에서는 계속 렌더링되는 지원 중단 값: `RETIRED_CORNER_EYE_PATTERNS`(`curly`), `RETIRED_CORNER_EYE_DOT_PATTERNS`(`diamond`, `star`, `banner`).

## 실행 환경 [#where-things-run]

- **어디서나, DOM 없이:** `toSVGString`, `createQRCodeTree`, `renderToString`, `getQRData`, 프레임 및 템플릿 헬퍼, `createQRArtImage`, `createQRSilhouette`, `getPrintLayout`, `getQRAsEPS`, `getQRAsPrintPDFBuffer`, `scanQRPixels`, `toQRdxCodeHTML`.
- **브라우저:** `downloadQRCode`와 그 밖의 다운로드 함수, `copyQRCodeToClipboard`, `getQRAsCanvas`, `getScanScore`, `getImageScanScore`, `handleImageLoad`, `loadQRArtImage`, `loadQRSilhouette`, `removeLogoBackground`, `createQRCode`, 커스텀 엘리먼트.
- **Node 전용:** `qrdx/node`의 `getQRAsPNG`.
- **React Server Components:** `QRCode`, `QRCodeSVG`, 그리고 DOM이 필요 없는 모든 것. `QRCodeCanvas`는 Client Component입니다.
