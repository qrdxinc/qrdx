Di akhir halaman ini, Anda akan memiliki kode QR bergaya dalam komponen Solid yang mengikuti sebuah signal, serta tombol yang menyimpannya sebagai PNG. `qrdx/solid` menyediakan dua komponen SVG milik pustaka React, yaitu `QRCodeSVG` dan `QRCode`, yang dibuat untuk SolidJS. Keduanya menggambar SVG yang sama seperti komponen React, mengikuti signal Anda, dan dapat dirender di server.

<NpmStatus package="qrdx" />

## Sebelum Anda mulai [#before-you-start]

- Proyek Solid 1.8 atau lebih baru (pada seri 1.x), dengan Vite atau SolidStart.
- Node.js 18 atau lebih baru.

## Membuatnya [#build-it]

### 1. Pasang qrdx [#1-install-qrdx]

```package-install
qrdx
```

`solid-js` adalah peer dependency opsional dari `qrdx`. Aplikasi Anda sudah memilikinya, dan Anda tidak memerlukan `react`.

### 2. Gambar kode yang mengikuti signal [#2-draw-a-code-that-follows-a-signal]

```tsx title="src/components/menu-code.tsx"
import { createSignal } from "solid-js";
import { QRCodeSVG } from "qrdx/solid";

export function MenuCode() {
  const [color, setColor] = createSignal("#0f172a");
  return (
    <>
      <QRCodeSVG
        value="https://example.com/menu"
        size={256}
        margin={4}
        fgColor={color()}
        frame={{ style: "banner-bottom", text: "Scan me" }}
        aria-label="QR code for the menu"
      />
      <button type="button" onClick={() => setColor("#1d4ed8")}>
        Blue
      </button>
    </>
  );
}
```

Halaman menampilkan kode gelap dengan banner "Scan me". Klik **Blue** dan kode digambar ulang dengan warna biru.

<Shot id="lib-solid-signal-code" />

`QRCodeSVG` menerima semua opsi yang diterima `QRCodeSVG` React: pola, warna dan gradien, logo (`imageSettings`), bingkai, bentuk, templat, dan seni. Atribut seperti `class`, `style`, atau `aria-label` dipasang pada `<svg>`, atau pada `<svg>` terluar dari bingkai bila ada bingkai.

`QRCode` menambahkan pintasan logo milik `QRCode` React: `logo`, `logoOptions`, `hideLogo`, dan `scale`. Komponen ini hanya menerima props kode dan `style`; letakkan `class` atau `aria-label` pada elemen yang membungkusnya, atau gunakan `QRCodeSVG`.

```tsx title="src/components/logo-code.tsx"
import { QRCode } from "qrdx/solid";

export function LogoCode() {
  return <QRCode value="https://example.com" size={256} logo="/logo.png" level="H" />;
}
```

Props bersifat reaktif, seperti pada komponen Solid mana pun. Saat `color()` berubah, kode digambar ulang. Event handler dalam props tidak dipasang pada `<svg>`, jadi letakkan pada elemen yang membungkus kode.

### 3. Simpan sebagai file [#3-save-it-as-a-file]

Komponen hanya menggambar kode. Unduhan, `toSVGString`, skor pemindaian, dan fungsi lainnya berasal dari `qrdx/core`. Itulah mesin yang sudah digunakan komponen, sehingga tidak dibundel dua kali.

```tsx title="src/components/downloadable-code.tsx"
import { downloadQRCode } from "qrdx/core";
import { QRCodeSVG } from "qrdx/solid";

const options = { value: "https://example.com", size: 256, margin: 4 };

export function DownloadableCode() {
  return (
    <>
      <QRCodeSVG {...options} />
      <button
        type="button"
        onClick={() =>
          downloadQRCode(options, {
            format: "png",
            size: { width: 1024, height: 1024 },
            filename: "qr-code.png",
          })
        }
      >
        Download PNG
      </button>
    </>
  );
}
```

Mengeklik tombol akan menyimpan `qr-code.png` pada 1024 px. [Vanilla JavaScript](/docs/vanilla-js) membahas `qrdx/core` secara lengkap.

## Cara menggambar [#how-it-draws]

Paket ini tidak berisi JSX Solid, sehingga tidak memerlukan kompiler Solid dan berfungsi dengan konfigurasi build apa pun.

- Di browser, komponen mengembalikan elemen `<svg>` itu sendiri, dibangun dengan `createElementNS` (tanpa mengurai HTML). Solid menempatkannya di halaman, menggantinya dengan yang baru saat perubahan prop mengubah markup, dan menghapusnya saat komponen di-unmount.
- Perubahan prop yang menghasilkan markup yang sama tidak mengubah halaman.

## Render di server dan hidrasi [#server-rendering-and-hydration]

Dengan `renderToString` dari `solid-js/web`, komponen menulis markup yang sama seperti `toSVGString` dari `qrdx/core`, ditambah kunci hidrasi `data-hk` milik Solid pada elemen akar. `hydrate` memakai kunci itu untuk mempertahankan `<svg>` dari server alih-alih menggambarnya lagi. Di dalam `<NoHydration>`, kunci tersebut dihilangkan.

Markup tidak memiliki id acak, sehingga server dan browser selalu sama.

## Jika terjadi masalah [#if-something-goes-wrong]

- **`Failed to resolve import "react"`.** Anda mengimpor dari `qrdx`, bukan `qrdx/solid`. Entri utama berisi komponen React; ubah impornya.
- **Click handler pada komponen tidak berfungsi.** Handler dibuang dari `<svg>`. Bungkus kode dalam sebuah elemen dan letakkan handler di sana.
- **`PDF export needs the optional "jspdf" package`.** Jalankan `npm install jspdf` di aplikasi Anda.
