Di akhir halaman ini, Anda akan memiliki kode QR bergaya yang digambar di halaman HTML biasa, diperbarui dari kode Anda, dan disimpan sebagai PNG, dengan bundler atau dengan satu tag script. `qrdx/vanilla` adalah mesin yang sama dengan yang digunakan komponen React untuk menggambar, sehingga hasilnya SVG yang sama, lengkap dengan semua pola, warna, logo, bingkai, dan ekspor, serta tidak mengimpor `react` maupun `react-dom`.

<NpmStatus package="qrdx" />

## Sebelum Anda mulai [#before-you-start]

- Halaman dengan bundler (Vite, webpack, Parcel, atau lainnya) untuk langkah 1 sampai 3. Tanpa bundler, lompat ke [langkah 4](#4-use-it-without-a-bundler).
- Node.js 18 atau lebih baru untuk bundler.

## Cara membuatnya [#build-it]

### 1. Instal qrdx [#1-install-qrdx]

```package-install
qrdx
```

`react` dan `react-dom` adalah peer dependency opsional. Anda tidak membutuhkannya untuk `qrdx/vanilla` atau `qrdx/core`.

### 2. Gambar kode ke dalam elemen [#2-draw-a-code-into-an-element]

```html title="index.html"
<div id="qr"></div>
<script type="module" src="/main.js"></script>
```

```js title="main.js"
import { createQRCode } from "qrdx/vanilla";

const qr = createQRCode("#qr", {
  value: "https://example.com/menu",
  size: 256,
  margin: 4,
  bodyPattern: "rounded",
  frame: { style: "banner-bottom", text: "Scan for the menu" },
  "aria-label": "QR code for the menu",
});
```

Sebuah `<svg>` muncul di dalam `#qr`: kode berukuran 256 px dengan modul membulat dan banner di bawahnya. `createQRCode(element, options)` menerima elemen atau selector CSS, serta setiap opsi yang diterima `QRCodeSVG` di React: pola, warna dan gradien, logo (`imageSettings`), bingkai, bentuk, templat, dan seni. Atribut seperti `className`, `style`, atau `aria-label` dipasang pada `<svg>`. Elemen dibuat dengan `createElementNS`, sehingga tidak ada HTML yang di-parse.

### 3. Perbarui, ekspor, dan hapus [#3-update-export-and-remove-it]

```js title="main.js"
qr.update({ fgColor: "#1d4ed8" }); // redraws the code in place, now blue

qr.toSVGString(); // '<svg xmlns="http://www.w3.org/2000/svg" …'
await qr.toDataURL("png", { size: 1024 }); // "data:image/png;base64,…"
await qr.download({ format: "png", size: 1024, filename: "menu.png" });

qr.destroy(); // removes the <svg>
```

- `update` menggabungkan opsi baru ke opsi yang ada lalu menggambar ulang. Berikan `undefined` untuk menghapus sebuah opsi. Jika markup tidak berubah, halaman tidak disentuh.
- `toDataURL` dan `download` secara default menghasilkan PNG dengan `size` asli kode. Format yang tersedia adalah `png`, `jpg`, `webp`, `svg`, `pdf`, dan `eps`. Bingkai membuat gambar lebih besar daripada kodenya. PDF membutuhkan paket opsional `jspdf`.
- `qr.svg` adalah elemen `<svg>` dan `qr.options` adalah opsi saat ini.
- `destroy` menghapus `<svg>`. `update` akan melempar error setelahnya.

### 4. Gunakan tanpa bundler [#4-use-it-without-a-bundler]

```html title="index.html"
<div id="qr"></div>
<script type="module">
  import { createQRCode } from "https://cdn.jsdelivr.net/npm/qrdx/dist/vanilla.browser.mjs";

  createQRCode("#qr", { value: "https://example.com", size: 256, margin: 4 });
</script>
```

`dist/vanilla.browser.mjs` adalah API yang sama dalam satu modul ES. Tambahkan `@` dan versi setelah `qrdx` pada URL untuk mengunci versi. Path yang sama berfungsi di unpkg.

File ini tidak menyertakan data pustaka bingkai resmi, sehingga halaman yang tidak memakainya tidak mengunduhnya. Untuk memakai bingkai resmi, impor dari file di sebelahnya:

```js title="index.html"
import { getOfficialFrame } from "https://cdn.jsdelivr.net/npm/qrdx/dist/frames-official.mjs";

const wifi = getOfficialFrame("wifi-card");
qr.update({ frame: { style: "custom", spec: wifi.spec } });
```

Ekspor PDF dan skor pemindaian memuat `jspdf` dan `jsqr` saat dijalankan. Halaman yang memakainya memetakan keduanya dengan import map, yang diletakkan sebelum script modul:

```html title="index.html"
<script type="importmap">
  {
    "imports": {
      "jspdf": "https://cdn.jsdelivr.net/npm/jspdf@4/+esm",
      "jsqr": "https://cdn.jsdelivr.net/npm/jsqr@1/+esm"
    }
  }
</script>
```

## Markup dan node DOM dengan qrdx/core [#markup-and-dom-nodes-with-qrdxcore]

`qrdx/core` memiliki semua yang ada di entri utama `qrdx` kecuali komponen React. Ia berfungsi di Node dan di browser.

```ts title="code.ts"
import {
  createQRCodeTree,
  renderToDOM,
  renderToString,
  resolveQRCodeProps,
  toSVGElement,
  toSVGString,
} from "qrdx/core";

// What <QRCodeSVG> renders, as a string (no DOM needed)
const svg = toSVGString({ value: "https://example.com", size: 256 });

// The same code as an <svg> element
document.body.append(toSVGElement({ value: "https://example.com" }));

// The code as plain { type, props, key } nodes, then markup or DOM nodes
const tree = createQRCodeTree({ value: "https://example.com" });
renderToString(tree);
renderToDOM(tree);

// <QRCode>'s logo API (logo, logoOptions, hideLogo, scale)
toSVGString(resolveQRCodeProps({ value: "https://example.com", logo: "/logo.png" }));
```

Keluarannya tidak memiliki id acak, sehingga markup yang dirender di server sama dengan yang ada di browser. Unduhan, skor pemindaian, serta PDF dan EPS siap cetak berasal dari fungsi yang sama seperti di pustaka React: `downloadQRCode`, `getQRCodeDataUrl`, `getScanScore`, `downloadPrintPDF`, dan lainnya. Untuk PNG di server, gunakan `getQRAsPNG` dari `qrdx/node`.

## Templat kustom tanpa JSX [#custom-templates-without-jsx]

`wrapper` milik templat menerima kode yang sudah digambar dan mengembalikannya dalam keadaan terbungkus. `h(type, props, ...children)` menuliskannya tanpa JSX:

```js title="labelled-template.js"
import { h, toSVGString } from "qrdx/core";

const Labelled = {
  id: "Labelled",
  name: "Labelled",
  wrapper: (children, props) =>
    h(
      "svg",
      { viewBox: "0 0 300 340", xmlns: "http://www.w3.org/2000/svg" },
      h("g", { transform: "translate(20, 20) scale(0.87)" }, children),
      h("text", { x: "150", y: "325", textAnchor: "middle" }, props?.label)
    ),
};

toSVGString({
  value: "https://example.com",
  customTemplate: Labelled,
  customProps: { label: "Scan me" },
});
```

Wrapper yang sama berfungsi di komponen React jika `h` diimpor dari `qrdx`.

## Jika terjadi masalah [#if-something-goes-wrong]

- **`qrdx: no element matches #qr`.** Script berjalan sebelum elemennya ada. Letakkan `<script type="module">` setelah elemen, atau tunggu `DOMContentLoaded`.
- **`qrdx: this QR code was destroyed`.** Anda memanggil `update` setelah `destroy`. Buat kode baru dengan `createQRCode`.
- **`PDF export needs the optional "jspdf" package`.** Instal `jspdf` bersama `qrdx`, atau tambahkan ke import map pada halaman tanpa bundler.
- **Kode tergambar tetapi ponsel tidak dapat membacanya.** Tambahkan `margin: 4`, pertahankan modul gelap di atas latar terang, dan periksa desain dengan `getScanScore`. Lihat [Kode tidak dapat dipindai](/docs/help/troubleshooting/wont-scan).
