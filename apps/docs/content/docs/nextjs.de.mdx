Am Ende dieser Seite hast du einen QR-Code, der von einer Server Component ohne Client-JavaScript gerendert wird, einen Code aus einem Route-Parameter, einen Live-Code, der an ein Eingabefeld gebunden ist, einen Code mit deinem Logo und einen Button, der ein SVG speichert. `QRCodeSVG` und `QRCode` verwenden keine reinen Client-Hooks, daher rendert eine Server Component den Code direkt ins HTML der Seite. Eine Client Component brauchst du nur, wenn sich der Wert im Browser ändert oder wenn du eine Datei speichern willst.

<NpmStatus package="qrdx" />

## Bevor du startest [#before-you-start]

- Ein Next.js-Projekt mit dem App Router. Die Beispiele verwenden die asynchronen `params` des App Routers, wie in Next.js 15 und 16.
- React 18 oder neuer, was der App Router ohnehin voraussetzt.

## So baust du es [#build-it]

### 1. qrdx installieren [#1-install-qrdx]

```package-install
qrdx
```

`react` und `react-dom` sind Peer-Dependencies, daher werden die Versionen deiner App verwendet.

### 2. Einen Code in einer Server Component rendern [#2-render-a-code-in-a-server-component]

```tsx title="app/page.tsx"
import { QRCodeSVG } from "qrdx";

export default function Page() {
  return (
    <QRCodeSVG
      value="https://example.com"
      size={256}
      margin={4}
      role="img"
      aria-label="QR code for example.com"
    />
  );
}
```

Öffne die Seite. Das `<svg>` ist Teil des HTML, das der Server sendet. Es erscheint also, bevor JavaScript geladen wird, eine statische Seite rendert es einmal beim Build, und Screenreader bekommen das `aria-label`.

<Shot id="lib-nextjs-server-code" />

`margin` ist die Ruhezone um den Code, gemessen in Modulen. Der Standardwert ist 0, was für einen Code in einer Karte mit eigenem Innenabstand passt. Der QR-Standard verlangt 4, die sichere Wahl auf unruhigem oder dunklem Hintergrund.

### 3. Den Wert aus einem Route-Parameter bilden [#3-build-the-value-from-a-route-param]

```tsx title="app/tickets/[id]/page.tsx"
import { QRCodeSVG } from "qrdx";

export default async function TicketPage({
  params,
}: {
  params: Promise<{ id: string }>;
}) {
  const { id } = await params;
  const url = `https://example.com/check-in/${encodeURIComponent(id)}`;
  return <QRCodeSVG value={url} size={200} margin={4} level="H" />;
}
```

Rufst du `/tickets/A-12` auf, öffnet der Code `https://example.com/check-in/A-12`. Next.js übergibt `params` als Promise, deshalb ist die Seite `async`. Kodiere alles, was von einem Nutzer oder aus einer Datenbank kommt, bevor es in eine URL gelangt. Level `H` erlaubt, dass bis zu 30 % des Codes beschädigt sind, was bei einem Badge hilft, das geknickt oder zerkratzt wird.

### 4. Einem Eingabefeld in einer Client Component folgen [#4-follow-an-input-in-a-client-component]

```tsx title="components/live-qr-code.tsx"
"use client";

import { QRCodeSVG } from "qrdx";
import { useState } from "react";

export function LiveQrCode() {
  const [value, setValue] = useState("https://example.com");
  return (
    <div>
      <input
        aria-label="Text or link to encode"
        value={value}
        onChange={(event) => setValue(event.target.value)}
      />
      {value ? <QRCodeSVG value={value} size={200} margin={4} /> : null}
    </div>
  );
}
```

Der Code wird bei jedem Tastendruck neu gezeichnet, und der erste Wert wird weiterhin auf dem Server gerendert. Eine Seite als Server Component kann diese Komponente unverändert importieren.

`QRCodeCanvas` ist ebenfalls eine Client Component (sie wird mit `"use client"` ausgeliefert), zeichnet aber nur einfache quadratische Module. Für gestaltete Codes nimm `QRCodeSVG` oder `QRCode`.

### 5. Ein Logo hinzufügen [#5-add-a-logo]

```tsx title="components/logo-qr-code.tsx"
import { QRCode } from "qrdx";

export function LogoQrCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      margin={4}
      level="H"
      logo="/logo.png"
    />
  );
}
```

`/logo.png` ist eine Datei im Ordner `public` deines Projekts. Das Logo wird in einem Viertel der Breite des Codes gezeichnet, und die Module dahinter werden freigeräumt. Der Code verlässt sich daher beim Scan auf die Fehlerkorrektur, deshalb ist `level` auf `H` gesetzt. `QRCode` verkleinert außerdem ein Logo, das zu groß ist, als dass der Code es ausgleichen könnte.

`logo` akzeptiert einen Pfad in deiner App, eine URL oder eine Data-URL. Für Downloads ist eine Data-URL am sichersten, weil ein Remote-Bild CORS-Header braucht, bevor der Browser es in die Datei kopieren darf. Mit `logoOptions` legst du Größe, Freiraum, Position und Zuschnitt des Logos fest; siehe [Logo im Code hinzufügen](/docs/features/logos).

### 6. Als SVG herunterladen [#6-download-as-svg]

```tsx title="components/download-svg-button.tsx"
"use client";

import { downloadQRCode } from "qrdx";

export function DownloadSvgButton({ value }: { value: string }) {
  return (
    <button
      type="button"
      onClick={() =>
        downloadQRCode(
          { value, level: "Q", margin: 4 },
          {
            format: "svg",
            size: { width: 1024, height: 1024 },
            filename: "qr-code.svg",
          },
        )
      }
    >
      Download SVG
    </button>
  );
}
```

Ein Klick auf den Button speichert `qr-code.svg`, eine Vektordatei mit 1024 px. `downloadQRCode` braucht das DOM des Browsers, daher ist der Button eine Client Component. Eine Seite als Server Component kann ihn trotzdem rendern und den Wert als Prop übergeben. Für andere Dateien setzt du `format` auf `png`, `jpg`, `webp`, `eps` oder `pdf` (PDF braucht das optionale Paket `jspdf`). [Export und Download](/docs/features/downloads) behandelt alle Optionen.

## Wenn du eine Bild-URL brauchst [#when-you-need-an-image-url]

E-Mails, Open-Graph-Bilder, Markdown-Dateien und andere Orte, an denen React nicht laufen kann, brauchen eine Bild-URL statt einer Komponente. Die [QR-Code-Image-API](/docs/developers/image-api) liefert eine ohne Schlüssel:

```html title="email.html"
<img src="https://api.qrdx.dev/v1/qr?data=https://example.com&format=png" width="256" height="256" alt="QR code for example.com" />
```

## Fertige Komponenten [#ready-made-components]

Die [shadcn/ui-Registry](/docs/developers/shadcn) installiert Komponenten in dein Projekt: einen [QR-Code mit Download-Buttons](/docs/components/qr-code), eine Karte, einen Teilen-Dialog, einen Generator, einen Scanner sowie Wi-Fi- und Kontakt-Codes.

```bash title="Terminal"
npx shadcn@latest add https://qrdx.dev/r/qr-code.json
```

## Wenn etwas schiefgeht [#if-something-goes-wrong]

- **`useRef only works in Client Components` (oder dasselbe für `useState`).** Du hast `QRCodeCanvas` oder eine Komponente mit Hooks aus einer Server Component gerendert. Füge `"use client"` oben in dieser Datei hinzu oder rendere stattdessen `QRCodeSVG`.
- **Das Logo erscheint auf der Seite, aber nicht in der heruntergeladenen Datei.** Das Bild kommt von einem anderen Origin ohne CORS-Header. Liefere es aus `public` aus oder übergib eine Data-URL.
- **`PDF export needs the optional "jspdf" package`.** Führe `npm install jspdf` in der App aus. Die anderen Formate brauchen nichts Zusätzliches.
