任何[动态二维码](/docs/dynamic-qr-codes)都可以放到 NFC 标签上。你把该二维码的 NFC 链接写入标签、贴纸或卡片，手机轻触后打开的位置与扫描二维码完全相同。轻触次数会和二维码扫描次数一起显示在该二维码的分析数据中，并分开统计。适合轻触比扫描更方便的场景：餐桌贴纸、名片、货架上的商品。所有套餐均可使用。

QRdx 不出售、印刷或寄送标签和卡片。请从任意 NFC 供应商处购买空白标签或卡片，然后在该二维码的页面中自行写入。

## 工作原理 [#how-it-works]

<Diagram id="nfc-link" />

二维码的 NFC 链接是在其短链接末尾加上 `?nfc`，例如 `https://qrdx.dev/q/aB3dE5f?nfc`，如果使用[自定义域名](/docs/custom-domains)，则类似 `https://go.example.com/menu?nfc`。它与短链接走同一个跳转流程，因此智能路由、密码、日程和扫描次数限制同样适用于轻触。末尾的 `?nfc` 只是告诉分析系统这次访问是一次轻触。二维码本身的链接保持不变，你已经印刷的二维码仍然照常使用。

要查找该链接，请在[二维码](/dashboard?to=codes)中打开该二维码，然后在其**概览**标签页中选择**用于 NFC**。

## 在 Android 上写入标签 [#write-a-tag-on-android]

Android 版 Chrome 可以直接在二维码的 NFC 页面中写入标签：

1. 在手机设置中打开 NFC。
2. 在 Chrome 中打开该二维码，选择**用于 NFC**，然后点击**写入 NFC 标签**。
3. 将标签平放在手机背面，直到页面显示**已写入**。
4. 用标签轻触手机进行测试，它会打开该链接。

通过网页写入需要 Web NFC，只有 Android 版 Chrome 支持。在电脑上，NFC 页面会显示一个二维码：用 Android 手机扫描它，登录后在手机上写入标签。

### 锁定标签 [#locking-a-tag]

标签写入完成后，如果浏览器支持，页面会提供锁定选项。已锁定的标签任何人都无法再修改或擦除，包括你自己，因此只锁定放在陌生人可能改写的位置的标签，例如咖啡馆桌子上的贴纸。标签中保存的是二维码的链接而不是目标地址，所以即使标签已锁定，你仍然可以在 QRdx 中更改它指向的目的地。

## 在 iPhone 上写入标签 [#write-a-tag-on-iphone]

Safari 无法写入 NFC 标签，请使用 App Store 中任意一款 NFC 写入应用：

1. 从二维码的 NFC 页面复制 NFC 链接。
2. 在应用中添加一条 URL 记录（有些应用称之为 Link 或 URI），并粘贴该链接。
3. 选择写入，将 iPhone 顶部贴近标签，直到应用提示完成。

写入需要 iPhone 7 或更新机型，且系统为 iOS 13 或更高版本。

## 该买哪种标签 [#which-tags-to-buy]

请选择 NTAG213、NTAG215 或 NTAG216 芯片。它们有贴纸、卡片、钥匙扣和腕带等形式。

| 芯片 | 存储容量 |
| --- | --- |
| NTAG213 | 144 字节 |
| NTAG215 | 504 字节 |
| NTAG216 | 888 字节 |

qrdx.dev 上的 NFC 链接约占 30 字节，所以三种芯片都能容纳。使用较长的自定义域名或后半部分较长的链接会占用更多空间；NFC 页面会显示你的链接需要多少字节，以及适用哪些芯片。

已打开 NFC 的 Android 手机，以及 iPhone XS 或更新机型，只要标签一接触手机就会打开其中的链接，无需安装应用。

## NFC 名片 [#nfc-business-cards]

[vCard Plus 页面](/docs/landing-pages#vcard-plus-and-save-contact)是带有**保存联系人**按钮的联系人页面，很适合用作 NFC 名片。对于打开这类页面的二维码，**概览**标签页会显示**将此名片放到 NFC**，页面编辑器中则有**放到 NFC**按钮。两者都会打开同一个 NFC 页面，并附有针对卡片的指南。

1. 购买空白 NFC 名片，或为已有的名片购买 NFC 贴纸。
2. 同时把该二维码印在名片上。没有 NFC 或未开启 NFC 的手机可以改为扫描它。
3. 在该二维码的 NFC 页面中，把 NFC 链接写入每张名片。

由于每张名片保存的都是该二维码的链接，在 QRdx 中编辑 vCard Plus 页面，就会更新你已经发出的所有名片。

## 分析数据中的轻触 [#taps-in-analytics]

二维码的**分析**标签页会按你选定的日期显示**二维码扫描与 NFC 轻触**，上方的总数同时包含两者。工作区的分析页面和共享的分析页面也显示同样的区分。NFC 链接出现之前的扫描计为二维码扫描。轻触与扫描遵循相同的规则：机器人和链接预览不计入。

## 限制与套餐 [#limits-and-plans]

NFC 链接在所有套餐中、对所有动态二维码都可使用。该二维码本身与其他二维码一样，计入你套餐的活跃二维码数量。

## 面向开发者 [#for-developers]

REST API 会在每个二维码上以 `nfcLink` 返回该链接。[扫描分析](/docs/developers/api/get-code-scans)包含带有两种计数的 `sources`，每条列出的扫描记录上也有 `source`（`qr` 或 `nfc`），CSV 导出中有 `source` 列，`scan.created` 的 [Webhook](/docs/webhooks) 也带有 `source`。
