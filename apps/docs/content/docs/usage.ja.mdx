まず使うべきコンポーネントは `QRCode` です。すべてのスタイルオプションと、シンプルな `logo` prop に対応しており、サーバー上でレンダリングされます。このページでは、よく設定する props を順に説明します。すべての prop については、[ライブラリ API リファレンス](/docs/api-reference)をご覧ください。

## コンポーネントを選ぶ [#choose-a-component]

| コンポーネント | 描画するもの | 使う場面 |
| --- | --- | --- |
| `QRCode` | すべてのスタイルオプションに対応した `<svg>`。`logo`、`logoOptions`、`hideLogo`、`scale` も使えます。それ以外の属性は受け取りません | ほとんどの場合 |
| `QRCodeSVG` | 同じ `<svg>`。ロゴはピクセル単位の生の `imageSettings` で指定します。それ以外の prop(`aria-label`、`className`、`role`)は `<svg>` に渡されます | `<svg>` に属性を付けたい場合、ロゴのレイアウトを自分で行う場合、または他のレンダラーのコードを移植する場合 |
| `QRCodeCanvas` | 単純な正方形のモジュールと単色で描画する `<canvas>` | canvas 要素が必要な場合。パターン、アイの色、グラデーション、テンプレートは無視されます |

`QRCode` と `QRCodeSVG` はブラウザ専用のフックを使わないため、React Server Components や静的 HTML でもレンダリングできます。`QRCodeCanvas` は `"use client"` 付きで提供されます。

```tsx title="components/menu-code.tsx"
import { QRCode } from "qrdx";

export function MenuCode() {
  return (
    <div role="img" aria-label="QR code for the menu">
      <QRCode value="https://example.com/menu" size={256} margin={4} />
    </div>
  );
}
```

`value` は渡した内容のままエンコードされるため、Wi-Fi のペイロード、vCard、`mailto:`、プレーンテキストのいずれも使えます。`QRCode` が受け取るのはコード自体の props と `style` だけです。上の例のように、ラップして accessible name を付けてください。`QRCodeSVG` は、`aria-label`、`className`、`role` などの属性を `<svg>` 自体に付けます。

## サイズとクワイエットゾーン [#size-and-quiet-zone]

- `size` は幅と高さをピクセルで指定します(デフォルトは 128)。128 px 未満になると、密度の高いコードは画面からのスキャンが難しくなります。
- `margin` はコードの周囲のクワイエットゾーンで、モジュール単位です(デフォルトは 0)。QR の規格では 4 が求められています。写真、模様、暗いページの上にコードを置く場合に設定してください。余白付きの白いカードの中に置く場合は 0 のままで構いません。
- `scale` は `QRCode` で `size` を何倍かにします。

フレームやテンプレートを使うと、出力サイズが変わります。[フレームまたはテンプレート](#frame-or-template)をご覧ください。

## 色 [#colors]

```tsx title="components/brand-code.tsx"
import { QRCode } from "qrdx";

export function BrandCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      fgColor="#1d4ed8"
      bgColor="#f8fafc"
      eyeColor="#0f172a"
      dotColor="#1d4ed8"
    />
  );
}
```

- `fgColor` はデータモジュール、`bgColor` は背景、`eyeColor` は3つの角のアイ、`dotColor` は各アイの内側のドットの色を指定します。アイの色のデフォルトは `fgColor` です。
- いずれも CSS の任意の色(`#1d4ed8`、`rgb(29 78 216)`、名前付きの色)またはグラデーションオブジェクトを指定できます。グラデーション、透過色、画像の塗りについては[色とグラデーションを設定する](/docs/features/colors-gradients)で説明しています。
- モジュールは背景より暗くしてください。スキャナーは明るい背景に暗いコードを読み取ります。暗い背景に明るいコードは、多くのスマートフォンのカメラでは読み取れますが、一部の古いアプリでは読み取れません。

## 形状 [#shapes]

```tsx title="components/rounded-code.tsx"
import { QRCode } from "qrdx";

export function RoundedCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      bodyPattern="rounded"
      cornerEyePattern="extra-rounded"
      cornerEyeDotPattern="rounded"
    />
  );
}
```

- `bodyPattern` はデータモジュールの形を指定します(デフォルトは `circle`)。選べる形は {facts.bodyPatterns} あります。
- `cornerEyePattern` は3つの角のアイの形を指定します(デフォルトは `gear`)。{facts.eyeShapes} のいずれかを選びます。
- `cornerEyeDotPattern` は各アイの内側のドットの形を指定します(デフォルトは `circle`)。{facts.eyeCentres} のいずれかを選びます。

[形状、アイ、フレーム](/docs/styles)では、すべての値をライブで確認できます。[モジュールとアイの形を選ぶ](/docs/features/patterns)では、モジュールのスケール、形状付きコード、組み合わせるとスキャンしにくくなるいくつかのペアについて説明しています。

## ロゴ [#logo]

```tsx title="components/logo-code.tsx"
import { QRCode } from "qrdx";

export function LogoCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      level="H"
      logo="/logo.png"
      logoOptions={{ size: 0.2, padding: 1 }}
    />
  );
}
```

`logo` には、アプリ内のパス、URL、データ URL を指定できます。ロゴの背後にあるモジュールは消去されるため、コードのスキャンは誤り訂正に頼ることになります。`level="H"` を使ってください。`logoOptions` では、コードに対するロゴの幅の割合(0.1 から 0.3、デフォルトは 0.25)、モジュール単位の余白、位置、トリミングを設定します。コンポーネントは、コードが修復できる範囲を超える大きさのロゴは描画しません。詳しくは[コードでロゴを追加する](/docs/features/logos)をご覧ください。

## フレームまたはテンプレート [#frame-or-template]

```tsx title="components/framed-code.tsx"
import { QRCode } from "qrdx";

export function FramedCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      frame={{ style: "banner-bottom", text: "Scan me", color: "#0f172a" }}
    />
  );
}
```

- `frame` はコードの周囲に行動喚起のフレームを描画します。コードの幅は `size` のままで、出力はフレームに合わせて大きくなります。組み込みスタイルが {facts.frameStyles} 種類あるほか、公式のフレームライブラリと独自のフレーム仕様も使えます。[フレーム、スキャンスコア、印刷用ファイル](/docs/features/frames)をご覧ください。
- `templateId` を指定すると、代わりに `Arrow` や `StandardBox` などのテンプレートを描画します。テンプレートは全体のアートワークを `size` で描画し、コードはその内側に小さく配置されます。[フレームテンプレートを使う](/docs/features/templates)をご覧ください。

両方を設定した場合は、テンプレートのアートワークの周囲にフレームが描画されます。

## 誤り訂正 [#error-correction]

| `level` | 破損に耐えられる割合 | 用途 |
| --- | --- | --- |
| `L` | 約 7% | きれいな画面、短いリンク、最小のコード |
| `M` | 約 15% | vCard などの長いペイロードで、コードを小さくすることを優先する場合 |
| `Q` | 約 25% | デフォルト。一般的な用途 |
| `H` | 約 30% | ロゴ、アート、傷がついたり折れたりする印刷物 |

レベルを上げるとモジュールが増えるため、同じサイズではコードの密度が高くなります。`autoLevel` は、ロゴがコードの 7% を超えて覆う場合に、レベルを自動的に `H` に引き上げます。既存のコードの見た目が変わらないよう、デフォルトではオフです。
