Al termine di questa pagina avrai un QR code con stili personalizzati, disegnato dall'elemento `<qrdx-code>` in una semplice pagina HTML, con le opzioni a oggetto impostate da uno script e un'esportazione in PNG. `qrdx/element` è costruito su `qrdx/core`, quindi disegna lo stesso SVG del `QRCodeSVG` di React, con ogni stile, cornice, logo ed esportazione. Non richiede alcun framework e funziona nei framework che renderizzano elementi DOM. È testato con React 19 e Vue 3.

<NpmStatus package="qrdx" />

## Prima di iniziare [#before-you-start]

- Una pagina a cui puoi aggiungere un `<script type="module">`. Non serve un bundler, ma puoi usarne uno.
- Per la strada con il bundler, Node.js 18 o successivo.

## Costruiscilo [#build-it]

### 1. Carica l'elemento [#1-load-the-element]

<Tabs items={["From a CDN", "With a bundler"]}>
<Tab value="From a CDN">

```html title="index.html"
<script
  type="module"
  src="https://cdn.jsdelivr.net/npm/qrdx/dist/element-define.browser.mjs"
></script>
```

`dist/element-define.browser.mjs` registra `<qrdx-code>`. Carica `dist/element.browser.mjs`, un unico modulo ES con il motore al suo interno. Per fissare una versione, aggiungi `@` e il numero di versione dopo `qrdx` nell'URL. Gli stessi percorsi funzionano su unpkg.

</Tab>
<Tab value="With a bundler">

```package-install
qrdx
```

```js title="main.js"
import "qrdx/element/define"; // registers <qrdx-code>
```

Importare `qrdx/element` da solo non registra nulla. Chiama `defineQRdxCode` tu stesso per scegliere il nome del tag:

```js title="main.js"
import { defineQRdxCode } from "qrdx/element";

defineQRdxCode(); // <qrdx-code>
defineQRdxCode("brand-qr"); // <brand-qr> as well
```

Puoi richiamarla senza rischi e, su un server, non fa nulla. Genera un errore se un altro elemento usa già quel nome.

</Tab>

### 2. Inserisci un codice nella pagina [#2-put-a-code-in-the-page]

```html title="index.html"
<qrdx-code
  value="https://example.com/menu"
  size="256"
  margin="4"
  body-pattern="rounded"
  label="QR code for the menu"
></qrdx-code>
```

La pagina mostra un codice di 256 px con moduli arrotondati. Modifica un attributo nell'inspector del browser e il codice viene ridisegnato.

<Shot id="lib-element-code" />

### 3. Imposta le opzioni a oggetto da uno script [#3-set-object-options-from-a-script]

Gradienti, cornici, loghi e le altre opzioni a oggetto sono proprietà. Impostale da uno script:

```js title="main.js"
const qr = document.querySelector("qrdx-code");

qr.fgColor = {
  type: "linear",
  angle: 45,
  stops: [
    { color: "#1d4ed8", offset: 0 },
    { color: "#0f172a", offset: 100 },
  ],
};
qr.frame = { style: "banner-bottom", text: "Scan for the menu" };
qr.imageSettings = { src: "/logo.png", width: 40, height: 40, excavate: true };
qr.props = { eyeColor: "#be123c" };
```

Il codice viene ridisegnato una sola volta, con il gradiente, il banner, il logo e gli occhi rossi. Senza uno script, metti le opzioni a oggetto nell'attributo `props` come JSON:

```html title="index.html"
<qrdx-code
  value="https://example.com"
  props='{"frame": {"style": "banner-bottom", "text": "Scan me"}}'
></qrdx-code>
```

### 4. Esportalo [#4-export-it]

```js title="main.js"
qr.toSVGString(); // '<svg xmlns="http://www.w3.org/2000/svg" …'
await qr.toDataURL("png", { size: 1024 }); // "data:image/png;base64,…"
await qr.download({ format: "png", size: 1024, filename: "menu.png" });
```

`download` salva `menu.png` a 1024 px. Le esportazioni disegnano il codice a partire da `qr.options`, come fanno `toSVGString` e `downloadQRCode` di `qrdx/core`, senza `part`, `role` e `aria-label` dell'elemento. `toDataURL` e `download` usano per impostazione predefinita il PNG alla `size` del codice. I formati sono `png`, `jpg`, `webp`, `svg`, `pdf` e `eps`. Senza un valore generano un errore (`toSVGString`) o vengono rifiutate.

Il PDF richiede il pacchetto opzionale `jspdf`. Da una CDN, mappalo con un import map posto prima dello script del modulo:

```html title="index.html"
<script type="importmap">
  { "imports": { "jspdf": "https://cdn.jsdelivr.net/npm/jspdf@4/+esm" } }
</script>
```

## Attributi [#attributes]

| Attributo | Cosa imposta |
| --- | --- |
| `value` | Il testo o l'URL da codificare. Senza di esso non viene disegnato nulla |
| `size` | Larghezza e altezza in pixel (una cornice si aggiunge a questo valore) |
| `level` | Correzione degli errori: `L`, `M`, `Q` o `H` |
| `fg-color`, `bg-color`, `eye-color`, `dot-color` | Colori a tinta unita |
| `body-pattern`, `corner-eye-pattern`, `corner-eye-dot-pattern` | Forme dei moduli, degli occhi e dei punti degli occhi |
| `margin` | Zona di silenzio, in moduli |
| `template-id` | Un template integrato |
| `module-scale` | Dimensione di ogni modulo, da 0.5 a 1 |
| `auto-level` | Porta la correzione degli errori a `H` quando un logo lo richiede |
| `shape` | `square`, `circle` o `heart` |
| `label` | Ciò che gli screen reader annunciano (predefinito "QR code") |
| `props` | Qualsiasi altra opzione, come JSON |

I numeri e i livelli non leggibili vengono ignorati. [Forme, occhi e cornici](/docs/styles) mostra ogni pattern.

## Proprietà [#properties]

Ogni attributo è anche una proprietà, con il nome dell'opzione: `qr.fgColor`, `qr.bodyPattern`, `qr.templateId`. Le opzioni che sono oggetti esistono solo come proprietà: gradienti e riempimenti con immagine, `frame`, `imageSettings`, `eyeColors`, `art`, `customTemplate` e `customProps`. `props` accetta tutte le opzioni in una volta.

- Un attributo o una proprietà con nome ha la precedenza sulla stessa opzione in `props`. Tra un attributo e la sua proprietà vince quello impostato per ultimo. Imposta una proprietà su `undefined` per eliminarla.
- Le proprietà non riscrivono gli attributi.
- Le modifiche vengono raggruppate. Per quante ne faccia di seguito, il codice viene ridisegnato una sola volta, in una microtask, e solo se il suo markup è cambiato.
- `qr.options` è ciò con cui il codice viene disegnato e `qr.svg` è l'`<svg>` disegnato.
- Le proprietà impostate prima che l'elemento sia definito vengono recuperate quando lo è.

Una cornice ufficiale proviene dal file accanto all'elemento:

```js title="main.js"
import { getOfficialFrame } from "https://cdn.jsdelivr.net/npm/qrdx/dist/frames-official.mjs";

qr.frame = { style: "custom", spec: getOfficialFrame("wifi-card").spec };
```

## Stili e accessibilità [#styling-and-accessibility]

Il codice viene disegnato in uno shadow root aperto. Il CSS della pagina non può raggiungere i suoi path, quindi una regola come `svg path { fill: red }` o `svg { width: 100% }` non può rovinare il codice. Applica gli stili all'`<svg>` dall'esterno con `::part(svg)`:

```css title="styles.css"
qrdx-code::part(svg) {
  border-radius: 12px;
}
```

L'elemento è `inline-block`. Il suo `<svg>` mantiene la sua `size`, ma si riduce per adattarsi a un contenitore più stretto.

L'`<svg>` ha `role="img"` e un `aria-label` preso dall'attributo `label`, oppure "QR code" in assenza di esso. L'etichetta non ripiega mai sul valore, che può contenere una password Wi-Fi o dati di contatto.

## Rendering lato server [#server-rendering]

`toQRdxCodeHTML(options)` restituisce il markup dell'elemento con il codice già disegnato in uno shadow root dichiarativo. I browser mostrano il codice prima che venga eseguito qualsiasi script, e l'elemento ne prende il controllo quando viene definito. Funziona in Node e non richiede il DOM.

```js title="server.js"
import { toQRdxCodeHTML } from "qrdx/element";

const html = toQRdxCodeHTML(
  {
    value: "https://example.com",
    size: 256,
    frame: { style: "banner-bottom", text: "Scan me" },
  },
  { label: "Link to example.com" }
);
// <qrdx-code value="https://example.com" size="256" label="Link to example.com"
//   props="{…}"><template shadowrootmode="open">…</template></qrdx-code>
```

Le opzioni semplici diventano attributi e le altre vanno in `props` come JSON, così l'elemento rilegge le stesse opzioni. `customTemplate` non può essere scritto come markup: impostalo come proprietà nel browser. Passa `tagName` se hai registrato un altro nome.

## React 19 [#react-19]

React 19 imposta una prop come proprietà quando l'elemento ne ha una, quindi gli oggetti funzionano come prop. Registra l'elemento una sola volta, prima del rendering:

```tsx title="components/menu-code.tsx"
import "qrdx/element/define";

export function MenuCode({ url }: { url: string }) {
  return (
    <qrdx-code
      value={url}
      size={256}
      body-pattern="rounded"
      frame={{ style: "banner-bottom", text: "Scan me" }}
      label="Menu"
    />
  );
}
```

Per TypeScript, aggiungi l'elemento a JSX in un file `.d.ts`:

```ts title="qrdx-code.d.ts"
import type { QRdxCodeElement, QRdxCodeJSXProps } from "qrdx/element";

declare module "react" {
  namespace JSX {
    interface IntrinsicElements {
      "qrdx-code": React.DetailedHTMLProps<
        React.HTMLAttributes<QRdxCodeElement>,
        QRdxCodeElement
      > &
        QRdxCodeJSXProps;
    }
  }
}
```

Un `ref` ti dà l'elemento, per `toDataURL` e `download`.

## Vue [#vue]

Indica al compilatore di Vue che `qrdx-code` è un elemento custom:

```js title="vite.config.js"
import vue from "@vitejs/plugin-vue";
import { defineConfig } from "vite";

export default defineConfig({
  plugins: [
    vue({
      template: {
        compilerOptions: { isCustomElement: (tag) => tag === "qrdx-code" },
      },
    }),
  ],
});
```

Poi importa `qrdx/element/define` una sola volta, in `main.js`, e collega le opzioni nei template. Vue imposta un binding come proprietà quando l'elemento ne ha una:

```vue title="src/App.vue"
<qrdx-code
  :value="url"
  :size="256"
  body-pattern="rounded"
  :frame="{ style: 'banner-bottom', text: 'Scan me' }"
  label="Menu"
/>
```

## Se qualcosa va storto [#if-something-goes-wrong]

- **Non viene disegnato nulla.** L'elemento non ha `value`, oppure lo script di definizione non è stato eseguito. Controlla l'attributo e verifica che `element-define` sia caricato come modulo.
- **Viene emesso un evento `qrdx-error`.** Il codice non può essere disegnato, per esempio perché il valore è troppo lungo per un QR code, oppure l'attributo `props` non è un oggetto JSON. L'errore si trova in `event.detail.error`. L'elemento rimuove il vecchio codice e registra l'errore nel log, a meno che un listener non chiami `event.preventDefault()`:

  ```js title="main.js"
  qr.addEventListener("qrdx-error", (event) => {
    event.preventDefault();
    showMessage("That text is too long for a QR code.");
  });
  ```

- **`qrdx: <qrdx-code> is already defined by another element`.** Un altro script ha registrato lo stesso nome di tag. Passa a `defineQRdxCode` un altro nome.
- **TypeScript: `Property 'qrdx-code' does not exist on type 'JSX.IntrinsicElements'`.** Aggiungi la dichiarazione dalla sezione React 19.
