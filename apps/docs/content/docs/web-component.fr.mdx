À la fin de cette page, vous aurez un QR code stylisé dessiné par l'élément `<qrdx-code>` dans une page HTML simple, avec des options de type objet définies depuis un script et un export en PNG. `qrdx/element` repose sur `qrdx/core` : il dessine donc le même SVG que le `QRCodeSVG` de React, avec tous les styles, cadres, logos et exports. Il n'a besoin d'aucun framework et fonctionne dans les frameworks qui produisent des éléments DOM. Il est testé avec React 19 et Vue 3.

<NpmStatus package="qrdx" />

## Avant de commencer [#before-you-start]

- Une page à laquelle vous pouvez ajouter un `<script type="module">`. Aucun bundler n'est nécessaire, mais vous pouvez en utiliser un.
- Pour la voie avec bundler, Node.js 18 ou une version plus récente.

## Mise en place [#build-it]

### 1. Charger l'élément [#1-load-the-element]

<Tabs items={["From a CDN", "With a bundler"]}>
<Tab value="From a CDN">

```html title="index.html"
<script
  type="module"
  src="https://cdn.jsdelivr.net/npm/qrdx/dist/element-define.browser.mjs"
></script>
```

`dist/element-define.browser.mjs` enregistre `<qrdx-code>`. Il charge `dist/element.browser.mjs`, un module ES unique qui contient le moteur. Ajoutez `@` et un numéro de version après `qrdx` dans l'URL pour épingler une version. Les mêmes chemins fonctionnent sur unpkg.

</Tab>
<Tab value="With a bundler">

```package-install
qrdx
```

```js title="main.js"
import "qrdx/element/define"; // registers <qrdx-code>
```

Importer `qrdx/element` seul n'enregistre rien. Appelez vous-même `defineQRdxCode` pour choisir le nom de la balise :

```js title="main.js"
import { defineQRdxCode } from "qrdx/element";

defineQRdxCode(); // <qrdx-code>
defineQRdxCode("brand-qr"); // <brand-qr> as well
```

Vous pouvez l'appeler plusieurs fois sans risque, et sur un serveur il ne fait rien. Il lève une erreur si un autre élément porte déjà ce nom.

</Tab>

### 2. Placer un code dans la page [#2-put-a-code-in-the-page]

```html title="index.html"
<qrdx-code
  value="https://example.com/menu"
  size="256"
  margin="4"
  body-pattern="rounded"
  label="QR code for the menu"
></qrdx-code>
```

La page affiche un code de 256 px avec des modules arrondis. Modifiez un attribut dans l'inspecteur du navigateur et le code est redessiné.

<Shot id="lib-element-code" />

### 3. Définir des options objet depuis un script [#3-set-object-options-from-a-script]

Les dégradés, cadres, logos et les autres options de type objet sont des propriétés. Définissez-les depuis un script :

```js title="main.js"
const qr = document.querySelector("qrdx-code");

qr.fgColor = {
  type: "linear",
  angle: 45,
  stops: [
    { color: "#1d4ed8", offset: 0 },
    { color: "#0f172a", offset: 100 },
  ],
};
qr.frame = { style: "banner-bottom", text: "Scan for the menu" };
qr.imageSettings = { src: "/logo.png", width: 40, height: 40, excavate: true };
qr.props = { eyeColor: "#be123c" };
```

Le code est redessiné une seule fois, avec le dégradé, la bannière, le logo et les yeux rouges. Sans script, placez les options objet dans l'attribut `props` au format JSON :

```html title="index.html"
<qrdx-code
  value="https://example.com"
  props='{"frame": {"style": "banner-bottom", "text": "Scan me"}}'
></qrdx-code>
```

### 4. L'exporter [#4-export-it]

```js title="main.js"
qr.toSVGString(); // '<svg xmlns="http://www.w3.org/2000/svg" …'
await qr.toDataURL("png", { size: 1024 }); // "data:image/png;base64,…"
await qr.download({ format: "png", size: 1024, filename: "menu.png" });
```

`download` enregistre `menu.png` en 1024 px. Les exports dessinent le code à partir de `qr.options`, comme le font `toSVGString` et `downloadQRCode` de `qrdx/core`, sans le `part`, le `role` et l'`aria-label` de l'élément. `toDataURL` et `download` produisent par défaut un PNG à la `size` du code. Les formats sont `png`, `jpg`, `webp`, `svg`, `pdf` et `eps`. Sans valeur, ils lèvent une erreur (`toSVGString`) ou sont rejetés.

Le PDF nécessite le paquet optionnel `jspdf`. Depuis un CDN, associez-le avec une import map placée avant le script de module :

```html title="index.html"
<script type="importmap">
  { "imports": { "jspdf": "https://cdn.jsdelivr.net/npm/jspdf@4/+esm" } }
</script>
```

## Attributs [#attributes]

| Attribut | Ce qu'il définit |
| --- | --- |
| `value` | Le texte ou l'URL à encoder. Rien n'est dessiné sans lui |
| `size` | Largeur et hauteur en pixels (un cadre s'y ajoute) |
| `level` | Correction d'erreur : `L`, `M`, `Q` ou `H` |
| `fg-color`, `bg-color`, `eye-color`, `dot-color` | Couleurs unies |
| `body-pattern`, `corner-eye-pattern`, `corner-eye-dot-pattern` | Formes des modules, des yeux et des points des yeux |
| `margin` | Zone de silence, en modules |
| `template-id` | Un modèle intégré |
| `module-scale` | Taille de chaque module, de 0.5 à 1 |
| `auto-level` | Passe la correction d'erreur à `H` lorsqu'un logo l'exige |
| `shape` | `square`, `circle` ou `heart` |
| `label` | Ce que les lecteurs d'écran annoncent (par défaut « QR code ») |
| `props` | Toute autre option, au format JSON |

Les nombres et niveaux illisibles sont ignorés. [Formes, yeux et cadres](/docs/styles) présente tous les motifs.

## Propriétés [#properties]

Chaque attribut est aussi une propriété, portant le nom de l'option : `qr.fgColor`, `qr.bodyPattern`, `qr.templateId`. Les options de type objet sont uniquement des propriétés : dégradés et remplissages d'image, `frame`, `imageSettings`, `eyeColors`, `art`, `customTemplate` et `customProps`. `props` accepte toutes les options à la fois.

- Un attribut ou une propriété nommée l'emporte sur la même option dans `props`. Entre un attribut et sa propriété, la dernière valeur définie l'emporte. Définissez une propriété à `undefined` pour la supprimer.
- Les propriétés n'écrivent pas d'attributs en retour.
- Les modifications sont regroupées. Quel que soit leur nombre à la suite, le code est redessiné une seule fois, dans une microtâche, et seulement si son balisage a changé.
- `qr.options` est ce avec quoi le code est dessiné, et `qr.svg` est le `<svg>` dessiné.
- Les propriétés définies avant que l'élément ne soit enregistré sont prises en compte dès qu'il l'est.

Un cadre officiel provient du fichier situé à côté de l'élément :

```js title="main.js"
import { getOfficialFrame } from "https://cdn.jsdelivr.net/npm/qrdx/dist/frames-official.mjs";

qr.frame = { style: "custom", spec: getOfficialFrame("wifi-card").spec };
```

## Style et accessibilité [#styling-and-accessibility]

Le code est dessiné dans un shadow root ouvert. Le CSS de la page ne peut pas atteindre ses tracés : une règle comme `svg path { fill: red }` ou `svg { width: 100% }` ne peut donc pas casser le code. Stylez le `<svg>` depuis l'extérieur avec `::part(svg)` :

```css title="styles.css"
qrdx-code::part(svg) {
  border-radius: 12px;
}
```

L'élément est en `inline-block`. Son `<svg>` conserve sa `size`, mais se réduit pour tenir dans un conteneur plus étroit.

Le `<svg>` possède `role="img"` et un `aria-label` issu de l'attribut `label`, ou « QR code » sans lui. Le libellé ne se rabat jamais sur la valeur, qui peut contenir un mot de passe Wi-Fi ou des coordonnées.

## Rendu serveur [#server-rendering]

`toQRdxCodeHTML(options)` renvoie le balisage de l'élément avec le code déjà dessiné dans un shadow root déclaratif. Les navigateurs affichent le code avant l'exécution de tout script, et l'élément prend le relais dès qu'il est enregistré. Il s'exécute dans Node et n'a besoin d'aucun DOM.

```js title="server.js"
import { toQRdxCodeHTML } from "qrdx/element";

const html = toQRdxCodeHTML(
  {
    value: "https://example.com",
    size: 256,
    frame: { style: "banner-bottom", text: "Scan me" },
  },
  { label: "Link to example.com" }
);
// <qrdx-code value="https://example.com" size="256" label="Link to example.com"
//   props="{…}"><template shadowrootmode="open">…</template></qrdx-code>
```

Les options simples deviennent des attributs et le reste est placé dans `props` au format JSON, si bien que l'élément relit les mêmes options. `customTemplate` ne peut pas être écrit sous forme de balisage : définissez-le comme propriété dans le navigateur. Passez `tagName` si vous avez enregistré un autre nom.

## React 19 [#react-19]

React 19 définit une prop comme propriété lorsque l'élément en possède une, donc les objets fonctionnent comme props. Enregistrez l'élément une fois, avant le rendu :

```tsx title="components/menu-code.tsx"
import "qrdx/element/define";

export function MenuCode({ url }: { url: string }) {
  return (
    <qrdx-code
      value={url}
      size={256}
      body-pattern="rounded"
      frame={{ style: "banner-bottom", text: "Scan me" }}
      label="Menu"
    />
  );
}
```

Pour TypeScript, ajoutez l'élément à JSX dans un fichier `.d.ts` :

```ts title="qrdx-code.d.ts"
import type { QRdxCodeElement, QRdxCodeJSXProps } from "qrdx/element";

declare module "react" {
  namespace JSX {
    interface IntrinsicElements {
      "qrdx-code": React.DetailedHTMLProps<
        React.HTMLAttributes<QRdxCodeElement>,
        QRdxCodeElement
      > &
        QRdxCodeJSXProps;
    }
  }
}
```

Une `ref` vous donne l'élément, pour `toDataURL` et `download`.

## Vue [#vue]

Indiquez au compilateur de Vue que `qrdx-code` est un élément personnalisé :

```js title="vite.config.js"
import vue from "@vitejs/plugin-vue";
import { defineConfig } from "vite";

export default defineConfig({
  plugins: [
    vue({
      template: {
        compilerOptions: { isCustomElement: (tag) => tag === "qrdx-code" },
      },
    }),
  ],
});
```

Importez ensuite `qrdx/element/define` une fois, dans `main.js`, et liez les options dans les templates. Vue définit une liaison comme propriété lorsque l'élément en possède une :

```vue title="src/App.vue"
<qrdx-code
  :value="url"
  :size="256"
  body-pattern="rounded"
  :frame="{ style: 'banner-bottom', text: 'Scan me' }"
  label="Menu"
/>
```

## En cas de problème [#if-something-goes-wrong]

- **Rien n'est dessiné.** L'élément n'a pas de `value`, ou le script de définition ne s'est pas exécuté. Vérifiez l'attribut, et que `element-define` est chargé en tant que module.
- **Un événement `qrdx-error` se déclenche.** Le code ne peut pas être dessiné, par exemple parce que la valeur est trop longue pour un QR code, ou parce que l'attribut `props` n'est pas un objet JSON. L'erreur se trouve dans `event.detail.error`. L'élément supprime l'ancien code et consigne l'erreur, sauf si un écouteur appelle `event.preventDefault()` :

  ```js title="main.js"
  qr.addEventListener("qrdx-error", (event) => {
    event.preventDefault();
    showMessage("That text is too long for a QR code.");
  });
  ```

- **`qrdx: <qrdx-code> is already defined by another element`.** Un autre script a enregistré le même nom de balise. Passez un autre nom à `defineQRdxCode`.
- **TypeScript : `Property 'qrdx-code' does not exist on type 'JSX.IntrinsicElements'`.** Ajoutez la déclaration de la section React 19.
