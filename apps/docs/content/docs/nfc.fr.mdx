Tout [QR code dynamique](/docs/dynamic-qr-codes) peut aussi être placé sur un tag NFC. Vous écrivez le lien NFC du code sur un tag, un autocollant ou une carte, et un téléphone qui le touche ouvre la même destination que le QR code. Les taps apparaissent dans les statistiques du code à côté des scans de QR code, comptabilisés séparément. Utilisez-le là où un tap est plus simple qu'un scan : autocollants de table, cartes de visite, rayons de produits. Cela fonctionne avec tous les forfaits.

QRdx ne vend, n'imprime et n'expédie ni tags ni cartes. Achetez des tags vierges auprès de n'importe quel fournisseur NFC et écrivez-les vous-même depuis la page du code.

## Fonctionnement [#how-it-works]

<Diagram id="nfc-link" />

Le lien NFC d'un code est son lien court suivi de `?nfc`, par exemple `https://qrdx.dev/q/aB3dE5f?nfc`, ou `https://go.example.com/menu?nfc` sur un [domaine personnalisé](/docs/custom-domains). Il passe par la même redirection que le lien court : le routage intelligent, les mots de passe, les planifications et les limites de scans s'appliquent donc aussi aux taps. La terminaison `?nfc` indique simplement aux statistiques que la visite était un tap. Le QR code garde son propre lien, et les codes que vous avez déjà imprimés fonctionnent exactement comme avant.

Pour trouver le lien, ouvrez le code depuis [Codes](/dashboard?to=codes) et choisissez **Utiliser avec NFC** dans son onglet **Aperçu**.

## Écrire un tag sur Android [#write-a-tag-on-android]

Chrome sur Android peut écrire des tags directement depuis la page NFC du code :

1. Activez le NFC dans les réglages du téléphone.
2. Ouvrez le code dans Chrome, choisissez **Utiliser avec NFC**, puis touchez **Écrire sur le tag NFC**.
3. Maintenez le tag à plat contre le dos du téléphone jusqu'à ce que la page affiche **Écrit**.
4. Approchez le tag du téléphone pour le tester. Il ouvre le lien.

L'écriture depuis une page web nécessite Web NFC, que seul Chrome sur Android propose. Sur un ordinateur, la page NFC affiche à la place un QR code : scannez-le avec le téléphone Android, connectez-vous et écrivez le tag à partir de là.

### Verrouiller un tag [#locking-a-tag]

Une fois le tag écrit, la page propose de le verrouiller si le navigateur le permet. Un tag verrouillé ne peut plus jamais être modifié ni effacé, par personne, vous y compris. Verrouillez donc uniquement les tags placés là où des inconnus pourraient les réécrire, comme un autocollant sur la table d'un café. Le tag contient le lien du code et non sa destination : vous pouvez donc toujours modifier depuis QRdx la destination d'un tag verrouillé.

## Écrire un tag sur iPhone [#write-a-tag-on-iphone]

Safari ne peut pas écrire de tags NFC, utilisez donc n'importe quelle application d'écriture NFC de l'App Store :

1. Copiez le lien NFC depuis la page NFC du code.
2. Dans l'application, ajoutez un enregistrement URL (certaines applications l'appellent Link ou URI) et collez le lien.
3. Choisissez Write et maintenez le haut de l'iPhone contre le tag jusqu'à ce que l'application indique que c'est terminé.

L'écriture nécessite un iPhone 7 ou ultérieur sous iOS 13 ou ultérieur.

## Quels tags acheter [#which-tags-to-buy]

Cherchez une puce NTAG213, NTAG215 ou NTAG216. Elles existent sous forme d'autocollants, de cartes, de porte-clés et de bracelets.

| Puce | Mémoire |
| --- | --- |
| NTAG213 | 144 octets |
| NTAG215 | 504 octets |
| NTAG216 | 888 octets |

Un lien NFC sur qrdx.dev occupe environ 30 octets : les trois puces peuvent donc le contenir. Les liens sur de longs domaines personnalisés ou avec de longues fins de chemin en demandent plus ; la page NFC indique combien d'octets il vous faut et quelles puces conviennent.

Les téléphones Android dont le NFC est activé, ainsi que l'iPhone XS ou ultérieur, ouvrent le lien d'un tag dès qu'il touche le téléphone, sans application.

## Cartes de visite NFC [#nfc-business-cards]

Une [page vCard Plus](/docs/landing-pages#vcard-plus-and-save-contact) est une page de contact avec un bouton **Enregistrer le contact**, et elle fait une très bonne carte de visite NFC. Pour un code qui en ouvre une, l'onglet **Aperçu** affiche **Mettre cette carte sur NFC**, et l'éditeur de page propose un bouton **Mettre sur NFC**. Les deux ouvrent la même page NFC avec un guide pour les cartes.

1. Achetez des cartes de visite NFC vierges, ou des autocollants NFC pour des cartes que vous avez déjà.
2. Imprimez aussi le QR code du code sur la carte. Les téléphones sans NFC, ou dont le NFC est désactivé, le scannent à la place.
3. Écrivez le lien NFC sur chaque carte depuis la page NFC du code.

Comme chaque carte contient le lien du code, modifier la page vCard Plus dans QRdx met à jour toutes les cartes que vous avez distribuées.

## Taps dans les statistiques [#taps-in-analytics]

L'onglet **Statistiques** d'un code affiche **Scans de QR code et taps NFC** pour les dates choisies, et les totaux au-dessus comptent les deux. La page Statistiques de l'espace de travail et les pages de statistiques partagées présentent la même répartition. Les scans antérieurs à l'existence des liens NFC sont comptés comme des scans de QR code. Les taps suivent les mêmes règles que les scans : les robots et les aperçus de liens ne sont pas comptés.

## Limites et forfaits [#limits-and-plans]

Les liens NFC fonctionnent avec tous les forfaits, pour tous les codes dynamiques. Le code lui-même compte dans les codes actifs de votre forfait comme n'importe quel autre.

## Pour les développeurs [#for-developers]

La REST API renvoie le lien sous le nom `nfcLink` pour chaque code. Les [statistiques de scans](/docs/developers/api/get-code-scans) incluent `sources` avec les deux totaux et une `source` (`qr` ou `nfc`) sur chaque scan listé, l'export CSV contient une colonne `source`, et les [webhooks](/docs/webhooks) pour `scan.created` transmettent aussi `source`.
