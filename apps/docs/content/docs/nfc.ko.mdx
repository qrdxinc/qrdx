모든 [동적 QR 코드](/docs/dynamic-qr-codes)는 NFC 태그에도 넣을 수 있습니다. 코드의 NFC 링크를 태그, 스티커, 카드에 기록하면, 여기에 휴대폰을 대는 사람은 QR 코드와 같은 곳으로 연결됩니다. 탭 횟수는 코드의 분석에 QR 스캔과 나란히, 따로 집계되어 표시됩니다. 스캔보다 탭이 더 편한 곳에 사용하세요. 테이블 스티커, 명함, 제품 진열대 등이 좋은 예입니다. 모든 플랜에서 사용할 수 있습니다.

QRdx는 태그나 카드를 판매, 인쇄, 배송하지 않습니다. 빈 태그는 NFC 공급업체에서 구매하고, 코드 페이지에서 직접 기록하세요.

## 작동 방식 [#how-it-works]

<Diagram id="nfc-link" />

코드의 NFC 링크는 단축 링크 끝에 `?nfc`를 붙인 형태입니다. 예를 들어 `https://qrdx.dev/q/aB3dE5f?nfc`이고, [사용자 지정 도메인](/docs/custom-domains)에서는 `https://go.example.com/menu?nfc`가 됩니다. 단축 링크와 같은 리디렉션을 거치므로 스마트 라우팅, 비밀번호, 일정, 스캔 제한이 탭에도 똑같이 적용됩니다. `?nfc`는 분석에 방문이 탭이었음을 알려 주는 역할만 합니다. QR 코드는 기존 링크를 그대로 유지하므로, 이미 인쇄한 코드도 전과 똑같이 작동합니다.

링크를 확인하려면 [코드](/dashboard?to=codes)에서 해당 코드를 열고 **개요** 탭에서 **NFC로 사용하기**를 선택하세요.

## Android에서 태그 기록하기 [#write-a-tag-on-android]

Android의 Chrome에서는 코드의 NFC 페이지에서 바로 태그를 기록할 수 있습니다.

1. 휴대폰 설정에서 NFC를 켭니다.
2. Chrome에서 코드를 열고 **NFC로 사용하기**를 선택한 다음 **NFC 태그에 기록**을 누릅니다.
3. 페이지에 **기록 완료**가 표시될 때까지 태그를 휴대폰 뒷면에 평평하게 대고 있습니다.
4. 태그를 휴대폰에 대어 테스트합니다. 링크가 열립니다.

웹 페이지에서 기록하려면 Web NFC가 필요하며, 이는 Android의 Chrome에서만 지원됩니다. 컴퓨터에서는 NFC 페이지에 QR 코드가 대신 표시됩니다. Android 휴대폰으로 이 코드를 스캔하고 로그인한 다음, 휴대폰에서 태그를 기록하세요.

### 태그 잠금 [#locking-a-tag]

태그를 기록하고 나면, 브라우저가 지원하는 경우 페이지에서 태그를 잠그도록 안내합니다. 잠긴 태그는 본인을 포함해 누구도 다시 변경하거나 지울 수 없으므로, 카페 테이블 위 스티커처럼 낯선 사람이 덮어쓸 수 있는 곳에 놓는 태그만 잠그세요. 태그에는 목적지가 아니라 코드의 링크가 들어 있으므로, 잠근 태그라도 QRdx에서 연결 대상을 바꿀 수 있습니다.

## iPhone에서 태그 기록하기 [#write-a-tag-on-iphone]

Safari는 NFC 태그를 기록할 수 없으므로 App Store의 NFC 기록 앱을 사용하세요.

1. 코드의 NFC 페이지에서 NFC 링크를 복사합니다.
2. 앱에서 URL 레코드(앱에 따라 Link 또는 URI라고도 합니다)를 추가하고 링크를 붙여넣습니다.
3. Write를 선택하고, 앱에 완료되었다고 표시될 때까지 iPhone 윗부분을 태그에 대고 있습니다.

기록하려면 iOS 13 이상이 설치된 iPhone 7 이상이 필요합니다.

## 어떤 태그를 구매해야 하나요 [#which-tags-to-buy]

NTAG213, NTAG215 또는 NTAG216 칩을 찾으세요. 스티커, 카드, 키링, 손목밴드 형태로 판매됩니다.

| 칩 | 메모리 |
| --- | --- |
| NTAG213 | 144바이트 |
| NTAG215 | 504바이트 |
| NTAG216 | 888바이트 |

qrdx.dev의 NFC 링크는 약 30바이트이므로 세 가지 칩 모두 저장할 수 있습니다. 긴 사용자 지정 도메인을 쓰거나 뒷부분이 긴 링크는 더 많은 공간이 필요합니다. NFC 페이지에서 내 링크에 필요한 바이트 수와 사용할 수 있는 칩을 확인할 수 있습니다.

NFC를 켠 Android 휴대폰과 iPhone XS 이상은 태그가 휴대폰에 닿는 즉시 앱 없이 태그의 링크를 엽니다.

## NFC 명함 [#nfc-business-cards]

[vCard Plus 페이지](/docs/landing-pages#vcard-plus-and-save-contact)는 **연락처 저장** 버튼이 있는 연락처 페이지이며, NFC 명함으로 활용하기 좋습니다. vCard Plus 페이지를 여는 코드는 **개요** 탭에 **이 명함을 NFC에 넣기**가 표시되고, 페이지 편집기에는 **NFC에 넣기** 버튼이 있습니다. 두 곳 모두 카드용 안내가 포함된 같은 NFC 페이지를 엽니다.

1. 빈 NFC 명함을 구매하거나, 이미 가지고 있는 명함에 붙일 NFC 스티커를 구매합니다.
2. 코드의 QR 코드도 명함에 인쇄합니다. NFC가 없거나 꺼져 있는 휴대폰에서는 이 코드를 스캔하면 됩니다.
3. 코드의 NFC 페이지에서 각 명함에 NFC 링크를 기록합니다.

각 명함에는 코드의 링크가 들어 있으므로, QRdx에서 vCard Plus 페이지를 수정하면 이미 나눠 준 모든 명함에 반영됩니다.

## 분석에서 보는 탭 [#taps-in-analytics]

코드의 **분석** 탭에는 선택한 기간의 **QR 스캔 및 NFC 탭**이 표시되고, 위쪽의 합계에는 두 가지가 모두 포함됩니다. 워크스페이스의 분석 페이지와 공유 분석 페이지에서도 같은 구분을 볼 수 있습니다. NFC 링크가 생기기 전의 스캔은 QR 스캔으로 집계됩니다. 탭에도 스캔과 같은 규칙이 적용되어 봇과 링크 미리보기는 집계되지 않습니다.

## 제한과 플랜 [#limits-and-plans]

NFC 링크는 모든 플랜에서 모든 동적 코드에 사용할 수 있습니다. 코드 자체는 다른 코드와 마찬가지로 플랜의 활성 코드 수에 포함됩니다.

## 개발자용 [#for-developers]

REST API는 모든 코드에 `nfcLink`로 링크를 반환합니다. [스캔 분석](/docs/developers/api/get-code-scans)에는 두 집계가 담긴 `sources`와 목록의 각 스캔에 `source`(`qr` 또는 `nfc`)가 포함되고, CSV 내보내기에는 `source` 열이 있으며, `scan.created`의 [웹훅](/docs/webhooks)에도 `source`가 포함됩니다.
