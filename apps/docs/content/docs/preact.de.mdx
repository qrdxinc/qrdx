Am Ende dieser Seite hast du einen gestalteten QR-Code in einer Preact-Komponente und einen Button, der ihn als PNG speichert. `qrdx/preact` enthält die zwei SVG-Komponenten der React-Bibliothek, `QRCodeSVG` und `QRCode`, gebaut für Preact. Sie zeichnen mit Preacts eigenem `h`, du brauchst also weder `preact/compat` noch `react`, und sie zeichnen dasselbe SVG wie die React-Komponenten.

<NpmStatus package="qrdx" />

## Bevor du startest [#before-you-start]

- Ein Projekt mit Preact 10 oder neuer, mit Vite oder einem anderen Bundler.
- Node.js 18 oder neuer.

## So baust du es [#build-it]

### 1. qrdx installieren [#1-install-qrdx]

```package-install
qrdx
```

`preact` ist eine optionale Peer-Dependency von `qrdx`. Deine App hat es bereits.

### 2. Einen Code zeichnen [#2-draw-a-code]

```tsx title="src/components/menu-code.tsx"
import { QRCodeSVG } from "qrdx/preact";

export function MenuCode() {
  return (
    <QRCodeSVG
      value="https://example.com/menu"
      size={256}
      margin={4}
      bodyPattern="rounded"
      frame={{ style: "banner-bottom", text: "Scan me" }}
      aria-label="QR code for the menu"
    />
  );
}
```

Die Seite zeigt einen 256-px-Code mit abgerundeten Modulen und einem „Scan me“-Banner darunter.

<Shot id="lib-preact-code" />

`QRCodeSVG` akzeptiert alle Optionen, die auch das React-`QRCodeSVG` akzeptiert: Muster, Farben und Verläufe, Logos (`imageSettings`), Rahmen, Formen, Vorlagen und Art. Attribute wie `class`, `style` oder `aria-label` landen auf dem `<svg>`, bei einem Rahmen auf dem äußeren `<svg>` des Rahmens.

`QRCode` ergänzt die Logo-Abkürzung des React-`QRCode`: `logo`, `logoOptions`, `hideLogo` und `scale`. Es akzeptiert nur die Props des Codes und `style`; setze `class` oder `aria-label` auf ein umgebendes Element oder verwende `QRCodeSVG`.

```tsx title="src/components/logo-code.tsx"
import { QRCode } from "qrdx/preact";

export function LogoCode() {
  return <QRCode value="https://example.com" size={256} logo="/logo.png" level="H" />;
}
```

Beide Komponenten zeichnen neu, wenn sich eine Prop ändert, und sparen sich die Arbeit, wenn sich keine geändert hat. Event-Handler in den Props werden wie in React nicht auf das `<svg>` gesetzt. Setze sie auf ein Element um den Code.

### 3. Als Datei speichern [#3-save-it-as-a-file]

Die Komponenten zeichnen nur den Code. Downloads, `toSVGString`, der Scan-Score und die übrigen Funktionen kommen aus `qrdx/core`. Das ist die Engine, die die Komponenten bereits nutzen, daher wird sie nicht doppelt gebündelt.

```tsx title="src/components/downloadable-code.tsx"
import { downloadQRCode } from "qrdx/core";
import { QRCodeSVG } from "qrdx/preact";

const options = { value: "https://example.com", size: 256, margin: 4 };

export function DownloadableCode() {
  return (
    <>
      <QRCodeSVG {...options} />
      <button
        type="button"
        onClick={() =>
          downloadQRCode(options, {
            format: "png",
            size: { width: 1024, height: 1024 },
            filename: "qr-code.png",
          })
        }
      >
        Download PNG
      </button>
    </>
  );
}
```

Ein Klick auf den Button speichert `qr-code.png` mit 1024 px. Halte die Optionen wie oben in einem Objekt, damit die Datei zum Code auf dem Bildschirm passt. [Vanilla JavaScript](/docs/vanilla-js) behandelt `qrdx/core` vollständig.

## Server-Rendering [#server-rendering]

`renderToString` aus `preact-render-to-string` schreibt dasselbe SVG wie `toSVGString` aus `qrdx/core`. Der einzige Unterschied liegt beim Escaping: Preact lässt `>` und `'` im Text unverändert, während der Core `&gt;` und `&#x27;` schreibt. Browser lesen beides gleich.

`hydrate` übernimmt das `<svg>` des Servers und zeichnet es nicht neu. Das Markup enthält keine zufälligen IDs, daher stimmen Server und Browser immer überein.

## Mit preact/compat [#with-preactcompat]

Wenn deine App `react` bereits auf `preact/compat` aliasiert, funktionieren auch die React-Komponenten aus `qrdx`: `import { QRCodeSVG } from "qrdx"`. `qrdx/preact` zeichnet denselben Code ohne den Alias, nimm es also lieber, wenn du `qrdx` zu einer Preact-App hinzufügst.

## Wenn etwas schiefgeht [#if-something-goes-wrong]

- **`Failed to resolve import "react"`.** Du hast aus `qrdx` statt aus `qrdx/preact` importiert, in einer App ohne `preact/compat`. Ändere den Import.
- **Ein Click-Handler auf der Komponente tut nichts.** Handler werden vom `<svg>` entfernt. Verpacke den Code in einen `<button>` oder ein `<div>` und setze den Handler dorthin.
- **`PDF export needs the optional "jspdf" package`.** Führe `npm install jspdf` in der App aus.
