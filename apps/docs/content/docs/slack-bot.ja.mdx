QRdx用Slackボットは、Slack内でQRコードを作成します。ボットを導入したSlackワークスペースのメンバーなら誰でも、リンクや任意のテキストからコードを作成し、メッセージの下にあるメニューでスタイルを変更して、ダウンロードできます。QRdxアカウントを連携すると、トラッキング付き（動的）のコードも作成できます。このコードはスキャン数をカウントでき、後からリンク先を変更することも可能です。チームがSlackでリンクを共有していて、会話を離れずにコードを作りたいときに便利です。

## 仕組み [#how-it-works]

ボットはメッセージの本文を保存せず、画像のアップロードも行いません。各コードは、メッセージ内のリンクをもとに QRdx が [image API](/docs/developers/image-api) を通じて生成する QR 画像で、内容とデザインはそのリンクに含まれています。コードのスタイルを変更するときも、リンクから両方を読み取り直すため、変更のために保存しておくものはありません。

<IfAvailable feature="slackBot" id="add-the-bot-to-slack" title="ボットをSlackに追加する">

1. QRdx で [設定 → 連携 → Slack](/settings/integrations/slack) を開き、**Add the bot to Slack** をクリックします。QRdx アカウントであれば、どのプランでも追加できます。
2. Slack ワークスペースを選んで承認します。ボットは、スラッシュコマンド、ボットへのメンション、ダイレクトメッセージの表示と、メッセージの投稿を求めます。
3. 設定ページに戻ります。ページには、ボットを追加した Slack ワークスペースが一覧表示されます。

同じ Slack アプリは、チャンネルへの[アラート](/docs/notifications#slack-and-discord)の投稿も行います。ボットを追加してもアラートはオンにならず、アラートを追加してもボットは追加されません。

</IfAvailable>

<IfAvailable feature="slackBot" id="make-a-qr-code" title="QRコードを作成する">

| 場所 | 操作 | コードが表示される場所 |
| --- | --- | --- |
| 任意のチャンネル | `/qr` の後にリンクまたはテキストを入力 | チャンネル内 |
| ボットが参加しているチャンネル | リンクまたはテキストを添えてボットにメンション | スレッド内 |
| ボットのダイレクトメッセージ | リンクまたはテキストを送信 | DM 内 |
| 任意のメッセージ | **その他のアクション** → **QRコードを作成** | メッセージのスレッド内 |

どの返信にも、QRコード画像、その下の内容、3つのボタン、以下で説明するスタイルメニューが付きます。ボタンは、**PNGをダウンロード**（1024ピクセル）、**SVGをダウンロード**、そしてデザインをさらに変更できる**エディタで開く**です。リンクの場合は、そのリンクが入力済みの状態でエディタが開きます。テキストの場合は、テキストがリンクに含まれることはないため、空のエディタが開きます。

ショートカットは、メッセージ内の最初のWebアドレスからコードを作成します。Webアドレスがない場合は、メッセージ全体のテキストから作成します。そのチャンネルにボットが参加していない場合は、あなただけにコードが表示され、「Only you can see this. Add the QRdx app to this channel to reply in threads.」というメモが付きます。

`/qr` だけを入力するか `/qr help` を入力すると、コマンドの一覧が表示されます。QRコードに収まらないほど長い内容の場合は、画像の代わりに短い説明が表示され、あなただけに見えます。

</IfAvailable>

<IfAvailable feature="slackBot" id="style-your-code" title="コードのスタイルを変更する">

各コードの下には、**Look**、**Color**、**Frame**、**Logo** の4つのメニューがあります。項目を選ぶと、コードがその場で更新され、新しいダウンロードリンクが表示されます。選択は、そのときのコードの状態に重ねて反映されます。コードのスタイルを変更できるのは、そのコードを作成した人だけです。ほかの人が選択した場合は、その人にだけ見えるメモが Slack に表示され、コードは元のままです。

Look には、エディタに組み込まれたデザインのうち、小さいサイズでも読み取りやすいものが含まれます。**Plain** は白地に黒のデザインです。Look を選ぶと、形と色が変わりますが、選択済みのフレームとロゴはそのまま残ります。Color を選ぶと、コード全体がその色になり、背景は白になります。Frame では「Scan me」というラベルが付き、Logo メニューではエディタのクイックアイコンから7つを選べます。

コードの作成時に、リンクまたはテキストの後ろにオプションを追加してスタイルを指定することもできます。オプション名は [QRdx CLI](/docs/developers/cli) と同じです。

```text title="Slack message"
/qr qrdx.dev --look modern --fg 0051ff --frame banner-bottom --frame-text "Scan me"
```

最初のオプションより前の部分が内容です。Look が最初に適用され、その上にほかのオプションが適用されます。そのため、`--look royal --fg 0051ff` は Royal の形を保ったまま青にします。オプションは、メンションやダイレクトメッセージでも使えます。オプションまたは値が正しくない場合は、ボットがあなただけに知らせ、使用できる値を一覧で示します。

| オプション | 変更される内容 | 値 |
| --- | --- | --- |
| `--look` | エディタのプリセットから選ぶデザイン全体 | `plain`, `classic`, `modern`, `royal`, `folio`, `caffeine`, `retro`, `bordeaux`, `blossom` |
| `--fg`（または `--color`） | ドット。コーナーアイも同時に変わります（別途指定した場合を除く） | `0051ff` のような16進数カラー、または `black`, `blue`, `green`, `red`, `purple`, `orange` |
| `--bg` | 背景 | `--fg` と同じ |
| `--eye-color` | 3つのコーナーアイ | `--fg` と同じ |
| `--dot-color` | コーナーアイの中心 | `--fg` と同じ |
| `--body` | ドットの形 | エディタの {facts.bodyPatterns} 種類のドット形状のいずれか（`rounded`、`circle`、`classy` など） |
| `--eye` | コーナーアイの形 | {facts.eyeShapes} 種類のアイ形状のいずれか（`square`、`rounded`、`gear` など） |
| `--dot` | アイ中心の形 | {facts.eyeCentres} 種類の中心形状のいずれか（`square`、`rounded`、`circle` など） |
| `--frame` | コードを囲むフレーム | `none`、または {facts.frameStyles} 種類の組み込みフレームのいずれか（`banner-bottom`、`banner-top`、`speech-bubble`、`polaroid` など） |
| `--frame-text` | フレームのラベル（最大24文字） | 任意のテキスト。スペースを含む場合は引用符で囲みます。`--frame` がない場合は、コードの下のバナーに表示されます |
| `--template` | テンプレートとして描画されるフレーム | `Arrow`, `StandardBox`, `SquareBorder`, `StrikedBox`, `DotRing`, `Halloween`, `default`（大文字・小文字は問いません） |
| `--logo` | 中央のアイコン | `link`, `wifi`, `location`, `phone`, `email`, `whatsapp`, `instagram`, `file`, `calendar`, `none` |

スタイルを指定したコードは、投稿前に、エディタと同じスキャンスコアで QRdx がチェックします。携帯電話で読み取りにくいデザインの場合は、QRdx が調整し（より暗い色、よりシンプルな形、より高い誤り訂正）、その旨をコードの下に表示します。それでも十分でない場合は、多くは内容が長いことが原因ですが、白地に黒のコードがメモ付きで投稿されます。`/qr` でスタイルを指定したコードは、チェックが終わってから投稿されるため、コマンドを送信して少ししてから表示されます。

**エディタで開く**を押すと、色、形、フレーム、枠線など、同じデザインでエディタが開きます。ロゴアイコンはリンクに含まれないため、エディタで選び直してください。

ショートカットで作成した、あなただけに見えるコードにはメニューがありません。また、トラッキング付きコードはプレーンなデザインのままです。

</IfAvailable>

<IfAvailable feature="slackBot" id="tracked-codes" title="トラッキング付きコード">

通常のコードにはリンクそのものが含まれます。トラッキング付きコードには、あなたのリンクへリダイレクトする短縮リンク（`https://qrdx.dev/q/<slug>`）が含まれます。そのため、QRdx がスキャン数を集計でき、リダイレクト先も変更できます。Slack からトラッキング付きコードを作成するには、最初に一度だけ QRdx アカウントを連携します。

1. `/qr link` を実行します。あなただけに見える **Link QRdx account** ボタンから QRdx が開きます。有効期間は10分間です。
2. 求められたら QRdx にサインインします。次に **Sign in with Slack** をクリックし、`/qr link` を実行したのと同じ Slack アカウントでサインインします。QRdx に伝わるのは Slack のユーザーとワークスペースだけで、QRdx はそれらが一致することを確認します。別の Slack アカウントでサインインした場合は、何も連携されません。
3. トラッキング付きコードの保存先にする QRdx ワークスペースを選び、**Confirm** をクリックします。この連携により、その Slack アカウントがあなたのワークスペースでコードを作成できるようになるため、最近確認していない場合は、先に QRdx から[本人確認](/docs/help/privacy-and-security/two-step-verification#confirm-its-you)を求められます。
4. Slack に戻ると、連携した QRdx アカウントとワークスペースの名前を記したダイレクトメッセージがボットから届きます。連携した覚えがない場合は、`/qr unlink` を実行してください。
5. `/qr track` の後に、`https://` または `http://` で始まるリンクを入力して実行します。ボットに `track` とリンクを添えてメンションすることもできます。

コードは、短縮リンクと、保存先の QRdx ワークスペース名とともにチャンネルに表示されます。ダッシュボード内のそのコードへ移動する **Open in QRdx** ボタンは、あなただけに見える別のメッセージで届きます。コードの名前は、リンク先サイトの名前に「from Slack」を付けたものになり、ワークスペースのコード一覧で、ほかのコードと同じように見つけられます。

トラッキング付きコードには、ダッシュボードで作成したコードと同じルールが適用されます。あなたのロールがコードの作成を許可していること、二段階認証を必須とするワークスペースではあなたのアカウントで二段階認証がオンになっていること、そしてプランの有効な動的QRコードの上限が適用されます。上限に達している場合は、ボットがその旨を伝え、プランへのリンクを示します。これらは毎回確認されるため、ワークスペースを退出したりアクセス権を失ったりすると、そのワークスペースではリンクが使えなくなります。

Slack アカウントごとに、Slack ワークスペースあたり1つのリンクを持てます。すでに連携済みの Slack アカウントで `/qr link` を実行すると、ページに、どの QRdx ワークスペースに連携されているか、またそれが別の QRdx アカウントかどうかが表示されます。このとき、ボタンは **Replace the link** になり、クリックするまで何も変更されません。リンクを削除するには `/qr unlink` を使うか、[設定 → 連携 → Slack](/settings/integrations/slack) の **Linked Slack accounts** にある **Unlink** を使います。

QRdx ワークスペースのオーナーと管理者は、**設定** → **API keys & apps** の **Slack accounts** で、そのワークスペースに連携されているすべての Slack アカウントを確認できます。表示されるのは、Slack ワークスペース、Slack ユーザー ID、代理として動作するメンバー、連携した日時です。そこで **Revoke** をクリックすると、リンクが削除されます。ワークスペースで[監査ログ](/docs/help/teams/audit-log)が使える場合、`/qr track` で作成したコードには、メンバー名に「via Slack」が付き、Slack のユーザー ID とワークスペース ID も記録されます。リンクの取り消しも記録されます。

## ボットが保持する情報 [#what-the-bot-keeps]

ボットがメッセージを読み取るのは、誰かが `/qr` を実行したとき、ボットにメンションしたとき、ボットにダイレクトメッセージを送ったとき、またはそのメッセージでショートカットを使ったときだけです。メッセージの本文は一切保存しません。QRコード画像は QRdx の[image API](/docs/developers/image-api)から提供され、Slack がメッセージ内のリンクから読み込むため、アップロードは行われません。

Slack ワークスペースごとに、QRdx は ID と名前、ボットの Slack ユーザー ID、付与されたスコープ、ボットのトークン（暗号化済み）、どの QRdx アカウントがいつ追加したかを保持します。連携した Slack アカウントごとには、Slack のユーザー ID とワークスペース ID、お使いの QRdx アカウント、選択したワークスペース、連携した日時を保持します。連携のために Slack でサインインしても、これ以外の情報は増えません。QRdx は Slack のユーザーとワークスペースを照合し、その後サインイン情報を破棄します。<IfAvailable feature="slackBot"> 連携した Slack アカウントは[データのエクスポート](/docs/help/account-and-billing/export-your-data)に含まれます。</IfAvailable>

1人のユーザーがチャンネルに大量の投稿をするのを防ぐため、ボットは1分間に各ユーザーが作成または再スタイルしたコードの数と、Slack ワークスペース全体および QRdx 全体で作成されたコードの数を数えます。リクエストが多すぎる場合、ボットは「QRdx is busy right now. Try again in a minute.」と返信します。どちらのカウントにもコンテンツは含まれません。

<IfAvailable feature="slackBot" id="remove-the-bot" title="ボットの削除">

Slack でアプリのページを開き、**Remove App** を選択します（Slack 管理者に依頼することもできます）。すると QRdx は、その Slack ワークスペースのボットトークンと、そこで作成されたすべての Slack アカウント連携を削除します。すでに作成したコードは QRdx に残り、トラッキング付きのコードも引き続き動作します。

</IfAvailable>

## 開発者向け [#for-developers]

このボットは2つの公開ツールの上に載った薄いレイヤーです。すべてのコードは[image API](/docs/developers/image-api)で生成され、トラッキング付きコードは通常の動的QRコードなので、[REST API](/docs/developers/api/list-codes)から読み取れます。同じスタイルオプションは [CLI](/docs/developers/cli) にもあります。

## セルフホスティング [#self-hosting]

このボットは、「Add to Slack」アラートと同じ Slack アプリを使い、そこに署名シークレットを追加します。`SLACK_CLIENT_ID`、`SLACK_CLIENT_SECRET`、`SLACK_SIGNING_SECRET` を設定してください。本番環境ではさらに `INTEGRATION_ENCRYPTION_KEY` も設定します。これはボットのトークンを暗号化するためのものです。これらがない場合、ボットのページとエンドポイントは存在しません。リポジトリ内の `plugins/slack/manifest.json` がアプリのマニフェストで、`plugins/slack/README.md` にそれを使ってアプリを作成する手順があります。マニフェストには `openid` ユーザースコープとリダイレクト URL `/api/integrations/slack/link/callback` が含まれており、ユーザーがアカウントを連携する際の Sign in with Slack に必要です。レート制限には Upstash Redis が必要で、ない場合はレート制限が無効になります。[セルフホスティング](/docs/self-hosting#optional-services)をご覧ください。
