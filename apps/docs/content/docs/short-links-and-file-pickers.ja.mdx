description: "QRエディタから、お持ちの Bitly、Rebrandly、Short.io アカウントでQRコードのリンクを短縮したり、Dropbox の共有リンクをエンコードしたりできます。"
---

連携アカウントを使うと、QRエディタで他のツールにあるリンクを利用できます。Bitly、Rebrandly、Short.io で管理している短縮リンクや、Dropbox などのクラウドドライブにあるファイルの共有リンクです。QRコードはそのリンクをエンコードするため、使い慣れたツールをそのまま使えます。リンクをそのツールのアナリティクスで管理し続けたい場合や、クラウドドライブにあるファイルをQRコードで開きたい場合にご利用ください。

<Callout type="info" title="すべてのプラン">
  連携アカウントはユーザーアカウントに紐づき、すべてのプランで利用できます。リンク先をQRdx内で編集でき、スキャン分析も使いたい場合は、代わりに[動的QRコード](/docs/dynamic-qr-codes)をご利用ください。
</Callout>

## 仕組み [#how-it-works]

[設定 → 連携](/settings/integrations)でアカウントを連携すると、QRエディタの **URL** タイプで、**Website address** フィールドの横にある **Use a link from…** メニューに表示されます。**Your accounts** の下に、各サービスでできることが表示されます。

- **Shorten**: Bitly、Rebrandly、Short.io。**Create new** で新しいリンクを作成するか、**Use existing** で既存のリンクを選びます。QRコードはその短縮リンクをエンコードするため、リンク先は後からそのサービスで変更でき、クリック数も計測されます。
- **File**: Dropbox<IfAvailable integration="onedrive">、OneDrive</IfAvailable><IfAvailable integration="box">、Box</IfAvailable><IfAvailable integration="notion">、Notion</IfAvailable>。参照または検索して、ファイルまたはフォルダを選びます。QRdx がその項目の共有リンクを作成し、QRコードがそれをエンコードします。

同じメニューには、決済リンクや予約リンクなど、連携済みのその他のコンテンツソースも表示されます。まだ連携していないサービスは、メニュー下部の **Connect an account** から追加できます。

<Shot id="use-a-link-from" />

トークンとAPIキーは暗号化して保存され、いつでも連携を解除できます。

## 短縮リンク [#short-links]

| サービス | 連携方法 | ドメイン | バックハーフ |
| --- | --- | --- | --- |
| Bitly | Bitly でサインインするか、汎用アクセストークンを貼り付けます（Settings → Developer settings → API） | bit.ly とブランドドメイン | Bitly が決定 |
| Rebrandly | APIキーを貼り付けます（Account → API keys） | rebrand.ly とブランドドメイン | 任意のスラッシュタグ、またはランダム |
| Short.io | シークレットAPIキーを貼り付けます（Integrations & API → API） | お使いの Short.io ドメイン | 任意のパス、またはランダム |

各連携の設定ページには、お使いのドメインが表示され、新しいリンクのデフォルトドメインを選べます。リンクごとに別のドメインを選ぶこともできます。

<Callout type="info" title="リンク先を後から変更する">
  QRdx はリンクを作成しますが、リンク先の編集は Bitly、Rebrandly、Short.io で行います。Bitly では、リンク先を変更できるのは有料プランのみです。
</Callout>

## ファイルピッカー [#file-pickers]

**Dropbox** は共有リンクをエンコードします（新規作成、または既存のリンクを再利用）。チームリンクのみを許可している場合を除き、リンクを知っている人なら誰でも開けます。

<IfAvailable integration="onedrive">

**OneDrive** は閲覧専用の共有リンクをエンコードします。リンクを知っている人なら誰でも開けますが、管理者が「Anyone」リンクを無効にしている場合は、組織内のユーザーのみが開けます。

</IfAvailable>

<IfAvailable integration="box">

**Box** は、「People with the link」に設定した項目の共有リンクをエンコードします。リンクを知っている人なら誰でも開けますが、管理者が必須にしている場合は、社内のユーザーのみが開けます。

</IfAvailable>

<IfAvailable integration="notion">

**Notion** はページの「Publish to web」リンクをエンコードします。ページを公開すると、誰でも開けるようになります。

</IfAvailable>

全員がリンクを開けるわけではない場合、選択した直後に QRdx が通知します。これにより、印刷したQRコードからサインインページに誘導してしまうことを防げます。

<IfAvailable integration="notion">

**Notion のページ。** QRdx から見えるのは、共有したページのみです。連携時に Notion がどのページを共有するかを尋ねます。後から追加するには、Notion でページを開き、**•••** → **Connections** をクリックして QRdx を追加します（または再連携してページを選びます）。Notion のAPIではページを公開できません。**Share** → **Publish** → **Publish to web** で自分で公開してから、もう一度ページを選ぶと、QRdx が公開リンクを使います。

</IfAvailable>

### ホスト型ページのファイル [#files-on-hosted-pages]

ホスト型ページでもクラウドのファイルを使えます。PDF、音声、動画、ダウンロードの各ブロックでは、連携済みのドライブが Dropbox のみの場合はアップロードボタンの横に **From Dropbox** ボタンが、複数連携している場合は **From cloud storage** ボタンが表示されます<IfAvailable integration="onedrive">（OneDrive を含む）</IfAvailable><IfAvailable integration="box">（Box を含む）</IfAvailable>。Dropbox<IfAvailable integration="box">と Box</IfAvailable>の場合、ページブロックにはファイルへの直接リンクが設定されるため、音声・動画プレーヤーやPDFビューアで読み込めます。<IfAvailable integration="onedrive"> OneDrive の共有リンクは OneDrive のビューアで開くため、ブロックではリンクとして表示されます。</IfAvailable>

## 連携の解除 [#disconnecting]

連携を解除すると、保存されたトークンが削除されます。Dropbox<IfAvailable integration="box">、Box</IfAvailable><IfAvailable integration="notion">、Notion</IfAvailable>では、QRdx がサービス側でもトークンを取り消します。Bitly、Rebrandly、Short.io では、今後使わない場合はそのサービスでもキーを削除してください<IfAvailable integration="onedrive">。OneDrive では、Microsoft アカウントのアプリのアクセス許可から QRdx を削除してください</IfAvailable>。

作成済みのQRコードはそのまま使えます。QRコードが保持しているのは短縮リンクまたは共有リンクで、トークンではないためです。

## 制限とプラン [#limits-and-plans]

連携アカウントには、それ自体のプラン制限はありません。作成されるリンクは、QRdx から見ると静的です。QRdx はそのスキャン数を計測できず、リンク先を変更することもできません。リンクに対してできることは、各サービス自体のプランによって決まります。

## セルフホスティング [#self-hosting]

Rebrandly と Short.io はサーバー側の設定が不要です。それ以外は、各サービスにアプリを作成し、そのクライアントIDとシークレットを環境変数に設定する必要があります。設定がない場合、本番環境では連携が非表示になります（ローカル開発では **Needs setup** バッジが表示されます）。Bitly は、設定がなくても貼り付けたアクセストークンで利用できます。

| 連携 | 変数 | リダイレクトURI |
| --- | --- | --- |
| Bitly（サインイン） | `BITLY_CLIENT_ID`, `BITLY_CLIENT_SECRET` | `<app url>/api/integrations/bitly/callback` |
| Dropbox | `DROPBOX_CLIENT_ID`, `DROPBOX_CLIENT_SECRET` | `<app url>/api/integrations/dropbox/callback` |
| OneDrive | `MICROSOFT_CLIENT_ID`, `MICROSOFT_CLIENT_SECRET` | `<app url>/api/integrations/onedrive/callback` |
| Box | `BOX_CLIENT_ID`, `BOX_CLIENT_SECRET` | `<app url>/api/integrations/box/callback` |
| Notion | `NOTION_CLIENT_ID`, `NOTION_CLIENT_SECRET` | `<app url>/api/integrations/notion/callback` |

`<app url>` は、開発環境では `http://localhost:3000`、それ以外では本番環境のURLです。また、すべての連携で、本番環境では `INTEGRATION_ENCRYPTION_KEY` が必要です。これは保存されたトークンとキーの暗号化に使われます。

リクエストするスコープ:

- **Dropbox:** `account_info.read`, `files.metadata.read`, `sharing.read`, `sharing.write`
- **OneDrive:** `offline_access`, `Files.ReadWrite`（共有リンクを作成するには、Microsoft Graph の書き込みアクセスが必要です）
- **Box:** すべてのファイルとフォルダの読み取りと書き込み（`root_readwrite`）
- **Bitly、Notion:** スコープなし。Notion では、共有するページをユーザーに尋ねます

[セルフホスティング](/docs/self-hosting#optional-services)をご覧ください。
