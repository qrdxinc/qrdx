读完本页，你将在 Vue 3 组件中得到一个带样式的二维码：它在服务端渲染，并能在水合时不出现不匹配，还有一个把它保存为 PNG 的按钮。`qrdx/vue` 提供了 React 组件 `QRCode` 和 `QRCodeSVG` 的 Vue 版本，以及一个 `useQRCode` 组合式函数。它们的 props 与 React 组件相同，绘制的 SVG 也相同。该入口基于 `qrdx/core` 构建，不会导入 `react`。

<NpmStatus package="qrdx" />

## 开始之前 [#before-you-start]

- 一个 Vue 3.3 或更高版本的项目，使用 Vite 或 Nuxt。从 Vue 3.4.20 起，TypeScript 会检查组件的 props。
- Node.js 18 或更高版本。

## 动手构建 [#build-it]

### 1. 安装 qrdx [#1-install-qrdx]

```package-install
qrdx
```

`vue` 是可选的对等依赖，因此会使用你应用自己的 Vue。

### 2. 绘制二维码 [#2-draw-a-code]

```vue title="src/App.vue"
<script setup lang="ts">
import { QRCode } from "qrdx/vue";
import { ref } from "vue";

const url = ref("https://example.com/menu");
</script>

<template>
  <QRCode
    :value="url"
    :size="256"
    :margin="4"
    body-pattern="rounded"
    :frame="{ style: 'banner-bottom', text: 'Scan for the menu' }"
    aria-label="QR code for the menu"
  />
</template>
```

页面会显示一个 256 px 的二维码，模块为圆角，下方有一个横幅。修改 `url` 后二维码会重新绘制，Vue 会原地更新 `<svg>`。

<Shot id="lib-framed-menu-code" />

`QRCode` 接受 React 版 `QRCode` 的 props：包括所有 `QRProps` 选项，以及用于设置 logo 的 `logo`、`logoOptions`、`hideLogo` 和 `scale`。在模板中，可以使用短横线命名（`body-pattern`）或驼峰命名。`auto-level` 或 `hide-logo` 这类标志无需赋值。`class`、`style`、`aria-label` 和其他属性会加在 `<svg>` 上；如果有边框，则加在边框的外层 `<svg>` 上，`@click` 这类监听器也一样。

### 3. 使用 useQRCode 保存为文件 [#3-save-it-as-a-file-with-useqrcode]

```vue title="src/components/DownloadCode.vue"
<script setup lang="ts">
import { useQRCode } from "qrdx/vue";
import { ref } from "vue";

const url = ref("https://example.com/menu");
const { svg, download } = useQRCode(() => ({
  value: url.value,
  size: 256,
  margin: 4,
  bodyPattern: "rounded",
}));
</script>

<template>
  <div v-html="svg" />
  <button type="button" @click="download({ format: 'png', size: 1024, filename: 'menu.png' })">
    Download PNG
  </button>
</template>
```

二维码根据它的标记显示，按钮会以 1024 px 保存 `menu.png`。`useQRCode(props)` 接受 `QRCode` 的 props，可以是对象、ref、响应式对象或 getter，并返回：

- `svg`：SVG 标记，是一个计算属性 ref。它会跟随 props 变化，在服务端渲染期间同样可用。
- `toDataURL(format, { size, quality })`：以 data URL 形式返回二维码。
- `download({ format, filename, size, quality })`：把二维码保存为文件。
- `options`：绘制二维码所用的选项，是一个计算属性 ref。

`toDataURL` 和 `download` 默认使用 PNG，尺寸为二维码自身的 `size`。支持的格式有 `png`、`jpg`、`webp`、`svg`、`pdf` 和 `eps`。PNG、JPG 和 WebP 需要浏览器环境，PDF 需要可选的 `jspdf` 包。

## QRCodeSVG 与原始图片设置 [#qrcodesvg-and-raw-image-settings]

`QRCodeSVG` 接受 `QRProps`，与 React 的 `QRCodeSVG` 相同。logo 通过 `imageSettings` 设置，单位为像素：

```vue title="src/components/LogoCode.vue"
<script setup lang="ts">
import { QRCodeSVG } from "qrdx/vue";
</script>

<template>
  <QRCodeSVG
    value="https://example.com"
    :size="256"
    level="H"
    :image-settings="{ src: '/logo.png', width: 48, height: 48, excavate: true }"
  />
</template>
```

除非要自行排布 logo，否则建议使用带 `logo` 和 `logoOptions` 的 `QRCode`。

## 服务端渲染与 Nuxt [#server-rendering-and-nuxt]

两个组件都可以用 Vue 的服务端渲染器（`vue/server-renderer`）渲染，因此二维码会成为服务端 HTML 的一部分。标记中没有随机 id，所以浏览器水合时不会出现不匹配。

在 Nuxt 中，可以在任意页面或组件里使用它们。它们在服务端渲染，并在浏览器中水合。放在 `<ClientOnly>` 内时，只会在浏览器中渲染。

## qrdx/core 的更多功能 [#more-from-qrdxcore]

`qrdx/vue` 会重新导出 `qrdx/core` 中的全部内容：`toSVGString`、`downloadQRCode`、`getQRCodeDataUrl`、`getScanScore`、官方边框库（`getOfficialFrame`）等。详见 [Vanilla JavaScript](/docs/vanilla-js)。如需在服务端生成 PNG，请使用 `qrdx/node` 中的 `getQRAsPNG`。

自定义模板的 `wrapper` 要用 `qrdx/vue` 导出的 `h` 来编写。它是核心库的 `h`，不是 Vue 的 `h`，因此当一个文件同时需要两者时，请给其中一个起别名导入：

```ts title="src/labelled-template.ts"
import { h } from "qrdx/vue";

export const Labelled = {
  id: "Labelled",
  name: "Labelled",
  wrapper: (children, props) =>
    h(
      "svg",
      { viewBox: "0 0 300 340", xmlns: "http://www.w3.org/2000/svg" },
      h("g", { transform: "translate(20, 20) scale(0.87)" }, children),
      h("text", { x: "150", y: "325", textAnchor: "middle" }, props?.label)
    ),
};
```

将它作为 `customTemplate` 传入，并通过 `customProps` 传入其 props：`<QRCode value="https://example.com" :custom-template="Labelled" :custom-props="{ label: 'Scan me' }" />`。

## 常见问题排查 [#if-something-goes-wrong]

- **`Failed to resolve component: QRCode`。** 该文件中没有导入此组件。请在其 `<script setup>` 中添加 `import { QRCode } from "qrdx/vue"`。
- **某个 prop 没有效果。** 你把本该传值的 prop 写成了字符串属性：`size="256"` 传入的是字符串，`:size="256"` 传入的才是数字。`frame` 和 `image-settings` 这类对象 props 始终需要加冒号。
- **`PDF export needs the optional "jspdf" package`。** 在应用中运行 `npm install jspdf`。
