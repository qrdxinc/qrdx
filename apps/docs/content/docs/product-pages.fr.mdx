Une page **Produit** est une [page hébergée](/docs/landing-pages) pour un code imprimé sur un emballage, une étiquette ou une étiquette volante. Elle contient ce que l'emballage n'a pas la place d'afficher : la liste complète des ingrédients, les allergènes, un tableau nutritionnel, les certifications, les consignes d'entretien et de recyclage. Comme toute page hébergée, vous pouvez la modifier après l'impression et voir chaque scan. Utilisez-la pour l'alimentaire, les boissons, les cosmétiques et tout ce qui nécessite un passeport produit.

<Callout type="info" title="Offres">
  Les pages produit comptent comme des pages hébergées, avec les mêmes [limites d'offre](/docs/plans-and-limits) que les autres types de pages. GS1 Digital Link nécessite un [domaine personnalisé](/docs/custom-domains), inclus dans Pro et Business.
</Callout>

Pressé ? Voici la page de tâche courte : [Créer une page mobile](/docs/help/pages-and-forms/create-a-page).

## Créer une page produit [#create-a-product-page]

1. Cliquez sur **Nouveau code** et choisissez **Produit**, ou sur **Nouvelle page** dans **Pages et formulaires**.
2. Choisissez un modèle :
   - **Alimentaire** : ingrédients, allergènes et tableau nutritionnel.
   - **Vins et boissons** : ingrédients et énergie pour 100 ml, une étiquette électronique pour une bouteille.
   - **Beauté et soins** : la liste complète des ingrédients, le mode d'emploi, les avertissements.
   - **Passeport produit** : matériaux, lieu de fabrication, entretien, réparation et fin de vie.
3. Remplacez le texte, les chiffres et la photo d'exemple par ceux de votre produit, puis cliquez sur **Publier**.

## Le bloc Détails du produit [#the-product-details-block]

| Élément | Ce qu'il affiche |
| --- | --- |
| Certifications et labels | Des mentions courtes comme « Certifié bio » ou « Emballage recyclable ». L'éditeur propose les plus courantes. N'indiquez que les labels que votre produit détient. |
| Ingrédients ou matériaux | Texte brut, sauts de ligne conservés |
| Allergènes | Les 14 allergènes que les entreprises alimentaires doivent déclarer dans l'UE et au Royaume-Uni, affichés sous la forme « Contient : … », avec une note telle que « Peut contenir des traces d'arachides » |
| Valeurs nutritionnelles | Un tableau : la base des valeurs (« Pour 100 g »), puis chaque nutriment et sa quantité. Les lignes peuvent être en retrait (« dont sucres »). Les lignes sans quantité sont masquées. |
| Plus d'informations | Des sections qui s'ouvrent au toucher : entretien, recyclage, avertissements, origine ou tout autre sujet |
| GTIN | Le numéro situé sous le code-barres du produit (8, 12, 13 ou 14 chiffres). QRdx vérifie sa clé de contrôle. Affiché sous les détails, sauf si vous le désactivez. |

Le bloc **Détails** (libellés et valeurs, sous forme de liste ou de tuiles) convient aux informations complémentaires : poids net, origine, teneur en alcool, taille.

<IfAvailable feature="customDomains" title="GS1 Digital Link">

[GS1 Digital Link](https://www.gs1.org/standards/gs1-digital-link) est la norme GS1 pour les QR codes sur les produits : le code contient une adresse web avec le GTIN du produit, par exemple `https://go.yourbrand.com/01/09506000134352`, de sorte qu'un même code puisse ouvrir votre page et porter le GTIN lu par un lecteur en caisse.

Lorsque le QR code d'une page produit utilise votre [domaine personnalisé](/docs/custom-domains) et que la page a un GTIN, cette adresse ouvre la page :

- `https://<your domain>/01/<GTIN>` ouvre la page produit et compte un scan de son code, exactement comme le lien court du code. Les contrôles du code (mot de passe, planification, limite de scans, pause) s'appliquent aussi.
- Une variante de produit grand public (`/22/<variant>`), un lot (`/10/<lot>`) et un numéro de série (`/21/<serial>`) peuvent suivre le GTIN, dans cet ordre, chacun jusqu'à 20 caractères. Ils sont acceptés, et la même page s'ouvre.
- Un GTIN avec une clé de contrôle incorrecte, ou des éléments dans le mauvais ordre, affiche « Ce lien produit n'est pas valide » au lieu d'une page.

Pour l'utiliser :

1. Déplacez le code de la page produit vers votre domaine personnalisé (**Modifier le lien** sur le code).
2. Saisissez le GTIN dans le bloc **Détails du produit** de la page et publiez. Le bloc affiche alors le GS1 Digital Link avec un bouton de copie.
3. Créez le QR code de votre emballage à partir de ce lien. Le lien court du code continue aussi de fonctionner.

Un GTIN ouvre une seule page produit par domaine. Si une autre page dont le code est sur le même domaine l'utilise déjà, la publication indique laquelle, afin que vous puissiez modifier l'une des deux.

### Uniquement sur votre propre domaine [#only-on-your-own-domain]

Sur l'adresse partagée de QRdx (`qrdx.dev`), les pages produit utilisent leur lien court habituel et les GTIN n'ouvrent jamais de page. Tout le monde peut créer un compte QRdx : une recherche de GTIN partagée permettrait à une personne de s'approprier le numéro de produit d'une autre marque. Sur votre propre domaine, seules les pages de votre espace de travail peuvent répondre.

## Limites et offres [#limits-and-plans]

| | Gratuit | Pro | Business |
| --- | --- | --- | --- |
| Pages produit | Dans la limite des 3 pages hébergées | Illimitées | Illimitées |
| GS1 Digital Link sur votre domaine | Non | Oui | Oui |

## Pour les développeurs [#for-developers]

Une page produit est une page hébergée : son code a donc `kind: "page"` dans la [REST API](/docs/developers/api/get-code). Le contenu de la page, GTIN compris, se modifie dans le tableau de bord.
