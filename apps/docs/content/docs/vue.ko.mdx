이 페이지를 끝까지 따라 하면 Vue 3 컴포넌트 안에 스타일이 적용된 QR 코드가 만들어집니다. 이 코드는 서버에서 렌더링되고 불일치 없이 하이드레이션되며, PNG로 저장하는 버튼도 함께 생깁니다. `qrdx/vue`에는 React 컴포넌트의 Vue 버전인 `QRCode`와 `QRCodeSVG`, 그리고 `useQRCode` 컴포저블이 들어 있습니다. React 컴포넌트와 같은 props를 받고 같은 SVG를 그립니다. 이 엔트리는 `qrdx/core`를 기반으로 만들어졌으며 `react`를 import하지 않습니다.

<NpmStatus package="qrdx" />

## 시작하기 전에 [#before-you-start]

- Vite 또는 Nuxt를 사용하는 Vue 3.3 이상 프로젝트가 필요합니다. TypeScript는 Vue 3.4.20부터 컴포넌트의 props를 검사합니다.
- Node.js 18 이상이 필요합니다.

## 만들어 보기 [#build-it]

### 1. qrdx 설치 [#1-install-qrdx]

```package-install
qrdx
```

`vue`는 선택적 peer dependency이므로 앱에서 사용하는 Vue가 그대로 쓰입니다.

### 2. 코드 그리기 [#2-draw-a-code]

```vue title="src/App.vue"
<script setup lang="ts">
import { QRCode } from "qrdx/vue";
import { ref } from "vue";

const url = ref("https://example.com/menu");
</script>

<template>
  <QRCode
    :value="url"
    :size="256"
    :margin="4"
    body-pattern="rounded"
    :frame="{ style: 'banner-bottom', text: 'Scan for the menu' }"
    aria-label="QR code for the menu"
  />
</template>
```

페이지에는 둥근 모듈로 이루어진 256 px 코드와 그 아래 배너가 표시됩니다. `url`을 바꾸면 코드가 다시 그려지며, Vue가 `<svg>`를 그 자리에서 업데이트합니다.

<Shot id="lib-framed-menu-code" />

`QRCode`는 React의 `QRCode`와 같은 props를 받습니다. 모든 `QRProps` 옵션과 더불어 로고용 `logo`, `logoOptions`, `hideLogo`, `scale`을 쓸 수 있습니다. 템플릿에서는 kebab-case(`body-pattern`)나 camelCase로 쓸 수 있습니다. `auto-level`이나 `hide-logo` 같은 플래그에는 값이 필요 없습니다. `class`, `style`, `aria-label` 등의 속성은 `<svg>`에 적용되고, 프레임이 있으면 프레임의 바깥쪽 `<svg>`에 적용됩니다. `@click` 같은 리스너도 마찬가지입니다.

### 3. useQRCode로 파일로 저장하기 [#3-save-it-as-a-file-with-useqrcode]

```vue title="src/components/DownloadCode.vue"
<script setup lang="ts">
import { useQRCode } from "qrdx/vue";
import { ref } from "vue";

const url = ref("https://example.com/menu");
const { svg, download } = useQRCode(() => ({
  value: url.value,
  size: 256,
  margin: 4,
  bodyPattern: "rounded",
}));
</script>

<template>
  <div v-html="svg" />
  <button type="button" @click="download({ format: 'png', size: 1024, filename: 'menu.png' })">
    Download PNG
  </button>
</template>
```

코드는 마크업으로 표시되고, 버튼을 누르면 `menu.png`가 1024 px로 저장됩니다. `useQRCode(props)`는 `QRCode`의 props를 객체, ref, reactive 객체, getter 중 어떤 형태로든 받으며 다음을 반환합니다.

- `svg`: computed ref로 제공되는 SVG 마크업입니다. props를 따라가며 서버 렌더링 중에도 동작합니다.
- `toDataURL(format, { size, quality })`: 코드를 data URL로 반환합니다.
- `download({ format, filename, size, quality })`: 코드를 파일로 저장합니다.
- `options`: 코드를 그리는 데 쓰이는 옵션이며 computed ref입니다.

`toDataURL`과 `download`의 기본값은 코드 자체의 `size`를 사용하는 PNG입니다. 사용할 수 있는 형식은 `png`, `jpg`, `webp`, `svg`, `pdf`, `eps`입니다. PNG, JPG, WebP는 브라우저가 필요하고, PDF는 선택 패키지인 `jspdf`가 필요합니다.

## QRCodeSVG와 원시 이미지 설정 [#qrcodesvg-and-raw-image-settings]

`QRCodeSVG`는 React의 `QRCodeSVG`처럼 `QRProps`를 받습니다. 로고는 `imageSettings`에 픽셀 단위로 지정합니다.

```vue title="src/components/LogoCode.vue"
<script setup lang="ts">
import { QRCodeSVG } from "qrdx/vue";
</script>

<template>
  <QRCodeSVG
    value="https://example.com"
    :size="256"
    level="H"
    :image-settings="{ src: '/logo.png', width: 48, height: 48, excavate: true }"
  />
</template>
```

로고 배치를 직접 하는 경우가 아니라면 `logo`와 `logoOptions`를 사용하는 `QRCode`를 권장합니다.

## 서버 렌더링과 Nuxt [#server-rendering-and-nuxt]

두 컴포넌트 모두 Vue의 서버 렌더러(`vue/server-renderer`)로 렌더링되므로 코드가 서버가 보내는 HTML에 포함됩니다. 마크업에 임의의 id가 없어서 브라우저에서 불일치 없이 하이드레이션됩니다.

Nuxt에서는 어떤 페이지나 컴포넌트에서든 사용할 수 있습니다. 서버에서 렌더링되고 브라우저에서 하이드레이션됩니다. `<ClientOnly>` 안에서는 브라우저에서만 렌더링됩니다.

## qrdx/core의 다른 기능 [#more-from-qrdxcore]

`qrdx/vue`는 `qrdx/core`의 모든 것을 다시 내보냅니다. `toSVGString`, `downloadQRCode`, `getQRCodeDataUrl`, `getScanScore`, 공식 프레임 라이브러리(`getOfficialFrame`) 등이 여기에 포함됩니다. 자세한 내용은 [Vanilla JavaScript](/docs/vanilla-js)에서 확인하세요. 서버에서 PNG가 필요하면 `qrdx/node`의 `getQRAsPNG`를 사용하세요.

커스텀 템플릿의 `wrapper`는 `qrdx/vue`가 내보내는 `h`로 작성합니다. 이는 Vue의 `h`가 아니라 core의 `h`이므로, 한 파일에서 둘 다 필요하면 하나를 다른 이름으로 import하세요.

```ts title="src/labelled-template.ts"
import { h } from "qrdx/vue";

export const Labelled = {
  id: "Labelled",
  name: "Labelled",
  wrapper: (children, props) =>
    h(
      "svg",
      { viewBox: "0 0 300 340", xmlns: "http://www.w3.org/2000/svg" },
      h("g", { transform: "translate(20, 20) scale(0.87)" }, children),
      h("text", { x: "150", y: "325", textAnchor: "middle" }, props?.label)
    ),
};
```

이를 `customTemplate`으로 전달하고, 해당 props는 `customProps`로 전달합니다. 예: `<QRCode value="https://example.com" :custom-template="Labelled" :custom-props="{ label: 'Scan me' }" />`

## 문제가 생겼다면 [#if-something-goes-wrong]

- **`Failed to resolve component: QRCode`.** 해당 파일에서 컴포넌트를 import하지 않았습니다. `<script setup>`에 `import { QRCode } from "qrdx/vue"`를 추가하세요.
- **prop이 적용되지 않아요.** 값이 필요한 곳에 속성 문자열로 작성했을 수 있습니다. `size="256"`은 문자열을, `:size="256"`은 숫자를 전달합니다. `frame`, `image-settings` 같은 객체 props에는 항상 콜론이 필요합니다.
- **`PDF export needs the optional "jspdf" package`.** 앱에서 `npm install jspdf`를 실행하세요.
