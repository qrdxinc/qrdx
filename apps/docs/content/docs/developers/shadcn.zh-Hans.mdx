QRdx 发布了一个 shadcn/ui registry,其中的二维码组件基于 `qrdx` 库构建。shadcn CLI 会把每个组件的源代码复制到你的项目中,因此代码归你所有,可以随意修改。如果你需要现成的界面组件,例如下载按钮、卡片、分享对话框或扫描器,请使用这个 registry;如果只需要二维码本身,请使用库自带的 `QRCode`。

<NpmStatus package="qrdx" />

<PackageManagerTabs command="npx shadcn@latest add https://qrdx.dev/r/qr-code.json" />

每个组件都有独立的页面,包含实时预览、源代码、安装步骤、示例和属性表。已经在 [Playground](/playground?open=code&lang=shadcn) 中设计好二维码样式?可以在那里复制 registry 中 QR Code 组件的代码。

## 会安装哪些内容 [#what-gets-installed]

每个组件都是 `components` 文件夹中的一个文件。CLI 还会安装 `qrdx`(以及大多数组件用于图标的 `lucide-react`),并添加该组件所依赖的 shadcn/ui 组件,例如 `button`、`card`、`dialog`、`dropdown-menu`、`input` 或 `label`。每个组件页面都会在安装标签页的 **Manual** 下列出它自己的依赖。

完整索引位于 [`https://qrdx.dev/r/registry.json`](https://qrdx.dev/r/registry.json),每个条目位于 `https://qrdx.dev/r/<name>.json`。

## 按名称安装 [#install-by-name]

如果想使用简短名称安装,请把该 registry 添加到你的 `components.json`:

```json title="components.json"
{
  "registries": {
    "@qrdx": "https://qrdx.dev/r/{name}.json"
  }
}
```

然后按名称添加一个或多个组件:

<PackageManagerTabs command="npx shadcn@latest add @qrdx/qr-code @qrdx/qr-code-download @qrdx/qr-code-share-dialog" />

## 样式与主题 [#styling-and-theming]

这些组件使用 Tailwind 类和标准的 shadcn/ui 主题令牌(`bg-card`、`border`、`text-muted-foreground`、`ring-ring`),并使用你自己的 Button、Card、Dialog 和 Input,因此会跟随你的主题和深色模式。二维码默认保持浅色背景,因为浅色底上的深色模块能被所有读码器扫描;如果想让二维码跟随主题,请参阅 [QR Code](/docs/components/qr-code#dark-mode) 页面。

每个组件都是 Client Component(文件以 `"use client"` 开头),因为它们包含按钮和状态。不过二维码本身仍在服务器端渲染,所以在按钮变为可交互之前,它就已经出现在页面的 HTML 中。Server Component 页面可以导入其中任何一个组件,并把服务器数据作为属性传入。

PDF 下载需要可选的 `jspdf` 包(`npm install jspdf`)。其余功能在 CLI 运行完成后即可使用。
