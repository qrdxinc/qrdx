このページを読み終えると、絵の中に QR コードが描き込まれた 1024 px の PNG を取得できるようになります。この画像は、お手元に届く前に QRdx がデコードして確認済みです。あわせて、固定テキストの代わりに動的QRコードをエンコードする方法、モードの選び方、各エラーの意味もわかります。

`POST https://api.qrdx.dev/v1/art` は、説明文から QR コードを AI アートの中に描き込み、画像を返します。Playground の Art タブやスタジオと同じ [AI QR アート](/ai/art)です。{facts.artModel} が絵を描き、QRdx がその画像をスキャンして内容どおりに読み取れることを確認してから、お手元に返します。モデルが描いた画像のままではスキャンできない場合、QRdx は必要な分だけコードを強調します。このときモデル自身のピクセルを使います。

<Callout type="info" title="API キーと月間画像数">
このエンドポイントには、`codes:write` スコープを持つ [API キー](/docs/developers/api-keys)が必要です（**Full access** キーには含まれています）。画像 1 枚につき、キーのワークスペースの月間 AI アート画像を 1 枚使います。これはアプリと同じ利用枠です。プランごとの数値は[プランと制限](/docs/plans-and-limits)をご覧ください。呼び出しが失敗した場合や、画像をスキャンできる状態にできなかった場合は、画像を消費しません。
</Callout>

## 始める前に [#before-you-start]

- `codes:write` を持つ API キー（`QRDX_API_KEY` としてエクスポートしてください）。
- タイムアウトが 60 秒以上の HTTP クライアント。1 回の呼び出しにかかる時間は、code モードで約 15〜45 秒、photo モードで約 25〜45 秒、scene モードで約 40〜55 秒です。scene モードは先に絵を描くためです。
- 動的コードの場合は、その `id`。[`GET /v1/codes`](/docs/developers/api/list-codes) または[作成時のレスポンス](/docs/developers/api/create-codes)から取得できます。

## 1. リンク用のコードを描く [#1-paint-a-code-for-a-link]

<Tabs groupId="language" persist items={["curl", "JavaScript", "Python"]}>

    ```bash title="Terminal"
    curl https://api.qrdx.dev/v1/art \
      -H "Authorization: Bearer $QRDX_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"text": "https://qrdx.dev", "prompt": "a koi pond at dusk, ink and watercolor"}' \
      --max-time 90 -o art.json
    ```
  </Tab>
  <Tab value="JavaScript">
    ```js title="art.mjs"
    import { writeFile } from "node:fs/promises";

    const response = await fetch("https://api.qrdx.dev/v1/art", {
      method: "POST",
      headers: {
        Authorization: `Bearer ${process.env.QRDX_API_KEY}`,
        "Content-Type": "application/json",
      },
      body: JSON.stringify({
        text: "https://qrdx.dev",
        prompt: "a koi pond at dusk, ink and watercolor",
      }),
      signal: AbortSignal.timeout(90_000),
    });
    const { data, credits } = await response.json();
    // data.imageUrl is a data: URL; save the PNG bytes
    const base64 = data.imageUrl.split(",")[1];
    await writeFile("art.png", Buffer.from(base64, "base64"));
    console.log(data.text, data.blend, credits.remaining);
    ```
  </Tab>
  <Tab value="Python">
    ```python title="art.py"
    import base64
    import os
    import requests

    response = requests.post(
        "https://api.qrdx.dev/v1/art",
        headers={"Authorization": f"Bearer {os.environ['QRDX_API_KEY']}"},
        json={"text": "https://qrdx.dev", "prompt": "a koi pond at dusk, ink and watercolor"},
        timeout=90,
    )
    response.raise_for_status()
    body = response.json()
    png = base64.b64decode(body["data"]["imageUrl"].split(",", 1)[1])
    open("art.png", "wb").write(png)
    print(body["data"]["text"], body["data"]["blend"], body["credits"]["remaining"])
    ```

レスポンスは JSON で、画像は `data:` URL として含まれます。

```json title="200 OK (fields)"
{
  "data": {
    "imageUrl": "data:image/png;base64,iVBORw0KGgo…",
    "width": 1024,
    "height": 1024,
    "seed": 2841337190,
    "mode": "code",
    "blend": "least",
    "blendStrength": 0.35,
    "text": "https://qrdx.dev",
    "visibility": 50,
    "creativity": 45
  },
  "credits": { "plan": "pro", "limit": 30, "used": 7, "remaining": 23, "pooled": false, "resetsAt": "2026-12-01T00:00:00.000Z" }
}
```

- `imageUrl` は、1024 px 四方の PNG を `data:` URL にしたものです。QRdx はコピーを保存しないため、必ず保存してください。
- `text` は、画像をスキャンしたときに読み取られる内容そのものです。QRdx は応答前にデコードして確認しています。
- `blend` は、画像をスキャンできるようにした方法を示します。`none`（モデルが描いたままの画像）、`least`（モデルの画像上で、ファインダーの四角、クワイエットゾーン、モジュールを必要な分だけ強調したもの）、`image-qr`（Image QR コードとして描き直したもの。最後の手段）のいずれかです。`blendStrength` は `0`（描いたまま）から `1`（Image QR）までの値です。
- `credits` は、この画像を生成した後のワークスペースの残り利用枠です。

JSON ではなく PNG そのものを取得するには、`?format=png` を追加するか、`Accept: image/png` を送信します。この場合、シード、モード、ブレンド、残りの画像数は、`X-QRdx-Seed`、`X-QRdx-Mode`、`X-QRdx-Blend`、`X-QRdx-Blend-Strength`、`X-QRdx-Credits-Remaining` ヘッダーで返されます。

```bash title="Terminal"
curl "https://api.qrdx.dev/v1/art?format=png" \
  -H "Authorization: Bearer $QRDX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"text": "https://qrdx.dev", "prompt": "a lighthouse on a cliff, woodcut print"}' \
  --max-time 90 -o art.png
```

## 2. 代わりに動的コードをエンコードする [#encode]

`text` と `code` のうち、ちょうど 1 つだけを送信してください。

- `text`：コードに含めるリンクまたはテキストです。最大 300 文字まで指定できます。アートは画像なので、印刷後に内容を変更することはできません。
- `code`：ワークスペース内の[動的QRコード](/docs/dynamic-qr-codes)の `id` です。アートにはそのコードの短縮リンクがエンコードされるため、印刷後でも転送先を変更でき、スキャン数は分析に表示されます。別のワークスペースのコードや、ゴミ箱にあるコードを指定すると `404` になります。

```bash title="Terminal"
curl https://api.qrdx.dev/v1/art \
  -H "Authorization: Bearer $QRDX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"code": "cm5code0spring0menu00001", "prompt": "a bistro chalkboard menu on a brick wall", "mode": "scene"}' \
  --max-time 90 -o art.json
```

この場合、レスポンスには `"code": { "id", "shortLink" }` も含まれ、`text` は短縮リンクになります。

## 3. モードとルックを選ぶ [#modes]

| `mode` | 得られるもの |
| --- | --- |
| `code`（デフォルト） | コード全体が絵になります。アートがモジュールの中に描き込まれ、ファインダーの四角は通常のまま、周囲には明るいクワイエットゾーンが付きます。最も確実にスキャンできます |
| `scene` | まず説明文から絵を描き、その中央にコードを描き込みます。絵がコードのすぐ際まで、さらにコードの中まで広がり、モジュールは絵の色と光でできています |
| `photo` | 手持ちの `photo` を絵として使う点以外は scene と同じです。被写体、色、光がコードの周囲と内部に残ります。写真はこのモードでのみ送信してください |

### クイックルック [#quick-looks]

クイックルックは、画材や雰囲気といった、あらかじめ用意されたスタイルです。QRdx がお客様の `prompt` に追加します。たとえば `"a koi pond in the rain"` に `"style": "watercolor"` を指定すると、鯉の泳ぐ池が水彩画で描かれます。`style` にはその id を送信してください。それ以外の値は `400 VALIDATION_ERROR` になります。ルックは [AI アートスタジオ](/ai/art)と Playground の Art タブにチップとして表示されるものと同じで、すべてのモードで使えます。

| `style` | ルック |
| --- | --- |
| `watercolor` | 水彩 |
| `oil-painting` | 油絵 |
| `anime` | アニメ |
| `cartoon` | カートゥーン |
| `pixel-art` | ドット絵 |
| `pop-art` | ポップアート |
| `charcoal` | 木炭画 |
| `ink` | インク画 |
| `cyberpunk` | サイバーパンク |
| `fantasy` | ファンタジー |
| `photographic` | 写真風 |
| `low-poly` | ローポリ |
| `papercut` | 切り絵 |

`prompt` は省略できます。省略すると、QRdx が送信された `mode`、`style`、`photo` に合わせて、まずプロンプトを作成します。被写体、場所、光を備えた具体的な 1 つのシーンを作ります。photo モードでは、アートが写真の内容を保てるように、写真に写っているものの説明を作ります。プロンプトの作成で、AI アート画像を追加で消費することはありません。このとき、作成された内容が `writtenPrompt` としてレスポンスに含まれるので、次回は編集して再送信できます。作成に失敗した場合は `502 AI_ART_DESCRIBE_FAILED` が返され、画像は消費されません。

## リクエストフィールド [#request-fields]

| フィールド | デフォルト | 説明 |
| --- | --- | --- |
| `text` | | コードにエンコードする内容。最大 300 文字。これか `code` のどちらかを送信します |
| `code` | | `text` の代わりに指定する、動的コードの `id` |
| `prompt` | 自動作成 | 描きたいアートを普通の言葉で記述します。送信する場合は 3 文字以上 |
| `mode` | `code` | `code`、`scene`、`photo` のいずれか。上記を参照してください |
| `style` | | クイックルックの id。プロンプトと組み合わされます |
| `negativePrompt` | | 絵に入れたくないもの |
| `visibility` | `50` | QR の見えやすさ（`0`〜`100`）。高いほどコードがはっきり見え、低いほど絵を優先します |
| `creativity` | `45` | `0` はプロンプトに忠実に従い、`100` は自由に解釈します |
| `seed` | ランダム | 以前のレスポンスのシードを送ると、似た画像になります |
| `reference` | | 色や形の参考にする画像（ロゴやパレットなど） |
| `photo` | | photo モードのみ。コードを描き込む対象の写真 |

`reference` と `photo` は、PNG または JPEG の `data:` URL（`data:image/jpeg;base64,…`）で指定します。`reference` は長辺を約 512 px（最大 600 KB）に縮小し、`photo` はアートが作られるサイズである約 1024 px の正方形（最大 1 MB）に切り抜いてください。これらはモデルに送られた後、破棄されます。QRdx が保存したり、ログに記録したりすることはありません。これより大きい画像は `413 AI_ART_IMAGE_TOO_LARGE` で拒否されます。完全なスキーマと Try it パネルは[リファレンスページ](/docs/developers/api/create-art)にあります。

## クレジットと制限 [#credits-and-limits]

API は、アプリと同じ月間 AI アート画像を、キーが属するワークスペースに対して消費します。フリー、Pro、Business にはそれぞれ月ごとの画像数が含まれており、Business ではチーム全体で共有されます。数値は[プランと制限](/docs/plans-and-limits)をご覧ください。画像数は毎月 1 日（UTC）にリセットされます。

- 月間の画像を使い切ると、API は `AI_ART_CREDITS_EXHAUSTED` を返します。フリーと Pro では `402` で、アップグレードすると枠が増えます。Business では `429` です。
- 月間の利用枠とは別に、1 人あたり 1 日に作成できる画像は最大 25 枚です（`429 AI_ART_DAILY_LIMIT`）。また、1 分あたり最大 12 枚まで開始できます。
- 各呼び出しは、ワークスペースの 1 日あたりの API クォータと、書き込みの 1 分あたりの制限にもカウントされます（[レート制限](/docs/developers/rest-api#rate-limits)）。

## 問題が発生した場合 [#if-something-goes-wrong]

エラーはAPI共通の形式(`code`、`message`、`status`)で返されます。すべてのエラーは[エラー](/docs/developers/errors)に一覧があります。`5xx`エラーでは、いずれも画像は使用されません。

| ステータス | `code` | 対処方法 |
| --- | --- | --- |
| 400 | `AI_ART_TEXT_TOO_LONG` | `text`を短くするか、動的QRコードの`code`を送信してください |
| 402 | `AI_ART_CREDITS_EXHAUSTED` | 毎月1日まで待つか、プランをアップグレードしてください |
| 413 | `AI_ART_IMAGE_TOO_LARGE` | `photo`または`reference`のサイズを小さくしてください |
| 429 | `AI_ART_CREDITS_EXHAUSTED` | Business:毎月1日まで待ってください |
| 429 | `AI_ART_DAILY_LIMIT` | 明日(UTC)にもう一度お試しください |
| 502 | `AI_ART_FAILED` | モデルが失敗したか、プロンプトを受け付けませんでした。もう一度試すか、表現を変えてください |
| 502 | `AI_ART_UNSCANNABLE` | `visibility`を上げるか、別のシードでもう一度お試しください |
| 502 | `AI_ART_DESCRIBE_FAILED` | `prompt`が送信されず、プロンプトの作成にも失敗しました。もう一度試すか、ご自身のプロンプトを送信してください |
| 503 | `AI_ART_BUSY` | モデルが混み合っています。1分ほど待ってからもう一度お試しください |
| 503 | `AI_NOT_CONFIGURED` | このサーバーではAIアートが設定されていません(セルフホスト) |
| 504 | `AI_ART_TIMEOUT` | モデルの処理に時間がかかりすぎました(シーンモードでは、画像の生成に時間がかかり、QRコードを描く時間が足りませんでした)。もう一度試すか、コードモードを使用してください |

Vercel AI Gatewayを使用していないセルフホスト環境では、すべての呼び出しに次の応答が返されます。

```json title="503 Service Unavailable"
{"code":"AI_NOT_CONFIGURED","message":"AI QR art is not configured on this server","status":503}
```

## MCP [#mcp]

接続にQRdxのAPIキーを設定すると、[MCPサーバー](/docs/developers/mcp)で`generate_ai_art`ツールを使用できます。このツールはリクエストボディと同じフィールドを受け取り、PNG、スキャン先、今月の残り画像数を返します。アシスタントには普通の言葉で依頼できます。

```txt title="Prompt"
Make AI QR art for my code cm5code0spring0menu00001: a bistro chalkboard menu on a brick wall, as a scene.
```

キーがない場合、ツールは追加方法を案内します。呼び出しにはREST APIと同様に最大1分かかります。

## セルフホスト [#self-hosting]

AIアートはVercel AI Gateway経由で動作します。ご自身のインスタンスでは`AI_GATEWAY_API_KEY`を設定してください。設定しない場合、`POST /v1/art`と`generate_ai_art`は`503 AI_NOT_CONFIGURED`を返します。
