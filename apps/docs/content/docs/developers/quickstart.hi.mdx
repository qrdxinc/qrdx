इस पेज के अंत तक आपके पास एक request से सेव की हुई QR code इमेज होगी, आपके workspace की API key होगी, एक डायनेमिक QR कोड होगा जिसका प्रिंट किया हुआ QR तब भी काम करता रहेगा जब आप बदल दें कि वह लोगों को कहाँ भेजता है, और उसके स्कैन analytics की पहली झलक होगी।

API के दो हिस्से हैं। इमेज के लिए कुछ नहीं चाहिए: न अकाउंट, न key। डायनेमिक QR कोड, स्कैन और webhooks किसी workspace के होते हैं, इसलिए उनके लिए API key चाहिए।

## शुरू करने से पहले [#before-you-start]

- curl, Node.js 18 या उससे नया, या `requests` पैकेज के साथ Python 3। जो आप इस्तेमाल करते हैं उसका टैब चुनें; आपका चुनाव सभी पेजों पर बना रहता है।
- स्टेप 2 से 4 के लिए एक QRdx अकाउंट। फ़्री अकाउंट काफ़ी है: फ़्री workspace में 10 सक्रिय डायनेमिक QR कोड और रोज़ 1,000 API requests मिलते हैं।

## 1. QR code इमेज बनाएँ (बिना key) [#1-make-a-qr-code-image-no-key]

इसे चलाएँ। यह एक QR code का PNG सेव करता है जो qrdx.dev खोलता है।

<Tabs groupId="language" persist items={["curl", "JavaScript", "Python"]}>
  <Tab value="curl">
    ```bash title="Terminal"
    curl "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=png" -o qr.png
    ```
  </Tab>
  <Tab value="JavaScript">
    ```js title="qr.mjs"
    // Node 18 or later
    import { writeFile } from "node:fs/promises";

    const url = new URL("https://api.qrdx.dev/v1/qr");
    url.searchParams.set("data", "https://qrdx.dev");
    url.searchParams.set("format", "png");

    const response = await fetch(url);
    await writeFile("qr.png", Buffer.from(await response.arrayBuffer()));
    console.log(response.status, response.headers.get("content-type"));
    ```
  </Tab>
  <Tab value="Python">
    ```python title="qr.py"
    # pip install requests
    import requests

    response = requests.get(
        "https://api.qrdx.dev/v1/qr",
        params={"data": "https://qrdx.dev", "format": "png"},
    )
    response.raise_for_status()
    open("qr.png", "wb").write(response.content)
    print(response.status_code, response.headers["content-type"])
    ```
  </Tab>
</Tabs>

```txt title="Output"
200 image/png
qr.png: PNG image data, 512 x 512, 8-bit/color RGBA, non-interlaced
```

यह एक काम करने वाली API call है। URL खुद ही इमेज है, इसलिए यह सीधे `<img>` टैग में भी काम करता है:

```html title="index.html"
<img src="https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&fg=111111&body=circle" alt="QR code for qrdx.dev" />
```

रंग, शेप, साइज़ और फ़ॉर्मेट query parameters से बदलें, या ब्राउज़र में [QR code इमेज रेंडर करें](/docs/developers/api/get-qr-image) पेज पर आज़माएँ: उसका **Try it** पैनल request भेजता है और इमेज दिखाता है। इमेज किसी भी quota में गिनी नहीं जातीं; सीमा हर IP address पर {facts.imageApiPerMinute} requests प्रति मिनट है।

## 2. API key बनाएँ [#create-an-api-key]

API में बाकी सब कुछ किसी workspace पर काम करता है: डायनेमिक QR कोड बनाना, उनकी destination बदलना, उनके स्कैन पढ़ना। इन requests में `Authorization` header में API key जाती है।

1. [Settings → API keys & apps](/dashboard?to=settings/developers&new=1) खोलें, ज़रूरत हो तो पहले साइन इन करें। **Create API key** फ़ॉर्म खुलता है।
2. key को कोई नाम दें, जैसे उस सर्वर का नाम जिस पर वह चलेगी, **Full access** रहने दें और **Create key** चुनें। QRdx पहले आपसे पुष्टि करने को कह सकता है कि यह आप ही हैं।
3. **Copy your API key** डायलॉग से key कॉपी करें। यह सिर्फ़ इसी बार दिखती है: QRdx उसका hash सेव करता है और उसे दोबारा नहीं दिखा सकता। अगर आप चाहें तो डायलॉग में एक curl request भी दिखती है, जिसमें आपकी key भरी हुई है और जो डायनेमिक QR कोड बनाती है; उसे पेस्ट कर सकते हैं।

<Shot id="create-key-dialog" />

<Shot id="api-key-copy-dialog" />

अगले स्टेप्स के लिए key को export करें:

```bash title="Terminal"
export QRDX_API_KEY=qrdx_...
```

key उसी workspace में आपकी तरह काम करती है जो उसे बनाते समय खुला था, और उससे की गई requests उस workspace के दैनिक quota में गिनी जाती हैं। [API keys](/docs/developers/api-keys) में scopes, टीमें, expiry और revoke करने की जानकारी है।

## 3. डायनेमिक QR कोड बनाएँ [#3-create-a-dynamic-code]

डायनेमिक QR कोड एक छोटा link होता है जिसे प्रिंट होने के बाद भी आप कहीं और पॉइंट कर सकते हैं:

<Tabs groupId="language" persist items={["curl", "JavaScript", "Python"]}>
  <Tab value="curl">
    ```bash title="Terminal"
    curl -X POST https://api.qrdx.dev/v1/codes \
      -H "Authorization: Bearer $QRDX_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"destinationUrl": "https://example.com", "title": "My first code"}'
    ```
  </Tab>
  <Tab value="JavaScript">
    ```js title="create.mjs"
    const response = await fetch("https://api.qrdx.dev/v1/codes", {
      method: "POST",
      headers: {
        Authorization: `Bearer ${process.env.QRDX_API_KEY}`,
        "Content-Type": "application/json",
      },
      body: JSON.stringify({
        destinationUrl: "https://example.com",
        title: "My first code",
      }),
    });
    const { data: code } = await response.json();
    console.log(response.status, code.id, code.shortLink);
    ```
  </Tab>
  <Tab value="Python">
    ```python title="create.py"
    import os
    import requests

    response = requests.post(
        "https://api.qrdx.dev/v1/codes",
        headers={"Authorization": f"Bearer {os.environ['QRDX_API_KEY']}"},
        json={"destinationUrl": "https://example.com", "title": "My first code"},
    )
    response.raise_for_status()
    code = response.json()["data"]
    print(response.status_code, code["id"], code["shortLink"])
    ```
  </Tab>
</Tabs>

Response `201 Created` होता है, जिसमें नया कोड होता है:

```json title="201 Created"
{
  "data": {
    "id": "cmwgwq0t80000iscg4ybn05kh",
    "slug": "l0q9fZn",
    "shortLink": "https://qrdx.dev/q/l0q9fZn",
    "defaultShortLink": "https://qrdx.dev/q/l0q9fZn",
    "nfcLink": "https://qrdx.dev/q/l0q9fZn?nfc",
    "domain": null,
    "destinationUrl": "https://example.com/",
    "title": "My first code",
    "contentType": "url",
    "kind": "redirect",
    "pageId": null,
    "status": "active",
    "style": null,
    "scanCount": 0,
    "lastScannedAt": null,
    "archivedAt": null,
    "createdAt": "2026-11-14T21:17:45.512Z",
    "updatedAt": "2026-11-14T21:17:45.512Z",
    "organizationId": "ws_ad2c5e1cce31ccf31535e78f08ab5b78",
    "preciseLocation": false
  }
}
```

अभी दो फ़ील्ड मायने रखते हैं। `shortLink` वही है जो QR code में encode होता है: उसे स्टेप 1 की इमेज API से रेंडर करें, `https://api.qrdx.dev/v1/qr?data=https://qrdx.dev/q/l0q9fZn&format=png`, और वही प्रिंट करें। `id` से आप आगे उस कोड को पहचानेंगे, इसलिए उसे संभालकर रखें:

```bash title="Terminal"
export CODE_ID=cmwgwq0t80000iscg4ybn05kh
```

[कोड बनाएँ](/docs/developers/api/create-codes) में वे सभी फ़ील्ड हैं जो आप भेज सकते हैं, जिनमें कस्टम back-half और डिज़ाइन भी शामिल हैं।

## 4. उसे कहीं और पॉइंट करें [#4-point-it-somewhere-else]

destination कभी भी बदलें; प्रिंट किया हुआ कोड काम करता रहता है:

```bash title="Terminal"
curl -X PATCH https://api.qrdx.dev/v1/codes/$CODE_ID \
  -H "Authorization: Bearer $QRDX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"destinationUrl": "https://example.com/new-page"}'
```

`200 OK` response वही कोड होता है जिसमें `"destinationUrl": "https://example.com/new-page"` और नया `updatedAt` होता है। कोड को अपने फ़ोन से स्कैन करें, फिर उसके analytics पढ़ें:

```bash title="Terminal"
curl "https://api.qrdx.dev/v1/codes/$CODE_ID/scans?range=7d" \
  -H "Authorization: Bearer $QRDX_API_KEY"
```

```json title="200 OK (before the first scan, trimmed)"
{
  "data": {
    "codeId": "cmwgwq0t80000iscg4ybn05kh",
    "range": "7d",
    "retentionDays": 365,
    "days": 7,
    "total": 0,
    "unique": 0,
    "interval": "day",
    "series": [{ "date": "2026-11-08", "count": 0 }, { "date": "2026-11-09", "count": 0 }],
    "countries": [],
    "devices": [],
    "sources": { "qr": 0, "nfc": 0 }
  }
}
```

स्कैन के बाद `total` बढ़ जाता है और `countries`, `cities`, `devices`, `os` और `browsers` भर जाते हैं। [स्कैन analytics पाएँ](/docs/developers/api/get-code-scans) में ranges और अलग-अलग स्कैन को पेज दर पेज देखने का तरीका समझाया गया है।

## कुछ गड़बड़ हो जाए तो [#if-something-goes-wrong]

हर error JSON होता है, जिसमें स्थिर `code` और एक संदेश होता है जो बताता है कि क्या करना है। इस पेज पर जो दो सबसे ज़्यादा मिल सकते हैं:

```json title="401 Unauthorized: the header is missing"
{
  "code": "UNAUTHORIZED",
  "message": "Missing API key. Send an API key as \"Authorization: Bearer <key>\"; create one at https://qrdx.dev/dashboard?to=settings/developers. OAuth access tokens go in the same header.",
  "status": 401,
  "docs": "https://qrdx.dev/docs/developers/api-keys"
}
```

```json title="400 Bad Request: the destination isn't a full URL"
{
  "code": "VALIDATION_ERROR",
  "message": "Invalid request body",
  "data": { "details": [{ "path": "destinationUrl", "message": "Enter a full URL, starting with https://" }] },
  "status": 400
}
```

`401 INVALID_TOKEN` का मतलब है कि key अधूरी कॉपी हुई, revoke हो गई या expire हो गई: नई बनाएँ। `403 INSUFFICIENT_SCOPE` का मतलब है कि आपने **Read only** key बनाई थी; स्टेप 3 के लिए `codes:write` चाहिए। [errors पेज](/docs/developers/errors) पर हर code उसके समाधान के साथ दिया है।

## दूसरे लोगों की ओर से काम करना [#get-an-access-token]

API key आपकी तरह काम करती है। अगर आपका प्रोडक्ट दूसरे लोगों के लिए QRdx को call करता है, तो इसके बजाय एक OAuth app रजिस्टर करें: हर व्यक्ति उसे एक बार मंज़ूरी देता है, और आपके सर्वर को उनके अकाउंट का access token मिलता है, जो उसी `Authorization: Bearer` header में भेजा जाता है। ऊपर की हर request key की जगह token के साथ बिना बदलाव के काम करती है। देखें [REST API और OAuth](/docs/developers/rest-api#get-an-access-token) और [इंटीग्रेशन बनाएँ](/docs/developers/build-an-integration)।
