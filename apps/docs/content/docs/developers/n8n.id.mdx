Setelah mengikuti halaman ini, sebuah alur kerja n8n dapat membuat gambar kode QR, membuat dan mengedit kode dinamis di workspace Anda, serta membaca data pemindaiannya. Alur kerja kedua dimulai setiap kali sebuah kode dipindai, dibuat, atau diubah, atau setiap kali ada formulir yang dikirim.

Paket `@qrdx/n8n-nodes-qrdx` menambahkan dua node ke [n8n](https://n8n.io):

- **QRdx** membuat gambar kode QR, membuat dan mengedit [kode QR dinamis](/docs/dynamic-qr-codes), serta membaca data pemindaian dan tema yang Anda simpan. AI Agent n8n dapat memakainya sebagai tool.
- **QRdx Trigger** memulai alur kerja saat kode Anda dipindai, dibuat, atau diubah, atau saat seseorang mengirim formulir di [halaman yang di-hosting](/docs/forms-and-pages).

<Callout type="info" title="n8n self-hosted">
Paket ini tersedia di npm sebagai [`@qrdx/n8n-nodes-qrdx`](https://www.npmjs.com/package/@qrdx/n8n-nodes-qrdx) dan diinstal pada n8n self-hosted. n8n Cloud hanya menjalankan node komunitas yang sudah diverifikasi n8n, dan node ini belum diverifikasi. Untuk menerima event di n8n Cloud, gunakan [node Webhook](#without-the-package).
</Callout>

## Sebelum Anda mulai [#before-you-start]

- n8n self-hosted tempat Anda dapat menginstal node komunitas.
- [Kunci API](/docs/developers/api-keys) dari workspace tempat node akan bekerja, untuk operasi kode, pemindaian, dan tema serta untuk trigger. Membuat gambar QR tidak memerlukan kunci.
- Untuk trigger: paket Business, karena [webhook](/docs/webhooks) termasuk di dalamnya, dan n8n yang dapat dijangkau melalui alamat `https://` publik.

## 1. Instal node [#1-install-the-nodes]

Di n8n, buka **Settings → Community Nodes**, pilih **Install**, masukkan `@qrdx/n8n-nodes-qrdx`, setujui catatan tentang node komunitas, lalu pilih **Install**. Setelah itu cari **QRdx** di panel node.

Jika n8n Anda menyembunyikan halaman tersebut, atau Anda mengelolanya lewat command line, instal paket di folder `nodes` pada folder pengguna n8n, lalu mulai ulang n8n:

```bash title="Terminal"
mkdir -p ~/.n8n/nodes
cd ~/.n8n/nodes
npm install @qrdx/n8n-nodes-qrdx
```

Jika n8n berjalan di Docker, jalankan perintah yang sama di dalam container (`docker exec -it n8n sh`) atau siapkan di image Anda.

## 2. Hubungkan workspace Anda [#2-connect-your-workspace]

Buat [kunci API](/docs/developers/api-keys) di [Settings → API keys & apps](/dashboard?to=settings/developers), lalu tambahkan kredensial **QRdx API** di n8n dengan kunci tersebut. Biarkan **Base URL** tetap `https://api.qrdx.dev/v1` kecuali Anda [meng-host sendiri](/docs/self-hosting) QRdx; dalam hal itu, gunakan alamat Anda diikuti `/api/v1`.

n8n menguji kredensial dengan membaca profil Anda, yang memerlukan scope `profile:read`, jadi kunci **Full access** adalah yang paling mudah. Kunci bekerja pada workspace tempat kunci itu dibuat.

## 3. Gunakan node QRdx [#3-use-the-qrdx-node]

| Resource | Operasi |
| --- | --- |
| **QR Image** | **Generate** gambar PNG, WebP, SVG, atau EPS. Tanpa kunci API, tanpa akun |
| **Code** | **Create**, **Get**, **Get Many**, **Update** (termasuk arsipkan dan pulihkan), **Delete** |
| **Scan** | **Get Many** (pemindaian individual, terbaru lebih dulu), **Get Summary** (total, jumlah harian, serta negara, kota, perangkat, browser, dan referrer teratas) |
| **Theme** | **Get**, **Get Many** |

**Generate** menaruh gambar di field biner yang bisa Anda lampirkan ke email atau unggah ke mana saja. Anda dapat mengatur ukuran, warna, bentuk body, eye, dan eye dot, koreksi kesalahan, margin, [bingkai](/docs/features/frames) beserta labelnya, dan ikon logo. Output juga berisi `url`: tautan ke gambar yang sama dari [Image API](/docs/developers/image-api), siap dipakai di tag `<img>`.

Operasi kode dan pemindaian memanggil [REST API](/docs/developers/rest-api) dengan kunci Anda dan dihitung dalam kuota API harian workspace. **Get Many** menelusuri halaman hasil untuk Anda. **Create** menerima URL tujuan, dan pada field tambahan berupa judul, back-half kustom (`slug`), dan domain kustom; **Update** menerima field yang sama ditambah arsipkan dan pulihkan. Galat tetap menampilkan pesan asli QRdx: misalnya, back-half kustom memerlukan Pro atau Business, dan di paket Gratis node menampilkan [galat](/docs/developers/errors) `PLAN_REQUIRED` dari API.

## 4. Mulai alur kerja dari event [#4-start-workflows-from-events]

Tambahkan node **QRdx Trigger**, pilih **Events**, lalu aktifkan alur kerja. Node berlangganan melalui [REST Hooks API](/docs/webhooks#zapier-make-and-n8n-rest-hooks) dan berhenti berlangganan saat Anda menonaktifkan alur kerja. Langganan tampil di **Settings → Webhooks** selama aktif.

| Event | Kapan |
| --- | --- |
| **Scans** | Kode dipindai. Pengiriman dikelompokkan: satu per menit dengan hingga 100 pemindaian beserta jumlah pastinya |
| **Scan Milestones** | Pemindaian pertama sebuah kode, lalu 10, 100, 500, 1.000 pemindaian dan seterusnya |
| **New Codes** | Kode QR dinamis dibuat |
| **Code Changes** | Tujuan, judul, desain, atau domain sebuah kode berubah |
| **Form Submissions** | Seseorang mengirim formulir di halaman yang di-hosting |

Node memeriksa `X-QRdx-Signature` pada setiap pengiriman dengan signing secret yang diberikan QRdx saat berlangganan, dan membalas `401` untuk apa pun yang tidak cocok. Di bawah **Options**, aktifkan **Output One Item per Scan** untuk mendapatkan batch Scans sebagai item terpisah, dan **Include Test Events** untuk menjalankan alur kerja saat Anda memilih **Send test** di **Settings → Webhooks**. Payload-nya sama dengan yang dijelaskan di [Webhook](/docs/webhooks#payloads).

Trigger memerlukan:

- paket Business, karena [webhook](/docs/webhooks) termasuk di dalamnya;
- kunci API dengan `codes:write` (**Full access**);
- n8n di alamat `https://` publik, karena QRdx tidak mengirim ke `localhost` atau jaringan privat. Jika berada di belakang proxy, atur `WEBHOOK_URL` n8n. Ini juga berlaku untuk URL pengujian yang dipakai n8n saat Anda memilih **Listen for test event**.

## Without the package [#without-the-package]

QRdx dapat mengirim event langsung ke node **Webhook** n8n, baik di n8n Cloud maupun n8n self-hosted:

1. Tambahkan node Webhook, atur metode HTTP ke `POST`, dan salin URL produksinya.
2. Aktifkan alur kerja. URL produksi hanya menjawab saat alur kerja aktif.
3. Di [Settings → Webhooks](/dashboard?to=settings/webhooks), pilih **Add endpoint**, tempel URL, dan pilih event-nya.

Setiap event memulai alur kerja dengan payload JSON. Untuk memeriksa tanda tangan, baca `X-QRdx-Signature` di node Code dan [verifikasi](/docs/webhooks#verify-signatures) dengan signing secret endpoint.

## Jika terjadi masalah [#if-something-goes-wrong]

### Uji kredensial gagal [#the-credential-test-fails]

Kunci tidak memiliki `profile:read` (kunci **Custom** tanpa scope itu), sudah dicabut atau kedaluwarsa, atau **Base URL** mengarah ke host yang salah. Kunci **Full access** dengan `https://api.qrdx.dev/v1` akan lolos.

### Trigger tidak mau aktif, atau `402 PLAN_REQUIRED` [#the-trigger-wont-activate-or-402-plan_required]

Webhook termasuk dalam paket Business. Upgrade workspace, atau gunakan node Webhook dan peringatan email dari [Notifikasi](/docs/notifications).

### Trigger aktif tetapi tidak ada yang masuk [#the-trigger-activates-but-nothing-arrives]

QRdx tidak dapat menjangkau n8n: QRdx menolak `http://`, `localhost`, dan alamat privat, serta tidak mengikuti pengalihan. Letakkan n8n di balik nama host `https://` publik dan atur `WEBHOOK_URL`. Lalu periksa pengiriman langganan di **Settings → Webhooks**.

### `PLAN_REQUIRED` saat Create [#plan_required-on-create]

Back-half kustom atau domain kustom memerlukan Pro atau Business. Kosongkan field tersebut di paket Gratis.
