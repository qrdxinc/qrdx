このページを読み終えると、README、`<img>` タグ、メールテンプレートに貼り付けられる、好みのスタイルのQRコード画像URLが手に入ります。また、APIが何を拒否するのか、その理由も分かります。

`GET https://api.qrdx.dev/v1/qr` は、QRコードをSVG、PNG、WebPの画像として、または印刷やデザインツール向けのベクターEPSファイルとして返します。すべてクエリ文字列で指定するので、URLそのものが画像になります。グラデーション、フレーム（カスタムフレームを含む）、枠線、アイと点の色、ロゴアイコンなど、エディターのスタイルも使えます。QRdxにアップロードしたロゴを除き、アカウントもAPIキーも不要です（[ロゴ](#logos)を参照）。

```md title="README.md"
![QR code](https://api.qrdx.dev/v1/qr?data=https://github.com/you/repo)
```

[Playgroundで試す](/playground?open=code&lang=image)：そこでコードのスタイルを整えて、画像URLをコピーできます。または、リファレンスページの[QRコード画像を生成する](/docs/developers/api/get-qr-image)からリクエストを送信できます。

## 1. 画像をリクエストする [#1-request-an-image]

<Tabs groupId="language" persist items={["curl", "JavaScript", "Python"]}>
  <Tab value="curl">
    ```bash title="Terminal"
    curl -o qr.png "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=png&size=1024"
    ```
  </Tab>
  <Tab value="JavaScript">
    ```js title="qr.mjs"
    import { writeFile } from "node:fs/promises";

    const url = new URL("https://api.qrdx.dev/v1/qr");
    url.searchParams.set("data", "https://qrdx.dev");
    url.searchParams.set("format", "png");
    url.searchParams.set("size", "1024");

    const response = await fetch(url);
    await writeFile("qr.png", Buffer.from(await response.arrayBuffer()));
    ```
  </Tab>
  <Tab value="Python">
    ```python title="qr.py"
    import requests

    response = requests.get(
        "https://api.qrdx.dev/v1/qr",
        params={"data": "https://qrdx.dev", "format": "png", "size": 1024},
    )
    response.raise_for_status()
    open("qr.png", "wb").write(response.content)
    ```
  </Tab>
</Tabs>

```txt title="Output"
qr.png: PNG image data, 1024 x 1024, 8-bit/color RGBA, non-interlaced
```

シェルでは、`&` が残るようにURLを引用符で囲んでください。HTMLページでは、URLをそのまま `src` に指定します。

```html title="index.html"
<img
  src="https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&size=256&fg=155dfc"
  width="256"
  height="256"
  alt="QR code for qrdx.dev"
/>
```

## 2. 形式を選ぶ [#2-pick-a-format]

| `format` | 返されるもの | 用途 |
| --- | --- | --- |
| `svg`（デフォルト） | `image/svg+xml` | Webページや、拡大縮小するもの全般 |
| `png` | `image/png` | メール、チャットアプリ、ドキュメント |
| `webp` | `image/webp`、可逆圧縮、透過を保持 | Webサイト：PNGと同じピクセルをより小さいファイルで |
| `eps` | `application/postscript`、`qr-code.eps` としてダウンロード | Illustrator、InDesign、印刷会社。この場合 `size` はポイント単位の幅（1インチあたり72）で、`144` は2インチです |

```bash title="Terminal"
curl -o qr.webp "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=webp&size=1024"
curl -o qr.eps "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=eps&size=144"
head -2 qr.eps
# %!PS-Adobe-3.0 EPSF-3.0
# %%BoundingBox: 0 0 144 144
```

## 3. スタイルを設定する [#3-style-it]

フラットなパラメーターで、色、形状、フレーム、ロゴを指定できます。

```txt title="Rounded modules with a frame drawn as a template"
https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&body=rounded&eye=rounded&dot=rounded&template=Arrow
```

```txt title="A built-in frame with its label, and a community frame by id"
https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&frame=banner-bottom&frameText=Scan%20the%20menu
https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&item=frame:wifi-card
```

グラデーション、カスタムフレーム、アイごとの色を使う場合は、デザイン全体をJSONにして `style` で送信します。

```js title="styled.mjs"
const style = {
  fgColor: {
    type: "linear",
    angle: 45,
    stops: [
      { color: "#1d4ed8", offset: 0 },
      { color: "#7c3aed", offset: 100 },
    ],
  },
  eyeColor: "#b91c1c",
  frame: { style: "banner-bottom", text: "Scan the menu" },
};
const src = `https://api.qrdx.dev/v1/qr?data=${encodeURIComponent(link)}&style=${encodeURIComponent(JSON.stringify(style))}`;
// 200 image/svg+xml, 634.88 × 727.04: the frame adds to the 512 px code
```

<Callout type="info">
`data` の値に `&`、`#`、`+`、スペースが含まれる場合はエンコードしてください（JavaScriptなら `encodeURIComponent` など）。そうしないと、URLがその文字で分割されてしまいます。`style` も同様にエンコードし、色は `#` を付けずに（または `%23` で）書いてください。そのままの `#` はURLフラグメントの開始と見なされ、送信されません。
</Callout>

## パラメーター [#parameters]

| パラメーター | デフォルト | 説明 |
| --- | --- | --- |
| `data` | 必須 | エンコードするテキストまたはURL（最大2048文字） |
| `format` | `svg` | `svg`、`png`、`webp`、`eps` |
| `size` | `512` | 幅と高さ（ピクセル）、`64` ～ `2048`（EPSではポイント） |
| `fg` | `000000` | モジュールの色（16進数。`155dfc`、`fff`、またはアルファ付きの8桁） |
| `bg` | `ffffff` | 背景色（16進数）。`00000000` で背景が透明になります |
| `eyeColor` | `fg` | 3つのコーナーアイの色 |
| `dotColor` | `fg` | 各コーナーアイの内側にある点の色 |
| `body` | `square` | データモジュールの形状。[パターン値](#pattern-values)を参照 |
| `eye` | `square` | コーナーアイの枠の形状 |
| `dot` | `square` | 各コーナーアイの内側にある点の形状 |
| `level` | `Q` | 誤り訂正：`L`（約7%）、`M`（15%）、`Q`（25%）、`H`（30%） |
| `margin` | `4` | コードの周囲の余白（クワイエットゾーン）、モジュール単位で `0` ～ `16` |
| `template` | なし | [テンプレートとして描画されたフレーム](/docs/features/templates)：画像全体の幅が `size` になり、コードはその内側で小さくなります |
| `frame` | なし | `banner-bottom`、`speech-bubble`、`circle` など、組み込みの行動喚起[フレーム](/docs/features/frames)。{facts.frameStyles} 種類の組み込みフレームのいずれかを指定できます |
| `frameText` | `Scan me` | フレームのラベル（最大24文字）。`style` や `item` のフレームのラベルも書き換えます |
| `style` | なし | エディターのデザイン全体をJSONで指定。[スタイル](#style)を参照 |
| `item` | なし | `frame:wifi-card` のように、IDで指定するコミュニティのフレームまたはテーマ。[コミュニティアイテム](#community-items)を参照 |
| `logoIcon` | なし | 中央に配置するクイックアイコンまたはブランドロゴ。[ロゴ](#logos)を参照 |
| `logoFileId` | なし | アップロードしたロゴのファイルID。APIキーが必要です。[ロゴ](#logos)を参照 |

列挙値（`level`、`format`、`template`、`frame`）は大文字と小文字を区別しません。フレームを使う場合、`size` はコード自体の幅で、どの形式でもフレーム分だけ画像が大きくなります。フラットなパラメーターは `style` より優先され、`style` は `item` より優先されます。

## スタイル [#style]

`style` は、保存済みテーマと同じフィールドを持つJSONでデザインを受け取ります。そのため、[`GET /v1/themes`](/docs/developers/api/list-themes) で取得したテーマや、[MCPサーバー](/docs/developers/mcp)の `design_qr` が返す `qrdxStyle` を、そのまま渡せます（アップロードしたロゴを除く。下記参照）。

| フィールド | 指定できる値 |
| --- | --- |
| `bgColor`、`fgColor`、`eyeColor`、`dotColor` | 色（`#155dfc` のような16進数、`rgb()`、`hsl()`、または色名）、またはグラデーション：`{ "type": "linear", "angle": 45, "stops": [...] }` または `{ "type": "radial", "stops": [...] }`。ストップは `{ "color", "offset" }` を2～8個指定します（offsetは0～100） |
| `bodyPattern`、`cornerEyePattern`、`cornerEyeDotPattern` | [パターン値](#pattern-values) |
| `level`、`margin` | 上記のパラメーターと同じ（`margin` は0～16） |
| `templateId` | テンプレートとして描画されたフレーム。なしの場合は `default` |
| `frame` | 組み込みフレーム `{ "style": "banner-bottom", "text": "Scan me", "color": "#155dfc", "textColor": "#ffffff" }`、またはカスタムフレーム `{ "style": "custom", "spec": { … } }`。specには、[コミュニティ](#community-items)のフレーム仕様、またはPlaygroundのフレームセクションで作成したカスタムフレームを指定します。仕様はエンジンのフレーム仕様ルールに照らして検証されます（マークアップ、リンク、画像は不可。最大32 KB） |
| `eyeColors` | アイごとの色。`eyeColor` と `dotColor` より優先されます：`{ "topLeft": { "outer": "#b91c1c", "inner": "#1d4ed8" }, "topRight": …, "bottomLeft": … }`。それぞれ色またはグラデーションを指定します |
| `moduleScale` | 各点のサイズ、`0.5` ～ `1`（デフォルトは `1`） |
| `shape` | `square`（デフォルト）または `circle`：装飾的な点で円形に並べたコード |
| `autoLevel` | ロゴがコードの7%を超えて覆う場合に、誤り訂正を `H` に引き上げます（ロゴがあるときは、ここでは常に有効） |
| `logoOptions` | ロゴのレイアウト：`size`（コードの幅の `0.1` ～ `0.3`。コードにモジュールの余裕がない場合、QRdxは縮小します）、`padding`（`0` ～ `2` モジュール）、`x` と `y`（`0` ～ `1`）、`shape`（`square`、`rounded`、`circle` の切り抜き）、`plate`（ロゴの背面の色） |
| `showLogo`、`logoIcon`、`logoFileId` | [ロゴ](#logos)を参照 |

`style` には、Playgroundリンクの `style` 値（`1.` で始まります）も指定できます。そのため、[Playground](/playground)から共有されたデザインを、ロゴなしで、そこでの見た目のとおりに描画できます。未知のフィールド、ロゴのアドレス（`customLogo`）、Logo QRやImage QRのアート（`art`）は、理由を示す `400` で拒否されます。

```json title="400 Bad Request"
{"code":"VALIDATION_ERROR","message":"Invalid query parameters","data":{"details":[{"param":"style.customLogo","message":"Logo images by address aren't accepted: upload the image to QRdx and pass its file id as logoFileId, or pick a logoIcon."}]},"status":400}
```

## コミュニティアイテム [#community-items]

`item` は、公開されている[コミュニティ](/community)のフレームまたはテーマを描画します。CC0で無料です。IDは [`GET /v1/community/items`](/docs/developers/api/list-community-items) で探すか、アイテムページを開いてタイプとスラッグから組み立てます。`/community/frames/wifi-card` は `frame:wifi-card` になります。フレームアイテムは、白地に黒のシンプルなコードに付きます。その中のコードを変えるには、`style` またはフラットなパラメーターを追加してください。`item` を使った描画は、アイテムが新バージョンになったり削除されたりすることがあるため、5分間キャッシュされます（CDNでは10分）。

## ロゴ [#logos]

- **クイックアイコン。** `logoIcon` を使うと、エディタのアイコンのうち1つを、中央の白いタイルの上に配置できます。指定できるのは `wifi`、`location`、`phone`、`email`、`link`、`file`、`calendar`、`whatsapp`、`instagram` です。これらは QRdx が自前で描画するため、キーは不要です。
- **ブランドロゴ。** `logoIcon` には、[Simple Icons](https://simpleicons.org) の {facts.brandLogos} 件のブランドも slug で指定できます。例:`spotify`、`paypal`、`googlemaps`、`appstore`。マークはブランドカラーのまま、プレートなしで描画されます。黒や白にしたい場合は `:black` または `:white` を付けます(`whatsapp:white`)。背面にプレートを置くには、`style` の `logoOptions.plate` を使います。[`GET /api/brand-logos`](https://qrdx.dev/api/brand-logos) で、利用できるすべての slug を確認できます。QRdx にない slug を指定すると `400` が返され、正しい形式の候補が示されます。
- **QRdx マーク** はエディタではデフォルトで表示されますが、ここでは描画されません。`showLogo: true` だけではロゴは追加されません。
- **ロゴを入れると誤り訂正レベルが上がります。** ロゴがコードの7%を超えて覆う場合、`level` の指定に関係なくレベル `H` で描画され、スキャンできる状態が保たれます。

```bash title="Terminal"
curl -o spotify.png "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=png&logoIcon=spotify"
```

<IfAvailable feature="fileStorage">

**独自のロゴ。** `logoFileId` を指定すると、[ダッシュボード → ファイル](/docs/files)でアップロードした、1 MB までの PNG または JPEG を描画します。ID は、ファイルのリンク `https://qrdx.dev/api/files/<id>` の最後の部分です。ファイルを所有するワークスペースの [API キー](/docs/developers/api-keys)を送信してください。

```bash title="Terminal"
curl -o qr.png -H "Authorization: Bearer $QRDX_API_KEY" \
  "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=png&logoFileId=<id>"
```

レスポンスはプライベート(`Cache-Control: private, no-store`)で、ワークスペースの1日あたりの API クォータに含まれます。別のワークスペースのファイルを指定すると `404`、キーなしのリクエストは `401` になります。QRdx は画像を自社のストレージから読み込み、本当に PNG または JPEG であることを確認します。送信された Web アドレスからロゴを取得することはありません。

</IfAvailable>

`logoOptions` では、これらのロゴのサイズ、位置、切り抜き、背景を指定できます。アップロードしたロゴ自体の背景除去は Playground で行います。Image API は、アップロードされたファイルをそのまま描画します。Logo QR と Image QR のアートは、ここでは利用できません。Playground が、ブラウザー上であなたの画像から生成します。アートコードは [Playground](/playground?tab=art) でデザインするか、[AI アート API](/docs/developers/ai-art-api) でコードを AI アートに仕上げてください。

### パターンの値 [#pattern-values]

- `body`: `circle`, `circle-large`, `square`, `diamond`, `circle-mixed`, `pacman`, `rounded`, `small-square`, `vertical-line`, `horizontal-line`, `liquid`, `liquid-horizontal`, `liquid-vertical`, `classy`, `classy-rounded`, `leaf`, `plus`, `hexagon`, `star`, `heart`, `random-dots`, `mosaic`, `octagon`
- `eye`: `square`, `rounded`, `gear`, `circle`, `diya`, `extra-rounded`, `message`, `pointy`, `leaf`, `drop`, `octagon`, `bevel`, `squircle`, `cushion`, `shield`, `petal`, `leaf-reverse`
- `dot`: `square`, `rounded`, `circle`, `message`, `message-reverse`, `diya`, `diya-reverse`, `rounded-triangle`, `leaf`, `drop`, `plus`, `cross-rounded`, `hexagon`, `octagon`, `flower`, `heart`, `squircle`, `dots`, `extra-rounded`, `leaf-reverse`, `drop-reverse`
- `template`: `default`, `Arrow`, `StandardBox`, `SquareBorder`, `StrikedBox`, `Halloween`, `DotRing`

これらは [`qrdx` React ライブラリ](/docs/features/patterns)と同じスタイルです。[MCP サーバー](/docs/developers/mcp)でも、簡単な説明付きで一覧を取得できます。

## レスポンス [#responses]

リクエストが成功すると、次のヘッダー付きで画像が返されます。

- `Content-Type: image/svg+xml`、`image/png`、`image/webp` または `application/postscript`(EPS は `qr-code.eps` のダウンロードとして送信されます)
- `Cache-Control: public, max-age=31536000, immutable`。ただし `item` を使うレンダリング(5分、CDN では10分)と、`logoFileId` を使うレンダリング(`private, no-store`)は除きます。
- `Access-Control-Allow-Origin: *`。どの Web サイトからでも `fetch` できます。

レンダリングは決定的です。同じクエリ文字列からは常に同じバイト列が返されるため、レスポンスを1年間キャッシュできます。元のパラメーターだけを使う URL は、これまでとまったく同じように描画されます。

## 問題が起きたときは [#if-something-goes-wrong]

### `"param": "size"` を伴う `400` [#400-with-param-size]

`size` が64未満、または2048を超えています。レスポンスの本文に上限が示されます。

```json title="400 Bad Request"
{"code":"VALIDATION_ERROR","message":"Invalid query parameters","data":{"details":[{"param":"size","message":"Too small: expected number to be >=64"}]},"status":400}
```

### `"param": "data"` を伴う `400` [#400-with-param-data]

選択した誤り訂正レベルでは、データが QR コードに収まりません。`level` を下げる(`L` が最も多く格納できます)か、データを短くしてください。長い URL には、動的QRコードの短縮リンクを使うのが一般的な解決策です。

```json title="400 Bad Request"
{"code":"VALIDATION_ERROR","message":"Invalid query parameters","data":{"details":[{"param":"data","message":"Data is too long for a QR code at error correction level H. Shorten it or use a lower level (L holds the most)."}]},"status":400}
```

### `"param": "logoIcon"` を伴う `400` [#400-with-param-logoicon]

slug が、QRdx にあるブランドでもクイックアイコンでもありません。メッセージには、使える形式(`spotify`、`paypal`、`googlemaps`、または `wifi`、`phone`、`email`)が示されます。

### 画像が正しく表示されない、または途中で切れる [#the-image-looks-wrong-or-is-split]

`data` または `style` に含まれる `&`、`#`、`+` がエンコードされておらず、その文字で URL が途切れています。両方の値をエンコードし、色は `#` なしで指定してください。

### `429 RATE_LIMITED` [#429-rate_limited]

1つの IP アドレスからのリクエストが、1分あたり {facts.imageApiPerMinute} 件を超えました。`Retry-After` に示された秒数だけ待ってください。同じ URL は常に同じ画像を返すので、毎回ライブで読み込まず、キャッシュするかファイルとして保存してください。

## 制限 [#limits]

- **レート制限:** IP アドレスごとに1分あたり {facts.imageApiPerMinute} リクエスト。画像は REST API の1日あたりのクォータを消費しません。
- **スキャン確認はありません。** Image API は、指定された内容をそのまま描画します。デザインのスキャンスコアを事前に確認して修正するには、[MCP サーバー](/docs/developers/mcp)の `design_qr` か、[Playground](/playground?tab=design) のスキャンスコアを使ってください。
- **`style` は URL 内で最大8,192文字**、JSON は最大40 KB です。
- **データは URL の一部です。** ほかの URL と同様に、サーバーログ、ブラウザー履歴、キャッシュに残る可能性があります。パスワードやその他の機密情報を含めないでください。

## スキャンのヒント [#scanning-tips]

- GitHub のダークモードの README など、暗い背景や複雑な背景の上に画像を置く場合は、`margin` を `2` 以上にしてください。
- `fg` と `bg` のコントラストを十分に確保してください。明るい背景に暗いモジュールの組み合わせが、最も確実にスキャンできます。
- デフォルト(四角いモジュール、4モジュール分の余白)は、どのリーダーでもスキャンできます。`circle` のドットなど装飾的な形は柔らかい印象になりますが、古いスキャナーでは読み取りにくい場合があります。[スキャンチェッカー](/tools/scan-checker)で確認してください。
- 印刷する前に、数台のスマートフォンでコードを試してください。

## セルフホスト [#self-hosting]

このエンドポイントは QRdx Web アプリの一部のため、[セルフホスト](/docs/self-hosting)したインスタンスでは、自分のドメインの `/api/v1/qr` で提供されます(例: `https://qr.example.com/api/v1/qr?data=…`)。短い `/v1/qr` パスは `api.qrdx.dev` でのみ動作します。レート制限は、Upstash Redis が設定されている場合はそれを使い、設定されていない場合はオフになります。
