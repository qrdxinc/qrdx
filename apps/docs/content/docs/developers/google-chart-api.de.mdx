Am Ende dieser Seite laden alle QR-Codes, die deine Seiten, E-Mails oder Tabellen bisher von `chart.googleapis.com` geholt haben, stattdessen von der QRdx [Image API](/docs/developers/image-api), in derselben Größe und mit derselben Fehlerkorrekturstufe, ohne Account und ohne Schlüssel.

Google hat seine Image Charts im April 2012 als veraltet markiert, darunter auch QR-Codes unter `chart.googleapis.com/chart?cht=qr`. Der Endpunkt antwortet heute mit `404` (geprüft am 15. November 2026), deshalb zeigt jedes alte `<img>`-Tag ein kaputtes Bild. Die QRdx Image API funktioniert genauso: eine `GET`-URL, die das Bild zurückgibt. Die Umstellung besteht also aus einem neuen Host und drei umbenannten Parametern.

## Bevor du anfängst [#before-you-start]

- Finde die Dateien, die noch die alte API verwenden. Der folgende Befehl listet sie auf, auch mit dem älteren Host `chart.apis.google.com`:

```bash title="Terminal"
grep -rlE "chart\.(googleapis|apis\.google)\.com/chart" .
```

- Arbeite in einem Git-Checkout oder an einem anderen Ort, an dem du die Änderung prüfen kannst, bevor sie live geht.

## 1. Eine URL vergleichen [#1-compare-one-url]

Die beiden URLs unten zeichnen dasselbe: ein PNG mit 300 × 300 von `https://example.com` mit Fehlerkorrektur `M` und 2 Modulen Rand.

```txt title="Before and after"
https://chart.googleapis.com/chart?cht=qr&chs=300x300&chl=https%3A%2F%2Fexample.com&chld=M|2
https://api.qrdx.dev/v1/qr?format=png&size=300&data=https%3A%2F%2Fexample.com&level=M&margin=2
```

```bash title="Terminal"
curl -o after.png "https://api.qrdx.dev/v1/qr?format=png&size=300&data=https%3A%2F%2Fexample.com&level=M&margin=2"
file after.png
# after.png: PNG image data, 300 x 300, 8-bit/color RGBA, non-interlaced
```

## 2. Die Parameter zuordnen [#2-map-the-parameters]

| Google Chart | QRdx | Hinweise |
| --- | --- | --- |
| `cht=qr` | nicht nötig | Der Endpunkt zeichnet nur QR-Codes. Wenn du es drin lässt, wird es ignoriert |
| `chl=<data>` | `data=<data>` | Genauso URL-codiert, bis zu 2.048 Zeichen |
| `chs=<width>x<height>` | `size=<width>` | Eine Zahl, da QR-Codes quadratisch sind: `64` bis `2048` Pixel |
| `chld=<level>\|<margin>` | `level=<level>&margin=<margin>` | Dieselben Buchstaben, `L`, `M`, `Q` und `H`. Der Rand wird in Modulen angegeben, `0` bis `16` |
| `choe=UTF-8` | nicht nötig | QRdx codiert Text immer als UTF-8, das war auch Googles Standard. Es gibt keine Option für Shift_JIS oder ISO-8859-1. Wenn du es drin lässt, wird es ignoriert |
| immer PNG | `format=png` | QRdx liefert SVG, außer du fragst `png`, `webp` oder `eps` an. Bleib bei PNG für E-Mails, da viele E-Mail-Clients kein SVG anzeigen |

Zwei Standardwerte unterscheiden sich. Ohne `chld` nutzte Google die Fehlerkorrektur `L`; QRdx nutzt `Q`, die mehr Beschädigung übersteht, aber einen dichteren Code ergibt. Füge `level=L` hinzu, wenn du das alte Aussehen brauchst. Beide verwenden standardmäßig 4 Module Rand.

## 3. Die URLs in deinen Dateien umschreiben [#3-rewrite-the-urls-in-your-files]

Das schreibt jede Google-Chart-QR-URL in den angegebenen Dateien um, beide Hosts eingeschlossen: Es ändert Host und Pfad, benennt `chl`, `chs` und `chld` um und fügt `format=png` hinzu, damit die Bilder PNG bleiben. Perl ist bei macOS und den meisten Linux-Distributionen dabei.

```bash title="Terminal"
perl -pi -e 's{https?://chart\.(?:googleapis|apis\.google)\.com/chart\?([^\s"\x27<>)]*)}{my $q = $1; $q =~ s/(^|[&;])chl=/${1}data=/; $q =~ s/(^|[&;])chs=(\d+)x\d+/${1}size=$2/; $q =~ s/(^|[&;])chld=([LMQH])(?:\||%7C)(\d+)/${1}level=$2&margin=$3/i; $q =~ s/(^|[&;])chld=([LMQH])/${1}level=$2/i; "https://api.qrdx.dev/v1/qr?format=png&$q"}ge' index.html
```

Auf einer Datei mit drei alten Tags ergibt das:

```html title="index.html (after)"
<img src="https://api.qrdx.dev/v1/qr?format=png&cht=qr&size=300&data=https%3A%2F%2Fexample.com&level=M&margin=2" alt="QR">
<img src="https://api.qrdx.dev/v1/qr?format=png&cht=qr&size=150&data=https%3A%2F%2Fexample.com%2Fmenu" alt="QR 2">
<img src="https://api.qrdx.dev/v1/qr?format=png&size=200&cht=qr&data=hello&level=H&choe=UTF-8" alt="QR 3">
```

Die übrig gebliebenen `cht=qr` und `choe=UTF-8` ignoriert QRdx; entferne sie von Hand, wenn du saubere URLs möchtest. Prüfe den Diff und führe dann das `grep` vom Anfang noch einmal aus: Es sollte nichts mehr auflisten.

## 4. Den Code ändern, der URLs baut [#4-change-the-code-that-builds-urls]

```js title="qr.js"
// Before
const src = `https://chart.googleapis.com/chart?cht=qr&chs=200x200&chl=${encodeURIComponent(link)}`;

// After
const src = `https://api.qrdx.dev/v1/qr?format=png&size=200&data=${encodeURIComponent(link)}`;
```

In Google Sheets:

```txt title="Sheets formula"
=IMAGE("https://api.qrdx.dev/v1/qr?format=png&size=150&data="&ENCODEURL(A2))
```

Sheets lädt Bilder über Googles eigene Server, deshalb kann eine Tabelle mit Hunderten Codes an das unten genannte Limit pro IP stoßen. Erzeuge bei einer langen Liste die Dateien einmalig mit dem [Bulk-Generator](/tools/bulk) oder mit `qrdx batch` aus dem [CLI](/docs/developers/cli).

## Wenn etwas schiefgeht [#if-something-goes-wrong]

### `400` mit `"param": "size"` [#400-with-param-size]

Ein `chs` unter 64 Pixeln (etwa `50x50`) oder über 2048 wird abgelehnt. Ändere diese Größen von Hand; `64` ist das Kleinste, was die Image API zeichnet.

```json title="400 Bad Request"
{"code":"VALIDATION_ERROR","message":"Invalid query parameters","data":{"details":[{"param":"size","message":"Too small: expected number to be >=64"}]},"status":400}
```

### Das Bild ist dichter als vorher [#the-image-is-denser-than-before]

Googles Standard-Fehlerkorrektur war `L`, die von QRdx ist `Q`. Füge `level=L` hinzu, um das alte Aussehen zu erhalten.

### `429` nach einem Massen-Reload [#429-after-a-bulk-reload]

Die Image API erlaubt {facts.imageApiPerMinute} Anfragen pro Minute und IP-Adresse. Warte die Sekunden aus dem Header `Retry-After` ab oder erzeuge die Dateien einmalig, statt sie live zu laden.

## Gut zu wissen [#what-else-to-know]

- **Caching:** Dieselbe URL liefert immer dieselben Bytes, daher werden Antworten ein Jahr lang gecacht (`Cache-Control: public, max-age=31536000, immutable`).
- **Weitere Optionen:** Farben (`fg`, `bg`), Modul- und Augenformen, ein Logo-Icon (`logoIcon`) und Rahmen. Probiere sie im [URL-Builder](/qr-code-api) aus oder lies die [Parameter](/docs/developers/image-api#parameters).
- **Self-Hosting:** Eine [selbst gehostete](/docs/self-hosting) QRdx-Instanz stellt dieselbe API unter `/api/v1/qr` auf deiner eigenen Domain bereit.
