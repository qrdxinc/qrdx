QRdx는 `qrdx` 라이브러리를 기반으로 만든 QR 코드 컴포넌트를 shadcn/ui 레지스트리로 제공합니다. shadcn CLI가 각 컴포넌트의 소스를 프로젝트에 복사하므로 코드를 직접 소유하고 원하는 대로 수정할 수 있습니다. 다운로드 버튼, 카드, 공유 대화상자, 스캐너처럼 완성된 UI가 필요할 때는 레지스트리를 사용하세요. QR 코드만 필요하다면 라이브러리의 `QRCode`를 사용하세요.

<NpmStatus package="qrdx" />

<PackageManagerTabs command="npx shadcn@latest add https://qrdx.dev/r/qr-code.json" />

각 컴포넌트에는 실시간 미리보기, 소스, 설치 방법, 예제, props 표가 있는 별도 페이지가 있습니다. [Playground](/playground?open=code&lang=shadcn)에서 코드를 꾸몄나요? 그곳에서 레지스트리의 QR Code 컴포넌트용 코드를 복사하세요.

## 설치되는 항목 [#what-gets-installed]

각 컴포넌트는 `components` 폴더에 파일 하나로 설치됩니다. CLI는 `qrdx`도 함께 설치하고(대부분의 컴포넌트가 아이콘에 사용하는 `lucide-react` 포함), 컴포넌트가 기반으로 하는 `button`, `card`, `dialog`, `dropdown-menu`, `input`, `label` 같은 shadcn/ui 컴포넌트도 추가합니다. 각 컴포넌트 페이지의 설치 탭에서 **Manual** 아래에 해당 컴포넌트의 의존성이 나와 있습니다.

전체 목록은 [`https://qrdx.dev/r/registry.json`](https://qrdx.dev/r/registry.json)에서, 각 항목은 `https://qrdx.dev/r/<name>.json`에서 확인할 수 있습니다.

## 이름으로 설치 [#install-by-name]

짧은 이름으로 설치하려면 `components.json`에 레지스트리를 추가하세요.

```json title="components.json"
{
  "registries": {
    "@qrdx": "https://qrdx.dev/r/{name}.json"
  }
}
```

그런 다음 이름으로 컴포넌트를 하나 또는 여러 개 추가하세요.

<PackageManagerTabs command="npx shadcn@latest add @qrdx/qr-code @qrdx/qr-code-download @qrdx/qr-code-share-dialog" />

## 스타일링과 테마 [#styling-and-theming]

컴포넌트는 표준 shadcn/ui 테마 토큰(`bg-card`, `border`, `text-muted-foreground`, `ring-ring`)과 함께 Tailwind 클래스를 사용하며, 프로젝트의 Button, Card, Dialog, Input을 그대로 사용합니다. 따라서 테마와 다크 모드를 그대로 따릅니다. QR 코드는 기본적으로 밝은 배경을 유지합니다. 밝은 타일 위의 어두운 모듈은 모든 리더기에서 스캔되기 때문입니다. 테마를 따르게 하는 방법은 [QR Code](/docs/components/qr-code#dark-mode) 페이지에서 확인하세요.

모든 컴포넌트는 버튼과 상태 때문에 Client Component입니다(파일이 `"use client"`로 시작합니다). 그래도 코드 자체는 서버에서 렌더링되므로 버튼이 동작하기 전에 이미 페이지의 HTML에 들어 있습니다. Server Component 페이지에서 어떤 컴포넌트든 가져와 서버 데이터를 props로 전달할 수 있습니다.

PDF 다운로드에는 선택 사항인 `jspdf` 패키지(`npm install jspdf`)가 필요합니다. 그 외의 기능은 CLI 실행이 끝나면 바로 작동합니다.
