Al terminar esta página tendrás una URL de imagen de código QR que podrás pegar en un README, en una etiqueta `<img>` o en una plantilla de correo, con el estilo que quieras, y sabrás qué rechaza la API y por qué.

`GET https://api.qrdx.dev/v1/qr` devuelve un código QR como imagen SVG, PNG o WebP, o como archivo EPS vectorial para impresión y herramientas de diseño. Todo va en la cadena de consulta, así que la propia URL es la imagen. También admite los estilos del editor: degradados, marcos (incluidos los marcos personalizados), bordes, colores de ojos y puntos e iconos de logo. No hace falta cuenta ni clave de API, salvo para un logo que hayas subido a QRdx (consulta [Logos](#logos)).

```md title="README.md"
![QR code](https://api.qrdx.dev/v1/qr?data=https://github.com/you/repo)
```

[Pruébalo en el Playground](/playground?open=code&lang=image): dale estilo a un código allí y copia la URL de su imagen. O envía peticiones desde la página de referencia [Generar una imagen de código QR](/docs/developers/api/get-qr-image).

## 1. Solicita una imagen [#1-request-an-image]

<Tabs groupId="language" persist items={["curl", "JavaScript", "Python"]}>
  <Tab value="curl">
    ```bash title="Terminal"
    curl -o qr.png "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=png&size=1024"
    ```
  </Tab>
  <Tab value="JavaScript">
    ```js title="qr.mjs"
    import { writeFile } from "node:fs/promises";

    const url = new URL("https://api.qrdx.dev/v1/qr");
    url.searchParams.set("data", "https://qrdx.dev");
    url.searchParams.set("format", "png");
    url.searchParams.set("size", "1024");

    const response = await fetch(url);
    await writeFile("qr.png", Buffer.from(await response.arrayBuffer()));
    ```
  </Tab>
  <Tab value="Python">
    ```python title="qr.py"
    import requests

    response = requests.get(
        "https://api.qrdx.dev/v1/qr",
        params={"data": "https://qrdx.dev", "format": "png", "size": 1024},
    )
    response.raise_for_status()
    open("qr.png", "wb").write(response.content)
    ```
  </Tab>
</Tabs>

```txt title="Output"
qr.png: PNG image data, 1024 x 1024, 8-bit/color RGBA, non-interlaced
```

Pon la URL entre comillas en un shell para que conserve el `&`. En una página HTML, la URL va directamente en `src`:

```html title="index.html"
<img
  src="https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&size=256&fg=155dfc"
  width="256"
  height="256"
  alt="QR code for qrdx.dev"
/>
```

## 2. Elige un formato [#2-pick-a-format]

| `format` | Devuelve | Cuándo |
| --- | --- | --- |
| `svg` (predeterminado) | `image/svg+xml` | Páginas web y todo lo que se escala |
| `png` | `image/png` | Correo, aplicaciones de chat, documentos |
| `webp` | `image/webp`, sin pérdida, conserva la transparencia | Sitios web: los píxeles del PNG en un archivo más pequeño |
| `eps` | `application/postscript`, enviado como descarga `qr-code.eps` | Illustrator, InDesign, imprentas. Aquí `size` es el ancho en puntos, 72 por pulgada, así que `144` son 2 pulgadas |

```bash title="Terminal"
curl -o qr.webp "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=webp&size=1024"
curl -o qr.eps "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=eps&size=144"
head -2 qr.eps
# %!PS-Adobe-3.0 EPSF-3.0
# %%BoundingBox: 0 0 144 144
```

## 3. Dale estilo [#3-style-it]

Los parámetros planos cubren colores, formas, un marco y un logo:

```txt title="Rounded modules with a frame drawn as a template"
https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&body=rounded&eye=rounded&dot=rounded&template=Arrow
```

```txt title="A built-in frame with its label, and a community frame by id"
https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&frame=banner-bottom&frameText=Scan%20the%20menu
https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&item=frame:wifi-card
```

Para degradados, marcos personalizados y colores por ojo, envía todo el diseño como JSON en `style`:

```js title="styled.mjs"
const style = {
  fgColor: {
    type: "linear",
    angle: 45,
    stops: [
      { color: "#1d4ed8", offset: 0 },
      { color: "#7c3aed", offset: 100 },
    ],
  },
  eyeColor: "#b91c1c",
  frame: { style: "banner-bottom", text: "Scan the menu" },
};
const src = `https://api.qrdx.dev/v1/qr?data=${encodeURIComponent(link)}&style=${encodeURIComponent(JSON.stringify(style))}`;
// 200 image/svg+xml, 634.88 × 727.04: the frame adds to the 512 px code
```

<Callout type="info">
Codifica el valor de `data` cuando contenga `&`, `#`, `+` o espacios, por ejemplo con `encodeURIComponent` en JavaScript. De lo contrario, la URL se corta en esos caracteres. Codifica `style` del mismo modo y escribe los colores sin el `#` (o como `%23`): un `#` sin codificar inicia el fragmento de la URL y nunca se envía.
</Callout>

## Parámetros [#parameters]

| Parámetro | Valor predeterminado | Descripción |
| --- | --- | --- |
| `data` | obligatorio | Texto o URL que se codifica, hasta 2048 caracteres |
| `format` | `svg` | `svg`, `png`, `webp` o `eps` |
| `size` | `512` | Ancho y alto en píxeles, de `64` a `2048` (puntos para EPS) |
| `fg` | `000000` | Color de los módulos en hexadecimal (`155dfc`, `fff`, o 8 dígitos con alfa) |
| `bg` | `ffffff` | Color de fondo en hexadecimal. `00000000` da un fondo transparente |
| `eyeColor` | `fg` | Color de los tres ojos de las esquinas |
| `dotColor` | `fg` | Color del punto dentro de cada ojo de esquina |
| `body` | `square` | Forma de los módulos de datos; consulta [Valores de patrón](#pattern-values) |
| `eye` | `square` | Forma de los marcos de los ojos de las esquinas |
| `dot` | `square` | Forma del punto dentro de cada ojo de esquina |
| `level` | `Q` | Corrección de errores: `L` (cerca del 7 %), `M` (15 %), `Q` (25 %) o `H` (30 %) |
| `margin` | `4` | Zona de silencio alrededor del código en módulos, de `0` a `16` |
| `template` | ninguno | Un [marco dibujado como plantilla](/docs/features/templates): la imagen completa mide `size` de ancho, con el código más pequeño en su interior |
| `frame` | ninguno | Un [marco](/docs/features/frames) integrado con llamada a la acción, como `banner-bottom`, `speech-bubble` o `circle`: cualquiera de los {facts.frameStyles} marcos integrados |
| `frameText` | `Scan me` | La etiqueta del marco, hasta 24 caracteres. También cambia la etiqueta del marco de un `style` o `item` |
| `style` | ninguno | El diseño completo del editor como JSON; consulta [Estilos](#style) |
| `item` | ninguno | Un marco o tema de la comunidad por id, como `frame:wifi-card`; consulta [Elementos de la comunidad](#community-items) |
| `logoIcon` | ninguno | Un icono rápido o un logo de marca en el centro; consulta [Logos](#logos) |
| `logoFileId` | ninguno | Un logo que hayas subido, por id de archivo; requiere una clave de API; consulta [Logos](#logos) |

Los valores de enumeración (`level`, `format`, `template`, `frame`) no distinguen mayúsculas de minúsculas. Con un marco, `size` es el ancho del código en sí y el marco se suma a la imagen, en todos los formatos. Los parámetros planos prevalecen sobre `style`, y `style` prevalece sobre `item`.

## Estilos [#style]

`style` recibe el diseño como JSON con los mismos campos que un tema guardado, así que un tema de [`GET /v1/themes`](/docs/developers/api/list-themes) o el `qrdxStyle` que devuelve `design_qr` del [servidor MCP](/docs/developers/mcp) se pueden pasar tal cual (sin un logo subido, ver más abajo):

| Campo | Admite |
| --- | --- |
| `bgColor`, `fgColor`, `eyeColor`, `dotColor` | Un color (hexadecimal como `#155dfc`, `rgb()`, `hsl()` o un nombre de color), o un degradado: `{ "type": "linear", "angle": 45, "stops": [...] }` o `{ "type": "radial", "stops": [...] }`, con 2 a 8 paradas de `{ "color", "offset" }` (offset de 0 a 100) |
| `bodyPattern`, `cornerEyePattern`, `cornerEyeDotPattern` | Los [valores de patrón](#pattern-values) |
| `level`, `margin` | Igual que los parámetros anteriores (`margin` de 0 a 16) |
| `templateId` | Un marco dibujado como plantilla, `default` para ninguno |
| `frame` | Un marco integrado, `{ "style": "banner-bottom", "text": "Scan me", "color": "#155dfc", "textColor": "#ffffff" }`, o uno personalizado, `{ "style": "custom", "spec": { … } }`, con una especificación de marco de la [comunidad](#community-items) o un marco personalizado creado en la sección Marco del Playground. Las especificaciones se validan con las reglas de especificación de marcos del motor (sin marcado, enlaces ni imágenes; máximo 32 KB) |
| `eyeColors` | Colores por ojo, sobre `eyeColor` y `dotColor`: `{ "topLeft": { "outer": "#b91c1c", "inner": "#1d4ed8" }, "topRight": …, "bottomLeft": … }`, cada uno un color o un degradado |
| `moduleScale` | Tamaño de cada punto, de `0.5` a `1` (predeterminado `1`) |
| `shape` | `square` (predeterminado) o `circle`: el código dentro de un disco de puntos decorativos |
| `autoLevel` | Sube la corrección de errores a `H` cuando el logo cubre más del 7 % del código (aquí siempre activo cuando hay logo) |
| `logoOptions` | La disposición del logo: `size` (de `0.1` a `0.3` del ancho del código; QRdx lo reduce cuando el código no puede ceder los módulos), `padding` (de `0` a `2` módulos), `x` e `y` (de `0` a `1`), `shape` (recorte `square`, `rounded` o `circle`) y `plate` (un color detrás) |
| `showLogo`, `logoIcon`, `logoFileId` | Consulta [Logos](#logos) |

`style` también admite el valor `style` de un enlace del Playground (empieza por `1.`), de modo que un diseño compartido desde el [Playground](/playground) se genera tal como se ve allí, sin su logo. Los campos desconocidos, las direcciones de logo (`customLogo`) y el arte de Logo QR o Image QR (`art`) se rechazan con un `400` que explica el motivo:

```json title="400 Bad Request"
{"code":"VALIDATION_ERROR","message":"Invalid query parameters","data":{"details":[{"param":"style.customLogo","message":"Logo images by address aren't accepted: upload the image to QRdx and pass its file id as logoFileId, or pick a logoIcon."}]},"status":400}
```

## Elementos de la comunidad [#community-items]

`item` genera un marco o tema publicado de la [comunidad](/community), gratis bajo CC0. Encuentra los ids con [`GET /v1/community/items`](/docs/developers/api/list-community-items), o abre la página de un elemento y usa su tipo y su slug: `/community/frames/wifi-card` es `frame:wifi-card`. Un elemento de tipo marco se coloca sobre un código liso en negro sobre blanco; añade `style` o parámetros planos para cambiar el código que hay debajo. Las imágenes generadas con `item` se guardan en caché durante 5 minutos (10 en el CDN), ya que un elemento puede recibir una nueva versión o ser retirado.

## Logos [#logos]

- **Iconos rápidos.** `logoIcon` coloca en el centro uno de los iconos del editor sobre una pieza blanca: `wifi`, `location`, `phone`, `email`, `link`, `file`, `calendar`, `whatsapp` o `instagram`. QRdx los dibuja por sí mismo y no necesitan clave.
- **Logotipos de marca.** `logoIcon` también acepta cualquiera de las {facts.brandLogos} marcas de [Simple Icons](https://simpleicons.org) mediante su slug: `spotify`, `paypal`, `googlemaps`, `appstore`. La marca se dibuja sin fondo y con el color de la marca; añade `:black` o `:white` para esos colores (`whatsapp:white`), y `logoOptions.plate` en `style` para poner una placa detrás. [`GET /api/brand-logos`](https://qrdx.dev/api/brand-logos) lista todos los slugs. Si usas un slug que QRdx no tiene, recibes un `400` que sugiere la forma correcta.
- **La marca QRdx** que el editor muestra por defecto no se dibuja aquí: `showLogo: true` por sí solo no añade ningún logotipo.
- **La corrección de errores sube con un logotipo.** Cuando un logotipo cubre más del 7 % del código, este se dibuja en el nivel `H`, sea cual sea el valor de `level`, para que siga pudiéndose escanear.

```bash title="Terminal"
curl -o spotify.png "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=png&logoIcon=spotify"
```

<IfAvailable feature="fileStorage">

**Tu propio logotipo.** `logoFileId` dibuja un PNG o JPEG de hasta 1 MB que hayas subido en [Panel → Archivos](/docs/files). El id es la última parte del enlace del archivo, `https://qrdx.dev/api/files/<id>`. Envía una [clave de API](/docs/developers/api-keys) del espacio de trabajo propietario del archivo:

```bash title="Terminal"
curl -o qr.png -H "Authorization: Bearer $QRDX_API_KEY" \
  "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=png&logoFileId=<id>"
```

La respuesta es privada (`Cache-Control: private, no-store`) y cuenta para la cuota diaria de API del espacio de trabajo. Un archivo de otro espacio de trabajo recibe `404`, y una solicitud sin clave recibe `401`. QRdx lee la imagen desde su propio almacenamiento y comprueba que sea realmente un PNG o JPEG; nunca descarga un logotipo desde una dirección web que tú envíes.

</IfAvailable>

`logoOptions` ajusta el tamaño, la posición, el recorte y el fondo de cualquiera de estos logotipos. Quitar el fondo propio de un logotipo subido se hace en el Playground; la Image API dibuja el archivo subido tal cual. El arte de Logo QR y de Image QR no está disponible aquí: el Playground lo genera a partir de tu imagen en el navegador. Diseña códigos de arte en el [Playground](/playground?tab=art), o convierte un código en arte con IA mediante la [API de arte con IA](/docs/developers/ai-art-api).

### Valores de patrones [#pattern-values]

- `body`: `circle`, `circle-large`, `square`, `diamond`, `circle-mixed`, `pacman`, `rounded`, `small-square`, `vertical-line`, `horizontal-line`, `liquid`, `liquid-horizontal`, `liquid-vertical`, `classy`, `classy-rounded`, `leaf`, `plus`, `hexagon`, `star`, `heart`, `random-dots`, `mosaic`, `octagon`
- `eye`: `square`, `rounded`, `gear`, `circle`, `diya`, `extra-rounded`, `message`, `pointy`, `leaf`, `drop`, `octagon`, `bevel`, `squircle`, `cushion`, `shield`, `petal`, `leaf-reverse`
- `dot`: `square`, `rounded`, `circle`, `message`, `message-reverse`, `diya`, `diya-reverse`, `rounded-triangle`, `leaf`, `drop`, `plus`, `cross-rounded`, `hexagon`, `octagon`, `flower`, `heart`, `squircle`, `dots`, `extra-rounded`, `leaf-reverse`, `drop-reverse`
- `template`: `default`, `Arrow`, `StandardBox`, `SquareBorder`, `StrikedBox`, `Halloween`, `DotRing`

Son los mismos estilos que ofrece la [biblioteca `qrdx` de React](/docs/features/patterns). El [servidor MCP](/docs/developers/mcp) también puede listarlos con descripciones breves.

## Respuestas [#responses]

Una solicitud correcta devuelve la imagen con:

- `Content-Type: image/svg+xml`, `image/png`, `image/webp` o `application/postscript` (EPS se envía como una descarga `qr-code.eps`)
- `Cache-Control: public, max-age=31536000, immutable`, excepto en los renders con `item` (5 minutos, 10 en la CDN) y con `logoFileId` (`private, no-store`)
- `Access-Control-Allow-Origin: *`, para que puedas usar `fetch` desde cualquier sitio web

El renderizado es determinista: la misma cadena de consulta siempre devuelve los mismos bytes, por eso las respuestas se pueden guardar en caché durante un año. Las URL que usan solo los parámetros originales se renderizan exactamente como siempre.

## Si algo sale mal [#if-something-goes-wrong]

### `400` con `"param": "size"` [#400-with-param-size]

`size` es menor que 64 o mayor que 2048. El cuerpo indica el límite:

```json title="400 Bad Request"
{"code":"VALIDATION_ERROR","message":"Invalid query parameters","data":{"details":[{"param":"size","message":"Too small: expected number to be >=64"}]},"status":400}
```

### `400` con `"param": "data"` [#400-with-param-data]

Los datos no caben en un código QR con el nivel de corrección de errores elegido. Usa un `level` más bajo (`L` es el que admite más datos) o datos más cortos; el enlace corto de un código dinámico suele resolver el problema con URL largas.

```json title="400 Bad Request"
{"code":"VALIDATION_ERROR","message":"Invalid query parameters","data":{"details":[{"param":"data","message":"Data is too long for a QR code at error correction level H. Shorten it or use a lower level (L holds the most)."}]},"status":400}
```

### `400` con `"param": "logoIcon"` [#400-with-param-logoicon]

El slug no es una marca que QRdx tenga ni un icono rápido. El mensaje sugiere las formas que funcionan (`spotify`, `paypal`, `googlemaps`, o `wifi`, `phone`, `email`).

### La imagen se ve mal o aparece cortada [#the-image-looks-wrong-or-is-split]

Un `&`, `#` o `+` en `data` o `style` no se codificó, y la URL se cortó en ese carácter. Codifica ambos valores y escribe los colores sin el `#`.

### `429 RATE_LIMITED` [#429-rate_limited]

Más de {facts.imageApiPerMinute} solicitudes por minuto desde una misma dirección IP. Espera los segundos indicados en `Retry-After`. La misma URL siempre devuelve la misma imagen, así que guárdala en caché o guarda el archivo en lugar de cargarla en directo.

## Límites [#limits]

- **Límite de frecuencia:** {facts.imageApiPerMinute} solicitudes por minuto por dirección IP. Las imágenes no consumen la cuota diaria de la REST API.
- **Sin comprobación de escaneo.** La Image API dibuja lo que le pides. Para comprobar y reparar antes la puntuación de escaneo de un diseño, usa `design_qr` en el [servidor MCP](/docs/developers/mcp), o la puntuación de escaneo en el [Playground](/playground?tab=design).
- **`style` admite hasta 8.192 caracteres** en la URL, y su JSON hasta 40 KB.
- **Los datos forman parte de la URL.** Como cualquier URL, puede acabar en registros del servidor, en el historial del navegador y en cachés. No incluyas contraseñas ni otros secretos.

## Consejos de escaneo [#scanning-tips]

- Mantén `margin` en `2` o más cuando la imagen esté sobre un fondo oscuro o recargado, como un README en el modo oscuro de GitHub.
- Mantén un buen contraste entre `fg` y `bg`. Los módulos oscuros sobre fondo claro son los que se escanean con más fiabilidad.
- Los valores por defecto (módulos cuadrados, margen de 4 módulos) se escanean en todos los lectores. Las formas estilizadas, como los puntos `circle`, se ven más suaves y algunos escáneres antiguos las leen peor: compruébalo con el [verificador de escaneo](/tools/scan-checker).
- Prueba el código con varios teléfonos antes de imprimirlo.

## Autoalojamiento [#self-hosting]

El endpoint forma parte de la aplicación web de QRdx, así que una instancia [autoalojada](/docs/self-hosting) lo sirve en `/api/v1/qr` en tu propio dominio (por ejemplo `https://qr.example.com/api/v1/qr?data=…`). La ruta corta `/v1/qr` solo funciona en `api.qrdx.dev`. El límite de frecuencia usa Upstash Redis cuando está configurado y, si no, queda desactivado.
