Al terminar esta página tendrás la URL de una imagen de código de barras para una etiqueta `<img>`, un feed de productos o una plantilla de etiquetas, sabrás cómo se validan los dígitos de control y los formatos, y sabrás cómo guardar códigos de barras en un espacio de trabajo para editarlos después.

`GET https://api.qrdx.dev/v1/barcode` devuelve una imagen de código de barras. Todo va en la cadena de consulta, así que la URL es la imagen. Dibuja los mismos formatos {facts.barcodeFormats} que el [generador de códigos de barras](/barcode-generator), con las mismas reglas, y devuelve el mismo SVG. No necesitas cuenta ni clave de API.

```html title="index.html"
<img
  src="https://api.qrdx.dev/v1/barcode?format=ean13&data=590123412345"
  alt="EAN-13 barcode 5901234123457"
/>
```

A ese número le falta un dígito, así que se añade el dígito de control (7). Si envías los 13 dígitos, se verifica el dígito de control: si es incorrecto, devuelve `400` e indica cuál debería ser.

## 1. Solicitar una imagen [#1-request-an-image]

<Tabs groupId="language" persist items={["curl", "JavaScript", "Python"]}>
  <Tab value="curl">
    ```bash title="Terminal"
    curl -o box.png "https://api.qrdx.dev/v1/barcode?format=ean13&data=5901234123457&type=png&scale=3"
    ```
  </Tab>
  <Tab value="JavaScript">
    ```js title="barcode.mjs"
    import { writeFile } from "node:fs/promises";

    const url = new URL("https://api.qrdx.dev/v1/barcode");
    url.search = new URLSearchParams({
      format: "ean13",
      data: "5901234123457",
      type: "png",
      scale: "3",
    }).toString();

    const response = await fetch(url);
    await writeFile("box.png", Buffer.from(await response.arrayBuffer()));
    ```
  </Tab>
  <Tab value="Python">
    ```python title="barcode.py"
    import requests

    response = requests.get(
        "https://api.qrdx.dev/v1/barcode",
        params={"format": "ean13", "data": "5901234123457", "type": "png", "scale": 3},
    )
    response.raise_for_status()
    open("box.png", "wb").write(response.content)
    ```
  </Tab>
</Tabs>

```txt title="Output"
200 image/png
box.png: PNG image data, 385 x 237, 8-bit/color RGBA, non-interlaced
```

En una shell, pon la URL entre comillas para conservar el `&`, y codifica los valores que contengan `&`, `#`, `+` o espacios, por ejemplo con `encodeURIComponent` en JavaScript.

## 2. Más ejemplos [#2-more-examples]

Un PDF vectorial de una etiqueta logística GS1-128, con paréntesis alrededor de cada Application Identifier:

```bash title="Terminal"
curl -o pallet.pdf "https://api.qrdx.dev/v1/barcode?format=gs1-128&type=pdf&data=(01)09501101530003(17)261231(10)AB-123"
# 200 application/pdf, 1 page
```

Una etiqueta de estantería Code 128 en azul oscuro, sin el texto bajo las barras, girada 90°:

```txt
https://api.qrdx.dev/v1/barcode?format=code128&data=SHELF-A12&fg=1e3a8a&text=false&rotate=90
```

Un Data Matrix con un margen más ancho:

```txt
https://api.qrdx.dev/v1/barcode?format=datamatrix&data=SN-0042-7781&quietZone=4
```

## 3. Mantener el valor fuera de la URL [#3-keep-the-value-out-of-the-url]

`POST https://api.qrdx.dev/v1/barcode` acepta los mismos campos como JSON y devuelve el mismo archivo, sin caché. Úsalo cuando el valor no deba acabar en registros, historiales o cachés como puede ocurrir con una URL:

```bash title="Terminal"
curl -o label.png https://api.qrdx.dev/v1/barcode \
  -H "Content-Type: application/json" \
  -d '{"format":"datamatrix","data":"Internal note 42","type":"png"}'
# 200 image/png, Cache-Control: no-store
```

En JSON, `text` es un booleano y `scale`, `height`, `quietZone` y `rotate` son números. Un cuerpo enviado sin `Content-Type: application/json` devuelve `415`:

```json title="415 Unsupported Media Type"
{"code":"UNSUPPORTED_MEDIA_TYPE","message":"Send a JSON body with Content-Type: application/json.","status":415}
```

## Parámetros [#parameters]

| Parámetro | Valor por defecto | Descripción |
| --- | --- | --- |
| `format` | obligatorio | El tipo de código de barras; consulta [Formatos](#formats). No importan las mayúsculas ni los guiones: `EAN-13` también funciona |
| `data` | obligatorio | El número o texto que se codifica, hasta 1.000 caracteres (menos en la mayoría de los formatos lineales) |
| `type` | `svg` | `svg`, `png`, `jpg`, `webp`, `avif`, `pdf` o `eps` |
| `scale` | `4` | Píxeles por módulo en PNG, JPG, WebP y AVIF, de `1` a `10` |
| `height` | depende del formato | Altura de las barras de los códigos lineales en milímetros al tamaño vectorial, de `5` a `60` (23 para EAN-13) |
| `quietZone` | el mínimo del formato | Margen en blanco en módulos: a cada lado en los códigos lineales (`0` a `20`), alrededor en los códigos 2D (`0` a `10`) |
| `text` | `true` | Imprime los dígitos o el texto bajo los códigos lineales |
| `fg` | `000000` | Barras y texto, en hexadecimal |
| `bg` | `ffffff` | Fondo, en hexadecimal |
| `rotate` | `0` | Giro en sentido horario: `0`, `90`, `180` o `270` |

Escribe los colores sin el `#`, o codifícalo como `%23`.

## Formatos [#formats]

| `format` | Código de barras | Admite |
| --- | --- | --- |
| `ean13` | EAN-13 | 12 dígitos (se añade el dígito de control) o 13 (se verifica) |
| `ean8` | EAN-8 | 7 dígitos u 8 |
| `upca` | UPC-A | 11 dígitos o 12 |
| `upce` | UPC-E | De 6 a 8 dígitos, o un UPC-A de 12 dígitos que se pueda abreviar |
| `itf14` | ITF-14 | 13 dígitos o 14 |
| `gs1-128` | GS1-128 | Application Identifiers entre paréntesis con sus valores; los dígitos de control de GTIN y SSCC se añaden o se verifican; hasta 48 caracteres de datos |
| `code128` | Code 128 | Hasta 80 caracteres ASCII imprimibles |
| `code39` | Code 39 | Hasta 40 mayúsculas, dígitos, espacios y `- . $ / + %` |
| `datamatrix` | Data Matrix | Cualquier texto de hasta 1.000 caracteres |
| `pdf417` | PDF417 | Cualquier texto de hasta 1.000 caracteres |
| `aztec` | Aztec | Cualquier texto de hasta 1.000 caracteres |

GS1 concede a las empresas licencias de los números de venta al por menor (EAN, UPC, ITF-14, el GTIN de GS1-128). La API dibuja cualquier número válido; no los emite ni los registra.

## Tamaños [#sizes]

PNG, JPG, WebP y AVIF usan `scale` píxeles por módulo, es decir, el ancho de la barra más estrecha. Una celda 2D mide dos módulos de ancho.

SVG, PDF y EPS son vectoriales, con un punto por módulo (0,353 mm), así que un EAN-13 con los valores por defecto mide unos 45 × 28 mm, alrededor del 107 % de su tamaño nominal. Escala los archivos vectoriales en tu diseño; en los códigos de barras de venta al por menor, mantén entre el 80 % y el 200 % y no recortes la altura de las barras.

## Respuestas [#responses]

Una solicitud correcta devuelve el archivo con:

- `Content-Type` del tipo de archivo. EPS llega como descarga (`Content-Disposition: attachment`); el resto se abre en línea con un nombre de archivo como `ean13-5901234123457.png`
- `Cache-Control: public, max-age=31536000, immutable` para `GET`: la misma consulta siempre devuelve los mismos bytes. Las respuestas de `POST` son `no-store`
- `Access-Control-Allow-Origin: *`, así que puedes usar `fetch` desde cualquier sitio web

## Códigos de barras guardados [#saved-barcodes]

Con una [clave de API](/docs/developers/api-keys), la REST API guarda códigos de barras en el espacio de trabajo de la clave, donde aparecen en **Barcodes** en el panel. Los permisos son los mismos que para los códigos: `codes:read` para listar y descargar, `codes:write` para modificar.

```bash title="Terminal"
curl https://api.qrdx.dev/v1/barcodes \
  -H "Authorization: Bearer $QRDX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"format":"ean13","value":"590123412345","title":"Spring box"}'
```

```json title="201 Created"
{
  "data": {
    "id": "cmwgwqcxo0003iscgecog7m1b",
    "title": "Spring box",
    "format": "ean13",
    "formatLabel": "EAN-13",
    "value": "5901234123457",
    "options": {
      "foreground": "#000000",
      "background": "#ffffff",
      "showText": true,
      "barHeightMm": 23,
      "quietZone": 11,
      "scale": 4,
      "rotation": 0
    },
    "folderId": null,
    "imageUrl": "https://qrdx.dev/api/v1/barcode?format=ean13&data=5901234123457",
    "createdAt": "2026-11-14T21:18:01.212Z",
    "updatedAt": "2026-11-14T21:18:01.212Z",
    "deletedAt": null,
    "organizationId": "ws_ad2c5e1cce31ccf31535e78f08ab5b78"
  }
}
```

El valor de 12 dígitos volvió con su dígito de control, y `options` contiene los valores por defecto del formato. Cada código de barras guardado tiene una `imageUrl`: la misma imagen de `GET /v1/barcode`, que puede cargar cualquiera que tenga el enlace. El endpoint `/image` de abajo es privado y necesita la clave.

| Endpoint | Qué hace |
| --- | --- |
| [`GET /v1/barcodes`](/docs/developers/api/list-barcodes) | Los lista, primero los modificados más recientemente; filtra con `q`, `format`, `folderId`, `status=trash` |
| [`POST /v1/barcodes`](/docs/developers/api/create-barcode) | Guarda uno. `options` admite `foreground`, `background`, `showText`, `barHeightMm`, `quietZone`, `scale` y `rotation` |
| [`GET /v1/barcodes/{id}`](/docs/developers/api/get-barcode) | Un código de barras |
| [`PATCH /v1/barcodes/{id}`](/docs/developers/api/update-barcode) | Cambia su título, formato, valor, opciones o carpeta |
| [`DELETE /v1/barcodes/{id}`](/docs/developers/api/delete-barcode) | Lo mueve a la papelera (`{ "deleted": false, "trashed": true }`); `?permanent=true` lo elimina definitivamente |
| [`GET /v1/barcodes/{id}/image`](/docs/developers/api/get-saved-barcode-image) | El archivo, dibujado tal como se guardó: `type` y `scale` como arriba. `Cache-Control: private, no-store` |

Todos los planes guardan códigos de barras: hasta 1.000 en Gratis, 10.000 en Pro y 100.000 en Business, sin contar la papelera. Estas solicitudes cuentan para la cuota diaria de API del espacio de trabajo y envían las cabeceras `X-RateLimit-*`, como el resto de la [REST API](/docs/developers/rest-api#rate-limits).

## Si algo sale mal [#if-something-goes-wrong]

### `400` con `"param": "data"` [#400-with-param-data]

El valor incumple las reglas del formato. El mensaje indica exactamente qué falla, ya sea un dígito de control, una longitud o un conjunto de caracteres:

```json title="400 Bad Request"
{"code":"VALIDATION_ERROR","message":"Invalid query parameters","data":{"details":[{"param":"data","message":"EAN-13: The check digit should be 7, not 8. Check the number, or leave the last digit off and it's worked out for you."}]},"status":400}
```

```json title="400 Bad Request"
{"code":"VALIDATION_ERROR","message":"Invalid query parameters","data":{"details":[{"param":"data","message":"Code 39: Code 39 has no lowercase letters. Use capitals, or Code 128 for mixed case."}]},"status":400}
```

### `400` con `"param": "format"` [#400-with-param-format]

Falta `format` o no es uno de los once ids de [Formatos](#formats). El mensaje los enumera.

### La imagen rasterizada se rechaza o se recorta [#the-raster-image-is-refused-or-cut]

Las imágenes rasterizadas miden como máximo 6.000 píxeles por lado. Reduce `scale` para valores largos, o usa SVG o PDF.

### `429 RATE_LIMITED` [#429-rate_limited]

Más de {facts.imageApiPerMinute} solicitudes por minuto desde una misma dirección IP, contando juntos `GET` y `POST /v1/barcode`. Espera los segundos indicados en `Retry-After`; las respuestas de `GET` se pueden almacenar en caché durante un año, así que carga cada imagen una sola vez.

## Límites [#limits]

- **Límite de frecuencia:** {facts.imageApiPerMinute} solicitudes por minuto y dirección IP para `GET` y `POST /v1/barcode`, igual que en la [API de imágenes QR](/docs/developers/image-api). Los códigos de barras guardados siguen los límites por minuto y la cuota diaria de la REST API.
- **Tamaño de imagen:** las imágenes rasterizadas miden como máximo 6.000 píxeles por lado.
- **Aquí no hay verificación de escaneo.** El [generador de códigos de barras](/barcode-generator) decodifica lo que dibuja antes de que lo descargues; la API dibuja lo que le pides. Imprime una prueba y escanéala con los lectores que lo van a leer.

## MCP [#mcp]

El [servidor MCP](/docs/developers/mcp) incluye `generate_barcode`, que comprueba el valor y devuelve un PNG con URL de imagen, y `save_barcode`, que guarda en el espacio de trabajo de la clave de API de la conexión.

## Alojamiento propio [#self-hosting]

Los endpoints forman parte de la aplicación web de QRdx, así que una instancia [autoalojada](/docs/self-hosting) los sirve en `/api/v1/barcode` y `/api/v1/barcodes` en tu propio dominio.
