Semua yang bisa dilakukan QRdx tersedia lewat kode. Mulailah dari apa yang ingin Anda bangun: setiap baris menyebutkan alatnya, apa yang dibutuhkan, dan halaman yang akan membawa Anda ke sana.

| Anda ingin | Gunakan | Membutuhkan |
| --- | --- | --- |
| Menaruh kode QR di halaman, email, atau README | [QR code image API](/docs/developers/image-api): URL `GET` yang langsung menjadi gambar | Tidak ada |
| Membuat barcode untuk label atau feed produk | [Barcode API](/docs/developers/barcode-api): sama seperti di atas, untuk EAN, UPC, Code 128, dan lainnya | Tidak ada |
| Membuat kode yang tujuannya bisa diubah setelah dicetak, dan membaca data pemindaiannya | [REST API](/docs/developers/quickstart): `POST /v1/codes`, `PATCH`, `GET …/scans` | [Kunci API](/docs/developers/api-keys) |
| Menanggapi pemindaian, kode baru, atau jawaban formulir di sistem Anda sendiri | [Webhook](/docs/webhooks): permintaan `POST` bertanda tangan ke URL Anda | Kunci API atau dasbor, paket Business |
| Membiarkan asisten AI membuat kode QR dalam obrolan | [Server MCP](/docs/developers/mcp): `https://mcp.qrdx.dev/mcp` | Tidak ada |
| Membuat kode QR dari skrip, proses build, atau CSV | [CLI](/docs/developers/cli): `npx @qrdx/cli` | Node.js 22 |
| Melukis kode QR ke dalam karya seni AI | [AI art API](/docs/developers/ai-art-api): `POST /v1/art` | Kunci API, gambar seni AI bulanan |
| Membiarkan orang lain menghubungkan akun QRdx mereka ke produk Anda | [Membangun integrasi](/docs/developers/build-an-integration): OAuth 2.0 dengan PKCE | Aplikasi OAuth |
| Mengotomatiskan QRdx di n8n | [Node n8n](/docs/developers/n8n): `@qrdx/n8n-nodes-qrdx` | n8n yang dihosting sendiri |
| Merender kode bergaya di dalam aplikasi React | [Pustaka React](/docs/getting-started): paket `qrdx` | npm |

## Permintaan pertama dalam dua menit [#first-request-in-two-minutes]

[Panduan memulai](/docs/developers/quickstart) membuat gambar kode QR dengan satu permintaan tanpa kunci, membuat kunci API, membuat kode dinamis, lalu mengarahkannya ke tujuan lain. Semua hal lain di halaman ini dibangun di atas empat langkah tersebut.

```bash title="Terminal"
curl "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=png" -o qr.png
```

## URL dasar dan autentikasi [#base-url-and-authentication]

REST API berada di `https://api.qrdx.dev/v1`. Rute yang sama juga dilayani di `https://qrdx.dev/api/v1`, dan instans [yang dihosting sendiri](/docs/self-hosting) melayaninya di `/api/v1` pada domainnya sendiri.

Permintaan membawa [kunci API](/docs/developers/api-keys) sebagai `Authorization: Bearer qrdx_…`. Kunci bekerja pada workspace tempat kunci itu dibuat, dengan peran Anda di sana. Aplikasi yang bertindak atas nama pengguna QRdx lain mengirim [token akses OAuth 2.0](/docs/developers/rest-api#get-an-access-token) pada header yang sama. Endpoint gambar, barcode, dan komunitas tidak membutuhkan keduanya.
