QRdx publie un registre shadcn/ui de composants de QR code basés sur la bibliothèque `qrdx`. La CLI shadcn copie le code source de chaque composant dans votre projet : le code vous appartient et vous pouvez le modifier. Utilisez le registre lorsque vous voulez un élément d'interface prêt à l'emploi, avec des boutons de téléchargement, une carte, une boîte de dialogue de partage ou un lecteur de scan ; utilisez le composant `QRCode` de la bibliothèque lorsque vous n'avez besoin que du code.

<NpmStatus package="qrdx" />

<PackageManagerTabs command="npx shadcn@latest add https://qrdx.dev/r/qr-code.json" />

Chaque composant a sa propre page avec un aperçu en direct, le code source, les étapes d'installation, des exemples et un tableau des props. Vous avez stylé un code dans le [Playground](/playground?open=code&lang=shadcn) ? Copiez-le depuis cette page pour obtenir le composant QR Code du registre.

## Ce qui est installé [#what-gets-installed]

Chaque composant est un fichier unique dans votre dossier `components`. La CLI installe aussi `qrdx` (ainsi que `lucide-react` pour les icônes utilisées par la plupart des composants) et ajoute les composants shadcn/ui sur lesquels il repose, comme `button`, `card`, `dialog`, `dropdown-menu`, `input` ou `label`. La page de chaque composant liste ses propres dépendances sous **Manual** dans les onglets d'installation.

L'index complet se trouve à l'adresse [`https://qrdx.dev/r/registry.json`](https://qrdx.dev/r/registry.json), et chaque élément à l'adresse `https://qrdx.dev/r/<name>.json`.

## Installer par nom [#install-by-name]

Pour installer avec un nom court, ajoutez le registre à votre `components.json` :

```json title="components.json"
{
  "registries": {
    "@qrdx": "https://qrdx.dev/r/{name}.json"
  }
}
```

Ajoutez ensuite un ou plusieurs composants par leur nom :

<PackageManagerTabs command="npx shadcn@latest add @qrdx/qr-code @qrdx/qr-code-download @qrdx/qr-code-share-dialog" />

## Style et thème [#styling-and-theming]

Les composants utilisent des classes Tailwind avec les jetons de thème standard de shadcn/ui (`bg-card`, `border`, `text-muted-foreground`, `ring-ring`) ainsi que vos propres Button, Card, Dialog et Input : ils suivent donc votre thème et le mode sombre. Les QR codes gardent par défaut un fond clair, car des modules sombres sur une tuile claire sont lus par tous les lecteurs ; la page [QR Code](/docs/components/qr-code#dark-mode) montre comment suivre plutôt le thème.

Chaque composant est un Client Component (son fichier commence par `"use client"`), en raison de ses boutons et de son état. Le code lui-même est tout de même rendu côté serveur : il est donc présent dans le HTML de la page avant que les boutons ne deviennent interactifs. Une page Server Component peut importer n'importe lequel d'entre eux et lui transmettre des données du serveur en props.

Les téléchargements PDF nécessitent le paquet optionnel `jspdf` (`npm install jspdf`). Tout le reste fonctionne dès que la CLI a terminé.
