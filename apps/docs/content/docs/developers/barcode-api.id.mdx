Setelah membaca halaman ini, Anda akan memiliki URL gambar barcode untuk tag `<img>`, feed produk, atau templat label, memahami cara digit pemeriksa dan format divalidasi, serta tahu cara menyimpan barcode ke workspace agar dapat diedit nanti.

`GET https://api.qrdx.dev/v1/barcode` mengembalikan gambar barcode. Semuanya ada di query string, sehingga URL itu sendiri adalah gambarnya. API ini menggambar format {facts.barcodeFormats} yang sama dengan [generator barcode](/barcode-generator), dengan aturan yang sama, dan menghasilkan SVG yang sama. Tidak perlu akun atau kunci API.

```html title="index.html"
<img
  src="https://api.qrdx.dev/v1/barcode?format=ean13&data=590123412345"
  alt="EAN-13 barcode 5901234123457"
/>
```

Angka tersebut kurang satu digit, sehingga digit pemeriksa (7) ditambahkan. Kirim ke-13 digit dan digit pemeriksa akan diverifikasi: digit yang salah mengembalikan `400` beserta nilai yang seharusnya.

## 1. Meminta gambar [#1-request-an-image]

<Tabs groupId="language" persist items={["curl", "JavaScript", "Python"]}>
  <Tab value="curl">
    ```bash title="Terminal"
    curl -o box.png "https://api.qrdx.dev/v1/barcode?format=ean13&data=5901234123457&type=png&scale=3"
    ```
  </Tab>
  <Tab value="JavaScript">
    ```js title="barcode.mjs"
    import { writeFile } from "node:fs/promises";

    const url = new URL("https://api.qrdx.dev/v1/barcode");
    url.search = new URLSearchParams({
      format: "ean13",
      data: "5901234123457",
      type: "png",
      scale: "3",
    }).toString();

    const response = await fetch(url);
    await writeFile("box.png", Buffer.from(await response.arrayBuffer()));
    ```
  </Tab>
  <Tab value="Python">
    ```python title="barcode.py"
    import requests

    response = requests.get(
        "https://api.qrdx.dev/v1/barcode",
        params={"format": "ean13", "data": "5901234123457", "type": "png", "scale": 3},
    )
    response.raise_for_status()
    open("box.png", "wb").write(response.content)
    ```
  </Tab>
</Tabs>

```txt title="Output"
200 image/png
box.png: PNG image data, 385 x 237, 8-bit/color RGBA, non-interlaced
```

Apit URL dengan tanda kutip di shell agar `&` tetap ada, dan enkode nilai yang mengandung `&`, `#`, `+`, atau spasi, misalnya dengan `encodeURIComponent` di JavaScript.

## 2. Contoh lainnya [#2-more-examples]

PDF vektor label logistik GS1-128, dengan tanda kurung di sekitar setiap Application Identifier:

```bash title="Terminal"
curl -o pallet.pdf "https://api.qrdx.dev/v1/barcode?format=gs1-128&type=pdf&data=(01)09501101530003(17)261231(10)AB-123"
# 200 application/pdf, 1 page
```

Label rak Code 128 berwarna biru tua, tanpa teks di bawah batang, diputar 90°:

```txt
https://api.qrdx.dev/v1/barcode?format=code128&data=SHELF-A12&fg=1e3a8a&text=false&rotate=90
```

Data Matrix dengan margin lebih lebar:

```txt
https://api.qrdx.dev/v1/barcode?format=datamatrix&data=SN-0042-7781&quietZone=4
```

## 3. Jauhkan nilai dari URL [#3-keep-the-value-out-of-the-url]

`POST https://api.qrdx.dev/v1/barcode` menerima kolom yang sama dalam bentuk JSON dan mengembalikan file yang sama, tanpa cache. Gunakan ini bila nilai tidak boleh tersimpan di log, riwayat, atau cache seperti halnya URL:

```bash title="Terminal"
curl -o label.png https://api.qrdx.dev/v1/barcode \
  -H "Content-Type: application/json" \
  -d '{"format":"datamatrix","data":"Internal note 42","type":"png"}'
# 200 image/png, Cache-Control: no-store
```

Dalam JSON, `text` bertipe boolean, sedangkan `scale`, `height`, `quietZone`, dan `rotate` berupa angka. Body yang dikirim tanpa `Content-Type: application/json` menghasilkan `415`:

```json title="415 Unsupported Media Type"
{"code":"UNSUPPORTED_MEDIA_TYPE","message":"Send a JSON body with Content-Type: application/json.","status":415}
```

## Parameter [#parameters]

| Parameter | Default | Deskripsi |
| --- | --- | --- |
| `format` | wajib | Jenis barcode; lihat [Format](#formats). Huruf besar/kecil dan tanda hubung tidak berpengaruh: `EAN-13` juga berfungsi |
| `data` | wajib | Angka atau teks yang di-enkode, hingga 1.000 karakter (lebih sedikit untuk sebagian besar format linear) |
| `type` | `svg` | `svg`, `png`, `jpg`, `webp`, `avif`, `pdf`, atau `eps` |
| `scale` | `4` | Piksel per modul pada PNG, JPG, WebP, dan AVIF, `1` sampai `10` |
| `height` | tergantung format | Tinggi batang barcode linear dalam milimeter pada ukuran vektor, `5` sampai `60` (23 untuk EAN-13) |
| `quietZone` | minimum format | Margin kosong dalam modul: di setiap sisi barcode linear (`0` sampai `20`), di sekeliling kode 2D (`0` sampai `10`) |
| `text` | `true` | Cetak digit atau teks di bawah barcode linear |
| `fg` | `000000` | Batang dan teks, dalam hex |
| `bg` | `ffffff` | Latar belakang, dalam hex |
| `rotate` | `0` | Rotasi searah jarum jam: `0`, `90`, `180`, atau `270` |

Tulis warna tanpa `#`, atau enkode sebagai `%23`.

## Format [#formats]

| `format` | Barcode | Menerima |
| --- | --- | --- |
| `ean13` | EAN-13 | 12 digit (digit pemeriksa ditambahkan) atau 13 (diperiksa) |
| `ean8` | EAN-8 | 7 digit atau 8 |
| `upca` | UPC-A | 11 digit atau 12 |
| `upce` | UPC-E | 6 sampai 8 digit, atau UPC-A 12 digit yang dapat dipersingkat |
| `itf14` | ITF-14 | 13 digit atau 14 |
| `gs1-128` | GS1-128 | Application Identifier dalam tanda kurung beserta nilainya; digit pemeriksa GTIN dan SSCC ditambahkan atau diperiksa; hingga 48 karakter data |
| `code128` | Code 128 | Hingga 80 karakter ASCII yang dapat dicetak |
| `code39` | Code 39 | Hingga 40 huruf kapital, digit, spasi, dan `- . $ / + %` |
| `datamatrix` | Data Matrix | Teks apa pun hingga 1.000 karakter |
| `pdf417` | PDF417 | Teks apa pun hingga 1.000 karakter |
| `aztec` | Aztec | Teks apa pun hingga 1.000 karakter |

Nomor ritel (EAN, UPC, ITF-14, GTIN pada GS1-128) dilisensikan kepada perusahaan oleh GS1. API ini menggambar nomor valid apa pun; API ini tidak menerbitkan atau mendaftarkannya.

## Ukuran [#sizes]

PNG, JPG, WebP, dan AVIF berukuran `scale` piksel per modul, yaitu lebar batang tersempit. Satu sel 2D selebar dua modul.

SVG, PDF, dan EPS adalah vektor dengan satu poin per modul (0,353 mm), sehingga EAN-13 pada pengaturan default berukuran sekitar 45 × 28 mm, sekitar 107% dari ukuran nominalnya. Skalakan file vektor di tata letak Anda; untuk barcode ritel, pertahankan antara 80% dan 200% dan jangan memotong tinggi batang.

## Respons [#responses]

Permintaan yang berhasil mengembalikan file dengan:

- `Content-Type` sesuai jenis file. EPS dikirim sebagai unduhan (`Content-Disposition: attachment`); yang lain dibuka langsung dengan nama file seperti `ean13-5901234123457.png`
- `Cache-Control: public, max-age=31536000, immutable` untuk `GET`: query yang sama selalu mengembalikan byte yang sama. Respons `POST` bersifat `no-store`
- `Access-Control-Allow-Origin: *`, sehingga Anda dapat memanggilnya dengan `fetch` dari situs web mana pun

## Barcode tersimpan [#saved-barcodes]

Dengan [kunci API](/docs/developers/api-keys), REST API menyimpan barcode di workspace milik kunci tersebut, tempat barcode muncul di bawah **Barcodes** di dasbor. Scope-nya sama seperti kode: `codes:read` untuk menampilkan daftar dan mengunduh, `codes:write` untuk mengubah.

```bash title="Terminal"
curl https://api.qrdx.dev/v1/barcodes \
  -H "Authorization: Bearer $QRDX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"format":"ean13","value":"590123412345","title":"Spring box"}'
```

```json title="201 Created"
{
  "data": {
    "id": "cmwgwqcxo0003iscgecog7m1b",
    "title": "Spring box",
    "format": "ean13",
    "formatLabel": "EAN-13",
    "value": "5901234123457",
    "options": {
      "foreground": "#000000",
      "background": "#ffffff",
      "showText": true,
      "barHeightMm": 23,
      "quietZone": 11,
      "scale": 4,
      "rotation": 0
    },
    "folderId": null,
    "imageUrl": "https://qrdx.dev/api/v1/barcode?format=ean13&data=5901234123457",
    "createdAt": "2026-11-14T21:18:01.212Z",
    "updatedAt": "2026-11-14T21:18:01.212Z",
    "deletedAt": null,
    "organizationId": "ws_ad2c5e1cce31ccf31535e78f08ab5b78"
  }
}
```

Nilai 12 digit dikembalikan beserta digit pemeriksanya, dan `options` berisi nilai default format. Setiap barcode tersimpan memiliki `imageUrl`: gambar yang sama dari `GET /v1/barcode`, yang dapat dimuat oleh siapa pun yang memiliki tautannya. Endpoint `/image` di bawah bersifat privat dan membutuhkan kunci.

| Endpoint | Fungsi |
| --- | --- |
| [`GET /v1/barcodes`](/docs/developers/api/list-barcodes) | Menampilkan daftar, perubahan terbaru lebih dulu; filter dengan `q`, `format`, `folderId`, `status=trash` |
| [`POST /v1/barcodes`](/docs/developers/api/create-barcode) | Menyimpan satu barcode. `options` menerima `foreground`, `background`, `showText`, `barHeightMm`, `quietZone`, `scale`, dan `rotation` |
| [`GET /v1/barcodes/{id}`](/docs/developers/api/get-barcode) | Satu barcode |
| [`PATCH /v1/barcodes/{id}`](/docs/developers/api/update-barcode) | Mengubah judul, format, nilai, opsi, atau folder |
| [`DELETE /v1/barcodes/{id}`](/docs/developers/api/delete-barcode) | Memindahkannya ke tempat sampah (`{ "deleted": false, "trashed": true }`); `?permanent=true` menghapusnya secara permanen |
| [`GET /v1/barcodes/{id}/image`](/docs/developers/api/get-saved-barcode-image) | File yang digambar sesuai penyimpanan: `type` dan `scale` seperti di atas. `Cache-Control: private, no-store` |

Setiap paket dapat menyimpan barcode: hingga 1.000 di Gratis, 10.000 di Pro, dan 100.000 di Business, tidak termasuk tempat sampah. Permintaan ini dihitung dalam kuota API harian workspace dan mengirim header `X-RateLimit-*`, seperti [REST API](/docs/developers/rest-api#rate-limits) lainnya.

## Jika terjadi masalah [#if-something-goes-wrong]

### `400` dengan `"param": "data"` [#400-with-param-data]

Nilai melanggar aturan format. Pesan menjelaskan dengan tepat apa masalahnya, baik digit pemeriksa, panjang, maupun kumpulan karakter:

```json title="400 Bad Request"
{"code":"VALIDATION_ERROR","message":"Invalid query parameters","data":{"details":[{"param":"data","message":"EAN-13: The check digit should be 7, not 8. Check the number, or leave the last digit off and it's worked out for you."}]},"status":400}
```

```json title="400 Bad Request"
{"code":"VALIDATION_ERROR","message":"Invalid query parameters","data":{"details":[{"param":"data","message":"Code 39: Code 39 has no lowercase letters. Use capitals, or Code 128 for mixed case."}]},"status":400}
```

### `400` dengan `"param": "format"` [#400-with-param-format]

`format` tidak ada atau bukan salah satu dari sebelas id di [Format](#formats). Pesan menampilkan daftarnya.

### Gambar raster ditolak atau terpotong [#the-raster-image-is-refused-or-cut]

Gambar raster berukuran paling besar 6.000 piksel per sisi. Turunkan `scale` untuk nilai yang panjang, atau gunakan SVG atau PDF.

### `429 RATE_LIMITED` [#429-rate_limited]

Melebihi {facts.imageApiPerMinute} permintaan per menit dari satu alamat IP, untuk `GET` dan `POST /v1/barcode` secara gabungan. Tunggu sejumlah detik pada `Retry-After`; respons `GET` dapat di-cache selama setahun, jadi muat setiap gambar sekali saja.

## Batasan [#limits]

- **Batas laju:** {facts.imageApiPerMinute} permintaan per menit per alamat IP untuk `GET` dan `POST /v1/barcode`, seperti pada [API gambar kode QR](/docs/developers/image-api). Barcode tersimpan mengikuti batas per menit dan kuota harian REST API.
- **Ukuran gambar:** gambar raster berukuran paling besar 6.000 piksel per sisi.
- **Tidak ada pemeriksaan pemindaian di sini.** [Generator barcode](/barcode-generator) mendekode hasil gambarnya sebelum Anda mengunduh; API menggambar apa yang Anda minta. Cetak uji coba dan pindai dengan pemindai yang akan membacanya.

## MCP [#mcp]

[Server MCP](/docs/developers/mcp) memiliki `generate_barcode`, yang memeriksa nilai dan mengembalikan PNG beserta URL gambar, dan `save_barcode`, yang menyimpan ke workspace milik kunci API pada koneksi tersebut.

## Hosting mandiri [#self-hosting]

Endpoint ini adalah bagian dari aplikasi web QRdx, sehingga instans [hosting mandiri](/docs/self-hosting) menyajikannya di `/api/v1/barcode` dan `/api/v1/barcodes` pada domain Anda sendiri.
