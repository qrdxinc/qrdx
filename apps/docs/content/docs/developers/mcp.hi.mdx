इस पेज के अंत तक आपका AI असिस्टेंट QR कोड बना सकेगा: किसी भी कंटेंट के लिए चेक किए गए स्कैन स्कोर के साथ QR कोड डिज़ाइन करना, उसे एडिटर की स्टाइल में रेंडर करना, Wi-Fi, कॉन्टैक्ट, ईमेल, SMS, लोकेशन और बैंक पेमेंट के लिए सही पेलोड बनाना, कम्युनिटी फ़्रेम ढूँढना और बारकोड बनाना। कनेक्शन में API key जोड़ने पर वह डिज़ाइन और बारकोड आपके वर्कस्पेस में सेव भी कर सकता है और AI आर्ट भी पेंट कर सकता है।

QRdx एक पब्लिक [Model Context Protocol](https://modelcontextprotocol.io) सर्वर चलाता है:

```txt title="Server URL"
https://mcp.qrdx.dev/mcp
```

यह Streamable HTTP ट्रांसपोर्ट इस्तेमाल करता है, कोई सेशन स्टेट नहीं रखता और इसके लिए अकाउंट, साइन-इन या API key की ज़रूरत नहीं है। यही सर्वर `https://qrdx.dev/api/mcp` पर भी जवाब देता है, और [कनेक्ट पेज](/mcp) पर वन-क्लिक बटन हैं और इस पेज से ज़्यादा क्लाइंट के स्टेप्स भी हैं।

[Playground में आज़माएँ](/playground?open=code&lang=mcp): वहाँ कोड को स्टाइल करें, फिर उसे `design_qr` आर्ग्युमेंट्स के रूप में अपने असिस्टेंट के लिए कॉपी करें।

## 1. क्लाइंट कनेक्ट करें [#1-connect-a-client]

    2. नाम `QRdx` रखें और `https://mcp.qrdx.dev/mcp` डालें। OAuth फ़ील्ड खाली छोड़ें।
    3. **Add** चुनें, फिर चैट के टूल्स मेन्यू से QRdx चालू करें।

    फ़्री प्लान में एक कस्टम कनेक्टर जोड़ा जा सकता है। Team और Enterprise प्लान में ओनर पूरे संगठन के लिए कनेक्टर जोड़ता है।

## 2. कोड माँगें [#2-ask-for-a-code]

फिर सीधे सादे शब्दों में माँगें। ये प्रॉम्प्ट जैसे लिखे हैं वैसे ही काम करते हैं:

```txt title="Prompts"
Make a QR code for https://example.com in our brand blue, #155dfc, with rounded modules.
Create a Wi-Fi QR code for the network Office Guest with password correct-horse-battery.
Design a Wi-Fi QR code for Cafe Guest in warm browns with a Free Wi-Fi banner, and tell me its scan score.
Generate a contact QR code for Ada Lovelace, ada@example.com, and add it to the README.
Find a community frame for a restaurant menu and use it for https://example.com/menu.
Draw an EAN-13 barcode for 590123412345 as a PNG.
```

पहले प्रॉम्प्ट के लिए असिस्टेंट `generate_qr_code` कॉल करता है और उसे PNG और ये लाइनें वापस मिलती हैं, जो सीधे पेस्ट करने के लिए तैयार हैं:

```txt title="generate_qr_code result"
QR code, 512x512px, error correction Q.
SVG URL: https://api.qrdx.dev/v1/qr?data=https%3A%2F%2Fexample.com&fg=155dfc&body=rounded
PNG URL: https://api.qrdx.dev/v1/qr?data=https%3A%2F%2Fexample.com&format=png&fg=155dfc&body=rounded
WebP URL (lossless, smaller than PNG): https://api.qrdx.dev/v1/qr?data=https%3A%2F%2Fexample.com&format=webp&fg=155dfc&body=rounded
EPS URL (vector, for print; 512 pt wide): https://api.qrdx.dev/v1/qr?data=https%3A%2F%2Fexample.com&format=eps&fg=155dfc&body=rounded
Markdown: ![QR code](https://api.qrdx.dev/v1/qr?data=https%3A%2F%2Fexample.com&fg=155dfc&body=rounded)
```

दूसरे के लिए वह `qr_payload_wifi` कॉल करता है, जो `WIFI:T:WPA;S:Office Guest;P:correct-horse-battery;;` लौटाता है, और उस स्ट्रिंग को `generate_qr_code` में `data` के रूप में या `design_qr` के कंटेंट के रूप में पास करता है।

## Tools [#tools]

| Tool | यह क्या करता है |
| --- | --- |
| `design_qr` | किसी भी कंटेंट टाइप के लिए कोड डिज़ाइन करता है। स्टाइल आपका असिस्टेंट चुनता है, या आप किसी बिल्ट-इन थीम या कम्युनिटी आइटम से शुरू कर सकते हैं। यह उसका स्कैन स्कोर जाँचता है और स्टाइल को तब तक ठीक करता है जब तक वह Great न हो जाए। यह स्कोर, क्या बदला गया, स्टाइल JSON, एक playground लिंक, एक PNG और SVG लौटाता है |
| `list_options` | `design_qr` जो भी वैल्यू स्वीकार करता है, उन सबकी सूची देता है: कंटेंट टाइप और उनके फ़ील्ड, रंग और ग्रेडिएंट, शेप, फ़्रेम (QRdx के आधिकारिक फ़्रेम की id के साथ), बॉर्डर, लोगो आइकन और ब्रांड लोगो, बिल्ट-इन थीम, एरर करेक्शन लेवल और सीमाएँ |
| `generate_qr_code` | एडिटर की स्टाइल के साथ QR कोड रेंडर करता है। यह एक PNG इमेज और सार्वजनिक [image API](/docs/developers/image-api) URL (SVG, PNG, लॉसलेस WebP और वेक्टर EPS) लौटाता है, जो Markdown, HTML या प्रिंट के लिए तैयार हैं। माँगने पर SVG मार्कअप भी देता है |
| `list_qr_styles` | बॉडी पैटर्न, कॉर्नर आई और आई डॉट शेप, फ़्रेम (बिल्ट-इन स्टाइल और टेम्पलेट के रूप में बनाए गए), लोगो आइकन, एरर करेक्शन लेवल, डिफ़ॉल्ट और सीमाओं की सूची देता है |
| `search_community` | प्रकाशित [कम्युनिटी](/community) फ़्रेम, थीम और कलेक्शन शब्दों, टाइप या टैग से खोजता है |
| `get_community_item` | एक कम्युनिटी आइटम, उसकी लागू होने वाली स्टाइल के साथ, जो `design_qr` या `generate_qr_code` के लिए तैयार है |
| `save_template` | किसी डिज़ाइन को आपके वर्कस्पेस में थीम के रूप में सेव करता है। इसके लिए [API key](#use-an-api-key) चाहिए |
| `generate_barcode` | वैल्यू जाँचने (चेक डिजिट, लंबाई, अक्षर) के बाद EAN-13, UPC-A, UPC-E, EAN-8, ITF-14, GS1-128, Code 128, Code 39, Data Matrix, PDF417 या Aztec बारकोड बनाता है। यह एक PNG और सार्वजनिक [barcode API](/docs/developers/barcode-api) URL लौटाता है |
| `save_barcode` | बारकोड को आपके वर्कस्पेस के Barcodes में सेव करता है। इसके लिए [API key](#use-an-api-key) चाहिए |
| `generate_ai_art` | QR कोड को AI आर्टवर्क में पेंट करता है और जाँचता है कि वह स्कैन होता है। यह वर्कस्पेस की मासिक AI art इमेज में से एक इस्तेमाल करता है और इसमें एक मिनट तक लग सकता है। इसके लिए [API key](#use-an-api-key) चाहिए। देखें [AI art API](/docs/developers/ai-art-api) |
| `qr_payload_wifi` | विशेष अक्षरों को एस्केप करके `WIFI:` नेटवर्क पेलोड बनाता है (WPA, WEP या ओपन, चाहें तो हिडन) |
| `qr_payload_vcard` | vCard 3.0 कॉन्टैक्ट (RFC 2426) बनाता है: नाम, संगठन, पद, फ़ोन, ईमेल, वेबसाइट, पता और नोट |
| `qr_payload_email` | वैकल्पिक cc, bcc, विषय और बॉडी के साथ `mailto:` लिंक (RFC 6068) बनाता है |
| `qr_payload_sms` | वैकल्पिक संदेश के साथ `sms:` लिंक (RFC 5724) बनाता है, या पुराना `SMSTO:` रूप |
| `qr_payload_geo` | अक्षांश और देशांतर से `geo:` लोकेशन (RFC 5870) बनाता है |
| `qr_payload_payment` | बैंक पेमेंट कोड बनाता है: Pix BR Code, SEPA क्रेडिट ट्रांसफ़र (EPC069-12), या PayNow, PromptPay या VietQR कोड (EMV, अपने CRC के साथ)। यह फ़ील्ड्स को वैसे ही जाँचता है जैसे Playground के फ़ॉर्म जाँचते हैं |

पेलोड टूल एक सादी स्ट्रिंग लौटाते हैं। आपका असिस्टेंट फिर उसे `data` के रूप में `generate_qr_code` को देता है।

### design_qr [#design_qr]

`design_qr` कंटेंट को एक टाइप और उसके फ़ील्ड के रूप में लेता है (वही टाइप और जाँच जो एडिटर के कंटेंट फ़ॉर्म में हैं; `list_options` उन्हें सूचीबद्ध करता है), और एक वैकल्पिक स्टाइल:

```json title="design_qr arguments"
{
  "content": { "type": "wifi", "ssid": "Cafe Guest", "password": "sunshine123", "encryption": "WPA" },
  "style": {
    "bgColor": "#FFF7ED",
    "fgColor": "#9A3412",
    "bodyPattern": "rounded",
    "cornerEyePattern": "rounded",
    "frame": { "style": "banner-bottom", "text": "Free Wi-Fi" }
  }
}
```

```txt title="design_qr result (first lines)"
Scan score 85/100 (great). No changes were needed. Content: WiFi · Cafe Guest (47 bytes). Open it in the playground: https://qrdx.dev/playground?style=1.eyJiIjoiI0ZGRjdFRCIs…&ref=mcp
```

नतीजे के JSON में `payload` (कोड में एन्कोड होने वाली सटीक स्ट्रिंग), `style`, `qrdxStyle`, `score`, `grade`, `stillFailing` (वे जाँचें जो अब भी फ़ेल हैं, हर एक के सुधार के साथ), `repairs`, `changes` और `playgroundUrl` होते हैं, और उसके बाद PNG और SVG आते हैं।

जो विकल्प आप छोड़ देते हैं उन्हें डिफ़ॉल्ट मिलते हैं (आँखें डॉट के रंग का पालन करती हैं, चौकोर शेप, मार्जिन 4, एरर करेक्शन Q, कोई फ़्रेम नहीं)। फिर QRdx डिज़ाइन पर एडिटर की स्कैन जाँच चलाता है: वह कोड रेंडर करता है, उसे फ़ोन-कैमरा मॉडल से 96, 160 और 320 px पर डिकोड करता है, और कंट्रास्ट, क्वाइट ज़ोन, आई शेप और शेप जोड़ियों की जाँच करता है। Great (85) से नीचे होने पर वह स्टाइल को तीन बार तक ठीक करता है, जितना हो सके कम बदलाव करते हुए (गहरे रंग जो अपनी hue रखते हैं, ज़्यादा सुरक्षित आई शेप, लंबे कंटेंट के लिए कम एरर करेक्शन)। अगर यह काफ़ी न हो, तो वह आपके फ़्रेम के साथ क्लासिक काले-सफ़ेद कोड पर लौट जाता है। नतीजा बताता है कि क्या बदला गया और क्यों।

`design_qr` के लिए QRdx की ओर से कोई AI मॉडल नहीं चलता: स्टाइल आपका असिस्टेंट चुनता है, QRdx उसे वैलिडेट, जाँचता और ठीक करता है। अमान्य कंटेंट (8 अक्षरों से छोटा WPA पासवर्ड, गलत बना ईमेल पता) कारण के साथ अस्वीकार कर दिया जाता है। `design_qr` की अपनी सीमा है: प्रति IP पता {facts.designQrPerMinute} कॉल प्रति मिनट।

और इनपुट:

- **`preset`**: id से किसी बिल्ट-इन थीम से शुरू करें (`list_options` उन्हें सूचीबद्ध करता है)। आपके सेट किए स्टाइल विकल्प उस पर भारी पड़ते हैं।
- **`community_item`**: id से किसी कम्युनिटी फ़्रेम या थीम से शुरू करें, जैसे `frame:wifi-card`। फ़्रेम आइटम क्लासिक कोड पर बैठता है; आपके स्टाइल विकल्प उसके नीचे का कोड बदलते हैं। QRdx के आधिकारिक फ़्रेम भी कम्युनिटी आइटम हैं, इसलिए `frame:diwali-diya` या `frame:menu-cutlery` यहाँ काम करता है।
- **कस्टम फ़्रेम**: `style.frame` फ़्रेम स्पेक के साथ `{ "style": "custom", "spec": … }` हो सकता है, जैसे `get_community_item` से मिला किसी कम्युनिटी फ़्रेम का स्पेक। वह जैसा है वैसा ही बनाया और स्कोर किया जाता है; रिपेयर कोड बदलते हैं, फ़्रेम कभी नहीं।
- **`style.logo`**: एक क्विक लोगो आइकन (`wifi`, `location`, `phone`, `email`, `link`, `file`, `calendar`, `whatsapp` या `instagram`), या [Simple Icons](https://simpleicons.org) स्लग से कोई ब्रांड लोगो (`spotify`, `paypal:white`)। `list_options` लोकप्रिय ब्रांड स्लग सूचीबद्ध करता है।
- **इंजन विकल्प**: `style.eyeColors` (हर आँख के लिए `#RRGGBB` रंग), `moduleScale` (डॉट का आकार, `0.5` से `1`), `shape` (गोल कोड के लिए `circle`), `autoLevel` और `logoOptions` (लोगो का आकार, खाली जगह, स्थिति, क्रॉप और प्लेट)। ये जैसे दिए गए हैं वैसे ही बनाए और स्कोर किए जाते हैं; रिपेयर इन्हें नहीं बदलते।

<IfAvailable feature="fileStorage">
`logo_file_id` इसके बजाय आपका QRdx पर अपलोड किया हुआ लोगो बनाता है, [API key](#use-an-api-key) के साथ।
</IfAvailable>

लोगो का स्कोर उन मॉड्यूल के हिसाब से होता है जिन्हें वे ढकते हैं, जैसा एडिटर में होता है, इसलिए रिपेयर एरर करेक्शन को H तक बढ़ा सकता है या लोगो हटा सकता है। एडिटर में डिफ़ॉल्ट रूप से दिखने वाला QRdx मार्क यहाँ नहीं बनाया जाता।

नतीजे का `qrdxStyle` एडिटर के स्टाइल JSON के रूप में डिज़ाइन है। इसे `save_template` को दें, किसी दूसरे आकार में वही डिज़ाइन रेंडर करने के लिए `style` के रूप में `generate_qr_code` को दें, या image API के [`style`](/docs/developers/image-api#style) को दें। `playground_url` डिज़ाइन को [Playground](/playground) में खोलता है: इसमें सिर्फ़ स्टाइल होती है, लोगो या कंटेंट कभी नहीं, और `playgroundLeftOut` बताता है कि क्या छोड़ा गया है।

### generate_qr_code [#generate_qr_code]

इनपुट [image API पैरामीटर](/docs/developers/image-api#parameters) से मेल खाते हैं: `data` (ज़रूरी), `size`, `fg`, `bg`, `eyeColor`, `dotColor`, `body`, `eye`, `dot`, `level`, `margin`, `template`, `frame`, `frameText`, `logoIcon`, `logoFileId`, `item` (कम्युनिटी आइटम id) और `style` (एडिटर का स्टाइल JSON: ग्रेडिएंट, कस्टम फ़्रेम और बाकी सब, जैसा `design_qr` लौटाता है)। फ़्लैट विकल्प `style` पर भारी पड़ते हैं, और `style` `item` पर। SVG मार्कअप को टेक्स्ट के रूप में भी पाने के लिए `include_svg` को `true` करें, जैसे `.svg` फ़ाइल सेव करने के लिए। यह डिफ़ॉल्ट रूप से बंद है क्योंकि मार्कअप अक्सर 50 से 150 KB का होता है, जो बातचीत को भर देगा।

`generate_qr_code` स्कैन स्कोर नहीं जाँचता; उसके लिए `design_qr` इस्तेमाल करें। आपके अपलोड किए लोगो वाले कोड का कोई सार्वजनिक इमेज URL नहीं होता, क्योंकि image API वह लोगो सिर्फ़ आपकी key वाले अनुरोधों के लिए बनाता है।

### QR कार्ड [#qr-card]

जो ऐप [MCP Apps](https://modelcontextprotocol.io/extensions/apps/overview) को सपोर्ट करते हैं, उनमें `design_qr` और `generate_qr_code` चैट में एक QR कार्ड भी दिखाते हैं। इसमें कोड, वह जो एन्कोड करता है (Wi-Fi कोड नेटवर्क का नाम दिखाता है, पासवर्ड कभी नहीं), आकार और एरर करेक्शन या स्कैन स्कोर, और एक **Open in editor** बटन होता है। एडिटर लिंक में `playground_url` की तरह सिर्फ़ स्टाइल होती है।

PNG और SVG बटन इस पर निर्भर करते हैं कि ऐप क्या अनुमति देता है। जहाँ ऐप कार्ड से फ़ाइलें सेव कर सकता है, वहाँ वे फ़ाइलें सेव करते हैं। नहीं तो वे image API URL को आपके ब्राउज़र में खोलते हैं, इसलिए `design_qr` का कार्ड उन्हें सिर्फ़ उन ऐप में दिखाता है जो फ़ाइलें सेव करते हैं: उसका कंटेंट कभी इमेज URL में नहीं जाता। ऐप लिंक खुलने से पहले आपसे पुष्टि माँग सकते हैं।

MCP Apps के बिना ऐप को पहले जैसा ही टेक्स्ट और इमेज मिलता है। क्लाइंट डेवलपर्स के लिए:

- कार्ड रिसोर्स `ui://qrdx/qr-card` (`text/html;profile=mcp-app`) है, जो `resources/list` में सूचीबद्ध है। दोनों टूल `_meta.ui.resourceUri` से उसकी ओर इशारा करते हैं।
- उसका डेटा टूल नतीजे के `_meta` में `dev.qrdx/qr-card` के अंतर्गत आता है, जो कार्ड के लिए है, मॉडल के लिए नहीं। टूल कोई `structuredContent` नहीं लौटाते।
- कार्ड एक अकेली HTML फ़ाइल है जिसकी स्टाइल और स्क्रिप्ट उसी में इनलाइन हैं। वह सिर्फ़ image API से कोड की इमेज लोड करता है (`https://api.qrdx.dev`, या सेल्फ़-होस्ट करने पर आपका अपना डोमेन), और उसकी content security policy (`_meta.ui.csp.resourceDomains`) सिर्फ़ उसी होस्ट को अनुमति देती है, किसी और को नहीं।

अगर आपने कार्ड आने से पहले QRdx कनेक्ट किया था, तो कनेक्टर हटाकर दोबारा जोड़ें, या उसके टूल रिफ़्रेश करें, ताकि ऐप नया टूल मेटाडेटा ले सके।

### कम्युनिटी [#community]

`search_community` प्रकाशित [कम्युनिटी](/community) फ़्रेम, थीम और कलेक्शन खोजता है, जो CC0 के तहत फ़्री हैं, शब्दों (`q`), `type` और `tag` से। `get_community_item` एक आइटम उसकी लागू होने वाली स्टाइल के साथ लौटाता है; उसकी id को `design_qr` को `community_item` के रूप में या `generate_qr_code` को `item` के रूप में दें। यही डेटा REST API पर [`/v1/community/items`](/docs/developers/api/list-community-items) पर है।

आइटम का टेक्स्ट कम्युनिटी सदस्य लिखते हैं। नाम, विवरण, हैंडल, टैग और फ़्रेम लेबल छोटे, एक लाइन में, और बिना लिंक, ईमेल या मार्कअप के लौटते हैं, और हर नतीजा कहता है कि इन्हें निर्देश नहीं, डेटा मानें।

## API key का उपयोग करें [#use-an-api-key]

कुछ tools के लिए कनेक्शन पर QRdx [API key](/docs/developers/api-keys) चाहिए, जिसे `Authorization: Bearer qrdx_…` के रूप में भेजा जाता है:

- **`save_template`** एक डिज़ाइन को थीम के रूप में सेव करता है। यह डैशबोर्ड में Themes के अंतर्गत दिखती है और एडिटर में उपलब्ध होती है। इसके लिए `codes:write` वाली key चाहिए, जो **Full access** keys में होती है। आपके अपने workspace की key आपकी थीम में सेव करती है; टीम की key तब टीम की साझा थीम में सेव करती है जब उसे बनाने वाला owner या admin हो और प्लान में टीम थीम शामिल हों। सेव करने पर प्लान की सेव की गई थीम की सीमा में गिनती होती है (देखें [प्लान और सीमाएँ](/docs/plans-and-limits)); सीमा पार होने पर tool API की `LIMIT_REACHED` एरर (`402`) लौटाता है।
- **`save_barcode`** एक बारकोड (फ़ॉर्मैट, वैल्यू, वैकल्पिक टाइटल और ड्रॉइंग विकल्प) key के workspace में सेव करता है, जो डैशबोर्ड में Barcodes के अंतर्गत दिखता है। इसके लिए `codes:write` वाली key चाहिए। हर प्लान में बारकोड सेव होते हैं, फ़्री में 1,000 तक; सीमा पार होने पर यह `LIMIT_REACHED` (`402`) लौटाता है।
- **`generate_ai_art`** किसी QR कोड को AI आर्टवर्क में बदलता है। इनपुट कोई link, टेक्स्ट या id से चुना गया डायनेमिक QR कोड हो सकता है। QRdx जाँच लेता है कि वह स्कैन होता है, उसके बाद यह PNG लौटाता है। इसमें वही फ़ील्ड हैं जो [`POST /v1/art`](/docs/developers/ai-art-api) में हैं, और इसके लिए `codes:write` वाली key चाहिए। हर इमेज key के workspace की मासिक AI art इमेज में से एक इस्तेमाल करती है, और एक कॉल में एक मिनट तक लग सकता है।
<IfAvailable feature="fileStorage">
- **आपके अपलोड किए हुए लोगो**, [Dashboard → Files](/docs/files) में, file id से (`design_qr` में `logo_file_id`, `generate_qr_code` में `logoFileId`): 1 MB तक की PNG या JPEG। key उसी workspace की होनी चाहिए जिसके पास वह फ़ाइल है।
</IfAvailable>

## अगर कुछ गड़बड़ हो जाए [#if-something-goes-wrong]

### क्लाइंट कनेक्ट नहीं हो पा रहा [#the-client-cant-connect]

जाँचें कि URL ठीक `https://mcp.qrdx.dev/mcp` है और transport HTTP (Streamable HTTP) है, SSE या stdio नहीं। जो क्लाइंट सिर्फ़ लोकल सर्वर चलाते हैं, उन्हें ऊपर बताया गया `mcp-remote` ब्रिज चाहिए। URL को ब्राउज़र में खोलने पर connect पेज पर रीडायरेक्ट होता है, यह सामान्य है: MCP क्लाइंट कभी HTML नहीं माँगते।

### असिस्टेंट कहता है कि किसी tool के लिए API key चाहिए [#the-assistant-says-a-tool-needs-an-api-key]

`save_template`, `save_barcode`, `generate_ai_art` और अपलोड किए गए लोगो के लिए कनेक्शन पर `Authorization: Bearer qrdx_…` चाहिए। ऊपर दिखाए अनुसार header जोड़ें और दोबारा कनेक्ट करें।

### `design_qr` कंटेंट को अस्वीकार करता है [#design_qr-refuses-the-content]

कंटेंट एडिटर के फ़ॉर्म वाली जाँचों में फ़ेल हुआ: 8 अक्षरों से छोटा WPA पासवर्ड, गलत ईमेल पता, या सीमा से बाहर पेमेंट फ़ील्ड। कारण जवाब में दिया होता है; `list_options` हर कंटेंट टाइप के फ़ील्ड और नियम बताता है।

### बहुत ज़्यादा requests [#too-many-requests]

सर्वर प्रति IP address प्रति मिनट {facts.mcpPerMinute} requests की अनुमति देता है, और `design_qr` के लिए {facts.designQrPerMinute}। key के साथ `save_template` प्रति user प्रति मिनट 30 तक सीमित भी है। एक मिनट रुकें और दोबारा कोशिश करें।

## प्राइवेसी और सीमाएँ [#privacy-and-limits]

- ये tools इमेज बनाते हैं, डिज़ाइन जाँचते हैं, टेक्स्ट फ़ॉर्मैट करते हैं और पब्लिक कम्युनिटी पढ़ते हैं। सिर्फ़ `save_template` और `save_barcode` कुछ लिखते हैं: जो थीम या बारकोड आप सेव करने को कहें, API key के workspace में। `generate_ai_art` workspace की मासिक AI art इमेज में से एक इस्तेमाल करता है, और न इमेज रखता है न आपकी भेजी फ़ोटो। सर्वर आपके बनाए कोड सेव नहीं करता।
- `generate_qr_code` और `generate_barcode` जो इमेज URL लौटाते हैं, उनमें एन्कोड किया गया डेटा होता है। अगर डेटा निजी है, जैसे Wi-Fi पासवर्ड, तो उन्हें साझा न करें।
- Requests प्रति IP address प्रति मिनट {facts.mcpPerMinute} तक सीमित हैं, और `design_qr` के लिए {facts.designQrPerMinute}।

## Self-hosting और लोकल डेवलपमेंट [#self-hosting-and-local-development]

MCP सर्वर QRdx वेब ऐप का हिस्सा है, इसलिए हर इंस्टेंस इसे `/api/mcp` पर चलाता है:

- **Self-hosted।** जब `NEXT_PUBLIC_APP_URL` आपका अपना डोमेन हो, तो connect पेज, snippets और install links `https://<your-domain>/api/mcp` इस्तेमाल करते हैं।
- **लोकल डेवलपमेंट।** `bun run dev` इसे `http://localhost:3000/api/mcp` पर चलाता है। connect पेज अब भी पब्लिक URL दिखाता है और लोकल URL संकेत के रूप में देता है, ताकि आप सर्वर में बदलाव रिलीज़ होने से पहले अपनी मशीन पर किसी क्लाइंट को जोड़कर टेस्ट कर सकें।
