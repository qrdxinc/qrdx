이 페이지를 끝까지 따라 하면 README, `<img>` 태그, 이메일 템플릿에 붙여 넣을 수 있는 QR 코드 이미지 URL을 원하는 스타일로 만들 수 있습니다. 또한 API가 어떤 요청을 거부하는지와 그 이유도 알게 됩니다.

`GET https://api.qrdx.dev/v1/qr`는 QR 코드를 SVG, PNG, WebP 이미지로 반환하며, 인쇄와 디자인 도구용 벡터 EPS 파일로도 반환합니다. 모든 설정이 쿼리 문자열에 들어 있으므로 URL 자체가 이미지입니다. 에디터의 스타일도 그대로 사용할 수 있습니다. 그라디언트, 프레임(사용자 지정 프레임 포함), 테두리, 눈 색상과 점 색상, 로고 아이콘을 지원합니다. QRdx에 업로드한 로고를 쓰는 경우(자세한 내용은 [로고](#logos) 참고)를 제외하면 계정이나 API 키가 필요하지 않습니다.

```md title="README.md"
![QR code](https://api.qrdx.dev/v1/qr?data=https://github.com/you/repo)
```

[Playground에서 사용해 보기](/playground?open=code&lang=image): 그곳에서 코드를 꾸민 뒤 이미지 URL을 복사하세요. 또는 [QR 코드 이미지 렌더링](/docs/developers/api/get-qr-image) 레퍼런스 페이지에서 요청을 직접 보낼 수 있습니다.

## 1. 이미지 요청하기 [#1-request-an-image]

<Tabs groupId="language" persist items={["curl", "JavaScript", "Python"]}>
  <Tab value="curl">
    ```bash title="Terminal"
    curl -o qr.png "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=png&size=1024"
    ```
  </Tab>
  <Tab value="JavaScript">
    ```js title="qr.mjs"
    import { writeFile } from "node:fs/promises";

    const url = new URL("https://api.qrdx.dev/v1/qr");
    url.searchParams.set("data", "https://qrdx.dev");
    url.searchParams.set("format", "png");
    url.searchParams.set("size", "1024");

    const response = await fetch(url);
    await writeFile("qr.png", Buffer.from(await response.arrayBuffer()));
    ```
  </Tab>
  <Tab value="Python">
    ```python title="qr.py"
    import requests

    response = requests.get(
        "https://api.qrdx.dev/v1/qr",
        params={"data": "https://qrdx.dev", "format": "png", "size": 1024},
    )
    response.raise_for_status()
    open("qr.png", "wb").write(response.content)
    ```
  </Tab>
</Tabs>

```txt title="Output"
qr.png: PNG image data, 1024 x 1024, 8-bit/color RGBA, non-interlaced
```

셸에서는 `&`가 유지되도록 URL을 따옴표로 감싸세요. HTML 페이지에서는 URL을 `src`에 그대로 넣으면 됩니다.

```html title="index.html"
<img
  src="https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&size=256&fg=155dfc"
  width="256"
  height="256"
  alt="QR code for qrdx.dev"
/>
```

## 2. 형식 선택하기 [#2-pick-a-format]

| `format` | 반환 값 | 사용 시점 |
| --- | --- | --- |
| `svg` (기본값) | `image/svg+xml` | 웹 페이지와 크기를 조절하는 모든 곳 |
| `png` | `image/png` | 이메일, 채팅 앱, 문서 |
| `webp` | `image/webp`, 무손실, 투명도 유지 | 웹사이트: PNG와 같은 픽셀을 더 작은 파일로 제공 |
| `eps` | `application/postscript`, `qr-code.eps` 다운로드로 전송 | Illustrator, InDesign, 인쇄소. 이때 `size`는 포인트 단위 너비이며 1인치가 72포인트이므로 `144`는 2인치입니다 |

```bash title="Terminal"
curl -o qr.webp "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=webp&size=1024"
curl -o qr.eps "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=eps&size=144"
head -2 qr.eps
# %!PS-Adobe-3.0 EPSF-3.0
# %%BoundingBox: 0 0 144 144
```

## 3. 스타일 적용하기 [#3-style-it]

단순 파라미터로 색상, 모양, 프레임, 로고를 지정할 수 있습니다.

```txt title="Rounded modules with a frame drawn as a template"
https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&body=rounded&eye=rounded&dot=rounded&template=Arrow
```

```txt title="A built-in frame with its label, and a community frame by id"
https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&frame=banner-bottom&frameText=Scan%20the%20menu
https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&item=frame:wifi-card
```

그라디언트, 사용자 지정 프레임, 눈별 색상을 쓰려면 전체 디자인을 JSON으로 `style`에 담아 보내세요.

```js title="styled.mjs"
const style = {
  fgColor: {
    type: "linear",
    angle: 45,
    stops: [
      { color: "#1d4ed8", offset: 0 },
      { color: "#7c3aed", offset: 100 },
    ],
  },
  eyeColor: "#b91c1c",
  frame: { style: "banner-bottom", text: "Scan the menu" },
};
const src = `https://api.qrdx.dev/v1/qr?data=${encodeURIComponent(link)}&style=${encodeURIComponent(JSON.stringify(style))}`;
// 200 image/svg+xml, 634.88 × 727.04: the frame adds to the 512 px code
```

<Callout type="info">
`data` 값에 `&`, `#`, `+` 또는 공백이 들어 있으면 값을 인코딩하세요. 예를 들어 JavaScript에서는 `encodeURIComponent`를 사용할 수 있습니다. 인코딩하지 않으면 URL이 해당 문자에서 잘립니다. `style`도 같은 방식으로 인코딩하고, 색상은 `#` 없이(또는 `%23`으로) 쓰세요. `#`를 그대로 쓰면 URL 프래그먼트가 시작되어 서버로 전송되지 않습니다.
</Callout>

## 파라미터 [#parameters]

| 파라미터 | 기본값 | 설명 |
| --- | --- | --- |
| `data` | 필수 | 인코딩할 텍스트 또는 URL, 최대 2048자 |
| `format` | `svg` | `svg`, `png`, `webp` 또는 `eps` |
| `size` | `512` | 픽셀 단위 너비와 높이, `64`에서 `2048`까지 (EPS는 포인트) |
| `fg` | `000000` | 모듈 색상(16진수: `155dfc`, `fff`, 또는 알파를 포함한 8자리) |
| `bg` | `ffffff` | 배경 색상(16진수). `00000000`은 투명 배경입니다 |
| `eyeColor` | `fg` | 세 모서리 눈의 색상 |
| `dotColor` | `fg` | 각 모서리 눈 안쪽 점의 색상 |
| `body` | `square` | 데이터 모듈의 모양. [패턴 값](#pattern-values) 참고 |
| `eye` | `square` | 모서리 눈 프레임의 모양 |
| `dot` | `square` | 각 모서리 눈 안쪽 점의 모양 |
| `level` | `Q` | 오류 정정: `L`(약 7%), `M`(15%), `Q`(25%), `H`(30%) |
| `margin` | `4` | 코드 주위 여백(콰이어트 존), 모듈 단위, `0`에서 `16`까지 |
| `template` | 없음 | [템플릿으로 그린 프레임](/docs/features/templates): 이미지 전체의 너비가 `size`이고 코드는 그 안에서 더 작게 표시됩니다 |
| `frame` | 없음 | `banner-bottom`, `speech-bubble`, `circle` 같은 기본 제공 행동 유도 [프레임](/docs/features/frames): 기본 제공 프레임 {facts.frameStyles}개 중 하나 |
| `frameText` | `Scan me` | 프레임에 표시되는 문구, 최대 24자. `style`이나 `item`의 프레임 문구도 바꿉니다 |
| `style` | 없음 | 에디터의 전체 디자인을 담은 JSON. [스타일](#style) 참고 |
| `item` | 없음 | `frame:wifi-card`처럼 ID로 지정하는 커뮤니티 프레임 또는 테마. [커뮤니티 항목](#community-items) 참고 |
| `logoIcon` | 없음 | 중앙에 넣는 간단한 아이콘 또는 브랜드 로고. [로고](#logos) 참고 |
| `logoFileId` | 없음 | 파일 ID로 지정하는 업로드한 로고. API 키가 필요합니다. [로고](#logos) 참고 |

열거형 값(`level`, `format`, `template`, `frame`)은 대소문자를 구분하지 않습니다. 프레임을 쓰면 `size`는 코드 자체의 너비가 되고, 프레임은 모든 형식에서 이미지에 추가됩니다. 단순 파라미터는 `style`보다 우선하고, `style`은 `item`보다 우선합니다.

## 스타일 [#style]

`style`은 저장된 테마와 같은 필드로 구성된 JSON 디자인을 받습니다. 그래서 [`GET /v1/themes`](/docs/developers/api/list-themes)에서 가져온 테마나 [MCP 서버](/docs/developers/mcp)의 `design_qr`가 반환하는 `qrdxStyle`을 그대로 전달할 수 있습니다(업로드한 로고는 제외, 아래 참고).

| 필드 | 값 |
| --- | --- |
| `bgColor`, `fgColor`, `eyeColor`, `dotColor` | 색상(`#155dfc` 같은 16진수, `rgb()`, `hsl()` 또는 색상 이름) 또는 그라디언트: `{ "type": "linear", "angle": 45, "stops": [...] }` 또는 `{ "type": "radial", "stops": [...] }`. `{ "color", "offset" }` 형태의 정지점을 2개에서 8개까지 지정하며 offset은 0에서 100입니다 |
| `bodyPattern`, `cornerEyePattern`, `cornerEyeDotPattern` | [패턴 값](#pattern-values) |
| `level`, `margin` | 위 파라미터와 같습니다(`margin`은 0에서 16) |
| `templateId` | 템플릿으로 그린 프레임. 없음은 `default` |
| `frame` | 기본 제공 프레임 `{ "style": "banner-bottom", "text": "Scan me", "color": "#155dfc", "textColor": "#ffffff" }` 또는 사용자 지정 프레임 `{ "style": "custom", "spec": { … } }`. 프레임 사양은 [커뮤니티](#community-items)에서 가져오거나 Playground의 프레임 섹션에서 만든 사용자 지정 프레임을 쓸 수 있습니다. 사양은 엔진의 프레임 사양 규칙에 따라 검사됩니다(마크업, 링크, 이미지 불가, 최대 32 KB) |
| `eyeColors` | `eyeColor`와 `dotColor`보다 우선하는 눈별 색상: `{ "topLeft": { "outer": "#b91c1c", "inner": "#1d4ed8" }, "topRight": …, "bottomLeft": … }`. 각 값은 색상 또는 그라디언트입니다 |
| `moduleScale` | 각 점의 크기, `0.5`에서 `1`까지(기본값 `1`) |
| `shape` | `square`(기본값) 또는 `circle`: 장식용 점으로 이루어진 원 안에 코드를 배치합니다 |
| `autoLevel` | 로고가 코드의 7% 넘게 가리면 오류 정정을 `H`로 올립니다(로고가 있으면 여기서는 항상 켜짐) |
| `logoOptions` | 로고 레이아웃: `size`(코드 너비의 `0.1`에서 `0.3`까지. 코드에 여유 모듈이 없으면 QRdx가 줄입니다), `padding`(`0`에서 `2` 모듈), `x`와 `y`(`0`에서 `1`), `shape`(`square`, `rounded`, `circle` 자르기), `plate`(로고 뒤의 색상) |
| `showLogo`, `logoIcon`, `logoFileId` | [로고](#logos) 참고 |

`style`은 Playground 링크의 `style` 값(`1.`로 시작)도 받습니다. 따라서 [Playground](/playground)에서 공유한 디자인을 로고 없이 그곳에서 보이는 그대로 렌더링할 수 있습니다. 알 수 없는 필드, 로고 주소(`customLogo`), Logo QR 또는 Image QR 아트(`art`)는 이유를 알려 주는 `400` 오류와 함께 거부됩니다.

```json title="400 Bad Request"
{"code":"VALIDATION_ERROR","message":"Invalid query parameters","data":{"details":[{"param":"style.customLogo","message":"Logo images by address aren't accepted: upload the image to QRdx and pass its file id as logoFileId, or pick a logoIcon."}]},"status":400}
```

## 커뮤니티 항목 [#community-items]

`item`은 게시된 [커뮤니티](/community) 프레임 또는 테마를 렌더링하며 CC0로 무료입니다. ID는 [`GET /v1/community/items`](/docs/developers/api/list-community-items)로 찾거나, 항목 페이지를 열어 유형과 슬러그를 쓰면 됩니다. `/community/frames/wifi-card`는 `frame:wifi-card`입니다. 프레임 항목은 흰 바탕에 검은색인 기본 코드에 적용됩니다. 그 아래의 코드를 바꾸려면 `style`이나 단순 파라미터를 추가하세요. 항목은 새 버전이 나오거나 삭제될 수 있으므로 `item`을 쓴 렌더링은 5분간 캐시됩니다(CDN에서는 10분).

## 로고 [#logos]

- **빠른 아이콘.** `logoIcon`은 에디터의 아이콘 중 하나를 가운데의 흰색 타일 위에 넣어요. 사용할 수 있는 값은 `wifi`, `location`, `phone`, `email`, `link`, `file`, `calendar`, `whatsapp`, `instagram`이에요. QRdx가 직접 그리므로 키가 필요 없어요.
- **브랜드 로고.** `logoIcon`은 [Simple Icons](https://simpleicons.org)의 {facts.brandLogos}개 브랜드도 슬러그로 받아요. 예: `spotify`, `paypal`, `googlemaps`, `appstore`. 마크는 배경 없이 브랜드 색상으로 그려져요. 검은색이나 흰색을 쓰려면 `:black` 또는 `:white`를 붙이세요(`whatsapp:white`). 마크 뒤에 판을 넣으려면 `style`의 `logoOptions.plate`를 사용하세요. [`GET /api/brand-logos`](https://qrdx.dev/api/brand-logos)에서 모든 슬러그를 확인할 수 있어요. QRdx에 없는 슬러그를 보내면 올바른 형식을 안내하는 `400`이 반환돼요.
- **QRdx 마크**는 에디터에서 기본으로 표시되지만 여기서는 그려지지 않아요. `showLogo: true`만으로는 로고가 추가되지 않아요.
- **로고를 넣으면 오류 정정 수준이 올라가요.** 로고가 코드의 7%보다 넓은 면적을 덮으면 `level` 값과 관계없이 코드가 `H` 수준으로 그려져서 스캔이 되도록 해요.

```bash title="Terminal"
curl -o spotify.png "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=png&logoIcon=spotify"
```

<IfAvailable feature="fileStorage">

**내 로고.** `logoFileId`는 [대시보드 → 파일](/docs/files)에 업로드한 최대 1MB의 PNG 또는 JPEG를 그려요. ID는 파일 링크 `https://qrdx.dev/api/files/<id>`의 마지막 부분이에요. 파일을 소유한 워크스페이스의 [API 키](/docs/developers/api-keys)를 함께 보내세요.

```bash title="Terminal"
curl -o qr.png -H "Authorization: Bearer $QRDX_API_KEY" \
  "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=png&logoFileId=<id>"
```

응답은 비공개(`Cache-Control: private, no-store`)이며 워크스페이스의 일일 API 할당량에 포함돼요. 다른 워크스페이스의 파일이면 `404`, 키 없이 요청하면 `401`이 반환돼요. QRdx는 자체 저장소에서 이미지를 읽고 실제로 PNG 또는 JPEG인지 확인해요. 사용자가 보낸 웹 주소에서 로고를 가져오지는 않아요.

</IfAvailable>

`logoOptions`로 이 모든 로고의 크기, 위치, 자르기, 배경을 지정할 수 있어요. 업로드한 로고의 배경 제거는 Playground에서 해요. Image API는 업로드한 파일을 그대로 그려요. Logo QR과 Image QR 아트는 여기서 사용할 수 없어요. Playground가 브라우저에서 사용자의 사진으로 만들기 때문이에요. 아트 코드는 [Playground](/playground?tab=art)에서 디자인하거나, [AI art API](/docs/developers/ai-art-api)로 코드를 AI 아트워크로 그려 보세요.

### 패턴 값 [#pattern-values]

- `body`: `circle`, `circle-large`, `square`, `diamond`, `circle-mixed`, `pacman`, `rounded`, `small-square`, `vertical-line`, `horizontal-line`, `liquid`, `liquid-horizontal`, `liquid-vertical`, `classy`, `classy-rounded`, `leaf`, `plus`, `hexagon`, `star`, `heart`, `random-dots`, `mosaic`, `octagon`
- `eye`: `square`, `rounded`, `gear`, `circle`, `diya`, `extra-rounded`, `message`, `pointy`, `leaf`, `drop`, `octagon`, `bevel`, `squircle`, `cushion`, `shield`, `petal`, `leaf-reverse`
- `dot`: `square`, `rounded`, `circle`, `message`, `message-reverse`, `diya`, `diya-reverse`, `rounded-triangle`, `leaf`, `drop`, `plus`, `cross-rounded`, `hexagon`, `octagon`, `flower`, `heart`, `squircle`, `dots`, `extra-rounded`, `leaf-reverse`, `drop-reverse`
- `template`: `default`, `Arrow`, `StandardBox`, `SquareBorder`, `StrikedBox`, `Halloween`, `DotRing`

이 스타일은 [`qrdx` React 라이브러리](/docs/features/patterns)와 같아요. [MCP 서버](/docs/developers/mcp)에서도 짧은 설명과 함께 목록을 볼 수 있어요.

## 응답 [#responses]

요청이 성공하면 다음 헤더와 함께 이미지를 반환해요.

- `Content-Type: image/svg+xml`, `image/png`, `image/webp` 또는 `application/postscript` (EPS는 `qr-code.eps` 다운로드로 전송돼요)
- `Cache-Control: public, max-age=31536000, immutable`. 단, `item`이 있는 렌더링(5분, CDN에서는 10분)과 `logoFileId`가 있는 렌더링(`private, no-store`)은 예외예요.
- `Access-Control-Allow-Origin: *`이므로 어떤 웹사이트에서든 `fetch`로 가져올 수 있어요.

렌더링은 결정적이에요. 같은 쿼리 문자열은 항상 같은 바이트를 반환하므로 응답을 1년 동안 캐시할 수 있어요. 기존 파라미터만 사용하는 URL은 예전과 똑같이 렌더링돼요.

## 문제가 생겼을 때 [#if-something-goes-wrong]

### `"param": "size"`가 포함된 `400` [#400-with-param-size]

`size`가 64보다 작거나 2048보다 커요. 응답 본문에 한도가 표시돼요.

```json title="400 Bad Request"
{"code":"VALIDATION_ERROR","message":"Invalid query parameters","data":{"details":[{"param":"size","message":"Too small: expected number to be >=64"}]},"status":400}
```

### `"param": "data"`가 포함된 `400` [#400-with-param-data]

선택한 오류 정정 수준에서 데이터가 QR 코드에 들어가지 않아요. 더 낮은 `level`(`L`이 가장 많이 담아요)을 사용하거나 데이터를 줄이세요. URL이 길다면 동적 QR 코드의 짧은 링크를 쓰는 것이 일반적인 해결 방법이에요.

```json title="400 Bad Request"
{"code":"VALIDATION_ERROR","message":"Invalid query parameters","data":{"details":[{"param":"data","message":"Data is too long for a QR code at error correction level H. Shorten it or use a lower level (L holds the most)."}]},"status":400}
```

### `"param": "logoIcon"`이 포함된 `400` [#400-with-param-logoicon]

슬러그가 QRdx에 있는 브랜드나 빠른 아이콘이 아니에요. 메시지에서 사용할 수 있는 형식(`spotify`, `paypal`, `googlemaps` 또는 `wifi`, `phone`, `email`)을 안내해요.

### 이미지가 이상하거나 잘려 보여요 [#the-image-looks-wrong-or-is-split]

`data` 또는 `style`의 `&`, `#`, `+`가 인코딩되지 않아 URL이 그 문자에서 잘렸어요. 두 값을 모두 인코딩하고, 색상은 `#` 없이 쓰세요.

### `429 RATE_LIMITED` [#429-rate_limited]

한 IP 주소에서 분당 {facts.imageApiPerMinute}회를 넘게 요청했어요. `Retry-After`에 표시된 초만큼 기다리세요. 같은 URL은 항상 같은 이미지를 반환하므로, 실시간으로 불러오지 말고 캐시하거나 파일로 저장하세요.

## 제한 [#limits]

- **요청 제한:** IP 주소당 분당 {facts.imageApiPerMinute}회예요. 이미지는 REST API의 일일 할당량을 사용하지 않아요.
- **스캔 검사 없음.** Image API는 요청한 대로 그리기만 해요. 디자인의 스캔 점수를 먼저 확인하고 보정하려면 [MCP 서버](/docs/developers/mcp)의 `design_qr`을 사용하거나 [Playground](/playground?tab=design)의 스캔 점수를 확인하세요.
- **`style`은 URL에서 최대 8,192자**이고, JSON은 최대 40KB예요.
- **데이터는 URL의 일부예요.** 다른 URL처럼 서버 로그, 브라우저 기록, 캐시에 남을 수 있어요. 비밀번호 같은 비밀 정보는 넣지 마세요.

## 스캔 팁 [#scanning-tips]

- 이미지를 어두운 배경이나 복잡한 배경(예: GitHub 다크 모드의 README) 위에 놓을 때는 `margin`을 `2` 이상으로 유지하세요.
- `fg`와 `bg`의 대비를 충분히 주세요. 밝은 배경에 어두운 모듈이 가장 안정적으로 스캔돼요.
- 기본값(정사각형 모듈, 4모듈 여백)은 모든 리더에서 스캔돼요. `circle` 점 같은 장식 모양은 더 부드러워 보이지만, 일부 오래된 스캐너는 인식률이 떨어질 수 있어요. [스캔 검사기](/tools/scan-checker)로 확인하세요.
- 인쇄하기 전에 여러 대의 휴대폰으로 코드를 테스트하세요.

## 셀프 호스팅 [#self-hosting]

이 엔드포인트는 QRdx 웹 앱의 일부이므로 [셀프 호스팅](/docs/self-hosting) 인스턴스는 사용자의 도메인에서 `/api/v1/qr`로 제공해요(예: `https://qr.example.com/api/v1/qr?data=…`). 짧은 `/v1/qr` 경로는 `api.qrdx.dev`에서만 동작해요. 요청 제한은 Upstash Redis가 설정되어 있으면 이를 사용하고, 설정되어 있지 않으면 꺼져 있어요.
