इस पेज के अंत तक आपके पास एक QR कोड इमेज URL होगा, जिसे आप README, `<img>` टैग या ईमेल टेम्पलेट में पेस्ट कर सकते हैं, अपनी पसंद की स्टाइल में। आप यह भी जान जाएँगे कि API किन चीज़ों को मना करती है और क्यों।

`GET https://api.qrdx.dev/v1/qr` एक QR कोड को SVG, PNG या WebP इमेज के रूप में लौटाता है, या प्रिंट और डिज़ाइन टूल के लिए वेक्टर EPS फ़ाइल के रूप में। सब कुछ query string में होता है, इसलिए URL ही इमेज है। यह एडिटर की स्टाइल भी लेता है: ग्रेडिएंट, फ़्रेम (कस्टम फ़्रेम सहित), बॉर्डर, आई और डॉट के रंग और लोगो आइकन। किसी अकाउंट या API key की ज़रूरत नहीं है, सिवाय उस लोगो के जो आपने QRdx पर अपलोड किया हो (देखें [लोगो](#logos))।

```md title="README.md"
![QR code](https://api.qrdx.dev/v1/qr?data=https://github.com/you/repo)
```

[Playground में आज़माएँ](/playground?open=code&lang=image): वहाँ कोड को स्टाइल करें, फिर उसका इमेज URL कॉपी करें। या [QR कोड इमेज रेंडर करें](/docs/developers/api/get-qr-image) रेफ़रेंस पेज से रिक्वेस्ट भेजें।

## 1. इमेज की रिक्वेस्ट करें [#1-request-an-image]

<Tabs groupId="language" persist items={["curl", "JavaScript", "Python"]}>
  <Tab value="curl">
    ```bash title="Terminal"
    curl -o qr.png "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=png&size=1024"
    ```
  </Tab>
  <Tab value="JavaScript">
    ```js title="qr.mjs"
    import { writeFile } from "node:fs/promises";

    const url = new URL("https://api.qrdx.dev/v1/qr");
    url.searchParams.set("data", "https://qrdx.dev");
    url.searchParams.set("format", "png");
    url.searchParams.set("size", "1024");

    const response = await fetch(url);
    await writeFile("qr.png", Buffer.from(await response.arrayBuffer()));
    ```
  </Tab>
  <Tab value="Python">
    ```python title="qr.py"
    import requests

    response = requests.get(
        "https://api.qrdx.dev/v1/qr",
        params={"data": "https://qrdx.dev", "format": "png", "size": 1024},
    )
    response.raise_for_status()
    open("qr.png", "wb").write(response.content)
    ```
  </Tab>
</Tabs>

```txt title="Output"
qr.png: PNG image data, 1024 x 1024, 8-bit/color RGBA, non-interlaced
```

शेल में URL को quotes में रखें ताकि `&` बना रहे। HTML पेज में URL सीधे `src` में जाता है:

```html title="index.html"
<img
  src="https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&size=256&fg=155dfc"
  width="256"
  height="256"
  alt="QR code for qrdx.dev"
/>
```

## 2. फ़ॉर्मैट चुनें [#2-pick-a-format]

| `format` | क्या लौटाता है | कब |
| --- | --- | --- |
| `svg` (डिफ़ॉल्ट) | `image/svg+xml` | वेब पेज और हर वह जगह जहाँ स्केल करना हो |
| `png` | `image/png` | ईमेल, चैट ऐप, डॉक्यूमेंट |
| `webp` | `image/webp`, lossless, ट्रांसपेरेंसी बनी रहती है | वेबसाइट: PNG के ही पिक्सल, छोटी फ़ाइल में |
| `eps` | `application/postscript`, `qr-code.eps` डाउनलोड के रूप में भेजा जाता है | Illustrator, InDesign, प्रिंट शॉप। इसमें `size` पॉइंट में चौड़ाई होती है, प्रति इंच 72, यानी `144` का मतलब 2 इंच |

```bash title="Terminal"
curl -o qr.webp "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=webp&size=1024"
curl -o qr.eps "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=eps&size=144"
head -2 qr.eps
# %!PS-Adobe-3.0 EPSF-3.0
# %%BoundingBox: 0 0 144 144
```

## 3. स्टाइल करें [#3-style-it]

फ़्लैट पैरामीटर रंग, आकार, फ़्रेम और लोगो को संभालते हैं:

```txt title="Rounded modules with a frame drawn as a template"
https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&body=rounded&eye=rounded&dot=rounded&template=Arrow
```

```txt title="A built-in frame with its label, and a community frame by id"
https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&frame=banner-bottom&frameText=Scan%20the%20menu
https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&item=frame:wifi-card
```

ग्रेडिएंट, कस्टम फ़्रेम और हर आई के अलग रंग के लिए, पूरा डिज़ाइन `style` में JSON के रूप में भेजें:

```js title="styled.mjs"
const style = {
  fgColor: {
    type: "linear",
    angle: 45,
    stops: [
      { color: "#1d4ed8", offset: 0 },
      { color: "#7c3aed", offset: 100 },
    ],
  },
  eyeColor: "#b91c1c",
  frame: { style: "banner-bottom", text: "Scan the menu" },
};
const src = `https://api.qrdx.dev/v1/qr?data=${encodeURIComponent(link)}&style=${encodeURIComponent(JSON.stringify(style))}`;
// 200 image/svg+xml, 634.88 × 727.04: the frame adds to the 512 px code
```

<Callout type="info">
जब `data` की वैल्यू में `&`, `#`, `+` या स्पेस हों, तो उसे encode करें, जैसे JavaScript में `encodeURIComponent` से। नहीं तो URL इन अक्षरों पर टूट जाता है। `style` को भी इसी तरह encode करें, और रंग `#` के बिना लिखें (या `%23` के रूप में): अकेला `#` URL fragment शुरू कर देता है और कभी भेजा नहीं जाता।
</Callout>

## पैरामीटर [#parameters]

| पैरामीटर | डिफ़ॉल्ट | विवरण |
| --- | --- | --- |
| `data` | ज़रूरी | एन्कोड करने के लिए टेक्स्ट या URL, अधिकतम 2048 अक्षर |
| `format` | `svg` | `svg`, `png`, `webp` या `eps` |
| `size` | `512` | पिक्सल में चौड़ाई और ऊँचाई, `64` से `2048` (EPS के लिए पॉइंट) |
| `fg` | `000000` | मॉड्यूल का रंग hex में (`155dfc`, `fff`, या alpha के साथ 8 अंक) |
| `bg` | `ffffff` | बैकग्राउंड का रंग hex में। `00000000` से बैकग्राउंड ट्रांसपेरेंट होता है |
| `eyeColor` | `fg` | तीनों कोने की आई का रंग |
| `dotColor` | `fg` | हर कोने की आई के अंदर के डॉट का रंग |
| `body` | `square` | डेटा मॉड्यूल का आकार; देखें [पैटर्न वैल्यू](#pattern-values) |
| `eye` | `square` | कोने की आई के फ़्रेम का आकार |
| `dot` | `square` | हर कोने की आई के अंदर के डॉट का आकार |
| `level` | `Q` | एरर करेक्शन: `L` (लगभग 7%), `M` (15%), `Q` (25%) या `H` (30%) |
| `margin` | `4` | कोड के चारों ओर खाली जगह (quiet zone), मॉड्यूल में, `0` से `16` |
| `template` | कोई नहीं | [टेम्पलेट के रूप में बना फ़्रेम](/docs/features/templates): पूरी इमेज `size` चौड़ी होती है और कोड उसके अंदर छोटा होता है |
| `frame` | कोई नहीं | बिल्ट-इन call-to-action [फ़्रेम](/docs/features/frames), जैसे `banner-bottom`, `speech-bubble` या `circle`: {facts.frameStyles} बिल्ट-इन फ़्रेम में से कोई भी |
| `frameText` | `Scan me` | फ़्रेम का लेबल, अधिकतम 24 अक्षर। यह `style` या `item` के फ़्रेम का लेबल भी बदल देता है |
| `style` | कोई नहीं | एडिटर का पूरा डिज़ाइन JSON के रूप में; देखें [स्टाइल](#style) |
| `item` | कोई नहीं | id से कोई कम्युनिटी फ़्रेम या थीम, जैसे `frame:wifi-card`; देखें [कम्युनिटी आइटम](#community-items) |
| `logoIcon` | कोई नहीं | बीच में एक क्विक आइकन या ब्रांड लोगो; देखें [लोगो](#logos) |
| `logoFileId` | कोई नहीं | file id से आपका अपलोड किया हुआ लोगो; इसके लिए API key चाहिए; देखें [लोगो](#logos) |

Enum वैल्यू (`level`, `format`, `template`, `frame`) में अक्षरों का case मायने नहीं रखता। फ़्रेम के साथ, `size` कोड की अपनी चौड़ाई होती है और फ़्रेम इमेज में जुड़ जाता है, हर फ़ॉर्मैट में। फ़्लैट पैरामीटर `style` पर भारी पड़ते हैं, और `style` `item` पर।

## स्टाइल [#style]

`style` डिज़ाइन को JSON के रूप में लेता है, उन्हीं फ़ील्ड के साथ जो सेव की गई थीम में होती हैं। इसलिए [`GET /v1/themes`](/docs/developers/api/list-themes) की थीम या [MCP server](/docs/developers/mcp) के `design_qr` से मिला `qrdxStyle` जैसा है वैसा ही पास किया जा सकता है (अपलोड किए गए लोगो को छोड़कर, नीचे देखें):

| फ़ील्ड | क्या लेता है |
| --- | --- |
| `bgColor`, `fgColor`, `eyeColor`, `dotColor` | एक रंग (hex जैसे `#155dfc`, `rgb()`, `hsl()` या रंग का नाम), या ग्रेडिएंट: `{ "type": "linear", "angle": 45, "stops": [...] }` या `{ "type": "radial", "stops": [...] }`, जिसमें `{ "color", "offset" }` के 2 से 8 stop हों (offset 0 से 100) |
| `bodyPattern`, `cornerEyePattern`, `cornerEyeDotPattern` | [पैटर्न वैल्यू](#pattern-values) |
| `level`, `margin` | ऊपर के पैरामीटर की तरह (`margin` 0 से 16) |
| `templateId` | टेम्पलेट के रूप में बना फ़्रेम, कोई नहीं के लिए `default` |
| `frame` | बिल्ट-इन फ़्रेम, `{ "style": "banner-bottom", "text": "Scan me", "color": "#155dfc", "textColor": "#ffffff" }`, या कस्टम फ़्रेम, `{ "style": "custom", "spec": { … } }`, जिसमें [कम्युनिटी](#community-items) से या playground के Frame सेक्शन में बना कस्टम frame spec हो। Spec की जाँच इंजन के frame-spec नियमों से होती है (कोई markup, लिंक या इमेज नहीं; अधिकतम 32 KB) |
| `eyeColors` | हर आई के अलग रंग, `eyeColor` और `dotColor` के ऊपर: `{ "topLeft": { "outer": "#b91c1c", "inner": "#1d4ed8" }, "topRight": …, "bottomLeft": … }`, हर एक रंग या ग्रेडिएंट |
| `moduleScale` | हर डॉट का आकार, `0.5` से `1` (डिफ़ॉल्ट `1`) |
| `shape` | `square` (डिफ़ॉल्ट) या `circle`: सजावटी डॉट के गोले में कोड |
| `autoLevel` | जब लोगो कोड के 7% से ज़्यादा हिस्से को ढके, तो एरर करेक्शन `H` कर देता है (लोगो होने पर यहाँ हमेशा चालू रहता है) |
| `logoOptions` | लोगो का लेआउट: `size` (कोड की चौड़ाई का `0.1` से `0.3`; जब कोड में उतने मॉड्यूल खाली नहीं होते तो QRdx इसे छोटा कर देता है), `padding` (`0` से `2` मॉड्यूल), `x` और `y` (`0` से `1`), `shape` (`square`, `rounded` या `circle` क्रॉप) और `plate` (उसके पीछे का रंग) |
| `showLogo`, `logoIcon`, `logoFileId` | देखें [लोगो](#logos) |

`style` playground लिंक की `style` वैल्यू भी लेता है (वह `1.` से शुरू होती है), इसलिए [playground](/playground) से शेयर किया गया डिज़ाइन वैसा ही रेंडर होता है जैसा वहाँ दिखता है, बस उसके लोगो के बिना। अज्ञात फ़ील्ड, लोगो के पते (`customLogo`) और Logo QR या Image QR आर्ट (`art`) को `400` के साथ मना कर दिया जाता है, जो कारण बताता है:

```json title="400 Bad Request"
{"code":"VALIDATION_ERROR","message":"Invalid query parameters","data":{"details":[{"param":"style.customLogo","message":"Logo images by address aren't accepted: upload the image to QRdx and pass its file id as logoFileId, or pick a logoIcon."}]},"status":400}
```

## कम्युनिटी आइटम [#community-items]

`item` एक प्रकाशित [कम्युनिटी](/community) फ़्रेम या थीम रेंडर करता है, जो CC0 के तहत फ़्री है। ids [`GET /v1/community/items`](/docs/developers/api/list-community-items) से खोजें, या किसी आइटम का पेज खोलकर उसका type और slug इस्तेमाल करें: `/community/frames/wifi-card` का मतलब `frame:wifi-card` है। फ़्रेम आइटम सादे सफ़ेद पर काले कोड पर लगता है; उसके नीचे का कोड बदलने के लिए `style` या फ़्लैट पैरामीटर जोड़ें। `item` वाले रेंडर 5 मिनट के लिए कैश होते हैं (CDN पर 10), क्योंकि किसी आइटम का नया वर्शन आ सकता है या उसे हटाया जा सकता है।

## लोगो [#logos]

- **क्विक आइकन।** `logoIcon` एडिटर का कोई एक आइकन सफ़ेद टाइल पर बीच में लगाता है: `wifi`, `location`, `phone`, `email`, `link`, `file`, `calendar`, `whatsapp` या `instagram`। इन्हें QRdx खुद बनाता है, और इनके लिए किसी key की ज़रूरत नहीं होती।
- **ब्रांड लोगो।** `logoIcon` [Simple Icons](https://simpleicons.org) के {facts.brandLogos} ब्रांड में से किसी का भी slug लेता है: `spotify`, `paypal`, `googlemaps`, `appstore`। निशान अपने ब्रांड कलर में बिना बैकग्राउंड के बनता है; ये रंग बदलने के लिए `:black` या `:white` जोड़ें (`whatsapp:white`), और उसके पीछे प्लेट के लिए `style` में `logoOptions.plate` दें। [`GET /api/brand-logos`](https://qrdx.dev/api/brand-logos) हर slug की सूची देता है। जो slug QRdx में नहीं है, उस पर `400` मिलता है जो सही रूप सुझाता है।
- **QRdx का निशान** जो एडिटर में डिफ़ॉल्ट रूप से दिखता है, यहाँ नहीं बनता: अकेले `showLogo: true` से कोई लोगो नहीं जुड़ता।
- **लोगो होने पर error correction बढ़ जाता है।** जब लोगो कोड के 7% से ज़्यादा हिस्से को ढकता है, तो `level` में कुछ भी लिखा हो, कोड `H` लेवल पर बनता है, ताकि वह फिर भी स्कैन हो सके।

```bash title="Terminal"
curl -o spotify.png "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=png&logoIcon=spotify"
```

<IfAvailable feature="fileStorage">

**आपका अपना लोगो।** `logoFileId` आपके [डैशबोर्ड → Files](/docs/files) में अपलोड की गई 1 MB तक की PNG या JPEG फ़ाइल बनाता है। id फ़ाइल के लिंक का आख़िरी हिस्सा होता है, `https://qrdx.dev/api/files/<id>`। उस वर्कस्पेस की [API key](/docs/developers/api-keys) भेजें जिसकी वह फ़ाइल है:

```bash title="Terminal"
curl -o qr.png -H "Authorization: Bearer $QRDX_API_KEY" \
  "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=png&logoFileId=<id>"
```

रिस्पॉन्स प्राइवेट होता है (`Cache-Control: private, no-store`) और वर्कस्पेस के रोज़ाना API कोटा में गिना जाता है। दूसरे वर्कस्पेस की फ़ाइल पर `404` मिलता है, और key के बिना किए गए अनुरोध पर `401`। QRdx इमेज को अपने स्टोरेज से पढ़ता है और जाँचता है कि वह सच में PNG या JPEG है; आपके भेजे वेब एड्रेस से वह कभी कोई लोगो नहीं लाता।

</IfAvailable>

`logoOptions` इनमें से किसी भी लोगो का साइज़, जगह, क्रॉप और बैकग्राउंड तय करता है। अपलोड किए गए लोगो का अपना बैकग्राउंड हटाने का काम Playground में होता है; image API अपलोड की गई फ़ाइल को जैसी है वैसी ही बनाता है। Logo QR और Image QR आर्ट यहाँ उपलब्ध नहीं हैं: Playground उन्हें ब्राउज़र में आपकी तस्वीर से बनाता है। आर्ट कोड [Playground](/playground?tab=art) में डिज़ाइन करें, या [AI art API](/docs/developers/ai-art-api) से किसी कोड को AI आर्टवर्क में बदलें।

### पैटर्न वैल्यू [#pattern-values]

- `body`: `circle`, `circle-large`, `square`, `diamond`, `circle-mixed`, `pacman`, `rounded`, `small-square`, `vertical-line`, `horizontal-line`, `liquid`, `liquid-horizontal`, `liquid-vertical`, `classy`, `classy-rounded`, `leaf`, `plus`, `hexagon`, `star`, `heart`, `random-dots`, `mosaic`, `octagon`
- `eye`: `square`, `rounded`, `gear`, `circle`, `diya`, `extra-rounded`, `message`, `pointy`, `leaf`, `drop`, `octagon`, `bevel`, `squircle`, `cushion`, `shield`, `petal`, `leaf-reverse`
- `dot`: `square`, `rounded`, `circle`, `message`, `message-reverse`, `diya`, `diya-reverse`, `rounded-triangle`, `leaf`, `drop`, `plus`, `cross-rounded`, `hexagon`, `octagon`, `flower`, `heart`, `squircle`, `dots`, `extra-rounded`, `leaf-reverse`, `drop-reverse`
- `template`: `default`, `Arrow`, `StandardBox`, `SquareBorder`, `StrikedBox`, `Halloween`, `DotRing`

ये वही स्टाइल हैं जो [`qrdx` React लाइब्रेरी](/docs/features/patterns) में हैं। [MCP सर्वर](/docs/developers/mcp) भी इन्हें छोटे विवरण के साथ सूचीबद्ध कर सकता है।

## रिस्पॉन्स [#responses]

सफल अनुरोध पर इमेज इन हेडर के साथ मिलती है:

- `Content-Type: image/svg+xml`, `image/png`, `image/webp` या `application/postscript` (EPS `qr-code.eps` डाउनलोड के रूप में भेजी जाती है)
- `Cache-Control: public, max-age=31536000, immutable`, सिवाय `item` वाले रेंडर के (5 मिनट, CDN पर 10) और `logoFileId` वाले रेंडर के (`private, no-store`)
- `Access-Control-Allow-Origin: *`, ताकि आप इसे किसी भी वेबसाइट से `fetch` कर सकें

रेंडरिंग डिटरमिनिस्टिक है: एक ही query string हमेशा वही बाइट लौटाती है, इसीलिए रिस्पॉन्स एक साल तक कैश किए जा सकते हैं। जो URL सिर्फ़ मूल पैरामीटर इस्तेमाल करते हैं, वे बिल्कुल वैसे ही बनते हैं जैसे हमेशा बनते आए हैं।

## कुछ गड़बड़ हो जाए तो [#if-something-goes-wrong]

### `"param": "size"` के साथ `400` [#400-with-param-size]

`size` 64 से कम या 2048 से ज़्यादा है। बॉडी में सीमा बताई जाती है:

```json title="400 Bad Request"
{"code":"VALIDATION_ERROR","message":"Invalid query parameters","data":{"details":[{"param":"size","message":"Too small: expected number to be >=64"}]},"status":400}
```

### `"param": "data"` के साथ `400` [#400-with-param-data]

चुने गए error correction लेवल पर डेटा QR कोड में नहीं समा रहा। कम `level` इस्तेमाल करें (`L` में सबसे ज़्यादा डेटा आता है) या डेटा छोटा करें; लंबे URL के लिए आम तौर पर डायनेमिक कोड का शॉर्ट लिंक ही हल है।

```json title="400 Bad Request"
{"code":"VALIDATION_ERROR","message":"Invalid query parameters","data":{"details":[{"param":"data","message":"Data is too long for a QR code at error correction level H. Shorten it or use a lower level (L holds the most)."}]},"status":400}
```

### `"param": "logoIcon"` के साथ `400` [#400-with-param-logoicon]

slug ऐसा ब्रांड नहीं है जो QRdx में हो, और न ही क्विक आइकन है। संदेश उन रूपों को सुझाता है जो काम करते हैं (`spotify`, `paypal`, `googlemaps`, या `wifi`, `phone`, `email`)।

### इमेज गलत दिखती है या बँटी हुई है [#the-image-looks-wrong-or-is-split]

`data` या `style` में कोई `&`, `#` या `+` एन्कोड नहीं हुआ था, इसलिए URL उसी अक्षर पर कट गया। दोनों वैल्यू एन्कोड करें, और रंग `#` के बिना लिखें।

### `429 RATE_LIMITED` [#429-rate_limited]

एक IP एड्रेस से एक मिनट में {facts.imageApiPerMinute} से ज़्यादा अनुरोध हुए। `Retry-After` में दिए सेकंड तक रुकें। एक ही URL हमेशा वही इमेज लौटाता है, इसलिए उसे लाइव लोड करने के बजाय कैश करें या फ़ाइल सेव कर लें।

## सीमाएँ [#limits]

- **रेट लिमिट:** हर IP एड्रेस से एक मिनट में {facts.imageApiPerMinute} अनुरोध। इमेज REST API के रोज़ाना कोटा का इस्तेमाल नहीं करतीं।
- **कोई स्कैन जाँच नहीं।** image API वही बनाता है जो आप माँगते हैं। किसी डिज़ाइन का स्कैन स्कोर पहले जाँचने और ठीक करने के लिए [MCP सर्वर](/docs/developers/mcp) पर `design_qr` इस्तेमाल करें, या [Playground](/playground?tab=design) में स्कैन स्कोर देखें।
- **`style` URL में 8,192 अक्षरों तक** हो सकता है, और उसका JSON 40 KB तक।
- **डेटा URL का हिस्सा है।** किसी भी URL की तरह यह सर्वर लॉग, ब्राउज़र हिस्ट्री और कैश में पहुँच सकता है। इसमें पासवर्ड या दूसरी गोपनीय चीज़ें न डालें।

## स्कैन के लिए सुझाव [#scanning-tips]

- जब इमेज गहरे या भरे-भरे बैकग्राउंड पर हो, जैसे GitHub के डार्क मोड में कोई README, तो `margin` को `2` या उससे ज़्यादा रखें।
- `fg` और `bg` के बीच अच्छा कंट्रास्ट रखें। हल्के बैकग्राउंड पर गहरे मॉड्यूल सबसे भरोसेमंद ढंग से स्कैन होते हैं।
- डिफ़ॉल्ट (चौकोर मॉड्यूल, 4 मॉड्यूल का मार्जिन) हर रीडर पर स्कैन होते हैं। `circle` डॉट जैसे स्टाइल वाले आकार नरम दिखते हैं, और कुछ पुराने स्कैनर उन्हें कम भरोसेमंद ढंग से पढ़ते हैं: [स्कैन चेकर](/tools/scan-checker) से जाँचें।
- प्रिंट करने से पहले कोड को कुछ फ़ोन से टेस्ट करें।

## सेल्फ-होस्टिंग [#self-hosting]

यह एंडपॉइंट QRdx वेब ऐप का हिस्सा है, इसलिए [सेल्फ-होस्ट किया](/docs/self-hosting) हुआ इंस्टेंस इसे आपके अपने डोमेन पर `/api/v1/qr` पर चलाता है (जैसे `https://qr.example.com/api/v1/qr?data=…`)। छोटा `/v1/qr` पाथ सिर्फ़ `api.qrdx.dev` पर काम करता है। रेट लिमिटिंग कॉन्फ़िगर होने पर Upstash Redis इस्तेमाल करती है, वरना बंद रहती है।
