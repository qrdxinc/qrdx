Todo lo que hace QRdx está disponible desde el código. Empieza por lo que quieres construir: cada fila indica la herramienta, lo que necesita y la página que te lleva hasta ella.

| Quieres | Usa | Necesita |
| --- | --- | --- |
| Poner un código QR en una página, un correo o un README | [API de imágenes de códigos QR](/docs/developers/image-api): una URL `GET` que es la imagen | Nada |
| Dibujar un código de barras para una etiqueta o un feed de productos | [API de códigos de barras](/docs/developers/barcode-api): lo mismo, para EAN, UPC, Code 128 y más | Nada |
| Crear códigos que puedas redirigir a otro destino después de imprimirlos y leer sus escaneos | [REST API](/docs/developers/quickstart): `POST /v1/codes`, `PATCH`, `GET …/scans` | Una [clave de API](/docs/developers/api-keys) |
| Reaccionar a escaneos, códigos nuevos o respuestas de formularios en tu propio sistema | [Webhooks](/docs/webhooks): solicitudes `POST` firmadas a tu URL | Una clave de API o el panel, plan Business |
| Dejar que un asistente de IA cree códigos QR en un chat | [Servidor MCP](/docs/developers/mcp): `https://mcp.qrdx.dev/mcp` | Nada |
| Crear códigos QR desde un script, una compilación o un CSV | [CLI](/docs/developers/cli): `npx @qrdx/cli` | Node.js 22 |
| Integrar un código QR en una obra de arte con IA | [API de arte con IA](/docs/developers/ai-art-api): `POST /v1/art` | Una clave de API, imágenes de arte con IA mensuales |
| Permitir que otras personas conecten su cuenta de QRdx con tu producto | [Crear una integración](/docs/developers/build-an-integration): OAuth 2.0 con PKCE | Una app OAuth |
| Automatizar QRdx en n8n | [Nodos de n8n](/docs/developers/n8n): `@qrdx/n8n-nodes-qrdx` | Un n8n autoalojado |
| Renderizar códigos con estilo dentro de una app de React | [Biblioteca de React](/docs/getting-started): el paquete `qrdx` | npm |

## Primera solicitud en dos minutos [#first-request-in-two-minutes]

La [guía de inicio rápido](/docs/developers/quickstart) crea una imagen de código QR con una solicitud sin clave, crea una clave de API, crea un código dinámico y lo redirige a otro destino. Todo lo demás en esta página se apoya en esos cuatro pasos.

```bash title="Terminal"
curl "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=png" -o qr.png
```

## URL base y autenticación [#base-url-and-authentication]

La REST API está en `https://api.qrdx.dev/v1`. Las mismas rutas responden en `https://qrdx.dev/api/v1`, y una instancia [autoalojada](/docs/self-hosting) las sirve en `/api/v1` en su propio dominio.

Las solicitudes llevan una [clave de API](/docs/developers/api-keys) como `Authorization: Bearer qrdx_…`. Una clave actúa sobre el espacio de trabajo en el que se creó, con tu rol en él. Las apps que actúan en nombre de otros usuarios de QRdx envían en su lugar un [token de acceso OAuth 2.0](/docs/developers/rest-api#get-an-access-token) en el mismo encabezado. Los endpoints de imágenes, de códigos de barras y de la comunidad no necesitan ninguno de los dos.
