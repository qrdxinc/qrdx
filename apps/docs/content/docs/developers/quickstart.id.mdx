Di akhir halaman ini, Anda akan memiliki gambar kode QR yang disimpan dari satu permintaan, kunci API untuk workspace Anda, kode dinamis yang QR cetaknya tetap berfungsi setelah Anda mengubah tujuan pengunjung, dan gambaran awal analitik pemindaiannya.

API ini memiliki dua bagian. Gambar tidak memerlukan apa pun: tanpa akun, tanpa kunci. Kode dinamis, pemindaian, dan webhook milik sebuah workspace, sehingga memerlukan kunci API.

## Sebelum Anda mulai [#before-you-start]

- curl, Node.js 18 atau yang lebih baru, atau Python 3 dengan paket `requests`. Pilih tab untuk yang Anda gunakan; pilihan Anda akan tetap berlaku di semua halaman.
- Akun QRdx untuk langkah 2 sampai 4. Akun gratis sudah cukup: workspace Gratis memiliki 10 kode dinamis aktif dan 1.000 permintaan API per hari.

## 1. Buat gambar kode QR (tanpa kunci) [#1-make-a-qr-code-image-no-key]

Jalankan perintah ini. Perintah ini menyimpan PNG kode QR yang membuka qrdx.dev.

<Tabs groupId="language" persist items={["curl", "JavaScript", "Python"]}>
  <Tab value="curl">
    ```bash title="Terminal"
    curl "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=png" -o qr.png
    ```
  </Tab>
  <Tab value="JavaScript">
    ```js title="qr.mjs"
    // Node 18 or later
    import { writeFile } from "node:fs/promises";

    const url = new URL("https://api.qrdx.dev/v1/qr");
    url.searchParams.set("data", "https://qrdx.dev");
    url.searchParams.set("format", "png");

    const response = await fetch(url);
    await writeFile("qr.png", Buffer.from(await response.arrayBuffer()));
    console.log(response.status, response.headers.get("content-type"));
    ```
  </Tab>
  <Tab value="Python">
    ```python title="qr.py"
    # pip install requests
    import requests

    response = requests.get(
        "https://api.qrdx.dev/v1/qr",
        params={"data": "https://qrdx.dev", "format": "png"},
    )
    response.raise_for_status()
    open("qr.png", "wb").write(response.content)
    print(response.status_code, response.headers["content-type"])
    ```
  </Tab>
</Tabs>

```txt title="Output"
200 image/png
qr.png: PNG image data, 512 x 512, 8-bit/color RGBA, non-interlaced
```

Itu sudah merupakan panggilan API yang berfungsi. URL itu sendiri adalah gambarnya, sehingga bisa langsung dipakai di tag `<img>`:

```html title="index.html"
<img src="https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&fg=111111&body=circle" alt="QR code for qrdx.dev" />
```

Ubah warna, bentuk, ukuran, dan format dengan parameter query, atau cobalah di browser pada halaman [Render a QR code image](/docs/developers/api/get-qr-image): panel **Try it** mengirim permintaan dan menampilkan gambarnya. Gambar tidak dihitung dalam kuota apa pun; batasnya adalah {facts.imageApiPerMinute} permintaan per menit untuk setiap alamat IP.

## 2. Buat kunci API [#create-an-api-key]

Semua hal lain di API bekerja pada sebuah workspace: membuat kode dinamis, mengubah tujuannya, membaca pemindaiannya. Permintaan tersebut membawa kunci API di header `Authorization`.

1. Buka [Settings → API keys & apps](/dashboard?to=settings/developers&new=1), dan masuk terlebih dahulu jika diperlukan. Formulir **Create API key** akan terbuka.
2. Beri nama pada kunci, misalnya nama server tempat kunci itu akan dijalankan, biarkan **Full access** terpilih, lalu pilih **Create key**. QRdx mungkin meminta Anda memastikan bahwa itu benar-benar Anda terlebih dahulu.
3. Salin kunci dari dialog **Copy your API key**. Kunci hanya ditampilkan sekali ini: QRdx menyimpan hash-nya dan tidak dapat menampilkannya lagi. Dialog itu juga menampilkan permintaan curl untuk membuat kode dinamis, dengan kunci Anda sudah terisi, jika Anda lebih suka menempelkannya.

<Shot id="create-key-dialog" />

<Shot id="api-key-copy-dialog" />

Ekspor kunci untuk langkah berikutnya:

```bash title="Terminal"
export QRDX_API_KEY=qrdx_...
```

Kunci ini bertindak atas nama Anda di workspace yang terbuka saat Anda membuatnya, dan permintaan dengan kunci ini dihitung dalam kuota harian workspace tersebut. [API keys](/docs/developers/api-keys) membahas cakupan, tim, masa berlaku, dan pencabutan.

## 3. Buat kode dinamis [#3-create-a-dynamic-code]

Kode dinamis adalah tautan pendek yang dapat Anda arahkan ke tempat lain setelah dicetak:

<Tabs groupId="language" persist items={["curl", "JavaScript", "Python"]}>
  <Tab value="curl">
    ```bash title="Terminal"
    curl -X POST https://api.qrdx.dev/v1/codes \
      -H "Authorization: Bearer $QRDX_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"destinationUrl": "https://example.com", "title": "My first code"}'
    ```
  </Tab>
  <Tab value="JavaScript">
    ```js title="create.mjs"
    const response = await fetch("https://api.qrdx.dev/v1/codes", {
      method: "POST",
      headers: {
        Authorization: `Bearer ${process.env.QRDX_API_KEY}`,
        "Content-Type": "application/json",
      },
      body: JSON.stringify({
        destinationUrl: "https://example.com",
        title: "My first code",
      }),
    });
    const { data: code } = await response.json();
    console.log(response.status, code.id, code.shortLink);
    ```
  </Tab>
  <Tab value="Python">
    ```python title="create.py"
    import os
    import requests

    response = requests.post(
        "https://api.qrdx.dev/v1/codes",
        headers={"Authorization": f"Bearer {os.environ['QRDX_API_KEY']}"},
        json={"destinationUrl": "https://example.com", "title": "My first code"},
    )
    response.raise_for_status()
    code = response.json()["data"]
    print(response.status_code, code["id"], code["shortLink"])
    ```
  </Tab>
</Tabs>

Responsnya adalah `201 Created` beserta kode baru:

```json title="201 Created"
{
  "data": {
    "id": "cmwgwq0t80000iscg4ybn05kh",
    "slug": "l0q9fZn",
    "shortLink": "https://qrdx.dev/q/l0q9fZn",
    "defaultShortLink": "https://qrdx.dev/q/l0q9fZn",
    "nfcLink": "https://qrdx.dev/q/l0q9fZn?nfc",
    "domain": null,
    "destinationUrl": "https://example.com/",
    "title": "My first code",
    "contentType": "url",
    "kind": "redirect",
    "pageId": null,
    "status": "active",
    "style": null,
    "scanCount": 0,
    "lastScannedAt": null,
    "archivedAt": null,
    "createdAt": "2026-11-14T21:17:45.512Z",
    "updatedAt": "2026-11-14T21:17:45.512Z",
    "organizationId": "ws_ad2c5e1cce31ccf31535e78f08ab5b78",
    "preciseLocation": false
  }
}
```

Ada dua kolom yang penting sekarang. `shortLink` adalah yang dikodekan oleh kode QR: render dengan API gambar dari langkah 1, `https://api.qrdx.dev/v1/qr?data=https://qrdx.dev/q/l0q9fZn&format=png`, lalu cetak. `id` adalah cara Anda merujuk ke kode ini mulai sekarang, jadi simpanlah:

```bash title="Terminal"
export CODE_ID=cmwgwq0t80000iscg4ybn05kh
```

[Create codes](/docs/developers/api/create-codes) mencantumkan setiap kolom yang dapat Anda kirim, termasuk back-half kustom dan desain.

## 4. Arahkan ke tujuan lain [#4-point-it-somewhere-else]

Ubah tujuan kapan saja; kode yang sudah dicetak tetap berfungsi:

```bash title="Terminal"
curl -X PATCH https://api.qrdx.dev/v1/codes/$CODE_ID \
  -H "Authorization: Bearer $QRDX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"destinationUrl": "https://example.com/new-page"}'
```

Respons `200 OK` adalah kode yang sama dengan `"destinationUrl": "https://example.com/new-page"` dan `updatedAt` yang baru. Pindai kode dengan ponsel Anda, lalu baca analitiknya:

```bash title="Terminal"
curl "https://api.qrdx.dev/v1/codes/$CODE_ID/scans?range=7d" \
  -H "Authorization: Bearer $QRDX_API_KEY"
```

```json title="200 OK (before the first scan, trimmed)"
{
  "data": {
    "codeId": "cmwgwq0t80000iscg4ybn05kh",
    "range": "7d",
    "retentionDays": 365,
    "days": 7,
    "total": 0,
    "unique": 0,
    "interval": "day",
    "series": [{ "date": "2026-11-08", "count": 0 }, { "date": "2026-11-09", "count": 0 }],
    "countries": [],
    "devices": [],
    "sources": { "qr": 0, "nfc": 0 }
  }
}
```

Setelah pemindaian, `total` bertambah dan `countries`, `cities`, `devices`, `os`, dan `browsers` terisi. [Get scan analytics](/docs/developers/api/get-code-scans) menjelaskan rentang waktu dan cara menelusuri setiap pemindaian satu per satu.

## Jika terjadi masalah [#if-something-goes-wrong]

Setiap error berupa JSON dengan `code` yang stabil dan pesan yang menjelaskan apa yang harus dilakukan. Dua yang paling mungkin Anda temui di halaman ini:

```json title="401 Unauthorized: the header is missing"
{
  "code": "UNAUTHORIZED",
  "message": "Missing API key. Send an API key as \"Authorization: Bearer <key>\"; create one at https://qrdx.dev/dashboard?to=settings/developers. OAuth access tokens go in the same header.",
  "status": 401,
  "docs": "https://qrdx.dev/docs/developers/api-keys"
}
```

```json title="400 Bad Request: the destination isn't a full URL"
{
  "code": "VALIDATION_ERROR",
  "message": "Invalid request body",
  "data": { "details": [{ "path": "destinationUrl", "message": "Enter a full URL, starting with https://" }] },
  "status": 400
}
```

`401 INVALID_TOKEN` berarti kunci tersalin tidak lengkap, sudah dicabut, atau sudah kedaluwarsa: buat yang baru. `403 INSUFFICIENT_SCOPE` berarti Anda membuat kunci **Read only**; langkah 3 memerlukan `codes:write`. [Halaman error](/docs/developers/errors) mencantumkan setiap kode beserta solusinya.

## Bertindak atas nama orang lain [#get-an-access-token]

Kunci API bertindak atas nama Anda. Jika produk Anda memanggil QRdx untuk orang lain, daftarkan aplikasi OAuth sebagai gantinya: setiap orang menyetujuinya sekali, lalu server Anda mendapatkan token akses untuk akun mereka, yang dikirim di header `Authorization: Bearer` yang sama. Setiap permintaan di atas bekerja tanpa perubahan dengan token sebagai pengganti kunci. Lihat [REST API dan OAuth](/docs/developers/rest-api#get-an-access-token) dan [Membangun integrasi](/docs/developers/build-an-integration).
