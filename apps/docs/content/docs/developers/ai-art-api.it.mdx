Al termine di questa pagina avrai un PNG da 1024 px in cui un QR code è inserito in un'immagine dipinta, decodificato da QRdx prima di arrivare a te, e saprai come codificare un codice dinamico al posto di un testo fisso, quale modalità scegliere e cosa significa ogni errore.

`POST https://api.qrdx.dev/v1/art` dipinge un QR code in un'opera d'arte AI a partire da una descrizione e restituisce l'immagine. È la stessa [arte QR con AI](/ai/art) della scheda Art del Playground e dello studio: {facts.artModel} dipinge l'immagine, poi QRdx verifica che la scansione porti al tuo contenuto prima di consegnartela. Se l'immagine del modello non si lascia scansionare così com'è, QRdx rafforza il codice solo quanto serve, sui pixel del modello stesso.

<Callout type="info" title="Chiave API e immagini mensili">
L'endpoint richiede una [chiave API](/docs/developers/api-keys) con lo scope `codes:write` (le chiavi **Accesso completo** lo hanno). Ogni immagine usa una delle immagini di arte AI mensili del workspace della chiave, la stessa quota usata dall'app; [Piani e limiti](/docs/plans-and-limits) riporta i numeri per ogni piano. Una chiamata che fallisce, o la cui immagine non può essere resa scansionabile, non usa nessuna immagine.
</Callout>

## Prima di iniziare [#before-you-start]

- Una chiave API con `codes:write`, esportata come `QRDX_API_KEY`.
- Un client HTTP con un timeout di almeno 60 secondi. Una chiamata richiede circa 15-45 secondi in modalità code, 25-45 in modalità photo e 40-55 in modalità scene, che dipinge prima la sua immagine.
- Per un codice dinamico, il suo `id` da [`GET /v1/codes`](/docs/developers/api/list-codes) o dalla risposta che [lo ha creato](/docs/developers/api/create-codes).

## 1. Dipingi un codice per un link [#1-paint-a-code-for-a-link]

      -H "Authorization: Bearer $QRDX_API_KEY" \

    ```

  <Tab value="JavaScript">

    const response = await fetch("https://api.qrdx.dev/v1/art", {

      headers: {
        Authorization: `Bearer ${process.env.QRDX_API_KEY}`,

      }),

    });
    const { data, credits } = await response.json();
    // data.imageUrl is a data: URL; save the PNG bytes
    const base64 = data.imageUrl.split(",")[1];
    await writeFile("art.png", Buffer.from(base64, "base64"));
    console.log(data.text, data.blend, credits.remaining);
    ```

  <Tab value="Python">
    ```python title="art.py"

    import os
    import requests

    response = requests.post(
        "https://api.qrdx.dev/v1/art",
        headers={"Authorization": f"Bearer {os.environ['QRDX_API_KEY']}"},

        timeout=90,
    )
    response.raise_for_status()
    body = response.json()
    png = base64.b64decode(body["data"]["imageUrl"].split(",", 1)[1])
    open("art.png", "wb").write(png)
    print(body["data"]["text"], body["data"]["blend"], body["credits"]["remaining"])
    ```

La risposta è un JSON con l'immagine come URL `data:`:

```json title="200 OK (fields)"
{
  "data": {
    "imageUrl": "data:image/png;base64,iVBORw0KGgo…",
    "width": 1024,
    "height": 1024,
    "seed": 2841337190,
    "mode": "code",
    "blend": "least",
    "blendStrength": 0.35,
    "text": "https://qrdx.dev",
    "visibility": 50,
    "creativity": 45
  },
  "credits": { "plan": "pro", "limit": 30, "used": 7, "remaining": 23, "pooled": false, "resetsAt": "2026-12-01T00:00:00.000Z" }
}
```

- `imageUrl` è un PNG quadrato da 1024 px come URL `data:`. QRdx non ne conserva una copia, quindi salvalo.
- `text` è esattamente ciò a cui porta la scansione dell'immagine. QRdx l'ha decodificato prima di rispondere.
- `blend` indica come l'immagine è stata resa scansionabile: `none` (l'immagine del modello così com'è), `least` (quadrati di posizionamento, zona di quiete e moduli rafforzati solo quanto serve, sull'immagine del modello) o `image-qr` (ridisegnata come QR code Image QR, l'ultima risorsa). `blendStrength` va da `0` (così com'è) a `1` (Image QR).
- `credits` è la quota del workspace dopo questa immagine.

Per ottenere direttamente il PNG invece del JSON, aggiungi `?format=png` oppure invia `Accept: image/png`. Seed, modalità, blend e immagini rimaste arrivano allora negli header `X-QRdx-Seed`, `X-QRdx-Mode`, `X-QRdx-Blend`, `X-QRdx-Blend-Strength` e `X-QRdx-Credits-Remaining`:

```bash title="Terminal"
curl "https://api.qrdx.dev/v1/art?format=png" \
  -H "Authorization: Bearer $QRDX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"text": "https://qrdx.dev", "prompt": "a lighthouse on a cliff, woodcut print"}' \
  --max-time 90 -o art.png
```

## 2. Codifica invece un codice dinamico [#encode]

Invia esattamente uno tra `text` e `code`:

- `text`: il link o il testo contenuto nel codice, fino a 300 caratteri. L'arte è un'immagine, quindi il suo contenuto non può cambiare dopo la stampa.
- `code`: l'`id` di uno dei [QR code dinamici](/docs/dynamic-qr-codes) del workspace. L'arte codifica il link breve del codice, quindi puoi cambiare la destinazione dopo la stampa e le sue scansioni compaiono nelle analisi. Un codice di un altro workspace, o nel cestino, restituisce `404`.

```bash title="Terminal"
curl https://api.qrdx.dev/v1/art \
  -H "Authorization: Bearer $QRDX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"code": "cm5code0spring0menu00001", "prompt": "a bistro chalkboard menu on a brick wall", "mode": "scene"}' \
  --max-time 90 -o art.json
```

La risposta contiene allora anche `"code": { "id", "shortLink" }`, e `text` è il link breve.

## 3. Scegli una modalità e uno stile [#modes]

| `mode` | Cosa ottieni |
| --- | --- |
| `code` (predefinita) | Il codice è l'intera immagine: la tua opera dipinta nei suoi moduli, con quadrati di posizionamento semplici e una zona di quiete chiara intorno. Si scansiona nel modo più affidabile |
| `scene` | Prima viene dipinta un'immagine dalla descrizione, poi il codice viene dipinto al suo centro, così l'immagine arriva fino al codice e lo attraversa, con i moduli fatti dei suoi colori e della sua luce |
| `photo` | Lo stesso, con la tua `photo` come immagine: mantiene soggetto, colori e luce intorno e attraverso il codice. Invia la foto solo con questa modalità |

### Stili rapidi [#quick-looks]

Uno stile rapido è uno stile già pronto, come una tecnica o un'atmosfera, che QRdx aggiunge al tuo `prompt`: `"a koi pond in the rain"` con `"style": "watercolor"` dipinge lo stagno di koi ad acquerello. Invia il suo id come `style`; qualsiasi altro valore è un `400 VALIDATION_ERROR`. Gli stili sono quelli proposti come chip nello [studio di arte AI](/ai/art) e nella scheda Art del Playground, e funzionano in ogni modalità.

| `style` | Stile |
| --- | --- |
| `watercolor` | Acquerello |
| `oil-painting` | Pittura a olio |
| `anime` | Anime |
| `cartoon` | Cartoon |
| `pixel-art` | Pixel art |
| `pop-art` | Pop art |
| `charcoal` | Carboncino |
| `ink` | Inchiostro |
| `cyberpunk` | Cyberpunk |
| `fantasy` | Fantasy |
| `photographic` | Fotografico |
| `low-poly` | Low poly |
| `papercut` | Carta ritagliata |

`prompt` è facoltativo. Se lo ometti, QRdx ne scrive prima uno in base a `mode`, `style` e `photo` che hai inviato: una scena concreta con un soggetto, un'ambientazione e la luce, oppure, in modalità photo, una descrizione di ciò che c'è nella tua foto così che l'arte lo mantenga. Scriverlo non usa nessuna immagine di arte AI aggiuntiva. La risposta include poi il testo scritto come `writtenPrompt`, così puoi inviarlo di nuovo, modificato, la volta successiva. Se la scrittura fallisce, ricevi `502 AI_ART_DESCRIBE_FAILED` e nessuna immagine viene usata.

## Campi della richiesta [#request-fields]

| Campo | Predefinito | Descrizione |
| --- | --- | --- |
| `text` | | Ciò che il codice codifica, fino a 300 caratteri. Invia questo oppure `code` |
| `code` | | L'`id` di un codice dinamico, al posto di `text` |
| `prompt` | scritto per te | L'opera da dipingere, in parole semplici, di almeno 3 caratteri se inviato |
| `mode` | `code` | `code`, `scene` o `photo`; vedi sopra |
| `style` | | L'id di uno stile rapido, combinato con il tuo prompt |
| `negativePrompt` | | Cosa tenere fuori dall'immagine |
| `visibility` | `50` | Visibilità del QR, da `0` a `100`: più alta mostra il codice più chiaramente, più bassa favorisce l'immagine |
| `creativity` | `45` | `0` segue il prompt alla lettera, `100` lo interpreta liberamente |
| `seed` | casuale | Invia un seed di una risposta precedente per ottenere un'immagine simile |
| `reference` | | Un'immagine di riferimento per colori e forme, come un logo o una palette |
| `photo` | | Solo modalità photo: l'immagine in cui dipingere il codice |

`reference` e `photo` sono URL `data:` PNG o JPEG (`data:image/jpeg;base64,…`). Riduci `reference` a circa 512 px sul lato più lungo (al massimo 600 KB) e ritaglia `photo` in formato quadrato a circa 1024 px (al massimo 1 MB), la dimensione a cui viene creata l'arte. Vengono inviate al modello e poi scartate: QRdx non le salva né le registra nei log. Le immagini più grandi vengono rifiutate con `413 AI_ART_IMAGE_TOO_LARGE`. La [pagina di riferimento](/docs/developers/api/create-art) contiene lo schema completo e un pannello Try it.

## Crediti e limiti [#credits-and-limits]

L'API attinge alle stesse immagini di arte AI mensili dell'app, conteggiate per il workspace a cui appartiene la chiave. Gratuito, Pro e Business includono ciascuno un certo numero di immagini al mese, e Business le condivide tra tutto il team; [Piani e limiti](/docs/plans-and-limits) riporta i numeri. Si azzerano il 1° di ogni mese (UTC).

- Quando le immagini del mese sono esaurite, l'API risponde `AI_ART_CREDITS_EXHAUSTED`: `402` su Gratuito e Pro, dove un upgrade ne aggiunge altre, e `429` su Business.
- Ogni persona può creare al massimo 25 immagini al giorno, oltre alla quota mensile (`429 AI_ART_DAILY_LIMIT`), e avviarne fino a 12 al minuto.
- Ogni chiamata conta anche per la quota API giornaliera del workspace e per il limite al minuto sulle scritture ([Limiti di frequenza](/docs/developers/rest-api#rate-limits)).

## Se qualcosa va storto [#if-something-goes-wrong]

Gli errori hanno la forma abituale dell'API (`code`, `message`, `status`); [Errori](/docs/developers/errors) li elenca tutti. Nessuno degli errori `5xx` usa un'immagine.

| Stato | `code` | Cosa fare |
| --- | --- | --- |
| 400 | `AI_ART_TEXT_TOO_LONG` | Accorcia `text`, oppure invia il `code` di un codice dinamico |
| 402 | `AI_ART_CREDITS_EXHAUSTED` | Aspetta il 1° del mese, oppure passa a un piano superiore |
| 413 | `AI_ART_IMAGE_TOO_LARGE` | Riduci le dimensioni di `photo` o `reference` |
| 429 | `AI_ART_CREDITS_EXHAUSTED` | Business: aspetta il 1° del mese |
| 429 | `AI_ART_DAILY_LIMIT` | Riprova domani (UTC) |
| 502 | `AI_ART_FAILED` | Il modello ha fallito o ha rifiutato il prompt. Riprova o riformulalo |
| 502 | `AI_ART_UNSCANNABLE` | Riprova con un valore di `visibility` più alto o con un altro seed |
| 502 | `AI_ART_DESCRIBE_FAILED` | Non è stato inviato alcun `prompt` e la sua scrittura è fallita. Riprova o invia il tuo |
| 503 | `AI_ART_BUSY` | Il modello è occupato. Aspetta un minuto e riprova |
| 503 | `AI_NOT_CONFIGURED` | L'arte AI non è configurata su questo server (self-hosted) |
| 504 | `AI_ART_TIMEOUT` | Il modello ha impiegato troppo tempo (in modalità scena, l'immagine ha lasciato troppo poco tempo per dipingere il codice). Riprova, oppure usa la modalità codice |

Un'istanza self-hosted senza Vercel AI Gateway risponde a ogni chiamata con:

```json title="503 Service Unavailable"
{"code":"AI_NOT_CONFIGURED","message":"AI QR art is not configured on this server","status":503}
```

## MCP [#mcp]

Con una chiave API QRdx sulla connessione, il [server MCP](/docs/developers/mcp) offre lo strumento `generate_ai_art`. Accetta gli stessi campi del corpo della richiesta e restituisce il PNG, a cosa porta la scansione e le immagini rimaste questo mese. Chiedilo al tuo assistente con parole semplici:

```txt title="Prompt"
Make AI QR art for my code cm5code0spring0menu00001: a bistro chalkboard menu on a brick wall, as a scene.
```

Senza una chiave, lo strumento risponde spiegando come aggiungerne una. La chiamata richiede fino a un minuto, come la REST API.

## Self-hosting [#self-hosting]

L'arte AI passa da Vercel AI Gateway. Sulla tua istanza, imposta `AI_GATEWAY_API_KEY`; senza, `POST /v1/art` e `generate_ai_art` rispondono `503 AI_NOT_CONFIGURED`.
