이 페이지를 끝까지 따라 하면 요청 한 번으로 저장한 QR 코드 이미지, 워크스페이스용 API 키, 사람들이 이동하는 위치를 바꿔도 인쇄한 QR이 계속 작동하는 동적 QR 코드, 그리고 해당 코드의 스캔 분석을 처음으로 확인해 볼 수 있습니다.

API는 두 부분으로 나뉩니다. 이미지는 계정도 키도 필요 없습니다. 동적 QR 코드, 스캔, 웹훅은 워크스페이스에 속하므로 API 키가 필요합니다.

## 시작하기 전에 [#before-you-start]

- curl, Node.js 18 이상, 또는 `requests` 패키지가 설치된 Python 3. 사용하는 도구의 탭을 선택하세요. 선택한 탭은 다른 페이지에서도 유지됩니다.
- 2~4단계에는 QRdx 계정이 필요합니다. 무료 계정이면 충분합니다. 무료 워크스페이스에서는 활성 동적 QR 코드 10개와 하루 API 요청 1,000회를 사용할 수 있습니다.

## 1. QR 코드 이미지 만들기 (키 없음) [#1-make-a-qr-code-image-no-key]

아래 명령을 실행하세요. qrdx.dev를 여는 QR 코드의 PNG를 저장합니다.

<Tabs groupId="language" persist items={["curl", "JavaScript", "Python"]}>
  <Tab value="curl">
    ```bash title="Terminal"
    curl "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=png" -o qr.png
    ```
  </Tab>
  <Tab value="JavaScript">
    ```js title="qr.mjs"
    // Node 18 or later
    import { writeFile } from "node:fs/promises";

    const url = new URL("https://api.qrdx.dev/v1/qr");
    url.searchParams.set("data", "https://qrdx.dev");
    url.searchParams.set("format", "png");

    const response = await fetch(url);
    await writeFile("qr.png", Buffer.from(await response.arrayBuffer()));
    console.log(response.status, response.headers.get("content-type"));
    ```
  </Tab>
  <Tab value="Python">
    ```python title="qr.py"
    # pip install requests
    import requests

    response = requests.get(
        "https://api.qrdx.dev/v1/qr",
        params={"data": "https://qrdx.dev", "format": "png"},
    )
    response.raise_for_status()
    open("qr.png", "wb").write(response.content)
    print(response.status_code, response.headers["content-type"])
    ```
  </Tab>
</Tabs>

```txt title="Output"
200 image/png
qr.png: PNG image data, 512 x 512, 8-bit/color RGBA, non-interlaced
```

이것이 실제로 작동하는 API 호출입니다. URL 자체가 이미지이므로 `<img>` 태그에서도 바로 사용할 수 있습니다.

```html title="index.html"
<img src="https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&fg=111111&body=circle" alt="QR code for qrdx.dev" />
```

색상, 모양, 크기, 형식은 쿼리 파라미터로 바꿀 수 있습니다. [QR 코드 이미지 렌더링](/docs/developers/api/get-qr-image) 페이지에서 브라우저로 직접 시험해 볼 수도 있습니다. **Try it** 패널이 요청을 보내고 이미지를 보여 줍니다. 이미지는 어떤 할당량에도 포함되지 않으며, 제한은 IP 주소당 분당 {facts.imageApiPerMinute}회 요청입니다.

## 2. API 키 만들기 [#create-an-api-key]

API의 나머지 기능은 모두 워크스페이스를 대상으로 동작합니다. 동적 QR 코드를 만들고, 연결 위치를 바꾸고, 스캔을 읽는 작업입니다. 이런 요청은 `Authorization` 헤더에 API 키를 담아 보냅니다.

1. [설정 → API 키 및 앱](/dashboard?to=settings/developers&new=1)을 엽니다. 필요하면 먼저 로그인하세요. **API 키 만들기** 양식이 열립니다.
2. 키 이름을 입력합니다. 키를 실행할 서버 이름 등이 좋습니다. **전체 액세스**를 그대로 두고 **키 만들기**를 선택하세요. QRdx가 먼저 본인 확인을 요청할 수 있습니다.
3. **API 키 복사** 대화상자에서 키를 복사합니다. 키는 이때 한 번만 표시됩니다. QRdx는 키의 해시만 저장하므로 다시 보여 줄 수 없습니다. 이 대화상자에는 내 키가 채워진, 동적 QR 코드를 만드는 curl 요청도 함께 표시되므로 원하면 그대로 붙여 넣어도 됩니다.

<Shot id="create-key-dialog" />

<Shot id="api-key-copy-dialog" />

다음 단계를 위해 키를 환경 변수로 내보내세요.

```bash title="Terminal"
export QRDX_API_KEY=qrdx_...
```

이 키는 발급할 당시 열려 있던 워크스페이스에서 내 권한으로 동작하며, 이 키로 보낸 요청은 해당 워크스페이스의 일일 할당량에 포함됩니다. 범위, 팀, 만료, 취소에 대해서는 [API 키](/docs/developers/api-keys)를 참고하세요.

## 3. 동적 QR 코드 만들기 [#3-create-a-dynamic-code]

동적 QR 코드는 인쇄한 뒤에도 다른 곳으로 연결을 바꿀 수 있는 짧은 링크입니다.

<Tabs groupId="language" persist items={["curl", "JavaScript", "Python"]}>
  <Tab value="curl">
    ```bash title="Terminal"
    curl -X POST https://api.qrdx.dev/v1/codes \
      -H "Authorization: Bearer $QRDX_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"destinationUrl": "https://example.com", "title": "My first code"}'
    ```
  </Tab>
  <Tab value="JavaScript">
    ```js title="create.mjs"
    const response = await fetch("https://api.qrdx.dev/v1/codes", {
      method: "POST",
      headers: {
        Authorization: `Bearer ${process.env.QRDX_API_KEY}`,
        "Content-Type": "application/json",
      },
      body: JSON.stringify({
        destinationUrl: "https://example.com",
        title: "My first code",
      }),
    });
    const { data: code } = await response.json();
    console.log(response.status, code.id, code.shortLink);
    ```
  </Tab>
  <Tab value="Python">
    ```python title="create.py"
    import os
    import requests

    response = requests.post(
        "https://api.qrdx.dev/v1/codes",
        headers={"Authorization": f"Bearer {os.environ['QRDX_API_KEY']}"},
        json={"destinationUrl": "https://example.com", "title": "My first code"},
    )
    response.raise_for_status()
    code = response.json()["data"]
    print(response.status_code, code["id"], code["shortLink"])
    ```
  </Tab>
</Tabs>

응답은 새 코드와 함께 `201 Created`로 돌아옵니다.

```json title="201 Created"
{
  "data": {
    "id": "cmwgwq0t80000iscg4ybn05kh",
    "slug": "l0q9fZn",
    "shortLink": "https://qrdx.dev/q/l0q9fZn",
    "defaultShortLink": "https://qrdx.dev/q/l0q9fZn",
    "nfcLink": "https://qrdx.dev/q/l0q9fZn?nfc",
    "domain": null,
    "destinationUrl": "https://example.com/",
    "title": "My first code",
    "contentType": "url",
    "kind": "redirect",
    "pageId": null,
    "status": "active",
    "style": null,
    "scanCount": 0,
    "lastScannedAt": null,
    "archivedAt": null,
    "createdAt": "2026-11-14T21:17:45.512Z",
    "updatedAt": "2026-11-14T21:17:45.512Z",
    "organizationId": "ws_ad2c5e1cce31ccf31535e78f08ab5b78",
    "preciseLocation": false
  }
}
```

지금 중요한 필드는 두 가지입니다. `shortLink`는 QR 코드에 인코딩되는 값입니다. 1단계의 이미지 API로 렌더링한 `https://api.qrdx.dev/v1/qr?data=https://qrdx.dev/q/l0q9fZn&format=png`를 인쇄하세요. `id`는 이후 이 코드를 가리키는 방법이므로 잘 보관하세요.

```bash title="Terminal"
export CODE_ID=cmwgwq0t80000iscg4ybn05kh
```

보낼 수 있는 모든 필드는 [코드 만들기](/docs/developers/api/create-codes)에서 확인할 수 있습니다. 사용자 지정 back-half와 디자인도 포함됩니다.

## 4. 다른 곳으로 연결하기 [#4-point-it-somewhere-else]

연결 위치는 언제든 바꿀 수 있으며, 인쇄한 코드는 계속 작동합니다.

```bash title="Terminal"
curl -X PATCH https://api.qrdx.dev/v1/codes/$CODE_ID \
  -H "Authorization: Bearer $QRDX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"destinationUrl": "https://example.com/new-page"}'
```

`200 OK` 응답은 같은 코드에 `"destinationUrl": "https://example.com/new-page"`와 새로운 `updatedAt`이 담겨 돌아옵니다. 휴대폰으로 코드를 스캔한 다음 분석을 읽어 보세요.

```bash title="Terminal"
curl "https://api.qrdx.dev/v1/codes/$CODE_ID/scans?range=7d" \
  -H "Authorization: Bearer $QRDX_API_KEY"
```

```json title="200 OK (before the first scan, trimmed)"
{
  "data": {
    "codeId": "cmwgwq0t80000iscg4ybn05kh",
    "range": "7d",
    "retentionDays": 365,
    "days": 7,
    "total": 0,
    "unique": 0,
    "interval": "day",
    "series": [{ "date": "2026-11-08", "count": 0 }, { "date": "2026-11-09", "count": 0 }],
    "countries": [],
    "devices": [],
    "sources": { "qr": 0, "nfc": 0 }
  }
}
```

스캔 후에는 `total`이 늘어나고 `countries`, `cities`, `devices`, `os`, `browsers`가 채워집니다. 범위 지정 방법과 개별 스캔을 페이지 단위로 가져오는 방법은 [스캔 분석 가져오기](/docs/developers/api/get-code-scans)에서 설명합니다.

## 문제가 생겼을 때 [#if-something-goes-wrong]

모든 오류는 변하지 않는 `code`와 해야 할 일을 알려 주는 메시지가 담긴 JSON으로 반환됩니다. 이 페이지에서 가장 자주 만날 두 가지는 다음과 같습니다.

```json title="401 Unauthorized: the header is missing"
{
  "code": "UNAUTHORIZED",
  "message": "Missing API key. Send an API key as \"Authorization: Bearer <key>\"; create one at https://qrdx.dev/dashboard?to=settings/developers. OAuth access tokens go in the same header.",
  "status": 401,
  "docs": "https://qrdx.dev/docs/developers/api-keys"
}
```

```json title="400 Bad Request: the destination isn't a full URL"
{
  "code": "VALIDATION_ERROR",
  "message": "Invalid request body",
  "data": { "details": [{ "path": "destinationUrl", "message": "Enter a full URL, starting with https://" }] },
  "status": 400
}
```

`401 INVALID_TOKEN`은 키를 일부만 복사했거나, 취소되었거나, 만료되었다는 뜻입니다. 새 키를 만드세요. `403 INSUFFICIENT_SCOPE`는 **읽기 전용** 키를 만들었다는 뜻이며, 3단계에는 `codes:write`가 필요합니다. 모든 코드와 해결 방법은 [오류 페이지](/docs/developers/errors)에 있습니다.

## 다른 사람을 대신해 동작하기 [#get-an-access-token]

API 키는 내 권한으로 동작합니다. 제품이 다른 사람을 대신해 QRdx를 호출한다면 OAuth 앱을 등록하세요. 각 사용자가 한 번 승인하면 서버가 그 사용자 계정의 액세스 토큰을 받으며, 같은 `Authorization: Bearer` 헤더로 보냅니다. 위의 모든 요청은 키 대신 토큰을 넣어도 그대로 동작합니다. [REST API와 OAuth](/docs/developers/rest-api#get-an-access-token) 및 [통합 만들기](/docs/developers/build-an-integration)를 참고하세요.
