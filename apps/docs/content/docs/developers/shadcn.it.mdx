QRdx pubblica un registry shadcn/ui di componenti QR code basati sulla libreria `qrdx`. La CLI di shadcn copia il codice sorgente di ogni componente nel tuo progetto, così il codice è tuo e puoi modificarlo. Usa il registry quando ti serve un pezzo di interfaccia già pronto, con pulsanti di download, una card, una finestra di condivisione o uno scanner; usa il `QRCode` della libreria quando ti serve solo il codice.

<NpmStatus package="qrdx" />

<PackageManagerTabs command="npx shadcn@latest add https://qrdx.dev/r/qr-code.json" />

Ogni componente ha una pagina dedicata con anteprima dal vivo, codice sorgente, passaggi di installazione, esempi e una tabella delle props. Hai personalizzato lo stile di un codice nel [Playground](/playground?open=code&lang=shadcn)? Copialo da lì per ottenere il componente QR Code del registry.

## Cosa viene installato [#what-gets-installed]

Ogni componente è un singolo file nella tua cartella `components`. La CLI installa anche `qrdx` (più `lucide-react` per le icone usate dalla maggior parte dei componenti) e aggiunge i componenti shadcn/ui su cui si basa, come `button`, `card`, `dialog`, `dropdown-menu`, `input` o `label`. Ogni pagina di componente elenca le proprie dipendenze sotto **Manual** nelle schede di installazione.

L'indice completo è su [`https://qrdx.dev/r/registry.json`](https://qrdx.dev/r/registry.json) e ogni elemento si trova su `https://qrdx.dev/r/<name>.json`.

## Installare per nome [#install-by-name]

Per installare con un nome breve, aggiungi il registry al tuo `components.json`:

```json title="components.json"
{
  "registries": {
    "@qrdx": "https://qrdx.dev/r/{name}.json"
  }
}
```

Poi aggiungi uno o più componenti per nome:

<PackageManagerTabs command="npx shadcn@latest add @qrdx/qr-code @qrdx/qr-code-download @qrdx/qr-code-share-dialog" />

## Stile e temi [#styling-and-theming]

I componenti usano classi Tailwind con i token standard del tema shadcn/ui (`bg-card`, `border`, `text-muted-foreground`, `ring-ring`) e i tuoi Button, Card, Dialog e Input, quindi seguono il tuo tema e la modalità scura. I QR code mantengono per impostazione predefinita uno sfondo chiaro, perché moduli scuri su un riquadro chiaro vengono letti da qualsiasi lettore; la pagina [QR Code](/docs/components/qr-code#dark-mode) mostra come seguire invece il tema.

Ogni componente è un Client Component (il suo file inizia con `"use client"`), a causa dei pulsanti e dello stato. Il codice stesso viene comunque renderizzato sul server, quindi è presente nell'HTML della pagina prima che i pulsanti diventino interattivi. Una pagina Server Component può importarli tutti e passare dati del server come props.

I download in PDF richiedono il pacchetto opzionale `jspdf` (`npm install jspdf`). Tutto il resto funziona appena la CLI ha finito.
