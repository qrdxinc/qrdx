Setelah mengikuti halaman ini, setiap kode QR yang dimuat halaman, email, atau spreadsheet Anda dari `chart.googleapis.com` akan dimuat dari [Image API](/docs/developers/image-api) QRdx, dengan ukuran dan tingkat koreksi kesalahan yang sama, tanpa akun atau kunci.

Google menghentikan Image Charts pada April 2012, termasuk kode QR di `chart.googleapis.com/chart?cht=qr`. Endpoint tersebut kini menjawab `404` (diperiksa pada 15 November 2026), sehingga setiap tag `<img>` lama menampilkan gambar rusak. Image API QRdx bekerja dengan cara yang sama, yaitu URL `GET` yang mengembalikan gambar, sehingga perubahannya hanya host baru dan tiga parameter yang berganti nama.

## Sebelum memulai [#before-you-start]

- Temukan file yang masih memakai API lama. Perintah di bawah ini mendaftarkannya, termasuk host lama `chart.apis.google.com`:

```bash title="Terminal"
grep -rlE "chart\.(googleapis|apis\.google)\.com/chart" .
```

- Bekerjalah di checkout git atau tempat lain yang memungkinkan Anda meninjau perubahan sebelum dipublikasikan.

## 1. Bandingkan satu URL [#1-compare-one-url]

Kedua URL di bawah ini menghasilkan gambar yang sama: PNG 300 × 300 untuk `https://example.com` dengan koreksi kesalahan `M` dan margin 2 modul.

```txt title="Before and after"
https://chart.googleapis.com/chart?cht=qr&chs=300x300&chl=https%3A%2F%2Fexample.com&chld=M|2
https://api.qrdx.dev/v1/qr?format=png&size=300&data=https%3A%2F%2Fexample.com&level=M&margin=2
```

```bash title="Terminal"
curl -o after.png "https://api.qrdx.dev/v1/qr?format=png&size=300&data=https%3A%2F%2Fexample.com&level=M&margin=2"
file after.png
# after.png: PNG image data, 300 x 300, 8-bit/color RGBA, non-interlaced
```

## 2. Petakan parameter [#2-map-the-parameters]

| Google Chart | QRdx | Catatan |
| --- | --- | --- |
| `cht=qr` | tidak diperlukan | Endpoint ini hanya menggambar kode QR. Jika disertakan, parameter ini diabaikan |
| `chl=<data>` | `data=<data>` | Di-encode URL dengan cara yang sama, hingga 2.048 karakter |
| `chs=<width>x<height>` | `size=<width>` | Satu angka, karena kode QR berbentuk persegi: `64` hingga `2048` piksel |
| `chld=<level>\|<margin>` | `level=<level>&margin=<margin>` | Huruf yang sama, yaitu `L`, `M`, `Q`, dan `H`. Margin dalam modul, `0` hingga `16` |
| `choe=UTF-8` | tidak diperlukan | QRdx selalu meng-encode teks sebagai UTF-8, yang merupakan default Google. Tidak ada opsi Shift_JIS atau ISO-8859-1. Jika disertakan, parameter ini diabaikan |
| selalu PNG | `format=png` | QRdx mengembalikan SVG kecuali Anda meminta `png`, `webp`, atau `eps`. Gunakan PNG untuk email, karena banyak klien email tidak menampilkan SVG |

Ada dua default yang berbeda. Tanpa `chld`, Google memakai koreksi kesalahan `L`; QRdx memakai `Q`, yang tahan terhadap lebih banyak kerusakan tetapi menghasilkan kode yang lebih padat. Tambahkan `level=L` jika Anda menginginkan tampilan lama. Keduanya memakai margin default 4 modul.

## 3. Tulis ulang URL di file Anda [#3-rewrite-the-urls-in-your-files]

Perintah ini menulis ulang setiap URL kode QR Google Chart di file yang Anda sebutkan, dari kedua host: mengubah host dan path, mengganti nama `chl`, `chs`, dan `chld`, serta menambahkan `format=png` agar gambar tetap PNG. Perl sudah tersedia di macOS dan sebagian besar distribusi Linux.

```bash title="Terminal"
perl -pi -e 's{https?://chart\.(?:googleapis|apis\.google)\.com/chart\?([^\s"\x27<>)]*)}{my $q = $1; $q =~ s/(^|[&;])chl=/${1}data=/; $q =~ s/(^|[&;])chs=(\d+)x\d+/${1}size=$2/; $q =~ s/(^|[&;])chld=([LMQH])(?:\||%7C)(\d+)/${1}level=$2&margin=$3/i; $q =~ s/(^|[&;])chld=([LMQH])/${1}level=$2/i; "https://api.qrdx.dev/v1/qr?format=png&$q"}ge' index.html
```

Jika dijalankan pada file dengan tiga tag lama, hasilnya:

```html title="index.html (after)"
<img src="https://api.qrdx.dev/v1/qr?format=png&cht=qr&size=300&data=https%3A%2F%2Fexample.com&level=M&margin=2" alt="QR">
<img src="https://api.qrdx.dev/v1/qr?format=png&cht=qr&size=150&data=https%3A%2F%2Fexample.com%2Fmenu" alt="QR 2">
<img src="https://api.qrdx.dev/v1/qr?format=png&size=200&cht=qr&data=hello&level=H&choe=UTF-8" alt="QR 3">
```

Sisa `cht=qr` dan `choe=UTF-8` diabaikan oleh QRdx; hapus secara manual jika Anda ingin URL yang rapi. Periksa diff, lalu jalankan lagi `grep` dari awal: seharusnya tidak ada yang tercantum.

## 4. Ubah kode yang membangun URL [#4-change-the-code-that-builds-urls]

```js title="qr.js"
// Before
const src = `https://chart.googleapis.com/chart?cht=qr&chs=200x200&chl=${encodeURIComponent(link)}`;

// After
const src = `https://api.qrdx.dev/v1/qr?format=png&size=200&data=${encodeURIComponent(link)}`;
```

Di Google Sheets:

```txt title="Sheets formula"
=IMAGE("https://api.qrdx.dev/v1/qr?format=png&size=150&data="&ENCODEURL(A2))
```

Sheets memuat gambar melalui server Google sendiri, sehingga sheet dengan ratusan kode bisa mencapai batas per IP di bawah. Untuk daftar yang panjang, buat file sekali saja dengan [generator massal](/tools/bulk) atau `qrdx batch` dari [CLI](/docs/developers/cli).

## Jika terjadi masalah [#if-something-goes-wrong]

### `400` dengan `"param": "size"` [#400-with-param-size]

`chs` di bawah 64 piksel (seperti `50x50`) atau di atas 2048 akan ditolak. Ubah ukuran tersebut secara manual; `64` adalah yang terkecil yang dapat digambar Image API.

```json title="400 Bad Request"
{"code":"VALIDATION_ERROR","message":"Invalid query parameters","data":{"details":[{"param":"size","message":"Too small: expected number to be >=64"}]},"status":400}
```

### Gambar lebih padat dari sebelumnya [#the-image-is-denser-than-before]

Koreksi kesalahan default Google adalah `L`; default QRdx adalah `Q`. Tambahkan `level=L` agar sesuai dengan tampilan lama.

### `429` setelah pemuatan ulang massal [#429-after-a-bulk-reload]

Image API mengizinkan {facts.imageApiPerMinute} permintaan per menit per alamat IP. Tunggu selama beberapa detik sesuai header `Retry-After`, atau buat file sekali saja alih-alih memuatnya secara langsung.

## Hal lain yang perlu diketahui [#what-else-to-know]

- **Caching:** URL yang sama selalu mengembalikan byte yang sama, sehingga respons di-cache selama satu tahun (`Cache-Control: public, max-age=31536000, immutable`).
- **Opsi lainnya:** warna (`fg`, `bg`), bentuk modul dan mata, ikon logo (`logoIcon`), dan bingkai. Cobalah di [pembuat URL](/qr-code-api), atau baca [parameter](/docs/developers/image-api#parameters).
- **Self-hosting:** QRdx yang [di-host sendiri](/docs/self-hosting) menyediakan API yang sama di `/api/v1/qr` pada domain Anda sendiri.
