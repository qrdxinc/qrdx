Al terminar esta página tendrás archivos de códigos QR creados desde tu terminal, con los mismos estilos que el Playground, y una carpeta de códigos generada a partir de un CSV con un solo comando, sin subir nada a ningún sitio.

`@qrdx/cli` genera los mismos códigos QR que el Playground y la [librería `qrdx`](/docs/getting-started) desde la línea de comandos. En scripts y CI nunca te hace preguntas; si ejecutas `qrdx generate` sin argumentos en una terminal, te pide el contenido y las opciones paso a paso.

## Antes de empezar [#before-you-start]

- Node.js 22 o posterior.
- La salida en PNG y WebP usa [sharp](https://sharp.pixelplumbing.com), una dependencia opcional que npm instala donde tu plataforma lo permite; SVG y EPS funcionan sin ella.
- El paquete `qrdx` de npm es la librería de React. La CLI solo está en `@qrdx/cli`.

## 1. Crea un código [#1-make-one-code]

Ejecútalo una vez con `npx`, o instálalo de forma global para obtener el comando `qrdx`:

```bash title="Terminal"
npx @qrdx/cli generate "https://example.com" -o qr.svg

npm install -g @qrdx/cli
qrdx generate "https://example.com" -o qr.png --size 1024
```

```txt title="Output"
◇  ✔  Saved to qr.png (1024×1024)
└  Done!
```

La extensión del archivo determina el formato; usa `--format` cuando el nombre del archivo no tenga extensión.

| Formato | Úsalo para | `--size` significa |
| --- | --- | --- |
| `.svg` | Páginas web, herramientas de diseño, escalar sin pérdida | Ancho en píxeles (por defecto 512) |
| `.png` | Documentos, presentaciones, cualquier lugar que necesite una imagen | Ancho en píxeles |
| `.webp` | Sitios web: los píxeles del PNG, sin pérdida, en un archivo más pequeño | Ancho en píxeles |
| `.eps` | Imprentas, Illustrator, InDesign | Ancho en puntos (72 por pulgada, así que `144` son 2 pulgadas) |

Los archivos EPS son PostScript vectorial. Los logos PNG y JPEG se incrustan tal cual; los demás formatos de logo se convierten con sharp si está instalado y, si no, se omiten con una advertencia.

## 2. Dale estilo [#2-style-it]

```bash title="Terminal"
# High-resolution PNG for print
qrdx generate "https://example.com" -o print.png --size 2048 --level H

# Vector EPS, 2 inches wide, for a print shop
qrdx generate "https://example.com" -o qr.eps --size 144

# Branded colors and patterns
qrdx generate "https://example.com" --body circle --eye rounded --fg "#1a1a2e" -o brand.svg

# Gradient foreground
qrdx generate "https://example.com" -o gradient.svg \
  --fg '{"type":"linear","stops":[{"color":"#6366f1","offset":0},{"color":"#ec4899","offset":100}],"angle":135}'

# "Scan for the menu" frame
qrdx generate "https://example.com/menu" --frame banner-bottom --frame-text "Scan for the menu" -o menu.png

# Wi-Fi network
qrdx generate "WIFI:T:WPA;S:MyNetwork;P:MyPassword;;" -o wifi.svg
```

```txt title="Output of the frame example"
◇  ✔  Saved to menu.png (635×727)
```

Con un marco, `--size` es el ancho del código y el marco se suma a la imagen. Para imprimir un [código QR dinámico](/docs/dynamic-qr-codes), pasa su enlace corto (`https://qrdx.dev/q/<slug>`) como dato.

| Opción | Por defecto | Descripción |
| --- | --- | --- |
| `-o`, `--output` | `qr.svg` | Archivo de salida |
| `--format` | según la extensión | `svg`, `png`, `webp` o `eps` |
| `--size` | `512` | Tamaño de salida (ver arriba) |
| `-l`, `--level` | `Q` | Corrección de errores: `L`, `M`, `Q` o `H` |
| `--body` | `square` | [Patrón](/docs/features/patterns) de los módulos de datos |
| `--eye` | `square` | Patrón del ojo de las esquinas |
| `--dot` | `square` | Patrón del punto del ojo de las esquinas |
| `--fg`, `--bg` | `#000000`, `#ffffff` | Primer plano y fondo: un color hexadecimal o un degradado JSON (`linear`, `radial` o `angular`) |
| `--eye-color`, `--dot-color` | `--fg` | Colores del ojo de las esquinas y de su punto |
| `--logo` | | URL de la imagen del logo central (úsalo con `--level H`) |
| `--no-logo` | | Omite la pregunta del logo en modo interactivo |
| `--margin` | `0` | Zona de silencio, en módulos |
| `--template` | | Un marco dibujado como plantilla: `Arrow`, `StandardBox`, `SquareBorder`, `StrikedBox`, `Halloween` o `DotRing` |
| `--frame` | | [Marco](/docs/features/frames) con llamada a la acción: cualquiera de los {facts.frameStyles} marcos incluidos, como `banner-bottom`, `rounded-border`, `circle`, `sticker` o `phone` (consulta [todos](/docs/styles#frames)) |
| `--frame-text` | `Scan me` | Etiqueta del marco, hasta 24 caracteres; `""` la oculta |
| `--frame-color`, `--frame-text-color` | | Colores del marco y de la etiqueta (hexadecimal) |

`qrdx --help` muestra todos los nombres de patrones. Un valor no válido termina con el código `1` y enumera lo que se acepta:

```txt title="qrdx generate https://example.com --body nope -o bad.svg"
✗ Invalid --body "nope". Expected one of: circle, circle-large, square, diamond, circle-mixed, pacman, rounded, small-square, vertical-line, horizontal-line, liquid, liquid-horizontal, liquid-vertical, classy, classy-rounded, leaf, plus, hexagon, star, heart, random-dots, mosaic, octagon
```

## 3. Crea muchos códigos desde un CSV [#3-make-many-codes-from-a-csv]

`qrdx batch` escribe en una carpeta un código QR estático por cada fila de un archivo CSV:

```csv title="products.csv"
sku,url
A-100,https://example.com/products/a-100
A-101,https://example.com/products/a-101
```

```bash title="Terminal"
qrdx batch products.csv -o codes --format png --size 1024 --body circle
```

```txt title="Output"
2 rows · 2 saved
✔  Saved 2 PNG codes to codes in 0.2 s
```

La carpeta contiene `A-100.png` y `A-101.png`. Lee las mismas columnas que el [generador masivo](/tools/bulk): el contenido, de una columna llamada `value`, `url`, `link`, `data`, `content`, `text` o `qr` (si no, la primera columna), y los nombres de archivo, de una llamada `file name`, `name`, `label`, `id`, `title` o `sku` (si no, `qr-00001`, `qr-00002`, etc.). Elige otras por el nombre del encabezado o el número de columna:

| Opción | Por defecto | Descripción |
| --- | --- | --- |
| `-o`, `--out` | `qr-codes` | Carpeta para los códigos |
| `--format` | `svg` | `svg`, `png` o `eps` |
| `--value-column` | se deduce | Columna con el contenido de cada código |
| `--name-column` | se deduce | Columna con los nombres de archivo |
| `--no-header` | | La primera fila es un código, no nombres de columna |
| `--jobs` | `4` para SVG, `8` en los demás | Códigos generados a la vez, de 1 a 64 |

Todas las opciones de estilo anteriores se aplican a todos los códigos. El CSV se lee como un flujo y cada código se guarda en cuanto se genera, así que el comando no tiene límite de filas: en un portátil, 10.000 códigos SVG tardaron unos 40 segundos y usaron menos de 200 MB de memoria. No se sube nada y no hace falta cuenta. Las filas que no se pueden codificar se omiten y se enumeran con el motivo en `errors.csv`, dentro de la carpeta de salida.

Para imprimir [códigos dinámicos](/docs/dynamic-qr-codes) en masa, créalos primero (con la importación de CSV del panel o con [`POST /v1/codes`](/docs/developers/api/create-codes)) y ejecuta `qrdx batch` sobre el CSV de resultados que te da la importación, con `--value-column short_link`.

## Si algo sale mal [#if-something-goes-wrong]

### `Invalid --body "…"` (o `--eye`, `--dot`, `--frame`) [#invalid---body--or---eye---dot---frame]

El valor no es ninguno de los nombres de patrón o de marco. El mensaje enumera los aceptados; `qrdx --help` también los muestra.

### La salida PNG o WebP falla, pero SVG funciona [#png-or-webp-output-fails-svg-works]

sharp no está instalado para tu plataforma. Reinstala `@qrdx/cli` con acceso a la red para que npm pueda descargar la dependencia opcional, o genera SVG o EPS.

### Se rechaza `--jobs` [#--jobs-is-refused]

Acepta un número de 1 a 64.

### Falta una fila en la carpeta de salida [#a-row-is-missing-from-the-output-folder]

Su contenido no se pudo codificar (está vacío o es demasiado largo para un código QR). Abre `errors.csv` en la carpeta de salida para ver la fila y el motivo.
