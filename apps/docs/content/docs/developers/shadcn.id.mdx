QRdx menerbitkan registry shadcn/ui berisi komponen kode QR yang dibuat di atas library `qrdx`. CLI shadcn menyalin source setiap komponen ke proyek Anda, sehingga Anda memiliki kodenya dan dapat mengubahnya. Gunakan registry ini ketika Anda menginginkan bagian UI yang sudah jadi, dengan tombol unduh, kartu, dialog berbagi, atau pemindai; gunakan `QRCode` bawaan library jika Anda hanya membutuhkan kodenya.

<NpmStatus package="qrdx" />

<PackageManagerTabs command="npx shadcn@latest add https://qrdx.dev/r/qr-code.json" />

Setiap komponen memiliki halamannya sendiri dengan pratinjau langsung, source, langkah instalasi, contoh, dan tabel props. Sudah menata gaya kode di [Playground](/playground?open=code&lang=shadcn)? Salin dari sana untuk mendapatkan komponen QR Code dari registry.

## Yang ikut terinstal [#what-gets-installed]

Setiap komponen berupa satu file di folder `components` Anda. CLI juga menginstal `qrdx` (serta `lucide-react` untuk ikon yang dipakai sebagian besar komponen) dan menambahkan komponen shadcn/ui yang menjadi dasarnya, seperti `button`, `card`, `dialog`, `dropdown-menu`, `input`, atau `label`. Halaman setiap komponen mencantumkan dependensinya sendiri di bawah **Manual** pada tab instalasi.

Indeks lengkapnya ada di [`https://qrdx.dev/r/registry.json`](https://qrdx.dev/r/registry.json), dan setiap item di `https://qrdx.dev/r/<name>.json`.

## Instal berdasarkan nama [#install-by-name]

Untuk menginstal dengan nama pendek, tambahkan registry ke `components.json` Anda:

```json title="components.json"
{
  "registries": {
    "@qrdx": "https://qrdx.dev/r/{name}.json"
  }
}
```

Lalu tambahkan satu atau beberapa komponen berdasarkan nama:

<PackageManagerTabs command="npx shadcn@latest add @qrdx/qr-code @qrdx/qr-code-download @qrdx/qr-code-share-dialog" />

## Gaya dan tema [#styling-and-theming]

Komponen menggunakan class Tailwind dengan token tema standar shadcn/ui (`bg-card`, `border`, `text-muted-foreground`, `ring-ring`) serta Button, Card, Dialog, dan Input milik Anda sendiri, sehingga mengikuti tema dan mode gelap Anda. Kode QR secara default memakai latar terang, karena modul gelap pada ubin terang dapat dipindai oleh semua pembaca; halaman [QR Code](/docs/components/qr-code#dark-mode) menunjukkan cara mengikuti tema sebagai gantinya.

Setiap komponen adalah Client Component (file-nya diawali dengan `"use client"`), karena memiliki tombol dan state. Kodenya sendiri tetap dirender di server, sehingga sudah ada di HTML halaman sebelum tombol menjadi interaktif. Halaman Server Component dapat mengimpor komponen mana pun dan meneruskan data server sebagai props.

Unduhan PDF membutuhkan paket opsional `jspdf` (`npm install jspdf`). Semua yang lain langsung berfungsi setelah CLI selesai.
