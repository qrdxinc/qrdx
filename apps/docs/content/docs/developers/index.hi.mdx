QRdx में जो कुछ भी होता है, वह सब कोड से उपलब्ध है। इससे शुरू करें कि आप क्या बनाना चाहते हैं: हर पंक्ति में टूल का नाम, उसकी ज़रूरतें और वह पेज दिया है जहाँ से आप आगे बढ़ सकते हैं।

| आप क्या करना चाहते हैं | इस्तेमाल करें | ज़रूरत |
| --- | --- | --- |
| किसी पेज, ईमेल या README में QR कोड लगाना | [QR code image API](/docs/developers/image-api): एक `GET` URL जो खुद इमेज है | कुछ नहीं |
| लेबल या प्रोडक्ट फ़ीड के लिए बारकोड बनाना | [Barcode API](/docs/developers/barcode-api): वही तरीका, EAN, UPC, Code 128 और अन्य के लिए | कुछ नहीं |
| ऐसे कोड बनाना जिन्हें प्रिंट के बाद कहीं और पॉइंट किया जा सके, और उनके स्कैन पढ़ना | [REST API](/docs/developers/quickstart): `POST /v1/codes`, `PATCH`, `GET …/scans` | एक [API key](/docs/developers/api-keys) |
| अपने सिस्टम में स्कैन, नए कोड या फ़ॉर्म के जवाबों पर प्रतिक्रिया देना | [Webhooks](/docs/webhooks): आपके URL पर साइन किए गए `POST` अनुरोध | API key या डैशबोर्ड, Business प्लान |
| AI असिस्टेंट से चैट में QR कोड बनवाना | [MCP सर्वर](/docs/developers/mcp): `https://mcp.qrdx.dev/mcp` | कुछ नहीं |
| स्क्रिप्ट, बिल्ड या CSV से QR कोड बनाना | [CLI](/docs/developers/cli): `npx @qrdx/cli` | Node.js 22 |
| AI आर्टवर्क में QR कोड पेंट करना | [AI art API](/docs/developers/ai-art-api): `POST /v1/art` | एक API key, हर महीने के AI art इमेज |
| दूसरे लोगों को अपना QRdx अकाउंट आपके प्रोडक्ट से जोड़ने देना | [इंटीग्रेशन बनाएँ](/docs/developers/build-an-integration): PKCE के साथ OAuth 2.0 | एक OAuth ऐप |
| n8n में QRdx को ऑटोमेट करना | [n8n nodes](/docs/developers/n8n): `@qrdx/n8n-nodes-qrdx` | सेल्फ़-होस्टेड n8n |
| React ऐप के अंदर स्टाइल वाले कोड रेंडर करना | [React लाइब्रेरी](/docs/getting-started): `qrdx` पैकेज | npm |

## दो मिनट में पहला अनुरोध [#first-request-in-two-minutes]

[क्विकस्टार्ट](/docs/developers/quickstart) में बिना key के एक अनुरोध से QR कोड इमेज बनती है, फिर API key बनती है, फिर एक डायनेमिक QR कोड बनता है और उसे कहीं और पॉइंट किया जाता है। इस पेज की बाकी सारी चीज़ें इन्हीं चार चरणों पर टिकी हैं।

```bash title="Terminal"
curl "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=png" -o qr.png
```

## Base URL और ऑथेंटिकेशन [#base-url-and-authentication]

REST API `https://api.qrdx.dev/v1` पर चलता है। वही routes `https://qrdx.dev/api/v1` पर भी जवाब देते हैं, और [सेल्फ़-होस्टेड](/docs/self-hosting) इंस्टेंस उन्हें अपने डोमेन पर `/api/v1` पर देता है।

अनुरोधों में [API key](/docs/developers/api-keys) `Authorization: Bearer qrdx_…` के रूप में जाती है। key उसी workspace पर काम करती है जिसमें वह बनी थी, और वहाँ आपकी भूमिका के साथ। जो ऐप दूसरे QRdx यूज़र्स की ओर से काम करते हैं, वे इसी header में [OAuth 2.0 access token](/docs/developers/rest-api#get-an-access-token) भेजते हैं। इमेज, बारकोड और कम्युनिटी endpoints को इनमें से किसी की ज़रूरत नहीं होती।
