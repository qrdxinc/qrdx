QRdx publica un registro de shadcn/ui con componentes de código QR creados con la biblioteca `qrdx`. La CLI de shadcn copia el código fuente de cada componente en tu proyecto, así que el código es tuyo y puedes modificarlo. Usa el registro cuando quieras una pieza de interfaz ya terminada, con botones de descarga, una tarjeta, un diálogo para compartir o un lector; usa el `QRCode` de la propia biblioteca cuando solo necesites el código.

<NpmStatus package="qrdx" />

<PackageManagerTabs command="npx shadcn@latest add https://qrdx.dev/r/qr-code.json" />

Cada componente tiene su propia página con vista previa en vivo, el código fuente, los pasos de instalación, ejemplos y una tabla de props. ¿Has diseñado un código en el [Playground](/playground?open=code&lang=shadcn)? Cópialo desde allí para obtener el componente QR Code del registro.

## Qué se instala [#what-gets-installed]

Cada componente es un único archivo en tu carpeta `components`. La CLI también instala `qrdx` (y `lucide-react` para los iconos que usan la mayoría de los componentes) y añade los componentes de shadcn/ui en los que se basa, como `button`, `card`, `dialog`, `dropdown-menu`, `input` o `label`. La página de cada componente enumera sus propias dependencias en **Manual**, dentro de las pestañas de instalación.

El índice completo está en [`https://qrdx.dev/r/registry.json`](https://qrdx.dev/r/registry.json), y cada elemento en `https://qrdx.dev/r/<name>.json`.

## Instalar por nombre [#install-by-name]

Para instalar con un nombre corto, añade el registro a tu `components.json`:

```json title="components.json"
{
  "registries": {
    "@qrdx": "https://qrdx.dev/r/{name}.json"
  }
}
```

Después añade uno o varios componentes por nombre:

<PackageManagerTabs command="npx shadcn@latest add @qrdx/qr-code @qrdx/qr-code-download @qrdx/qr-code-share-dialog" />

## Estilos y temas [#styling-and-theming]

Los componentes usan clases de Tailwind con los tokens de tema estándar de shadcn/ui (`bg-card`, `border`, `text-muted-foreground`, `ring-ring`) y tus propios Button, Card, Dialog e Input, así que siguen tu tema y el modo oscuro. Los códigos QR mantienen por defecto un fondo claro, porque los módulos oscuros sobre un fondo claro se escanean con cualquier lector; la página de [QR Code](/docs/components/qr-code#dark-mode) muestra cómo hacer que siga el tema.

Todos los componentes son Client Components (su archivo empieza con `"use client"`), por sus botones y su estado. Aun así, el código se renderiza en el servidor, por lo que ya está en el HTML de la página antes de que los botones sean interactivos. Una página que sea Server Component puede importar cualquiera de ellos y pasarle datos del servidor como props.

Las descargas en PDF necesitan el paquete opcional `jspdf` (`npm install jspdf`). Todo lo demás funciona en cuanto termina la CLI.
