이 페이지를 끝까지 따라 하면 그림 속에 QR 코드가 들어간 1024px PNG를 받게 됩니다. 이 이미지는 전달되기 전에 QRdx가 디코딩해 확인한 것입니다. 또한 고정 텍스트 대신 동적 QR 코드를 인코딩하는 방법, 어떤 모드를 선택할지, 각 오류가 무엇을 뜻하는지도 알게 됩니다.

`POST https://api.qrdx.dev/v1/art`는 설명을 바탕으로 QR 코드를 AI 아트워크 안에 그려 넣고 이미지를 반환합니다. Playground의 Art 탭과 스튜디오에서 쓰는 [AI QR 아트](/ai/art)와 같은 기능입니다. {facts.artModel}이(가) 그림을 그리고, QRdx는 이미지를 전달하기 전에 그 이미지가 내 콘텐츠로 스캔되는지 확인합니다. 모델이 그린 이미지가 그대로는 스캔되지 않으면, QRdx는 모델의 픽셀 위에서 필요한 만큼만 코드를 강화합니다.

<Callout type="info" title="API 키와 월간 이미지">
이 엔드포인트에는 `codes:write` 스코프가 있는 [API 키](/docs/developers/api-keys)가 필요합니다(**Full access** 키에는 이 스코프가 있습니다). 이미지는 한 장당 키가 속한 워크스페이스의 월간 AI 아트 이미지 1장을 사용하며, 앱에서 쓰는 사용량과 같습니다. 플랜별 수치는 [플랜과 한도](/docs/plans-and-limits)에서 확인하세요. 호출이 실패하거나 이미지가 스캔되도록 만들 수 없는 경우에는 이미지가 차감되지 않습니다.
</Callout>

## 시작하기 전에 [#before-you-start]

- `codes:write` 스코프가 있는 API 키. `QRDX_API_KEY`로 내보내 두세요.
- 타임아웃이 60초 이상인 HTTP 클라이언트. 호출 한 번에 코드 모드는 약 15~45초, 사진 모드는 25~45초, 장면 모드는 먼저 그림을 그리기 때문에 40~55초가 걸립니다.
- 동적 QR 코드를 쓰려면 해당 코드의 `id`가 필요합니다. [`GET /v1/codes`](/docs/developers/api/list-codes)나 [코드를 생성했을 때의](/docs/developers/api/create-codes) 응답에서 확인할 수 있습니다.

## 1. 링크용 코드 그리기 [#1-paint-a-code-for-a-link]

<Tabs groupId="language" persist items={["curl", "JavaScript", "Python"]}>
  <Tab value="curl">
    ```bash title="Terminal"
    curl https://api.qrdx.dev/v1/art \
      -H "Authorization: Bearer $QRDX_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"text": "https://qrdx.dev", "prompt": "a koi pond at dusk, ink and watercolor"}' \
      --max-time 90 -o art.json
    ```
  </Tab>
  <Tab value="JavaScript">
    ```js title="art.mjs"
    import { writeFile } from "node:fs/promises";

    const response = await fetch("https://api.qrdx.dev/v1/art", {
      method: "POST",
      headers: {
        Authorization: `Bearer ${process.env.QRDX_API_KEY}`,
        "Content-Type": "application/json",
      },
      body: JSON.stringify({
        text: "https://qrdx.dev",
        prompt: "a koi pond at dusk, ink and watercolor",
      }),
      signal: AbortSignal.timeout(90_000),
    });
    const { data, credits } = await response.json();
    // data.imageUrl is a data: URL; save the PNG bytes
    const base64 = data.imageUrl.split(",")[1];
    await writeFile("art.png", Buffer.from(base64, "base64"));
    console.log(data.text, data.blend, credits.remaining);
    ```
  </Tab>
  <Tab value="Python">
    ```python title="art.py"
    import base64
    import os
    import requests

    response = requests.post(
        "https://api.qrdx.dev/v1/art",
        headers={"Authorization": f"Bearer {os.environ['QRDX_API_KEY']}"},
        json={"text": "https://qrdx.dev", "prompt": "a koi pond at dusk, ink and watercolor"},
        timeout=90,
    )
    response.raise_for_status()
    body = response.json()
    png = base64.b64decode(body["data"]["imageUrl"].split(",", 1)[1])
    open("art.png", "wb").write(png)
    print(body["data"]["text"], body["data"]["blend"], body["credits"]["remaining"])
    ```
  </Tab>
</Tabs>

응답은 이미지가 `data:` URL로 담긴 JSON입니다.

```json title="200 OK (fields)"
{
  "data": {
    "imageUrl": "data:image/png;base64,iVBORw0KGgo…",
    "width": 1024,
    "height": 1024,
    "seed": 2841337190,
    "mode": "code",
    "blend": "least",
    "blendStrength": 0.35,
    "text": "https://qrdx.dev",
    "visibility": 50,
    "creativity": 45
  },
  "credits": { "plan": "pro", "limit": 30, "used": 7, "remaining": 23, "pooled": false, "resetsAt": "2026-12-01T00:00:00.000Z" }
}
```

- `imageUrl`은 `data:` URL 형태의 1024px 정사각형 PNG입니다. QRdx는 사본을 보관하지 않으니 직접 저장하세요.
- `text`는 이미지를 스캔하면 나오는 내용 그대로입니다. QRdx가 응답하기 전에 디코딩해 확인했습니다.
- `blend`는 이미지가 스캔되도록 만든 방식을 나타냅니다. `none`(모델이 그린 이미지 그대로), `least`(모델의 이미지 위에서 파인더 사각형, 여백, 모듈을 필요한 만큼만 강화), `image-qr`(Image QR 코드로 다시 그림, 최후의 수단) 중 하나입니다. `blendStrength`는 `0`(그린 그대로)에서 `1`(Image QR)까지입니다.
- `credits`는 이 이미지를 만든 뒤 워크스페이스에 남은 사용량입니다.

JSON 대신 PNG 파일 자체를 받으려면 `?format=png`를 추가하거나 `Accept: image/png`를 보내세요. 그러면 시드, 모드, 블렌드, 남은 이미지 수가 `X-QRdx-Seed`, `X-QRdx-Mode`, `X-QRdx-Blend`, `X-QRdx-Blend-Strength`, `X-QRdx-Credits-Remaining` 헤더로 전달됩니다.

```bash title="Terminal"
curl "https://api.qrdx.dev/v1/art?format=png" \
  -H "Authorization: Bearer $QRDX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"text": "https://qrdx.dev", "prompt": "a lighthouse on a cliff, woodcut print"}' \
  --max-time 90 -o art.png
```

## 2. 대신 동적 QR 코드 인코딩하기 [#encode]

`text`와 `code` 중 정확히 하나만 보내세요.

- `text`: 코드에 담을 링크나 텍스트이며 최대 300자입니다. 아트는 그림이므로 인쇄한 뒤에는 내용을 바꿀 수 없습니다.
- `code`: 워크스페이스에 있는 [동적 QR 코드](/docs/dynamic-qr-codes) 중 하나의 `id`입니다. 아트에는 해당 코드의 단축 링크가 인코딩되므로 인쇄한 뒤에도 이동 위치를 바꿀 수 있고, 스캔 기록은 분석에 표시됩니다. 다른 워크스페이스의 코드나 휴지통에 있는 코드는 `404`입니다.

```bash title="Terminal"
curl https://api.qrdx.dev/v1/art \
  -H "Authorization: Bearer $QRDX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"code": "cm5code0spring0menu00001", "prompt": "a bistro chalkboard menu on a brick wall", "mode": "scene"}' \
  --max-time 90 -o art.json
```

이 경우 응답에는 `"code": { "id", "shortLink" }`도 포함되며, `text`는 단축 링크가 됩니다.

## 3. 모드와 스타일 고르기 [#modes]

| `mode` | 결과 |
| --- | --- |
| `code` (기본값) | 코드 자체가 그림 전체입니다. 아트워크가 모듈 안에 그려지고, 파인더 사각형은 단순하게 유지되며 주변에는 밝은 여백이 있습니다. 가장 안정적으로 스캔됩니다 |
| `scene` | 먼저 설명에 따라 그림을 그린 다음 그 가운데에 코드를 그려 넣습니다. 그림이 코드 바로 앞까지, 그리고 코드를 가로질러 이어지며 모듈은 그림의 색과 빛으로 만들어집니다 |
| `photo` | 내가 보낸 `photo`를 그림으로 사용해 같은 방식으로 만듭니다. 코드 주변과 코드 안에서도 사진의 피사체, 색, 빛이 유지됩니다. 사진은 이 모드에서만 보내세요 |

### 퀵 룩 [#quick-looks]

퀵 룩은 매체나 분위기 같은 미리 만들어 둔 스타일로, QRdx가 내 `prompt`에 덧붙입니다. 예를 들어 `"a koi pond in the rain"`에 `"style": "watercolor"`를 지정하면 비 오는 연못의 잉어를 수채화로 그립니다. 스타일의 id를 `style`로 보내세요. 다른 값은 `400 VALIDATION_ERROR`가 됩니다. 이 스타일은 [AI 아트 스튜디오](/ai/art)와 Playground의 Art 탭에서 칩으로 제공되는 것과 같으며, 모든 모드에서 사용할 수 있습니다.

| `style` | 스타일 |
| --- | --- |
| `watercolor` | 수채화 |
| `oil-painting` | 유화 |
| `anime` | 애니메이션 |
| `cartoon` | 카툰 |
| `pixel-art` | 픽셀 아트 |
| `pop-art` | 팝 아트 |
| `charcoal` | 목탄화 |
| `ink` | 잉크 |
| `cyberpunk` | 사이버펑크 |
| `fantasy` | 판타지 |
| `photographic` | 사진 |
| `low-poly` | 로우 폴리 |
| `papercut` | 페이퍼컷 |

`prompt`는 선택 사항입니다. 생략하면 QRdx가 보낸 `mode`, `style`, `photo`에 맞춰 먼저 프롬프트를 작성합니다. 피사체, 배경, 빛이 있는 구체적인 장면 하나를 쓰며, 사진 모드에서는 아트가 사진의 내용을 유지하도록 사진 속 내용을 설명합니다. 프롬프트 작성에는 AI 아트 이미지가 추가로 사용되지 않습니다. 이때 응답에는 작성된 내용이 `writtenPrompt`로 포함되므로, 다음에는 수정해서 다시 보낼 수 있습니다. 작성에 실패하면 `502 AI_ART_DESCRIBE_FAILED`가 반환되고 이미지는 차감되지 않습니다.

## 요청 필드 [#request-fields]

| 필드 | 기본값 | 설명 |
| --- | --- | --- |
| `text` | | 코드에 인코딩할 내용이며 최대 300자입니다. 이 필드나 `code` 중 하나를 보내세요 |
| `code` | | `text` 대신 사용하는 동적 QR 코드의 `id` |
| `prompt` | 자동 작성 | 그릴 아트워크를 평범한 말로 설명한 것이며, 보낼 때는 3자 이상이어야 합니다 |
| `mode` | `code` | `code`, `scene`, `photo` 중 하나이며 위 내용을 참고하세요 |
| `style` | | 퀵 룩의 id이며 프롬프트와 함께 적용됩니다 |
| `negativePrompt` | | 그림에서 제외할 내용 |
| `visibility` | `50` | QR 가시성, `0`~`100`. 높을수록 코드가 더 선명하게 보이고, 낮을수록 그림을 우선합니다 |
| `creativity` | `45` | `0`은 프롬프트를 그대로 따르고, `100`은 자유롭게 해석합니다 |
| `seed` | 무작위 | 비슷한 이미지를 얻으려면 이전 응답의 시드를 보내세요 |
| `reference` | | 색상과 형태의 참고용 이미지(로고나 팔레트 등) |
| `photo` | | 사진 모드 전용. 코드를 그려 넣을 그림 |

`reference`와 `photo`는 PNG 또는 JPEG `data:` URL(`data:image/jpeg;base64,…`)입니다. `reference`는 긴 변이 약 512px이 되도록 줄이고(최대 600KB), `photo`는 아트가 만들어지는 크기인 약 1024px 정사각형으로 잘라 주세요(최대 1MB). 이 이미지들은 모델에 전달된 뒤 폐기되며, QRdx는 저장하거나 로그에 남기지 않습니다. 더 큰 이미지는 `413 AI_ART_IMAGE_TOO_LARGE`로 거부됩니다. 전체 스키마와 Try it 패널은 [레퍼런스 페이지](/docs/developers/api/create-art)에서 볼 수 있습니다.

## 사용량과 한도 [#credits-and-limits]

API는 앱과 같은 월간 AI 아트 이미지를 사용하며, 키가 속한 워크스페이스 기준으로 집계됩니다. 무료, Pro, Business 플랜에는 각각 월간 이미지가 포함되어 있고, Business에서는 팀 전체가 공유합니다. 수치는 [플랜과 한도](/docs/plans-and-limits)에서 확인하세요. 사용량은 매월 1일(UTC)에 초기화됩니다.

- 그 달의 이미지를 모두 사용하면 API는 `AI_ART_CREDITS_EXHAUSTED`로 응답합니다. 업그레이드하면 더 받을 수 있는 무료와 Pro에서는 `402`, Business에서는 `429`입니다.
- 한 사람이 하루에 만들 수 있는 이미지는 월간 사용량과 별개로 최대 25장이며(`429 AI_ART_DAILY_LIMIT`), 분당 최대 12장까지 시작할 수 있습니다.
- 각 호출은 워크스페이스의 일일 API 할당량과 쓰기 요청의 분당 한도에도 포함됩니다([요청 한도](/docs/developers/rest-api#rate-limits)).

## 문제가 발생했을 때 [#if-something-goes-wrong]

오류는 API의 일반적인 형식(`code`, `message`, `status`)으로 반환돼요. 전체 목록은 [오류](/docs/developers/errors)에서 확인할 수 있어요. `5xx` 오류에서는 이미지를 사용하지 않아요.

| 상태 | `code` | 대처 방법 |
| --- | --- | --- |
| 400 | `AI_ART_TEXT_TOO_LONG` | `text`를 줄이거나, 동적 QR 코드의 `code`를 보내세요 |
| 402 | `AI_ART_CREDITS_EXHAUSTED` | 다음 달 1일까지 기다리거나 플랜을 업그레이드하세요 |
| 413 | `AI_ART_IMAGE_TOO_LARGE` | `photo` 또는 `reference`의 크기를 줄이세요 |
| 429 | `AI_ART_CREDITS_EXHAUSTED` | Business: 다음 달 1일까지 기다리세요 |
| 429 | `AI_ART_DAILY_LIMIT` | 내일(UTC) 다시 시도하세요 |
| 502 | `AI_ART_FAILED` | 모델이 실패했거나 프롬프트를 거부했습니다. 다시 시도하거나 프롬프트를 바꿔 보세요 |
| 502 | `AI_ART_UNSCANNABLE` | `visibility`를 더 높게 설정하거나 다른 시드로 다시 시도하세요 |
| 502 | `AI_ART_DESCRIBE_FAILED` | `prompt`를 보내지 않았는데 프롬프트 작성에 실패했습니다. 다시 시도하거나 직접 작성한 프롬프트를 보내세요 |
| 503 | `AI_ART_BUSY` | 모델이 사용 중입니다. 1분 뒤에 다시 시도하세요 |
| 503 | `AI_NOT_CONFIGURED` | 이 서버(셀프 호스팅)에는 AI 아트가 설정되어 있지 않습니다 |
| 504 | `AI_ART_TIMEOUT` | 모델이 너무 오래 걸렸습니다(장면 모드에서는 그림 때문에 코드를 그릴 시간이 부족했습니다). 다시 시도하거나 코드 모드를 사용하세요 |

Vercel AI Gateway가 없는 셀프 호스팅 인스턴스는 모든 호출에 다음과 같이 응답해요.

```json title="503 Service Unavailable"
{"code":"AI_NOT_CONFIGURED","message":"AI QR art is not configured on this server","status":503}
```

## MCP [#mcp]

연결에 QRdx API 키가 있으면 [MCP 서버](/docs/developers/mcp)에서 `generate_ai_art` 도구를 사용할 수 있어요. 이 도구는 요청 본문과 같은 필드를 받고, PNG와 스캔 결과로 연결되는 내용, 이번 달에 남은 이미지 수를 반환해요. 어시스턴트에게 평범한 말로 요청해 보세요.

```txt title="Prompt"
Make AI QR art for my code cm5code0spring0menu00001: a bistro chalkboard menu on a brick wall, as a scene.
```

키가 없으면 도구가 키를 추가하는 방법을 알려 줘요. REST API처럼 호출에 최대 1분이 걸려요.

## 셀프 호스팅 [#self-hosting]

AI 아트는 Vercel AI Gateway를 통해 실행돼요. 직접 운영하는 인스턴스에서는 `AI_GATEWAY_API_KEY`를 설정하세요. 설정하지 않으면 `POST /v1/art`와 `generate_ai_art`가 `503 AI_NOT_CONFIGURED`로 응답해요.
