Setelah membaca halaman ini, asisten AI Anda dapat membuat kode QR: mendesain kode untuk konten apa pun dengan skor pemindaian yang sudah diperiksa, merendernya dalam gaya editor, menyusun payload yang tepat untuk Wi-Fi, kontak, email, SMS, lokasi, dan pembayaran bank, mencari bingkai komunitas, serta menggambar barcode. Dengan kunci API pada koneksi, asisten juga dapat menyimpan desain dan barcode ke workspace Anda serta membuat karya seni AI.

QRdx menjalankan server [Model Context Protocol](https://modelcontextprotocol.io) publik di:

```txt title="Server URL"
https://mcp.qrdx.dev/mcp
```

Server ini menggunakan transport Streamable HTTP, tidak menyimpan status sesi, dan tidak memerlukan akun, proses masuk, maupun kunci API. Server yang sama juga menjawab di `https://qrdx.dev/api/mcp`, dan [halaman koneksi](/mcp) menyediakan tombol sekali klik serta langkah untuk lebih banyak klien daripada yang ditampilkan di halaman ini.

[Coba di playground](/playground?open=code&lang=mcp): atur gaya kode di sana, lalu salin sebagai argumen `design_qr` untuk asisten Anda.

## 2. Minta sebuah kode [#2-ask-for-a-code]

Lalu minta dengan kata-kata biasa. Perintah berikut berfungsi apa adanya:

```txt title="Prompts"
Make a QR code for https://example.com in our brand blue, #155dfc, with rounded modules.
Create a Wi-Fi QR code for the network Office Guest with password correct-horse-battery.
Design a Wi-Fi QR code for Cafe Guest in warm browns with a Free Wi-Fi banner, and tell me its scan score.
Generate a contact QR code for Ada Lovelace, ada@example.com, and add it to the README.
Find a community frame for a restaurant menu and use it for https://example.com/menu.
Draw an EAN-13 barcode for 590123412345 as a PNG.
```

Untuk perintah pertama, asisten memanggil `generate_qr_code` dan menerima PNG beserta baris-baris berikut, siap untuk ditempel:

```txt title="generate_qr_code result"
QR code, 512x512px, error correction Q.
SVG URL: https://api.qrdx.dev/v1/qr?data=https%3A%2F%2Fexample.com&fg=155dfc&body=rounded
PNG URL: https://api.qrdx.dev/v1/qr?data=https%3A%2F%2Fexample.com&format=png&fg=155dfc&body=rounded
WebP URL (lossless, smaller than PNG): https://api.qrdx.dev/v1/qr?data=https%3A%2F%2Fexample.com&format=webp&fg=155dfc&body=rounded
EPS URL (vector, for print; 512 pt wide): https://api.qrdx.dev/v1/qr?data=https%3A%2F%2Fexample.com&format=eps&fg=155dfc&body=rounded
Markdown: ![QR code](https://api.qrdx.dev/v1/qr?data=https%3A%2F%2Fexample.com&fg=155dfc&body=rounded)
```

Untuk perintah kedua, asisten memanggil `qr_payload_wifi`, yang mengembalikan `WIFI:T:WPA;S:Office Guest;P:correct-horse-battery;;`, lalu meneruskan string itu sebagai `data` ke `generate_qr_code` atau sebagai konten `design_qr`.

## Tool [#tools]

| Tool | Fungsi |
| --- | --- |
| `design_qr` | Merancang kode untuk jenis konten apa pun dengan gaya yang dipilih asisten Anda, atau dimulai dari tema bawaan atau item komunitas, memeriksa skor pemindaiannya, lalu memperbaiki gaya sampai skornya Great. Mengembalikan skor, apa yang diubah, JSON gaya, tautan playground, PNG, dan SVG |
| `list_options` | Menampilkan setiap nilai yang diterima `design_qr`: jenis konten beserta kolomnya, warna dan gradien, bentuk, bingkai (dengan id bingkai resmi QRdx), border, ikon logo dan logo merek, tema bawaan, tingkat koreksi kesalahan, dan batasannya |
| `generate_qr_code` | Merender kode QR dengan gaya dari editor. Mengembalikan gambar PNG dan URL [image API](/docs/developers/image-api) publik (SVG, PNG, WebP lossless, dan EPS vektor) yang siap dipakai untuk Markdown, HTML, atau cetak, serta markup SVG jika diminta |
| `list_qr_styles` | Menampilkan pola badan, bentuk mata sudut dan titik mata, bingkai (gaya bawaan dan yang digambar sebagai templat), ikon logo, tingkat koreksi kesalahan, nilai default, dan batasan |
| `search_community` | Mencari bingkai, tema, dan koleksi [komunitas](/community) yang sudah dipublikasikan berdasarkan kata, jenis, atau tag |
| `get_community_item` | Satu item komunitas beserta gaya yang diterapkannya, siap dipakai untuk `design_qr` atau `generate_qr_code` |
| `save_template` | Menyimpan desain sebagai tema di workspace Anda. Memerlukan [kunci API](#use-an-api-key) |
| `generate_barcode` | Menggambar barcode EAN-13, UPC-A, UPC-E, EAN-8, ITF-14, GS1-128, Code 128, Code 39, Data Matrix, PDF417, atau Aztec setelah memeriksa nilainya (digit pemeriksa, panjang, karakter). Mengembalikan PNG dan URL [barcode API](/docs/developers/barcode-api) publik |
| `save_barcode` | Menyimpan barcode ke Barcode di workspace Anda. Memerlukan [kunci API](#use-an-api-key) |
| `generate_ai_art` | Melukis kode QR ke dalam karya seni AI dan memeriksa apakah kode tersebut bisa dipindai. Memakai salah satu gambar seni AI bulanan workspace dan memerlukan waktu hingga satu menit. Memerlukan [kunci API](#use-an-api-key). Lihat [AI art API](/docs/developers/ai-art-api) |
| `qr_payload_wifi` | Membuat payload jaringan `WIFI:` (WPA, WEP, atau terbuka, bisa disembunyikan) dengan karakter khusus yang di-escape |
| `qr_payload_vcard` | Membuat kontak vCard 3.0 (RFC 2426): nama, organisasi, jabatan, telepon, email, situs web, alamat, dan catatan |
| `qr_payload_email` | Membuat tautan `mailto:` (RFC 6068) dengan cc, bcc, subjek, dan isi pesan opsional |
| `qr_payload_sms` | Membuat tautan `sms:` (RFC 5724) dengan pesan opsional, atau bentuk lama `SMSTO:` |
| `qr_payload_geo` | Membuat lokasi `geo:` (RFC 5870) dari lintang dan bujur |
| `qr_payload_payment` | Membuat kode pembayaran bank: Pix BR Code, transfer kredit SEPA (EPC069-12), atau kode PayNow, PromptPay, atau VietQR (EMV, beserta CRC-nya). Kolomnya diperiksa seperti pada formulir di playground |

Tool payload mengembalikan string biasa. Asisten Anda kemudian meneruskannya sebagai `data` ke `generate_qr_code`.

### design_qr [#design_qr]

`design_qr` menerima konten berupa jenis dan kolomnya, dengan jenis dan pemeriksaan yang sama seperti formulir konten di editor (`list_options` menampilkannya), serta gaya opsional:

```json title="design_qr arguments"
{
  "content": { "type": "wifi", "ssid": "Cafe Guest", "password": "sunshine123", "encryption": "WPA" },
  "style": {
    "bgColor": "#FFF7ED",
    "fgColor": "#9A3412",
    "bodyPattern": "rounded",
    "cornerEyePattern": "rounded",
    "frame": { "style": "banner-bottom", "text": "Free Wi-Fi" }
  }
}
```

```txt title="design_qr result (first lines)"
Scan score 85/100 (great). No changes were needed. Content: WiFi · Cafe Guest (47 bytes). Open it in the playground: https://qrdx.dev/playground?style=1.eyJiIjoiI0ZGRjdFRCIs…&ref=mcp
```

JSON hasilnya berisi `payload` (string persis yang dikodekan kode QR), `style`, `qrdxStyle`, `score`, `grade`, `stillFailing` (pemeriksaan yang masih gagal, masing-masing dengan saran perbaikan), `repairs`, `changes`, dan `playgroundUrl`, diikuti PNG dan SVG.

Opsi yang Anda lewatkan akan memakai nilai default (mata mengikuti warna titik, bentuk persegi, margin 4, koreksi kesalahan Q, tanpa bingkai). QRdx lalu menjalankan pemeriksaan pemindaian editor pada desain tersebut: kode dirender, didekode pada 96, 160, dan 320 px melalui model kamera ponsel, lalu kontras, zona tenang, bentuk mata, dan pasangan bentuk diperiksa. Jika di bawah Great (85), gaya diperbaiki hingga tiga kali dengan perubahan sesedikit mungkin (warna lebih gelap yang mempertahankan rona, bentuk mata yang lebih aman, koreksi kesalahan lebih rendah untuk konten panjang). Jika itu belum cukup, hasilnya kembali ke kode klasik hitam di atas putih dengan bingkai Anda. Hasilnya menjelaskan apa yang diubah dan alasannya.

Tidak ada model AI yang berjalan di sisi QRdx untuk `design_qr`: asisten Anda memilih gaya, lalu QRdx memvalidasi, memeriksa, dan memperbaikinya. Konten yang tidak valid (kata sandi WPA kurang dari 8 karakter, alamat email yang salah format) ditolak disertai alasannya. `design_qr` memiliki batas sendiri sebesar {facts.designQrPerMinute} panggilan per menit per alamat IP.

Masukan lainnya:

- **`preset`**: mulai dari tema bawaan berdasarkan id (`list_options` menampilkannya). Opsi gaya yang Anda atur lebih diutamakan daripada tema ini.
- **`community_item`**: mulai dari bingkai atau tema komunitas berdasarkan id, misalnya `frame:wifi-card`. Item bingkai berada di atas kode klasik; opsi gaya Anda mengubah kode di bawahnya. Bingkai resmi QRdx juga merupakan item komunitas, sehingga `frame:diwali-diya` atau `frame:menu-cutlery` bisa dipakai di sini.
- **Bingkai kustom**: `style.frame` bisa berupa `{ "style": "custom", "spec": … }` dengan spesifikasi bingkai, seperti milik bingkai komunitas dari `get_community_item`. Bingkai digambar dan dinilai apa adanya; perbaikan mengubah kode, tidak pernah bingkainya.
- **`style.logo`**: ikon logo cepat (`wifi`, `location`, `phone`, `email`, `link`, `file`, `calendar`, `whatsapp`, atau `instagram`), atau logo merek berdasarkan slug [Simple Icons](https://simpleicons.org) (`spotify`, `paypal:white`). `list_options` menampilkan slug merek yang populer.
- **Opsi engine**: `style.eyeColors` (warna `#RRGGBB` per mata), `moduleScale` (ukuran titik, `0.5` hingga `1`), `shape` (`circle` untuk kode bulat), `autoLevel`, dan `logoOptions` (ukuran logo, ruang kosong, posisi, pemangkasan, dan alas). Semuanya digambar dan dinilai sesuai pengaturan; perbaikan tidak mengubahnya.

<IfAvailable feature="fileStorage">
`logo_file_id` menggambar logo yang Anda unggah ke QRdx, dengan [kunci API](#use-an-api-key).
</IfAvailable>

Logo dinilai berdasarkan modul yang ditutupinya, seperti di editor, sehingga perbaikan bisa menaikkan koreksi kesalahan ke H atau menghapus logo. Tanda QRdx yang ditampilkan editor secara default tidak digambar di sini.

`qrdxStyle` pada hasil adalah desain dalam bentuk JSON gaya editor. Teruskan ke `save_template`, ke `generate_qr_code` sebagai `style` untuk merender desain yang sama pada ukuran lain, atau ke [`style`](/docs/developers/image-api#style) pada Image API. `playground_url` membuka desain di [playground](/playground): hanya membawa gaya, tidak pernah logo atau kontennya, dan `playgroundLeftOut` menjelaskan apa yang tidak disertakan.

### generate_qr_code [#generate_qr_code]

Masukannya sama dengan [parameter image API](/docs/developers/image-api#parameters): `data` (wajib), `size`, `fg`, `bg`, `eyeColor`, `dotColor`, `body`, `eye`, `dot`, `level`, `margin`, `template`, `frame`, `frameText`, `logoIcon`, `logoFileId`, `item` (id item komunitas), dan `style` (JSON gaya editor: gradien, bingkai kustom, dan lainnya, seperti yang dikembalikan `design_qr`). Opsi datar lebih diutamakan daripada `style`, dan `style` lebih diutamakan daripada `item`. Atur `include_svg` ke `true` untuk mendapatkan juga markup SVG sebagai teks, misalnya untuk menyimpan file `.svg`. Opsi ini nonaktif secara default karena markup sering berukuran 50 hingga 150 KB, yang akan memenuhi percakapan.

`generate_qr_code` tidak memeriksa skor pemindaian; gunakan `design_qr` untuk itu. Kode dengan logo yang Anda unggah tidak memiliki URL gambar publik, karena image API hanya menggambar logo tersebut untuk permintaan dengan kunci Anda.

### Kartu QR [#qr-card]

Di aplikasi yang mendukung [MCP Apps](https://modelcontextprotocol.io/extensions/apps/overview), `design_qr` dan `generate_qr_code` juga menampilkan kartu QR di obrolan. Kartu ini berisi kode, apa yang dikodekannya (kode Wi-Fi menampilkan nama jaringan, tidak pernah kata sandinya), ukuran, serta koreksi kesalahan atau skor pemindaian, dan tombol **Open in editor**. Tautan editor hanya membawa gaya, seperti `playground_url`.

Tombol PNG dan SVG bergantung pada apa yang diizinkan aplikasi. Jika aplikasi bisa menyimpan file dari kartu, tombol tersebut menyimpannya. Jika tidak, tombol membuka URL image API di browser Anda, sehingga kartu `design_qr` hanya menampilkannya di aplikasi yang bisa menyimpan file: kontennya tidak pernah masuk ke URL gambar. Aplikasi mungkin meminta konfirmasi Anda sebelum tautan dibuka.

Aplikasi tanpa MCP Apps mendapat teks dan gambar yang sama seperti sebelumnya. Untuk pengembang klien:

- Kartu ini adalah resource `ui://qrdx/qr-card` (`text/html;profile=mcp-app`), yang tercantum di `resources/list`. Kedua tool mengarah ke resource ini dengan `_meta.ui.resourceUri`.
- Datanya datang di `_meta` pada hasil tool, di bawah `dev.qrdx/qr-card`, yang ditujukan untuk kartu dan bukan untuk model. Tool tidak mengembalikan `structuredContent`.
- Kartu adalah satu file HTML dengan gaya dan skrip inline. Satu-satunya yang dimuatnya adalah gambar kode dari image API (`https://api.qrdx.dev`, atau domain Anda sendiri jika di-hosting sendiri), dan content security policy-nya (`_meta.ui.csp.resourceDomains`) hanya mengizinkan host tersebut.

Jika Anda menghubungkan QRdx sebelum kartu ini ada, hapus konektornya lalu tambahkan lagi, atau muat ulang tool-nya, agar aplikasi mengambil metadata tool yang baru.

### Komunitas [#community]

`search_community` mencari bingkai, tema, dan koleksi [komunitas](/community) yang sudah dipublikasikan, gratis di bawah CC0, berdasarkan kata (`q`), `type`, dan `tag`. `get_community_item` mengembalikan satu item beserta gaya yang diterapkannya; teruskan id-nya ke `design_qr` sebagai `community_item` atau ke `generate_qr_code` sebagai `item`. Data yang sama tersedia di REST API pada [`/v1/community/items`](/docs/developers/api/list-community-items).

Teks item ditulis oleh anggota komunitas. Nama, deskripsi, handle, tag, dan label bingkai dikembalikan dalam bentuk singkat, satu baris, dan tanpa tautan, email, atau markup, dan setiap hasil menyatakan agar diperlakukan sebagai data, bukan instruksi.

## Gunakan kunci API [#use-an-api-key]

Beberapa alat memerlukan [kunci API](/docs/developers/api-keys) QRdx pada koneksi, yang dikirim sebagai `Authorization: Bearer qrdx_…`:

- **`save_template`** menyimpan desain sebagai tema, yang tercantum di Tema pada dasbor dan ditawarkan di editor. Alat ini memerlukan kunci dengan `codes:write`, yang dimiliki kunci **Akses penuh**. Kunci dari workspace Anda sendiri menyimpan ke tema Anda; kunci tim menyimpan ke tema bersama tim jika pembuatnya adalah owner atau admin dan paket tersebut mendukung tema tim. Penyimpanan dihitung terhadap batas tema tersimpan pada paket (lihat [Paket dan batas](/docs/plans-and-limits)); jika melebihinya, alat ini mengembalikan galat `LIMIT_REACHED` (`402`) dari API.
- **`save_barcode`** menyimpan barcode (format, nilai, judul opsional, dan opsi gambar) ke workspace milik kunci, yang tercantum di Barcode pada dasbor. Alat ini memerlukan kunci dengan `codes:write`. Semua paket dapat menyimpan barcode, hingga 1.000 pada paket Gratis; jika melebihi batas, alat ini mengembalikan `LIMIT_REACHED` (`402`).
- **`generate_ai_art`** melukis kode QR menjadi karya seni AI, dari tautan atau teks atau kode dinamis berdasarkan id-nya, dan mengembalikan PNG setelah QRdx memeriksa bahwa kode dapat dipindai. Alat ini menerima kolom yang sama dengan [`POST /v1/art`](/docs/developers/ai-art-api) dan memerlukan kunci dengan `codes:write`. Setiap gambar memakai satu dari gambar seni AI bulanan milik workspace kunci, dan satu panggilan dapat memakan waktu hingga satu menit.
<IfAvailable feature="fileStorage">
- **Logo yang Anda unggah** di [Dasbor → File](/docs/files), berdasarkan id file (`logo_file_id` di `design_qr`, `logoFileId` di `generate_qr_code`): PNG atau JPEG hingga 1 MB. Kunci harus milik workspace yang memiliki file tersebut.
</IfAvailable>

Tanpa kunci, alat-alat ini menjawab dengan cara menambahkannya:

```txt title="save_template without a key"

```

## Jika terjadi masalah [#if-something-goes-wrong]

### Klien tidak dapat terhubung [#the-client-cant-connect]

Pastikan URL-nya persis `https://mcp.qrdx.dev/mcp` dan transportnya HTTP (Streamable HTTP), bukan SSE atau stdio. Klien yang hanya menjalankan server lokal memerlukan jembatan `mcp-remote` di atas. Membuka URL tersebut di browser akan dialihkan ke halaman koneksi, dan itu wajar: klien MCP tidak pernah meminta HTML.

### Asisten mengatakan suatu alat memerlukan kunci API [#the-assistant-says-a-tool-needs-an-api-key]

`save_template`, `save_barcode`, `generate_ai_art`, dan logo yang diunggah memerlukan `Authorization: Bearer qrdx_…` pada koneksi. Tambahkan header seperti yang ditunjukkan di atas lalu hubungkan kembali.

### `design_qr` menolak konten [#design_qr-refuses-the-content]

Konten tidak lolos pemeriksaan yang sama dengan formulir di editor: kata sandi WPA kurang dari 8 karakter, alamat email yang salah format, atau kolom pembayaran di luar rentang. Alasannya ada di jawaban; `list_options` mencantumkan kolom dan aturan setiap jenis konten.

### Terlalu banyak permintaan [#too-many-requests]

Server mengizinkan {facts.mcpPerMinute} permintaan per menit per alamat IP, dan `design_qr` {facts.designQrPerMinute}. Dengan kunci, `save_template` juga dibatasi 30 per menit per pengguna. Tunggu semenit lalu coba lagi.

## Privasi dan batas [#privacy-and-limits]

- Alat-alat ini merender gambar, memeriksa desain, memformat teks, dan membaca komunitas publik. Hanya `save_template` dan `save_barcode` yang menulis sesuatu: tema atau barcode yang Anda minta untuk disimpan, di workspace milik kunci API. `generate_ai_art` memakai satu dari gambar seni AI bulanan workspace, dan tidak menyimpan gambar maupun foto yang Anda kirim. Server tidak menyimpan kode yang Anda buat.
- URL gambar yang dikembalikan `generate_qr_code` dan `generate_barcode` berisi data yang dienkode. Jangan bagikan jika datanya bersifat pribadi, seperti kata sandi Wi-Fi.
- Permintaan dibatasi {facts.mcpPerMinute} per menit per alamat IP, dan `design_qr` {facts.designQrPerMinute}.

## Self-hosting dan pengembangan lokal [#self-hosting-and-local-development]

Server MCP adalah bagian dari aplikasi web QRdx, sehingga setiap instans menyajikannya di `/api/mcp`:

- **Self-hosted.** Jika `NEXT_PUBLIC_APP_URL` adalah domain Anda sendiri, halaman koneksi, cuplikan, dan tautan instalasi memakai `https://<your-domain>/api/mcp`.
- **Pengembangan lokal.** `bun run dev` menyajikannya di `http://localhost:3000/api/mcp`. Halaman koneksi tetap menampilkan URL publik dan menawarkan URL lokal sebagai petunjuk, sehingga Anda dapat mengarahkan klien ke mesin Anda untuk menguji perubahan pada server sebelum dirilis.
