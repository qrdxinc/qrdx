Al terminar esta página, todos los códigos QR que tus páginas, correos o hojas de cálculo cargaban desde `chart.googleapis.com` se cargarán desde la [Image API](/docs/developers/image-api) de QRdx, con el mismo tamaño y nivel de corrección de errores, sin cuenta ni clave.

Google dejó obsoletos sus Image Charts en abril de 2012, incluidos los códigos QR de `chart.googleapis.com/chart?cht=qr`. Hoy el endpoint responde `404` (comprobado el 15 de noviembre de 2026), así que todas las etiquetas `<img>` antiguas muestran una imagen rota. La Image API de QRdx funciona igual: una URL `GET` que devuelve la imagen, así que el cambio consiste en un nuevo host y tres parámetros con otro nombre.

## Antes de empezar [#before-you-start]

- Busca los archivos que aún usan la API antigua. El comando siguiente los lista, incluido el host anterior `chart.apis.google.com`:

```bash title="Terminal"
grep -rlE "chart\.(googleapis|apis\.google)\.com/chart" .
```

- Trabaja en un repositorio git u otro lugar donde puedas revisar el cambio antes de publicarlo.

## 1. Compara una URL [#1-compare-one-url]

Las dos URL siguientes dibujan lo mismo: un PNG de 300 × 300 de `https://example.com` con corrección de errores `M` y un margen de 2 módulos.

```txt title="Before and after"
https://chart.googleapis.com/chart?cht=qr&chs=300x300&chl=https%3A%2F%2Fexample.com&chld=M|2
https://api.qrdx.dev/v1/qr?format=png&size=300&data=https%3A%2F%2Fexample.com&level=M&margin=2
```

```bash title="Terminal"
curl -o after.png "https://api.qrdx.dev/v1/qr?format=png&size=300&data=https%3A%2F%2Fexample.com&level=M&margin=2"
file after.png
# after.png: PNG image data, 300 x 300, 8-bit/color RGBA, non-interlaced
```

## 2. Equivalencia de parámetros [#2-map-the-parameters]

| Google Chart | QRdx | Notas |
| --- | --- | --- |
| `cht=qr` | no hace falta | El endpoint solo dibuja códigos QR. Si lo dejas, se ignora |
| `chl=<data>` | `data=<data>` | Se codifica como URL igual que antes, hasta 2.048 caracteres |
| `chs=<width>x<height>` | `size=<width>` | Un solo número, porque los códigos QR son cuadrados: de `64` a `2048` píxeles |
| `chld=<level>\|<margin>` | `level=<level>&margin=<margin>` | Las mismas letras: `L`, `M`, `Q` y `H`. El margen se da en módulos, de `0` a `16` |
| `choe=UTF-8` | no hace falta | QRdx siempre codifica el texto como UTF-8, que era el valor por defecto de Google. No hay opción de Shift_JIS ni de ISO-8859-1. Si lo dejas, se ignora |
| siempre PNG | `format=png` | QRdx devuelve SVG a menos que pidas `png`, `webp` o `eps`. Usa PNG para correo, porque muchos clientes de correo no muestran SVG |

Hay dos valores por defecto distintos. Sin `chld`, Google usaba corrección de errores `L`; QRdx usa `Q`, que resiste más daño pero genera un código más denso. Añade `level=L` si quieres el aspecto antiguo. Ambos usan un margen de 4 módulos por defecto.

## 3. Reescribe las URL en tus archivos [#3-rewrite-the-urls-in-your-files]

Esto reescribe todas las URL de códigos QR de Google Chart en los archivos que indiques, con ambos hosts: cambia el host y la ruta, renombra `chl`, `chs` y `chld`, y añade `format=png` para que las imágenes sigan siendo PNG. Perl viene incluido en macOS y en la mayoría de las distribuciones de Linux.

```bash title="Terminal"
perl -pi -e 's{https?://chart\.(?:googleapis|apis\.google)\.com/chart\?([^\s"\x27<>)]*)}{my $q = $1; $q =~ s/(^|[&;])chl=/${1}data=/; $q =~ s/(^|[&;])chs=(\d+)x\d+/${1}size=$2/; $q =~ s/(^|[&;])chld=([LMQH])(?:\||%7C)(\d+)/${1}level=$2&margin=$3/i; $q =~ s/(^|[&;])chld=([LMQH])/${1}level=$2/i; "https://api.qrdx.dev/v1/qr?format=png&$q"}ge' index.html
```

Ejecutado sobre un archivo con tres etiquetas antiguas, produce:

```html title="index.html (after)"
<img src="https://api.qrdx.dev/v1/qr?format=png&cht=qr&size=300&data=https%3A%2F%2Fexample.com&level=M&margin=2" alt="QR">
<img src="https://api.qrdx.dev/v1/qr?format=png&cht=qr&size=150&data=https%3A%2F%2Fexample.com%2Fmenu" alt="QR 2">
<img src="https://api.qrdx.dev/v1/qr?format=png&size=200&cht=qr&data=hello&level=H&choe=UTF-8" alt="QR 3">
```

QRdx ignora los `cht=qr` y `choe=UTF-8` que quedan; quítalos a mano si quieres URL más limpias. Revisa el diff y vuelve a ejecutar el `grep` del principio: no debería listar nada.

## 4. Cambia el código que construye las URL [#4-change-the-code-that-builds-urls]

```js title="qr.js"
// Before
const src = `https://chart.googleapis.com/chart?cht=qr&chs=200x200&chl=${encodeURIComponent(link)}`;

// After
const src = `https://api.qrdx.dev/v1/qr?format=png&size=200&data=${encodeURIComponent(link)}`;
```

En Google Sheets:

```txt title="Sheets formula"
=IMAGE("https://api.qrdx.dev/v1/qr?format=png&size=150&data="&ENCODEURL(A2))
```

Sheets carga las imágenes a través de los servidores de Google, así que una hoja con cientos de códigos puede toparse con el límite por IP que se indica más abajo. Para una lista larga, crea los archivos una sola vez con el [generador masivo](/tools/bulk) o con `qrdx batch` de la [CLI](/docs/developers/cli).

## Si algo sale mal [#if-something-goes-wrong]

### `400` con `"param": "size"` [#400-with-param-size]

Se rechaza un `chs` menor de 64 píxeles (como `50x50`) o mayor de 2048. Cambia esos tamaños a mano; `64` es lo mínimo que dibuja la Image API.

```json title="400 Bad Request"
{"code":"VALIDATION_ERROR","message":"Invalid query parameters","data":{"details":[{"param":"size","message":"Too small: expected number to be >=64"}]},"status":400}
```

### La imagen es más densa que antes [#the-image-is-denser-than-before]

La corrección de errores por defecto de Google era `L`; la de QRdx es `Q`. Añade `level=L` para igualar el aspecto antiguo.

### `429` tras una recarga masiva [#429-after-a-bulk-reload]

La Image API permite {facts.imageApiPerMinute} solicitudes por minuto por dirección IP. Espera los segundos indicados en el encabezado `Retry-After`, o genera los archivos una sola vez en lugar de cargarlos en directo.

## Qué más conviene saber [#what-else-to-know]

- **Caché:** la misma URL siempre devuelve los mismos bytes, así que las respuestas se almacenan en caché durante un año (`Cache-Control: public, max-age=31536000, immutable`).
- **Más opciones:** colores (`fg`, `bg`), formas de módulos y de ojos, un icono de logotipo (`logoIcon`) y marcos. Pruébalas en el [constructor de URL](/qr-code-api), o consulta los [parámetros](/docs/developers/image-api#parameters).
- **Autoalojamiento:** una instancia de QRdx [autoalojada](/docs/self-hosting) ofrece la misma API en `/api/v1/qr` en tu propio dominio.
