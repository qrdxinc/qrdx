A path alias keeps codes printed with another provider's links working after your domain moves to QRdx: `go.example.com/r/abc` opens the code as its own short link does, with its scans, password, schedule, scan limit and pause. Aliases belong to the code's current domain, so a code on QRdx's own domain has none (`NO_CUSTOM_DOMAIN`). More in [Path aliases](https://qrdx.dev/docs/migrate#path-aliases).

**Scope:** `codes:read` or `codes:write`, for API keys and OAuth tokens alike.
