**No key or token needed**, and it doesn't use your daily quota: put the URL straight into an `<img>` tag. The same query always returns the same bytes, so responses are cached for a year. Limit: 300 requests a minute per IP address, like `GET /qr`.

**Formats.** EAN-13, EAN-8, UPC-A, UPC-E, ITF-14, GS1-128 and GS1 DataBar Expanded (GTIN and SSCC fields) and GS1 DataBar (its GTIN) take the number with or without its check digit: one digit short and it's added, the full length and it's checked. A wrong check digit, a wrong length or a character the format can't hold is a `400` that says what's wrong. ISBN, ISSN and ISMN are EAN-13s with the number printed above the bars: an ISBN-13 or a whole ISBN-10 (converted to 978), an ISSN (`0317-8471`) or its 13-digit 977 number, an ISMN (979-0) or its old M form, each with or without its check digit; a 2- or 5-digit add-on follows after a space (`978-1-873671-00-9 52250`), and an ISSN's 2-digit sequence variant comes before it (`0317-8471 00 05`, 00 when left out). Code 128 takes printable ASCII, Code 39 and Code 93 capitals, digits and `- . $ / + %` (Code 93's two check characters are added for you), Codabar a start and stop letter (A to D) around digits and `- $ : / . +`, Data Matrix, PDF417 and Aztec any text up to 1,000 characters, and DotCode any text up to about 390 letters or 780 digits. USPS Intelligent Mail takes the 20-digit tracking code (barcode ID, service type ID, mailer ID and serial number) and a routing ZIP Code of 0, 5, 9 or 11 digits, with or without spaces and hyphens (`01 234 567094 987654321 01234-5678-91`).

**Sizes.** Raster images are `scale` pixels per module (a linear bar or a 2D cell's half). SVG, PDF and EPS are vectors at one point per module (0.353 mm, about 107% of an EAN-13's nominal size), with bars `height` millimetres tall. USPS Intelligent Mail is drawn at the size USPS-B-3200 sets: bars 0.02 in wide, about 22 to the inch and 3.96 mm tall whatever `height` says, with `scale` from 2, as for DotCode.

**BMP** is an uncompressed 24-bit bitmap, for legacy systems and embedded tools that only take BMP. It has no alpha channel; the background is always a solid color, so it has the same pixels as the PNG.
