QRdx のあらゆる機能はコードから利用できます。作りたいものから探してください。各行に、ツール、必要なもの、そこへ進むためのページを示しています。

| やりたいこと | 使うもの | 必要なもの |
| --- | --- | --- |
| ページ、メール、README に QRコードを入れる | [QR code image API](/docs/developers/image-api): そのまま画像になる `GET` URL | なし |
| ラベルや商品フィード用のバーコードを描画する | [Barcode API](/docs/developers/barcode-api): 同じ方式で、EAN、UPC、Code 128 などに対応 | なし |
| 印刷後でも転送先を変えられるコードを作成し、スキャンを取得する | [REST API](/docs/developers/quickstart): `POST /v1/codes`、`PATCH`、`GET …/scans` | [APIキー](/docs/developers/api-keys) |
| スキャン、新しいコード、フォームの回答に自分のシステムで反応する | [Webhook](/docs/webhooks): お客様の URL に送られる署名付き `POST` リクエスト | APIキーまたはダッシュボード、Business プラン |
| AI アシスタントにチャットで QRコードを作らせる | [MCP server](/docs/developers/mcp): `https://mcp.qrdx.dev/mcp` | なし |
| スクリプト、ビルド、CSV から QRコードを作る | [CLI](/docs/developers/cli): `npx @qrdx/cli` | Node.js 22 |
| AI アートに QRコードを描き込む | [AI art API](/docs/developers/ai-art-api): `POST /v1/art` | APIキー、月ごとの AI アート画像枠 |
| 他のユーザーが自分の QRdx アカウントをお客様の製品に接続できるようにする | [連携を構築する](/docs/developers/build-an-integration): PKCE 付き OAuth 2.0 | OAuth アプリ |
| n8n で QRdx を自動化する | [n8n ノード](/docs/developers/n8n): `@qrdx/n8n-nodes-qrdx` | セルフホストの n8n |
| React アプリ内でスタイル付きコードを描画する | [React ライブラリ](/docs/getting-started): `qrdx` パッケージ | npm |

## 2分で最初のリクエスト [#first-request-in-two-minutes]

[クイックスタート](/docs/developers/quickstart)では、キー不要のリクエスト 1 回で QRコード画像を作成し、APIキーを作成し、動的QRコードを作成して、別の転送先に切り替えます。このページの他の内容は、この 4 つのステップを土台にしています。

```bash title="Terminal"
curl "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=png" -o qr.png
```

## ベース URL と認証 [#base-url-and-authentication]

REST API は `https://api.qrdx.dev/v1` にあります。同じルートは `https://qrdx.dev/api/v1` でも応答し、[セルフホスト](/docs/self-hosting)したインスタンスでは、そのドメインの `/api/v1` で提供されます。

リクエストには [APIキー](/docs/developers/api-keys)を `Authorization: Bearer qrdx_…` として付けます。キーは、作成したワークスペースで、そこでのお客様のロールとして動作します。他の QRdx ユーザーに代わって動作するアプリは、代わりに [OAuth 2.0 アクセストークン](/docs/developers/rest-api#get-an-access-token)を同じヘッダーで送ります。画像、バーコード、コミュニティのエンドポイントはどちらも不要です。
