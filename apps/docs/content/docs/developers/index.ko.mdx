QRdx의 모든 기능은 코드로 사용할 수 있습니다. 만들려는 것에서 시작하세요. 각 행에 도구, 필요한 것, 해당 내용을 안내하는 페이지가 나와 있습니다.

| 하고 싶은 일 | 사용할 도구 | 필요한 것 |
| --- | --- | --- |
| 페이지, 이메일, README에 QR 코드 넣기 | [QR 코드 이미지 API](/docs/developers/image-api): 이미지 자체인 `GET` URL | 없음 |
| 라벨이나 상품 피드용 바코드 그리기 | [바코드 API](/docs/developers/barcode-api): 같은 방식으로 EAN, UPC, Code 128 등 지원 | 없음 |
| 인쇄한 뒤에도 다른 곳으로 연결을 바꿀 수 있는 코드를 만들고 스캔 내역 확인하기 | [REST API](/docs/developers/quickstart): `POST /v1/codes`, `PATCH`, `GET …/scans` | [API 키](/docs/developers/api-keys) |
| 스캔, 새 코드, 폼 응답에 자체 시스템이 반응하도록 하기 | [웹훅](/docs/webhooks): 지정한 URL로 보내는 서명된 `POST` 요청 | API 키 또는 대시보드, Business 플랜 |
| AI 어시스턴트가 채팅에서 QR 코드를 만들게 하기 | [MCP 서버](/docs/developers/mcp): `https://mcp.qrdx.dev/mcp` | 없음 |
| 스크립트, 빌드, CSV로 QR 코드 만들기 | [CLI](/docs/developers/cli): `npx @qrdx/cli` | Node.js 22 |
| AI 아트에 QR 코드 그려 넣기 | [AI 아트 API](/docs/developers/ai-art-api): `POST /v1/art` | API 키, 월별 AI 아트 이미지 |
| 다른 사용자가 자신의 QRdx 계정을 내 제품에 연결하게 하기 | [연동 만들기](/docs/developers/build-an-integration): PKCE를 사용하는 OAuth 2.0 | OAuth 앱 |
| n8n에서 QRdx 자동화하기 | [n8n 노드](/docs/developers/n8n): `@qrdx/n8n-nodes-qrdx` | 셀프 호스팅 n8n |
| React 앱 안에서 스타일이 적용된 코드 렌더링하기 | [React 라이브러리](/docs/getting-started): `qrdx` 패키지 | npm |

## 2분 만에 첫 요청 보내기 [#first-request-in-two-minutes]

[빠른 시작](/docs/developers/quickstart)에서는 키 없이 요청 한 번으로 QR 코드 이미지를 만들고, API 키를 만든 다음, 동적 QR 코드를 만들어 다른 곳으로 연결을 바꿉니다. 이 페이지의 나머지 내용은 이 네 단계를 바탕으로 합니다.

```bash title="Terminal"
curl "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=png" -o qr.png
```

## 기본 URL과 인증 [#base-url-and-authentication]

REST API는 `https://api.qrdx.dev/v1`에 있습니다. 같은 경로를 `https://qrdx.dev/api/v1`에서도 사용할 수 있으며, [셀프 호스팅](/docs/self-hosting) 인스턴스는 자체 도메인의 `/api/v1`에서 제공합니다.

요청에는 [API 키](/docs/developers/api-keys)를 `Authorization: Bearer qrdx_…` 형식으로 포함합니다. 키는 생성된 워크스페이스에서 해당 워크스페이스의 내 역할로 동작합니다. 다른 QRdx 사용자를 대신해 동작하는 앱은 같은 헤더에 [OAuth 2.0 액세스 토큰](/docs/developers/rest-api#get-an-access-token)을 보냅니다. 이미지, 바코드, 커뮤니티 엔드포인트는 둘 다 필요하지 않습니다.
