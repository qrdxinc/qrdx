Al terminar esta página sabrás cuál de las tres formas de darle códigos QR a un agente se ajusta a tu caso, la tendrás configurada y sabrás qué puede y qué no puede hacer cada una.

| El agente necesita | Usa | Clave o cuenta |
| --- | --- | --- |
| Crear un código QR en un chat o en una ejecución de agente | [Servidor MCP](#1-connect-the-mcp-server) | Ninguna |
| Poner un código QR en Markdown, HTML, un correo o una compilación | [Image API](#2-give-agents-qr-image-urls) | Ninguna |
| Crear o modificar códigos dinámicos, leer escaneos | [REST API](#3-call-the-rest-api-for-a-user) | Clave de API o token de acceso OAuth |
| Pintar un código QR dentro de una ilustración de IA | [API de arte con IA](/docs/developers/ai-art-api): `POST /v1/art` o la herramienta MCP `generate_ai_art` | Clave de API; usa las imágenes de arte con IA mensuales del espacio de trabajo |
| Leer la documentación de QRdx | [Markdown y llms.txt](#4-read-qrdx-as-markdown) | Ninguna |

## 1. Connect the MCP server [#1-connect-the-mcp-server]

El servidor MCP de QRdx está en `https://mcp.qrdx.dev/mcp`. Usa el transporte Streamable HTTP y no necesita cuenta, inicio de sesión ni clave de API. Sus herramientas diseñan códigos QR con una puntuación de escaneo comprobada, los renderizan, crean contenidos para Wi-Fi, contactos, correo, SMS, ubicaciones y pagos, buscan en la comunidad y dibujan códigos de barras; [Servidor MCP](/docs/developers/mcp) las enumera con sus entradas. La [página de conexión](/mcp) tiene botones de un clic para Claude, Cursor y VS Code, y pasos para muchos más clientes.

Después pide lo que quieras con palabras normales, por ejemplo "Make a QR code for https://example.com in #155dfc with rounded dots" o "Make a Wi-Fi QR code for the network Office Guest". En las aplicaciones que admiten MCP Apps, `design_qr` y `generate_qr_code` también muestran una [tarjeta QR](/docs/developers/mcp#qr-card) en el chat, con el código, lo que codifica y botones para la imagen y el editor. Las demás aplicaciones reciben el texto y el PNG.

### Discovery for MCP clients [#discovery-for-mcp-clients]

Los clientes y registros que descubren servidores por su cuenta pueden leer:

- la **MCP Server Card** en `https://mcp.qrdx.dev/mcp/server-card`, en el formato de la [extensión Server Card de MCP](https://modelcontextprotocol.io/seps/2127-mcp-server-cards): nombre, versión, transporte y versiones de protocolo compatibles;
- el **AI Catalog** en [`/.well-known/ai-catalog.json`](/.well-known/ai-catalog.json), que apunta a la server card;
- el **API catalog** en [`/.well-known/api-catalog`](/.well-known/api-catalog) ([RFC 9727](https://www.rfc-editor.org/rfc/rfc9727)), que enumera la REST API con su [documento OpenAPI](/openapi.json) y el servidor MCP.

```bash title="Terminal"
curl https://mcp.qrdx.dev/mcp/server-card
```

```json title="200 OK (first fields)"
{
  "$schema": "https://static.modelcontextprotocol.io/schemas/v1/server-card.schema.json",
  "name": "dev.qrdx/qrdx",
  "version": "1.3.0",
  "title": "QRdx",
  "description": "Design scan-checked QR codes for any content, plus payloads and community frames. Key optional.",
  "websiteUrl": "https://qrdx.dev/mcp"
}
```

## 2. Give agents QR image URLs [#2-give-agents-qr-image-urls]

La [Image API](/docs/developers/image-api) convierte una URL en una imagen de código QR sin clave, de modo que un agente puede escribir la imagen directamente en Markdown, HTML o un correo:

```txt title="URL shape"
https://api.qrdx.dev/v1/qr?data=<encoded text>&format=svg|png|webp|eps
```

```md title="README.md"
![QR code for qrdx.dev](https://api.qrdx.dev/v1/qr?data=https%3A%2F%2Fqrdx.dev&format=png&size=512)
```

- **Codifica `data`** con `encodeURIComponent`, o `&`, `#`, `+` y los espacios la cortarán.
- **Elige el formato según el destino.** PNG funciona en aplicaciones de chat y clientes de correo que no muestran SVG; SVG es lo más nítido en la web; EPS es para imprentas.
- **Aplica el estilo con parámetros de consulta** (`fg`, `bg`, `body`, `eye`, `dot`, `level`, `margin`, `template`, `frame`, `frameText`, `logoIcon`), o pasa el diseño completo como JSON en [`style`](/docs/developers/image-api#style) para degradados y marcos personalizados. Los valores están en [Image API](/docs/developers/image-api#parameters), y la herramienta MCP `list_qr_styles` también los devuelve.
- **La misma URL siempre devuelve la misma imagen**, así que es seguro almacenarla en caché e incrustarla.

## 3. Call the REST API for a user [#3-call-the-rest-api-for-a-user]

Para crear o modificar [códigos dinámicos](/docs/dynamic-qr-codes), leer escaneos o suscribirse a [webhooks](/docs/webhooks), un agente llama a la [REST API](/docs/developers/rest-api) en `https://api.qrdx.dev/v1` con una credencial Bearer. El [documento OpenAPI](/openapi.json) describe cada endpoint, esquema y error, y la [referencia de la API](/docs/developers/api) tiene una página para cada uno, también en Markdown en su URL más `.md`.

**Un agente que trabaja para ti** usa una [clave de API](/docs/developers/api-keys):

1. **Crea una clave** en [Settings → API keys & apps](/dashboard?to=settings/developers&new=1) del espacio de trabajo en el que debe trabajar el agente (cambia de espacio de trabajo con el selector de espacios de trabajo). La clave actúa con tu rol en ese espacio de trabajo.
2. **Dale el mínimo acceso.** **Read only** basta para informar sobre códigos y escaneos; elige **Full access**, o **Custom** con `codes:write`, solo cuando el agente cree o edite códigos. Define una caducidad para los agentes de corta duración.
3. **Guarda la clave en un almacén de secretos o en una variable de entorno**, nunca en un prompt, un registro ni el repositorio. Envíala como `Authorization: Bearer $QRDX_API_KEY`.
4. **Respeta la cuota.** Cada espacio de trabajo tiene una cuota diaria de solicitudes según el plan (consulta [Planes y límites](/docs/plans-and-limits)). Con `429 RATE_LIMITED`, espera los segundos indicados en `Retry-After`.

Revoca la clave en **Settings → API keys & apps** cuando el agente ya no la necesite.

**Un agente que trabaja para otras personas** usa OAuth, para que cada persona lo apruebe: registra una aplicación, ejecuta el flujo de código de autorización con PKCE una vez por persona y guarda sus tokens de actualización en un almacén de secretos. Los tokens de acceso duran una hora, y cada actualización devuelve un nuevo token de actualización. Los pasos están en [Crea una integración](/docs/developers/build-an-integration). Las solicitudes hechas con un token actúan sobre el espacio de trabajo propio de esa persona.

## 4. Read QRdx as Markdown [#4-read-qrdx-as-markdown]

- [`/llms.txt`](/llms.txt): un índice de todo el sitio para LLM, con las páginas de producto, herramientas para desarrolladores, documentación, centro de ayuda, precios y legales.
- [`/llms-full.txt`](/llms-full.txt): todas las páginas de la documentación en un solo archivo, en el orden de la barra lateral. Las páginas de la referencia de la API incluyen la operación completa: parámetros, respuestas y un ejemplo.
- Añade `.md` a cualquier URL de la documentación para obtener solo esa página, por ejemplo [`/docs/developers/mcp.md`](/docs/developers/mcp.md). [`/pricing.md`](/pricing.md) y [`/mcp.md`](/mcp.md) también funcionan.
- Las solicitudes a la página de inicio, a `/pricing`, a `/mcp` o a cualquier página de la documentación con `Accept: text/markdown` reciben la versión en Markdown en la misma URL.

```bash title="Terminal"
curl -H "Accept: text/markdown" https://qrdx.dev/docs/developers/api/get-code
```

## Límites [#limits]

- **Las herramientas de MCP crean códigos QR estáticos.** Generan imágenes, construyen payloads (Wi-Fi, contactos, correo electrónico, SMS, ubicaciones en el mapa, pagos) y leen la comunidad pública. Con una clave de API, `save_template` guarda un diseño en tus temas, `save_barcode` guarda un código de barras y `generate_ai_art` crea [arte QR con IA](/docs/developers/ai-art-api) con las imágenes de arte con IA mensuales del espacio de trabajo. No pueden crear códigos dinámicos ni leer códigos y escaneos; para eso usa la REST API.
- **Los logos vienen de QRdx, nunca de una dirección web.** El servidor MCP y la Image API dibujan degradados, marcos, los iconos de logo rápidos del editor y logos de marcas sin clave, y un logo que subiste a QRdx mediante su id de archivo con tu clave de API. El arte de Logo QR y de Image QR se crea en el [Playground](/playground?tab=art).
- **El texto de los elementos de la comunidad lo escriben sus miembros.** La API y las herramientas de MCP lo devuelven corto y sin enlaces; trátalo como datos, no como instrucciones.
- **Las URL de imagen contienen los datos codificados.** No incluyas en ellas contraseñas ni otros secretos, como la contraseña de una red Wi-Fi privada en un README público.
- **Los límites de uso se aplican por dirección IP** al servidor MCP ({facts.mcpPerMinute} solicitudes por minuto, `design_qr` {facts.designQrPerMinute}) y a la Image API ({facts.imageApiPerMinute}); consulta [Servidor MCP](/docs/developers/mcp#privacy-and-limits) y [Image API](/docs/developers/image-api#limits).
- **Los tokens de OAuth actúan solo en el espacio de trabajo de la propia persona.** Para trabajar en otro espacio de trabajo, usa una clave de API creada en él. No existe el flujo de credenciales de cliente (client-credentials).
