Al terminar esta página, tu asistente de IA podrá crear códigos QR: diseñar uno para cualquier contenido con una puntuación de escaneo verificada, renderizarlo con los estilos del editor, construir los datos correctos para Wi-Fi, contactos, correo electrónico, SMS, ubicaciones y pagos bancarios, buscar marcos de la comunidad y dibujar códigos de barras. Con una clave de API en la conexión, también puede guardar diseños y códigos de barras en tu espacio de trabajo y pintar arte con IA.

QRdx ejecuta un servidor público de [Model Context Protocol](https://modelcontextprotocol.io) en:

```txt title="Server URL"
https://mcp.qrdx.dev/mcp
```

Usa el transporte Streamable HTTP, no guarda estado de sesión y no necesita cuenta, inicio de sesión ni clave de API. El mismo servidor también responde en `https://qrdx.dev/api/mcp`, y la [página de conexión](/mcp) tiene botones de un clic y pasos para más clientes de los que muestra esta página.

[Pruébalo en el Playground](/playground?open=code&lang=mcp): da estilo a un código allí y cópialo como argumentos de `design_qr` para tu asistente.

## 2. Pide un código [#2-ask-for-a-code]

Luego pide lo que quieras con tus propias palabras. Estos prompts funcionan tal cual:

```txt title="Prompts"
Make a QR code for https://example.com in our brand blue, #155dfc, with rounded modules.
Create a Wi-Fi QR code for the network Office Guest with password correct-horse-battery.
Design a Wi-Fi QR code for Cafe Guest in warm browns with a Free Wi-Fi banner, and tell me its scan score.
Generate a contact QR code for Ada Lovelace, ada@example.com, and add it to the README.
Find a community frame for a restaurant menu and use it for https://example.com/menu.
Draw an EAN-13 barcode for 590123412345 as a PNG.
```

Con el primer prompt, el asistente llama a `generate_qr_code` y recibe el PNG y estas líneas, listas para pegar:

```txt title="generate_qr_code result"
QR code, 512x512px, error correction Q.
SVG URL: https://api.qrdx.dev/v1/qr?data=https%3A%2F%2Fexample.com&fg=155dfc&body=rounded
PNG URL: https://api.qrdx.dev/v1/qr?data=https%3A%2F%2Fexample.com&format=png&fg=155dfc&body=rounded
WebP URL (lossless, smaller than PNG): https://api.qrdx.dev/v1/qr?data=https%3A%2F%2Fexample.com&format=webp&fg=155dfc&body=rounded
EPS URL (vector, for print; 512 pt wide): https://api.qrdx.dev/v1/qr?data=https%3A%2F%2Fexample.com&format=eps&fg=155dfc&body=rounded
Markdown: ![QR code](https://api.qrdx.dev/v1/qr?data=https%3A%2F%2Fexample.com&fg=155dfc&body=rounded)
```

Con el segundo, llama a `qr_payload_wifi`, que devuelve `WIFI:T:WPA;S:Office Guest;P:correct-horse-battery;;`, y pasa esa cadena como `data` a `generate_qr_code` o como contenido de `design_qr`.

## Herramientas [#tools]

| Herramienta | Qué hace |
| --- | --- |
| `design_qr` | Diseña un código para cualquier tipo de contenido con el estilo que elija tu asistente, o a partir de un tema integrado o de un elemento de la comunidad, comprueba su puntuación de escaneo y repara el estilo hasta que sea Excelente. Devuelve la puntuación, lo que cambió, el JSON del estilo, un enlace al playground, un PNG y el SVG |
| `list_options` | Lista todos los valores que acepta `design_qr`: tipos de contenido y sus campos, colores y degradados, formas, marcos (con los ids de los marcos oficiales de QRdx), bordes, iconos de logo y logos de marcas, temas integrados, niveles de corrección de errores y límites |
| `generate_qr_code` | Genera un código QR con los estilos del editor. Devuelve una imagen PNG y URL públicas de la [Image API](/docs/developers/image-api) (SVG, PNG, WebP sin pérdida y EPS vectorial) listas para Markdown, HTML o impresión, además del marcado SVG si lo pides |
| `list_qr_styles` | Lista los patrones del cuerpo, las formas de los ojos de las esquinas y de los puntos del ojo, los marcos (los estilos integrados y los dibujados como plantillas), los iconos de logo, los niveles de corrección de errores, los valores por defecto y los límites |
| `search_community` | Busca marcos, temas y colecciones publicados en la [comunidad](/community) por palabras, tipo o etiqueta |
| `get_community_item` | Un elemento de la comunidad con el estilo que aplica, listo para `design_qr` o `generate_qr_code` |
| `save_template` | Guarda un diseño como tema en tu espacio de trabajo. Requiere una [clave de API](#use-an-api-key) |
| `generate_barcode` | Dibuja un código de barras EAN-13, UPC-A, UPC-E, EAN-8, ITF-14, GS1-128, Code 128, Code 39, Data Matrix, PDF417 o Aztec después de validar el valor (dígitos de control, longitudes, caracteres). Devuelve un PNG y URL públicas de la [API de códigos de barras](/docs/developers/barcode-api) |
| `save_barcode` | Guarda un código de barras en los Códigos de barras de tu espacio de trabajo. Requiere una [clave de API](#use-an-api-key) |
| `generate_ai_art` | Pinta un código QR dentro de una obra de arte con IA y comprueba que se escanee. Usa una de las imágenes de arte con IA mensuales del espacio de trabajo y tarda hasta un minuto. Requiere una [clave de API](#use-an-api-key). Consulta la [API de arte con IA](/docs/developers/ai-art-api) |
| `qr_payload_wifi` | Construye un payload de red `WIFI:` (WPA, WEP o abierta, opcionalmente oculta) con los caracteres especiales escapados |
| `qr_payload_vcard` | Construye un contacto vCard 3.0 (RFC 2426): nombre, organización, cargo, teléfonos, correo electrónico, sitio web, dirección y nota |
| `qr_payload_email` | Construye un enlace `mailto:` (RFC 6068) con cc, bcc, asunto y cuerpo opcionales |
| `qr_payload_sms` | Construye un enlace `sms:` (RFC 5724) con un mensaje opcional, o la forma anterior `SMSTO:` |
| `qr_payload_geo` | Construye una ubicación `geo:` (RFC 5870) a partir de la latitud y la longitud |
| `qr_payload_payment` | Construye un código de pago bancario: un BR Code de Pix, una transferencia SEPA (EPC069-12), o un código PayNow, PromptPay o VietQR (EMV, con su CRC). Valida los campos igual que los formularios del playground |

Las herramientas de payload devuelven una cadena de texto simple. Después, tu asistente la pasa como `data` a `generate_qr_code`.

### design_qr [#design_qr]

`design_qr` recibe el contenido como un tipo y sus campos, los mismos tipos y validaciones que los formularios de contenido del editor (`list_options` los lista), y un estilo opcional:

```json title="design_qr arguments"
{
  "content": { "type": "wifi", "ssid": "Cafe Guest", "password": "sunshine123", "encryption": "WPA" },
  "style": {
    "bgColor": "#FFF7ED",
    "fgColor": "#9A3412",
    "bodyPattern": "rounded",
    "cornerEyePattern": "rounded",
    "frame": { "style": "banner-bottom", "text": "Free Wi-Fi" }
  }
}
```

```txt title="design_qr result (first lines)"
Scan score 85/100 (great). No changes were needed. Content: WiFi · Cafe Guest (47 bytes). Open it in the playground: https://qrdx.dev/playground?style=1.eyJiIjoiI0ZGRjdFRCIs…&ref=mcp
```

El JSON del resultado incluye `payload` (la cadena exacta que codifica el código), `style`, `qrdxStyle`, `score`, `grade`, `stillFailing` (las comprobaciones que aún fallan, con una solución para cada una), `repairs`, `changes` y `playgroundUrl`, seguidos del PNG y el SVG.

Las opciones que omitas toman valores por defecto (los ojos siguen el color de los puntos, formas cuadradas, margen 4, corrección de errores Q, sin marco). Después, QRdx ejecuta en el diseño la comprobación de escaneo del editor: genera el código, lo decodifica a 96, 160 y 320 px con un modelo de cámara de teléfono, y comprueba el contraste, la zona de silencio, las formas de los ojos y las combinaciones de formas. Si queda por debajo de Excelente (85), repara el estilo, hasta tres veces, cambiando lo mínimo posible (colores más oscuros que conservan su tono, una forma de ojo más segura, menos corrección de errores para contenido largo). Si eso no basta, recurre a un código clásico negro sobre blanco con tu marco. El resultado indica qué se cambió y por qué.

En `design_qr` no se ejecuta ningún modelo de IA por parte de QRdx: tu asistente elige el estilo, y QRdx lo valida, lo comprueba y lo repara. El contenido no válido (una contraseña WPA de menos de 8 caracteres, una dirección de correo mal formada) se rechaza indicando el motivo. `design_qr` tiene su propio límite de {facts.designQrPerMinute} llamadas por minuto por dirección IP.

Más entradas:

- **`preset`**: parte de un tema integrado por su id (`list_options` los lista). Las opciones de estilo que definas tienen prioridad sobre él.
- **`community_item`**: parte de un marco o tema de la comunidad por su id, como `frame:wifi-card`. Un elemento de tipo marco se coloca sobre un código clásico; tus opciones de estilo cambian el código que hay debajo. Los marcos oficiales de QRdx también son elementos de la comunidad, así que aquí funcionan `frame:diwali-diya` o `frame:menu-cutlery`.
- **Un marco personalizado**: `style.frame` puede ser `{ "style": "custom", "spec": … }` con una especificación de marco, como la de un marco de la comunidad obtenida con `get_community_item`. Se dibuja y se puntúa tal cual; las reparaciones cambian el código, nunca el marco.
- **`style.logo`**: un icono de logo rápido (`wifi`, `location`, `phone`, `email`, `link`, `file`, `calendar`, `whatsapp` o `instagram`), o un logo de marca por su slug de [Simple Icons](https://simpleicons.org) (`spotify`, `paypal:white`). `list_options` lista los slugs de las marcas más populares.
- **Opciones del motor**: `style.eyeColors` (colores `#RRGGBB` por ojo), `moduleScale` (tamaño de los puntos, de `0.5` a `1`), `shape` (`circle` para un código redondo), `autoLevel` y `logoOptions` (el tamaño del logo, el espacio libre, la posición, el recorte y la placa). Se dibujan y se puntúan tal como los indicas; las reparaciones no los cambian.

<IfAvailable feature="fileStorage">
`logo_file_id` dibuja en su lugar un logo que subiste a QRdx, con una [clave de API](#use-an-api-key).
</IfAvailable>

Los logos se puntúan según los módulos que cubren, igual que en el editor, así que una reparación puede subir la corrección de errores a H o quitar el logo. La marca de QRdx que el editor muestra por defecto no se dibuja aquí.

El `qrdxStyle` del resultado es el diseño como JSON de estilo del editor. Pásalo a `save_template`, a `generate_qr_code` como `style` para generar el mismo diseño con otro tamaño, o al [`style`](/docs/developers/image-api#style) de la Image API. `playground_url` abre el diseño en el [playground](/playground): lleva solo el estilo, nunca el logo ni el contenido, y `playgroundLeftOut` indica lo que deja fuera.

### generate_qr_code [#generate_qr_code]

Las entradas coinciden con los [parámetros de la Image API](/docs/developers/image-api#parameters): `data` (obligatorio), `size`, `fg`, `bg`, `eyeColor`, `dotColor`, `body`, `eye`, `dot`, `level`, `margin`, `template`, `frame`, `frameText`, `logoIcon`, `logoFileId`, `item` (un id de elemento de la comunidad) y `style` (el JSON de estilo del editor: degradados, marcos personalizados y el resto, tal como lo devuelve `design_qr`). Las opciones planas tienen prioridad sobre `style`, y `style` tiene prioridad sobre `item`. Define `include_svg` como `true` para obtener también el marcado SVG como texto, por ejemplo para guardar un archivo `.svg`. Está desactivado por defecto porque el marcado suele pesar entre 50 y 150 KB, lo que llenaría la conversación.

`generate_qr_code` no comprueba la puntuación de escaneo; usa `design_qr` para eso. Un código con tu logo subido no tiene URL de imagen pública, ya que la Image API solo dibuja ese logo en las solicitudes hechas con tu clave.

### La tarjeta QR [#qr-card]

En las aplicaciones compatibles con [MCP Apps](https://modelcontextprotocol.io/extensions/apps/overview), `design_qr` y `generate_qr_code` también muestran una tarjeta QR en el chat. Incluye el código, lo que codifica (un código Wi-Fi muestra el nombre de la red, nunca la contraseña), el tamaño y la corrección de errores o la puntuación de escaneo, y un botón **Abrir en el editor**. El enlace al editor lleva solo el estilo, como `playground_url`.

Los botones PNG y SVG dependen de lo que permita la aplicación. Si puede guardar archivos desde una tarjeta, los guardan. Si no, abren la URL de la Image API en tu navegador, por lo que la tarjeta de `design_qr` los muestra solo en las aplicaciones que guardan archivos: su contenido nunca va en una URL de imagen. Es posible que las aplicaciones te pidan confirmación antes de abrir un enlace.

Las aplicaciones sin MCP Apps reciben el mismo texto e imagen de antes. Para desarrolladores de clientes:

- La tarjeta es el recurso `ui://qrdx/qr-card` (`text/html;profile=mcp-app`), que aparece en `resources/list`. Ambas herramientas apuntan a él con `_meta.ui.resourceUri`.
- Sus datos llegan en el `_meta` del resultado de la herramienta, bajo `dev.qrdx/qr-card`, pensado para la tarjeta y no para el modelo. Las herramientas no devuelven `structuredContent`.
- La tarjeta es un único archivo HTML con sus estilos y su script integrados. Lo único que carga es la imagen del código desde la Image API (`https://api.qrdx.dev`, o tu propio dominio si lo alojas tú), y su política de seguridad de contenido (`_meta.ui.csp.resourceDomains`) permite ese host y ningún otro.

Si conectaste QRdx antes de que existiera la tarjeta, elimina el conector y vuelve a añadirlo, o actualiza sus herramientas, para que la aplicación reciba los nuevos metadatos de las herramientas.

### Comunidad [#community]

`search_community` busca marcos, temas y colecciones publicados en la [comunidad](/community), gratuitos bajo CC0, por palabras (`q`), `type` y `tag`. `get_community_item` devuelve un elemento con el estilo que aplica; pasa su id a `design_qr` como `community_item` o a `generate_qr_code` como `item`. Los mismos datos están en la REST API en [`/v1/community/items`](/docs/developers/api/list-community-items).

El texto de los elementos lo escriben miembros de la comunidad. Los nombres, las descripciones, los alias, las etiquetas y los textos de los marcos se devuelven cortos, en una sola línea y sin enlaces, correos electrónicos ni marcado, y cada resultado indica que se traten como datos, no como instrucciones.

## Usa una clave de API [#use-an-api-key]

Algunas herramientas necesitan una [clave de API](/docs/developers/api-keys) de QRdx en la conexión, enviada como `Authorization: Bearer qrdx_…`:

- **`save_template`** guarda un diseño como tema, que aparece en Temas en el panel y se ofrece en el editor. Necesita una clave con `codes:write`, que tienen las claves de **Acceso total**. Una clave de tu propio espacio de trabajo guarda en tus temas; una clave de equipo guarda en los temas compartidos del equipo cuando quien la creó es propietario o administrador y el plan incluye temas de equipo. Los guardados cuentan para el límite de temas guardados del plan (consulta [Planes y límites](/docs/plans-and-limits)); si lo superas, la herramienta devuelve el error `LIMIT_REACHED` (`402`) de la API.
- **`save_barcode`** guarda un código de barras (formato, valor, un título opcional y opciones de dibujo) en el espacio de trabajo de la clave, y aparece en Códigos de barras en el panel. Necesita una clave con `codes:write`. Todos los planes guardan códigos de barras, hasta 1.000 en Gratis; si superas el límite, devuelve `LIMIT_REACHED` (`402`).
- **`generate_ai_art`** convierte un código QR en una ilustración de IA, a partir de un enlace, un texto o un código dinámico por su id, y devuelve el PNG una vez que QRdx ha comprobado que se escanea. Acepta los mismos campos que [`POST /v1/art`](/docs/developers/ai-art-api) y necesita una clave con `codes:write`. Cada imagen consume una de las imágenes de arte con IA mensuales del espacio de trabajo de la clave, y una llamada puede tardar hasta un minuto.
<IfAvailable feature="fileStorage">
- **Logotipos que subiste** en [Panel → Archivos](/docs/files), por id de archivo (`logo_file_id` en `design_qr`, `logoFileId` en `generate_qr_code`): un PNG o JPEG de hasta 1 MB. La clave debe pertenecer al espacio de trabajo propietario del archivo.
</IfAvailable>


## Si algo sale mal [#if-something-goes-wrong]

### El cliente no puede conectarse [#the-client-cant-connect]

Comprueba que la URL sea exactamente `https://mcp.qrdx.dev/mcp` y que el transporte sea HTTP (Streamable HTTP), no SSE ni stdio. Los clientes que solo ejecutan servidores locales necesitan el puente `mcp-remote` mencionado arriba. Al abrir la URL en un navegador se redirige a la página de conexión, y es lo esperado: los clientes MCP nunca piden HTML.

### El asistente dice que una herramienta necesita una clave de API [#the-assistant-says-a-tool-needs-an-api-key]

`save_template`, `save_barcode`, `generate_ai_art` y los logotipos subidos necesitan `Authorization: Bearer qrdx_…` en la conexión. Añade el encabezado como se muestra arriba y vuelve a conectar.

### `design_qr` rechaza el contenido [#design_qr-refuses-the-content]

El contenido no superó las mismas comprobaciones que los formularios del editor: una contraseña WPA de menos de 8 caracteres, una dirección de correo mal formada, un campo de pago fuera de rango. El motivo aparece en la respuesta; `list_options` muestra los campos y las reglas de cada tipo de contenido.

### Demasiadas solicitudes [#too-many-requests]

El servidor permite {facts.mcpPerMinute} solicitudes por minuto por dirección IP, y `design_qr` {facts.designQrPerMinute}. Con una clave, `save_template` también está limitado a 30 por minuto por usuario. Espera un minuto e inténtalo de nuevo.

## Privacidad y límites [#privacy-and-limits]

- Las herramientas generan imágenes, comprueban diseños, dan formato a texto y leen la comunidad pública. Solo `save_template` y `save_barcode` escriben algo: el tema o el código de barras que les pides guardar, en el espacio de trabajo de la clave de API. `generate_ai_art` consume una de las imágenes de arte con IA mensuales del espacio de trabajo, y no conserva ni la imagen ni la foto que envías. El servidor no guarda los códigos que generas.
- Las URL de imagen que devuelven `generate_qr_code` y `generate_barcode` contienen los datos codificados. No las compartas si los datos son privados, como una contraseña de Wi-Fi.
- Las solicitudes están limitadas a {facts.mcpPerMinute} por minuto por dirección IP, y `design_qr` a {facts.designQrPerMinute}.

## Autoalojamiento y desarrollo local [#self-hosting-and-local-development]

El servidor MCP forma parte de la aplicación web de QRdx, así que cada instancia lo sirve en `/api/mcp`:

- **Autoalojado.** Cuando `NEXT_PUBLIC_APP_URL` es tu propio dominio, la página de conexión, los fragmentos y los enlaces de instalación usan `https://<your-domain>/api/mcp`.
- **Desarrollo local.** `bun run dev` lo sirve en `http://localhost:3000/api/mcp`. La página de conexión sigue mostrando la URL pública y ofrece la local como sugerencia, para que puedas apuntar un cliente a tu máquina y probar cambios en el servidor antes de publicarlos.
