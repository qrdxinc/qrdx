Ao final desta página, você vai saber qual das três formas de dar QR codes a um agente serve para o seu caso, vai ter tudo configurado e vai saber o que cada uma pode e não pode fazer.

| O agente precisa | Use | Chave ou conta |
| --- | --- | --- |
| Gerar um QR code em um chat ou em uma execução de agente | [Servidor MCP](#1-connect-the-mcp-server) | Nenhuma |
| Colocar um QR code em Markdown, HTML, um e-mail ou um build | [Image API](#2-give-agents-qr-image-urls) | Nenhuma |
| Criar ou alterar QR codes dinâmicos, ler leituras | [REST API](#3-call-the-rest-api-for-a-user) | Chave de API ou token de acesso OAuth |
| Pintar um QR code em uma arte de IA | [API de arte com IA](/docs/developers/ai-art-api): `POST /v1/art` ou a ferramenta MCP `generate_ai_art` | Chave de API; usa as imagens de arte com IA mensais do workspace |
| Ler a documentação do QRdx | [Markdown e llms.txt](#4-read-qrdx-as-markdown) | Nenhuma |

## 1. Connect the MCP server [#1-connect-the-mcp-server]

O servidor MCP do QRdx fica em `https://mcp.qrdx.dev/mcp`. Ele usa o transporte Streamable HTTP e não exige conta, login nem chave de API. Suas ferramentas criam QR codes com uma nota de leitura verificada, renderizam os códigos, montam payloads para Wi-Fi, contatos, e-mail, SMS, localizações e pagamentos, pesquisam na comunidade e desenham códigos de barras; o [servidor MCP](/docs/developers/mcp) lista todas com seus parâmetros. A [página de conexão](/mcp) tem botões de um clique para Claude, Cursor e VS Code e instruções para muitos outros clientes.

### Discovery for MCP clients [#discovery-for-mcp-clients]

Clientes e registros que descobrem servidores por conta própria podem ler:

- o **MCP Server Card** em `https://mcp.qrdx.dev/mcp/server-card`, no formato da [extensão Server Card](https://modelcontextprotocol.io/seps/2127-mcp-server-cards) do MCP: nome, versão, transporte e versões de protocolo compatíveis;
- o **AI Catalog** em [`/.well-known/ai-catalog.json`](/.well-known/ai-catalog.json), que aponta para o server card;
- o **API catalog** em [`/.well-known/api-catalog`](/.well-known/api-catalog) ([RFC 9727](https://www.rfc-editor.org/rfc/rfc9727)), que lista a REST API com seu [documento OpenAPI](/openapi.json) e o servidor MCP.

```bash title="Terminal"
curl https://mcp.qrdx.dev/mcp/server-card
```

```json title="200 OK (first fields)"
{
  "$schema": "https://static.modelcontextprotocol.io/schemas/v1/server-card.schema.json",
  "name": "dev.qrdx/qrdx",
  "version": "1.3.0",
  "title": "QRdx",
  "description": "Design scan-checked QR codes for any content, plus payloads and community frames. Key optional.",
  "websiteUrl": "https://qrdx.dev/mcp"
}
```

## 2. Give agents QR image URLs [#2-give-agents-qr-image-urls]

A [Image API](/docs/developers/image-api) transforma uma URL em uma imagem de QR code sem chave, então um agente pode escrever a imagem direto em Markdown, HTML ou um e-mail:

```txt title="URL shape"
https://api.qrdx.dev/v1/qr?data=<encoded text>&format=svg|png|webp|eps
```

```md title="README.md"
![QR code for qrdx.dev](https://api.qrdx.dev/v1/qr?data=https%3A%2F%2Fqrdx.dev&format=png&size=512)
```

- **Codifique `data`** com `encodeURIComponent`, ou `&`, `#`, `+` e espaços vão quebrá-lo.
- **Escolha o formato conforme o destino.** PNG funciona em apps de chat e clientes de e-mail que não exibem SVG; SVG é o mais nítido na web; EPS é para gráficas.
- **Estilize com parâmetros de consulta** (`fg`, `bg`, `body`, `eye`, `dot`, `level`, `margin`, `template`, `frame`, `frameText`, `logoIcon`), ou passe o design inteiro como JSON em [`style`](/docs/developers/image-api#style) para gradientes e molduras personalizadas. Os valores estão listados em [Image API](/docs/developers/image-api#parameters), e a ferramenta MCP `list_qr_styles` também os retorna.
- **A mesma URL sempre retorna a mesma imagem**, então é seguro fazer cache e incorporar.

## 3. Call the REST API for a user [#3-call-the-rest-api-for-a-user]

Para criar ou alterar [QR codes dinâmicos](/docs/dynamic-qr-codes), ler leituras ou assinar [webhooks](/docs/webhooks), um agente chama a [REST API](/docs/developers/rest-api) em `https://api.qrdx.dev/v1` com uma credencial Bearer. O [documento OpenAPI](/openapi.json) descreve cada endpoint, schema e erro, e a [referência da API](/docs/developers/api) tem uma página para cada um, também em Markdown na própria URL mais `.md`.

**Um agente trabalhando por você** usa uma [chave de API](/docs/developers/api-keys):

1. **Crie uma chave** em [Settings → API keys & apps](/dashboard?to=settings/developers&new=1) do workspace em que o agente deve trabalhar (troque de workspace com o seletor de workspace). A chave age com o seu papel nesse workspace.
2. **Dê o menor acesso possível.** **Read only** basta para gerar relatórios de códigos e leituras; escolha **Full access**, ou **Custom** com `codes:write`, só quando o agente criar ou editar códigos. Defina uma validade para agentes de curta duração.
3. **Guarde a chave em um cofre de segredos ou em uma variável de ambiente**, nunca em um prompt, um log ou no repositório. Envie-a como `Authorization: Bearer $QRDX_API_KEY`.
4. **Respeite a cota.** Cada workspace tem uma cota diária de requisições conforme o plano (veja [Planos e limites](/docs/plans-and-limits)). Em `429 RATE_LIMITED`, espere o número de segundos indicado em `Retry-After`.

Revogue a chave em **Settings → API keys & apps** quando o agente não precisar mais dela.

**Um agente que trabalha para outras pessoas** usa OAuth, para que cada pessoa o aprove: registre um app, execute o fluxo de código de autorização com PKCE uma vez por pessoa e guarde os refresh tokens delas em um cofre de segredos. Os tokens de acesso duram uma hora, e cada renovação retorna um novo refresh token. Os passos estão em [Crie uma integração](/docs/developers/build-an-integration). As requisições feitas com um token agem no workspace da própria pessoa.

## 4. Read QRdx as Markdown [#4-read-qrdx-as-markdown]

- [`/llms.txt`](/llms.txt): um índice do site inteiro para LLMs, com o produto, ferramentas para desenvolvedores, documentação, central de ajuda, preços e páginas legais.
- [`/llms-full.txt`](/llms-full.txt): todas as páginas da documentação em um único arquivo, na ordem da barra lateral. As páginas da referência da API incluem a operação completa: parâmetros, respostas e um exemplo.
- Adicione `.md` a qualquer URL da documentação para obter só aquela página, por exemplo [`/docs/developers/mcp.md`](/docs/developers/mcp.md). [`/pricing.md`](/pricing.md) e [`/mcp.md`](/mcp.md) também funcionam.
- Requisições à página inicial, a `/pricing`, a `/mcp` ou a qualquer página da documentação com `Accept: text/markdown` recebem a versão em Markdown na mesma URL.

```bash title="Terminal"
curl -H "Accept: text/markdown" https://qrdx.dev/docs/developers/api/get-code
```

## Limites [#limits]

- **As ferramentas do MCP geram QR codes estáticos.** Elas renderizam imagens, montam payloads (Wi-Fi, contatos, e-mail, SMS, localizações no mapa, pagamentos) e leem a comunidade pública. Com uma chave de API, `save_template` salva um design nos seus temas, `save_barcode` salva um código de barras e `generate_ai_art` cria [arte de QR com IA](/docs/developers/ai-art-api) usando as imagens de arte com IA mensais do workspace. Elas não conseguem criar códigos dinâmicos nem ler códigos e leituras; para isso, use a REST API.
- **Os logos vêm do QRdx, nunca de um endereço da web.** O servidor MCP e a Image API desenham gradientes, molduras, os ícones de logo rápidos do editor e logos de marcas sem precisar de chave, e um logo que você enviou ao QRdx, pelo id do arquivo, com a sua chave de API. A arte de Logo QR e de Image QR é feita no [Playground](/playground?tab=art).
- **O texto dos itens da comunidade é escrito por membros.** A API e as ferramentas do MCP o devolvem curto e sem links; trate-o como dado, não como instrução.
- **As URLs de imagem contêm os dados codificados.** Não coloque senhas nem outros segredos nelas, como a senha de um Wi-Fi privado em um README público.
- **Os limites de requisições se aplicam por endereço IP** ao servidor MCP ({facts.mcpPerMinute} requisições por minuto, `design_qr` {facts.designQrPerMinute}) e à Image API ({facts.imageApiPerMinute}); veja [Servidor MCP](/docs/developers/mcp#privacy-and-limits) e [Image API](/docs/developers/image-api#limits).
- **Os tokens OAuth atuam apenas no workspace da própria pessoa.** Para trabalhar em outro workspace, use uma chave de API criada nele. Não existe concessão client-credentials.
