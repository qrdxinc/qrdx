Tout ce que fait QRdx est accessible par le code. Partez de ce que vous voulez construire : chaque ligne indique l'outil, ce dont il a besoin et la page qui vous y mène.

| Vous voulez | Utilisez | Prérequis |
| --- | --- | --- |
| Placer un QR code dans une page, un e-mail ou un README | [API d'image de QR code](/docs/developers/image-api) : une URL `GET` qui est l'image | Rien |
| Dessiner un code-barres pour une étiquette ou un flux de produits | [API de codes-barres](/docs/developers/barcode-api) : la même chose, pour EAN, UPC, Code 128 et plus | Rien |
| Créer des codes que vous pouvez rediriger ailleurs après l'impression, et consulter leurs scans | [REST API](/docs/developers/quickstart) : `POST /v1/codes`, `PATCH`, `GET …/scans` | Une [clé d'API](/docs/developers/api-keys) |
| Réagir aux scans, aux nouveaux codes ou aux réponses de formulaire dans votre propre système | [Webhooks](/docs/webhooks) : requêtes `POST` signées envoyées à votre URL | Une clé d'API ou le tableau de bord, plan Business |
| Laisser un assistant IA créer des QR codes dans une conversation | [Serveur MCP](/docs/developers/mcp) : `https://mcp.qrdx.dev/mcp` | Rien |
| Créer des QR codes depuis un script, un build ou un CSV | [CLI](/docs/developers/cli) : `npx @qrdx/cli` | Node.js 22 |
| Intégrer un QR code dans une illustration IA | [API d'art IA](/docs/developers/ai-art-api) : `POST /v1/art` | Une clé d'API, des images d'art IA mensuelles |
| Permettre à d'autres personnes de connecter leur compte QRdx à votre produit | [Créer une intégration](/docs/developers/build-an-integration) : OAuth 2.0 avec PKCE | Une application OAuth |
| Automatiser QRdx dans n8n | [Nœuds n8n](/docs/developers/n8n) : `@qrdx/n8n-nodes-qrdx` | Une instance n8n auto-hébergée |
| Générer des codes stylisés dans une application React | [Bibliothèque React](/docs/getting-started) : le paquet `qrdx` | npm |

## Première requête en deux minutes [#first-request-in-two-minutes]

Le [démarrage rapide](/docs/developers/quickstart) génère une image de QR code avec une seule requête sans clé, crée une clé d'API, crée un code dynamique et le redirige ailleurs. Tout le reste de cette page repose sur ces quatre étapes.

```bash title="Terminal"
curl "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=png" -o qr.png
```

## URL de base et authentification [#base-url-and-authentication]

La REST API se trouve à l'adresse `https://api.qrdx.dev/v1`. Les mêmes routes répondent à `https://qrdx.dev/api/v1`, et une instance [auto-hébergée](/docs/self-hosting) les sert sous `/api/v1` sur son propre domaine.

Les requêtes transmettent une [clé d'API](/docs/developers/api-keys) sous la forme `Authorization: Bearer qrdx_…`. Une clé agit sur l'espace de travail où elle a été créée, avec votre rôle dans celui-ci. Les applications qui agissent pour d'autres utilisateurs de QRdx envoient à la place un [jeton d'accès OAuth 2.0](/docs/developers/rest-api#get-an-access-token) dans le même en-tête. Les points de terminaison d'image, de code-barres et de communauté n'ont besoin ni de l'un ni de l'autre.
