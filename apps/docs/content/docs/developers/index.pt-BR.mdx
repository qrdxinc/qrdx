Tudo o que o QRdx faz está disponível por código. Comece pelo que você quer construir: cada linha mostra a ferramenta, o que ela exige e a página que leva você até lá.

| Você quer | Use | Precisa de |
| --- | --- | --- |
| Colocar um QR code em uma página, um e-mail ou um README | [Image API de QR code](/docs/developers/image-api): uma URL `GET` que é a própria imagem | Nada |
| Desenhar um código de barras para uma etiqueta ou um feed de produtos | [API de código de barras](/docs/developers/barcode-api): o mesmo, para EAN, UPC, Code 128 e mais | Nada |
| Criar códigos que você pode apontar para outro destino depois de impressos, e ver as leituras deles | [REST API](/docs/developers/quickstart): `POST /v1/codes`, `PATCH`, `GET …/scans` | Uma [chave de API](/docs/developers/api-keys) |
| Reagir a leituras, novos códigos ou respostas de formulário no seu próprio sistema | [Webhooks](/docs/webhooks): requisições `POST` assinadas para a sua URL | Uma chave de API ou o painel, plano Business |
| Deixar um assistente de IA criar QR codes em um chat | [Servidor MCP](/docs/developers/mcp): `https://mcp.qrdx.dev/mcp` | Nada |
| Criar QR codes a partir de um script, um build ou um CSV | [CLI](/docs/developers/cli): `npx @qrdx/cli` | Node.js 22 |
| Pintar um QR code em uma arte de IA | [API de arte com IA](/docs/developers/ai-art-api): `POST /v1/art` | Uma chave de API, imagens de arte com IA mensais |
| Deixar outras pessoas conectarem a conta QRdx delas ao seu produto | [Criar uma integração](/docs/developers/build-an-integration): OAuth 2.0 com PKCE | Um app OAuth |
| Automatizar o QRdx no n8n | [Nós do n8n](/docs/developers/n8n): `@qrdx/n8n-nodes-qrdx` | Um n8n auto-hospedado |
| Renderizar códigos estilizados dentro de um app React | [Biblioteca React](/docs/getting-started): o pacote `qrdx` | npm |

## Primeira requisição em dois minutos [#first-request-in-two-minutes]

O [início rápido](/docs/developers/quickstart) gera uma imagem de QR code com uma requisição sem chave, cria uma chave de API, cria um QR code dinâmico e o aponta para outro destino. Todo o resto desta página se apoia nesses quatro passos.

```bash title="Terminal"
curl "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=png" -o qr.png
```

## URL base e autenticação [#base-url-and-authentication]

A REST API fica em `https://api.qrdx.dev/v1`. As mesmas rotas respondem em `https://qrdx.dev/api/v1`, e uma instância [auto-hospedada](/docs/self-hosting) as serve em `/api/v1` no próprio domínio.

As requisições levam uma [chave de API](/docs/developers/api-keys) como `Authorization: Bearer qrdx_…`. Uma chave atua no workspace em que foi criada, com o seu papel nele. Apps que agem em nome de outros usuários do QRdx enviam, no lugar dela, um [token de acesso OAuth 2.0](/docs/developers/rest-api#get-an-access-token) no mesmo header. Os endpoints de imagem, código de barras e comunidade não precisam de nenhum dos dois.
