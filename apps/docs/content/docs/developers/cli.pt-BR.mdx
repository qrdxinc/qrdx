Ao final desta página, você terá arquivos de QR code feitos no seu terminal, com os mesmos estilos do Playground, e uma pasta de códigos gerada a partir de um CSV com um único comando, sem enviar nada para lugar nenhum.

O `@qrdx/cli` gera os mesmos QR codes do Playground e da [biblioteca `qrdx`](/docs/getting-started) pela linha de comando. Em scripts e no CI, ele nunca faz perguntas; execute `qrdx generate` sem argumentos em um terminal e ele pergunta o conteúdo e as opções passo a passo.

## Antes de começar [#before-you-start]

- Node.js 22 ou superior.
- A saída em PNG e WebP usa o [sharp](https://sharp.pixelplumbing.com), uma dependência opcional que o npm instala onde a sua plataforma for compatível; SVG e EPS funcionam sem ele.
- O pacote npm `qrdx` é a biblioteca React. A CLI está apenas em `@qrdx/cli`.

## 1. Gere um código [#1-make-one-code]

Execute uma vez com `npx` ou instale globalmente para ter o comando `qrdx`:

```bash title="Terminal"
npx @qrdx/cli generate "https://example.com" -o qr.svg

npm install -g @qrdx/cli
qrdx generate "https://example.com" -o qr.png --size 1024
```

```txt title="Output"
◇  ✔  Saved to qr.png (1024×1024)
└  Done!
```

A extensão do arquivo define o formato; se o nome do arquivo não tiver extensão, use `--format`.

| Formato | Use para | `--size` significa |
| --- | --- | --- |
| `.svg` | Páginas web, ferramentas de design, ampliar sem perda | Largura em pixels (padrão 512) |
| `.png` | Documentos, slides, qualquer lugar que precise de uma imagem | Largura em pixels |
| `.webp` | Sites: os pixels do PNG, sem perda, em um arquivo menor | Largura em pixels |
| `.eps` | Gráficas, Illustrator, InDesign | Largura em pontos (72 por polegada, então `144` são 2 polegadas) |

Arquivos EPS são PostScript vetorial. Logos em PNG e JPEG são incorporados como estão; outros formatos de logo são convertidos com o sharp quando ele está instalado e, caso contrário, ficam de fora com um aviso.

## 2. Estilize [#2-style-it]

```bash title="Terminal"
# High-resolution PNG for print
qrdx generate "https://example.com" -o print.png --size 2048 --level H

# Vector EPS, 2 inches wide, for a print shop
qrdx generate "https://example.com" -o qr.eps --size 144

# Branded colors and patterns
qrdx generate "https://example.com" --body circle --eye rounded --fg "#1a1a2e" -o brand.svg

# Gradient foreground
qrdx generate "https://example.com" -o gradient.svg \
  --fg '{"type":"linear","stops":[{"color":"#6366f1","offset":0},{"color":"#ec4899","offset":100}],"angle":135}'

# "Scan for the menu" frame
qrdx generate "https://example.com/menu" --frame banner-bottom --frame-text "Scan for the menu" -o menu.png

# Wi-Fi network
qrdx generate "WIFI:T:WPA;S:MyNetwork;P:MyPassword;;" -o wifi.svg
```

```txt title="Output of the frame example"
◇  ✔  Saved to menu.png (635×727)
```

Com moldura, `--size` é a largura do código e a moldura se soma à imagem. Para imprimir um [QR code dinâmico](/docs/dynamic-qr-codes), passe o link curto dele (`https://qrdx.dev/q/<slug>`) como dado.

| Flag | Padrão | Descrição |
| --- | --- | --- |
| `-o`, `--output` | `qr.svg` | Arquivo de saída |
| `--format` | pela extensão | `svg`, `png`, `webp` ou `eps` |
| `--size` | `512` | Tamanho da saída (veja acima) |
| `-l`, `--level` | `Q` | Correção de erros: `L`, `M`, `Q` ou `H` |
| `--body` | `square` | [Padrão](/docs/features/patterns) dos módulos de dados |
| `--eye` | `square` | Padrão do olho dos cantos |
| `--dot` | `square` | Padrão do ponto do olho dos cantos |
| `--fg`, `--bg` | `#000000`, `#ffffff` | Primeiro plano e fundo: uma cor hex ou um gradiente em JSON (`linear`, `radial` ou `angular`) |
| `--eye-color`, `--dot-color` | `--fg` | Cores do olho dos cantos e do ponto do olho |
| `--logo` | | URL da imagem do logo central (use com `--level H`) |
| `--no-logo` | | Pula a pergunta do logo no modo interativo |
| `--margin` | `0` | Zona de silêncio, em módulos |
| `--template` | | Uma moldura desenhada como template: `Arrow`, `StandardBox`, `SquareBorder`, `StrikedBox`, `Halloween` ou `DotRing` |
| `--frame` | | [Moldura](/docs/features/frames) com chamada para ação: qualquer uma das {facts.frameStyles} molduras incluídas, como `banner-bottom`, `rounded-border`, `circle`, `sticker` ou `phone` (veja [todas elas](/docs/styles#frames)) |
| `--frame-text` | `Scan me` | Texto da moldura, até 24 caracteres; `""` o oculta |
| `--frame-color`, `--frame-text-color` | | Cores da moldura e do texto (hex) |

`qrdx --help` lista todos os nomes de padrões. Um valor inválido encerra com o código `1` e lista o que é aceito:

```txt title="qrdx generate https://example.com --body nope -o bad.svg"
✗ Invalid --body "nope". Expected one of: circle, circle-large, square, diamond, circle-mixed, pacman, rounded, small-square, vertical-line, horizontal-line, liquid, liquid-horizontal, liquid-vertical, classy, classy-rounded, leaf, plus, hexagon, star, heart, random-dots, mosaic, octagon
```

## 3. Gere vários códigos a partir de um CSV [#3-make-many-codes-from-a-csv]

`qrdx batch` grava em uma pasta um QR code estático para cada linha de um arquivo CSV:

```csv title="products.csv"
sku,url
A-100,https://example.com/products/a-100
A-101,https://example.com/products/a-101
```

```bash title="Terminal"
qrdx batch products.csv -o codes --format png --size 1024 --body circle
```

```txt title="Output"
2 rows · 2 saved
✔  Saved 2 PNG codes to codes in 0.2 s
```

A pasta contém `A-100.png` e `A-101.png`. Ele lê as mesmas colunas do [gerador em massa](/tools/bulk): o conteúdo vem de uma coluna chamada `value`, `url`, `link`, `data`, `content`, `text` ou `qr` (ou, na falta delas, da primeira coluna), e os nomes de arquivo vêm de uma chamada `file name`, `name`, `label`, `id`, `title` ou `sku` (ou, na falta delas, `qr-00001`, `qr-00002` e assim por diante). Escolha outras pelo nome do cabeçalho ou pelo número da coluna:

| Flag | Padrão | Descrição |
| --- | --- | --- |
| `-o`, `--out` | `qr-codes` | Pasta para os códigos |
| `--format` | `svg` | `svg`, `png` ou `eps` |
| `--value-column` | detectada | Coluna com o conteúdo de cada código |
| `--name-column` | detectada | Coluna com os nomes de arquivo |
| `--no-header` | | A primeira linha é um código, não nomes de colunas |
| `--jobs` | `4` para SVG, `8` nos demais | Códigos gerados ao mesmo tempo, de 1 a 64 |

Todas as opções de estilo acima valem para todos os códigos. O CSV é lido como um fluxo e cada código é salvo assim que fica pronto, então o comando não tem limite de linhas: em um notebook, 10.000 códigos SVG levaram cerca de 40 segundos e menos de 200 MB de memória. Nada é enviado e não é preciso ter conta. As linhas que não podem ser codificadas são puladas e listadas, com o motivo, em `errors.csv` na pasta de saída.

Para imprimir [códigos dinâmicos](/docs/dynamic-qr-codes) em massa, crie-os primeiro (pela importação de CSV do painel ou por [`POST /v1/codes`](/docs/developers/api/create-codes)) e execute `qrdx batch` no CSV de resultados que a importação entrega, com `--value-column short_link`.

## Se algo der errado [#if-something-goes-wrong]

### `Invalid --body "…"` (ou `--eye`, `--dot`, `--frame`) [#invalid---body--or---eye---dot---frame]

O valor não é um dos nomes de padrão ou de moldura. A mensagem lista os aceitos; `qrdx --help` também os lista.

### A saída em PNG ou WebP falha, mas SVG funciona [#png-or-webp-output-fails-svg-works]

O sharp não está instalado para a sua plataforma. Reinstale o `@qrdx/cli` com acesso à rede para que o npm baixe a dependência opcional, ou gere SVG ou EPS.

### `--jobs` é recusado [#--jobs-is-refused]

Ele aceita um número de 1 a 64.

### Falta uma linha na pasta de saída [#a-row-is-missing-from-the-output-folder]

O conteúdo dela não pôde ser codificado (vazio ou longo demais para um QR code). Abra `errors.csv` na pasta de saída para ver a linha e o motivo.

## Use com um agente de código com IA [#use-it-from-an-ai-coding-agent]

A [skill `generate-qr`](https://github.com/qrdxinc/qrdx/tree/main/skills/generate-qr) do repositório ensina agentes como o Claude Code a chamar a CLI. Para agentes que oferecem suporte a MCP, o [servidor MCP](/docs/developers/mcp) não precisa de nenhuma instalação.
