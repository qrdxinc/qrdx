Ao final desta página, você terá um PNG de 1024 px em que um QR code fica dentro de uma imagem pintada, decodificado pelo QRdx antes de chegar até você. Você também vai saber como codificar um código dinâmico em vez de um texto fixo, qual modo escolher e o que significa cada erro.

`POST https://api.qrdx.dev/v1/art` pinta um QR code em uma arte de IA a partir de uma descrição e devolve a imagem. É a mesma [arte de QR com IA](/ai/art) da aba Art do Playground e do estúdio: {facts.artModel} pinta a imagem e, depois, o QRdx confere se ela leva ao seu conteúdo antes de entregá-la a você. Quando a imagem do modelo não é lida como foi desenhada, o QRdx reforça o código só o necessário, sobre os próprios pixels do modelo.

<Callout type="info" title="Chave de API e imagens mensais">
O endpoint precisa de uma [chave de API](/docs/developers/api-keys) com o escopo `codes:write` (chaves de **Acesso total** já o têm). Cada imagem usa uma das imagens de arte com IA mensais do workspace da chave, a mesma cota que o app usa; [Planos e limites](/docs/plans-and-limits) mostra os números de cada plano. Uma chamada que falha, ou cuja imagem não consegue ser lida, não usa nenhuma imagem.
</Callout>

## Antes de começar [#before-you-start]

- Uma chave de API com `codes:write`, exportada como `QRDX_API_KEY`.
- Um cliente HTTP com timeout de pelo menos 60 segundos. Uma chamada leva cerca de 15 a 45 segundos no modo code, 25 a 45 no modo photo e 40 a 55 no modo scene, que pinta a imagem primeiro.
- Para um código dinâmico, o `id` dele, obtido em [`GET /v1/codes`](/docs/developers/api/list-codes) ou na resposta que [o criou](/docs/developers/api/create-codes).

## 1. Pinte um código para um link [#1-paint-a-code-for-a-link]

<Tabs groupId="language" persist items={["curl", "JavaScript", "Python"]}>

    ```bash title="Terminal"
    curl https://api.qrdx.dev/v1/art \
      -H "Authorization: Bearer $QRDX_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"text": "https://qrdx.dev", "prompt": "a koi pond at dusk, ink and watercolor"}' \
      --max-time 90 -o art.json
    ```
  </Tab>
  <Tab value="JavaScript">
    ```js title="art.mjs"
    import { writeFile } from "node:fs/promises";

    const response = await fetch("https://api.qrdx.dev/v1/art", {
      method: "POST",
      headers: {
        Authorization: `Bearer ${process.env.QRDX_API_KEY}`,
        "Content-Type": "application/json",
      },
      body: JSON.stringify({
        text: "https://qrdx.dev",
        prompt: "a koi pond at dusk, ink and watercolor",
      }),
      signal: AbortSignal.timeout(90_000),
    });
    const { data, credits } = await response.json();
    // data.imageUrl is a data: URL; save the PNG bytes
    const base64 = data.imageUrl.split(",")[1];
    await writeFile("art.png", Buffer.from(base64, "base64"));
    console.log(data.text, data.blend, credits.remaining);
    ```
  </Tab>
  <Tab value="Python">
    ```python title="art.py"
    import base64
    import os
    import requests

    response = requests.post(
        "https://api.qrdx.dev/v1/art",
        headers={"Authorization": f"Bearer {os.environ['QRDX_API_KEY']}"},
        json={"text": "https://qrdx.dev", "prompt": "a koi pond at dusk, ink and watercolor"},
        timeout=90,
    )
    response.raise_for_status()
    body = response.json()
    png = base64.b64decode(body["data"]["imageUrl"].split(",", 1)[1])
    open("art.png", "wb").write(png)
    print(body["data"]["text"], body["data"]["blend"], body["credits"]["remaining"])
    ```

A resposta é um JSON com a imagem como uma URL `data:`:

```json title="200 OK (fields)"
{
  "data": {
    "imageUrl": "data:image/png;base64,iVBORw0KGgo…",
    "width": 1024,
    "height": 1024,
    "seed": 2841337190,
    "mode": "code",
    "blend": "least",
    "blendStrength": 0.35,
    "text": "https://qrdx.dev",
    "visibility": 50,
    "creativity": 45
  },
  "credits": { "plan": "pro", "limit": 30, "used": 7, "remaining": 23, "pooled": false, "resetsAt": "2026-12-01T00:00:00.000Z" }
}
```

- `imageUrl` é um PNG quadrado de 1024 px, como URL `data:`. O QRdx não guarda uma cópia, então salve a imagem.
- `text` é exatamente o que a imagem leva a ler. O QRdx decodificou esse conteúdo antes de responder.
- `blend` indica como a imagem foi ajustada para ser lida: `none` (a imagem do modelo como desenhada), `least` (os quadrados de posição, a zona de silêncio e os módulos reforçados só o necessário, sobre a imagem do modelo) ou `image-qr` (redesenhada como um QR code Image QR, o último recurso). `blendStrength` vai de `0` (como desenhada) a `1` (Image QR).
- `credits` é a cota do workspace depois desta imagem.

Para receber o PNG em si em vez de JSON, adicione `?format=png` ou envie `Accept: image/png`. Nesse caso, a seed, o modo, o blend e as imagens restantes chegam nos cabeçalhos `X-QRdx-Seed`, `X-QRdx-Mode`, `X-QRdx-Blend`, `X-QRdx-Blend-Strength` e `X-QRdx-Credits-Remaining`:

```bash title="Terminal"
curl "https://api.qrdx.dev/v1/art?format=png" \
  -H "Authorization: Bearer $QRDX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"text": "https://qrdx.dev", "prompt": "a lighthouse on a cliff, woodcut print"}' \
  --max-time 90 -o art.png
```

## 2. Codifique um código dinâmico [#encode]

Envie exatamente um entre `text` e `code`:

- `text`: o link ou texto que o código contém, com até 300 caracteres. A arte é uma imagem, então o conteúdo não pode mudar depois de impressa.
- `code`: o `id` de um dos [QR codes dinâmicos](/docs/dynamic-qr-codes) do workspace. A arte codifica o link curto do código, então você pode mudar o destino depois de imprimir, e as leituras aparecem nas análises. Um código de outro workspace, ou um que esteja na lixeira, resulta em `404`.

```bash title="Terminal"
curl https://api.qrdx.dev/v1/art \
  -H "Authorization: Bearer $QRDX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"code": "cm5code0spring0menu00001", "prompt": "a bistro chalkboard menu on a brick wall", "mode": "scene"}' \
  --max-time 90 -o art.json
```

A resposta então também traz `"code": { "id", "shortLink" }`, e `text` é o link curto.

## 3. Escolha um modo e um visual [#modes]

| `mode` | O que você recebe |
| --- | --- |
| `code` (padrão) | O código é a imagem inteira: sua arte pintada nos módulos, com quadrados de posição simples e uma zona de silêncio clara ao redor. É o que lê com mais confiabilidade |
| `scene` | Primeiro uma imagem é pintada a partir da descrição, depois o código é pintado no meio dela, de modo que a imagem chega até o código e passa por ele, com os módulos feitos das cores e da luz da imagem |
| `photo` | O mesmo, usando sua própria `photo` como imagem: ela mantém o assunto, as cores e a luz ao redor e através do código. Envie a foto somente com este modo |

### Visuais rápidos [#quick-looks]

Um visual rápido é um estilo pronto, como uma técnica ou um clima, que o QRdx acrescenta ao seu `prompt`: `"a koi pond in the rain"` com `"style": "watercolor"` pinta o lago de carpas como uma aquarela. Envie o id dele como `style`; qualquer outro valor resulta em `400 VALIDATION_ERROR`. Os visuais são os oferecidos como chips no [estúdio de arte com IA](/ai/art) e na aba Art do Playground, e funcionam em todos os modos.

| `style` | Visual |
| --- | --- |
| `watercolor` | Aquarela |
| `oil-painting` | Pintura a óleo |
| `anime` | Anime |
| `cartoon` | Desenho animado |
| `pixel-art` | Pixel art |
| `pop-art` | Pop art |
| `charcoal` | Carvão |
| `ink` | Nanquim |
| `cyberpunk` | Cyberpunk |
| `fantasy` | Fantasia |
| `photographic` | Fotográfico |
| `low-poly` | Low poly |
| `papercut` | Recorte de papel |

`prompt` é opcional. Se você não enviar, o QRdx primeiro escreve um para o `mode`, o `style` e a `photo` que você enviou: uma cena concreta com um assunto, um cenário e a luz, ou, no modo photo, uma descrição do que há na sua foto para que a arte a preserve. Escrever o prompt não usa nenhuma imagem de arte com IA extra. A resposta então inclui o que foi escrito como `writtenPrompt`, para você poder enviá-lo de novo, editado, da próxima vez. Se a escrita falhar, você recebe `502 AI_ART_DESCRIBE_FAILED` e nenhuma imagem é usada.

## Campos da requisição [#request-fields]

| Campo | Padrão | Descrição |
| --- | --- | --- |
| `text` | | O que o código codifica, com até 300 caracteres. Envie este ou `code` |
| `code` | | O `id` de um código dinâmico, no lugar de `text` |
| `prompt` | escrito para você | A arte a pintar, em palavras simples, com pelo menos 3 caracteres quando enviado |
| `mode` | `code` | `code`, `scene` ou `photo`; veja acima |
| `style` | | O id de um visual rápido, combinado com o seu prompt |
| `negativePrompt` | | O que deve ficar fora da imagem |
| `visibility` | `50` | Visibilidade do QR, de `0` a `100`: quanto maior, mais nítido fica o código; quanto menor, mais a imagem é favorecida |
| `creativity` | `45` | `0` segue o prompt ao pé da letra, `100` o interpreta livremente |
| `seed` | aleatória | Envie uma seed de uma resposta anterior para obter uma imagem parecida |
| `reference` | | Uma imagem de referência para cores e formas, como um logo ou uma paleta |
| `photo` | | Somente no modo photo: a imagem em que o código será pintado |

`reference` e `photo` são URLs `data:` de PNG ou JPEG (`data:image/jpeg;base64,…`). Reduza uma `reference` para cerca de 512 px no lado mais longo (no máximo 600 KB) e recorte uma `photo` em formato quadrado, com cerca de 1024 px (no máximo 1 MB), o tamanho em que a arte é feita. Elas vão para o modelo e são descartadas: o QRdx nunca as armazena nem as registra em log. Imagens maiores são recusadas com `413 AI_ART_IMAGE_TOO_LARGE`. A [página de referência](/docs/developers/api/create-art) tem o esquema completo e um painel Try it.

## Créditos e limites [#credits-and-limits]

A API usa as mesmas imagens de arte com IA mensais do app, contadas para o workspace ao qual a chave pertence. Os planos Grátis, Pro e Business incluem, cada um, um número de imagens por mês, e o Business as compartilha entre toda a equipe; [Planos e limites](/docs/plans-and-limits) tem os números. Elas são renovadas no dia 1º de cada mês (UTC).

- Quando as imagens do mês acabam, a API responde `AI_ART_CREDITS_EXHAUSTED`: `402` nos planos Grátis e Pro, em que um upgrade adiciona mais, e `429` no Business.
- Cada pessoa pode gerar no máximo 25 imagens por dia, além da cota mensal (`429 AI_ART_DAILY_LIMIT`), e iniciar até 12 imagens por minuto.
- Cada chamada também conta para a cota diária de API do workspace e para o limite por minuto de gravações ([Limites de taxa](/docs/developers/rest-api#rate-limits)).

## Se algo der errado [#if-something-goes-wrong]

Os erros seguem o formato usual da API (`code`, `message`, `status`); [Erros](/docs/developers/errors) lista todos. Nenhum dos erros `5xx` usa uma imagem.

| Status | `code` | O que fazer |
| --- | --- | --- |
| 400 | `AI_ART_TEXT_TOO_LONG` | Encurte `text` ou envie o `code` de um código dinâmico |
| 402 | `AI_ART_CREDITS_EXHAUSTED` | Espere até o dia 1º do mês ou faça upgrade |
| 413 | `AI_ART_IMAGE_TOO_LARGE` | Reduza o tamanho de `photo` ou `reference` |
| 429 | `AI_ART_CREDITS_EXHAUSTED` | Business: espere até o dia 1º do mês |
| 429 | `AI_ART_DAILY_LIMIT` | Tente de novo amanhã (UTC) |
| 502 | `AI_ART_FAILED` | O modelo falhou ou recusou o prompt. Tente de novo ou reescreva o prompt |
| 502 | `AI_ART_UNSCANNABLE` | Tente de novo com um `visibility` maior ou outra seed |
| 502 | `AI_ART_DESCRIBE_FAILED` | Nenhum `prompt` foi enviado e a geração de um falhou. Tente de novo ou envie o seu |
| 503 | `AI_ART_BUSY` | O modelo está ocupado. Espere um minuto e tente de novo |
| 503 | `AI_NOT_CONFIGURED` | A arte com IA não está configurada neste servidor (auto-hospedado) |
| 504 | `AI_ART_TIMEOUT` | O modelo demorou demais (no modo cena, a imagem deixou pouco tempo para pintar o código). Tente de novo ou use o modo código |

Uma instância auto-hospedada sem o Vercel AI Gateway responde a toda chamada com:

```json title="503 Service Unavailable"
{"code":"AI_NOT_CONFIGURED","message":"AI QR art is not configured on this server","status":503}
```

## MCP [#mcp]

Com uma chave de API do QRdx na conexão, o [servidor MCP](/docs/developers/mcp) tem uma ferramenta `generate_ai_art`. Ela recebe os mesmos campos do corpo da requisição e retorna o PNG, para onde ele aponta na leitura e quantas imagens restam neste mês. Peça ao seu assistente com palavras simples:

```txt title="Prompt"
Make AI QR art for my code cm5code0spring0menu00001: a bistro chalkboard menu on a brick wall, as a scene.
```

Sem uma chave, a ferramenta responde explicando como adicionar uma. A chamada leva até um minuto, como na REST API.

## Auto-hospedagem [#self-hosting]

A arte com IA roda pelo Vercel AI Gateway. Na sua própria instância, defina `AI_GATEWAY_API_KEY`; sem ela, `POST /v1/art` e `generate_ai_art` respondem `503 AI_NOT_CONFIGURED`.
