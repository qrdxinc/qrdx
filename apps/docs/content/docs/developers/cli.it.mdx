Alla fine di questa pagina avrai creato dal terminale dei file di QR code con gli stessi stili del Playground, e una cartella di codici generati da un CSV con un solo comando, senza caricare nulla da nessuna parte.

`@qrdx/cli` genera dalla riga di comando gli stessi QR code del Playground e della [libreria `qrdx`](/docs/getting-started). Negli script e nella CI non fa mai domande; se esegui `qrdx generate` senza argomenti in un terminale, ti chiede il contenuto e le opzioni passo dopo passo.

## Prima di iniziare [#before-you-start]

- Node.js 22 o successivo.
- L'output PNG e WebP usa [sharp](https://sharp.pixelplumbing.com), una dipendenza opzionale che npm installa dove la tua piattaforma la supporta; SVG ed EPS funzionano anche senza.
- Il pacchetto npm `qrdx` è la libreria React. La CLI è solo in `@qrdx/cli`.

## 1. Crea un codice [#1-make-one-code]

Eseguilo una volta con `npx`, oppure installalo globalmente per avere il comando `qrdx`:

```bash title="Terminal"
npx @qrdx/cli generate "https://example.com" -o qr.svg

npm install -g @qrdx/cli
qrdx generate "https://example.com" -o qr.png --size 1024
```

```txt title="Output"
◇  ✔  Saved to qr.png (1024×1024)
└  Done!
```

L'estensione del file determina il formato; in alternativa usa `--format` quando il nome del file non ha estensione.

| Formato | Quando usarlo | Significato di `--size` |
| --- | --- | --- |
| `.svg` | Pagine web, strumenti di design, ridimensionamento senza perdite | Larghezza in pixel (predefinito 512) |
| `.png` | Documenti, presentazioni, ovunque serva un'immagine | Larghezza in pixel |
| `.webp` | Siti web: i pixel del PNG, senza perdita, in un file più piccolo | Larghezza in pixel |
| `.eps` | Tipografie, Illustrator, InDesign | Larghezza in punti (72 per pollice, quindi `144` sono 2 pollici) |

I file EPS sono PostScript vettoriale. I loghi PNG e JPEG vengono incorporati così come sono; gli altri formati di logo vengono convertiti con sharp se è installato, altrimenti vengono omessi con un avviso.

## 2. Dagli uno stile [#2-style-it]

```bash title="Terminal"
# High-resolution PNG for print
qrdx generate "https://example.com" -o print.png --size 2048 --level H

# Vector EPS, 2 inches wide, for a print shop
qrdx generate "https://example.com" -o qr.eps --size 144

# Branded colors and patterns
qrdx generate "https://example.com" --body circle --eye rounded --fg "#1a1a2e" -o brand.svg

# Gradient foreground
qrdx generate "https://example.com" -o gradient.svg \
  --fg '{"type":"linear","stops":[{"color":"#6366f1","offset":0},{"color":"#ec4899","offset":100}],"angle":135}'

# "Scan for the menu" frame
qrdx generate "https://example.com/menu" --frame banner-bottom --frame-text "Scan for the menu" -o menu.png

# Wi-Fi network
qrdx generate "WIFI:T:WPA;S:MyNetwork;P:MyPassword;;" -o wifi.svg
```

```txt title="Output of the frame example"
◇  ✔  Saved to menu.png (635×727)
```

Con una cornice, `--size` è la larghezza del codice e la cornice si aggiunge all'immagine. Per stampare un [QR code dinamico](/docs/dynamic-qr-codes), passa come dato il suo link breve (`https://qrdx.dev/q/<slug>`).

| Flag | Predefinito | Descrizione |
| --- | --- | --- |
| `-o`, `--output` | `qr.svg` | File di output |
| `--format` | dall'estensione | `svg`, `png`, `webp` o `eps` |
| `--size` | `512` | Dimensione dell'output (vedi sopra) |
| `-l`, `--level` | `Q` | Correzione degli errori: `L`, `M`, `Q` o `H` |
| `--body` | `square` | [Pattern](/docs/features/patterns) dei moduli dati |
| `--eye` | `square` | Pattern dell'occhio d'angolo |
| `--dot` | `square` | Pattern del punto dell'occhio d'angolo |
| `--fg`, `--bg` | `#000000`, `#ffffff` | Primo piano e sfondo: un colore esadecimale o un gradiente JSON (`linear`, `radial` o `angular`) |
| `--eye-color`, `--dot-color` | `--fg` | Colori dell'occhio d'angolo e del suo punto |
| `--logo` | | URL dell'immagine del logo al centro (da usare con `--level H`) |
| `--no-logo` | | Salta la richiesta del logo in modalità interattiva |
| `--margin` | `0` | Zona di silenzio, in moduli |
| `--template` | | Una cornice disegnata come template: `Arrow`, `StandardBox`, `SquareBorder`, `StrikedBox`, `Halloween` o `DotRing` |
| `--frame` | | [Cornice](/docs/features/frames) con invito all'azione: una qualsiasi delle {facts.frameStyles} cornici integrate, come `banner-bottom`, `rounded-border`, `circle`, `sticker` o `phone` (vedi [tutte](/docs/styles#frames)) |
| `--frame-text` | `Scan me` | Etichetta della cornice, fino a 24 caratteri; `""` la nasconde |
| `--frame-color`, `--frame-text-color` | | Colori della cornice e dell'etichetta (esadecimale) |

`qrdx --help` elenca tutti i nomi dei pattern. Un valore non valido termina con codice `1` ed elenca quelli accettati:

```txt title="qrdx generate https://example.com --body nope -o bad.svg"
✗ Invalid --body "nope". Expected one of: circle, circle-large, square, diamond, circle-mixed, pacman, rounded, small-square, vertical-line, horizontal-line, liquid, liquid-horizontal, liquid-vertical, classy, classy-rounded, leaf, plus, hexagon, star, heart, random-dots, mosaic, octagon
```

## 3. Crea molti codici da un CSV [#3-make-many-codes-from-a-csv]

`qrdx batch` scrive in una cartella un QR code statico per ogni riga di un file CSV:

```csv title="products.csv"
sku,url
A-100,https://example.com/products/a-100
A-101,https://example.com/products/a-101
```

```bash title="Terminal"
qrdx batch products.csv -o codes --format png --size 1024 --body circle
```

```txt title="Output"
2 rows · 2 saved
✔  Saved 2 PNG codes to codes in 0.2 s
```

La cartella contiene `A-100.png` e `A-101.png`. Legge le stesse colonne del [generatore in blocco](/tools/bulk): il contenuto da una colonna chiamata `value`, `url`, `link`, `data`, `content`, `text` o `qr` (altrimenti la prima colonna), e i nomi dei file da una colonna chiamata `file name`, `name`, `label`, `id`, `title` o `sku` (altrimenti `qr-00001`, `qr-00002` e così via). Puoi sceglierne altre per nome dell'intestazione o per numero di colonna:

| Flag | Predefinito | Descrizione |
| --- | --- | --- |
| `-o`, `--out` | `qr-codes` | Cartella per i codici |
| `--format` | `svg` | `svg`, `png` o `eps` |
| `--value-column` | dedotta | Colonna con il contenuto di ogni codice |
| `--name-column` | dedotta | Colonna con i nomi dei file |
| `--no-header` | | La prima riga è un codice, non i nomi delle colonne |
| `--jobs` | `4` per SVG, `8` negli altri casi | Codici generati contemporaneamente, da 1 a 64 |

Tutte le opzioni di stile viste sopra si applicano a tutti i codici. Il CSV viene letto come flusso e ogni codice viene salvato appena creato, quindi il comando non ha limiti di righe: su un portatile, 10.000 codici SVG hanno richiesto circa 40 secondi e meno di 200 MB di memoria. Non viene caricato nulla e non serve alcun account. Le righe che non possono essere codificate vengono saltate ed elencate con il motivo in `errors.csv` nella cartella di output.

Per stampare in blocco [codici dinamici](/docs/dynamic-qr-codes), creali prima (con l'importazione CSV della dashboard o con [`POST /v1/codes`](/docs/developers/api/create-codes)) ed esegui `qrdx batch` sul CSV dei risultati che l'importazione ti fornisce, con `--value-column short_link`.

## Se qualcosa va storto [#if-something-goes-wrong]

### `Invalid --body "…"` (o `--eye`, `--dot`, `--frame`) [#invalid---body--or---eye---dot---frame]

Il valore non è uno dei nomi di pattern o cornici. Il messaggio elenca quelli accettati; li elenca anche `qrdx --help`.

### L'output PNG o WebP non riesce, SVG funziona [#png-or-webp-output-fails-svg-works]

sharp non è installato per la tua piattaforma. Reinstalla `@qrdx/cli` con accesso alla rete così che npm possa scaricare la dipendenza opzionale, oppure genera SVG o EPS.

### `--jobs` viene rifiutato [#--jobs-is-refused]

Accetta un numero da 1 a 64.

### Una riga manca nella cartella di output [#a-row-is-missing-from-the-output-folder]

Il suo contenuto non è stato codificabile (vuoto, o troppo lungo per un QR code). Apri `errors.csv` nella cartella di output per vedere la riga e il motivo.

## Usalo da un agente di programmazione AI [#use-it-from-an-ai-coding-agent]

La [skill `generate-qr`](https://github.com/qrdxinc/qrdx/tree/main/skills/generate-qr) del repository insegna ad agenti come Claude Code a chiamare la CLI. Per gli agenti che supportano MCP, il [server MCP](/docs/developers/mcp) non richiede alcuna installazione.
