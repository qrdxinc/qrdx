QRdx एक shadcn/ui रजिस्ट्री पब्लिश करता है, जिसमें `qrdx` लाइब्रेरी पर बने QR code कंपोनेंट हैं। shadcn CLI हर कंपोनेंट का सोर्स आपके प्रोजेक्ट में कॉपी कर देता है, इसलिए कोड आपका अपना होता है और आप उसे बदल सकते हैं। जब आपको तैयार UI चाहिए, जैसे डाउनलोड बटन, कार्ड, शेयर डायलॉग या स्कैनर, तब रजिस्ट्री का इस्तेमाल करें। अगर आपको सिर्फ़ कोड चाहिए, तो लाइब्रेरी का अपना `QRCode` इस्तेमाल करें।

<NpmStatus package="qrdx" />

<PackageManagerTabs command="npx shadcn@latest add https://qrdx.dev/r/qr-code.json" />

हर कंपोनेंट का अपना पेज है, जिसमें लाइव प्रीव्यू, सोर्स, इंस्टॉलेशन के स्टेप, उदाहरण और props की टेबल मिलती है। क्या आपने [Playground](/playground?open=code&lang=shadcn) में कोई कोड स्टाइल किया है? रजिस्ट्री के QR Code कंपोनेंट के लिए उसे वहीं से कॉपी करें।

## क्या इंस्टॉल होता है [#what-gets-installed]

हर कंपोनेंट आपके `components` फ़ोल्डर में एक अकेली फ़ाइल होती है। CLI `qrdx` भी इंस्टॉल करता है (साथ में `lucide-react`, जो ज़्यादातर कंपोनेंट के आइकन के लिए इस्तेमाल होता है) और वे shadcn/ui कंपोनेंट जोड़ता है जिन पर कंपोनेंट बना है, जैसे `button`, `card`, `dialog`, `dropdown-menu`, `input` या `label`। हर कंपोनेंट पेज पर इंस्टॉलेशन टैब में **Manual** के नीचे उसकी अपनी dependencies दी गई हैं।

पूरा इंडेक्स [`https://qrdx.dev/r/registry.json`](https://qrdx.dev/r/registry.json) पर है, और हर आइटम `https://qrdx.dev/r/<name>.json` पर।

## नाम से इंस्टॉल करें [#install-by-name]

छोटे नाम से इंस्टॉल करने के लिए, रजिस्ट्री को अपनी `components.json` में जोड़ें:

```json title="components.json"
{
  "registries": {
    "@qrdx": "https://qrdx.dev/r/{name}.json"
  }
}
```

फिर एक या कई कंपोनेंट नाम से जोड़ें:

<PackageManagerTabs command="npx shadcn@latest add @qrdx/qr-code @qrdx/qr-code-download @qrdx/qr-code-share-dialog" />

## स्टाइलिंग और थीमिंग [#styling-and-theming]

कंपोनेंट Tailwind क्लास और shadcn/ui के स्टैंडर्ड थीम टोकन (`bg-card`, `border`, `text-muted-foreground`, `ring-ring`) के साथ आपके अपने Button, Card, Dialog और Input इस्तेमाल करते हैं, इसलिए वे आपकी थीम और डार्क मोड को फ़ॉलो करते हैं। QR code में डिफ़ॉल्ट रूप से हल्का बैकग्राउंड रहता है, क्योंकि हल्की टाइल पर गहरे मॉड्यूल हर रीडर से स्कैन हो जाते हैं। थीम को फ़ॉलो करवाने का तरीका [QR Code](/docs/components/qr-code#dark-mode) पेज पर बताया गया है।

हर कंपोनेंट एक Client Component है (उसकी फ़ाइल `"use client"` से शुरू होती है), क्योंकि उसमें बटन और state हैं। फिर भी कोड सर्वर पर ही रेंडर होता है, इसलिए बटन इंटरैक्टिव होने से पहले ही वह पेज के HTML में मौजूद होता है। Server Component पेज इनमें से कोई भी इम्पोर्ट कर सकता है और सर्वर का डेटा props के रूप में दे सकता है।

PDF डाउनलोड के लिए वैकल्पिक `jspdf` पैकेज चाहिए (`npm install jspdf`)। बाकी सब कुछ CLI के खत्म होते ही काम करता है।
