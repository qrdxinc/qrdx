Alla fine di questa pagina il tuo assistente AI sarà in grado di creare QR code: ne progetterà uno per qualsiasi contenuto con un punteggio di scansione verificato, lo genererà negli stili dell'editor, costruirà il payload giusto per Wi-Fi, contatti, email, SMS, posizioni e pagamenti bancari, troverà i frame della community e disegnerà codici a barre. Con una chiave API sulla connessione potrà anche salvare design e codici a barre nel tuo workspace e creare arte con l'AI.

QRdx gestisce un server pubblico [Model Context Protocol](https://modelcontextprotocol.io) all'indirizzo:

```txt title="Server URL"
https://mcp.qrdx.dev/mcp
```

Usa il trasporto Streamable HTTP, non mantiene lo stato della sessione e non richiede account, accesso né chiave API. Lo stesso server risponde anche su `https://qrdx.dev/api/mcp`, e la [pagina di connessione](/mcp) ha pulsanti con un clic e istruzioni per più client di quelli mostrati in questa pagina.

[Provalo nel playground](/playground?open=code&lang=mcp): dai uno stile a un codice, poi copialo come argomenti di `design_qr` per il tuo assistente.

## 2. Chiedi un codice [#2-ask-for-a-code]

Poi chiedi a parole tue. Questi prompt funzionano così come sono:

```txt title="Prompts"
Make a QR code for https://example.com in our brand blue, #155dfc, with rounded modules.
Create a Wi-Fi QR code for the network Office Guest with password correct-horse-battery.
Design a Wi-Fi QR code for Cafe Guest in warm browns with a Free Wi-Fi banner, and tell me its scan score.
Generate a contact QR code for Ada Lovelace, ada@example.com, and add it to the README.
Find a community frame for a restaurant menu and use it for https://example.com/menu.
Draw an EAN-13 barcode for 590123412345 as a PNG.
```

Per il primo prompt, l'assistente chiama `generate_qr_code` e ottiene il PNG e queste righe, pronte da incollare:

```txt title="generate_qr_code result"
QR code, 512x512px, error correction Q.
SVG URL: https://api.qrdx.dev/v1/qr?data=https%3A%2F%2Fexample.com&fg=155dfc&body=rounded
PNG URL: https://api.qrdx.dev/v1/qr?data=https%3A%2F%2Fexample.com&format=png&fg=155dfc&body=rounded
WebP URL (lossless, smaller than PNG): https://api.qrdx.dev/v1/qr?data=https%3A%2F%2Fexample.com&format=webp&fg=155dfc&body=rounded
EPS URL (vector, for print; 512 pt wide): https://api.qrdx.dev/v1/qr?data=https%3A%2F%2Fexample.com&format=eps&fg=155dfc&body=rounded
Markdown: ![QR code](https://api.qrdx.dev/v1/qr?data=https%3A%2F%2Fexample.com&fg=155dfc&body=rounded)
```

Per il secondo, chiama `qr_payload_wifi`, che restituisce `WIFI:T:WPA;S:Office Guest;P:correct-horse-battery;;`, e passa quella stringa come `data` a `generate_qr_code` o come contenuto di `design_qr`.

## Strumenti [#tools]

| Strumento | Cosa fa |
| --- | --- |
| `design_qr` | Progetta un codice per qualsiasi tipo di contenuto con lo stile scelto dal tuo assistente, oppure partendo da un tema integrato o da un elemento della community, controlla il punteggio di scansione e ripara lo stile finché non è Ottimo. Restituisce il punteggio, cosa ha cambiato, il JSON dello stile, un link al playground, un PNG e l'SVG |
| `list_options` | Elenca ogni valore accettato da `design_qr`: tipi di contenuto e relativi campi, colori e sfumature, forme, cornici (con gli id delle cornici ufficiali di QRdx), bordi, icone logo e loghi di brand, temi integrati, livelli di correzione degli errori e limiti |
| `generate_qr_code` | Genera un QR code con gli stili dell'editor. Restituisce un'immagine PNG e URL pubblici della [image API](/docs/developers/image-api) (SVG, PNG, WebP lossless ed EPS vettoriale) pronti per Markdown, HTML o stampa, più il markup SVG su richiesta |
| `list_qr_styles` | Elenca i pattern del corpo, le forme di occhi d'angolo e punti dell'occhio, le cornici (gli stili integrati e quelli disegnati come modelli), le icone logo, i livelli di correzione degli errori, i valori predefiniti e i limiti |
| `search_community` | Trova cornici, temi e raccolte pubblicati nella [community](/community) per parole, tipo o tag |
| `get_community_item` | Un elemento della community con lo stile che applica, pronto per `design_qr` o `generate_qr_code` |
| `save_template` | Salva un design come tema nel tuo workspace. Richiede una [chiave API](#use-an-api-key) |
| `generate_barcode` | Disegna un codice a barre EAN-13, UPC-A, UPC-E, EAN-8, ITF-14, GS1-128, Code 128, Code 39, Data Matrix, PDF417 o Aztec dopo aver controllato il valore (cifre di controllo, lunghezze, caratteri). Restituisce un PNG e URL pubblici della [barcode API](/docs/developers/barcode-api) |
| `save_barcode` | Salva un codice a barre nei Codici a barre del tuo workspace. Richiede una [chiave API](#use-an-api-key) |
| `generate_ai_art` | Dipinge un QR code dentro un'opera d'arte IA e verifica che si possa scansionare. Usa una delle immagini d'arte IA mensili del workspace e richiede fino a un minuto. Richiede una [chiave API](#use-an-api-key). Vedi [AI art API](/docs/developers/ai-art-api) |
| `qr_payload_wifi` | Costruisce un payload di rete `WIFI:` (WPA, WEP o aperta, eventualmente nascosta) con i caratteri speciali sottoposti a escape |
| `qr_payload_vcard` | Costruisce un contatto vCard 3.0 (RFC 2426): nome, organizzazione, titolo, telefoni, email, sito web, indirizzo e nota |
| `qr_payload_email` | Costruisce un link `mailto:` (RFC 6068) con cc, bcc, oggetto e corpo facoltativi |
| `qr_payload_sms` | Costruisce un link `sms:` (RFC 5724) con un messaggio facoltativo, oppure la vecchia forma `SMSTO:` |
| `qr_payload_geo` | Costruisce una posizione `geo:` (RFC 5870) da latitudine e longitudine |
| `qr_payload_payment` | Costruisce un codice di pagamento bancario: un BR Code Pix, un bonifico SEPA (EPC069-12), oppure un codice PayNow, PromptPay o VietQR (EMV, con il relativo CRC). Controlla i campi come fanno i moduli del playground |

Gli strumenti payload restituiscono una semplice stringa. Il tuo assistente la passa poi come `data` a `generate_qr_code`.

### design_qr [#design_qr]

`design_qr` riceve il contenuto come tipo e relativi campi, con gli stessi tipi e controlli dei moduli di contenuto dell'editor (`list_options` li elenca), e uno stile facoltativo:

```json title="design_qr arguments"
{
  "content": { "type": "wifi", "ssid": "Cafe Guest", "password": "sunshine123", "encryption": "WPA" },
  "style": {
    "bgColor": "#FFF7ED",
    "fgColor": "#9A3412",
    "bodyPattern": "rounded",
    "cornerEyePattern": "rounded",
    "frame": { "style": "banner-bottom", "text": "Free Wi-Fi" }
  }
}
```

```txt title="design_qr result (first lines)"
Scan score 85/100 (great). No changes were needed. Content: WiFi · Cafe Guest (47 bytes). Open it in the playground: https://qrdx.dev/playground?style=1.eyJiIjoiI0ZGRjdFRCIs…&ref=mcp
```

Il JSON del risultato contiene `payload` (la stringa esatta codificata dal codice), `style`, `qrdxStyle`, `score`, `grade`, `stillFailing` (i controlli ancora falliti, ciascuno con una correzione), `repairs`, `changes` e `playgroundUrl`, seguiti dal PNG e dall'SVG.

Le opzioni che ometti ricevono valori predefiniti (gli occhi seguono il colore dei punti, forme quadrate, margine 4, correzione degli errori Q, nessuna cornice). QRdx esegue poi sul design il controllo di scansione dell'editor: genera il codice, lo decodifica a 96, 160 e 320 px con un modello di fotocamera di telefono e verifica contrasto, zona di quiete, forme degli occhi e coppie di forme. Sotto Ottimo (85), ripara lo stile, fino a tre volte, cambiando il minimo possibile (colori più scuri che mantengono la tinta, una forma dell'occhio più sicura, meno correzione degli errori per contenuti lunghi). Se non basta, ripiega su un classico codice nero su bianco con la tua cornice. Il risultato indica cosa è stato cambiato e perché.

Per `design_qr` non gira alcun modello IA lato QRdx: il tuo assistente sceglie lo stile, QRdx lo convalida, lo controlla e lo ripara. I contenuti non validi (una password WPA di meno di 8 caratteri, un indirizzo email malformato) vengono rifiutati con il motivo. `design_qr` ha un proprio limite di {facts.designQrPerMinute} chiamate al minuto per indirizzo IP.

Altri input:

- **`preset`**: parti da un tema integrato tramite id (`list_options` li elenca). Le opzioni di stile che imposti hanno la precedenza.
- **`community_item`**: parti da una cornice o un tema della community tramite id, come `frame:wifi-card`. Un elemento cornice si appoggia a un codice classico; le tue opzioni di stile cambiano il codice sottostante. Anche le cornici ufficiali di QRdx sono elementi della community, quindi qui funzionano `frame:diwali-diya` o `frame:menu-cutlery`.
- **Una cornice personalizzata**: `style.frame` può essere `{ "style": "custom", "spec": … }` con una specifica di cornice, come quella di una cornice della community ottenuta da `get_community_item`. Viene disegnata e valutata così com'è; le riparazioni cambiano il codice, mai la cornice.
- **`style.logo`**: una rapida icona logo (`wifi`, `location`, `phone`, `email`, `link`, `file`, `calendar`, `whatsapp` o `instagram`), oppure un logo di brand tramite il suo slug di [Simple Icons](https://simpleicons.org) (`spotify`, `paypal:white`). `list_options` elenca gli slug dei brand più diffusi.
- **Opzioni del motore**: `style.eyeColors` (colori `#RRGGBB` per ogni occhio), `moduleScale` (dimensione dei punti, da `0.5` a `1`), `shape` (`circle` per un codice rotondo), `autoLevel` e `logoOptions` (dimensione, spazio libero, posizione, ritaglio e sfondo del logo). Vengono disegnate e valutate come indicate; le riparazioni non le modificano.

<IfAvailable feature="fileStorage">
`logo_file_id` disegna invece un logo che hai caricato su QRdx, con una [chiave API](#use-an-api-key).
</IfAvailable>

I loghi sono valutati in base ai moduli che coprono, come nell'editor, quindi una riparazione può portare la correzione degli errori a H o rimuovere il logo. Il marchio QRdx che l'editor mostra per impostazione predefinita qui non viene disegnato.

Il `qrdxStyle` del risultato è il design sotto forma di JSON di stile dell'editor. Passalo a `save_template`, a `generate_qr_code` come `style` per generare lo stesso design a un'altra dimensione, oppure allo [`style`](/docs/developers/image-api#style) della image API. `playground_url` apre il design nel [playground](/playground): contiene solo lo stile, mai il logo né il contenuto, e `playgroundLeftOut` indica cosa lascia fuori.

### generate_qr_code [#generate_qr_code]

Gli input corrispondono ai [parametri della image API](/docs/developers/image-api#parameters): `data` (obbligatorio), `size`, `fg`, `bg`, `eyeColor`, `dotColor`, `body`, `eye`, `dot`, `level`, `margin`, `template`, `frame`, `frameText`, `logoIcon`, `logoFileId`, `item` (un id di elemento della community) e `style` (il JSON di stile dell'editor: sfumature, cornici personalizzate e il resto, come lo restituisce `design_qr`). Le opzioni singole hanno la precedenza su `style`, e `style` ha la precedenza su `item`. Imposta `include_svg` su `true` per ottenere anche il markup SVG come testo, per esempio per salvare un file `.svg`. È disattivato per impostazione predefinita perché il markup pesa spesso da 50 a 150 KB, e riempirebbe la conversazione.

`generate_qr_code` non controlla il punteggio di scansione; per quello usa `design_qr`. Un codice con il tuo logo caricato non ha un URL di immagine pubblico, perché la image API disegna quel logo solo per le richieste con la tua chiave.

### La scheda QR [#qr-card]

Nelle app che supportano [MCP Apps](https://modelcontextprotocol.io/extensions/apps/overview), `design_qr` e `generate_qr_code` mostrano anche una scheda QR nella chat. Contiene il codice, ciò che codifica (un codice Wi-Fi mostra il nome della rete, mai la password), la dimensione e la correzione degli errori o il punteggio di scansione, e un pulsante **Apri nell'editor**. Il link all'editor contiene solo lo stile, come `playground_url`.

I pulsanti PNG e SVG dipendono da ciò che consente l'app. Dove può salvare file da una scheda, li salvano. Altrimenti aprono nel browser l'URL della image API, quindi la scheda di `design_qr` li mostra solo nelle app che salvano file: il suo contenuto non finisce mai in un URL di immagine. Le app possono chiederti di confermare prima di aprire un link.

Le app senza MCP Apps ricevono lo stesso testo e la stessa immagine di prima. Per gli sviluppatori di client:

- La scheda è la risorsa `ui://qrdx/qr-card` (`text/html;profile=mcp-app`), elencata da `resources/list`. Entrambi gli strumenti puntano ad essa con `_meta.ui.resourceUri`.
- I suoi dati arrivano nel `_meta` del risultato dello strumento, sotto `dev.qrdx/qr-card`, pensato per la scheda e non per il modello. Gli strumenti non restituiscono `structuredContent`.
- La scheda è un singolo file HTML con stili e script inline. L'unica cosa che carica è l'immagine del codice dalla image API (`https://api.qrdx.dev`, o il tuo dominio se self-hosted), e la sua content security policy (`_meta.ui.csp.resourceDomains`) consente quell'host e nient'altro.

Se hai collegato QRdx prima che la scheda esistesse, rimuovi il connettore e aggiungilo di nuovo, oppure aggiorna i suoi strumenti, così l'app recupera i nuovi metadati degli strumenti.

### Community [#community]

`search_community` trova cornici, temi e raccolte pubblicati nella [community](/community), gratuiti con licenza CC0, per parole (`q`), `type` e `tag`. `get_community_item` restituisce un elemento con lo stile che applica; passa il suo id a `design_qr` come `community_item` o a `generate_qr_code` come `item`. Gli stessi dati sono disponibili nella REST API su [`/v1/community/items`](/docs/developers/api/list-community-items).

I testi degli elementi sono scritti dai membri della community. Nomi, descrizioni, handle, tag ed etichette delle cornici vengono restituiti brevi, su una sola riga e senza link, email o markup, e ogni risultato indica di trattarli come dati, non come istruzioni.

## Usare una chiave API [#use-an-api-key]

Alcuni strumenti richiedono una [chiave API](/docs/developers/api-keys) di QRdx sulla connessione, inviata come `Authorization: Bearer qrdx_…`:

- **`save_template`** salva un design come tema, elencato in Temi nella dashboard e proposto nell'editor. Richiede una chiave con `codes:write`, che hanno le chiavi con **Accesso completo**. Una chiave del tuo workspace salva nei tuoi temi; una chiave del team salva nei temi condivisi del team quando chi l'ha creata è proprietario o amministratore e il piano include i temi del team. I salvataggi contano per il limite di temi salvati del piano (vedi [Piani e limiti](/docs/plans-and-limits)); oltre il limite, lo strumento restituisce l'errore `LIMIT_REACHED` (`402`) dell'API.
- **`save_barcode`** salva un codice a barre (formato, valore, un titolo facoltativo e le opzioni di disegno) nel workspace della chiave, elencato in Codici a barre nella dashboard. Richiede una chiave con `codes:write`. Tutti i piani possono salvare codici a barre, fino a 1.000 nel piano Gratuito; oltre il limite restituisce `LIMIT_REACHED` (`402`).
- **`generate_ai_art`** trasforma un QR code in un'immagine artistica con l'IA, a partire da un link, da un testo o da un QR code dinamico tramite il suo id, e restituisce il PNG dopo che QRdx ha verificato che si possa scansionare. Accetta gli stessi campi di [`POST /v1/art`](/docs/developers/ai-art-api) e richiede una chiave con `codes:write`. Ogni immagine usa una delle immagini AI art mensili del workspace della chiave, e una chiamata può richiedere fino a un minuto.
<IfAvailable feature="fileStorage">
- **Logo che hai caricato** in [Dashboard → File](/docs/files), tramite l'id del file (`logo_file_id` in `design_qr`, `logoFileId` in `generate_qr_code`): un PNG o JPEG fino a 1 MB. La chiave deve appartenere al workspace proprietario del file.
</IfAvailable>

## Se qualcosa va storto [#if-something-goes-wrong]

### Il client non riesce a connettersi [#the-client-cant-connect]

Controlla che l'URL sia esattamente `https://mcp.qrdx.dev/mcp` e che il trasporto sia HTTP (Streamable HTTP), non SSE né stdio. I client che eseguono solo server locali hanno bisogno del bridge `mcp-remote` indicato sopra. Aprendo l'URL in un browser si viene reindirizzati alla pagina di connessione: è normale, perché i client MCP non richiedono mai HTML.

### L'assistente dice che uno strumento richiede una chiave API [#the-assistant-says-a-tool-needs-an-api-key]

`save_template`, `save_barcode`, `generate_ai_art` e i logo caricati richiedono `Authorization: Bearer qrdx_…` sulla connessione. Aggiungi l'header come mostrato sopra e riconnettiti.

### `design_qr` rifiuta il contenuto [#design_qr-refuses-the-content]

Il contenuto non ha superato gli stessi controlli dei moduli dell'editor: una password WPA di meno di 8 caratteri, un indirizzo email non valido, un campo di pagamento fuori intervallo. Il motivo è indicato nella risposta; `list_options` elenca i campi e le regole di ogni tipo di contenuto.

### Troppe richieste [#too-many-requests]

Il server consente {facts.mcpPerMinute} richieste al minuto per indirizzo IP, e {facts.designQrPerMinute} per `design_qr`. Con una chiave, anche `save_template` è limitato a 30 al minuto per utente. Aspetta un minuto e riprova.

## Privacy e limiti [#privacy-and-limits]

- Gli strumenti generano immagini, controllano i design, formattano testo e leggono la community pubblica. Solo `save_template` e `save_barcode` scrivono qualcosa: il tema o il codice a barre che chiedi di salvare, nel workspace della chiave API. `generate_ai_art` usa una delle immagini AI art mensili del workspace e non conserva né l'immagine né la foto che invii. Il server non salva i codici che generi.
- Gli URL delle immagini restituiti da `generate_qr_code` e `generate_barcode` contengono i dati codificati. Non condividerli se i dati sono privati, come la password di una rete Wi-Fi.
- Le richieste sono limitate a {facts.mcpPerMinute} al minuto per indirizzo IP, e a {facts.designQrPerMinute} per `design_qr`.

## Self-hosting e sviluppo locale [#self-hosting-and-local-development]

Il server MCP fa parte dell'app web di QRdx, quindi ogni istanza lo espone su `/api/mcp`:

- **Self-hosted.** Quando `NEXT_PUBLIC_APP_URL` è il tuo dominio, la pagina di connessione, gli snippet e i link di installazione usano `https://<your-domain>/api/mcp`.
- **Sviluppo locale.** `bun run dev` lo espone su `http://localhost:3000/api/mcp`. La pagina di connessione mostra comunque l'URL pubblico e propone quello locale come suggerimento, così puoi puntare un client sulla tua macchina per testare le modifiche al server prima che vengano rilasciate.
