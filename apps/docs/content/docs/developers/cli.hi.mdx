इस पेज के अंत तक आप अपने टर्मिनल से QR कोड फ़ाइलें बना चुके होंगे, वही स्टाइल में जो Playground में मिलती हैं, और एक ही कमांड में CSV से कोड्स का पूरा फ़ोल्डर भी बना चुके होंगे। कुछ भी कहीं अपलोड नहीं होता।

`@qrdx/cli` कमांड लाइन से वही QR कोड बनाता है जो Playground और [`qrdx` लाइब्रेरी](/docs/getting-started) बनाती हैं। स्क्रिप्ट और CI में यह कभी कुछ नहीं पूछता। टर्मिनल में बिना आर्guments के `qrdx generate` चलाएँ तो यह कंटेंट और विकल्प एक-एक करके पूछता है।

<NpmStatus package="@qrdx/cli" />

## शुरू करने से पहले [#before-you-start]

- Node.js 22 या उससे नया।
- PNG और WebP आउटपुट [sharp](https://sharp.pixelplumbing.com) इस्तेमाल करते हैं। यह एक वैकल्पिक dependency है, जिसे npm आपके प्लेटफ़ॉर्म पर सपोर्ट होने पर इंस्टॉल करता है। SVG और EPS इसके बिना भी चलते हैं।
- `qrdx` npm पैकेज React लाइब्रेरी है। CLI सिर्फ़ `@qrdx/cli` में है।

## 1. एक कोड बनाएँ [#1-make-one-code]

इसे `npx` से एक बार चलाएँ, या ग्लोबली इंस्टॉल करके `qrdx` कमांड पाएँ:

```bash title="Terminal"
npx @qrdx/cli generate "https://example.com" -o qr.svg

npm install -g @qrdx/cli
qrdx generate "https://example.com" -o qr.png --size 1024
```

```txt title="Output"
◇  ✔  Saved to qr.png (1024×1024)
└  Done!
```

फ़ाइल एक्सटेंशन से फ़ॉर्मैट तय होता है। अगर फ़ाइल के नाम में एक्सटेंशन नहीं है तो `--format` इस्तेमाल करें।

| फ़ॉर्मैट | कब इस्तेमाल करें | `--size` का मतलब |
| --- | --- | --- |
| `.svg` | वेब पेज, डिज़ाइन टूल, बिना क्वालिटी खोए स्केल करना | पिक्सल में चौड़ाई (डिफ़ॉल्ट 512) |
| `.png` | डॉक्यूमेंट, स्लाइड, जहाँ भी इमेज चाहिए | पिक्सल में चौड़ाई |
| `.webp` | वेबसाइट: PNG के ही पिक्सल, लॉसलेस, छोटी फ़ाइल में | पिक्सल में चौड़ाई |
| `.eps` | प्रिंट शॉप, Illustrator, InDesign | पॉइंट में चौड़ाई (प्रति इंच 72, यानी `144` का मतलब 2 इंच) |

EPS फ़ाइलें वेक्टर PostScript होती हैं। PNG और JPEG लोगो जैसे हैं वैसे ही एम्बेड होते हैं। दूसरे लोगो फ़ॉर्मैट sharp इंस्टॉल होने पर उससे कन्वर्ट होते हैं, वरना चेतावनी के साथ छोड़ दिए जाते हैं।

## 2. स्टाइल करें [#2-style-it]

```bash title="Terminal"
# High-resolution PNG for print
qrdx generate "https://example.com" -o print.png --size 2048 --level H

# Vector EPS, 2 inches wide, for a print shop
qrdx generate "https://example.com" -o qr.eps --size 144

# Branded colors and patterns
qrdx generate "https://example.com" --body circle --eye rounded --fg "#1a1a2e" -o brand.svg

# Gradient foreground
qrdx generate "https://example.com" -o gradient.svg \
  --fg '{"type":"linear","stops":[{"color":"#6366f1","offset":0},{"color":"#ec4899","offset":100}],"angle":135}'

# "Scan for the menu" frame
qrdx generate "https://example.com/menu" --frame banner-bottom --frame-text "Scan for the menu" -o menu.png

# Wi-Fi network
qrdx generate "WIFI:T:WPA;S:MyNetwork;P:MyPassword;;" -o wifi.svg
```

```txt title="Output of the frame example"
◇  ✔  Saved to menu.png (635×727)
```

फ़्रेम के साथ `--size` कोड की चौड़ाई होती है और फ़्रेम इमेज में अलग से जुड़ता है। [डायनेमिक QR कोड](/docs/dynamic-qr-codes) प्रिंट करने के लिए उसका शॉर्ट लिंक (`https://qrdx.dev/q/<slug>`) डेटा के रूप में दें।

| फ़्लैग | डिफ़ॉल्ट | विवरण |
| --- | --- | --- |
| `-o`, `--output` | `qr.svg` | आउटपुट फ़ाइल |
| `--format` | एक्सटेंशन से | `svg`, `png`, `webp` या `eps` |
| `--size` | `512` | आउटपुट साइज़ (ऊपर देखें) |
| `-l`, `--level` | `Q` | एरर करेक्शन: `L`, `M`, `Q` या `H` |
| `--body` | `square` | डेटा मॉड्यूल का [पैटर्न](/docs/features/patterns) |
| `--eye` | `square` | कोने की आँख का पैटर्न |
| `--dot` | `square` | कोने की आँख के डॉट का पैटर्न |
| `--fg`, `--bg` | `#000000`, `#ffffff` | फ़ोरग्राउंड और बैकग्राउंड: हेक्स रंग या JSON ग्रेडिएंट (`linear`, `radial` या `angular`) |
| `--eye-color`, `--dot-color` | `--fg` | कोने की आँख और आँख के डॉट के रंग |
| `--logo` | | बीच में लगने वाली लोगो इमेज का URL (`--level H` के साथ इस्तेमाल करें) |
| `--no-logo` | | इंटरैक्टिव मोड में लोगो का सवाल छोड़ें |
| `--margin` | `0` | क्वाइट ज़ोन, मॉड्यूल में |
| `--template` | | टेम्पलेट के रूप में बना फ़्रेम: `Arrow`, `StandardBox`, `SquareBorder`, `StrikedBox`, `Halloween` या `DotRing` |
| `--frame` | | कॉल-टू-एक्शन [फ़्रेम](/docs/features/frames): {facts.frameStyles} बिल्ट-इन फ़्रेम में से कोई भी, जैसे `banner-bottom`, `rounded-border`, `circle`, `sticker` या `phone` ([सभी देखें](/docs/styles#frames)) |
| `--frame-text` | `Scan me` | फ़्रेम का लेबल, ज़्यादा से ज़्यादा 24 अक्षर; `""` देने पर छिप जाता है |
| `--frame-color`, `--frame-text-color` | | फ़्रेम और लेबल के रंग (हेक्स) |

`qrdx --help` हर पैटर्न का नाम दिखाता है। गलत वैल्यू देने पर कोड `1` के साथ बाहर निकल जाता है और बताता है कि कौन-सी वैल्यू मान्य हैं:

```txt title="qrdx generate https://example.com --body nope -o bad.svg"
✗ Invalid --body "nope". Expected one of: circle, circle-large, square, diamond, circle-mixed, pacman, rounded, small-square, vertical-line, horizontal-line, liquid, liquid-horizontal, liquid-vertical, classy, classy-rounded, leaf, plus, hexagon, star, heart, random-dots, mosaic, octagon
```

## 3. CSV से कई कोड बनाएँ [#3-make-many-codes-from-a-csv]

`qrdx batch` CSV फ़ाइल की हर पंक्ति के लिए एक स्टैटिक QR कोड बनाकर एक फ़ोल्डर में लिखता है:

```csv title="products.csv"
sku,url
A-100,https://example.com/products/a-100
A-101,https://example.com/products/a-101
```

```bash title="Terminal"
qrdx batch products.csv -o codes --format png --size 1024 --body circle
```

```txt title="Output"
2 rows · 2 saved
✔  Saved 2 PNG codes to codes in 0.2 s
```

फ़ोल्डर में `A-100.png` और `A-101.png` बन जाती हैं। यह वही कॉलम पढ़ता है जो [बल्क जेनरेटर](/tools/bulk) पढ़ता है: कंटेंट `value`, `url`, `link`, `data`, `content`, `text` या `qr` नाम के कॉलम से (वरना पहले कॉलम से), और फ़ाइल के नाम `file name`, `name`, `label`, `id`, `title` या `sku` नाम के कॉलम से (वरना `qr-00001`, `qr-00002` और इसी तरह)। दूसरे कॉलम चुनने के लिए हेडर का नाम या कॉलम नंबर दें:

| फ़्लैग | डिफ़ॉल्ट | विवरण |
| --- | --- | --- |
| `-o`, `--out` | `qr-codes` | कोड्स का फ़ोल्डर |
| `--format` | `svg` | `svg`, `png` या `eps` |
| `--value-column` | अंदाज़े से | हर कोड का कंटेंट जिस कॉलम में है |
| `--name-column` | अंदाज़े से | फ़ाइल नामों वाला कॉलम |
| `--no-header` | | पहली पंक्ति भी एक कोड है, कॉलम के नाम नहीं |
| `--jobs` | SVG के लिए `4`, बाकी के लिए `8` | एक समय में बनने वाले कोड, 1 से 64 |

ऊपर के सभी स्टाइल विकल्प सभी कोड्स पर लागू होते हैं। CSV को स्ट्रीम की तरह पढ़ा जाता है और हर कोड बनते ही सेव हो जाता है, इसलिए कमांड में पंक्तियों की कोई सीमा नहीं है: लैपटॉप पर 10,000 SVG कोड लगभग 40 सेकंड में बने और 200 MB से कम मेमोरी लगी। कुछ भी अपलोड नहीं होता और अकाउंट की ज़रूरत नहीं है। जिन पंक्तियों को एनकोड नहीं किया जा सकता, उन्हें छोड़ दिया जाता है और कारण के साथ आउटपुट फ़ोल्डर की `errors.csv` में लिख दिया जाता है।

[डायनेमिक कोड](/docs/dynamic-qr-codes) बड़ी संख्या में प्रिंट करने के लिए, पहले उन्हें बनाएँ (डैशबोर्ड का CSV इंपोर्ट या [`POST /v1/codes`](/docs/developers/api/create-codes)), फिर इंपोर्ट से मिली नतीजों वाली CSV पर `--value-column short_link` के साथ `qrdx batch` चलाएँ।

## अगर कुछ गड़बड़ हो जाए [#if-something-goes-wrong]

### `Invalid --body "…"` (या `--eye`, `--dot`, `--frame`) [#invalid---body--or---eye---dot---frame]

वैल्यू किसी मान्य पैटर्न या फ़्रेम का नाम नहीं है। संदेश में मान्य नाम दिए होते हैं। `qrdx --help` भी उन्हें दिखाता है।

### PNG या WebP आउटपुट फ़ेल होता है, SVG चलता है [#png-or-webp-output-fails-svg-works]

आपके प्लेटफ़ॉर्म के लिए sharp इंस्टॉल नहीं है। `@qrdx/cli` को नेटवर्क एक्सेस के साथ दोबारा इंस्टॉल करें ताकि npm वैकल्पिक dependency ला सके, या SVG या EPS आउटपुट लें।

### `--jobs` स्वीकार नहीं होता [#--jobs-is-refused]

यह 1 से 64 तक की संख्या लेता है।

### आउटपुट फ़ोल्डर में एक पंक्ति नहीं मिल रही [#a-row-is-missing-from-the-output-folder]

उसका कंटेंट एनकोड नहीं हो सका (खाली है, या QR कोड के लिए बहुत लंबा है)। उस पंक्ति और कारण के लिए आउटपुट फ़ोल्डर में `errors.csv` खोलें।
