QRdx は、`qrdx` ライブラリをベースにしたQRコードコンポーネントの shadcn/ui レジストリを公開しています。shadcn CLI が各コンポーネントのソースコードをプロジェクトにコピーするため、コードは自分のものとなり、自由に変更できます。ダウンロードボタン、カード、共有ダイアログ、スキャナーなど、完成したUIが必要なときはレジストリを使ってください。コードだけが必要な場合は、ライブラリ自体の `QRCode` を使います。

<NpmStatus package="qrdx" />

<PackageManagerTabs command="npx shadcn@latest add https://qrdx.dev/r/qr-code.json" />

各コンポーネントには専用のページがあり、ライブプレビュー、ソースコード、インストール手順、使用例、props の表を掲載しています。[Playground](/playground?open=code&lang=shadcn)でコードをスタイル設定した場合は、そこからレジストリの QR Code コンポーネント用にコピーできます。

## インストールされるもの [#what-gets-installed]

各コンポーネントは、`components` フォルダー内の1つのファイルです。CLI は `qrdx`（ほとんどのコンポーネントがアイコンに使う `lucide-react` も含む）もインストールし、コンポーネントの土台となる `button`、`card`、`dialog`、`dropdown-menu`、`input`、`label` などの shadcn/ui コンポーネントも追加します。各コンポーネントのページでは、インストールタブの **Manual** に依存関係を一覧で記載しています。

完全なインデックスは [`https://qrdx.dev/r/registry.json`](https://qrdx.dev/r/registry.json) にあり、各アイテムは `https://qrdx.dev/r/<name>.json` にあります。

## 名前でインストールする [#install-by-name]

短い名前でインストールするには、`components.json` にレジストリを追加します。

```json title="components.json"
{
  "registries": {
    "@qrdx": "https://qrdx.dev/r/{name}.json"
  }
}
```

その後、名前を指定して1つまたは複数のコンポーネントを追加します。

<PackageManagerTabs command="npx shadcn@latest add @qrdx/qr-code @qrdx/qr-code-download @qrdx/qr-code-share-dialog" />

## スタイルとテーマ [#styling-and-theming]

コンポーネントは、標準の shadcn/ui テーマトークン（`bg-card`、`border`、`text-muted-foreground`、`ring-ring`）を使った Tailwind クラスと、お使いの Button、Card、Dialog、Input で構成されています。そのため、テーマやダークモードに従います。QRコードは、デフォルトで明るい背景を保ちます。明るいタイルに暗いモジュールを置く形なら、どのリーダーでもスキャンできるためです。テーマに合わせたい場合は、[QR Code](/docs/components/qr-code#dark-mode)のページをご覧ください。

すべてのコンポーネントは、ボタンや状態を持つため Client Component です（ファイルの先頭は `"use client"` です）。ただしコード自体はサーバーでレンダリングされるので、ボタンが操作可能になる前からページの HTML に含まれています。Server Component のページからどのコンポーネントでもインポートでき、サーバーのデータを props として渡せます。

PDF のダウンロードには、オプションの `jspdf` パッケージ（`npm install jspdf`）が必要です。それ以外は、CLI の完了後すぐに動作します。
