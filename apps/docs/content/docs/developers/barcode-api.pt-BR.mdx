Ao final desta página, você terá uma URL de imagem de código de barras para usar em uma tag `<img>`, em um feed de produtos ou em um modelo de etiqueta, saberá como os dígitos verificadores e os formatos são validados e saberá como salvar códigos de barras em um workspace para editá-los depois.

`GET https://api.qrdx.dev/v1/barcode` retorna uma imagem de código de barras. Tudo vai na query string, então a URL é a própria imagem. Ela desenha os mesmos formatos de {facts.barcodeFormats} do [gerador de código de barras](/barcode-generator), com as mesmas regras, e devolve o mesmo SVG. Não é preciso conta nem chave de API.

```html title="index.html"
<img
  src="https://api.qrdx.dev/v1/barcode?format=ean13&data=590123412345"
  alt="EAN-13 barcode 5901234123457"
/>
```

Esse número tem um dígito a menos, então o dígito verificador (7) é adicionado. Se você enviar os 13 dígitos, o dígito verificador é conferido: um dígito errado retorna `400` e informa qual deveria ser.

## 1. Solicitar uma imagem [#1-request-an-image]

<Tabs groupId="language" persist items={["curl", "JavaScript", "Python"]}>
  <Tab value="curl">
    ```bash title="Terminal"
    curl -o box.png "https://api.qrdx.dev/v1/barcode?format=ean13&data=5901234123457&type=png&scale=3"
    ```
  </Tab>
  <Tab value="JavaScript">
    ```js title="barcode.mjs"
    import { writeFile } from "node:fs/promises";

    const url = new URL("https://api.qrdx.dev/v1/barcode");
    url.search = new URLSearchParams({
      format: "ean13",
      data: "5901234123457",
      type: "png",
      scale: "3",
    }).toString();

    const response = await fetch(url);
    await writeFile("box.png", Buffer.from(await response.arrayBuffer()));
    ```
  </Tab>
  <Tab value="Python">
    ```python title="barcode.py"
    import requests

    response = requests.get(
        "https://api.qrdx.dev/v1/barcode",
        params={"format": "ean13", "data": "5901234123457", "type": "png", "scale": 3},
    )
    response.raise_for_status()
    open("box.png", "wb").write(response.content)
    ```
  </Tab>
</Tabs>

```txt title="Output"
200 image/png
box.png: PNG image data, 385 x 237, 8-bit/color RGBA, non-interlaced
```

Coloque a URL entre aspas no shell para manter o `&`, e codifique valores que contenham `&`, `#`, `+` ou espaços, por exemplo com `encodeURIComponent` em JavaScript.

## 2. Mais exemplos [#2-more-examples]

Um PDF vetorial de uma etiqueta logística GS1-128, com colchetes em volta de cada Application Identifier:

```bash title="Terminal"
curl -o pallet.pdf "https://api.qrdx.dev/v1/barcode?format=gs1-128&type=pdf&data=(01)09501101530003(17)261231(10)AB-123"
# 200 application/pdf, 1 page
```

Uma etiqueta de prateleira em Code 128 em azul-escuro, sem o texto sob as barras, girada 90°:

```txt
https://api.qrdx.dev/v1/barcode?format=code128&data=SHELF-A12&fg=1e3a8a&text=false&rotate=90
```

Um Data Matrix com uma margem maior:

```txt
https://api.qrdx.dev/v1/barcode?format=datamatrix&data=SN-0042-7781&quietZone=4
```

## 3. Mantenha o valor fora da URL [#3-keep-the-value-out-of-the-url]

`POST https://api.qrdx.dev/v1/barcode` recebe os mesmos campos em JSON e retorna o mesmo arquivo, sem cache. Use quando o valor não deve acabar em logs, históricos ou caches, como acontece com uma URL:

```bash title="Terminal"
curl -o label.png https://api.qrdx.dev/v1/barcode \
  -H "Content-Type: application/json" \
  -d '{"format":"datamatrix","data":"Internal note 42","type":"png"}'
# 200 image/png, Cache-Control: no-store
```

Em JSON, `text` é um booleano e `scale`, `height`, `quietZone` e `rotate` são números. Um corpo enviado sem `Content-Type: application/json` retorna `415`:

```json title="415 Unsupported Media Type"
{"code":"UNSUPPORTED_MEDIA_TYPE","message":"Send a JSON body with Content-Type: application/json.","status":415}
```

## Parâmetros [#parameters]

| Parâmetro | Padrão | Descrição |
| --- | --- | --- |
| `format` | obrigatório | O tipo de código de barras; veja [Formatos](#formats). Maiúsculas e hifens não importam: `EAN-13` também funciona |
| `data` | obrigatório | O número ou texto a codificar, até 1.000 caracteres (menos na maioria dos formatos lineares) |
| `type` | `svg` | `svg`, `png`, `jpg`, `webp`, `avif`, `pdf` ou `eps` |
| `scale` | `4` | Pixels por módulo em PNG, JPG, WebP e AVIF, de `1` a `10` |
| `height` | depende do formato | Altura das barras dos códigos lineares em milímetros no tamanho vetorial, de `5` a `60` (23 para EAN-13) |
| `quietZone` | o mínimo do formato | Margem em branco, em módulos: em cada lado dos códigos lineares (`0` a `20`), ao redor de todo o código 2D (`0` a `10`) |
| `text` | `true` | Imprime os dígitos ou o texto sob os códigos lineares |
| `fg` | `000000` | Barras e texto, em hex |
| `bg` | `ffffff` | Fundo, em hex |
| `rotate` | `0` | Rotação no sentido horário: `0`, `90`, `180` ou `270` |

Escreva as cores sem o `#`, ou codifique-o como `%23`.

## Formatos [#formats]

| `format` | Código de barras | Aceita |
| --- | --- | --- |
| `ean13` | EAN-13 | 12 dígitos (dígito verificador adicionado) ou 13 (conferido) |
| `ean8` | EAN-8 | 7 dígitos ou 8 |
| `upca` | UPC-A | 11 dígitos ou 12 |
| `upce` | UPC-E | 6 a 8 dígitos, ou um UPC-A de 12 dígitos que possa ser abreviado |
| `itf14` | ITF-14 | 13 dígitos ou 14 |
| `gs1-128` | GS1-128 | Application Identifiers entre colchetes com seus valores; dígitos verificadores de GTIN e SSCC adicionados ou conferidos; até 48 caracteres de dados |
| `code128` | Code 128 | Até 80 caracteres ASCII imprimíveis |
| `code39` | Code 39 | Até 40 letras maiúsculas, dígitos, espaços e `- . $ / + %` |
| `datamatrix` | Data Matrix | Qualquer texto de até 1.000 caracteres |
| `pdf417` | PDF417 | Qualquer texto de até 1.000 caracteres |
| `aztec` | Aztec | Qualquer texto de até 1.000 caracteres |

Os números de varejo (EAN, UPC, ITF-14, o GTIN do GS1-128) são licenciados para empresas pela GS1. A API desenha qualquer número válido; ela não emite nem registra números.

## Tamanhos [#sizes]

Em PNG, JPG, WebP e AVIF, são `scale` pixels por módulo, a largura da barra mais estreita. Uma célula 2D tem dois módulos de largura.

SVG, PDF e EPS são vetores a um ponto por módulo (0,353 mm), então um EAN-13 com os padrões sai com cerca de 45 × 28 mm, cerca de 107% do tamanho nominal. Redimensione os arquivos vetoriais no seu layout; para códigos de barras de varejo, mantenha entre 80% e 200% e não reduza a altura das barras.

## Respostas [#responses]

Uma requisição bem-sucedida retorna o arquivo com:

- `Content-Type` do tipo do arquivo. O EPS vem como download (`Content-Disposition: attachment`); os demais abrem direto no navegador com um nome de arquivo como `ean13-5901234123457.png`
- `Cache-Control: public, max-age=31536000, immutable` para `GET`: a mesma consulta sempre retorna os mesmos bytes. As respostas de `POST` são `no-store`
- `Access-Control-Allow-Origin: *`, para você poder usar `fetch` a partir de qualquer site

## Códigos de barras salvos [#saved-barcodes]

Com uma [chave de API](/docs/developers/api-keys), a REST API guarda códigos de barras no workspace da chave, onde eles aparecem em **Barcodes** no painel. Os escopos são os mesmos dos códigos: `codes:read` para listar e baixar, `codes:write` para alterar.

```bash title="Terminal"
curl https://api.qrdx.dev/v1/barcodes \
  -H "Authorization: Bearer $QRDX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"format":"ean13","value":"590123412345","title":"Spring box"}'
```

```json title="201 Created"
{
  "data": {
    "id": "cmwgwqcxo0003iscgecog7m1b",
    "title": "Spring box",
    "format": "ean13",
    "formatLabel": "EAN-13",
    "value": "5901234123457",
    "options": {
      "foreground": "#000000",
      "background": "#ffffff",
      "showText": true,
      "barHeightMm": 23,
      "quietZone": 11,
      "scale": 4,
      "rotation": 0
    },
    "folderId": null,
    "imageUrl": "https://qrdx.dev/api/v1/barcode?format=ean13&data=5901234123457",
    "createdAt": "2026-11-14T21:18:01.212Z",
    "updatedAt": "2026-11-14T21:18:01.212Z",
    "deletedAt": null,
    "organizationId": "ws_ad2c5e1cce31ccf31535e78f08ab5b78"
  }
}
```

O valor de 12 dígitos voltou com o dígito verificador, e `options` traz os padrões do formato. Cada código de barras salvo tem uma `imageUrl`: a mesma imagem de `GET /v1/barcode`, que qualquer pessoa com o link pode carregar. O endpoint `/image` abaixo é privado e exige a chave.

| Endpoint | O que faz |
| --- | --- |
| [`GET /v1/barcodes`](/docs/developers/api/list-barcodes) | Lista os códigos, da alteração mais recente para a mais antiga; filtre com `q`, `format`, `folderId`, `status=trash` |
| [`POST /v1/barcodes`](/docs/developers/api/create-barcode) | Salva um código. `options` aceita `foreground`, `background`, `showText`, `barHeightMm`, `quietZone`, `scale` e `rotation` |
| [`GET /v1/barcodes/{id}`](/docs/developers/api/get-barcode) | Um código de barras |
| [`PATCH /v1/barcodes/{id}`](/docs/developers/api/update-barcode) | Altera título, formato, valor, opções ou pasta |
| [`DELETE /v1/barcodes/{id}`](/docs/developers/api/delete-barcode) | Move para a lixeira (`{ "deleted": false, "trashed": true }`); `?permanent=true` exclui de vez |
| [`GET /v1/barcodes/{id}/image`](/docs/developers/api/get-saved-barcode-image) | O arquivo, desenhado como foi salvo: `type` e `scale` como acima. `Cache-Control: private, no-store` |

Todos os planos salvam códigos de barras: até 1.000 no Grátis, 10.000 no Pro e 100.000 no Business, sem contar a lixeira. Essas requisições contam na cota diária de API do workspace e enviam os cabeçalhos `X-RateLimit-*`, como o resto da [REST API](/docs/developers/rest-api#rate-limits).

## Se algo der errado [#if-something-goes-wrong]

### `400` com `"param": "data"` [#400-with-param-data]

O valor quebra as regras do formato. A mensagem diz exatamente o quê, seja um dígito verificador, um tamanho ou um conjunto de caracteres:

```json title="400 Bad Request"
{"code":"VALIDATION_ERROR","message":"Invalid query parameters","data":{"details":[{"param":"data","message":"EAN-13: The check digit should be 7, not 8. Check the number, or leave the last digit off and it's worked out for you."}]},"status":400}
```

```json title="400 Bad Request"
{"code":"VALIDATION_ERROR","message":"Invalid query parameters","data":{"details":[{"param":"data","message":"Code 39: Code 39 has no lowercase letters. Use capitals, or Code 128 for mixed case."}]},"status":400}
```

### `400` com `"param": "format"` [#400-with-param-format]

`format` está ausente ou não é um dos onze ids em [Formatos](#formats). A mensagem lista todos.

### A imagem raster é recusada ou cortada [#the-raster-image-is-refused-or-cut]

As imagens raster têm no máximo 6.000 pixels de lado. Reduza `scale` para valores longos, ou use SVG ou PDF.

### `429 RATE_LIMITED` [#429-rate_limited]

Mais de {facts.imageApiPerMinute} requisições por minuto a partir de um mesmo endereço IP, somando `GET` e `POST /v1/barcode`. Espere o número de segundos indicado em `Retry-After`; as respostas de `GET` podem ficar em cache por um ano, então carregue cada imagem uma só vez.

## Limites [#limits]

- **Limite de requisições:** {facts.imageApiPerMinute} requisições por minuto por endereço IP para `GET` e `POST /v1/barcode`, como na [API de imagem de QR code](/docs/developers/image-api). Os códigos de barras salvos seguem os limites por minuto e a cota diária da REST API.
- **Tamanho da imagem:** as imagens raster têm no máximo 6.000 pixels de lado.
- **Sem verificação de leitura aqui.** O [gerador de código de barras](/barcode-generator) decodifica o que desenha antes de você baixar; a API desenha o que você pedir. Imprima um teste e leia com os leitores que vão usar o código.

## MCP [#mcp]

O [servidor MCP](/docs/developers/mcp) tem `generate_barcode`, que confere o valor e retorna um PNG com URLs de imagem, e `save_barcode`, que salva no workspace da chave de API da conexão.

## Hospedagem própria [#self-hosting]

Os endpoints fazem parte do app web do QRdx, então uma instância [hospedada por você](/docs/self-hosting) os serve em `/api/v1/barcode` e `/api/v1/barcodes` no seu próprio domínio.
