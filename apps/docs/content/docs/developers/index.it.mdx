Tutto ciò che fa QRdx è disponibile da codice. Parti da ciò che vuoi costruire: ogni riga indica lo strumento, ciò che richiede e la pagina che ti porta a destinazione.

| Vuoi | Usa | Richiede |
| --- | --- | --- |
| Inserire un QR code in una pagina, in un'email o in un README | [QR code image API](/docs/developers/image-api): un URL `GET` che è l'immagine | Niente |
| Disegnare un codice a barre per un'etichetta o un feed prodotti | [Barcode API](/docs/developers/barcode-api): lo stesso, per EAN, UPC, Code 128 e altri | Niente |
| Creare codici che puoi far puntare altrove dopo la stampa e leggerne le scansioni | [REST API](/docs/developers/quickstart): `POST /v1/codes`, `PATCH`, `GET …/scans` | Una [chiave API](/docs/developers/api-keys) |
| Reagire a scansioni, nuovi codici o risposte dei moduli nel tuo sistema | [Webhook](/docs/webhooks): richieste `POST` firmate verso il tuo URL | Una chiave API o la dashboard, piano Business |
| Lasciare che un assistente AI crei QR code in una chat | [Server MCP](/docs/developers/mcp): `https://mcp.qrdx.dev/mcp` | Niente |
| Creare QR code da uno script, da una build o da un CSV | [CLI](/docs/developers/cli): `npx @qrdx/cli` | Node.js 22 |
| Dipingere un QR code dentro un'illustrazione AI | [AI art API](/docs/developers/ai-art-api): `POST /v1/art` | Una chiave API, immagini AI art mensili |
| Permettere ad altri di collegare il loro account QRdx al tuo prodotto | [Crea un'integrazione](/docs/developers/build-an-integration): OAuth 2.0 con PKCE | Un'app OAuth |
| Automatizzare QRdx in n8n | [Nodi n8n](/docs/developers/n8n): `@qrdx/n8n-nodes-qrdx` | Un n8n self-hosted |
| Generare codici stilizzati in un'app React | [Libreria React](/docs/getting-started): il pacchetto `qrdx` | npm |

## Prima richiesta in due minuti [#first-request-in-two-minutes]

La [guida rapida](/docs/developers/quickstart) crea l'immagine di un QR code con una richiesta senza chiave, crea una chiave API, crea un QR code dinamico e lo fa puntare altrove. Tutto il resto di questa pagina si basa su questi quattro passaggi.

```bash title="Terminal"
curl "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=png" -o qr.png
```

## URL di base e autenticazione [#base-url-and-authentication]

La REST API si trova su `https://api.qrdx.dev/v1`. Le stesse route rispondono su `https://qrdx.dev/api/v1`, e un'istanza [self-hosted](/docs/self-hosting) le espone su `/api/v1` nel proprio dominio.

Le richieste includono una [chiave API](/docs/developers/api-keys) come `Authorization: Bearer qrdx_…`. Una chiave agisce sul workspace in cui è stata creata, con il tuo ruolo in quel workspace. Le app che agiscono per conto di altri utenti QRdx inviano invece nello stesso header un [token di accesso OAuth 2.0](/docs/developers/rest-api#get-an-access-token). Gli endpoint per immagini, codici a barre e community non richiedono né l'una né l'altro.
