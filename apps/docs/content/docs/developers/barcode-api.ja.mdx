このページを読み終えると、`<img>` タグ、商品フィード、ラベルテンプレートで使えるバーコード画像のURLが手に入ります。また、チェックディジットとフォーマットがどのように検証されるか、そして後から編集できるようにバーコードをワークスペースに保存する方法もわかります。

`GET https://api.qrdx.dev/v1/barcode` はバーコード画像を返します。すべてクエリ文字列で指定するため、URLがそのまま画像になります。[バーコードジェネレーター](/barcode-generator)と同じ{facts.barcodeFormats}種類のフォーマットを同じルールで描画し、同じSVGを返します。アカウントもAPIキーも不要です。

```html title="index.html"
<img
  src="https://api.qrdx.dev/v1/barcode?format=ean13&data=590123412345"
  alt="EAN-13 barcode 5901234123457"
/>
```

この番号は1桁足りないため、チェックディジット（7）が追加されます。13桁すべてを送信した場合は、チェックディジットが検証されます。誤っていると `400` が返り、正しい値が示されます。

## 1. 画像をリクエストする [#1-request-an-image]

<Tabs groupId="language" persist items={["curl", "JavaScript", "Python"]}>
  <Tab value="curl">
    ```bash title="Terminal"
    curl -o box.png "https://api.qrdx.dev/v1/barcode?format=ean13&data=5901234123457&type=png&scale=3"
    ```
  </Tab>
  <Tab value="JavaScript">
    ```js title="barcode.mjs"
    import { writeFile } from "node:fs/promises";

    const url = new URL("https://api.qrdx.dev/v1/barcode");
    url.search = new URLSearchParams({
      format: "ean13",
      data: "5901234123457",
      type: "png",
      scale: "3",
    }).toString();

    const response = await fetch(url);
    await writeFile("box.png", Buffer.from(await response.arrayBuffer()));
    ```
  </Tab>
  <Tab value="Python">
    ```python title="barcode.py"
    import requests

    response = requests.get(
        "https://api.qrdx.dev/v1/barcode",
        params={"format": "ean13", "data": "5901234123457", "type": "png", "scale": 3},
    )
    response.raise_for_status()
    open("box.png", "wb").write(response.content)
    ```
  </Tab>
</Tabs>

```txt title="Output"
200 image/png
box.png: PNG image data, 385 x 237, 8-bit/color RGBA, non-interlaced
```

シェルでは `&` が消えないようにURLを引用符で囲んでください。`&`、`#`、`+`、スペースを含む値はエンコードしてください（JavaScriptなら `encodeURIComponent` を使えます）。

## 2. その他の例 [#2-more-examples]

GS1-128の物流ラベルをベクターPDFで出力する例です。各アプリケーション識別子（Application Identifier）は括弧で囲みます。

```bash title="Terminal"
curl -o pallet.pdf "https://api.qrdx.dev/v1/barcode?format=gs1-128&type=pdf&data=(01)09501101530003(17)261231(10)AB-123"
# 200 application/pdf, 1 page
```

バーの下の文字を非表示にし、90°回転させた、濃い青のCode 128の棚ラベルです。

```txt
https://api.qrdx.dev/v1/barcode?format=code128&data=SHELF-A12&fg=1e3a8a&text=false&rotate=90
```

余白を広げたData Matrixです。

```txt
https://api.qrdx.dev/v1/barcode?format=datamatrix&data=SN-0042-7781&quietZone=4
```

## 3. 値をURLに含めない [#3-keep-the-value-out-of-the-url]

`POST https://api.qrdx.dev/v1/barcode` は、同じフィールドをJSONで受け取り、同じファイルをキャッシュなしで返します。URLの場合のようにログ、履歴、キャッシュへ値が残らないようにしたいときに使います。

```bash title="Terminal"
curl -o label.png https://api.qrdx.dev/v1/barcode \
  -H "Content-Type: application/json" \
  -d '{"format":"datamatrix","data":"Internal note 42","type":"png"}'
# 200 image/png, Cache-Control: no-store
```

JSONでは、`text` は真偽値、`scale`、`height`、`quietZone`、`rotate` は数値です。`Content-Type: application/json` なしで本文を送ると `415` になります。

```json title="415 Unsupported Media Type"
{"code":"UNSUPPORTED_MEDIA_TYPE","message":"Send a JSON body with Content-Type: application/json.","status":415}
```

## パラメータ [#parameters]

| パラメータ | デフォルト | 説明 |
| --- | --- | --- |
| `format` | 必須 | バーコードの種類です。[フォーマット](#formats)を参照してください。大文字・小文字とダッシュは区別されないため、`EAN-13` でも動作します |
| `data` | 必須 | エンコードする数字またはテキストです。最大1,000文字です（多くのリニア形式ではそれより短くなります） |
| `type` | `svg` | `svg`、`png`、`jpg`、`webp`、`avif`、`pdf`、`eps` |
| `scale` | `4` | PNG、JPG、WebP、AVIFでの1モジュールあたりのピクセル数です。`1`〜`10` |
| `height` | フォーマットによる | リニアバーコードのバーの高さです。ベクターサイズでのミリメートル単位で、`5`〜`60`（EAN-13は23） |
| `quietZone` | フォーマットの最小値 | モジュール単位の余白です。リニアバーコードでは左右それぞれ（`0`〜`20`）、2Dコードでは四方すべて（`0`〜`10`） |
| `text` | `true` | リニアバーコードの下に数字またはテキストを表示します |
| `fg` | `000000` | バーとテキストの色（16進数） |
| `bg` | `ffffff` | 背景色（16進数） |
| `rotate` | `0` | 時計回りの回転角度です。`0`、`90`、`180`、`270` |

色は `#` を付けずに書くか、`%23` としてエンコードしてください。

## フォーマット [#formats]

| `format` | バーコード | 受け付ける値 |
| --- | --- | --- |
| `ean13` | EAN-13 | 12桁（チェックディジットを追加）または13桁（検証） |
| `ean8` | EAN-8 | 7桁または8桁 |
| `upca` | UPC-A | 11桁または12桁 |
| `upce` | UPC-E | 6〜8桁、または短縮可能な12桁のUPC-A |
| `itf14` | ITF-14 | 13桁または14桁 |
| `gs1-128` | GS1-128 | 括弧付きのアプリケーション識別子とその値。GTINとSSCCのチェックディジットは追加または検証されます。データは最大48文字 |
| `code128` | Code 128 | 印刷可能なASCII文字で最大80文字 |
| `code39` | Code 39 | 大文字、数字、スペース、`- . $ / + %` で最大40文字 |
| `datamatrix` | Data Matrix | 最大1,000文字の任意のテキスト |
| `pdf417` | PDF417 | 最大1,000文字の任意のテキスト |
| `aztec` | Aztec | 最大1,000文字の任意のテキスト |

流通用の番号（EAN、UPC、ITF-14、GS1-128のGTIN）は、GS1が企業にライセンスしています。このAPIは有効な番号であれば何でも描画しますが、番号の発行や登録は行いません。

## サイズ [#sizes]

PNG、JPG、WebP、AVIFでは、1モジュール（最も細いバーの幅）が `scale` ピクセルになります。2Dのセルは2モジュール幅です。

SVG、PDF、EPSは1モジュールあたり1ポイント（0.353 mm）のベクターです。そのため、デフォルト設定のEAN-13は約45 × 28 mmとなり、公称サイズの約107%になります。ベクターファイルはレイアウト側で拡大・縮小してください。流通用バーコードでは80%〜200%の範囲に収め、バーの高さは削らないでください。

## レスポンス [#responses]

リクエストが成功すると、次のヘッダーとともにファイルが返ります。

- `Content-Type` はファイル形式に対応します。EPSはダウンロードとして返され（`Content-Disposition: attachment`）、それ以外は `ean13-5901234123457.png` のようなファイル名でインライン表示されます
- `GET` では `Cache-Control: public, max-age=31536000, immutable` が付きます。同じクエリは常に同じバイト列を返します。`POST` のレスポンスは `no-store` です
- `Access-Control-Allow-Origin: *` により、どのウェブサイトからでも `fetch` できます

## 保存したバーコード [#saved-barcodes]

[APIキー](/docs/developers/api-keys)を使うと、REST APIはキーのワークスペースにバーコードを保存します。保存したバーコードはダッシュボードの **Barcodes** に表示されます。スコープはコードと同じで、一覧表示とダウンロードには `codes:read`、変更には `codes:write` が必要です。

```bash title="Terminal"
curl https://api.qrdx.dev/v1/barcodes \
  -H "Authorization: Bearer $QRDX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"format":"ean13","value":"590123412345","title":"Spring box"}'
```

```json title="201 Created"
{
  "data": {
    "id": "cmwgwqcxo0003iscgecog7m1b",
    "title": "Spring box",
    "format": "ean13",
    "formatLabel": "EAN-13",
    "value": "5901234123457",
    "options": {
      "foreground": "#000000",
      "background": "#ffffff",
      "showText": true,
      "barHeightMm": 23,
      "quietZone": 11,
      "scale": 4,
      "rotation": 0
    },
    "folderId": null,
    "imageUrl": "https://qrdx.dev/api/v1/barcode?format=ean13&data=5901234123457",
    "createdAt": "2026-11-14T21:18:01.212Z",
    "updatedAt": "2026-11-14T21:18:01.212Z",
    "deletedAt": null,
    "organizationId": "ws_ad2c5e1cce31ccf31535e78f08ab5b78"
  }
}
```

12桁の値はチェックディジット付きで返され、`options` にはフォーマットのデフォルト値が入ります。保存した各バーコードには `imageUrl` があります。これは `GET /v1/barcode` と同じ画像で、リンクを知っていれば誰でも読み込めます。以下の `/image` エンドポイントは非公開で、キーが必要です。

| エンドポイント | 内容 |
| --- | --- |
| [`GET /v1/barcodes`](/docs/developers/api/list-barcodes) | 更新日時の新しい順に一覧表示します。`q`、`format`、`folderId`、`status=trash` で絞り込めます |
| [`POST /v1/barcodes`](/docs/developers/api/create-barcode) | 1件を保存します。`options` には `foreground`、`background`、`showText`、`barHeightMm`、`quietZone`、`scale`、`rotation` を指定できます |
| [`GET /v1/barcodes/{id}`](/docs/developers/api/get-barcode) | バーコードを1件取得します |
| [`PATCH /v1/barcodes/{id}`](/docs/developers/api/update-barcode) | タイトル、フォーマット、値、オプション、フォルダーを変更します |
| [`DELETE /v1/barcodes/{id}`](/docs/developers/api/delete-barcode) | ゴミ箱に移動します（`{ "deleted": false, "trashed": true }`）。`?permanent=true` を付けると完全に削除します |
| [`GET /v1/barcodes/{id}/image`](/docs/developers/api/get-saved-barcode-image) | 保存した内容のとおりに描画したファイルです。`type` と `scale` は上記と同じです。`Cache-Control: private, no-store` |

バーコードの保存はすべてのプランで利用できます。上限はフリーが1,000件、Proが10,000件、Businessが100,000件で、ゴミ箱内のものは数えません。これらのリクエストはワークスペースの1日のAPIクォータに含まれ、[REST API](/docs/developers/rest-api#rate-limits)のほかのリクエストと同様に `X-RateLimit-*` ヘッダーが返されます。

## 問題が発生したとき [#if-something-goes-wrong]

### `"param": "data"` を伴う `400` [#400-with-param-data]

値がフォーマットのルールに違反しています。メッセージには、チェックディジット、長さ、文字セットのどれが原因かが具体的に示されます。

```json title="400 Bad Request"
{"code":"VALIDATION_ERROR","message":"Invalid query parameters","data":{"details":[{"param":"data","message":"EAN-13: The check digit should be 7, not 8. Check the number, or leave the last digit off and it's worked out for you."}]},"status":400}
```

```json title="400 Bad Request"
{"code":"VALIDATION_ERROR","message":"Invalid query parameters","data":{"details":[{"param":"data","message":"Code 39: Code 39 has no lowercase letters. Use capitals, or Code 128 for mixed case."}]},"status":400}
```

### `"param": "format"` を伴う `400` [#400-with-param-format]

`format` が指定されていないか、[フォーマット](#formats)にある11種類のIDのいずれでもありません。メッセージにIDの一覧が表示されます。

### ラスター画像が拒否される、または切り取られる [#the-raster-image-is-refused-or-cut]

ラスター画像は1辺が最大6,000ピクセルです。長い値では `scale` を小さくするか、SVGまたはPDFを使ってください。

### `429 RATE_LIMITED` [#429-rate_limited]

1つのIPアドレスからのリクエストが、`GET` と `POST /v1/barcode` を合わせて1分あたり{facts.imageApiPerMinute}件を超えました。`Retry-After` に示された秒数だけ待ってください。`GET` のレスポンスは1年間キャッシュできるため、各画像は1回だけ読み込むようにしてください。

## 制限 [#limits]

- **レート制限:** `GET` と `POST /v1/barcode` を合わせて、IPアドレスごとに1分あたり{facts.imageApiPerMinute}件です。[QR画像API](/docs/developers/image-api)と同じです。保存したバーコードには、REST APIの1分あたりの制限と1日のクォータが適用されます。
- **画像サイズ:** ラスター画像は1辺が最大6,000ピクセルです。
- **ここではスキャンチェックを行いません。** [バーコードジェネレーター](/barcode-generator)はダウンロード前に描画結果をデコードして確認しますが、APIは指定されたとおりに描画するだけです。テスト印刷を行い、実際に読み取るスキャナーでスキャンしてください。

## MCP [#mcp]

[MCPサーバー](/docs/developers/mcp)には、値を検証してPNGと画像URLを返す `generate_barcode` と、接続しているAPIキーのワークスペースに保存する `save_barcode` があります。

## セルフホスティング [#self-hosting]

これらのエンドポイントはQRdxのWebアプリに含まれているため、[セルフホスト](/docs/self-hosting)したインスタンスでは、自分のドメイン上の `/api/v1/barcode` と `/api/v1/barcodes` で利用できます。
