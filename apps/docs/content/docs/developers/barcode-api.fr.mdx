À la fin de cette page, vous disposerez d'une URL d'image de code-barres utilisable dans une balise `<img>`, un flux produit ou un modèle d'étiquette. Vous saurez aussi comment les chiffres de contrôle et les formats sont validés, et comment enregistrer des codes-barres dans un espace de travail pour les modifier plus tard.

`GET https://api.qrdx.dev/v1/barcode` renvoie une image de code-barres. Tout se trouve dans la chaîne de requête : l'URL est l'image. Elle dessine les mêmes formats {facts.barcodeFormats} que le [générateur de codes-barres](/barcode-generator), avec les mêmes règles, et renvoie le même SVG. Aucun compte ni clé API n'est nécessaire.

```html title="index.html"
<img
  src="https://api.qrdx.dev/v1/barcode?format=ean13&data=590123412345"
  alt="EAN-13 barcode 5901234123457"
/>
```

Il manque un chiffre à ce nombre, donc le chiffre de contrôle (7) est ajouté. Si vous envoyez les 13 chiffres, le chiffre de contrôle est vérifié : un chiffre erroné renvoie `400` et indique quelle devrait être la valeur.

## 1. Demander une image [#1-request-an-image]

<Tabs groupId="language" persist items={["curl", "JavaScript", "Python"]}>
  <Tab value="curl">
    ```bash title="Terminal"
    curl -o box.png "https://api.qrdx.dev/v1/barcode?format=ean13&data=5901234123457&type=png&scale=3"
    ```
  </Tab>
  <Tab value="JavaScript">
    ```js title="barcode.mjs"
    import { writeFile } from "node:fs/promises";

    const url = new URL("https://api.qrdx.dev/v1/barcode");
    url.search = new URLSearchParams({
      format: "ean13",
      data: "5901234123457",
      type: "png",
      scale: "3",
    }).toString();

    const response = await fetch(url);
    await writeFile("box.png", Buffer.from(await response.arrayBuffer()));
    ```
  </Tab>
  <Tab value="Python">
    ```python title="barcode.py"
    import requests

    response = requests.get(
        "https://api.qrdx.dev/v1/barcode",
        params={"format": "ean13", "data": "5901234123457", "type": "png", "scale": 3},
    )
    response.raise_for_status()
    open("box.png", "wb").write(response.content)
    ```
  </Tab>
</Tabs>

```txt title="Output"
200 image/png
box.png: PNG image data, 385 x 237, 8-bit/color RGBA, non-interlaced
```

Dans un shell, placez l'URL entre guillemets pour conserver le `&`, et encodez les valeurs qui contiennent `&`, `#`, `+` ou des espaces, par exemple avec `encodeURIComponent` en JavaScript.

## 2. Autres exemples [#2-more-examples]

Un PDF vectoriel d'une étiquette logistique GS1-128, avec des parenthèses ou crochets autour de chaque identifiant d'application (Application Identifier) :

```bash title="Terminal"
curl -o pallet.pdf "https://api.qrdx.dev/v1/barcode?format=gs1-128&type=pdf&data=(01)09501101530003(17)261231(10)AB-123"
# 200 application/pdf, 1 page
```

Une étiquette de rayon Code 128 en bleu foncé, sans le texte sous les barres, pivotée de 90° :

```txt
https://api.qrdx.dev/v1/barcode?format=code128&data=SHELF-A12&fg=1e3a8a&text=false&rotate=90
```

Un Data Matrix avec une marge plus large :

```txt
https://api.qrdx.dev/v1/barcode?format=datamatrix&data=SN-0042-7781&quietZone=4
```

## 3. Garder la valeur hors de l'URL [#3-keep-the-value-out-of-the-url]

`POST https://api.qrdx.dev/v1/barcode` accepte les mêmes champs en JSON et renvoie le même fichier, sans mise en cache. Utilisez-le lorsque la valeur ne doit pas se retrouver dans les journaux, l'historique ou les caches, comme c'est possible avec une URL :

```bash title="Terminal"
curl -o label.png https://api.qrdx.dev/v1/barcode \
  -H "Content-Type: application/json" \
  -d '{"format":"datamatrix","data":"Internal note 42","type":"png"}'
# 200 image/png, Cache-Control: no-store
```

En JSON, `text` est un booléen, et `scale`, `height`, `quietZone` et `rotate` sont des nombres. Un corps envoyé sans `Content-Type: application/json` renvoie une erreur `415` :

```json title="415 Unsupported Media Type"
{"code":"UNSUPPORTED_MEDIA_TYPE","message":"Send a JSON body with Content-Type: application/json.","status":415}
```

## Paramètres [#parameters]

| Paramètre | Valeur par défaut | Description |
| --- | --- | --- |
| `format` | obligatoire | Le type de code-barres ; voir [Formats](#formats). La casse et les tirets n'ont pas d'importance : `EAN-13` fonctionne aussi |
| `data` | obligatoire | Le nombre ou le texte à encoder, jusqu'à 1 000 caractères (moins pour la plupart des formats linéaires) |
| `type` | `svg` | `svg`, `png`, `jpg`, `webp`, `avif`, `pdf` ou `eps` |
| `scale` | `4` | Pixels par module en PNG, JPG, WebP et AVIF, de `1` à `10` |
| `height` | dépend du format | Hauteur des barres des codes-barres linéaires en millimètres à la taille vectorielle, de `5` à `60` (23 pour l'EAN-13) |
| `quietZone` | le minimum du format | Marge blanche en modules : de chaque côté pour les codes-barres linéaires (`0` à `20`), tout autour pour les codes 2D (`0` à `10`) |
| `text` | `true` | Affiche les chiffres ou le texte sous les codes-barres linéaires |
| `fg` | `000000` | Barres et texte, en hexadécimal |
| `bg` | `ffffff` | Arrière-plan, en hexadécimal |
| `rotate` | `0` | Rotation dans le sens horaire : `0`, `90`, `180` ou `270` |

Écrivez les couleurs sans le `#`, ou encodez-le en `%23`.

## Formats [#formats]

| `format` | Code-barres | Accepte |
| --- | --- | --- |
| `ean13` | EAN-13 | 12 chiffres (chiffre de contrôle ajouté) ou 13 (vérifié) |
| `ean8` | EAN-8 | 7 chiffres ou 8 |
| `upca` | UPC-A | 11 chiffres ou 12 |
| `upce` | UPC-E | 6 à 8 chiffres, ou un UPC-A de 12 chiffres pouvant être raccourci |
| `itf14` | ITF-14 | 13 chiffres ou 14 |
| `gs1-128` | GS1-128 | Identifiants d'application entre parenthèses ou crochets avec leurs valeurs ; chiffres de contrôle GTIN et SSCC ajoutés ou vérifiés ; jusqu'à 48 caractères de données |
| `code128` | Code 128 | Jusqu'à 80 caractères ASCII imprimables |
| `code39` | Code 39 | Jusqu'à 40 majuscules, chiffres, espaces et `- . $ / + %` |
| `datamatrix` | Data Matrix | Tout texte jusqu'à 1 000 caractères |
| `pdf417` | PDF417 | Tout texte jusqu'à 1 000 caractères |
| `aztec` | Aztec | Tout texte jusqu'à 1 000 caractères |

Les numéros de vente au détail (EAN, UPC, ITF-14, GTIN du GS1-128) sont attribués aux entreprises sous licence par GS1. L'API dessine tout numéro valide ; elle ne les émet ni ne les enregistre.

## Tailles [#sizes]

Pour PNG, JPG, WebP et AVIF, `scale` correspond au nombre de pixels par module, c'est-à-dire la largeur de la barre la plus étroite. Une cellule 2D fait deux modules de large.

SVG, PDF et EPS sont des vecteurs à un point par module (0,353 mm). Un EAN-13 avec les valeurs par défaut mesure donc environ 45 × 28 mm, soit environ 107 % de sa taille nominale. Redimensionnez les fichiers vectoriels dans votre mise en page ; pour les codes-barres de vente au détail, restez entre 80 % et 200 % et ne réduisez pas la hauteur des barres.

## Réponses [#responses]

Une requête réussie renvoie le fichier avec :

- `Content-Type` correspondant au type de fichier. L'EPS est fourni en téléchargement (`Content-Disposition: attachment`) ; les autres s'ouvrent directement avec un nom de fichier tel que `ean13-5901234123457.png`
- `Cache-Control: public, max-age=31536000, immutable` pour `GET` : la même requête renvoie toujours les mêmes octets. Les réponses `POST` sont en `no-store`
- `Access-Control-Allow-Origin: *`, afin de pouvoir l'appeler avec `fetch` depuis n'importe quel site web

## Codes-barres enregistrés [#saved-barcodes]

Avec une [clé API](/docs/developers/api-keys), la REST API conserve les codes-barres dans l'espace de travail de la clé, où ils apparaissent sous **Barcodes** dans le tableau de bord. Les portées sont les mêmes que pour les codes : `codes:read` pour lister et télécharger, `codes:write` pour modifier.

```bash title="Terminal"
curl https://api.qrdx.dev/v1/barcodes \
  -H "Authorization: Bearer $QRDX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"format":"ean13","value":"590123412345","title":"Spring box"}'
```

```json title="201 Created"
{
  "data": {
    "id": "cmwgwqcxo0003iscgecog7m1b",
    "title": "Spring box",
    "format": "ean13",
    "formatLabel": "EAN-13",
    "value": "5901234123457",
    "options": {
      "foreground": "#000000",
      "background": "#ffffff",
      "showText": true,
      "barHeightMm": 23,
      "quietZone": 11,
      "scale": 4,
      "rotation": 0
    },
    "folderId": null,
    "imageUrl": "https://qrdx.dev/api/v1/barcode?format=ean13&data=5901234123457",
    "createdAt": "2026-11-14T21:18:01.212Z",
    "updatedAt": "2026-11-14T21:18:01.212Z",
    "deletedAt": null,
    "organizationId": "ws_ad2c5e1cce31ccf31535e78f08ab5b78"
  }
}
```

La valeur à 12 chiffres est revenue avec son chiffre de contrôle, et `options` contient les valeurs par défaut du format. Chaque code-barres enregistré possède une `imageUrl` : la même image que `GET /v1/barcode`, que toute personne disposant du lien peut charger. L'endpoint `/image` ci-dessous est privé et nécessite la clé.

| Endpoint | Fonction |
| --- | --- |
| [`GET /v1/barcodes`](/docs/developers/api/list-barcodes) | Les liste, dernière modification en premier ; filtrez avec `q`, `format`, `folderId`, `status=trash` |
| [`POST /v1/barcodes`](/docs/developers/api/create-barcode) | En enregistre un. `options` accepte `foreground`, `background`, `showText`, `barHeightMm`, `quietZone`, `scale` et `rotation` |
| [`GET /v1/barcodes/{id}`](/docs/developers/api/get-barcode) | Un code-barres |
| [`PATCH /v1/barcodes/{id}`](/docs/developers/api/update-barcode) | Modifie son titre, son format, sa valeur, ses options ou son dossier |
| [`DELETE /v1/barcodes/{id}`](/docs/developers/api/delete-barcode) | Le déplace dans la corbeille (`{ "deleted": false, "trashed": true }`) ; `?permanent=true` le supprime définitivement |
| [`GET /v1/barcodes/{id}/image`](/docs/developers/api/get-saved-barcode-image) | Le fichier, dessiné tel qu'enregistré : `type` et `scale` comme ci-dessus. `Cache-Control: private, no-store` |

Tous les forfaits permettent d'enregistrer des codes-barres : jusqu'à 1 000 avec Gratuit, 10 000 avec Pro et 100 000 avec Business, sans compter la corbeille. Ces requêtes comptent dans le quota quotidien d'API de l'espace de travail et renvoient les en-têtes `X-RateLimit-*`, comme le reste de la [REST API](/docs/developers/rest-api#rate-limits).

## En cas de problème [#if-something-goes-wrong]

### `400` avec `"param": "data"` [#400-with-param-data]

La valeur enfreint les règles du format. Le message indique précisément laquelle, qu'il s'agisse d'un chiffre de contrôle, d'une longueur ou d'un jeu de caractères :

```json title="400 Bad Request"
{"code":"VALIDATION_ERROR","message":"Invalid query parameters","data":{"details":[{"param":"data","message":"EAN-13: The check digit should be 7, not 8. Check the number, or leave the last digit off and it's worked out for you."}]},"status":400}
```

```json title="400 Bad Request"
{"code":"VALIDATION_ERROR","message":"Invalid query parameters","data":{"details":[{"param":"data","message":"Code 39: Code 39 has no lowercase letters. Use capitals, or Code 128 for mixed case."}]},"status":400}
```

### `400` avec `"param": "format"` [#400-with-param-format]

`format` est absent ou ne fait pas partie des onze identifiants de [Formats](#formats). Le message les énumère.

### L'image raster est refusée ou tronquée [#the-raster-image-is-refused-or-cut]

Les images raster font au maximum 6 000 pixels de côté. Réduisez `scale` pour les valeurs longues, ou utilisez SVG ou PDF.

### `429 RATE_LIMITED` [#429-rate_limited]

Plus de {facts.imageApiPerMinute} requêtes par minute depuis une même adresse IP, pour `GET` et `POST /v1/barcode` confondus. Attendez le nombre de secondes indiqué dans `Retry-After` ; les réponses `GET` peuvent être mises en cache pendant un an, donc chargez chaque image une seule fois.

## Limites [#limits]

- **Limite de débit :** {facts.imageApiPerMinute} requêtes par minute et par adresse IP pour `GET` et `POST /v1/barcode`, comme pour l'[API d'image QR](/docs/developers/image-api). Les codes-barres enregistrés suivent les limites par minute et le quota quotidien de la REST API.
- **Taille de l'image :** les images raster font au maximum 6 000 pixels de côté.
- **Pas de vérification par scan ici.** Le [générateur de codes-barres](/barcode-generator) décode ce qu'il dessine avant le téléchargement ; l'API dessine ce que vous demandez. Imprimez un test et scannez-le avec les lecteurs qui devront le lire.

## MCP [#mcp]

Le [serveur MCP](/docs/developers/mcp) propose `generate_barcode`, qui vérifie la valeur et renvoie un PNG avec des URL d'image, et `save_barcode`, qui enregistre dans l'espace de travail de la clé API de la connexion.

## Auto-hébergement [#self-hosting]

Les endpoints font partie de l'application web QRdx : une instance [auto-hébergée](/docs/self-hosting) les sert donc sur `/api/v1/barcode` et `/api/v1/barcodes` sur votre propre domaine.
