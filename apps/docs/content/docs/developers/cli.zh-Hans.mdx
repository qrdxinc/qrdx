读完本页，你将能在终端中生成与 Playground 样式相同的二维码文件，还能用一条命令从 CSV 批量生成一个二维码文件夹，全程不会上传任何内容。

`@qrdx/cli` 可在命令行中渲染与 Playground 和 [`qrdx` 库](/docs/getting-started)相同的二维码。在脚本和 CI 中，它不会弹出任何提示；如果在终端中不带参数运行 `qrdx generate`，它会逐步询问内容和选项。

## 开始之前 [#before-you-start]

- Node.js 22 或更高版本。
- PNG 和 WebP 输出使用 [sharp](https://sharp.pixelplumbing.com)。它是一个可选依赖，在你的平台支持时由 npm 自动安装；SVG 和 EPS 无需它即可使用。
- npm 上的 `qrdx` 包是 React 库。CLI 只在 `@qrdx/cli` 中。

## 1. 生成一个二维码 [#1-make-one-code]

用 `npx` 运行一次，或全局安装以获得 `qrdx` 命令：

```bash title="Terminal"
npx @qrdx/cli generate "https://example.com" -o qr.svg

npm install -g @qrdx/cli
qrdx generate "https://example.com" -o qr.png --size 1024
```

```txt title="Output"
◇  ✔  Saved to qr.png (1024×1024)
└  Done!
```

文件扩展名决定输出格式；如果文件名没有扩展名，请使用 `--format`。

| 格式 | 适用场景 | `--size` 的含义 |
| --- | --- | --- |
| `.svg` | 网页、设计工具，无损缩放 | 宽度，单位为像素（默认 512） |
| `.png` | 文档、幻灯片，以及任何需要图片的地方 | 宽度，单位为像素 |
| `.webp` | 网站：像素与 PNG 相同、无损，文件更小 | 宽度，单位为像素 |
| `.eps` | 印刷厂、Illustrator、InDesign | 宽度，单位为点（每英寸 72 点，因此 `144` 即 2 英寸） |

EPS 文件是矢量 PostScript。PNG 和 JPEG 格式的 logo 会原样嵌入；其他格式的 logo 在已安装 sharp 时会用它转换，否则会被省略并给出警告。

## 2. 设置样式 [#2-style-it]

```bash title="Terminal"
# High-resolution PNG for print
qrdx generate "https://example.com" -o print.png --size 2048 --level H

# Vector EPS, 2 inches wide, for a print shop
qrdx generate "https://example.com" -o qr.eps --size 144

# Branded colors and patterns
qrdx generate "https://example.com" --body circle --eye rounded --fg "#1a1a2e" -o brand.svg

# Gradient foreground
qrdx generate "https://example.com" -o gradient.svg \
  --fg '{"type":"linear","stops":[{"color":"#6366f1","offset":0},{"color":"#ec4899","offset":100}],"angle":135}'

# "Scan for the menu" frame
qrdx generate "https://example.com/menu" --frame banner-bottom --frame-text "Scan for the menu" -o menu.png

# Wi-Fi network
qrdx generate "WIFI:T:WPA;S:MyNetwork;P:MyPassword;;" -o wifi.svg
```

```txt title="Output of the frame example"
◇  ✔  Saved to menu.png (635×727)
```

使用边框时，`--size` 是二维码本身的宽度，边框会在此基础上增加图像尺寸。要打印[动态二维码](/docs/dynamic-qr-codes)，请把它的短链接（`https://qrdx.dev/q/<slug>`）作为数据传入。

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `-o`, `--output` | `qr.svg` | 输出文件 |
| `--format` | 取自扩展名 | `svg`、`png`、`webp` 或 `eps` |
| `--size` | `512` | 输出尺寸（见上文） |
| `-l`, `--level` | `Q` | 纠错等级：`L`、`M`、`Q` 或 `H` |
| `--body` | `square` | 数据模块的[图案](/docs/features/patterns) |
| `--eye` | `square` | 角落定位眼图案 |
| `--dot` | `square` | 角落定位眼中心点图案 |
| `--fg`, `--bg` | `#000000`, `#ffffff` | 前景色和背景色：十六进制颜色或 JSON 渐变（`linear`、`radial` 或 `angular`） |
| `--eye-color`, `--dot-color` | `--fg` | 角落定位眼和中心点的颜色 |
| `--logo` | | 中心 logo 图片的 URL（请配合 `--level H` 使用） |
| `--no-logo` | | 在交互模式下跳过 logo 提示 |
| `--margin` | `0` | 静区，单位为模块 |
| `--template` | | 以模板方式绘制的边框：`Arrow`、`StandardBox`、`SquareBorder`、`StrikedBox`、`Halloween` 或 `DotRing` |
| `--frame` | | 行动号召[边框](/docs/features/frames)：{facts.frameStyles} 种内置边框中的任意一种，例如 `banner-bottom`、`rounded-border`、`circle`、`sticker` 或 `phone`（见[全部边框](/docs/styles#frames)） |
| `--frame-text` | `Scan me` | 边框文字，最多 24 个字符；`""` 表示隐藏 |
| `--frame-color`, `--frame-text-color` | | 边框和文字的颜色（十六进制） |

`qrdx --help` 会列出所有图案名称。传入无效值时，命令会以代码 `1` 退出，并列出可接受的值：

```txt title="qrdx generate https://example.com --body nope -o bad.svg"
✗ Invalid --body "nope". Expected one of: circle, circle-large, square, diamond, circle-mixed, pacman, rounded, small-square, vertical-line, horizontal-line, liquid, liquid-horizontal, liquid-vertical, classy, classy-rounded, leaf, plus, hexagon, star, heart, random-dots, mosaic, octagon
```

## 3. 从 CSV 批量生成二维码 [#3-make-many-codes-from-a-csv]

`qrdx batch` 会为 CSV 文件的每一行生成一个静态二维码，并写入一个文件夹：

```csv title="products.csv"
sku,url
A-100,https://example.com/products/a-100
A-101,https://example.com/products/a-101
```

```bash title="Terminal"
qrdx batch products.csv -o codes --format png --size 1024 --body circle
```

```txt title="Output"
2 rows · 2 saved
✔  Saved 2 PNG codes to codes in 0.2 s
```

文件夹中会包含 `A-100.png` 和 `A-101.png`。它读取的列与[批量生成器](/tools/bulk)相同：内容取自名为 `value`、`url`、`link`、`data`、`content`、`text` 或 `qr` 的列（否则取第一列），文件名取自名为 `file name`、`name`、`label`、`id`、`title` 或 `sku` 的列（否则依次为 `qr-00001`、`qr-00002`，以此类推）。你也可以按表头名称或列号指定其他列：

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `-o`, `--out` | `qr-codes` | 存放二维码的文件夹 |
| `--format` | `svg` | `svg`、`png` 或 `eps` |
| `--value-column` | 自动识别 | 包含每个二维码内容的列 |
| `--name-column` | 自动识别 | 包含文件名的列 |
| `--no-header` | | 第一行是二维码内容，而不是列名 |
| `--jobs` | SVG 为 `4`，其他为 `8` | 同时渲染的二维码数量，1 到 64 |

上面所有样式选项都会应用于每一个二维码。CSV 以流的方式读取，每个二维码一生成就立即保存，因此该命令没有行数限制：在一台笔记本电脑上，生成 10,000 个 SVG 二维码约耗时 40 秒，内存占用不到 200 MB。不会上传任何内容，也无需账号。无法编码的行会被跳过，并连同原因列在输出文件夹的 `errors.csv` 中。

要批量打印[动态二维码](/docs/dynamic-qr-codes)，请先创建它们（使用控制台的 CSV 导入或 [`POST /v1/codes`](/docs/developers/api/create-codes)），然后对导入后得到的结果 CSV 运行 `qrdx batch`，并加上 `--value-column short_link`。

## 出现问题时 [#if-something-goes-wrong]

### `Invalid --body "…"`（或 `--eye`、`--dot`、`--frame`） [#invalid---body--or---eye---dot---frame]

该值不是有效的图案名称或边框名称。错误信息会列出可接受的值；`qrdx --help` 也会列出。

### PNG 或 WebP 输出失败，但 SVG 正常 [#png-or-webp-output-fails-svg-works]

你的平台上没有安装 sharp。请在联网的情况下重新安装 `@qrdx/cli`，以便 npm 获取这个可选依赖，或者改为输出 SVG 或 EPS。

### `--jobs` 被拒绝 [#--jobs-is-refused]

它只接受 1 到 64 之间的数字。

### 输出文件夹中缺少某一行 [#a-row-is-missing-from-the-output-folder]

该行的内容无法编码（为空，或对二维码来说太长）。请打开输出文件夹中的 `errors.csv`，查看对应的行和原因。
