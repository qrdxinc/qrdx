Ao final desta página, todo QR code que suas páginas, e-mails ou planilhas carregavam de `chart.googleapis.com` passa a ser carregado da [Image API](/docs/developers/image-api) do QRdx, com o mesmo tamanho e o mesmo nível de correção de erros, sem conta nem chave.

O Google descontinuou o Image Charts em abril de 2012, incluindo os QR codes em `chart.googleapis.com/chart?cht=qr`. Hoje o endpoint responde `404` (verificado em 15 de novembro de 2026), então toda tag `<img>` antiga mostra uma imagem quebrada. A Image API do QRdx funciona do mesmo jeito: uma URL `GET` que retorna a imagem. Por isso, a mudança é um novo host e três parâmetros com nome diferente.

## Antes de começar [#before-you-start]

- Encontre os arquivos que ainda usam a API antiga. O comando abaixo lista todos, incluindo o host mais antigo `chart.apis.google.com`:

```bash title="Terminal"
grep -rlE "chart\.(googleapis|apis\.google)\.com/chart" .
```

- Trabalhe em um checkout do git ou em outro lugar onde você possa revisar a mudança antes de publicá-la.

## 1. Compare uma URL [#1-compare-one-url]

As duas URLs abaixo geram o mesmo resultado: um PNG de 300 × 300 de `https://example.com` com correção de erros `M` e margem de 2 módulos.

```txt title="Before and after"
https://chart.googleapis.com/chart?cht=qr&chs=300x300&chl=https%3A%2F%2Fexample.com&chld=M|2
https://api.qrdx.dev/v1/qr?format=png&size=300&data=https%3A%2F%2Fexample.com&level=M&margin=2
```

```bash title="Terminal"
curl -o after.png "https://api.qrdx.dev/v1/qr?format=png&size=300&data=https%3A%2F%2Fexample.com&level=M&margin=2"
file after.png
# after.png: PNG image data, 300 x 300, 8-bit/color RGBA, non-interlaced
```

## 2. Mapeie os parâmetros [#2-map-the-parameters]

| Google Chart | QRdx | Observações |
| --- | --- | --- |
| `cht=qr` | desnecessário | O endpoint só gera QR codes. Se for mantido, é ignorado |
| `chl=<data>` | `data=<data>` | Codificado como URL do mesmo jeito, com até 2.048 caracteres |
| `chs=<width>x<height>` | `size=<width>` | Um único número, porque QR codes são quadrados: de `64` a `2048` pixels |
| `chld=<level>\|<margin>` | `level=<level>&margin=<margin>` | As mesmas letras: `L`, `M`, `Q` e `H`. A margem é em módulos, de `0` a `16` |
| `choe=UTF-8` | desnecessário | O QRdx sempre codifica o texto em UTF-8, que era o padrão do Google. Não há opção de Shift_JIS nem de ISO-8859-1. Se for mantido, é ignorado |
| sempre PNG | `format=png` | O QRdx retorna SVG, a menos que você peça `png`, `webp` ou `eps`. Use PNG em e-mails, porque muitos clientes de e-mail não exibem SVG |

Dois padrões são diferentes. Sem `chld`, o Google usava correção de erros `L`; o QRdx usa `Q`, que resiste a mais danos, mas gera um código mais denso. Adicione `level=L` se quiser o visual antigo. Nos dois, a margem padrão é de 4 módulos.

## 3. Reescreva as URLs nos seus arquivos [#3-rewrite-the-urls-in-your-files]

Este comando reescreve todas as URLs de QR code do Google Chart nos arquivos que você indicar, nos dois hosts: troca o host e o caminho, renomeia `chl`, `chs` e `chld` e adiciona `format=png` para que as imagens continuem em PNG. O Perl já vem no macOS e na maioria das distribuições Linux.

```bash title="Terminal"
perl -pi -e 's{https?://chart\.(?:googleapis|apis\.google)\.com/chart\?([^\s"\x27<>)]*)}{my $q = $1; $q =~ s/(^|[&;])chl=/${1}data=/; $q =~ s/(^|[&;])chs=(\d+)x\d+/${1}size=$2/; $q =~ s/(^|[&;])chld=([LMQH])(?:\||%7C)(\d+)/${1}level=$2&margin=$3/i; $q =~ s/(^|[&;])chld=([LMQH])/${1}level=$2/i; "https://api.qrdx.dev/v1/qr?format=png&$q"}ge' index.html
```

Executado em um arquivo com três tags antigas, o resultado é:

```html title="index.html (after)"
<img src="https://api.qrdx.dev/v1/qr?format=png&cht=qr&size=300&data=https%3A%2F%2Fexample.com&level=M&margin=2" alt="QR">
<img src="https://api.qrdx.dev/v1/qr?format=png&cht=qr&size=150&data=https%3A%2F%2Fexample.com%2Fmenu" alt="QR 2">
<img src="https://api.qrdx.dev/v1/qr?format=png&size=200&cht=qr&data=hello&level=H&choe=UTF-8" alt="QR 3">
```

Os `cht=qr` e `choe=UTF-8` que sobraram são ignorados pelo QRdx; remova-os manualmente se quiser URLs mais limpas. Confira o diff e execute de novo o `grep` do início: ele não deve listar nada.

## 4. Altere o código que monta as URLs [#4-change-the-code-that-builds-urls]

```js title="qr.js"
// Before
const src = `https://chart.googleapis.com/chart?cht=qr&chs=200x200&chl=${encodeURIComponent(link)}`;

// After
const src = `https://api.qrdx.dev/v1/qr?format=png&size=200&data=${encodeURIComponent(link)}`;
```

No Google Sheets:

```txt title="Sheets formula"
=IMAGE("https://api.qrdx.dev/v1/qr?format=png&size=150&data="&ENCODEURL(A2))
```

O Sheets carrega imagens pelos servidores do próprio Google, então uma planilha com centenas de códigos pode atingir o limite por IP descrito abaixo. Para uma lista longa, gere os arquivos uma única vez com o [gerador em massa](/tools/bulk) ou com o `qrdx batch` da [CLI](/docs/developers/cli).

## Se algo der errado [#if-something-goes-wrong]

### `400` com `"param": "size"` [#400-with-param-size]

Um `chs` abaixo de 64 pixels (como `50x50`) ou acima de 2048 é recusado. Altere esses tamanhos manualmente; `64` é o menor tamanho que a Image API gera.

```json title="400 Bad Request"
{"code":"VALIDATION_ERROR","message":"Invalid query parameters","data":{"details":[{"param":"size","message":"Too small: expected number to be >=64"}]},"status":400}
```

### A imagem está mais densa que antes [#the-image-is-denser-than-before]

O nível de correção de erros padrão do Google era `L`; o do QRdx é `Q`. Adicione `level=L` para igualar o visual antigo.

### `429` após uma recarga em massa [#429-after-a-bulk-reload]

A Image API permite {facts.imageApiPerMinute} requisições por minuto por endereço IP. Espere os segundos indicados no cabeçalho `Retry-After` ou gere os arquivos uma única vez em vez de carregá-los ao vivo.

## O que mais saber [#what-else-to-know]

- **Cache:** a mesma URL sempre retorna os mesmos bytes, então as respostas ficam em cache por um ano (`Cache-Control: public, max-age=31536000, immutable`).
- **Mais opções:** cores (`fg`, `bg`), formatos de módulos e de olhos, um ícone de logo (`logoIcon`) e molduras. Experimente no [construtor de URL](/qr-code-api) ou leia os [parâmetros](/docs/developers/image-api#parameters).
- **Hospedagem própria:** um QRdx [hospedado por você](/docs/self-hosting) oferece a mesma API em `/api/v1/qr` no seu próprio domínio.
