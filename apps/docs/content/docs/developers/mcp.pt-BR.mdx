Ao final desta página, seu assistente de IA poderá criar QR codes: desenhar um para qualquer conteúdo com uma nota de leitura verificada, gerá-lo nos estilos do editor, montar o payload certo para Wi-Fi, contatos, e-mail, SMS, localizações e pagamentos bancários, encontrar molduras da comunidade e desenhar códigos de barras. Com uma chave de API na conexão, ele também pode salvar designs e códigos de barras no seu workspace e criar arte com IA.

O QRdx mantém um servidor público de [Model Context Protocol](https://modelcontextprotocol.io) em:

```txt title="Server URL"
https://mcp.qrdx.dev/mcp
```

Ele usa o transporte Streamable HTTP, não guarda estado de sessão e não exige conta, login nem chave de API. O mesmo servidor também responde em `https://qrdx.dev/api/mcp`, e a [página de conexão](/mcp) tem botões de um clique e passos para mais clientes do que esta página mostra.

[Experimente no Playground](/playground?open=code&lang=mcp): estilize um código lá e depois copie-o como argumentos de `design_qr` para o seu assistente.

## 2. Peça um código [#2-ask-for-a-code]

Depois é só pedir em linguagem simples. Estes prompts funcionam como estão:

```txt title="Prompts"
Make a QR code for https://example.com in our brand blue, #155dfc, with rounded modules.
Create a Wi-Fi QR code for the network Office Guest with password correct-horse-battery.
Design a Wi-Fi QR code for Cafe Guest in warm browns with a Free Wi-Fi banner, and tell me its scan score.
Generate a contact QR code for Ada Lovelace, ada@example.com, and add it to the README.
Find a community frame for a restaurant menu and use it for https://example.com/menu.
Draw an EAN-13 barcode for 590123412345 as a PNG.
```

No primeiro prompt, o assistente chama `generate_qr_code` e recebe de volta o PNG e estas linhas, prontas para colar:

```txt title="generate_qr_code result"
QR code, 512x512px, error correction Q.
SVG URL: https://api.qrdx.dev/v1/qr?data=https%3A%2F%2Fexample.com&fg=155dfc&body=rounded
PNG URL: https://api.qrdx.dev/v1/qr?data=https%3A%2F%2Fexample.com&format=png&fg=155dfc&body=rounded
WebP URL (lossless, smaller than PNG): https://api.qrdx.dev/v1/qr?data=https%3A%2F%2Fexample.com&format=webp&fg=155dfc&body=rounded
EPS URL (vector, for print; 512 pt wide): https://api.qrdx.dev/v1/qr?data=https%3A%2F%2Fexample.com&format=eps&fg=155dfc&body=rounded
Markdown: ![QR code](https://api.qrdx.dev/v1/qr?data=https%3A%2F%2Fexample.com&fg=155dfc&body=rounded)
```

No segundo, ele chama `qr_payload_wifi`, que retorna `WIFI:T:WPA;S:Office Guest;P:correct-horse-battery;;`, e passa essa string como `data` para `generate_qr_code` ou como o conteúdo de `design_qr`.

## Ferramentas [#tools]

| Ferramenta | O que faz |
| --- | --- |
| `design_qr` | Cria o design de um código para qualquer tipo de conteúdo, com o estilo que seu assistente escolher, ou partindo de um tema integrado ou de um item da comunidade, verifica a pontuação de leitura e repara o estilo até ele ficar Ótimo. Retorna a pontuação, o que mudou, o JSON do estilo, um link do Playground, um PNG e o SVG |
| `list_options` | Lista todos os valores que `design_qr` aceita: tipos de conteúdo e seus campos, cores e gradientes, formas, molduras (com os ids das molduras oficiais do QRdx), bordas, ícones de logo e logos de marcas, temas integrados, níveis de correção de erros e limites |
| `generate_qr_code` | Gera um QR code com os estilos do editor. Retorna uma imagem PNG e URLs públicas da [Image API](/docs/developers/image-api) (SVG, PNG, WebP sem perdas e EPS vetorial) prontas para Markdown, HTML ou impressão, além do código SVG, se você pedir |
| `list_qr_styles` | Lista padrões de corpo, formas dos olhos dos cantos e dos pontos dos olhos, molduras (os estilos integrados e as desenhadas como modelos), ícones de logo, níveis de correção de erros, padrões e limites |
| `search_community` | Encontra molduras, temas e coleções publicados na [comunidade](/community) por palavras, tipo ou tag |
| `get_community_item` | Retorna um item da comunidade com o estilo que ele aplica, pronto para `design_qr` ou `generate_qr_code` |
| `save_template` | Salva um design como tema no seu workspace. Exige uma [chave de API](#use-an-api-key) |
| `generate_barcode` | Desenha um código de barras EAN-13, UPC-A, UPC-E, EAN-8, ITF-14, GS1-128, Code 128, Code 39, Data Matrix, PDF417 ou Aztec depois de validar o valor (dígitos verificadores, comprimentos, caracteres). Retorna um PNG e URLs públicas da [API de códigos de barras](/docs/developers/barcode-api) |
| `save_barcode` | Salva um código de barras nos Códigos de barras do seu workspace. Exige uma [chave de API](#use-an-api-key) |
| `generate_ai_art` | Pinta um QR code em uma arte de IA e verifica se ele é lido. Usa uma das imagens de arte de IA mensais do workspace e leva até um minuto. Exige uma [chave de API](#use-an-api-key). Veja a [API de arte de IA](/docs/developers/ai-art-api) |
| `qr_payload_wifi` | Monta um payload de rede `WIFI:` (WPA, WEP ou aberta, opcionalmente oculta) com os caracteres especiais escapados |
| `qr_payload_vcard` | Monta um contato vCard 3.0 (RFC 2426): nome, organização, cargo, telefones, e-mail, site, endereço e observação |
| `qr_payload_email` | Monta um link `mailto:` (RFC 6068) com cc, bcc, assunto e corpo opcionais |
| `qr_payload_sms` | Monta um link `sms:` (RFC 5724) com mensagem opcional, ou a forma mais antiga `SMSTO:` |
| `qr_payload_geo` | Monta uma localização `geo:` (RFC 5870) a partir de latitude e longitude |
| `qr_payload_payment` | Monta um código de pagamento bancário: um BR Code do Pix, uma transferência de crédito SEPA (EPC069-12) ou um código PayNow, PromptPay ou VietQR (EMV, com o CRC). Ele valida os campos como os formulários do Playground |

As ferramentas de payload retornam uma string simples. Depois, seu assistente a passa como `data` para `generate_qr_code`.

### design_qr [#design_qr]

`design_qr` recebe o conteúdo como um tipo e seus campos, os mesmos tipos e validações dos formulários de conteúdo do editor (`list_options` os lista), e um estilo opcional:

```json title="design_qr arguments"
{
  "content": { "type": "wifi", "ssid": "Cafe Guest", "password": "sunshine123", "encryption": "WPA" },
  "style": {
    "bgColor": "#FFF7ED",
    "fgColor": "#9A3412",
    "bodyPattern": "rounded",
    "cornerEyePattern": "rounded",
    "frame": { "style": "banner-bottom", "text": "Free Wi-Fi" }
  }
}
```

```txt title="design_qr result (first lines)"
Scan score 85/100 (great). No changes were needed. Content: WiFi · Cafe Guest (47 bytes). Open it in the playground: https://qrdx.dev/playground?style=1.eyJiIjoiI0ZGRjdFRCIs…&ref=mcp
```

O JSON do resultado contém `payload` (a string exata que o código codifica), `style`, `qrdxStyle`, `score`, `grade`, `stillFailing` (verificações que ainda falham, cada uma com uma correção), `repairs`, `changes` e `playgroundUrl`, seguidos do PNG e do SVG.

As opções que você omite recebem valores padrão (olhos seguem a cor dos pontos, formas quadradas, margem 4, correção de erros Q, sem moldura). Em seguida, o QRdx executa no design a verificação de leitura do editor: ele renderiza o código, decodifica em 96, 160 e 320 px com um modelo de câmera de celular e verifica contraste, zona de silêncio, formas dos olhos e pares de formas. Abaixo de Ótimo (85), ele repara o estilo, até três vezes, mudando o mínimo possível (cores mais escuras que mantêm o tom, uma forma de olho mais segura, menos correção de erros para conteúdo longo). Se isso não bastar, ele recorre a um código clássico preto sobre branco, com a sua moldura. O resultado informa o que foi alterado e por quê.

Nenhum modelo de IA roda no lado do QRdx para `design_qr`: seu assistente escolhe o estilo, e o QRdx valida, verifica e repara. Conteúdo inválido (uma senha WPA com menos de 8 caracteres, um endereço de e-mail malformado) é recusado com o motivo. `design_qr` tem seu próprio limite de {facts.designQrPerMinute} chamadas por minuto por endereço IP.

Mais entradas:

- **`preset`**: parte de um tema integrado pelo id (`list_options` os lista). As opções de estilo que você definir têm prioridade sobre ele.
- **`community_item`**: parte de uma moldura ou tema da comunidade pelo id, como `frame:wifi-card`. Um item de moldura fica sobre um código clássico; suas opções de estilo mudam o código que está por baixo. As molduras oficiais do QRdx também são itens da comunidade, então `frame:diwali-diya` ou `frame:menu-cutlery` funcionam aqui.
- **Uma moldura personalizada**: `style.frame` pode ser `{ "style": "custom", "spec": … }` com uma especificação de moldura, como a de uma moldura da comunidade obtida com `get_community_item`. Ela é desenhada e pontuada como está; os reparos mudam o código, nunca a moldura.
- **`style.logo`**: um ícone de logo rápido (`wifi`, `location`, `phone`, `email`, `link`, `file`, `calendar`, `whatsapp` ou `instagram`), ou um logo de marca pelo slug do [Simple Icons](https://simpleicons.org) (`spotify`, `paypal:white`). `list_options` lista os slugs de marcas populares.
- **Opções do motor**: `style.eyeColors` (cores `#RRGGBB` por olho), `moduleScale` (tamanho do ponto, de `0.5` a `1`), `shape` (`circle` para um código redondo), `autoLevel` e `logoOptions` (tamanho, espaço livre, posição, recorte e placa do logo). Elas são desenhadas e pontuadas como foram informadas; os reparos não as alteram.

<IfAvailable feature="fileStorage">
`logo_file_id` desenha um logo que você enviou ao QRdx, com uma [chave de API](#use-an-api-key).
</IfAvailable>

Os logos são pontuados pelos módulos que cobrem, como no editor, então um reparo pode aumentar a correção de erros para H ou remover o logo. A marca QRdx que o editor mostra por padrão não é desenhada aqui.

O `qrdxStyle` do resultado é o design como JSON de estilo do editor. Passe-o para `save_template`, para `generate_qr_code` como `style` para renderizar o mesmo design em outro tamanho, ou para o [`style`](/docs/developers/image-api#style) da Image API. `playground_url` abre o design no [Playground](/playground): ele leva só o estilo, nunca o logo nem o conteúdo, e `playgroundLeftOut` informa o que fica de fora.

### generate_qr_code [#generate_qr_code]

As entradas correspondem aos [parâmetros da Image API](/docs/developers/image-api#parameters): `data` (obrigatório), `size`, `fg`, `bg`, `eyeColor`, `dotColor`, `body`, `eye`, `dot`, `level`, `margin`, `template`, `frame`, `frameText`, `logoIcon`, `logoFileId`, `item` (um id de item da comunidade) e `style` (o JSON de estilo do editor: gradientes, molduras personalizadas e o resto, como `design_qr` o retorna). As opções simples têm prioridade sobre `style`, e `style` tem prioridade sobre `item`. Defina `include_svg` como `true` para receber também o código SVG como texto, por exemplo para salvar um arquivo `.svg`. Ele vem desativado por padrão porque o código costuma ter de 50 a 150 KB, o que encheria a conversa.

`generate_qr_code` não verifica a pontuação de leitura; use `design_qr` para isso. Um código com o seu logo enviado não tem URL de imagem pública, já que a Image API só desenha esse logo em requisições com a sua chave.

### O cartão de QR [#qr-card]

Em apps que oferecem suporte a [MCP Apps](https://modelcontextprotocol.io/extensions/apps/overview), `design_qr` e `generate_qr_code` também mostram um cartão de QR no chat. Ele traz o código, o que ele codifica (um código de Wi-Fi mostra o nome da rede, nunca a senha), o tamanho e a correção de erros ou a pontuação de leitura, e um botão **Abrir no editor**. O link do editor leva só o estilo, como `playground_url`.

Os botões PNG e SVG dependem do que o app permite. Onde ele consegue salvar arquivos a partir de um cartão, eles salvam. Caso contrário, abrem a URL da Image API no navegador, então o cartão de `design_qr` só mostra esses botões em apps que salvam arquivos: o conteúdo dele nunca vai em uma URL de imagem. Os apps podem pedir que você confirme antes de abrir um link.

Apps sem MCP Apps recebem o mesmo texto e imagem de antes. Para quem desenvolve clientes:

- O cartão é o recurso `ui://qrdx/qr-card` (`text/html;profile=mcp-app`), listado por `resources/list`. As duas ferramentas apontam para ele com `_meta.ui.resourceUri`.
- Os dados dele vêm no `_meta` do resultado da ferramenta, em `dev.qrdx/qr-card`, que se destina ao cartão e não ao modelo. As ferramentas não retornam `structuredContent`.
- O cartão é um único arquivo HTML com estilos e script embutidos. A única coisa que ele carrega é a imagem do código a partir da Image API (`https://api.qrdx.dev`, ou o seu próprio domínio, quando hospedado por você), e a política de segurança de conteúdo dele (`_meta.ui.csp.resourceDomains`) permite esse host e nenhum outro.

Se você conectou o QRdx antes de o cartão existir, remova o conector e adicione de novo, ou atualize as ferramentas dele, para que o app receba os novos metadados das ferramentas.

### Comunidade [#community]

`search_community` encontra molduras, temas e coleções publicados na [comunidade](/community), grátis sob CC0, por palavras (`q`), `type` e `tag`. `get_community_item` retorna um item com o estilo que ele aplica; passe o id dele para `design_qr` como `community_item` ou para `generate_qr_code` como `item`. Os mesmos dados estão na REST API em [`/v1/community/items`](/docs/developers/api/list-community-items).

O texto dos itens é escrito por membros da comunidade. Nomes, descrições, handles, tags e rótulos de moldura voltam curtos, em uma só linha e sem links, e-mails ou marcação, e cada resultado diz para tratá-los como dados, não como instruções.

## Use uma chave de API [#use-an-api-key]

Algumas ferramentas precisam de uma [chave de API](/docs/developers/api-keys) do QRdx na conexão, enviada como `Authorization: Bearer qrdx_…`:

- **`save_template`** salva um design como tema, listado em Temas no painel e disponível no editor. Precisa de uma chave com `codes:write`, que as chaves com **Acesso total** têm. Uma chave do seu próprio workspace salva nos seus temas; uma chave de equipe salva nos temas compartilhados da equipe quando quem a criou é proprietário ou administrador e o plano tem temas de equipe. Cada salvamento conta para o limite de temas salvos do plano (veja [Planos e limites](/docs/plans-and-limits)); acima dele, a ferramenta retorna o erro `LIMIT_REACHED` (`402`) da API.
- **`save_barcode`** salva um código de barras (formato, valor, um título opcional e opções de desenho) no workspace da chave, listado em Códigos de barras no painel. Precisa de uma chave com `codes:write`. Todos os planos salvam códigos de barras, até 1.000 no Grátis; acima do limite, retorna `LIMIT_REACHED` (`402`).
- **`generate_ai_art`** transforma um QR code em arte de IA, a partir de um link, de um texto ou de um QR code dinâmico pelo id, e retorna o PNG depois que o QRdx confirma que ele tem leitura. Aceita os mesmos campos de [`POST /v1/art`](/docs/developers/ai-art-api) e precisa de uma chave com `codes:write`. Cada imagem usa uma das imagens de arte de IA mensais do workspace da chave, e uma chamada pode levar até um minuto.
<IfAvailable feature="fileStorage">
- **Logos que você enviou** em [Painel → Arquivos](/docs/files), pelo id do arquivo (`logo_file_id` em `design_qr`, `logoFileId` em `generate_qr_code`): um PNG ou JPEG de até 1 MB. A chave precisa pertencer ao workspace dono do arquivo.
</IfAvailable>

## Se algo der errado [#if-something-goes-wrong]

### O cliente não consegue se conectar [#the-client-cant-connect]

Confira se a URL é exatamente `https://mcp.qrdx.dev/mcp` e se o transporte é HTTP (Streamable HTTP), não SSE nem stdio. Clientes que só executam servidores locais precisam da ponte `mcp-remote` mostrada acima. Abrir a URL no navegador redireciona para a página de conexão, e isso é esperado: clientes MCP nunca pedem HTML.

### O assistente diz que uma ferramenta precisa de uma chave de API [#the-assistant-says-a-tool-needs-an-api-key]

`save_template`, `save_barcode`, `generate_ai_art` e os logos enviados precisam de `Authorization: Bearer qrdx_…` na conexão. Adicione o cabeçalho como mostrado acima e reconecte.

### `design_qr` recusa o conteúdo [#design_qr-refuses-the-content]

O conteúdo não passou nas mesmas verificações dos formulários do editor: uma senha WPA com menos de 8 caracteres, um endereço de e-mail malformado, um campo de pagamento fora do intervalo. O motivo vem na resposta; `list_options` lista os campos e as regras de cada tipo de conteúdo.

### Muitas requisições [#too-many-requests]

O servidor aceita {facts.mcpPerMinute} requisições por minuto por endereço IP, e `design_qr` aceita {facts.designQrPerMinute}. Com uma chave, `save_template` também é limitado a 30 por minuto por usuário. Espere um minuto e tente de novo.

## Privacidade e limites [#privacy-and-limits]

- As ferramentas geram imagens, verificam designs, formatam texto e leem a comunidade pública. Só `save_template` e `save_barcode` gravam algo: o tema ou o código de barras que você pede para salvar, no workspace da chave de API. `generate_ai_art` usa uma das imagens de arte de IA mensais do workspace e não guarda nem a imagem nem a foto que você envia. O servidor não salva os códigos que você gera.
- As URLs de imagem que `generate_qr_code` e `generate_barcode` retornam contêm os dados codificados. Não as compartilhe se os dados forem privados, como a senha de uma rede Wi-Fi.
- As requisições são limitadas a {facts.mcpPerMinute} por minuto por endereço IP, e `design_qr` a {facts.designQrPerMinute}.

## Hospedagem própria e desenvolvimento local [#self-hosting-and-local-development]

O servidor MCP faz parte do app web do QRdx, então toda instância o serve em `/api/mcp`:

- **Hospedagem própria.** Quando `NEXT_PUBLIC_APP_URL` é o seu próprio domínio, a página de conexão, os snippets e os links de instalação usam `https://<your-domain>/api/mcp`.
- **Desenvolvimento local.** `bun run dev` o serve em `http://localhost:3000/api/mcp`. A página de conexão continua mostrando a URL pública e oferece a local como dica, para você apontar um cliente para a sua máquina e testar mudanças no servidor antes de elas serem publicadas.
