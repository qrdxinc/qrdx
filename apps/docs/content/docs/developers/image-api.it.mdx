Alla fine di questa pagina avrai l'URL di un'immagine QR code da incollare in un README, in un tag `<img>` o in un template email, con lo stile che preferisci, e saprai cosa rifiuta l'API e perché.

`GET https://api.qrdx.dev/v1/qr` restituisce un QR code come immagine SVG, PNG o WebP, oppure come file EPS vettoriale per la stampa e gli strumenti di design. Tutto sta nella query string, quindi l'URL stesso è l'immagine. Accetta anche gli stili dell'editor: gradienti, cornici (comprese quelle personalizzate), bordi, colori di occhi e punti e icone logo. Non servono account né chiave API, tranne per un logo caricato su QRdx (vedi [Logo](#logos)).

```md title="README.md"
![QR code](https://api.qrdx.dev/v1/qr?data=https://github.com/you/repo)
```

[Provalo nel Playground](/playground?open=code&lang=image): crea lì lo stile di un codice, poi copia l'URL della sua immagine. Oppure invia richieste dalla pagina di riferimento [Genera un'immagine QR code](/docs/developers/api/get-qr-image).

## 1. Richiedi un'immagine [#1-request-an-image]

<Tabs groupId="language" persist items={["curl", "JavaScript", "Python"]}>
  <Tab value="curl">
    ```bash title="Terminal"
    curl -o qr.png "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=png&size=1024"
    ```
  </Tab>
  <Tab value="JavaScript">
    ```js title="qr.mjs"
    import { writeFile } from "node:fs/promises";

    const url = new URL("https://api.qrdx.dev/v1/qr");
    url.searchParams.set("data", "https://qrdx.dev");
    url.searchParams.set("format", "png");
    url.searchParams.set("size", "1024");

    const response = await fetch(url);
    await writeFile("qr.png", Buffer.from(await response.arrayBuffer()));
    ```
  </Tab>
  <Tab value="Python">
    ```python title="qr.py"
    import requests

    response = requests.get(
        "https://api.qrdx.dev/v1/qr",
        params={"data": "https://qrdx.dev", "format": "png", "size": 1024},
    )
    response.raise_for_status()
    open("qr.png", "wb").write(response.content)
    ```
  </Tab>
</Tabs>

```txt title="Output"
qr.png: PNG image data, 1024 x 1024, 8-bit/color RGBA, non-interlaced
```

In una shell metti l'URL tra virgolette, così mantiene il carattere `&`. In una pagina HTML l'URL va direttamente in `src`:

```html title="index.html"
<img
  src="https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&size=256&fg=155dfc"
  width="256"
  height="256"
  alt="QR code for qrdx.dev"
/>
```

## 2. Scegli un formato [#2-pick-a-format]

| `format` | Restituisce | Quando |
| --- | --- | --- |
| `svg` (predefinito) | `image/svg+xml` | Pagine web e tutto ciò che deve scalare |
| `png` | `image/png` | Email, app di chat, documenti |
| `webp` | `image/webp`, lossless, trasparenza mantenuta | Siti web: i pixel del PNG in un file più leggero |
| `eps` | `application/postscript`, inviato come download `qr-code.eps` | Illustrator, InDesign, tipografie. `size` è in questo caso la larghezza in punti, 72 per pollice, quindi `144` sono 2 pollici |

```bash title="Terminal"
curl -o qr.webp "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=webp&size=1024"
curl -o qr.eps "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=eps&size=144"
head -2 qr.eps
# %!PS-Adobe-3.0 EPSF-3.0
# %%BoundingBox: 0 0 144 144
```

## 3. Dai uno stile [#3-style-it]

I parametri semplici coprono colori, forme, una cornice e un logo:

```txt title="Rounded modules with a frame drawn as a template"
https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&body=rounded&eye=rounded&dot=rounded&template=Arrow
```

```txt title="A built-in frame with its label, and a community frame by id"
https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&frame=banner-bottom&frameText=Scan%20the%20menu
https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&item=frame:wifi-card
```

Per gradienti, cornici personalizzate e colori per ogni occhio, invia l'intero design come JSON in `style`:

```js title="styled.mjs"
const style = {
  fgColor: {
    type: "linear",
    angle: 45,
    stops: [
      { color: "#1d4ed8", offset: 0 },
      { color: "#7c3aed", offset: 100 },
    ],
  },
  eyeColor: "#b91c1c",
  frame: { style: "banner-bottom", text: "Scan the menu" },
};
const src = `https://api.qrdx.dev/v1/qr?data=${encodeURIComponent(link)}&style=${encodeURIComponent(JSON.stringify(style))}`;
// 200 image/svg+xml, 634.88 × 727.04: the frame adds to the 512 px code
```

<Callout type="info">
Codifica il valore di `data` quando contiene `&`, `#`, `+` o spazi, ad esempio con `encodeURIComponent` in JavaScript. Altrimenti l'URL viene diviso in corrispondenza di questi caratteri. Codifica `style` allo stesso modo e scrivi i colori senza `#` (oppure come `%23`): un `#` semplice avvia il frammento dell'URL e non viene mai inviato.
</Callout>

## Parametri [#parameters]

| Parametro | Predefinito | Descrizione |
| --- | --- | --- |
| `data` | obbligatorio | Testo o URL da codificare, fino a 2048 caratteri |
| `format` | `svg` | `svg`, `png`, `webp` o `eps` |
| `size` | `512` | Larghezza e altezza in pixel, da `64` a `2048` (punti per EPS) |
| `fg` | `000000` | Colore dei moduli in esadecimale (`155dfc`, `fff`, oppure 8 cifre con alpha) |
| `bg` | `ffffff` | Colore di sfondo in esadecimale. `00000000` dà uno sfondo trasparente |
| `eyeColor` | `fg` | Colore dei tre occhi agli angoli |
| `dotColor` | `fg` | Colore del punto all'interno di ogni occhio agli angoli |
| `body` | `square` | Forma dei moduli dei dati; vedi [Valori dei pattern](#pattern-values) |
| `eye` | `square` | Forma delle cornici degli occhi agli angoli |
| `dot` | `square` | Forma del punto all'interno di ogni occhio agli angoli |
| `level` | `Q` | Correzione degli errori: `L` (circa 7%), `M` (15%), `Q` (25%) o `H` (30%) |
| `margin` | `4` | Zona di rispetto attorno al codice in moduli, da `0` a `16` |
| `template` | nessuno | Una [cornice disegnata come template](/docs/features/templates): l'intera immagine è larga `size`, con il codice più piccolo al suo interno |
| `frame` | nessuno | Una [cornice](/docs/features/frames) predefinita con invito all'azione, come `banner-bottom`, `speech-bubble` o `circle`: una qualsiasi delle {facts.frameStyles} cornici predefinite |
| `frameText` | `Scan me` | L'etichetta della cornice, fino a 24 caratteri. Cambia anche l'etichetta della cornice di uno `style` o di un `item` |
| `style` | nessuno | L'intero design dell'editor in JSON; vedi [Stili](#style) |
| `item` | nessuno | Una cornice o un tema della community tramite id, come `frame:wifi-card`; vedi [Elementi della community](#community-items) |
| `logoIcon` | nessuno | Un'icona rapida o un logo di brand al centro; vedi [Logo](#logos) |
| `logoFileId` | nessuno | Un logo che hai caricato, tramite file id; richiede una chiave API; vedi [Logo](#logos) |

I valori enum (`level`, `format`, `template`, `frame`) non distinguono tra maiuscole e minuscole. Con una cornice, `size` è la larghezza del codice stesso e la cornice si aggiunge all'immagine, in ogni formato. I parametri semplici hanno la precedenza su `style`, e `style` ha la precedenza su `item`.

## Stili [#style]

`style` accetta il design come JSON con gli stessi campi di un tema salvato, quindi un tema da [`GET /v1/themes`](/docs/developers/api/list-themes) o il `qrdxStyle` restituito da `design_qr` del [server MCP](/docs/developers/mcp) può essere passato così com'è (senza un logo caricato, vedi sotto):

| Campo | Accetta |
| --- | --- |
| `bgColor`, `fgColor`, `eyeColor`, `dotColor` | Un colore (esadecimale come `#155dfc`, `rgb()`, `hsl()` o un nome di colore), oppure un gradiente: `{ "type": "linear", "angle": 45, "stops": [...] }` o `{ "type": "radial", "stops": [...] }`, con da 2 a 8 stop di `{ "color", "offset" }` (offset da 0 a 100) |
| `bodyPattern`, `cornerEyePattern`, `cornerEyeDotPattern` | I [valori dei pattern](#pattern-values) |
| `level`, `margin` | Come i parametri sopra (`margin` da 0 a 16) |
| `templateId` | Una cornice disegnata come template, `default` per nessuna |
| `frame` | Una cornice predefinita, `{ "style": "banner-bottom", "text": "Scan me", "color": "#155dfc", "textColor": "#ffffff" }`, oppure una personalizzata, `{ "style": "custom", "spec": { … } }`, con una specifica di cornice dalla [community](#community-items) o una cornice personalizzata creata nella sezione Cornice del Playground. Le specifiche vengono verificate rispetto alle regole del motore per le specifiche di cornice (niente markup, link o immagini; al massimo 32 KB) |
| `eyeColors` | Colori per ogni occhio, sopra `eyeColor` e `dotColor`: `{ "topLeft": { "outer": "#b91c1c", "inner": "#1d4ed8" }, "topRight": …, "bottomLeft": … }`, ciascuno un colore o un gradiente |
| `moduleScale` | Dimensione di ogni punto, da `0.5` a `1` (predefinito `1`) |
| `shape` | `square` (predefinito) o `circle`: il codice in un disco di punti decorativi |
| `autoLevel` | Porta la correzione degli errori a `H` quando il logo copre più del 7% del codice (qui sempre attivo quando c'è un logo) |
| `logoOptions` | Il layout del logo: `size` (da `0.1` a `0.3` della larghezza del codice; QRdx lo riduce quando il codice non può cedere i moduli), `padding` (da `0` a `2` moduli), `x` e `y` (da `0` a `1`), `shape` (ritaglio `square`, `rounded` o `circle`) e `plate` (un colore dietro al logo) |
| `showLogo`, `logoIcon`, `logoFileId` | Vedi [Logo](#logos) |

`style` accetta anche il valore `style` del link di un Playground (inizia con `1.`), quindi un design condiviso dal [Playground](/playground) viene generato come appare lì, senza il suo logo. I campi sconosciuti, gli indirizzi dei logo (`customLogo`) e l'arte di Logo QR o Image QR (`art`) vengono rifiutati con un `400` che ne spiega il motivo:

```json title="400 Bad Request"
{"code":"VALIDATION_ERROR","message":"Invalid query parameters","data":{"details":[{"param":"style.customLogo","message":"Logo images by address aren't accepted: upload the image to QRdx and pass its file id as logoFileId, or pick a logoIcon."}]},"status":400}
```

## Elementi della community [#community-items]

`item` genera una cornice o un tema pubblicato della [community](/community), gratuito con licenza CC0. Trova gli id con [`GET /v1/community/items`](/docs/developers/api/list-community-items), oppure apri la pagina di un elemento e usa il suo tipo e il suo slug: `/community/frames/wifi-card` è `frame:wifi-card`. Un elemento cornice si applica a un codice semplice nero su bianco; aggiungi `style` o parametri semplici per cambiare il codice sottostante. Le immagini generate con `item` sono in cache per 5 minuti (10 sulla CDN), perché un elemento può avere una nuova versione o essere rimosso.

## Logo [#logos]

- **Icone rapide.** `logoIcon` mette al centro, su un riquadro bianco, una delle icone dell'editor: `wifi`, `location`, `phone`, `email`, `link`, `file`, `calendar`, `whatsapp` o `instagram`. QRdx le disegna da sé e non serve nessuna chiave.
- **Logo di brand.** `logoIcon` accetta anche uno qualsiasi dei {facts.brandLogos} brand di [Simple Icons](https://simpleicons.org) tramite slug: `spotify`, `paypal`, `googlemaps`, `appstore`. Il marchio viene disegnato senza sfondo, nel colore del brand; aggiungi `:black` o `:white` per usare quei colori (`whatsapp:white`), e `logoOptions.plate` in `style` per aggiungere una piastra dietro. [`GET /api/brand-logos`](https://qrdx.dev/api/brand-logos) elenca tutti gli slug. Se usi uno slug che QRdx non ha, ricevi un `400` che suggerisce la forma corretta.
- **Il marchio QRdx** che l'editor mostra di default qui non viene disegnato: `showLogo: true` da solo non aggiunge alcun logo.
- **La correzione degli errori aumenta con un logo.** Quando un logo copre più del 7% del codice, il codice viene disegnato al livello `H`, qualunque cosa dica `level`, così resta leggibile alla scansione.

```bash title="Terminal"
curl -o spotify.png "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=png&logoIcon=spotify"
```

<IfAvailable feature="fileStorage">

**Il tuo logo.** `logoFileId` disegna un PNG o JPEG fino a 1 MB che hai caricato in [Dashboard → File](/docs/files). L'id è l'ultima parte del link del file, `https://qrdx.dev/api/files/<id>`. Invia una [chiave API](/docs/developers/api-keys) del workspace che possiede il file:

```bash title="Terminal"
curl -o qr.png -H "Authorization: Bearer $QRDX_API_KEY" \
  "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=png&logoFileId=<id>"
```

La risposta è privata (`Cache-Control: private, no-store`) e conta nella quota giornaliera API del workspace. Un file di un altro workspace restituisce `404`, e una richiesta senza chiave restituisce `401`. QRdx legge l'immagine dal proprio storage e verifica che sia davvero un PNG o JPEG; non scarica mai un logo da un indirizzo web che gli invii.

</IfAvailable>

`logoOptions` dimensiona, posiziona, ritaglia e dà uno sfondo a ciascuno di questi logo. La rimozione dello sfondo di un logo caricato si fa nel Playground; l'Image API disegna il file caricato così com'è. Le grafiche Logo QR e Image QR non sono disponibili qui: il Playground le costruisce dalla tua immagine nel browser. Progetta i codici artistici nel [Playground](/playground?tab=art), oppure trasforma un codice in un'opera di AI con l'[AI art API](/docs/developers/ai-art-api).

### Valori dei pattern [#pattern-values]

- `body`: `circle`, `circle-large`, `square`, `diamond`, `circle-mixed`, `pacman`, `rounded`, `small-square`, `vertical-line`, `horizontal-line`, `liquid`, `liquid-horizontal`, `liquid-vertical`, `classy`, `classy-rounded`, `leaf`, `plus`, `hexagon`, `star`, `heart`, `random-dots`, `mosaic`, `octagon`
- `eye`: `square`, `rounded`, `gear`, `circle`, `diya`, `extra-rounded`, `message`, `pointy`, `leaf`, `drop`, `octagon`, `bevel`, `squircle`, `cushion`, `shield`, `petal`, `leaf-reverse`
- `dot`: `square`, `rounded`, `circle`, `message`, `message-reverse`, `diya`, `diya-reverse`, `rounded-triangle`, `leaf`, `drop`, `plus`, `cross-rounded`, `hexagon`, `octagon`, `flower`, `heart`, `squircle`, `dots`, `extra-rounded`, `leaf-reverse`, `drop-reverse`
- `template`: `default`, `Arrow`, `StandardBox`, `SquareBorder`, `StrikedBox`, `Halloween`, `DotRing`

Sono gli stessi stili della [libreria React `qrdx`](/docs/features/patterns). Anche il [server MCP](/docs/developers/mcp) può elencarli con brevi descrizioni.

## Risposte [#responses]

Una richiesta riuscita restituisce l'immagine con:

- `Content-Type: image/svg+xml`, `image/png`, `image/webp` o `application/postscript` (l'EPS viene inviato come download `qr-code.eps`)
- `Cache-Control: public, max-age=31536000, immutable`, tranne per i rendering con `item` (5 minuti, 10 sulla CDN) e con `logoFileId` (`private, no-store`)
- `Access-Control-Allow-Origin: *`, così puoi usare `fetch` da qualsiasi sito web

Il rendering è deterministico: la stessa query string restituisce sempre gli stessi byte, ed è per questo che le risposte possono essere messe in cache per un anno. Gli URL che usano solo i parametri originali vengono renderizzati esattamente come sempre.

## Se qualcosa va storto [#if-something-goes-wrong]

### `400` con `"param": "size"` [#400-with-param-size]

`size` è inferiore a 64 o superiore a 2048. Il corpo indica il limite:

```json title="400 Bad Request"
{"code":"VALIDATION_ERROR","message":"Invalid query parameters","data":{"details":[{"param":"size","message":"Too small: expected number to be >=64"}]},"status":400}
```

### `400` con `"param": "data"` [#400-with-param-data]

I dati non entrano in un QR code al livello di correzione degli errori scelto. Usa un `level` più basso (`L` è quello che ne contiene di più) oppure dati più brevi; per gli URL lunghi, di solito la soluzione è il link breve di un QR code dinamico.

```json title="400 Bad Request"
{"code":"VALIDATION_ERROR","message":"Invalid query parameters","data":{"details":[{"param":"data","message":"Data is too long for a QR code at error correction level H. Shorten it or use a lower level (L holds the most)."}]},"status":400}
```

### `400` con `"param": "logoIcon"` [#400-with-param-logoicon]

Lo slug non corrisponde a un brand che QRdx ha né a un'icona rapida. Il messaggio suggerisce le forme che funzionano (`spotify`, `paypal`, `googlemaps`, oppure `wifi`, `phone`, `email`).

### L'immagine appare sbagliata o tagliata [#the-image-looks-wrong-or-is-split]

Un `&`, `#` o `+` in `data` o `style` non è stato codificato, quindi l'URL è stato interrotto in quel punto. Codifica entrambi i valori e scrivi i colori senza il `#`.

### `429 RATE_LIMITED` [#429-rate_limited]

Più di {facts.imageApiPerMinute} richieste al minuto da un singolo indirizzo IP. Attendi i secondi indicati in `Retry-After`. Lo stesso URL restituisce sempre la stessa immagine, quindi metti in cache o salva il file invece di caricarla dal vivo.

## Limiti [#limits]

- **Limite di frequenza:** {facts.imageApiPerMinute} richieste al minuto per indirizzo IP. Le immagini non usano la quota giornaliera della REST API.
- **Nessun controllo della scansione.** L'Image API disegna ciò che chiedi. Per verificare e correggere prima il punteggio di scansione di un design, usa `design_qr` sul [server MCP](/docs/developers/mcp), oppure il punteggio di scansione nel [Playground](/playground?tab=design).
- **`style` può essere lungo fino a 8.192 caratteri** nell'URL, e il suo JSON fino a 40 KB.
- **I dati fanno parte dell'URL.** Come qualsiasi URL, può finire nei log del server, nella cronologia del browser e nelle cache. Non inserirvi password o altri segreti.

## Consigli per la scansione [#scanning-tips]

- Tieni `margin` a `2` o più quando l'immagine si trova su uno sfondo scuro o movimentato, come un README nella modalità scura di GitHub.
- Mantieni un buon contrasto tra `fg` e `bg`. I moduli scuri su sfondo chiaro sono quelli che si leggono con più affidabilità.
- I valori predefiniti (moduli quadrati, margine di 4 moduli) funzionano con ogni lettore. Le forme stilizzate, come i punti `circle`, sono più morbide e alcuni scanner meno recenti le leggono con meno affidabilità: verifica con il [controllo della scansione](/tools/scan-checker).
- Prova il codice con qualche telefono prima di stamparlo.

## Self-hosting [#self-hosting]

L'endpoint fa parte dell'app web QRdx, quindi un'istanza [self-hosted](/docs/self-hosting) lo serve su `/api/v1/qr` nel tuo dominio (per esempio `https://qr.example.com/api/v1/qr?data=…`). Il percorso breve `/v1/qr` funziona solo su `api.qrdx.dev`. Il rate limiting usa Upstash Redis quando è configurato, altrimenti è disattivato.
