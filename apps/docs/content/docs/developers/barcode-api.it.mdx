Alla fine di questa pagina avrai l'URL di un'immagine di codice a barre da usare in un tag `<img>`, in un feed prodotti o in un modello di etichetta, saprai come vengono validati i check digit e i formati e come salvare i codici a barre in un workspace per modificarli in seguito.

`GET https://api.qrdx.dev/v1/barcode` restituisce l'immagine di un codice a barre. Tutto sta nella query string, quindi l'URL è l'immagine. Disegna gli stessi formati {facts.barcodeFormats} del [generatore di codici a barre](/barcode-generator), con le stesse regole, e restituisce lo stesso SVG. Non servono un account né una chiave API.

```html title="index.html"
<img
  src="https://api.qrdx.dev/v1/barcode?format=ean13&data=590123412345"
  alt="EAN-13 barcode 5901234123457"
/>
```

A quel numero manca una cifra, quindi viene aggiunto il check digit (7). Se invii tutte le 13 cifre, il check digit viene verificato: se è sbagliato ottieni `400` con il valore corretto.

## 1. Richiedi un'immagine [#1-request-an-image]

<Tabs groupId="language" persist items={["curl", "JavaScript", "Python"]}>
  <Tab value="curl">
    ```bash title="Terminal"
    curl -o box.png "https://api.qrdx.dev/v1/barcode?format=ean13&data=5901234123457&type=png&scale=3"
    ```
  </Tab>
  <Tab value="JavaScript">
    ```js title="barcode.mjs"
    import { writeFile } from "node:fs/promises";

    const url = new URL("https://api.qrdx.dev/v1/barcode");
    url.search = new URLSearchParams({
      format: "ean13",
      data: "5901234123457",
      type: "png",
      scale: "3",
    }).toString();

    const response = await fetch(url);
    await writeFile("box.png", Buffer.from(await response.arrayBuffer()));
    ```
  </Tab>
  <Tab value="Python">
    ```python title="barcode.py"
    import requests

    response = requests.get(
        "https://api.qrdx.dev/v1/barcode",
        params={"format": "ean13", "data": "5901234123457", "type": "png", "scale": 3},
    )
    response.raise_for_status()
    open("box.png", "wb").write(response.content)
    ```
  </Tab>
</Tabs>

```txt title="Output"
200 image/png
box.png: PNG image data, 385 x 237, 8-bit/color RGBA, non-interlaced
```

In una shell metti l'URL tra virgolette per mantenere il carattere `&`, e codifica i valori che contengono `&`, `#`, `+` o spazi, ad esempio con `encodeURIComponent` in JavaScript.

## 2. Altri esempi [#2-more-examples]

Un PDF vettoriale di un'etichetta logistica GS1-128, con parentesi attorno a ogni Application Identifier:

```bash title="Terminal"
curl -o pallet.pdf "https://api.qrdx.dev/v1/barcode?format=gs1-128&type=pdf&data=(01)09501101530003(17)261231(10)AB-123"
# 200 application/pdf, 1 page
```

Un'etichetta da scaffale Code 128 in blu scuro, senza il testo sotto le barre, ruotata di 90°:

```txt
https://api.qrdx.dev/v1/barcode?format=code128&data=SHELF-A12&fg=1e3a8a&text=false&rotate=90
```

Un Data Matrix con un margine più ampio:

```txt
https://api.qrdx.dev/v1/barcode?format=datamatrix&data=SN-0042-7781&quietZone=4
```

## 3. Tieni il valore fuori dall'URL [#3-keep-the-value-out-of-the-url]

`POST https://api.qrdx.dev/v1/barcode` accetta gli stessi campi in JSON e restituisce lo stesso file, senza cache. Usalo quando il valore non deve finire in log, cronologia o cache come può succedere con un URL:

```bash title="Terminal"
curl -o label.png https://api.qrdx.dev/v1/barcode \
  -H "Content-Type: application/json" \
  -d '{"format":"datamatrix","data":"Internal note 42","type":"png"}'
# 200 image/png, Cache-Control: no-store
```

In JSON, `text` è un booleano mentre `scale`, `height`, `quietZone` e `rotate` sono numeri. Un body inviato senza `Content-Type: application/json` genera un `415`:

```json title="415 Unsupported Media Type"
{"code":"UNSUPPORTED_MEDIA_TYPE","message":"Send a JSON body with Content-Type: application/json.","status":415}
```

## Parametri [#parameters]

| Parametro | Predefinito | Descrizione |
| --- | --- | --- |
| `format` | obbligatorio | Il tipo di codice a barre; vedi [Formati](#formats). Maiuscole e trattini non contano: funziona anche `EAN-13` |
| `data` | obbligatorio | Il numero o il testo da codificare, fino a 1.000 caratteri (meno per la maggior parte dei formati lineari) |
| `type` | `svg` | `svg`, `png`, `jpg`, `webp`, `avif`, `pdf` o `eps` |
| `scale` | `4` | Pixel per modulo in PNG, JPG, WebP e AVIF, da `1` a `10` |
| `height` | dipende dal formato | Altezza delle barre dei codici lineari in millimetri alla dimensione vettoriale, da `5` a `60` (23 per EAN-13) |
| `quietZone` | il minimo del formato | Margine bianco in moduli: su ogni lato dei codici lineari (da `0` a `20`), tutto attorno ai codici 2D (da `0` a `10`) |
| `text` | `true` | Stampa le cifre o il testo sotto i codici a barre lineari |
| `fg` | `000000` | Barre e testo, in esadecimale |
| `bg` | `ffffff` | Sfondo, in esadecimale |
| `rotate` | `0` | Rotazione in senso orario: `0`, `90`, `180` o `270` |

Scrivi i colori senza `#`, oppure codificalo come `%23`.

## Formati [#formats]

| `format` | Codice a barre | Accetta |
| --- | --- | --- |
| `ean13` | EAN-13 | 12 cifre (check digit aggiunto) o 13 (verificato) |
| `ean8` | EAN-8 | 7 cifre o 8 |
| `upca` | UPC-A | 11 cifre o 12 |
| `upce` | UPC-E | da 6 a 8 cifre, oppure un UPC-A di 12 cifre che può essere abbreviato |
| `itf14` | ITF-14 | 13 cifre o 14 |
| `gs1-128` | GS1-128 | Application Identifier tra parentesi con i loro valori; check digit di GTIN e SSCC aggiunti o verificati; fino a 48 caratteri di dati |
| `code128` | Code 128 | Fino a 80 caratteri ASCII stampabili |
| `code39` | Code 39 | Fino a 40 tra maiuscole, cifre, spazi e `- . $ / + %` |
| `datamatrix` | Data Matrix | Qualsiasi testo fino a 1.000 caratteri |
| `pdf417` | PDF417 | Qualsiasi testo fino a 1.000 caratteri |
| `aztec` | Aztec | Qualsiasi testo fino a 1.000 caratteri |

I numeri retail (EAN, UPC, ITF-14, il GTIN di GS1-128) sono concessi in licenza alle aziende da GS1. L'API disegna qualsiasi numero valido, ma non li emette né li registra.

## Dimensioni [#sizes]

PNG, JPG, WebP e AVIF usano `scale` pixel per modulo, cioè la larghezza della barra più sottile. Una cella 2D è larga due moduli.

SVG, PDF ed EPS sono vettoriali, con un punto per modulo (0,353 mm), quindi un EAN-13 con i valori predefiniti risulta di circa 45 × 28 mm, circa il 107% della dimensione nominale. Scala i file vettoriali nel tuo layout; per i codici a barre retail, mantieni tra l'80% e il 200% e non tagliare l'altezza delle barre.

## Risposte [#responses]

Una richiesta riuscita restituisce il file con:

- `Content-Type` del tipo di file. L'EPS arriva come download (`Content-Disposition: attachment`); gli altri si aprono inline con un nome file come `ean13-5901234123457.png`
- `Cache-Control: public, max-age=31536000, immutable` per `GET`: la stessa query restituisce sempre gli stessi byte. Le risposte `POST` sono `no-store`
- `Access-Control-Allow-Origin: *`, così puoi usare `fetch` da qualsiasi sito web

## Codici a barre salvati [#saved-barcodes]

Con una [chiave API](/docs/developers/api-keys), la REST API conserva i codici a barre nel workspace della chiave, dove compaiono sotto **Barcodes** nella dashboard. Stessi scope dei codici: `codes:read` per elencare e scaricare, `codes:write` per modificare.

```bash title="Terminal"
curl https://api.qrdx.dev/v1/barcodes \
  -H "Authorization: Bearer $QRDX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"format":"ean13","value":"590123412345","title":"Spring box"}'
```

```json title="201 Created"
{
  "data": {
    "id": "cmwgwqcxo0003iscgecog7m1b",
    "title": "Spring box",
    "format": "ean13",
    "formatLabel": "EAN-13",
    "value": "5901234123457",
    "options": {
      "foreground": "#000000",
      "background": "#ffffff",
      "showText": true,
      "barHeightMm": 23,
      "quietZone": 11,
      "scale": 4,
      "rotation": 0
    },
    "folderId": null,
    "imageUrl": "https://qrdx.dev/api/v1/barcode?format=ean13&data=5901234123457",
    "createdAt": "2026-11-14T21:18:01.212Z",
    "updatedAt": "2026-11-14T21:18:01.212Z",
    "deletedAt": null,
    "organizationId": "ws_ad2c5e1cce31ccf31535e78f08ab5b78"
  }
}
```

Il valore di 12 cifre è tornato con il suo check digit, e `options` contiene i valori predefiniti del formato. Ogni codice a barre salvato ha un `imageUrl`: la stessa immagine di `GET /v1/barcode`, che può caricare chiunque abbia il link. L'endpoint `/image` qui sotto è privato e richiede la chiave.

| Endpoint | Cosa fa |
| --- | --- |
| [`GET /v1/barcodes`](/docs/developers/api/list-barcodes) | Li elenca, dalla modifica più recente; filtra con `q`, `format`, `folderId`, `status=trash` |
| [`POST /v1/barcodes`](/docs/developers/api/create-barcode) | Ne salva uno. `options` accetta `foreground`, `background`, `showText`, `barHeightMm`, `quietZone`, `scale` e `rotation` |
| [`GET /v1/barcodes/{id}`](/docs/developers/api/get-barcode) | Un codice a barre |
| [`PATCH /v1/barcodes/{id}`](/docs/developers/api/update-barcode) | Ne modifica titolo, formato, valore, opzioni o cartella |
| [`DELETE /v1/barcodes/{id}`](/docs/developers/api/delete-barcode) | Lo sposta nel cestino (`{ "deleted": false, "trashed": true }`); `?permanent=true` lo elimina definitivamente |
| [`GET /v1/barcodes/{id}/image`](/docs/developers/api/get-saved-barcode-image) | Il file, disegnato come salvato: `type` e `scale` come sopra. `Cache-Control: private, no-store` |

Ogni piano permette di salvare codici a barre: fino a 1.000 con Gratuito, 10.000 con Pro e 100.000 con Business, cestino escluso. Queste richieste contano per la quota API giornaliera del workspace e inviano gli header `X-RateLimit-*`, come il resto della [REST API](/docs/developers/rest-api#rate-limits).

## Se qualcosa va storto [#if-something-goes-wrong]

### `400` con `"param": "data"` [#400-with-param-data]

Il valore viola le regole del formato. Il messaggio dice esattamente cosa, indicando un check digit, una lunghezza o un set di caratteri:

```json title="400 Bad Request"
{"code":"VALIDATION_ERROR","message":"Invalid query parameters","data":{"details":[{"param":"data","message":"EAN-13: The check digit should be 7, not 8. Check the number, or leave the last digit off and it's worked out for you."}]},"status":400}
```

```json title="400 Bad Request"
{"code":"VALIDATION_ERROR","message":"Invalid query parameters","data":{"details":[{"param":"data","message":"Code 39: Code 39 has no lowercase letters. Use capitals, or Code 128 for mixed case."}]},"status":400}
```

### `400` con `"param": "format"` [#400-with-param-format]

`format` manca o non è uno degli undici id in [Formati](#formats). Il messaggio li elenca.

### L'immagine raster viene rifiutata o tagliata [#the-raster-image-is-refused-or-cut]

Le immagini raster misurano al massimo 6.000 pixel per lato. Riduci `scale` per valori lunghi, oppure usa SVG o PDF.

### `429 RATE_LIMITED` [#429-rate_limited]

Hai superato {facts.imageApiPerMinute} richieste al minuto da un singolo indirizzo IP, contando insieme `GET` e `POST /v1/barcode`. Attendi i secondi indicati in `Retry-After`; le risposte `GET` possono essere messe in cache per un anno, quindi carica ogni immagine una sola volta.

## Limiti [#limits]

- **Rate limit:** {facts.imageApiPerMinute} richieste al minuto per indirizzo IP per `GET` e `POST /v1/barcode`, come per l'[API immagini QR](/docs/developers/image-api). I codici a barre salvati seguono i limiti al minuto della REST API e la quota giornaliera.
- **Dimensione dell'immagine:** le immagini raster misurano al massimo 6.000 pixel per lato.
- **Nessun controllo della scansione qui.** Il [generatore di codici a barre](/barcode-generator) decodifica ciò che disegna prima del download; l'API disegna ciò che chiedi. Stampa una prova e scansionala con gli scanner che la leggeranno.

## MCP [#mcp]

Il [server MCP](/docs/developers/mcp) ha `generate_barcode`, che controlla il valore e restituisce un PNG con gli URL delle immagini, e `save_barcode`, che salva nel workspace della chiave API usata nella connessione.

## Self-hosting [#self-hosting]

Gli endpoint fanno parte dell'app web QRdx, quindi un'istanza [self-hosted](/docs/self-hosting) li serve su `/api/v1/barcode` e `/api/v1/barcodes` sul tuo dominio.
