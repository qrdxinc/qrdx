À la fin de cette page, vous aurez l'image d'un QR code enregistrée à partir d'une seule requête, une clé API pour votre espace de travail, un QR code dynamique dont le QR imprimé continue de fonctionner après avoir changé la destination, et un premier aperçu de ses statistiques de scan.

L'API se compose de deux parties. Les images ne demandent rien : ni compte, ni clé. Les QR codes dynamiques, les scans et les webhooks appartiennent à un espace de travail, ils nécessitent donc une clé API.

## Avant de commencer [#before-you-start]

- curl, Node.js 18 ou version ultérieure, ou Python 3 avec le paquet `requests`. Choisissez l'onglet correspondant à votre outil ; ce choix est conservé d'une page à l'autre.
- Un compte QRdx pour les étapes 2 à 4. Un compte gratuit suffit : les espaces de travail Gratuit disposent de 10 QR codes dynamiques actifs et de 1 000 requêtes API par jour.

## 1. Générer l'image d'un QR code (sans clé) [#1-make-a-qr-code-image-no-key]

Exécutez ceci. Cela enregistre un PNG d'un QR code qui ouvre qrdx.dev.

<Tabs groupId="language" persist items={["curl", "JavaScript", "Python"]}>
  <Tab value="curl">
    ```bash title="Terminal"
    curl "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=png" -o qr.png
    ```
  </Tab>
  <Tab value="JavaScript">
    ```js title="qr.mjs"
    // Node 18 or later
    import { writeFile } from "node:fs/promises";

    const url = new URL("https://api.qrdx.dev/v1/qr");
    url.searchParams.set("data", "https://qrdx.dev");
    url.searchParams.set("format", "png");

    const response = await fetch(url);
    await writeFile("qr.png", Buffer.from(await response.arrayBuffer()));
    console.log(response.status, response.headers.get("content-type"));
    ```
  </Tab>
  <Tab value="Python">
    ```python title="qr.py"
    # pip install requests
    import requests

    response = requests.get(
        "https://api.qrdx.dev/v1/qr",
        params={"data": "https://qrdx.dev", "format": "png"},
    )
    response.raise_for_status()
    open("qr.png", "wb").write(response.content)
    print(response.status_code, response.headers["content-type"])
    ```
  </Tab>
</Tabs>

```txt title="Output"
200 image/png
qr.png: PNG image data, 512 x 512, 8-bit/color RGBA, non-interlaced
```

C'est un appel d'API fonctionnel. L'URL est elle-même l'image : elle fonctionne donc aussi directement dans une balise `<img>` :

```html title="index.html"
<img src="https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&fg=111111&body=circle" alt="QR code for qrdx.dev" />
```

Modifiez les couleurs, les formes, la taille et le format avec des paramètres de requête, ou essayez-les dans le navigateur sur la page [Générer l'image d'un QR code](/docs/developers/api/get-qr-image) : son panneau **Try it** envoie la requête et affiche l'image. Les images ne comptent dans aucun quota ; la limite est de {facts.imageApiPerMinute} requêtes par minute et par adresse IP.

## 2. Créer une clé API [#create-an-api-key]

Tout le reste de l'API agit sur un espace de travail : créer des QR codes dynamiques, modifier leur destination, lire leurs scans. Ces requêtes transmettent une clé API dans l'en-tête `Authorization`.

1. Ouvrez [Paramètres → Clés API et applications](/dashboard?to=settings/developers&new=1), en vous connectant d'abord si nécessaire. Le formulaire **Create API key** s'ouvre.
2. Donnez un nom à la clé, par exemple celui du serveur sur lequel elle sera utilisée, conservez **Full access** et choisissez **Create key**. QRdx peut d'abord vous demander de confirmer votre identité.
3. Copiez la clé depuis la boîte de dialogue **Copy your API key**. Elle n'est affichée qu'une seule fois : QRdx n'en conserve qu'un hash et ne peut plus l'afficher. La boîte de dialogue montre aussi une requête curl qui crée un QR code dynamique, avec votre clé déjà renseignée, si vous préférez la coller telle quelle.

<Shot id="create-key-dialog" />

<Shot id="api-key-copy-dialog" />

Exportez la clé pour les étapes suivantes :

```bash title="Terminal"
export QRDX_API_KEY=qrdx_...
```

La clé agit en votre nom dans l'espace de travail qui était ouvert lors de sa création, et les requêtes qui l'utilisent comptent dans le quota quotidien de cet espace de travail. [Clés API](/docs/developers/api-keys) détaille les portées, les équipes, l'expiration et la révocation.

## 3. Créer un QR code dynamique [#3-create-a-dynamic-code]

Un QR code dynamique est un lien court dont vous pouvez modifier la destination après l'impression :

<Tabs groupId="language" persist items={["curl", "JavaScript", "Python"]}>
  <Tab value="curl">
    ```bash title="Terminal"
    curl -X POST https://api.qrdx.dev/v1/codes \
      -H "Authorization: Bearer $QRDX_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"destinationUrl": "https://example.com", "title": "My first code"}'
    ```
  </Tab>
  <Tab value="JavaScript">
    ```js title="create.mjs"
    const response = await fetch("https://api.qrdx.dev/v1/codes", {
      method: "POST",
      headers: {
        Authorization: `Bearer ${process.env.QRDX_API_KEY}`,
        "Content-Type": "application/json",
      },
      body: JSON.stringify({
        destinationUrl: "https://example.com",
        title: "My first code",
      }),
    });
    const { data: code } = await response.json();
    console.log(response.status, code.id, code.shortLink);
    ```
  </Tab>
  <Tab value="Python">
    ```python title="create.py"
    import os
    import requests

    response = requests.post(
        "https://api.qrdx.dev/v1/codes",
        headers={"Authorization": f"Bearer {os.environ['QRDX_API_KEY']}"},
        json={"destinationUrl": "https://example.com", "title": "My first code"},
    )
    response.raise_for_status()
    code = response.json()["data"]
    print(response.status_code, code["id"], code["shortLink"])
    ```
  </Tab>
</Tabs>

La réponse est `201 Created` avec le nouveau code :

```json title="201 Created"
{
  "data": {
    "id": "cmwgwq0t80000iscg4ybn05kh",
    "slug": "l0q9fZn",
    "shortLink": "https://qrdx.dev/q/l0q9fZn",
    "defaultShortLink": "https://qrdx.dev/q/l0q9fZn",
    "nfcLink": "https://qrdx.dev/q/l0q9fZn?nfc",
    "domain": null,
    "destinationUrl": "https://example.com/",
    "title": "My first code",
    "contentType": "url",
    "kind": "redirect",
    "pageId": null,
    "status": "active",
    "style": null,
    "scanCount": 0,
    "lastScannedAt": null,
    "archivedAt": null,
    "createdAt": "2026-11-14T21:17:45.512Z",
    "updatedAt": "2026-11-14T21:17:45.512Z",
    "organizationId": "ws_ad2c5e1cce31ccf31535e78f08ab5b78",
    "preciseLocation": false
  }
}
```

Deux champs comptent maintenant. `shortLink` est ce que le QR code encode : générez-le avec l'Image API de l'étape 1, `https://api.qrdx.dev/v1/qr?data=https://qrdx.dev/q/l0q9fZn&format=png`, puis imprimez-le. `id` est la façon dont vous désignez le code désormais, conservez-le :

```bash title="Terminal"
export CODE_ID=cmwgwq0t80000iscg4ybn05kh
```

[Créer des codes](/docs/developers/api/create-codes) liste tous les champs que vous pouvez envoyer, notamment une fin de lien personnalisée et un design.

## 4. Le rediriger ailleurs [#4-point-it-somewhere-else]

Changez la destination à tout moment ; le code imprimé continue de fonctionner :

```bash title="Terminal"
curl -X PATCH https://api.qrdx.dev/v1/codes/$CODE_ID \
  -H "Authorization: Bearer $QRDX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"destinationUrl": "https://example.com/new-page"}'
```

La réponse `200 OK` est le même code avec `"destinationUrl": "https://example.com/new-page"` et un nouveau `updatedAt`. Scannez le code avec votre téléphone, puis consultez ses statistiques :

```bash title="Terminal"
curl "https://api.qrdx.dev/v1/codes/$CODE_ID/scans?range=7d" \
  -H "Authorization: Bearer $QRDX_API_KEY"
```

```json title="200 OK (before the first scan, trimmed)"
{
  "data": {
    "codeId": "cmwgwq0t80000iscg4ybn05kh",
    "range": "7d",
    "retentionDays": 365,
    "days": 7,
    "total": 0,
    "unique": 0,
    "interval": "day",
    "series": [{ "date": "2026-11-08", "count": 0 }, { "date": "2026-11-09", "count": 0 }],
    "countries": [],
    "devices": [],
    "sources": { "qr": 0, "nfc": 0 }
  }
}
```

Après un scan, `total` augmente et `countries`, `cities`, `devices`, `os` et `browsers` se remplissent. [Obtenir les statistiques de scan](/docs/developers/api/get-code-scans) explique les plages de dates et la façon de parcourir les scans individuels page par page.

## En cas de problème [#if-something-goes-wrong]

Chaque erreur est renvoyée en JSON avec un `code` stable et un message qui indique quoi faire. Les deux que vous risquez le plus de rencontrer sur cette page :

```json title="401 Unauthorized: the header is missing"
{
  "code": "UNAUTHORIZED",
  "message": "Missing API key. Send an API key as \"Authorization: Bearer <key>\"; create one at https://qrdx.dev/dashboard?to=settings/developers. OAuth access tokens go in the same header.",
  "status": 401,
  "docs": "https://qrdx.dev/docs/developers/api-keys"
}
```

```json title="400 Bad Request: the destination isn't a full URL"
{
  "code": "VALIDATION_ERROR",
  "message": "Invalid request body",
  "data": { "details": [{ "path": "destinationUrl", "message": "Enter a full URL, starting with https://" }] },
  "status": 400
}
```

Une erreur `401 INVALID_TOKEN` signifie que la clé a été copiée incomplète, révoquée ou qu'elle a expiré : créez-en une nouvelle. Une erreur `403 INSUFFICIENT_SCOPE` signifie que vous avez créé une clé **Read only** ; l'étape 3 nécessite `codes:write`. La [page des erreurs](/docs/developers/errors) liste chaque code avec sa solution.

## Agir pour d'autres personnes [#get-an-access-token]

Une clé API agit en votre nom. Si votre produit appelle QRdx pour d'autres personnes, enregistrez plutôt une application OAuth : chaque personne l'approuve une fois, et votre serveur obtient un jeton d'accès pour son compte, envoyé dans le même en-tête `Authorization: Bearer`. Toutes les requêtes ci-dessus fonctionnent sans changement avec un jeton à la place de la clé. Consultez [REST API et OAuth](/docs/developers/rest-api#get-an-access-token) et [Créer une intégration](/docs/developers/build-an-integration).
