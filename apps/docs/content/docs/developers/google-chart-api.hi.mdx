इस पेज के अंत तक, आपके पेजों, ईमेल या स्प्रेडशीट में `chart.googleapis.com` से लोड होने वाला हर QR कोड उसी साइज़ और error correction level पर QRdx [image API](/docs/developers/image-api) से लोड होगा, बिना किसी अकाउंट या key के।

Google ने अप्रैल 2012 में अपने Image Charts को deprecate कर दिया था, जिनमें `chart.googleapis.com/chart?cht=qr` वाले QR कोड भी शामिल थे। यह endpoint आज `404` देता है (15 नवंबर 2026 को जाँचा गया), इसलिए हर पुराना `<img>` टैग टूटी हुई इमेज दिखाता है। QRdx image API भी उसी तरह काम करती है, यानी एक `GET` URL जो इमेज लौटाता है, इसलिए बदलाव में बस नया host और तीन बदले हुए पैरामीटर हैं।

## शुरू करने से पहले [#before-you-start]

- वे फ़ाइलें ढूँढें जो अभी भी पुरानी API इस्तेमाल करती हैं। नीचे की कमांड उन्हें लिस्ट करती है, पुराने `chart.apis.google.com` host समेत:

```bash title="Terminal"
grep -rlE "chart\.(googleapis|apis\.google)\.com/chart" .
```

- git checkout में या किसी ऐसी जगह काम करें जहाँ बदलाव लाइव होने से पहले आप उसे रिव्यू कर सकें।

## 1. एक URL की तुलना करें [#1-compare-one-url]

नीचे के दोनों URL एक ही चीज़ बनाते हैं: `https://example.com` का 300 × 300 PNG, error correction `M` और 2-module margin के साथ।

```txt title="Before and after"
https://chart.googleapis.com/chart?cht=qr&chs=300x300&chl=https%3A%2F%2Fexample.com&chld=M|2
https://api.qrdx.dev/v1/qr?format=png&size=300&data=https%3A%2F%2Fexample.com&level=M&margin=2
```

```bash title="Terminal"
curl -o after.png "https://api.qrdx.dev/v1/qr?format=png&size=300&data=https%3A%2F%2Fexample.com&level=M&margin=2"
file after.png
# after.png: PNG image data, 300 x 300, 8-bit/color RGBA, non-interlaced
```

## 2. पैरामीटर मैप करें [#2-map-the-parameters]

| Google Chart | QRdx | नोट्स |
| --- | --- | --- |
| `cht=qr` | ज़रूरत नहीं | यह endpoint सिर्फ़ QR कोड बनाता है। छोड़ देने पर इसे अनदेखा किया जाता है |
| `chl=<data>` | `data=<data>` | उसी तरह URL-encode करें, 2,048 characters तक |
| `chs=<width>x<height>` | `size=<width>` | एक ही संख्या, क्योंकि QR कोड चौकोर होते हैं: `64` से `2048` pixel |
| `chld=<level>\|<margin>` | `level=<level>&margin=<margin>` | वही अक्षर, `L`, `M`, `Q` और `H`। margin modules में होता है, `0` से `16` |
| `choe=UTF-8` | ज़रूरत नहीं | QRdx टेक्स्ट को हमेशा UTF-8 में encode करता है, जो Google का भी default था। Shift_JIS या ISO-8859-1 का विकल्प नहीं है। छोड़ देने पर इसे अनदेखा किया जाता है |
| हमेशा PNG | `format=png` | QRdx SVG लौटाता है, जब तक आप `png`, `webp` या `eps` न माँगें। ईमेल के लिए PNG ही रखें, क्योंकि कई ईमेल क्लाइंट SVG नहीं दिखाते |

दो defaults अलग हैं। `chld` न होने पर Google error correction `L` इस्तेमाल करता था; QRdx `Q` इस्तेमाल करता है, जो ज़्यादा नुकसान सह लेता है लेकिन कोड को ज़्यादा घना बनाता है। पुराना लुक चाहिए तो `level=L` जोड़ें। दोनों का default margin 4 modules है।

## 3. अपनी फ़ाइलों में URL दोबारा लिखें [#3-rewrite-the-urls-in-your-files]

यह आपकी बताई फ़ाइलों में हर Google Chart QR URL को दोबारा लिखता है, दोनों host समेत: यह host और path बदलता है, `chl`, `chs` और `chld` का नाम बदलता है, और `format=png` जोड़ता है ताकि इमेज PNG ही रहें। Perl macOS और ज़्यादातर Linux distributions के साथ आता है।

```bash title="Terminal"
perl -pi -e 's{https?://chart\.(?:googleapis|apis\.google)\.com/chart\?([^\s"\x27<>)]*)}{my $q = $1; $q =~ s/(^|[&;])chl=/${1}data=/; $q =~ s/(^|[&;])chs=(\d+)x\d+/${1}size=$2/; $q =~ s/(^|[&;])chld=([LMQH])(?:\||%7C)(\d+)/${1}level=$2&margin=$3/i; $q =~ s/(^|[&;])chld=([LMQH])/${1}level=$2/i; "https://api.qrdx.dev/v1/qr?format=png&$q"}ge' index.html
```

तीन पुराने टैग वाली फ़ाइल पर चलाने पर यह ऐसा नतीजा देता है:

```html title="index.html (after)"
<img src="https://api.qrdx.dev/v1/qr?format=png&cht=qr&size=300&data=https%3A%2F%2Fexample.com&level=M&margin=2" alt="QR">
<img src="https://api.qrdx.dev/v1/qr?format=png&cht=qr&size=150&data=https%3A%2F%2Fexample.com%2Fmenu" alt="QR 2">
<img src="https://api.qrdx.dev/v1/qr?format=png&size=200&cht=qr&data=hello&level=H&choe=UTF-8" alt="QR 3">
```

बचे हुए `cht=qr` और `choe=UTF-8` को QRdx अनदेखा करता है; साफ़-सुथरे URL चाहिए तो उन्हें हाथ से हटा दें। diff जाँचें, फिर शुरुआत वाली `grep` दोबारा चलाएँ: उसे कुछ भी लिस्ट नहीं करना चाहिए।

## 4. URL बनाने वाला कोड बदलें [#4-change-the-code-that-builds-urls]

```js title="qr.js"
// Before
const src = `https://chart.googleapis.com/chart?cht=qr&chs=200x200&chl=${encodeURIComponent(link)}`;

// After
const src = `https://api.qrdx.dev/v1/qr?format=png&size=200&data=${encodeURIComponent(link)}`;
```

Google Sheets में:

```txt title="Sheets formula"
=IMAGE("https://api.qrdx.dev/v1/qr?format=png&size=150&data="&ENCODEURL(A2))
```

Sheets इमेज Google के अपने servers से लोड करता है, इसलिए सैकड़ों कोड वाली शीट नीचे बताई गई प्रति-IP सीमा तक पहुँच सकती है। लंबी लिस्ट के लिए, फ़ाइलें एक बार [bulk generator](/tools/bulk) से या [CLI](/docs/developers/cli) के `qrdx batch` से बना लें।

## अगर कुछ गड़बड़ हो [#if-something-goes-wrong]

### `"param": "size"` के साथ `400` [#400-with-param-size]

64 pixel से छोटा `chs` (जैसे `50x50`) या 2048 से बड़ा `chs` मना कर दिया जाता है। ऐसे साइज़ हाथ से बदलें; `64` सबसे छोटा साइज़ है जो image API बनाती है।

```json title="400 Bad Request"
{"code":"VALIDATION_ERROR","message":"Invalid query parameters","data":{"details":[{"param":"size","message":"Too small: expected number to be >=64"}]},"status":400}
```

### इमेज पहले से ज़्यादा घनी है [#the-image-is-denser-than-before]

Google का default error correction `L` था; QRdx का `Q` है। पुराने लुक से मिलाने के लिए `level=L` जोड़ें।

### bulk reload के बाद `429` [#429-after-a-bulk-reload]

image API हर IP address से प्रति मिनट {facts.imageApiPerMinute} requests की अनुमति देती है। `Retry-After` header में बताए सेकंड रुकें, या फ़ाइलें लाइव लोड करने की जगह एक बार बना लें।

## और क्या जानना चाहिए [#what-else-to-know]

- **Caching:** एक ही URL हमेशा वही bytes लौटाता है, इसलिए responses एक साल के लिए cache होते हैं (`Cache-Control: public, max-age=31536000, immutable`)।
- **और विकल्प:** रंग (`fg`, `bg`), module और eye के आकार, logo आइकन (`logoIcon`) और frames। इन्हें [URL builder](/qr-code-api) में आज़माएँ, या [पैरामीटर](/docs/developers/image-api#parameters) पढ़ें।
- **Self-hosting:** [self-hosted](/docs/self-hosting) QRdx आपके अपने डोमेन पर `/api/v1/qr` पर वही API देता है।
