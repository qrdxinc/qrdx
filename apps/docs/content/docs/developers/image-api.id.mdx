Setelah membaca halaman ini, Anda akan memiliki URL gambar kode QR yang dapat ditempel ke README, tag `<img>`, atau templat email, dengan gaya sesuai keinginan Anda, dan Anda akan tahu apa yang ditolak oleh API beserta alasannya.

`GET https://api.qrdx.dev/v1/qr` mengembalikan kode QR sebagai gambar SVG, PNG, atau WebP, atau sebagai file EPS vektor untuk alat cetak dan desain. Semuanya ada di query string, jadi URL itu sendiri adalah gambarnya. API ini juga mendukung gaya dari editor: gradien, bingkai (termasuk bingkai kustom), border, warna mata dan titik, serta ikon logo. Tidak perlu akun atau kunci API, kecuali untuk logo yang Anda unggah ke QRdx (lihat [Logo](#logos)).

```md title="README.md"
![QR code](https://api.qrdx.dev/v1/qr?data=https://github.com/you/repo)
```

[Coba di playground](/playground?open=code&lang=image): atur gaya kode di sana, lalu salin URL gambarnya. Atau kirim permintaan dari halaman referensi [Render gambar kode QR](/docs/developers/api/get-qr-image).

## 1. Minta gambar [#1-request-an-image]

<Tabs groupId="language" persist items={["curl", "JavaScript", "Python"]}>
  <Tab value="curl">
    ```bash title="Terminal"
    curl -o qr.png "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=png&size=1024"
    ```
  </Tab>
  <Tab value="JavaScript">
    ```js title="qr.mjs"
    import { writeFile } from "node:fs/promises";

    const url = new URL("https://api.qrdx.dev/v1/qr");
    url.searchParams.set("data", "https://qrdx.dev");
    url.searchParams.set("format", "png");
    url.searchParams.set("size", "1024");

    const response = await fetch(url);
    await writeFile("qr.png", Buffer.from(await response.arrayBuffer()));
    ```
  </Tab>
  <Tab value="Python">
    ```python title="qr.py"
    import requests

    response = requests.get(
        "https://api.qrdx.dev/v1/qr",
        params={"data": "https://qrdx.dev", "format": "png", "size": 1024},
    )
    response.raise_for_status()
    open("qr.png", "wb").write(response.content)
    ```
  </Tab>
</Tabs>

```txt title="Output"
qr.png: PNG image data, 1024 x 1024, 8-bit/color RGBA, non-interlaced
```

Beri tanda kutip pada URL di shell agar `&` tetap ada. Di halaman HTML, URL langsung dimasukkan ke `src`:

```html title="index.html"
<img
  src="https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&size=256&fg=155dfc"
  width="256"
  height="256"
  alt="QR code for qrdx.dev"
/>
```

## 2. Pilih format [#2-pick-a-format]

| `format` | Hasil | Kapan digunakan |
| --- | --- | --- |
| `svg` (default) | `image/svg+xml` | Halaman web dan apa pun yang perlu diskalakan |
| `png` | `image/png` | Email, aplikasi chat, dokumen |
| `webp` | `image/webp`, lossless, transparansi dipertahankan | Situs web: piksel yang sama dengan PNG dalam file yang lebih kecil |
| `eps` | `application/postscript`, dikirim sebagai unduhan `qr-code.eps` | Illustrator, InDesign, percetakan. `size` kemudian adalah lebar dalam poin, 72 per inci, jadi `144` berarti 2 inci |

```bash title="Terminal"
curl -o qr.webp "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=webp&size=1024"
curl -o qr.eps "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=eps&size=144"
head -2 qr.eps
# %!PS-Adobe-3.0 EPSF-3.0
# %%BoundingBox: 0 0 144 144
```

## 3. Atur gayanya [#3-style-it]

Parameter datar mencakup warna, bentuk, bingkai, dan logo:

```txt title="Rounded modules with a frame drawn as a template"
https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&body=rounded&eye=rounded&dot=rounded&template=Arrow
```

```txt title="A built-in frame with its label, and a community frame by id"
https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&frame=banner-bottom&frameText=Scan%20the%20menu
https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&item=frame:wifi-card
```

Untuk gradien, bingkai kustom, dan warna per mata, kirim seluruh desain sebagai JSON di `style`:

```js title="styled.mjs"
const style = {
  fgColor: {
    type: "linear",
    angle: 45,
    stops: [
      { color: "#1d4ed8", offset: 0 },
      { color: "#7c3aed", offset: 100 },
    ],
  },
  eyeColor: "#b91c1c",
  frame: { style: "banner-bottom", text: "Scan the menu" },
};
const src = `https://api.qrdx.dev/v1/qr?data=${encodeURIComponent(link)}&style=${encodeURIComponent(JSON.stringify(style))}`;
// 200 image/svg+xml, 634.88 × 727.04: the frame adds to the 512 px code
```

<Callout type="info">
Enkode nilai `data` jika berisi `&`, `#`, `+`, atau spasi, misalnya dengan `encodeURIComponent` di JavaScript. Jika tidak, URL akan terpotong pada karakter tersebut. Enkode `style` dengan cara yang sama, dan tulis warna tanpa `#` (atau sebagai `%23`): `#` saja akan memulai fragmen URL dan tidak pernah dikirim.
</Callout>

## Parameter [#parameters]

| Parameter | Default | Deskripsi |
| --- | --- | --- |
| `data` | wajib | Teks atau URL yang akan dienkode, hingga 2048 karakter |
| `format` | `svg` | `svg`, `png`, `webp`, atau `eps` |
| `size` | `512` | Lebar dan tinggi dalam piksel, `64` hingga `2048` (poin untuk EPS) |
| `fg` | `000000` | Warna modul dalam hex (`155dfc`, `fff`, atau 8 digit dengan alfa) |
| `bg` | `ffffff` | Warna latar dalam hex. `00000000` menghasilkan latar transparan |
| `eyeColor` | `fg` | Warna ketiga mata sudut |
| `dotColor` | `fg` | Warna titik di dalam setiap mata sudut |
| `body` | `square` | Bentuk modul data; lihat [Nilai pola](#pattern-values) |
| `eye` | `square` | Bentuk bingkai mata sudut |
| `dot` | `square` | Bentuk titik di dalam setiap mata sudut |
| `level` | `Q` | Koreksi kesalahan: `L` (sekitar 7%), `M` (15%), `Q` (25%), atau `H` (30%) |
| `margin` | `4` | Zona tenang di sekitar kode dalam modul, `0` hingga `16` |
| `template` | tidak ada | [Bingkai yang digambar sebagai templat](/docs/features/templates): seluruh gambar selebar `size`, dengan kode yang lebih kecil di dalamnya |
| `frame` | tidak ada | [Bingkai](/docs/features/frames) ajakan bertindak bawaan, seperti `banner-bottom`, `speech-bubble`, atau `circle`: salah satu dari {facts.frameStyles} bingkai bawaan |
| `frameText` | `Scan me` | Label bingkai, hingga 24 karakter. Juga mengganti label bingkai dari `style` atau `item` |
| `style` | tidak ada | Seluruh desain editor sebagai JSON; lihat [Gaya](#style) |
| `item` | tidak ada | Bingkai atau tema komunitas berdasarkan id, seperti `frame:wifi-card`; lihat [Item komunitas](#community-items) |
| `logoIcon` | tidak ada | Ikon cepat atau logo merek di tengah; lihat [Logo](#logos) |
| `logoFileId` | tidak ada | Logo yang Anda unggah, berdasarkan id file; memerlukan kunci API; lihat [Logo](#logos) |

Nilai enum (`level`, `format`, `template`, `frame`) tidak peka huruf besar/kecil. Dengan bingkai, `size` adalah lebar kode itu sendiri dan bingkai menambah ukuran gambar, di semua format. Parameter datar mengalahkan `style`, dan `style` mengalahkan `item`.

## Gaya [#style]

`style` menerima desain sebagai JSON dengan bidang yang sama seperti tema tersimpan, sehingga tema dari [`GET /v1/themes`](/docs/developers/api/list-themes) atau `qrdxStyle` yang dikembalikan `design_qr` dari [server MCP](/docs/developers/mcp) dapat diteruskan apa adanya (kecuali logo yang diunggah, lihat di bawah):

| Bidang | Menerima |
| --- | --- |
| `bgColor`, `fgColor`, `eyeColor`, `dotColor` | Warna (hex seperti `#155dfc`, `rgb()`, `hsl()`, atau nama warna), atau gradien: `{ "type": "linear", "angle": 45, "stops": [...] }` atau `{ "type": "radial", "stops": [...] }`, dengan 2 hingga 8 stop berupa `{ "color", "offset" }` (offset 0 hingga 100) |
| `bodyPattern`, `cornerEyePattern`, `cornerEyeDotPattern` | [Nilai pola](#pattern-values) |
| `level`, `margin` | Sama seperti parameter di atas (`margin` 0 hingga 16) |
| `templateId` | Bingkai yang digambar sebagai templat, `default` untuk tanpa templat |
| `frame` | Bingkai bawaan, `{ "style": "banner-bottom", "text": "Scan me", "color": "#155dfc", "textColor": "#ffffff" }`, atau bingkai kustom, `{ "style": "custom", "spec": { … } }`, dengan spesifikasi bingkai dari [komunitas](#community-items) atau bingkai kustom yang dibuat di bagian Bingkai playground. Spesifikasi diperiksa berdasarkan aturan spesifikasi bingkai mesin (tanpa markup, tautan, atau gambar; maksimal 32 KB) |
| `eyeColors` | Warna per mata, di atas `eyeColor` dan `dotColor`: `{ "topLeft": { "outer": "#b91c1c", "inner": "#1d4ed8" }, "topRight": …, "bottomLeft": … }`, masing-masing berupa warna atau gradien |
| `moduleScale` | Ukuran setiap titik, `0.5` hingga `1` (default `1`) |
| `shape` | `square` (default) atau `circle`: kode di dalam cakram berisi titik dekoratif |
| `autoLevel` | Naikkan koreksi kesalahan ke `H` ketika logo menutupi lebih dari 7% kode (selalu aktif di sini ketika ada logo) |
| `logoOptions` | Tata letak logo: `size` (`0.1` hingga `0.3` dari lebar kode; QRdx memperkecilnya ketika kode tidak punya cukup modul), `padding` (`0` hingga `2` modul), `x` dan `y` (`0` hingga `1`), `shape` (potongan `square`, `rounded`, atau `circle`), dan `plate` (warna di belakangnya) |
| `showLogo`, `logoIcon`, `logoFileId` | Lihat [Logo](#logos) |

`style` juga menerima nilai `style` dari tautan playground (diawali `1.`), sehingga desain yang dibagikan dari [playground](/playground) dirender sama seperti tampilannya di sana, tanpa logonya. Bidang yang tidak dikenal, alamat logo (`customLogo`), dan seni Logo QR atau Image QR (`art`) ditolak dengan `400` yang menjelaskan alasannya:

```json title="400 Bad Request"
{"code":"VALIDATION_ERROR","message":"Invalid query parameters","data":{"details":[{"param":"style.customLogo","message":"Logo images by address aren't accepted: upload the image to QRdx and pass its file id as logoFileId, or pick a logoIcon."}]},"status":400}
```

## Item komunitas [#community-items]

`item` merender bingkai atau tema [komunitas](/community) yang dipublikasikan, gratis di bawah CC0. Temukan id dengan [`GET /v1/community/items`](/docs/developers/api/list-community-items), atau buka halaman item dan gunakan tipe serta slug-nya: `/community/frames/wifi-card` menjadi `frame:wifi-card`. Item bingkai ditempatkan pada kode hitam di atas putih polos; tambahkan `style` atau parameter datar untuk mengubah kode di bawahnya. Hasil render dengan `item` di-cache selama 5 menit (10 menit di CDN), karena sebuah item bisa mendapat versi baru atau diturunkan.

## Logo [#logos]

- **Ikon cepat.** `logoIcon` menempatkan salah satu ikon editor pada ubin putih di bagian tengah: `wifi`, `location`, `phone`, `email`, `link`, `file`, `calendar`, `whatsapp` atau `instagram`. QRdx menggambarnya sendiri, dan tidak memerlukan kunci.
- **Logo merek.** `logoIcon` juga menerima salah satu dari {facts.brandLogos} merek dari [Simple Icons](https://simpleicons.org) berdasarkan slug: `spotify`, `paypal`, `googlemaps`, `appstore`. Logo digambar polos dengan warna mereknya; tambahkan `:black` atau `:white` untuk warna tersebut (`whatsapp:white`), dan `logoOptions.plate` di `style` untuk pelat di belakangnya. [`GET /api/brand-logos`](https://qrdx.dev/api/brand-logos) menampilkan daftar semua slug. Slug yang tidak dimiliki QRdx akan mendapat `400` yang menyarankan bentuk yang benar.
- **Logo QRdx** yang ditampilkan editor secara default tidak digambar di sini: `showLogo: true` saja tidak menambahkan logo.
- **Koreksi kesalahan naik untuk logo.** Jika logo menutupi lebih dari 7% kode, kode digambar pada level `H`, apa pun nilai `level`, sehingga tetap dapat dipindai.

```bash title="Terminal"
curl -o spotify.png "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=png&logoIcon=spotify"
```

<IfAvailable feature="fileStorage">

**Logo Anda sendiri.** `logoFileId` menggambar PNG atau JPEG hingga 1 MB yang Anda unggah di [Dasbor → File](/docs/files). Id adalah bagian terakhir dari tautan file, `https://qrdx.dev/api/files/<id>`. Kirim [kunci API](/docs/developers/api-keys) dari workspace pemilik file:

```bash title="Terminal"
curl -o qr.png -H "Authorization: Bearer $QRDX_API_KEY" \
  "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=png&logoFileId=<id>"
```

Responsnya bersifat privat (`Cache-Control: private, no-store`) dan dihitung dalam kuota API harian workspace. File dari workspace lain mendapat `404`, dan permintaan tanpa kunci mendapat `401`. QRdx membaca gambar dari penyimpanannya sendiri dan memeriksa bahwa file tersebut benar-benar PNG atau JPEG; QRdx tidak pernah mengambil logo dari alamat web yang Anda kirim.

</IfAvailable>

`logoOptions` mengatur ukuran, penempatan, pemotongan, dan latar dari semua logo ini. Menghapus latar belakang bawaan logo yang diunggah dilakukan di Playground; Image API menggambar file yang diunggah apa adanya. Seni Logo QR dan Image QR tidak tersedia di sini: Playground membuatnya dari gambar Anda di browser. Rancang kode seni di [Playground](/playground?tab=art), atau ubah kode menjadi karya seni AI dengan [API seni AI](/docs/developers/ai-art-api).

### Nilai pola [#pattern-values]

- `body`: `circle`, `circle-large`, `square`, `diamond`, `circle-mixed`, `pacman`, `rounded`, `small-square`, `vertical-line`, `horizontal-line`, `liquid`, `liquid-horizontal`, `liquid-vertical`, `classy`, `classy-rounded`, `leaf`, `plus`, `hexagon`, `star`, `heart`, `random-dots`, `mosaic`, `octagon`
- `eye`: `square`, `rounded`, `gear`, `circle`, `diya`, `extra-rounded`, `message`, `pointy`, `leaf`, `drop`, `octagon`, `bevel`, `squircle`, `cushion`, `shield`, `petal`, `leaf-reverse`
- `dot`: `square`, `rounded`, `circle`, `message`, `message-reverse`, `diya`, `diya-reverse`, `rounded-triangle`, `leaf`, `drop`, `plus`, `cross-rounded`, `hexagon`, `octagon`, `flower`, `heart`, `squircle`, `dots`, `extra-rounded`, `leaf-reverse`, `drop-reverse`
- `template`: `default`, `Arrow`, `StandardBox`, `SquareBorder`, `StrikedBox`, `Halloween`, `DotRing`

Ini adalah gaya yang sama dengan [pustaka React `qrdx`](/docs/features/patterns). [Server MCP](/docs/developers/mcp) juga dapat menampilkan daftarnya beserta deskripsi singkat.

## Respons [#responses]

Permintaan yang berhasil mengembalikan gambar dengan:

- `Content-Type: image/svg+xml`, `image/png`, `image/webp` atau `application/postscript` (EPS dikirim sebagai unduhan `qr-code.eps`)
- `Cache-Control: public, max-age=31536000, immutable`, kecuali untuk render dengan `item` (5 menit, 10 di CDN) dan dengan `logoFileId` (`private, no-store`)
- `Access-Control-Allow-Origin: *`, sehingga Anda dapat memanggilnya dengan `fetch` dari situs web mana pun

Proses render bersifat deterministik: query string yang sama selalu menghasilkan byte yang sama, itulah sebabnya respons dapat di-cache selama setahun. URL yang hanya memakai parameter asli dirender persis seperti biasanya.

## Jika terjadi masalah [#if-something-goes-wrong]

### `400` dengan `"param": "size"` [#400-with-param-size]

`size` kurang dari 64 atau lebih dari 2048. Isi respons menyebutkan batasnya:

```json title="400 Bad Request"
{"code":"VALIDATION_ERROR","message":"Invalid query parameters","data":{"details":[{"param":"size","message":"Too small: expected number to be >=64"}]},"status":400}
```

### `400` dengan `"param": "data"` [#400-with-param-data]

Data tidak muat dalam kode QR pada level koreksi kesalahan yang dipilih. Gunakan `level` yang lebih rendah (`L` menampung paling banyak) atau data yang lebih pendek; tautan pendek dari kode QR dinamis biasanya menjadi solusi untuk URL panjang.

```json title="400 Bad Request"
{"code":"VALIDATION_ERROR","message":"Invalid query parameters","data":{"details":[{"param":"data","message":"Data is too long for a QR code at error correction level H. Shorten it or use a lower level (L holds the most)."}]},"status":400}
```

### `400` dengan `"param": "logoIcon"` [#400-with-param-logoicon]

Slug bukan merek yang dimiliki QRdx maupun ikon cepat. Pesan tersebut menyarankan bentuk yang berfungsi (`spotify`, `paypal`, `googlemaps`, atau `wifi`, `phone`, `email`).

### Gambar tampak salah atau terpotong [#the-image-looks-wrong-or-is-split]

Karakter `&`, `#` atau `+` di `data` atau `style` tidak di-encode, sehingga URL terpotong pada karakter tersebut. Encode kedua nilai itu, dan tulis warna tanpa `#`.

### `429 RATE_LIMITED` [#429-rate_limited]

Lebih dari {facts.imageApiPerMinute} permintaan per menit dari satu alamat IP. Tunggu sesuai jumlah detik pada `Retry-After`. URL yang sama selalu mengembalikan gambar yang sama, jadi simpan di cache atau simpan filenya alih-alih memuatnya secara langsung.

## Batas [#limits]

- **Batas laju:** {facts.imageApiPerMinute} permintaan per menit per alamat IP. Gambar tidak menggunakan kuota harian REST API.
- **Tanpa pemeriksaan pemindaian.** Image API menggambar apa yang Anda minta. Untuk memeriksa dan memperbaiki skor pemindaian suatu desain terlebih dahulu, gunakan `design_qr` di [server MCP](/docs/developers/mcp), atau skor pemindaian di [Playground](/playground?tab=design).
- **`style` maksimal 8.192 karakter** di URL, dan JSON-nya maksimal 40 KB.
- **Data adalah bagian dari URL.** Seperti URL lainnya, data bisa tercatat di log server, riwayat browser, dan cache. Jangan menaruh kata sandi atau rahasia lain di dalamnya.

## Tips pemindaian [#scanning-tips]

- Pertahankan `margin` pada `2` atau lebih saat gambar berada di latar belakang gelap atau ramai, seperti README di mode gelap GitHub.
- Jaga kontras yang baik antara `fg` dan `bg`. Modul gelap pada latar terang paling andal dipindai.
- Pengaturan default (modul persegi, margin 4 modul) dapat dipindai di semua pembaca. Bentuk bergaya seperti titik `circle` terlihat lebih lembut, dan beberapa pemindai lama membacanya kurang andal: periksa dengan [pemeriksa pemindaian](/tools/scan-checker).
- Uji kode dengan beberapa ponsel sebelum mencetaknya.

## Hosting mandiri [#self-hosting]

Endpoint ini adalah bagian dari aplikasi web QRdx, sehingga instance [hosting mandiri](/docs/self-hosting) menyajikannya di `/api/v1/qr` pada domain Anda sendiri (misalnya `https://qr.example.com/api/v1/qr?data=…`). Path singkat `/v1/qr` hanya berfungsi di `api.qrdx.dev`. Pembatasan laju menggunakan Upstash Redis jika dikonfigurasi, dan nonaktif jika tidak.
