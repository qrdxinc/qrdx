Alla fine di questa pagina, ogni QR code che le tue pagine, email o fogli di calcolo caricavano da `chart.googleapis.com` verrà caricato dalla [Image API](/docs/developers/image-api) di QRdx, con la stessa dimensione e lo stesso livello di correzione degli errori, senza account né chiave.

Google ha deprecato le sue Image Charts nell'aprile 2012, compresi i QR code di `chart.googleapis.com/chart?cht=qr`. Oggi l'endpoint risponde `404` (verificato il 15 novembre 2026), quindi ogni vecchio tag `<img>` mostra un'immagine non caricata. La Image API di QRdx funziona allo stesso modo: un URL `GET` che restituisce l'immagine. Il cambiamento si riduce quindi a un nuovo host e tre parametri rinominati.

## Prima di iniziare [#before-you-start]

- Trova i file che usano ancora la vecchia API. Il comando qui sotto li elenca, compreso il vecchio host `chart.apis.google.com`:

```bash title="Terminal"
grep -rlE "chart\.(googleapis|apis\.google)\.com/chart" .
```

- Lavora in una copia git o in un altro posto dove puoi rivedere la modifica prima che vada online.

## 1. Confronta un URL [#1-compare-one-url]

I due URL qui sotto producono lo stesso risultato: un PNG 300 × 300 di `https://example.com` con livello di correzione degli errori `M` e un margine di 2 moduli.

```txt title="Before and after"
https://chart.googleapis.com/chart?cht=qr&chs=300x300&chl=https%3A%2F%2Fexample.com&chld=M|2
https://api.qrdx.dev/v1/qr?format=png&size=300&data=https%3A%2F%2Fexample.com&level=M&margin=2
```

```bash title="Terminal"
curl -o after.png "https://api.qrdx.dev/v1/qr?format=png&size=300&data=https%3A%2F%2Fexample.com&level=M&margin=2"
file after.png
# after.png: PNG image data, 300 x 300, 8-bit/color RGBA, non-interlaced
```

## 2. Associa i parametri [#2-map-the-parameters]

| Google Chart | QRdx | Note |
| --- | --- | --- |
| `cht=qr` | non necessario | L'endpoint disegna solo QR code. Se lo lasci, viene ignorato |
| `chl=<data>` | `data=<data>` | Codificato come URL allo stesso modo, fino a 2.048 caratteri |
| `chs=<width>x<height>` | `size=<width>` | Un solo numero, perché i QR code sono quadrati: da `64` a `2048` pixel |
| `chld=<level>\|<margin>` | `level=<level>&margin=<margin>` | Le stesse lettere, `L`, `M`, `Q` e `H`. Il margine è in moduli, da `0` a `16` |
| `choe=UTF-8` | non necessario | QRdx codifica sempre il testo in UTF-8, che era l'impostazione predefinita di Google. Non esiste un'opzione Shift_JIS o ISO-8859-1. Se lo lasci, viene ignorato |
| sempre PNG | `format=png` | QRdx restituisce SVG a meno che tu non chieda `png`, `webp` o `eps`. Mantieni PNG per le email, perché molti client di posta non mostrano SVG |

Due valori predefiniti sono diversi. Senza `chld`, Google usava il livello di correzione degli errori `L`; QRdx usa `Q`, che resiste a più danni ma produce un codice più denso. Aggiungi `level=L` se vuoi l'aspetto di prima. Entrambi usano per impostazione predefinita un margine di 4 moduli.

## 3. Riscrivi gli URL nei tuoi file [#3-rewrite-the-urls-in-your-files]

Questo comando riscrive ogni URL QR di Google Chart nei file che indichi, entrambi gli host inclusi: cambia host e percorso, rinomina `chl`, `chs` e `chld`, e aggiunge `format=png` in modo che le immagini restino PNG. Perl è incluso in macOS e nella maggior parte delle distribuzioni Linux.

```bash title="Terminal"
perl -pi -e 's{https?://chart\.(?:googleapis|apis\.google)\.com/chart\?([^\s"\x27<>)]*)}{my $q = $1; $q =~ s/(^|[&;])chl=/${1}data=/; $q =~ s/(^|[&;])chs=(\d+)x\d+/${1}size=$2/; $q =~ s/(^|[&;])chld=([LMQH])(?:\||%7C)(\d+)/${1}level=$2&margin=$3/i; $q =~ s/(^|[&;])chld=([LMQH])/${1}level=$2/i; "https://api.qrdx.dev/v1/qr?format=png&$q"}ge' index.html
```

Eseguito su un file con tre vecchi tag, produce:

```html title="index.html (after)"
<img src="https://api.qrdx.dev/v1/qr?format=png&cht=qr&size=300&data=https%3A%2F%2Fexample.com&level=M&margin=2" alt="QR">
<img src="https://api.qrdx.dev/v1/qr?format=png&cht=qr&size=150&data=https%3A%2F%2Fexample.com%2Fmenu" alt="QR 2">
<img src="https://api.qrdx.dev/v1/qr?format=png&size=200&cht=qr&data=hello&level=H&choe=UTF-8" alt="QR 3">
```

I `cht=qr` e `choe=UTF-8` rimasti vengono ignorati da QRdx; rimuovili a mano se vuoi URL più puliti. Controlla il diff, poi esegui di nuovo il `grep` iniziale: non dovrebbe elencare nulla.

## 4. Modifica il codice che costruisce gli URL [#4-change-the-code-that-builds-urls]

```js title="qr.js"
// Before
const src = `https://chart.googleapis.com/chart?cht=qr&chs=200x200&chl=${encodeURIComponent(link)}`;

// After
const src = `https://api.qrdx.dev/v1/qr?format=png&size=200&data=${encodeURIComponent(link)}`;
```

In Google Sheets:

```txt title="Sheets formula"
=IMAGE("https://api.qrdx.dev/v1/qr?format=png&size=150&data="&ENCODEURL(A2))
```

Sheets carica le immagini tramite i server di Google, quindi un foglio con centinaia di codici può raggiungere il limite per IP indicato qui sotto. Per un elenco lungo, crea i file una sola volta con il [generatore in blocco](/tools/bulk) oppure con `qrdx batch` della [CLI](/docs/developers/cli).

## Se qualcosa va storto [#if-something-goes-wrong]

### `400` con `"param": "size"` [#400-with-param-size]

Un `chs` inferiore a 64 pixel (come `50x50`) o superiore a 2048 viene rifiutato. Cambia quelle dimensioni a mano; `64` è il minimo che la Image API disegna.

```json title="400 Bad Request"
{"code":"VALIDATION_ERROR","message":"Invalid query parameters","data":{"details":[{"param":"size","message":"Too small: expected number to be >=64"}]},"status":400}
```

### L'immagine è più densa di prima [#the-image-is-denser-than-before]

Il livello di correzione degli errori predefinito di Google era `L`; quello di QRdx è `Q`. Aggiungi `level=L` per ottenere l'aspetto precedente.

### `429` dopo un ricaricamento in blocco [#429-after-a-bulk-reload]

La Image API consente {facts.imageApiPerMinute} richieste al minuto per indirizzo IP. Attendi i secondi indicati nell'header `Retry-After`, oppure genera i file una sola volta invece di caricarli dal vivo.

## Altre cose da sapere [#what-else-to-know]

- **Cache:** lo stesso URL restituisce sempre gli stessi byte, quindi le risposte vengono messe in cache per un anno (`Cache-Control: public, max-age=31536000, immutable`).
- **Altre opzioni:** colori (`fg`, `bg`), forme dei moduli e degli occhi, un'icona logo (`logoIcon`) e cornici. Provale nel [costruttore di URL](/qr-code-api), oppure leggi i [parametri](/docs/developers/image-api#parameters).
- **Self-hosting:** un QRdx [self-hosted](/docs/self-hosting) serve la stessa API su `/api/v1/qr` sul tuo dominio.
