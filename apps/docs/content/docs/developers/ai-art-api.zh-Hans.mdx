读完本页，你将得到一张 1024 px 的 PNG：二维码融入一幅绘制的画面中，并且在交付给你之前已由 QRdx 解码验证。你还会了解如何编码动态二维码而非固定文本、如何选择模式，以及每种错误的含义。

`POST https://api.qrdx.dev/v1/art` 会根据描述将二维码绘入 AI 艺术作品，并返回图片。它与 Playground 的“艺术”标签页和工作室中的 [AI 二维码艺术](/ai/art)相同：由 {facts.artModel} 绘制画面，然后 QRdx 会在交付前检查它是否能扫描出你的内容。如果模型生成的图片按原样无法扫描，QRdx 只会在模型自身的像素上按需增强二维码。

<Callout type="info" title="API 密钥与每月图片额度">
该端点需要具有 `codes:write` 权限范围的 [API 密钥](/docs/developers/api-keys)（**完全访问**密钥具备该权限）。每张图片会消耗该密钥所属工作区每月 AI 艺术图片额度中的一张，与应用使用的是同一份额度；各套餐的具体数量见[套餐与限制](/docs/plans-and-limits)。调用失败，或图片无法做到可扫描时，不会消耗额度。
</Callout>

## 开始之前 [#before-you-start]

- 一个具有 `codes:write` 权限的 API 密钥，并导出为 `QRDX_API_KEY`。
- 超时时间至少为 60 秒的 HTTP 客户端。一次调用在 code 模式下约需 15 到 45 秒，在 photo 模式下约需 25 到 45 秒，在 scene 模式下约需 40 到 55 秒，因为它要先绘制画面。
- 若使用动态二维码，需要它的 `id`，可从 [`GET /v1/codes`](/docs/developers/api/list-codes) 或[创建它](/docs/developers/api/create-codes)时的响应中获取。

## 1. 为链接绘制二维码 [#1-paint-a-code-for-a-link]

<Tabs groupId="language" persist items={["curl", "JavaScript", "Python"]}>
  <Tab value="curl">
    ```bash title="Terminal"
    curl https://api.qrdx.dev/v1/art \
      -H "Authorization: Bearer $QRDX_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"text": "https://qrdx.dev", "prompt": "a koi pond at dusk, ink and watercolor"}' \
      --max-time 90 -o art.json
    ```
  </Tab>
  <Tab value="JavaScript">
    ```js title="art.mjs"
    import { writeFile } from "node:fs/promises";

    const response = await fetch("https://api.qrdx.dev/v1/art", {
      method: "POST",
      headers: {
        Authorization: `Bearer ${process.env.QRDX_API_KEY}`,
        "Content-Type": "application/json",
      },
      body: JSON.stringify({
        text: "https://qrdx.dev",
        prompt: "a koi pond at dusk, ink and watercolor",
      }),
      signal: AbortSignal.timeout(90_000),
    });
    const { data, credits } = await response.json();
    // data.imageUrl is a data: URL; save the PNG bytes
    const base64 = data.imageUrl.split(",")[1];
    await writeFile("art.png", Buffer.from(base64, "base64"));
    console.log(data.text, data.blend, credits.remaining);
    ```
  </Tab>
  <Tab value="Python">
    ```python title="art.py"
    import base64
    import os
    import requests

    response = requests.post(
        "https://api.qrdx.dev/v1/art",
        headers={"Authorization": f"Bearer {os.environ['QRDX_API_KEY']}"},
        json={"text": "https://qrdx.dev", "prompt": "a koi pond at dusk, ink and watercolor"},
        timeout=90,
    )
    response.raise_for_status()
    body = response.json()
    png = base64.b64decode(body["data"]["imageUrl"].split(",", 1)[1])
    open("art.png", "wb").write(png)
    print(body["data"]["text"], body["data"]["blend"], body["credits"]["remaining"])
    ```
  </Tab>
</Tabs>

响应为 JSON，图片以 `data:` URL 的形式给出：

```json title="200 OK (fields)"
{
  "data": {
    "imageUrl": "data:image/png;base64,iVBORw0KGgo…",
    "width": 1024,
    "height": 1024,
    "seed": 2841337190,
    "mode": "code",
    "blend": "least",
    "blendStrength": 0.35,
    "text": "https://qrdx.dev",
    "visibility": 50,
    "creativity": 45
  },
  "credits": { "plan": "pro", "limit": 30, "used": 7, "remaining": 23, "pooled": false, "resetsAt": "2026-12-01T00:00:00.000Z" }
}
```

- `imageUrl` 是以 `data:` URL 表示的 1024 px 方形 PNG。QRdx 不保留副本，请自行保存。
- `text` 就是这张图片扫描后得到的内容。QRdx 在响应之前已对其解码。
- `blend` 表示图片是如何做到可扫描的：`none`（模型生成的原图）、`least`（仅按需增强定位方块、静区和模块，基于模型的图片）或 `image-qr`（重绘为 Image QR 二维码，最后的手段）。`blendStrength` 的范围从 `0`（原图）到 `1`（Image QR）。
- `credits` 是本张图片生成后工作区的剩余额度。

若想直接获得 PNG 而非 JSON，请添加 `?format=png` 或发送 `Accept: image/png`。此时种子、模式、融合方式和剩余图片数会通过 `X-QRdx-Seed`、`X-QRdx-Mode`、`X-QRdx-Blend`、`X-QRdx-Blend-Strength` 和 `X-QRdx-Credits-Remaining` 响应头返回：

```bash title="Terminal"
curl "https://api.qrdx.dev/v1/art?format=png" \
  -H "Authorization: Bearer $QRDX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"text": "https://qrdx.dev", "prompt": "a lighthouse on a cliff, woodcut print"}' \
  --max-time 90 -o art.png
```

## 2. 改为编码动态二维码 [#encode]

`text` 和 `code` 只能二选一发送：

- `text`：二维码包含的链接或文本，最多 300 个字符。艺术图是一幅图片，所以印刷之后其内容无法更改。
- `code`：工作区中某个[动态二维码](/docs/dynamic-qr-codes)的 `id`。艺术图编码的是该二维码的短链接，因此印刷后你仍可更改其指向的目标，并且扫描数据会显示在分析中。来自其他工作区或位于回收站中的二维码会返回 `404`。

```bash title="Terminal"
curl https://api.qrdx.dev/v1/art \
  -H "Authorization: Bearer $QRDX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"code": "cm5code0spring0menu00001", "prompt": "a bistro chalkboard menu on a brick wall", "mode": "scene"}' \
  --max-time 90 -o art.json
```

此时响应中还会包含 `"code": { "id", "shortLink" }`，并且 `text` 为该短链接。

## 3. 选择模式和风格 [#modes]

| `mode` | 效果 |
| --- | --- |
| `code`（默认） | 二维码就是整幅画面：你的艺术作品绘入其模块中，带有普通的定位方块，周围是浅色静区。扫描最可靠 |
| `scene` | 先根据描述绘制一幅画面，再将二维码绘入画面中央，使画面一直延伸到二维码内部并穿过它，模块由画面的色彩与光线构成 |
| `photo` | 与上面类似，但以你自己的 `photo` 作为画面：它的主体、色彩和光线会保留在二维码周围并贯穿其中。仅在此模式下发送照片 |

### 快捷风格 [#quick-looks]

快捷风格是现成的样式，例如某种绘画媒介或氛围，QRdx 会将其添加到你自己的 `prompt` 中：`"a koi pond in the rain"` 搭配 `"style": "watercolor"` 会把锦鲤池塘绘制成水彩画。请将其 id 作为 `style` 发送；任何其他值都会返回 `400 VALIDATION_ERROR`。这些风格与 [AI 艺术工作室](/ai/art)和 Playground 的“艺术”标签页中以标签形式提供的风格相同，并且适用于所有模式。

| `style` | 风格 |
| --- | --- |
| `watercolor` | 水彩 |
| `oil-painting` | 油画 |
| `anime` | 动漫 |
| `cartoon` | 卡通 |
| `pixel-art` | 像素艺术 |
| `pop-art` | 波普艺术 |
| `charcoal` | 炭笔 |
| `ink` | 水墨 |
| `cyberpunk` | 赛博朋克 |
| `fantasy` | 奇幻 |
| `photographic` | 摄影 |
| `low-poly` | 低多边形 |
| `papercut` | 剪纸 |

`prompt` 是可选的。省略它时，QRdx 会先根据你发送的 `mode`、`style` 和 `photo` 为你写一段：一个具体的场景，包含主体、环境和光线；在 photo 模式下则是对照片内容的描述，以便艺术图保留这些内容。撰写提示词不会额外消耗 AI 艺术图片额度。响应中会以 `writtenPrompt` 返回所写的内容，方便你下次编辑后再次发送。如果撰写失败，你会收到 `502 AI_ART_DESCRIBE_FAILED`，且不会消耗任何图片额度。

## 请求字段 [#request-fields]

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `text` | | 二维码编码的内容，最多 300 个字符。与 `code` 二选一发送 |
| `code` | | 动态二维码的 `id`，用于替代 `text` |
| `prompt` | 自动撰写 | 要绘制的艺术作品，用通俗的文字描述，发送时至少 3 个字符 |
| `mode` | `code` | `code`、`scene` 或 `photo`；见上文 |
| `style` | | 快捷风格的 id，与你的提示词组合使用 |
| `negativePrompt` | | 画面中要避免出现的内容 |
| `visibility` | `50` | 二维码可见度，`0` 到 `100`：数值越高二维码越清晰，越低则越偏向画面 |
| `creativity` | `45` | `0` 严格遵循提示词，`100` 则自由发挥 |
| `seed` | 随机 | 发送之前响应中的种子，可得到相似的图片 |
| `reference` | | 用于参考色彩和形状的参考图，例如徽标或调色板 |
| `photo` | | 仅限 photo 模式：要将二维码绘入的图片 |

`reference` 和 `photo` 为 PNG 或 JPEG 的 `data:` URL（`data:image/jpeg;base64,…`）。请将 `reference` 缩小到最长边约 512 px（不超过 600 KB），并将 `photo` 裁剪为约 1024 px 的正方形（不超过 1 MB），这也是艺术图生成时使用的尺寸。它们会发送给模型，随后即被丢弃：QRdx 绝不会存储或记录它们。过大的图片会被拒绝，并返回 `413 AI_ART_IMAGE_TOO_LARGE`。完整的数据结构和“试一试”面板见[参考页面](/docs/developers/api/create-art)。

## 额度与限制 [#credits-and-limits]

API 使用的是与应用相同的每月 AI 艺术图片额度，按密钥所属的工作区计算。免费版、Pro 和 Business 每月都包含一定数量的图片，其中 Business 在整个团队内共享；具体数量见[套餐与限制](/docs/plans-and-limits)。额度在每月 1 日（UTC）重置。

- 当月图片额度用完后，API 会返回 `AI_ART_CREDITS_EXHAUSTED`：免费版和 Pro 为 `402`，升级后可获得更多额度；Business 为 `429`。
- 除每月额度外，每人每天最多可生成 25 张图片（`429 AI_ART_DAILY_LIMIT`），每分钟最多可发起 12 张。
- 每次调用还会计入工作区的每日 API 配额以及每分钟写入限制（[速率限制](/docs/developers/rest-api#rate-limits)）。

## 出错时怎么办 [#if-something-goes-wrong]

错误沿用 API 一贯的结构（`code`、`message`、`status`），完整列表见[错误](/docs/developers/errors)。所有 `5xx` 错误都不会返回图像。

| 状态码 | `code` | 处理方式 |
| --- | --- | --- |
| 400 | `AI_ART_TEXT_TOO_LONG` | 缩短 `text`，或改为发送动态码的 `code` |
| 402 | `AI_ART_CREDITS_EXHAUSTED` | 等到每月 1 日，或升级套餐 |
| 413 | `AI_ART_IMAGE_TOO_LARGE` | 缩小 `photo` 或 `reference` 的尺寸 |
| 429 | `AI_ART_CREDITS_EXHAUSTED` | Business：等到每月 1 日 |
| 429 | `AI_ART_DAILY_LIMIT` | 明天（UTC）再试 |
| 502 | `AI_ART_FAILED` | 模型生成失败或拒绝了该提示词。请重试或改写提示词 |
| 502 | `AI_ART_UNSCANNABLE` | 调高 `visibility` 或更换种子后重试 |
| 502 | `AI_ART_DESCRIBE_FAILED` | 未发送 `prompt`，且自动生成提示词失败。请重试或自行发送提示词 |
| 503 | `AI_ART_BUSY` | 模型繁忙。请等待一分钟后重试 |
| 503 | `AI_NOT_CONFIGURED` | 此服务器未配置 AI 艺术码（自托管） |
| 504 | `AI_ART_TIMEOUT` | 模型耗时过长（在场景模式下，画面占用了过多时间，导致没有足够时间绘制二维码）。请重试，或使用二维码模式 |

未接入 Vercel AI Gateway 的自托管实例会用以下内容响应每一次调用：

```json title="503 Service Unavailable"
{"code":"AI_NOT_CONFIGURED","message":"AI QR art is not configured on this server","status":503}
```

## MCP [#mcp]

连接时带上 QRdx API 密钥后，[MCP 服务器](/docs/developers/mcp)会提供 `generate_ai_art` 工具。它接受与请求体相同的字段，并返回 PNG、扫描后指向的内容，以及本月剩余的图像数量。你可以直接用日常语言向助手提出需求：

```txt title="Prompt"
Make AI QR art for my code cm5code0spring0menu00001: a bistro chalkboard menu on a brick wall, as a scene.
```

没有密钥时，该工具会回复如何添加密钥。与 REST API 一样，调用最长需要一分钟。

## 自托管 [#self-hosting]

AI 艺术码通过 Vercel AI Gateway 运行。在你自己的实例上，请设置 `AI_GATEWAY_API_KEY`；未设置时，`POST /v1/art` 和 `generate_ai_art` 会返回 `503 AI_NOT_CONFIGURED`。
