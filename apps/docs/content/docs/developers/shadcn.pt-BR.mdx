A QRdx publica um registro shadcn/ui com componentes de QR code criados com a biblioteca `qrdx`. A CLI do shadcn copia o código-fonte de cada componente para o seu projeto, então o código é seu e você pode alterá-lo. Use o registro quando quiser uma peça de interface pronta, com botões de download, um card, um diálogo de compartilhamento ou um leitor; use o `QRCode` da própria biblioteca quando precisar só do código.

<NpmStatus package="qrdx" />

<PackageManagerTabs command="npx shadcn@latest add https://qrdx.dev/r/qr-code.json" />

Cada componente tem sua própria página, com prévia ao vivo, código-fonte, passos de instalação, exemplos e uma tabela de props. Estilizou um código no [Playground](/playground?open=code&lang=shadcn)? Copie-o de lá para o componente QR Code do registro.

## O que é instalado [#what-gets-installed]

Cada componente é um único arquivo na sua pasta `components`. A CLI também instala o `qrdx` (e o `lucide-react` para os ícones que a maioria dos componentes usa) e adiciona os componentes shadcn/ui em que ele se baseia, como `button`, `card`, `dialog`, `dropdown-menu`, `input` ou `label`. A página de cada componente lista suas próprias dependências em **Manual**, nas abas de instalação.

O índice completo está em [`https://qrdx.dev/r/registry.json`](https://qrdx.dev/r/registry.json), e cada item em `https://qrdx.dev/r/<name>.json`.

## Instalar pelo nome [#install-by-name]

Para instalar com um nome curto, adicione o registro ao seu `components.json`:

```json title="components.json"
{
  "registries": {
    "@qrdx": "https://qrdx.dev/r/{name}.json"
  }
}
```

Depois adicione um ou vários componentes pelo nome:

<PackageManagerTabs command="npx shadcn@latest add @qrdx/qr-code @qrdx/qr-code-download @qrdx/qr-code-share-dialog" />

## Estilo e tema [#styling-and-theming]

Os componentes usam classes do Tailwind com os tokens de tema padrão do shadcn/ui (`bg-card`, `border`, `text-muted-foreground`, `ring-ring`) e o seu próprio Button, Card, Dialog e Input, então acompanham o seu tema e o modo escuro. Os QR codes mantêm um fundo claro por padrão, porque módulos escuros sobre um bloco claro são lidos por qualquer leitor; a página do [QR Code](/docs/components/qr-code#dark-mode) mostra como acompanhar o tema.

Todo componente é um Client Component (o arquivo começa com `"use client"`), por causa dos botões e do estado. Mesmo assim, o código em si é renderizado no servidor, então já está no HTML da página antes de os botões ficarem interativos. Uma página Server Component pode importar qualquer um deles e passar dados do servidor como props.

Os downloads em PDF precisam do pacote opcional `jspdf` (`npm install jspdf`). Todo o resto funciona assim que a CLI termina.
