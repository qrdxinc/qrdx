Ao final desta página, você terá um QR code estilizado em um componente Solid que acompanha um signal, e um botão que o salva como PNG. O `qrdx/solid` traz os dois componentes SVG da biblioteca React, `QRCodeSVG` e `QRCode`, feitos para SolidJS. Eles desenham o mesmo SVG dos componentes React, acompanham seus signals e renderizam em um servidor.

<NpmStatus package="qrdx" />

## Antes de começar [#before-you-start]

- Um projeto com Solid 1.8 ou mais recente (na linha 1.x), com Vite ou SolidStart.
- Node.js 18 ou mais recente.

## Passo a passo [#build-it]

### 1. Instale o qrdx [#1-install-qrdx]

```package-install
qrdx
```

`solid-js` é uma peer dependency opcional do `qrdx`. Seu app já a tem, e você não precisa do `react`.

### 2. Desenhe um código que acompanha um signal [#2-draw-a-code-that-follows-a-signal]

```tsx title="src/components/menu-code.tsx"
import { createSignal } from "solid-js";
import { QRCodeSVG } from "qrdx/solid";

export function MenuCode() {
  const [color, setColor] = createSignal("#0f172a");
  return (
    <>
      <QRCodeSVG
        value="https://example.com/menu"
        size={256}
        margin={4}
        fgColor={color()}
        frame={{ style: "banner-bottom", text: "Scan me" }}
        aria-label="QR code for the menu"
      />
      <button type="button" onClick={() => setColor("#1d4ed8")}>
        Blue
      </button>
    </>
  );
}
```

A página mostra um código escuro com um banner "Scan me". Clique em **Blue** e o código é redesenhado em azul.

<Shot id="lib-solid-signal-code" />

O `QRCodeSVG` aceita todas as opções que o `QRCodeSVG` do React aceita: padrões, cores e gradientes, logos (`imageSettings`), molduras, formas, modelos e arte. Atributos como `class`, `style` ou `aria-label` vão no `<svg>`, ou no `<svg>` externo da moldura quando há uma moldura.

O `QRCode` acrescenta o atalho de logo do `QRCode` do React: `logo`, `logoOptions`, `hideLogo` e `scale`. Ele aceita apenas as props do código e `style`; coloque `class` ou `aria-label` em um elemento ao redor dele, ou use o `QRCodeSVG`.

```tsx title="src/components/logo-code.tsx"
import { QRCode } from "qrdx/solid";

export function LogoCode() {
  return <QRCode value="https://example.com" size={256} logo="/logo.png" level="H" />;
}
```

As props são reativas, como em qualquer componente Solid. Quando `color()` muda, o código é redesenhado. Os manipuladores de evento nas props não são colocados no `<svg>`, então coloque-os em um elemento ao redor do código.

### 3. Salve como arquivo [#3-save-it-as-a-file]

Os componentes apenas desenham o código. Downloads, `toSVGString`, a pontuação de leitura e as demais funções vêm do `qrdx/core`. Esse é o motor que os componentes já usam, então ele não é incluído duas vezes no bundle.

```tsx title="src/components/downloadable-code.tsx"
import { downloadQRCode } from "qrdx/core";
import { QRCodeSVG } from "qrdx/solid";

const options = { value: "https://example.com", size: 256, margin: 4 };

export function DownloadableCode() {
  return (
    <>
      <QRCodeSVG {...options} />
      <button
        type="button"
        onClick={() =>
          downloadQRCode(options, {
            format: "png",
            size: { width: 1024, height: 1024 },
            filename: "qr-code.png",
          })
        }
      >
        Download PNG
      </button>
    </>
  );
}
```

Ao clicar no botão, `qr-code.png` é salvo com 1024 px. A página [JavaScript puro](/docs/vanilla-js) cobre o `qrdx/core` por completo.

## Como ele desenha [#how-it-draws]

O pacote não tem JSX do Solid, então não precisa do compilador do Solid e funciona com qualquer configuração de build.

- No navegador, o componente retorna o próprio elemento `<svg>`, criado com `createElementNS` (nenhum HTML é interpretado). O Solid o coloca na página, troca por um novo quando uma mudança de prop altera a marcação e o remove quando o componente é desmontado.
- Uma mudança de prop que gera a mesma marcação deixa a página como está.

## Renderização no servidor e hidratação [#server-rendering-and-hydration]

Com `renderToString` de `solid-js/web`, um componente escreve a mesma marcação que `toSVGString` do `qrdx/core`, mais a chave de hidratação `data-hk` do Solid no elemento raiz. O `hydrate` usa essa chave para manter o `<svg>` do servidor em vez de desenhá-lo de novo. Dentro de `<NoHydration>`, a chave é omitida.

A marcação não tem ids aleatórios, então o servidor e o navegador sempre concordam.

## Se algo der errado [#if-something-goes-wrong]

- **`Failed to resolve import "react"`.** Você importou de `qrdx` em vez de `qrdx/solid`. A entrada principal tem os componentes React; troque o import.
- **Um manipulador de clique no componente não faz nada.** Os manipuladores são descartados do `<svg>`. Envolva o código em um elemento e coloque o manipulador nele.
- **`PDF export needs the optional "jspdf" package`.** Execute `npm install jspdf` no app.
