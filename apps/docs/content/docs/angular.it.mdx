Al termine di questa pagina avrai un QR code personalizzato in un componente Angular, collegato a un signal, e un pulsante che lo salva come SVG. `qrdx/angular` è un componente standalone, `<qrdx-qr-code>`, basato sullo stesso motore dei componenti React. Accetta le prop di `<QRCode>` di React come input signal e disegna lo stesso SVG. Esegue il rendering sul server con `@angular/ssr` e si idrata senza errori.

<NpmStatus package="qrdx" />

## Prima di iniziare [#before-you-start]

- Un progetto Angular 20 o successivo, creato con l'Angular CLI. Funzionano sia le build di produzione sia `ng serve`.
- Node.js 18 o successivo.

## Realizzalo [#build-it]

### 1. Installa qrdx [#1-install-qrdx]

```package-install
qrdx
```

`@angular/core` è una peer dependency opzionale di `qrdx`, quindi installarlo non aggiunge mai Angular alle app che non lo usano, e non aggiunge mai React alla tua.

### 2. Disegna un codice [#2-draw-a-code]

Importa `QRCode` e aggiungilo agli `imports` del tuo componente. Non serve alcun NgModule.

```ts title="src/app/app.ts"
import { Component, signal } from "@angular/core";
import { QRCode, type QRCodeProps } from "qrdx/angular";

@Component({
  selector: "app-root",
  imports: [QRCode],
  template: `
    <qrdx-qr-code
      [value]="url()"
      [size]="240"
      [margin]="4"
      level="Q"
      bodyPattern="rounded"
      [fgColor]="fgColor"
      [frame]="{ style: 'banner-bottom', text: 'Scan me' }"
      aria-label="QR code for example.com"
    />
  `,
})
export class App {
  protected readonly url = signal("https://example.com");
  protected readonly fgColor: QRCodeProps["fgColor"] = {
    type: "linear",
    angle: 45,
    stops: [
      { color: "#1d4ed8", offset: 0 },
      { color: "#0f172a", offset: 100 },
    ],
  };
}
```

`ng serve` mostra un codice di 240 px con moduli arrotondati, un gradiente dal blu al blu scuro e un banner "Scan me". Imposta `url` su un altro link e il codice viene ridisegnato. Quando una modifica lascia invariato il markup, la pagina non viene toccata.

### 3. Salvalo come file [#3-save-it-as-a-file]

Il componente scarica ed esporta il codice che disegna, come `qrdx/vanilla`. Puoi raggiungerlo con una variabile di riferimento del template o con `viewChild(QRCode)`:

```html title="src/app/app.html"
<qrdx-qr-code #qr value="https://example.com" [size]="256" [margin]="4" />
<button type="button" (click)="qr.download({ format: 'svg', filename: 'qr-code.svg' })">
  Download SVG
</button>
```

Facendo clic sul pulsante viene salvato `qr-code.svg`.

- `download({ format, size, filename, quality })` salva un file: PNG per impostazione predefinita, oppure `"jpg"`, `"webp"`, `"svg"`, `"pdf"` o `"eps"`. Il PDF richiede il pacchetto opzionale `jspdf`.
- `toDataURL(format, { size, quality })` restituisce il codice come data URL.
- `markup()` è il markup SVG, `options()` sono le prop con cui viene disegnato il codice e `svg` è l'elemento `<svg>`.

Tutto ciò che è in `qrdx/core` è esportato anche da `qrdx/angular`, quindi `toSVGString`, `downloadQRCode`, `getScanScore` e il resto arrivano dallo stesso import.

## Input [#inputs]

Ogni prop di `<QRCode>` di React è un input con lo stesso nome e lo stesso tipo, e Angular verifica i tuoi binding rispetto a questi quando compila i template. `value` è obbligatorio.

| Input | Cosa fanno |
| --- | --- |
| `value`, `size`, `level`, `margin`, `autoLevel` | Contenuto, dimensione in pixel, correzione degli errori, zona di rispetto e aumento del livello per un logo grande |
| `fgColor`, `bgColor`, `eyeColor`, `dotColor`, `eyeColors` | Colori, gradienti e riempimenti con immagini |
| `bodyPattern`, `cornerEyePattern`, `cornerEyeDotPattern`, `moduleScale` | Forme dei punti e degli occhi |
| `logo`, `logoOptions`, `hideLogo`, `scale` | Un logo al centro, disposto come in `<QRCode>` |
| `frame`, `shape`, `art` | Cornici con invito all'azione, contorni a cerchio e a cuore, Logo QR e Image QR |
| `templateId`, `customTemplate`, `customProps` | Template |
| `frameLabelMarkers`, `partMarkers` | Indicatori per l'anteprima in tempo reale di un editor |
| `svgStyle` | Stili inline per l'`<svg>` (il `style` di `QRCode`) |

`style` si chiama `svgStyle` perché un input chiamato `style` prenderebbe il posto dell'attributo `style` dell'elemento stesso. Gli attributi che metti su `<qrdx-qr-code>`, come `class`, `style` o `aria-label`, restano su quell'elemento; l'`<svg>` si trova al suo interno.

Gli stili del tuo componente non raggiungono l'`<svg>`, perché Angular li limita agli elementi del tuo template. Per fare in modo che un codice riempia il suo contenitore, usa `svgStyle`:

```html title="src/app/app.html"
<qrdx-qr-code value="https://example.com" [svgStyle]="{ width: '100%', height: 'auto' }" />
```

## Rendering lato server e idratazione [#server-rendering-and-hydration]

Con `@angular/ssr`, l'HTML del server contiene già il codice, quindi viene mostrato prima che l'app si carichi. Nel browser, Angular idrata la pagina e mantiene l'elemento `<qrdx-qr-code>`; il componente poi disegna di nuovo il suo codice, identico a quello del server. Non ti serve `ngSkipHydration`.

L'output non contiene id casuali, quindi server e browser disegnano lo stesso markup.

## Se qualcosa va storto [#if-something-goes-wrong]

- **`NG8001: 'qrdx-qr-code' is not a known element`.** `QRCode` manca dall'array `imports` del componente. Aggiungilo, come nel passaggio 2.
- **Una regola CSS per `svg` nel tuo componente non ha effetto.** Angular limita i tuoi stili al tuo template. Usa l'input `svgStyle`, oppure metti la regola in un foglio di stile globale.
- **`PDF export needs the optional "jspdf" package`.** Esegui `npm install jspdf` nell'app.
