모든 [동적 QR 코드](/docs/dynamic-qr-codes)는 쿠키 없이 스캔을 기록합니다. 추적은 여기서 두 단계를 더 나아갑니다. 코드가 여는 호스팅 페이지에 직접 만든 픽셀을 불러오고, 웹사이트의 구매 같은 전환을 방문자를 데려온 스캔에 귀속할 수 있습니다. QR 트래픽이 팀에서 이미 쓰는 도구에 나타나야 할 때, 또는 어떤 코드가 매출을 만드는지 알아야 할 때 사용하세요.

<Callout type="info" title="픽셀은 Pro, 전환은 Business">
  추적 픽셀은 Pro와 Business에 포함되고, 전환 추적은 Business에 포함됩니다. 둘 다 코드의 **설정** 탭에서 설정합니다. [요금제와 한도](/docs/plans-and-limits)를 참고하세요.
</Callout>

급하신가요? [스캔 확인하기](/docs/help/dynamic-codes/scans)에서 모든 요금제에서 제공하는 분석을 확인할 수 있습니다.

## 작동 방식 [#how-it-works]

<Diagram id="tracking-paths" />

코드는 호스팅 페이지를 열거나 웹사이트로 리디렉션하며, 각 경로마다 사용하는 도구가 다릅니다. 호스팅 페이지에서는 QRdx가 HTML을 제어하므로 방문자가 동의한 뒤에 픽셀을 불러올 수 있습니다. 웹사이트에서는 QRdx가 아무것도 제어하지 못하므로, URL에 서명된 스캔 ID를 담아 사이트에 전달하고 방문자가 전환하면 사이트가 이를 다시 보고합니다.

## 모든 코드의 분석 [#analytics-on-every-code]

시간별 스캔, 국가, 도시, 기기, 운영 체제, 브라우저, 리퍼러 외에도 각 코드의 **분석** 탭에는 다음 항목이 표시됩니다.

- **스캔 시간대:** 시간대별, 요일별 스캔 수를 UTC 또는 사용자의 시간대 기준으로 보여줍니다.
- **언어:** 각 방문자가 선호하는 브라우저 언어입니다(브라우저가 보내지 않으면 "알 수 없음").
- **A/B 분할:** 각 [A/B 분할 규칙](/docs/smart-routing#ab-tests)의 변형별 스캔 수입니다.
- **페이지 활동**(호스팅 페이지): 페이지 조회수, 고유 방문자 수, 탭 수, 가장 많이 탭한 링크와 버튼입니다.
- **전환**: 코드에 전환이 있는 경우 표시됩니다.

<Shot id="when-people-scan" />

사이드바의 **코드** → **분석**에서는 워크스페이스의 모든 코드를 합산해 보여줍니다. 합계, 시간별 스캔, 상위 코드, 국가, 기기, 언어, 스캔 시간대, 최대 4개 코드를 나란히 비교한 결과가 포함됩니다. 봇과 링크 미리보기는 집계되지 않고, "고유" 방문자는 하루에 한 번만 집계되며, IP 주소는 저장되지 않습니다.

## 호스팅 페이지의 추적 픽셀 [#tracking-pixels-on-hosted-pages-pro]

호스팅 페이지를 여는 코드는 코드의 **설정** 탭에 있는 **추적 픽셀** 패널에서 직접 만든 태그를 해당 페이지에 불러올 수 있습니다.

| 제공업체 | ID 형식 |
| --- | --- |
| Google Analytics 4 | `G-` 뒤에 영문자와 숫자 4~20자 |
| Meta (Facebook) 픽셀 | 숫자 6~20자 |
| TikTok 픽셀 | 영문자와 숫자 10~30자 |
| LinkedIn Insight Tag | 파트너 ID, 숫자 3~12자 |

<Shot id="pixels-panel" />

픽셀은 설정한 경우에만 불러옵니다. 호스팅 페이지에서 사용자의 픽셀 외에 실행되는 스크립트는 QRdx 자체의 페이지 활동 카운터뿐이며, 이 카운터는 조회수와 탭 수를 QRdx에만 보고하고 다른 곳에는 보고하지 않습니다.

<IfAvailable feature="customDomains">

**Google Tag Manager**(`GTM-` 뒤에 영문자와 숫자 4~12자)는 페이지가 [사용자 지정 도메인](/docs/custom-domains) 중 하나에서 열릴 때만 불러옵니다. 컨테이너는 어떤 스크립트든 실행할 수 있으므로, 방문자가 QRdx에 로그인했을 수 있는 qrdx.dev에서는 절대 실행되지 않습니다.

</IfAvailable>

### 동의 [#consent]

픽셀은 방문자가 동의하기 전에는 불러오지 않습니다.

- **필요한 지역(EU, EEA, 영국, 스위스, 위치 불명)**, 기본값입니다. 해당 지역의 방문자와 위치를 알 수 없는 방문자에게는 사용 중인 제공업체를 명시한 짧은 배너가 표시되고, **수락** 또는 **거부**를 선택합니다. 선택은 해당 페이지에 기억되며, **쿠키 설정**에서 변경할 수 있습니다. 그 외 지역에서는 픽셀이 바로 로드되지만, Global Privacy Control 신호를 보내는 브라우저는 예외입니다.
- **모든 방문자:** 모든 사람에게 먼저 배너가 표시됩니다.

개인정보 처리방침과 픽셀이 수집한 데이터의 사용 방식에 대한 책임은 사용자에게 있습니다. 사용자의 웹사이트를 여는 코드는 해당 사이트로 바로 이동하므로, 픽셀은 사이트에 직접 추가하세요.

## 전환 추적 [#conversion-tracking]

전환 추적을 사용하면 어떤 스캔이 판매, 가입 또는 기타 목표로 이어졌는지 매출과 함께 알 수 있습니다. 웹사이트를 여는 코드에서 작동합니다.

1. 코드의 **설정** 탭에서 **전환 추적**을 켭니다. 이후 모든 스캔은 서명된 `qrdx_sid` 매개변수가 추가된 URL을 엽니다. 예: `https://shop.example/?qrdx_sid=…`
2. 방문자가 처음 도착하는 페이지와 전환이 일어나는 페이지에 스니펫을 추가합니다.

```html title="Your website (before </body>)"
<script async src="https://qrdx.dev/conversions.js"></script>
<script>
  window.qrdx = window.qrdx || function () {
    (window.qrdx.q = window.qrdx.q || []).push(arguments);
  };
  // Where the conversion happens, for example your order confirmation page:
  qrdx("conversion", { name: "purchase", value: 49.99, currency: "USD", id: "ORDER-1234" });
</script>
```

스크립트는 `qrdx_sid`를 사용자 도메인의 퍼스트파티 쿠키에 30일 동안 저장하고(브라우저 세션 동안에만 유지하려면 스크립트 태그에 `data-storage="session"`을 추가하세요) 주소 표시줄에서는 제거합니다. 전환은 스캔을 통해 도착한 방문자에 대해서만 전송되므로, 다른 방문자는 추적되지 않습니다.

| 필드 | 의미 |
| --- | --- |
| `name` | 발생한 일. 예: `purchase`, `signup` (기본값 `conversion`) |
| `value` | 금액, 소수점 2자리까지 (선택) |
| `currency` | `USD` 같은 ISO 4217 코드. 값을 지정하면 기본값은 `USD` |
| `id` | 주문 또는 이벤트 ID. 같은 ID를 두 번 보내도 한 번만 기록됩니다 |
| `metadata` | 추가 키/값 쌍 최대 20개 (선택) |

### 한도 [#limits]

- 스캔은 발생 후 30일 동안 귀속할 수 있습니다.
- `qrdx_sid`는 서명되어 있으므로 추측하거나 다른 코드를 가리키도록 변경할 수 없습니다.
- 브라우저 보고는 해당 코드의 전환 추적이 켜져 있어야 하며, 각 스캔은 시간당 최대 10건의 전환을 보고할 수 있습니다. 토큰을 사용한 서버 보고에는 두 제한이 모두 없습니다.
- 워크스페이스가 Business에서 벗어나면 전환 기록이 중단됩니다. 기존 전환은 분석에 그대로 남으며, 추적은 언제든지 끌 수 있습니다.

## 개발자용 [#for-developers]

브라우저보다 더 안정적인 백엔드에서 전환을 보고하려면 `qrdx_sid`를 주문과 함께 보관하고, [API 키](/docs/developers/api-keys) 또는 `codes:write` 범위가 있는 OAuth 토큰으로 [`POST /v1/conversions`](/docs/developers/api/create-conversion)를 호출하세요.

```bash title="Terminal"
curl -X POST https://api.qrdx.dev/v1/conversions \
  -H "Authorization: Bearer $QRDX_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"sid": "<qrdx_sid>", "name": "purchase", "value": 49.99, "currency": "USD", "id": "ORDER-1234"}'
```

API는 새 전환이면 `201`로, `id`가 이미 기록되어 있으면 `"duplicate": true`와 함께 `200`으로 응답합니다. 토큰을 사용하면 스캔을 알 수 없을 때 `sid` 대신 `"code": "<code id>"`를 보낼 수도 있습니다.
