QRdx 机器人可以在 Telegram 内把链接或任意文本变成二维码。它免费使用,也不需要 QRdx 账号。当你需要立刻把二维码发给聊天中的某个人时,就可以用它:给访客的 Wi-Fi 密码、发给群组的链接、桌台上的菜单。

## 工作原理 [#how-it-works]

QRdx 不会保存你生成的二维码,机器人读取每条消息也只是为了回复它。每个二维码都是 QRdx 根据一条链接渲染出的图片,这条链接包含你的内容和你选择的设计,因此重新设计二维码时,会从该链接中读回这两项信息。与任何链接一样,它可能会留在日志和缓存中,所以不要用密码或其他机密信息生成二维码。Telegram 会像保存其他消息一样,把消息保留在聊天中。

## 私聊 [#private-chat]

给机器人发送一条链接或一段文本,它会回复二维码和四个按钮:

- **下载 PNG** 打开图片,可直接保存或分享。
- **下载 SVG** 打开矢量版本,适用于印刷和设计工具。
- **在编辑器中打开** 以相同的设计打开 QRdx 编辑器。网址会一并带入,其他文本则不会,请自行粘贴到编辑器中。
- **样式** 直接在聊天中更改二维码的外观(见下文)。

二维码包含你发送的内容,换行也会保留;首尾空格会被去掉,像 `qrdx.dev` 这样的纯域名会变成 `https://qrdx.dev`。发送 `/help`(或 `/start`)可查看机器人的用法。如果文本太长,一个二维码放不下,机器人会告知;改用指向完整文本页面的链接,可以得到更小、更易扫描的二维码。

## 设计你的二维码 [#style-your-code]

点击二维码下方的 **样式**,下载按钮会换成 **外观**、**颜色**、**边框** 和 **Logo**,其下是 **下载 PNG** 和 **完成**。每个分组会展开各自的选项,当前二维码正在使用的选项旁有 ✓,点击 **返回** 可回到上一级。点击某个选项,机器人会重新绘制图片。点击 **完成** 会恢复下载按钮。每次更改都基于二维码的当前状态。在群组中,只有请求该二维码的人可以重新设计它;其他人点击时会收到一条简短提示。

这些外观是编辑器内置设计中在小尺寸下也易于识别的一部分;**Plain** 是黑底白字的那一款。选择外观会改变形状和颜色,并保留你已选的边框和 Logo。选择颜色会把整个二维码设为该颜色,背景为白色。边框会添加“Scan me”标签,Logo 菜单提供编辑器的七个快捷图标。

你也可以在生成二维码时,在链接或文本后面添加选项来设计它,选项名称与 [QRdx CLI](/docs/developers/cli) 相同。这在私聊中、群组里的 `/qr` 之后以及内联模式下都适用;在内联模式中,由于还没有可修改的消息,这是设计二维码的唯一方式:

```text title="Telegram message"
qrdx.dev --look modern --fg 0051ff --frame banner-bottom --frame-text "Scan me"
```

第一个选项之前的所有内容都是二维码的内容。系统先应用外观,再在其上应用其他选项,所以 `--look royal --fg 0051ff` 会保留 Royal 的形状并改为蓝色。如果你的手机把 `--` 自动变成长破折号,同样可以识别。选项或取值有误时,回复中会列出该选项可用的取值。

| 选项 | 更改内容 | 取值 |
| --- | --- | --- |
| `--look` | 整体设计,来自编辑器的某个预设 | `plain`, `classic`, `modern`, `royal`, `folio`, `caffeine`, `retro`, `bordeaux`, `blossom` |
| `--fg`(或 `--color`) | 圆点,以及未单独设置时的角上定位眼 | 十六进制颜色,如 `0051ff`,或 `black`, `blue`, `green`, `red`, `purple`, `orange` |
| `--bg` | 背景 | 与 `--fg` 相同 |
| `--eye-color` | 三个角上的定位眼 | 与 `--fg` 相同 |
| `--dot-color` | 定位眼的中心 | 与 `--fg` 相同 |
| `--body` | 圆点的形状 | 编辑器中 {facts.bodyPatterns} 种圆点形状中的任意一种,如 `rounded`、`circle` 或 `classy` |
| `--eye` | 角上定位眼的形状 | {facts.eyeShapes} 种定位眼形状中的任意一种,如 `square`、`rounded` 或 `gear` |
| `--dot` | 定位眼中心的形状 | {facts.eyeCentres} 种中心形状中的任意一种,如 `square`、`rounded` 或 `circle` |
| `--frame` | 二维码周围的边框 | `none` 或 {facts.frameStyles} 种内置边框中的任意一种,如 `banner-bottom`、`banner-top`、`speech-bubble` 或 `polaroid` |
| `--frame-text` | 边框的标签,最多 24 个字符 | 任意文本,含空格时需加引号。未设置 `--frame` 时,文本会显示在二维码下方的横幅上 |
| `--template` | 以模板方式绘制的边框 | `Arrow`、`StandardBox`、`SquareBorder`、`StrikedBox`、`DotRing`、`Halloween` 或 `default`,大小写均可 |
| `--logo` | 中间的图标 | `link`, `wifi`, `location`, `phone`, `email`, `whatsapp`, `instagram`, `file`, `calendar` 或 `none` |

机器人发送设计过的二维码之前,QRdx 会用与编辑器相同的扫描评分对其进行检查。如果某个设计不便手机识别,QRdx 会自行调整(更深的颜色、更简单的形状或更高的纠错等级),并在说明文字中告知。如果仍然不够,通常是因为内容太长,你会收到黑底白字的二维码,并附有说明。

**在编辑器中打开** 会以相同的设计打开编辑器:颜色、形状、边框和边距。Logo 图标不会随链接带入,请在编辑器中重新选择。

## 任意聊天中的内联模式 [#inline-mode-in-any-chat]

无需把机器人加入聊天,就可以向任意聊天发送二维码。在消息输入框中依次输入 `@`、机器人的用户名、一个空格,再输入链接或文本。稍等片刻,二维码会出现在输入框上方。点击它即可发送,同样带有三个下载和编辑器按钮。你的聊天对象不需要使用该机器人。在文本中添加 `--options` 即可设计内联二维码。

## 群组 [#groups]

把机器人添加到群组,然后发送 `/qr`,后面跟上链接或文本,例如 `/qr https://example.com/menu`。机器人会回复你的消息并附上二维码。

群组中的机器人默认开启隐私模式,这个机器人也保持开启,所以它看不到群组中的对话。Telegram 只会把发给它的命令以及对它自己消息的回复传给它。它会响应 `/qr`、`/start` 和 `/help`,忽略其他所有内容。当群组中有多个机器人,或机器人不响应单独的 `/qr` 时,请在命令中加上它的用户名:`/qr@`,后面跟用户名,再跟链接或文本。

## 限制与套餐 [#limits-and-plans]

机器人免费使用,没有套餐之分。如果你在短时间内生成大量二维码,机器人会请你等待一分钟再生成下一个;每次重新设计都算作生成一个二维码。当同时使用的人很多时,它可能会提示繁忙,请一分钟后再试。

## 移除机器人 [#remove-the-bot]

在私聊中,打开机器人的资料页并将其屏蔽,或删除该聊天。在群组中,由管理员在成员列表中移除机器人。

机器人已发送的二维码会保留在聊天中。它们的 **下载 PNG**、**下载 SVG** 和 **在编辑器中打开** 按钮仍可使用,因为它们直接链接到 QRdx;**样式** 依赖机器人,机器人移除后即失效。

## 面向开发者 [#for-developers]

机器人发送的每个二维码都来自 [Image API](/docs/developers/image-api),输入的选项则是 [CLI](/docs/developers/cli) 的选项。若要在自己的脚本中生成二维码,请直接使用其中任意一个。

## 自托管 [#self-hosting]

自托管的 QRdx 服务器可以运行自己的机器人。用 [@BotFather](https://t.me/BotFather) 创建一个机器人,在服务器上设置 `TELEGRAM_BOT_TOKEN`、`TELEGRAM_WEBHOOK_SECRET` 和 `TELEGRAM_BOT_USERNAME`,然后运行设置脚本。具体步骤见 [`plugins/telegram/README.md`](https://github.com/qrdxinc/qrdx/blob/main/plugins/telegram/README.md)。在这三个变量全部设置之前,机器人的路由会返回 404,你的网站也不会列出该机器人。速率限制需要 Upstash Redis;没有它则不启用。请参阅[自托管](/docs/self-hosting#optional-services)。
