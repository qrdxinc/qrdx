QRdxはオープンソースのQRコードプラットフォームです。静的QRコードはアカウント不要で無料で作成でき、動的QRコードは印刷後に変更でき、ホスト型ページとスキャン分析も利用できます。動的QRコードは、解約後もすべてのプランで動作し続けます（[Never-Hostage保証](/guarantee)）。
