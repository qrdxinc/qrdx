`handleImageLoad` mendekode kode QR dari elemen gambar di browser dan mengembalikan teksnya. Gunakan fungsi ini untuk membaca kode dari unggahan, tangkapan layar, atau foto tanpa mengirim gambar ke mana pun. Untuk area tarik-dan-lepas siap pakai, pasang komponen [QR Code Scanner](/docs/components/qr-code-scanner) yang dibangun di atasnya.

| Fungsi | Hasil | Catatan |
| --- | --- | --- |
| `handleImageLoad(img, size, returnFullData?)` | `Promise<string \| QRCode \| "NO_QR">` | Teks hasil dekode, atau hasil lengkap dari dekoder jika `returnFullData` diaktifkan. `"NO_QR"` jika tidak ada kode yang ditemukan. Hanya untuk browser |
| `downloadImageWithBoundingBox(img, corners, filename)` | `void` | Menyimpan gambar sebagai PNG dengan kode yang ditemukan diberi garis tepi merah |
| `getImageScanScore(imageOrBlob, options?)` | `Promise<ImageScanScoreResult>` | Mendekode dan memberi skor pada gambar yang sudah ada. Lihat [Apakah bisa dipindai?](/docs/features/frames#will-it-scan) |
| `scanQRPixels(pixels, expected, options?)` | `Promise<PixelScanResult>` | Memeriksa apakah piksel RGBA terdekode menjadi `expected`, di Node |

## Mendekode gambar yang diunggah [#decode-an-uploaded-image]

```tsx title="components/qr-reader.tsx"
"use client";

import { handleImageLoad } from "qrdx";
import { useState } from "react";

async function decodeFile(file: File): Promise<string | null> {
  const url = URL.createObjectURL(file);
  try {
    const image = new Image();
    image.src = url;
    await image.decode();
    const result = await handleImageLoad(image, image.naturalWidth);
    return typeof result === "string" && result !== "NO_QR" ? result : null;
  } finally {
    URL.revokeObjectURL(url);
  }
}

export function QrReader() {
  const [result, setResult] = useState("");

  async function onChange(event: React.ChangeEvent<HTMLInputElement>) {
    const file = event.target.files?.[0];
    if (!file) return;
    try {
      setResult((await decodeFile(file)) ?? "No QR code found");
    } catch {
      setResult("Could not read that image");
    }
  }

  return (
    <div>
      <input
        accept="image/*"
        aria-label="Image with a QR code"
        type="file"
        onChange={onChange}
      />
      {result ? <p>{result}</p> : null}
    </div>
  );
}
```

Pilih tangkapan layar sebuah kode, lalu tautannya muncul di bawah input. `image.decode()` menunggu file selesai dimuat; `handleImageLoad` kemudian menggambar gambar pada kanvas dan menjalankan jsQR, yang dimuat sesuai kebutuhan sehingga tidak ikut masuk ke bundel yang tidak pernah melakukan pemindaian.

## Cara kerja deteksi [#how-detection-works]

`handleImageLoad(img, size, returnFullData)` mencoba seluruh gambar terlebih dahulu, lalu empat potongan (area kiri bawah, kanan bawah, kanan atas, dan tengah pada 65% dari gambar), masing-masing pada enam skala dari 100% hingga 10%. Fungsi ini mengembalikan dekode pertama yang berhasil, sehingga kode yang hanya menempati sebagian kecil tangkapan layar tetap ditemukan. Gambar yang sangat lebar atau tinggi diperkecil terlebih dahulu.

- `img` harus berupa `<img>` yang sudah dimuat. Tunggu `decode()` atau peristiwa `load`.
- `size` dipertahankan demi kompatibilitas dengan rilis sebelumnya dan diabaikan: skala diambil dari dimensi gambar itu sendiri. Berikan lebar gambar.
- `returnFullData` mengembalikan objek hasil jsQR, bukan teksnya.

Kode yang buram, terpotong di tepi, atau lebih terang daripada latar belakangnya (modul terang pada latar gelap) dilaporkan sebagai `"NO_QR"`.

## Posisi dan data mentah [#position-and-raw-data]

Dengan `returnFullData` diaktifkan, hasilnya adalah objek asli dari dekoder:

```ts title="lib/decode-full.ts"
import { handleImageLoad } from "qrdx";

const found = await handleImageLoad(image, image.naturalWidth, true);
if (found !== "NO_QR") {
  found.data; // "https://example.com"
  found.version; // 1 to 40
  found.binaryData; // the raw bytes, as number[]
  found.chunks; // the encoded segments and their modes
  found.location.topLeftCorner; // { x, y } in the image's pixels, and the other three corners
}
```

`downloadImageWithBoundingBox` menggambar garis tepi kode pada gambar asli lalu menyimpannya, yang membantu saat sebuah foto terdekode menjadi hasil yang tidak terduga. Sudut diberikan dengan urutan kiri atas, kanan atas, kiri bawah, kanan bawah:

```ts title="lib/debug-detection.ts"
import { downloadImageWithBoundingBox, handleImageLoad } from "qrdx";

const found = await handleImageLoad(image, image.naturalWidth, true);
if (found !== "NO_QR") {
  const { topLeftCorner, topRightCorner, bottomLeftCorner, bottomRightCorner } = found.location;
  downloadImageWithBoundingBox(
    image,
    [topLeftCorner, topRightCorner, bottomLeftCorner, bottomRightCorner],
    "found-code.png"
  );
}
```

## Beri skor pada gambar, bukan hanya mendekodenya [#score-an-image-instead-of-only-decoding-it]

`getImageScanScore` mendekode gambar yang sudah ada dan juga melaporkan seberapa andal gambar tersebut dapat dipindai: dekode pada tiga ukuran dengan keburaman seperti kamera, kontras, polaritas, zona tenang, dan resolusi. Fungsi ini menerima `File`, `Blob`, atau `<img>`.

```ts title="lib/score-image.ts"
import { getImageScanScore } from "qrdx";

const { data, score, grade, checks } = await getImageScanScore(file);
// data: "https://example.com" or null
// score: 0 to 100, grade: "great" | "ok" | "risky" | "fails"
```

[Pemeriksa pemindaian](/tools/scan-checker) dibangun di atasnya. Di Node, `scanQRPixels(pixels, expected)` memeriksa apakah piksel RGBA (dari `decodePNGPixels` atau `sharp().raw()`) terdekode menjadi nilai yang diketahui.

## Jika terjadi masalah [#if-something-goes-wrong]

- **Setiap gambar mengembalikan `"NO_QR"`.** Gambar belum dimuat saat Anda memanggil fungsi. Gunakan await pada `image.decode()` terlebih dahulu. Jika sudah dimuat, kode mungkin terlalu kecil, buram, terpotong, atau terbalik; coba gambar yang lebih tajam dengan seluruh kode dan sedikit margin di sekelilingnya.
- **`handleImageLoad` dipanggil di server.** Fungsi ini memerlukan kanvas. Panggil dari Client Component atau event handler, atau gunakan `scanQRPixels` di Node.
- **Garis tepi dari `downloadImageWithBoundingBox` berbentuk pita (bow tie).** Urutan sudut salah. Berikan kiri atas, kanan atas, kiri bawah, kanan bawah.
