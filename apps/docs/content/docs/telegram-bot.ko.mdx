QRdx 봇은 링크나 텍스트를 Telegram 안에서 바로 QR 코드로 만들어 줍니다. 무료이며 QRdx 계정이 필요 없습니다. 채팅에서 누군가에게 지금 바로 코드를 전달해야 할 때 사용하세요. 손님에게 줄 Wi-Fi 비밀번호, 그룹에 공유할 링크, 테이블에 놓을 메뉴 등이 그 예입니다.

## 작동 방식 [#how-it-works]

QRdx는 여러분이 만든 코드를 저장하지 않으며, 봇은 메시지에 답하기 위해서만 각 메시지를 읽습니다. 모든 코드는 QRdx가 여러분의 콘텐츠와 선택한 디자인이 담긴 링크로 렌더링한 이미지입니다. 그래서 코드의 스타일을 바꿀 때는 그 링크에서 두 가지를 다시 읽어 옵니다. 링크는 다른 링크와 마찬가지로 로그와 캐시에 남을 수 있으므로, 비밀번호 같은 비밀 정보는 코드로 만들지 마세요. Telegram은 다른 메시지와 마찬가지로 채팅에 메시지를 보관합니다.

## 개인 채팅 [#private-chat]

봇에 링크나 텍스트를 보내면 QR 코드와 버튼 네 개로 답합니다.

- **PNG 다운로드**는 저장하거나 공유하기 좋은 이미지를 엽니다.
- **SVG 다운로드**는 인쇄와 디자인 도구에 적합한 벡터 버전을 엽니다.
- **편집기에서 열기**는 같은 디자인으로 QRdx 편집기를 엽니다. 웹 주소는 함께 전달됩니다. 그 밖의 텍스트는 전달되지 않으니 편집기에 직접 붙여넣으세요.
- **스타일**은 채팅 안에서 바로 코드의 모양을 바꿉니다(아래 참고).

코드에는 보낸 내용이 줄바꿈까지 그대로 담깁니다. 앞뒤 공백은 제거되고, `qrdx.dev` 같은 도메인만 보내면 `https://qrdx.dev`로 바뀝니다. `/help`(또는 `/start`)를 보내면 봇 사용법을 볼 수 있습니다. 텍스트가 너무 길어 QR 코드 하나에 담을 수 없으면 봇이 알려 줍니다. 전체 텍스트가 있는 페이지의 링크를 사용하면 더 작고 스캔하기 쉬운 코드를 만들 수 있습니다.

## 코드 스타일 바꾸기 [#style-your-code]

코드 아래의 **스타일**을 탭하면 다운로드 버튼 대신 **모양**, **색상**, **프레임**, **로고**가 나타나고, 그 아래에 **PNG 다운로드**와 **완료**가 표시됩니다. 각 그룹을 열면 옵션이 나오며, 현재 코드에 적용된 옵션 옆에는 ✓가 표시되고 **뒤로**를 누르면 돌아갑니다. 옵션을 탭하면 봇이 사진을 다시 그립니다. **완료**를 누르면 다운로드 버튼이 다시 나타납니다. 각 변경은 현재 코드 상태를 기준으로 적용됩니다. 그룹에서는 코드를 요청한 사람만 스타일을 바꿀 수 있으며, 다른 사람이 탭하면 짧은 안내가 표시됩니다.

모양은 작은 크기에서도 잘 읽히는 편집기 기본 디자인 중 일부입니다. **Plain**은 흰 배경에 검은색인 디자인입니다. 모양을 고르면 도형과 색상이 바뀌고, 선택해 둔 프레임과 로고는 유지됩니다. 색상을 고르면 코드 전체가 흰 배경 위에서 해당 색으로 바뀝니다. 프레임에는 "Scan me" 라벨이 추가되고, 로고 메뉴에서는 편집기의 빠른 아이콘 일곱 개를 고를 수 있습니다.

코드를 만들 때 링크나 텍스트 뒤에 옵션을 붙여 스타일을 지정할 수도 있습니다. 옵션 이름은 [QRdx CLI](/docs/developers/cli)와 같습니다. 개인 채팅, 그룹의 `/qr` 뒤, 인라인 모드에서 사용할 수 있습니다. 인라인 모드는 아직 바꿀 메시지가 없으므로 이 방법이 코드를 꾸미는 유일한 방법입니다.

```text title="Telegram message"
qrdx.dev --look modern --fg 0051ff --frame banner-bottom --frame-text "Scan me"
```

첫 번째 옵션 앞의 내용은 모두 콘텐츠로 처리됩니다. 모양이 먼저 적용되고 그 위에 나머지 옵션이 적용되므로, `--look royal --fg 0051ff`를 쓰면 Royal의 도형을 유지한 채 파란색이 됩니다. 휴대폰이 `--`를 긴 대시로 바꿔도 동작합니다. 잘못된 옵션이나 값을 입력하면 사용할 수 있는 값을 나열한 답장이 옵니다.

| 옵션 | 바뀌는 항목 | 값 |
| --- | --- | --- |
| `--look` | 편집기 프리셋 중 하나로 전체 디자인 | `plain`, `classic`, `modern`, `royal`, `folio`, `caffeine`, `retro`, `bordeaux`, `blossom` |
| `--fg` (또는 `--color`) | 점, 그리고 따로 지정하지 않으면 모서리 눈 | `0051ff` 같은 16진수 색상 또는 `black`, `blue`, `green`, `red`, `purple`, `orange` |
| `--bg` | 배경 | `--fg`와 같음 |
| `--eye-color` | 세 모서리 눈 | `--fg`와 같음 |
| `--dot-color` | 모서리 눈의 중심 | `--fg`와 같음 |
| `--body` | 점의 모양 | `rounded`, `circle`, `classy` 등 편집기의 {facts.bodyPatterns}가지 점 모양 중 하나 |
| `--eye` | 모서리 눈의 모양 | `square`, `rounded`, `gear` 등 {facts.eyeShapes}가지 눈 모양 중 하나 |
| `--dot` | 눈 중심의 모양 | `square`, `rounded`, `circle` 등 {facts.eyeCentres}가지 중심 모양 중 하나 |
| `--frame` | 코드 주위의 프레임 | `none` 또는 `banner-bottom`, `banner-top`, `speech-bubble`, `polaroid` 등 {facts.frameStyles}가지 기본 프레임 중 하나 |
| `--frame-text` | 프레임의 라벨, 최대 24자 | 아무 텍스트. 공백이 있으면 따옴표로 묶습니다. `--frame`이 없으면 코드 아래 배너에 표시됩니다 |
| `--template` | 템플릿으로 그린 프레임 | `Arrow`, `StandardBox`, `SquareBorder`, `StrikedBox`, `DotRing`, `Halloween` 또는 `default`, 대소문자 무관 |
| `--logo` | 가운데에 들어가는 아이콘 | `link`, `wifi`, `location`, `phone`, `email`, `whatsapp`, `instagram`, `file`, `calendar` 또는 `none` |

봇이 스타일을 적용한 코드를 보내기 전에, QRdx는 편집기와 같은 스캔 점수로 코드를 검사합니다. 휴대폰이 읽기 어려운 디자인이면 QRdx가 이를 조정하고(더 어두운 색, 더 단순한 도형, 더 높은 오류 정정) 설명 문구에 그 사실을 알립니다. 그래도 부족하면(대개 콘텐츠가 길 때) 안내와 함께 흰 배경에 검은색 코드가 전송됩니다.

**편집기에서 열기**는 색상, 도형, 프레임, 테두리 등 같은 디자인으로 편집기를 엽니다. 로고 아이콘은 링크에 포함되지 않으므로 편집기에서 다시 선택하세요.

## 모든 채팅에서 인라인 모드 [#inline-mode-in-any-chat]

봇을 추가하지 않고도 어떤 채팅에든 코드를 보낼 수 있습니다. 메시지 입력란에 `@`, 봇의 사용자 이름, 공백, 링크나 텍스트를 차례로 입력하세요. 잠시 후 입력란 위에 코드가 나타납니다. 탭하면 전송되며, 다운로드와 편집기 버튼 세 개가 함께 표시됩니다. 메시지를 받는 사람은 봇이 없어도 됩니다. 인라인 코드의 스타일을 지정하려면 텍스트에 `--options`를 추가하세요.

## 그룹 [#groups]

그룹에 봇을 추가한 다음 `/qr` 뒤에 링크나 텍스트를 보내세요. 예: `/qr https://example.com/menu`. 봇이 여러분의 메시지에 코드로 답장합니다.

그룹의 봇은 기본적으로 개인정보 보호 모드가 켜져 있으며, 이 봇도 켜 둔 상태를 유지하므로 그룹의 대화를 볼 수 없습니다. Telegram은 봇을 대상으로 한 명령과 봇 자신의 메시지에 대한 답장만 전달합니다. 봇은 `/qr`, `/start`, `/help`에만 응답하고 나머지는 무시합니다. 그룹에 봇이 둘 이상이거나 봇이 단순한 `/qr`에 응답하지 않으면 명령에 봇의 사용자 이름을 붙이세요. `/qr@` 뒤에 사용자 이름, 그다음에 링크나 텍스트를 입력합니다.

## 한도와 요금제 [#limits-and-plans]

봇은 무료이며 요금제가 없습니다. 짧은 시간에 코드를 많이 만들면 봇이 다음 코드를 만들기 전에 1분 기다려 달라고 안내합니다. 스타일을 바꿀 때마다 코드 한 개로 계산됩니다. 동시에 많은 사람이 사용하면 봇이 바쁘다고 답할 수 있습니다. 1분 뒤에 다시 시도하세요.

## 봇 제거하기 [#remove-the-bot]

개인 채팅에서는 봇의 프로필을 열어 차단하거나 채팅을 삭제하세요. 그룹에서는 관리자가 멤버 목록에서 봇을 제거합니다.

봇이 이미 보낸 코드는 채팅에 그대로 남습니다. 코드의 **PNG 다운로드**, **SVG 다운로드**, **편집기에서 열기** 버튼은 QRdx로 바로 연결되므로 계속 작동합니다. 반면 **스타일**은 봇이 필요하므로 봇이 없어지면 작동하지 않습니다.

## 개발자용 [#for-developers]

봇이 보내는 모든 코드는 [Image API](/docs/developers/image-api)에서 만들어지며, 입력하는 옵션은 [CLI](/docs/developers/cli)의 옵션입니다. 직접 만든 스크립트로 코드를 만들려면 둘 중 하나를 바로 사용하세요.

## 셀프 호스팅 [#self-hosting]

직접 호스팅하는 QRdx 서버에서 자체 봇을 실행할 수 있습니다. [@BotFather](https://t.me/BotFather)로 봇을 만들고, 서버에 `TELEGRAM_BOT_TOKEN`, `TELEGRAM_WEBHOOK_SECRET`, `TELEGRAM_BOT_USERNAME`을 설정한 다음 설정 스크립트를 실행하세요. 자세한 단계는 [`plugins/telegram/README.md`](https://github.com/qrdxinc/qrdx/blob/main/plugins/telegram/README.md)에 있습니다. 세 변수를 모두 설정하기 전에는 봇의 경로가 404로 응답하고 사이트에 봇이 표시되지 않습니다. 속도 제한에는 Upstash Redis가 필요하며, 없으면 속도 제한이 꺼집니다. [셀프 호스팅](/docs/self-hosting#optional-services)을 참고하세요.
