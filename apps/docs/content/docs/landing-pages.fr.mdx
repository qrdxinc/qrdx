Une page d'atterrissage hébergée est une page mobile que QRdx diffuse pour vous à l'adresse `https://qrdx.dev/p/<slug>` (ou sur votre [domaine personnalisé](/docs/custom-domains)). Chaque page est fournie avec un [QR code dynamique](/docs/dynamic-qr-codes) : vous pouvez donc continuer à modifier la page une fois le code imprimé et suivre chaque scan. Utilisez-la quand le code n'a encore aucune destination, ou quand une page adaptée au téléphone vaut mieux que votre site : un menu, une carte de contact, une liste de liens, un événement, la fiche d'un produit.

<Callout type="info" title="Offres">
  L'offre Gratuit inclut 3 pages hébergées avec un pied de page « Made with QRdx ». Pro supprime ce pied de page et la limite ; Business ajoute les pages en marque blanche et le CSS personnalisé. Chaque page utilise aussi l'un des codes dynamiques de votre offre. Consultez [Offres et limites](/docs/plans-and-limits).
</Callout>

Vous êtes pressé ? Voici les pages de tâches courtes : [Créer une page mobile](/docs/help/pages-and-forms/create-a-page) et [Changer ce qu'ouvre un code imprimé](/docs/help/dynamic-codes/change-the-type).

## Fonctionnement [#how-it-works]

<Diagram id="hosted-page-anatomy" />

Une page est un empilement de blocs : un en-tête, des liens, une carte de contact, un menu, un formulaire. Vous les organisez dans l'éditeur, puis vous publiez ; QRdx génère la page sur ses serveurs, ce qui la rend rapide sur mobile et vous dispense d'avoir votre propre site. Le lien court du code ouvre la page, et tout ce que proposent les [contrôles du code](/docs/code-controls) s'y applique : mot de passe, planification, limite de scans.

## Créer une page [#create-a-page]

1. Ouvrez **Pages & forms** dans la barre latérale et cliquez sur **New page**, ou cliquez sur **New code** dans la liste des codes et choisissez un type de page à la place de **Website link**.
2. Choisissez l'un des {facts.hostedPageTypes} [types de pages](#page-types) et un modèle dans sa galerie.
3. Cliquez sur **Create page**. L'éditeur s'ouvre avec les blocs du modèle, et le QR code de la page est prêt à être téléchargé.

<Shot id="page-templates" />

Vous avez déjà imprimé un code qui ouvre un site web ? Ouvrez-le et cliquez sur **Change type** pour le transformer en page, avec le même lien court.

Les modèles contiennent des exemples de noms, de prix, de chiffres et de photos pour que vous voyiez comment la page s'assemble. Tant que vous n'avez pas publié une première fois, l'éditeur vous rappelle de les remplacer par les vôtres.

## Types de pages [#page-types]

Chaque type de page est un point de départ : n'importe quel bloc peut être ajouté à n'importe quelle page, et une page créée à partir d'un type peut ressembler à un autre.

| Type de page | Conçu pour | Commence avec |
| --- | --- | --- |
| **Link list** | Lien en bio, créateurs, podcasts | En-tête de profil, liens, icônes de réseaux sociaux |
| **Social media** | Tous les profils derrière un seul code | En-tête de profil, une ligne par réseau avec votre identifiant |
| **Business** | Boutiques, salons, bureaux | Horaires, adresse et carte, contact, un appel à l'action |
| **vCard Plus** | Cartes de visite numériques | Carte de contact avec **Save contact** |
| **Menu** | Cafés, restaurants, bars | Menu avec étiquettes alimentaires et allergènes ([en savoir plus](/docs/forms-and-pages#menu)) |
| **Coupon** | Réductions et cadeaux | Coupon avec un code, un code-barres ou un bouton d'utilisation ([en savoir plus](/docs/forms-and-pages#coupon)) |
| **Event** | Fêtes, conférences, webinaires, mariages | Événement avec ajout au calendrier ([en savoir plus](/docs/forms-and-pages#event)) |
| **App download** | Un seul code pour tous les app stores | Téléchargement d'application ([en savoir plus](/docs/forms-and-pages#app-download)) |
| **Feedback & forms** | Avis, enquêtes NPS, inscriptions | Formulaire, et liens d'avis sur le modèle de retour client ([en savoir plus](/docs/forms-and-pages#forms)) |
| **Product** | Emballages, étiquettes, étiquettes volantes | Ingrédients, allergènes, valeurs nutritionnelles, certifications, entretien, GS1 Digital Link ([en savoir plus](/docs/product-pages)) |
| **Appointments** | Salons, cliniques, tuteurs | Services et tarifs, formulaire de demande de rendez-vous, horaires |
| **Payments & tips** | Pourboires, dons, factures | Liens de paiement et coordonnées bancaires à copier |
| **Property listing** | Biens à vendre ou à louer, portes ouvertes | Prix et caractéristiques, photos, agent, formulaire de demande de visite ou d'inscription |
| **Pet ID tag** | Médailles de collier, affiches d'animal perdu | Bouton d'appel, informations sur l'animal, formulaire « je l'ai trouvé » |
| **Medical ID** | Médailles, bracelets, cartes d'allergie | Contact d'urgence, pathologies, allergies, traitements |
| **PDF** | Brochures, manuels, bibliothèques de documents | Un PDF à lire ou à télécharger, ou plusieurs fichiers |
| **Images** | Galeries et portfolios | Galerie de photos |
| **MP3 / Audio** | Musique, podcasts, messages vocaux | Lecteur audio |
| **Video** | Vidéos de produits, clips | Vidéo |
| **Playlist** | Mix, visites audio, livres audio | Plusieurs pistes lues à la suite |
| **Custom page** | Tout le reste | Une page vierge ou une annonce |

<IfAvailable feature="fileStorage" unavailable>

Le téléversement de fichiers n'est pas configuré sur ce déploiement : les cinq types reposant sur un fichier (PDF, Images, MP3 / Audio, Video et Playlist) sont donc masqués dans le sélecteur. Les blocs peuvent toujours renvoyer vers des fichiers hébergés ailleurs.

</IfAvailable>

**Appointments** envoie les demandes de rendez-vous vers les [réponses](/docs/forms-and-pages#responses) et les notifications de la page, et peut renvoyer vers votre outil de réservation. Il n'affiche pas de calendrier en direct des créneaux libres : vous confirmez chaque demande vous-même.

**Payments & tips** n'encaisse jamais de paiement. Chaque bouton ouvre la page propre de l'application de paiement (PayPal, Venmo, Cash App, Revolut, Wise), et les coordonnées bancaires, les identifiants UPI et les adresses de portefeuille disposent de boutons de copie.

Les pages **Pet ID tag** et **Medical ID** peuvent être lues par toute personne qui scanne le code. N'ajoutez que ce qui aide quelqu'un qui trouve votre animal ou qui vous porte secours en cas d'urgence.

## Modifier et publier [#edit-and-publish]

L'éditeur comporte trois onglets et un aperçu mobile en direct. Touchez un bloc dans l'aperçu pour accéder directement à ses réglages.

- **Blocks** : ajoutez des blocs avec **Add block**, réorganisez-les par glisser-déposer (ou avec les boutons fléchés), masquez un bloc sans le supprimer, dupliquez-le ou retirez-le. Chaque bloc a son propre formulaire ; les problèmes (par exemple un lien sans `https://`) sont signalés sur le bloc et doivent être corrigés avant la publication.
- **Design** : utilisez les couleurs de l'un de vos [thèmes QR enregistrés](/dashboard?to=themes) pour que la page corresponde au code imprimé, choisissez une palette prédéfinie ou réglez chaque couleur vous-même. Choisissez une police, un rayon d'angle, un arrière-plan uni, en dégradé ou en image, et un logo facultatif. **Match colors** déduit des couleurs de texte et de cartes lisibles à partir de votre arrière-plan et de votre couleur d'accent, et un avertissement s'affiche lorsque le contraste du texte est faible.
- **Settings** : la description et l'image de l'aperçu de partage, **Show in search engines** (désactivé par défaut) et **Custom CSS** avec Business.

<Shot id="page-editor" />

Cliquez sur **Publish** (ou appuyez sur <kbd>⌘</kbd>/<kbd>Ctrl</kbd> + <kbd>S</kbd>) pour mettre vos modifications en ligne. Rien ne change pour les visiteurs tant que vous n'avez pas publié ; les modifications non publiées sont conservées dans votre navigateur, ce qui vous permet de les restaurer après avoir fermé l'onglet. Chaque publication est enregistrée comme une version. Si un collègue publie la même page pendant que vous la modifiez, QRdx vous demande de recharger la page au lieu d'écraser ses modifications.

| Bouton | Un appel à l'action : un lien web, une adresse e-mail ou un numéro de téléphone |

| Image | Une photo ou une bannière, avec un lien facultatif |
| Vidéo | Une vidéo YouTube, Vimeo ou Loom. Elle ne se charge depuis le site de la vidéo qu'une fois que le visiteur appuie sur lecture |
| PDF, Galerie, Audio, Fichier vidéo, Téléchargements | Des fichiers que vous importez ou vers lesquels vous faites un lien ([en savoir plus](/docs/files)) |
| Carte de contact | Nom, poste, téléphones, e-mails, site web, adresse, actions rapides (appeler, WhatsApp, e-mail, site web, itinéraire), **Enregistrer le contact** et **Partager** |

| Wi-Fi | Nom du réseau et mot de passe avec boutons de copie ([en savoir plus](/docs/forms-and-pages#menu)) |
| Détails | Des libellés et des valeurs sous forme de liste ou de grille de tuiles (chambres, race, groupe sanguin, poids net) |
| Événement | Date, lieu, organisateur et ajout au calendrier ([en savoir plus](/docs/forms-and-pages#event)) |
| Formulaire, Liens d'avis | Des questions avec une boîte de réception des réponses, et des boutons d'avis ([en savoir plus](/docs/forms-and-pages#forms)) |
| Menu, Coupon | Des sections et des articles avec leurs prix, et un coupon avec code-barres ([en savoir plus](/docs/forms-and-pages)) |
| Détails du produit | Certifications, ingrédients, allergènes, tableau nutritionnel, sections qui s'ouvrent au toucher, et le GTIN ([en savoir plus](/docs/product-pages)) |
| Liens de paiement | PayPal, Venmo, Cash App, Revolut, Wise, UPI, virement bancaire et portefeuilles crypto. Les boutons ouvrent chaque application ; les détails ont des boutons de copie. La page n'encaisse jamais le paiement |
| Séparateur, Espacement | Outils de mise en page |

### vCard Plus et Enregistrer le contact [#vcard-plus-and-save-contact]

**Enregistrer le contact** télécharge un fichier vCard 3.0 (`.vcf`) que les téléphones ouvrent dans leur application de contacts. Il contient le nom, l'entreprise, le poste, les téléphones, les e-mails, le site web, l'adresse, la biographie, les profils sociaux de la page et la photo. Une photo importée dans le stockage QRdx est intégrée au fichier si elle pèse 1 Mo ou moins ; les photos plus lourdes, ainsi que celles liées depuis d'autres sites, sont incluses sous forme de lien, car QRdx ne télécharge jamais d'images depuis d'autres sites. **Partager** ouvre la feuille de partage du téléphone, ou copie le lien de la page sur ordinateur. Pour mettre aussi la carte sur une carte NFC, consultez [Cartes de visite NFC](/docs/nfc#nfc-business-cards).

## Ce que les visiteurs obtiennent [#what-visitors-get]

- Des pages rapides, générées côté serveur et conçues pour les téléphones. Le seul script QRdx présent sur la page compte les vues et les appuis pour votre carte **Activité de la page** ; il n'y a ni analyse produit ni widget d'assistance. Vos propres [pixels de suivi](/docs/tracking-and-conversions#tracking-pixels-on-hosted-pages-pro) ne se chargent que si vous les ajoutez au code.
- Masquées des moteurs de recherche, sauf si vous activez **Afficher dans les moteurs de recherche**.
- Des aperçus de partage (titre, description, image) pour les applications de messagerie et les réseaux sociaux. Les codes protégés par mot de passe ne révèlent jamais les détails de la page dans les aperçus.
- Un petit lien **Signaler un abus** sur chaque page, y compris les pages en marque blanche.

La protection par mot de passe, les dates de début et de fin, les limites de scans et la mise en pause des [contrôles du code](/docs/code-controls) s'appliquent aussi à la page et à son fichier **Enregistrer le contact**, y compris lorsque quelqu'un ouvre directement le lien de la page.

## Limites et offres [#limits-and-plans]

| | Gratuit | Pro | Business |
| --- | --- | --- | --- |
| Pages hébergées | 3 | Illimitées | Illimitées |
| Pied de page « Made with QRdx » | Affiché | Supprimé | Supprimé |
| Marque blanche (votre logo comme icône du navigateur, sans marque QRdx) | Non | Non | Oui |
| CSS personnalisé | Non | Non | Oui |

Les limites ne vous empêchent que de créer de nouvelles pages. Les pages que vous avez déjà continuent de fonctionner avec toutes les offres, y compris après un passage à une offre inférieure. Après un passage de Business à une offre inférieure, le CSS personnalisé d'une page n'est plus appliqué, et l'éditeur refuse de publier de nouveau cette page tant que vous n'avez pas supprimé le CSS dans ses **Paramètres**.

### CSS personnalisé [#custom-css]

Avec Business, écrivez du CSS simple dans **Paramètres** → **CSS personnalisé**. Les règles ne s'appliquent qu'à l'intérieur de votre page : chaque sélecteur est limité au contenu de la page, et chaque bloc peut être ciblé avec `.lp-block-<type>`, par exemple `.lp-block-links a` ou `.lp-block-contact h1`. Par sécurité, le CSS ne peut pas charger de fichiers (`url()`, `@import`, `@font-face`), ne peut pas utiliser d'échappements par barre oblique inverse, et ne prend en charge que les at-rules `@media`, `@supports`, `@container` et `@keyframes`.

## Pour les développeurs [#for-developers]

Le `kind` d'un code dans la [REST API](/docs/developers/api/update-code) vaut `redirect` ou `page`, et `PATCH /v1/codes/{id}` passe de l'un à l'autre comme le fait **Changer de type**. Les pages elles-mêmes se construisent dans l'éditeur ; l'API ne modifie pas les blocs.
