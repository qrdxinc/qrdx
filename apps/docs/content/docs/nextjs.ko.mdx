이 페이지를 끝까지 따라 하면 클라이언트 JavaScript 없이 Server Component에서 렌더링한 QR 코드, 라우트 매개변수로 만든 코드, 입력란에 연결된 실시간 코드, 로고가 들어간 코드, SVG를 저장하는 버튼을 만들 수 있습니다. `QRCodeSVG`와 `QRCode`는 클라이언트 전용 훅을 사용하지 않으므로 Server Component가 코드를 페이지 HTML에 바로 렌더링합니다. 브라우저에서 값이 바뀌거나 파일을 저장해야 할 때만 Client Component가 필요합니다.

<NpmStatus package="qrdx" />

## 시작하기 전에 [#before-you-start]

- App Router를 사용하는 Next.js 프로젝트가 필요합니다. 예제는 Next.js 15와 16처럼 App Router의 비동기 `params`를 사용합니다.
- React 18 이상이 필요합니다. App Router에서 이미 요구하는 버전입니다.

## 만들어 보기 [#build-it]

### 1. qrdx 설치 [#1-install-qrdx]

```package-install
qrdx
```

`react`와 `react-dom`은 피어 의존성이므로 앱에서 사용하는 버전이 그대로 쓰입니다.

### 2. Server Component에서 코드 렌더링 [#2-render-a-code-in-a-server-component]

```tsx title="app/page.tsx"
import { QRCodeSVG } from "qrdx";

export default function Page() {
  return (
    <QRCodeSVG
      value="https://example.com"
      size={256}
      margin={4}
      role="img"
      aria-label="QR code for example.com"
    />
  );
}
```

페이지를 열어 보세요. `<svg>`가 서버가 보내는 HTML에 포함되어 있으므로 JavaScript가 로드되기 전에도 표시됩니다. 정적 페이지는 빌드할 때 한 번 렌더링하고, 스크린 리더는 `aria-label`을 읽어 줍니다.

<Shot id="lib-nextjs-server-code" />

`margin`은 코드 주변의 여백(콰이어트 존)이며 모듈 단위입니다. 기본값은 0이라서 자체 패딩이 있는 카드 안의 코드에 적합합니다. QR 표준은 4를 권장하며, 배경이 복잡하거나 어두울 때 안전한 선택입니다.

### 3. 라우트 매개변수로 값 만들기 [#3-build-the-value-from-a-route-param]

```tsx title="app/tickets/[id]/page.tsx"
import { QRCodeSVG } from "qrdx";

export default async function TicketPage({
  params,
}: {
  params: Promise<{ id: string }>;
}) {
  const { id } = await params;
  const url = `https://example.com/check-in/${encodeURIComponent(id)}`;
  return <QRCodeSVG value={url} size={200} margin={4} level="H" />;
}
```

`/tickets/A-12`에 접속하면 코드는 `https://example.com/check-in/A-12`를 엽니다. Next.js는 `params`를 프로미스로 전달하므로 페이지는 `async`입니다. 사용자나 데이터베이스에서 온 값은 URL에 넣기 전에 반드시 인코딩하세요. `H` 레벨은 코드의 최대 30%까지 손상되어도 읽을 수 있어서, 접히거나 긁히기 쉬운 배지에 도움이 됩니다.

### 4. Client Component에서 입력값 따라가기 [#4-follow-an-input-in-a-client-component]

```tsx title="components/live-qr-code.tsx"
"use client";

import { QRCodeSVG } from "qrdx";
import { useState } from "react";

export function LiveQrCode() {
  const [value, setValue] = useState("https://example.com");
  return (
    <div>
      <input
        aria-label="Text or link to encode"
        value={value}
        onChange={(event) => setValue(event.target.value)}
      />
      {value ? <QRCodeSVG value={value} size={200} margin={4} /> : null}
    </div>
  );
}
```

코드는 키를 누를 때마다 다시 그려지며, 첫 번째 값은 여전히 서버에서 렌더링됩니다. Server Component 페이지에서 이 컴포넌트를 그대로 import할 수 있습니다.

`QRCodeCanvas`도 Client Component이지만(`"use client"`가 포함되어 있습니다) 단순한 사각형 모듈만 그립니다. 스타일을 적용한 코드에는 `QRCodeSVG`나 `QRCode`를 사용하세요.

### 5. 로고 추가 [#5-add-a-logo]

```tsx title="components/logo-qr-code.tsx"
import { QRCode } from "qrdx";

export function LogoQrCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      margin={4}
      level="H"
      logo="/logo.png"
    />
  );
}
```

`/logo.png`는 프로젝트의 `public` 폴더에 있는 파일입니다. 로고는 코드 너비의 4분의 1 크기로 그려지고 뒤에 있는 모듈은 지워지므로, 코드는 오류 정정에 의존해 스캔됩니다. 그래서 `level`이 `H`입니다. 또한 `QRCode`는 코드가 복구할 수 없을 만큼 큰 로고를 자동으로 줄여 줍니다.

`logo`에는 앱 내 경로, URL, 데이터 URL을 넣을 수 있습니다. 다운로드에는 데이터 URL이 가장 안전합니다. 원격 이미지는 브라우저가 파일로 복사하려면 CORS 헤더가 필요하기 때문입니다. `logoOptions`로 로고의 크기, 여백, 위치, 자르기를 설정합니다. [코드로 로고 추가하기](/docs/features/logos)를 참고하세요.

### 6. SVG로 다운로드 [#6-download-as-svg]

```tsx title="components/download-svg-button.tsx"
"use client";

import { downloadQRCode } from "qrdx";

export function DownloadSvgButton({ value }: { value: string }) {
  return (
    <button
      type="button"
      onClick={() =>
        downloadQRCode(
          { value, level: "Q", margin: 4 },
          {
            format: "svg",
            size: { width: 1024, height: 1024 },
            filename: "qr-code.svg",
          },
        )
      }
    >
      Download SVG
    </button>
  );
}
```

버튼을 클릭하면 1024 px 벡터 파일인 `qr-code.svg`가 저장됩니다. `downloadQRCode`는 브라우저의 DOM이 필요하므로 버튼은 Client Component여야 합니다. Server Component 페이지에서 이 버튼을 렌더링하고 값을 prop으로 전달할 수 있습니다. 다른 파일 형식이 필요하면 `format`을 `png`, `jpg`, `webp`, `eps`, `pdf` 중 하나로 설정하세요(PDF는 선택 패키지인 `jspdf`가 필요합니다). 모든 옵션은 [내보내기 및 다운로드](/docs/features/downloads)에서 확인할 수 있습니다.

## 이미지 URL이 필요할 때 [#when-you-need-an-image-url]

이메일, Open Graph 이미지, Markdown 파일처럼 React를 실행할 수 없는 곳에서는 컴포넌트 대신 이미지 URL이 필요합니다. [QR 코드 이미지 API](/docs/developers/image-api)는 키 없이 이미지 URL을 반환합니다.

```html title="email.html"
<img src="https://api.qrdx.dev/v1/qr?data=https://example.com&format=png" width="256" height="256" alt="QR code for example.com" />
```

## 바로 쓸 수 있는 컴포넌트 [#ready-made-components]

[shadcn/ui 레지스트리](/docs/developers/shadcn)를 사용하면 프로젝트에 컴포넌트를 설치할 수 있습니다. [다운로드 버튼이 있는 QR 코드](/docs/components/qr-code), 카드, 공유 대화상자, 생성기, 스캐너, Wi-Fi 및 연락처 코드가 있습니다.

```bash title="Terminal"
npx shadcn@latest add https://qrdx.dev/r/qr-code.json
```

## 문제가 생겼을 때 [#if-something-goes-wrong]

- **`useRef only works in Client Components`(또는 `useState`에 대한 같은 오류).** Server Component에서 `QRCodeCanvas`나 훅을 사용하는 컴포넌트를 렌더링했습니다. 해당 파일 맨 위에 `"use client"`를 추가하거나 `QRCodeSVG`를 대신 렌더링하세요.
- **로고가 페이지에는 보이지만 다운로드한 파일에는 없습니다.** CORS 헤더가 없는 다른 출처의 이미지입니다. `public`에서 제공하거나 데이터 URL을 전달하세요.
- **`PDF export needs the optional "jspdf" package`.** 앱에서 `npm install jspdf`를 실행하세요. 다른 형식은 추가 설치가 필요 없습니다.
