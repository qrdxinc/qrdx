`handleImageLoad` decodiert einen QR-Code aus einem Bildelement im Browser und gibt dessen Text zurück. Damit liest du Codes aus Uploads, Screenshots oder Fotos, ohne das Bild irgendwohin zu senden. Für eine fertige Drop-Zone installierst du die Komponente [QR Code Scanner](/docs/components/qr-code-scanner), die darauf aufbaut.

| Funktion | Rückgabe | Hinweise |
| --- | --- | --- |
| `handleImageLoad(img, size, returnFullData?)` | `Promise<string \| QRCode \| "NO_QR">` | Der decodierte Text oder mit `returnFullData` das vollständige Ergebnis des Decoders. `"NO_QR"`, wenn nichts gefunden wird. Nur im Browser |
| `downloadImageWithBoundingBox(img, corners, filename)` | `void` | Speichert das Bild als PNG, wobei der gefundene Code rot umrandet ist |
| `getImageScanScore(imageOrBlob, options?)` | `Promise<ImageScanScoreResult>` | Decodiert und bewertet ein vorhandenes Bild. Siehe [Lässt er sich scannen?](/docs/features/frames#will-it-scan) |
| `scanQRPixels(pixels, expected, options?)` | `Promise<PixelScanResult>` | Prüft in Node, ob RGBA-Pixel zu `expected` decodiert werden |

## Hochgeladenes Bild decodieren [#decode-an-uploaded-image]

```tsx title="components/qr-reader.tsx"
"use client";

import { handleImageLoad } from "qrdx";
import { useState } from "react";

async function decodeFile(file: File): Promise<string | null> {
  const url = URL.createObjectURL(file);
  try {
    const image = new Image();
    image.src = url;
    await image.decode();
    const result = await handleImageLoad(image, image.naturalWidth);
    return typeof result === "string" && result !== "NO_QR" ? result : null;
  } finally {
    URL.revokeObjectURL(url);
  }
}

export function QrReader() {
  const [result, setResult] = useState("");

  async function onChange(event: React.ChangeEvent<HTMLInputElement>) {
    const file = event.target.files?.[0];
    if (!file) return;
    try {
      setResult((await decodeFile(file)) ?? "No QR code found");
    } catch {
      setResult("Could not read that image");
    }
  }

  return (
    <div>
      <input
        accept="image/*"
        aria-label="Image with a QR code"
        type="file"
        onChange={onChange}
      />
      {result ? <p>{result}</p> : null}
    </div>
  );
}
```

Wähle einen Screenshot eines Codes aus, und sein Link erscheint unter dem Eingabefeld. `image.decode()` wartet, bis die Datei geladen ist. `handleImageLoad` zeichnet das Bild dann auf ein Canvas und führt jsQR aus, das erst bei Bedarf geladen wird, damit es nicht in Bundles landet, die nie scannen.

## So funktioniert die Erkennung [#how-detection-works]

`handleImageLoad(img, size, returnFullData)` probiert zuerst das ganze Bild aus, dann vier Ausschnitte (unten links, unten rechts, oben rechts und die Mitte mit jeweils 65 % des Bildes), jeweils in sechs Maßstäben von 100 % bis 10 %. Es gibt die erste erfolgreiche Decodierung zurück, sodass auch ein Code gefunden wird, der nur einen kleinen Teil eines Screenshots einnimmt. Sehr breite oder hohe Bilder werden zuerst verkleinert.

- `img` muss ein geladenes `<img>` sein. Warte auf `decode()` oder das `load`-Ereignis.
- `size` bleibt aus Kompatibilitätsgründen mit früheren Versionen erhalten und wird ignoriert: Die Maßstäbe ergeben sich aus den eigenen Abmessungen des Bildes. Übergib die Breite des Bildes.
- `returnFullData` gibt statt des Textes das Ergebnisobjekt von jsQR zurück.

Ein Code, der unscharf, an den Rändern abgeschnitten oder heller als sein Hintergrund ist (helle Module auf dunklem Grund), wird als `"NO_QR"` gemeldet.

## Position und Rohdaten [#position-and-raw-data]

Wenn `returnFullData` gesetzt ist, ist das Ergebnis das eigene Objekt des Decoders:

```ts title="lib/decode-full.ts"
import { handleImageLoad } from "qrdx";

const found = await handleImageLoad(image, image.naturalWidth, true);
if (found !== "NO_QR") {
  found.data; // "https://example.com"
  found.version; // 1 to 40
  found.binaryData; // the raw bytes, as number[]
  found.chunks; // the encoded segments and their modes
  found.location.topLeftCorner; // { x, y } in the image's pixels, and the other three corners
}
```

`downloadImageWithBoundingBox` zeichnet den Umriss des Codes auf das Originalbild und speichert es. Das hilft, wenn ein Foto zu etwas Unerwartetem decodiert wird. Die Ecken werden in dieser Reihenfolge übergeben: oben links, oben rechts, unten links, unten rechts:

```ts title="lib/debug-detection.ts"
import { downloadImageWithBoundingBox, handleImageLoad } from "qrdx";

const found = await handleImageLoad(image, image.naturalWidth, true);
if (found !== "NO_QR") {
  const { topLeftCorner, topRightCorner, bottomLeftCorner, bottomRightCorner } = found.location;
  downloadImageWithBoundingBox(
    image,
    [topLeftCorner, topRightCorner, bottomLeftCorner, bottomRightCorner],
    "found-code.png"
  );
}
```

## Ein Bild bewerten, statt es nur zu decodieren [#score-an-image-instead-of-only-decoding-it]

`getImageScanScore` decodiert ein vorhandenes Bild und gibt zusätzlich an, wie zuverlässig es sich scannen ließe: Es decodiert in drei Größen mit kameraähnlicher Unschärfe und prüft Kontrast, Polarität, Ruhezone und Auflösung. Es akzeptiert eine `File`, einen `Blob` oder ein `<img>`.

```ts title="lib/score-image.ts"
import { getImageScanScore } from "qrdx";

const { data, score, grade, checks } = await getImageScanScore(file);
// data: "https://example.com" or null
// score: 0 to 100, grade: "great" | "ok" | "risky" | "fails"
```

Der [Scan-Checker](/tools/scan-checker) baut darauf auf. In Node prüft `scanQRPixels(pixels, expected)`, ob RGBA-Pixel (aus `decodePNGPixels` oder `sharp().raw()`) zu einem bekannten Wert decodiert werden.

## Wenn etwas schiefgeht [#if-something-goes-wrong]

- **Jedes Bild liefert `"NO_QR"`.** Das Bild war beim Aufruf der Funktion noch nicht geladen. Warte zuerst mit `await` auf `image.decode()`. Wenn es geladen ist, ist der Code möglicherweise zu klein, unscharf, beschnitten oder invertiert. Versuche ein schärferes Bild, das den ganzen Code mit etwas Rand drumherum zeigt.
- **`handleImageLoad` wird auf dem Server aufgerufen.** Es braucht ein Canvas. Rufe es aus einer Client Component oder einem Event-Handler auf, oder nutze `scanQRPixels` in Node.
- **Der Umriss von `downloadImageWithBoundingBox` sieht wie eine Schleife aus.** Die Ecken stehen in der falschen Reihenfolge. Übergib oben links, oben rechts, unten links, unten rechts.
