Alla fine di questa pagina avrai un QR code generato da un Server Component senza JavaScript lato client, un codice creato da un parametro della route, un codice in tempo reale collegato a un input, un codice con il tuo logo e un pulsante che salva un SVG. `QRCodeSVG` e `QRCode` non usano hook solo client, quindi un Server Component genera il codice direttamente nell'HTML della pagina. Ti serve un Client Component solo quando il valore cambia nel browser o per salvare un file.

<NpmStatus package="qrdx" />

## Prima di iniziare [#before-you-start]

- Un progetto Next.js con App Router. Gli esempi usano i `params` asincroni dell'App Router, come in Next.js 15 e 16.
- React 18 o successivo, già richiesto dall'App Router.

## Come si fa [#build-it]

### 1. Installa qrdx [#1-install-qrdx]

```package-install
qrdx
```

`react` e `react-dom` sono peer dependency, quindi vengono usate le versioni della tua app.

### 2. Genera un codice in un Server Component [#2-render-a-code-in-a-server-component]

```tsx title="app/page.tsx"
import { QRCodeSVG } from "qrdx";

export default function Page() {
  return (
    <QRCodeSVG
      value="https://example.com"
      size={256}
      margin={4}
      role="img"
      aria-label="QR code for example.com"
    />
  );
}
```

Apri la pagina. L'`<svg>` fa parte dell'HTML inviato dal server, quindi compare prima che venga caricato qualsiasi JavaScript, una pagina statica lo genera una sola volta in fase di build e gli screen reader leggono l'`aria-label`.

<Shot id="lib-nextjs-server-code" />

`margin` è la zona di rispetto attorno al codice, in moduli. Il valore predefinito è 0, adatto a un codice dentro una card con un proprio padding. Lo standard QR richiede 4, la scelta più sicura su uno sfondo carico o scuro.

### 3. Crea il valore da un parametro della route [#3-build-the-value-from-a-route-param]

```tsx title="app/tickets/[id]/page.tsx"
import { QRCodeSVG } from "qrdx";

export default async function TicketPage({
  params,
}: {
  params: Promise<{ id: string }>;
}) {
  const { id } = await params;
  const url = `https://example.com/check-in/${encodeURIComponent(id)}`;
  return <QRCodeSVG value={url} size={200} margin={4} level="H" />;
}
```

Visita `/tickets/A-12` e il codice aprirà `https://example.com/check-in/A-12`. Next.js passa `params` come promise, quindi la pagina è `async`. Codifica tutto ciò che arriva da un utente o da un database prima di inserirlo in un URL. Il livello `H` permette di danneggiare fino al 30% del codice, utile su un badge che viene piegato o graffiato.

### 4. Segui un input in un Client Component [#4-follow-an-input-in-a-client-component]

```tsx title="components/live-qr-code.tsx"
"use client";

import { QRCodeSVG } from "qrdx";
import { useState } from "react";

export function LiveQrCode() {
  const [value, setValue] = useState("https://example.com");
  return (
    <div>
      <input
        aria-label="Text or link to encode"
        value={value}
        onChange={(event) => setValue(event.target.value)}
      />
      {value ? <QRCodeSVG value={value} size={200} margin={4} /> : null}
    </div>
  );
}
```

Il codice viene ridisegnato a ogni tasto premuto e il primo valore viene comunque generato sul server. Una pagina Server Component può importare questo componente così com'è.

Anche `QRCodeCanvas` è un Client Component (include `"use client"`), ma disegna solo semplici moduli quadrati. Usa `QRCodeSVG` o `QRCode` per i codici con stile.

### 5. Aggiungi un logo [#5-add-a-logo]

```tsx title="components/logo-qr-code.tsx"
import { QRCode } from "qrdx";

export function LogoQrCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      margin={4}
      level="H"
      logo="/logo.png"
    />
  );
}
```

`/logo.png` è un file nella cartella `public` del tuo progetto. Il logo viene disegnato a un quarto della larghezza del codice e i moduli dietro di esso vengono rimossi, quindi il codice si affida alla correzione degli errori per essere letto: per questo `level` è `H`. `QRCode` riduce inoltre un logo troppo grande perché il codice possa ripararsi.

`logo` accetta un percorso della tua app, un URL o un data URL. Per i download il data URL è la scelta più sicura, perché un'immagine remota richiede header CORS prima che il browser possa copiarla nel file. `logoOptions` imposta dimensione, spazio libero, posizione e ritaglio del logo; vedi [Aggiungere un logo nel codice](/docs/features/logos).

### 6. Scarica come SVG [#6-download-as-svg]

```tsx title="components/download-svg-button.tsx"
"use client";

import { downloadQRCode } from "qrdx";

export function DownloadSvgButton({ value }: { value: string }) {
  return (
    <button
      type="button"
      onClick={() =>
        downloadQRCode(
          { value, level: "Q", margin: 4 },
          {
            format: "svg",
            size: { width: 1024, height: 1024 },
            filename: "qr-code.svg",
          },
        )
      }
    >
      Download SVG
    </button>
  );
}
```

Facendo clic sul pulsante si salva `qr-code.svg`, un file vettoriale da 1024 px. `downloadQRCode` richiede il DOM del browser, quindi il pulsante è un Client Component. Una pagina Server Component può comunque generarlo e passargli il valore come prop. Per altri file, imposta `format` su `png`, `jpg`, `webp`, `eps` o `pdf` (il PDF richiede il pacchetto opzionale `jspdf`). [Esportazione e download](/docs/features/downloads) descrive tutte le opzioni.

## Quando ti serve l'URL di un'immagine [#when-you-need-an-image-url]

Email, immagini Open Graph, file Markdown e altri luoghi che non possono eseguire React hanno bisogno dell'URL di un'immagine invece di un componente. L'[API immagine per QR code](/docs/developers/image-api) ne restituisce uno senza chiave:

```html title="email.html"
<img src="https://api.qrdx.dev/v1/qr?data=https://example.com&format=png" width="256" height="256" alt="QR code for example.com" />
```

## Componenti pronti all'uso [#ready-made-components]

Il [registry shadcn/ui](/docs/developers/shadcn) installa componenti nel tuo progetto: un [QR code con pulsanti di download](/docs/components/qr-code), una card, una finestra di condivisione, un generatore, uno scanner e codici per Wi-Fi e contatti.

```bash title="Terminal"
npx shadcn@latest add https://qrdx.dev/r/qr-code.json
```

## Se qualcosa va storto [#if-something-goes-wrong]

- **`useRef only works in Client Components` (o lo stesso per `useState`).** Hai usato `QRCodeCanvas`, o un componente con hook, in un Server Component. Aggiungi `"use client"` all'inizio di quel file, oppure usa `QRCodeSVG`.
- **Il logo compare nella pagina ma non nel file scaricato.** L'immagine proviene da un'altra origine senza header CORS. Servila da `public` oppure passa un data URL.
- **`PDF export needs the optional "jspdf" package`.** Esegui `npm install jspdf` nell'app. Gli altri formati non richiedono nulla di aggiuntivo.
