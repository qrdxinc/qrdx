QRdx는 다른 서비스의 링크와 동적 코드를 한 번에 가져올 수 있어서, 이미 배포한 코드를 다시 인쇄하지 않고도 이전할 수 있습니다. 가져오기는 항상 세 단계로 진행됩니다. 가져올 항목을 고르고, 미리 보고, 가져옵니다. 다른 서비스에 있는 코드를 QRdx에서 편집하고 추적하고 싶을 때 이 가이드를 사용하세요.

<Callout type="info" title="요금제">
  가져오기는 모든 요금제에서 사용할 수 있으며, 요금제의 활성 코드 한도 안에서 가능합니다. 기존 back-half를 유지하려면 Pro 또는 Business가 필요합니다. [요금제와 한도](/docs/plans-and-limits)를 참고하세요.
</Callout>

급하신가요? 간단한 안내 페이지가 있습니다: [다른 서비스의 코드 가져오기](/docs/help/dynamic-codes/import).

## 작동 방식 [#how-it-works]

<Diagram id="import-flow" />

[코드](/dashboard?to=codes)를 열고 **⋯** 메뉴 → **코드 가져오기** → **Bitly 및 다른 앱에서**를 선택하세요. 소스는 두 가지입니다.

- **연결된 계정:** Bitly, Rebrandly, Short.io. QRdx가 해당 서비스의 API로 링크 목록을 불러옵니다.
- **내보내기 파일:** QR Code Generator PRO, Uniqode (Beaconstac), Flowcode, QR TIGER, ME-QR, TinyURL, Hovercode, Scanova, 또는 대상 URL이 담긴 모든 CSV.

가져오는 동안 기존 계정은 전혀 바뀌지 않습니다.

### 가져오기로 만들어지는 것 [#what-an-import-creates]

각 링크나 코드는 다음 정보를 가진 [동적 QR 코드](/docs/dynamic-qr-codes)가 됩니다.

- 대상 URL과 제목
- 태그(선택)와 "Imported from Bitly" 같은 폴더(이름을 바꾸거나 끌 수 있습니다)
- `Imported from Bitly bit.ly/3AbCdEf on 2026-11-01.` 같은 메모와 링크의 원래 생성일. 새 코드의 생성일은 QRdx가 직접 지정합니다.

미리 보기에서는 만들어질 코드 수, 새로 생기는 태그, 건너뛰는 항목을 확인할 수 있습니다.

- **이미 가져옴:** 이전에(어떤 이전 실행에서든) 가져온 링크는 항상 건너뛰므로, 가져오기를 두 번 실행해도 중복이 생기지 않습니다.
- **같은 대상이 있음:** 대상에 이미 QRdx 코드가 있는 링크는 기본적으로 건너뜁니다. 그래도 가져오려면 옵션을 선택하세요.
- **요금제 한도 초과:** 요금제의 활성 코드 수에 맞지 않는 링크입니다. 미리 보기에서 들어갈 수 있는 앞쪽 링크만 가져오거나 업그레이드할 수 있습니다.
- **가져올 수 없음:** 대상이 없거나 올바르지 않은 링크, 이미 QRdx 단축 링크를 가리키는 링크입니다.

가져오기는 50개씩 일괄 처리되며 진행 표시줄이 나타납니다. 대화 상자를 닫아도 안전합니다. 가져오기 도구를 다시 열면 **최근 가져오기**에서 이어서 진행됩니다. 요약에는 생성, 건너뜀, 실패한 코드와 그 이유가 표시됩니다.

## 연결된 계정에서 가져오기 [#from-a-connected-account]

1. 서비스를 선택하세요. 아직 연결되지 않았다면 바로 연결하면 됩니다(로그인하거나 API 키 또는 토큰을 붙여 넣으세요). 토큰은 암호화되어 저장되며, [설정 → 연동](/settings/integrations)에서 연결을 해제할 수 있습니다.
2. 검색하고, 도메인이나 태그로 필터링한 뒤 링크를 선택하세요. **일치하는 링크 모두 선택**은 한 번에 최대 1,000개까지 가져옵니다. 나머지는 다시 실행하세요.
3. 미리 보기를 확인하고 **가져오기**를 클릭하세요.

| 서비스 | 연결 방법 | 링크 목록 | 인쇄한 코드 계속 작동 |
| --- | --- | --- | --- |
| Bitly | 로그인 또는 일반 액세스 토큰 | 예 | 유료 Bitly 요금제만 가능: 한 달에 링크 리디렉션 Core 5개, Growth 20개, Premium 110개 |
| Rebrandly | API 키 | 예 | Rebrandly의 월간 대상 수정 한도 내에서 가능: Essentials 10회, Professional 50회, Growth 150회(무료는 없음) |
| Short.io | API 키 | 예, 한 번에 도메인 하나 | 예, 모든 요금제 |

요금제 한도는 각 서비스가 정한 것이며 시간이 지나면서 바뀝니다. 각 서비스의 요금 페이지를 확인하세요.

## 인쇄한 코드 계속 작동시키기 [#keep-printed-codes-working]

다른 서비스에서 인쇄한 QR 코드에는 그 서비스의 단축 링크가 담겨 있습니다. 연결된 계정에서 가져온 후 요약 화면에 **인쇄한 코드를 계속 작동시키기**가 나타납니다.

1. **시험 실행**에서 모든 기존 링크와 그 링크가 가리키게 될 QRdx 링크를 보여 줍니다. 아직 아무것도 바뀌지 않습니다.
2. 확인하면 QRdx가 각 기존 링크의 대상을 새 QRdx 코드로 바꿉니다. 방문자는 여전히 같은 페이지에 도착하고, 이제 모든 스캔이 QRdx 분석에 표시됩니다. 기존 서비스에는 여전히 클릭이 먼저 기록됩니다.
3. **실행 취소**를 누르면 가져올 때 QRdx가 저장해 둔 원래 대상으로 되돌립니다.

서비스가 거부하는 경우(예: 링크 리디렉션이 남지 않은 Bitly 요금제) QRdx는 중단하고 이유를 알려 주며, 남은 링크는 그대로 둡니다. 대상에 이미 QRdx 코드가 있어 건너뛴 링크는 그 기존 코드를 가리킵니다.<IfAvailable feature="customDomains"> back-half가 사용자의 도메인(아래 참고)과 함께 이동하는 링크는 변경되지 않습니다. DNS를 전환하면 그 링크가 곧 QRdx 링크가 됩니다.</IfAvailable>

<Callout type="warn" title="기존 계정은 당분간 유지하세요">
  확신이 설 때까지 서비스 연결을 유지하세요. 실행 취소에는 연결이 필요합니다. 기존 링크가 계속 리디렉션되려면 기존 계정도 활성 상태여야 합니다.
</Callout>

## 기존 back-half 유지하기 [#keep-the-original-back-halves]

Pro와 Business에서는 가져오기 미리 보기에서 **기존 back-half 유지**를 선택하세요. QRdx가 유지할 수 있는 경우 각 코드가 임의 값 대신 기존 back-half를 받으므로, `bit.ly/spring-menu`는 `qrdx.dev/q/spring-menu`가 됩니다.

- back-half는 3~64자의 영문자, 숫자, `-`, `_`로 이루어져 있고, `-`로 시작하거나 끝나지 않으며([사용자 지정 back-half](/docs/dynamic-qr-codes#custom-back-halves) 참고), 예약어가 아니고, `qrdx.dev`에서 어떤 QRdx 코드도 아직 사용하지 않는 경우 유지됩니다<IfAvailable feature="customDomains"> (사용자의 도메인에서는 그 도메인의 내 코드만 해당)</IfAvailable>.
- 그렇지 않으면 코드에 생성된 back-half가 지정되며, 미리 보기에 변경 내용과 이유가 표시됩니다. 예: `spring-menu → Ab3xK9q · Another QRdx code already uses this back-half on qrdx.dev`. 가져오기는 미리 보기에 표시된 back-half를 그대로 사용합니다.
- back-half는 Bitly, Short.io와 마찬가지로 대소문자를 구분합니다.

유지할 수 없는 back-half에는 생성된 값이 지정됩니다. 해당 링크는 다시 인쇄하거나 기존 서비스에서 리디렉션을 설정해야 합니다.

<IfAvailable feature="customDomains" id="your-own-domain-go-yourbrand-com" title="내 도메인(go.yourbrand.com)">

링크에 내 도메인을 사용한다면 그 도메인을 QRdx로 옮기고 back-half를 유지할 수 있어서, DNS를 전환한 뒤에도 `go.yourbrand.com/spring-menu`가 계속 작동합니다.

1. 먼저 **설정** → **도메인**에서 도메인을 추가하세요. 지금은 인증하지 않아도 됩니다. 그러면 back-half는 도메인 자체에 유지되며, 내 코드끼리만 겹치지 않으면 되고 몇몇 기술 용어만 예약되어 있습니다.
2. 가져오기 미리 보기에서 **기존 back-half 유지**를 선택하고 **링크 위치**에서 도메인을 고르세요. 미리 보기에 유지되는 back-half가 표시됩니다.
3. 가져오세요. 코드가 도메인에 만들어지고 back-half를 바로 확보합니다.
4. 도메인의 DNS를 QRdx로 연결하고 인증하세요([사용자 지정 도메인](/docs/custom-domains) 참고). 한가한 시간에 진행하세요. DNS가 이동하는 즉시 도메인의 링크는 기존 서비스에서 작동을 멈추고, 인증이 끝나면 QRdx에서 작동하기 시작합니다.

가져올 때 도메인이 아직 QRdx에 없다면 back-half는 대신 `qrdx.dev`에 유지됩니다(QRdx 전체에서 겹치지 않아야 합니다). 도메인을 추가하고 인증한 뒤 가져오기 요약에서 **코드 연결**을 클릭하면 그 코드들을 도메인으로 옮길 수 있습니다.

</IfAvailable>

## 내보내기 파일에서 가져오기 [#from-an-export-file]

1. 파일을 준비합니다(아래 단계 참고). QRdx는 한 번에 최대 2 MB, 1,000행까지의 CSV를 읽습니다. Excel 파일은 먼저 CSV로 저장하거나 다운로드하세요.
2. 가져오기 도구에서 제공업체를 선택하고 파일을 업로드하세요. QRdx는 가능한 경우 제공업체의 열을 자동으로 인식하며, 매핑은 직접 바꿀 수 있어요. 필수 항목은 대상 주소뿐입니다. 이전 단축 링크(또는 코드 ID)가 있으면 다시 업로드할 때 이미 가져온 코드를 건너뜁니다.
3. 미리 본 뒤 가져오고, **Copy all new links** 또는 **Download mapping CSV**(이전 링크 → 새 QRdx 링크)를 사용하세요.

QRdx는 제공업체 자체 도메인에 있는 코드를 변경할 수 없습니다. 인쇄한 코드가 계속 작동하게 하려면 이전 제공업체에서 각 동적 코드를 열고, 대상 주소를 매핑에 있는 새 QRdx 링크로 설정하세요. 이 코드들이 리디렉션되려면 이전 계정이 활성 상태여야 합니다. 해지하기 전에 QRdx 코드로 다시 인쇄하세요.<IfAvailable feature="customDomains"> 직접 소유한 도메인의 코드는 다시 인쇄하지 않고 도메인과 함께 옮길 수 있습니다. 위의 [내 도메인](#your-own-domain-go-yourbrand-com)을 참고하세요.</IfAvailable>

### QR Code Generator PRO [#qr-code-generator-pro]

코드 목록을 내보내는 공식 기능은 없습니다. 각 코드의 **Name**, **Short URL**, **Destination URL**을 담은 스프레드시트를 만드세요. 코드를 새 주소로 연결하려면 코드 → **Details** → **Edit**에서 URL을 바꾸고 저장하세요. 코드가 많다면 일괄 업데이트 기능에서 새 URL이 담긴 CSV로 최대 500개 코드를 처리할 수 있습니다.

### Uniqode (Beaconstac) [#uniqode-beaconstac]

**QR Codes → Dynamic**에서 전체를 선택하고 **⋯ → Export**를 누르세요. 조직별 또는 폴더별로 내보냅니다. 내보낸 파일의 열(QR Code Name, QR Code URL, Destination URL, Labels 등)은 인식됩니다. 새 주소로 연결하려면 코드 → **Edit** → 새 URL → **Next** → **Save** 순서로 진행하세요.

### Flowcode [#flowcode]

Flowcode는 폴더에 있는 코드만 내보내므로 먼저 코드를 폴더로 옮기세요. 그런 다음 **Folder** 섹션을 열고 폴더를 선택한 뒤 **Download URLs**를 클릭하세요. CSV의 열(Flowcode Name, Short Links, Scan Destination)이 인식되며, 일괄 생성 시트의 열(Flowcode Name, Flowcode Scan URL)도 인식됩니다. 새 주소로 연결하려면 **Assets** → 해당 코드 → **Overview** → **Destination** → **Save** 순서로 진행하세요.

### QR TIGER [#qr-tiger]

**My Account** → 카테고리(예: URL) 선택 → **Download QR List**를 누르세요. 카테고리마다 한 번씩 진행합니다. 새 주소로 연결하려면 **My Account → Dashboard → URL** → 해당 캠페인 → **Edit** → **Save** 순서로 진행하세요.

### ME-QR [#me-qr]

내보내기 기능은 없습니다. 각 코드의 Name, QR 링크, Destination URL을 정리하세요. 새 주소로 연결하려면 ME-QR 코드 목록에서 코드를 수정하세요.

### TinyURL [#tinyurl]

TinyURL은 유료 플랜에서 CSV 내보내기를 제공한다고 안내합니다. 링크를 CSV로 내보내거나 Alias와 Long URL을 정리하세요. TinyURL의 대상 주소를 수정하려면 유료 TinyURL 플랜이 필요합니다.

### Hovercode, Scanova 및 기타 [#hovercode-scanova-and-others]

제공업체에서 코드를 CSV로 내보낸 뒤(Hovercode는 Business 플랜에서 CSV 내보내기를 제공한다고 안내하고, Scanova는 다운로드 링크를 이메일로 보냅니다) 열 매핑을 확인하세요. 대상 주소 열이 있는 CSV라면 **Another provider (CSV)**로 가져올 수 있어요.

정적 QR 코드(goQR.me, QR Code Monkey, Adobe Express 등의 도구로 만든 코드)는 대상 주소 자체가 코드에 담겨 있어 해당 도구 없이도 계속 작동합니다. 새로 인쇄할 때 수정할 수 있고 추적도 되는 코드가 필요한 경우에만 CSV로 대상 주소를 가져오세요.

## QR 코드 라이브러리에서 가져오기 [#from-a-qr-code-library]

라이브러리는 정적 코드를 렌더링하므로 따로 옮길 것이 없습니다. 이미 인쇄한 코드는 계속 작동합니다. 앱의 렌더링 방식을 바꾸려면 `qrdx`를 설치하고 컴포넌트를 교체하세요.

### qrcode.react에서 [#from-qrcode-react]

```tsx title="Before and after"
// Before
import { QRCodeSVG } from "qrcode.react";

<QRCodeSVG value="https://example.com" size={256} fgColor="#111827" />;

// After
import { QRCodeSVG } from "qrdx";

<QRCodeSVG
  value="https://example.com"
  size={256}
  fgColor="#111827"
  bodyPattern="rounded"
/>;
```

`value`, `size`, `level`, `fgColor`, `bgColor`, `marginSize`(`margin`으로), `imageSettings`는 그대로 사용할 수 있습니다. qrdx는 패턴, 그라데이션, 템플릿을 추가로 제공합니다. [API 레퍼런스](/docs/api-reference)를 참고하세요.

### qr-code-styling에서 [#from-qr-code-styling]

```tsx title="Before and after"
// Before
import QRCodeStyling from "qr-code-styling";

const qr = new QRCodeStyling({
  data: "https://example.com",
  width: 256,
  dotsOptions: { type: "rounded", color: "#111827" },
  image: "/logo.png",
});
qr.append(ref.current);

// After
import { QRCodeSVG } from "qrdx";

<QRCodeSVG
  value="https://example.com"
  size={256}
  bodyPattern="rounded"
  fgColor="#111827"
  imageSettings={{ src: "/logo.png", width: 64, height: 64, excavate: true }}
/>;
```

qrdx는 React 컴포넌트이므로 추가할 인스턴스가 없습니다. 다른 요소처럼 렌더링하면 됩니다. 다운로드에는 [API 레퍼런스](/docs/api-reference)의 헬퍼를 사용하세요.

## 개발자용 [#for-developers]

스크립트로 코드를 옮기려면 [코드 API](/docs/developers/api/create-codes)로 코드를 생성하세요. Pro와 Business에서는 요청당 최대 {facts.apiBatchCodes}개까지 가능하며, 유지하려는 back-half에는 `slug`를, 재시도해도 배치가 중복되지 않도록 `Idempotency-Key`를 사용하세요.
