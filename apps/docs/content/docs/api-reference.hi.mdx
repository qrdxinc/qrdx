यह पेज बताता है कि `qrdx` क्या-क्या एक्सपोर्ट करता है, एंट्री पॉइंट और काम के हिसाब से, हर prop के टाइप और डिफ़ॉल्ट के साथ। इनका इस्तेमाल कैसे करें, यह फ़ीचर पेज समझाते हैं; यह पेज किसी नाम को खोजने के लिए है।

## एंट्री पॉइंट [#entry-points]

| यहाँ से इम्पोर्ट करें | इसमें क्या है | ज़रूरत |
| --- | --- | --- |
| `qrdx` | React कॉम्पोनेंट (`QRCode`, `QRCodeSVG`, `QRCodeCanvas`, `getQRAsSVG`) और `qrdx/core` की सारी चीज़ें | `react`, `react-dom` |
| `qrdx/core` | React के बिना पूरा इंजन: मार्कअप, डाउनलोड, प्रिंट फ़ाइलें, स्कैन स्कोर, फ़्रेम, टेम्पलेट, आर्ट और टाइप | कुछ नहीं |
| `qrdx/vanilla` | `createQRCode`, साथ में `qrdx/core` | एक DOM |
| `qrdx/element` | `<qrdx-code>` कस्टम एलिमेंट: `QRdxCodeElement`, `defineQRdxCode`, `toQRdxCodeHTML` | ड्रॉ करने के लिए DOM; मार्कअप रेंडर करने के लिए कुछ नहीं |
| `qrdx/element/define` | इम्पोर्ट होते ही `<qrdx-code>` रजिस्टर करता है | एक DOM |
| `qrdx/node` | `getQRAsPNG` | `@resvg/resvg-js` या `sharp` |
| `qrdx/vue` | `QRCode`, `QRCodeSVG`, `useQRCode`, साथ में `qrdx/core` | `vue` 3.3 या नया |
| `qrdx/preact` | `QRCode`, `QRCodeSVG` | `preact` 10 या नया |
| `qrdx/solid` | `QRCode`, `QRCodeSVG` | `solid-js` 1.8 या नया |
| `qrdx/angular` | `QRCode` कॉम्पोनेंट (`<qrdx-qr-code>`), साथ में `qrdx/core` | `@angular/core` 20 या नया |
| `qrdx/types` | हर टाइप, ऑप्शन लिस्ट और zod स्कीमा, रेंडरर के बिना | कुछ नहीं |

हर फ़्रेमवर्क पैकेज एक ऑप्शनल peer dependency है: `qrdx` इंस्टॉल करने से कोई ऐसा पैकेज नहीं जुड़ता जिसे आप इस्तेमाल नहीं करते। PDF के लिए `jspdf` भी ऑप्शनल है।

## कॉम्पोनेंट [#components]

### QRCode [#qrcode]

ज़्यादातर इस्तेमाल के लिए यही कॉम्पोनेंट है। `QRProps` के साथ एक आसान लोगो API, जो `<svg>` के रूप में रेंडर होता है। यह सिर्फ़ ब्राउज़र में चलने वाले hooks इस्तेमाल नहीं करता, इसलिए React Server Components में रेंडर हो जाता है।

```tsx title="components/example.tsx"
import { QRCode } from "qrdx";

<QRCode value="https://example.com" size={256} margin={4} level="H" logo="/logo.png" />;
```

| Prop | टाइप | डिफ़ॉल्ट | यह क्या करता है |
| --- | --- | --- | --- |
| `value` | `string` | ज़रूरी | एनकोड किया जाने वाला टेक्स्ट या URL, जैसा दिया गया है ठीक वैसा |
| `size` | `number` | `128` | चौड़ाई और ऊँचाई, पिक्सल में। फ़्रेम इसमें जुड़ता है; टेम्पलेट इसके अंदर फ़िट होता है |
| `scale` | `number` | `1` | `size` को गुणा करता है |
| `level` | `"L" \| "M" \| "Q" \| "H"` | `"Q"` | एरर करेक्शन: कोड का लगभग 7%, 15%, 25% या 30% हिस्सा खराब हो सकता है |
| `margin` | `number` | `0` | कोड के चारों ओर खाली जगह (quiet zone), मॉड्यूल में। स्टैंडर्ड में 4 माँगा गया है |
| `fgColor` | `ColorConfig` | `"#000000"` | डेटा मॉड्यूल का रंग: CSS रंग, ग्रेडिएंट या इमेज फ़िल |
| `bgColor` | `ColorConfig` | `"#FFFFFF"` | बैकग्राउंड। `"transparent"` देने पर कोई बैकग्राउंड नहीं बनता |
| `eyeColor` | `ColorConfig` | `fgColor` | तीनों कोने की आँखों (eyes) का रंग |
| `dotColor` | `ColorConfig` | `fgColor` | हर आँख के अंदर के डॉट का रंग |
| `eyeColors` | `EyeColors` | none | `topLeft`, `topRight` और `bottomLeft` के लिए अलग-अलग `outer` और `inner` रंग; हर एक `eyeColor` और `dotColor` को ओवरराइड करता है |
| `bodyPattern` | `BodyPattern` | `"circle"` | डेटा मॉड्यूल का आकार, इनमें से एक {facts.bodyPatterns} |
| `cornerEyePattern` | `CornerEyePattern` | `"gear"` | कोने की आँखों का आकार, इनमें से एक {facts.eyeShapes} |
| `cornerEyeDotPattern` | `CornerEyeDotPattern` | `"circle"` | आँख के डॉट का आकार, इनमें से एक {facts.eyeCentres} |
| `moduleScale` | `number` | `1` | हर डेटा मॉड्यूल का साइज़, 0.5 से 1। हर पैटर्न उस सबसे छोटे साइज़ पर रुक जाता है जिस पर कोड अब भी स्कैन होता है (`MODULE_SCALE_FLOOR`) |
| `logo` | `string` | none | बीच में बनाया जाने वाला पाथ, URL या data URL, जिसके पीछे के मॉड्यूल हटा दिए जाते हैं। इसके बिना कोई लोगो नहीं बनता |
| `logoOptions` | `LogoOptions` | none | लोगो का `size` (0.1 से 0.3, डिफ़ॉल्ट 0.25), `padding` (0 से 2 मॉड्यूल), `x` और `y` (0 से 1), `shape` और `plate` |
| `hideLogo` | `boolean` | `false` | `logo` सेट होने पर भी लोगो छिपा देता है |
| `autoLevel` | `boolean` | `false` | जब लोगो कोड के 7% से ज़्यादा हिस्से को ढकता है, तो `level` को बढ़ाकर `H` कर देता है (`AUTO_LEVEL_LOGO_COVERAGE`) |
| `frame` | `AnyQRFrame` | none | कॉल-टू-एक्शन फ़्रेम: `{ style, text, color, textColor, secondaryText, secondaryColor, fontScale }`, या `{ style: "custom", spec }`। आउटपुट फ़्रेम के हिसाब से बड़ा हो जाता है |
| `templateId` | `string` | none | `size` पर बनाया गया टेम्पलेट, जिसके अंदर कोड होता है: `"Arrow"`, `"StandardBox"`, `"SquareBorder"`, `"StrikedBox"`, `"Halloween"`, `"DotRing"` या `"default"` |
| `customTemplate` | `TemplateDefinition` | none | कोड में बनाया गया आपका अपना टेम्पलेट। `templateId` पर प्राथमिकता पाता है |
| `customProps` | `Record<string, any>` | none | टेम्पलेट के `wrapper` के लिए props, जैसे `DotRingProps` |
| `shape` | `"square" \| "circle" \| "heart" \| QRSilhouette` | `"square"` | कोड को डिस्क, दिल या आपकी अपनी आउटलाइन में रखता है, जो सजावटी मॉड्यूल से भरी होती है |
| `art` | `QRArt` | none | किसी तस्वीर को मॉड्यूल में मिलाता है: `{ mode, image, intensity, variant, matchEyes }` |
| `style` | `CSSProperties` | none | `<svg>` के लिए इनलाइन स्टाइल |
| `frameLabelMarkers` | `boolean` | `false` | एडिटर के लिए: हर फ़्रेम लेबल `<text>` पर `data-qrdx-frame-label` लगाता है। एक्सपोर्ट में यह कभी शामिल नहीं होता |
| `partMarkers` | `boolean` | `false` | एडिटर के लिए: बनाए गए हिस्सों पर `data-qrdx-part` लगाता है। एक्सपोर्ट में यह कभी शामिल नहीं होता |
| `isOGContext` | `boolean` | `false` | Open Graph इमेज रेंडरर के लिए लोगो को पोज़िशन किए गए `<img>` के रूप में बनाता है |

`QRCode` सिर्फ़ यही props लेता है; बाकी कोई भी prop छोड़ दिया जाता है। `QRCodeSVG` बाकी किसी भी prop (`className`, `aria-label`, `role`, `data-*`, …) को `<svg>` पर लगाता है, या फ़्रेम होने पर फ़्रेम के बाहरी `<svg>` पर। इवेंट हैंडलर मार्कअप में शामिल नहीं किए जाते।

### QRCodeSVG [#qrcodesvg]

`QRProps` के साथ React के SVG एट्रिब्यूट (`QRPropsSVG`): वही props जो `QRCode` में हैं, पर `logo`, `logoOptions`, `hideLogo` और `scale` के बिना। लोगो `imageSettings` से दिया जाता है, पिक्सल में:

| फ़ील्ड | टाइप | डिफ़ॉल्ट | यह क्या करता है |
| --- | --- | --- | --- |
| `src` | `string` | ज़रूरी | इमेज, URL या data URL के रूप में |
| `width`, `height` | `number` | ज़रूरी | `size` वाले ही पिक्सल में साइज़ |
| `excavate` | `boolean` | ज़रूरी | इमेज के पीछे के मॉड्यूल हटा देता है |
| `x`, `y` | `number` | बीच में | इमेज का ऊपरी बायाँ कोना |
| `padding` | `number` | `0` | मॉड्यूल हटाते समय इमेज के चारों ओर अतिरिक्त खाली जगह, पिक्सल में |
| `shape` | `"square" \| "rounded" \| "circle"` | `"square"` | इमेज को क्रॉप करता है |
| `plate` | `string` | none | इमेज के पीछे उसी के आकार में एक ठोस प्लेट |

अगर लोगो कोड की मरम्मत क्षमता से बड़ा है, तो उसे उसके केंद्र के चारों ओर छोटा कर दिया जाता है (`capImageSettings`, `QRCode` जैसा ही बजट)।

### QRCodeCanvas [#qrcodecanvas]

`QRProps` के साथ React के canvas एट्रिब्यूट (`QRPropsCanvas`), जो डिवाइस के पिक्सल रेशियो पर `<canvas>` में बनता है। यह ठोस रंगों के साथ सादे चौकोर मॉड्यूल बनाता है: ग्रेडिएंट अपने पहले स्टॉप पर लौट जाता है, और पैटर्न, आई कलर, `eyeColors`, `moduleScale`, `art` और टेम्पलेट props को अनदेखा किया जाता है। यह `"use client"` के साथ आता है।

### getQRAsSVG [#getqrassvg]

`getQRAsSVG(props: QRPropsSVG): Promise<JSX.Element>` कोड को React एलिमेंट के रूप में लौटाता है, जिसमें लोगो data URL के रूप में एम्बेड होता है। स्ट्रिंग चाहिए तो `toSVGString` या `getSVGString` इस्तेमाल करें।

## डाउनलोड और एक्सपोर्ट [#download-and-export]

| Function | Returns | Notes |
| --- | --- | --- |
| `downloadQRCode(props, { format, size, filename?, quality? })` | `Promise<void>` | फ़ाइल सेव करता है। `size` 50 से 5000 px तक और स्क्वेयर होता है; रास्टर फ़ॉर्मैट के लिए डिफ़ॉल्ट फ़ाइल नाम में पिक्सल साइज़ लिखा होता है |
| `getQRCodeDataUrl(props, format, size, { quality? })` | `Promise<string>` | वही फ़ाइल, data URL के रूप में |
| `getQRAsWebP(props, { quality? })` | `Promise<Blob>` | `quality` सेट न हो तो लॉसलेस; जहाँ ब्राउज़र एन्कोड नहीं कर सकता, वहाँ यह खुद एन्कोड करता है |
| `copyQRCodeToClipboard(props, size?)` | `Promise<void>` | क्लिपबोर्ड पर एक PNG। इसे यूज़र के किसी एक्शन से कॉल करें |
| `getSVGString(props)` | `Promise<string>` | लोगो एम्बेड किया हुआ SVG मार्कअप |
| `toSVGString(props)` | `string` | SVG मार्कअप, सिंक्रोनस, लोगो एम्बेड नहीं होता। कहीं भी चलता है |
| `toSVGElement(props, document?)` | `SVGSVGElement` | कोड एक DOM एलिमेंट के रूप में |
| `getQRAsSVGDataUri(props)` | `Promise<string>` | `data:image/svg+xml,…`, हर एक्सपोर्ट का पहला चरण |
| `getQRAsCanvas(props, mimeType, getCanvas?)` | `Promise<string \| HTMLCanvasElement>` | एक data URL, या `getCanvas` देने पर खुद canvas |
| `getQRAsPNG(props, { size?, loadExternalLogos? })` | `Promise<Uint8Array>` | Node में PNG बाइट्स, `qrdx/node` से। इसके लिए `@resvg/resvg-js` या `sharp` चाहिए |
| `validateSize(width, height)` | `{ isValid, error? }` | साइज़ का वह नियम जो `downloadQRCode` लागू करता है |
| `getDownloadFilename(format, size, frame?)` | `string` | डिफ़ॉल्ट फ़ाइल नाम |
| `withQRSize(props, size)` | `QRProps` | `size` पर बने props, जिनमें पिक्सल लोगो साथ में स्केल होता है |
| `canvasToWebP(canvas, { quality? })`, `blobToDataUrl(blob)`, `encodeWebPLossless(rgba, width, height)` | | WebP हेल्पर |

कॉन्स्टेंट: `DownloadFormat` है `"png" \| "jpg" \| "webp" \| "svg" \| "pdf" \| "eps"`; `DOWNLOAD_FORMATS` हर एक को उसके MIME टाइप और एक्सटेंशन से मैप करता है; `PRESET_SIZES` में `small` (200), `medium` (400), `large` (800), `xlarge` (1200), `2xl` (1600) और `3xl` (2000) हैं; `DEFAULT_SIZE` 128 है।

## प्रिंट और EPS [#print-and-eps]

| Function | Returns | Notes |
| --- | --- | --- |
| `getPrintLayout(props, { size, unit?, bleed?, cropMarks?, colorMode? })` | `PrintLayout` | mm में फ़िज़िकल साइज़: `codeWidth`, `trimWidth`, `trimHeight`, `bleed`, `pageWidth`, `pageHeight`, `moduleSize`, `moduleCount`, `maxScanDistance`। `size` 5 mm से 2 m तक होता है |
| `getQRAsPrintPDF(props, options)` | `Promise<string>` | वेक्टर PDF, data URL के रूप में। इसके लिए `jspdf` चाहिए |
| `getQRAsPrintPDFBuffer(props, options)` | `Promise<ArrayBuffer>` | वही PDF बाइट्स में, Node के लिए |
| `getQRAsPrintSVG(props, { size, unit? })` | `Promise<string>` | mm या in में `width` और `height` वाला SVG |
| `downloadPrintPDF(props, options & { filename? })`, `downloadPrintSVG(props, options & { filename? })` | `Promise<void>` | इन दोनों के ब्राउज़र डाउनलोड |
| `getQRAsEPS(props, { sizeMm?, bleedMm?, colorMode? })` | `Promise<string>` | EPSF-3.0 टेक्स्ट। इमेज फ़िल होने पर `EPS_IMAGE_FILL_REASON` एरर देता है |
| `downloadPrintEPS(props, options & { filename? })` | `Promise<void>` | ब्राउज़र डाउनलोड |
| `svgToEPS(svg, { width?, colorMode?, bleed?, bleedColor?, title? })` | `Promise<string>` | लाइब्रेरी द्वारा रेंडर किए गए किसी भी SVG को बदलता है |
| `epsToDataUrl(eps)`, `hasImageFill(props)`, `rgbToCmyk(color)`, `getQRModuleCount(props)` | | हेल्पर |

`PrintOptions`: `size` (number), `unit` (`"mm"` या `"in"`, डिफ़ॉल्ट `"mm"`), `bleed` (mm, 0 से 20), `cropMarks` (boolean), `colorMode` (`"rgb"` या `"cmyk"`)।

## स्कैन स्कोर और डिटेक्शन [#scan-score-and-detection]

| Function | Returns | Notes |
| --- | --- | --- |
| `getScanScore(props, { sizes?, signal? })` | `Promise<ScanScoreResult>` | `{ score, grade, checks }`। सिर्फ़ ब्राउज़र में; jsQR ज़रूरत पड़ने पर लोड करता है। डिफ़ॉल्ट साइज़ 96, 160 और 320 px (`SCAN_TEST_SIZES`) |
| `getImageScanScore(imageOrBlob, options?)` | `Promise<ImageScanScoreResult>` | पहले से मौजूद इमेज के लिए वही, साथ में `data` और `version`। सिर्फ़ ब्राउज़र में |
| `getScanScoreFromPixels(pixels, options?)` | `Promise<ImageScanScoreResult>` | Node में RGBA पिक्सल पर इमेज स्कोर |
| `scanQRPixels(pixels, expected, { sizes? })` | `Promise<PixelScanResult>` | जाँचता है कि पिक्सल जैसे हैं वैसे और कैमरा मॉडल से गुज़रकर भी `expected` में डिकोड होते हैं। Node |
| `getScanContrast(props)` | `{ ratio, required, inverted }` | अकेले कंट्रास्ट की जाँच |
| `getStylePairRisk(props)` | `StylePairRisk \| null` | शेप की ऐसी जोड़ी जो कुछ स्कैनर नहीं पढ़ पाते, साथ में एक `fix` |
| `handleImageLoad(img, size, returnFullData?)` | `Promise<string \| QRCode \| "NO_QR">` | `<img>` से QR कोड डिकोड करता है। देखें [QR डिटेक्शन](/docs/qr-detection) |
| `downloadImageWithBoundingBox(img, corners, filename)` | `void` | मिले हुए कोड पर आउटलाइन के साथ इमेज सेव करता है |

ग्रेड `"great"`, `"ok"`, `"risky"` और `"fails"` हैं। हर चेक `{ id, passed, message, fix?, skipped? }` होता है। कंट्रास्ट की सीमाएँ: `SCAN_CONTRAST_MIN` 4.5, `SCAN_CONTRAST_LOW` 3, `SCAN_CONTRAST_FAIL` 1.5, और `SCAN_IMAGE_CONTRAST_MIN` 7 कोड के अंदर की तस्वीर के लिए और 12 उसके पीछे की तस्वीर के लिए। कमज़ोर जोड़ियाँ `WEAK_BODY_EYES`, `WEAK_DOT_EYES`, `WEAK_SHARP_DOT_EYES`, `SHARP_DOT_EYE_SAFE_BODIES`, `WEAK_EYES` और `WEAK_DOTS` के रूप में आती हैं।

## Types और option lists [#types-and-option-lists]

नीचे दिए गए types `qrdx`, `qrdx/core` और `qrdx/types` से आते हैं। Option lists सामान्य arrays हैं; zod schemas (`qrPropsSchema`, `frameSchema`, `frameSpecSchema`, `colorConfigSchema`, `qrArtSchema`, `logoOptionsSchema`, `imageSettingsSchema` और बाकी) इन्हीं से बने हैं।

| Type | Shape |
| --- | --- |
| `QRProps` | ऊपर वाली props तालिका, logo API के बिना |
| `QRCodeProps` | `QRProps` के साथ `logo`, `logoOptions`, `hideLogo`, `scale` |
| `QRSVGOptions` | `QRProps` के साथ कोई भी root attribute: core यही बनाता है |
| `ColorConfig` | `string \| SolidColor \| LinearGradient \| RadialGradient \| AngularGradient \| ImagePaint` |
| `LinearGradient` | `{ type: "linear", stops, angle? }`; `angle` डिग्री में, डिफ़ॉल्ट 0 |
| `RadialGradient` | `{ type: "radial", stops }` |
| `AngularGradient` | `{ type: "angular", stops, angle? }` |
| `GradientStop` | `{ color, offset }`; `offset` 0 से 100 |
| `ImagePaint` | `{ type: "image", src, fit?, scale?, position?, opacity?, underlay? }` |
| `ImageSettings`, `LogoOptions`, `EyeColors` | जैसा ऊपर की तालिकाओं में है |
| `QRFrame` | `{ style: FrameStyle, text?, color?, textColor?, secondaryText?, secondaryColor?, fontScale? }` |
| `QRCustomFrame`, `AnyQRFrame`, `FrameSpec` | `{ style: "custom", spec, ...labels and colors }`, union, और spec का format |
| `QRArt`, `QRArtImage` | `{ mode, image, intensity?, variant?, matchEyes? }` और `{ width, height, data }` |
| `QRCodeShape`, `QRSilhouette` | `"square" \| "circle" \| "heart"` या `{ type: "silhouette", width, height, cells }` |
| `TemplateDefinition`, `BaseTemplateProps`, `TemplateConfig` | Templates |
| `DownloadFormat`, `DownloadSize`, `DownloadOptions`, `PrintOptions`, `PrintLayout`, `EPSOptions` | Export |
| `ScanScoreResult`, `ImageScanScoreResult`, `ScanCheck`, `ScanGrade`, `StylePairRisk` | स्कैन स्कोर |
| `BodyPattern`, `CornerEyePattern`, `CornerEyeDotPattern`, `FrameStyle`, `ErrorLevel` | Option unions |

Option lists: `BODY_PATTERN`, `CORNER_EYE_PATTERNS`, `CORNER_EYE_DOT_PATTERNS`, `FRAME_STYLES`, `QR_SHAPES`, `LOGO_SHAPES`, `EYE_POSITIONS`। हटाए गए values, जो सेव किए गए डिज़ाइनों के लिए अब भी रेंडर होते हैं: `RETIRED_CORNER_EYE_PATTERNS` (`curly`) और `RETIRED_CORNER_EYE_DOT_PATTERNS` (`diamond`, `star`, `banner`)।

## कहाँ क्या चलता है [#where-things-run]

- **कहीं भी, DOM के बिना:** `toSVGString`, `createQRCodeTree`, `renderToString`, `getQRData`, frame और template helpers, `createQRArtImage`, `createQRSilhouette`, `getPrintLayout`, `getQRAsEPS`, `getQRAsPrintPDFBuffer`, `scanQRPixels`, `toQRdxCodeHTML`।
- **Browser:** `downloadQRCode` और बाकी downloads, `copyQRCodeToClipboard`, `getQRAsCanvas`, `getScanScore`, `getImageScanScore`, `handleImageLoad`, `loadQRArtImage`, `loadQRSilhouette`, `removeLogoBackground`, `createQRCode`, custom element।
- **सिर्फ़ Node:** `qrdx/node` से `getQRAsPNG`।
- **React Server Components:** `QRCode`, `QRCodeSVG` और वह सब कुछ जिसे DOM की ज़रूरत नहीं। `QRCodeCanvas` एक Client Component है।
