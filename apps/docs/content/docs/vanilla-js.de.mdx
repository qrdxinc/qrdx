Am Ende dieser Seite hast du einen gestalteten QR-Code in eine einfache HTML-Seite gezeichnet, aus deinem Code heraus aktualisiert und als PNG gespeichert, entweder mit einem Bundler oder mit einem einzigen Script-Tag. `qrdx/vanilla` ist dieselbe Engine, mit der auch die React-Komponenten zeichnen. Sie erzeugt also dasselbe SVG, mit allen Mustern, Farben, Logos, Rahmen und Exporten, und importiert weder `react` noch `react-dom`.

<NpmStatus package="qrdx" />

## Bevor du anfängst [#before-you-start]

- Eine Seite mit einem Bundler (Vite, webpack, Parcel oder einem anderen) für die Schritte 1 bis 3. Ohne Bundler springst du direkt zu [Schritt 4](#4-use-it-without-a-bundler).
- Node.js 18 oder neuer für den Bundler.

## So baust du es [#build-it]

### 1. qrdx installieren [#1-install-qrdx]

```package-install
qrdx
```

`react` und `react-dom` sind optionale Peer-Abhängigkeiten. Für `qrdx/vanilla` oder `qrdx/core` brauchst du sie nicht.

### 2. Einen Code in ein Element zeichnen [#2-draw-a-code-into-an-element]

```html title="index.html"
<div id="qr"></div>
<script type="module" src="/main.js"></script>
```

```js title="main.js"
import { createQRCode } from "qrdx/vanilla";

const qr = createQRCode("#qr", {
  value: "https://example.com/menu",
  size: 256,
  margin: 4,
  bodyPattern: "rounded",
  frame: { style: "banner-bottom", text: "Scan for the menu" },
  "aria-label": "QR code for the menu",
});
```

In `#qr` erscheint ein `<svg>`: ein 256 px großer Code mit abgerundeten Modulen und einem Banner darunter. `createQRCode(element, options)` akzeptiert ein Element oder einen CSS-Selektor und jede Option, die auch das React-`QRCodeSVG` kennt: Muster, Farben und Verläufe, Logos (`imageSettings`), Rahmen, Formen, Vorlagen und Art. Attribute wie `className`, `style` oder `aria-label` landen auf dem `<svg>`. Das Element wird mit `createElementNS` aufgebaut, es wird also kein HTML geparst.

### 3. Aktualisieren, exportieren und entfernen [#3-update-export-and-remove-it]

```js title="main.js"
qr.update({ fgColor: "#1d4ed8" }); // redraws the code in place, now blue

qr.toSVGString(); // '<svg xmlns="http://www.w3.org/2000/svg" …'
await qr.toDataURL("png", { size: 1024 }); // "data:image/png;base64,…"
await qr.download({ format: "png", size: 1024, filename: "menu.png" });

qr.destroy(); // removes the <svg>
```

- `update` führt neue Optionen mit den aktuellen zusammen und zeichnet neu. Übergib `undefined`, um eine Option zu entfernen. Ändert sich das Markup nicht, wird die Seite nicht angefasst.
- `toDataURL` und `download` liefern standardmäßig PNG in der eigenen `size` des Codes. Die Formate sind `png`, `jpg`, `webp`, `svg`, `pdf` und `eps`. Ein Rahmen macht das Bild größer als den Code. PDF benötigt das optionale Paket `jspdf`.
- `qr.svg` ist das `<svg>`-Element und `qr.options` sind die aktuellen Optionen.
- `destroy` entfernt das `<svg>`. Danach wirft `update` einen Fehler.

### 4. Ohne Bundler verwenden [#4-use-it-without-a-bundler]

```html title="index.html"
<div id="qr"></div>
<script type="module">
  import { createQRCode } from "https://cdn.jsdelivr.net/npm/qrdx/dist/vanilla.browser.mjs";

  createQRCode("#qr", { value: "https://example.com", size: 256, margin: 4 });
</script>
```

`dist/vanilla.browser.mjs` ist dieselbe API als einzelnes ES-Modul. Hänge in der URL nach `qrdx` ein `@` und eine Version an, um eine Version festzulegen. Derselbe Pfad funktioniert auch auf unpkg.

Die Datei enthält die Daten der offiziellen Rahmenbibliothek nicht, damit Seiten, die sie nicht nutzen, sie auch nicht herunterladen. Um einen offiziellen Rahmen zu verwenden, importiere ihn aus der Datei daneben:

```js title="index.html"
import { getOfficialFrame } from "https://cdn.jsdelivr.net/npm/qrdx/dist/frames-official.mjs";

const wifi = getOfficialFrame("wifi-card");
qr.update({ frame: { style: "custom", spec: wifi.spec } });
```

Der PDF-Export und der Scan-Score laden `jspdf` und `jsqr`, sobald sie laufen. Eine Seite, die sie nutzt, ordnet beide mit einer Import Map zu, die vor dem Modul-Script steht:

```html title="index.html"
<script type="importmap">
  {
    "imports": {
      "jspdf": "https://cdn.jsdelivr.net/npm/jspdf@4/+esm",
      "jsqr": "https://cdn.jsdelivr.net/npm/jsqr@1/+esm"
    }
  }
</script>
```

## Markup und DOM-Knoten mit qrdx/core [#markup-and-dom-nodes-with-qrdxcore]

`qrdx/core` enthält alles, was der Haupteinstieg `qrdx` hat, außer den React-Komponenten. Es funktioniert in Node und im Browser.

```ts title="code.ts"
import {
  createQRCodeTree,
  renderToDOM,
  renderToString,
  resolveQRCodeProps,
  toSVGElement,
  toSVGString,
} from "qrdx/core";

// What <QRCodeSVG> renders, as a string (no DOM needed)
const svg = toSVGString({ value: "https://example.com", size: 256 });

// The same code as an <svg> element
document.body.append(toSVGElement({ value: "https://example.com" }));

// The code as plain { type, props, key } nodes, then markup or DOM nodes
const tree = createQRCodeTree({ value: "https://example.com" });
renderToString(tree);
renderToDOM(tree);

// <QRCode>'s logo API (logo, logoOptions, hideLogo, scale)
toSVGString(resolveQRCodeProps({ value: "https://example.com", logo: "/logo.png" }));
```

Die Ausgabe enthält keine zufälligen IDs, daher stimmt auf einem Server gerendertes Markup mit dem des Browsers überein. Downloads, der Scan-Score und druckfertige PDF- und EPS-Dateien kommen aus denselben Funktionen wie in der React-Bibliothek: `downloadQRCode`, `getQRCodeDataUrl`, `getScanScore`, `downloadPrintPDF` und die übrigen. Für PNG auf einem Server nutze `getQRAsPNG` aus `qrdx/node`.

## Eigene Vorlagen ohne JSX [#custom-templates-without-jsx]

Der `wrapper` einer Vorlage erhält den gezeichneten Code und gibt ihn eingepackt zurück. Mit `h(type, props, ...children)` schreibst du einen ohne JSX:

```js title="labelled-template.js"
import { h, toSVGString } from "qrdx/core";

const Labelled = {
  id: "Labelled",
  name: "Labelled",
  wrapper: (children, props) =>
    h(
      "svg",
      { viewBox: "0 0 300 340", xmlns: "http://www.w3.org/2000/svg" },
      h("g", { transform: "translate(20, 20) scale(0.87)" }, children),
      h("text", { x: "150", y: "325", textAnchor: "middle" }, props?.label)
    ),
};

toSVGString({
  value: "https://example.com",
  customTemplate: Labelled,
  customProps: { label: "Scan me" },
});
```

Derselbe Wrapper funktioniert auch in den React-Komponenten, wenn du `h` stattdessen aus `qrdx` importierst.

## Wenn etwas schiefgeht [#if-something-goes-wrong]

- **`qrdx: no element matches #qr`.** Das Script lief, bevor das Element existierte. Setze das `<script type="module">` hinter das Element oder warte auf `DOMContentLoaded`.
- **`qrdx: this QR code was destroyed`.** Du hast `update` nach `destroy` aufgerufen. Erstelle mit `createQRCode` einen neuen Code.
- **`PDF export needs the optional "jspdf" package`.** Installiere `jspdf` neben `qrdx` oder füge es auf einer Seite ohne Bundler der Import Map hinzu.
- **Der Code wird gezeichnet, aber ein Handy liest ihn nicht.** Füge `margin: 4` hinzu, halte dunkle Module auf hellem Hintergrund und prüfe das Design mit `getScanScore`. Siehe [Ein Code lässt sich nicht scannen](/docs/help/troubleshooting/wont-scan).
