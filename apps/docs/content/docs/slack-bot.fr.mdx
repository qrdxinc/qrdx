Le bot QRdx pour Slack crée des QR codes directement dans Slack. Toute personne d'un espace de travail Slack où le bot est installé peut créer un code à partir d'un lien ou d'un texte quelconque, modifier son style depuis les menus sous le message, et le télécharger. Les personnes qui associent leur compte QRdx peuvent aussi créer des codes suivis (dynamiques), qui comptabilisent les scans et peuvent rediriger vers une autre destination par la suite. Utilisez-le lorsqu'une équipe partage des liens dans Slack et souhaite obtenir un code sans quitter la conversation.

## Fonctionnement [#how-it-works]

Le bot ne stocke jamais le texte des messages et n'envoie jamais d'image. Chaque code est une image QR que QRdx génère à partir du lien contenu dans le message, via l'[image API](/docs/developers/image-api), avec le contenu et le design inclus dans ce lien. Pour modifier le style d'un code, QRdx relit ces deux éléments depuis le lien : rien n'a donc besoin d'être enregistré pour le changer.

<IfAvailable feature="slackBot" id="add-the-bot-to-slack" title="Ajouter le bot à Slack">

1. Dans QRdx, ouvrez [Paramètres → Intégrations → Slack](/settings/integrations/slack) et cliquez sur **Ajouter le bot à Slack**. N'importe quel compte QRdx peut le faire, quel que soit son offre.
2. Choisissez l'espace de travail Slack et validez. Le bot demande à voir sa commande slash, les mentions dont il fait l'objet et ses messages privés, ainsi que l'autorisation de publier des messages.
3. Vous revenez à la page des paramètres, qui liste les espaces de travail Slack auxquels vous avez ajouté le bot.

La même application Slack publie aussi des [alertes](/docs/notifications#slack-and-discord) dans un canal. Ajouter le bot n'active pas les alertes, et ajouter les alertes n'ajoute pas le bot.

</IfAvailable>

<IfAvailable feature="slackBot" id="make-a-qr-code" title="Créer un QR code">

| Où | Que faire | Où le code apparaît |
| --- | --- | --- |
| N'importe quel canal | `/qr` suivi d'un lien ou d'un texte | Dans le canal |
| Un canal où se trouve le bot | Mentionnez le bot avec un lien ou un texte | Dans le fil de discussion |
| Les messages privés du bot | Envoyez un lien ou un texte | Dans le message privé |
| N'importe quel message | **Plus d'actions** → **Créer un QR code** | Dans le fil du message |

Chaque réponse est une image de QR code accompagnée du contenu en dessous, de trois boutons et des menus de style décrits plus bas. Les boutons sont **Télécharger en PNG** (1024 pixels), **Télécharger en SVG** et **Ouvrir dans l'éditeur**, où vous pouvez modifier davantage le design. Un lien ouvre l'éditeur avec ce lien déjà renseigné ; un texte ouvre un éditeur vide, car un texte n'est jamais placé dans un lien.

Le raccourci crée un code à partir de la première adresse web du message, ou de tout son texte s'il n'en contient pas. Si le bot n'est pas dans ce canal, vous seul voyez le code, avec la note « Only you can see this. Add the QRdx app to this channel to reply in threads. »

`/qr` seul, ou `/qr help`, affiche les commandes. Si le contenu est trop long pour un QR code, vous obtenez une courte explication à la place d'une image, visible par vous seul.

</IfAvailable>

<IfAvailable feature="slackBot" id="style-your-code" title="Personnaliser votre code">

Sous chaque code se trouvent quatre menus : **Style**, **Couleur**, **Cadre** et **Logo**. Faites un choix et le code change sur place, avec de nouveaux liens de téléchargement. Chaque choix s'applique au code tel qu'il est à ce moment-là. Seule la personne qui a créé le code peut en modifier le style ; quand quelqu'un d'autre fait un choix, Slack lui affiche une note visible par lui seul, et le code reste inchangé.

Les styles sont une sélection de designs intégrés à l'éditeur qui restent lisibles en petit ; **Simple** est le style noir sur blanc. Choisir un style change les formes et les couleurs, et conserve le cadre et le logo que vous avez choisis. Une couleur applique cette couleur à tout le code sur fond blanc. Les cadres ajoutent une étiquette « Scan me », et le menu du logo propose sept des icônes rapides de l'éditeur.

Vous pouvez aussi personnaliser un code lors de sa création en ajoutant des options après le lien ou le texte, avec les mêmes noms que dans la [CLI QRdx](/docs/developers/cli) :

```text title="Slack message"
/qr qrdx.dev --look modern --fg 0051ff --frame banner-bottom --frame-text "Scan me"
```

Tout ce qui précède la première option est le contenu. Le style est appliqué en premier, puis les autres options par-dessus : `--look royal --fg 0051ff` conserve donc les formes de Royal en bleu. Les options fonctionnent aussi dans les mentions et les messages privés. Si une option ou une valeur est incorrecte, le bot vous le signale en privé et liste les valeurs acceptées.

| Option | Ce qu'elle modifie | Valeurs |
| --- | --- | --- |
| `--look` | Le design complet, à partir d'un des préréglages de l'éditeur | `plain`, `classic`, `modern`, `royal`, `folio`, `caffeine`, `retro`, `bordeaux`, `blossom` |
| `--fg` (ou `--color`) | Les points, ainsi que les yeux d'angle sauf si vous les définissez aussi | Une couleur hexadécimale comme `0051ff`, ou `black`, `blue`, `green`, `red`, `purple`, `orange` |
| `--bg` | L'arrière-plan | Les mêmes que pour `--fg` |
| `--eye-color` | Les trois yeux d'angle | Les mêmes que pour `--fg` |
| `--dot-color` | Les centres des yeux d'angle | Les mêmes que pour `--fg` |
| `--body` | La forme des points | L'une des {facts.bodyPatterns} formes de points de l'éditeur, comme `rounded`, `circle` ou `classy` |
| `--eye` | La forme des yeux d'angle | L'une des {facts.eyeShapes} formes d'yeux, comme `square`, `rounded` ou `gear` |
| `--dot` | La forme des centres des yeux | L'une des {facts.eyeCentres} formes de centres, comme `square`, `rounded` ou `circle` |
| `--frame` | Un cadre autour du code | `none` ou l'un des {facts.frameStyles} cadres intégrés, comme `banner-bottom`, `banner-top`, `speech-bubble` ou `polaroid` |
| `--frame-text` | L'étiquette du cadre, 24 caractères maximum | N'importe quel texte, entre guillemets s'il contient des espaces. Sans `--frame`, il est placé sur une bannière sous le code |
| `--template` | Un cadre dessiné comme un modèle | `Arrow`, `StandardBox`, `SquareBorder`, `StrikedBox`, `DotRing`, `Halloween` ou `default`, en majuscules ou minuscules |
| `--logo` | Une icône au centre | `link`, `wifi`, `location`, `phone`, `email`, `whatsapp`, `instagram`, `file`, `calendar` ou `none` |

Avant la publication d'un code personnalisé, QRdx le vérifie avec le même score de scan que l'éditeur. Lorsqu'un design serait difficile à lire pour les téléphones, QRdx l'ajuste (couleurs plus sombres, formes plus simples ou correction d'erreur renforcée) et l'indique sous le code. Si cela ne suffit toujours pas, généralement parce que le contenu est long, vous recevez le code en noir sur blanc avec une note. Un code personnalisé créé avec `/qr` arrive un instant après l'envoi de la commande, le temps de la vérification.

**Ouvrir dans l'éditeur** ouvre l'éditeur avec le même design : couleurs, formes, cadre et bordure. L'icône du logo n'est pas transmise dans le lien : choisissez-la de nouveau dans l'éditeur.

Les codes issus du raccourci que vous seul pouvez voir n'ont pas de menus, et les codes suivis conservent le design simple.

</IfAvailable>

<IfAvailable feature="slackBot" id="tracked-codes" title="Codes suivis">

Un code simple contient le lien lui-même. Un code suivi contient un lien court (`https://qrdx.dev/q/<slug>`) qui redirige vers votre lien : QRdx compte ainsi ses scans et vous pouvez changer sa destination. Pour en créer depuis Slack, associez une fois votre compte QRdx :

1. Exécutez `/qr link`. Un bouton **Associer le compte QRdx**, visible par vous seul, ouvre QRdx. Il est valable 10 minutes.
2. Connectez-vous à QRdx si on vous le demande. Cliquez ensuite sur **Se connecter avec Slack** et connectez-vous avec le même compte Slack que celui qui a exécuté `/qr link`. Slack ne transmet à QRdx que votre utilisateur et votre espace de travail Slack, et QRdx vérifie qu'ils correspondent. Si vous vous connectez à Slack avec un autre compte, rien n'est associé.
3. Choisissez l'espace de travail QRdx dans lequel iront vos codes suivis et cliquez sur **Confirmer**. QRdx vous demande d'abord de [confirmer votre identité](/docs/help/privacy-and-security/two-step-verification#confirm-its-you), sauf si vous l'avez fait récemment, car l'association permet à ce compte Slack de créer des codes dans votre espace de travail.
4. De retour dans Slack, le bot vous envoie un message privé indiquant le compte QRdx et l'espace de travail auxquels vous êtes associé. Si vous n'avez pas fait cette association, exécutez `/qr unlink`.
5. Exécutez `/qr track` suivi d'un lien commençant par `https://` ou `http://`. Vous pouvez aussi mentionner le bot avec `track` et un lien.

Le code apparaît dans le canal avec son lien court et le nom de l'espace de travail QRdx auquel il appartient. Le bouton **Ouvrir dans QRdx**, qui mène au code dans votre tableau de bord, arrive dans un message séparé que vous seul pouvez voir. Le code porte le nom du site du lien suivi de « from Slack », et vous le retrouvez parmi les codes de l'espace de travail comme n'importe quel autre.

Les codes suivis obéissent aux mêmes règles que les codes créés dans le tableau de bord : votre rôle doit permettre de créer des codes, un espace de travail qui exige la vérification en deux étapes impose qu'elle soit activée sur votre compte, et la limite de votre offre en QR codes dynamiques actifs s'applique. Lorsque vous atteignez la limite, le bot vous l'indique et renvoie vers les offres. Ces vérifications ont lieu à chaque fois : quitter un espace de travail ou perdre l'accès empêche donc l'association d'y fonctionner.

Chaque compte Slack a une seule association par espace de travail Slack. Quand vous exécutez `/qr link` pour un compte Slack déjà associé, la page indique à quel espace de travail QRdx il est associé, et si c'est dans un autre compte QRdx. Le bouton devient alors **Remplacer l'association**, et rien ne change tant que vous n'avez pas cliqué dessus. `/qr unlink` supprime une association, tout comme **Dissocier** sous **Comptes Slack associés** dans [Paramètres → Intégrations → Slack](/settings/integrations/slack).

Les propriétaires et les administrateurs d'un espace de travail QRdx voient tous les comptes Slack qui y sont associés sous **Comptes Slack** dans **Paramètres** → **Clés API et applications** : l'espace de travail Slack, l'identifiant de l'utilisateur Slack, le membre au nom duquel il agit et la date d'association. **Révoquer** y supprime une association. Si l'espace de travail dispose du [journal d'audit](/docs/help/teams/audit-log), les codes créés avec `/qr track` affichent le nom du membre « via Slack », avec les identifiants de l'utilisateur et de l'espace de travail Slack, et la révocation d'une association est elle aussi enregistrée.

</IfAvailable>

## Ce que le bot conserve [#what-the-bot-keeps]

Le bot ne lit un message que lorsque quelqu'un exécute `/qr`, mentionne le bot, lui écrit directement ou utilise le raccourci sur ce message. Il ne stocke jamais le texte des messages. Les images de QR code proviennent de l'[Image API](/docs/developers/image-api) de QRdx, que Slack charge depuis le lien du message : rien n'est donc importé.

Pour chaque espace de travail Slack, QRdx conserve son identifiant et son nom, l'identifiant d'utilisateur Slack du bot, les autorisations (scopes) accordées, le jeton du bot (chiffré), le compte QRdx qui l'a ajouté et la date d'ajout. Pour chaque compte Slack lié, il conserve les identifiants de l'utilisateur et de l'espace de travail Slack, votre compte QRdx, l'espace de travail que vous avez choisi et la date de la liaison. La connexion avec Slack pour lier votre compte n'ajoute rien à cela : QRdx compare l'utilisateur et l'espace de travail Slack, puis oublie la connexion.<IfAvailable feature="slackBot"> Vos comptes Slack liés figurent dans votre [export de données](/docs/help/account-and-billing/export-your-data).</IfAvailable>

Pour éviter qu'une seule personne n'inonde un canal, le bot compte les codes que chaque personne crée ou restylise en une minute, ainsi que les codes créés ensemble par un espace de travail Slack et par l'ensemble de QRdx. Quand il y en a trop, il répond « QRdx is busy right now. Try again in a minute. » Aucun de ces compteurs ne contient de contenu.

<IfAvailable feature="slackBot" id="remove-the-bot" title="Supprimer le bot">

Dans Slack, ouvrez la page de l'application et choisissez **Remove App** (ou demandez à un administrateur Slack de le faire). QRdx supprime alors le jeton du bot de cet espace de travail Slack et toutes les liaisons de comptes Slack effectuées depuis celui-ci. Les codes déjà créés restent dans QRdx, et les codes suivis continuent de fonctionner.

</IfAvailable>

## Pour les développeurs [#for-developers]

Le bot est une fine couche au-dessus de deux outils publics : l'[Image API](/docs/developers/image-api) génère chaque code, et les codes suivis sont de simples QR codes dynamiques que vous pouvez lire via la [REST API](/docs/developers/api/list-codes). Les mêmes options de style existent dans la [CLI](/docs/developers/cli).

## Auto-hébergement [#self-hosting]

Le bot utilise la même application Slack que les alertes « Add to Slack », avec son secret de signature en plus. Définissez `SLACK_CLIENT_ID`, `SLACK_CLIENT_SECRET` et `SLACK_SIGNING_SECRET`, ainsi que `INTEGRATION_ENCRYPTION_KEY` en production, qui chiffre les jetons du bot. Sans ces variables, les pages et les points de terminaison du bot n'existent pas. `plugins/slack/manifest.json` dans le dépôt est le manifeste de l'application, et `plugins/slack/README.md` explique pas à pas comment créer l'application à partir de celui-ci. Le manifeste inclut le scope utilisateur `openid` et l'URL de redirection `/api/integrations/slack/link/callback`, dont Sign in with Slack a besoin quand quelqu'un lie son compte. Les limites de débit nécessitent Upstash Redis ; sans lui, elles sont désactivées. Voir [Auto-hébergement](/docs/self-hosting#optional-services).
