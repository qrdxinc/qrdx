À la fin de cette page, vous aurez un QR code stylisé dessiné dans une page HTML simple, mis à jour depuis votre code et enregistré en PNG, avec un bundler ou avec une seule balise script. `qrdx/vanilla` est le même moteur que celui utilisé par les composants React : il dessine donc le même SVG, avec tous les motifs, couleurs, logos, cadres et exports, et il n'importe ni `react` ni `react-dom`.

<NpmStatus package="qrdx" />

## Avant de commencer [#before-you-start]

- Une page avec un bundler (Vite, webpack, Parcel ou un autre) pour les étapes 1 à 3. Sans bundler, passez directement à l'[étape 4](#4-use-it-without-a-bundler).
- Node.js 18 ou version ultérieure pour le bundler.

## Mise en place [#build-it]

### 1. Installer qrdx [#1-install-qrdx]

```package-install
qrdx
```

`react` et `react-dom` sont des dépendances peer facultatives. Vous n'en avez pas besoin pour `qrdx/vanilla` ni pour `qrdx/core`.

### 2. Dessiner un code dans un élément [#2-draw-a-code-into-an-element]

```html title="index.html"
<div id="qr"></div>
<script type="module" src="/main.js"></script>
```

```js title="main.js"
import { createQRCode } from "qrdx/vanilla";

const qr = createQRCode("#qr", {
  value: "https://example.com/menu",
  size: 256,
  margin: 4,
  bodyPattern: "rounded",
  frame: { style: "banner-bottom", text: "Scan for the menu" },
  "aria-label": "QR code for the menu",
});
```

Un élément `<svg>` apparaît dans `#qr` : un code de 256 px avec des modules arrondis et une bannière en dessous. `createQRCode(element, options)` accepte un élément ou un sélecteur CSS, ainsi que toutes les options de `QRCodeSVG` côté React : motifs, couleurs et dégradés, logos (`imageSettings`), cadres, formes, modèles et illustrations. Les attributs comme `className`, `style` ou `aria-label` sont appliqués au `<svg>`. L'élément est construit avec `createElementNS` : aucun HTML n'est analysé.

### 3. Mettre à jour, exporter et supprimer [#3-update-export-and-remove-it]

```js title="main.js"
qr.update({ fgColor: "#1d4ed8" }); // redraws the code in place, now blue

qr.toSVGString(); // '<svg xmlns="http://www.w3.org/2000/svg" …'
await qr.toDataURL("png", { size: 1024 }); // "data:image/png;base64,…"
await qr.download({ format: "png", size: 1024, filename: "menu.png" });

qr.destroy(); // removes the <svg>
```

- `update` fusionne les nouvelles options avec les options actuelles et redessine le code. Passez `undefined` pour supprimer une option. Si le balisage ne change pas, la page n'est pas modifiée.
- `toDataURL` et `download` utilisent par défaut le PNG, à la `size` propre du code. Les formats disponibles sont `png`, `jpg`, `webp`, `svg`, `pdf` et `eps`. Un cadre rend l'image plus grande que le code. Le PDF nécessite le paquet facultatif `jspdf`.
- `qr.svg` est l'élément `<svg>` et `qr.options` contient les options actuelles.
- `destroy` supprime le `<svg>`. `update` génère une erreur après cela.

### 4. Utiliser sans bundler [#4-use-it-without-a-bundler]

```html title="index.html"
<div id="qr"></div>
<script type="module">
  import { createQRCode } from "https://cdn.jsdelivr.net/npm/qrdx/dist/vanilla.browser.mjs";

  createQRCode("#qr", { value: "https://example.com", size: 256, margin: 4 });
</script>
```

`dist/vanilla.browser.mjs` offre la même API sous la forme d'un seul module ES. Ajoutez `@` suivi d'une version après `qrdx` dans l'URL pour figer une version. Le même chemin fonctionne sur unpkg.

Le fichier n'inclut pas les données de la bibliothèque de cadres officiels, afin que les pages qui ne l'utilisent pas ne la téléchargent pas. Pour utiliser un cadre officiel, importez-le depuis le fichier voisin :

```js title="index.html"
import { getOfficialFrame } from "https://cdn.jsdelivr.net/npm/qrdx/dist/frames-official.mjs";

const wifi = getOfficialFrame("wifi-card");
qr.update({ frame: { style: "custom", spec: wifi.spec } });
```

L'export PDF et le score de scan chargent `jspdf` et `jsqr` au moment de leur exécution. Une page qui les utilise déclare les deux avec une import map, placée avant le script de type module :

```html title="index.html"
<script type="importmap">
  {
    "imports": {
      "jspdf": "https://cdn.jsdelivr.net/npm/jspdf@4/+esm",
      "jsqr": "https://cdn.jsdelivr.net/npm/jsqr@1/+esm"
    }
  }
</script>
```

## Balisage et nœuds DOM avec qrdx/core [#markup-and-dom-nodes-with-qrdxcore]

`qrdx/core` contient tout ce que contient l'entrée principale `qrdx`, sauf les composants React. Il fonctionne dans Node et dans le navigateur.

```ts title="code.ts"
import {
  createQRCodeTree,
  renderToDOM,
  renderToString,
  resolveQRCodeProps,
  toSVGElement,
  toSVGString,
} from "qrdx/core";

// What <QRCodeSVG> renders, as a string (no DOM needed)
const svg = toSVGString({ value: "https://example.com", size: 256 });

// The same code as an <svg> element
document.body.append(toSVGElement({ value: "https://example.com" }));

// The code as plain { type, props, key } nodes, then markup or DOM nodes
const tree = createQRCodeTree({ value: "https://example.com" });
renderToString(tree);
renderToDOM(tree);

// <QRCode>'s logo API (logo, logoOptions, hideLogo, scale)
toSVGString(resolveQRCodeProps({ value: "https://example.com", logo: "/logo.png" }));
```

La sortie ne contient aucun identifiant aléatoire : le balisage généré sur un serveur correspond donc à celui du navigateur. Les téléchargements, le score de scan et les PDF et EPS prêts pour l'impression proviennent des mêmes fonctions que dans la bibliothèque React : `downloadQRCode`, `getQRCodeDataUrl`, `getScanScore`, `downloadPrintPDF` et les autres. Pour obtenir un PNG sur un serveur, utilisez `getQRAsPNG` depuis `qrdx/node`.

## Modèles personnalisés sans JSX [#custom-templates-without-jsx]

Le `wrapper` d'un modèle reçoit le code dessiné et le renvoie enveloppé. `h(type, props, ...children)` permet d'en écrire un sans JSX :

```js title="labelled-template.js"
import { h, toSVGString } from "qrdx/core";

const Labelled = {
  id: "Labelled",
  name: "Labelled",
  wrapper: (children, props) =>
    h(
      "svg",
      { viewBox: "0 0 300 340", xmlns: "http://www.w3.org/2000/svg" },
      h("g", { transform: "translate(20, 20) scale(0.87)" }, children),
      h("text", { x: "150", y: "325", textAnchor: "middle" }, props?.label)
    ),
};

toSVGString({
  value: "https://example.com",
  customTemplate: Labelled,
  customProps: { label: "Scan me" },
});
```

Le même wrapper fonctionne dans les composants React si vous importez `h` depuis `qrdx`.

## En cas de problème [#if-something-goes-wrong]

- **`qrdx: no element matches #qr`.** Le script s'est exécuté avant que l'élément n'existe. Placez le `<script type="module">` après l'élément, ou attendez `DOMContentLoaded`.
- **`qrdx: this QR code was destroyed`.** Vous avez appelé `update` après `destroy`. Créez un nouveau code avec `createQRCode`.
- **`PDF export needs the optional "jspdf" package`.** Installez `jspdf` à côté de `qrdx`, ou ajoutez-le à l'import map sur une page sans bundler.
- **Le code est dessiné, mais un téléphone ne le lit pas.** Ajoutez `margin: 4`, conservez des modules foncés sur un fond clair, et vérifiez le design avec `getScanScore`. Consultez [Un code ne se scanne pas](/docs/help/troubleshooting/wont-scan).
