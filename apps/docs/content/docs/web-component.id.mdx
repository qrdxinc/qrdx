Setelah membaca halaman ini, Anda akan memiliki kode QR bergaya yang digambar oleh elemen `<qrdx-code>` di halaman HTML biasa, dengan opsi objek yang diatur dari skrip dan ekspor ke PNG. `qrdx/element` dibangun di atas `qrdx/core`, sehingga menggambar SVG yang sama dengan `QRCodeSVG` di React, lengkap dengan semua gaya, bingkai, logo, dan ekspor. Elemen ini tidak memerlukan framework, dan dapat dipakai di framework yang merender elemen DOM. Elemen ini sudah diuji di React 19 dan Vue 3.

<NpmStatus package="qrdx" />

## Sebelum memulai [#before-you-start]

- Halaman yang dapat Anda tambahi `<script type="module">`. Bundler tidak diperlukan, tetapi boleh dipakai.
- Untuk jalur bundler, Node.js 18 atau lebih baru.

## Membuatnya [#build-it]

### 1. Muat elemen [#1-load-the-element]

<Tabs items={["From a CDN", "With a bundler"]}>
<Tab value="From a CDN">

```html title="index.html"
<script
  type="module"
  src="https://cdn.jsdelivr.net/npm/qrdx/dist/element-define.browser.mjs"
></script>
```

`dist/element-define.browser.mjs` mendaftarkan `<qrdx-code>`. File ini memuat `dist/element.browser.mjs`, satu modul ES dengan mesin di dalamnya. Tambahkan `@` dan nomor versi setelah `qrdx` pada URL untuk mengunci versi. Path yang sama berlaku di unpkg.

</Tab>
<Tab value="With a bundler">

```package-install
qrdx
```

```js title="main.js"
import "qrdx/element/define"; // registers <qrdx-code>
```

Mengimpor `qrdx/element` saja tidak mendaftarkan apa pun. Panggil `defineQRdxCode` sendiri untuk memilih nama tag:

```js title="main.js"
import { defineQRdxCode } from "qrdx/element";

defineQRdxCode(); // <qrdx-code>
defineQRdxCode("brand-qr"); // <brand-qr> as well
```

Aman dipanggil berulang kali, dan di server fungsi ini tidak melakukan apa pun. Fungsi ini melempar galat jika elemen lain sudah memakai nama tersebut.

</Tab>
</Tabs>

### 2. Letakkan kode di halaman [#2-put-a-code-in-the-page]

```html title="index.html"
<qrdx-code
  value="https://example.com/menu"
  size="256"
  margin="4"
  body-pattern="rounded"
  label="QR code for the menu"
></qrdx-code>
```

Halaman menampilkan kode 256 px dengan modul membulat. Ubah atribut di inspektur peramban dan kode akan digambar ulang.

<Shot id="lib-element-code" />

### 3. Atur opsi objek dari skrip [#3-set-object-options-from-a-script]

Gradien, bingkai, logo, dan opsi objek lainnya adalah properti. Atur dari skrip:

```js title="main.js"
const qr = document.querySelector("qrdx-code");

qr.fgColor = {
  type: "linear",
  angle: 45,
  stops: [
    { color: "#1d4ed8", offset: 0 },
    { color: "#0f172a", offset: 100 },
  ],
};
qr.frame = { style: "banner-bottom", text: "Scan for the menu" };
qr.imageSettings = { src: "/logo.png", width: 40, height: 40, excavate: true };
qr.props = { eyeColor: "#be123c" };
```

Kode digambar ulang satu kali, dengan gradien, banner, logo, dan mata berwarna merah. Tanpa skrip, taruh opsi objek di atribut `props` sebagai JSON:

```html title="index.html"
<qrdx-code
  value="https://example.com"
  props='{"frame": {"style": "banner-bottom", "text": "Scan me"}}'
></qrdx-code>
```

### 4. Ekspor [#4-export-it]

```js title="main.js"
qr.toSVGString(); // '<svg xmlns="http://www.w3.org/2000/svg" …'
await qr.toDataURL("png", { size: 1024 }); // "data:image/png;base64,…"
await qr.download({ format: "png", size: 1024, filename: "menu.png" });
```

`download` menyimpan `menu.png` dengan lebar 1024 px. Ekspor menggambar kode dari `qr.options`, seperti `toSVGString` dan `downloadQRCode` dari `qrdx/core`, tanpa `part`, `role`, dan `aria-label` milik elemen. `toDataURL` dan `download` secara bawaan menghasilkan PNG dengan `size` kode. Formatnya adalah `png`, `jpg`, `webp`, `svg`, `pdf`, dan `eps`. Tanpa nilai, fungsi akan melempar galat (`toSVGString`) atau ditolak.

PDF memerlukan paket opsional `jspdf`. Dari CDN, petakan dengan import map yang diletakkan sebelum skrip modul:

```html title="index.html"
<script type="importmap">
  { "imports": { "jspdf": "https://cdn.jsdelivr.net/npm/jspdf@4/+esm" } }
</script>
```

## Atribut [#attributes]

| Atribut | Yang diatur |
| --- | --- |
| `value` | Teks atau URL yang dikodekan. Tanpa atribut ini, tidak ada yang digambar |
| `size` | Lebar dan tinggi dalam piksel (bingkai menambah ukurannya) |
| `level` | Koreksi galat: `L`, `M`, `Q`, atau `H` |
| `fg-color`, `bg-color`, `eye-color`, `dot-color` | Warna solid |
| `body-pattern`, `corner-eye-pattern`, `corner-eye-dot-pattern` | Bentuk modul, mata, dan titik mata |
| `margin` | Zona tenang, dalam modul |
| `template-id` | Templat bawaan |
| `module-scale` | Ukuran tiap modul, 0.5 sampai 1 |
| `auto-level` | Menaikkan koreksi galat ke `H` saat logo membutuhkannya |
| `shape` | `square`, `circle`, atau `heart` |
| `label` | Yang diumumkan pembaca layar (bawaan "QR code") |
| `props` | Opsi lain apa pun, sebagai JSON |

Angka dan level yang tidak dapat dibaca akan diabaikan. [Bentuk, mata, dan bingkai](/docs/styles) menampilkan setiap pola.

## Properti [#properties]

Setiap atribut juga merupakan properti, dengan nama opsinya: `qr.fgColor`, `qr.bodyPattern`, `qr.templateId`. Opsi berupa objek hanya tersedia sebagai properti: gradien dan isian gambar, `frame`, `imageSettings`, `eyeColors`, `art`, `customTemplate`, dan `customProps`. `props` menerima semua opsi sekaligus.

- Atribut atau properti bernama menang atas opsi yang sama di `props`. Antara atribut dan propertinya, yang diatur terakhir yang menang. Atur properti ke `undefined` untuk menghapusnya.
- Properti tidak menulis balik ke atribut.
- Perubahan dikelompokkan. Sebanyak apa pun perubahan berturut-turut, kode digambar ulang satu kali, dalam microtask, dan hanya jika markup-nya berubah.
- `qr.options` adalah opsi yang dipakai untuk menggambar kode, dan `qr.svg` adalah `<svg>` yang telah digambar.
- Properti yang diatur sebelum elemen didefinisikan akan diambil saat elemen didefinisikan.

Bingkai resmi berasal dari file di samping elemen:

```js title="main.js"
import { getOfficialFrame } from "https://cdn.jsdelivr.net/npm/qrdx/dist/frames-official.mjs";

qr.frame = { style: "custom", spec: getOfficialFrame("wifi-card").spec };
```

## Gaya dan aksesibilitas [#styling-and-accessibility]

Kode digambar di shadow root terbuka. CSS halaman tidak dapat menjangkau path-nya, sehingga aturan seperti `svg path { fill: red }` atau `svg { width: 100% }` tidak dapat merusak kode. Atur gaya `<svg>` dari luar dengan `::part(svg)`:

```css title="styles.css"
qrdx-code::part(svg) {
  border-radius: 12px;
}
```

Elemen ini berupa `inline-block`. `<svg>`-nya mempertahankan `size` tetapi mengecil agar muat di kontainer yang lebih sempit.

`<svg>` memiliki `role="img"` dan `aria-label` dari atribut `label`, atau "QR code" jika tidak ada. Label tidak pernah memakai value sebagai cadangan, karena value bisa berisi kata sandi Wi-Fi atau detail kontak.

## Rendering di server [#server-rendering]

`toQRdxCodeHTML(options)` mengembalikan markup elemen dengan kode yang sudah digambar di declarative shadow root. Peramban menampilkan kode sebelum skrip apa pun berjalan, dan elemen mengambil alih saat didefinisikan. Fungsi ini berjalan di Node dan tidak memerlukan DOM.

```js title="server.js"
import { toQRdxCodeHTML } from "qrdx/element";

const html = toQRdxCodeHTML(
  {
    value: "https://example.com",
    size: 256,
    frame: { style: "banner-bottom", text: "Scan me" },
  },
  { label: "Link to example.com" }
);
// <qrdx-code value="https://example.com" size="256" label="Link to example.com"
//   props="{…}"><template shadowrootmode="open">…</template></qrdx-code>
```

Opsi sederhana menjadi atribut dan sisanya masuk ke `props` sebagai JSON, sehingga elemen membaca kembali opsi yang sama. `customTemplate` tidak dapat ditulis sebagai markup: atur sebagai properti di peramban. Berikan `tagName` jika Anda mendaftarkan nama lain.

## React 19 [#react-19]

React 19 mengatur prop sebagai properti jika elemen memilikinya, sehingga objek dapat dipakai sebagai prop. Daftarkan elemen sekali, sebelum merender:

```tsx title="components/menu-code.tsx"
import "qrdx/element/define";

export function MenuCode({ url }: { url: string }) {
  return (
    <qrdx-code
      value={url}
      size={256}
      body-pattern="rounded"
      frame={{ style: "banner-bottom", text: "Scan me" }}
      label="Menu"
    />
  );
}
```

Untuk TypeScript, tambahkan elemen ke JSX di file `.d.ts`:

```ts title="qrdx-code.d.ts"
import type { QRdxCodeElement, QRdxCodeJSXProps } from "qrdx/element";

declare module "react" {
  namespace JSX {
    interface IntrinsicElements {
      "qrdx-code": React.DetailedHTMLProps<
        React.HTMLAttributes<QRdxCodeElement>,
        QRdxCodeElement
      > &
        QRdxCodeJSXProps;
    }
  }
}
```

`ref` memberi Anda elemen tersebut, untuk `toDataURL` dan `download`.

## Vue [#vue]

Beri tahu compiler Vue bahwa `qrdx-code` adalah elemen kustom:

```js title="vite.config.js"
import vue from "@vitejs/plugin-vue";
import { defineConfig } from "vite";

export default defineConfig({
  plugins: [
    vue({
      template: {
        compilerOptions: { isCustomElement: (tag) => tag === "qrdx-code" },
      },
    }),
  ],
});
```

Lalu impor `qrdx/element/define` sekali, di `main.js`, dan ikat opsi di templat. Vue mengatur binding sebagai properti jika elemen memilikinya:

```vue title="src/App.vue"
<qrdx-code
  :value="url"
  :size="256"
  body-pattern="rounded"
  :frame="{ style: 'banner-bottom', text: 'Scan me' }"
  label="Menu"
/>
```

## Jika terjadi masalah [#if-something-goes-wrong]

- **Tidak ada yang digambar.** Elemen tidak punya `value`, atau skrip pendefinisi belum berjalan. Periksa atributnya, dan pastikan `element-define` dimuat sebagai modul.
- **Event `qrdx-error` terpicu.** Kode tidak dapat digambar, misalnya karena value terlalu panjang untuk kode QR, atau atribut `props` bukan objek JSON. Galatnya ada di `event.detail.error`. Elemen menghapus kode lama dan mencatat galat, kecuali listener memanggil `event.preventDefault()`:

  ```js title="main.js"
  qr.addEventListener("qrdx-error", (event) => {
    event.preventDefault();
    showMessage("That text is too long for a QR code.");
  });
  ```

- **`qrdx: <qrdx-code> is already defined by another element`.** Skrip lain mendaftarkan nama tag yang sama. Berikan nama lain ke `defineQRdxCode`.
- **TypeScript: `Property 'qrdx-code' does not exist on type 'JSX.IntrinsicElements'`.** Tambahkan deklarasi dari bagian React 19.
