ये हेल्पर छोटे फ़ंक्शन हैं जिन्हें रेंडरर और स्कैन स्कोर इस्तेमाल करते हैं, और जिन्हें आपके अपने UI के लिए एक्सपोर्ट किया गया है: कोई प्रतिनिधि रंग चुनना, कॉन्ट्रास्ट जाँचना, डाउनलोड साइज़ वैलिडेट करना और canvas फ़ीचर पहचानना। जहाँ अलग से बताया गया है उसे छोड़कर ये हर जगह चलते हैं।

| फ़ंक्शन | रिटर्न | नोट्स |
| --- | --- | --- |
| `getSolidColor(color, fallback?)` | `string` | एक रंग जो `ColorConfig` का प्रतिनिधित्व करता है: स्ट्रिंग, सॉलिड का `color`, ग्रेडिएंट का पहला स्टॉप, इमेज फ़िल का `underlay`, नहीं तो `fallback` (`"#000000"`) |
| `getContrastRatio(a, b)` | `number` | दो CSS रंगों के बीच WCAG कॉन्ट्रास्ट रेशियो, 1 से 21। पारदर्शी रंगों को पहले सफ़ेद पर कंपोज़िट किया जाता है। अगर कोई रंग पार्स नहीं हो सके तो 1 लौटाता है |
| `getContrastLevel(ratio)` | `{ level, warning, message }` | 7 से `AAA`, 4.5 से `AA`, 3 से `AA Large` (`warning: true` के साथ), 3 से नीचे `Fail` |
| `getLuminance(r, g, b)` | `number` | sRGB रंग की रिलेटिव ल्यूमिनेंस, 0 से 1 |
| `hexToRgb(hex)` | `{ r, g, b } \| null` | 3, 4, 6 और 8 अंकों का hex पढ़ता है, alpha को छोड़ देता है। बाकी किसी भी चीज़ के लिए `null` |
| `validateSize(width, height)` | `{ isValid, error? }` | वह नियम जो हर डाउनलोड पर लागू होता है: 50 से 5000 px और वर्गाकार |
| `SUPPORTS_PATH2D` | `boolean` | क्या इस एनवायरनमेंट का canvas `addPath` के साथ `Path2D` को सपोर्ट करता है |

## रंग [#colors]

```ts title="lib/colors.ts"
import { getSolidColor, hexToRgb } from "qrdx";

getSolidColor({
  type: "linear",
  angle: 45,
  stops: [
    { color: "#ff6b6b", offset: 0 },
    { color: "#4ecdc4", offset: 100 },
  ],
});
// "#ff6b6b": the first stop

getSolidColor({ type: "image", src: photo, underlay: "#111111" }); // "#111111"
getSolidColor(undefined, "#ffffff"); // "#ffffff"

hexToRgb("#ff6b6b"); // { r: 255, g: 107, b: 107 }
hexToRgb("#f00"); // { r: 255, g: 0, b: 0 }
hexToRgb("red"); // null
```

जहाँ आपको स्वैच, CSS बैकग्राउंड या फ़ॉलबैक के लिए एक रंग चाहिए, वहाँ `getSolidColor` इस्तेमाल करें। रेंडरर इसे वहाँ इस्तेमाल करता है जहाँ कोई फ़ॉर्मैट ग्रेडिएंट नहीं बना सकता, जैसे `QRCodeCanvas` और Canvas फ़्रेम ड्रॉइंग।

## कॉन्ट्रास्ट [#contrast]

```ts title="lib/contrast.ts"
import { getContrastLevel, getContrastRatio, getLuminance } from "qrdx";

getContrastRatio("#000000", "#ffffff"); // 21
getContrastRatio("#1d4ed8", "#f8fafc"); // 6.4
getContrastRatio("rgba(29, 78, 216, 0.5)", "#ffffff"); // the blue over white, so lower

getContrastLevel(4.5);
// { level: "AA", warning: false, message: "Good contrast" }

getContrastLevel(2);
// { level: "Fail", warning: true, message: "Poor contrast - QR code may not scan properly" }

getLuminance(255, 255, 255); // 1
```

स्कैन स्कोर 4.5 या उससे ज़्यादा के रेशियो (`SCAN_CONTRAST_MIN`) पर कोड को पास करता है, उससे नीचे अंक काटता है और 1.5 से नीचे फ़ेल कर देता है। तस्वीरों के लिए ज़्यादा चाहिए: `SCAN_IMAGE_CONTRAST_MIN` मॉड्यूल में इमेज फ़िल के लिए 7 है और उनके पीछे की इमेज के लिए 12। `getScanContrast(props)` पूरे डिज़ाइन पर स्कोर की अपनी जाँच चलाता है, हर ग्रेडिएंट स्टॉप और आई कलर समेत; देखें [फ़्रेम, स्कैन स्कोर और प्रिंट फ़ाइलें](/docs/features/frames#will-it-scan)।

लाइव कॉन्ट्रास्ट चेकर बनाने में बारह लाइन लगती हैं:

```tsx title="components/contrast-checker.tsx"
"use client";

import { getContrastLevel, getContrastRatio } from "qrdx";
import { useState } from "react";

export function ContrastChecker() {
  const [fgColor, setFgColor] = useState("#000000");
  const [bgColor, setBgColor] = useState("#ffffff");
  const ratio = getContrastRatio(fgColor, bgColor);
  const level = getContrastLevel(ratio);

  return (
    <div>
      <input
        aria-label="Module color"
        type="color"
        value={fgColor}
        onChange={(event) => setFgColor(event.target.value)}
      />
      <input
        aria-label="Background color"
        type="color"
        value={bgColor}
        onChange={(event) => setBgColor(event.target.value)}
      />
      <p>
        {ratio.toFixed(2)}:1, {level.level}. {level.message}
      </p>
    </div>
  );
}
```

## वैलिडेशन [#validation]

```ts title="lib/sizes.ts"
import { validateSize } from "qrdx";

validateSize(1024, 1024); // { isValid: true }
validateSize(40, 40); // { isValid: false, error: "Size must be at least 50x50 pixels" }
validateSize(6000, 6000); // { isValid: false, error: "Size must not exceed 5000x5000 pixels" }
validateSize(400, 300); // { isValid: false, error: "Width and height must be equal for QR codes" }
```

साइज़ गलत होने पर `downloadQRCode`, `getQRCodeDataUrl` और `copyQRCodeToClipboard` वही `error` टेक्स्ट throw करते हैं, इसलिए फ़ॉर्म इसे पहले ही जाँच सकता है।

## फ़ीचर डिटेक्शन [#feature-detection]

```ts title="lib/features.ts"
import { SUPPORTS_PATH2D } from "qrdx";

if (SUPPORTS_PATH2D) {
  // draw module paths with Path2D
}
```

`SUPPORTS_PATH2D` मॉड्यूल लोड होते समय एक बार कैलकुलेट होता है, इसलिए सर्वर पर यह `false` होता है।

## अन्य हेल्पर [#other-helpers]

- `getColorString(color)` और `normalizeColorConfig(color)` `ColorConfig` के रूपों को एक-दूसरे में बदलते हैं; `isGradient(color)` और `isImagePaint(color)` उन्हें अलग पहचानते हैं।
- `sanitizeFrameText(text)` और `isLatin1Text(text)` फ़्रेम लेबल के नियम लागू करते हैं (24 अक्षर; PDF और EPS के लिए Latin-1)।
- `decodePNGPixels(bytes)` 8-बिट PNG को बिना DOM के RGBA पिक्सल में पढ़ता है, Node में `createQRArtImage`, `createQRSilhouette` या `scanQRPixels` के लिए।
- `rgbToCmyk(color)` वह कन्वर्शन है जिसे CMYK प्रिंट फ़ाइलें इस्तेमाल करती हैं।
