`handleImageLoad` decodifica um QR code a partir de um elemento de imagem no navegador e retorna o texto dele. Use para ler códigos de uploads, capturas de tela ou fotos sem enviar a imagem para lugar nenhum. Se você quer uma área de soltar arquivos pronta, instale o componente [QR Code Scanner](/docs/components/qr-code-scanner), que é construído em cima dela.

| Função | Retorno | Observações |
| --- | --- | --- |
| `handleImageLoad(img, size, returnFullData?)` | `Promise<string \| QRCode \| "NO_QR">` | O texto decodificado, ou o resultado completo do decodificador com `returnFullData`. `"NO_QR"` quando nada é encontrado. Somente no navegador |
| `downloadImageWithBoundingBox(img, corners, filename)` | `void` | Salva a imagem como PNG com o código encontrado contornado em vermelho |
| `getImageScanScore(imageOrBlob, options?)` | `Promise<ImageScanScoreResult>` | Decodifica e dá uma nota a uma imagem existente. Veja [Vai ler?](/docs/features/frames#will-it-scan) |
| `scanQRPixels(pixels, expected, options?)` | `Promise<PixelScanResult>` | Verifica se pixels RGBA decodificam para `expected`, no Node |

## Decodifique uma imagem enviada [#decode-an-uploaded-image]

```tsx title="components/qr-reader.tsx"
"use client";

import { handleImageLoad } from "qrdx";
import { useState } from "react";

async function decodeFile(file: File): Promise<string | null> {
  const url = URL.createObjectURL(file);
  try {
    const image = new Image();
    image.src = url;
    await image.decode();
    const result = await handleImageLoad(image, image.naturalWidth);
    return typeof result === "string" && result !== "NO_QR" ? result : null;
  } finally {
    URL.revokeObjectURL(url);
  }
}

export function QrReader() {
  const [result, setResult] = useState("");

  async function onChange(event: React.ChangeEvent<HTMLInputElement>) {
    const file = event.target.files?.[0];
    if (!file) return;
    try {
      setResult((await decodeFile(file)) ?? "No QR code found");
    } catch {
      setResult("Could not read that image");
    }
  }

  return (
    <div>
      <input
        accept="image/*"
        aria-label="Image with a QR code"
        type="file"
        onChange={onChange}
      />
      {result ? <p>{result}</p> : null}
    </div>
  );
}
```

Escolha uma captura de tela de um código e o link dele aparece embaixo do campo. `image.decode()` espera o arquivo carregar; depois `handleImageLoad` desenha a imagem em um canvas e executa o jsQR, que ele carrega sob demanda para ficar fora dos bundles que nunca fazem leitura.

## Como a detecção funciona [#how-detection-works]

`handleImageLoad(img, size, returnFullData)` tenta primeiro a imagem inteira e depois quatro recortes (as regiões inferior esquerda, inferior direita, superior direita e central, com 65% da imagem), cada um em seis escalas, de 100% até 10%. Ele retorna a primeira decodificação que der certo, então um código que ocupa uma parte pequena de uma captura de tela ainda é encontrado. Imagens muito largas ou muito altas são reduzidas antes.

- `img` precisa ser um `<img>` já carregado. Espere `decode()` ou o evento `load`.
- `size` é mantido por compatibilidade com versões anteriores e é ignorado: as escalas vêm das dimensões da própria imagem. Passe a largura da imagem.
- `returnFullData` retorna o objeto de resultado do jsQR em vez do texto.

Um código borrado, cortado nas bordas ou mais claro que o fundo (módulos claros sobre escuro) é reportado como `"NO_QR"`.

## Posição e dados brutos [#position-and-raw-data]

Com `returnFullData` ativado, o resultado é o objeto do próprio decodificador:

```ts title="lib/decode-full.ts"
import { handleImageLoad } from "qrdx";

const found = await handleImageLoad(image, image.naturalWidth, true);
if (found !== "NO_QR") {
  found.data; // "https://example.com"
  found.version; // 1 to 40
  found.binaryData; // the raw bytes, as number[]
  found.chunks; // the encoded segments and their modes
  found.location.topLeftCorner; // { x, y } in the image's pixels, and the other three corners
}
```

`downloadImageWithBoundingBox` desenha o contorno do código na imagem original e a salva, o que ajuda quando uma foto decodifica para algo inesperado. Os cantos vão na ordem superior esquerdo, superior direito, inferior esquerdo, inferior direito:

```ts title="lib/debug-detection.ts"
import { downloadImageWithBoundingBox, handleImageLoad } from "qrdx";

const found = await handleImageLoad(image, image.naturalWidth, true);
if (found !== "NO_QR") {
  const { topLeftCorner, topRightCorner, bottomLeftCorner, bottomRightCorner } = found.location;
  downloadImageWithBoundingBox(
    image,
    [topLeftCorner, topRightCorner, bottomLeftCorner, bottomRightCorner],
    "found-code.png"
  );
}
```

## Dê uma nota a uma imagem em vez de só decodificá-la [#score-an-image-instead-of-only-decoding-it]

`getImageScanScore` decodifica uma imagem existente e também informa com que confiabilidade ela seria lida: decodifica em três tamanhos com desfoque de câmera, contraste, polaridade, zona de silêncio e resolução. Aceita um `File`, um `Blob` ou um `<img>`.

```ts title="lib/score-image.ts"
import { getImageScanScore } from "qrdx";

const { data, score, grade, checks } = await getImageScanScore(file);
// data: "https://example.com" or null
// score: 0 to 100, grade: "great" | "ok" | "risky" | "fails"
```

O [verificador de leitura](/tools/scan-checker) é construído em cima dela. No Node, `scanQRPixels(pixels, expected)` verifica se pixels RGBA (de `decodePNGPixels` ou `sharp().raw()`) decodificam para um valor conhecido.

## Se algo der errado [#if-something-goes-wrong]

- **Toda imagem retorna `"NO_QR"`.** A imagem não tinha terminado de carregar quando você chamou a função. Use await em `image.decode()` antes. Se ela já está carregada, o código pode estar pequeno, borrado, cortado ou invertido; tente uma imagem mais nítida, com o código inteiro e uma margem ao redor.
- **`handleImageLoad` é chamada no servidor.** Ela precisa de um canvas. Chame a partir de um Client Component ou de um manipulador de evento, ou use `scanQRPixels` no Node.
- **O contorno de `downloadImageWithBoundingBox` parece uma gravata-borboleta.** Os cantos estão na ordem errada. Passe superior esquerdo, superior direito, inferior esquerdo, inferior direito.
