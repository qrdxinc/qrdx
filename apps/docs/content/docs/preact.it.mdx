Alla fine di questa pagina avrai un QR code stilizzato in un componente Preact e un pulsante che lo salva come PNG. `qrdx/preact` offre i due componenti SVG della libreria React, `QRCodeSVG` e `QRCode`, realizzati per Preact. Disegnano con l'`h` di Preact, quindi non ti servono né `preact/compat` né `react`, e producono lo stesso SVG dei componenti React.

<NpmStatus package="qrdx" />

## Prima di iniziare [#before-you-start]

- Un progetto con Preact 10 o successivo, con Vite o un altro bundler.
- Node.js 18 o successivo.

## Come si fa [#build-it]

### 1. Installa qrdx [#1-install-qrdx]

```package-install
qrdx
```

`preact` è una peer dependency opzionale di `qrdx`. La tua app ce l'ha già.

### 2. Disegna un codice [#2-draw-a-code]

```tsx title="src/components/menu-code.tsx"
import { QRCodeSVG } from "qrdx/preact";

export function MenuCode() {
  return (
    <QRCodeSVG
      value="https://example.com/menu"
      size={256}
      margin={4}
      bodyPattern="rounded"
      frame={{ style: "banner-bottom", text: "Scan me" }}
      aria-label="QR code for the menu"
    />
  );
}
```

La pagina mostra un codice da 256 px con moduli arrotondati e un banner "Scan me" sotto.

<Shot id="lib-preact-code" />

`QRCodeSVG` accetta tutte le opzioni del `QRCodeSVG` di React: pattern, colori e gradienti, loghi (`imageSettings`), cornici, forme, template e art. Attributi come `class`, `style` o `aria-label` vanno sull'`<svg>`, oppure sull'`<svg>` esterno della cornice quando c'è una cornice.

`QRCode` aggiunge la scorciatoia per il logo del `QRCode` di React: `logo`, `logoOptions`, `hideLogo` e `scale`. Accetta solo le prop del codice e `style`; metti `class` o `aria-label` su un elemento attorno al codice, oppure usa `QRCodeSVG`.

```tsx title="src/components/logo-code.tsx"
import { QRCode } from "qrdx/preact";

export function LogoCode() {
  return <QRCode value="https://example.com" size={256} logo="/logo.png" level="H" />;
}
```

Entrambi i componenti si ridisegnano quando cambia una prop e saltano il lavoro quando non cambia nulla. Gli event handler nelle prop non vengono messi sull'`<svg>`, come in React. Mettili su un elemento attorno al codice.

### 3. Salvalo come file [#3-save-it-as-a-file]

I componenti si limitano a disegnare il codice. I download, `toSVGString`, il punteggio di scansione e le altre funzioni arrivano da `qrdx/core`. È il motore che i componenti usano già, quindi non viene incluso due volte nel bundle.

```tsx title="src/components/downloadable-code.tsx"
import { downloadQRCode } from "qrdx/core";
import { QRCodeSVG } from "qrdx/preact";

const options = { value: "https://example.com", size: 256, margin: 4 };

export function DownloadableCode() {
  return (
    <>
      <QRCodeSVG {...options} />
      <button
        type="button"
        onClick={() =>
          downloadQRCode(options, {
            format: "png",
            size: { width: 1024, height: 1024 },
            filename: "qr-code.png",
          })
        }
      >
        Download PNG
      </button>
    </>
  );
}
```

Cliccando il pulsante si salva `qr-code.png` a 1024 px. Tieni le opzioni in un unico oggetto, come sopra, così il file corrisponde al codice a schermo. [JavaScript vanilla](/docs/vanilla-js) tratta `qrdx/core` per intero.

## Rendering lato server [#server-rendering]

`renderToString` di `preact-render-to-string` scrive lo stesso SVG di `toSVGString` di `qrdx/core`. L'unica differenza è l'escaping: Preact lascia `>` e `'` così come sono nel testo, mentre il core scrive `&gt;` e `&#x27;`. I browser leggono le due forme allo stesso modo.

`hydrate` mantiene l'`<svg>` del server e non lo ridisegna. Il markup non contiene id casuali, quindi server e browser concordano sempre.

## Con preact/compat [#with-preactcompat]

Se la tua app ha già un alias da `react` a `preact/compat`, funzionano anche i componenti React di `qrdx`: `import { QRCodeSVG } from "qrdx"`. `qrdx/preact` disegna lo stesso codice senza alias, quindi preferiscilo quando aggiungi `qrdx` a un'app Preact.

## Se qualcosa va storto [#if-something-goes-wrong]

- **`Failed to resolve import "react"`.** Hai importato da `qrdx` invece che da `qrdx/preact`, in un'app senza `preact/compat`. Cambia l'import.
- **Un click handler sul componente non fa nulla.** Gli handler vengono scartati dall'`<svg>`. Racchiudi il codice in un `<button>` o in un `<div>` e metti lì l'handler.
- **`PDF export needs the optional "jspdf" package`.** Esegui `npm install jspdf` nell'app.
