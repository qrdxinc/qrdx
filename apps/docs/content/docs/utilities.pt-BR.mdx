Estes helpers são as pequenas funções que o renderizador e a nota de leitura usam, exportadas para a sua própria UI: escolher uma cor representativa, verificar o contraste, validar o tamanho de um download e detectar recursos do canvas. Eles rodam em qualquer lugar, exceto onde indicado.

| Função | Retorno | Observações |
| --- | --- | --- |
| `getSolidColor(color, fallback?)` | `string` | Uma cor que representa um `ColorConfig`: a string, o `color` de uma cor sólida, a primeira parada de um gradiente, o `underlay` de um preenchimento de imagem ou, se nada disso existir, `fallback` (`"#000000"`) |
| `getContrastRatio(a, b)` | `number` | A razão de contraste WCAG entre duas cores CSS, de 1 a 21. Cores transparentes são combinadas sobre o branco antes. Retorna 1 quando uma cor não pode ser interpretada |
| `getContrastLevel(ratio)` | `{ level, warning, message }` | `AAA` a partir de 7, `AA` a partir de 4.5, `AA Large` a partir de 3 (com `warning: true`), `Fail` abaixo de 3 |
| `getLuminance(r, g, b)` | `number` | Luminância relativa de uma cor sRGB, de 0 a 1 |
| `hexToRgb(hex)` | `{ r, g, b } \| null` | Lê hex de 3, 4, 6 e 8 dígitos, descartando o alfa. `null` para qualquer outro formato |
| `validateSize(width, height)` | `{ isValid, error? }` | A regra que todo download aplica: de 50 a 5000 px e quadrado |
| `SUPPORTS_PATH2D` | `boolean` | Indica se o canvas deste ambiente suporta `Path2D` com `addPath` |

## Cores [#colors]

```ts title="lib/colors.ts"
import { getSolidColor, hexToRgb } from "qrdx";

getSolidColor({
  type: "linear",
  angle: 45,
  stops: [
    { color: "#ff6b6b", offset: 0 },
    { color: "#4ecdc4", offset: 100 },
  ],
});
// "#ff6b6b": the first stop

getSolidColor({ type: "image", src: photo, underlay: "#111111" }); // "#111111"
getSolidColor(undefined, "#ffffff"); // "#ffffff"

hexToRgb("#ff6b6b"); // { r: 255, g: 107, b: 107 }
hexToRgb("#f00"); // { r: 255, g: 0, b: 0 }
hexToRgb("red"); // null
```

Use `getSolidColor` onde você precisar de uma única cor para uma amostra, um fundo CSS ou um fallback. O renderizador a usa onde um formato não consegue desenhar um gradiente, como em `QRCodeCanvas` e no desenho de moldura no Canvas.

## Contraste [#contrast]

```ts title="lib/contrast.ts"
import { getContrastLevel, getContrastRatio, getLuminance } from "qrdx";

getContrastRatio("#000000", "#ffffff"); // 21
getContrastRatio("#1d4ed8", "#f8fafc"); // 6.4
getContrastRatio("rgba(29, 78, 216, 0.5)", "#ffffff"); // the blue over white, so lower

getContrastLevel(4.5);
// { level: "AA", warning: false, message: "Good contrast" }

getContrastLevel(2);
// { level: "Fail", warning: true, message: "Poor contrast - QR code may not scan properly" }

getLuminance(255, 255, 255); // 1
```

A nota de leitura aprova um código com razão de 4.5 ou mais (`SCAN_CONTRAST_MIN`), tira pontos abaixo disso e reprova abaixo de 1.5. Imagens exigem mais: `SCAN_IMAGE_CONTRAST_MIN` é 7 para um preenchimento de imagem nos módulos e 12 para um atrás deles. `getScanContrast(props)` executa a verificação da própria nota em um design inteiro, incluindo todas as paradas de gradiente e as cores dos olhos; veja [Molduras, nota de leitura e arquivos de impressão](/docs/features/frames#will-it-scan).

Um verificador de contraste ao vivo cabe em uma dúzia de linhas:

```tsx title="components/contrast-checker.tsx"
"use client";

import { getContrastLevel, getContrastRatio } from "qrdx";
import { useState } from "react";

export function ContrastChecker() {
  const [fgColor, setFgColor] = useState("#000000");
  const [bgColor, setBgColor] = useState("#ffffff");
  const ratio = getContrastRatio(fgColor, bgColor);
  const level = getContrastLevel(ratio);

  return (
    <div>
      <input
        aria-label="Module color"
        type="color"
        value={fgColor}
        onChange={(event) => setFgColor(event.target.value)}
      />
      <input
        aria-label="Background color"
        type="color"
        value={bgColor}
        onChange={(event) => setBgColor(event.target.value)}
      />
      <p>
        {ratio.toFixed(2)}:1, {level.level}. {level.message}
      </p>
    </div>
  );
}
```

## Validação [#validation]

```ts title="lib/sizes.ts"
import { validateSize } from "qrdx";

validateSize(1024, 1024); // { isValid: true }
validateSize(40, 40); // { isValid: false, error: "Size must be at least 50x50 pixels" }
validateSize(6000, 6000); // { isValid: false, error: "Size must not exceed 5000x5000 pixels" }
validateSize(400, 300); // { isValid: false, error: "Width and height must be equal for QR codes" }
```

`downloadQRCode`, `getQRCodeDataUrl` e `copyQRCodeToClipboard` lançam o mesmo texto de `error` quando um tamanho falha, então um formulário pode verificar antes.

## Detecção de recursos [#feature-detection]

```ts title="lib/features.ts"
import { SUPPORTS_PATH2D } from "qrdx";

if (SUPPORTS_PATH2D) {
  // draw module paths with Path2D
}
```

`SUPPORTS_PATH2D` é calculado uma vez quando o módulo é carregado, então ele é `false` em um servidor.

## Outros helpers [#other-helpers]

- `getColorString(color)` e `normalizeColorConfig(color)` convertem as formas de `ColorConfig` entre si; `isGradient(color)` e `isImagePaint(color)` as distinguem.
- `sanitizeFrameText(text)` e `isLatin1Text(text)` aplicam as regras do texto da moldura (24 caracteres; Latin-1 para PDF e EPS).
- `decodePNGPixels(bytes)` lê um PNG de 8 bits em pixels RGBA sem DOM, para `createQRArtImage`, `createQRSilhouette` ou `scanQRPixels` no Node.
- `rgbToCmyk(color)` é a conversão usada pelos arquivos de impressão CMYK.
