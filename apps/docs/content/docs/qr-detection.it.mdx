`handleImageLoad` decodifica un QR code da un elemento immagine nel browser e restituisce il suo testo. Usalo per leggere codici da caricamenti, screenshot o foto senza inviare l'immagine da nessuna parte. Per una drop zone già pronta, installa il componente [QR Code Scanner](/docs/components/qr-code-scanner), che si basa su di esso.

| Funzione | Restituisce | Note |
| --- | --- | --- |
| `handleImageLoad(img, size, returnFullData?)` | `Promise<string \| QRCode \| "NO_QR">` | Il testo decodificato, oppure il risultato completo del decodificatore con `returnFullData`. `"NO_QR"` quando non viene trovato nulla. Solo browser |
| `downloadImageWithBoundingBox(img, corners, filename)` | `void` | Salva l'immagine come PNG con il codice trovato evidenziato in rosso |
| `getImageScanScore(imageOrBlob, options?)` | `Promise<ImageScanScoreResult>` | Decodifica e assegna un punteggio a un'immagine esistente. Vedi [Si legge?](/docs/features/frames#will-it-scan) |
| `scanQRPixels(pixels, expected, options?)` | `Promise<PixelScanResult>` | Verifica che i pixel RGBA vengano decodificati in `expected`, in Node |

## Decodificare un'immagine caricata [#decode-an-uploaded-image]

```tsx title="components/qr-reader.tsx"
"use client";

import { handleImageLoad } from "qrdx";
import { useState } from "react";

async function decodeFile(file: File): Promise<string | null> {
  const url = URL.createObjectURL(file);
  try {
    const image = new Image();
    image.src = url;
    await image.decode();
    const result = await handleImageLoad(image, image.naturalWidth);
    return typeof result === "string" && result !== "NO_QR" ? result : null;
  } finally {
    URL.revokeObjectURL(url);
  }
}

export function QrReader() {
  const [result, setResult] = useState("");

  async function onChange(event: React.ChangeEvent<HTMLInputElement>) {
    const file = event.target.files?.[0];
    if (!file) return;
    try {
      setResult((await decodeFile(file)) ?? "No QR code found");
    } catch {
      setResult("Could not read that image");
    }
  }

  return (
    <div>
      <input
        accept="image/*"
        aria-label="Image with a QR code"
        type="file"
        onChange={onChange}
      />
      {result ? <p>{result}</p> : null}
    </div>
  );
}
```

## Come funziona il rilevamento [#how-detection-works]

`handleImageLoad(img, size, returnFullData)` prova prima l'immagine intera, poi quattro ritagli (le regioni in basso a sinistra, in basso a destra, in alto a destra e al centro, al 65% dell'immagine), ciascuno a sei scale dal 100% fino al 10%. Restituisce la prima decodifica riuscita, quindi un codice che occupa una piccola parte di uno screenshot viene comunque trovato. Le immagini molto larghe o molto alte vengono prima ridimensionate.

- `img` deve essere un `<img>` già caricato. Attendi `decode()` o l'evento `load`.
- `size` è mantenuto per compatibilità con le versioni precedenti e viene ignorato: le scale derivano dalle dimensioni dell'immagine stessa. Passa la larghezza dell'immagine.
- `returnFullData` restituisce l'oggetto risultato di jsQR invece del testo.

Un codice sfocato, tagliato ai bordi o più chiaro del suo sfondo (moduli chiari su scuro) viene segnalato come `"NO_QR"`.

## Posizione e dati grezzi [#position-and-raw-data]

Con `returnFullData` attivo, il risultato è l'oggetto del decodificatore:

```ts title="lib/decode-full.ts"
import { handleImageLoad } from "qrdx";

const found = await handleImageLoad(image, image.naturalWidth, true);
if (found !== "NO_QR") {
  found.data; // "https://example.com"
  found.version; // 1 to 40
  found.binaryData; // the raw bytes, as number[]
  found.chunks; // the encoded segments and their modes
  found.location.topLeftCorner; // { x, y } in the image's pixels, and the other three corners
}
```

`downloadImageWithBoundingBox` disegna il contorno del codice sull'immagine originale e la salva, il che è utile quando una foto viene decodificata in qualcosa di inatteso. Gli angoli vanno in questo ordine: in alto a sinistra, in alto a destra, in basso a sinistra, in basso a destra:

```ts title="lib/debug-detection.ts"
import { downloadImageWithBoundingBox, handleImageLoad } from "qrdx";

const found = await handleImageLoad(image, image.naturalWidth, true);
if (found !== "NO_QR") {
  const { topLeftCorner, topRightCorner, bottomLeftCorner, bottomRightCorner } = found.location;
  downloadImageWithBoundingBox(
    image,
    [topLeftCorner, topRightCorner, bottomLeftCorner, bottomRightCorner],
    "found-code.png"
  );
}
```

## Assegnare un punteggio a un'immagine invece di limitarsi a decodificarla [#score-an-image-instead-of-only-decoding-it]

`getImageScanScore` decodifica un'immagine esistente e indica anche quanto affidabilmente verrebbe letta: decodifica a tre dimensioni con sfocatura simile a quella di una fotocamera, contrasto, polarità, zona di quiete e risoluzione. Accetta un `File`, un `Blob` o un `<img>`.

```ts title="lib/score-image.ts"
import { getImageScanScore } from "qrdx";

const { data, score, grade, checks } = await getImageScanScore(file);
// data: "https://example.com" or null
// score: 0 to 100, grade: "great" | "ok" | "risky" | "fails"
```

Il [controllo scansione](/tools/scan-checker) si basa su di essa. In Node, `scanQRPixels(pixels, expected)` verifica che i pixel RGBA (da `decodePNGPixels` o `sharp().raw()`) vengano decodificati in un valore noto.

## Se qualcosa va storto [#if-something-goes-wrong]

- **Ogni immagine restituisce `"NO_QR"`.** L'immagine non era stata caricata quando hai chiamato la funzione. Usa prima `await` su `image.decode()`. Se è caricata, il codice potrebbe essere troppo piccolo, sfocato, ritagliato o invertito; prova con un'immagine più nitida che contenga tutto il codice con un po' di margine intorno.
- **`handleImageLoad` viene chiamata sul server.** Richiede un canvas. Chiamala da un Client Component o da un gestore di eventi, oppure usa `scanQRPixels` in Node.
- **Il contorno di `downloadImageWithBoundingBox` è a farfalla.** Gli angoli sono nell'ordine sbagliato. Passa in alto a sinistra, in alto a destra, in basso a sinistra, in basso a destra.
