`handleImageLoad` は、ブラウザ上の画像要素からQRコードをデコードし、そのテキストを返します。アップロードされた画像、スクリーンショット、写真からコードを読み取るときに、画像をどこにも送信せずに使えます。すぐに使えるドロップゾーンが必要な場合は、これをもとに作られた [QR Code Scanner](/docs/components/qr-code-scanner) コンポーネントをインストールしてください。

| 関数 | 戻り値 | 備考 |
| --- | --- | --- |
| `handleImageLoad(img, size, returnFullData?)` | `Promise<string \| QRCode \| "NO_QR">` | デコードされたテキストを返します。`returnFullData` を指定すると、デコーダーの完全な結果を返します。何も見つからない場合は `"NO_QR"` を返します。ブラウザ専用です |
| `downloadImageWithBoundingBox(img, corners, filename)` | `void` | 見つかったコードを赤で囲み、画像をPNGとして保存します |
| `getImageScanScore(imageOrBlob, options?)` | `Promise<ImageScanScoreResult>` | 既存の画像をデコードしてスコア化します。[スキャンできる？](/docs/features/frames#will-it-scan)を参照してください |
| `scanQRPixels(pixels, expected, options?)` | `Promise<PixelScanResult>` | Node で、RGBAピクセルが `expected` にデコードされることを確認します |

## アップロードされた画像をデコードする [#decode-an-uploaded-image]

```tsx title="components/qr-reader.tsx"
"use client";

import { handleImageLoad } from "qrdx";
import { useState } from "react";

async function decodeFile(file: File): Promise<string | null> {
  const url = URL.createObjectURL(file);
  try {
    const image = new Image();
    image.src = url;
    await image.decode();
    const result = await handleImageLoad(image, image.naturalWidth);
    return typeof result === "string" && result !== "NO_QR" ? result : null;
  } finally {
    URL.revokeObjectURL(url);
  }
}

export function QrReader() {
  const [result, setResult] = useState("");

  async function onChange(event: React.ChangeEvent<HTMLInputElement>) {
    const file = event.target.files?.[0];
    if (!file) return;
    try {
      setResult((await decodeFile(file)) ?? "No QR code found");
    } catch {
      setResult("Could not read that image");
    }
  }

  return (
    <div>
      <input
        accept="image/*"
        aria-label="Image with a QR code"
        type="file"
        onChange={onChange}
      />
      {result ? <p>{result}</p> : null}
    </div>
  );
}
```

コードのスクリーンショットを選ぶと、入力欄の下にそのリンクが表示されます。`image.decode()` はファイルの読み込みを待ちます。続いて `handleImageLoad` が画像をキャンバスに描画し、jsQR を実行します。jsQR は必要になったときに読み込まれるため、スキャンを行わないバンドルには含まれません。

## 検出の仕組み [#how-detection-works]

`handleImageLoad(img, size, returnFullData)` は、まず画像全体を試し、次に4つの切り抜き領域(画像の65%の大きさの左下、右下、右上、中央)を試します。いずれも100%から10%までの6段階のスケールで行います。最初にデコードに成功した結果を返すため、スクリーンショットのうち小さな部分しか占めていないコードでも見つかります。非常に幅の広い画像や縦長の画像は、先に縮小されます。

- `img` は読み込み済みの `<img>` である必要があります。`decode()` または `load` イベントを待ってください。
- `size` は以前のリリースとの互換性のために残されており、無視されます。スケールは画像自体の寸法から決まります。画像の幅を渡してください。
- `returnFullData` を指定すると、テキストの代わりに jsQR の結果オブジェクトを返します。

ぼやけているコード、端が切れているコード、背景より明るいコード(暗い背景に明るいモジュール)は `"NO_QR"` と報告されます。

## 位置と生データ [#position-and-raw-data]

`returnFullData` を指定すると、結果はデコーダー自身のオブジェクトになります。

```ts title="lib/decode-full.ts"
import { handleImageLoad } from "qrdx";

const found = await handleImageLoad(image, image.naturalWidth, true);
if (found !== "NO_QR") {
  found.data; // "https://example.com"
  found.version; // 1 to 40
  found.binaryData; // the raw bytes, as number[]
  found.chunks; // the encoded segments and their modes
  found.location.topLeftCorner; // { x, y } in the image's pixels, and the other three corners
}
```

`downloadImageWithBoundingBox` は、元の画像にコードの輪郭を描いて保存します。写真が予想外の内容にデコードされるときに役立ちます。コーナーは、左上、右上、左下、右下の順に指定します。

```ts title="lib/debug-detection.ts"
import { downloadImageWithBoundingBox, handleImageLoad } from "qrdx";

const found = await handleImageLoad(image, image.naturalWidth, true);
if (found !== "NO_QR") {
  const { topLeftCorner, topRightCorner, bottomLeftCorner, bottomRightCorner } = found.location;
  downloadImageWithBoundingBox(
    image,
    [topLeftCorner, topRightCorner, bottomLeftCorner, bottomRightCorner],
    "found-code.png"
  );
}
```

## デコードだけでなく画像をスコア化する [#score-an-image-instead-of-only-decoding-it]

`getImageScanScore` は既存の画像をデコードするだけでなく、どれだけ確実にスキャンできるかも報告します。カメラを想定したぼかし、コントラスト、極性、クワイエットゾーン、解像度の条件で、3つのサイズでデコードします。`File`、`Blob`、`<img>` を受け取ります。

```ts title="lib/score-image.ts"
import { getImageScanScore } from "qrdx";

const { data, score, grade, checks } = await getImageScanScore(file);
// data: "https://example.com" or null
// score: 0 to 100, grade: "great" | "ok" | "risky" | "fails"
```

[スキャンチェッカー](/tools/scan-checker)はこれをもとに作られています。Node では、`scanQRPixels(pixels, expected)` により、RGBAピクセル(`decodePNGPixels` または `sharp().raw()` から取得したもの)が既知の値にデコードされることを確認できます。

## うまくいかない場合 [#if-something-goes-wrong]

- **どの画像でも `"NO_QR"` が返る。** 関数を呼び出した時点で画像が読み込まれていませんでした。先に `image.decode()` を待ってください。読み込まれている場合は、コードが小さすぎる、ぼやけている、切り取られている、または反転している可能性があります。コード全体とその周囲の余白が写った、より鮮明な画像を試してください。
- **`handleImageLoad` がサーバーで呼び出されている。** キャンバスが必要です。Client Component またはイベントハンドラーから呼び出すか、Node では `scanQRPixels` を使ってください。
- **`downloadImageWithBoundingBox` の輪郭が蝶ネクタイのようになる。** コーナーの順序が間違っています。左上、右上、左下、右下の順に渡してください。
