Ao final desta página, você terá um QR code estilizado em um componente Vue 3, renderizado no servidor e hidratado sem divergência, e um botão que o salva como PNG. O `qrdx/vue` traz versões em Vue dos componentes React, `QRCode` e `QRCodeSVG`, além de um composable `useQRCode`. Eles recebem as mesmas props dos componentes React e desenham o mesmo SVG. A entrada é construída sobre o `qrdx/core` e não importa `react`.

<NpmStatus package="qrdx" />

## Antes de começar [#before-you-start]

- Um projeto com Vue 3.3 ou mais recente, usando Vite ou Nuxt. O TypeScript verifica as props dos componentes a partir do Vue 3.4.20.
- Node.js 18 ou mais recente.

## Passo a passo [#build-it]

### 1. Instale o qrdx [#1-install-qrdx]

```package-install
qrdx
```

`vue` é uma peer dependency opcional, então o Vue do seu próprio app é usado.

### 2. Desenhe um código [#2-draw-a-code]

```vue title="src/App.vue"
<script setup lang="ts">
import { QRCode } from "qrdx/vue";
import { ref } from "vue";

const url = ref("https://example.com/menu");
</script>

<template>
  <QRCode
    :value="url"
    :size="256"
    :margin="4"
    body-pattern="rounded"
    :frame="{ style: 'banner-bottom', text: 'Scan for the menu' }"
    aria-label="QR code for the menu"
  />
</template>
```

A página mostra um código de 256 px com módulos arredondados e um banner embaixo. Altere `url` e o código é redesenhado, com o Vue atualizando o `<svg>` no mesmo lugar.

<Shot id="lib-framed-menu-code" />

O `QRCode` recebe as props do `QRCode` do React: todas as opções de `QRProps`, mais `logo`, `logoOptions`, `hideLogo` e `scale` para um logo. Em um template, escreva-as em kebab-case (`body-pattern`) ou camelCase. Uma flag como `auto-level` ou `hide-logo` não precisa de valor. `class`, `style`, `aria-label` e outros atributos vão no `<svg>`, ou no `<svg>` externo da moldura quando há uma moldura, e o mesmo vale para listeners como `@click`.

### 3. Salve como arquivo com useQRCode [#3-save-it-as-a-file-with-useqrcode]

```vue title="src/components/DownloadCode.vue"
<script setup lang="ts">
import { useQRCode } from "qrdx/vue";
import { ref } from "vue";

const url = ref("https://example.com/menu");
const { svg, download } = useQRCode(() => ({
  value: url.value,
  size: 256,
  margin: 4,
  bodyPattern: "rounded",
}));
</script>

<template>
  <div v-html="svg" />
  <button type="button" @click="download({ format: 'png', size: 1024, filename: 'menu.png' })">
    Download PNG
  </button>
</template>
```

O código aparece a partir do seu markup, e o botão salva `menu.png` com 1024 px. `useQRCode(props)` recebe as props do `QRCode` como objeto, ref, objeto reativo ou getter, e retorna:

- `svg`: o markup SVG como uma ref computada. Ela acompanha as props e funciona durante a renderização no servidor.
- `toDataURL(format, { size, quality })`: o código como data URL.
- `download({ format, filename, size, quality })`: salva o código como arquivo.
- `options`: as opções com que o código é desenhado, como uma ref computada.

`toDataURL` e `download` usam PNG por padrão, no `size` do próprio código. Os formatos são `png`, `jpg`, `webp`, `svg`, `pdf` e `eps`. PNG, JPG e WebP precisam de um navegador, e PDF precisa do pacote opcional `jspdf`.

## QRCodeSVG e configurações de imagem bruta [#qrcodesvg-and-raw-image-settings]

O `QRCodeSVG` recebe `QRProps`, como o `QRCodeSVG` do React. Um logo vai em `imageSettings`, em pixels:

```vue title="src/components/LogoCode.vue"
<script setup lang="ts">
import { QRCodeSVG } from "qrdx/vue";
</script>

<template>
  <QRCodeSVG
    value="https://example.com"
    :size="256"
    level="H"
    :image-settings="{ src: '/logo.png', width: 48, height: 48, excavate: true }"
  />
</template>
```

Prefira o `QRCode` com `logo` e `logoOptions`, a menos que você mesmo defina o layout do logo.

## Renderização no servidor e Nuxt [#server-rendering-and-nuxt]

Os dois componentes renderizam com o renderizador de servidor do Vue (`vue/server-renderer`), então o código faz parte do HTML do servidor. O markup não tem ids aleatórios, por isso o navegador o hidrata sem divergência.

No Nuxt, use-os em qualquer página ou componente. Eles renderizam no servidor e hidratam no navegador. Dentro de `<ClientOnly>`, renderizam somente no navegador.

## Mais recursos do qrdx/core [#more-from-qrdxcore]

O `qrdx/vue` reexporta tudo o que está no `qrdx/core`: `toSVGString`, `downloadQRCode`, `getQRCodeDataUrl`, `getScanScore`, a biblioteca oficial de molduras (`getOfficialFrame`) e o resto. O [Vanilla JavaScript](/docs/vanilla-js) cobre esses itens. Para PNG em um servidor, use `getQRAsPNG` do `qrdx/node`.

O `wrapper` de um template personalizado é escrito com o `h` exportado pelo `qrdx/vue`. Esse é o `h` do core, não o do Vue, então importe um deles com outro nome quando um arquivo precisar dos dois:

```ts title="src/labelled-template.ts"
import { h } from "qrdx/vue";

export const Labelled = {
  id: "Labelled",
  name: "Labelled",
  wrapper: (children, props) =>
    h(
      "svg",
      { viewBox: "0 0 300 340", xmlns: "http://www.w3.org/2000/svg" },
      h("g", { transform: "translate(20, 20) scale(0.87)" }, children),
      h("text", { x: "150", y: "325", textAnchor: "middle" }, props?.label)
    ),
};
```

Passe-o como `customTemplate`, com as props dele em `customProps`: `<QRCode value="https://example.com" :custom-template="Labelled" :custom-props="{ label: 'Scan me' }" />`.

## Se algo der errado [#if-something-goes-wrong]

- **`Failed to resolve component: QRCode`.** O componente não foi importado nesse arquivo. Adicione `import { QRCode } from "qrdx/vue"` ao `<script setup>` dele.
- **Uma prop não tem efeito.** Você a escreveu como string de atributo onde ela precisa de um valor: `size="256"` passa uma string, `:size="256"` passa um número. Props de objeto, como `frame` e `image-settings`, sempre precisam dos dois-pontos.
- **`PDF export needs the optional "jspdf" package`.** Execute `npm install jspdf` no app.
