读完本页，你将得到一个随信号（signal）变化的带样式二维码 Solid 组件，以及一个可将其保存为 PNG 的按钮。`qrdx/solid` 为 SolidJS 提供了与 React 库相同的两个 SVG 组件：`QRCodeSVG` 和 `QRCode`。它们绘制的 SVG 与 React 组件相同，会跟随你的信号更新，也可以在服务端渲染。

<NpmStatus package="qrdx" />

## 开始之前 [#before-you-start]

- 一个 Solid 1.8 或更高版本（1.x 系列）的项目，使用 Vite 或 SolidStart。
- Node.js 18 或更高版本。

## 动手构建 [#build-it]

### 1. 安装 qrdx [#1-install-qrdx]

```package-install
qrdx
```

`solid-js` 是 `qrdx` 的可选对等依赖（peer dependency）。你的应用已经包含它，也不需要 `react`。

### 2. 绘制随信号变化的二维码 [#2-draw-a-code-that-follows-a-signal]

```tsx title="src/components/menu-code.tsx"
import { createSignal } from "solid-js";
import { QRCodeSVG } from "qrdx/solid";

export function MenuCode() {
  const [color, setColor] = createSignal("#0f172a");
  return (
    <>
      <QRCodeSVG
        value="https://example.com/menu"
        size={256}
        margin={4}
        fgColor={color()}
        frame={{ style: "banner-bottom", text: "Scan me" }}
        aria-label="QR code for the menu"
      />
      <button type="button" onClick={() => setColor("#1d4ed8")}>
        Blue
      </button>
    </>
  );
}
```

页面会显示一个带有“Scan me”横幅的深色二维码。点击 **Blue**，二维码会以蓝色重新绘制。

<Shot id="lib-solid-signal-code" />

`QRCodeSVG` 支持 React 版 `QRCodeSVG` 的所有选项：图案、颜色和渐变、徽标（`imageSettings`）、边框、形状、模板和艺术效果。`class`、`style` 或 `aria-label` 等属性会加在 `<svg>` 上；如果有边框，则加在边框最外层的 `<svg>` 上。

`QRCode` 增加了 React 版 `QRCode` 的徽标快捷方式：`logo`、`logoOptions`、`hideLogo` 和 `scale`。它只接受二维码的属性和 `style`；请把 `class` 或 `aria-label` 放在包裹它的元素上，或者改用 `QRCodeSVG`。

```tsx title="src/components/logo-code.tsx"
import { QRCode } from "qrdx/solid";

export function LogoCode() {
  return <QRCode value="https://example.com" size={256} logo="/logo.png" level="H" />;
}
```

与任何 Solid 组件一样，属性是响应式的。`color()` 变化时，二维码会重新绘制。属性中的事件处理函数不会加到 `<svg>` 上，请把它们放在包裹二维码的元素上。

### 3. 保存为文件 [#3-save-it-as-a-file]

这些组件只负责绘制二维码。下载、`toSVGString`、扫描评分和其他函数来自 `qrdx/core`。组件本来就使用这个引擎，所以不会被重复打包。

```tsx title="src/components/downloadable-code.tsx"
import { downloadQRCode } from "qrdx/core";
import { QRCodeSVG } from "qrdx/solid";

const options = { value: "https://example.com", size: 256, margin: 4 };

export function DownloadableCode() {
  return (
    <>
      <QRCodeSVG {...options} />
      <button
        type="button"
        onClick={() =>
          downloadQRCode(options, {
            format: "png",
            size: { width: 1024, height: 1024 },
            filename: "qr-code.png",
          })
        }
      >
        Download PNG
      </button>
    </>
  );
}
```

点击按钮会以 1024 px 保存 `qr-code.png`。[Vanilla JavaScript](/docs/vanilla-js) 完整介绍了 `qrdx/core`。

## 绘制方式 [#how-it-draws]

该软件包不含 Solid JSX，因此无需 Solid 编译器，可适用于任何构建配置。

- 在浏览器中，组件会返回用 `createElementNS` 构建的 `<svg>` 元素本身（不解析任何 HTML）。Solid 将它放到页面上；当属性变化导致标记改变时，会换上新的元素；组件卸载时会将其移除。
- 如果属性变化后绘制的标记相同，页面不会改动。

## 服务端渲染与激活 [#server-rendering-and-hydration]

使用 `solid-js/web` 的 `renderToString` 时，组件输出的标记与 `qrdx/core` 的 `toSVGString` 相同，并在根元素上加上 Solid 的 `data-hk` 激活键。`hydrate` 会根据这个键保留服务端的 `<svg>`，而不是重新绘制。在 `<NoHydration>` 内部，不会输出该键。

标记中没有随机 id，因此服务端与浏览器的结果始终一致。

## 遇到问题时 [#if-something-goes-wrong]

- **`Failed to resolve import "react"`。** 你从 `qrdx` 而不是 `qrdx/solid` 导入了内容。主入口提供的是 React 组件，请修改导入路径。
- **组件上的点击处理函数没有反应。** 处理函数不会加到 `<svg>` 上。请用一个元素包裹二维码，并把处理函数放在该元素上。
- **`PDF export needs the optional "jspdf" package`。** 在应用中运行 `npm install jspdf`。
