このページでは、`qrdx` がエクスポートするものを、エントリポイント別・用途別に、各propの型とデフォルト値とともに一覧にしています。使い方は各機能のページで説明しています。このページは名前を調べるためのものです。

## エントリポイント [#entry-points]

| インポート元 | 含まれるもの | 必要なもの |
| --- | --- | --- |
| `qrdx` | Reactコンポーネント(`QRCode`、`QRCodeSVG`、`QRCodeCanvas`、`getQRAsSVG`)と、`qrdx/core` のすべて | `react`、`react-dom` |
| `qrdx/core` | Reactなしのエンジン一式:マークアップ、ダウンロード、印刷用ファイル、スキャンスコア、フレーム、テンプレート、アート、型 | なし |
| `qrdx/vanilla` | `createQRCode` と `qrdx/core` | DOM |
| `qrdx/element` | カスタム要素 `<qrdx-code>`:`QRdxCodeElement`、`defineQRdxCode`、`toQRdxCodeHTML` | 描画にはDOMが必要。マークアップの出力には不要 |
| `qrdx/element/define` | インポートすると `<qrdx-code>` を登録します | DOM |
| `qrdx/node` | `getQRAsPNG` | `@resvg/resvg-js` または `sharp` |
| `qrdx/vue` | `QRCode`、`QRCodeSVG`、`useQRCode` と `qrdx/core` | `vue` 3.3以降 |
| `qrdx/preact` | `QRCode`、`QRCodeSVG` | `preact` 10以降 |
| `qrdx/solid` | `QRCode`、`QRCodeSVG` | `solid-js` 1.8以降 |
| `qrdx/angular` | `QRCode` コンポーネント(`<qrdx-qr-code>`)と `qrdx/core` | `@angular/core` 20以降 |
| `qrdx/types` | レンダラーを含まない、すべての型、オプション一覧、zodスキーマ | なし |

フレームワーク向けのパッケージはすべてオプションのpeer dependencyです。`qrdx` をインストールしても、使わないものが追加されることはありません。PDF用の `jspdf` もオプションです。

## コンポーネント [#components]

### QRCode [#qrcode]

ほとんどの用途に向くコンポーネントです。`QRProps` にシンプルなロゴAPIを加えたもので、`<svg>` として描画されます。ブラウザ専用のフックを使わないため、React Server Components でも描画できます。

```tsx title="components/example.tsx"
import { QRCode } from "qrdx";

<QRCode value="https://example.com" size={256} margin={4} level="H" logo="/logo.png" />;
```

| Prop | 型 | デフォルト | 内容 |
| --- | --- | --- | --- |
| `value` | `string` | 必須 | エンコードするテキストまたはURL。指定したとおりに使われます |
| `size` | `number` | `128` | 幅と高さ(ピクセル)。フレームを付けるとその分大きくなり、テンプレートは内側に収まります |
| `scale` | `number` | `1` | `size` に掛ける倍率 |
| `level` | `"L" \| "M" \| "Q" \| "H"` | `"Q"` | 誤り訂正レベル。コードの約7%、15%、25%、30%が破損しても読み取れます |
| `margin` | `number` | `0` | コードの周囲の余白(クワイエットゾーン)。単位はモジュール。規格では4が求められています |
| `fgColor` | `ColorConfig` | `"#000000"` | データモジュールの色。CSSカラー、グラデーション、画像塗りのいずれか |
| `bgColor` | `ColorConfig` | `"#FFFFFF"` | 背景。`"transparent"` を指定すると背景は描画されません |
| `eyeColor` | `ColorConfig` | `fgColor` | 3つの角のアイの色 |
| `dotColor` | `ColorConfig` | `fgColor` | 各アイの内側のドットの色 |
| `eyeColors` | `EyeColors` | なし | `topLeft`、`topRight`、`bottomLeft` ごとの `outer` と `inner` の色。それぞれ `eyeColor` と `dotColor` より優先されます |
| `bodyPattern` | `BodyPattern` | `"circle"` | データモジュールの形。{facts.bodyPatterns} のいずれか |
| `cornerEyePattern` | `CornerEyePattern` | `"gear"` | 角のアイの形。{facts.eyeShapes} のいずれか |
| `cornerEyeDotPattern` | `CornerEyeDotPattern` | `"circle"` | アイのドットの形。{facts.eyeCentres} のいずれか |
| `moduleScale` | `number` | `1` | 各データモジュールの大きさ。0.5〜1。各パターンは、スキャンできる最小サイズ(`MODULE_SCALE_FLOOR`)で下限になります |
| `logo` | `string` | なし | 中央に描画するパス、URL、またはデータURL。背後のモジュールは消去されます。指定しなければロゴは描画されません |
| `logoOptions` | `LogoOptions` | なし | ロゴの `size`(0.1〜0.3、デフォルト0.25)、`padding`(0〜2モジュール)、`x` と `y`(0〜1)、`shape`、`plate` |
| `hideLogo` | `boolean` | `false` | `logo` が設定されていてもロゴを隠します |
| `autoLevel` | `boolean` | `false` | ロゴがコードの7%を超えて覆う場合(`AUTO_LEVEL_LOGO_COVERAGE`)、`level` を `H` に引き上げます |
| `frame` | `AnyQRFrame` | なし | 行動を促すフレーム:`{ style, text, color, textColor, secondaryText, secondaryColor, fontScale }`、または `{ style: "custom", spec }`。出力はフレームが収まるように大きくなります |
| `templateId` | `string` | なし | `size` で描画され、内側にコードが収まるテンプレート:`"Arrow"`、`"StandardBox"`、`"SquareBorder"`、`"StrikedBox"`、`"Halloween"`、`"DotRing"`、`"default"` |
| `customTemplate` | `TemplateDefinition` | なし | コードで描画する独自のテンプレート。`templateId` より優先されます |
| `customProps` | `Record<string, any>` | なし | テンプレートの `wrapper` に渡すprops(`DotRingProps` など) |
| `shape` | `"square" \| "circle" \| "heart" \| QRSilhouette` | `"square"` | コードを円、ハート、または独自の輪郭の中に配置し、装飾モジュールで埋めます |
| `art` | `QRArt` | なし | 画像をモジュールに溶け込ませます:`{ mode, image, intensity, variant, matchEyes }` |
| `style` | `CSSProperties` | なし | `<svg>` に付けるインラインスタイル |
| `frameLabelMarkers` | `boolean` | `false` | エディター向け。各フレームラベルの `<text>` に `data-qrdx-frame-label` を付けます。エクスポートには含まれません |
| `partMarkers` | `boolean` | `false` | エディター向け。描画された各パーツに `data-qrdx-part` を付けます。エクスポートには含まれません |
| `isOGContext` | `boolean` | `false` | Open Graph画像のレンダラー向けに、ロゴを配置された `<img>` として描画します |

`QRCode` が受け取るのはこれらのpropsだけで、それ以外のpropは破棄されます。`QRCodeSVG` は、それ以外のprop(`className`、`aria-label`、`role`、`data-*` など)を `<svg>` に付けます。フレームがある場合は、フレームの外側の `<svg>` に付けます。イベントハンドラーはマークアップに含まれません。

### QRCodeSVG [#qrcodesvg]

`QRProps` にReactのSVG属性を加えたもの(`QRPropsSVG`)です。`QRCode` と同じpropsから `logo`、`logoOptions`、`hideLogo`、`scale` を除いたものを受け取ります。ロゴはピクセル単位の `imageSettings` で指定します。

| フィールド | 型 | デフォルト | 内容 |
| --- | --- | --- | --- |
| `src` | `string` | 必須 | 画像。URLまたはデータURL |
| `width`, `height` | `number` | 必須 | `size` と同じピクセル単位のサイズ |
| `excavate` | `boolean` | 必須 | 画像の背後のモジュールを消去します |
| `x`, `y` | `number` | 中央 | 画像の左上隅の位置 |
| `padding` | `number` | `0` | 消去する場合に、画像の周囲に追加する空白(ピクセル) |
| `shape` | `"square" \| "rounded" \| "circle"` | `"square"` | 画像の切り抜き形状 |
| `plate` | `string` | なし | 画像の背後に、その形状で敷く単色のプレート |

コードが修復できる範囲を超える大きさのロゴは、中心を基準に縮小されます(`capImageSettings`。`QRCode` と同じ上限です)。

### QRCodeCanvas [#qrcodecanvas]

`QRProps` にReactのcanvas属性を加えたもの(`QRPropsCanvas`)で、デバイスのピクセル比で `<canvas>` に描画します。単色の通常の四角いモジュールだけを描画します。グラデーションは最初のカラーストップに置き換わり、パターン、アイの色、`eyeColors`、`moduleScale`、`art`、テンプレート関連のpropsは無視されます。`"use client"` 付きで提供されます。

### getQRAsSVG [#getqrassvg]

`getQRAsSVG(props: QRPropsSVG): Promise<JSX.Element>` は、ロゴをデータURLとして埋め込んだReact要素としてコードを返します。文字列が必要な場合は、`toSVGString` または `getSVGString` を使ってください。

## ダウンロードとエクスポート [#download-and-export]

| 関数 | 戻り値 | 備考 |
| --- | --- | --- |
| `downloadQRCode(props, { format, size, filename?, quality? })` | `Promise<void>` | ファイルを保存します。`size` は 50〜5000 px の正方形で、ラスター形式ではデフォルトのファイル名にピクセルサイズが入ります |
| `getQRCodeDataUrl(props, format, size, { quality? })` | `Promise<string>` | 同じファイルをデータ URL で返します |
| `getQRAsWebP(props, { quality? })` | `Promise<Blob>` | `quality` を指定しない限りロスレスです。ブラウザが対応していない場合は自前でエンコードします |
| `copyQRCodeToClipboard(props, size?)` | `Promise<void>` | PNG をクリップボードにコピーします。ユーザー操作から呼び出してください |
| `getSVGString(props)` | `Promise<string>` | ロゴを埋め込んだ SVG マークアップです |
| `toSVGString(props)` | `string` | 同期で返す SVG マークアップです。ロゴは埋め込まれません。どこでも実行できます |
| `toSVGElement(props, document?)` | `SVGSVGElement` | コードを DOM 要素として返します |
| `getQRAsSVGDataUri(props)` | `Promise<string>` | `data:image/svg+xml,…`。すべてのエクスポートの最初のステップです |
| `getQRAsCanvas(props, mimeType, getCanvas?)` | `Promise<string \| HTMLCanvasElement>` | データ URL を返します。`getCanvas` を指定するとキャンバス自体を返します |
| `getQRAsPNG(props, { size?, loadExternalLogos? })` | `Promise<Uint8Array>` | Node 上の PNG バイト列で、`qrdx/node` から利用します。`@resvg/resvg-js` または `sharp` が必要です |
| `validateSize(width, height)` | `{ isValid, error? }` | `downloadQRCode` が適用するサイズのルールです |
| `getDownloadFilename(format, size, frame?)` | `string` | デフォルトのファイル名です |
| `withQRSize(props, size)` | `QRProps` | `size` で描画する props です。ピクセル指定のロゴも合わせて拡縮されます |
| `canvasToWebP(canvas, { quality? })`, `blobToDataUrl(blob)`, `encodeWebPLossless(rgba, width, height)` | | WebP 用のヘルパーです |

定数：`DownloadFormat` は `"png" \| "jpg" \| "webp" \| "svg" \| "pdf" \| "eps"` です。`DOWNLOAD_FORMATS` は各形式を MIME タイプと拡張子に対応付けます。`PRESET_SIZES` には `small`（200）、`medium`（400）、`large`（800）、`xlarge`（1200）、`2xl`（1600）、`3xl`（2000）があります。`DEFAULT_SIZE` は 128 です。

| `downloadPrintPDF(props, options & { filename? })`, `downloadPrintSVG(props, options & { filename? })` | `Promise<void>` | この 2 つをブラウザでダウンロードします |
| `getQRAsEPS(props, { sizeMm?, bleedMm?, colorMode? })` | `Promise<string>` | EPSF-3.0 のテキストです。画像フィルの場合は `EPS_IMAGE_FILL_REASON` をスローします |
| `downloadPrintEPS(props, options & { filename? })` | `Promise<void>` | ブラウザでダウンロードします |
| `svgToEPS(svg, { width?, colorMode?, bleed?, bleedColor?, title? })` | `Promise<string>` | ライブラリが描画する任意の SVG を変換します |
| `epsToDataUrl(eps)`, `hasImageFill(props)`, `rgbToCmyk(color)`, `getQRModuleCount(props)` | | ヘルパーです |

`PrintOptions`：`size`（数値）、`unit`（`"mm"` または `"in"`、デフォルトは `"mm"`）、`bleed`（mm、0〜20）、`cropMarks`（真偽値）、`colorMode`（`"rgb"` または `"cmyk"`）。

## スキャンスコアと検出 [#scan-score-and-detection]

| 関数 | 戻り値 | 備考 |
| --- | --- | --- |
| `getScanScore(props, { sizes?, signal? })` | `Promise<ScanScoreResult>` | `{ score, grade, checks }`。ブラウザ専用で、jsQR を必要に応じて読み込みます。デフォルトのサイズは 96、160、320 px（`SCAN_TEST_SIZES`）です |
| `getImageScanScore(imageOrBlob, options?)` | `Promise<ImageScanScoreResult>` | 既存の画像に対する同じ処理で、`data` と `version` も返します。ブラウザ専用です |
| `getScanScoreFromPixels(pixels, options?)` | `Promise<ImageScanScoreResult>` | RGBA ピクセルに対する画像スコアです。Node 向けです |
| `scanQRPixels(pixels, expected, { sizes? })` | `Promise<PixelScanResult>` | ピクセルがそのままの状態と、カメラモデルを通した状態の両方で `expected` にデコードされるかを確認します。Node 向けです |
| `getScanContrast(props)` | `{ ratio, required, inverted }` | コントラストチェックのみを実行します |
| `getStylePairRisk(props)` | `StylePairRisk \| null` | 一部のスキャナーが読み取れない形状の組み合わせを、`fix` 付きで返します |
| `handleImageLoad(img, size, returnFullData?)` | `Promise<string \| QRCode \| "NO_QR">` | `<img>` から QR コードをデコードします。[QR 検出](/docs/qr-detection)を参照してください |
| `downloadImageWithBoundingBox(img, corners, filename)` | `void` | 見つかったコードを枠で囲んだ画像を保存します |

グレードは `"great"`、`"ok"`、`"risky"`、`"fails"` です。各チェックは `{ id, passed, message, fix?, skipped? }` です。コントラストの基準値：`SCAN_CONTRAST_MIN` は 4.5、`SCAN_CONTRAST_LOW` は 3、`SCAN_CONTRAST_FAIL` は 1.5、`SCAN_IMAGE_CONTRAST_MIN` はコード内の画像で 7、背景に置く画像で 12 です。弱い組み合わせは `WEAK_BODY_EYES`、`WEAK_DOT_EYES`、`WEAK_SHARP_DOT_EYES`、`SHARP_DOT_EYE_SAFE_BODIES`、`WEAK_EYES`、`WEAK_DOTS` として提供されます。

## テンプレート [#templates]

| エクスポート | 内容 |
| --- | --- |
| `TEMPLATES` | レジストリ：`default`、`Arrow`、`StandardBox`、`SquareBorder`、`StrikedBox`、`Halloween`、`DotRing` |
| `getTemplate(id)` | 1 つの `TemplateDefinition` を返します。ない場合は `undefined` です |
| `getAllTemplates()`, `getTemplateIds()` | 一覧と ID です |
| `Arrow`, `StandardBox`, `SquareBorder`, `StrikedBox`, `Halloween`, `DotRing`, `defaultTemplate` | 定義そのものです。`DotRingProps` は Dot Ring の `customProps` の型です |

`TemplateDefinition<TCustomProps>` は `{ id, name, description?, spec?, wrapper(children, props?, config?) }` です。wrapper は 300×300 のキャンバスに描画し、`{ fgColor, bgColor, ...customProps }` と `{ url, pixelSize }` を受け取ります。

## レンダリングのプリミティブ [#rendering-primitives]

`qrdx/core` が提供する、React に依存しないレンダラーです。

| エクスポート | 内容 |
| --- | --- |
| `createQRCodeTree(options)` | コードをプレーンな `{ type, props, key }` ノード（`QRNode`）として返します |
| `renderToString(tree)`, `renderToDOM(tree, document?)` | マークアップ、または DOM ノードを返します |
| `toHyperscript(tree, createElement)` | ツリーを他のフレームワークの要素に変換します。Vue と Preact のエントリーはこれを基にしています |
| `h(type, props, ...children)`, `Fragment`, `isQRNode(value)` | JSX を使わずにテンプレートの wrapper を書けます |
| `getQRAsSVGNode(options)` | ロゴを埋め込んだ `Promise<QRNode>` を返します |
| `getQRCodeData(props)`, `getQRCodeSVGProps(props, data)` | `resolveQRCodeProps` を構成する 2 つの処理です |

## 型とオプション一覧 [#types-and-option-lists]

以下の型は `qrdx`、`qrdx/core`、`qrdx/types` から提供されます。オプション一覧は単純な配列で、zodスキーマ（`qrPropsSchema`、`frameSchema`、`frameSpecSchema`、`colorConfigSchema`、`qrArtSchema`、`logoOptionsSchema`、`imageSettingsSchema` など）はこれらをもとに作られています。

| 型 | 形 |
| --- | --- |
| `QRProps` | 上記のpropsの表から、ロゴAPIを除いたもの |
| `QRCodeProps` | `QRProps` に `logo`、`logoOptions`、`hideLogo`、`scale` を加えたもの |
| `QRSVGOptions` | `QRProps` に任意のルート属性を加えたもの。コアが描画する内容です |
| `ColorConfig` | `string \| SolidColor \| LinearGradient \| RadialGradient \| AngularGradient \| ImagePaint` |
| `LinearGradient` | `{ type: "linear", stops, angle? }`。`angle` は度単位で、デフォルトは 0 です |
| `RadialGradient` | `{ type: "radial", stops }` |
| `AngularGradient` | `{ type: "angular", stops, angle? }` |
| `GradientStop` | `{ color, offset }`。`offset` は 0 から 100 です |
| `ImagePaint` | `{ type: "image", src, fit?, scale?, position?, opacity?, underlay? }` |
| `ImageSettings`、`LogoOptions`、`EyeColors` | 上記の表のとおりです |
| `QRFrame` | `{ style: FrameStyle, text?, color?, textColor?, secondaryText?, secondaryColor?, fontScale? }` |
| `QRCustomFrame`、`AnyQRFrame`、`FrameSpec` | `{ style: "custom", spec, ...labels and colors }`、そのユニオン型、およびspecの形式 |
| `QRArt`、`QRArtImage` | `{ mode, image, intensity?, variant?, matchEyes? }` と `{ width, height, data }` |
| `QRCodeShape`、`QRSilhouette` | `"square" \| "circle" \| "heart"` または `{ type: "silhouette", width, height, cells }` |
| `TemplateDefinition`、`BaseTemplateProps`、`TemplateConfig` | テンプレート |
| `DownloadFormat`、`DownloadSize`、`DownloadOptions`、`PrintOptions`、`PrintLayout`、`EPSOptions` | エクスポート |
| `ScanScoreResult`、`ImageScanScoreResult`、`ScanCheck`、`ScanGrade`、`StylePairRisk` | スキャンスコア |
| `BodyPattern`、`CornerEyePattern`、`CornerEyeDotPattern`、`FrameStyle`、`ErrorLevel` | オプションのユニオン型 |

オプション一覧：`BODY_PATTERN`、`CORNER_EYE_PATTERNS`、`CORNER_EYE_DOT_PATTERNS`、`FRAME_STYLES`、`QR_SHAPES`、`LOGO_SHAPES`、`EYE_POSITIONS`。保存済みのデザイン向けに引き続き描画される廃止済みの値：`RETIRED_CORNER_EYE_PATTERNS`（`curly`）と `RETIRED_CORNER_EYE_DOT_PATTERNS`（`diamond`、`star`、`banner`）。

## 実行できる環境 [#where-things-run]

- **どこでも実行可能（DOM不要）：** `toSVGString`、`createQRCodeTree`、`renderToString`、`getQRData`、フレームとテンプレートのヘルパー、`createQRArtImage`、`createQRSilhouette`、`getPrintLayout`、`getQRAsEPS`、`getQRAsPrintPDFBuffer`、`scanQRPixels`、`toQRdxCodeHTML`。
- **ブラウザ：** `downloadQRCode` とその他のダウンロード関数、`copyQRCodeToClipboard`、`getQRAsCanvas`、`getScanScore`、`getImageScanScore`、`handleImageLoad`、`loadQRArtImage`、`loadQRSilhouette`、`removeLogoBackground`、`createQRCode`、カスタム要素。
- **Nodeのみ：** `qrdx/node` の `getQRAsPNG`。
- **React Server Components：** `QRCode`、`QRCodeSVG`、およびDOMを必要としないすべての機能。`QRCodeCanvas` はClient Componentです。
