Esta página lista o que o `qrdx` exporta, por ponto de entrada e por tarefa, com o tipo e o valor padrão de cada prop. As páginas de recursos explicam como usar; esta serve para consultar um nome.

## Pontos de entrada [#entry-points]

| Importe de | O que tem | Requer |
| --- | --- | --- |
| `qrdx` | Os componentes React (`QRCode`, `QRCodeSVG`, `QRCodeCanvas`, `getQRAsSVG`) mais tudo de `qrdx/core` | `react`, `react-dom` |
| `qrdx/core` | O motor completo sem React: markup, downloads, arquivos de impressão, a nota de leitura, molduras, templates, arte e tipos | Nada |
| `qrdx/vanilla` | `createQRCode`, mais `qrdx/core` | Um DOM |
| `qrdx/element` | O custom element `<qrdx-code>`: `QRdxCodeElement`, `defineQRdxCode`, `toQRdxCodeHTML` | Um DOM para desenhar; nada para gerar markup |
| `qrdx/element/define` | Registra `<qrdx-code>` ao ser importado | Um DOM |
| `qrdx/node` | `getQRAsPNG` | `@resvg/resvg-js` ou `sharp` |
| `qrdx/vue` | `QRCode`, `QRCodeSVG`, `useQRCode`, mais `qrdx/core` | `vue` 3.3 ou mais recente |
| `qrdx/preact` | `QRCode`, `QRCodeSVG` | `preact` 10 ou mais recente |
| `qrdx/solid` | `QRCode`, `QRCodeSVG` | `solid-js` 1.8 ou mais recente |
| `qrdx/angular` | O componente `QRCode` (`<qrdx-qr-code>`), mais `qrdx/core` | `@angular/core` 20 ou mais recente |
| `qrdx/types` | Todos os tipos, listas de opções e schemas zod, sem o renderizador | Nada |

Todo pacote de framework é uma peer dependency opcional: instalar o `qrdx` nunca adiciona uma que você não usa. O `jspdf` também é opcional, para PDF.

## Componentes [#components]

### QRCode [#qrcode]

O componente para a maioria dos usos. `QRProps` mais uma API simples de logo, renderizado como um `<svg>`. Não usa hooks exclusivos do navegador, então renderiza em React Server Components.

```tsx title="components/example.tsx"
import { QRCode } from "qrdx";

<QRCode value="https://example.com" size={256} margin={4} level="H" logo="/logo.png" />;
```

| Prop | Tipo | Padrão | O que faz |
| --- | --- | --- | --- |
| `value` | `string` | obrigatório | O texto ou a URL a codificar, exatamente como informado |
| `size` | `number` | `128` | Largura e altura em pixels. Uma moldura aumenta esse valor; um template cabe dentro dele |
| `scale` | `number` | `1` | Multiplica `size` |
| `level` | `"L" \| "M" \| "Q" \| "H"` | `"Q"` | Correção de erros: cerca de 7%, 15%, 25% ou 30% do código pode estar danificado |
| `margin` | `number` | `0` | Zona silenciosa ao redor do código, em módulos. O padrão da norma pede 4 |
| `fgColor` | `ColorConfig` | `"#000000"` | Cor dos módulos de dados: uma cor CSS, um gradiente ou um preenchimento com imagem |
| `bgColor` | `ColorConfig` | `"#FFFFFF"` | Fundo. `"transparent"` não pinta nada |
| `eyeColor` | `ColorConfig` | `fgColor` | Cor dos três olhos dos cantos |
| `dotColor` | `ColorConfig` | `fgColor` | Cor do ponto dentro de cada olho |
| `eyeColors` | `EyeColors` | nenhum | Cores `outer` e `inner` por olho para `topLeft`, `topRight` e `bottomLeft`; cada uma substitui `eyeColor` e `dotColor` |
| `bodyPattern` | `BodyPattern` | `"circle"` | Forma dos módulos de dados, uma entre {facts.bodyPatterns} |
| `cornerEyePattern` | `CornerEyePattern` | `"gear"` | Forma dos olhos dos cantos, uma entre {facts.eyeShapes} |
| `cornerEyeDotPattern` | `CornerEyeDotPattern` | `"circle"` | Forma dos pontos dos olhos, uma entre {facts.eyeCentres} |
| `moduleScale` | `number` | `1` | Tamanho de cada módulo de dados, de 0,5 a 1. Cada padrão para no menor tamanho que ainda é lido (`MODULE_SCALE_FLOOR`) |
| `logo` | `string` | nenhum | Um caminho, URL ou data URL desenhado no meio, com os módulos atrás dele removidos. Sem essa prop, nenhum logo é desenhado |
| `logoOptions` | `LogoOptions` | nenhum | O `size` do logo (0,1 a 0,3, padrão 0,25), `padding` (0 a 2 módulos), `x` e `y` (0 a 1), `shape` e `plate` |
| `hideLogo` | `boolean` | `false` | Oculta o logo mesmo quando `logo` está definido |
| `autoLevel` | `boolean` | `false` | Eleva `level` para `H` quando o logo cobre mais de 7% do código (`AUTO_LEVEL_LOGO_COVERAGE`) |
| `frame` | `AnyQRFrame` | nenhum | Uma moldura de chamada para ação: `{ style, text, color, textColor, secondaryText, secondaryColor, fontScale }`, ou `{ style: "custom", spec }`. A saída cresce para acomodá-la |
| `templateId` | `string` | nenhum | Um template desenhado em `size` com o código dentro: `"Arrow"`, `"StandardBox"`, `"SquareBorder"`, `"StrikedBox"`, `"Halloween"`, `"DotRing"` ou `"default"` |
| `customTemplate` | `TemplateDefinition` | nenhum | Um template que você desenha em código. Tem prioridade sobre `templateId` |
| `customProps` | `Record<string, any>` | nenhum | Props para o `wrapper` do template, como `DotRingProps` |
| `shape` | `"square" \| "circle" \| "heart" \| QRSilhouette` | `"square"` | Coloca o código em um disco, um coração ou um contorno seu, preenchido com módulos decorativos |
| `art` | `QRArt` | nenhum | Mistura uma imagem aos módulos: `{ mode, image, intensity, variant, matchEyes }` |
| `style` | `CSSProperties` | nenhum | Estilos inline para o `<svg>` |
| `frameLabelMarkers` | `boolean` | `false` | Para editores: marca cada `<text>` de rótulo da moldura com `data-qrdx-frame-label`. As exportações nunca incluem isso |
| `partMarkers` | `boolean` | `false` | Para editores: marca as partes desenhadas com `data-qrdx-part`. As exportações nunca incluem isso |
| `isOGContext` | `boolean` | `false` | Desenha o logo como um `<img>` posicionado, para renderizadores de imagem Open Graph |

O `QRCode` aceita somente essas props; qualquer outra é descartada. O `QRCodeSVG` coloca qualquer outra prop (`className`, `aria-label`, `role`, `data-*`, …) no `<svg>`, ou no `<svg>` externo da moldura quando há uma moldura. Os manipuladores de eventos ficam fora do markup.

### QRCodeSVG [#qrcodesvg]

`QRProps` mais os atributos SVG do React (`QRPropsSVG`): as mesmas props do `QRCode`, sem `logo`, `logoOptions`, `hideLogo` e `scale`. O logo é definido por `imageSettings`, em pixels:

| Campo | Tipo | Padrão | O que faz |
| --- | --- | --- | --- |
| `src` | `string` | obrigatório | A imagem, como URL ou data URL |
| `width`, `height` | `number` | obrigatório | Tamanho nos mesmos pixels de `size` |
| `excavate` | `boolean` | obrigatório | Remove os módulos atrás da imagem |
| `x`, `y` | `number` | centralizado | Canto superior esquerdo da imagem |
| `padding` | `number` | `0` | Espaço livre extra ao redor da imagem, em pixels, ao remover módulos |
| `shape` | `"square" \| "rounded" \| "circle"` | `"square"` | Recorta a imagem |
| `plate` | `string` | nenhum | Uma placa sólida atrás da imagem, no formato dela |

Um logo maior do que o código consegue reparar é reduzido em torno do seu centro (`capImageSettings`, o mesmo limite do `QRCode`).

### QRCodeCanvas [#qrcodecanvas]

`QRProps` mais os atributos de canvas do React (`QRPropsCanvas`), desenhado em um `<canvas>` na proporção de pixels do dispositivo. Desenha módulos quadrados simples com cores sólidas: um gradiente usa só a primeira cor, e as props de padrão, cor dos olhos, `eyeColors`, `moduleScale`, `art` e template são ignoradas. Vem com `"use client"`.

### getQRAsSVG [#getqrassvg]

`getQRAsSVG(props: QRPropsSVG): Promise<JSX.Element>` retorna o código como um elemento React, com o logo embutido como data URL. Para obter uma string, use `toSVGString` ou `getSVGString`.

## Download e exportação [#download-and-export]

| Função | Retorna | Observações |
| --- | --- | --- |
| `downloadQRCode(props, { format, size, filename?, quality? })` | `Promise<void>` | Salva um arquivo. `size` vai de 50 a 5000 px e é quadrado; nos formatos raster, o nome de arquivo padrão informa o tamanho em pixels |
| `getQRCodeDataUrl(props, format, size, { quality? })` | `Promise<string>` | O mesmo arquivo como data URL |
| `getQRAsWebP(props, { quality? })` | `Promise<Blob>` | Sem perdas, a menos que `quality` seja definido; faz a codificação por conta própria onde o navegador não consegue |
| `copyQRCodeToClipboard(props, size?)` | `Promise<void>` | Coloca um PNG na área de transferência. Chame a partir de um gesto do usuário |
| `getSVGString(props)` | `Promise<string>` | Marcação SVG com o logo embutido |
| `toSVGString(props)` | `string` | Marcação SVG, síncrona, sem logo embutido. Roda em qualquer lugar |
| `toSVGElement(props, document?)` | `SVGSVGElement` | O código como elemento do DOM |
| `getQRAsSVGDataUri(props)` | `Promise<string>` | `data:image/svg+xml,…`, o primeiro passo de toda exportação |
| `getQRAsCanvas(props, mimeType, getCanvas?)` | `Promise<string \| HTMLCanvasElement>` | Uma data URL, ou o próprio canvas com `getCanvas` |
| `getQRAsPNG(props, { size?, loadExternalLogos? })` | `Promise<Uint8Array>` | Bytes de PNG no Node, a partir de `qrdx/node`. Precisa de `@resvg/resvg-js` ou `sharp` |
| `validateSize(width, height)` | `{ isValid, error? }` | A regra de tamanho que `downloadQRCode` aplica |
| `getDownloadFilename(format, size, frame?)` | `string` | O nome de arquivo padrão |
| `withQRSize(props, size)` | `QRProps` | As props desenhadas em `size`, com um logo em pixels redimensionado junto |
| `canvasToWebP(canvas, { quality? })`, `blobToDataUrl(blob)`, `encodeWebPLossless(rgba, width, height)` | | Auxiliares de WebP |

Constantes: `DownloadFormat` é `"png" \| "jpg" \| "webp" \| "svg" \| "pdf" \| "eps"`; `DOWNLOAD_FORMATS` associa cada um ao seu tipo MIME e extensão; `PRESET_SIZES` tem `small` (200), `medium` (400), `large` (800), `xlarge` (1200), `2xl` (1600) e `3xl` (2000); `DEFAULT_SIZE` é 128.

## Impressão e EPS [#print-and-eps]

| Função | Retorna | Observações |
| --- | --- | --- |
| `getPrintLayout(props, { size, unit?, bleed?, cropMarks?, colorMode? })` | `PrintLayout` | Tamanhos físicos em mm: `codeWidth`, `trimWidth`, `trimHeight`, `bleed`, `pageWidth`, `pageHeight`, `moduleSize`, `moduleCount`, `maxScanDistance`. `size` vai de 5 mm a 2 m |
| `getQRAsPrintPDF(props, options)` | `Promise<string>` | Um PDF vetorial como data URL. Precisa de `jspdf` |
| `getQRAsPrintPDFBuffer(props, options)` | `Promise<ArrayBuffer>` | O mesmo PDF em bytes, para Node |
| `getQRAsPrintSVG(props, { size, unit? })` | `Promise<string>` | SVG com `width` e `height` em mm ou in |
| `downloadPrintPDF(props, options & { filename? })`, `downloadPrintSVG(props, options & { filename? })` | `Promise<void>` | Downloads no navegador dos dois |
| `getQRAsEPS(props, { sizeMm?, bleedMm?, colorMode? })` | `Promise<string>` | Texto EPSF-3.0. Lança `EPS_IMAGE_FILL_REASON` para um preenchimento com imagem |
| `downloadPrintEPS(props, options & { filename? })` | `Promise<void>` | Download no navegador |
| `svgToEPS(svg, { width?, colorMode?, bleed?, bleedColor?, title? })` | `Promise<string>` | Converte qualquer SVG que a biblioteca renderiza |
| `epsToDataUrl(eps)`, `hasImageFill(props)`, `rgbToCmyk(color)`, `getQRModuleCount(props)` | | Auxiliares |

`PrintOptions`: `size` (número), `unit` (`"mm"` ou `"in"`, padrão `"mm"`), `bleed` (mm, de 0 a 20), `cropMarks` (booleano), `colorMode` (`"rgb"` ou `"cmyk"`).

## Pontuação de leitura e detecção [#scan-score-and-detection]

| Função | Retorna | Observações |
| --- | --- | --- |
| `getScanScore(props, { sizes?, signal? })` | `Promise<ScanScoreResult>` | `{ score, grade, checks }`. Somente no navegador; carrega o jsQR sob demanda. Tamanhos padrão: 96, 160 e 320 px (`SCAN_TEST_SIZES`) |
| `getImageScanScore(imageOrBlob, options?)` | `Promise<ImageScanScoreResult>` | O mesmo para uma imagem existente, mais `data` e `version`. Somente no navegador |
| `getScanScoreFromPixels(pixels, options?)` | `Promise<ImageScanScoreResult>` | A pontuação de imagem sobre pixels RGBA, no Node |
| `scanQRPixels(pixels, expected, { sizes? })` | `Promise<PixelScanResult>` | Verifica se os pixels decodificam para `expected`, como estão e pelo modelo de câmera. Node |
| `getScanContrast(props)` | `{ ratio, required, inverted }` | A verificação de contraste isolada |
| `getStylePairRisk(props)` | `StylePairRisk \| null` | Um par de formas que alguns leitores não reconhecem, com um `fix` |
| `handleImageLoad(img, size, returnFullData?)` | `Promise<string \| QRCode \| "NO_QR">` | Decodifica um QR code a partir de uma `<img>`. Veja [Detecção de QR](/docs/qr-detection) |
| `downloadImageWithBoundingBox(img, corners, filename)` | `void` | Salva a imagem com o código encontrado contornado |

As notas são `"great"`, `"ok"`, `"risky"` e `"fails"`. Cada verificação é `{ id, passed, message, fix?, skipped? }`. Limites de contraste: `SCAN_CONTRAST_MIN` 4.5, `SCAN_CONTRAST_LOW` 3, `SCAN_CONTRAST_FAIL` 1.5 e `SCAN_IMAGE_CONTRAST_MIN` 7 para uma imagem dentro do código e 12 atrás dele. Os pares fracos vêm como `WEAK_BODY_EYES`, `WEAK_DOT_EYES`, `WEAK_SHARP_DOT_EYES`, `SHARP_DOT_EYE_SAFE_BODIES`, `WEAK_EYES` e `WEAK_DOTS`.

## Logos [#logos]

| Função | Retorna | Observações |
| --- | --- | --- |
| `getQRData(props)` | as props com `imageSettings` | Posiciona `logo` e `logoOptions` para um código de 1024 px, limitado ao orçamento de correção de erros |
| `resolveQRCodeProps(props)` | `QRSVGOptions` | As props de `QRCode` como o renderizador as desenha, com `scale` aplicado |
| `getLogoSizeLimit({ value, level, margin, shape, autoLevel, logoOptions })` | `number` | O maior `logoOptions.size` que cabe, ou 0 |
| `getLogoBlockDamage(...)`, `logoFitsBudget(...)`, `getCodewordMap(...)`, `damagedCodewords(...)` | | As partes do orçamento. `LOGO_EC_SAFETY` é 0.6 |
| `removeLogoBackground(src)` | `Promise<string \| null>` | O logo com o fundo sólido removido, como data URL de PNG. Navegador |
| `removeLogoBackdrop(pixels)` | `LogoPixels \| null` | O mesmo sobre pixels RGBA, em qualquer lugar |

Limites: `LOGO_SIZE_MIN` 0.1, `LOGO_SIZE_MAX` 0.3, `LOGO_SIZE_DEFAULT` 0.25, `LOGO_PADDING_MAX` 2, `LOGO_SHAPES` (`square`, `rounded`, `circle`).

## Molduras [#frames]

| Exportação | O que é |
| --- | --- |
| `BUILT_IN_FRAMES` | Todas as molduras integradas: `{ style, name, tags, labelOn, spec }`, na ordem do seletor |
| `BUILT_IN_FRAME_SPECS`, `getBuiltInFrame(style)` | As specs por estilo |
| `frameSpecOf(frame)` | A spec que uma moldura desenha, ou `null` |
| `getFrameColors(frame)` | `{ frame, text, accent }`, a partir das opções ou dos padrões da spec |
| `getFrameDimensions(size, frame)` | O `{ width, height }` de saída para um código de `size` px |
| `getFrameLayout(size, frame)`, `getFrameText(frame)`, `getFrameSecondaryText(frame)`, `frameLabels(layout)`, `isFrameActive(frame)` | Auxiliares de layout |
| `OFFICIAL_FRAMES`, `OFFICIAL_FRAME_INDEX`, `getOfficialFrame(id)`, `OFFICIAL_FRAME_COLLECTIONS`, `OFFICIAL_FRAME_COUNT` | A biblioteca de molduras oficiais. As molduras são construídas como um módulo próprio, então, se não forem usadas, não custam nada |
| `resolveFrameSpec(spec)`, `getFrameSpecIssues(spec)`, `frameSpecSchema` | Valida uma spec; `resolveFrameSpec` lança `FrameSpecError` |
| `importFrameSvg(svg, options)` | Transforma um desenho SVG em uma spec de moldura, com avisos (`FRAME_IMPORT_LIMITS`) |
| `frameSpecHash(spec)` | Um hash estável de uma spec |

Constantes: `FRAME_STYLES` (os {facts.frameStyles} estilos integrados mais `none`), `DEFAULT_FRAME_TEXT` (`"Scan me"`), `FRAME_TEXT_MAX_LENGTH` (24), `FRAME_FONT_SCALE_MIN` (0.5), `FRAME_FONT_SCALE_MAX` (1.5), `CUSTOM_FRAME_STYLE` (`"custom"`), `GRADIENT_FRAME_DEFAULTS`.

## Templates [#templates]

| Exportação | O que é |
| --- | --- |
| `TEMPLATES` | O registro: `default`, `Arrow`, `StandardBox`, `SquareBorder`, `StrikedBox`, `Halloween`, `DotRing` |
| `getTemplate(id)` | Um `TemplateDefinition`, ou `undefined` |
| `getAllTemplates()`, `getTemplateIds()` | A lista e os ids |
| `Arrow`, `StandardBox`, `SquareBorder`, `StrikedBox`, `Halloween`, `DotRing`, `defaultTemplate` | As próprias definições. `DotRingProps` tipa o `customProps` do Dot Ring |

`TemplateDefinition<TCustomProps>` é `{ id, name, description?, spec?, wrapper(children, props?, config?) }`. O wrapper desenha em um canvas de 300 por 300 e recebe `{ fgColor, bgColor, ...customProps }` e `{ url, pixelSize }`.

## Formas e arte [#shapes-and-art]

| Exportação | O que é |
| --- | --- |
| `createQRArtImage(pixels, { maxSize?, square? })` | Amostra pixels RGBA em um `QRArtImage`. Em qualquer lugar |
| `loadQRArtImage(source, { mode?, maxSize? })` | O mesmo a partir de um arquivo, data URL ou `<img>`. Navegador |
| `isQRArtActive(art)`, `getQRArtVariant(art)`, `getQRArtColorIssue(props)` | Auxiliares de arte |
| `createQRSilhouette(pixels, { mode?, cells? })`, `loadQRSilhouette(source, options?)` | Uma `QRSilhouette` para `shape`, a partir de pixels ou de uma imagem |

| `isShapedCode(shape)`, `getQRShapePath(...)`, `circleQuietZone(...)`, `getLayoutMargin(...)` | Auxiliares de forma |
| `clampModuleScale(scale, pattern?)`, `MODULE_SCALE_FLOOR` | O menor `moduleScale` com que cada padrão ainda é lido |

Constantes: `QR_SHAPES` (`square`, `circle`, `heart`), `QR_CIRCLE_QUIET_MIN` (3), `QR_SILHOUETTE_MAX_CELLS` (64), `QR_ART_MODES` (`logo`, `halftone`), `QR_ART_VARIANTS`, `QR_ART_MAX_SAMPLE_SIZE` (192), `DEFAULT_ART_INTENSITY` (0.6).

| Exportação | O que é |

## Tipos e listas de opções [#types-and-option-lists]

Os tipos abaixo vêm de `qrdx`, `qrdx/core` e `qrdx/types`. As listas de opções são arrays simples; os schemas zod (`qrPropsSchema`, `frameSchema`, `frameSpecSchema`, `colorConfigSchema`, `qrArtSchema`, `logoOptionsSchema`, `imageSettingsSchema` e os demais) são construídos a partir delas.

| Tipo | Formato |
| --- | --- |
| `QRProps` | A tabela de props acima, sem a API de logo |
| `QRCodeProps` | `QRProps` mais `logo`, `logoOptions`, `hideLogo`, `scale` |
| `QRSVGOptions` | `QRProps` mais qualquer atributo da raiz: o que o núcleo desenha |
| `ColorConfig` | `string \| SolidColor \| LinearGradient \| RadialGradient \| AngularGradient \| ImagePaint` |
| `LinearGradient` | `{ type: "linear", stops, angle? }`; `angle` em graus, padrão 0 |
| `RadialGradient` | `{ type: "radial", stops }` |
| `AngularGradient` | `{ type: "angular", stops, angle? }` |
| `GradientStop` | `{ color, offset }`; `offset` de 0 a 100 |
| `ImagePaint` | `{ type: "image", src, fit?, scale?, position?, opacity?, underlay? }` |
| `ImageSettings`, `LogoOptions`, `EyeColors` | Como nas tabelas acima |
| `QRFrame` | `{ style: FrameStyle, text?, color?, textColor?, secondaryText?, secondaryColor?, fontScale? }` |
| `QRCustomFrame`, `AnyQRFrame`, `FrameSpec` | `{ style: "custom", spec, ...labels and colors }`, a união e o formato da spec |
| `QRArt`, `QRArtImage` | `{ mode, image, intensity?, variant?, matchEyes? }` e `{ width, height, data }` |
| `QRCodeShape`, `QRSilhouette` | `"square" \| "circle" \| "heart"` ou `{ type: "silhouette", width, height, cells }` |
| `TemplateDefinition`, `BaseTemplateProps`, `TemplateConfig` | Templates |
| `DownloadFormat`, `DownloadSize`, `DownloadOptions`, `PrintOptions`, `PrintLayout`, `EPSOptions` | Exportação |
| `ScanScoreResult`, `ImageScanScoreResult`, `ScanCheck`, `ScanGrade`, `StylePairRisk` | A pontuação de leitura |
| `BodyPattern`, `CornerEyePattern`, `CornerEyeDotPattern`, `FrameStyle`, `ErrorLevel` | As uniões de opções |

Listas de opções: `BODY_PATTERN`, `CORNER_EYE_PATTERNS`, `CORNER_EYE_DOT_PATTERNS`, `FRAME_STYLES`, `QR_SHAPES`, `LOGO_SHAPES`, `EYE_POSITIONS`. Valores aposentados que ainda são renderizados em designs salvos: `RETIRED_CORNER_EYE_PATTERNS` (`curly`) e `RETIRED_CORNER_EYE_DOT_PATTERNS` (`diamond`, `star`, `banner`).

## Onde cada coisa roda [#where-things-run]

- **Em qualquer lugar, sem DOM:** `toSVGString`, `createQRCodeTree`, `renderToString`, `getQRData`, os helpers de frame e de template, `createQRArtImage`, `createQRSilhouette`, `getPrintLayout`, `getQRAsEPS`, `getQRAsPrintPDFBuffer`, `scanQRPixels`, `toQRdxCodeHTML`.
- **Navegador:** `downloadQRCode` e os outros downloads, `copyQRCodeToClipboard`, `getQRAsCanvas`, `getScanScore`, `getImageScanScore`, `handleImageLoad`, `loadQRArtImage`, `loadQRSilhouette`, `removeLogoBackground`, `createQRCode`, o custom element.
- **Somente Node:** `getQRAsPNG`, de `qrdx/node`.
- **React Server Components:** `QRCode`, `QRCodeSVG` e tudo o que não precisa de DOM. `QRCodeCanvas` é um Client Component.
