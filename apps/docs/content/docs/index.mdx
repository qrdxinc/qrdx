QRdx is an open-source QR code platform (the app is AGPL-3.0, the `qrdx` library and CLI are MIT): static codes for free with no account, and dynamic codes you can change after printing, with hosted pages and scan analytics. A dynamic code keeps working on every plan, even after you cancel ([the Never-Hostage Guarantee](/guarantee)).
