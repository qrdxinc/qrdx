Akun yang terhubung memungkinkan editor QR memakai tautan yang ada di alat lain Anda: tautan pendek yang Anda kelola di Bitly, Rebrandly, atau Short.io, atau tautan berbagi ke file di Dropbox atau penyimpanan cloud lainnya. Kode QR mengenkode tautan tersebut, sehingga Anda tetap memakai alat yang sudah biasa Anda gunakan. Gunakan fitur ini jika tautan Anda harus tetap berada di analitik alat tersebut, atau jika kode perlu membuka file yang Anda simpan di penyimpanan cloud.

<Callout type="info" title="Semua paket">
  Akun yang terhubung adalah milik akun pengguna Anda dan berfungsi di semua paket. Jika Anda lebih suka tujuan tetap bisa diedit di QRdx sendiri, lengkap dengan analitik pemindaian, gunakan [kode QR dinamis](/docs/dynamic-qr-codes).
</Callout>

## Cara kerjanya [#how-it-works]

Hubungkan akun di [Pengaturan → Integrasi](/settings/integrations) dan akun tersebut akan muncul di tipe **URL** pada editor QR, di menu **Use a link from…** di samping kolom **Website address**. Di bawah **Your accounts**, setiap layanan menjelaskan fungsinya:

- **Shorten**: Bitly, Rebrandly, atau Short.io. Buat tautan di bawah **Create new**, atau pilih tautan yang sudah Anda miliki di bawah **Use existing**. Kode QR mengenkode tautan pendek tersebut, sehingga Anda dapat mengubah tujuannya nanti di layanan itu, dan layanan itu menghitung kliknya.
- **File**: Dropbox<IfAvailable integration="onedrive">, OneDrive</IfAvailable><IfAvailable integration="box">, Box</IfAvailable><IfAvailable integration="notion">, Notion</IfAvailable>. Telusuri atau cari, lalu pilih file atau folder. QRdx membuat tautan berbagi untuk item tersebut dan kode QR mengenkodenya.

Menu yang sama menampilkan sumber konten terhubung lainnya, seperti tautan pembayaran dan pemesanan. Layanan yang belum Anda hubungkan ada di balik **Connect an account** di bagian bawah menu.

<Shot id="use-a-link-from" />

Token dan kunci API disimpan terenkripsi, dan Anda dapat memutuskan koneksi kapan saja.

## Tautan pendek [#short-links]

| Layanan | Cara menghubungkan | Domain | Back-half |
| --- | --- | --- | --- |
| Bitly | Masuk dengan Bitly, atau tempel token akses generik (Settings → Developer settings → API) | bit.ly dan domain bermerek Anda | Dipilih oleh Bitly |
| Rebrandly | Tempel kunci API (Account → API keys) | rebrand.ly dan domain bermerek Anda | Slashtag Anda sendiri, atau acak |
| Short.io | Tempel kunci API rahasia (Integrations & API → API) | Domain Short.io Anda | Path Anda sendiri, atau acak |

Halaman pengaturan setiap integrasi menampilkan domain Anda dan memungkinkan Anda memilih domain default untuk tautan baru. Anda tetap bisa memilih domain lain untuk setiap tautan.

<Callout type="info" title="Mengubah tujuan nanti">
  QRdx membuat tautan; mengubah tujuannya dilakukan di Bitly, Rebrandly, atau Short.io. Bitly hanya mengizinkan paket berbayar untuk mengubah tujuan tautan.
</Callout>

## Pemilih file [#file-pickers]

**Dropbox** mengenkode tautan berbagi (dibuat baru, atau tautan yang sudah ada dipakai ulang). Siapa pun yang memiliki tautan dapat membukanya, kecuali tim Anda hanya mengizinkan tautan tim.

<IfAvailable integration="onedrive">

**OneDrive** mengenkode tautan berbagi hanya-lihat. Siapa pun yang memiliki tautan dapat membukanya; hanya organisasi Anda yang bisa jika admin Anda menonaktifkan tautan "Anyone".

</IfAvailable>

<IfAvailable integration="box">

**Box** mengenkode tautan bersama item tersebut, yang diatur ke "People with the link". Siapa pun yang memiliki tautan dapat membukanya; hanya perusahaan Anda yang bisa jika admin Anda mewajibkannya.

</IfAvailable>

<IfAvailable integration="notion">

**Notion** mengenkode tautan "Publish to web" milik halaman. Siapa pun dapat membukanya setelah halaman dipublikasikan.

</IfAvailable>

Jika tautan tidak dapat dibuka oleh semua orang, QRdx memberi tahu Anda tepat setelah Anda memilih, sehingga kode yang dicetak tidak mengarahkan orang ke halaman masuk.

<IfAvailable integration="notion">

**Halaman Notion.** QRdx hanya melihat halaman yang Anda bagikan kepadanya: Notion menanyakan halaman mana saat Anda menghubungkan. Untuk menambahkan lebih banyak nanti, buka halaman di Notion, klik **•••** → **Connections** lalu tambahkan QRdx (atau hubungkan ulang dan pilih halamannya). API Notion tidak dapat memublikasikan halaman. Publikasikan sendiri (**Share** → **Publish** → **Publish to web**), lalu pilih lagi agar QRdx memakai tautan publiknya.

</IfAvailable>

### File di halaman yang di-hosting [#files-on-hosted-pages]

Halaman yang di-hosting juga dapat memakai file cloud: blok PDF, audio, video, dan unduhan mendapat tombol **From Dropbox** di samping tombol unggah jika Dropbox adalah satu-satunya penyimpanan yang terhubung, atau **From cloud storage** jika Anda menghubungkan lebih dari satu<IfAvailable integration="onedrive">, termasuk OneDrive</IfAvailable><IfAvailable integration="box">, termasuk Box</IfAvailable>. Untuk Dropbox<IfAvailable integration="box"> dan Box</IfAvailable>, blok halaman mendapat tautan langsung ke file, sehingga pemutar audio dan video serta penampil PDF dapat memuatnya.<IfAvailable integration="onedrive"> Tautan berbagi OneDrive membuka penampil OneDrive, sehingga blok menampilkannya sebagai tautan.</IfAvailable>

## Memutuskan koneksi [#disconnecting]

Memutuskan koneksi menghapus token yang tersimpan. Untuk Dropbox<IfAvailable integration="box">, Box</IfAvailable><IfAvailable integration="notion">, Notion</IfAvailable>, QRdx juga mencabutnya di layanan tersebut. Untuk Bitly, Rebrandly, dan Short.io, hapus juga kuncinya di layanan itu jika Anda tidak lagi menggunakannya<IfAvailable integration="onedrive">; untuk OneDrive, hapus QRdx dari izin aplikasi akun Microsoft Anda</IfAvailable>.

Kode QR yang sudah Anda buat tetap berfungsi: kode tersebut menyimpan tautan pendek atau tautan berbagi, bukan token Anda.

## Batas dan paket [#limits-and-plans]

Akun yang terhubung tidak memiliki batas paket tersendiri. Dari sudut pandang QRdx, tautan yang dibuatnya bersifat statis: QRdx tidak menghitung pemindaiannya dan tidak dapat mengubah tujuannya. Paket masing-masing layanan menentukan apa yang dapat Anda lakukan dengan tautan di sana.

## Hosting mandiri [#self-hosting]

Rebrandly dan Short.io tidak memerlukan apa pun di server. Yang lainnya memerlukan aplikasi di setiap layanan, dengan client ID dan secret-nya di environment; tanpa itu integrasi disembunyikan di produksi (pengembangan lokal menampilkan lencana **Needs setup**). Bitly tetap berfungsi tanpa itu, melalui token akses yang ditempelkan.

| Integrasi | Variabel | Redirect URI |
| --- | --- | --- |
| Bitly (masuk) | `BITLY_CLIENT_ID`, `BITLY_CLIENT_SECRET` | `<app url>/api/integrations/bitly/callback` |
| Dropbox | `DROPBOX_CLIENT_ID`, `DROPBOX_CLIENT_SECRET` | `<app url>/api/integrations/dropbox/callback` |
| OneDrive | `MICROSOFT_CLIENT_ID`, `MICROSOFT_CLIENT_SECRET` | `<app url>/api/integrations/onedrive/callback` |
| Box | `BOX_CLIENT_ID`, `BOX_CLIENT_SECRET` | `<app url>/api/integrations/box/callback` |
| Notion | `NOTION_CLIENT_ID`, `NOTION_CLIENT_SECRET` | `<app url>/api/integrations/notion/callback` |

`<app url>` adalah `http://localhost:3000` saat pengembangan dan URL produksi Anda untuk selainnya. Setiap integrasi juga memerlukan `INTEGRATION_ENCRYPTION_KEY` di produksi, yang mengenkripsi token dan kunci yang tersimpan.

Scope yang perlu diminta:

- **Dropbox:** `account_info.read`, `files.metadata.read`, `sharing.read`, `sharing.write`
- **OneDrive:** `offline_access`, `Files.ReadWrite` (Microsoft Graph memerlukan akses tulis untuk membuat tautan berbagi)
- **Box:** Read and write all files and folders (`root_readwrite`)
- **Bitly, Notion:** tanpa scope; Notion menanyakan kepada pengguna halaman mana yang dibagikan

Lihat [Hosting mandiri](/docs/self-hosting#optional-services).
