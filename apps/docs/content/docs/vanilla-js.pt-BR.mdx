Ao final desta página, você terá um QR code estilizado desenhado em uma página HTML simples, atualizado pelo seu código e salvo como PNG, com um bundler ou com uma única tag script. `qrdx/vanilla` é o mesmo motor que os componentes React usam para desenhar, então ele gera o mesmo SVG, com todos os padrões, cores, logos, molduras e exportações, e não importa `react` nem `react-dom`.

<NpmStatus package="qrdx" />

## Antes de começar [#before-you-start]

- Uma página com um bundler (Vite, webpack, Parcel ou outro) para os passos 1 a 3. Sem bundler, pule para o [passo 4](#4-use-it-without-a-bundler).
- Node.js 18 ou mais recente para o bundler.

## Monte [#build-it]

### 1. Instale o qrdx [#1-install-qrdx]

```package-install
qrdx
```

`react` e `react-dom` são peer dependencies opcionais. Você não precisa delas para `qrdx/vanilla` nem para `qrdx/core`.

### 2. Desenhe um código em um elemento [#2-draw-a-code-into-an-element]

```html title="index.html"
<div id="qr"></div>
<script type="module" src="/main.js"></script>
```

```js title="main.js"
import { createQRCode } from "qrdx/vanilla";

const qr = createQRCode("#qr", {
  value: "https://example.com/menu",
  size: 256,
  margin: 4,
  bodyPattern: "rounded",
  frame: { style: "banner-bottom", text: "Scan for the menu" },
  "aria-label": "QR code for the menu",
});
```

Um `<svg>` aparece dentro de `#qr`: um código de 256 px com módulos arredondados e um banner embaixo. `createQRCode(element, options)` aceita um elemento ou um seletor CSS, e todas as opções do `QRCodeSVG` do React: padrões, cores e gradientes, logos (`imageSettings`), molduras, formas, templates e arte. Atributos como `className`, `style` ou `aria-label` vão no `<svg>`. O elemento é construído com `createElementNS`, então nenhum HTML é interpretado.

### 3. Atualize, exporte e remova [#3-update-export-and-remove-it]

```js title="main.js"
qr.update({ fgColor: "#1d4ed8" }); // redraws the code in place, now blue

qr.toSVGString(); // '<svg xmlns="http://www.w3.org/2000/svg" …'
await qr.toDataURL("png", { size: 1024 }); // "data:image/png;base64,…"
await qr.download({ format: "png", size: 1024, filename: "menu.png" });

qr.destroy(); // removes the <svg>
```

- `update` mescla as novas opções nas atuais e redesenha. Passe `undefined` para descartar uma opção. Quando o markup não muda, a página não é alterada.
- `toDataURL` e `download` usam PNG por padrão, no `size` do próprio código. Os formatos são `png`, `jpg`, `webp`, `svg`, `pdf` e `eps`. Uma moldura deixa a imagem maior que o código. O PDF precisa do pacote opcional `jspdf`.
- `qr.svg` é o elemento `<svg>` e `qr.options` são as opções atuais.
- `destroy` remove o `<svg>`. Depois dele, `update` lança um erro.

### 4. Use sem bundler [#4-use-it-without-a-bundler]

```html title="index.html"
<div id="qr"></div>
<script type="module">
  import { createQRCode } from "https://cdn.jsdelivr.net/npm/qrdx/dist/vanilla.browser.mjs";

  createQRCode("#qr", { value: "https://example.com", size: 256, margin: 4 });
</script>
```

`dist/vanilla.browser.mjs` é a mesma API em um único módulo ES. Adicione `@` e uma versão depois de `qrdx` na URL para fixar uma versão. O mesmo caminho funciona no unpkg.

O arquivo deixa de fora os dados da biblioteca oficial de molduras, para que páginas que não a usam não precisem baixá-la. Para usar uma moldura oficial, importe-a do arquivo ao lado:

```js title="index.html"
import { getOfficialFrame } from "https://cdn.jsdelivr.net/npm/qrdx/dist/frames-official.mjs";

const wifi = getOfficialFrame("wifi-card");
qr.update({ frame: { style: "custom", spec: wifi.spec } });
```

A exportação em PDF e a pontuação de leitura carregam `jspdf` e `jsqr` quando são executadas. Uma página que as usa mapeia os dois com um import map, colocado antes do script de módulo:

```html title="index.html"
<script type="importmap">
  {
    "imports": {
      "jspdf": "https://cdn.jsdelivr.net/npm/jspdf@4/+esm",
      "jsqr": "https://cdn.jsdelivr.net/npm/jsqr@1/+esm"
    }
  }
</script>
```

## Markup e nós do DOM com qrdx/core [#markup-and-dom-nodes-with-qrdxcore]

`qrdx/core` tem tudo o que a entrada principal `qrdx` tem, exceto os componentes React. Funciona no Node e no navegador.

```ts title="code.ts"
import {
  createQRCodeTree,
  renderToDOM,
  renderToString,
  resolveQRCodeProps,
  toSVGElement,
  toSVGString,
} from "qrdx/core";

// What <QRCodeSVG> renders, as a string (no DOM needed)
const svg = toSVGString({ value: "https://example.com", size: 256 });

// The same code as an <svg> element
document.body.append(toSVGElement({ value: "https://example.com" }));

// The code as plain { type, props, key } nodes, then markup or DOM nodes
const tree = createQRCodeTree({ value: "https://example.com" });
renderToString(tree);
renderToDOM(tree);

// <QRCode>'s logo API (logo, logoOptions, hideLogo, scale)
toSVGString(resolveQRCodeProps({ value: "https://example.com", logo: "/logo.png" }));
```

A saída não tem ids aleatórios, então o markup renderizado em um servidor é igual ao do navegador. Downloads, pontuação de leitura e PDF e EPS prontos para impressão vêm das mesmas funções da biblioteca React: `downloadQRCode`, `getQRCodeDataUrl`, `getScanScore`, `downloadPrintPDF` e as demais. Para PNG em um servidor, use `getQRAsPNG` de `qrdx/node`.

## Templates personalizados sem JSX [#custom-templates-without-jsx]

O `wrapper` de um template recebe o código desenhado e o devolve envolvido. `h(type, props, ...children)` escreve um sem JSX:

```js title="labelled-template.js"
import { h, toSVGString } from "qrdx/core";

const Labelled = {
  id: "Labelled",
  name: "Labelled",
  wrapper: (children, props) =>
    h(
      "svg",
      { viewBox: "0 0 300 340", xmlns: "http://www.w3.org/2000/svg" },
      h("g", { transform: "translate(20, 20) scale(0.87)" }, children),
      h("text", { x: "150", y: "325", textAnchor: "middle" }, props?.label)
    ),
};

toSVGString({
  value: "https://example.com",
  customTemplate: Labelled,
  customProps: { label: "Scan me" },
});
```

O mesmo wrapper funciona nos componentes React, desde que `h` seja importado de `qrdx`.

## Se algo der errado [#if-something-goes-wrong]

- **`qrdx: no element matches #qr`.** O script rodou antes de o elemento existir. Coloque o `<script type="module">` depois do elemento, ou espere o `DOMContentLoaded`.
- **`qrdx: this QR code was destroyed`.** Você chamou `update` depois de `destroy`. Crie um novo código com `createQRCode`.
- **`PDF export needs the optional "jspdf" package`.** Instale `jspdf` junto com `qrdx`, ou adicione-o ao import map em uma página sem bundler.
- **O código é desenhado, mas o celular não faz a leitura.** Adicione `margin: 4`, mantenha módulos escuros sobre fundo claro e confira o design com `getScanScore`. Veja [Um código não é lido](/docs/help/troubleshooting/wont-scan).
