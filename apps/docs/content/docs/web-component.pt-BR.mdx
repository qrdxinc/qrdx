Ao final desta página, você terá um QR code estilizado desenhado pelo elemento `<qrdx-code>` em uma página HTML simples, com opções de objeto definidas por um script e uma exportação para PNG. O `qrdx/element` é construído sobre o `qrdx/core`, então desenha o mesmo SVG do `QRCodeSVG` do React, com todos os estilos, molduras, logos e exportações. Ele não precisa de framework e funciona em frameworks que renderizam elementos do DOM. Foi testado no React 19 e no Vue 3.

<NpmStatus package="qrdx" />

## Antes de começar [#before-you-start]

- Uma página à qual você possa adicionar um `<script type="module">`. Não é preciso bundler, mas dá para usar um.
- Para o caminho com bundler, Node.js 18 ou mais recente.

## Passo a passo [#build-it]

### 1. Carregue o elemento [#1-load-the-element]

<Tabs items={["From a CDN", "With a bundler"]}>
<Tab value="From a CDN">

```html title="index.html"
<script
  type="module"
  src="https://cdn.jsdelivr.net/npm/qrdx/dist/element-define.browser.mjs"
></script>
```

O `dist/element-define.browser.mjs` registra o `<qrdx-code>`. Ele carrega o `dist/element.browser.mjs`, um único módulo ES com o motor dentro. Para fixar uma versão, adicione `@` e a versão depois de `qrdx` na URL. Os mesmos caminhos funcionam no unpkg.

</Tab>
<Tab value="With a bundler">

```package-install
qrdx
```

```js title="main.js"
import "qrdx/element/define"; // registers <qrdx-code>
```

Importar `qrdx/element` sozinho não registra nada. Chame `defineQRdxCode` você mesmo para escolher o nome da tag:

```js title="main.js"
import { defineQRdxCode } from "qrdx/element";

defineQRdxCode(); // <qrdx-code>
defineQRdxCode("brand-qr"); // <brand-qr> as well
```

Chamar de novo é seguro e, em um servidor, não faz nada. Ela gera um erro se outro elemento já tiver esse nome.

</Tab>
</Tabs>

### 2. Coloque um código na página [#2-put-a-code-in-the-page]

```html title="index.html"
<qrdx-code
  value="https://example.com/menu"
  size="256"
  margin="4"
  body-pattern="rounded"
  label="QR code for the menu"
></qrdx-code>
```

A página mostra um código de 256 px com módulos arredondados. Edite um atributo no inspetor do navegador e o código é redesenhado.

<Shot id="lib-element-code" />

### 3. Defina opções de objeto por um script [#3-set-object-options-from-a-script]

Gradientes, molduras, logos e as outras opções de objeto são propriedades. Defina-as por um script:

```js title="main.js"
const qr = document.querySelector("qrdx-code");

qr.fgColor = {
  type: "linear",
  angle: 45,
  stops: [
    { color: "#1d4ed8", offset: 0 },
    { color: "#0f172a", offset: 100 },
  ],
};
qr.frame = { style: "banner-bottom", text: "Scan for the menu" };
qr.imageSettings = { src: "/logo.png", width: 40, height: 40, excavate: true };
qr.props = { eyeColor: "#be123c" };
```

O código é redesenhado uma vez, com o gradiente, o banner, o logo e os olhos vermelhos. Sem um script, coloque as opções de objeto no atributo `props`, como JSON:

```html title="index.html"
<qrdx-code
  value="https://example.com"
  props='{"frame": {"style": "banner-bottom", "text": "Scan me"}}'
></qrdx-code>
```

### 4. Exporte [#4-export-it]

```js title="main.js"
qr.toSVGString(); // '<svg xmlns="http://www.w3.org/2000/svg" …'
await qr.toDataURL("png", { size: 1024 }); // "data:image/png;base64,…"
await qr.download({ format: "png", size: 1024, filename: "menu.png" });
```

O `download` salva `menu.png` com 1024 px. As exportações desenham o código a partir de `qr.options`, como fazem `toSVGString` e `downloadQRCode` do `qrdx/core`, sem o `part`, o `role` e o `aria-label` do elemento. `toDataURL` e `download` usam PNG por padrão, no `size` do código. Os formatos são `png`, `jpg`, `webp`, `svg`, `pdf` e `eps`. Sem um valor, eles geram erro (`toSVGString`) ou são rejeitados.

O PDF precisa do pacote opcional `jspdf`. Em uma CDN, mapeie-o com um import map colocado antes do script do módulo:

```html title="index.html"
<script type="importmap">
  { "imports": { "jspdf": "https://cdn.jsdelivr.net/npm/jspdf@4/+esm" } }
</script>
```

## Atributos [#attributes]

| Atributo | O que define |
| --- | --- |
| `value` | O texto ou a URL a codificar. Sem ele, nada é desenhado |
| `size` | Largura e altura em pixels (uma moldura soma a isso) |
| `level` | Correção de erros: `L`, `M`, `Q` ou `H` |
| `fg-color`, `bg-color`, `eye-color`, `dot-color` | Cores sólidas |
| `body-pattern`, `corner-eye-pattern`, `corner-eye-dot-pattern` | Formas dos módulos, dos olhos e dos pontos dos olhos |
| `margin` | Zona de silêncio, em módulos |
| `template-id` | Um modelo integrado |
| `module-scale` | Tamanho de cada módulo, de 0.5 a 1 |
| `auto-level` | Eleva a correção de erros para `H` quando um logo exige |
| `shape` | `square`, `circle` ou `heart` |
| `label` | O que os leitores de tela anunciam (padrão "QR code") |
| `props` | Qualquer outra opção, como JSON |

Números e níveis que não puderem ser lidos são ignorados. [Formas, olhos e molduras](/docs/styles) mostra todos os padrões.

## Propriedades [#properties]

Cada atributo também é uma propriedade, com o nome da opção: `qr.fgColor`, `qr.bodyPattern`, `qr.templateId`. As opções que são objetos existem apenas como propriedades: gradientes e preenchimentos de imagem, `frame`, `imageSettings`, `eyeColors`, `art`, `customTemplate` e `customProps`. O `props` recebe todas as opções de uma vez.

- Um atributo ou uma propriedade nomeada vence a mesma opção em `props`. Entre um atributo e a propriedade correspondente, vale o que foi definido por último. Defina uma propriedade como `undefined` para descartá-la.
- As propriedades não escrevem de volta nos atributos.
- As mudanças são agrupadas. Não importa quantas você faça em sequência, o código é redesenhado uma vez, em uma microtask, e só se a marcação mudou.
- `qr.options` é o que o código usa para ser desenhado, e `qr.svg` é o `<svg>` desenhado.
- As propriedades definidas antes de o elemento ser registrado são aproveitadas quando ele é.

Uma moldura oficial vem do arquivo que fica ao lado do elemento:

```js title="main.js"
import { getOfficialFrame } from "https://cdn.jsdelivr.net/npm/qrdx/dist/frames-official.mjs";

qr.frame = { style: "custom", spec: getOfficialFrame("wifi-card").spec };
```

## Estilo e acessibilidade [#styling-and-accessibility]

O código é desenhado em um shadow root aberto. O CSS da página não alcança seus paths, então uma regra como `svg path { fill: red }` ou `svg { width: 100% }` não consegue quebrar o código. Estilize o `<svg>` por fora com `::part(svg)`:

```css title="styles.css"
qrdx-code::part(svg) {
  border-radius: 12px;
}
```

O elemento é `inline-block`. O `<svg>` mantém o `size`, mas encolhe para caber em um contêiner mais estreito.

O `<svg>` tem `role="img"` e um `aria-label` vindo do atributo `label`, ou "QR code" se não houver. O rótulo nunca recorre ao valor, que pode conter uma senha de Wi-Fi ou dados de contato.

## Renderização no servidor [#server-rendering]

`toQRdxCodeHTML(options)` retorna a marcação do elemento com o código já desenhado em um declarative shadow root. Os navegadores mostram o código antes de qualquer script rodar, e o elemento assume quando é registrado. Ela roda no Node e não precisa de DOM.

```js title="server.js"
import { toQRdxCodeHTML } from "qrdx/element";

const html = toQRdxCodeHTML(
  {
    value: "https://example.com",
    size: 256,
    frame: { style: "banner-bottom", text: "Scan me" },
  },
  { label: "Link to example.com" }
);
// <qrdx-code value="https://example.com" size="256" label="Link to example.com"
//   props="{…}"><template shadowrootmode="open">…</template></qrdx-code>
```

As opções simples viram atributos e o restante vai em `props` como JSON, de modo que o elemento lê de volta as mesmas opções. O `customTemplate` não pode ser escrito como marcação: defina-o como propriedade no navegador. Passe `tagName` se você registrou outro nome.

## React 19 [#react-19]

O React 19 define uma prop como propriedade quando o elemento tem uma, então objetos funcionam como props. Registre o elemento uma vez, antes de renderizar:

```tsx title="components/menu-code.tsx"
import "qrdx/element/define";

export function MenuCode({ url }: { url: string }) {
  return (
    <qrdx-code
      value={url}
      size={256}
      body-pattern="rounded"
      frame={{ style: "banner-bottom", text: "Scan me" }}
      label="Menu"
    />
  );
}
```

No TypeScript, adicione o elemento ao JSX em um arquivo `.d.ts`:

```ts title="qrdx-code.d.ts"
import type { QRdxCodeElement, QRdxCodeJSXProps } from "qrdx/element";

declare module "react" {
  namespace JSX {
    interface IntrinsicElements {
      "qrdx-code": React.DetailedHTMLProps<
        React.HTMLAttributes<QRdxCodeElement>,
        QRdxCodeElement
      > &
        QRdxCodeJSXProps;
    }
  }
}
```

Um `ref` dá acesso ao elemento, para usar `toDataURL` e `download`.

## Vue [#vue]

Avise o compilador do Vue que `qrdx-code` é um custom element:

```js title="vite.config.js"
import vue from "@vitejs/plugin-vue";
import { defineConfig } from "vite";

export default defineConfig({
  plugins: [
    vue({
      template: {
        compilerOptions: { isCustomElement: (tag) => tag === "qrdx-code" },
      },
    }),
  ],
});
```

Depois importe `qrdx/element/define` uma vez, no `main.js`, e vincule as opções nos templates. O Vue define um vínculo como propriedade quando o elemento tem uma:

```vue title="src/App.vue"
<qrdx-code
  :value="url"
  :size="256"
  body-pattern="rounded"
  :frame="{ style: 'banner-bottom', text: 'Scan me' }"
  label="Menu"
/>
```

## Se algo der errado [#if-something-goes-wrong]

- **Nada é desenhado.** O elemento não tem `value`, ou o script que o registra não rodou. Confira o atributo e se o `element-define` está carregado como módulo.
- **Um evento `qrdx-error` é disparado.** O código não pode ser desenhado, por exemplo porque o valor é longo demais para um QR code, ou porque o atributo `props` não é um objeto JSON. O erro está em `event.detail.error`. O elemento remove o código antigo e registra o erro no log, a menos que um listener chame `event.preventDefault()`:

  ```js title="main.js"
  qr.addEventListener("qrdx-error", (event) => {
    event.preventDefault();
    showMessage("That text is too long for a QR code.");
  });
  ```

- **`qrdx: <qrdx-code> is already defined by another element`.** Outro script registrou o mesmo nome de tag. Passe outro nome para `defineQRdxCode`.
- **TypeScript: `Property 'qrdx-code' does not exist on type 'JSX.IntrinsicElements'`.** Adicione a declaração da seção React 19.
