Al termine di questa pagina avrai un QR code personalizzato in un componente Vue 3, renderizzato sul server e idratato senza discrepanze, e un pulsante che lo salva come PNG. `qrdx/vue` include le versioni Vue dei componenti React, `QRCode` e `QRCodeSVG`, più un composable `useQRCode`. Accettano le stesse prop dei componenti React e disegnano lo stesso SVG. L'entry è costruita su `qrdx/core` e non importa `react`.

<NpmStatus package="qrdx" />

## Prima di iniziare [#before-you-start]

- Un progetto con Vue 3.3 o successivo, con Vite o Nuxt. TypeScript controlla le prop dei componenti a partire da Vue 3.4.20.
- Node.js 18 o successivo.

## Realizzalo [#build-it]

### 1. Installa qrdx [#1-install-qrdx]

```package-install
qrdx
```

`vue` è una peer dependency opzionale, quindi viene usato il Vue della tua app.

### 2. Disegna un codice [#2-draw-a-code]

```vue title="src/App.vue"
<script setup lang="ts">
import { QRCode } from "qrdx/vue";
import { ref } from "vue";

const url = ref("https://example.com/menu");
</script>

<template>
  <QRCode
    :value="url"
    :size="256"
    :margin="4"
    body-pattern="rounded"
    :frame="{ style: 'banner-bottom', text: 'Scan for the menu' }"
    aria-label="QR code for the menu"
  />
</template>
```

La pagina mostra un codice da 256 px con moduli arrotondati e un banner sotto. Cambia `url` e il codice viene ridisegnato, con Vue che aggiorna l'`<svg>` sul posto.

<Shot id="lib-framed-menu-code" />

`QRCode` accetta le prop del `QRCode` di React: ogni opzione di `QRProps`, più `logo`, `logoOptions`, `hideLogo` e `scale` per il logo. In un template puoi scriverle in kebab-case (`body-pattern`) o in camelCase. Un flag come `auto-level` o `hide-logo` non richiede alcun valore. `class`, `style`, `aria-label` e altri attributi vanno sull'`<svg>`, oppure sull'`<svg>` esterno della cornice quando c'è una cornice, e lo stesso vale per i listener come `@click`.

### 3. Salvalo come file con useQRCode [#3-save-it-as-a-file-with-useqrcode]

```vue title="src/components/DownloadCode.vue"
<script setup lang="ts">
import { useQRCode } from "qrdx/vue";
import { ref } from "vue";

const url = ref("https://example.com/menu");
const { svg, download } = useQRCode(() => ({
  value: url.value,
  size: 256,
  margin: 4,
  bodyPattern: "rounded",
}));
</script>

<template>
  <div v-html="svg" />
  <button type="button" @click="download({ format: 'png', size: 1024, filename: 'menu.png' })">
    Download PNG
  </button>
</template>
```

Il codice viene mostrato a partire dal suo markup e il pulsante salva `menu.png` a 1024 px. `useQRCode(props)` accetta le prop di `QRCode` come oggetto, ref, oggetto reattivo o getter, e restituisce:

- `svg`: il markup SVG come ref calcolato. Segue le prop e funziona durante il rendering sul server.
- `toDataURL(format, { size, quality })`: il codice come data URL.
- `download({ format, filename, size, quality })`: salva il codice come file.
- `options`: le opzioni con cui viene disegnato il codice, come ref calcolato.

`toDataURL` e `download` usano per impostazione predefinita PNG con il `size` del codice stesso. I formati sono `png`, `jpg`, `webp`, `svg`, `pdf` e `eps`. PNG, JPG e WebP richiedono un browser, mentre PDF richiede il pacchetto opzionale `jspdf`.

## QRCodeSVG e impostazioni immagine grezze [#qrcodesvg-and-raw-image-settings]

`QRCodeSVG` accetta `QRProps`, come il `QRCodeSVG` di React. Un logo va in `imageSettings`, in pixel:

```vue title="src/components/LogoCode.vue"
<script setup lang="ts">
import { QRCodeSVG } from "qrdx/vue";
</script>

<template>
  <QRCodeSVG
    value="https://example.com"
    :size="256"
    level="H"
    :image-settings="{ src: '/logo.png', width: 48, height: 48, excavate: true }"
  />
</template>
```

Preferisci `QRCode` con `logo` e `logoOptions`, a meno che tu non gestisca da solo il layout del logo.

## Rendering sul server e Nuxt [#server-rendering-and-nuxt]

Entrambi i componenti vengono renderizzati con il renderer server di Vue (`vue/server-renderer`), quindi il codice fa parte dell'HTML del server. Il markup non contiene id casuali, quindi il browser lo idrata senza discrepanze.

In Nuxt, usali in qualsiasi pagina o componente. Vengono renderizzati sul server e idratati nel browser. All'interno di `<ClientOnly>` vengono renderizzati solo nel browser.

## Altro da qrdx/core [#more-from-qrdxcore]

`qrdx/vue` riesporta tutto ciò che c'è in `qrdx/core`: `toSVGString`, `downloadQRCode`, `getQRCodeDataUrl`, `getScanScore`, la libreria ufficiale di cornici (`getOfficialFrame`) e il resto. [JavaScript puro](/docs/vanilla-js) li descrive. Per il PNG su un server, usa `getQRAsPNG` da `qrdx/node`.

Il `wrapper` di un template personalizzato si scrive con l'`h` esportato da `qrdx/vue`. Quello è l'`h` del core, non quello di Vue, quindi importa uno dei due con un altro nome quando un file ha bisogno di entrambi:

```ts title="src/labelled-template.ts"
import { h } from "qrdx/vue";

export const Labelled = {
  id: "Labelled",
  name: "Labelled",
  wrapper: (children, props) =>
    h(
      "svg",
      { viewBox: "0 0 300 340", xmlns: "http://www.w3.org/2000/svg" },
      h("g", { transform: "translate(20, 20) scale(0.87)" }, children),
      h("text", { x: "150", y: "325", textAnchor: "middle" }, props?.label)
    ),
};
```

Passalo come `customTemplate`, con le sue prop in `customProps`: `<QRCode value="https://example.com" :custom-template="Labelled" :custom-props="{ label: 'Scan me' }" />`.

## Se qualcosa va storto [#if-something-goes-wrong]

- **`Failed to resolve component: QRCode`.** Il componente non è importato in quel file. Aggiungi `import { QRCode } from "qrdx/vue"` al suo `<script setup>`.
- **Una prop non ha effetto.** L'hai scritta come stringa di attributo dove serve un valore: `size="256"` passa una stringa, `:size="256"` un numero. Le prop oggetto come `frame` e `image-settings` richiedono sempre i due punti.
- **`PDF export needs the optional "jspdf" package`.** Esegui `npm install jspdf` nella tua app.
