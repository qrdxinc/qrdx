इस पेज के अंत तक आपके पास Angular component में एक स्टाइल किया हुआ QR कोड होगा, जो एक signal से जुड़ा होगा, और एक बटन होगा जो उसे SVG के रूप में सेव करता है। `qrdx/angular` एक standalone component है, `<qrdx-qr-code>`, जो React components वाले इंजन पर ही बना है। यह React के `<QRCode>` के props को signal inputs के रूप में लेता है और वही SVG बनाता है। यह `@angular/ssr` के साथ सर्वर पर रेंडर होता है और बिना errors के hydrate होता है।

## शुरू करने से पहले [#before-you-start]

- Angular 20 या उससे नया प्रोजेक्ट, जो Angular CLI से बना हो। Production builds और `ng serve` दोनों काम करते हैं।
- Node.js 18 या उससे नया।

## इसे बनाएँ [#build-it]

### 1. qrdx इंस्टॉल करें [#1-install-qrdx]

```package-install
qrdx
```

`@angular/core`, `qrdx` की एक optional peer dependency है, इसलिए इसे इंस्टॉल करने से Angular उन apps में नहीं जुड़ता जो उसका उपयोग नहीं करते, और आपके app में React भी नहीं जुड़ता।

### 2. कोड बनाएँ [#2-draw-a-code]

`QRCode` इम्पोर्ट करें और उसे अपने component के `imports` में जोड़ें। NgModule की ज़रूरत नहीं है।

```ts title="src/app/app.ts"
import { Component, signal } from "@angular/core";
import { QRCode, type QRCodeProps } from "qrdx/angular";

@Component({
  selector: "app-root",
  imports: [QRCode],
  template: `
    <qrdx-qr-code
      [value]="url()"
      [size]="240"
      [margin]="4"
      level="Q"
      bodyPattern="rounded"
      [fgColor]="fgColor"
      [frame]="{ style: 'banner-bottom', text: 'Scan me' }"
      aria-label="QR code for example.com"
    />
  `,
})
export class App {
  protected readonly url = signal("https://example.com");
  protected readonly fgColor: QRCodeProps["fgColor"] = {
    type: "linear",
    angle: 45,
    stops: [
      { color: "#1d4ed8", offset: 0 },
      { color: "#0f172a", offset: 100 },
    ],
  };
}
```

`ng serve` में 240 px का कोड दिखता है, जिसमें गोल modules, नीले से नेवी रंग का gradient और "Scan me" बैनर है। `url` को किसी दूसरे link पर सेट करें और कोड फिर से बन जाता है। जब किसी बदलाव से markup वही रहता है, तो पेज को छुआ नहीं जाता।

### 3. इसे फ़ाइल के रूप में सेव करें [#3-save-it-as-a-file]

यह component अपने बनाए कोड को डाउनलोड और export कर सकता है, जैसे `qrdx/vanilla`। इसे template reference variable या `viewChild(QRCode)` से पाएँ:

```html title="src/app/app.html"
<qrdx-qr-code #qr value="https://example.com" [size]="256" [margin]="4" />
<button type="button" (click)="qr.download({ format: 'svg', filename: 'qr-code.svg' })">
  Download SVG
</button>
```

बटन क्लिक करने पर `qr-code.svg` सेव होती है।

- `download({ format, size, filename, quality })` फ़ाइल सेव करता है: डिफ़ॉल्ट रूप से PNG, या `"jpg"`, `"webp"`, `"svg"`, `"pdf"` या `"eps"`। PDF के लिए optional `jspdf` पैकेज चाहिए।
- `toDataURL(format, { size, quality })` कोड को data URL के रूप में लौटाता है।
- `markup()` SVG markup है, `options()` वे props हैं जिनसे कोड बना है, और `svg` वह `<svg>` element है।

`qrdx/core` में जो कुछ है वह `qrdx/angular` से भी export होता है, इसलिए `toSVGString`, `downloadQRCode`, `getScanScore` और बाकी सब उसी import से मिलते हैं।

## Inputs [#inputs]

React के `<QRCode>` का हर prop उसी नाम और type के साथ एक input है, और Angular आपके templates compile करते समय आपकी bindings को इनसे जाँचता है। `value` ज़रूरी है।

| Inputs | ये क्या करते हैं |
| --- | --- |
| `value`, `size`, `level`, `margin`, `autoLevel` | कंटेंट, पिक्सल साइज़, error correction, quiet zone, और बड़े लोगो के लिए लेवल बढ़ाना |
| `fgColor`, `bgColor`, `eyeColor`, `dotColor`, `eyeColors` | रंग, gradients और इमेज fills |
| `bodyPattern`, `cornerEyePattern`, `cornerEyeDotPattern`, `moduleScale` | डॉट और आँख के आकार |
| `logo`, `logoOptions`, `hideLogo`, `scale` | बीच में लोगो, जिसका layout `<QRCode>` जैसा है |
| `frame`, `shape`, `art` | call to action वाले फ़्रेम, गोल और दिल के आकार, Logo QR और Image QR |
| `templateId`, `customTemplate`, `customProps` | टेम्पलेट |
| `frameLabelMarkers`, `partMarkers` | editor के लाइव प्रीव्यू के लिए मार्कर |
| `svgStyle` | `<svg>` के लिए inline styles (`QRCode` का `style`) |

`style` को `svgStyle` इसलिए कहा गया है क्योंकि `style` नाम का input element के अपने `style` attribute को हथिया लेता। `<qrdx-qr-code>` पर आप जो attributes लगाते हैं, जैसे `class`, `style` या `aria-label`, वे उसी element पर रहते हैं; `<svg>` उसके अंदर होता है।

आपके component की अपनी styles `<svg>` तक नहीं पहुँचतीं, क्योंकि Angular उन्हें आपके template के elements तक सीमित रखता है। कोड को उसके container में पूरा फैलाने के लिए `svgStyle` का उपयोग करें:

```html title="src/app/app.html"
<qrdx-qr-code value="https://example.com" [svgStyle]="{ width: '100%', height: 'auto' }" />
```

## Server rendering और hydration [#server-rendering-and-hydration]

`@angular/ssr` के साथ, सर्वर के HTML में कोड पहले से होता है, इसलिए app लोड होने से पहले ही दिख जाता है। ब्राउज़र में Angular पेज को hydrate करता है और `<qrdx-qr-code>` element को बनाए रखता है; फिर component अपना कोड दोबारा बनाता है, जो सर्वर वाले जैसा ही होता है। आपको `ngSkipHydration` की ज़रूरत नहीं है।

आउटपुट में कोई random ids नहीं हैं, इसलिए सर्वर और ब्राउज़र एक ही markup बनाते हैं।

## कुछ गड़बड़ हो जाए तो [#if-something-goes-wrong]

- **`NG8001: 'qrdx-qr-code' is not a known element`।** `QRCode` component की `imports` array में नहीं है। चरण 2 की तरह इसे जोड़ें।
- **आपके component में `svg` के लिए CSS rule का कोई असर नहीं होता।** Angular आपकी styles को आपके अपने template तक सीमित रखता है। `svgStyle` input का उपयोग करें, या rule को global stylesheet में रखें।
- **`PDF export needs the optional "jspdf" package`।** app में `npm install jspdf` चलाएँ।
