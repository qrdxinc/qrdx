이 페이지는 라이브러리가 제공하는 모든 모양을 옵션 이름, 그리고 `bodyPattern`, `cornerEyePattern`, `cornerEyeDotPattern`, `frame.style`에 복사해 넣을 값과 함께 보여 줍니다. 코드를 작성하기 전에 원하는 스타일을 고르는 데 활용하세요. 각 타일은 다운로드 파일과 같은 렌더러로 그려지며, 브라우저에서 jsQR로 하나씩 디코딩하므로 **Scans** 배지는 실시간 결과입니다.

모든 값은 패키지에서도 테스트됩니다(`packages/qrdx/tests/catalog-*.test.ts`). 휴대폰 카메라 모델(대비 손실과 모듈 4분의 1 크기의 블러)로 모듈당 4, 6, 9픽셀에서 디코딩하며, 다른 모든 본문, 눈, 중심과 조합하고, 오류 정정 수준 L, M, Q, H에서, 148px와 1024px 크기로, 어두운 배경의 밝은 코드, 브랜드 색상, 중앙 로고를 적용한 경우까지 확인합니다. 일부 조합은 함께 쓰면 인식률이 떨어집니다. [피해야 할 조합](#pairs-to-avoid)을 참고하세요.

## Body patterns [#body-patterns]

데이터 모듈의 모양입니다(`bodyPattern`, 기본값 `circle`). 연결형 스타일(`liquid`, `classy`)은 이웃한 모듈을 하나의 윤곽으로 합칩니다. `random-dots`와 `mosaic`은 모듈마다 달라 보이지만 결정적이므로, 같은 값이면 항상 같은 코드가 그려집니다.

<QrCatalog kind="body" />

## Eye frames [#eye-frames]

세 모서리 마커의 바깥 링입니다(`cornerEyePattern`, 기본값 `gear`). `leaf`, `leaf-reverse`, `drop`, `petal`은 각 눈이 코드의 모서리를 향하도록 회전합니다. 각 타일은 눈과 함께 권장 중심을 보여 줍니다.

<QrCatalog kind="eye" />

## Eye centers [#eye-centers]

각 모서리 마커의 채워진 중심입니다(`cornerEyeDotPattern`, 기본값 `circle`). 사각형 눈 안에 표시됩니다.

<QrCatalog kind="dot" />

## Frames [#frames]

행동 유도 프레임은 코드 주위에 그려지므로 코드와 여백 영역(quiet zone)이 가려지지 않으며, 다운로드되는 이미지는 프레임에 맞게 커집니다. 아래의 기본 제공 프레임은 각각 프레임 사양이며, [공식 및 커뮤니티 프레임](/docs/features/frames)과 같은 엔진으로 그려집니다. 모든 프레임은 `text`(최대 24자), `color`, `textColor`, `fontScale`(0.5~1.5)을 받습니다. `banner-top-bottom`, `circle`, `menu-card`는 `secondaryText`도 표시하며, `gradient-border`는 `color`에서 `secondaryColor`로 이어지는 그라데이션입니다.

<QrCatalog kind="frame" />

```tsx title="components/framed-code.tsx"
import { QRCode } from "qrdx";

export function FramedCode() {
  return (
    <QRCode
      value="https://example.com"
      bodyPattern="liquid"
      cornerEyePattern="leaf"
      cornerEyeDotPattern="leaf"
      frame={{ style: "circle", text: "Scan me", secondaryText: "example.com" }}
    />
  );
}
```

## Pairs to avoid [#pairs-to-avoid]

단독으로는 스캔되는 모양도 몇 가지 조합에서는 패키지의 디코딩 테스트에서 함께 실패합니다. Playground에서는 이런 조합을 함께 선택할 수 없으며, 스캔 점수가 경고합니다(`style-pair`).

- `diamond` 본문과 `square` 눈, `pacman`과 `rounded`, `small-square`와 `square` 또는 `rounded` 눈은 가까이서도 인식되지 않습니다.

`circle` 눈은 테스트에 사용하는 두 디코더(jsQR와 ZXing) 모두에서 읽히지만, 일부 스캐너 앱이 인식하지 못할 수 있어 **주의**로 표시됩니다. 이 조합은 패키지에 `WEAK_BODY_EYES`로 포함되어 있으며, `getStylePairRisk(props)`는 해당 스타일에 대한 경고를 반환합니다.

## Retired shapes [#retired-shapes]

`curly` 눈과 `diamond`, `star`, `banner` 중심은 안정적으로 스캔되지 않아 제거되었습니다. 대부분의 Android 스캐너가 사용하는 디코더인 ZXing은 휴대폰 거리에서 curly 눈과 diamond, star 중심을 인식하지 못하고, jsQR은 선명한 렌더링에서 banner 중심을 모두 인식하지 못합니다. 이 모양으로 저장한 코드는 이전과 똑같이 불러오고 렌더링되며, Image API도 기존 링크를 위해 계속 그려 주지만, 선택기, 프리셋, AI 테마에서는 더 이상 제공하지 않습니다. 이름은 지원 중단된 값(`RETIRED_CORNER_EYE_PATTERNS`, `RETIRED_CORNER_EYE_DOT_PATTERNS`)으로만 남아 있습니다.
