호스팅 랜딩 페이지는 QRdx가 `https://qrdx.dev/p/<slug>` 주소(또는 [사용자 지정 도메인](/docs/custom-domains))에서 대신 제공하는 모바일 페이지입니다. 모든 페이지에는 [동적 QR 코드](/docs/dynamic-qr-codes)가 함께 제공되므로, 코드를 인쇄한 뒤에도 페이지를 계속 수정할 수 있고 모든 스캔을 확인할 수 있습니다. 코드가 연결할 대상이 아직 없거나, 웹사이트보다 휴대폰 크기의 페이지가 더 나을 때 사용하세요. 메뉴, 연락처 카드, 링크 목록, 행사, 제품 상세 정보 등이 그 예입니다.

<Callout type="info" title="요금제">
  무료 요금제에는 "Made with QRdx" 푸터가 표시되는 호스팅 페이지 3개가 포함됩니다. Pro는 푸터와 개수 제한이 없고, Business는 화이트 라벨 페이지와 사용자 지정 CSS를 추가로 제공합니다. 각 페이지는 요금제의 동적 코드도 하나씩 사용합니다. [요금제와 한도](/docs/plans-and-limits)를 참고하세요.
</Callout>

바쁘신가요? 간단한 작업 안내 페이지가 있습니다. [모바일 페이지 만들기](/docs/help/pages-and-forms/create-a-page), [인쇄된 코드가 여는 내용 바꾸기](/docs/help/dynamic-codes/change-the-type).

## 작동 방식 [#how-it-works]

<Diagram id="hosted-page-anatomy" />

페이지는 헤더, 링크, 연락처 카드, 메뉴, 양식 같은 블록을 쌓아 만듭니다. 편집기에서 블록을 배치하고 게시하면 QRdx가 서버에서 페이지를 렌더링하므로, 휴대폰에서 빠르게 열리고 별도의 사이트가 필요 없습니다. 코드의 짧은 링크가 페이지를 열며, [코드 제어](/docs/code-controls)의 모든 기능(비밀번호, 일정, 스캔 제한)을 페이지에 적용할 수 있습니다.

## 페이지 만들기 [#create-a-page]

1. 사이드바에서 **Pages & forms**를 열고 **New page**를 클릭하거나, 코드 목록에서 **New code**를 클릭한 다음 **Website link** 대신 페이지 유형을 선택하세요.
2. {facts.hostedPageTypes}가지 [페이지 유형](#page-types) 중 하나를 고르고 갤러리에서 템플릿을 선택하세요.
3. **Create page**를 클릭하세요. 템플릿의 블록이 담긴 편집기가 열리고, 페이지의 QR 코드를 바로 다운로드할 수 있어요.

<Shot id="page-templates" />

이미 웹사이트를 여는 코드를 인쇄하셨나요? 코드를 열고 **Change type**을 클릭하면 같은 짧은 링크를 유지한 채 페이지로 바꿀 수 있어요.

템플릿에는 페이지가 어떻게 구성되는지 볼 수 있도록 샘플 이름, 가격, 숫자, 사진이 들어 있습니다. 처음 게시하기 전까지 편집기가 이를 직접 만든 내용으로 바꾸라고 알려 드립니다.

## 페이지 유형 [#page-types]

모든 페이지 유형은 시작점일 뿐입니다. 어떤 블록이든 모든 페이지에 추가할 수 있고, 한 유형으로 만든 페이지를 다른 유형처럼 꾸밀 수도 있습니다.

| 페이지 유형 | 용도 | 기본 구성 |
| --- | --- | --- |
| **Link list** | 프로필 링크, 크리에이터, 팟캐스트 | 프로필 헤더, 링크, 소셜 아이콘 |
| **Social media** | 모든 프로필을 코드 하나로 | 프로필 헤더, 네트워크별 한 줄과 내 계정 이름 |
| **Business** | 상점, 미용실, 사무실 | 영업시간, 주소와 지도, 연락처, 행동 유도 버튼 |
| **vCard Plus** | 디지털 명함 | **Save contact**가 있는 연락처 카드 |
| **Menu** | 카페, 레스토랑, 바 | 식이 태그와 알레르기 유발 성분이 있는 메뉴 ([자세히](/docs/forms-and-pages#menu)) |
| **Coupon** | 할인과 무료 증정 | 코드, 바코드 또는 사용 버튼이 있는 쿠폰 ([자세히](/docs/forms-and-pages#coupon)) |
| **Event** | 파티, 컨퍼런스, 웨비나, 결혼식 | 캘린더에 추가 기능이 있는 행사 ([자세히](/docs/forms-and-pages#event)) |
| **App download** | 모든 앱 스토어를 코드 하나로 | 앱 다운로드 ([자세히](/docs/forms-and-pages#app-download)) |
| **Feedback & forms** | 리뷰, NPS 설문, 가입 | 양식, 그리고 피드백 템플릿의 리뷰 링크 ([자세히](/docs/forms-and-pages#forms)) |
| **Product** | 포장, 라벨, 행택 | 성분, 알레르기 유발 성분, 영양 정보, 인증, 관리 방법, GS1 Digital Link ([자세히](/docs/product-pages)) |
| **Appointments** | 미용실, 병원, 튜터 | 서비스와 가격, 예약 요청 양식, 영업시간 |
| **Payments & tips** | 팁 통, 기부, 청구서 | 결제 링크와 복사할 수 있는 계좌 정보 |
| **Property listing** | 매매 또는 임대 주택, 오픈 하우스 | 가격과 정보, 사진, 중개인, 방문 요청 또는 방문자 등록 양식 |
| **Pet ID tag** | 목걸이 태그, 실종 동물 포스터 | 전화 버튼, 반려동물 정보, "찾았어요" 양식 |
| **Medical ID** | 태그, 손목 밴드, 알레르기 카드 | 비상 연락처, 질환, 알레르기, 복용 약 |
| **PDF** | 브로셔, 매뉴얼, 문서 라이브러리 | 읽거나 다운로드할 PDF 또는 여러 파일 |
| **Images** | 갤러리와 포트폴리오 | 사진 갤러리 |
| **MP3 / Audio** | 음악, 팟캐스트, 음성 메시지 | 오디오 플레이어 |
| **Video** | 제품 영상, 클립 | 동영상 |
| **Playlist** | 믹스, 오디오 투어, 오디오북 | 연속 재생되는 여러 트랙 |
| **Custom page** | 그 외 모든 용도 | 빈 페이지 또는 공지 |

<IfAvailable feature="fileStorage" unavailable>

이 배포 환경에는 파일 업로드가 설정되어 있지 않아, 업로드 기반의 다섯 가지 유형(PDF, Images, MP3 / Audio, Video, Playlist)은 선택 화면에서 숨겨집니다. 블록에서 다른 곳에 호스팅된 파일을 링크하는 것은 여전히 가능합니다.

</IfAvailable>

**Appointments**는 예약 요청을 페이지의 [응답](/docs/forms-and-pages#responses)과 알림으로 보내며, 사용 중인 예약 도구로 연결할 수도 있습니다. 가능한 시간을 보여 주는 실시간 캘린더는 제공하지 않으므로, 각 요청은 직접 확인해야 합니다.

**Payments & tips**는 결제를 직접 처리하지 않습니다. 각 버튼은 결제 앱(PayPal, Venmo, Cash App, Revolut, Wise)의 자체 페이지를 열고, 계좌 정보, UPI ID, 지갑 주소에는 복사 버튼이 있습니다.

**Pet ID tag**와 **Medical ID** 페이지는 코드를 스캔하는 누구나 볼 수 있습니다. 반려동물을 발견한 사람이나 응급 상황에서 도움을 줄 사람에게 필요한 정보만 추가하세요.

## 편집 및 게시 [#edit-and-publish]

편집기에는 탭이 세 개 있고 실시간 휴대폰 미리보기가 있습니다. 미리보기에서 블록을 탭하면 해당 블록의 설정으로 이동합니다.

- **Blocks**: **Add block**으로 블록을 추가하고, 드래그(또는 화살표 버튼)로 순서를 바꾸며, 삭제하지 않고 블록을 숨기거나 복제하거나 제거할 수 있어요. 블록마다 고유한 양식이 있으며, 문제(예: `https://`가 없는 링크)는 블록에 표시되고 게시하기 전에 수정해야 해요.
- **Design**: [저장된 QR 테마](/dashboard?to=themes) 중 하나의 색상을 사용하면 페이지가 인쇄된 코드와 어울려요. 미리 준비된 팔레트를 고르거나 각 색상을 직접 설정할 수도 있어요. 글꼴, 모서리 둥글기, 단색·그라데이션·이미지 배경, 선택 사항인 로고를 고를 수 있어요. **Match colors**는 배경색과 강조색을 바탕으로 읽기 좋은 텍스트 색과 카드 색을 만들어 주며, 텍스트 대비가 낮으면 경고가 표시돼요.
- **Settings**: 공유 미리보기 설명과 이미지, **Show in search engines**(기본값은 꺼짐), 그리고 Business의 **Custom CSS**가 있어요.

<Shot id="page-editor" />

**Publish**를 클릭하거나 <kbd>⌘</kbd>/<kbd>Ctrl</kbd> + <kbd>S</kbd>를 눌러 변경 사항을 적용하세요. 게시하기 전에는 방문자에게 아무것도 바뀌지 않으며, 게시하지 않은 수정 내용은 브라우저에 보관되므로 탭을 닫은 뒤에도 복원할 수 있습니다. 게시할 때마다 버전으로 저장됩니다. 편집하는 동안 팀원이 같은 페이지를 게시하면, QRdx는 변경 사항을 덮어쓰는 대신 새로고침하라고 안내합니다.

### vCard Plus와 연락처 저장 [#vcard-plus-and-save-contact]

**연락처 저장**은 vCard 3.0 파일(`.vcf`)을 다운로드하며, 휴대폰의 연락처 앱에서 열 수 있어요. 파일에는 이름, 회사, 직함, 전화번호, 이메일, 웹사이트, 주소, 소개, 페이지의 소셜 프로필, 사진이 들어 있어요. QRdx 저장소에 업로드한 사진은 1MB 이하이면 파일에 포함돼요. 그보다 큰 사진과 다른 사이트에서 링크한 사진은 링크로 포함돼요. QRdx는 다른 사이트의 이미지를 절대 다운로드하지 않기 때문이에요. **공유**를 누르면 휴대폰의 공유 시트가 열리고, 컴퓨터에서는 페이지 링크가 복사돼요. 이 카드를 NFC 카드에도 넣으려면 [NFC 명함](/docs/nfc#nfc-business-cards)을 참고하세요.

## 방문자가 얻는 것 [#what-visitors-get]

- 휴대폰에 맞춰 만든 빠른 서버 렌더링 페이지예요. 페이지에 있는 QRdx 스크립트는 **페이지 활동** 카드에 표시할 조회수와 탭 수를 집계하는 것 하나뿐이며, 제품 분석이나 지원 위젯은 없어요. 직접 추가한 [추적 픽셀](/docs/tracking-and-conversions#tracking-pixels-on-hosted-pages-pro)은 코드에 넣은 경우에만 불러와요.
- **검색 엔진에 표시**를 켜지 않으면 검색 엔진에 노출되지 않아요.
- 채팅 앱과 소셜 네트워크용 공유 미리보기(제목, 설명, 이미지)를 제공해요. 비밀번호로 보호된 코드는 미리보기에 페이지 정보를 절대 보여 주지 않아요.
- 화이트 라벨 페이지를 포함한 모든 페이지에 작은 **악용 신고** 링크가 있어요.

[코드 제어](/docs/code-controls)의 비밀번호 보호, 시작일과 종료일, 스캔 한도, 일시 중지는 페이지와 해당 페이지의 **연락처 저장** 파일에도 적용돼요. 누군가 페이지 링크를 직접 열 때도 마찬가지예요.

## 한도와 요금제 [#limits-and-plans]

| | 무료 | Pro | Business |
| --- | --- | --- | --- |
| 호스팅 페이지 | 3 | 무제한 | 무제한 |
| "Made with QRdx" 푸터 | 표시됨 | 제거됨 | 제거됨 |
| 화이트 라벨 (내 로고를 브라우저 아이콘으로 사용, QRdx 브랜딩 없음) | 아니요 | 아니요 | 예 |
| 사용자 지정 CSS | 아니요 | 아니요 | 예 |

한도는 새 페이지를 만드는 것만 막아요. 이미 가진 페이지는 다운그레이드 후에도 모든 요금제에서 계속 작동해요. Business에서 다운그레이드하면 페이지의 사용자 지정 CSS가 더 이상 적용되지 않으며, 페이지의 **설정**에서 CSS를 삭제할 때까지 편집기에서 해당 페이지를 다시 게시할 수 없어요.

### 사용자 지정 CSS [#custom-css]

Business에서는 **설정** → **사용자 지정 CSS**에 일반 CSS를 작성할 수 있어요. 규칙은 페이지 안에서만 적용돼요. 모든 선택자는 페이지 콘텐츠로 범위가 한정되며, 각 블록은 `.lp-block-<type>`으로 지정할 수 있어요. 예를 들면 `.lp-block-links a` 또는 `.lp-block-contact h1`이에요. 안전을 위해 CSS는 파일을 불러올 수 없고(`url()`, `@import`, `@font-face`), 백슬래시 이스케이프를 사용할 수 없으며, `@media`, `@supports`, `@container`, `@keyframes` at-rule만 지원해요.

## 개발자용 [#for-developers]

[REST API](/docs/developers/api/update-code)에서 코드의 `kind`는 `redirect` 또는 `page`이며, `PATCH /v1/codes/{id}`는 **유형 변경**과 같은 방식으로 둘 사이를 전환해요. 페이지 자체는 편집기에서 만들며, API로는 블록을 편집할 수 없어요.
