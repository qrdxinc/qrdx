इस पेज के अंत तक आपके पास ये सब होंगे: Server Component से रेंडर किया गया QR कोड (बिना client JavaScript के), route param से बना कोड, इनपुट से जुड़ा लाइव कोड, आपके लोगो वाला कोड, और SVG सेव करने वाला बटन। `QRCodeSVG` और `QRCode` में सिर्फ़ client वाले hooks इस्तेमाल नहीं होते, इसलिए Server Component कोड को सीधे पेज के HTML में रेंडर कर देता है। Client Component की ज़रूरत तभी पड़ती है जब वैल्यू ब्राउज़र में बदलती हो या फ़ाइल सेव करनी हो।

<NpmStatus package="qrdx" />

## शुरू करने से पहले [#before-you-start]

- App Router पर चलने वाला Next.js प्रोजेक्ट। उदाहरणों में App Router के async `params` इस्तेमाल हुए हैं, जैसे Next.js 15 और 16 में।
- React 18 या नया वर्शन, जो App Router में पहले से ज़रूरी है।

## बनाएँ [#build-it]

### 1. qrdx इंस्टॉल करें [#1-install-qrdx]

```package-install
qrdx
```

`react` और `react-dom` peer dependencies हैं, इसलिए आपके app के अपने वर्शन इस्तेमाल होते हैं।

### 2. Server Component में कोड रेंडर करें [#2-render-a-code-in-a-server-component]

```tsx title="app/page.tsx"
import { QRCodeSVG } from "qrdx";

export default function Page() {
  return (
    <QRCodeSVG
      value="https://example.com"
      size={256}
      margin={4}
      role="img"
      aria-label="QR code for example.com"
    />
  );
}
```

पेज खोलें। `<svg>` उस HTML का हिस्सा है जो सर्वर भेजता है, इसलिए यह किसी भी JavaScript के लोड होने से पहले दिख जाता है, स्टैटिक पेज इसे build के समय एक बार रेंडर करता है, और screen readers को `aria-label` मिलता है।

<Shot id="lib-nextjs-server-code" />

`margin` कोड के चारों ओर की quiet zone है, modules में। इसकी डिफ़ॉल्ट वैल्यू 0 है, जो अपनी padding वाले कार्ड के अंदर रखे कोड के लिए ठीक है। QR स्टैंडर्ड 4 माँगता है, जो व्यस्त या गहरे बैकग्राउंड पर सुरक्षित चुनाव है।

### 3. Route param से वैल्यू बनाएँ [#3-build-the-value-from-a-route-param]

```tsx title="app/tickets/[id]/page.tsx"
import { QRCodeSVG } from "qrdx";

export default async function TicketPage({
  params,
}: {
  params: Promise<{ id: string }>;
}) {
  const { id } = await params;
  const url = `https://example.com/check-in/${encodeURIComponent(id)}`;
  return <QRCodeSVG value={url} size={200} margin={4} level="H" />;
}
```

`/tickets/A-12` खोलें और कोड `https://example.com/check-in/A-12` खोलेगा। Next.js `params` को promise के रूप में देता है, इसलिए पेज `async` है। यूज़र या डेटाबेस से आने वाली किसी भी चीज़ को URL में डालने से पहले encode करें। लेवल `H` कोड के 30% तक हिस्से को खराब होने देता है, जो मुड़ने या खरोंचे जाने वाले बैज पर मदद करता है।

### 4. Client Component में इनपुट को फ़ॉलो करें [#4-follow-an-input-in-a-client-component]

```tsx title="components/live-qr-code.tsx"
"use client";

import { QRCodeSVG } from "qrdx";
import { useState } from "react";

export function LiveQrCode() {
  const [value, setValue] = useState("https://example.com");
  return (
    <div>
      <input
        aria-label="Text or link to encode"
        value={value}
        onChange={(event) => setValue(event.target.value)}
      />
      {value ? <QRCodeSVG value={value} size={200} margin={4} /> : null}
    </div>
  );
}
```

हर keystroke पर कोड दोबारा बनता है, और पहली वैल्यू फिर भी सर्वर पर रेंडर होती है। Server Component पेज इस component को जैसा है वैसा import कर सकता है।

`QRCodeCanvas` भी एक Client Component है (यह `"use client"` के साथ आता है), लेकिन यह सिर्फ़ सादे चौकोर modules बनाता है। स्टाइल वाले कोड के लिए `QRCodeSVG` या `QRCode` इस्तेमाल करें।

### 5. लोगो जोड़ें [#5-add-a-logo]

```tsx title="components/logo-qr-code.tsx"
import { QRCode } from "qrdx";

export function LogoQrCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      margin={4}
      level="H"
      logo="/logo.png"
    />
  );
}
```

`/logo.png` आपके प्रोजेक्ट के `public` फ़ोल्डर की एक फ़ाइल है। लोगो कोड की चौड़ाई के एक चौथाई आकार में बनता है और उसके पीछे के modules साफ़ कर दिए जाते हैं, इसलिए कोड स्कैन होने के लिए error correction पर निर्भर करता है: इसीलिए `level` `H` है। `QRCode` ऐसे लोगो को भी छोटा कर देता है जो कोड के सुधार करने की क्षमता से बड़ा हो।

`logo` में आपके app का path, URL या data URL दिया जा सकता है। डाउनलोड के लिए data URL सबसे सुरक्षित है, क्योंकि रिमोट इमेज को ब्राउज़र फ़ाइल में कॉपी करे, इससे पहले उसे CORS headers चाहिए। `logoOptions` लोगो का आकार, खाली जगह, स्थिति और crop तय करता है; देखें [कोड में लोगो जोड़ें](/docs/features/logos)।

### 6. SVG के रूप में डाउनलोड करें [#6-download-as-svg]

```tsx title="components/download-svg-button.tsx"
"use client";

import { downloadQRCode } from "qrdx";

export function DownloadSvgButton({ value }: { value: string }) {
  return (
    <button
      type="button"
      onClick={() =>
        downloadQRCode(
          { value, level: "Q", margin: 4 },
          {
            format: "svg",
            size: { width: 1024, height: 1024 },
            filename: "qr-code.svg",
          },
        )
      }
    >
      Download SVG
    </button>
  );
}
```

बटन क्लिक करने पर `qr-code.svg` सेव होती है, जो 1024 px की वेक्टर फ़ाइल है। `downloadQRCode` को ब्राउज़र के DOM की ज़रूरत है, इसलिए बटन एक Client Component है। Server Component पेज फिर भी इसे रेंडर कर सकता है और वैल्यू को prop के रूप में दे सकता है। दूसरी फ़ाइलों के लिए `format` को `png`, `jpg`, `webp`, `eps` या `pdf` पर सेट करें (PDF के लिए वैकल्पिक `jspdf` पैकेज चाहिए)। [Export और डाउनलोड](/docs/features/downloads) में सभी विकल्प दिए हैं।

## जब आपको इमेज URL चाहिए [#when-you-need-an-image-url]

ईमेल, Open Graph इमेज, Markdown फ़ाइलें और दूसरी जगहें जहाँ React नहीं चल सकता, वहाँ component की जगह इमेज URL चाहिए। [QR code इमेज API](/docs/developers/image-api) बिना key के एक देती है:

```html title="email.html"
<img src="https://api.qrdx.dev/v1/qr?data=https://example.com&format=png" width="256" height="256" alt="QR code for example.com" />
```

[shadcn/ui registry](/docs/developers/shadcn) components को आपके प्रोजेक्ट में इंस्टॉल करती है: [डाउनलोड बटन वाला QR कोड](/docs/components/qr-code), एक कार्ड, share dialog, जनरेटर, स्कैनर, और Wi-Fi व कॉन्टैक्ट कोड।

## कुछ गड़बड़ हो जाए तो [#if-something-goes-wrong]

- **`useRef only works in Client Components` (या `useState` के लिए यही मैसेज)।** आपने Server Component से `QRCodeCanvas` या hooks वाला कोई component रेंडर किया है। उस फ़ाइल के ऊपर `"use client"` जोड़ें, या इसकी जगह `QRCodeSVG` रेंडर करें।
- **लोगो पेज पर दिखता है पर डाउनलोड की गई फ़ाइल में नहीं।** इमेज किसी दूसरे origin से आ रही है और उसमें CORS headers नहीं हैं। उसे `public` से सर्व करें, या data URL दें।
- **`PDF export needs the optional "jspdf" package`।** app में `npm install jspdf` चलाएँ। बाकी फ़ॉर्मैट के लिए कुछ अतिरिक्त नहीं चाहिए।
