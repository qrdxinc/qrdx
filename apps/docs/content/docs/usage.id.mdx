`QRCode` adalah komponen yang sebaiknya Anda pilih: komponen ini menerima semua opsi gaya dan prop `logo` yang sederhana, serta dirender di server. Halaman ini membahas prop yang paling sering Anda atur. Untuk semua prop, lihat [referensi API pustaka](/docs/api-reference).

<NpmStatus package="qrdx" />

## Pilih komponen [#choose-a-component]

| Komponen | Yang digambar | Gunakan saat |
| --- | --- | --- |
| `QRCode` | Sebuah `<svg>` dengan semua opsi gaya, ditambah `logo`, `logoOptions`, `hideLogo`, dan `scale`. Tidak menerima atribut lain | Hampir selalu |
| `QRCodeSVG` | `<svg>` yang sama, dengan logo diberikan sebagai `imageSettings` mentah dalam piksel. Prop lain apa pun (`aria-label`, `className`, `role`) dipasang pada `<svg>` | Anda perlu atribut pada `<svg>`, Anda menata logo sendiri, atau Anda memindahkan kode dari perender lain |
| `QRCodeCanvas` | Sebuah `<canvas>` dengan modul persegi polos dan warna solid | Anda memerlukan elemen canvas. Pola, warna mata, gradien, dan templat diabaikan |

`QRCode` dan `QRCodeSVG` tidak memakai hook khusus browser, sehingga keduanya dirender di React Server Components dan di HTML statis. `QRCodeCanvas` dikirim dengan `"use client"`.

```tsx title="components/menu-code.tsx"
import { QRCode } from "qrdx";

export function MenuCode() {
  return (
    <div role="img" aria-label="QR code for the menu">
      <QRCode value="https://example.com/menu" size={256} margin={4} />
    </div>
  );
}
```

`value` dienkode persis seperti yang Anda berikan, sehingga payload Wi-Fi, vCard, `mailto:`, atau teks biasa semuanya dapat digunakan. `QRCode` hanya menerima prop milik kode itu sendiri dan `style`, tidak ada yang lain: beri nama yang dapat diakses dengan membungkusnya, seperti di atas. `QRCodeSVG` memasang `aria-label`, `className`, `role`, dan atribut lain pada `<svg>` itu sendiri.

## Ukuran dan zona tenang [#size-and-quiet-zone]

- `size` adalah lebar dan tinggi dalam piksel (bawaan 128). Di bawah sekitar 128 px, kode yang padat sulit dipindai dari layar.
- `margin` adalah zona tenang di sekeliling kode, dalam modul (bawaan 0). Standar QR meminta 4. Atur nilai ini saat kode berada di atas foto, pola, atau halaman gelap; kode di dalam kartu putih dengan padding sendiri dapat tetap memakai 0.
- `scale` mengalikan `size` pada `QRCode`.

Bingkai atau templat mengubah ukuran keluaran. Lihat [Bingkai atau templat](#frame-or-template).

## Warna [#colors]

```tsx title="components/brand-code.tsx"
import { QRCode } from "qrdx";

export function BrandCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      fgColor="#1d4ed8"
      bgColor="#f8fafc"
      eyeColor="#0f172a"
      dotColor="#1d4ed8"
    />
  );
}
```

- `fgColor` mewarnai modul data, `bgColor` latar belakang, `eyeColor` ketiga mata sudut, dan `dotColor` titik di dalam setiap mata. Warna mata secara bawaan mengikuti `fgColor`.
- Masing-masing menerima warna CSS apa pun (`#1d4ed8`, `rgb(29 78 216)`, warna bernama), atau objek gradien. [Atur warna dan gradien](/docs/features/colors-gradients) membahas gradien, warna transparan, dan isian gambar.
- Jaga agar modul lebih gelap daripada latar belakang. Pemindai membaca gelap di atas terang; kode terang di latar gelap berfungsi di sebagian besar kamera ponsel, tetapi tidak di beberapa aplikasi lama.

## Bentuk [#shapes]

```tsx title="components/rounded-code.tsx"
import { QRCode } from "qrdx";

export function RoundedCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      bodyPattern="rounded"
      cornerEyePattern="extra-rounded"
      cornerEyeDotPattern="rounded"
    />
  );
}
```

- `bodyPattern` membentuk modul data (bawaan `circle`). Tersedia {facts.bodyPatterns} pilihan.
- `cornerEyePattern` membentuk ketiga mata sudut (bawaan `gear`), salah satu dari {facts.eyeShapes}.
- `cornerEyeDotPattern` membentuk titik di dalam setiap mata (bawaan `circle`), salah satu dari {facts.eyeCentres}.

[Bentuk, mata, dan bingkai](/docs/styles) menggambar setiap nilai secara langsung. [Pilih bentuk modul dan mata](/docs/features/patterns) menjelaskan skala modul, kode berbentuk, dan beberapa pasangan yang sulit dipindai bila digabungkan.

## Logo [#logo]

```tsx title="components/logo-code.tsx"
import { QRCode } from "qrdx";

export function LogoCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      level="H"
      logo="/logo.png"
      logoOptions={{ size: 0.2, padding: 1 }}
    />
  );
}
```

`logo` menerima path di aplikasi Anda, URL, atau data URL. Modul di belakangnya dihapus, sehingga kode mengandalkan koreksi kesalahan agar dapat dipindai: gunakan `level="H"`. `logoOptions` mengatur lebar logo sebagai bagian dari kode (0,1 sampai 0,3, bawaan 0,25), ruang kosongnya dalam modul, posisinya, dan pemangkasannya. Komponen tidak pernah menggambar logo yang lebih besar dari yang dapat diperbaiki oleh kode. [Tambahkan logo lewat kode](/docs/features/logos) memuat detailnya.

## Bingkai atau templat [#frame-or-template]

```tsx title="components/framed-code.tsx"
import { QRCode } from "qrdx";

export function FramedCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      frame={{ style: "banner-bottom", text: "Scan me", color: "#0f172a" }}
    />
  );
}
```

- `frame` menggambar bingkai ajakan bertindak di sekeliling kode. Kode tetap selebar `size` dan keluaran membesar mengikuti bingkai. Tersedia {facts.frameStyles} gaya bawaan, ditambah pustaka bingkai resmi dan spesifikasi bingkai Anda sendiri. Lihat [Bingkai, skor pemindaian, dan file cetak](/docs/features/frames).
- `templateId` menggambar templat seperti `Arrow` atau `StandardBox` sebagai gantinya. Templat menggambar seluruh karya seninya pada `size`, dengan kode yang lebih kecil di dalamnya. Lihat [Gunakan templat bingkai](/docs/features/templates).

Jika keduanya diatur, bingkai digambar di sekeliling karya seni templat.

## Koreksi kesalahan [#error-correction]

| `level` | Dapat rusak | Gunakan untuk |
| --- | --- | --- |
| `L` | sekitar 7% | Layar bersih, tautan pendek, kode terkecil |
| `M` | sekitar 15% | Payload panjang seperti vCard, saat kode yang lebih kecil lebih penting |
| `Q` | sekitar 25% | Bawaan. Penggunaan umum |
| `H` | sekitar 30% | Logo, seni, cetakan yang bisa tergores atau terlipat |

Level yang lebih tinggi menambah modul, sehingga kode menjadi lebih padat pada ukuran yang sama. `autoLevel` menaikkan level ke `H` secara otomatis saat logo menutupi lebih dari 7% kode; opsi ini nonaktif secara bawaan agar kode yang sudah ada tetap tampil sama.
