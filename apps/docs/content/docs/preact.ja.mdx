このページを終えると、Preact コンポーネント内にスタイル付きQRコードが表示され、PNG として保存するボタンも使えるようになります。`qrdx/preact` には、React ライブラリの2つの SVG コンポーネント `QRCodeSVG` と `QRCode` が Preact 向けに用意されています。Preact 自身の `h` で描画するため `preact/compat` も `react` も不要で、React コンポーネントと同じ SVG を描画します。

<NpmStatus package="qrdx" />

## 始める前に [#before-you-start]

- Preact 10 以降のプロジェクト（Vite などのバンドラー）。
- Node.js 18 以降。

## 作り方 [#build-it]

### 1. qrdx をインストールする [#1-install-qrdx]

```package-install
qrdx
```

`preact` は `qrdx` のオプションのピア依存関係です。アプリにはすでに入っているはずです。

### 2. コードを描画する [#2-draw-a-code]

```tsx title="src/components/menu-code.tsx"
import { QRCodeSVG } from "qrdx/preact";

export function MenuCode() {
  return (
    <QRCodeSVG
      value="https://example.com/menu"
      size={256}
      margin={4}
      bodyPattern="rounded"
      frame={{ style: "banner-bottom", text: "Scan me" }}
      aria-label="QR code for the menu"
    />
  );
}
```

ページには、角丸のモジュールで描かれた 256 px のコードと、その下に「Scan me」のバナーが表示されます。

<Shot id="lib-preact-code" />

`QRCodeSVG` は、React の `QRCodeSVG` が受け取るすべてのオプションを受け取ります。パターン、色とグラデーション、ロゴ（`imageSettings`）、フレーム、シェイプ、テンプレート、アートが使えます。`class`、`style`、`aria-label` などの属性は `<svg>` に付きます。フレームがある場合は、フレームの外側の `<svg>` に付きます。

`QRCode` は、React の `QRCode` にあるロゴ用のショートカットとして `logo`、`logoOptions`、`hideLogo`、`scale` を追加します。受け取るのはコードの props と `style` だけです。`class` や `aria-label` は周囲の要素に付けるか、`QRCodeSVG` を使ってください。

```tsx title="src/components/logo-code.tsx"
import { QRCode } from "qrdx/preact";

export function LogoCode() {
  return <QRCode value="https://example.com" size={256} logo="/logo.png" level="H" />;
}
```

どちらのコンポーネントも、prop が変わると再描画し、変わらなければ処理を省きます。props に含まれるイベントハンドラーは、React と同様に `<svg>` には付きません。コードを囲む要素に付けてください。

### 3. ファイルとして保存する [#3-save-it-as-a-file]

コンポーネントはコードを描画するだけです。ダウンロード、`toSVGString`、スキャンスコアなどの関数は `qrdx/core` から使います。これはコンポーネントがすでに使っているエンジンなので、二重にバンドルされることはありません。

```tsx title="src/components/downloadable-code.tsx"
import { downloadQRCode } from "qrdx/core";
import { QRCodeSVG } from "qrdx/preact";

const options = { value: "https://example.com", size: 256, margin: 4 };

export function DownloadableCode() {
  return (
    <>
      <QRCodeSVG {...options} />
      <button
        type="button"
        onClick={() =>
          downloadQRCode(options, {
            format: "png",
            size: { width: 1024, height: 1024 },
            filename: "qr-code.png",
          })
        }
      >
        Download PNG
      </button>
    </>
  );
}
```

ボタンをクリックすると、1024 px の `qr-code.png` が保存されます。上のようにオプションを1つのオブジェクトにまとめておくと、保存されるファイルが画面上のコードと一致します。`qrdx/core` の詳細は [Vanilla JavaScript](/docs/vanilla-js) をご覧ください。

## サーバーレンダリング [#server-rendering]

`preact-render-to-string` の `renderToString` は、`qrdx/core` の `toSVGString` と同じ SVG を出力します。違いはエスケープだけです。テキスト中の `>` と `'` を、Preact はそのまま出力し、core は `&gt;` と `&#x27;` として出力します。ブラウザーはどちらも同じように解釈します。

`hydrate` はサーバーの `<svg>` を保持し、再描画しません。マークアップにランダムな ID は含まれないため、サーバーとブラウザーは常に一致します。

## preact/compat を使う場合 [#with-preactcompat]

アプリですでに `react` を `preact/compat` のエイリアスにしている場合は、`qrdx` の React コンポーネントも使えます：`import { QRCodeSVG } from "qrdx"`。`qrdx/preact` はエイリアスなしで同じコードを描画するため、Preact アプリに `qrdx` を追加するときはこちらをおすすめします。

## うまくいかない場合 [#if-something-goes-wrong]

- **`Failed to resolve import "react"`。** `preact/compat` のないアプリで、`qrdx/preact` ではなく `qrdx` からインポートしています。インポート元を変更してください。
- **コンポーネントに付けたクリックハンドラーが動作しない。** ハンドラーは `<svg>` から取り除かれます。コードを `<button>` または `<div>` で囲み、そこにハンドラーを付けてください。
- **`PDF export needs the optional "jspdf" package`。** アプリで `npm install jspdf` を実行してください。
