À la fin de cette page, vous aurez un QR code rendu par un Server Component sans JavaScript côté client, un code construit à partir d'un paramètre de route, un code en direct lié à un champ de saisie, un code avec votre logo et un bouton qui enregistre un SVG. `QRCodeSVG` et `QRCode` n'utilisent aucun hook réservé au client : un Server Component rend donc le code directement dans le HTML de la page. Vous n'avez besoin d'un Client Component que lorsque la valeur change dans le navigateur ou pour enregistrer un fichier.

<NpmStatus package="qrdx" />

## Avant de commencer [#before-you-start]

- Un projet Next.js utilisant l'App Router. Les exemples utilisent le `params` asynchrone de l'App Router, comme dans Next.js 15 et 16.
- React 18 ou une version plus récente, ce que l'App Router exige déjà.

## Mise en place [#build-it]

### 1. Installer qrdx [#1-install-qrdx]

```package-install
qrdx
```

`react` et `react-dom` sont des dépendances peer : les versions de votre application sont donc utilisées.

### 2. Afficher un code dans un Server Component [#2-render-a-code-in-a-server-component]

```tsx title="app/page.tsx"
import { QRCodeSVG } from "qrdx";

export default function Page() {
  return (
    <QRCodeSVG
      value="https://example.com"
      size={256}
      margin={4}
      role="img"
      aria-label="QR code for example.com"
    />
  );
}
```

Ouvrez la page. Le `<svg>` fait partie du HTML envoyé par le serveur : il s'affiche donc avant le chargement de tout JavaScript, une page statique le rend une seule fois au moment du build, et les lecteurs d'écran disposent de l'`aria-label`.

<Shot id="lib-nextjs-server-code" />

`margin` est la zone de silence autour du code, en modules. Elle vaut 0 par défaut, ce qui convient à un code placé dans une carte avec son propre remplissage. La norme QR demande 4, le choix le plus sûr sur un fond chargé ou sombre.

### 3. Construire la valeur à partir d'un paramètre de route [#3-build-the-value-from-a-route-param]

```tsx title="app/tickets/[id]/page.tsx"
import { QRCodeSVG } from "qrdx";

export default async function TicketPage({
  params,
}: {
  params: Promise<{ id: string }>;
}) {
  const { id } = await params;
  const url = `https://example.com/check-in/${encodeURIComponent(id)}`;
  return <QRCodeSVG value={url} size={200} margin={4} level="H" />;
}
```

Visitez `/tickets/A-12` et le code ouvre `https://example.com/check-in/A-12`. Next.js transmet `params` sous forme de promesse, la page est donc `async`. Encodez tout ce qui provient d'un utilisateur ou d'une base de données avant de l'insérer dans une URL. Le niveau `H` tolère jusqu'à 30 % de code endommagé, ce qui aide sur un badge plié ou rayé.

### 4. Suivre un champ de saisie dans un Client Component [#4-follow-an-input-in-a-client-component]

```tsx title="components/live-qr-code.tsx"
"use client";

import { QRCodeSVG } from "qrdx";
import { useState } from "react";

export function LiveQrCode() {
  const [value, setValue] = useState("https://example.com");
  return (
    <div>
      <input
        aria-label="Text or link to encode"
        value={value}
        onChange={(event) => setValue(event.target.value)}
      />
      {value ? <QRCodeSVG value={value} size={200} margin={4} /> : null}
    </div>
  );
}
```

Le code est redessiné à chaque frappe, et la première valeur est toujours rendue côté serveur. Une page Server Component peut importer ce composant tel quel.

`QRCodeCanvas` est lui aussi un Client Component (il est fourni avec `"use client"`), mais il ne dessine que des modules carrés simples. Utilisez `QRCodeSVG` ou `QRCode` pour des codes stylisés.

### 5. Ajouter un logo [#5-add-a-logo]

```tsx title="components/logo-qr-code.tsx"
import { QRCode } from "qrdx";

export function LogoQrCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      margin={4}
      level="H"
      logo="/logo.png"
    />
  );
}
```

`/logo.png` est un fichier du dossier `public` de votre projet. Le logo est dessiné au quart de la largeur du code et les modules situés derrière sont effacés : le code s'appuie donc sur la correction d'erreur pour être scanné, c'est pourquoi `level` vaut `H`. `QRCode` réduit aussi un logo trop grand pour que le code puisse le compenser.

`logo` accepte un chemin dans votre application, une URL ou une URL de données (data URL). Pour les téléchargements, une data URL est le choix le plus sûr, car une image distante nécessite des en-têtes CORS avant que le navigateur puisse la copier dans le fichier. `logoOptions` définit la taille, l'espace libre, la position et le recadrage du logo ; voir [Ajouter un logo dans le code](/docs/features/logos).

### 6. Télécharger en SVG [#6-download-as-svg]

```tsx title="components/download-svg-button.tsx"
"use client";

import { downloadQRCode } from "qrdx";

export function DownloadSvgButton({ value }: { value: string }) {
  return (
    <button
      type="button"
      onClick={() =>
        downloadQRCode(
          { value, level: "Q", margin: 4 },
          {
            format: "svg",
            size: { width: 1024, height: 1024 },
            filename: "qr-code.svg",
          },
        )
      }
    >
      Download SVG
    </button>
  );
}
```

Un clic sur le bouton enregistre `qr-code.svg`, un fichier vectoriel de 1024 px. `downloadQRCode` a besoin du DOM du navigateur : le bouton est donc un Client Component. Une page Server Component peut tout de même l'afficher et lui transmettre la valeur en prop. Pour d'autres fichiers, définissez `format` sur `png`, `jpg`, `webp`, `eps` ou `pdf` (le PDF nécessite le paquet optionnel `jspdf`). [Export et téléchargement](/docs/features/downloads) détaille toutes les options.

## Quand il vous faut une URL d'image [#when-you-need-an-image-url]

Les e-mails, les images Open Graph, les fichiers Markdown et les autres endroits qui ne peuvent pas exécuter React ont besoin d'une URL d'image plutôt que d'un composant. L'[API d'image de QR code](/docs/developers/image-api) en renvoie une sans clé :

```html title="email.html"
<img src="https://api.qrdx.dev/v1/qr?data=https://example.com&format=png" width="256" height="256" alt="QR code for example.com" />
```

## Composants prêts à l'emploi [#ready-made-components]

Le [registre shadcn/ui](/docs/developers/shadcn) installe des composants dans votre projet : un [QR code avec boutons de téléchargement](/docs/components/qr-code), une carte, une boîte de dialogue de partage, un générateur, un scanner, et des codes Wi-Fi et de contact.

```bash title="Terminal"
npx shadcn@latest add https://qrdx.dev/r/qr-code.json
```

## En cas de problème [#if-something-goes-wrong]

- **`useRef only works in Client Components` (ou la même erreur pour `useState`).** Vous avez rendu `QRCodeCanvas`, ou un composant utilisant des hooks, depuis un Server Component. Ajoutez `"use client"` en haut de ce fichier, ou utilisez plutôt `QRCodeSVG`.
- **Le logo s'affiche sur la page mais pas dans le fichier téléchargé.** L'image provient d'une autre origine sans en-têtes CORS. Servez-la depuis `public`, ou transmettez une data URL.
- **`PDF export needs the optional "jspdf" package`.** Exécutez `npm install jspdf` dans l'application. Les autres formats n'ont besoin de rien de plus.
