Cette page répertorie ce qu'exporte `qrdx`, par point d'entrée et par tâche, avec le type et la valeur par défaut de chaque prop. Les pages de fonctionnalités expliquent comment les utiliser ; celle-ci sert à retrouver un nom.

## Points d'entrée [#entry-points]

| Importer depuis | Contenu | Prérequis |
| --- | --- | --- |
| `qrdx` | Les composants React (`QRCode`, `QRCodeSVG`, `QRCodeCanvas`, `getQRAsSVG`) et tout le contenu de `qrdx/core` | `react`, `react-dom` |
| `qrdx/core` | Tout le moteur sans React : balisage, téléchargements, fichiers d'impression, score de scan, cadres, modèles, art et types | Aucun |
| `qrdx/vanilla` | `createQRCode`, ainsi que `qrdx/core` | Un DOM |
| `qrdx/element` | L'élément personnalisé `<qrdx-code>` : `QRdxCodeElement`, `defineQRdxCode`, `toQRdxCodeHTML` | Un DOM pour dessiner ; rien pour générer le balisage |
| `qrdx/element/define` | Enregistre `<qrdx-code>` à l'import | Un DOM |
| `qrdx/node` | `getQRAsPNG` | `@resvg/resvg-js` ou `sharp` |
| `qrdx/vue` | `QRCode`, `QRCodeSVG`, `useQRCode`, ainsi que `qrdx/core` | `vue` 3.3 ou version ultérieure |
| `qrdx/preact` | `QRCode`, `QRCodeSVG` | `preact` 10 ou version ultérieure |
| `qrdx/solid` | `QRCode`, `QRCodeSVG` | `solid-js` 1.8 ou version ultérieure |
| `qrdx/angular` | Le composant `QRCode` (`<qrdx-qr-code>`), ainsi que `qrdx/core` | `@angular/core` 20 ou version ultérieure |
| `qrdx/types` | Tous les types, listes d'options et schémas zod, sans le moteur de rendu | Aucun |

Chaque package de framework est une peer dependency facultative : installer `qrdx` n'en ajoute jamais un que vous n'utilisez pas. `jspdf` est lui aussi facultatif, pour le PDF.

## Composants [#components]

### QRCode [#qrcode]

Le composant adapté à la plupart des usages. `QRProps` plus une API de logo simple, rendu sous forme de `<svg>`. Il n'utilise aucun hook réservé au navigateur, il peut donc être rendu dans les React Server Components.

```tsx title="components/example.tsx"
import { QRCode } from "qrdx";

<QRCode value="https://example.com" size={256} margin={4} level="H" logo="/logo.png" />;
```

| Prop | Type | Par défaut | Rôle |
| --- | --- | --- | --- |
| `value` | `string` | obligatoire | Le texte ou l'URL à encoder, tel quel |
| `size` | `number` | `128` | Largeur et hauteur en pixels. Un cadre s'y ajoute ; un modèle s'inscrit à l'intérieur |
| `scale` | `number` | `1` | Multiplie `size` |
| `level` | `"L" \| "M" \| "Q" \| "H"` | `"Q"` | Correction d'erreur : environ 7 %, 15 %, 25 % ou 30 % du code peuvent être endommagés |
| `margin` | `number` | `0` | Zone de silence autour du code, en modules. La norme en demande 4 |
| `fgColor` | `ColorConfig` | `"#000000"` | Couleur des modules de données : une couleur CSS, un dégradé ou un remplissage par image |
| `bgColor` | `ColorConfig` | `"#FFFFFF"` | Arrière-plan. `"transparent"` n'en peint aucun |
| `eyeColor` | `ColorConfig` | `fgColor` | Couleur des trois yeux d'angle |
| `dotColor` | `ColorConfig` | `fgColor` | Couleur du point à l'intérieur de chaque œil |
| `eyeColors` | `EyeColors` | aucune | Couleurs `outer` et `inner` propres à chaque œil pour `topLeft`, `topRight` et `bottomLeft` ; chacune remplace `eyeColor` et `dotColor` |
| `bodyPattern` | `BodyPattern` | `"circle"` | Forme des modules de données, l'une de {facts.bodyPatterns} |
| `cornerEyePattern` | `CornerEyePattern` | `"gear"` | Forme des yeux d'angle, l'une de {facts.eyeShapes} |
| `cornerEyeDotPattern` | `CornerEyeDotPattern` | `"circle"` | Forme des points des yeux, l'une de {facts.eyeCentres} |
| `moduleScale` | `number` | `1` | Taille de chaque module de données, de 0,5 à 1. Chaque motif s'arrête à la plus petite taille qui reste scannable (`MODULE_SCALE_FLOOR`) |
| `logo` | `string` | aucun | Un chemin, une URL ou une URL de données dessiné au centre, les modules situés derrière étant effacés. Sans cette prop, aucun logo n'est dessiné |
| `logoOptions` | `LogoOptions` | aucune | Le `size` du logo (0,1 à 0,3, 0,25 par défaut), `padding` (0 à 2 modules), `x` et `y` (0 à 1), `shape` et `plate` |
| `hideLogo` | `boolean` | `false` | Masque le logo même si `logo` est défini |
| `autoLevel` | `boolean` | `false` | Passe `level` à `H` quand le logo couvre plus de 7 % du code (`AUTO_LEVEL_LOGO_COVERAGE`) |
| `frame` | `AnyQRFrame` | aucun | Un cadre d'appel à l'action : `{ style, text, color, textColor, secondaryText, secondaryColor, fontScale }`, ou `{ style: "custom", spec }`. Le rendu s'agrandit pour l'accueillir |
| `templateId` | `string` | aucun | Un modèle dessiné à la taille `size`, avec le code à l'intérieur : `"Arrow"`, `"StandardBox"`, `"SquareBorder"`, `"StrikedBox"`, `"Halloween"`, `"DotRing"` ou `"default"` |
| `customTemplate` | `TemplateDefinition` | aucun | Un modèle que vous dessinez en code. Prioritaire sur `templateId` |
| `customProps` | `Record<string, any>` | aucune | Props pour le `wrapper` du modèle, comme `DotRingProps` |
| `shape` | `"square" \| "circle" \| "heart" \| QRSilhouette` | `"square"` | Place le code dans un disque, un cœur ou votre propre contour rempli de modules décoratifs |
| `art` | `QRArt` | aucun | Fond une image dans les modules : `{ mode, image, intensity, variant, matchEyes }` |
| `style` | `CSSProperties` | aucun | Styles en ligne du `<svg>` |
| `frameLabelMarkers` | `boolean` | `false` | Pour les éditeurs : marque chaque `<text>` d'étiquette de cadre avec `data-qrdx-frame-label`. Les exports ne l'incluent jamais |
| `partMarkers` | `boolean` | `false` | Pour les éditeurs : marque les parties dessinées avec `data-qrdx-part`. Les exports ne l'incluent jamais |
| `isOGContext` | `boolean` | `false` | Dessine le logo sous forme d'`<img>` positionnée, pour les moteurs de rendu d'images Open Graph |

`QRCode` n'accepte que ces props ; toute autre prop est ignorée. `QRCodeSVG` place toute autre prop (`className`, `aria-label`, `role`, `data-*`, …) sur le `<svg>`, ou sur le `<svg>` extérieur du cadre lorsqu'il y a un cadre. Les gestionnaires d'événements sont exclus du balisage.

### QRCodeSVG [#qrcodesvg]

`QRProps` plus les attributs SVG de React (`QRPropsSVG`) : les mêmes props que `QRCode`, sans `logo`, `logoOptions`, `hideLogo` ni `scale`. Le logo se définit avec `imageSettings`, en pixels :

| Champ | Type | Par défaut | Rôle |
| --- | --- | --- | --- |
| `src` | `string` | obligatoire | L'image, sous forme d'URL ou d'URL de données |
| `width`, `height` | `number` | obligatoire | Taille dans les mêmes pixels que `size` |
| `excavate` | `boolean` | obligatoire | Efface les modules situés derrière l'image |
| `x`, `y` | `number` | centré | Coin supérieur gauche de l'image |
| `padding` | `number` | `0` | Espace libre supplémentaire autour de l'image, en pixels, lorsque les modules sont effacés |
| `shape` | `"square" \| "rounded" \| "circle"` | `"square"` | Recadre l'image |
| `plate` | `string` | aucun | Une plaque pleine derrière l'image, à sa forme |

Un logo plus grand que ce que le code peut réparer est réduit autour de son centre (`capImageSettings`, avec le même budget que `QRCode`).

### QRCodeCanvas [#qrcodecanvas]

`QRProps` plus les attributs canvas de React (`QRPropsCanvas`), dessiné sur un `<canvas>` au ratio de pixels de l'appareil. Il dessine des modules carrés simples avec des couleurs unies : un dégradé se réduit à sa première couleur, et les props de motif, de couleur d'œil, `eyeColors`, `moduleScale`, `art` et de modèle sont ignorées. Il est livré avec `"use client"`.

### getQRAsSVG [#getqrassvg]

`getQRAsSVG(props: QRPropsSVG): Promise<JSX.Element>` renvoie le code sous forme d'élément React, avec son logo intégré en URL de données. Pour obtenir une chaîne, utilisez `toSVGString` ou `getSVGString`.

## Téléchargement et export [#download-and-export]

| Fonction | Retourne | Notes |
| --- | --- | --- |
| `downloadQRCode(props, { format, size, filename?, quality? })` | `Promise<void>` | Enregistre un fichier. `size` va de 50 à 5000 px et le fichier est carré ; pour les formats matriciels, le nom de fichier par défaut indique la taille en pixels |
| `getQRCodeDataUrl(props, format, size, { quality? })` | `Promise<string>` | Le même fichier sous forme d'URL de données |
| `getQRAsWebP(props, { quality? })` | `Promise<Blob>` | Sans perte, sauf si `quality` est défini ; effectue lui-même l'encodage lorsque le navigateur ne le peut pas |
| `copyQRCodeToClipboard(props, size?)` | `Promise<void>` | Place un PNG dans le presse-papiers. À appeler depuis une action de l'utilisateur |
| `getSVGString(props)` | `Promise<string>` | Balisage SVG avec le logo intégré |
| `toSVGString(props)` | `string` | Balisage SVG, synchrone, sans intégration du logo. Fonctionne partout |
| `toSVGElement(props, document?)` | `SVGSVGElement` | Le code sous forme d'élément DOM |
| `getQRAsSVGDataUri(props)` | `Promise<string>` | `data:image/svg+xml,…`, la première étape de chaque export |
| `getQRAsCanvas(props, mimeType, getCanvas?)` | `Promise<string \| HTMLCanvasElement>` | Une URL de données, ou le canvas lui-même avec `getCanvas` |
| `getQRAsPNG(props, { size?, loadExternalLogos? })` | `Promise<Uint8Array>` | Octets PNG sous Node, depuis `qrdx/node`. Nécessite `@resvg/resvg-js` ou `sharp` |
| `validateSize(width, height)` | `{ isValid, error? }` | La règle de taille appliquée par `downloadQRCode` |
| `getDownloadFilename(format, size, frame?)` | `string` | Le nom de fichier par défaut |
| `withQRSize(props, size)` | `QRProps` | Les props dessinées à `size`, avec un logo en pixels mis à l'échelle en conséquence |
| `canvasToWebP(canvas, { quality? })`, `blobToDataUrl(blob)`, `encodeWebPLossless(rgba, width, height)` | | Utilitaires WebP |

Constantes : `DownloadFormat` vaut `"png" \| "jpg" \| "webp" \| "svg" \| "pdf" \| "eps"` ; `DOWNLOAD_FORMATS` associe chacun à son type MIME et à son extension ; `PRESET_SIZES` contient `small` (200), `medium` (400), `large` (800), `xlarge` (1200), `2xl` (1600) et `3xl` (2000) ; `DEFAULT_SIZE` vaut 128.

## Impression et EPS [#print-and-eps]

| Fonction | Retourne | Notes |
| --- | --- | --- |
| `getPrintLayout(props, { size, unit?, bleed?, cropMarks?, colorMode? })` | `PrintLayout` | Dimensions physiques en mm : `codeWidth`, `trimWidth`, `trimHeight`, `bleed`, `pageWidth`, `pageHeight`, `moduleSize`, `moduleCount`, `maxScanDistance`. `size` va de 5 mm à 2 m |
| `getQRAsPrintPDF(props, options)` | `Promise<string>` | Un PDF vectoriel sous forme d'URL de données. Nécessite `jspdf` |
| `getQRAsPrintPDFBuffer(props, options)` | `Promise<ArrayBuffer>` | Le même PDF sous forme d'octets, pour Node |
| `getQRAsPrintSVG(props, { size, unit? })` | `Promise<string>` | SVG avec `width` et `height` en mm ou en pouces (in) |
| `downloadPrintPDF(props, options & { filename? })`, `downloadPrintSVG(props, options & { filename? })` | `Promise<void>` | Téléchargements des deux dans le navigateur |
| `getQRAsEPS(props, { sizeMm?, bleedMm?, colorMode? })` | `Promise<string>` | Texte EPSF-3.0. Lève `EPS_IMAGE_FILL_REASON` pour un remplissage par image |
| `downloadPrintEPS(props, options & { filename? })` | `Promise<void>` | Téléchargement dans le navigateur |
| `svgToEPS(svg, { width?, colorMode?, bleed?, bleedColor?, title? })` | `Promise<string>` | Convertit n'importe quel SVG produit par la bibliothèque |
| `epsToDataUrl(eps)`, `hasImageFill(props)`, `rgbToCmyk(color)`, `getQRModuleCount(props)` | | Utilitaires |

`PrintOptions` : `size` (nombre), `unit` (`"mm"` ou `"in"`, `"mm"` par défaut), `bleed` (mm, de 0 à 20), `cropMarks` (booléen), `colorMode` (`"rgb"` ou `"cmyk"`).

## Score de scan et détection [#scan-score-and-detection]

| Fonction | Retourne | Notes |
| --- | --- | --- |
| `getScanScore(props, { sizes?, signal? })` | `Promise<ScanScoreResult>` | `{ score, grade, checks }`. Navigateur uniquement ; charge jsQR à la demande. Tailles par défaut : 96, 160 et 320 px (`SCAN_TEST_SIZES`) |
| `getImageScanScore(imageOrBlob, options?)` | `Promise<ImageScanScoreResult>` | Le même pour une image existante, avec en plus `data` et `version`. Navigateur uniquement |
| `getScanScoreFromPixels(pixels, options?)` | `Promise<ImageScanScoreResult>` | Le score d'image sur des pixels RGBA, sous Node |
| `scanQRPixels(pixels, expected, { sizes? })` | `Promise<PixelScanResult>` | Vérifie que les pixels se décodent en `expected`, tels quels et via le modèle de caméra. Node |
| `getScanContrast(props)` | `{ ratio, required, inverted }` | La vérification du contraste seule |
| `getStylePairRisk(props)` | `StylePairRisk \| null` | Une association de formes que certains lecteurs ne détectent pas, avec un `fix` |
| `handleImageLoad(img, size, returnFullData?)` | `Promise<string \| QRCode \| "NO_QR">` | Décode un QR code à partir d'un `<img>`. Voir [Détection de QR code](/docs/qr-detection) |
| `downloadImageWithBoundingBox(img, corners, filename)` | `void` | Enregistre l'image avec le code trouvé encadré |

Les niveaux sont `"great"`, `"ok"`, `"risky"` et `"fails"`. Chaque vérification est `{ id, passed, message, fix?, skipped? }`. Seuils de contraste : `SCAN_CONTRAST_MIN` 4.5, `SCAN_CONTRAST_LOW` 3, `SCAN_CONTRAST_FAIL` 1.5, et `SCAN_IMAGE_CONTRAST_MIN` 7 pour une image dans le code et 12 derrière celui-ci. Les associations faibles sont fournies sous les noms `WEAK_BODY_EYES`, `WEAK_DOT_EYES`, `WEAK_SHARP_DOT_EYES`, `SHARP_DOT_EYE_SAFE_BODIES`, `WEAK_EYES` et `WEAK_DOTS`.

## Modèles [#templates]

| Export | Description |
| --- | --- |
| `TEMPLATES` | Le registre : `default`, `Arrow`, `StandardBox`, `SquareBorder`, `StrikedBox`, `Halloween`, `DotRing` |
| `getTemplate(id)` | Un `TemplateDefinition`, ou `undefined` |

## Types et listes d'options [#types-and-option-lists]

Les types ci-dessous proviennent de `qrdx`, `qrdx/core` et `qrdx/types`. Les listes d'options sont de simples tableaux ; les schémas zod (`qrPropsSchema`, `frameSchema`, `frameSpecSchema`, `colorConfigSchema`, `qrArtSchema`, `logoOptionsSchema`, `imageSettingsSchema` et les autres) sont construits à partir d'elles.

| Type | Forme |
| --- | --- |
| `QRProps` | Le tableau des props ci-dessus, sans l'API du logo |
| `QRCodeProps` | `QRProps` plus `logo`, `logoOptions`, `hideLogo`, `scale` |
| `QRSVGOptions` | `QRProps` plus n'importe quel attribut racine : ce que dessine le cœur |
| `ColorConfig` | `string \| SolidColor \| LinearGradient \| RadialGradient \| AngularGradient \| ImagePaint` |
| `LinearGradient` | `{ type: "linear", stops, angle? }` ; `angle` en degrés, 0 par défaut |
| `RadialGradient` | `{ type: "radial", stops }` |
| `AngularGradient` | `{ type: "angular", stops, angle? }` |
| `GradientStop` | `{ color, offset }` ; `offset` de 0 à 100 |
| `ImagePaint` | `{ type: "image", src, fit?, scale?, position?, opacity?, underlay? }` |
| `ImageSettings`, `LogoOptions`, `EyeColors` | Comme dans les tableaux ci-dessus |
| `QRFrame` | `{ style: FrameStyle, text?, color?, textColor?, secondaryText?, secondaryColor?, fontScale? }` |
| `QRCustomFrame`, `AnyQRFrame`, `FrameSpec` | `{ style: "custom", spec, ...labels and colors }`, l'union, et le format de spec |
| `QRArt`, `QRArtImage` | `{ mode, image, intensity?, variant?, matchEyes? }` et `{ width, height, data }` |
| `QRCodeShape`, `QRSilhouette` | `"square" \| "circle" \| "heart"` ou `{ type: "silhouette", width, height, cells }` |
| `TemplateDefinition`, `BaseTemplateProps`, `TemplateConfig` | Modèles |
| `DownloadFormat`, `DownloadSize`, `DownloadOptions`, `PrintOptions`, `PrintLayout`, `EPSOptions` | Export |
| `ScanScoreResult`, `ImageScanScoreResult`, `ScanCheck`, `ScanGrade`, `StylePairRisk` | Le score de scan |
| `BodyPattern`, `CornerEyePattern`, `CornerEyeDotPattern`, `FrameStyle`, `ErrorLevel` | Les unions d'options |

Listes d'options : `BODY_PATTERN`, `CORNER_EYE_PATTERNS`, `CORNER_EYE_DOT_PATTERNS`, `FRAME_STYLES`, `QR_SHAPES`, `LOGO_SHAPES`, `EYE_POSITIONS`. Valeurs retirées qui s'affichent toujours pour les designs enregistrés : `RETIRED_CORNER_EYE_PATTERNS` (`curly`) et `RETIRED_CORNER_EYE_DOT_PATTERNS` (`diamond`, `star`, `banner`).

## Où les fonctions s'exécutent [#where-things-run]

- **Partout, sans DOM :** `toSVGString`, `createQRCodeTree`, `renderToString`, `getQRData`, les helpers de cadre et de modèle, `createQRArtImage`, `createQRSilhouette`, `getPrintLayout`, `getQRAsEPS`, `getQRAsPrintPDFBuffer`, `scanQRPixels`, `toQRdxCodeHTML`.
- **Navigateur :** `downloadQRCode` et les autres téléchargements, `copyQRCodeToClipboard`, `getQRAsCanvas`, `getScanScore`, `getImageScanScore`, `handleImageLoad`, `loadQRArtImage`, `loadQRSilhouette`, `removeLogoBackground`, `createQRCode`, l'élément personnalisé.
- **Node uniquement :** `getQRAsPNG` depuis `qrdx/node`.
