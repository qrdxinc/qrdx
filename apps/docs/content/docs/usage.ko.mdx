`QRCode`는 가장 먼저 사용할 컴포넌트입니다. 모든 스타일 옵션과 간단한 `logo` prop을 지원하고, 서버에서 렌더링됩니다. 이 페이지에서는 가장 자주 설정하는 props를 설명합니다. 전체 prop은 [라이브러리 API 레퍼런스](/docs/api-reference)에서 확인하세요.

## 컴포넌트 선택 [#choose-a-component]

| 컴포넌트 | 그리는 대상 | 사용하는 경우 |
| --- | --- | --- |
| `QRCode` | 모든 스타일 옵션과 `logo`, `logoOptions`, `hideLogo`, `scale`을 지원하는 `<svg>`. 다른 속성은 받지 않습니다 | 거의 모든 경우 |
| `QRCodeSVG` | 같은 `<svg>`이며, 로고를 픽셀 단위의 원시 `imageSettings`로 지정합니다. 다른 prop(`aria-label`, `className`, `role`)은 `<svg>`에 적용됩니다 | `<svg>`에 속성을 지정해야 하거나, 로고 배치를 직접 하거나, 다른 렌더러의 코드를 옮겨 올 때 |
| `QRCodeCanvas` | 단순한 정사각형 모듈과 단색을 사용하는 `<canvas>` | canvas 요소가 필요할 때. 패턴, 눈 색상, 그라데이션, 템플릿은 무시됩니다 |

`QRCode`와 `QRCodeSVG`는 브라우저 전용 훅을 사용하지 않으므로 React Server Components와 정적 HTML에서도 렌더링됩니다. `QRCodeCanvas`는 `"use client"`와 함께 제공됩니다.

```tsx title="components/menu-code.tsx"
import { QRCode } from "qrdx";

export function MenuCode() {
  return (
    <div role="img" aria-label="QR code for the menu">
      <QRCode value="https://example.com/menu" size={256} margin={4} />
    </div>
  );
}
```

`value`는 전달한 그대로 인코딩되므로 Wi-Fi 페이로드, vCard, `mailto:`, 일반 텍스트 모두 사용할 수 있습니다. `QRCode`는 코드 고유의 props와 `style`만 받습니다. 접근 가능한 이름이 필요하면 위 예시처럼 감싸서 지정하세요. `QRCodeSVG`는 `aria-label`, `className`, `role` 등 다른 속성을 `<svg>` 자체에 적용합니다.

## 크기와 여백 [#size-and-quiet-zone]

- `size`는 너비와 높이를 픽셀로 지정합니다(기본값 128). 약 128px보다 작으면 밀도가 높은 코드는 화면에서 스캔하기 어렵습니다.
- `margin`은 코드 주위의 여백(quiet zone)을 모듈 단위로 지정합니다(기본값 0). QR 표준은 4를 요구합니다. 코드를 사진, 패턴, 어두운 페이지 위에 놓을 때 설정하세요. 자체 패딩이 있는 흰색 카드 안에 넣는다면 0으로 두어도 됩니다.
- `scale`은 `QRCode`에서 `size`에 배율을 곱합니다.

프레임이나 템플릿을 사용하면 출력 크기가 달라집니다. [프레임 또는 템플릿](#frame-or-template)을 참고하세요.

## 색상 [#colors]

```tsx title="components/brand-code.tsx"
import { QRCode } from "qrdx";

export function BrandCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      fgColor="#1d4ed8"
      bgColor="#f8fafc"
      eyeColor="#0f172a"
      dotColor="#1d4ed8"
    />
  );
}
```

- `fgColor`는 데이터 모듈, `bgColor`는 배경, `eyeColor`는 세 개의 모서리 눈, `dotColor`는 각 눈 안쪽의 점에 색을 지정합니다. 눈 색상의 기본값은 `fgColor`입니다.
- 각 prop은 CSS 색상(`#1d4ed8`, `rgb(29 78 216)`, 색상 이름) 또는 그라데이션 객체를 받습니다. 그라데이션, 투명 색상, 이미지 채우기는 [색상과 그라데이션 설정](/docs/features/colors-gradients)에서 다룹니다.
- 모듈은 배경보다 어둡게 유지하세요. 스캐너는 밝은 바탕의 어두운 코드를 읽도록 만들어져 있습니다. 어두운 배경 위의 밝은 코드는 대부분의 휴대폰 카메라에서 인식되지만 일부 오래된 앱에서는 인식되지 않습니다.

## 모양 [#shapes]

```tsx title="components/rounded-code.tsx"
import { QRCode } from "qrdx";

export function RoundedCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      bodyPattern="rounded"
      cornerEyePattern="extra-rounded"
      cornerEyeDotPattern="rounded"
    />
  );
}
```

- `bodyPattern`은 데이터 모듈의 모양을 정합니다(기본값 `circle`). {facts.bodyPatterns} 중에서 선택할 수 있습니다.
- `cornerEyePattern`은 세 개의 모서리 눈의 모양을 정합니다(기본값 `gear`). {facts.eyeShapes} 중 하나입니다.
- `cornerEyeDotPattern`은 각 눈 안쪽 점의 모양을 정합니다(기본값 `circle`). {facts.eyeCentres} 중 하나입니다.

[모양, 눈, 프레임](/docs/styles)에서는 모든 값을 실시간으로 볼 수 있습니다. [모듈과 눈 모양 선택](/docs/features/patterns)에서는 모듈 배율, 모양이 있는 코드, 함께 쓰면 스캔이 잘 되지 않는 몇몇 조합을 설명합니다.

## 로고 [#logo]

```tsx title="components/logo-code.tsx"
import { QRCode } from "qrdx";

export function LogoCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      level="H"
      logo="/logo.png"
      logoOptions={{ size: 0.2, padding: 1 }}
    />
  );
}
```

`logo`는 앱 내 경로, URL, data URL을 받습니다. 로고 뒤의 모듈은 지워지므로 코드는 오류 정정에 의존해 스캔됩니다. `level="H"`를 사용하세요. `logoOptions`로 코드 대비 로고 너비 비율(0.1~0.3, 기본값 0.25), 모듈 단위 여백, 위치, 자르기를 설정합니다. 컴포넌트는 코드가 복구할 수 있는 크기보다 큰 로고를 그리지 않습니다. 자세한 내용은 [코드에서 로고 추가](/docs/features/logos)를 참고하세요.

## 프레임 또는 템플릿 [#frame-or-template]

```tsx title="components/framed-code.tsx"
import { QRCode } from "qrdx";

export function FramedCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      frame={{ style: "banner-bottom", text: "Scan me", color: "#0f172a" }}
    />
  );
}
```

- `frame`은 코드 주위에 행동 유도 프레임을 그립니다. 코드는 `size` 너비를 유지하고 출력은 프레임에 맞게 커집니다. 기본 제공 스타일 {facts.frameStyles}개와 공식 프레임 라이브러리, 직접 만든 프레임 사양을 사용할 수 있습니다. [프레임, 스캔 점수, 인쇄 파일](/docs/features/frames)을 참고하세요.
- `templateId`는 `Arrow`나 `StandardBox` 같은 템플릿을 대신 그립니다. 템플릿은 전체 아트워크를 `size`로 그리며, 코드는 그 안에서 더 작게 표시됩니다. [프레임 템플릿 사용](/docs/features/templates)을 참고하세요.

둘 다 설정하면 템플릿의 아트워크 주위에 프레임이 그려집니다.

## 오류 정정 [#error-correction]

| `level` | 손상 허용 범위 | 사용 용도 |
| --- | --- | --- |
| `L` | 약 7% | 깨끗한 화면, 짧은 링크, 가장 작은 코드 |
| `M` | 약 15% | vCard처럼 긴 페이로드에서 코드 크기를 더 줄여야 할 때 |
| `Q` | 약 25% | 기본값. 일반 용도 |
| `H` | 약 30% | 로고, 아트, 긁히거나 접힐 수 있는 인쇄물 |

레벨이 높을수록 모듈이 늘어나므로 같은 크기에서 코드가 더 촘촘해집니다. `autoLevel`은 로고가 코드의 7%보다 넓은 영역을 가리면 레벨을 자동으로 `H`로 올립니다. 기존 코드의 모양이 바뀌지 않도록 기본값은 꺼져 있습니다.
