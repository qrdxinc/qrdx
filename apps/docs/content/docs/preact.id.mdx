Di akhir halaman ini, Anda akan memiliki kode QR bergaya dalam komponen Preact beserta tombol yang menyimpannya sebagai PNG. `qrdx/preact` menyediakan dua komponen SVG milik pustaka React, yaitu `QRCodeSVG` dan `QRCode`, yang dibuat untuk Preact. Keduanya menggambar dengan `h` bawaan Preact, jadi Anda tidak memerlukan `preact/compat` maupun `react`, dan SVG yang dihasilkan sama dengan komponen React.

<NpmStatus package="qrdx" />

## Sebelum memulai [#before-you-start]

- Proyek Preact 10 atau lebih baru, dengan Vite atau bundler lainnya.
- Node.js 18 atau lebih baru.

## Membuatnya [#build-it]

### 1. Instal qrdx [#1-install-qrdx]

```package-install
qrdx
```

`preact` adalah peer dependency opsional dari `qrdx`. Aplikasi Anda sudah memilikinya.

### 2. Gambar sebuah kode [#2-draw-a-code]

```tsx title="src/components/menu-code.tsx"
import { QRCodeSVG } from "qrdx/preact";

export function MenuCode() {
  return (
    <QRCodeSVG
      value="https://example.com/menu"
      size={256}
      margin={4}
      bodyPattern="rounded"
      frame={{ style: "banner-bottom", text: "Scan me" }}
      aria-label="QR code for the menu"
    />
  );
}
```

Halaman menampilkan kode berukuran 256 px dengan modul membulat dan banner "Scan me" di bawahnya.

<Shot id="lib-preact-code" />

`QRCodeSVG` menerima semua opsi yang diterima `QRCodeSVG` React: pola, warna dan gradien, logo (`imageSettings`), bingkai, bentuk, templat, dan seni. Atribut seperti `class`, `style`, atau `aria-label` dipasang pada `<svg>`, atau pada `<svg>` terluar bingkai jika ada bingkai.

`QRCode` menambahkan pintasan logo milik `QRCode` React: `logo`, `logoOptions`, `hideLogo`, dan `scale`. Komponen ini hanya menerima props kode dan `style`; letakkan `class` atau `aria-label` pada elemen yang membungkusnya, atau gunakan `QRCodeSVG`.

```tsx title="src/components/logo-code.tsx"
import { QRCode } from "qrdx/preact";

export function LogoCode() {
  return <QRCode value="https://example.com" size={256} logo="/logo.png" level="H" />;
}
```

Kedua komponen menggambar ulang saat sebuah prop berubah dan melewati pekerjaan itu jika tidak ada yang berubah. Event handler di props tidak dipasang pada `<svg>`, seperti di React. Pasang pada elemen yang membungkus kode.

### 3. Simpan sebagai file [#3-save-it-as-a-file]

Komponen hanya menggambar kode. Unduhan, `toSVGString`, skor pemindaian, dan fungsi lainnya berasal dari `qrdx/core`. Itulah mesin yang sudah dipakai komponen, sehingga tidak dibundel dua kali.

```tsx title="src/components/downloadable-code.tsx"
import { downloadQRCode } from "qrdx/core";
import { QRCodeSVG } from "qrdx/preact";

const options = { value: "https://example.com", size: 256, margin: 4 };

export function DownloadableCode() {
  return (
    <>
      <QRCodeSVG {...options} />
      <button
        type="button"
        onClick={() =>
          downloadQRCode(options, {
            format: "png",
            size: { width: 1024, height: 1024 },
            filename: "qr-code.png",
          })
        }
      >
        Download PNG
      </button>
    </>
  );
}
```

Mengeklik tombol menyimpan `qr-code.png` berukuran 1024 px. Simpan opsi dalam satu objek, seperti di atas, agar file sesuai dengan kode di layar. [Vanilla JavaScript](/docs/vanilla-js) membahas `qrdx/core` secara lengkap.

## Perenderan di server [#server-rendering]

`renderToString` dari `preact-render-to-string` menulis SVG yang sama dengan `toSVGString` dari `qrdx/core`. Satu-satunya perbedaan ada pada escaping: Preact membiarkan `>` dan `'` apa adanya di dalam teks, sedangkan core menulis `&gt;` dan `&#x27;`. Browser membaca keduanya dengan cara yang sama.

`hydrate` mempertahankan `<svg>` dari server dan tidak menggambarnya lagi. Markup tidak memiliki id acak, sehingga server dan browser selalu cocok.

## Dengan preact/compat [#with-preactcompat]

Jika aplikasi Anda sudah membuat alias `react` ke `preact/compat`, komponen React dari `qrdx` juga berfungsi: `import { QRCodeSVG } from "qrdx"`. `qrdx/preact` menggambar kode yang sama tanpa alias, jadi pilih ini saat Anda menambahkan `qrdx` ke aplikasi Preact.

## Jika terjadi masalah [#if-something-goes-wrong]

- **`Failed to resolve import "react"`.** Anda mengimpor dari `qrdx` alih-alih `qrdx/preact`, di aplikasi tanpa `preact/compat`. Ubah impornya.
- **Click handler pada komponen tidak berfungsi.** Handler dibuang dari `<svg>`. Bungkus kode dengan `<button>` atau `<div>` dan pasang handler di sana.
- **`PDF export needs the optional "jspdf" package`.** Jalankan `npm install jspdf` di aplikasi.
