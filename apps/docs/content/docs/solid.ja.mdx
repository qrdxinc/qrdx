このページを終えると、シグナルに追従するスタイル付きQRコードを持つ Solid コンポーネントと、それを PNG として保存するボタンが完成します。`qrdx/solid` には、React ライブラリの2つの SVG コンポーネント `QRCodeSVG` と `QRCode` が SolidJS 向けに用意されています。React コンポーネントと同じ SVG を描画し、シグナルに追従し、サーバーでもレンダリングできます。

<NpmStatus package="qrdx" />

## 始める前に [#before-you-start]

- Solid 1.8 以降（1.x 系）のプロジェクトで、Vite または SolidStart を使用していること。
- Node.js 18 以降。

## 作成手順 [#build-it]

### 1. qrdx をインストールする [#1-install-qrdx]

```package-install
qrdx
```

`solid-js` は `qrdx` のオプションのピア依存関係です。アプリにはすでに入っているはずで、`react` は不要です。

### 2. シグナルに追従するコードを描画する [#2-draw-a-code-that-follows-a-signal]

```tsx title="src/components/menu-code.tsx"
import { createSignal } from "solid-js";
import { QRCodeSVG } from "qrdx/solid";

export function MenuCode() {
  const [color, setColor] = createSignal("#0f172a");
  return (
    <>
      <QRCodeSVG
        value="https://example.com/menu"
        size={256}
        margin={4}
        fgColor={color()}
        frame={{ style: "banner-bottom", text: "Scan me" }}
        aria-label="QR code for the menu"
      />
      <button type="button" onClick={() => setColor("#1d4ed8")}>
        Blue
      </button>
    </>
  );
}
```

ページには「Scan me」のバナー付きの暗い色のコードが表示されます。**Blue** をクリックすると、コードが青で再描画されます。

<Shot id="lib-solid-signal-code" />

`QRCodeSVG` は、React の `QRCodeSVG` が受け取るすべてのオプションを受け取ります。パターン、色とグラデーション、ロゴ（`imageSettings`）、フレーム、形状、テンプレート、アートが使えます。`class`、`style`、`aria-label` などの属性は `<svg>` に付きます。フレームがある場合は、フレームの外側の `<svg>` に付きます。

`QRCode` には、React の `QRCode` にあるロゴのショートカットが加わります。`logo`、`logoOptions`、`hideLogo`、`scale` です。受け取るのはコードの props と `style` のみです。`class` や `aria-label` はその周りの要素に付けるか、`QRCodeSVG` を使ってください。

```tsx title="src/components/logo-code.tsx"
import { QRCode } from "qrdx/solid";

export function LogoCode() {
  return <QRCode value="https://example.com" size={256} logo="/logo.png" level="H" />;
}
```

props は、ほかの Solid コンポーネントと同様にリアクティブです。`color()` が変わると、コードが再描画されます。props のイベントハンドラーは `<svg>` には付かないため、コードの周りの要素に付けてください。

### 3. ファイルとして保存する [#3-save-it-as-a-file]

コンポーネントはコードを描画するだけです。ダウンロード、`toSVGString`、スキャンスコアなどの関数は `qrdx/core` にあります。これはコンポーネントがすでに使っているエンジンなので、二重にバンドルされることはありません。

```tsx title="src/components/downloadable-code.tsx"
import { downloadQRCode } from "qrdx/core";
import { QRCodeSVG } from "qrdx/solid";

const options = { value: "https://example.com", size: 256, margin: 4 };

export function DownloadableCode() {
  return (
    <>
      <QRCodeSVG {...options} />
      <button
        type="button"
        onClick={() =>
          downloadQRCode(options, {
            format: "png",
            size: { width: 1024, height: 1024 },
            filename: "qr-code.png",
          })
        }
      >
        Download PNG
      </button>
    </>
  );
}
```

ボタンをクリックすると、`qr-code.png` が 1024 px で保存されます。`qrdx/core` については [Vanilla JavaScript](/docs/vanilla-js) で詳しく説明しています。

## 描画のしくみ [#how-it-draws]

パッケージには Solid の JSX が含まれていないため、Solid コンパイラーは不要で、どのビルド構成でも動作します。

- ブラウザーでは、コンポーネントは `createElementNS` で作成した `<svg>` 要素そのものを返します（HTML は解析しません）。Solid がそれをページに配置し、prop の変更でマークアップが変わるときは新しいものに差し替え、コンポーネントがアンマウントされると削除します。
- 同じマークアップになる prop の変更では、ページは変更されません。

## サーバーレンダリングとハイドレーション [#server-rendering-and-hydration]

`solid-js/web` の `renderToString` を使うと、コンポーネントは `qrdx/core` の `toSVGString` と同じマークアップを出力し、ルート要素に Solid のハイドレーションキー `data-hk` が加わります。`hydrate` はこのキーを使って、`<svg>` を再描画せずサーバーのものを保持します。`<NoHydration>` の内側では、このキーは付きません。

マークアップにはランダムな id がないため、サーバーとブラウザーの出力は常に一致します。

## うまくいかない場合 [#if-something-goes-wrong]

- **`Failed to resolve import "react"`。** `qrdx/solid` ではなく `qrdx` からインポートしています。メインのエントリーには React コンポーネントが入っています。インポート元を変更してください。
- **コンポーネントに付けたクリックハンドラーが動作しない。** ハンドラーは `<svg>` から除外されます。コードを要素で包み、そこにハンドラーを付けてください。
- **`PDF export needs the optional "jspdf" package`。** アプリで `npm install jspdf` を実行してください。
