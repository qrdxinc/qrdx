Le bot QRdx crée des QR codes directement dans Discord, sans qu'un compte QRdx soit nécessaire. Chaque réponse affiche le code avec des boutons pour le télécharger en PNG ou en SVG, ou pour l'ouvrir dans l'[éditeur](/playground) et modifier son apparence. Utilisez-le lorsqu'un serveur partage des liens et souhaite obtenir un code dans le salon sans quitter Discord.

## Fonctionnement [#how-it-works]

QRdx n'enregistre pas les codes que vous créez, et le bot ne peut pas lire vos conversations. Discord transmet à QRdx ce que vous saisissez après `/qr`, ou le seul message que vous avez choisi pour **Make QR code**. Le contenu et le design choisis sont intégrés au lien de l'image, et Discord charge l'image depuis l'[Image API](/docs/developers/image-api) de QRdx. Pour modifier le style d'un code, QRdx relit ces deux informations dans ce lien : il n'enregistre donc pas le code pour le restyliser. Comme tout lien, il peut se retrouver dans des journaux et des caches : ne créez donc pas de codes à partir de mots de passe ou d'autres secrets.

<IfAvailable feature="discordBot" id="add-the-bot" title="Ajouter le bot">

1. Ouvrez la page [Bot Discord](/integrations/discord-bot) et cliquez sur **Add to Discord**.
2. Discord vous demande où l'ajouter :
   - **Votre compte :** utilisez-le dans les messages privés, les groupes privés et les serveurs dont vous faites partie.
   - **Un serveur :** tous les membres du serveur peuvent l'utiliser. Vous devez y disposer de la permission **Gérer le serveur**.

Certains serveurs n'autorisent pas les applications personnelles des membres à publier pour tout le monde. Dans ce cas, les réponses du bot installé sur votre compte ne sont visibles que par vous.

</IfAvailable>

<IfAvailable feature="discordBot" id="make-a-code-with-qr" title="Créer un code avec /qr">

1. Dans n'importe quelle conversation, saisissez `/qr` et choisissez la commande dans la liste.
2. Saisissez ou collez un lien ou du texte dans **content**, puis appuyez sur Enter.

Le bot répond avec le code, son contenu comme titre, trois boutons et les menus de style décrits ci-dessous. Les boutons sont **Download PNG** (1024 px), **Download SVG** et **Open in editor**. Un lien s'ouvre dans l'éditeur avec le design du code. Le texte n'est pas transmis dans le lien vers l'éditeur : collez-le vous-même.

Pour garder le code pour vous, définissez **private** sur **True**. Vous seul voyez cette réponse, et Discord la supprime lorsque vous la masquez ou rechargez l'application.

Un contenu très long peut ne pas tenir dans un seul QR code, ou être trop long pour que Discord l'affiche sous forme d'image. Le bot vous le signale dans un message que vous seul pouvez voir.

</IfAvailable>

<IfAvailable feature="discordBot" id="style-your-code" title="Personnaliser votre code">

`/qr` propose trois autres options que vous pouvez renseigner avant d'appuyer sur Enter :

| Option | Fonction | Choix |
| --- | --- | --- |
| **look** | Applique l'un des designs intégrés de l'éditeur | Plain, Classic, Modern, Royal, Folio, Caffeine, Retro, Bordeaux, Blossom |
| **color** | Met tout le code dans une seule couleur sur fond blanc | Black, Blue, Green, Red, Purple, Orange |
| **frame** | Ajoute un cadre portant la mention « Scan me » | No frame, Banner, Top banner, Bubble, Polaroid |

Le style est appliqué en premier et la couleur par-dessus : avec **look** Royal et **color** Blue, le code conserve les formes de Royal en bleu.

Sous chaque code se trouvent quatre menus, **Look**, **Color**, **Frame** et **Logo**, avec les mêmes choix, plus sept icônes de logo rapides de l'éditeur. Faites un choix et le code change sur place. Chaque modification s'appuie sur le code tel qu'il est à ce moment-là. Seule la personne qui a créé le code peut le restyliser. Toute autre personne qui fait un choix reçoit une note visible par elle seule, et le code reste tel quel.

Avant l'affichage d'un code stylisé, QRdx le vérifie avec le même score de scan que l'éditeur ; Discord indique donc brièvement que QRdx réfléchit. Lorsqu'un design serait difficile à lire pour les téléphones, QRdx l'ajuste (couleurs plus foncées, formes plus simples ou correction d'erreur renforcée) et l'indique sous le code. Si cela ne suffit toujours pas, généralement parce que le contenu est long, vous obtenez le code en noir sur blanc, accompagné d'une note.

**Open in editor** ouvre l'éditeur avec le même design : couleurs, formes et cadre. L'icône du logo n'est pas transmise dans le lien : choisissez-la à nouveau dans l'éditeur.

</IfAvailable>

<IfAvailable feature="discordBot" id="make-a-code-from-a-message" title="Créer un code à partir d'un message">

Sur ordinateur, faites un clic droit sur un message et choisissez **Apps** → **Make QR code**. Sur mobile, appuyez longuement sur le message, puis touchez **Apps** → **Make QR code**.

Le code contient la première adresse web du message. Un message qui n'en contient pas devient un code de son texte. Toutes les personnes présentes dans la conversation voient la réponse. Les réponses ne mentionnent ni ne notifient jamais personne, quel que soit le contenu du message.

</IfAvailable>

## Limites et formules [#limits-and-plans]

Le bot est gratuit et n'est lié à aucune formule. Pour éviter qu'une seule personne inonde un salon, QRdx compte les codes que chaque compte Discord crée ou restylise en une minute. Il compte aussi les codes créés par l'ensemble des utilisateurs, et lorsqu'il en arrive trop en une minute, le bot indique qu'il est occupé. Aucun de ces compteurs ne contient de contenu, et tous deux expirent au bout de cette minute.

<IfAvailable feature="discordBot" id="remove-the-bot" title="Supprimer le bot">

- **De votre compte :** ouvrez **User Settings** → **Authorized Apps** et cliquez sur **Deauthorize** à côté de QRdx.
- **D'un serveur :** une personne disposant de **Manage Server** ouvre **Server Settings** → **Integrations**, choisit QRdx et le supprime.

</IfAvailable>

## Pour les développeurs [#for-developers]

Chaque code envoyé par le bot provient de l'[Image API](/docs/developers/image-api), que vous pouvez appeler directement depuis votre propre bot ou script. La [CLI](/docs/developers/cli) propose les mêmes styles, couleurs et cadres depuis un terminal.

## Auto-hébergement [#self-hosting]

Le bot fonctionne sur votre propre QRdx dès que vous enregistrez une application Discord et définissez `DISCORD_APPLICATION_ID` et `DISCORD_PUBLIC_KEY`. [`plugins/discord/README.md`](https://github.com/qrdxinc/qrdx/tree/main/plugins/discord) détaille les étapes. Les limites de débit nécessitent Upstash Redis ; sans lui, elles sont désactivées. Consultez [Auto-hébergement](/docs/self-hosting#optional-services).
