`QrCodeDownload` は、形式とサイズのメニューを開くボタンです。コードをファイルとして保存するか、PNG をクリップボードにコピーします。表示しているコードの隣に、同じスタイルオブジェクトを渡して配置すると、ファイルがプレビューと一致します。

## 使い方 [#usage]

```tsx title="components/example.tsx"
import { QrCodeDownload } from "@/components/qr-code-download";
```

```tsx title="components/example.tsx"
<QrCodeDownload value="https://qrdx.dev" />
```

メニューには、各形式が短い説明つきで並び、その下にサイズの選択と **画像をコピー** が表示されます。**画像をコピー** を選ぶと、PNG がクリップボードに入ります。ファイルはブラウザー上で生成され、アップロードされることはありません。

## 例 [#examples]

### スタイルを反映した書き出し [#styled-export]

画面に表示しているものと同じスタイルオブジェクトを `qr` に渡すと、書き出したすべてのファイルがプレビューと一致します。`formats`、`sizes`、`label`、`variant` で、メニューとそのボタンを調整できます。

### 形式 [#formats]

| 形式 | 出力 |
| --- | --- |
| `png` | コードの背景つきの画像 |
| `jpg` | 単色の背景の画像 |
| `svg` | どんなサイズにも拡大できるベクター形式 |
| `pdf` | 1ページのドキュメント。オプションの `jspdf` パッケージが必要です（`npm install jspdf`） |
| `eps` | 印刷所やデザインツール向けのベクター形式 |

ラスター形式のサイズは 50 から 5000 ピクセルまで指定できます。`sizes` に1つだけ指定すると、サイズの選択は表示されません。メニューでは、ラスター形式の横にピクセルサイズが、SVG と EPS の横には「vector」が表示されます。

### ダウンロード後の処理 [#after-a-download]

ファイルの保存または画像のコピーが終わると、`onComplete` が形式（コピーの場合は `"copy"`）を引数にして呼び出されます。書き出しに失敗すると、`onError` がエラーを受け取り、メッセージもボタンの下に表示されます。

```tsx title="components/tracked-download.tsx"
import { QrCodeDownload } from "@/components/qr-code-download";

export function TrackedDownload({ url }: { url: string }) {
  return (
    <QrCodeDownload
      value={url}
      onComplete={(action) => console.log("exported", action)}
      onError={(error) => console.error(error.message)}
    />
  );
}
```

## アクセシビリティとレンダリング [#accessibility-and-rendering]

- トリガーには、お使いの Button を使用します。ファイルの生成中は `aria-busy` が設定されます。結果は polite なライブリージョンで通知され、エラーは `role="alert"` つきでボタンの下に表示されます。
- メニューには、お使いの DropdownMenu を使用します。そのため、キーボード操作とフォーカスは、テーマのコンポーネントの動作に従います。
- コピーにはユーザー操作とセキュアコンテキスト（HTTPS または localhost）が必要です。満たさない場合はブラウザーに拒否され、エラーがボタンの下に表示されます。
- このコンポーネントは Client Component です。サーバー上では、ボタン以外の見た目は何も描画されません。
