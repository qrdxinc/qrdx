`QrCode`는 접근 가능한 이름, 캡션, PNG 및 SVG 다운로드 버튼을 갖춘 QR 코드를 SVG로 렌더링하며, 직접 소유하는 하나의 컴포넌트로 제공됩니다. 주문 확인, 티켓, 메뉴, Wi-Fi 카드처럼 누군가 저장하고 싶어 할 만한 코드를 페이지에 보여줄 때 사용하세요.

## 사용법 [#usage]

```tsx title="components/example.tsx"
import { QrCode } from "@/components/qr-code";
```

```tsx title="components/example.tsx"
<QrCode value="https://qrdx.dev" />
```

코드는 `role="img"` 상자 안에 SVG로 렌더링되므로 어떤 크기에서도 선명하게 유지되고, 스크린 리더가 코드의 연결 대상을 읽어 줍니다. 코드 아래의 버튼 두 개로 1024 px PNG와 SVG를 저장할 수 있습니다.

## 예제 [#examples]

### 크기 [#sizes]

`size`는 화면에 표시되는 가로와 세로 크기를 픽셀 단위로 정합니다. 다운로드에는 `downloadSize`가 사용되므로, 페이지에서는 작은 코드여도 인쇄에 적합한 파일을 내보낼 수 있습니다.

<ComponentPreview name="qr-code-sizes" />

### 색상 [#colors]

`fgColor`와 `bgColor`에는 모든 CSS 색상을 사용할 수 있습니다. `eyeColor`와 `dotColor`는 세 개의 모서리 눈 모양에 따로 색을 지정합니다. 모든 스캐너가 코드를 읽을 수 있도록 모듈은 배경보다 어둡게 유지하세요.

<ComponentPreview name="qr-code-colors" />

### 그라디언트 [#gradients]

색상 대신 qrdx 그라디언트를 전달하세요. `angle`을 지정한 `linear` 또는 `radial`을 사용할 수 있습니다. 그라디언트는 PNG, SVG, PDF 다운로드에도 그대로 적용됩니다.

<ComponentPreview name="qr-code-gradient" />

### 패턴 [#patterns]

`bodyPattern`은 데이터 모듈의 모양을, `cornerEyePattern`은 모서리 프레임의 모양을, `cornerEyeDotPattern`은 그 안쪽 점의 모양을 정합니다. 사용할 수 있는 모든 모양은 [모듈과 눈 모양 선택](/docs/features/patterns)에서 확인할 수 있습니다.

<ComponentPreview name="qr-code-patterns" />

### 로고 [#logo]

`logo`는 가운데에 이미지를 배치하고 그 뒤의 모듈을 비웁니다. 일부가 가려져도 코드가 스캔되도록 오류 정정 레벨 `H`를 사용하세요. 데이터 URL을 사용하면 다운로드에도 로고가 유지되며, 원격 이미지는 CORS 헤더가 필요합니다.

<ComponentPreview name="qr-code-logo" />

### 프레임 템플릿 [#frame-templates]

`templateId`는 qrdx의 [프레임 템플릿](/docs/features/templates) 중 하나를 코드 주위에 그립니다. `caption`과 함께 사용하면 프레임 아래에 행동 유도 문구를 넣을 수 있습니다.

<ComponentPreview name="qr-code-template" />

### 다운로드 형식 [#download-formats]

`downloadFormats`로 표시할 버튼을 고릅니다: `png`, `jpg`, `svg`, `pdf`. PDF 내보내기에는 선택 사항인 `jspdf` 패키지가 필요합니다(`npm install jspdf`). 버튼을 숨기려면 `[]`를 전달하세요.

<ComponentPreview name="qr-code-downloads" />

형식과 크기를 하나의 메뉴로 제공하려면 [QR Code Download](/docs/components/qr-code-download)를 사용하세요.

### 다크 모드 [#dark-mode]

기본 흰색 배경은 다크 테마에서 가장 안전한 선택입니다. 밝은 타일 위의 어두운 모듈은 모든 리더에서 스캔됩니다. 대신 테마를 따르게 하려면 `fgColor="currentColor"`와 투명 배경을 설정하세요. 이 경우 다크 모드에서 코드가 반전되며, 휴대폰 카메라는 읽을 수 있지만 일부 오래된 스캐너는 읽지 못합니다.

## Next.js 페이지에서 [#in-a-nextjs-page]

`QrCode`는 클라이언트 컴포넌트입니다(다운로드 버튼 때문에 파일이 `"use client"`로 시작합니다). 따라서 서버 컴포넌트 페이지에서 가져와 서버 데이터를 props로 전달할 수 있습니다:

```tsx title="app/menu/page.tsx"
import { QrCode } from "@/components/qr-code";

export default function MenuPage() {
  return (
    <QrCode
      value="https://example.com/menu"
      caption="Scan to see the menu"
      filename="menu-qr"
    />
  );
}
```

코드 자체는 여전히 서버에서 렌더링되므로, 버튼이 상호작용 가능해지기 전에 이미 페이지의 HTML에 들어 있습니다. App Router에서 코드를 렌더링하는 방법은 [Next.js의 QR 코드](/docs/nextjs)를 참고하세요.

## 링크뿐 아니라 모든 콘텐츠 [#any-content-not-only-links]

`value`는 전달한 그대로 인코딩되므로 Wi-Fi 네트워크, 연락처 카드, `mailto:`, `tel:`, 일반 텍스트 등 어떤 QR 페이로드든 사용할 수 있습니다. Wi-Fi의 경우 비밀번호가 포함된 원본 페이로드 대신 코드의 용도를 스크린 리더가 읽도록 `label`을 설정하세요.

```tsx title="components/guest-wifi.tsx"
import { QrCode } from "@/components/qr-code";

export function GuestWifi() {
  return (
    <QrCode
      value="WIFI:T:WPA;S:Cafe Guest;P:sunshine123;;"
      label="QR code to join the Cafe Guest Wi-Fi"
      caption="Cafe Guest Wi-Fi"
    />
  );
}
```

폼에서 페이로드를 만들려면 특수 문자를 대신 이스케이프해 주는 [Wi-Fi QR Code](/docs/components/wifi-qr-code) 또는 [vCard QR Code](/docs/components/vcard-qr-code)를 사용하세요.

## 입력란의 값 사용 [#a-value-from-an-input]

```tsx title="components/link-qr-code.tsx"
"use client";

import { useState } from "react";
import { QrCode } from "@/components/qr-code";

export function LinkQrCode() {
  const [value, setValue] = useState("https://example.com");
  return (
    <div className="grid justify-items-center gap-4">
      <input
        aria-label="Link"
        className="w-full rounded-md border px-3 py-2"
        value={value}
        onChange={(event) => setValue(event.target.value)}
      />
      {value ? <QrCode value={value} downloadFormats={[]} /> : null}
    </div>
  );
}
```

`downloadFormats={[]}`는 사용자가 아직 입력 중일 때 버튼을 숨깁니다. 값이 확정되면 버튼을 표시하세요.

## 인쇄용 다운로드 [#print-ready-downloads]

```tsx title="components/table-code.tsx"
import { QrCode } from "@/components/qr-code";

export function TableCode() {
  return (
    <QrCode
      value="https://example.com/order?table=12"
      level="H"
      margin={4}
      downloadFormats={["svg", "png", "pdf"]}
      downloadSize={2048}
      filename="table-12"
    />
  );
}
```

- **SVG**는 흐려지지 않고 어떤 크기로도 확대할 수 있어, 인쇄소나 디자인 도구에 가장 적합한 파일입니다.
- `downloadSize={2048}`의 **PNG**는 300 pixels per inch 기준으로 너비 약 17 cm(6.8 inches)까지 선명하게 인쇄됩니다. `downloadSize`는 50에서 5000 픽셀까지 지정할 수 있습니다.
- **PDF**에는 선택 사항인 `jspdf` 패키지가 필요합니다(`npm install jspdf`).
- `filename`은 확장자를 제외한 파일 이름을 지정합니다: `table-12.svg`, `table-12.png`.

## 접근성 [#accessibility]

- 코드는 `role="img"` 요소 안에 있으며, 이 요소의 `aria-label`은 `label`이거나, `label`이 없으면 `QR code: <value>`입니다. 값이 공개 링크가 아니라면 항상 `label`을 설정하세요.
- 다운로드 버튼은 시각적으로 숨겨진 범례 "Download QR code"가 있는 `<fieldset>`입니다. 다운로드 결과는 polite 라이브 리전을 통해 안내되며, 오류는 `role="alert"`와 함께 버튼 아래에 표시됩니다.
- `caption`은 figure의 `<figcaption>`으로 렌더링됩니다.

## 스캔되는지 확인하기 [#make-sure-it-scans]

- **대비.** 밝은 배경 위의 어두운 모듈은 모든 리더에서 스캔됩니다. 어두운 배경 위의 밝은 코드는 대부분의 휴대폰 카메라에서 작동하지만 일부 오래된 스캐너에서는 작동하지 않습니다.
- **여백(Quiet zone).** `margin`의 기본값은 2 모듈입니다. 코드가 사진, 패턴, 어두운 페이지 위에 있을 때는 4를 사용하세요.
- **로고.** 로고가 가리는 모듈이 있어도 코드가 유지되도록 `logo`와 함께 `level="H"`를 사용하세요.
- **인쇄 크기.** 약 25 cm 거리에서 스캔하는 짧은 링크에는 너비 약 2.5 cm의 코드가 필요합니다. 다른 거리에 대해서는 [인쇄 크기 계산기](/tools/print-size)로 계산해 보세요.
- **테스트.** 완성된 코드를 여러 대의 휴대폰으로 스캔하거나, 이미지를 [스캔 검사기](/tools/scan-checker)에 업로드해 보세요.
