`QrCodeScanner` ist eine Drop-Zone, die einen QR-Code im Browser aus einer Bilddatei dekodiert und dir den Text liefert. Nutze sie, um Tickets anhand von Screenshots einzuchecken, Codes aus hochgeladenen Fotos zu lesen oder einen selbst erzeugten Code zu prüfen. Sie liest Bilddateien, keinen Live-Kamerastream.

## Verwendung [#usage]

```tsx title="components/example.tsx"
import { QrCodeScanner } from "@/components/qr-code-scanner";
```

```tsx title="components/example.tsx"
<QrCodeScanner onResult={(value) => console.log(value)} />
```

Nutzer ziehen ein Bild in die Zone oder klicken, um eines auszuwählen. Das Dekodieren läuft im Browser mit den [Erkennungs-Helfern](/docs/qr-detection) von qrdx, sodass das Bild das Gerät nie verlässt. Das Ergebnis erscheint mit einem Button **Kopieren** und, wenn es eine `http`- oder `https`-URL ist, zusätzlich mit einem Button **Link öffnen**.

## Beispiele [#examples]

### Ein Ergebnis prüfen [#checking-a-result]

`onResult` erhält den dekodierten Text, sodass du darauf reagieren kannst, zum Beispiel um ein Ticket einzuchecken. `label` ändert die Überschrift in der Drop-Zone. Lade den Beispiel-Code oben herunter und zieh ihn hinein, um ein gültiges Ticket zu sehen.

## Was der Reader anzeigt [#what-the-reader-shows]

| Zustand | Meldung |
| --- | --- |
| Scan läuft | "Scanning…" |
| Kein Code im Bild | "No QR code found. Try a sharper or closer image." |
| Keine Bilddatei | "Choose an image file." |
| Das Bild kann nicht gelesen werden | "Could not read that image." |
| Gefunden | Der dekodierte Text, mit **Kopieren** und, bei Links, **Link öffnen** |

Der Decoder probiert das ganze Bild und vier Ausschnitte in mehreren Maßstäben aus, sodass auch ein Code gefunden wird, der nur einen kleinen Teil eines Screenshots einnimmt.

## Barrierefreiheit und Rendering [#accessibility-and-rendering]

- Die Drop-Zone ist ein `<label>` für ein visuell verstecktes Dateieingabefeld. Sie funktioniert daher wie jede Dateiauswahl mit Tastatur und Screenreadern.
- Ergebnisse und Fehler werden über eine Live-Region mit höflicher Ansage (polite) vorgelesen.
- **Link öffnen** öffnet in einem neuen Tab mit `rel="noopener noreferrer nofollow"`, damit eine gescannte Seite nicht auf deine zugreifen kann.
- Die Komponente ist eine Client Component. Sie braucht das Canvas des Browsers und lädt beim ersten Scan den Decoder bei Bedarf nach.
