`QrCodeDownload` è un unico pulsante che apre un menu di formati e dimensioni e salva il codice come file, oppure copia un PNG negli appunti. Usalo accanto a qualsiasi codice che visualizzi, con lo stesso oggetto di stile, così il file corrisponde all'anteprima.

## Utilizzo [#usage]

```tsx title="components/example.tsx"
import { QrCodeDownload } from "@/components/qr-code-download";
```

```tsx title="components/example.tsx"
<QrCodeDownload value="https://qrdx.dev" />
```

Il menu elenca ogni formato con un breve suggerimento, un selettore di dimensione e **Copia immagine**, che mette un PNG negli appunti. I file vengono generati nel browser; non viene caricato nulla.

## Esempi [#examples]

### Esportazione con stile [#styled-export]

Passa a `qr` lo stesso oggetto di stile che usi per il rendering a schermo, così ogni file esportato corrisponde all'anteprima. `formats`, `sizes`, `label` e `variant` definiscono il menu e il suo pulsante.

<ComponentPreview name="qr-code-download-styled" />

### Formati [#formats]

| Formato | Output |
| --- | --- |
| `png` | Immagine con lo sfondo del codice |
| `jpg` | Immagine con sfondo a tinta unita |
| `svg` | Vettoriale che si adatta a qualsiasi dimensione |
| `pdf` | Documento di una sola pagina. Richiede il pacchetto opzionale `jspdf` (`npm install jspdf`) |
| `eps` | Vettoriale per tipografie e strumenti di design |

Le dimensioni raster vanno da 50 a 5000 pixel. Passa una sola voce in `sizes` per nascondere il selettore di dimensione. Il menu mostra la dimensione in pixel accanto ai formati raster e "vector" accanto a SVG ed EPS.

### Dopo un download [#after-a-download]

`onComplete` viene chiamato con il formato, oppure con `"copy"`, dopo che un file è stato salvato o l'immagine è stata copiata. `onError` riceve l'errore quando un'esportazione fallisce; il messaggio compare anche sotto il pulsante.

```tsx title="components/tracked-download.tsx"
import { QrCodeDownload } from "@/components/qr-code-download";

export function TrackedDownload({ url }: { url: string }) {
  return (
    <QrCodeDownload
      value={url}
      onComplete={(action) => console.log("exported", action)}
      onError={(error) => console.error(error.message)}
    />
  );
}
```

## Accessibilità e rendering [#accessibility-and-rendering]

- Il trigger è il tuo Button, con `aria-busy` mentre un file viene generato. Un risultato viene annunciato tramite una live region polite, e un errore compare sotto il pulsante con `role="alert"`.
- Il menu è il tuo DropdownMenu, quindi la navigazione da tastiera e il focus seguono i componenti del tuo tema.
- La copia richiede un gesto dell'utente e un contesto sicuro (HTTPS o localhost); altrimenti il browser la rifiuta e l'errore compare sotto il pulsante.
- Il componente è un Client Component. Sul server non genera nulla di visivo oltre al pulsante.
