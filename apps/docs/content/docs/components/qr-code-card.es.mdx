`QrCodeCard` coloca un código QR en una tarjeta con un marco de llamada a la acción, un encabezado, una línea de texto y un pie para botones. Úsalo cuando el código sea el protagonista de la tarjeta: un display de mesa, una pantalla de check-in, la vista previa de un cartel de evento, un recuadro de "descarga nuestra app".

## Uso [#usage]

```tsx title="components/example.tsx"
import { QrCodeCard } from "@/components/qr-code-card";
```

```tsx title="components/example.tsx"
<QrCodeCard
  value="https://example.com/menu"
  title="Our menu"
  description="Scan to see today's specials."
/>
```

Todo lo que pases como children se muestra en el pie de la tarjeta, por ejemplo un botón de copiar o un [menú de descarga](/docs/components/qr-code-download).

## Ejemplos [#examples]

### Marcos [#frames]

`frame` coloca la llamada a la acción debajo del código (`"bottom"`), encima (`"top"`) o elimina el marco (`"none"`). `cta` cambia la etiqueta y `frameClassName` modifica el estilo del marco, por ejemplo con el color de tu marca.

<ComponentPreview name="qr-code-card-frames" />

Por defecto, el marco usa los colores `foreground` y `background` de tu tema, así que se lee bien tanto en modo claro como oscuro. El código en sí mantiene un fondo claro, que todos los lectores pueden leer.

### Estilo del código [#styling-the-code]

`qr` acepta cualquier opción de estilo de qrdx: `fgColor`, `bgColor`, degradados, `bodyPattern`, patrones de esquina, `logo` y `templateId`.

```tsx title="components/brand-card.tsx"
import { QrCodeCard } from "@/components/qr-code-card";

export function BrandCard() {
  return (
    <QrCodeCard
      value="https://example.com"
      title="example.com"
      qr={{
        fgColor: "#155DFC",
        bodyPattern: "rounded",
        cornerEyePattern: "extra-rounded",
      }}
    />
  );
}
```

## Accesibilidad y renderizado [#accessibility-and-rendering]

- El código se encuentra dentro de un elemento `role="img"` cuyo `aria-label` es `label`, o `QR code: <value>` si no se define. Define `label` cuando el valor no sea un enlace público.
- `title` se muestra como el encabezado de la tarjeta y `description` debajo; ambos aceptan cualquier nodo de React.
- El componente es un Client Component. Una página de Server Component puede importarlo y pasarle datos del servidor como props, y el código se renderiza en el servidor.
