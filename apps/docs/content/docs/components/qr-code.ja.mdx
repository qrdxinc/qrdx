`QrCode` は、アクセシブルな名前、キャプション、PNG と SVG のダウンロードボタンを備えたQRコードを SVG として表示する、自分のプロジェクトで管理できるコンポーネントです。注文確認、チケット、メニュー、Wi-Fi カードなど、ユーザーが保存したくなるコードを表示するページで使えます。

## 使い方 [#usage]

```tsx title="components/example.tsx"
import { QrCode } from "@/components/qr-code";
```

```tsx title="components/example.tsx"
<QrCode value="https://qrdx.dev" />
```

コードは `role="img"` のボックス内に SVG として表示されるので、どのサイズでも鮮明に表示され、スクリーンリーダーはリンク先を読み上げます。下の2つのボタンで、1024 px の PNG と SVG を保存できます。

## 例 [#examples]

### サイズ [#sizes]

`size` は画面上の幅と高さをピクセルで指定します。ダウンロードには `downloadSize` が使われるため、ページ上で小さなコードでも印刷に適したファイルを書き出せます。

<ComponentPreview name="qr-code-sizes" />

### 色 [#colors]

`fgColor` と `bgColor` には任意のCSSカラーを指定できます。`eyeColor` と `dotColor` は、3つのコーナーアイを個別に色付けします。どのスキャナーでも読み取れるよう、モジュールは背景より暗くしてください。

<ComponentPreview name="qr-code-colors" />

### グラデーション [#gradients]

色の代わりに qrdx のグラデーションを渡します。`angle` を指定する `linear` か、`radial` を使えます。グラデーションは PNG、SVG、PDF のダウンロードにも反映されます。

<ComponentPreview name="qr-code-gradient" />

### パターン [#patterns]

`bodyPattern` はデータモジュール、`cornerEyePattern` はコーナーの枠、`cornerEyeDotPattern` は枠内のドットの形を指定します。すべての形は[モジュールとアイの形を選ぶ](/docs/features/patterns)で確認できます。

<ComponentPreview name="qr-code-patterns" />

### ロゴ [#logo]

`logo` は画像を中央に配置し、その背後のモジュールを取り除きます。一部が隠れてもスキャンできるように、誤り訂正レベルは `H` を使ってください。データURLを使うとダウンロードにもロゴが含まれます。リモート画像には CORS ヘッダーが必要です。

<ComponentPreview name="qr-code-logo" />

### フレームテンプレート [#frame-templates]

`templateId` は、qrdx の[フレームテンプレート](/docs/features/templates)のひとつをコードの周囲に描画します。`caption` と組み合わせると、フレームの下に行動を促す文を表示できます。

<ComponentPreview name="qr-code-template" />

### ダウンロード形式 [#download-formats]

`downloadFormats` で表示するボタンを選びます。指定できるのは `png`、`jpg`、`svg`、`pdf` です。PDF の書き出しには、オプションの `jspdf` パッケージ(`npm install jspdf`)が必要です。`[]` を渡すとボタンを非表示にできます。

<ComponentPreview name="qr-code-downloads" />

形式とサイズを1つのメニューにまとめたい場合は、[QR Code Download](/docs/components/qr-code-download) を使ってください。

### ダークモード [#dark-mode]

ダークテーマでは、デフォルトの白い背景が最も安全です。明るいタイル上の暗いモジュールは、どのリーダーでも読み取れます。代わりにテーマに合わせたい場合は、`fgColor="currentColor"` を設定し、背景を透明にします。この場合、ダークモードではコードが反転します。スマートフォンのカメラは読み取れますが、一部の古いスキャナーでは読み取れません。

<ComponentPreview name="qr-code-dark-mode" />

## Next.js のページで使う [#in-a-nextjs-page]

`QrCode` は Client Component です(ダウンロードボタンのため、ファイルの先頭に `"use client"` があります)。そのため、Server Component のページからインポートして、サーバーのデータを props として渡せます。

```tsx title="app/menu/page.tsx"
import { QrCode } from "@/components/qr-code";

export default function MenuPage() {
  return (
    <QrCode
      value="https://example.com/menu"
      caption="Scan to see the menu"
      filename="menu-qr"
    />
  );
}
```

コード自体はサーバー側で描画されるので、ボタンが操作可能になる前からページの HTML に含まれています。App Router でのコードの描画について詳しくは、[Next.js のQRコード](/docs/nextjs)をご覧ください。

## リンク以外のコンテンツ [#any-content-not-only-links]

`value` は渡したとおりにエンコードされるため、Wi-Fi ネットワーク、連絡先カード、`mailto:`、`tel:`、プレーンテキストなど、あらゆるQRのペイロードを使えます。`label` を設定すると、スクリーンリーダーは生のペイロード(Wi-Fi の場合はパスワードを含みます)ではなく、そのコードが何をするものかを読み上げます。

```tsx title="components/guest-wifi.tsx"
import { QrCode } from "@/components/qr-code";

export function GuestWifi() {
  return (
    <QrCode
      value="WIFI:T:WPA;S:Cafe Guest;P:sunshine123;;"
      label="QR code to join the Cafe Guest Wi-Fi"
      caption="Cafe Guest Wi-Fi"
    />
  );
}
```

フォームからペイロードを作成する場合は、特殊文字を自動でエスケープする [Wi-Fi QR Code](/docs/components/wifi-qr-code) または [vCard QR Code](/docs/components/vcard-qr-code) を使ってください。

## 入力欄の値を使う [#a-value-from-an-input]

```tsx title="components/link-qr-code.tsx"
"use client";

import { useState } from "react";
import { QrCode } from "@/components/qr-code";

export function LinkQrCode() {
  const [value, setValue] = useState("https://example.com");
  return (
    <div className="grid justify-items-center gap-4">
      <input
        aria-label="Link"
        className="w-full rounded-md border px-3 py-2"
        value={value}
        onChange={(event) => setValue(event.target.value)}
      />
      {value ? <QrCode value={value} downloadFormats={[]} /> : null}
    </div>
  );
}
```

`downloadFormats={[]}` は、入力中にボタンを非表示にします。値が確定してから表示してください。

## 印刷向けのダウンロード [#print-ready-downloads]

```tsx title="components/table-code.tsx"
import { QrCode } from "@/components/qr-code";

export function TableCode() {
  return (
    <QrCode
      value="https://example.com/order?table=12"
      level="H"
      margin={4}
      downloadFormats={["svg", "png", "pdf"]}
      downloadSize={2048}
      filename="table-12"
    />
  );
}
```

- **SVG** はぼやけることなく任意のサイズに拡大できるため、印刷業者やデザインツールに渡すファイルとして最適です。
- `downloadSize={2048}` の **PNG** は、300 ppi で幅約 17 cm(6.8 インチ)まで鮮明に印刷できます。`downloadSize` には 50 から 5000 ピクセルを指定できます。
- **PDF** には、オプションの `jspdf` パッケージ(`npm install jspdf`)が必要です。
- `filename` は拡張子を除いたファイル名を指定します。例: `table-12.svg`、`table-12.png`。

## アクセシビリティ [#accessibility]

- コードは `role="img"` の要素内にあり、その `aria-label` は `label` の値です。`label` がない場合は `QR code: <value>` になります。値が公開リンクでない場合は、必ず `label` を設定してください。
- ダウンロードボタンは、視覚的に非表示の legend「Download QR code」を持つ `<fieldset>` です。ダウンロードの結果は polite のライブリージョンで通知され、エラーは `role="alert"` でボタンの下に表示されます。
- `caption` は、figure の `<figcaption>` として描画されます。

## 確実にスキャンできるようにする [#make-sure-it-scans]

- **コントラスト。** 明るい背景に暗いモジュールの組み合わせは、どのリーダーでもスキャンできます。暗い背景に明るいコードは、ほとんどのスマートフォンのカメラでは読み取れますが、一部の古いスキャナーでは読み取れません。
- **クワイエットゾーン。** `margin` のデフォルトは 2 モジュールです。コードが写真、模様、暗いページの上にある場合は 4 にしてください。
- **ロゴ。** `logo` を使う場合は `level="H"` を指定し、ロゴが覆うモジュールがあってもコードを読み取れるようにします。
- **印刷サイズ。** 約 25 cm 離れた位置から短いリンクをスキャンする場合、コードの幅は約 2.5 cm 必要です。他の距離については、[印刷サイズ計算ツール](/tools/print-size)で算出できます。
- **テストする。** 完成したコードを複数のスマートフォンでスキャンするか、画像を[スキャンチェッカー](/tools/scan-checker)にアップロードして確認してください。
