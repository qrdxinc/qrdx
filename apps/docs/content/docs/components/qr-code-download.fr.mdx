`QrCodeDownload` est un bouton unique qui ouvre un menu de formats et de tailles, puis enregistre le code dans un fichier ou copie un PNG dans le presse-papiers. Utilisez-le à côté de n'importe quel code que vous affichez, avec le même objet de style, afin que le fichier corresponde à l'aperçu.

## Utilisation [#usage]

```tsx title="components/example.tsx"
import { QrCodeDownload } from "@/components/qr-code-download";
```

```tsx title="components/example.tsx"
<QrCodeDownload value="https://qrdx.dev" />
```

Le menu liste chaque format avec une courte indication, un sélecteur de taille et **Copier l'image**, qui place un PNG dans le presse-papiers. Les fichiers sont générés dans le navigateur ; rien n'est envoyé.

## Exemples [#examples]

### Export avec style [#styled-export]

Donnez à `qr` le même objet de style que celui que vous affichez à l'écran, afin que chaque fichier exporté corresponde à l'aperçu. `formats`, `sizes`, `label` et `variant` définissent l'apparence du menu et de son bouton.

<ComponentPreview name="qr-code-download-styled" />

### Formats [#formats]

| Format | Résultat |
| --- | --- |
| `png` | Image avec l'arrière-plan du code |
| `jpg` | Image avec un arrière-plan uni |
| `svg` | Vectoriel qui s'adapte à toutes les tailles |
| `pdf` | Document d'une seule page. Nécessite le paquet facultatif `jspdf` (`npm install jspdf`) |
| `eps` | Vectoriel pour les imprimeurs et les outils de conception |

Les tailles raster vont de 50 à 5000 pixels. Passez une seule entrée dans `sizes` pour masquer le sélecteur de taille. Le menu affiche la taille en pixels à côté des formats raster et « vectoriel » à côté de SVG et EPS.

### Après un téléchargement [#after-a-download]

`onComplete` est appelé avec le format, ou `"copy"`, une fois qu'un fichier est enregistré ou que l'image est copiée. `onError` reçoit l'erreur lorsqu'un export échoue ; le message s'affiche aussi sous le bouton.

```tsx title="components/tracked-download.tsx"
import { QrCodeDownload } from "@/components/qr-code-download";

export function TrackedDownload({ url }: { url: string }) {
  return (
    <QrCodeDownload
      value={url}
      onComplete={(action) => console.log("exported", action)}
      onError={(error) => console.error(error.message)}
    />
  );
}
```

## Accessibilité et rendu [#accessibility-and-rendering]

- Le déclencheur est votre Button, avec `aria-busy` pendant la génération d'un fichier. Un résultat est annoncé via une région live en mode polite, et une erreur s'affiche sous le bouton avec `role="alert"`.
- Le menu est votre DropdownMenu : la navigation au clavier et le focus suivent donc les composants de votre thème.
- La copie nécessite un geste de l'utilisateur et un contexte sécurisé (HTTPS ou localhost) ; sinon, le navigateur la rejette et l'erreur s'affiche sous le bouton.
- Le composant est un Client Component. Il n'affiche rien de visuel côté serveur en dehors du bouton.
