`VCardQrCode` は、スマートフォンのカメラでスキャンすると連絡先を保存できるコードを表示し、その下に名前と役職を表示します。名刺、社員名簿、カンファレンスのバッジ、メール署名のページなどにお使いください。

## 使い方 [#usage]

```tsx title="components/example.tsx"
import { VCardQrCode } from "@/components/vcard-qr-code";
```

```tsx title="components/example.tsx"
<VCardQrCode
  contact={{
    firstName: "Ada",
    lastName: "Lovelace",
    organization: "Analytical Engines",
    email: "ada@example.com",
  }}
/>
```

コードをスキャンすると、スマートフォンのカメラが連絡先の保存を提案します。空のフィールドは含まれないため、コードが小さくなり、スキャンも速くなります。

## 例 [#examples]

### vCardビルダー [#vcard-builder]

`buildVCard` は、コードにエンコードされる vCard 3.0 のテキストを返します。カンマ、セミコロン、バックスラッシュ、改行はエスケープされます。任意のQRレンダラーと組み合わせて使えるほか、同じ連絡先を `.vcf` ファイルとしてダウンロードできるようにする際にも使えます。

<ComponentPreview name="vcard-qr-code-payload" />

連絡先カードはリンクよりも多くのテキストを保持するため、このコンポーネントではモジュールを大きく保てるよう、誤り訂正レベル `M` を使用します。必要なフィールドだけを追加し、印刷サイズの目安は[印刷サイズ計算ツール](/tools/print-size)で確認してください。

## アクセシビリティとレンダリング [#accessibility-and-rendering]

- コードには `aria-label="QR code with the contact card for <name>"` が設定されています。カードの各フィールドは読み上げられません。
- コードの下にある名前、役職、組織名は、figure の `<figcaption>` です。コードだけを表示するには `showDetails={false}` を設定します。
- このコンポーネントは Client Component ですが、コードはサーバー上でレンダリングされます。

### VCardContact [#vcardcontact]

<auto-type-table path="../../../../../packages/docs-assets/registry/qrdx/vcard-qr-code.tsx" name="VCardContact" />

`buildVCard(contact: VCardContact): string` は、`N`、`FN`、`ORG`、`TITLE`、`TEL`（勤務先と携帯）、`EMAIL`、`URL`、`ADR`、`NOTE` の各行を出力します。いずれも、そのフィールドが設定されている場合のみです。
