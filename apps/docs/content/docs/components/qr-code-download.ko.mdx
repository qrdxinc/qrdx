`QrCodeDownload`는 형식과 크기 메뉴를 여는 버튼 하나로, 코드를 파일로 저장하거나 PNG를 클립보드에 복사합니다. 화면에 렌더링하는 모든 코드 옆에 같은 스타일 객체와 함께 사용하면 파일이 미리보기와 일치합니다.

## 사용법 [#usage]

```tsx title="components/example.tsx"
import { QrCodeDownload } from "@/components/qr-code-download";
```

```tsx title="components/example.tsx"
<QrCodeDownload value="https://qrdx.dev" />
```

메뉴에는 각 형식과 짧은 설명, 크기 선택기, 그리고 PNG를 클립보드에 넣는 **이미지 복사**가 표시됩니다. 파일은 브라우저에서 렌더링되며 어디에도 업로드되지 않습니다.

## 예제 [#examples]

### 스타일이 적용된 내보내기 [#styled-export]

화면에 렌더링하는 것과 같은 스타일 객체를 `qr`에 전달하면 내보내는 모든 파일이 미리보기와 일치합니다. `formats`, `sizes`, `label`, `variant`로 메뉴와 버튼을 설정할 수 있습니다.

### 형식 [#formats]

| 형식 | 출력 |
| --- | --- |
| `png` | 코드의 배경이 포함된 이미지 |
| `jpg` | 단색 배경의 이미지 |
| `svg` | 어떤 크기로도 확대할 수 있는 벡터 |
| `pdf` | 한 페이지짜리 문서. 선택 패키지인 `jspdf`가 필요합니다(`npm install jspdf`) |
| `eps` | 인쇄소와 디자인 도구용 벡터 |

래스터 크기는 50~5000픽셀입니다. `sizes`에 항목을 하나만 전달하면 크기 선택기가 숨겨집니다. 메뉴에는 래스터 형식 옆에 픽셀 크기가, SVG와 EPS 옆에는 "vector"가 표시됩니다.

### 다운로드 후 [#after-a-download]

파일이 저장되거나 이미지가 복사되면 `onComplete`가 형식 또는 `"copy"`와 함께 호출됩니다. 내보내기에 실패하면 `onError`가 오류를 받으며, 메시지는 버튼 아래에도 표시됩니다.

```tsx title="components/tracked-download.tsx"
import { QrCodeDownload } from "@/components/qr-code-download";

export function TrackedDownload({ url }: { url: string }) {
  return (
    <QrCodeDownload
      value={url}
      onComplete={(action) => console.log("exported", action)}
      onError={(error) => console.error(error.message)}
    />
  );
}
```

## 접근성과 렌더링 [#accessibility-and-rendering]

- 트리거는 사용 중인 Button이며, 파일을 렌더링하는 동안 `aria-busy`가 설정됩니다. 결과는 polite 라이브 영역으로 안내되고, 오류는 `role="alert"`와 함께 버튼 아래에 표시됩니다.
- 메뉴는 사용 중인 DropdownMenu이므로 키보드 탐색과 포커스는 테마의 컴포넌트를 따릅니다.
- 복사하려면 사용자 동작과 보안 컨텍스트(HTTPS 또는 localhost)가 필요합니다. 그렇지 않으면 브라우저가 거부하며 오류가 버튼 아래에 표시됩니다.
- 이 컴포넌트는 Client Component입니다. 서버에서는 버튼 외에 시각적인 요소를 렌더링하지 않습니다.
