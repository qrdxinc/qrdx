`QrCodeCard` coloca um QR code em um card com uma moldura de chamada para ação, um título, uma linha de texto e um rodapé para botões. Use onde o código é o centro do card: um display de mesa, uma tela de check-in, a prévia de um cartaz de evento, um bloco de "baixe nosso app".

## Uso [#usage]

```tsx title="components/example.tsx"
import { QrCodeCard } from "@/components/qr-code-card";
```

```tsx title="components/example.tsx"
<QrCodeCard
  value="https://example.com/menu"
  title="Our menu"
  description="Scan to see today's specials."
/>
```

Tudo o que você passar como children é renderizado no rodapé do card, como um botão de copiar ou um [menu de download](/docs/components/qr-code-download).

## Exemplos [#examples]

### Molduras [#frames]

`frame` coloca a chamada para ação embaixo do código (`"bottom"`), em cima dele (`"top"`) ou omite a moldura (`"none"`). `cta` muda o texto, e `frameClassName` altera o estilo da moldura, por exemplo com a cor da sua marca.

<ComponentPreview name="qr-code-card-frames" />

Por padrão, a moldura usa as cores `foreground` e `background` do seu tema, então fica legível nos modos claro e escuro. O código em si mantém um fundo claro, que todo leitor consegue ler.

### Estilizando o código [#styling-the-code]

`qr` aceita qualquer opção de estilo do qrdx: `fgColor`, `bgColor`, gradientes, `bodyPattern`, padrões de canto, `logo` e `templateId`.

```tsx title="components/brand-card.tsx"
import { QrCodeCard } from "@/components/qr-code-card";

export function BrandCard() {
  return (
    <QrCodeCard
      value="https://example.com"
      title="example.com"
      qr={{
        fgColor: "#155DFC",
        bodyPattern: "rounded",
        cornerEyePattern: "extra-rounded",
      }}
    />
  );
}
```

## Acessibilidade e renderização [#accessibility-and-rendering]

- O código fica dentro de um elemento `role="img"` cujo `aria-label` é `label`, ou `QR code: <value>` se não houver `label`. Defina `label` quando o valor não for um link público.
- `title` é renderizado como o título do card e `description` logo abaixo; ambos aceitam qualquer nó React.
- O componente é um Client Component. Uma página Server Component pode importá-lo e passar dados do servidor como props, e o código é renderizado no servidor.
