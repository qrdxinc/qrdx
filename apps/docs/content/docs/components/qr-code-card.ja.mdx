`QrCodeCard` は、行動を促すフレーム付きのQRコード、見出し、説明文、ボタン用のフッターをカードにまとめます。コードがカードの主役になる場面で使います。たとえば、テーブルテント、チェックイン画面、イベントポスターのプレビュー、「アプリをダウンロード」タイルなどです。

## 使い方 [#usage]

```tsx title="components/example.tsx"
import { QrCodeCard } from "@/components/qr-code-card";
```

```tsx title="components/example.tsx"
<QrCodeCard
  value="https://example.com/menu"
  title="Our menu"
  description="Scan to see today's specials."
/>
```

children として渡した要素はすべてカードのフッターに表示されます。コピーボタンや[ダウンロードメニュー](/docs/components/qr-code-download)などを置けます。

## 例 [#examples]

### フレーム [#frames]

`frame` は、行動を促すフレームをコードの下 (`"bottom"`)、上 (`"top"`) に置くか、フレームなし (`"none"`) にします。`cta` はラベルを変更し、`frameClassName` はフレームのスタイルを変更します。たとえばブランドカラーを適用できます。

<ComponentPreview name="qr-code-card-frames" />

フレームには、デフォルトでテーマの `foreground` と `background` の色が使われるため、ライトモードでもダークモードでも読みやすい状態を保てます。コード自体は明るい背景のままなので、どのスキャナーでも読み取れます。

### コードのスタイル設定 [#styling-the-code]

`qr` には、`fgColor`、`bgColor`、グラデーション、`bodyPattern`、コーナーパターン、`logo`、`templateId` など、qrdx のあらゆるスタイルオプションを指定できます。

```tsx title="components/brand-card.tsx"
import { QrCodeCard } from "@/components/qr-code-card";

export function BrandCard() {
  return (
    <QrCodeCard
      value="https://example.com"
      title="example.com"
      qr={{
        fgColor: "#155DFC",
        bodyPattern: "rounded",
        cornerEyePattern: "extra-rounded",
      }}
    />
  );
}
```

## アクセシビリティとレンダリング [#accessibility-and-rendering]

- コードは `role="img"` の要素内に配置され、その `aria-label` には `label` が使われます。`label` がない場合は `QR code: <value>` になります。値が公開リンクでない場合は `label` を設定してください。
- `title` はカードの見出しとして、`description` はその下に表示されます。どちらも任意の React ノードを受け取れます。
- このコンポーネントは Client Component です。Server Component のページからインポートして、サーバーのデータを props として渡せます。コードはサーバー側でレンダリングされます。
