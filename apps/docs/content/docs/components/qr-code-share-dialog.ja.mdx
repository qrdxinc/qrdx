`QrCodeShareDialog` は、リンクをQRコードとして表示するダイアログを開きます。ダイアログには、コピーできるリンク欄、PNGのダウンロード、スマートフォンではシステムの共有シートも用意されています。招待、ドキュメント、プロフィールなど、近くにいる相手にリンクを渡す場面で、「共有」ボタンの先に配置して使います。

## 使い方 [#usage]

```tsx title="components/example.tsx"
import { QrCodeShareDialog } from "@/components/qr-code-share-dialog";
```

```tsx title="components/example.tsx"
<QrCodeShareDialog url="https://example.com/invite/abc123" />
```

ダイアログには、コード、コピーボタン付きの読み取り専用のリンク欄、**Download PNG** が表示されます。共有シートに対応しているデバイス（ほとんどのスマートフォン）では、**Share…** ボタンからそれを開けます。

## 例 [#examples]

### カスタムトリガー [#custom-trigger]

ツールバーのアイコンボタンなど、独自のトリガーを children として渡します。`title`、`description`、`qr` でダイアログをカスタマイズできます。

<ComponentPreview name="qr-code-share-dialog-trigger" />

### 制御コンポーネントとして使う [#controlled]

このダイアログは [Dialog](https://ui.shadcn.com/docs/components/dialog) の props を受け取るので、コードから開くことができます。

```tsx title="components/share-after-save.tsx"
"use client";

import { useState } from "react";
import { QrCodeShareDialog } from "@/components/qr-code-share-dialog";

export function ShareAfterSave({ url }: { url: string }) {
  const [open, setOpen] = useState(false);
  return (
    <>
      <button type="button" onClick={() => setOpen(true)}>
        Save and share
      </button>
      <QrCodeShareDialog url={url} open={open} onOpenChange={setOpen} />
    </>
  );
}
```

## アクセシビリティとレンダリング [#accessibility-and-rendering]

- このダイアログはお使いの Dialog そのものなので、開くとフォーカスがダイアログ内に移り、閉じるとトリガーに戻ります。
- コードには `aria-label="QR code: <url>"` が設定されています。リンク欄には視覚的に非表示の「Link」ラベルがあります。コピーボタンのラベルは、コピー後しばらくのあいだ「Link copied」に変わります。
- **Share…** ボタンは `navigator.share` が存在する環境でのみ、ブラウザーでの最初のレンダリング後に表示されます。これにより、サーバーのHTMLとクライアントの初回描画が一致します。
- リンク欄をクリックすると、リンク全体が選択されます。コピーにはセキュアコンテキスト（HTTPS または localhost）が必要です。
