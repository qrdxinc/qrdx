`QrCode` muestra un código QR como SVG con un nombre accesible, un pie de imagen y botones de descarga en PNG y SVG, todo en un componente que es tuyo. Úsalo donde una página muestre un código que alguien pueda querer guardar: una confirmación de pedido, una entrada, un menú, una tarjeta de Wi-Fi.

## Uso [#usage]

```tsx title="components/example.tsx"
import { QrCode } from "@/components/qr-code";
```

```tsx title="components/example.tsx"
<QrCode value="https://qrdx.dev" />
```

El código se muestra como SVG dentro de un cuadro con `role="img"`, así que se ve nítido a cualquier tamaño y los lectores de pantalla anuncian a dónde enlaza. Dos botones debajo guardan un PNG de 1024 px y un SVG.

## Ejemplos [#examples]

### Tamaños [#sizes]

`size` define el ancho y el alto en pantalla, en píxeles. Las descargas usan `downloadSize`, de modo que un código pequeño en la página igualmente exporta un archivo listo para imprimir.

<ComponentPreview name="qr-code-sizes" />

### Colores [#colors]

`fgColor` y `bgColor` aceptan cualquier color CSS. `eyeColor` y `dotColor` colorean por separado los tres ojos de las esquinas. Mantén los módulos más oscuros que el fondo para que cualquier lector pueda leer el código.

<ComponentPreview name="qr-code-colors" />

### Degradados [#gradients]

Pasa un degradado de qrdx en lugar de un color: `linear` con un `angle`, o `radial`. Los degradados se mantienen en las descargas en PNG, SVG y PDF.

<ComponentPreview name="qr-code-gradient" />

### Patrones [#patterns]

`bodyPattern` da forma a los módulos de datos, `cornerEyePattern` a los marcos de las esquinas y `cornerEyeDotPattern` a los puntos que hay dentro de ellos. [Elegir formas de módulos y ojos](/docs/features/patterns) enumera todas las formas.

<ComponentPreview name="qr-code-patterns" />

### Logo [#logo]

`logo` coloca una imagen en el centro y despeja los módulos que quedan detrás. Usa el nivel de corrección de errores `H` para que el código siga escaneándose aunque esté parcialmente cubierto. Una URL de datos mantiene el logo en las descargas; una imagen remota necesita encabezados CORS.

<ComponentPreview name="qr-code-logo" />

### Plantillas de marco [#frame-templates]

`templateId` dibuja alrededor del código una de las [plantillas de marco](/docs/features/templates) de qrdx. Combínalo con `caption` para añadir una llamada a la acción bajo el marco.

<ComponentPreview name="qr-code-template" />

### Formatos de descarga [#download-formats]

`downloadFormats` elige los botones: `png`, `jpg`, `svg` y `pdf`. La exportación a PDF necesita el paquete opcional `jspdf` (`npm install jspdf`). Pasa `[]` para ocultar los botones.

<ComponentPreview name="qr-code-downloads" />

Para un único menú con formatos y tamaños, usa [QR Code Download](/docs/components/qr-code-download).

### Modo oscuro [#dark-mode]

El fondo blanco predeterminado es la opción más segura en temas oscuros: módulos oscuros sobre un recuadro claro se escanean con cualquier lector. Para seguir el tema, define `fgColor="currentColor"` y un fondo transparente. Así el código se invierte en modo oscuro, algo que las cámaras de los teléfonos leen pero que algunos lectores antiguos no.

<ComponentPreview name="qr-code-dark-mode" />

## En una página de Next.js [#in-a-nextjs-page]

`QrCode` es un Client Component (su archivo empieza con `"use client"` por los botones de descarga), así que una página que sea Server Component puede importarlo y pasarle datos del servidor como props:

```tsx title="app/menu/page.tsx"
import { QrCode } from "@/components/qr-code";

export default function MenuPage() {
  return (
    <QrCode
      value="https://example.com/menu"
      caption="Scan to see the menu"
      filename="menu-qr"
    />
  );
}
```

El código en sí se sigue renderizando en el servidor, por lo que ya está en el HTML de la página antes de que los botones sean interactivos. Para saber más sobre cómo renderizar códigos en el App Router, consulta [Códigos QR en Next.js](/docs/nextjs).

## Cualquier contenido, no solo enlaces [#any-content-not-only-links]

`value` se codifica exactamente como lo pases, así que sirve cualquier contenido QR: una red Wi-Fi, una tarjeta de contacto, `mailto:`, `tel:` o texto sin formato. Define `label` para que los lectores de pantalla anuncien qué hace el código en lugar del contenido en bruto, que en el caso del Wi-Fi incluye la contraseña.

```tsx title="components/guest-wifi.tsx"
import { QrCode } from "@/components/qr-code";

export function GuestWifi() {
  return (
    <QrCode
      value="WIFI:T:WPA;S:Cafe Guest;P:sunshine123;;"
      label="QR code to join the Cafe Guest Wi-Fi"
      caption="Cafe Guest Wi-Fi"
    />
  );
}
```

Para construir el contenido a partir de un formulario, usa [Wi-Fi QR Code](/docs/components/wifi-qr-code) o [vCard QR Code](/docs/components/vcard-qr-code), que escapan los caracteres especiales por ti.

## Un valor desde un campo de entrada [#a-value-from-an-input]

```tsx title="components/link-qr-code.tsx"
"use client";

import { useState } from "react";
import { QrCode } from "@/components/qr-code";

export function LinkQrCode() {
  const [value, setValue] = useState("https://example.com");
  return (
    <div className="grid justify-items-center gap-4">
      <input
        aria-label="Link"
        className="w-full rounded-md border px-3 py-2"
        value={value}
        onChange={(event) => setValue(event.target.value)}
      />
      {value ? <QrCode value={value} downloadFormats={[]} /> : null}
    </div>
  );
}
```

`downloadFormats={[]}` oculta los botones mientras alguien todavía está escribiendo; muéstralos cuando el valor sea definitivo.

## Descargas listas para imprimir [#print-ready-downloads]

```tsx title="components/table-code.tsx"
import { QrCode } from "@/components/qr-code";

export function TableCode() {
  return (
    <QrCode
      value="https://example.com/order?table=12"
      level="H"
      margin={4}
      downloadFormats={["svg", "png", "pdf"]}
      downloadSize={2048}
      filename="table-12"
    />
  );
}
```

- **SVG** se escala a cualquier tamaño sin perder nitidez, por lo que es el mejor archivo para una imprenta o una herramienta de diseño.
- **PNG** con `downloadSize={2048}` se imprime con nitidez hasta unos 17 cm (6,8 pulgadas) de ancho a 300 píxeles por pulgada. `downloadSize` admite de 50 a 5000 píxeles.
- **PDF** necesita el paquete opcional `jspdf` (`npm install jspdf`).
- `filename` da nombre al archivo sin su extensión: `table-12.svg`, `table-12.png`.

## Accesibilidad [#accessibility]

- El código está en un elemento `role="img"` cuyo `aria-label` es `label`, o `QR code: <value>` si no se define. Define `label` siempre que el valor no sea un enlace público.
- Los botones de descarga son un `<fieldset>` con una leyenda visualmente oculta, "Descargar código QR". El resultado de una descarga se anuncia mediante una región activa educada (polite) y un error aparece bajo los botones con `role="alert"`.
- `caption` se muestra como el `<figcaption>` de la figura.

## Asegúrate de que se escanee [#make-sure-it-scans]

- **Contraste.** Los módulos oscuros sobre un fondo claro se escanean con cualquier lector. Un código claro sobre fondo oscuro funciona en la mayoría de las cámaras de teléfono, pero no en algunos lectores antiguos.
- **Zona de silencio.** `margin` es 2 módulos de forma predeterminada. Usa 4 cuando el código esté sobre una foto, un patrón o una página oscura.
- **Logos.** Usa `level="H"` con un `logo`, para que el código sobreviva a los módulos que el logo tapa.
- **Tamaño de impresión.** Un enlace corto escaneado desde unos 25 cm necesita un código de unos 2,5 cm de ancho; la [calculadora de tamaño de impresión](/tools/print-size) calcula el tamaño para otras distancias.
- **Pruébalo.** Escanea el código terminado con varios teléfonos, o sube una imagen al [verificador de escaneo](/tools/scan-checker).
