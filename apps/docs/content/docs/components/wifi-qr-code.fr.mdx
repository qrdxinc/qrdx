`WifiQrCode` affiche un code qui connecte un téléphone à un réseau Wi-Fi lorsque son appareil photo le scanne, avec le nom du réseau en dessous. Utilisez-le pour une carte du réseau invité à l'accueil, un chevalet de table dans un café ou la page de bienvenue d'une location.

## Utilisation [#usage]

```tsx title="components/example.tsx"
import { WifiQrCode } from "@/components/wifi-qr-code";
```

```tsx title="components/example.tsx"
<WifiQrCode ssid="Cafe Guest" password="espresso-2024" />
```

Les appareils photo d'iOS et d'Android proposent de rejoindre le réseau lorsqu'ils scannent le code. Aucune application n'est nécessaire. Sous le code, le composant affiche le nom du réseau et « Scan with your camera to join ».

## Exemples [#examples]

### Variantes [#variants]

`showPassword` affiche le mot de passe pour les invités qui préfèrent le saisir. Utilisez `encryption="nopass"` pour les réseaux ouverts et `hidden` pour les réseaux qui ne diffusent pas leur nom.

<ComponentPreview name="wifi-qr-code-variants" />

### Générateur de payload [#payload-builder]

`buildWifiPayload` renvoie le texte `WIFI:` encodé par le code. Il échappe `\`, `;`, `,`, `:` et `"` dans les noms et les mots de passe, ce qui est généralement là que les payloads écrits à la main posent problème. Utilisez-le avec n'importe quel moteur de rendu de QR code, ou pour afficher le payload à des fins de débogage.

<ComponentPreview name="wifi-qr-code-payload" />

## Accessibilité et rendu [#accessibility-and-rendering]

- Le code a `aria-label="QR code to join the Wi-Fi network <ssid>"`. Le payload, qui contient le mot de passe, n'est jamais lu à voix haute.
- Le nom et le mot de passe sous le code constituent le `<figcaption>` de la figure. Définissez `showDetails={false}` pour afficher le code seul.
- Le composant est un Client Component, et le code est rendu côté serveur.

Toute autre prop, comme `className`, est transmise au `<figure>` englobant.

### buildWifiPayload [#buildwifipayload]

`buildWifiPayload(network: WifiNetwork): string` prend les mêmes champs de réseau que le composant : `ssid`, `password`, `encryption` et `hidden`. `"WPA"` couvre WPA, WPA2 et WPA3 ; `"WEP"` et `"nopass"` sont les autres valeurs. Avec `"nopass"`, le mot de passe est omis.
