`QrCodeShareDialog` apre una finestra che mostra un link come QR code, con il link in un campo che puoi copiare, il download in PNG e, sui telefoni, il menu di condivisione del sistema. Usalo dietro un pulsante "Condividi" ovunque le persone passino un link a qualcuno che hanno accanto: un invito, un documento, un profilo.

## Utilizzo [#usage]

```tsx title="components/example.tsx"
import { QrCodeShareDialog } from "@/components/qr-code-share-dialog";
```

```tsx title="components/example.tsx"
<QrCodeShareDialog url="https://example.com/invite/abc123" />
```

La finestra mostra il codice, il link in un campo di sola lettura con un pulsante di copia e **Scarica PNG**. Sui dispositivi con un menu di condivisione (la maggior parte dei telefoni), un pulsante **Condividi…** lo apre.

## Esempi [#examples]

### Trigger personalizzato [#custom-trigger]

Passa il tuo trigger come children, ad esempio un pulsante con icona in una barra degli strumenti. `title`, `description` e `qr` personalizzano la finestra.

<ComponentPreview name="qr-code-share-dialog-trigger" />

### Controllato [#controlled]

La finestra accetta le props di [Dialog](https://ui.shadcn.com/docs/components/dialog), quindi puoi aprirla dal codice:

```tsx title="components/share-after-save.tsx"
"use client";

import { useState } from "react";
import { QrCodeShareDialog } from "@/components/qr-code-share-dialog";

export function ShareAfterSave({ url }: { url: string }) {
  const [open, setOpen] = useState(false);
  return (
    <>
      <button type="button" onClick={() => setOpen(true)}>
        Save and share
      </button>
      <QrCodeShareDialog url={url} open={open} onOpenChange={setOpen} />
    </>
  );
}
```

## Accessibilità e rendering [#accessibility-and-rendering]

- La finestra è il tuo Dialog, quindi il focus si sposta al suo interno quando si apre e torna al trigger quando si chiude.
- Il codice ha `aria-label="QR code: <url>"` e il campo del link ha un'etichetta "Link" nascosta visivamente. L'etichetta del pulsante di copia cambia in "Link copiato" per un istante dopo la copia.
- Il pulsante **Condividi…** compare solo dove esiste `navigator.share`, dopo il primo rendering nel browser, così l'HTML del server e il primo rendering del client coincidono.
- Facendo clic sul campo del link, l'intero link viene selezionato. Per copiare serve un contesto sicuro (HTTPS o localhost).
