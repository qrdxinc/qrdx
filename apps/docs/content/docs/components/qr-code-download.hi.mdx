`QrCodeDownload` एक ऐसा बटन है जो फ़ॉर्मैट और साइज़ का मेन्यू खोलता है और कोड को फ़ाइल के रूप में सेव करता है, या PNG को क्लिपबोर्ड पर कॉपी करता है। इसे अपने रेंडर किए हर कोड के बगल में उसी स्टाइल ऑब्जेक्ट के साथ इस्तेमाल करें, ताकि फ़ाइल प्रीव्यू से मेल खाए।

## इस्तेमाल [#usage]

```tsx title="components/example.tsx"
import { QrCodeDownload } from "@/components/qr-code-download";
```

```tsx title="components/example.tsx"
<QrCodeDownload value="https://qrdx.dev" />
```

मेन्यू में हर फ़ॉर्मैट एक छोटे हिंट के साथ दिखता है, साथ में साइज़ पिकर और **Copy image** होता है, जो PNG को क्लिपबोर्ड पर रखता है। फ़ाइलें ब्राउज़र में ही रेंडर होती हैं; कुछ भी अपलोड नहीं होता।

## उदाहरण [#examples]

### स्टाइल के साथ एक्सपोर्ट [#styled-export]

`qr` को वही स्टाइल ऑब्जेक्ट दें जो आप स्क्रीन पर रेंडर करते हैं, ताकि हर एक्सपोर्ट की गई फ़ाइल प्रीव्यू से मेल खाए। `formats`, `sizes`, `label` और `variant` मेन्यू और उसके बटन का रूप तय करते हैं।

<ComponentPreview name="qr-code-download-styled" />

### फ़ॉर्मैट [#formats]

| फ़ॉर्मैट | आउटपुट |
| --- | --- |
| `png` | कोड के बैकग्राउंड वाली इमेज |
| `jpg` | ठोस बैकग्राउंड वाली इमेज |
| `svg` | वेक्टर, जो किसी भी साइज़ तक स्केल होता है |
| `pdf` | एक पेज का डॉक्यूमेंट। इसके लिए वैकल्पिक `jspdf` पैकेज चाहिए (`npm install jspdf`) |
| `eps` | प्रिंट शॉप और डिज़ाइन टूल्स के लिए वेक्टर |

रास्टर साइज़ 50 से 5000 पिक्सल तक होती हैं। साइज़ पिकर छिपाने के लिए `sizes` में सिर्फ़ एक एंट्री दें। मेन्यू रास्टर फ़ॉर्मैट के बगल में पिक्सल साइज़ और SVG तथा EPS के बगल में "vector" दिखाता है।

### डाउनलोड के बाद [#after-a-download]

फ़ाइल सेव होने या इमेज कॉपी होने के बाद `onComplete` को फ़ॉर्मैट के साथ, या `"copy"` के साथ कॉल किया जाता है। एक्सपोर्ट फ़ेल होने पर `onError` को एरर मिलता है; संदेश बटन के नीचे भी दिखता है।

```tsx title="components/tracked-download.tsx"
import { QrCodeDownload } from "@/components/qr-code-download";

export function TrackedDownload({ url }: { url: string }) {
  return (
    <QrCodeDownload
      value={url}
      onComplete={(action) => console.log("exported", action)}
      onError={(error) => console.error(error.message)}
    />
  );
}
```

## एक्सेसिबिलिटी और रेंडरिंग [#accessibility-and-rendering]

- ट्रिगर आपका Button है, जिसमें फ़ाइल रेंडर होने के दौरान `aria-busy` रहता है। नतीजा polite live region से बताया जाता है, और एरर बटन के नीचे `role="alert"` के साथ दिखता है।
- मेन्यू आपका DropdownMenu है, इसलिए कीबोर्ड नेविगेशन और फ़ोकस आपकी थीम के कॉम्पोनेंट्स के अनुसार चलते हैं।
- कॉपी करने के लिए यूज़र का कोई एक्शन और सिक्योर कॉन्टेक्स्ट (HTTPS या localhost) चाहिए; वरना ब्राउज़र उसे रिजेक्ट कर देता है और एरर बटन के नीचे दिखता है।
- यह कॉम्पोनेंट एक Client Component है। सर्वर पर यह बटन के अलावा कुछ भी विज़ुअल रेंडर नहीं करता।
