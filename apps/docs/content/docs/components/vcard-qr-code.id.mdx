`VCardQrCode` menampilkan kode yang menyimpan kontak saat kamera ponsel memindainya, dengan nama dan jabatan di bawahnya. Gunakan pada kartu nama, direktori staf, tanda pengenal konferensi, atau halaman tanda tangan email.

## Penggunaan [#usage]

```tsx title="components/example.tsx"
import { VCardQrCode } from "@/components/vcard-qr-code";
```

```tsx title="components/example.tsx"
<VCardQrCode
  contact={{
    firstName: "Ada",
    lastName: "Lovelace",
    organization: "Analytical Engines",
    email: "ada@example.com",
  }}
/>
```

Kamera ponsel menawarkan untuk menyimpan kontak saat memindai kode tersebut. Kolom yang kosong dihilangkan, sehingga kode tetap kecil dan cepat dipindai.

## Contoh [#examples]

### Pembuat vCard [#vcard-builder]

`buildVCard` mengembalikan teks vCard 3.0 yang dienkode oleh kode tersebut, dengan koma, titik koma, garis miring terbalik, dan jeda baris yang di-escape. Gunakan dengan perender QR apa pun, atau untuk menawarkan kontak yang sama sebagai unduhan `.vcf`.

<ComponentPreview name="vcard-qr-code-payload" />

Kartu kontak memuat teks lebih banyak daripada sebuah tautan, sehingga komponen ini menggunakan tingkat koreksi kesalahan `M` agar modulnya tetap besar. Tambahkan hanya kolom yang dibutuhkan orang, dan periksa ukuran cetak yang sesuai dengan [kalkulator ukuran cetak](/tools/print-size).

## Aksesibilitas dan perenderan [#accessibility-and-rendering]

- Kode memiliki `aria-label="QR code with the contact card for <name>"`. Isi kolom kartu tidak dibacakan.
- Nama serta jabatan dan organisasi di bawah kode adalah `<figcaption>` dari figure. Atur `showDetails={false}` untuk menampilkan kode saja.
- Komponen ini adalah Client Component, dan kodenya dirender di server.
