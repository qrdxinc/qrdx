`WifiQrCode` は、スマートフォンのカメラでスキャンするとWi-Fiネットワークに接続できるコードを表示し、その下にネットワーク名を表示します。受付のゲスト用ネットワークカードや、カフェのテーブルPOP、民泊のウェルカムページなどにお使いください。

## 使い方 [#usage]

```tsx title="components/example.tsx"
import { WifiQrCode } from "@/components/wifi-qr-code";
```

```tsx title="components/example.tsx"
<WifiQrCode ssid="Cafe Guest" password="espresso-2024" />
```

iOSとAndroidのカメラは、コードをスキャンするとネットワークへの接続を提案します。アプリは不要です。コードの下には、ネットワーク名と「Scan with your camera to join」が表示されます。

## 例 [#examples]

### バリエーション [#variants]

`showPassword` を指定すると、手入力するゲスト向けにパスワードを表示します。オープンネットワークには `encryption="nopass"` を、ネットワーク名を公開していないネットワークには `hidden` を使用してください。

<ComponentPreview name="wifi-qr-code-variants" />

### ペイロードビルダー [#payload-builder]

`buildWifiPayload` は、コードにエンコードされる `WIFI:` 形式のテキストを返します。ネットワーク名とパスワード内の `\`、`;`、`,`、`:`、`"` をエスケープします。手書きのペイロードでは、ここで問題が起きがちです。任意のQRレンダラーと組み合わせて使えるほか、デバッグ用にペイロードを出力する際にも使えます。

<ComponentPreview name="wifi-qr-code-payload" />

## アクセシビリティとレンダリング [#accessibility-and-rendering]

- コードには `aria-label="QR code to join the Wi-Fi network <ssid>"` が設定されています。パスワードを含むペイロードが読み上げられることはありません。
- コードの下に表示されるネットワーク名とパスワードは、figure の `<figcaption>` です。コードだけを表示するには `showDetails={false}` を設定します。
- このコンポーネントはClient Componentで、コードはサーバー上でレンダリングされます。

`className` などその他のpropsは、外側の `<figure>` に渡されます。

### buildWifiPayload [#buildwifipayload]

`buildWifiPayload(network: WifiNetwork): string` は、コンポーネントと同じネットワークのフィールド（`ssid`、`password`、`encryption`、`hidden`）を受け取ります。`"WPA"` はWPA、WPA2、WPA3に対応します。ほかの値は `"WEP"` と `"nopass"` です。`"nopass"` の場合、パスワードは含まれません。
