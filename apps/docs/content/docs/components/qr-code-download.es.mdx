`QrCodeDownload` es un único botón que abre un menú de formatos y tamaños y guarda el código como archivo, o copia un PNG al portapapeles. Úsalo junto a cualquier código que renderices, con el mismo objeto de estilo, para que el archivo coincida con la vista previa.

## Uso [#usage]

```tsx title="components/example.tsx"
import { QrCodeDownload } from "@/components/qr-code-download";
```

```tsx title="components/example.tsx"
<QrCodeDownload value="https://qrdx.dev" />
```

El menú muestra cada formato con una breve descripción, un selector de tamaño y **Copiar imagen**, que pone un PNG en el portapapeles. Los archivos se generan en el navegador; no se sube nada.

## Ejemplos [#examples]

### Exportación con estilo [#styled-export]

Pasa a `qr` el mismo objeto de estilo que renderizas en pantalla, para que cada archivo exportado coincida con la vista previa. `formats`, `sizes`, `label` y `variant` dan forma al menú y a su botón.

### Formatos [#formats]

| Formato | Resultado |
| --- | --- |
| `png` | Imagen con el fondo del código |
| `jpg` | Imagen con fondo sólido |
| `svg` | Vector que se escala a cualquier tamaño |
| `pdf` | Documento de una sola página. Requiere el paquete opcional `jspdf` (`npm install jspdf`) |
| `eps` | Vector para imprentas y herramientas de diseño |

Los tamaños de imagen de mapa de bits van de 50 a 5000 píxeles. Pasa una sola entrada en `sizes` para ocultar el selector de tamaño. El menú muestra el tamaño en píxeles junto a los formatos de mapa de bits y "vector" junto a SVG y EPS.

### Después de una descarga [#after-a-download]

`onComplete` se llama con el formato, o con `"copy"`, después de guardar un archivo o copiar la imagen. `onError` recibe el error cuando falla una exportación; el mensaje también aparece debajo del botón.

```tsx title="components/tracked-download.tsx"
import { QrCodeDownload } from "@/components/qr-code-download";

export function TrackedDownload({ url }: { url: string }) {
  return (
    <QrCodeDownload
      value={url}
      onComplete={(action) => console.log("exported", action)}
      onError={(error) => console.error(error.message)}
    />
  );
}
```

## Accesibilidad y renderizado [#accessibility-and-rendering]

- El disparador es tu Button, con `aria-busy` mientras se genera un archivo. El resultado se anuncia mediante una región activa educada (polite) y un error aparece debajo del botón con `role="alert"`.
- El menú es tu DropdownMenu, así que la navegación con teclado y el foco siguen los componentes de tu tema.
- Copiar requiere un gesto del usuario y un contexto seguro (HTTPS o localhost); de lo contrario el navegador lo rechaza y el error aparece debajo del botón.
- El componente es un Client Component. En el servidor no renderiza nada visual aparte del botón.
