`QrCodeCard`는 행동 유도 프레임, 제목, 한 줄 설명, 버튼용 푸터와 함께 QR 코드를 카드에 담아 줍니다. 테이블 텐트, 체크인 화면, 행사 포스터 미리보기, "앱 다운로드" 타일처럼 코드가 카드의 핵심인 곳에 사용하세요.

## 사용법 [#usage]

```tsx title="components/example.tsx"
import { QrCodeCard } from "@/components/qr-code-card";
```

```tsx title="components/example.tsx"
<QrCodeCard
  value="https://example.com/menu"
  title="Our menu"
  description="Scan to see today's specials."
/>
```

children으로 전달하는 내용은 모두 카드 푸터에 렌더링됩니다. 복사 버튼이나 [다운로드 메뉴](/docs/components/qr-code-download) 등을 넣을 수 있습니다.

## 예시 [#examples]

### 프레임 [#frames]

`frame`은 행동 유도 문구를 코드 아래(`"bottom"`)나 위(`"top"`)에 놓거나, 프레임을 없앱니다(`"none"`). `cta`로 문구를 바꾸고, `frameClassName`으로 프레임 스타일을 바꿀 수 있습니다. 예를 들어 브랜드 색상을 적용할 수 있습니다.

<ComponentPreview name="qr-code-card-frames" />

프레임은 기본적으로 테마의 `foreground`와 `background` 색상을 사용하므로 라이트 모드와 다크 모드에서 모두 읽기 쉽습니다. 코드 자체는 모든 스캐너가 읽을 수 있도록 밝은 배경을 유지합니다.

### 코드 스타일 지정 [#styling-the-code]

`qr`은 모든 qrdx 스타일 옵션을 받습니다. `fgColor`, `bgColor`, 그라데이션, `bodyPattern`, 모서리 패턴, `logo`, `templateId`를 사용할 수 있습니다.

```tsx title="components/brand-card.tsx"
import { QrCodeCard } from "@/components/qr-code-card";

export function BrandCard() {
  return (
    <QrCodeCard
      value="https://example.com"
      title="example.com"
      qr={{
        fgColor: "#155DFC",
        bodyPattern: "rounded",
        cornerEyePattern: "extra-rounded",
      }}
    />
  );
}
```

## 접근성과 렌더링 [#accessibility-and-rendering]

- 코드는 `role="img"` 요소 안에 있으며, `aria-label`은 `label` 값입니다. `label`이 없으면 `QR code: <value>`가 됩니다. value가 공개 링크가 아니라면 `label`을 설정하세요.
- `title`은 카드의 제목으로, `description`은 그 아래에 렌더링됩니다. 둘 다 React 노드를 받을 수 있습니다.
- 이 컴포넌트는 Client Component입니다. Server Component 페이지에서 가져와 서버 데이터를 props로 전달할 수 있으며, 코드는 서버에서 렌더링됩니다.
