`QrCodeGenerator` è un piccolo generatore in un unico componente: un campo di testo, un'anteprima che si ridisegna mentre scrivi, una riga di preset di stile e i pulsanti di download. Usalo per offrire ai tuoi utenti un modo per creare codici all'interno del tuo prodotto, senza mandarli altrove.

## Utilizzo [#usage]

```tsx title="components/example.tsx"
import { QrCodeGenerator } from "@/components/qr-code-generator";
```

```tsx title="components/example.tsx"
<QrCodeGenerator defaultValue="https://example.com" />
```

L'anteprima si aggiorna mentre scrivi. Ogni pulsante di preset mostra un piccolo esempio del suo stile, e i download usano il preset selezionato a 1024 pixel. Con il campo vuoto l'anteprima mostra "Type some text to generate a code" e i pulsanti di download sono disattivati.

## Esempi [#examples]

### Preset personalizzati [#custom-presets]

Sostituisci i preset integrati con i tuoi. Un preset è composto da un `id`, un `name` e uno `style` con qualsiasi opzione di qrdx, inclusi gradienti, loghi e `level` di correzione degli errori.

<ComponentPreview name="qr-code-generator-presets" />

I preset integrati sono esportati come `QR_CODE_PRESETS`, quindi puoi estenderli:

```tsx title="components/brand-generator.tsx"
import {
  QR_CODE_PRESETS,
  QrCodeGenerator,
} from "@/components/qr-code-generator";

export function BrandGenerator() {
  return (
    <QrCodeGenerator
      presets={[
        ...QR_CODE_PRESETS,
        { id: "brand", name: "Brand", style: { fgColor: "#155DFC" } },
      ]}
    />
  );
}
```

### Salvare il risultato [#saving-the-result]

`onChange` comunica il testo e il preset selezionato a ogni modifica, per esempio per memorizzare la scelta dell'utente:

```tsx title="components/draft-generator.tsx"
import { QrCodeGenerator } from "@/components/qr-code-generator";

export function DraftGenerator({
  saveDraft,
}: {
  saveDraft: (draft: { value: string; style: object }) => void;
}) {
  return (
    <QrCodeGenerator
      onChange={({ value, preset }) =>
        saveDraft({ value, style: preset.style })
      }
    />
  );
}
```

## Accessibilità e rendering [#accessibility-and-rendering]

- Il campo ha un'etichetta visibile "Text or URL", e i preset sono un `<fieldset>` con la legenda "Style". Ogni preset è un pulsante a due stati con `aria-pressed`, e il suo codice di esempio è nascosto agli screen reader.
- L'anteprima è un elemento `role="img"` con l'etichetta `QR code: <value>`, oppure "Empty QR code preview" se non c'è testo.
- Un errore di download compare sotto l'anteprima con `role="alert"`.
- Il componente è un Client Component con un proprio stato. Puoi renderizzarlo da qualsiasi pagina; passa `defaultValue` e `defaultPreset` per farlo partire già compilato.
