`QrCode` rendert einen QR-Code als SVG mit zugänglichem Namen, Bildunterschrift sowie Download-Buttons für PNG und SVG, alles in einer Komponente, die dir gehört. Nutze sie überall dort, wo eine Seite einen Code zeigt, den jemand speichern möchte: eine Bestellbestätigung, ein Ticket, eine Speisekarte, eine Wi-Fi-Karte.

## Verwendung [#usage]

```tsx title="components/example.tsx"
import { QrCode } from "@/components/qr-code";
```

```tsx title="components/example.tsx"
<QrCode value="https://qrdx.dev" />
```

Der Code wird als SVG in einer `role="img"`-Box gerendert. So bleibt er bei jeder Größe scharf, und Screenreader sagen an, worauf er verlinkt. Zwei Buttons darunter speichern ein PNG mit 1024 px und ein SVG.

## Beispiele [#examples]

### Größen [#sizes]

`size` legt Breite und Höhe auf dem Bildschirm in Pixeln fest. Downloads verwenden `downloadSize`, sodass ein kleiner Code auf der Seite trotzdem eine druckfertige Datei exportiert.

<ComponentPreview name="qr-code-sizes" />

### Farben [#colors]

`fgColor` und `bgColor` akzeptieren jede CSS-Farbe. `eyeColor` und `dotColor` färben die drei Eckaugen separat. Halte die Module dunkler als den Hintergrund, damit jeder Scanner den Code lesen kann.

<ComponentPreview name="qr-code-colors" />

### Verläufe [#gradients]

Übergib statt einer Farbe einen qrdx-Verlauf: `linear` mit einem `angle` oder `radial`. Verläufe werden in PNG-, SVG- und PDF-Downloads übernommen.

<ComponentPreview name="qr-code-gradient" />

### Muster [#patterns]

`bodyPattern` formt die Datenmodule, `cornerEyePattern` die Eckrahmen und `cornerEyeDotPattern` die Punkte darin. [Modul- und Augenformen wählen](/docs/features/patterns) listet alle Formen auf.

<ComponentPreview name="qr-code-patterns" />

### Logo [#logo]

`logo` setzt ein Bild in die Mitte und räumt die Module dahinter frei. Nutze die Fehlerkorrekturstufe `H`, damit sich der Code auch mit teilweise verdecktem Bereich noch scannen lässt. Eine Data-URL behält das Logo in Downloads; ein Remote-Bild braucht CORS-Header.

<ComponentPreview name="qr-code-logo" />

### Rahmenvorlagen [#frame-templates]

`templateId` zeichnet eine der [Rahmenvorlagen](/docs/features/templates) von qrdx um den Code. Kombiniere sie mit `caption` für einen Call-to-Action unter dem Rahmen.

<ComponentPreview name="qr-code-template" />

### Download-Formate [#download-formats]

`downloadFormats` wählt die Buttons aus: `png`, `jpg`, `svg` und `pdf`. Der PDF-Export braucht das optionale Paket `jspdf` (`npm install jspdf`). Übergib `[]`, um die Buttons auszublenden.

<ComponentPreview name="qr-code-downloads" />

Für ein einzelnes Menü mit Formaten und Größen nutze [QR Code Download](/docs/components/qr-code-download).

### Dark Mode [#dark-mode]

Der weiße Standardhintergrund ist in dunklen Themes die sicherste Wahl: dunkle Module auf hellem Untergrund lassen sich mit jedem Lesegerät scannen. Wenn der Code stattdessen dem Theme folgen soll, setze `fgColor="currentColor"` und einen transparenten Hintergrund. Der Code wird dann im Dark Mode invertiert, was Handykameras lesen, einige ältere Scanner aber nicht.

<ComponentPreview name="qr-code-dark-mode" />

## In einer Next.js-Seite [#in-a-nextjs-page]

`QrCode` ist eine Client Component (die Datei beginnt wegen der Download-Buttons mit `"use client"`). Eine Seite als Server Component kann sie daher importieren und Serverdaten als Props übergeben:

```tsx title="app/menu/page.tsx"
import { QrCode } from "@/components/qr-code";

export default function MenuPage() {
  return (
    <QrCode
      value="https://example.com/menu"
      caption="Scan to see the menu"
      filename="menu-qr"
    />
  );
}
```

Der Code selbst wird weiterhin auf dem Server gerendert, sodass er im HTML der Seite steht, bevor die Buttons interaktiv werden. Mehr zum Rendern von Codes im App Router findest du unter [QR-Codes in Next.js](/docs/nextjs).

## Beliebige Inhalte, nicht nur Links [#any-content-not-only-links]

`value` wird genau so codiert, wie du es übergibst, daher funktioniert jede QR-Payload: ein Wi-Fi-Netzwerk, eine Kontaktkarte, `mailto:`, `tel:` oder reiner Text. Setze `label`, damit Screenreader ansagen, was der Code bewirkt, statt die rohe Payload vorzulesen, die bei Wi-Fi das Passwort enthält.

```tsx title="components/guest-wifi.tsx"
import { QrCode } from "@/components/qr-code";

export function GuestWifi() {
  return (
    <QrCode
      value="WIFI:T:WPA;S:Cafe Guest;P:sunshine123;;"
      label="QR code to join the Cafe Guest Wi-Fi"
      caption="Cafe Guest Wi-Fi"
    />
  );
}
```

Um die Payload aus einem Formular zu erzeugen, nutze [Wi-Fi QR Code](/docs/components/wifi-qr-code) oder [vCard QR Code](/docs/components/vcard-qr-code), die Sonderzeichen für dich maskieren.

## Ein Wert aus einem Eingabefeld [#a-value-from-an-input]

```tsx title="components/link-qr-code.tsx"
"use client";

import { useState } from "react";
import { QrCode } from "@/components/qr-code";

export function LinkQrCode() {
  const [value, setValue] = useState("https://example.com");
  return (
    <div className="grid justify-items-center gap-4">
      <input
        aria-label="Link"
        className="w-full rounded-md border px-3 py-2"
        value={value}
        onChange={(event) => setValue(event.target.value)}
      />
      {value ? <QrCode value={value} downloadFormats={[]} /> : null}
    </div>
  );
}
```

`downloadFormats={[]}` blendet die Buttons aus, solange noch getippt wird. Zeige sie, sobald der Wert feststeht.

## Druckfertige Downloads [#print-ready-downloads]

```tsx title="components/table-code.tsx"
import { QrCode } from "@/components/qr-code";

export function TableCode() {
  return (
    <QrCode
      value="https://example.com/order?table=12"
      level="H"
      margin={4}
      downloadFormats={["svg", "png", "pdf"]}
      downloadSize={2048}
      filename="table-12"
    />
  );
}
```

- **SVG** skaliert ohne Unschärfe auf jede Größe und ist daher die beste Datei für eine Druckerei oder ein Design-Tool.
- **PNG** mit `downloadSize={2048}` druckt bei 300 Pixeln pro Zoll bis zu etwa 17 cm (6,8 Zoll) Breite scharf. `downloadSize` akzeptiert 50 bis 5000 Pixel.
- **PDF** braucht das optionale Paket `jspdf` (`npm install jspdf`).
- `filename` benennt die Datei ohne Endung: `table-12.svg`, `table-12.png`.

## Barrierefreiheit [#accessibility]

- Der Code sitzt in einem `role="img"`-Element, dessen `aria-label` dem `label` entspricht, oder ohne `label` `QR code: <value>`. Setze `label` immer dann, wenn der Wert kein öffentlicher Link ist.
- Die Download-Buttons bilden ein `<fieldset>` mit einer visuell versteckten Legende, "Download QR code". Das Ergebnis eines Downloads wird über eine Live-Region mit `polite` angesagt, und ein Fehler erscheint mit `role="alert"` unter den Buttons.
- `caption` wird als `<figcaption>` der Figure gerendert.

## So stellst du sicher, dass er sich scannen lässt [#make-sure-it-scans]

- **Kontrast.** Dunkle Module auf hellem Hintergrund lassen sich mit jedem Lesegerät scannen. Ein heller Code auf dunklem Hintergrund funktioniert mit den meisten Handykameras, aber nicht mit einigen älteren Scannern.
- **Ruhezone.** `margin` ist standardmäßig 2 Module. Nutze 4, wenn der Code auf einem Foto, einem Muster oder einer dunklen Seite sitzt.
- **Logos.** Nutze `level="H"` mit einem `logo`, damit der Code die vom Logo verdeckten Module übersteht.
- **Druckgröße.** Ein kurzer Link, der aus etwa 25 cm Entfernung gescannt wird, braucht einen Code von etwa 2,5 cm Breite; der [Druckgrößenrechner](/tools/print-size) ermittelt die Größe für andere Entfernungen.
- **Teste ihn.** Scanne den fertigen Code mit ein paar Handys oder lade ein Bild in den [Scan-Checker](/tools/scan-checker) hoch.
