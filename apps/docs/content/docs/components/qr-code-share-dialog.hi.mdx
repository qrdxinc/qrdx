`QrCodeShareDialog` एक डायलॉग खोलता है, जो किसी लिंक को QR कोड के रूप में दिखाता है। साथ में लिंक एक ऐसे फ़ील्ड में होता है जिसे आप कॉपी कर सकते हैं, PNG डाउनलोड का विकल्प होता है और फ़ोन पर सिस्टम की शेयर शीट भी मिलती है। इसे "Share" बटन के पीछे लगाएँ, जहाँ भी लोग अपने पास खड़े किसी व्यक्ति को लिंक देते हैं: जैसे इन्वाइट, डॉक्यूमेंट या प्रोफ़ाइल।

## उपयोग [#usage]

```tsx title="components/example.tsx"
import { QrCodeShareDialog } from "@/components/qr-code-share-dialog";
```

```tsx title="components/example.tsx"
<QrCodeShareDialog url="https://example.com/invite/abc123" />
```

डायलॉग में कोड दिखता है, साथ में लिंक एक रीड-ओनली फ़ील्ड में कॉपी बटन के साथ और **Download PNG** बटन। जिन डिवाइस में शेयर शीट होती है (ज़्यादातर फ़ोन), वहाँ **Share…** बटन उसे खोलता है।

## उदाहरण [#examples]

### कस्टम ट्रिगर [#custom-trigger]

अपना ट्रिगर children के रूप में पास करें, जैसे टूलबार में कोई आइकन बटन। `title`, `description` और `qr` से डायलॉग को कस्टमाइज़ किया जा सकता है।

<ComponentPreview name="qr-code-share-dialog-trigger" />

### कंट्रोल्ड [#controlled]

यह डायलॉग [Dialog](https://ui.shadcn.com/docs/components/dialog) के props स्वीकार करता है, इसलिए आप इसे कोड से खोल सकते हैं:

```tsx title="components/share-after-save.tsx"
"use client";

import { useState } from "react";
import { QrCodeShareDialog } from "@/components/qr-code-share-dialog";

export function ShareAfterSave({ url }: { url: string }) {
  const [open, setOpen] = useState(false);
  return (
    <>
      <button type="button" onClick={() => setOpen(true)}>
        Save and share
      </button>
      <QrCodeShareDialog url={url} open={open} onOpenChange={setOpen} />
    </>
  );
}
```

## एक्सेसिबिलिटी और रेंडरिंग [#accessibility-and-rendering]

- यह डायलॉग आपका ही Dialog है, इसलिए खुलने पर फ़ोकस उसके अंदर चला जाता है और बंद होने पर ट्रिगर पर लौट आता है।
- कोड में `aria-label="QR code: <url>"` होता है और लिंक फ़ील्ड पर "Link" का एक विज़ुअली हिडन लेबल होता है। कॉपी करने के बाद कुछ देर के लिए कॉपी बटन का लेबल "Link copied" हो जाता है।
- **Share…** बटन सिर्फ़ वहीं दिखता है जहाँ `navigator.share` मौजूद है, और ब्राउज़र में पहले रेंडर के बाद दिखता है, ताकि सर्वर का HTML और क्लाइंट का पहला पेंट एक जैसे रहें।
- लिंक फ़ील्ड पर क्लिक करने से पूरा लिंक सेलेक्ट हो जाता है। कॉपी करने के लिए सिक्योर कॉन्टेक्स्ट (HTTPS या localhost) ज़रूरी है।
