`WifiQrCode` rendert einen Code, der ein Wi-Fi-Netzwerk verbindet, wenn eine Smartphone-Kamera ihn scannt. Darunter steht der Netzwerkname. Nutze ihn für eine Gäste-WLAN-Karte an der Rezeption, einen Tischaufsteller im Café oder die Willkommensseite einer Ferienunterkunft.

## Verwendung [#usage]

```tsx title="components/example.tsx"
import { WifiQrCode } from "@/components/wifi-qr-code";
```

```tsx title="components/example.tsx"
<WifiQrCode ssid="Cafe Guest" password="espresso-2024" />
```

Die Kameras von iOS und Android bieten an, dem Netzwerk beizutreten, sobald sie den Code scannen. Es ist keine App nötig. Unter dem Code zeigt die Komponente den Netzwerknamen und "Scan with your camera to join" an.

## Beispiele [#examples]

### Varianten [#variants]

`showPassword` gibt das Passwort für Gäste aus, die es eintippen. Verwende `encryption="nopass"` für offene Netzwerke und `hidden` für Netzwerke, die ihren Namen nicht aussenden.

<ComponentPreview name="wifi-qr-code-variants" />

### Payload-Builder [#payload-builder]

`buildWifiPayload` gibt den `WIFI:`-Text zurück, den der Code kodiert. Die Funktion escaped `\`, `;`, `,`, `:` und `"` in Namen und Passwörtern. Genau dort brechen von Hand geschriebene Payloads meistens. Du kannst sie mit jedem QR-Renderer verwenden oder den Payload zum Debuggen ausgeben.

<ComponentPreview name="wifi-qr-code-payload" />

## Barrierefreiheit und Rendering [#accessibility-and-rendering]

- Der Code hat `aria-label="QR code to join the Wi-Fi network <ssid>"`. Der Payload, der das Passwort enthält, wird nie vorgelesen.
- Name und Passwort unter dem Code sind die `<figcaption>` der Figure. Mit `showDetails={false}` zeigst du nur den Code an.
- Die Komponente ist eine Client Component, der Code wird auf dem Server gerendert.

Jede andere Prop, etwa `className`, wird an das umschließende `<figure>` weitergegeben.

### buildWifiPayload [#buildwifipayload]

`buildWifiPayload(network: WifiNetwork): string` nimmt dieselben Netzwerkfelder wie die Komponente: `ssid`, `password`, `encryption` und `hidden`. `"WPA"` deckt WPA, WPA2 und WPA3 ab, `"WEP"` und `"nopass"` sind die weiteren Werte. Bei `"nopass"` entfällt das Passwort.
