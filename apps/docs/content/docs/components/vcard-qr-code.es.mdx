`VCardQrCode` muestra un código que guarda un contacto cuando la cámara de un teléfono lo escanea, con el nombre y el cargo debajo. Úsalo en una tarjeta de visita, un directorio de personal, una credencial de conferencia o una página de firma de correo.

## Uso [#usage]

```tsx title="components/example.tsx"
import { VCardQrCode } from "@/components/vcard-qr-code";
```

```tsx title="components/example.tsx"
<VCardQrCode
  contact={{
    firstName: "Ada",
    lastName: "Lovelace",
    organization: "Analytical Engines",
    email: "ada@example.com",
  }}
/>
```

Las cámaras de los teléfonos ofrecen guardar el contacto cuando escanean el código. Los campos vacíos se omiten, lo que mantiene el código pequeño y rápido de escanear.

## Ejemplos [#examples]

### Constructor de vCard [#vcard-builder]

`buildVCard` devuelve el texto vCard 3.0 que codifica el código, con las comas, los puntos y coma, las barras invertidas y los saltos de línea escapados. Úsalo con cualquier generador de QR, o para ofrecer el mismo contacto como descarga `.vcf`.

<ComponentPreview name="vcard-qr-code-payload" />

Las tarjetas de contacto contienen más texto que un enlace, así que el componente usa el nivel de corrección de errores `M` para mantener los módulos grandes. Añade solo los campos que la gente necesite y comprueba qué tamaño debe tener la impresión con la [calculadora de tamaño de impresión](/tools/print-size).

## Accesibilidad y renderizado [#accessibility-and-rendering]

- El código tiene `aria-label="QR code with the contact card for <name>"`. Los campos de la tarjeta no se leen en voz alta.
- El nombre y el cargo y la organización bajo el código son el `<figcaption>` de la figura. Define `showDetails={false}` para mostrar solo el código.
- El componente es un Client Component, y el código se renderiza en el servidor.

`buildVCard(contact: VCardContact): string` escribe las líneas `N`, `FN`, `ORG`, `TITLE`, `TEL` (trabajo y móvil), `EMAIL`, `URL`, `ADR` y `NOTE`, cada una solo cuando el campo está definido.
