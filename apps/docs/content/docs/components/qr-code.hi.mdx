`QrCode` एक QR code को SVG के रूप में दिखाता है, जिसमें accessible नाम, कैप्शन और PNG व SVG डाउनलोड बटन होते हैं, और यह सब एक ही कंपोनेंट में मिलता है जो आपके अपने कोड में रहता है। इसे वहाँ इस्तेमाल करें जहाँ पेज पर ऐसा कोड दिखता हो जिसे कोई सेव करना चाहे: ऑर्डर कन्फ़र्मेशन, टिकट, मेन्यू, Wi-Fi कार्ड।

## इस्तेमाल [#usage]

```tsx title="components/example.tsx"
import { QrCode } from "@/components/qr-code";
```

```tsx title="components/example.tsx"
<QrCode value="https://qrdx.dev" />
```

कोड `role="img"` वाले बॉक्स के अंदर SVG के रूप में दिखता है, इसलिए यह किसी भी साइज़ पर साफ़ रहता है और स्क्रीन रीडर बताते हैं कि वह किस चीज़ से लिंक है। इसके नीचे दो बटन 1024 px का PNG और एक SVG सेव करते हैं।

## उदाहरण [#examples]

### साइज़ [#sizes]

`size` स्क्रीन पर चौड़ाई और ऊँचाई पिक्सेल में तय करता है। डाउनलोड में `downloadSize` इस्तेमाल होता है, इसलिए पेज पर छोटा कोड भी प्रिंट के लिए तैयार फ़ाइल एक्सपोर्ट करता है।

<ComponentPreview name="qr-code-sizes" />

### रंग [#colors]

`fgColor` और `bgColor` कोई भी CSS रंग लेते हैं। `eyeColor` और `dotColor` तीनों कोने की आँखों को अलग से रंगते हैं। मॉड्यूल को बैकग्राउंड से गहरा रखें ताकि हर स्कैनर कोड पढ़ सके।

<ComponentPreview name="qr-code-colors" />

### ग्रेडिएंट [#gradients]

रंग की जगह qrdx ग्रेडिएंट दें: `angle` के साथ `linear`, या `radial`। ग्रेडिएंट PNG, SVG और PDF डाउनलोड में भी आते हैं।

<ComponentPreview name="qr-code-gradient" />

### पैटर्न [#patterns]

`bodyPattern` डेटा मॉड्यूल का आकार तय करता है, `cornerEyePattern` कोने के फ़्रेम का और `cornerEyeDotPattern` उनके अंदर के डॉट का। [मॉड्यूल और आँखों के आकार चुनें](/docs/features/patterns) में सभी आकार दिए हैं।

<ComponentPreview name="qr-code-patterns" />

### लोगो [#logo]

`logo` बीच में एक इमेज रखता है और उसके पीछे के मॉड्यूल हटा देता है। एरर करेक्शन लेवल `H` इस्तेमाल करें ताकि कोड का कुछ हिस्सा ढका होने पर भी वह स्कैन हो। data URL लोगो को डाउनलोड में बनाए रखता है; रिमोट इमेज के लिए CORS हेडर चाहिए।

<ComponentPreview name="qr-code-logo" />

### फ़्रेम टेम्पलेट [#frame-templates]

`templateId` कोड के चारों ओर qrdx के [फ़्रेम टेम्पलेट](/docs/features/templates) में से एक बनाता है। फ़्रेम के नीचे कॉल टू एक्शन के लिए इसके साथ `caption` दें।

<ComponentPreview name="qr-code-template" />

### डाउनलोड फ़ॉर्मैट [#download-formats]

`downloadFormats` बटन चुनता है: `png`, `jpg`, `svg` और `pdf`। PDF एक्सपोर्ट के लिए वैकल्पिक `jspdf` पैकेज चाहिए (`npm install jspdf`)। बटन छिपाने के लिए `[]` दें।

<ComponentPreview name="qr-code-downloads" />

फ़ॉर्मैट और साइज़ वाले एक ही मेन्यू के लिए [QR Code Download](/docs/components/qr-code-download) इस्तेमाल करें।

### डार्क मोड [#dark-mode]

डार्क थीम में डिफ़ॉल्ट सफ़ेद बैकग्राउंड सबसे सुरक्षित विकल्प है: हल्की टाइल पर गहरे मॉड्यूल हर रीडर से स्कैन होते हैं। थीम के हिसाब से चलाने के लिए `fgColor="currentColor"` और पारदर्शी बैकग्राउंड सेट करें। तब कोड डार्क मोड में उलट जाता है, जिसे फ़ोन कैमरे पढ़ लेते हैं, लेकिन कुछ पुराने स्कैनर नहीं पढ़ पाते।

## Next.js पेज में [#in-a-nextjs-page]

`QrCode` एक Client Component है (डाउनलोड बटन की वजह से इसकी फ़ाइल `"use client"` से शुरू होती है), इसलिए Server Component पेज इसे इम्पोर्ट करके सर्वर डेटा को props के रूप में दे सकता है:

```tsx title="app/menu/page.tsx"
import { QrCode } from "@/components/qr-code";

export default function MenuPage() {
  return (
    <QrCode
      value="https://example.com/menu"
      caption="Scan to see the menu"
      filename="menu-qr"
    />
  );
}
```

कोड खुद अब भी सर्वर पर रेंडर होता है, इसलिए बटन के इंटरैक्टिव होने से पहले ही वह पेज के HTML में मौजूद होता है। App Router में कोड रेंडर करने के बारे में और जानने के लिए [Next.js में QR कोड](/docs/nextjs) देखें।

## कोई भी कंटेंट, सिर्फ़ लिंक नहीं [#any-content-not-only-links]

`value` को ठीक वैसे ही एन्कोड किया जाता है जैसा आप देते हैं, इसलिए कोई भी QR पेलोड चलता है: Wi-Fi नेटवर्क, कॉन्टैक्ट कार्ड, `mailto:`, `tel:` या सादा टेक्स्ट। `label` सेट करें ताकि स्क्रीन रीडर कच्चे पेलोड की जगह यह बताएँ कि कोड क्या करता है; Wi-Fi के पेलोड में पासवर्ड भी होता है।

```tsx title="components/guest-wifi.tsx"
import { QrCode } from "@/components/qr-code";

export function GuestWifi() {
  return (
    <QrCode
      value="WIFI:T:WPA;S:Cafe Guest;P:sunshine123;;"
      label="QR code to join the Cafe Guest Wi-Fi"
      caption="Cafe Guest Wi-Fi"
    />
  );
}
```

फ़ॉर्म से पेलोड बनाने के लिए [Wi-Fi QR Code](/docs/components/wifi-qr-code) या [vCard QR Code](/docs/components/vcard-qr-code) इस्तेमाल करें, जो स्पेशल कैरेक्टर आपके लिए एस्केप कर देते हैं।

## इनपुट से मिली वैल्यू [#a-value-from-an-input]

```tsx title="components/link-qr-code.tsx"
"use client";

import { useState } from "react";
import { QrCode } from "@/components/qr-code";

export function LinkQrCode() {
  const [value, setValue] = useState("https://example.com");
  return (
    <div className="grid justify-items-center gap-4">
      <input
        aria-label="Link"
        className="w-full rounded-md border px-3 py-2"
        value={value}
        onChange={(event) => setValue(event.target.value)}
      />
      {value ? <QrCode value={value} downloadFormats={[]} /> : null}
    </div>
  );
}
```

`downloadFormats={[]}` जब तक कोई टाइप कर रहा है तब तक बटन छिपाए रखता है; वैल्यू फ़ाइनल होने पर उन्हें दिखाएँ।

## प्रिंट के लिए तैयार डाउनलोड [#print-ready-downloads]

```tsx title="components/table-code.tsx"
import { QrCode } from "@/components/qr-code";

export function TableCode() {
  return (
    <QrCode
      value="https://example.com/order?table=12"
      level="H"
      margin={4}
      downloadFormats={["svg", "png", "pdf"]}
      downloadSize={2048}
      filename="table-12"
    />
  );
}
```

- **SVG** बिना धुंधला हुए किसी भी साइज़ तक स्केल होता है, इसलिए प्रिंट शॉप या डिज़ाइन टूल के लिए यह सबसे अच्छी फ़ाइल है।
- `downloadSize={2048}` पर **PNG** 300 पिक्सेल प्रति इंच पर लगभग 17 सेमी (6.8 इंच) चौड़ाई तक साफ़ प्रिंट होता है। `downloadSize` 50 से 5000 पिक्सेल तक लेता है।
- **PDF** के लिए वैकल्पिक `jspdf` पैकेज चाहिए (`npm install jspdf`)।
- `filename` फ़ाइल का नाम एक्सटेंशन के बिना तय करता है: `table-12.svg`, `table-12.png`।

## Accessibility [#accessibility]

- कोड एक `role="img"` एलिमेंट में रहता है, जिसका `aria-label` `label` होता है, या `label` न होने पर `QR code: <value>`। जब value सार्वजनिक लिंक न हो, तो हमेशा `label` सेट करें।
- डाउनलोड बटन एक `<fieldset>` में होते हैं, जिसकी लेजेंड "Download QR code" नज़र से छिपी रहती है। डाउनलोड का नतीजा एक polite live region से बताया जाता है, और एरर `role="alert"` के साथ बटनों के नीचे दिखता है।
- `caption` फ़िगर के `<figcaption>` के रूप में रेंडर होता है।

## पक्का करें कि कोड स्कैन हो [#make-sure-it-scans]

- **कॉन्ट्रास्ट।** हल्के बैकग्राउंड पर गहरे मॉड्यूल हर रीडर से स्कैन होते हैं। गहरे बैकग्राउंड पर हल्का कोड ज़्यादातर फ़ोन कैमरों पर चलता है, लेकिन कुछ पुराने स्कैनरों पर नहीं।
- **क्वाइट ज़ोन।** `margin` का डिफ़ॉल्ट 2 मॉड्यूल है। जब कोड फ़ोटो, पैटर्न या गहरे पेज पर हो तो 4 इस्तेमाल करें।
- **लोगो।** `logo` के साथ `level="H"` इस्तेमाल करें, ताकि लोगो से ढके मॉड्यूल के बाद भी कोड बचा रहे।
- **प्रिंट साइज़।** लगभग 25 सेमी दूर से स्कैन होने वाले छोटे लिंक के लिए लगभग 2.5 सेमी चौड़ा कोड चाहिए; दूसरी दूरियों का हिसाब [प्रिंट साइज़ कैलकुलेटर](/tools/print-size) लगा देता है।
- **टेस्ट करें।** तैयार कोड को कुछ फ़ोन से स्कैन करें, या [स्कैन चेकर](/tools/scan-checker) पर कोई इमेज अपलोड करें।
