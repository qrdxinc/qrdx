`QrCodeScanner` es una zona de arrastre que decodifica un código QR a partir de un archivo de imagen, en el navegador, y te entrega el texto. Úsalo para registrar entradas desde capturas de pantalla, leer códigos de fotos que suben las personas o verificar un código que hayas generado. Lee archivos de imagen, no una transmisión en vivo de la cámara.

## Uso [#usage]

```tsx title="components/example.tsx"
import { QrCodeScanner } from "@/components/qr-code-scanner";
```

```tsx title="components/example.tsx"
<QrCodeScanner onResult={(value) => console.log(value)} />
```

Las personas sueltan una imagen o hacen clic para elegir una. La decodificación se ejecuta en el navegador con los [ayudantes de detección](/docs/qr-detection) de qrdx, así que la imagen nunca sale del dispositivo. El resultado aparece con un botón **Copiar**, y también un botón **Abrir enlace** cuando es una URL `http` o `https`.

## Ejemplos [#examples]

### Comprobar un resultado [#checking-a-result]

`onResult` recibe el texto decodificado, para que puedas actuar con él, por ejemplo para registrar una entrada. `label` cambia el encabezado de la zona de arrastre. Descarga el código de muestra de arriba y suéltalo para ver una entrada válida.

## Qué muestra el lector [#what-the-reader-shows]

| Estado | Mensaje |
| --- | --- |
| Escaneando | "Scanning…" |
| No hay ningún código en la imagen | "No QR code found. Try a sharper or closer image." |
| No es un archivo de imagen | "Choose an image file." |
| No se puede leer la imagen | "Could not read that image." |
| Encontrado | El texto decodificado, con **Copiar** y, para enlaces, **Abrir enlace** |

El decodificador prueba la imagen completa y cuatro recortes, a varias escalas, así que se encuentra un código aunque ocupe solo una pequeña parte de una captura de pantalla.

## Accesibilidad y renderizado [#accessibility-and-rendering]

- La zona de arrastre es un `<label>` de un campo de archivo oculto visualmente, por lo que funciona con el teclado y con lectores de pantalla como cualquier selector de archivos.
- Los resultados y los errores se anuncian mediante una región activa con nivel educado (polite).
- **Abrir enlace** se abre en una pestaña nueva con `rel="noopener noreferrer nofollow"`, de modo que una página escaneada no pueda acceder a la tuya.
- El componente es un Client Component. Necesita el canvas del navegador y, en el primer escaneo, carga el decodificador bajo demanda.
