`WifiQrCode` 会渲染一个二维码，手机相机扫描后即可加入 Wi-Fi 网络，二维码下方显示网络名称。可用于前台的访客网络卡片、咖啡馆的桌牌，或民宿的欢迎页面。

## 用法 [#usage]

```tsx title="components/example.tsx"
import { WifiQrCode } from "@/components/wifi-qr-code";
```

```tsx title="components/example.tsx"
<WifiQrCode ssid="Cafe Guest" password="espresso-2024" />
```

iOS 和 Android 的相机在扫描该二维码时，会提示加入网络，无需安装应用。组件会在二维码下方显示网络名称和“Scan with your camera to join”。

## 示例 [#examples]

### 变体 [#variants]

`showPassword` 会显示密码，方便访客手动输入。开放网络请使用 `encryption="nopass"`，不广播名称的网络请使用 `hidden`。

<ComponentPreview name="wifi-qr-code-variants" />

### 载荷构建器 [#payload-builder]

`buildWifiPayload` 返回二维码所编码的 `WIFI:` 文本。它会对名称和密码中的 `\`、`;`、`,`、`:` 和 `"` 进行转义，而手写载荷通常正是在这些地方出错。它可以配合任何二维码渲染器使用，也可以用来输出载荷以便调试。

<ComponentPreview name="wifi-qr-code-payload" />

## 无障碍与渲染 [#accessibility-and-rendering]

- 二维码带有 `aria-label="QR code to join the Wi-Fi network <ssid>"`。包含密码的载荷不会被朗读出来。
- 二维码下方的名称和密码是该 figure 的 `<figcaption>`。设置 `showDetails={false}` 可以只显示二维码。
- 该组件是 Client Component，二维码在服务器端渲染。

### buildWifiPayload [#buildwifipayload]

`buildWifiPayload(network: WifiNetwork): string` 接收与组件相同的网络字段：`ssid`、`password`、`encryption` 和 `hidden`。`"WPA"` 涵盖 WPA、WPA2 和 WPA3；其他可选值为 `"WEP"` 和 `"nopass"`。使用 `"nopass"` 时，密码会被省略。
