`QrCodeGenerator` ist ein kleiner Generator in einer einzigen Komponente: ein Textfeld, eine Vorschau, die sich beim Tippen neu zeichnet, eine Reihe von Stil-Presets und Download-Buttons. Damit gibst du deinen eigenen Nutzern die Möglichkeit, direkt in deinem Produkt Codes zu erstellen, ohne sie woandershin zu schicken.

## Verwendung [#usage]

```tsx title="components/example.tsx"
import { QrCodeGenerator } from "@/components/qr-code-generator";
```

```tsx title="components/example.tsx"
<QrCodeGenerator defaultValue="https://example.com" />
```

Die Vorschau aktualisiert sich beim Tippen. Jeder Preset-Button zeigt eine kleine Vorschau seines Stils, und Downloads verwenden das ausgewählte Preset mit 1024 Pixeln. Bei leerem Feld zeigt die Vorschau „Type some text to generate a code“, und die Download-Buttons sind deaktiviert.

## Beispiele [#examples]

### Eigene Presets [#custom-presets]

Ersetze die integrierten Presets durch deine eigenen. Ein Preset besteht aus einer `id`, einem `name` und einem `style` mit beliebigen qrdx-Optionen, darunter Verläufe, Logos und die Fehlerkorrektur `level`.

<ComponentPreview name="qr-code-generator-presets" />

Die integrierten Presets werden als `QR_CODE_PRESETS` exportiert, sodass du sie erweitern kannst:

```tsx title="components/brand-generator.tsx"
import {
  QR_CODE_PRESETS,
  QrCodeGenerator,
} from "@/components/qr-code-generator";

export function BrandGenerator() {
  return (
    <QrCodeGenerator
      presets={[
        ...QR_CODE_PRESETS,
        { id: "brand", name: "Brand", style: { fgColor: "#155DFC" } },
      ]}
    />
  );
}
```

### Ergebnis speichern [#saving-the-result]

`onChange` meldet bei jeder Änderung den Text und das ausgewählte Preset, zum Beispiel um die Auswahl des Nutzers zu speichern:

```tsx title="components/draft-generator.tsx"
import { QrCodeGenerator } from "@/components/qr-code-generator";

export function DraftGenerator({
  saveDraft,
}: {
  saveDraft: (draft: { value: string; style: object }) => void;
}) {
  return (
    <QrCodeGenerator
      onChange={({ value, preset }) =>
        saveDraft({ value, style: preset.style })
      }
    />
  );
}
```

## Barrierefreiheit und Rendering [#accessibility-and-rendering]

- Das Feld hat das sichtbare Label „Text or URL“, und die Presets sind ein `<fieldset>` mit der Legende „Style“. Jedes Preset ist ein Toggle-Button mit `aria-pressed`, und sein Beispielcode ist für Screenreader ausgeblendet.
- Die Vorschau ist ein Element mit `role="img"` und dem Label `QR code: <value>`, oder „Empty QR code preview“, wenn kein Text vorhanden ist.
- Ein Download-Fehler wird unter der Vorschau mit `role="alert"` angezeigt.
- Die Komponente ist eine Client Component mit eigenem State. Du kannst sie in jeder Seite rendern; mit `defaultValue` und `defaultPreset` startet sie bereits befüllt.
