`QrCodeGenerator` 是一个小巧的一体化生成器组件：包含一个文本输入框、一个随输入实时重绘的预览、一排样式预设和下载按钮。你可以用它让自己的用户直接在你的产品内生成二维码，无需跳转到其他地方。

## 用法 [#usage]

```tsx title="components/example.tsx"
import { QrCodeGenerator } from "@/components/qr-code-generator";
```

```tsx title="components/example.tsx"
<QrCodeGenerator defaultValue="https://example.com" />
```

预览会随着输入实时更新。每个预设按钮都会显示其样式的小样，下载时使用所选预设，尺寸为 1024 像素。输入框为空时，预览会显示“Type some text to generate a code”，下载按钮处于禁用状态。

## 示例 [#examples]

### 自定义预设 [#custom-presets]

用你自己的预设替换内置预设。一个预设包含 `id`、`name` 和 `style`，其中 `style` 可以使用任意 qrdx 选项，包括渐变、徽标和纠错 `level`。

<ComponentPreview name="qr-code-generator-presets" />

内置预设以 `QR_CODE_PRESETS` 导出，因此你可以在其基础上扩展：

```tsx title="components/brand-generator.tsx"
import {
  QR_CODE_PRESETS,
  QrCodeGenerator,
} from "@/components/qr-code-generator";

export function BrandGenerator() {
  return (
    <QrCodeGenerator
      presets={[
        ...QR_CODE_PRESETS,
        { id: "brand", name: "Brand", style: { fgColor: "#155DFC" } },
      ]}
    />
  );
}
```

### 保存结果 [#saving-the-result]

每次变化时，`onChange` 都会返回文本和所选预设，例如可以用它来保存用户的选择：

```tsx title="components/draft-generator.tsx"
import { QrCodeGenerator } from "@/components/qr-code-generator";

export function DraftGenerator({
  saveDraft,
}: {
  saveDraft: (draft: { value: string; style: object }) => void;
}) {
  return (
    <QrCodeGenerator
      onChange={({ value, preset }) =>
        saveDraft({ value, style: preset.style })
      }
    />
  );
}
```

## 无障碍与渲染 [#accessibility-and-rendering]

- 输入框带有可见的“Text or URL”标签，预设位于一个 `<fieldset>` 中，图例为“Style”。每个预设都是带有 `aria-pressed` 的切换按钮，其示例二维码对屏幕阅读器隐藏。
- 预览是一个 `role="img"` 元素，标签为 `QR code: <value>`；没有文本时标签为“Empty QR code preview”。
- 下载出错时，错误信息会以 `role="alert"` 显示在预览下方。
- 该组件是带有自身状态的 Client Component。可在任意页面中渲染；传入 `defaultValue` 和 `defaultPreset` 即可让它以已填写的状态启动。
