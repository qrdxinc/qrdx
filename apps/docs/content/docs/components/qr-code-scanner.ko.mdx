`QrCodeScanner`는 브라우저에서 이미지 파일의 QR 코드를 디코딩해 텍스트를 넘겨주는 드롭 영역입니다. 스크린샷으로 티켓을 체크인하거나, 사용자가 업로드한 사진에서 코드를 읽거나, 직접 만든 코드를 확인할 때 사용하세요. 이미지 파일을 읽으며, 실시간 카메라 영상은 읽지 않습니다.

## 사용법 [#usage]

```tsx title="components/example.tsx"
import { QrCodeScanner } from "@/components/qr-code-scanner";
```

```tsx title="components/example.tsx"
<QrCodeScanner onResult={(value) => console.log(value)} />
```

이미지를 드롭하거나 클릭해서 선택합니다. 디코딩은 qrdx의 [감지 헬퍼](/docs/qr-detection)로 브라우저에서 실행되므로 이미지가 기기 밖으로 나가지 않습니다. 결과는 **복사** 버튼과 함께 표시되며, 결과가 `http` 또는 `https` URL이면 **링크 열기** 버튼도 표시됩니다.

### 결과 확인하기 [#checking-a-result]

`onResult`는 디코딩된 텍스트를 받으므로, 예를 들어 티켓을 체크인하는 등 원하는 동작을 실행할 수 있습니다. `label`은 드롭 영역의 제목을 바꿉니다. 위의 샘플 코드를 다운로드해 드롭하면 유효한 티켓을 확인할 수 있습니다.

## 리더에 표시되는 내용 [#what-the-reader-shows]

| 상태 | 메시지 |
| --- | --- |
| 스캔 중 | "Scanning…" |
| 이미지에 코드가 없음 | "No QR code found. Try a sharper or closer image." |
| 이미지 파일이 아님 | "Choose an image file." |
| 이미지를 읽을 수 없음 | "Could not read that image." |
| 찾음 | 디코딩된 텍스트와 **복사** 버튼, 링크인 경우 **링크 열기** 버튼 |

디코더는 전체 이미지와 네 개의 잘라낸 영역을 여러 배율로 시도하므로, 스크린샷의 작은 부분만 차지하는 코드도 찾아냅니다.

## 접근성과 렌더링 [#accessibility-and-rendering]

- 드롭 영역은 시각적으로 숨겨진 파일 입력의 `<label>`이므로, 일반 파일 선택기처럼 키보드와 스크린 리더로 사용할 수 있습니다.
- 결과와 오류는 polite live region을 통해 안내됩니다.
- **링크 열기**는 `rel="noopener noreferrer nofollow"`와 함께 새 탭에서 열리므로, 스캔한 페이지가 사용자의 페이지에 접근할 수 없습니다.
- 이 컴포넌트는 Client Component입니다. 브라우저의 canvas가 필요하며, 첫 스캔 때 디코더를 필요한 시점에 불러옵니다.
