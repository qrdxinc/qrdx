`VCardQrCode` 会渲染一个二维码，手机相机扫描后即可保存联系人，二维码下方显示姓名和职位。可用于名片、员工通讯录、会议胸牌或邮件签名页。

## 用法 [#usage]

```tsx title="components/example.tsx"
import { VCardQrCode } from "@/components/vcard-qr-code";
```

```tsx title="components/example.tsx"
<VCardQrCode
  contact={{
    firstName: "Ada",
    lastName: "Lovelace",
    organization: "Analytical Engines",
    email: "ada@example.com",
  }}
/>
```

手机相机扫描二维码后，会提示保存联系人。空字段会被省略，这样二维码更小，扫描也更快。

## 示例 [#examples]

### vCard 构建器 [#vcard-builder]

`buildVCard` 返回二维码所编码的 vCard 3.0 文本，其中的逗号、分号、反斜杠和换行都已转义。你可以将它用于任何二维码渲染器，或者用它把同一个联系人作为 `.vcf` 文件提供下载。

<ComponentPreview name="vcard-qr-code-payload" />

联系人名片包含的文本比链接更多，因此该组件使用纠错级别 `M`，以保持模块较大。只添加人们需要的字段，并使用[打印尺寸计算器](/tools/print-size)检查应以多大尺寸打印。

## 无障碍与渲染 [#accessibility-and-rendering]

- 二维码带有 `aria-label="QR code with the contact card for <name>"`。名片中的各个字段不会被朗读出来。
- 二维码下方的姓名、职位和单位是该 figure 的 `<figcaption>`。设置 `showDetails={false}` 可只显示二维码。
- 该组件是 Client Component，二维码在服务器端渲染。

`buildVCard(contact: VCardContact): string` 会写入 `N`、`FN`、`ORG`、`TITLE`、`TEL`（工作和手机）、`EMAIL`、`URL`、`ADR` 和 `NOTE` 行，每一行仅在对应字段已设置时写入。
