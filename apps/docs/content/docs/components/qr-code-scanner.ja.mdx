`QrCodeScanner` は、画像ファイルからQRコードをブラウザー上でデコードし、テキストを返すドロップゾーンです。スクリーンショットからチケットをチェックインしたり、ユーザーがアップロードした写真からコードを読み取ったり、生成したコードを検証したりする場合に使えます。読み取るのは画像ファイルで、カメラのライブ映像には対応していません。

## 使い方 [#usage]

```tsx title="components/example.tsx"
import { QrCodeScanner } from "@/components/qr-code-scanner";
```

```tsx title="components/example.tsx"
<QrCodeScanner onResult={(value) => console.log(value)} />
```

画像をドロップするか、クリックして選択します。デコードはqrdxの[検出ヘルパー](/docs/qr-detection)を使ってブラウザー上で実行されるため、画像がデバイスの外に出ることはありません。結果には **コピー** ボタンが表示され、結果が `http` または `https` のURLの場合は **リンクを開く** ボタンも表示されます。

## リーダーの表示 [#what-the-reader-shows]

| 状態 | メッセージ |
| --- | --- |
| スキャン中 | "Scanning…" |
| 画像にコードがない | "No QR code found. Try a sharper or closer image." |
| 画像ファイルではない | "Choose an image file." |
| 画像を読み込めない | "Could not read that image." |
| 検出 | デコードされたテキストと **コピー**。リンクの場合は **リンクを開く** も表示 |

デコーダーは画像全体と4つの切り抜きを、複数の倍率で試します。そのため、スクリーンショットのごく一部しか占めていないコードでも検出できます。

## アクセシビリティとレンダリング [#accessibility-and-rendering]

- ドロップゾーンは、視覚的に非表示のファイル入力に対応する `<label>` です。そのため、通常のファイル選択と同じようにキーボードやスクリーンリーダーで操作できます。
- 結果とエラーは、polite のライブリージョンで読み上げられます。
- **リンクを開く** は `rel="noopener noreferrer nofollow"` を付けて新しいタブで開くため、スキャンしたページからこちらのページにアクセスされることはありません。
- このコンポーネントはクライアントコンポーネントです。ブラウザーのcanvasが必要で、最初のスキャン時にデコーダーをオンデマンドで読み込みます。
