`QrCodeGenerator`는 하나의 컴포넌트에 담긴 작은 생성기입니다. 텍스트 입력란, 입력할 때마다 다시 그려지는 미리보기, 스타일 프리셋 목록, 다운로드 버튼으로 구성됩니다. 사용자를 다른 곳으로 보내지 않고도 제품 안에서 직접 코드를 만들 수 있게 하려는 경우에 사용하세요.

## 사용법 [#usage]

```tsx title="components/example.tsx"
import { QrCodeGenerator } from "@/components/qr-code-generator";
```

```tsx title="components/example.tsx"
<QrCodeGenerator defaultValue="https://example.com" />
```

미리보기는 입력할 때마다 업데이트됩니다. 각 프리셋 버튼에는 해당 스타일의 작은 샘플이 표시되며, 다운로드는 선택한 프리셋을 1024픽셀로 적용합니다. 입력란이 비어 있으면 미리보기에 "Type some text to generate a code"라고 표시되고 다운로드 버튼은 비활성화됩니다.

## 예시 [#examples]

### 사용자 지정 프리셋 [#custom-presets]

기본 제공 프리셋을 직접 만든 프리셋으로 바꿀 수 있습니다. 프리셋은 `id`, `name`, 그리고 그라디언트, 로고, 오류 정정 `level`을 포함한 모든 qrdx 옵션을 담을 수 있는 `style`로 구성됩니다.

<ComponentPreview name="qr-code-generator-presets" />

기본 제공 프리셋은 `QR_CODE_PRESETS`로 내보내지므로 이를 확장할 수 있습니다.

```tsx title="components/brand-generator.tsx"
import {
  QR_CODE_PRESETS,
  QrCodeGenerator,
} from "@/components/qr-code-generator";

export function BrandGenerator() {
  return (
    <QrCodeGenerator
      presets={[
        ...QR_CODE_PRESETS,
        { id: "brand", name: "Brand", style: { fgColor: "#155DFC" } },
      ]}
    />
  );
}
```

### 결과 저장하기 [#saving-the-result]

`onChange`는 변경될 때마다 텍스트와 선택된 프리셋을 전달합니다. 예를 들어 사용자의 선택을 저장할 때 활용할 수 있습니다.

```tsx title="components/draft-generator.tsx"
import { QrCodeGenerator } from "@/components/qr-code-generator";

export function DraftGenerator({
  saveDraft,
}: {
  saveDraft: (draft: { value: string; style: object }) => void;
}) {
  return (
    <QrCodeGenerator
      onChange={({ value, preset }) =>
        saveDraft({ value, style: preset.style })
      }
    />
  );
}
```

## 접근성과 렌더링 [#accessibility-and-rendering]

- 입력란에는 눈에 보이는 "Text or URL" 레이블이 있고, 프리셋은 범례가 "Style"인 `<fieldset>`입니다. 각 프리셋은 `aria-pressed`를 가진 토글 버튼이며, 샘플 코드는 스크린 리더에서 숨겨집니다.
- 미리보기는 `role="img"` 요소이며 `QR code: <value>`라는 레이블이 붙습니다. 텍스트가 없으면 "Empty QR code preview"로 표시됩니다.
- 다운로드 오류는 미리보기 아래에 `role="alert"`와 함께 표시됩니다.
- 이 컴포넌트는 자체 상태를 가진 Client Component입니다. 어느 페이지에서든 렌더링할 수 있으며, `defaultValue`와 `defaultPreset`을 전달하면 값이 채워진 상태로 시작합니다.
