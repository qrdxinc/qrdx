`VCardQrCode` rendert einen Code, der einen Kontakt speichert, wenn eine Handykamera ihn scannt. Name und Funktion stehen darunter. Nutze ihn auf einer Visitenkarte, in einem Mitarbeiterverzeichnis, auf einem Konferenz-Badge oder auf einer Seite für E-Mail-Signaturen.

## Verwendung [#usage]

```tsx title="components/example.tsx"
import { VCardQrCode } from "@/components/vcard-qr-code";
```

```tsx title="components/example.tsx"
<VCardQrCode
  contact={{
    firstName: "Ada",
    lastName: "Lovelace",
    organization: "Analytical Engines",
    email: "ada@example.com",
  }}
/>
```

Handykameras bieten an, den Kontakt zu speichern, wenn sie den Code scannen. Leere Felder werden weggelassen, damit der Code klein und schnell zu scannen bleibt.

## Beispiele [#examples]

### vCard-Builder [#vcard-builder]

`buildVCard` gibt den vCard-3.0-Text zurück, den der Code kodiert. Kommas, Semikolons, Backslashes und Zeilenumbrüche werden dabei maskiert. Verwende ihn mit jedem QR-Renderer oder um denselben Kontakt als `.vcf`-Download anzubieten.

<ComponentPreview name="vcard-qr-code-payload" />

Kontaktkarten enthalten mehr Text als ein Link, deshalb nutzt die Komponente die Fehlerkorrekturstufe `M`, um die Module groß zu halten. Füge nur die Felder hinzu, die Leute wirklich brauchen, und prüfe mit dem [Druckgrößenrechner](/tools/print-size), wie groß du den Code drucken solltest.

## Barrierefreiheit und Rendering [#accessibility-and-rendering]

- Der Code hat `aria-label="QR code with the contact card for <name>"`. Die Felder der Karte werden nicht vorgelesen.
- Der Name sowie Titel und Organisation unter dem Code bilden die `<figcaption>` des Figure-Elements. Setze `showDetails={false}`, um nur den Code anzuzeigen.
- Die Komponente ist eine Client Component, und der Code wird auf dem Server gerendert.

### VCardContact [#vcardcontact]

<auto-type-table path="../../../../../packages/docs-assets/registry/qrdx/vcard-qr-code.tsx" name="VCardContact" />

`buildVCard(contact: VCardContact): string` schreibt die Zeilen `N`, `FN`, `ORG`, `TITLE`, `TEL` (geschäftlich und mobil), `EMAIL`, `URL`, `ADR` und `NOTE`, jeweils nur, wenn das Feld gesetzt ist.
