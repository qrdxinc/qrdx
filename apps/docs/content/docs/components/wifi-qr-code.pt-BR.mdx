`WifiQrCode` renderiza um código que conecta a uma rede Wi-Fi quando a câmera do celular faz a leitura, com o nome da rede abaixo dele. Use em um cartão da rede de visitantes na recepção, em um display de mesa em uma cafeteria ou na página de boas-vindas de um imóvel de aluguel.

## Uso [#usage]

```tsx title="components/example.tsx"
import { WifiQrCode } from "@/components/wifi-qr-code";
```

```tsx title="components/example.tsx"
<WifiQrCode ssid="Cafe Guest" password="espresso-2024" />
```

As câmeras do iOS e do Android oferecem a opção de conectar à rede ao fazer a leitura do código. Não precisa de app. Abaixo do código, o componente exibe o nome da rede e "Scan with your camera to join".

## Exemplos [#examples]

### Variantes [#variants]

`showPassword` exibe a senha para os convidados que preferem digitá-la. Use `encryption="nopass"` para redes abertas e `hidden` para redes que não divulgam o nome.

<ComponentPreview name="wifi-qr-code-variants" />

### Construtor de payload [#payload-builder]

`buildWifiPayload` retorna o texto `WIFI:` que o código codifica. Ele faz o escape de `\`, `;`, `,`, `:` e `"` em nomes e senhas, que é onde os payloads escritos à mão costumam quebrar. Use com qualquer renderizador de QR code, ou para imprimir o payload ao depurar.

<ComponentPreview name="wifi-qr-code-payload" />

## Acessibilidade e renderização [#accessibility-and-rendering]

- O código tem `aria-label="QR code to join the Wi-Fi network <ssid>"`. O payload, que contém a senha, nunca é lido em voz alta.
- O nome e a senha abaixo do código são o `<figcaption>` da figura. Defina `showDetails={false}` para exibir só o código.
- O componente é um Client Component, e o código é renderizado no servidor.

Qualquer outra prop, como `className`, é repassada ao `<figure>` que envolve o componente.

### buildWifiPayload [#buildwifipayload]

`buildWifiPayload(network: WifiNetwork): string` recebe os mesmos campos de rede que o componente: `ssid`, `password`, `encryption` e `hidden`. `"WPA"` cobre WPA, WPA2 e WPA3; `"WEP"` e `"nopass"` são os outros valores. Com `"nopass"`, a senha é omitida.
