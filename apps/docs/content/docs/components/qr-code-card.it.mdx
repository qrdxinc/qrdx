`QrCodeCard` mette un QR code in una card con una cornice di invito all'azione, un titolo, una riga di testo e un footer per i pulsanti. Usalo dove il codice è il centro della card: un segnatavolo, una schermata di check-in, l'anteprima di una locandina per un evento, un riquadro "scarica la nostra app".

## Utilizzo [#usage]

```tsx title="components/example.tsx"
import { QrCodeCard } from "@/components/qr-code-card";
```

```tsx title="components/example.tsx"
<QrCodeCard
  value="https://example.com/menu"
  title="Our menu"
  description="Scan to see today's specials."
/>
```

Tutto ciò che passi come children viene mostrato nel footer della card, per esempio un pulsante di copia o un [menu di download](/docs/components/qr-code-download).

## Esempi [#examples]

### Cornici [#frames]

`frame` mette l'invito all'azione sotto il codice (`"bottom"`), sopra (`"top"`) oppure elimina la cornice (`"none"`). `cta` cambia l'etichetta e `frameClassName` modifica lo stile della cornice, per esempio con il colore del tuo brand.

<ComponentPreview name="qr-code-card-frames" />

Per impostazione predefinita la cornice usa i colori `foreground` e `background` del tuo tema, così resta leggibile in modalità chiara e scura. Il codice invece mantiene uno sfondo chiaro, che ogni scanner riesce a leggere.

### Personalizzare lo stile del codice [#styling-the-code]

`qr` accetta qualsiasi opzione di stile di qrdx: `fgColor`, `bgColor`, gradienti, `bodyPattern`, motivi degli angoli, `logo` e `templateId`.

```tsx title="components/brand-card.tsx"
import { QrCodeCard } from "@/components/qr-code-card";

export function BrandCard() {
  return (
    <QrCodeCard
      value="https://example.com"
      title="example.com"
      qr={{
        fgColor: "#155DFC",
        bodyPattern: "rounded",
        cornerEyePattern: "extra-rounded",
      }}
    />
  );
}
```

## Accessibilità e rendering [#accessibility-and-rendering]

- Il codice si trova in un elemento `role="img"` il cui `aria-label` è `label`, oppure `QR code: <value>` se `label` non è impostato. Imposta `label` quando il valore non è un link pubblico.
- `title` viene mostrato come titolo della card e `description` sotto di esso; entrambi accettano qualsiasi nodo React.
- Il componente è un Client Component. Una pagina Server Component può importarlo e passargli dati del server come props, e il codice viene renderizzato sul server.
