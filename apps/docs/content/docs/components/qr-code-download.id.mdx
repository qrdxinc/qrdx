`QrCodeDownload` adalah satu tombol yang membuka menu format dan ukuran, lalu menyimpan kode sebagai file atau menyalin PNG ke clipboard. Gunakan di samping kode apa pun yang Anda render, dengan objek gaya yang sama, agar file sesuai dengan pratinjau.

## Penggunaan [#usage]

```tsx title="components/example.tsx"
import { QrCodeDownload } from "@/components/qr-code-download";
```

```tsx title="components/example.tsx"
<QrCodeDownload value="https://qrdx.dev" />
```

Menu menampilkan setiap format dengan petunjuk singkat, pemilih ukuran, dan **Copy image**, yang menaruh PNG di clipboard. File dirender di browser; tidak ada yang diunggah.

## Contoh [#examples]

### Ekspor dengan gaya [#styled-export]

Berikan objek gaya yang sama dengan yang Anda render di layar ke `qr`, agar setiap file yang diekspor sesuai dengan pratinjau. `formats`, `sizes`, `label`, dan `variant` mengatur menu beserta tombolnya.

### Format [#formats]

| Format | Keluaran |
| --- | --- |
| `png` | Gambar dengan latar belakang kode |
| `jpg` | Gambar dengan latar belakang solid |
| `svg` | Vektor yang dapat diskalakan ke ukuran apa pun |
| `pdf` | Dokumen satu halaman. Memerlukan paket opsional `jspdf` (`npm install jspdf`) |
| `eps` | Vektor untuk percetakan dan alat desain |

Ukuran raster berkisar dari 50 hingga 5000 piksel. Berikan satu entri di `sizes` untuk menyembunyikan pemilih ukuran. Menu menampilkan ukuran piksel di samping format raster dan "vector" di samping SVG dan EPS.

### Setelah unduhan [#after-a-download]

`onComplete` dipanggil dengan format tersebut, atau `"copy"`, setelah file disimpan atau gambar disalin. `onError` menerima error saat ekspor gagal; pesannya juga muncul di bawah tombol.

```tsx title="components/tracked-download.tsx"
import { QrCodeDownload } from "@/components/qr-code-download";

export function TrackedDownload({ url }: { url: string }) {
  return (
    <QrCodeDownload
      value={url}
      onComplete={(action) => console.log("exported", action)}
      onError={(error) => console.error(error.message)}
    />
  );
}
```

## Aksesibilitas dan rendering [#accessibility-and-rendering]

- Pemicunya adalah Button Anda, dengan `aria-busy` selama file dirender. Hasilnya diumumkan melalui live region yang sopan (polite), dan error muncul di bawah tombol dengan `role="alert"`.
- Menu ini adalah DropdownMenu Anda, sehingga navigasi keyboard dan fokus mengikuti komponen tema Anda.
- Penyalinan memerlukan gestur pengguna dan konteks aman (HTTPS atau localhost); jika tidak, browser menolaknya, dan error muncul di bawah tombol.
- Komponen ini adalah Client Component. Di server, komponen ini tidak merender tampilan apa pun selain tombol.
