`VCardQrCode` affiche un code qui enregistre un contact lorsqu'un appareil photo de téléphone le scanne, avec le nom et la fonction en dessous. Utilisez-le sur une carte de visite, dans un annuaire du personnel, sur un badge de conférence ou sur une page de signature d'e-mail.

## Utilisation [#usage]

```tsx title="components/example.tsx"
import { VCardQrCode } from "@/components/vcard-qr-code";
```

```tsx title="components/example.tsx"
<VCardQrCode
  contact={{
    firstName: "Ada",
    lastName: "Lovelace",
    organization: "Analytical Engines",
    email: "ada@example.com",
  }}
/>
```

Les appareils photo des téléphones proposent d'enregistrer le contact lorsqu'ils scannent le code. Les champs vides sont omis, ce qui garde le code petit et rapide à scanner.

## Exemples [#examples]

### Générateur vCard [#vcard-builder]

`buildVCard` renvoie le texte vCard 3.0 encodé par le code, avec les virgules, les points-virgules, les barres obliques inverses et les sauts de ligne échappés. Utilisez-le avec n'importe quel moteur de rendu de QR code, ou pour proposer le même contact en téléchargement `.vcf`.

<ComponentPreview name="vcard-qr-code-payload" />

Une fiche de contact contient plus de texte qu'un lien. Le composant utilise donc le niveau de correction d'erreur `M` afin de garder des modules de grande taille. N'ajoutez que les champs utiles, et vérifiez la taille d'impression avec le [calculateur de taille d'impression](/tools/print-size).

## Accessibilité et rendu [#accessibility-and-rendering]

- Le code porte `aria-label="QR code with the contact card for <name>"`. Les champs de la fiche ne sont pas lus à voix haute.
- Le nom, ainsi que le titre et l'organisation sous le code, forment le `<figcaption>` de la figure. Définissez `showDetails={false}` pour n'afficher que le code.
- Le composant est un Client Component, et le code est rendu sur le serveur.

### VCardContact [#vcardcontact]

<auto-type-table path="../../../../../packages/docs-assets/registry/qrdx/vcard-qr-code.tsx" name="VCardContact" />

`buildVCard(contact: VCardContact): string` écrit les lignes `N`, `FN`, `ORG`, `TITLE`, `TEL` (professionnel et mobile), `EMAIL`, `URL`, `ADR` et `NOTE`, chacune uniquement lorsque le champ est renseigné.
