`QrCodeCard` menempatkan kode QR di dalam kartu dengan bingkai ajakan bertindak, judul, satu baris teks, dan footer untuk tombol. Gunakan di tempat kode menjadi inti kartu: tenda meja, layar check-in, pratinjau poster acara, atau tile "unduh aplikasi kami".

## Penggunaan [#usage]

```tsx title="components/example.tsx"
import { QrCodeCard } from "@/components/qr-code-card";
```

```tsx title="components/example.tsx"
<QrCodeCard
  value="https://example.com/menu"
  title="Our menu"
  description="Scan to see today's specials."
/>
```

Apa pun yang Anda berikan sebagai children akan dirender di footer kartu, misalnya tombol salin atau [menu unduh](/docs/components/qr-code-download).

## Contoh [#examples]

### Bingkai [#frames]

`frame` menempatkan ajakan bertindak di bawah kode (`"bottom"`), di atasnya (`"top"`), atau menghilangkan bingkai (`"none"`). `cta` mengubah labelnya, dan `frameClassName` mengubah gaya bingkai, misalnya dengan warna merek Anda.

<ComponentPreview name="qr-code-card-frames" />

Secara default, bingkai memakai warna `foreground` dan `background` dari tema Anda, sehingga tetap terbaca dalam mode terang maupun gelap. Kodenya sendiri tetap berlatar terang, yang dapat dibaca oleh semua pemindai.

### Menata gaya kode [#styling-the-code]

`qr` menerima semua opsi gaya qrdx: `fgColor`, `bgColor`, gradien, `bodyPattern`, pola sudut, `logo`, dan `templateId`.

```tsx title="components/brand-card.tsx"
import { QrCodeCard } from "@/components/qr-code-card";

export function BrandCard() {
  return (
    <QrCodeCard
      value="https://example.com"
      title="example.com"
      qr={{
        fgColor: "#155DFC",
        bodyPattern: "rounded",
        cornerEyePattern: "extra-rounded",
      }}
    />
  );
}
```

## Aksesibilitas dan perenderan [#accessibility-and-rendering]

- Kode berada dalam elemen `role="img"` dengan `aria-label` berisi `label`, atau `QR code: <value>` jika `label` tidak diisi. Isi `label` bila nilainya bukan tautan publik.
- `title` dirender sebagai judul kartu dan `description` di bawahnya; keduanya menerima React node apa pun.
- Komponen ini adalah Client Component. Halaman Server Component dapat mengimpornya dan meneruskan data server sebagai props, dan kodenya dirender di server.
