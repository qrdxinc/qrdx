`QrCodeShareDialog` öffnet einen Dialog, der einen Link als QR-Code anzeigt, dazu den Link in einem Feld zum Kopieren, einen PNG-Download und auf Smartphones das System-Teilen-Menü. Setze ihn hinter einen „Teilen"-Button, überall dort, wo Leute einen Link an jemanden weitergeben, der direkt neben ihnen steht: eine Einladung, ein Dokument, ein Profil.

## Verwendung [#usage]

```tsx title="components/example.tsx"
import { QrCodeShareDialog } from "@/components/qr-code-share-dialog";
```

```tsx title="components/example.tsx"
<QrCodeShareDialog url="https://example.com/invite/abc123" />
```

Der Dialog zeigt den Code, den Link in einem schreibgeschützten Feld mit Kopieren-Button und **PNG herunterladen**. Auf Geräten mit Teilen-Menü (die meisten Smartphones) öffnet ein Button **Teilen…** dieses Menü.

## Beispiele [#examples]

### Eigener Trigger [#custom-trigger]

Übergib deinen eigenen Trigger als Children, zum Beispiel einen Icon-Button in einer Toolbar. Mit `title`, `description` und `qr` passt du den Dialog an.

<ComponentPreview name="qr-code-share-dialog-trigger" />

### Gesteuert [#controlled]

Der Dialog akzeptiert die Props von [Dialog](https://ui.shadcn.com/docs/components/dialog), sodass du ihn per Code öffnen kannst:

```tsx title="components/share-after-save.tsx"
"use client";

import { useState } from "react";
import { QrCodeShareDialog } from "@/components/qr-code-share-dialog";

export function ShareAfterSave({ url }: { url: string }) {
  const [open, setOpen] = useState(false);
  return (
    <>
      <button type="button" onClick={() => setOpen(true)}>
        Save and share
      </button>
      <QrCodeShareDialog url={url} open={open} onOpenChange={setOpen} />
    </>
  );
}
```

## Barrierefreiheit und Rendering [#accessibility-and-rendering]

- Der Dialog ist dein Dialog: Der Fokus springt beim Öffnen hinein und kehrt beim Schließen zum Trigger zurück.
- Der Code hat `aria-label="QR code: <url>"`, und das Linkfeld hat ein visuell verstecktes Label „Link". Das Label des Kopieren-Buttons wechselt nach dem Kopieren kurz zu „Link kopiert".
- Der Button **Teilen…** erscheint nur dort, wo `navigator.share` existiert, und zwar nach dem ersten Render im Browser, damit das HTML des Servers und der erste Paint des Clients übereinstimmen.
- Ein Klick auf das Linkfeld markiert den ganzen Link. Zum Kopieren ist ein sicherer Kontext nötig (HTTPS oder localhost).
