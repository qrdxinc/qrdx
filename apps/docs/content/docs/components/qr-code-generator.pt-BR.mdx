`QrCodeGenerator` é um gerador pequeno em um só componente: um campo de texto, uma prévia que se redesenha enquanto você digita, uma fileira de estilos prontos e botões de download. Use-o para dar aos seus próprios usuários um jeito de criar códigos dentro do seu produto, sem mandá-los para outro lugar.

## Uso [#usage]

```tsx title="components/example.tsx"
import { QrCodeGenerator } from "@/components/qr-code-generator";
```

```tsx title="components/example.tsx"
<QrCodeGenerator defaultValue="https://example.com" />
```

A prévia é atualizada enquanto você digita. Cada botão de estilo mostra uma pequena amostra do seu visual, e os downloads usam o estilo selecionado com 1024 pixels. Com o campo vazio, a prévia mostra "Type some text to generate a code" e os botões de download ficam desativados.

## Exemplos [#examples]

### Estilos personalizados [#custom-presets]

Substitua os estilos prontos pelos seus. Um estilo é composto por um `id`, um `name` e um `style` com qualquer opção do qrdx, incluindo gradientes, logos e `level` de correção de erros.

<ComponentPreview name="qr-code-generator-presets" />

Os estilos prontos são exportados como `QR_CODE_PRESETS`, então você pode estendê-los:

```tsx title="components/brand-generator.tsx"
import {
  QR_CODE_PRESETS,
  QrCodeGenerator,
} from "@/components/qr-code-generator";

export function BrandGenerator() {
  return (
    <QrCodeGenerator
      presets={[
        ...QR_CODE_PRESETS,
        { id: "brand", name: "Brand", style: { fgColor: "#155DFC" } },
      ]}
    />
  );
}
```

### Salvando o resultado [#saving-the-result]

`onChange` informa o texto e o estilo selecionado a cada mudança, por exemplo para guardar a escolha do usuário:

```tsx title="components/draft-generator.tsx"
import { QrCodeGenerator } from "@/components/qr-code-generator";

export function DraftGenerator({
  saveDraft,
}: {
  saveDraft: (draft: { value: string; style: object }) => void;
}) {
  return (
    <QrCodeGenerator
      onChange={({ value, preset }) =>
        saveDraft({ value, style: preset.style })
      }
    />
  );
}
```

## Acessibilidade e renderização [#accessibility-and-rendering]

- O campo tem o rótulo visível "Text or URL", e os estilos formam um `<fieldset>` com a legenda "Style". Cada estilo é um botão de alternância com `aria-pressed`, e o código de amostra fica oculto para leitores de tela.
- A prévia é um elemento `role="img"` com o rótulo `QR code: <value>`, ou "Empty QR code preview" quando não há texto.
- Um erro de download aparece abaixo da prévia com `role="alert"`.
- O componente é um Client Component com estado próprio. Renderize-o em qualquer página; passe `defaultValue` e `defaultPreset` para iniciá-lo já preenchido.
