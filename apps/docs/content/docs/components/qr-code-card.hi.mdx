`QrCodeCard` एक QR कोड को कार्ड में रखता है, जिसके साथ कॉल-टू-एक्शन फ़्रेम, एक हेडिंग, टेक्स्ट की एक लाइन और बटनों के लिए एक फ़ूटर होता है। इसे वहाँ इस्तेमाल करें जहाँ कार्ड का मुख्य हिस्सा कोड ही हो: टेबल टेंट, चेक-इन स्क्रीन, इवेंट पोस्टर का प्रीव्यू, "हमारा app डाउनलोड करें" टाइल।

## इस्तेमाल [#usage]

```tsx title="components/example.tsx"
import { QrCodeCard } from "@/components/qr-code-card";
```

```tsx title="components/example.tsx"
<QrCodeCard
  value="https://example.com/menu"
  title="Our menu"
  description="Scan to see today's specials."
/>
```

children के रूप में आप जो भी पास करते हैं, वह कार्ड के फ़ूटर में दिखता है, जैसे कॉपी बटन या [डाउनलोड मेन्यू](/docs/components/qr-code-download)।

## उदाहरण [#examples]

### फ़्रेम [#frames]

`frame` कॉल टू एक्शन को कोड के नीचे (`"bottom"`), ऊपर (`"top"`) रखता है, या फ़्रेम हटा देता है (`"none"`)। `cta` लेबल बदलता है, और `frameClassName` फ़्रेम की स्टाइल बदलता है, जैसे आपके ब्रांड के रंग के साथ।

<ComponentPreview name="qr-code-card-frames" />

फ़्रेम डिफ़ॉल्ट रूप से आपकी थीम के `foreground` और `background` रंग इस्तेमाल करता है, इसलिए यह लाइट और डार्क मोड दोनों में पढ़ने लायक रहता है। कोड की बैकग्राउंड हल्की ही रहती है, जिसे हर स्कैनर पढ़ लेता है।

### कोड की स्टाइलिंग [#styling-the-code]

`qr` कोई भी qrdx स्टाइल ऑप्शन लेता है: `fgColor`, `bgColor`, ग्रेडिएंट, `bodyPattern`, कॉर्नर पैटर्न, `logo` और `templateId`।

```tsx title="components/brand-card.tsx"
import { QrCodeCard } from "@/components/qr-code-card";

export function BrandCard() {
  return (
    <QrCodeCard
      value="https://example.com"
      title="example.com"
      qr={{
        fgColor: "#155DFC",
        bodyPattern: "rounded",
        cornerEyePattern: "extra-rounded",
      }}
    />
  );
}
```

## एक्सेसिबिलिटी और रेंडरिंग [#accessibility-and-rendering]

- कोड एक `role="img"` एलिमेंट में रहता है, जिसका `aria-label` `label` होता है, और `label` न होने पर `QR code: <value>` होता है। जब value कोई पब्लिक लिंक न हो, तब `label` सेट करें।
- `title` कार्ड की हेडिंग के रूप में दिखता है और `description` उसके नीचे; दोनों कोई भी React node ले सकते हैं।
- यह कॉम्पोनेंट एक Client Component है। Server Component पेज इसे इम्पोर्ट करके सर्वर का डेटा props के रूप में पास कर सकता है, और कोड सर्वर पर रेंडर होता है।
