`QrCodeShareDialog` abre um diálogo que mostra um link como QR code, com o link em um campo que você pode copiar, um download em PNG e, em celulares, a folha de compartilhamento do sistema. Use-o atrás de um botão "Compartilhar" em qualquer lugar onde as pessoas passam um link para alguém que está ao lado: um convite, um documento, um perfil.

## Uso [#usage]

```tsx title="components/example.tsx"
import { QrCodeShareDialog } from "@/components/qr-code-share-dialog";
```

```tsx title="components/example.tsx"
<QrCodeShareDialog url="https://example.com/invite/abc123" />
```

O diálogo mostra o código, o link em um campo somente leitura com um botão de copiar e **Baixar PNG**. Em dispositivos com folha de compartilhamento (a maioria dos celulares), um botão **Compartilhar…** a abre.

## Exemplos [#examples]

### Gatilho personalizado [#custom-trigger]

Passe seu próprio gatilho como children, como um botão de ícone em uma barra de ferramentas. `title`, `description` e `qr` personalizam o diálogo.

<ComponentPreview name="qr-code-share-dialog-trigger" />

### Controlado [#controlled]

O diálogo aceita as props do [Dialog](https://ui.shadcn.com/docs/components/dialog), então você pode abri-lo pelo código:

```tsx title="components/share-after-save.tsx"
"use client";

import { useState } from "react";
import { QrCodeShareDialog } from "@/components/qr-code-share-dialog";

export function ShareAfterSave({ url }: { url: string }) {
  const [open, setOpen] = useState(false);
  return (
    <>
      <button type="button" onClick={() => setOpen(true)}>
        Save and share
      </button>
      <QrCodeShareDialog url={url} open={open} onOpenChange={setOpen} />
    </>
  );
}
```

## Acessibilidade e renderização [#accessibility-and-rendering]

- O diálogo é o seu Dialog, então o foco vai para dentro dele quando abre e volta para o gatilho quando fecha.
- O código tem `aria-label="QR code: <url>"`, e o campo do link tem um rótulo "Link" visualmente oculto. O rótulo do botão de copiar muda para "Link copiado" por um instante depois de uma cópia.
- O botão **Compartilhar…** aparece somente onde `navigator.share` existe, depois da primeira renderização no navegador, para que o HTML do servidor e a primeira renderização do cliente sejam iguais.
- Clicar no campo do link seleciona o link inteiro. Copiar exige um contexto seguro (HTTPS ou localhost).
