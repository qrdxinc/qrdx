`QrCode` mostra un QR code come SVG con un nome accessibile, una didascalia e pulsanti di download in PNG e SVG, in un unico componente che ti appartiene. Usalo ovunque una pagina mostri un codice che qualcuno potrebbe voler salvare: una conferma d'ordine, un biglietto, un menu, una scheda Wi-Fi.

## Utilizzo [#usage]

```tsx title="components/example.tsx"
import { QrCode } from "@/components/qr-code";
```

```tsx title="components/example.tsx"
<QrCode value="https://qrdx.dev" />
```

Il codice viene mostrato come SVG dentro un riquadro `role="img"`, quindi resta nitido a qualsiasi dimensione e gli screen reader annunciano a cosa rimanda. Due pulsanti sotto il codice salvano un PNG da 1024 px e un SVG.

## Esempi [#examples]

### Dimensioni [#sizes]

`size` imposta larghezza e altezza a schermo in pixel. I download usano `downloadSize`, quindi un codice piccolo nella pagina esporta comunque un file pronto per la stampa.

<ComponentPreview name="qr-code-sizes" />

### Colori [#colors]

`fgColor` e `bgColor` accettano qualsiasi colore CSS. `eyeColor` e `dotColor` colorano separatamente i tre occhi agli angoli. Mantieni i moduli più scuri dello sfondo, così ogni lettore può leggere il codice.

<ComponentPreview name="qr-code-colors" />

### Gradienti [#gradients]

Passa un gradiente qrdx al posto di un colore: `linear` con un `angle`, oppure `radial`. I gradienti vengono mantenuti nei download PNG, SVG e PDF.

<ComponentPreview name="qr-code-gradient" />

### Pattern [#patterns]

`bodyPattern` dà forma ai moduli dei dati, `cornerEyePattern` alle cornici degli angoli e `cornerEyeDotPattern` ai punti al loro interno. [Scegli le forme di moduli e occhi](/docs/features/patterns) elenca tutte le forme.

<ComponentPreview name="qr-code-patterns" />

### Logo [#logo]

`logo` inserisce un'immagine al centro e libera i moduli sotto di essa. Usa il livello di correzione degli errori `H`, così il codice si scansiona anche con una parte coperta. Un data URL mantiene il logo nei download; un'immagine remota richiede gli header CORS.

<ComponentPreview name="qr-code-logo" />

### Template di cornice [#frame-templates]

`templateId` disegna intorno al codice uno dei [template di cornice](/docs/features/templates) di qrdx. Abbinalo a `caption` per una call to action sotto la cornice.

<ComponentPreview name="qr-code-template" />

### Formati di download [#download-formats]

`downloadFormats` sceglie i pulsanti: `png`, `jpg`, `svg` e `pdf`. L'esportazione in PDF richiede il pacchetto opzionale `jspdf` (`npm install jspdf`). Passa `[]` per nascondere i pulsanti.

<ComponentPreview name="qr-code-downloads" />

Per un unico menu con formati e dimensioni, usa [QR Code Download](/docs/components/qr-code-download).

### Modalità scura [#dark-mode]

Lo sfondo bianco predefinito è la scelta più sicura nei temi scuri: moduli scuri su un riquadro chiaro si scansionano con ogni lettore. Per seguire invece il tema, imposta `fgColor="currentColor"` e uno sfondo trasparente. In modalità scura il codice si inverte: le fotocamere dei telefoni lo leggono, ma alcuni lettori più vecchi no.

<ComponentPreview name="qr-code-dark-mode" />

## In una pagina Next.js [#in-a-nextjs-page]

`QrCode` è un Client Component (il suo file inizia con `"use client"` a causa dei pulsanti di download), quindi una pagina Server Component può importarlo e passargli dati del server come prop:

```tsx title="app/menu/page.tsx"
import { QrCode } from "@/components/qr-code";

export default function MenuPage() {
  return (
    <QrCode
      value="https://example.com/menu"
      caption="Scan to see the menu"
      filename="menu-qr"
    />
  );
}
```

Il codice stesso viene comunque renderizzato sul server, quindi è presente nell'HTML della pagina prima che i pulsanti diventino interattivi. Per saperne di più sul rendering dei codici nell'App Router, consulta [QR code in Next.js](/docs/nextjs).

## Qualsiasi contenuto, non solo link [#any-content-not-only-links]

`value` viene codificato esattamente come lo passi, quindi funziona qualsiasi payload QR: una rete Wi-Fi, un biglietto da visita, `mailto:`, `tel:` o testo semplice. Imposta `label` in modo che gli screen reader annuncino la funzione del codice invece del payload grezzo, che per il Wi-Fi include la password.

```tsx title="components/guest-wifi.tsx"
import { QrCode } from "@/components/qr-code";

export function GuestWifi() {
  return (
    <QrCode
      value="WIFI:T:WPA;S:Cafe Guest;P:sunshine123;;"
      label="QR code to join the Cafe Guest Wi-Fi"
      caption="Cafe Guest Wi-Fi"
    />
  );
}
```

Per costruire il payload da un modulo, usa [Wi-Fi QR Code](/docs/components/wifi-qr-code) o [vCard QR Code](/docs/components/vcard-qr-code), che gestiscono per te l'escape dei caratteri speciali.

## Un valore da un campo di input [#a-value-from-an-input]

```tsx title="components/link-qr-code.tsx"
"use client";

import { useState } from "react";
import { QrCode } from "@/components/qr-code";

export function LinkQrCode() {
  const [value, setValue] = useState("https://example.com");
  return (
    <div className="grid justify-items-center gap-4">
      <input
        aria-label="Link"
        className="w-full rounded-md border px-3 py-2"
        value={value}
        onChange={(event) => setValue(event.target.value)}
      />
      {value ? <QrCode value={value} downloadFormats={[]} /> : null}
    </div>
  );
}
```

`downloadFormats={[]}` nasconde i pulsanti mentre qualcuno sta ancora scrivendo; mostrali quando il valore è definitivo.

## Download pronti per la stampa [#print-ready-downloads]

```tsx title="components/table-code.tsx"
import { QrCode } from "@/components/qr-code";

export function TableCode() {
  return (
    <QrCode
      value="https://example.com/order?table=12"
      level="H"
      margin={4}
      downloadFormats={["svg", "png", "pdf"]}
      downloadSize={2048}
      filename="table-12"
    />
  );
}
```

- **SVG** si ridimensiona a qualsiasi misura senza sfocarsi, quindi è il file migliore per una tipografia o uno strumento di design.
- **PNG** con `downloadSize={2048}` si stampa nitido fino a circa 17 cm (6,8 pollici) di larghezza a 300 pixel per pollice. `downloadSize` accetta da 50 a 5000 pixel.
- **PDF** richiede il pacchetto opzionale `jspdf` (`npm install jspdf`).
- `filename` dà il nome al file senza estensione: `table-12.svg`, `table-12.png`.

## Accessibilità [#accessibility]

- Il codice si trova in un elemento `role="img"` il cui `aria-label` è `label`, oppure `QR code: <value>` se manca. Imposta `label` ogni volta che il valore non è un link pubblico.
- I pulsanti di download sono un `<fieldset>` con una legenda nascosta visivamente, "Download QR code". L'esito di un download viene annunciato tramite una live region polite, e un errore compare sotto i pulsanti con `role="alert"`.
- `caption` viene reso come `<figcaption>` della figure.

## Controlla che si scansioni [#make-sure-it-scans]

- **Contrasto.** Moduli scuri su sfondo chiaro si scansionano con ogni lettore. Un codice chiaro su sfondo scuro funziona con la maggior parte delle fotocamere dei telefoni, ma non con alcuni lettori più vecchi.
- **Zona di rispetto.** `margin` è 2 moduli per impostazione predefinita. Usa 4 quando il codice sta su una foto, un motivo o una pagina scura.
- **Loghi.** Usa `level="H"` con un `logo`, così il codice resiste ai moduli coperti dal logo.
- **Dimensione di stampa.** Un link breve scansionato da circa 25 cm richiede un codice largo circa 2,5 cm; il [calcolatore della dimensione di stampa](/tools/print-size) ricava i valori per altre distanze.
- **Provalo.** Scansiona il codice finito con qualche telefono, oppure carica un'immagine nel [controllo scansione](/tools/scan-checker).
