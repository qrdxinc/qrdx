`VCardQrCode` renderiza um código que salva um contato quando a câmera de um celular faz a leitura, com o nome e o cargo logo abaixo. Use em um cartão de visita, em um diretório de funcionários, em um crachá de conferência ou na página de assinatura de e-mail.

## Uso [#usage]

```tsx title="components/example.tsx"
import { VCardQrCode } from "@/components/vcard-qr-code";
```

```tsx title="components/example.tsx"
<VCardQrCode
  contact={{
    firstName: "Ada",
    lastName: "Lovelace",
    organization: "Analytical Engines",
    email: "ada@example.com",
  }}
/>
```

As câmeras dos celulares oferecem a opção de salvar o contato quando fazem a leitura do código. Campos vazios são omitidos, o que mantém o código pequeno e rápido de ler.

## Exemplos [#examples]

### Construtor de vCard [#vcard-builder]

`buildVCard` retorna o texto vCard 3.0 que o código codifica, com vírgulas, ponto e vírgula, barras invertidas e quebras de linha com escape. Use com qualquer renderizador de QR code, ou para oferecer o mesmo contato como download de `.vcf`.

<ComponentPreview name="vcard-qr-code-payload" />

Cartões de contato guardam mais texto do que um link, então o componente usa o nível de correção de erros `M` para manter os módulos grandes. Adicione só os campos de que as pessoas precisam e confira o tamanho ideal de impressão com a [calculadora de tamanho de impressão](/tools/print-size).

## Acessibilidade e renderização [#accessibility-and-rendering]

- O código tem `aria-label="QR code with the contact card for <name>"`. Os campos do cartão não são lidos em voz alta.
- O nome e o cargo e a organização abaixo do código formam o `<figcaption>` da figura. Defina `showDetails={false}` para mostrar apenas o código.
- O componente é um Client Component, e o código é renderizado no servidor.
