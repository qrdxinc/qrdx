`QrCodeGenerator` は、テキストフィールド、入力に合わせて再描画されるプレビュー、スタイルプリセットの一覧、ダウンロードボタンを1つにまとめた小さなジェネレーターです。ユーザーを別のサイトに移動させることなく、お使いのプロダクト内でQRコードを作成できるようにします。

## 使い方 [#usage]

```tsx title="components/example.tsx"
import { QrCodeGenerator } from "@/components/qr-code-generator";
```

```tsx title="components/example.tsx"
<QrCodeGenerator defaultValue="https://example.com" />
```

プレビューは入力に合わせて更新されます。各プリセットボタンにはそのスタイルの小さなサンプルが表示され、ダウンロードには選択中のプリセットが1024ピクセルで使われます。フィールドが空のときは、プレビューに「Type some text to generate a code」と表示され、ダウンロードボタンは無効になります。

## 使用例 [#examples]

### カスタムプリセット [#custom-presets]

組み込みのプリセットを独自のものに置き換えられます。プリセットは `id`、`name`、そして `style` で構成され、`style` にはグラデーション、ロゴ、誤り訂正 `level` を含む、qrdx の任意のオプションを指定できます。

<ComponentPreview name="qr-code-generator-presets" />

組み込みのプリセットは `QR_CODE_PRESETS` としてエクスポートされているため、拡張することもできます。

```tsx title="components/brand-generator.tsx"
import {
  QR_CODE_PRESETS,
  QrCodeGenerator,
} from "@/components/qr-code-generator";

export function BrandGenerator() {
  return (
    <QrCodeGenerator
      presets={[
        ...QR_CODE_PRESETS,
        { id: "brand", name: "Brand", style: { fgColor: "#155DFC" } },
      ]}
    />
  );
}
```

### 結果の保存 [#saving-the-result]

`onChange` は、変更のたびにテキストと選択中のプリセットを通知します。たとえば、ユーザーの選択を保存する場合に使えます。

```tsx title="components/draft-generator.tsx"
import { QrCodeGenerator } from "@/components/qr-code-generator";

export function DraftGenerator({
  saveDraft,
}: {
  saveDraft: (draft: { value: string; style: object }) => void;
}) {
  return (
    <QrCodeGenerator
      onChange={({ value, preset }) =>
        saveDraft({ value, style: preset.style })
      }
    />
  );
}
```

## アクセシビリティとレンダリング [#accessibility-and-rendering]

- フィールドには「Text or URL」というラベルが表示され、プリセットは凡例「Style」を持つ `<fieldset>` になっています。各プリセットは `aria-pressed` を持つトグルボタンで、サンプルのコードはスクリーンリーダーからは隠されています。
- プレビューは `role="img"` の要素で、`QR code: <value>` というラベルが付きます。テキストがない場合は「Empty QR code preview」になります。
- ダウンロードエラーは、`role="alert"` を付けてプレビューの下に表示されます。
- このコンポーネントは独自の状態を持つ Client Component です。任意のページからレンダリングできます。最初から入力済みの状態にするには、`defaultValue` と `defaultPreset` を渡します。
