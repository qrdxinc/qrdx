`QrCodeScanner` è una drop zone che decodifica un QR code da un file immagine, nel browser, e ti restituisce il testo. Usalo per registrare biglietti da screenshot, leggere codici da foto caricate dagli utenti o verificare un codice che hai generato. Legge file immagine, non un flusso live della fotocamera.

## Utilizzo [#usage]

```tsx title="components/example.tsx"
import { QrCodeScanner } from "@/components/qr-code-scanner";
```

```tsx title="components/example.tsx"
<QrCodeScanner onResult={(value) => console.log(value)} />
```

L'utente trascina un'immagine oppure fa clic per sceglierne una. La decodifica avviene nel browser con gli [helper di rilevamento](/docs/qr-detection) di qrdx, quindi l'immagine non lascia mai il dispositivo. Il risultato compare con un pulsante **Copy**, più un pulsante **Open link** quando è un URL `http` o `https`.

## Cosa mostra il lettore [#what-the-reader-shows]

| Stato | Messaggio |
| --- | --- |
| Scansione in corso | "Scanning…" |
| Nessun codice nell'immagine | "No QR code found. Try a sharper or closer image." |
| Non è un file immagine | "Choose an image file." |
| L'immagine non può essere letta | "Could not read that image." |
| Trovato | Il testo decodificato, con **Copy** e, per i link, **Open link** |

Il decodificatore prova l'immagine intera e quattro ritagli, a diverse scale, quindi un codice che occupa una piccola parte di uno screenshot viene comunque trovato.

## Accessibilità e rendering [#accessibility-and-rendering]

- La drop zone è una `<label>` per un input file nascosto visivamente, quindi funziona con la tastiera e con gli screen reader come qualsiasi selettore di file.
- Risultati ed errori vengono annunciati tramite una live region polite.
- **Open link** si apre in una nuova scheda con `rel="noopener noreferrer nofollow"`, così una pagina scansionata non può raggiungere la tua.
- Il componente è un Client Component. Richiede il canvas del browser e, alla prima scansione, carica il decodificatore on demand.
