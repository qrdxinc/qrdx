`QrCodeDownload` é um único botão que abre um menu de formatos e tamanhos e salva o código como arquivo, ou copia um PNG para a área de transferência. Use-o ao lado de qualquer código que você renderizar, com o mesmo objeto de estilo, para que o arquivo seja igual à prévia.

## Uso [#usage]

```tsx title="components/example.tsx"
import { QrCodeDownload } from "@/components/qr-code-download";
```

```tsx title="components/example.tsx"
<QrCodeDownload value="https://qrdx.dev" />
```

O menu lista cada formato com uma dica curta, um seletor de tamanho e **Copiar imagem**, que coloca um PNG na área de transferência. Os arquivos são gerados no navegador; nada é enviado para servidor algum.

## Exemplos [#examples]

### Exportação com estilo [#styled-export]

Passe para `qr` o mesmo objeto de estilo que você renderiza na tela, para que todo arquivo exportado seja igual à prévia. `formats`, `sizes`, `label` e `variant` definem o menu e o botão dele.

<ComponentPreview name="qr-code-download-styled" />

### Formatos [#formats]

| Formato | Saída |
| --- | --- |
| `png` | Imagem com o fundo do código |
| `jpg` | Imagem com fundo sólido |
| `svg` | Vetor que escala para qualquer tamanho |
| `pdf` | Documento de uma página. Precisa do pacote opcional `jspdf` (`npm install jspdf`) |
| `eps` | Vetor para gráficas e ferramentas de design |

Os tamanhos raster vão de 50 a 5000 pixels. Passe uma única entrada em `sizes` para ocultar o seletor de tamanho. O menu mostra o tamanho em pixels ao lado dos formatos raster e "vetor" ao lado de SVG e EPS.

### Depois de um download [#after-a-download]

`onComplete` é chamado com o formato, ou `"copy"`, depois que um arquivo é salvo ou a imagem é copiada. `onError` recebe o erro quando uma exportação falha; a mensagem também aparece abaixo do botão.

```tsx title="components/tracked-download.tsx"
import { QrCodeDownload } from "@/components/qr-code-download";

export function TrackedDownload({ url }: { url: string }) {
  return (
    <QrCodeDownload
      value={url}
      onComplete={(action) => console.log("exported", action)}
      onError={(error) => console.error(error.message)}
    />
  );
}
```

## Acessibilidade e renderização [#accessibility-and-rendering]

- O gatilho é o seu Button, com `aria-busy` enquanto um arquivo é gerado. O resultado é anunciado por uma região live educada (polite), e um erro aparece abaixo do botão com `role="alert"`.
- O menu é o seu DropdownMenu, então a navegação por teclado e o foco seguem os componentes do seu tema.
- Copiar exige um gesto do usuário e um contexto seguro (HTTPS ou localhost); caso contrário, o navegador rejeita a ação e o erro aparece abaixo do botão.
- O componente é um Client Component. No servidor, ele não renderiza nada visual além do botão.
