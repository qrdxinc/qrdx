`QrCodeCard` 会把二维码放进一张卡片中，配有行动号召边框、标题、一行说明文字，以及用于放置按钮的页脚。适合以二维码为核心的卡片场景：桌牌、签到屏幕、活动海报预览、“下载我们的应用”磁贴。

## 使用 [#usage]

```tsx title="components/example.tsx"
import { QrCodeCard } from "@/components/qr-code-card";
```

```tsx title="components/example.tsx"
<QrCodeCard
  value="https://example.com/menu"
  title="Our menu"
  description="Scan to see today's specials."
/>
```

传入的所有子元素都会渲染在卡片页脚中，例如复制按钮或[下载菜单](/docs/components/qr-code-download)。

## 示例 [#examples]

### 边框 [#frames]

`frame` 可以把行动号召放在二维码下方（`"bottom"`）、上方（`"top"`），或者不显示边框（`"none"`）。`cta` 用于修改文字标签，`frameClassName` 用于重新设置边框样式，例如换成你的品牌色。

<ComponentPreview name="qr-code-card-frames" />

边框默认使用主题的 `foreground` 和 `background` 颜色，因此在浅色和深色模式下都清晰易读。二维码本身保持浅色背景，所有扫描器都能识别。

### 设置二维码样式 [#styling-the-code]

`qr` 接受任何 qrdx 样式选项：`fgColor`、`bgColor`、渐变、`bodyPattern`、定位角图案、`logo` 和 `templateId`。

```tsx title="components/brand-card.tsx"
import { QrCodeCard } from "@/components/qr-code-card";

export function BrandCard() {
  return (
    <QrCodeCard
      value="https://example.com"
      title="example.com"
      qr={{
        fgColor: "#155DFC",
        bodyPattern: "rounded",
        cornerEyePattern: "extra-rounded",
      }}
    />
  );
}
```

## 无障碍与渲染 [#accessibility-and-rendering]

- 二维码位于一个 `role="img"` 元素中，其 `aria-label` 为 `label`；如果未设置，则为 `QR code: <value>`。当 value 不是公开链接时，请设置 `label`。
- `title` 渲染为卡片标题，`description` 渲染在标题下方；两者都接受任意 React 节点。
- 该组件是客户端组件（Client Component）。服务端组件页面可以导入它，并以 props 形式传入服务端数据，二维码在服务端渲染。
