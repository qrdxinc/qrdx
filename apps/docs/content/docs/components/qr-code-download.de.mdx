`QrCodeDownload` ist ein einzelner Button, der ein Menü mit Formaten und Größen öffnet und den Code als Datei speichert oder ein PNG in die Zwischenablage kopiert. Nutze ihn neben jedem Code, den du renderst, mit demselben Style-Objekt, damit die Datei zur Vorschau passt.

## Verwendung [#usage]

```tsx title="components/example.tsx"
import { QrCodeDownload } from "@/components/qr-code-download";
```

```tsx title="components/example.tsx"
<QrCodeDownload value="https://qrdx.dev" />
```

Das Menü listet jedes Format mit einem kurzen Hinweis auf, dazu eine Größenauswahl und **Bild kopieren**, was ein PNG in die Zwischenablage legt. Die Dateien werden im Browser gerendert; es wird nichts hochgeladen.

## Beispiele [#examples]

### Gestylter Export [#styled-export]

Gib `qr` dasselbe Style-Objekt, das du auch auf dem Bildschirm renderst, damit jede exportierte Datei zur Vorschau passt. `formats`, `sizes`, `label` und `variant` bestimmen das Menü und seinen Button.

<ComponentPreview name="qr-code-download-styled" />

### Formate [#formats]

| Format | Ausgabe |
| --- | --- |
| `png` | Bild mit dem Hintergrund des Codes |
| `jpg` | Bild mit einfarbigem Hintergrund |
| `svg` | Vektorgrafik, die sich auf jede Größe skalieren lässt |
| `pdf` | Dokument mit einer Seite. Benötigt das optionale Paket `jspdf` (`npm install jspdf`) |
| `eps` | Vektorgrafik für Druckereien und Design-Tools |

Rastergrößen reichen von 50 bis 5000 Pixeln. Übergib in `sizes` nur einen Eintrag, um die Größenauswahl auszublenden. Das Menü zeigt neben Rasterformaten die Pixelgröße und neben SVG und EPS „Vektor“ an.

### Nach einem Download [#after-a-download]

`onComplete` wird mit dem Format oder mit `"copy"` aufgerufen, nachdem eine Datei gespeichert oder das Bild kopiert wurde. `onError` erhält den Fehler, wenn ein Export fehlschlägt; die Meldung erscheint außerdem unter dem Button.

```tsx title="components/tracked-download.tsx"
import { QrCodeDownload } from "@/components/qr-code-download";

export function TrackedDownload({ url }: { url: string }) {
  return (
    <QrCodeDownload
      value={url}
      onComplete={(action) => console.log("exported", action)}
      onError={(error) => console.error(error.message)}
    />
  );
}
```

## Barrierefreiheit und Rendering [#accessibility-and-rendering]

- Der Auslöser ist dein Button, mit `aria-busy`, während eine Datei gerendert wird. Ein Ergebnis wird über eine Live-Region mit „polite“ angekündigt, und ein Fehler erscheint mit `role="alert"` unter dem Button.
- Das Menü ist dein DropdownMenu, daher folgen Tastaturnavigation und Fokus den Komponenten deines Themes.
- Kopieren benötigt eine Nutzeraktion und einen sicheren Kontext (HTTPS oder localhost); sonst lehnt der Browser es ab, und der Fehler erscheint unter dem Button.
- Die Komponente ist eine Client Component. Auf dem Server rendert sie außer dem Button nichts Sichtbares.
