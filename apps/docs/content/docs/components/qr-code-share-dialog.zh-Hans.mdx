`QrCodeShareDialog` 会打开一个对话框，以二维码形式显示链接，同时提供可复制链接的输入框、PNG 下载，在手机上还提供系统分享面板。当用户需要把链接交给身边的人时，例如邀请、文档或个人主页，可以把它放在“分享”按钮后面使用。

## 用法 [#usage]

```tsx title="components/example.tsx"
import { QrCodeShareDialog } from "@/components/qr-code-share-dialog";
```

```tsx title="components/example.tsx"
<QrCodeShareDialog url="https://example.com/invite/abc123" />
```

对话框中显示二维码、带复制按钮的只读链接输入框，以及 **下载 PNG**。在支持分享面板的设备（大多数手机）上，还会出现 **分享…** 按钮，点击即可打开分享面板。

## 示例 [#examples]

### 自定义触发器 [#custom-trigger]

将你自己的触发器作为子元素传入，例如工具栏中的图标按钮。`title`、`description` 和 `qr` 可用于自定义对话框。

### 受控模式 [#controlled]

该对话框接受 [Dialog](https://ui.shadcn.com/docs/components/dialog) 的属性，因此你可以通过代码打开它：

```tsx title="components/share-after-save.tsx"
"use client";

import { useState } from "react";
import { QrCodeShareDialog } from "@/components/qr-code-share-dialog";

export function ShareAfterSave({ url }: { url: string }) {
  const [open, setOpen] = useState(false);
  return (
    <>
      <button type="button" onClick={() => setOpen(true)}>
        Save and share
      </button>
      <QrCodeShareDialog url={url} open={open} onOpenChange={setOpen} />
    </>
  );
}
```

## 无障碍与渲染 [#accessibility-and-rendering]

- 该对话框就是你自己的 Dialog，因此打开时焦点会移入对话框，关闭时焦点会回到触发器。
- 二维码带有 `aria-label="QR code: <url>"`，链接输入框带有视觉上隐藏的“链接”标签。复制后，复制按钮的标签会短暂变为“链接已复制”。
- **分享…** 按钮仅在存在 `navigator.share` 的环境中显示，并且是在浏览器完成首次渲染之后才出现，因此服务器端的 HTML 与客户端的首次绘制保持一致。
- 点击链接输入框会选中整个链接。复制功能需要安全上下文（HTTPS 或 localhost）。
