`QrCodeScanner` adalah area tarik-dan-lepas yang mendekode kode QR dari berkas gambar, di browser, lalu memberikan teksnya kepada Anda. Gunakan untuk memeriksa tiket dari tangkapan layar, membaca kode dari foto yang diunggah pengguna, atau memverifikasi kode yang Anda buat. Komponen ini membaca berkas gambar, bukan umpan kamera langsung.

## Penggunaan [#usage]

```tsx title="components/example.tsx"
import { QrCodeScanner } from "@/components/qr-code-scanner";
```

```tsx title="components/example.tsx"
<QrCodeScanner onResult={(value) => console.log(value)} />
```

Pengguna menjatuhkan gambar atau mengeklik untuk memilihnya. Dekode berjalan di browser dengan [fungsi bantu deteksi](/docs/qr-detection) dari qrdx, sehingga gambar tidak pernah meninggalkan perangkat. Hasilnya muncul dengan tombol **Copy**, ditambah tombol **Open link** jika hasilnya berupa URL `http` atau `https`.

## Contoh [#examples]

### Memeriksa hasil [#checking-a-result]

`onResult` menerima teks hasil dekode, sehingga Anda dapat menindaklanjutinya, misalnya untuk memeriksa tiket. `label` mengubah judul di area tarik-dan-lepas. Unduh kode contoh di atas dan jatuhkan ke area tersebut untuk melihat tiket yang valid.

## Yang ditampilkan pembaca [#what-the-reader-shows]

| Status | Pesan |
| --- | --- |
| Pemindaian | "Scanning…" |
| Tidak ada kode di gambar | "No QR code found. Try a sharper or closer image." |
| Bukan berkas gambar | "Choose an image file." |
| Gambar tidak dapat dibaca | "Could not read that image." |
| Ditemukan | Teks hasil dekode, dengan **Copy** dan, untuk tautan, **Open link** |

Dekoder mencoba seluruh gambar dan empat potongan, pada beberapa skala, sehingga kode yang hanya menempati sebagian kecil tangkapan layar tetap dapat ditemukan.

## Aksesibilitas dan rendering [#accessibility-and-rendering]

- Area tarik-dan-lepas adalah `<label>` untuk input berkas yang tersembunyi secara visual, sehingga dapat digunakan dengan keyboard dan pembaca layar seperti pemilih berkas pada umumnya.
- Hasil dan kesalahan diumumkan melalui live region dengan tingkat polite.
- **Open link** terbuka di tab baru dengan `rel="noopener noreferrer nofollow"`, sehingga halaman hasil pemindaian tidak dapat mengakses halaman Anda.
- Komponen ini adalah Client Component. Komponen ini memerlukan canvas browser dan, pada pemindaian pertama, memuat dekoder sesuai kebutuhan.
