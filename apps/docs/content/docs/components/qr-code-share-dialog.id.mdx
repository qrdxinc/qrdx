`QrCodeShareDialog` membuka dialog yang menampilkan tautan sebagai kode QR, lengkap dengan tautan di kolom yang bisa disalin, unduhan PNG, dan, di ponsel, lembar berbagi sistem. Gunakan di balik tombol "Bagikan" di mana pun orang menyerahkan tautan kepada seseorang yang berdiri di dekatnya: undangan, dokumen, atau profil.

## Penggunaan [#usage]

```tsx title="components/example.tsx"
import { QrCodeShareDialog } from "@/components/qr-code-share-dialog";
```

```tsx title="components/example.tsx"
<QrCodeShareDialog url="https://example.com/invite/abc123" />
```

Dialog menampilkan kode, tautan di kolom hanya-baca dengan tombol salin, dan **Download PNG**. Di perangkat yang memiliki lembar berbagi (sebagian besar ponsel), tombol **Share…** akan membukanya.

## Contoh [#examples]

### Pemicu kustom [#custom-trigger]

Teruskan pemicu Anda sendiri sebagai children, misalnya tombol ikon di bilah alat. `title`, `description`, dan `qr` menyesuaikan dialog.

<ComponentPreview name="qr-code-share-dialog-trigger" />

### Terkontrol [#controlled]

Dialog menerima props [Dialog](https://ui.shadcn.com/docs/components/dialog), sehingga Anda bisa membukanya dari kode:

```tsx title="components/share-after-save.tsx"
"use client";

import { useState } from "react";
import { QrCodeShareDialog } from "@/components/qr-code-share-dialog";

export function ShareAfterSave({ url }: { url: string }) {
  const [open, setOpen] = useState(false);
  return (
    <>
      <button type="button" onClick={() => setOpen(true)}>
        Save and share
      </button>
      <QrCodeShareDialog url={url} open={open} onOpenChange={setOpen} />
    </>
  );
}
```

## Aksesibilitas dan perenderan [#accessibility-and-rendering]

- Dialog ini adalah Dialog Anda, sehingga fokus berpindah ke dalamnya saat dibuka dan kembali ke pemicu saat ditutup.
- Kode memiliki `aria-label="QR code: <url>"`, dan kolom tautan memiliki label "Link" yang tersembunyi secara visual. Label tombol salin berubah menjadi "Link copied" sesaat setelah penyalinan.
- Tombol **Share…** hanya muncul di tempat `navigator.share` tersedia, setelah render pertama di browser, sehingga HTML dari server dan tampilan pertama di klien tetap sama.
- Mengeklik kolom tautan akan memilih seluruh tautan. Penyalinan memerlukan konteks aman (HTTPS atau localhost).
