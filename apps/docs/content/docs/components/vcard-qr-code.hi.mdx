`VCardQrCode` एक ऐसा कोड रेंडर करता है जो फ़ोन कैमरे से स्कैन होने पर कॉन्टैक्ट सेव कर देता है। कोड के नीचे नाम और पद दिखता है। इसे बिज़नेस कार्ड, स्टाफ़ डायरेक्टरी, कॉन्फ़्रेंस बैज या ईमेल सिग्नेचर पेज पर इस्तेमाल करें।

## इस्तेमाल [#usage]

```tsx title="components/example.tsx"
import { VCardQrCode } from "@/components/vcard-qr-code";
```

```tsx title="components/example.tsx"
<VCardQrCode
  contact={{
    firstName: "Ada",
    lastName: "Lovelace",
    organization: "Analytical Engines",
    email: "ada@example.com",
  }}
/>
```

फ़ोन कैमरा कोड स्कैन करते ही कॉन्टैक्ट सेव करने का विकल्प देता है। खाली फ़ील्ड छोड़ दिए जाते हैं, जिससे कोड छोटा रहता है और जल्दी स्कैन होता है।

## उदाहरण [#examples]

### vCard बिल्डर [#vcard-builder]

`buildVCard` वह vCard 3.0 टेक्स्ट लौटाता है जिसे कोड एनकोड करता है। इसमें कॉमा, सेमीकोलन, बैकस्लैश और लाइन ब्रेक एस्केप किए जाते हैं। इसे किसी भी QR रेंडरर के साथ इस्तेमाल करें, या उसी कॉन्टैक्ट को `.vcf` डाउनलोड के रूप में देने के लिए इस्तेमाल करें।

<ComponentPreview name="vcard-qr-code-payload" />

कॉन्टैक्ट कार्ड में किसी लिंक से ज़्यादा टेक्स्ट होता है, इसलिए कॉम्पोनेंट मॉड्यूल बड़े रखने के लिए error correction level `M` इस्तेमाल करता है। सिर्फ़ वही फ़ील्ड जोड़ें जिनकी लोगों को ज़रूरत है, और प्रिंट का साइज़ कितना बड़ा रखना है, यह [प्रिंट साइज़ कैलकुलेटर](/tools/print-size) से जाँचें।

## एक्सेसिबिलिटी और रेंडरिंग [#accessibility-and-rendering]

- कोड में `aria-label="QR code with the contact card for <name>"` होता है। कार्ड के फ़ील्ड पढ़कर नहीं सुनाए जाते।
- कोड के नीचे का नाम, और टाइटल व संगठन figure का `<figcaption>` हैं। सिर्फ़ कोड दिखाने के लिए `showDetails={false}` सेट करें।
- यह कॉम्पोनेंट एक Client Component है, और कोड सर्वर पर रेंडर होता है।
