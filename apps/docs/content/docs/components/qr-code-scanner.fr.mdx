`QrCodeScanner` est une zone de dépôt qui décode un QR code à partir d'un fichier image, dans le navigateur, et vous renvoie le texte. Utilisez-le pour valider des billets à partir de captures d'écran, lire des codes dans des photos importées par vos utilisateurs, ou vérifier un code que vous avez généré. Il lit des fichiers image, pas un flux de caméra en direct.

## Utilisation [#usage]

```tsx title="components/example.tsx"
import { QrCodeScanner } from "@/components/qr-code-scanner";
```

```tsx title="components/example.tsx"
<QrCodeScanner onResult={(value) => console.log(value)} />
```

L'utilisateur dépose une image ou clique pour en choisir une. Le décodage s'exécute dans le navigateur avec les [fonctions de détection](/docs/qr-detection) de qrdx, de sorte que l'image ne quitte jamais l'appareil. Le résultat s'affiche avec un bouton **Copier**, ainsi qu'un bouton **Ouvrir le lien** lorsqu'il s'agit d'une URL `http` ou `https`.

## Ce qu'affiche le lecteur [#what-the-reader-shows]

| État | Message |
| --- | --- |
| Scan en cours | "Scanning…" |
| Aucun code dans l'image | "No QR code found. Try a sharper or closer image." |
| Fichier qui n'est pas une image | "Choose an image file." |
| Image illisible | "Could not read that image." |
| Code trouvé | Le texte décodé, avec **Copier** et, pour les liens, **Ouvrir le lien** |

Le décodeur essaie l'image entière et quatre recadrages, à plusieurs échelles, de sorte qu'un code qui n'occupe qu'une petite partie d'une capture d'écran est tout de même trouvé.

## Accessibilité et rendu [#accessibility-and-rendering]

- La zone de dépôt est un `<label>` associé à un champ de fichier masqué visuellement, ce qui la rend utilisable au clavier et avec les lecteurs d'écran, comme n'importe quel sélecteur de fichier.
- Les résultats et les erreurs sont annoncés par une région live en mode polite.
- **Ouvrir le lien** s'ouvre dans un nouvel onglet avec `rel="noopener noreferrer nofollow"`, afin qu'une page scannée ne puisse pas accéder à la vôtre.
- Le composant est un Client Component. Il a besoin du canvas du navigateur et, lors du premier scan, charge le décodeur à la demande.
