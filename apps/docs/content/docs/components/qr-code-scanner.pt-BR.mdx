`QrCodeScanner` é uma área de soltar arquivos que decodifica um QR code de uma imagem, no navegador, e devolve o texto para você. Use para fazer check-in de ingressos a partir de capturas de tela, ler códigos de fotos enviadas pelas pessoas ou verificar um código que você gerou. Ele lê arquivos de imagem, não a imagem ao vivo da câmera.

## Uso [#usage]

```tsx title="components/example.tsx"
import { QrCodeScanner } from "@/components/qr-code-scanner";
```

```tsx title="components/example.tsx"
<QrCodeScanner onResult={(value) => console.log(value)} />
```

As pessoas soltam uma imagem ou clicam para escolher uma. A decodificação roda no navegador com os [auxiliares de detecção](/docs/qr-detection) do qrdx, então a imagem nunca sai do dispositivo. O resultado aparece com um botão **Copiar**, além de um botão **Abrir link** quando for uma URL `http` ou `https`.

## O que o leitor mostra [#what-the-reader-shows]

| Estado | Mensagem |
| --- | --- |
| Lendo | "Lendo…" |
| Nenhum código na imagem | "Nenhum QR code encontrado. Tente uma imagem mais nítida ou mais próxima." |
| Não é um arquivo de imagem | "Escolha um arquivo de imagem." |
| Não foi possível ler a imagem | "Não foi possível ler essa imagem." |
| Encontrado | O texto decodificado, com **Copiar** e, para links, **Abrir link** |

O decodificador tenta a imagem inteira e quatro recortes, em várias escalas, então um código que ocupa uma pequena parte de uma captura de tela ainda é encontrado.

## Acessibilidade e renderização [#accessibility-and-rendering]

- A área de soltar é um `<label>` de um campo de arquivo oculto visualmente, então funciona com o teclado e com leitores de tela como qualquer seletor de arquivos.
- Resultados e erros são anunciados por uma região live com prioridade polite.
- **Abrir link** abre em uma nova aba com `rel="noopener noreferrer nofollow"`, para que uma página lida não consiga acessar a sua.
- O componente é um Client Component. Ele precisa do canvas do navegador e, na primeira leitura, carrega o decodificador sob demanda.
