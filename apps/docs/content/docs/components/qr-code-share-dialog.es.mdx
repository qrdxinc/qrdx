`QrCodeShareDialog` abre un diálogo que muestra un enlace como código QR, con el enlace en un campo que puedes copiar, una descarga en PNG y, en teléfonos, el menú de compartir del sistema. Úsalo detrás de un botón "Compartir" en cualquier lugar donde las personas pasen un enlace a alguien que tienen al lado: una invitación, un documento, un perfil.

## Uso [#usage]

```tsx title="components/example.tsx"
import { QrCodeShareDialog } from "@/components/qr-code-share-dialog";
```

```tsx title="components/example.tsx"
<QrCodeShareDialog url="https://example.com/invite/abc123" />
```

El diálogo muestra el código, el enlace en un campo de solo lectura con un botón para copiar, y **Descargar PNG**. En dispositivos con menú de compartir (la mayoría de los teléfonos), un botón **Compartir…** lo abre.

## Ejemplos [#examples]

### Disparador personalizado [#custom-trigger]

Pasa tu propio disparador como children, por ejemplo un botón de icono en una barra de herramientas. `title`, `description` y `qr` personalizan el diálogo.

<ComponentPreview name="qr-code-share-dialog-trigger" />

### Controlado [#controlled]

El diálogo acepta las props de [Dialog](https://ui.shadcn.com/docs/components/dialog), así que puedes abrirlo desde el código:

```tsx title="components/share-after-save.tsx"
"use client";

import { useState } from "react";
import { QrCodeShareDialog } from "@/components/qr-code-share-dialog";

export function ShareAfterSave({ url }: { url: string }) {
  const [open, setOpen] = useState(false);
  return (
    <>
      <button type="button" onClick={() => setOpen(true)}>
        Save and share
      </button>
      <QrCodeShareDialog url={url} open={open} onOpenChange={setOpen} />
    </>
  );
}
```

## Accesibilidad y renderizado [#accessibility-and-rendering]

- El diálogo es tu Dialog, así que el foco se mueve a él al abrirse y vuelve al disparador al cerrarse.
- El código tiene `aria-label="QR code: <url>"`, y el campo del enlace tiene una etiqueta "Enlace" oculta visualmente. La etiqueta del botón de copiar cambia a "Enlace copiado" durante un momento después de copiar.
- El botón **Compartir…** aparece solo donde existe `navigator.share`, después del primer renderizado en el navegador, de modo que el HTML del servidor y el primer pintado del cliente coinciden.
- Al hacer clic en el campo del enlace se selecciona todo el enlace. Copiar requiere un contexto seguro (HTTPS o localhost).
