`WifiQrCode`는 휴대폰 카메라로 스캔하면 Wi-Fi 네트워크에 연결되는 코드를 렌더링하고, 그 아래에 네트워크 이름을 표시합니다. 접수처의 게스트 네트워크 카드, 카페의 테이블 안내판, 숙소의 환영 페이지에 사용해 보세요.

## 사용법 [#usage]

```tsx title="components/example.tsx"
import { WifiQrCode } from "@/components/wifi-qr-code";
```

```tsx title="components/example.tsx"
<WifiQrCode ssid="Cafe Guest" password="espresso-2024" />
```

iOS와 Android 카메라는 코드를 스캔하면 네트워크에 연결할지 물어봅니다. 별도의 앱은 필요하지 않습니다. 코드 아래에는 네트워크 이름과 "Scan with your camera to join"이 표시됩니다.

## 예시 [#examples]

### 변형 [#variants]

`showPassword`는 비밀번호를 직접 입력하려는 손님을 위해 비밀번호를 표시합니다. 개방형 네트워크에는 `encryption="nopass"`를, 네트워크 이름을 공개하지 않는 네트워크에는 `hidden`을 사용하세요.

<ComponentPreview name="wifi-qr-code-variants" />

### 페이로드 빌더 [#payload-builder]

`buildWifiPayload`는 코드에 인코딩되는 `WIFI:` 텍스트를 반환합니다. 이름과 비밀번호에 들어 있는 `\`, `;`, `,`, `:`, `"`를 이스케이프 처리하는데, 직접 작성한 페이로드는 대개 이 부분에서 문제가 생깁니다. 어떤 QR 렌더러와도 함께 사용할 수 있고, 디버깅을 위해 페이로드를 출력하는 데도 쓸 수 있습니다.

## 접근성과 렌더링 [#accessibility-and-rendering]

- 코드에는 `aria-label="QR code to join the Wi-Fi network <ssid>"`가 지정되어 있습니다. 비밀번호가 담긴 페이로드는 음성으로 읽히지 않습니다.
- 코드 아래의 이름과 비밀번호는 figure의 `<figcaption>`입니다. 코드만 표시하려면 `showDetails={false}`를 설정하세요.
- 이 컴포넌트는 Client Component이며, 코드는 서버에서 렌더링됩니다.

### buildWifiPayload [#buildwifipayload]

`buildWifiPayload(network: WifiNetwork): string`은 컴포넌트와 동일한 네트워크 필드인 `ssid`, `password`, `encryption`, `hidden`을 받습니다. `"WPA"`는 WPA, WPA2, WPA3를 모두 포함하며, 나머지 값은 `"WEP"`와 `"nopass"`입니다. `"nopass"`를 사용하면 비밀번호는 제외됩니다.
