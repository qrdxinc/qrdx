`QrCodeGenerator` adalah generator kecil dalam satu komponen: kolom teks, pratinjau yang digambar ulang saat Anda mengetik, deretan preset gaya, dan tombol unduh. Gunakan komponen ini agar pengguna Anda bisa membuat kode langsung di dalam produk Anda, tanpa perlu diarahkan ke tempat lain.

## Penggunaan [#usage]

```tsx title="components/example.tsx"
import { QrCodeGenerator } from "@/components/qr-code-generator";
```

```tsx title="components/example.tsx"
<QrCodeGenerator defaultValue="https://example.com" />
```

Pratinjau diperbarui saat Anda mengetik. Setiap tombol preset menampilkan contoh kecil gayanya, dan unduhan menggunakan preset yang dipilih pada ukuran 1024 piksel. Jika kolom kosong, pratinjau menampilkan "Type some text to generate a code" dan tombol unduh dinonaktifkan.

## Contoh [#examples]

### Preset kustom [#custom-presets]

Ganti preset bawaan dengan preset Anda sendiri. Sebuah preset terdiri dari `id`, `name`, dan `style` dengan opsi qrdx apa pun, termasuk gradien, logo, dan `level` koreksi kesalahan.

<ComponentPreview name="qr-code-generator-presets" />

Preset bawaan diekspor sebagai `QR_CODE_PRESETS`, sehingga Anda bisa memperluasnya:

```tsx title="components/brand-generator.tsx"
import {
  QR_CODE_PRESETS,
  QrCodeGenerator,
} from "@/components/qr-code-generator";

export function BrandGenerator() {
  return (
    <QrCodeGenerator
      presets={[
        ...QR_CODE_PRESETS,
        { id: "brand", name: "Brand", style: { fgColor: "#155DFC" } },
      ]}
    />
  );
}
```

### Menyimpan hasil [#saving-the-result]

`onChange` melaporkan teks dan preset yang dipilih pada setiap perubahan, misalnya untuk menyimpan pilihan pengguna:

```tsx title="components/draft-generator.tsx"
import { QrCodeGenerator } from "@/components/qr-code-generator";

export function DraftGenerator({
  saveDraft,
}: {
  saveDraft: (draft: { value: string; style: object }) => void;
}) {
  return (
    <QrCodeGenerator
      onChange={({ value, preset }) =>
        saveDraft({ value, style: preset.style })
      }
    />
  );
}
```

## Aksesibilitas dan rendering [#accessibility-and-rendering]

- Kolom ini memiliki label "Text or URL" yang terlihat, dan preset berupa `<fieldset>` dengan legenda "Style". Setiap preset adalah tombol toggle dengan `aria-pressed`, dan kode contohnya disembunyikan dari pembaca layar.
- Pratinjau adalah elemen `role="img"` dengan label `QR code: <value>`, atau "Empty QR code preview" jika tidak ada teks.
- Kesalahan unduhan ditampilkan di bawah pratinjau dengan `role="alert"`.
- Komponen ini adalah Client Component dengan state sendiri. Render dari halaman mana pun; berikan `defaultValue` dan `defaultPreset` agar komponen langsung terisi saat dimulai.
