`QrCodeCard` place un QR code dans une carte avec un cadre d'appel à l'action, un titre, une ligne de texte et un pied de carte pour des boutons. Utilisez-le quand le code est l'élément central de la carte : un chevalet de table, un écran d'enregistrement, un aperçu d'affiche d'événement, une vignette « téléchargez notre application ».

## Utilisation [#usage]

```tsx title="components/example.tsx"
import { QrCodeCard } from "@/components/qr-code-card";
```

```tsx title="components/example.tsx"
<QrCodeCard
  value="https://example.com/menu"
  title="Our menu"
  description="Scan to see today's specials."
/>
```

Tout ce que vous passez en enfants s'affiche dans le pied de la carte, par exemple un bouton de copie ou un [menu de téléchargement](/docs/components/qr-code-download).

## Exemples [#examples]

### Cadres [#frames]

`frame` place l'appel à l'action sous le code (`"bottom"`), au-dessus (`"top"`) ou supprime le cadre (`"none"`). `cta` modifie le libellé, et `frameClassName` change le style du cadre, par exemple avec la couleur de votre marque.

<ComponentPreview name="qr-code-card-frames" />

Par défaut, le cadre utilise les couleurs `foreground` et `background` de votre thème, ce qui le garde lisible en mode clair comme en mode sombre. Le code lui-même conserve un fond clair, que tous les lecteurs savent lire.

### Personnaliser le style du code [#styling-the-code]

`qr` accepte toutes les options de style de qrdx : `fgColor`, `bgColor`, les dégradés, `bodyPattern`, les motifs de coins, `logo` et `templateId`.

```tsx title="components/brand-card.tsx"
import { QrCodeCard } from "@/components/qr-code-card";

export function BrandCard() {
  return (
    <QrCodeCard
      value="https://example.com"
      title="example.com"
      qr={{
        fgColor: "#155DFC",
        bodyPattern: "rounded",
        cornerEyePattern: "extra-rounded",
      }}
    />
  );
}
```

## Accessibilité et rendu [#accessibility-and-rendering]

- Le code se trouve dans un élément `role="img"` dont l'attribut `aria-label` correspond à `label`, ou à `QR code: <value>` si `label` est absent. Renseignez `label` quand la valeur n'est pas un lien public.
- `title` s'affiche comme titre de la carte et `description` en dessous ; les deux acceptent n'importe quel nœud React.
- Le composant est un Client Component. Une page Server Component peut l'importer et lui passer des données serveur en props, et le code est rendu côté serveur.
