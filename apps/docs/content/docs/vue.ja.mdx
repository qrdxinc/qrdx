このページを読み終えると、Vue 3 のコンポーネントでスタイル付きQRコードがサーバー上で描画され、ハイドレーションの不一致なしに動作し、PNG として保存するボタンも使える状態になります。`qrdx/vue` には、React コンポーネントの Vue 版である `QRCode` と `QRCodeSVG`、そして `useQRCode` コンポーザブルが含まれています。props は React コンポーネントと同じで、描画される SVG も同じです。エントリーポイントは `qrdx/core` をベースにしており、`react` はインポートしません。

<NpmStatus package="qrdx" />

## はじめる前に [#before-you-start]

- Vite または Nuxt を使った Vue 3.3 以降のプロジェクト。コンポーネントの props を TypeScript が検査するのは Vue 3.4.20 以降です。
- Node.js 18 以降。

## 作成手順 [#build-it]

### 1. qrdx をインストールする [#1-install-qrdx]

```package-install
qrdx
```

`vue` は任意のピア依存関係なので、アプリ自身の Vue が使われます。

### 2. コードを描画する [#2-draw-a-code]

```vue title="src/App.vue"
<script setup lang="ts">
import { QRCode } from "qrdx/vue";
import { ref } from "vue";

const url = ref("https://example.com/menu");
</script>

<template>
  <QRCode
    :value="url"
    :size="256"
    :margin="4"
    body-pattern="rounded"
    :frame="{ style: 'banner-bottom', text: 'Scan for the menu' }"
    aria-label="QR code for the menu"
  />
</template>
```

ページには、角丸モジュールの 256 px のコードと、その下にバナーが表示されます。`url` を変更するとコードが再描画され、Vue が `<svg>` をその場で更新します。

<Shot id="lib-framed-menu-code" />

`QRCode` は React の `QRCode` と同じ props を受け取ります。すべての `QRProps` オプションに加えて、ロゴ用の `logo`、`logoOptions`、`hideLogo`、`scale` も使えます。テンプレートでは、ケバブケース(`body-pattern`)でもキャメルケースでも記述できます。`auto-level` や `hide-logo` のようなフラグには値は不要です。`class`、`style`、`aria-label` などの属性は `<svg>` に付きます。フレームがある場合はフレームの外側の `<svg>` に付き、`@click` などのリスナーも同様です。

### 3. useQRCode でファイルとして保存する [#3-save-it-as-a-file-with-useqrcode]

```vue title="src/components/DownloadCode.vue"
<script setup lang="ts">
import { useQRCode } from "qrdx/vue";
import { ref } from "vue";

const url = ref("https://example.com/menu");
const { svg, download } = useQRCode(() => ({
  value: url.value,
  size: 256,
  margin: 4,
  bodyPattern: "rounded",
}));
</script>

<template>
  <div v-html="svg" />
  <button type="button" @click="download({ format: 'png', size: 1024, filename: 'menu.png' })">
    Download PNG
  </button>
</template>
```

コードはマークアップから表示され、ボタンを押すと `menu.png` が 1024 px で保存されます。`useQRCode(props)` は、`QRCode` の props をオブジェクト、ref、リアクティブオブジェクト、またはゲッターとして受け取り、次を返します。

- `svg`: SVG マークアップを算出 ref として返します。props に追従し、サーバーサイドレンダリング中でも動作します。
- `toDataURL(format, { size, quality })`: コードをデータ URL として返します。
- `download({ format, filename, size, quality })`: コードをファイルとして保存します。
- `options`: コードの描画に使われるオプションを算出 ref として返します。

`toDataURL` と `download` は、既定ではコード自身の `size` の PNG になります。使える形式は `png`、`jpg`、`webp`、`svg`、`pdf`、`eps` です。PNG、JPG、WebP にはブラウザーが必要で、PDF には任意パッケージの `jspdf` が必要です。

## QRCodeSVG と生の画像設定 [#qrcodesvg-and-raw-image-settings]

`QRCodeSVG` は、React の `QRCodeSVG` と同様に `QRProps` を受け取ります。ロゴは `imageSettings` にピクセル単位で指定します。

```vue title="src/components/LogoCode.vue"
<script setup lang="ts">
import { QRCodeSVG } from "qrdx/vue";
</script>

<template>
  <QRCodeSVG
    value="https://example.com"
    :size="256"
    level="H"
    :image-settings="{ src: '/logo.png', width: 48, height: 48, excavate: true }"
  />
</template>
```

ロゴの配置を自分で行う場合を除き、`logo` と `logoOptions` を使った `QRCode` をおすすめします。

## サーバーサイドレンダリングと Nuxt [#server-rendering-and-nuxt]

どちらのコンポーネントも Vue のサーバーレンダラー(`vue/server-renderer`)で描画できるため、コードはサーバーの HTML に含まれます。マークアップにランダムな id は含まれないので、ブラウザーは不一致なしでハイドレートします。

Nuxt では、任意のページやコンポーネントで使えます。サーバー上で描画され、ブラウザーでハイドレートされます。`<ClientOnly>` の内側ではブラウザーでのみ描画されます。

## qrdx/core のその他の機能 [#more-from-qrdxcore]

`qrdx/vue` は `qrdx/core` のすべてを再エクスポートします。`toSVGString`、`downloadQRCode`、`getQRCodeDataUrl`、`getScanScore`、公式フレームライブラリ(`getOfficialFrame`)などです。詳しくは [Vanilla JavaScript](/docs/vanilla-js) を参照してください。サーバーで PNG を生成するには、`qrdx/node` の `getQRAsPNG` を使います。

カスタムテンプレートの `wrapper` は、`qrdx/vue` がエクスポートする `h` で記述します。これは Vue の `h` ではなくコアの `h` なので、1 つのファイルで両方が必要な場合は、どちらかを別名でインポートしてください。

```ts title="src/labelled-template.ts"
import { h } from "qrdx/vue";

export const Labelled = {
  id: "Labelled",
  name: "Labelled",
  wrapper: (children, props) =>
    h(
      "svg",
      { viewBox: "0 0 300 340", xmlns: "http://www.w3.org/2000/svg" },
      h("g", { transform: "translate(20, 20) scale(0.87)" }, children),
      h("text", { x: "150", y: "325", textAnchor: "middle" }, props?.label)
    ),
};
```

これを `customTemplate` として渡し、その props は `customProps` に指定します。`<QRCode value="https://example.com" :custom-template="Labelled" :custom-props="{ label: 'Scan me' }" />`

## うまくいかない場合 [#if-something-goes-wrong]

- **`Failed to resolve component: QRCode`。** そのファイルでコンポーネントがインポートされていません。`<script setup>` に `import { QRCode } from "qrdx/vue"` を追加してください。
- **props が効かない。** 値が必要な props を属性文字列として書いています。`size="256"` は文字列を渡し、`:size="256"` は数値を渡します。`frame` や `image-settings` などのオブジェクト型の props には、常にコロンが必要です。
- **`PDF export needs the optional "jspdf" package`。** アプリで `npm install jspdf` を実行してください。
