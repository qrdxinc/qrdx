Eine **Produkt**-Seite ist eine [gehostete Seite](/docs/landing-pages) für einen Code, der auf eine Verpackung, ein Etikett oder einen Hang-Tag gedruckt wird. Sie enthält, wofür auf der Verpackung kein Platz ist: die vollständige Zutatenliste, Allergene, eine Nährwerttabelle, Zertifizierungen sowie Pflege- und Recyclinghinweise. Wie jede gehostete Seite kannst du sie nach dem Druck ändern und jeden Scan sehen. Nutze sie für Lebensmittel, Getränke, Kosmetik und alles, was einen Produktpass braucht.

<Callout type="info" title="Tarife">
  Produktseiten zählen als gehostete Seiten und unterliegen denselben [Tarifgrenzen](/docs/plans-and-limits) wie alle anderen Seitentypen. GS1 Digital Link braucht eine [eigene Domain](/docs/custom-domains), die in Pro und Business enthalten ist.
</Callout>

Es muss schnell gehen? Hier die kurze Anleitung: [Mobile Seite erstellen](/docs/help/pages-and-forms/create-a-page).

## Produktseite erstellen [#create-a-product-page]

1. Klicke auf **Neuer Code** und wähle **Produkt**, oder auf **Neue Seite** unter **Seiten & Formulare**.
2. Wähle eine Vorlage:
   - **Lebensmittel**: Zutaten, Allergene und eine Nährwerttabelle.
   - **Wein & Getränke**: Zutaten und Energie pro 100 ml, ein E-Label für eine Flasche.
   - **Beauty & Pflege**: die vollständige Zutatenliste, Anwendung, Warnhinweise.
   - **Produktpass**: Materialien, Herstellungsort, Pflege, Reparatur und Lebensende.
3. Ersetze den Beispieltext, die Zahlen und das Foto durch die Angaben zu deinem Produkt und klicke dann auf **Veröffentlichen**.

## Der Block „Produktdetails" [#the-product-details-block]

| Teil | Was er zeigt |
| --- | --- |
| Zertifizierungen und Labels | Kurze Labels wie „Bio-zertifiziert" oder „Recycelbare Verpackung". Der Editor schlägt gängige vor. Führe nur Labels auf, die dein Produkt tatsächlich hat. |
| Zutaten oder Materialien | Reiner Text, Zeilenumbrüche bleiben erhalten |
| Allergene | Die 14 Allergene, die Lebensmittelunternehmen in der EU und im Vereinigten Königreich angeben müssen, angezeigt als „Enthält: …", plus ein Hinweis wie „Kann Spuren von Erdnüssen enthalten" |
| Nährwerte | Eine Tabelle: worauf sich die Werte beziehen („Pro 100 g"), dann jeder Nährstoff mit seiner Menge. Zeilen können eingerückt werden („davon Zucker"). Zeilen ohne Menge werden ausgeblendet. |
| Weitere Informationen | Abschnitte, die sich per Tippen öffnen: Pflege, Recycling, Warnhinweise, Herkunft oder alles andere |
| GTIN | Die Nummer unter dem Barcode des Produkts (8, 12, 13 oder 14 Ziffern). QRdx prüft die Prüfziffer. Wird unter den Details angezeigt, sofern du es nicht ausschaltest. |

Der Block **Details** (Bezeichnungen und Werte, als Liste oder Kacheln) passt zu den Fakten rundherum: Nettogewicht, Herkunft, Alkoholgehalt, Größe.

<IfAvailable feature="customDomains" title="GS1 Digital Link">

[GS1 Digital Link](https://www.gs1.org/standards/gs1-digital-link) ist der GS1-Standard für QR-Codes auf Produkten: Der Code enthält eine Webadresse mit der GTIN des Produkts, etwa `https://go.yourbrand.com/01/09506000134352`. So kann derselbe Code deine Seite öffnen und die GTIN tragen, die ein Kassenscanner liest.

Wenn der QR-Code einer Produktseite deine [eigene Domain](/docs/custom-domains) nutzt und die Seite eine GTIN hat, öffnet diese Adresse die Seite:

- `https://<your domain>/01/<GTIN>` öffnet die Produktseite und zählt einen Scan ihres Codes, genau wie der Kurzlink des Codes. Auch die Code-Steuerung (Passwort, Zeitplan, Scan-Limit, Pause) greift.
- Eine Variante eines Konsumguts (`/22/<variant>`), eine Charge oder ein Los (`/10/<lot>`) und eine Seriennummer (`/21/<serial>`) können in dieser Reihenfolge auf die GTIN folgen, jeweils bis zu 20 Zeichen. Sie werden akzeptiert, und es öffnet sich dieselbe Seite.
- Eine GTIN mit falscher Prüfziffer oder Teile in der falschen Reihenfolge zeigen statt einer Seite „Dieser Produktlink ist ungültig".

So nutzt du es:

1. Verschiebe den Code der Produktseite auf deine eigene Domain (**Link bearbeiten** am Code).
2. Gib die GTIN im Block **Produktdetails** der Seite ein und veröffentliche. Der Block zeigt dann den GS1 Digital Link mit einer Kopieren-Schaltfläche.
3. Erstelle den QR-Code für deine Verpackung aus diesem Link. Der Kurzlink des Codes funktioniert weiterhin.

Eine GTIN öffnet pro Domain eine Produktseite. Wenn eine andere Seite mit einem Code auf derselben Domain sie schon nutzt, nennt dir das Veröffentlichen diese Seite, damit du eine der beiden ändern kannst.

### Nur auf deiner eigenen Domain [#only-on-your-own-domain]

Auf der gemeinsamen Adresse von QRdx (`qrdx.dev`) nutzen Produktseiten ihren normalen Kurzlink, und GTINs öffnen nie eine Seite. Jeder kann ein QRdx-Konto erstellen, daher könnte jemand mit einer gemeinsamen GTIN-Abfrage die Produktnummer einer fremden Marke für sich beanspruchen. Auf deiner eigenen Domain können nur die Seiten deines Workspace antworten.

## Grenzen und Tarife [#limits-and-plans]

| | Kostenlos | Pro | Business |
| --- | --- | --- | --- |
| Produktseiten | Innerhalb der 3 gehosteten Seiten | Unbegrenzt | Unbegrenzt |
| GS1 Digital Link auf deiner Domain | Nein | Ja | Ja |

## Für Entwickler [#for-developers]

Eine Produktseite ist eine gehostete Seite, daher hat ihr Code in der [REST API](/docs/developers/api/get-code) `kind: "page"`. Den Inhalt der Seite, einschließlich der GTIN, bearbeitest du im Dashboard.
