このページを終えると、通常の HTML ページ上で `<qrdx-code>` 要素が描画したスタイル付きQRコードができあがります。オブジェクト形式のオプションはスクリプトから設定し、PNG へのエクスポートも行います。`qrdx/element` は `qrdx/core` を土台にしているため、React の `QRCodeSVG` と同じ SVG を、あらゆるスタイル、フレーム、ロゴ、エクスポートに対応して描画します。フレームワークは不要で、DOM 要素をレンダリングするフレームワークでも動作します。React 19 と Vue 3 で動作を確認しています。

<NpmStatus package="qrdx" />

## 始める前に [#before-you-start]

- `<script type="module">` を追加できるページ。バンドラーは不要ですが、使っても構いません。
- バンドラーを使う場合は、Node.js 18 以降。

## 作成手順 [#build-it]

### 1. 要素を読み込む [#1-load-the-element]

<Tabs items={["From a CDN", "With a bundler"]}>
<Tab value="From a CDN">

```html title="index.html"
<script
  type="module"
  src="https://cdn.jsdelivr.net/npm/qrdx/dist/element-define.browser.mjs"
></script>
```

`dist/element-define.browser.mjs` は `<qrdx-code>` を登録します。このファイルは `dist/element.browser.mjs` を読み込みます。これはエンジンを内蔵した 1 つの ES モジュールです。バージョンを固定するには、URL の `qrdx` の後ろに `@` とバージョンを付けます。unpkg でも同じパスが使えます。

</Tab>
<Tab value="With a bundler">

```package-install
qrdx
```

```js title="main.js"
import "qrdx/element/define"; // registers <qrdx-code>
```

`qrdx/element` をインポートするだけでは何も登録されません。タグ名を自分で決めるには、`defineQRdxCode` を呼び出します。

```js title="main.js"
import { defineQRdxCode } from "qrdx/element";

defineQRdxCode(); // <qrdx-code>
defineQRdxCode("brand-qr"); // <brand-qr> as well
```

繰り返し呼び出しても問題なく、サーバー上では何も行いません。同じ名前を別の要素がすでに使っている場合は、エラーをスローします。

</Tab>
</Tabs>

### 2. ページにコードを置く [#2-put-a-code-in-the-page]

```html title="index.html"
<qrdx-code
  value="https://example.com/menu"
  size="256"
  margin="4"
  body-pattern="rounded"
  label="QR code for the menu"
></qrdx-code>
```

ページには、角丸モジュールの 256 px のコードが表示されます。ブラウザーのインスペクターで属性を編集すると、コードが再描画されます。

<Shot id="lib-element-code" />

### 3. スクリプトからオブジェクト形式のオプションを設定する [#3-set-object-options-from-a-script]

グラデーション、フレーム、ロゴなどのオブジェクト形式のオプションはプロパティです。スクリプトから設定します。

```js title="main.js"
const qr = document.querySelector("qrdx-code");

qr.fgColor = {
  type: "linear",
  angle: 45,
  stops: [
    { color: "#1d4ed8", offset: 0 },
    { color: "#0f172a", offset: 100 },
  ],
};
qr.frame = { style: "banner-bottom", text: "Scan for the menu" };
qr.imageSettings = { src: "/logo.png", width: 40, height: 40, excavate: true };
qr.props = { eyeColor: "#be123c" };
```

コードは、グラデーション、バナー、ロゴ、赤い目とともに 1 回だけ再描画されます。スクリプトを使わない場合は、オブジェクト形式のオプションを JSON として `props` 属性に指定します。

```html title="index.html"
<qrdx-code
  value="https://example.com"
  props='{"frame": {"style": "banner-bottom", "text": "Scan me"}}'
></qrdx-code>
```

### 4. エクスポートする [#4-export-it]

```js title="main.js"
qr.toSVGString(); // '<svg xmlns="http://www.w3.org/2000/svg" …'
await qr.toDataURL("png", { size: 1024 }); // "data:image/png;base64,…"
await qr.download({ format: "png", size: 1024, filename: "menu.png" });
```

`download` は `menu.png` を 1024 px で保存します。エクスポートは、`qrdx/core` の `toSVGString` や `downloadQRCode` と同様に `qr.options` からコードを描画し、要素の `part`、`role`、`aria-label` は含めません。`toDataURL` と `download` は、デフォルトでコードの `size` の PNG になります。使える形式は `png`、`jpg`、`webp`、`svg`、`pdf`、`eps` です。値がない場合は、スローされるか（`toSVGString`）、reject されます。

PDF にはオプションの `jspdf` パッケージが必要です。CDN から使う場合は、モジュールスクリプトの前に置いた import map で割り当てます。

```html title="index.html"
<script type="importmap">
  { "imports": { "jspdf": "https://cdn.jsdelivr.net/npm/jspdf@4/+esm" } }
</script>
```

## 属性 [#attributes]

| 属性 | 設定する内容 |
| --- | --- |
| `value` | エンコードするテキストまたは URL。指定がない場合は何も描画されません |
| `size` | 幅と高さ（ピクセル単位。フレームを付けるとその分が加わります） |
| `level` | 誤り訂正レベル：`L`、`M`、`Q`、`H` |
| `fg-color`、`bg-color`、`eye-color`、`dot-color` | 単色の色 |
| `body-pattern`、`corner-eye-pattern`、`corner-eye-dot-pattern` | モジュール、目、目のドットの形状 |
| `margin` | クワイエットゾーン（モジュール単位） |
| `template-id` | 組み込みテンプレート |
| `module-scale` | 各モジュールのサイズ（0.5 から 1） |
| `auto-level` | ロゴが必要とする場合に、誤り訂正を `H` に引き上げます |
| `shape` | `square`、`circle`、`heart` |
| `label` | スクリーンリーダーが読み上げる内容（デフォルトは "QR code"） |
| `props` | その他のオプション（JSON） |

読み取れない数値やレベルは無視されます。すべてのパターンは [形状、目、フレーム](/docs/styles) で確認できます。

## プロパティ [#properties]

各属性は、オプション名と同じ名前のプロパティでもあります（`qr.fgColor`、`qr.bodyPattern`、`qr.templateId`）。オブジェクト形式のオプションはプロパティ専用です。グラデーションと画像の塗り、`frame`、`imageSettings`、`eyeColors`、`art`、`customTemplate`、`customProps` が該当します。`props` では、すべてのオプションをまとめて指定できます。

- 同じオプションが `props` にもある場合は、属性または名前付きプロパティが優先されます。属性とそのプロパティの間では、最後に設定した方が優先されます。プロパティを `undefined` に設定すると、その指定を取り消せます。
- プロパティは属性に書き戻されません。
- 変更はまとめて処理されます。続けて何回変更しても、コードはマイクロタスクで 1 回だけ再描画され、マークアップが変わった場合に限られます。
- `qr.options` はコードの描画に使われるオプションで、`qr.svg` は描画された `<svg>` です。
- 要素が定義される前に設定されたプロパティは、定義時に反映されます。

公式フレームは、要素と同じ場所にあるファイルから読み込みます。

```js title="main.js"
import { getOfficialFrame } from "https://cdn.jsdelivr.net/npm/qrdx/dist/frames-official.mjs";

qr.frame = { style: "custom", spec: getOfficialFrame("wifi-card").spec };
```

## スタイルとアクセシビリティ [#styling-and-accessibility]

コードは open の shadow root 内に描画されます。ページの CSS からはそのパスに届かないため、`svg path { fill: red }` や `svg { width: 100% }` のようなルールでコードが壊れることはありません。外部から `<svg>` にスタイルを付けるには、`::part(svg)` を使います。

```css title="styles.css"
qrdx-code::part(svg) {
  border-radius: 12px;
}
```

要素は `inline-block` です。内部の `<svg>` は `size` の大きさを保ちますが、コンテナーが狭い場合はそれに合わせて縮みます。

`<svg>` には `role="img"` が付き、`aria-label` には `label` 属性の値が入ります。指定がない場合は "QR code" になります。ラベルが value に切り替わることはありません。value には Wi-Fi のパスワードや連絡先が含まれる場合があるためです。

## サーバーレンダリング [#server-rendering]

`toQRdxCodeHTML(options)` は、宣言的 shadow root の中にコードを描画済みの状態で、要素のマークアップを返します。ブラウザーはスクリプトが実行される前にコードを表示し、要素が定義された時点で処理を引き継ぎます。Node で動作し、DOM は不要です。

```js title="server.js"
import { toQRdxCodeHTML } from "qrdx/element";

const html = toQRdxCodeHTML(
  {
    value: "https://example.com",
    size: 256,
    frame: { style: "banner-bottom", text: "Scan me" },
  },
  { label: "Link to example.com" }
);
// <qrdx-code value="https://example.com" size="256" label="Link to example.com"
//   props="{…}"><template shadowrootmode="open">…</template></qrdx-code>
```

単純なオプションは属性になり、残りは JSON として `props` に入るため、要素は同じオプションを読み戻せます。`customTemplate` はマークアップとして書き出せないので、ブラウザー側でプロパティとして設定してください。別の名前で登録した場合は `tagName` を渡します。

## React 19 [#react-19]

React 19 は、要素にプロパティがある場合、props をプロパティとして設定します。そのため、オブジェクトも props として渡せます。レンダリングの前に、要素を 1 回登録します。

```tsx title="components/menu-code.tsx"
import "qrdx/element/define";

export function MenuCode({ url }: { url: string }) {
  return (
    <qrdx-code
      value={url}
      size={256}
      body-pattern="rounded"
      frame={{ style: "banner-bottom", text: "Scan me" }}
      label="Menu"
    />
  );
}
```

TypeScript では、`.d.ts` ファイルで要素を JSX に追加します。

```ts title="qrdx-code.d.ts"
import type { QRdxCodeElement, QRdxCodeJSXProps } from "qrdx/element";

declare module "react" {
  namespace JSX {
    interface IntrinsicElements {
      "qrdx-code": React.DetailedHTMLProps<
        React.HTMLAttributes<QRdxCodeElement>,
        QRdxCodeElement
      > &
        QRdxCodeJSXProps;
    }
  }
}
```

`ref` から要素を取得でき、`toDataURL` や `download` に使えます。

## Vue [#vue]

`qrdx-code` がカスタム要素であることを Vue のコンパイラーに伝えます。

```js title="vite.config.js"
import vue from "@vitejs/plugin-vue";
import { defineConfig } from "vite";

export default defineConfig({
  plugins: [
    vue({
      template: {
        compilerOptions: { isCustomElement: (tag) => tag === "qrdx-code" },
      },
    }),
  ],
});
```

次に、`main.js` で `qrdx/element/define` を 1 回インポートし、テンプレート内でオプションをバインドします。Vue は、要素にプロパティがある場合、バインディングをプロパティとして設定します。

```vue title="src/App.vue"
<qrdx-code
  :value="url"
  :size="256"
  body-pattern="rounded"
  :frame="{ style: 'banner-bottom', text: 'Scan me' }"
  label="Menu"
/>
```

## うまくいかない場合 [#if-something-goes-wrong]

- **何も描画されない。** 要素に `value` がないか、定義用のスクリプトが実行されていません。属性と、`element-define` がモジュールとして読み込まれているかを確認してください。
- **`qrdx-error` イベントが発生する。** コードを描画できません。たとえば、値が QRコードには長すぎる場合や、`props` 属性が JSON オブジェクトではない場合です。エラーは `event.detail.error` に入っています。リスナーが `event.preventDefault()` を呼ばない限り、要素は古いコードを削除し、エラーをログに出力します。

  ```js title="main.js"
  qr.addEventListener("qrdx-error", (event) => {
    event.preventDefault();
    showMessage("That text is too long for a QR code.");
  });
  ```

- **`qrdx: <qrdx-code> is already defined by another element`。** 別のスクリプトが同じタグ名を登録しています。`defineQRdxCode` に別の名前を渡してください。
- **TypeScript：`Property 'qrdx-code' does not exist on type 'JSX.IntrinsicElements'`。** React 19 のセクションにある宣言を追加してください。
