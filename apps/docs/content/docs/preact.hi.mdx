इस पेज के अंत तक आपके पास एक Preact कंपोनेंट में स्टाइल्ड QR कोड होगा और एक बटन होगा जो उसे PNG के रूप में सेव करता है। `qrdx/preact` में React लाइब्रेरी के दोनों SVG कंपोनेंट, `QRCodeSVG` और `QRCode`, Preact के लिए बने मिलते हैं। ये Preact के अपने `h` से बनते हैं, इसलिए आपको `preact/compat` या `react` की ज़रूरत नहीं है, और ये React कंपोनेंट जैसा ही SVG बनाते हैं।

## शुरू करने से पहले [#before-you-start]

- Preact 10 या नया वर्शन वाला प्रोजेक्ट, Vite या किसी और bundler के साथ।
- Node.js 18 या नया।

## बनाइए [#build-it]

### 1. qrdx इंस्टॉल करें [#1-install-qrdx]

```package-install
qrdx
```

`preact`, `qrdx` की एक वैकल्पिक peer dependency है। आपके ऐप में यह पहले से मौजूद है।

### 2. कोड बनाएँ [#2-draw-a-code]

```tsx title="src/components/menu-code.tsx"
import { QRCodeSVG } from "qrdx/preact";

export function MenuCode() {
  return (
    <QRCodeSVG
      value="https://example.com/menu"
      size={256}
      margin={4}
      bodyPattern="rounded"
      frame={{ style: "banner-bottom", text: "Scan me" }}
      aria-label="QR code for the menu"
    />
  );
}
```

पेज पर गोल मॉड्यूल वाला 256 px का कोड दिखता है, और उसके नीचे "Scan me" बैनर होता है।

<Shot id="lib-preact-code" />

`QRCodeSVG` वे सभी विकल्प लेता है जो React का `QRCodeSVG` लेता है: पैटर्न, रंग और ग्रेडिएंट, लोगो (`imageSettings`), फ़्रेम, शेप, टेम्पलेट और आर्ट। `class`, `style` या `aria-label` जैसे एट्रिब्यूट `<svg>` पर लगते हैं, और फ़्रेम होने पर फ़्रेम के बाहरी `<svg>` पर।

`QRCode` में React के `QRCode` का लोगो शॉर्टकट जुड़ा है: `logo`, `logoOptions`, `hideLogo` और `scale`। यह सिर्फ़ कोड के props और `style` लेता है; `class` या `aria-label` को इसके आसपास के किसी एलिमेंट पर लगाएँ, या `QRCodeSVG` इस्तेमाल करें।

```tsx title="src/components/logo-code.tsx"
import { QRCode } from "qrdx/preact";

export function LogoCode() {
  return <QRCode value="https://example.com" size={256} logo="/logo.png" level="H" />;
}
```

दोनों कंपोनेंट prop बदलने पर दोबारा बनते हैं, और कुछ न बदलने पर काम छोड़ देते हैं। props में दिए गए इवेंट हैंडलर `<svg>` पर नहीं लगाए जाते, जैसा React में होता है। उन्हें कोड के आसपास के किसी एलिमेंट पर लगाएँ।

### 3. फ़ाइल के रूप में सेव करें [#3-save-it-as-a-file]

कंपोनेंट सिर्फ़ कोड बनाते हैं। डाउनलोड, `toSVGString`, स्कैन स्कोर और बाकी फ़ंक्शन `qrdx/core` से आते हैं। यह वही इंजन है जिसे कंपोनेंट पहले से इस्तेमाल करते हैं, इसलिए यह दो बार बंडल नहीं होता।

```tsx title="src/components/downloadable-code.tsx"
import { downloadQRCode } from "qrdx/core";
import { QRCodeSVG } from "qrdx/preact";

const options = { value: "https://example.com", size: 256, margin: 4 };

export function DownloadableCode() {
  return (
    <>
      <QRCodeSVG {...options} />
      <button
        type="button"
        onClick={() =>
          downloadQRCode(options, {
            format: "png",
            size: { width: 1024, height: 1024 },
            filename: "qr-code.png",
          })
        }
      >
        Download PNG
      </button>
    </>
  );
}
```

बटन क्लिक करने पर `qr-code.png` 1024 px में सेव होती है। विकल्पों को ऊपर की तरह एक ही ऑब्जेक्ट में रखें, ताकि फ़ाइल स्क्रीन पर दिख रहे कोड से मेल खाए। `qrdx/core` की पूरी जानकारी [Vanilla JavaScript](/docs/vanilla-js) में है।

## सर्वर रेंडरिंग [#server-rendering]

`preact-render-to-string` का `renderToString` वही SVG लिखता है जो `qrdx/core` का `toSVGString` लिखता है। फ़र्क़ सिर्फ़ escaping में है: Preact टेक्स्ट में `>` और `'` को जैसा है वैसा रखता है, जबकि core `&gt;` और `&#x27;` लिखता है। ब्राउज़र दोनों को एक जैसा पढ़ते हैं।

`hydrate` सर्वर के `<svg>` को रखता है और उसे दोबारा नहीं बनाता। मार्कअप में कोई रैंडम id नहीं होती, इसलिए सर्वर और ब्राउज़र हमेशा एक जैसे रहते हैं।

## preact/compat के साथ [#with-preactcompat]

अगर आपका ऐप पहले से `react` को `preact/compat` का alias बनाता है, तो `qrdx` के React कंपोनेंट भी काम करते हैं: `import { QRCodeSVG } from "qrdx"`। `qrdx/preact` बिना alias के वही कोड बनाता है, इसलिए Preact ऐप में `qrdx` जोड़ते समय इसे ही चुनें।

## कुछ गड़बड़ हो तो [#if-something-goes-wrong]

- **`Failed to resolve import "react"`।** आपने `preact/compat` के बिना ऐप में `qrdx/preact` की जगह `qrdx` से import किया है। import बदल दें।
- **कंपोनेंट पर लगा क्लिक हैंडलर कुछ नहीं करता।** हैंडलर `<svg>` से हटा दिए जाते हैं। कोड को `<button>` या `<div>` में रखें और हैंडलर वहाँ लगाएँ।
- **`PDF export needs the optional "jspdf" package`।** ऐप में `npm install jspdf` चलाएँ।
