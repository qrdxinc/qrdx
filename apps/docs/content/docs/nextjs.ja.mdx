このページを読み終えると、クライアント側JavaScriptなしでServer Componentが表示するQRコード、ルートパラメータから作ったコード、入力欄に連動するライブコード、ロゴ付きのコード、SVGを保存するボタンが用意できます。`QRCodeSVG`と`QRCode`はクライアント専用のフックを使わないため、Server Componentがコードをそのままページ内のHTMLとして出力します。Client Componentが必要になるのは、ブラウザー上で値が変わる場合と、ファイルを保存する場合だけです。

<NpmStatus package="qrdx" />

## はじめる前に [#before-you-start]

- App Routerを使ったNext.jsプロジェクト。例ではNext.js 15や16と同じく、App Routerの非同期の`params`を使います。
- React 18以降。App Routerがもともと必要としているバージョンです。

## 作り方 [#build-it]

### 1. qrdxをインストールする [#1-install-qrdx]

```package-install
qrdx
```

`react`と`react-dom`はピア依存関係なので、アプリ自身のバージョンが使われます。

### 2. Server Componentでコードを表示する [#2-render-a-code-in-a-server-component]

```tsx title="app/page.tsx"
import { QRCodeSVG } from "qrdx";

export default function Page() {
  return (
    <QRCodeSVG
      value="https://example.com"
      size={256}
      margin={4}
      role="img"
      aria-label="QR code for example.com"
    />
  );
}
```

ページを開いてください。`<svg>`はサーバーが送るHTMLに含まれているため、JavaScriptが読み込まれる前から表示されます。静的ページではビルド時に一度だけ生成され、スクリーンリーダーは`aria-label`を読み上げます。

<Shot id="lib-nextjs-server-code" />

`margin`はコードの周囲の余白(クワイエットゾーン)で、単位はモジュールです。デフォルトは0で、独自のパディングを持つカードの中に置くコードに向いています。QRの規格では4が求められており、背景が複雑な場合や暗い場合は4にすると安全です。

### 3. ルートパラメータから値を作る [#3-build-the-value-from-a-route-param]

```tsx title="app/tickets/[id]/page.tsx"
import { QRCodeSVG } from "qrdx";

export default async function TicketPage({
  params,
}: {
  params: Promise<{ id: string }>;
}) {
  const { id } = await params;
  const url = `https://example.com/check-in/${encodeURIComponent(id)}`;
  return <QRCodeSVG value={url} size={200} margin={4} level="H" />;
}
```

`/tickets/A-12`にアクセスすると、コードは`https://example.com/check-in/A-12`を開きます。Next.jsは`params`をPromiseとして渡すため、ページは`async`にします。ユーザーやデータベースから来る値は、URLに入れる前に必ずエンコードしてください。レベル`H`ではコードの最大30%が損傷しても読み取れるので、折れたり傷ついたりするバッジに役立ちます。

### 4. Client Componentで入力に追従させる [#4-follow-an-input-in-a-client-component]

```tsx title="components/live-qr-code.tsx"
"use client";

import { QRCodeSVG } from "qrdx";
import { useState } from "react";

export function LiveQrCode() {
  const [value, setValue] = useState("https://example.com");
  return (
    <div>
      <input
        aria-label="Text or link to encode"
        value={value}
        onChange={(event) => setValue(event.target.value)}
      />
      {value ? <QRCodeSVG value={value} size={200} margin={4} /> : null}
    </div>
  );
}
```

コードはキー入力のたびに再描画され、最初の値は引き続きサーバー側で表示されます。Server Componentのページは、このコンポーネントをそのままインポートできます。

`QRCodeCanvas`もClient Componentですが(`"use client"`付きで提供されます)、描画できるのは通常の四角いモジュールだけです。スタイル付きのコードには`QRCodeSVG`か`QRCode`を使ってください。

### 5. ロゴを追加する [#5-add-a-logo]

```tsx title="components/logo-qr-code.tsx"
import { QRCode } from "qrdx";

export function LogoQrCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      margin={4}
      level="H"
      logo="/logo.png"
    />
  );
}
```

`/logo.png`は、プロジェクトの`public`フォルダー内にあるファイルです。ロゴはコード幅の4分の1の大きさで描画され、背後のモジュールは消去されます。そのため、コードは誤り訂正に頼ってスキャンされます。`level`を`H`にしているのはこのためです。また、`QRCode`は、コードが修復できないほど大きいロゴを自動的に縮小します。

`logo`には、アプリ内のパス、URL、データURLを指定できます。ダウンロードする場合はデータURLが最も確実です。外部の画像は、ブラウザーがファイルにコピーするためにCORSヘッダーが必要だからです。`logoOptions`ではロゴのサイズ、余白、位置、切り抜きを設定できます。詳しくは[コードでロゴを追加する](/docs/features/logos)をご覧ください。

### 6. SVGとしてダウンロードする [#6-download-as-svg]

```tsx title="components/download-svg-button.tsx"
"use client";

import { downloadQRCode } from "qrdx";

export function DownloadSvgButton({ value }: { value: string }) {
  return (
    <button
      type="button"
      onClick={() =>
        downloadQRCode(
          { value, level: "Q", margin: 4 },
          {
            format: "svg",
            size: { width: 1024, height: 1024 },
            filename: "qr-code.svg",
          },
        )
      }
    >
      Download SVG
    </button>
  );
}
```

ボタンをクリックすると、1024 pxのベクターファイル`qr-code.svg`が保存されます。`downloadQRCode`はブラウザーのDOMを必要とするため、ボタンはClient Componentにします。Server Componentのページからこのボタンを表示し、値をpropとして渡すこともできます。ほかの形式で保存するには、`format`に`png`、`jpg`、`webp`、`eps`、`pdf`のいずれかを指定します(PDFにはオプションの`jspdf`パッケージが必要です)。すべてのオプションは[エクスポートとダウンロード](/docs/features/downloads)で説明しています。

## 画像のURLが必要なとき [#when-you-need-an-image-url]

メール、Open Graph画像、Markdownファイルなど、Reactを実行できない場所では、コンポーネントではなく画像のURLが必要です。[QRコード画像API](/docs/developers/image-api)なら、キーなしでURLを取得できます。

```html title="email.html"
<img src="https://api.qrdx.dev/v1/qr?data=https://example.com&format=png" width="256" height="256" alt="QR code for example.com" />
```

## すぐに使えるコンポーネント [#ready-made-components]

[shadcn/uiレジストリ](/docs/developers/shadcn)を使うと、コンポーネントをプロジェクトにインストールできます。[ダウンロードボタン付きQRコード](/docs/components/qr-code)、カード、共有ダイアログ、ジェネレーター、スキャナー、Wi-Fiや連絡先のコードが用意されています。

```bash title="Terminal"
npx shadcn@latest add https://qrdx.dev/r/qr-code.json
```

## うまくいかない場合 [#if-something-goes-wrong]

- **`useRef only works in Client Components`(または`useState`について同じメッセージ)。** Server Componentから`QRCodeCanvas`やフックを使うコンポーネントを表示しています。そのファイルの先頭に`"use client"`を追加するか、代わりに`QRCodeSVG`を使ってください。
- **ページにはロゴが表示されるのに、ダウンロードしたファイルには表示されない。** 画像がCORSヘッダーのない別のオリジンから読み込まれています。`public`から配信するか、データURLを渡してください。
- **`PDF export needs the optional "jspdf" package`。** アプリで`npm install jspdf`を実行してください。ほかの形式には追加の作業は必要ありません。
