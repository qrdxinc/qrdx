Questi helper sono le piccole funzioni usate dal renderer e dal punteggio di scansione, esportate per la tua interfaccia: scegliere un colore rappresentativo, controllare il contrasto, validare la dimensione di un download e rilevare le funzionalità del canvas. Funzionano ovunque, tranne dove indicato.

| Funzione | Restituisce | Note |
| --- | --- | --- |
| `getSolidColor(color, fallback?)` | `string` | Un colore che rappresenta un `ColorConfig`: la stringa, il `color` di un colore pieno, il primo punto di un gradiente, l'`underlay` di un riempimento con immagine, altrimenti `fallback` (`"#000000"`) |
| `getContrastRatio(a, b)` | `number` | Il rapporto di contrasto WCAG tra due colori CSS, da 1 a 21. I colori trasparenti vengono prima composti su bianco. Restituisce 1 quando un colore non può essere interpretato |
| `getContrastLevel(ratio)` | `{ level, warning, message }` | `AAA` da 7, `AA` da 4.5, `AA Large` da 3 (con `warning: true`), `Fail` sotto 3 |
| `getLuminance(r, g, b)` | `number` | Luminanza relativa di un colore sRGB, da 0 a 1 |
| `hexToRgb(hex)` | `{ r, g, b } \| null` | Legge esadecimali a 3, 4, 6 e 8 cifre, scartando l'alfa. `null` in tutti gli altri casi |
| `validateSize(width, height)` | `{ isValid, error? }` | La regola applicata da ogni download: da 50 a 5000 px e quadrato |
| `SUPPORTS_PATH2D` | `boolean` | Indica se il canvas di questo ambiente supporta `Path2D` con `addPath` |

## Colori [#colors]

```ts title="lib/colors.ts"
import { getSolidColor, hexToRgb } from "qrdx";

getSolidColor({
  type: "linear",
  angle: 45,
  stops: [
    { color: "#ff6b6b", offset: 0 },
    { color: "#4ecdc4", offset: 100 },
  ],
});
// "#ff6b6b": the first stop

getSolidColor({ type: "image", src: photo, underlay: "#111111" }); // "#111111"
getSolidColor(undefined, "#ffffff"); // "#ffffff"

hexToRgb("#ff6b6b"); // { r: 255, g: 107, b: 107 }
hexToRgb("#f00"); // { r: 255, g: 0, b: 0 }
hexToRgb("red"); // null
```

Usa `getSolidColor` quando ti serve un solo colore per una campione, uno sfondo CSS o un fallback. Il renderer lo usa dove un formato non può disegnare un gradiente, come `QRCodeCanvas` e il disegno della cornice su Canvas.

## Contrasto [#contrast]

```ts title="lib/contrast.ts"
import { getContrastLevel, getContrastRatio, getLuminance } from "qrdx";

getContrastRatio("#000000", "#ffffff"); // 21
getContrastRatio("#1d4ed8", "#f8fafc"); // 6.4
getContrastRatio("rgba(29, 78, 216, 0.5)", "#ffffff"); // the blue over white, so lower

getContrastLevel(4.5);
// { level: "AA", warning: false, message: "Good contrast" }

getContrastLevel(2);
// { level: "Fail", warning: true, message: "Poor contrast - QR code may not scan properly" }

getLuminance(255, 255, 255); // 1
```

Il punteggio di scansione approva un codice con un rapporto di 4.5 o più (`SCAN_CONTRAST_MIN`), toglie punti sotto questa soglia e lo boccia sotto 1.5. Le immagini richiedono di più: `SCAN_IMAGE_CONTRAST_MIN` è 7 per un riempimento con immagine nei moduli e 12 per uno dietro di essi. `getScanContrast(props)` esegue il controllo del punteggio su un intero design, compresi ogni punto del gradiente e i colori degli occhi; vedi [Cornici, punteggio di scansione e file di stampa](/docs/features/frames#will-it-scan).

Un controllo del contrasto in tempo reale richiede una dozzina di righe:

```tsx title="components/contrast-checker.tsx"
"use client";

import { getContrastLevel, getContrastRatio } from "qrdx";
import { useState } from "react";

export function ContrastChecker() {
  const [fgColor, setFgColor] = useState("#000000");
  const [bgColor, setBgColor] = useState("#ffffff");
  const ratio = getContrastRatio(fgColor, bgColor);
  const level = getContrastLevel(ratio);

  return (
    <div>
      <input
        aria-label="Module color"
        type="color"
        value={fgColor}
        onChange={(event) => setFgColor(event.target.value)}
      />
      <input
        aria-label="Background color"
        type="color"
        value={bgColor}
        onChange={(event) => setBgColor(event.target.value)}
      />
      <p>
        {ratio.toFixed(2)}:1, {level.level}. {level.message}
      </p>
    </div>
  );
}
```

## Validazione [#validation]

```ts title="lib/sizes.ts"
import { validateSize } from "qrdx";

validateSize(1024, 1024); // { isValid: true }
validateSize(40, 40); // { isValid: false, error: "Size must be at least 50x50 pixels" }
validateSize(6000, 6000); // { isValid: false, error: "Size must not exceed 5000x5000 pixels" }
validateSize(400, 300); // { isValid: false, error: "Width and height must be equal for QR codes" }
```

`downloadQRCode`, `getQRCodeDataUrl` e `copyQRCodeToClipboard` generano lo stesso testo `error` quando una dimensione non è valida, quindi un modulo può controllarla prima.

## Rilevamento delle funzionalità [#feature-detection]

```ts title="lib/features.ts"
import { SUPPORTS_PATH2D } from "qrdx";

if (SUPPORTS_PATH2D) {
  // draw module paths with Path2D
}
```

`SUPPORTS_PATH2D` viene calcolato una sola volta al caricamento del modulo, quindi è `false` su un server.

## Altri helper [#other-helpers]

- `getColorString(color)` e `normalizeColorConfig(color)` convertono tra loro le forme di `ColorConfig`; `isGradient(color)` e `isImagePaint(color)` le distinguono.
- `sanitizeFrameText(text)` e `isLatin1Text(text)` applicano le regole per l'etichetta della cornice (24 caratteri; Latin-1 per PDF ed EPS).
- `decodePNGPixels(bytes)` legge un PNG a 8 bit in pixel RGBA senza DOM, per `createQRArtImage`, `createQRSilhouette` o `scanQRPixels` in Node.
- `rgbToCmyk(color)` è la conversione usata dai file di stampa CMYK.
