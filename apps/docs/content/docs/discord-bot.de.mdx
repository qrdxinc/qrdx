Der QRdx-Bot erstellt QR-Codes direkt in Discord, und du brauchst dafür keinen QRdx-Account. Jede Antwort zeigt den Code mit Buttons, um ihn als PNG oder SVG herunterzuladen oder im [Editor](/playground) zu öffnen und sein Aussehen zu ändern. Nutze ihn, wenn auf einem Server Links geteilt werden und du einen Code im Channel möchtest, ohne Discord zu verlassen.

## So funktioniert es [#how-it-works]

QRdx speichert die Codes, die du erstellst, nicht, und der Bot kann deine Chats nicht lesen. Discord sendet QRdx nur das, was du nach `/qr` eingibst, oder die eine Nachricht, die du für **QR-Code erstellen** ausgewählt hast. Der Inhalt und das gewählte Design stecken im Bildlink, und Discord lädt das Bild von der QRdx [Image API](/docs/developers/image-api). Beim Umgestalten eines Codes werden beide wieder aus diesem Link gelesen, QRdx muss den Code dafür also nicht speichern. Wie jeder Link kann er in Logs und Caches landen. Erstelle deshalb keine Codes aus Passwörtern oder anderen Geheimnissen.

<IfAvailable feature="discordBot" id="add-the-bot" title="Den Bot hinzufügen">

1. Öffne die Seite [Discord-Bot](/integrations/discord-bot) und klicke auf **Zu Discord hinzufügen**.
2. Discord fragt, wo der Bot hinzugefügt werden soll:
   - **Dein Account:** Nutze ihn in DMs, Gruppen-DMs und auf den Servern, auf denen du bist.
   - **Ein Server:** Alle auf dem Server können ihn nutzen. Dafür brauchst du dort die Berechtigung **Server verwalten**.

Auf manchen Servern dürfen die eigenen Apps von Mitgliedern nicht für alle posten. Dort sind Antworten des Bots über deinen Account nur für dich sichtbar.

</IfAvailable>

<IfAvailable feature="discordBot" id="make-a-code-with-qr" title="Einen Code mit /qr erstellen">

1. Gib in einem beliebigen Chat `/qr` ein und wähle den Befehl aus der Liste.
2. Gib einen Link oder einen Text in **content** ein oder füge ihn dort ein und drücke dann Enter.

Der Bot antwortet mit dem Code, seinem Inhalt als Titel, drei Buttons und den unten beschriebenen Stilmenüs. Die Buttons sind **PNG herunterladen** (1024 px), **SVG herunterladen** und **Im Editor öffnen**. Ein Link öffnet sich im Editor mit dem Design des Codes. Text wird nicht im Editor-Link übertragen, füge ihn dort also selbst ein.

Damit der Code nur dir gehört, setze **private** auf **True**. Nur du siehst diese Antwort, und Discord entfernt sie, wenn du sie ausblendest oder neu lädst.

Sehr langer Inhalt passt eventuell nicht in einen QR-Code oder ist zu lang, als dass Discord ihn als Bild anzeigen könnte. Der Bot teilt dir das in einer Nachricht mit, die nur du sehen kannst.

</IfAvailable>

<IfAvailable feature="discordBot" id="style-your-code" title="Deinen Code gestalten">

`/qr` hat drei weitere Optionen, die du vor dem Drücken von Enter ausfüllen kannst:

| Option | Was sie bewirkt | Auswahl |
| --- | --- | --- |
| **look** | Wendet eines der integrierten Designs des Editors an | Plain, Classic, Modern, Royal, Folio, Caffeine, Retro, Bordeaux, Blossom |
| **color** | Färbt den ganzen Code in einer Farbe auf Weiß | Schwarz, Blau, Grün, Rot, Violett, Orange |
| **frame** | Fügt einen Rahmen mit dem Text „Scan me“ hinzu | Kein Rahmen, Banner, Banner oben, Sprechblase, Polaroid |

Zuerst wird der Look angewendet und darüber die Farbe. **look** Royal mit **color** Blau behält also die Formen von Royal in Blau.

Unter jedem Code findest du vier Menüs, **Look**, **Color**, **Frame** und **Logo**, mit denselben Auswahlmöglichkeiten plus sieben der schnellen Logo-Icons des Editors. Wähle etwas aus, und der Code ändert sich an Ort und Stelle. Jede Änderung baut auf dem aktuellen Stand des Codes auf. Nur die Person, die den Code erstellt hat, kann ihn umgestalten. Alle anderen erhalten bei einer Auswahl einen Hinweis, den nur sie sehen, und der Code bleibt unverändert.

Bevor ein gestalteter Code erscheint, prüft QRdx ihn mit demselben Scan-Score wie der Editor. Deshalb zeigt Discord zuerst kurz an, dass QRdx nachdenkt. Wäre ein Design für Smartphones schwer lesbar, passt QRdx es an (dunklere Farben, schlichtere Formen oder mehr Fehlerkorrektur) und sagt das unter dem Code. Reicht das immer noch nicht, meist weil der Inhalt lang ist, bekommst du den Code in Schwarz auf Weiß mit einem Hinweis.

**Im Editor öffnen** öffnet den Editor mit demselben Design: Farben, Formen und Rahmen. Das Logo-Icon wird nicht im Link übertragen, wähle es also im Editor erneut aus.

</IfAvailable>

<IfAvailable feature="discordBot" id="make-a-code-from-a-message" title="Einen Code aus einer Nachricht erstellen">

Klicke am Desktop mit der rechten Maustaste auf eine Nachricht und wähle **Apps** → **QR-Code erstellen**. Halte auf dem Handy die Nachricht gedrückt und tippe auf **Apps** → **QR-Code erstellen**.

Der Code enthält die erste Webadresse der Nachricht. Aus einer Nachricht ohne Webadresse wird ein Code ihres Textes. Alle im Chat sehen die Antwort. Antworten erwähnen oder pingen nie jemanden, egal was in der Nachricht steht.

</IfAvailable>

## Limits und Tarife [#limits-and-plans]

Der Bot ist kostenlos und hat keinen Tarif. Damit eine einzelne Person einen Channel nicht überflutet, zählt QRdx die Codes, die jeder Discord-Account pro Minute erstellt oder umgestaltet. Außerdem zählt es die Codes aller zusammen, und wenn in einer Minute zu viele eintreffen, meldet der Bot, dass er ausgelastet ist. Keiner der beiden Zähler speichert Inhalte, und beide laufen nach dieser Minute ab.

<IfAvailable feature="discordBot" id="remove-the-bot" title="Den Bot entfernen">

- **Von deinem Account:** Öffne **Benutzereinstellungen** → **Autorisierte Apps** und klicke neben QRdx auf **Autorisierung aufheben**.
- **Von einem Server:** Jemand mit **Server verwalten** öffnet **Servereinstellungen** → **Integrationen**, wählt QRdx aus und entfernt es.

</IfAvailable>

## Für Entwickler [#for-developers]

Jeder Code, den der Bot sendet, stammt von der [Image API](/docs/developers/image-api), die du direkt aus deinem eigenen Bot oder Skript aufrufen kannst. Die [CLI](/docs/developers/cli) bietet dieselben Looks, Farben und Rahmen im Terminal.

## Self-Hosting [#self-hosting]

Der Bot funktioniert auf deinem eigenen QRdx, sobald du eine Discord-App registrierst und `DISCORD_APPLICATION_ID` und `DISCORD_PUBLIC_KEY` setzt. [`plugins/discord/README.md`](https://github.com/qrdxinc/qrdx/tree/main/plugins/discord) enthält die Schritte. Rate Limits brauchen Upstash Redis; ohne es sind sie deaktiviert. Siehe [Self-Hosting](/docs/self-hosting#optional-services).
