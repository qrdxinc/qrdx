## 入口 [#entry-points]

| 导入来源 | 包含内容 | 依赖 |
| --- | --- | --- |
| `qrdx` | React 组件（`QRCode`、`QRCodeSVG`、`QRCodeCanvas`、`getQRAsSVG`）以及 `qrdx/core` 中的全部内容 | `react`、`react-dom` |
| `qrdx/core` | 不依赖 React 的完整引擎：标记、下载、打印文件、扫描评分、边框、模板、艺术效果和类型 | 无 |
| `qrdx/vanilla` | `createQRCode`，以及 `qrdx/core` | DOM |
| `qrdx/element` | `<qrdx-code>` 自定义元素：`QRdxCodeElement`、`defineQRdxCode`、`toQRdxCodeHTML` | 绘制时需要 DOM；渲染标记则不需要 |
| `qrdx/element/define` | 导入时注册 `<qrdx-code>` | DOM |
| `qrdx/node` | `getQRAsPNG` | `@resvg/resvg-js` 或 `sharp` |
| `qrdx/vue` | `QRCode`、`QRCodeSVG`、`useQRCode`，以及 `qrdx/core` | `vue` 3.3 或更高版本 |
| `qrdx/preact` | `QRCode`、`QRCodeSVG` | `preact` 10 或更高版本 |
| `qrdx/solid` | `QRCode`、`QRCodeSVG` | `solid-js` 1.8 或更高版本 |
| `qrdx/angular` | `QRCode` 组件（`<qrdx-qr-code>`），以及 `qrdx/core` | `@angular/core` 20 或更高版本 |
| `qrdx/types` | 所有类型、选项列表和 zod 模式，不含渲染器 | 无 |

每个框架包都是可选的对等依赖：安装 `qrdx` 不会添加你用不到的包。`jspdf` 同样是可选的，用于 PDF。

## 组件 [#components]

### QRCode [#qrcode]

适用于大多数场景的组件。它是 `QRProps` 加上简单的 logo API，渲染为 `<svg>`。它不使用仅限浏览器的 hook，因此可以在 React Server Components 中渲染。

```tsx title="components/example.tsx"
import { QRCode } from "qrdx";

<QRCode value="https://example.com" size={256} margin={4} level="H" logo="/logo.png" />;
```

| 属性 | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `value` | `string` | 必填 | 要编码的文本或 URL，按原样编码 |
| `size` | `number` | `128` | 宽度和高度，单位为像素。边框会增加尺寸；模板则适配在其内部 |
| `scale` | `number` | `1` | 对 `size` 进行倍数缩放 |
| `level` | `"L" \| "M" \| "Q" \| "H"` | `"Q"` | 纠错等级：二维码约 7%、15%、25% 或 30% 的区域受损仍可识别 |
| `margin` | `number` | `0` | 二维码周围的静区，单位为模块。标准要求为 4 |
| `fgColor` | `ColorConfig` | `"#000000"` | 数据模块的颜色：CSS 颜色、渐变或图像填充 |
| `bgColor` | `ColorConfig` | `"#FFFFFF"` | 背景。`"transparent"` 表示不绘制背景 |
| `eyeColor` | `ColorConfig` | `fgColor` | 三个角上定位眼的颜色 |
| `dotColor` | `ColorConfig` | `fgColor` | 每个定位眼内部圆点的颜色 |
| `eyeColors` | `EyeColors` | 无 | 为 `topLeft`、`topRight` 和 `bottomLeft` 分别设置 `outer` 和 `inner` 颜色；各自覆盖 `eyeColor` 和 `dotColor` |
| `bodyPattern` | `BodyPattern` | `"circle"` | 数据模块的形状，可选 {facts.bodyPatterns} 之一 |
| `cornerEyePattern` | `CornerEyePattern` | `"gear"` | 角上定位眼的形状，可选 {facts.eyeShapes} 之一 |
| `cornerEyeDotPattern` | `CornerEyeDotPattern` | `"circle"` | 定位眼圆点的形状，可选 {facts.eyeCentres} 之一 |
| `moduleScale` | `number` | `1` | 每个数据模块的大小，范围 0.5 到 1。每种图案都不会小于仍可扫描的最小尺寸（`MODULE_SCALE_FLOOR`） |
| `logo` | `string` | 无 | 绘制在中间的路径、URL 或 data URL，其后方的模块会被清除。未设置则不绘制 logo |
| `logoOptions` | `LogoOptions` | 无 | logo 的 `size`（0.1 到 0.3，默认 0.25）、`padding`（0 到 2 个模块）、`x` 和 `y`（0 到 1）、`shape` 和 `plate` |
| `hideLogo` | `boolean` | `false` | 即使设置了 `logo` 也隐藏 logo |
| `autoLevel` | `boolean` | `false` | 当 logo 覆盖超过 7% 的二维码面积时，将 `level` 提升为 `H`（`AUTO_LEVEL_LOGO_COVERAGE`） |
| `frame` | `AnyQRFrame` | 无 | 行动号召边框：`{ style, text, color, textColor, secondaryText, secondaryColor, fontScale }`，或 `{ style: "custom", spec }`。输出尺寸会增大以容纳边框 |
| `templateId` | `string` | 无 | 按 `size` 绘制的模板，二维码位于其中：`"Arrow"`、`"StandardBox"`、`"SquareBorder"`、`"StrikedBox"`、`"Halloween"`、`"DotRing"` 或 `"default"` |
| `customTemplate` | `TemplateDefinition` | 无 | 你用代码绘制的模板。优先于 `templateId` |
| `customProps` | `Record<string, any>` | 无 | 传给模板 `wrapper` 的属性，例如 `DotRingProps` |
| `shape` | `"square" \| "circle" \| "heart" \| QRSilhouette` | `"square"` | 将二维码放入圆盘、心形或你自己的轮廓中，并用装饰性模块填充 |
| `art` | `QRArt` | 无 | 将图片融入模块：`{ mode, image, intensity, variant, matchEyes }` |
| `style` | `CSSProperties` | 无 | `<svg>` 的内联样式 |
| `frameLabelMarkers` | `boolean` | `false` | 供编辑器使用：为每个边框标签 `<text>` 添加 `data-qrdx-frame-label` 标记。导出文件不包含该标记 |
| `partMarkers` | `boolean` | `false` | 供编辑器使用：为绘制的各部分添加 `data-qrdx-part` 标记。导出文件不包含该标记 |
| `isOGContext` | `boolean` | `false` | 为 Open Graph 图像渲染器将 logo 绘制为定位的 `<img>` |

`QRCode` 只接受上述属性，其他属性会被丢弃。`QRCodeSVG` 会把其他任何属性（`className`、`aria-label`、`role`、`data-*` 等）放到 `<svg>` 上；如果有边框，则放到边框最外层的 `<svg>` 上。事件处理器不会写入标记。

### QRCodeSVG [#qrcodesvg]

`QRProps` 加上 React 的 SVG 属性（`QRPropsSVG`）：属性与 `QRCode` 相同，但没有 `logo`、`logoOptions`、`hideLogo` 和 `scale`。logo 通过 `imageSettings` 设置，单位为像素：

| 字段 | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `src` | `string` | 必填 | 图像，URL 或 data URL |
| `width`, `height` | `number` | 必填 | 尺寸，所用像素与 `size` 相同 |
| `excavate` | `boolean` | 必填 | 清除图像后方的模块 |
| `x`, `y` | `number` | 居中 | 图像的左上角 |
| `padding` | `number` | `0` | 清除模块时，图像周围额外留出的空白，单位为像素 |
| `shape` | `"square" \| "rounded" \| "circle"` | `"square"` | 裁剪图像 |
| `plate` | `string` | 无 | 图像后方按其形状绘制的纯色底板 |

超出二维码纠错能力的 logo 会围绕其中心缩小（`capImageSettings`，与 `QRCode` 的预算相同）。

### QRCodeCanvas [#qrcodecanvas]

`QRProps` 加上 React 的 canvas 属性（`QRPropsCanvas`），按设备像素比绘制在 `<canvas>` 上。它只绘制纯色的普通方形模块：渐变会退回到第一个色标，图案、定位眼颜色、`eyeColors`、`moduleScale`、`art` 和模板相关属性都会被忽略。它带有 `"use client"`。

### getQRAsSVG [#getqrassvg]

`getQRAsSVG(props: QRPropsSVG): Promise<JSX.Element>` 以 React 元素的形式返回二维码，其中的 logo 以 data URL 嵌入。如需字符串，请使用 `toSVGString` 或 `getSVGString`。

## 下载与导出 [#download-and-export]

| 函数 | 返回值 | 说明 |
| --- | --- | --- |
| `downloadQRCode(props, { format, size, filename?, quality? })` | `Promise<void>` | 保存文件。`size` 为 50 到 5000 px，且为正方形；对于位图格式，默认文件名会注明像素尺寸 |
| `getQRCodeDataUrl(props, format, size, { quality? })` | `Promise<string>` | 同一文件，以 data URL 形式返回 |
| `getQRAsWebP(props, { quality? })` | `Promise<Blob>` | 除非设置了 `quality`，否则为无损；浏览器不支持时会自行编码 |
| `copyQRCodeToClipboard(props, size?)` | `Promise<void>` | 将 PNG 放入剪贴板。请在用户操作中调用 |
| `getSVGString(props)` | `Promise<string>` | 内嵌 Logo 的 SVG 标记 |
| `toSVGString(props)` | `string` | SVG 标记，同步返回，不嵌入 Logo。可在任何环境运行 |
| `toSVGElement(props, document?)` | `SVGSVGElement` | 以 DOM 元素形式返回二维码 |
| `getQRAsSVGDataUri(props)` | `Promise<string>` | `data:image/svg+xml,…`，是每次导出的第一步 |
| `getQRAsCanvas(props, mimeType, getCanvas?)` | `Promise<string \| HTMLCanvasElement>` | 返回 data URL；传入 `getCanvas` 时返回画布本身 |
| `getQRAsPNG(props, { size?, loadExternalLogos? })` | `Promise<Uint8Array>` | 在 Node 中返回 PNG 字节，来自 `qrdx/node`。需要 `@resvg/resvg-js` 或 `sharp` |
| `validateSize(width, height)` | `{ isValid, error? }` | `downloadQRCode` 使用的尺寸规则 |
| `getDownloadFilename(format, size, frame?)` | `string` | 默认文件名 |
| `withQRSize(props, size)` | `QRProps` | 按 `size` 绘制的 props，像素 Logo 会同步缩放 |
| `canvasToWebP(canvas, { quality? })`、`blobToDataUrl(blob)`、`encodeWebPLossless(rgba, width, height)` | | WebP 辅助函数 |

常量：`DownloadFormat` 为 `"png" \| "jpg" \| "webp" \| "svg" \| "pdf" \| "eps"`；`DOWNLOAD_FORMATS` 将每种格式映射到其 MIME 类型和扩展名；`PRESET_SIZES` 包含 `small`（200）、`medium`（400）、`large`（800）、`xlarge`（1200）、`2xl`（1600）和 `3xl`（2000）；`DEFAULT_SIZE` 为 128。

## 印刷与 EPS [#print-and-eps]

| 函数 | 返回值 | 说明 |
| --- | --- | --- |
| `getPrintLayout(props, { size, unit?, bleed?, cropMarks?, colorMode? })` | `PrintLayout` | 以 mm 为单位的物理尺寸：`codeWidth`、`trimWidth`、`trimHeight`、`bleed`、`pageWidth`、`pageHeight`、`moduleSize`、`moduleCount`、`maxScanDistance`。`size` 为 5 mm 到 2 m |
| `getQRAsPrintPDF(props, options)` | `Promise<string>` | 矢量 PDF，以 data URL 形式返回。需要 `jspdf` |
| `getQRAsPrintPDFBuffer(props, options)` | `Promise<ArrayBuffer>` | 同一 PDF 的字节形式，适用于 Node |
| `getQRAsPrintSVG(props, { size, unit? })` | `Promise<string>` | `width` 和 `height` 以 mm 或 in 为单位的 SVG |
| `downloadPrintPDF(props, options & { filename? })`、`downloadPrintSVG(props, options & { filename? })` | `Promise<void>` | 在浏览器中下载这两种文件 |
| `getQRAsEPS(props, { sizeMm?, bleedMm?, colorMode? })` | `Promise<string>` | EPSF-3.0 文本。遇到图像填充时抛出 `EPS_IMAGE_FILL_REASON` |
| `downloadPrintEPS(props, options & { filename? })` | `Promise<void>` | 在浏览器中下载 |
| `svgToEPS(svg, { width?, colorMode?, bleed?, bleedColor?, title? })` | `Promise<string>` | 转换本库渲染出的任意 SVG |
| `epsToDataUrl(eps)`、`hasImageFill(props)`、`rgbToCmyk(color)`、`getQRModuleCount(props)` | | 辅助函数 |

`PrintOptions`：`size`（数字）、`unit`（`"mm"` 或 `"in"`，默认 `"mm"`）、`bleed`（mm，0 到 20）、`cropMarks`（布尔值）、`colorMode`（`"rgb"` 或 `"cmyk"`）。

## 扫描评分与识别 [#scan-score-and-detection]

| 函数 | 返回值 | 说明 |
| --- | --- | --- |
| `getScanScore(props, { sizes?, signal? })` | `Promise<ScanScoreResult>` | `{ score, grade, checks }`。仅限浏览器；按需加载 jsQR。默认尺寸为 96、160 和 320 px（`SCAN_TEST_SIZES`） |
| `getImageScanScore(imageOrBlob, options?)` | `Promise<ImageScanScoreResult>` | 针对现有图像的同类评分，另含 `data` 和 `version`。仅限浏览器 |
| `getScanScoreFromPixels(pixels, options?)` | `Promise<ImageScanScoreResult>` | 在 Node 中对 RGBA 像素计算图像评分 |
| `scanQRPixels(pixels, expected, { sizes? })` | `Promise<PixelScanResult>` | 检查像素按原样以及经过相机模型处理后，是否都能解码为 `expected`。适用于 Node |
| `getScanContrast(props)` | `{ ratio, required, inverted }` | 单独的对比度检查 |
| `getStylePairRisk(props)` | `StylePairRisk \| null` | 部分扫描器会漏识的形状组合，附带 `fix` |
| `handleImageLoad(img, size, returnFullData?)` | `Promise<string \| QRCode \| "NO_QR">` | 从 `<img>` 中解码二维码。参见 [二维码识别](/docs/qr-detection) |
| `downloadImageWithBoundingBox(img, corners, filename)` | `void` | 保存图像，并用轮廓标出找到的二维码 |

等级为 `"great"`、`"ok"`、`"risky"` 和 `"fails"`。每项检查为 `{ id, passed, message, fix?, skipped? }`。对比度阈值：`SCAN_CONTRAST_MIN` 为 4.5，`SCAN_CONTRAST_LOW` 为 3，`SCAN_CONTRAST_FAIL` 为 1.5，`SCAN_IMAGE_CONTRAST_MIN` 为 7（图片位于二维码内）和 12（图片位于二维码之后）。较弱的组合以 `WEAK_BODY_EYES`、`WEAK_DOT_EYES`、`WEAK_SHARP_DOT_EYES`、`SHARP_DOT_EYE_SAFE_BODIES`、`WEAK_EYES` 和 `WEAK_DOTS` 导出。

## Logo [#logos]

| 函数 | 返回值 | 说明 |
| --- | --- | --- |
| `getQRData(props)` | 带有 `imageSettings` 的 props | 按 1024 px 的二维码排布 `logo` 和 `logoOptions`，并限制在纠错预算之内 |
| `resolveQRCodeProps(props)` | `QRSVGOptions` | 将 `QRCode` 的 props 转为渲染器实际绘制的内容，已应用 `scale` |

| `getLogoBlockDamage(...)`、`logoFitsBudget(...)`、`getCodewordMap(...)`、`damagedCodewords(...)` | | 预算的各个组成部分。`LOGO_EC_SAFETY` 为 0.6 |
| `removeLogoBackground(src)` | `Promise<string \| null>` | 去除纯色背景后的 Logo，以 PNG data URL 返回。仅限浏览器 |
| `removeLogoBackdrop(pixels)` | `LogoPixels \| null` | 对 RGBA 像素执行同样的操作，可在任何环境运行 |

限制：`LOGO_SIZE_MIN` 为 0.1，`LOGO_SIZE_MAX` 为 0.3，`LOGO_SIZE_DEFAULT` 为 0.25，`LOGO_PADDING_MAX` 为 2，`LOGO_SHAPES`（`square`、`rounded`、`circle`）。

| 导出项 | 说明 |

## 渲染基础接口 [#rendering-primitives]

不依赖 React 的渲染器，来自 `qrdx/core`：

| 导出项 | 说明 |
| --- | --- |
| `createQRCodeTree(options)` | 以普通 `{ type, props, key }` 节点（`QRNode`）表示的二维码 |
| `renderToString(tree)`、`renderToDOM(tree, document?)` | 输出标记，或 DOM 节点 |
| `toHyperscript(tree, createElement)` | 将树转为其他框架的元素。Vue 和 Preact 入口即基于此构建 |
| `h(type, props, ...children)`、`Fragment`、`isQRNode(value)` | 无需 JSX 即可编写模板 wrapper |
| `getQRAsSVGNode(options)` | 内嵌 Logo 的 `Promise<QRNode>` |
| `getQRCodeData(props)`、`getQRCodeSVGProps(props, data)` | `resolveQRCodeProps` 的两个组成部分 |

## 类型与选项列表 [#types-and-option-lists]

下列类型来自 `qrdx`、`qrdx/core` 和 `qrdx/types`。选项列表是普通数组；zod schema（`qrPropsSchema`、`frameSchema`、`frameSpecSchema`、`colorConfigSchema`、`qrArtSchema`、`logoOptionsSchema`、`imageSettingsSchema` 等）均由它们构建。

| 类型 | 结构 |
| --- | --- |
| `QRProps` | 上文的 props 表，不含 logo API |
| `QRCodeProps` | `QRProps` 加上 `logo`、`logoOptions`、`hideLogo`、`scale` |
| `QRSVGOptions` | `QRProps` 加上任意根节点属性：核心绘制所用的选项 |
| `ColorConfig` | `string \| SolidColor \| LinearGradient \| RadialGradient \| AngularGradient \| ImagePaint` |
| `LinearGradient` | `{ type: "linear", stops, angle? }`；`angle` 单位为度，默认 0 |
| `RadialGradient` | `{ type: "radial", stops }` |
| `AngularGradient` | `{ type: "angular", stops, angle? }` |
| `GradientStop` | `{ color, offset }`；`offset` 取值 0 到 100 |
| `ImagePaint` | `{ type: "image", src, fit?, scale?, position?, opacity?, underlay? }` |
| `ImageSettings`、`LogoOptions`、`EyeColors` | 见上文各表 |
| `QRFrame` | `{ style: FrameStyle, text?, color?, textColor?, secondaryText?, secondaryColor?, fontScale? }` |
| `QRCustomFrame`、`AnyQRFrame`、`FrameSpec` | `{ style: "custom", spec, ...labels and colors }`、联合类型，以及 spec 格式 |
| `QRArt`、`QRArtImage` | `{ mode, image, intensity?, variant?, matchEyes? }` 和 `{ width, height, data }` |
| `QRCodeShape`、`QRSilhouette` | `"square" \| "circle" \| "heart"` 或 `{ type: "silhouette", width, height, cells }` |
| `TemplateDefinition`、`BaseTemplateProps`、`TemplateConfig` | 模板 |
| `DownloadFormat`、`DownloadSize`、`DownloadOptions`、`PrintOptions`、`PrintLayout`、`EPSOptions` | 导出 |
| `ScanScoreResult`、`ImageScanScoreResult`、`ScanCheck`、`ScanGrade`、`StylePairRisk` | 扫描评分 |
| `BodyPattern`、`CornerEyePattern`、`CornerEyeDotPattern`、`FrameStyle`、`ErrorLevel` | 选项联合类型 |

选项列表：`BODY_PATTERN`、`CORNER_EYE_PATTERNS`、`CORNER_EYE_DOT_PATTERNS`、`FRAME_STYLES`、`QR_SHAPES`、`LOGO_SHAPES`、`EYE_POSITIONS`。已停用但仍可渲染已保存设计的值：`RETIRED_CORNER_EYE_PATTERNS`（`curly`）和 `RETIRED_CORNER_EYE_DOT_PATTERNS`（`diamond`、`star`、`banner`）。

## 运行环境 [#where-things-run]

- **任意环境，无需 DOM：** `toSVGString`、`createQRCodeTree`、`renderToString`、`getQRData`、边框和模板辅助函数、`createQRArtImage`、`createQRSilhouette`、`getPrintLayout`、`getQRAsEPS`、`getQRAsPrintPDFBuffer`、`scanQRPixels`、`toQRdxCodeHTML`。
- **浏览器：** `downloadQRCode` 及其他下载函数、`copyQRCodeToClipboard`、`getQRAsCanvas`、`getScanScore`、`getImageScanScore`、`handleImageLoad`、`loadQRArtImage`、`loadQRSilhouette`、`removeLogoBackground`、`createQRCode`、自定义元素。
- **仅限 Node：** `qrdx/node` 中的 `getQRAsPNG`。
- **React Server Components：** `QRCode`、`QRCodeSVG` 以及所有无需 DOM 的内容。`QRCodeCanvas` 是 Client Component。
