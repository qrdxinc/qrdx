À la fin de cette page, vous aurez un QR code personnalisé affiché par un composant React et un bouton qui l'enregistre au format SVG. La bibliothèque dessine elle-même le code : vous n'avez besoin ni de compte ni de clé d'API.

<NpmStatus package="qrdx" />

## Avant de commencer [#before-you-start]

- Une application React en version 18 ou supérieure. Next.js, Vite, Remix et les autres fonctionnent tous.
- Node.js 18 ou supérieur.

Vous voulez voir les options avant d'écrire du code ? Personnalisez un code dans le [Playground](/playground?open=code&lang=react) et copiez-le sous forme de composant React.

## Mise en place [#build-it]

### 1. Installer qrdx [#1-install-qrdx]

```package-install
qrdx
```

`react` et `react-dom` sont des dépendances de type peer : le paquet utilise donc les versions déjà présentes dans votre application. Rien d'autre n'est installé : l'export PDF nécessite le paquet facultatif `jspdf`, et seulement si vous l'utilisez.

### 2. Afficher un code [#2-render-a-code]

```tsx title="components/first-qr-code.tsx"
import { QRCode } from "qrdx";

export function FirstQrCode() {
  return <QRCode value="https://example.com" size={256} />;
}
```

Placez le composant dans une page. Vous voyez un code de 256 px avec l'apparence par défaut de la bibliothèque : modules arrondis, yeux d'angle en forme d'engrenage, noir sur blanc. Pointez l'appareil photo d'un téléphone vers l'écran et il ouvre example.com.

<Shot id="lib-first-code" />

`QRCode` affiche un `<svg>` et n'utilise aucun hook réservé au navigateur : il fonctionne donc dans les React Server Components et s'affiche dans le HTML de la page avant l'exécution de tout JavaScript. Seul, il n'apporte rien aux lecteurs d'écran : l'étape 3 montre comment l'étiqueter.

### 3. Le personnaliser [#3-style-it]

```tsx title="components/styled-qr-code.tsx"
import { QRCode } from "qrdx";

export function StyledQrCode() {
  return (
    <QRCode
      value="https://example.com/menu"
      size={256}
      margin={4}
      fgColor="#1d4ed8"
      bodyPattern="rounded"
      cornerEyePattern="extra-rounded"
      cornerEyeDotPattern="rounded"
      frame={{ style: "banner-bottom", text: "Scan for the menu" }}
    />
  );
}
```

Le code est maintenant bleu avec des modules arrondis, et une bannière en dessous indique « Scan for the menu ». Le résultat dépasse 256 px de haut, car un cadre est ajouté autour du code au lieu d'être dessiné par-dessus : le code reste donc scannable.

<Shot id="lib-styled-code" />

Rôle de chaque prop :

- `margin` est la zone de silence autour du code, en modules. La valeur par défaut est 0, adaptée à un code placé dans une carte qui a son propre espacement. Utilisez 4 sur un fond chargé ou sombre.
- `fgColor` accepte n'importe quelle couleur CSS ou un dégradé. `bgColor`, `eyeColor` et `dotColor` fonctionnent de la même façon.
- `bodyPattern`, `cornerEyePattern` et `cornerEyeDotPattern` définissent la forme des modules, des yeux d'angle et des points qu'ils contiennent. Il existe {facts.bodyPatterns} motifs de corps, {facts.eyeShapes} formes d'yeux et {facts.eyeCentres} centres d'yeux, tous dessinés en direct dans [Formes, yeux et cadres](/docs/styles).
- `frame` ajoute l'un des {facts.frameStyles} cadres d'appel à l'action intégrés, ou un cadre de votre création.
- `QRCode` n'accepte que les props propres au code et `style`, rien d'autre. Pour donner un nom accessible ou une classe au code, enveloppez-le dans un élément (`<div role="img" aria-label="QR code for the menu">`), ou utilisez `QRCodeSVG`, qui place `aria-label`, `className` et tout autre attribut sur le `<svg>`.

### 4. L'enregistrer sous forme de fichier [#4-save-it-as-a-file]

```tsx title="components/download-svg-button.tsx"
"use client";

import { downloadQRCode } from "qrdx";

const menuCode = {
  value: "https://example.com/menu",
  margin: 4,
  fgColor: "#1d4ed8",
  bodyPattern: "rounded",
  frame: { style: "banner-bottom", text: "Scan for the menu" },
} as const;

export function DownloadSvgButton() {
  return (
    <button
      type="button"
      onClick={() =>
        downloadQRCode(menuCode, {
          format: "svg",
          size: { width: 1024, height: 1024 },
          filename: "menu.svg",
        })
      }
    >
      Download SVG
    </button>
  );
}
```

Un clic sur le bouton enregistre `menu.svg` : le même code qu'à l'écran, dessiné en 1024 px et net à toutes les tailles, c'est-à-dire le fichier que demande un imprimeur. Définissez `format` sur `png`, `jpg` ou `webp` pour une image, `eps` pour un fichier vectoriel destiné aux outils de design, ou `pdf` (nécessite le paquet facultatif `jspdf`).

`downloadQRCode` utilise le DOM du navigateur : le bouton doit donc se trouver dans un Client Component. Un Server Component peut quand même l'afficher. Gardez les options du code dans un seul objet, comme ci-dessus, pour que le fichier corresponde à l'aperçu.

### 5. Vérifier que le code se scanne [#5-check-that-it-scans]

Scannez le code avec deux ou trois téléphones avant de l'imprimer. Pour un design aux couleurs inhabituelles ou avec un logo, `getScanScore` exécute les mêmes vérifications dans le navigateur et renvoie un score, une note et les points à corriger :

```tsx title="lib/check-code.ts"
import { getScanScore } from "qrdx";

const { score, grade, checks } = await getScanScore({
  value: "https://example.com/menu",
  fgColor: "#1d4ed8",
  bodyPattern: "rounded",
});
// score: 0 to 100, grade: "great" | "ok" | "risky" | "fails"
// checks: [{ id, passed, message, fix? }]
```

Vous pouvez aussi importer une capture d'écran ou une photo d'un code imprimé dans le [vérificateur de scan](/tools/scan-checker).

## En cas de problème [#if-something-goes-wrong]

- **`Module not found: Can't resolve 'qrdx'`.** Installez le paquet dans l'espace de travail ou l'application qui l'importe, puis redémarrez le serveur de développement.
- **Le code s'affiche mais les téléphones ne le lisent pas.** Ajoutez `margin={4}`, gardez des modules sombres sur un fond clair et affichez-le avec une largeur d'au moins 128 px à l'écran. [Un code ne se scanne pas](/docs/help/troubleshooting/wont-scan) liste les autres causes.
- **`PDF export needs the optional "jspdf" package`.** Exécutez `npm install jspdf` dans le même paquet. SVG, PNG, JPG, WebP et EPS n'ont besoin de rien de plus.
