Am Ende dieser Seite hast du einen gestylten QR-Code in einer Vue-3-Komponente, der auf dem Server gerendert und ohne Mismatch hydriert wird, plus einen Button, der ihn als PNG speichert. `qrdx/vue` enthält Vue-Versionen der React-Komponenten `QRCode` und `QRCodeSVG` sowie ein Composable `useQRCode`. Sie nehmen dieselben Props wie die React-Komponenten und zeichnen dasselbe SVG. Der Einstiegspunkt basiert auf `qrdx/core` und importiert `react` nicht.

<NpmStatus package="qrdx" />

## Bevor du anfängst [#before-you-start]

- Ein Projekt mit Vue 3.3 oder neuer, mit Vite oder Nuxt. TypeScript prüft die Props der Komponenten ab Vue 3.4.20.
- Node.js 18 oder neuer.

## So baust du es [#build-it]

### 1. qrdx installieren [#1-install-qrdx]

```package-install
qrdx
```

`vue` ist eine optionale Peer-Dependency, daher wird das Vue deiner App verwendet.

### 2. Einen Code zeichnen [#2-draw-a-code]

```vue title="src/App.vue"
<script setup lang="ts">
import { QRCode } from "qrdx/vue";
import { ref } from "vue";

const url = ref("https://example.com/menu");
</script>

<template>
  <QRCode
    :value="url"
    :size="256"
    :margin="4"
    body-pattern="rounded"
    :frame="{ style: 'banner-bottom', text: 'Scan for the menu' }"
    aria-label="QR code for the menu"
  />
</template>
```

Die Seite zeigt einen 256 px großen Code mit abgerundeten Modulen und einem Banner darunter. Ändere `url`, und der Code wird neu gezeichnet, wobei Vue das `<svg>` direkt an Ort und Stelle aktualisiert.

<Shot id="lib-framed-menu-code" />

`QRCode` nimmt die Props des React-`QRCode`: jede `QRProps`-Option sowie `logo`, `logoOptions`, `hideLogo` und `scale` für ein Logo. Im Template schreibst du sie in kebab-case (`body-pattern`) oder camelCase. Ein Flag wie `auto-level` oder `hide-logo` braucht keinen Wert. `class`, `style`, `aria-label` und andere Attribute landen auf dem `<svg>`, bei einem Rahmen auf dem äußeren `<svg>` des Rahmens, ebenso Listener wie `@click`.

### 3. Mit useQRCode als Datei speichern [#3-save-it-as-a-file-with-useqrcode]

```vue title="src/components/DownloadCode.vue"
<script setup lang="ts">
import { useQRCode } from "qrdx/vue";
import { ref } from "vue";

const url = ref("https://example.com/menu");
const { svg, download } = useQRCode(() => ({
  value: url.value,
  size: 256,
  margin: 4,
  bodyPattern: "rounded",
}));
</script>

<template>
  <div v-html="svg" />
  <button type="button" @click="download({ format: 'png', size: 1024, filename: 'menu.png' })">
    Download PNG
  </button>
</template>
```

Der Code wird aus seinem Markup angezeigt, und der Button speichert `menu.png` mit 1024 px. `useQRCode(props)` nimmt die Props von `QRCode` als Objekt, Ref, reaktives Objekt oder Getter entgegen und gibt zurück:

- `svg`: das SVG-Markup als Computed Ref. Es folgt den Props und funktioniert beim Server-Rendering.
- `toDataURL(format, { size, quality })`: der Code als Data-URL.
- `download({ format, filename, size, quality })`: speichert den Code als Datei.
- `options`: die Optionen, mit denen der Code gezeichnet wird, als Computed Ref.

`toDataURL` und `download` verwenden standardmäßig PNG in der eigenen `size` des Codes. Die Formate sind `png`, `jpg`, `webp`, `svg`, `pdf` und `eps`. PNG, JPG und WebP brauchen einen Browser, und PDF braucht das optionale Paket `jspdf`.

## QRCodeSVG und rohe Bildeinstellungen [#qrcodesvg-and-raw-image-settings]

`QRCodeSVG` nimmt `QRProps`, wie das React-`QRCodeSVG`. Ein Logo gibst du in `imageSettings` in Pixeln an:

```vue title="src/components/LogoCode.vue"
<script setup lang="ts">
import { QRCodeSVG } from "qrdx/vue";
</script>

<template>
  <QRCodeSVG
    value="https://example.com"
    :size="256"
    level="H"
    :image-settings="{ src: '/logo.png', width: 48, height: 48, excavate: true }"
  />
</template>
```

Nimm lieber `QRCode` mit `logo` und `logoOptions`, es sei denn, du legst das Logo selbst aus.

## Server-Rendering und Nuxt [#server-rendering-and-nuxt]

Beide Komponenten rendern mit dem Server-Renderer von Vue (`vue/server-renderer`), sodass der Code Teil des HTML vom Server ist. Das Markup enthält keine zufälligen IDs, daher hydriert der Browser es ohne Mismatch.

In Nuxt kannst du sie in jeder Seite oder Komponente verwenden. Sie rendern auf dem Server und hydrieren im Browser. In `<ClientOnly>` rendern sie nur im Browser.

## Mehr aus qrdx/core [#more-from-qrdxcore]

`qrdx/vue` exportiert alles aus `qrdx/core` erneut: `toSVGString`, `downloadQRCode`, `getQRCodeDataUrl`, `getScanScore`, die offizielle Rahmenbibliothek (`getOfficialFrame`) und den Rest. [Vanilla JavaScript](/docs/vanilla-js) behandelt sie. Für PNG auf einem Server nutze `getQRAsPNG` aus `qrdx/node`.

Der `wrapper` eines eigenen Templates wird mit dem `h` geschrieben, das `qrdx/vue` exportiert. Das ist das `h` des Cores, nicht das von Vue. Importiere daher eines der beiden unter anderem Namen, wenn eine Datei beide braucht:

```ts title="src/labelled-template.ts"
import { h } from "qrdx/vue";

export const Labelled = {
  id: "Labelled",
  name: "Labelled",
  wrapper: (children, props) =>
    h(
      "svg",
      { viewBox: "0 0 300 340", xmlns: "http://www.w3.org/2000/svg" },
      h("g", { transform: "translate(20, 20) scale(0.87)" }, children),
      h("text", { x: "150", y: "325", textAnchor: "middle" }, props?.label)
    ),
};
```

Übergib es als `customTemplate`, mit seinen Props in `customProps`: `<QRCode value="https://example.com" :custom-template="Labelled" :custom-props="{ label: 'Scan me' }" />`.

## Wenn etwas schiefgeht [#if-something-goes-wrong]

- **`Failed to resolve component: QRCode`.** Die Komponente ist in dieser Datei nicht importiert. Füge `import { QRCode } from "qrdx/vue"` in das `<script setup>` ein.
- **Ein Prop hat keine Wirkung.** Du hast ihn als Attribut-String geschrieben, obwohl er einen Wert braucht: `size="256"` übergibt einen String, `:size="256"` eine Zahl. Objekt-Props wie `frame` und `image-settings` brauchen immer den Doppelpunkt.
- **`PDF export needs the optional "jspdf" package`.** Führe `npm install jspdf` in der App aus.
