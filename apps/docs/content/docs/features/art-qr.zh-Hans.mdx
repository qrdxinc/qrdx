`art` 属性可以把 Logo 或照片以矢量图形的方式融入二维码的模块，不使用 AI：Logo QR 会在你的 Logo 形状内部为模块重新着色，Image QR 则让你的照片透过每一个模块显示出来。两者都由库本身绘制，因此可以离线运行，也能在服务器和 Node 中使用，而且结果始终是真正可用的二维码。本页介绍该属性、图片的取样方式，以及如何保持可扫描性。

想在 Playground 或控制台中设计？请参阅帮助中的[将 Logo 或照片融入二维码](/docs/help/designing/art)。

QRdx 有三种把二维码变成艺术作品的方式：

| | 工作方式 | 输出 | 成本 |
| --- | --- | --- | --- |
| **Logo QR**（`mode: "logo"`） | Logo 形状内的模块采用其颜色，其余模块褪为较浅的色调 | 矢量（SVG、PDF、EPS、PNG） | 免费 |
| **Image QR**（`mode: "halftone"`） | 每个模块都显示你的照片，中心方块保留真实的值 | 矢量（SVG、PDF、EPS、PNG） | 免费 |
| **AI 艺术** | AI 图像模型把二维码重绘为一幅场景，每张图像都经过验证可扫描 | 1024 px 图像，2048 px 印刷副本 | AI 艺术图像额度来自所在套餐 |

## 绘制艺术二维码 [#draw-an-art-code]

传入 `art` 属性，指定模式、已取样的图片和可选的强度：

```tsx title="components/logo-art-code.tsx"
import { loadQRArtImage, type QRArtImage, QRCode } from "qrdx";

// Browser: sample an uploaded file, a data URL or an <img>
export async function sampleLogo(file: File): Promise<QRArtImage> {
  return await loadQRArtImage(file, { mode: "logo" });
}

export function LogoArtCode({ image }: { image: QRArtImage }) {
  return (
    <QRCode
      value="https://example.com"
      size={512}
      level="H"
      art={{ mode: "logo", image, intensity: 0.7 }}
    />
  );
}
```

在服务器或 Node 中，请自行解码图片，并把 RGBA 像素传给 `createQRArtImage`：

```ts title="lib/sample-photo.ts"
import { createQRArtImage } from "qrdx";
import sharp from "sharp";

const { data, info } = await sharp("photo.jpg")
  .ensureAlpha()
  .raw()
  .toBuffer({ resolveWithObject: true });

export const image = createQRArtImage(
  { data, width: info.width, height: info.height },
  { maxSize: 96, square: true }
);
// art={{ mode: "halftone", image, intensity: 0.8 }}
```

`art.image` 是普通的 JSON（`{ width, height, data }`，其中 data 为 base64 编码的 RGBA），因此你可以将它与已保存的设计一起存储，并在任何地方同步渲染同一个二维码，无需再次获取图片。

| 选项 | 取值 | 说明 |
| --- | --- | --- |
| `mode` | `logo`、`halftone` | `halftone` 在编辑器中即 Image QR |
| `image` | 来自 `loadQRArtImage` 或 `createQRArtImage` | 最多 192 × 192 个样本。`loadQRArtImage` 默认横向取 160 个样本 |
| `intensity` | `0` 到 `1` | 默认为 `0.6`；`0` 看起来就像普通二维码 |
| `variant` | `blend`、`badge`（logo）；`color`、`mono`（halftone） | 模式内的外观。`badge` 会把描摹后的 Logo 放在带色调二维码中央的圆角底板上；`mono` 是黑白半色调。每种模式的默认值是第一个值 |
| `matchEyes` | `true`、`false` | 仅限 Logo 模式：根据 Logo 为角部定位点着色（默认 `true`）。单独设置的 `eyeColors` 仍然优先 |

艺术效果会取代主体图案；角部定位点仍使用各自的 `cornerEyePattern`、`cornerEyeDotPattern` 和颜色。艺术效果使用渐变 `fgColor` 或 `bgColor` 的第一个颜色，并要求浅色背景上有深色前景；颜色反转时会退回为普通外观。请使用 `level="H"`，它能为艺术效果留出最大空间。

## 如何保持可扫描性 [#how-scannability-is-kept]

- **Logo QR**：Logo 内部的深色模块会被重新着色，但只会加深到扫描器仍视为深色的亮度；Logo 内部的浅色模块会得到一个淡色调，并保持在浅色阈值之上。Logo 外部的深色模块会褪为灰色，但不会比深色阈值更浅。
- **Logo QR badge**：底板下的每个模块都可能破坏一个码字。底板的大小经过设定，使任何纠错块损失的码字都不超过其可修复数量的 60%，其余部分留给摄像头。强度会让底板增大，直至达到该尺寸。较小的二维码使用较小的 Logo，最小的几种（版本 1、L 或 M 级的版本 2、L 级的版本 3）不绘制底板。
- **Image QR**：每个模块被划分为 3 × 3 的网格。外围单元格显示照片，并根据模块的值调深或调浅，中心则保留精确的前景色或背景色，这正是扫描器取样的位置。
- 定位、定时、校正、格式和版本模块始终以实心方式绘制。

打印前请用 `getScanScore(props)` 检查任何设计，并用真实的手机摄像头测试。

## 导出艺术二维码 [#export-art-codes]

艺术二维码是矢量图形，因此每种导出格式都能保持清晰：

```ts title="lib/export-art.ts"
import { downloadQRCode, getQRAsEPS, getQRAsPrintPDF } from "qrdx";

await downloadQRCode(props, { format: "svg", size: { width: 1024, height: 1024 } });
const pdf = await getQRAsPrintPDF(props, { size: 40, unit: "mm", colorMode: "cmyk" });
const eps = await getQRAsEPS(props, { sizeMm: 40, bleedMm: 3, colorMode: "cmyk" });
```

`getQRAsEPS` 会写出带有以磅为单位的 `%%BoundingBox` 的 EPSF-3.0 文件，每个模块、定位点和边框都是 PostScript 路径。与印刷 PDF 一样，它保留线性和径向渐变（作为 PostScript Level 3 渐变），且不含透明度。PNG 和 JPEG 格式的 Logo 会作为图像嵌入；其他格式的 Logo 在浏览器中会被转换，在服务器上则会被省略。边框文字使用 Helvetica，因此 Latin-1 之外的字符会打印为 `?`。`svgToEPS(svg, { width })` 可转换本库渲染的任何 SVG。CLI 同样可以写出 EPS：`qrdx generate "https://example.com" -o qr.eps`。

<IfAvailable feature="aiArt" id="ai-art" title="AI 艺术">

[AI 二维码艺术](/ai/art)通过 Vercel AI Gateway，使用 {facts.artModel} 把你的二维码变成一幅场景。你可以按类别浏览或搜索 {facts.aiArtStyles} 种风格预设，每种都带有通过扫描检查的预览和需要避免的内容；还有一个**二维码可见度**滑块（模型对二维码的偏重程度）、一个**创意度**滑块（模型解读提示词的自由程度）、每次生成 1 到 4 个变体，以及可选的参考图像（例如 Logo 或调色板），其颜色和形状会被沿用。

每张图像在你看到之前都会在服务器上检查。QRdx 向模型发送一个普通的黑白二维码（纠错等级 H、方形模块、较宽的静区），并要求模型保留模块网格、定位点和静区。随后它用 jsQR 解码模型生成的图像，既按原样解码，也通过手机摄像头模型解码。如果失败，它会在模型绘制的图像中找到模块网格，并尽可能少地在模型自己的图像上加强二维码：先是定位点和静区，再是模块，逐步提高强度，直到图像可扫描，包括二维码在摄像头视野中较小的情况。二维码可见度决定它最多可以加强到什么程度。只有这样仍然不够时，它才会把图像重绘为 Image QR 二维码。仍无法解码出你确切内容的图像不会交付。随后你的浏览器会为各变体评分并选出最佳的一个；可以下载 1024 px 版本，或 2048 px 的印刷副本（经过重新采样并再次检查）。

每张交付的图像会消耗套餐每月 AI 艺术图像额度中的一张：免费版账户每月 3 张，Pro 30 张，Business 150 张，由工作区内所有人共享。失败或未通过扫描检查的图像不消耗额度，印刷副本免费。AI 艺术是栅格图像，其内容是固定的，因此如果需要可编辑的链接，请在其中放入[动态二维码](/docs/dynamic-qr-codes)的短链接。开发者可以通过 [AI art API](/docs/developers/ai-art-api) 生成。
