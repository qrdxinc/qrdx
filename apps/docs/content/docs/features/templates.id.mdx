Template adalah bingkai yang memuat kode di dalam karya seni dengan ukuran tetap. Berikan id-nya sebagai `templateId`, lalu komponen menggambar seluruh karya seni pada `size`, dengan kode yang lebih kecil di dalamnya. Halaman ini mencantumkan template bawaan, opsi Dot Ring, dan cara menggambar template dalam kode.

Mendesain di Playground atau dasbor? Template adalah kotak pilihan di grup **Classic** pada pemilih bingkai; lihat [Tambahkan bingkai dan ajakan bertindak](/docs/help/designing/frames) di Bantuan.

Template berbeda dari [bingkai](/docs/features/frames) lainnya dalam satu hal: ukuran. Bingkai menambahkan ruang di sekitar kode, sehingga `size` adalah lebar kode dan gambar membesar. Template menggambar seluruh karya seninya pada `size`, dengan kode yang lebih kecil di dalamnya.

## Template bawaan [#built-in-templates]

| `templateId` | Nama | Warna |
| --- | --- | --- |
| `Arrow` | Arrow | Warna gelap kode (`fgColor`) |
| `StandardBox` | Standard Box | `fgColor` |
| `SquareBorder` | Square Border | `fgColor` |
| `StrikedBox` | Striked Box | Warna gelapnya sendiri |
| `Halloween` | Halloween | Oranye, hijau, dan hitam miliknya sendiri |
| `DotRing` | Dot Ring | Cincinnya dengan `fgColor`, teksnya berwarna putih; keduanya dapat diubah (lihat di bawah) |

`default` tidak menggambar karya seni. Template ini hanya menggeser kode sedikit ke dalam, menjadi 95% dari `size`. Tanpa `templateId`, kode memenuhi `size`.

```tsx title="components/arrow-code.tsx"
import { QRCode } from "qrdx";

export function ArrowCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      templateId="Arrow"
      fgColor="#1a56db"
    />
  );
}
```

Warna, pola, dan logo tetap berada pada prop milik kode itu sendiri, sehingga template bekerja dengan gaya apa pun:

```tsx title="components/boxed-logo-code.tsx"
import { QRCode } from "qrdx";

export function BoxedLogoCode() {
  return (
    <QRCode
      value="https://example.com"
      size={512}
      templateId="StandardBox"
      fgColor="#1a56db"
      level="H"
      logo="/logo.png"
    />
  );
}
```

Image API menerima template sebagai `template` dan CLI sebagai `--template`.

## Dot Ring [#dot-ring]

Kode berbentuk bulat. Kode berada di dalam cakram titik-titik di dalam cincin gelap, dengan satu baris teks yang mengikuti cincin. Titik yang tampil berasal dari hash isi kode, sehingga setiap tautan mendapat cincin tersendiri dan tautan yang sama selalu mendapat cincin yang sama.

```tsx title="components/dot-ring-code.tsx"
import { QRCode } from "qrdx";

export function DotRingCode() {
  return (
    <QRCode
      value="https://example.com"
      size={512}
      templateId="DotRing"
      bodyPattern="circle-large"
      customProps={{
        customText: "Scan for the menu",
        textPosition: "bottom",
        textColor: "#fde047",
        outerCircleColor: "#1e3a8a",
      }}
    />
  );
}
```

Pengaturannya ada di `customProps`, dengan tipe `DotRingProps`:

| Prop | Bawaan | Catatan |
| --- | --- | --- |
| `customText` | "Scan the QR code *" empat kali mengelilingi cincin | Teks di sepanjang cincin; `""` membiarkan cincin kosong. Teks yang terlalu panjang untuk cincin akan disesuaikan (lihat di bawah) |
| `textFill` | `"none"` | `"repeat"` mengulang teks mengelilingi seluruh cincin (lihat di bawah) |
| `textPosition` | `"top"` | `"top"`: di tengah bagian atas, terbaca searah jarum jam. `"bottom"`: di tengah bagian bawah, terbaca dari kiri ke kanan |
| `textRotation` | `0` | Memutar teks mengelilingi pusat, dalam derajat searah jarum jam |
| `textColor` | `#ffffff` | Warna teks |
| `fontFamily` | system font stack | Keluarga font CSS untuk teks |
| `fontWeight` | `900` | Ketebalan font |
| `fontSize` | `32` | Dalam gambar template berukuran 593 unit, tempat kode selebar 300. Teks panjang bisa digambar lebih kecil |
| `fontLetterSpacing` | `3.5` | Ruang tambahan antarhuruf, dalam satuan yang sama. Teks panjang dan `textFill` menyesuaikannya |
| `outerCircleColor` | `fgColor` | Warna cincin |
| `strokeWidth`, `strokeColor` | `0`, `#000000` | Garis tepi di sepanjang kedua sisi cincin |
| `outerStrokeWidth`, `outerStrokeColor` | `strokeWidth`, `strokeColor` | Hanya tepi luar cincin |
| `innerStrokeWidth`, `innerStrokeColor` | `strokeWidth`, `strokeColor` | Hanya tepi dalam cincin |

Teks yang muat di cincin ditampilkan apa adanya, di tengah bagian atas atau di sepanjang bagian bawah. Teks yang terlalu panjang tidak pernah menabrak awal teksnya sendiri: huruf dirapatkan lebih dulu, lalu font diperkecil hingga setengah ukuran bawaan. Setelah itu, teks menutup cincin dengan spasi antarkata di titik pertemuan dengan awalnya. Jika masih belum muat, teks yang mengulang suatu frasa mempertahankan salinan utuh sebanyak yang muat, sedangkan teks lain dipotong setelah kata utuh terakhir yang muat dan diakhiri dengan elipsis.

Logo ditempatkan di tengah seperti pada kode mana pun. Tautan panjang (kode dengan lebar lebih dari 49 modul) mempertahankan pita terang antara kode dan titik-titik, sehingga tetap dapat dipindai saat dicetak kecil.

Teks tersebut adalah teks SVG dengan font yang Anda pilih; bawaannya adalah system font stack, jadi tidak ada yang diunduh. Unduhan SVG dan PNG di browser menggunakan font milik pengguna yang melihatnya. PDF dan EPS mencetaknya dalam Helvetica Bold, jadi gunakan teks Latin-1 di sana. `getQRAsPNG` dari `qrdx/node` memerlukan font yang terpasang di server, seperti label bingkai.

### Isi cincin [#fill-the-ring]

Frasa pendek membuat sebagian cincin kosong. Atur `textFill: "repeat"` untuk mengulangnya sebanyak yang muat, dengan jarak yang diratakan sehingga cincin tertutup dengan celah yang sama seperti antarsalinan:

```tsx title="components/docs-ring-code.tsx"
import { QRCode } from "qrdx";

export function DocsRingCode() {
  return (
    <QRCode
      value="https://example.com/docs"
      size={512}
      templateId="DotRing"
      customProps={{ customText: "Read the docs *", textFill: "repeat" }}
    />
  );
}
```

Berikan frasa itu sekali saja. Teks yang sudah mengulang suatu frasa, seperti `"Make your own * Make your own *"`, dibaca sebagai frasa tersebut, sehingga mengisi cincin dengan cara yang sama.

## Template adalah spesifikasi bingkai [#templates-are-frame-specs]

Karya seni Arrow, Standard Box, Square Border, Striked Box, dan Halloween adalah [spesifikasi bingkai](/docs/features/frames#frame-specs), dengan format JSON yang sama seperti bingkai lainnya, digambar oleh mesin yang sama. `getTemplate(id).spec` mengembalikannya. Gunakan sebagai bingkai bila Anda menginginkan ukuran ala bingkai (kode mempertahankan ukurannya dan karya seni membesar di sekelilingnya) dan opsi warna bingkai:

```tsx title="components/arrow-frame-code.tsx"
import { getTemplate, QRCode } from "qrdx";

const spec = getTemplate("Arrow")?.spec;

export function ArrowFrameCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      frame={spec && { style: "custom", spec, color: "#1a56db" }}
    />
  );
}
```

Dot Ring tidak punya spesifikasi: titik-titiknya berasal dari isi kode, jadi digambar dalam kode (lihat [Gambar template dalam kode](#draw-a-template-in-code)).

`templateId` menggambar karya seni yang sama seperti sebelumnya. Desain tersimpan, URL gambar, perintah CLI, dan kode yang memakai id template tampil sama seperti biasanya.

## Registri template [#template-registry]

```ts title="lib/templates.ts"
import { getAllTemplates, getTemplate, getTemplateIds } from "qrdx";

getTemplateIds(); // ["default", "Arrow", "StandardBox", "SquareBorder", "StrikedBox", "Halloween", "DotRing"]
getAllTemplates(); // every TemplateDefinition, with its id and name
getTemplate("Halloween"); // one by id, or undefined
```

## Gambar template dalam kode [#draw-a-template-in-code]

Spesifikasi bingkai menjelaskan karya seni yang tetap. Bila karya seni harus dihitung, tulis `TemplateDefinition` lalu berikan sebagai `customTemplate`. `wrapper`-nya menerima kode sebagai `children` dan mengembalikan SVG yang akan digambar. Ia menggambar pada kanvas 300 kali 300, dan kode juga datang dengan ukuran itu, jadi perkecil agar ada ruang untuk karya seni Anda. `props` membawa `fgColor` dan `bgColor` milik kode, dan argumen ketiga berisi `url` dan `pixelSize` kode.

Contoh ini menggambar cincin di sekeliling kode:

```tsx title="components/ring-template-code.tsx"
import { QRCode, type TemplateDefinition } from "qrdx";

const ringTemplate: TemplateDefinition = {
  id: "ring",
  name: "Ring",
  wrapper: (children, props) => (
    <svg
      viewBox="0 0 300 300"
      width="300"
      height="300"
      xmlns="http://www.w3.org/2000/svg"
    >
      <circle
        cx="150"
        cy="150"
        r="140"
        fill="none"
        stroke={props?.fgColor ?? "#000000"}
        strokeWidth="8"
      />
      {/* The code at half size, centered */}
      <g transform="translate(75, 75) scale(0.5)">{children}</g>
    </svg>
  ),
};

export function RingTemplateCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      customTemplate={ringTemplate}
      fgColor="#1a56db"
    />
  );
}
```

`customTemplate` menang atas `templateId` bila keduanya diatur. Jaga agar kode cukup besar untuk dipindai dari jarak orang memegang ponselnya, dan sisakan celah terang antara kode dan karya seni Anda. Periksa hasilnya dengan [skor pemindaian](/docs/features/frames#will-it-scan). Tanpa JSX, tulis wrapper dengan `h` dari `qrdx/core`; lihat [Vanilla JavaScript](/docs/vanilla-js#custom-templates-without-jsx).
