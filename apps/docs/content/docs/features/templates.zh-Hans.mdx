模板是一种边框,它把二维码嵌入尺寸固定的图案之中。将模板的 id 作为 `templateId` 传入,组件就会按 `size` 绘制完整图案,二维码在其中显得更小。本页列出内置模板、Dot Ring 的选项,以及如何用代码绘制模板。

想在 Playground 或控制台中设计?模板位于边框选择器的 **经典** 分组中的图块里,参见帮助中的[添加边框和行动号召](/docs/help/designing/frames)。

模板与其他[边框](/docs/features/frames)有一点不同:尺寸。边框会在二维码周围增加空间,因此 `size` 是二维码的宽度,图像会变大。模板则按 `size` 绘制整个图案,二维码在其中更小。

## 内置模板 [#built-in-templates]

| `templateId` | 名称 | 颜色 |
| --- | --- | --- |
| `Arrow` | Arrow | 二维码的深色(`fgColor`) |
| `StandardBox` | Standard Box | `fgColor` |
| `SquareBorder` | Square Border | `fgColor` |
| `StrikedBox` | Striked Box | 自带的深色 |
| `Halloween` | Halloween | 自带的橙色、绿色和黑色 |
| `DotRing` | Dot Ring | 圆环使用 `fgColor`,文字为白色;两者都可以更改(见下文) |

`default` 不绘制任何图案,只是把二维码略微内缩到 `size` 的 95%。没有 `templateId` 时,二维码会填满 `size`。

```tsx title="components/arrow-code.tsx"
import { QRCode } from "qrdx";

export function ArrowCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      templateId="Arrow"
      fgColor="#1a56db"
    />
  );
}
```

<Shot id="lib-templates" />

颜色、图案和徽标仍由二维码自身的属性控制,因此模板可以搭配任何样式:

```tsx title="components/boxed-logo-code.tsx"
import { QRCode } from "qrdx";

export function BoxedLogoCode() {
  return (
    <QRCode
      value="https://example.com"
      size={512}
      templateId="StandardBox"
      fgColor="#1a56db"
      level="H"
      logo="/logo.png"
    />
  );
}
```

Image API 中用 `template` 传入模板,CLI 中用 `--template`。

## Dot Ring [#dot-ring]

圆形二维码。二维码位于深色圆环内的点阵圆盘中,沿圆环排布一行文字。哪些点显示由二维码内容的哈希决定,因此每个链接都有专属的圆环,同一个链接始终得到相同的圆环。

```tsx title="components/dot-ring-code.tsx"
import { QRCode } from "qrdx";

export function DotRingCode() {
  return (
    <QRCode
      value="https://example.com"
      size={512}
      templateId="DotRing"
      bodyPattern="circle-large"
      customProps={{
        customText: "Scan for the menu",
        textPosition: "bottom",
        textColor: "#fde047",
        outerCircleColor: "#1e3a8a",
      }}
    />
  );
}
```

它的设置放在 `customProps` 中,类型为 `DotRingProps`:

| 属性 | 默认值 | 说明 |
| --- | --- | --- |
| `customText` | “Scan the QR code *”,绕圈重复四次 | 沿圆环排布的文字;`""` 表示圆环留空。过长的文字会被适配(见下文) |
| `textFill` | `"none"` | `"repeat"` 会让文字在整圈圆环上重复(见下文) |
| `textPosition` | `"top"` | `"top"`:居中于顶部,按顺时针方向阅读。`"bottom"`:居中沿底部排布,从左到右阅读 |
| `textRotation` | `0` | 使文字绕中心旋转,单位为度,顺时针方向 |
| `textColor` | `#ffffff` | 文字颜色 |
| `fontFamily` | 系统字体栈 | 文字的 CSS 字体族 |
| `fontWeight` | `900` | 字重 |
| `fontSize` | `32` | 以模板 593 单位的绘图为准,其中二维码宽 300。较长的文字可能会以更小的字号绘制 |
| `fontLetterSpacing` | `3.5` | 字母之间额外的间距,单位相同。较长的文字和 `textFill` 会对其进行调整 |
| `outerCircleColor` | `fgColor` | 圆环颜色 |
| `strokeWidth`, `strokeColor` | `0`, `#000000` | 沿圆环两侧边缘的描边 |
| `outerStrokeWidth`, `outerStrokeColor` | `strokeWidth`, `strokeColor` | 仅圆环外缘 |
| `innerStrokeWidth`, `innerStrokeColor` | `strokeWidth`, `strokeColor` | 仅圆环内缘 |

能放进圆环的文字会按原样排布,居中于顶部或沿底部。过长的文字不会与自己的开头相撞:先缩小字母间距,再缩小字号,最小为默认字号的一半。随后文字会在与开头相接处用一个词间距闭合圆环。如果仍然放不下,重复短语的文字会保留能放下的完整份数,其他文字则在能放下的最后一个完整单词之后截断,并以省略号结尾。

和任何二维码一样,徽标放在中间。较长的链接(宽度超过 49 个模块的二维码)会在二维码和点阵之间保留一圈浅色带,这样即使小尺寸打印也能扫描。

文字是 SVG 文本,使用你选择的字体;默认是系统字体栈,因此不会下载任何字体。在浏览器中下载 SVG 和 PNG 时使用查看者的字体。PDF 和 EPS 用 Helvetica Bold 打印文字,因此请在其中使用 Latin-1 文本。`qrdx/node` 中的 `getQRAsPNG` 需要服务器上安装字体,边框标签也是如此。

### 填满圆环 [#fill-the-ring]

较短的短语会让圆环的一部分空着。设置 `textFill: "repeat"` 可让它尽可能多次地重复,并均匀调整间距,使圆环闭合处的空隙与各份文字之间的空隙相同:

```tsx title="components/docs-ring-code.tsx"
import { QRCode } from "qrdx";

export function DocsRingCode() {
  return (
    <QRCode
      value="https://example.com/docs"
      size={512}
      templateId="DotRing"
      customProps={{ customText: "Read the docs *", textFill: "repeat" }}
    />
  );
}
```

短语只需给出一次。已经重复短语的文字,例如 `"Make your own * Make your own *"`,会被识别为该短语,因此同样会填满圆环。

## 模板就是边框规格 [#templates-are-frame-specs]

Arrow、Standard Box、Square Border、Striked Box 和 Halloween 的图案是一份[边框规格](/docs/features/frames#frame-specs),与其他所有边框使用相同的 JSON 格式,由同一个引擎绘制。`getTemplate(id).spec` 会返回它。如果你想要边框式的尺寸(二维码保持原有大小,图案在其周围扩展)以及边框的颜色选项,可以把它当作边框使用:

```tsx title="components/arrow-frame-code.tsx"
import { getTemplate, QRCode } from "qrdx";

const spec = getTemplate("Arrow")?.spec;

export function ArrowFrameCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      frame={spec && { style: "custom", spec, color: "#1a56db" }}
    />
  );
}
```

Dot Ring 没有规格:它的点来自二维码的内容,因此用代码绘制(参见[用代码绘制模板](#draw-a-template-in-code))。

`templateId` 绘制的图案与以前相同。使用模板 id 的已保存设计、图像 URL、CLI 命令和代码,看起来与以往完全一样。

## 模板注册表 [#template-registry]

```ts title="lib/templates.ts"
import { getAllTemplates, getTemplate, getTemplateIds } from "qrdx";

getTemplateIds(); // ["default", "Arrow", "StandardBox", "SquareBorder", "StrikedBox", "Halloween", "DotRing"]
getAllTemplates(); // every TemplateDefinition, with its id and name
getTemplate("Halloween"); // one by id, or undefined
```

## 用代码绘制模板 [#draw-a-template-in-code]

边框规格描述的是固定的图案。如果图案需要计算得出,请编写 `TemplateDefinition` 并将其作为 `customTemplate` 传入。它的 `wrapper` 以 `children` 的形式接收二维码,并返回要绘制的 SVG。它在 300 × 300 的画布上绘制,二维码也以该尺寸传入,因此请将其缩小,为你的图案留出空间。`props` 携带二维码的 `fgColor` 和 `bgColor`,第三个参数包含二维码的 `url` 和 `pixelSize`。

下面这个示例在二维码周围绘制一个圆环:

```tsx title="components/ring-template-code.tsx"
import { QRCode, type TemplateDefinition } from "qrdx";

const ringTemplate: TemplateDefinition = {
  id: "ring",
  name: "Ring",
  wrapper: (children, props) => (
    <svg
      viewBox="0 0 300 300"
      width="300"
      height="300"
      xmlns="http://www.w3.org/2000/svg"
    >
      <circle
        cx="150"
        cy="150"
        r="140"
        fill="none"
        stroke={props?.fgColor ?? "#000000"}
        strokeWidth="8"
      />
      {/* The code at half size, centered */}
      <g transform="translate(75, 75) scale(0.5)">{children}</g>
    </svg>
  ),
};

export function RingTemplateCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      customTemplate={ringTemplate}
      fgColor="#1a56db"
    />
  );
}
```

同时设置时,`customTemplate` 优先于 `templateId`。请让二维码足够大,以便人们在手持手机的距离上能够扫描,并在二维码与图案之间留出浅色间隙。用[扫描评分](/docs/features/frames#will-it-scan)检查结果。如果不使用 JSX,请用 `qrdx/core` 中的 `h` 编写 wrapper;参见 [Vanilla JavaScript](/docs/vanilla-js#custom-templates-without-jsx)。
