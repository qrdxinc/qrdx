`QRCode` में `logo` prop होता है और वह लोगो का लेआउट अपने आप कर देता है: वह लोगो के पीछे के मॉड्यूल खाली कर देता है और लोगो को कभी इतना बड़ा नहीं बनाता कि कोड उसे ठीक न कर सके। इस पेज में लेआउट के विकल्प, सीमाएँ और नीचे काम करने वाला raw `imageSettings` API बताया गया है।

अगर आप कोड की जगह playground या डैशबोर्ड में डिज़ाइन कर रहे हैं, तो Help में [लोगो जोड़ें](/docs/help/designing/logos) देखें।

## तीन लाइन में लोगो [#a-logo-in-three-lines]

```tsx title="components/logo-code.tsx"
import { QRCode } from "qrdx";

export function LogoCode() {
  return (
    <QRCode value="https://example.com" size={256} level="H" logo="/logo.png" />
  );
}
```

`logo` में आपके app का पाथ, URL या data URL दिया जा सकता है। लोगो कोड की चौड़ाई के एक चौथाई साइज़ में बनता है, उसके पीछे के मॉड्यूल खाली हो जाते हैं, और स्कैन के लिए कोड error correction पर निर्भर करता है। `level="H"` (कोड का 30% हिस्सा खराब हो सकता है) इस्तेमाल करें, या कम से कम डिफ़ॉल्ट `Q` (25%) रखें।

## साइज़, खाली जगह और पोज़िशन [#size-clear-space-and-position]

`logoOptions` लोगो का लेआउट ऐसी इकाइयों में तय करता है जो रेंडर साइज़ पर निर्भर नहीं करतीं:

| विकल्प | रेंज | डिफ़ॉल्ट | क्या करता है |
| --- | --- | --- | --- |
| `size` | 0.1 से 0.3 | 0.25 | कोड की चौड़ाई के हिसाब से लोगो की चौड़ाई। 25% से ऊपर पैकेज के decode टेस्ट में लेवल H भी पढ़ना बंद कर देता है |
| `padding` | 0 से 2 | 0 | लोगो के चारों ओर खाली जगह, मॉड्यूल में |
| `x`, `y` | 0 से 1 | 0.5 | कोड में लोगो का केंद्र कहाँ रहे। लोगो हमेशा कोड के अंदर ही रहता है |
| `shape` | `square`, `rounded`, `circle` | `square` | लोगो को क्रॉप करता है |
| `plate` | एक रंग | कोई नहीं | लोगो के पीछे उसी आकार की ठोस प्लेट |

```tsx title="components/placed-logo-code.tsx"
import { QRCode } from "qrdx";

export function PlacedLogoCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      level="H"
      logo="/logo.png"
      logoOptions={{ size: 0.2, padding: 1, x: 0.6, y: 0.55 }}
    />
  );
}
```

हटाए हुए लोगो को तीनों कोने की आँखों से और नीचे दाएँ कोने के पास वाले छोटे चौकोर से दूर रखें (alignment pattern, जिसे decoder perspective ठीक करने के लिए इस्तेमाल करते हैं)। जो लोगो इनमें से किसी को ढकता है, उसे स्कैन स्कोर फ़ेल कर देता है।

## लोगो कितना बड़ा हो सकता है [#how-big-a-logo-can-be]

लोगो (अपनी खाली जगह के साथ) जिस भी codeword को छूता है उसे खराब कर देता है, और हर error-correction ब्लॉक सीमित संख्या में ही ठीक कर सकता है। `QRCode` और `getQRData` खराब हुए codeword ब्लॉक-दर-ब्लॉक गिनते हैं और लोगो को तब तक छोटा करते हैं जब तक सबसे खराब ब्लॉक अपनी repair क्षमता का ज़्यादा से ज़्यादा 60% (`LOGO_EC_SAFETY`) इस्तेमाल न करे। छोटे कोड में कम जगह होती है: लेवल Q पर छोटे लिंक में चौड़ाई का करीब 13% से 17% लोगो आता है, और लेवल H या छोटी वैल्यू से ज़्यादा जगह बनती है।

- `getLogoSizeLimit(props)` वह सबसे बड़ा `size` लौटाता है जो कोड में फ़िट होता है, ताकि स्लाइडर वहीं रुक सके।
- `QRCodeSVG`, `QRCodeCanvas` और `getQRAsSVG` पर raw `imageSettings` को भी यही सीमा मिलती है: जो लोगो फ़िट होता है वह जैसा दिया गया वैसा बनता है, और बड़ा लोगो अपने ही केंद्र के चारों ओर छोटा कर दिया जाता है।
- जब भी खाली किया गया हिस्सा कोड के 7% (`AUTO_LEVEL_LOGO_COVERAGE`) से ज़्यादा ढके, तब `autoLevel` error correction को `H` तक बढ़ा देता है। यह डिफ़ॉल्ट रूप से बंद है, इसलिए मौजूदा कोड अपना लेवल बनाए रखते हैं।
- स्कैन स्कोर उन्हीं codeword को गिनता है और सीमा आपके लोगो को छोटा करे, उससे पहले चेतावनी देता है।

## आकार, प्लेट और बैकग्राउंड [#shape-plate-and-background]

```tsx title="components/round-logo-code.tsx"
import { QRCode } from "qrdx";

export function RoundLogoCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      level="H"
      logo="/logo.png"
      logoOptions={{ size: 0.22, shape: "circle", plate: "#ffffff" }}
    />
  );
}
```

क्रॉप एक SVG clip path है। प्रिंट PDF और EPS भी उसी आउटलाइन पर क्लिप होते हैं, इसलिए हर डाउनलोड एक जैसा दिखता है। EPS में ट्रांसपेरेंसी नहीं होती, इसलिए लोगो के पारदर्शी हिस्से वहाँ सफ़ेद छपते हैं।

अगर लोगो किसी ठोस बॉक्स पर है (JPEG में आम है), तो उसे हटाएँ: `removeLogoBackground(src)` ब्राउज़र में साफ़ किया हुआ PNG data URL के रूप में लौटाता है, और `removeLogoBackdrop(pixels)` यही काम कहीं भी RGBA पिक्सल पर करता है। जब चारों कोनों का रंग एक ही हो, तो वे उस रंग को किनारों से अंदर की ओर साफ़ करते हैं, इसलिए निशान के अंदर वही रंग (जैसे सफ़ेद अक्षर) बना रहता है। इमेज में ठोस बैकग्राउंड न हो तो दोनों `null` लौटाते हैं।

## Raw इमेज सेटिंग्स [#raw-image-settings]

`QRCodeSVG` और `QRCodeCanvas` लोगो को `imageSettings` के रूप में लेते हैं, उन्हीं पिक्सल में जिनमें `size` होता है। जब आप लोगो का लेआउट खुद करें या किसी दूसरे renderer से कोड पोर्ट करें, तब इसका इस्तेमाल करें।

```tsx title="components/image-settings-code.tsx"
import { QRCodeSVG } from "qrdx";

export function ImageSettingsCode() {
  return (
    <QRCodeSVG
      value="https://example.com"
      size={512}
      level="H"
      autoLevel
      imageSettings={{
        src: "/logo.png",
        width: 110,
        height: 110,
        excavate: true,
        padding: 8,
      }}
    />
  );
}
```

- `width` और `height` पिक्सल में हैं। लोगो को बीच में रखने के लिए `x` और `y` छोड़ दें।
- `excavate` लोगो के पीछे के मॉड्यूल खाली करता है। इसे चालू रखें, सिवाय तब जब लोगो पारदर्शी हो और आप चाहें कि उसमें से मॉड्यूल दिखें।
- `padding` लोगो के चारों ओर अतिरिक्त मॉड्यूल खाली करता है, उन्हीं पिक्सल में जिनमें `width` और `height` हैं।
- `shape` और `plate` वैसे ही काम करते हैं जैसे `logoOptions` में।
- `margin` कुछ भी हो, लोगो अपना पिक्सल साइज़ बनाए रखता है।

`getQRData(props)` 1024 px के कोड के लिए `logo` और `logoOptions` को इन्हीं `imageSettings` में बदल देता है, इसी तरह `QRCode` और डाउनलोड helpers एक ही लेआउट साझा करते हैं।

## डाउनलोड और फ़ॉर्मैट [#downloads-and-formats]

- PNG और JPEG लोगो हर एक्सपोर्ट में एम्बेड होते हैं। SVG और WebP लोगो ब्राउज़र के एक्सपोर्ट में बनते हैं और सर्वर पर बने PNG में नहीं आते।
- डाउनलोड के लिए data URL सबसे सुरक्षित है। रिमोट इमेज को फ़ाइल में कॉपी करने से पहले ब्राउज़र को CORS हेडर चाहिए; उनके बिना फ़ाइल में लोगो नहीं होगा।
- रंगीन कोड पर ट्रांसपेरेंसी वाला PNG सबसे साफ़ नतीजा देता है। JPEG के लिए बैकग्राउंड रंग की `plate` जोड़ें या पहले उसका बॉक्स हटाएँ।
- लोगो वाले कोड को प्रिंट करने से पहले दो-तीन फ़ोन पर टेस्ट करें, या [स्कैन स्कोर](/docs/features/frames#will-it-scan) से जाँचें।
