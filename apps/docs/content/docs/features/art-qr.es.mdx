La prop `art` integra un logo o una foto en los módulos de un código, como formas vectoriales y sin IA: Logo QR recolorea los módulos que quedan dentro de la forma de tu logo, e Image QR muestra tu foto a través de cada módulo. La propia biblioteca dibuja ambos, así que funcionan sin conexión, en el servidor y en Node, y el resultado siempre es un código QR real. Esta página cubre la prop, cómo se muestrea la imagen y cómo se mantiene la capacidad de escaneo.

¿Prefieres diseñar en el Playground o en el panel? Consulta [Integra un logo o una foto en el código](/docs/help/designing/art) en la Ayuda.

QRdx ofrece tres formas de convertir un código en una obra de arte:

| | Cómo funciona | Resultado | Costo |
| --- | --- | --- | --- |
| **Logo QR** (`mode: "logo"`) | Los módulos dentro de la forma de tu logo toman sus colores; el resto se aclara hacia un tono más claro | Vectorial (SVG, PDF, EPS, PNG) | Gratis |
| **Image QR** (`mode: "halftone"`) | Cada módulo muestra tu foto alrededor de un cuadrado central que conserva el valor real | Vectorial (SVG, PDF, EPS, PNG) | Gratis |
| **Arte con IA** | Un modelo de imágenes con IA redibuja el código como una escena, y se verifica que cada imagen se escanee | Imagen de 1024 px, copia de impresión de 2048 px | Imágenes de arte con IA según el plan |

## Dibuja un código artístico [#draw-an-art-code]

Pasa una prop `art` con un modo, una imagen muestreada y una intensidad opcional:

```tsx title="components/logo-art-code.tsx"
import { loadQRArtImage, type QRArtImage, QRCode } from "qrdx";

// Browser: sample an uploaded file, a data URL or an <img>
export async function sampleLogo(file: File): Promise<QRArtImage> {
  return await loadQRArtImage(file, { mode: "logo" });
}

export function LogoArtCode({ image }: { image: QRArtImage }) {
  return (
    <QRCode
      value="https://example.com"
      size={512}
      level="H"
      art={{ mode: "logo", image, intensity: 0.7 }}
    />
  );
}
```

En el servidor o en Node, decodifica la imagen tú mismo y pasa los píxeles RGBA a `createQRArtImage`:

```ts title="lib/sample-photo.ts"
import { createQRArtImage } from "qrdx";
import sharp from "sharp";

const { data, info } = await sharp("photo.jpg")
  .ensureAlpha()
  .raw()
  .toBuffer({ resolveWithObject: true });

export const image = createQRArtImage(
  { data, width: info.width, height: info.height },
  { maxSize: 96, square: true }
);
// art={{ mode: "halftone", image, intensity: 0.8 }}
```

`art.image` es JSON simple (`{ width, height, data }` con RGBA en base64), así que puedes guardarlo junto con un diseño y renderizar el mismo código en cualquier lugar, de forma síncrona, sin volver a descargar la imagen.

| Opción | Valores | Notas |
| --- | --- | --- |
| `mode` | `logo`, `halftone` | `halftone` es Image QR en el editor |
| `image` | de `loadQRArtImage` o `createQRArtImage` | Como máximo 192 por 192 muestras. `loadQRArtImage` muestrea 160 de ancho por defecto |
| `intensity` | de `0` a `1` | Por defecto `0.6`; con `0` se ve como un código normal |
| `variant` | `blend`, `badge` (logo); `color`, `mono` (halftone) | El aspecto dentro del modo. `badge` coloca el logo trazado sobre una placa redondeada en el centro de un código teñido; `mono` es un medio tono en blanco y negro. El primer valor es el predeterminado de cada modo |
| `matchEyes` | `true`, `false` | Solo en modo logo: colorea los ojos de las esquinas a partir del logo (por defecto `true`). Los `eyeColors` de cada ojo siguen teniendo prioridad |

El arte reemplaza el patrón del cuerpo; los ojos de las esquinas conservan su `cornerEyePattern`, `cornerEyeDotPattern` y sus colores. El arte usa el primer color de un `fgColor` o `bgColor` con degradado, y necesita un primer plano oscuro sobre un fondo claro; con colores invertidos recurre a un aspecto normal. Usa `level="H"`, que le da al arte el mayor margen.

## Cómo se mantiene la capacidad de escaneo [#how-scannability-is-kept]

- **Logo QR**: los módulos oscuros dentro del logo se recolorean, pero solo se oscurecen hasta una luminancia que un escáner aún lee como oscura; los módulos claros dentro del logo reciben un tinte pálido que se mantiene por encima del umbral de claridad. Los módulos oscuros fuera del logo se atenúan a gris, nunca más claro que el umbral de oscuridad.
- **Placa de Logo QR (badge)**: cada módulo bajo la placa puede estropear una palabra de código. La placa tiene un tamaño tal que ningún bloque de corrección de errores pierde más del 60 % de las palabras de código que puede reparar, lo que deja el resto para la cámara. La intensidad hace crecer la placa hasta ese tamaño. Los códigos pequeños reciben un logo más pequeño, y los más pequeños (versión 1, versión 2 en L o M, versión 3 en L) no dibujan placa.
- **Image QR**: cada módulo se divide en una cuadrícula de 3 por 3. Las celdas exteriores muestran la foto, más oscura o más clara según el valor del módulo, y el centro conserva el color exacto de primer plano o de fondo, que es donde los escáneres toman la muestra.
- Los módulos de búsqueda, temporización, alineación, formato y versión siempre se dibujan sólidos.

Revisa cualquier diseño con `getScanScore(props)` antes de imprimir y pruébalo con la cámara de un teléfono real.

## Exporta códigos artísticos [#export-art-codes]

Los códigos artísticos son formas vectoriales, así que cada exportación los mantiene nítidos:

```ts title="lib/export-art.ts"
import { downloadQRCode, getQRAsEPS, getQRAsPrintPDF } from "qrdx";

await downloadQRCode(props, { format: "svg", size: { width: 1024, height: 1024 } });
const pdf = await getQRAsPrintPDF(props, { size: 40, unit: "mm", colorMode: "cmyk" });
const eps = await getQRAsEPS(props, { sizeMm: 40, bleedMm: 3, colorMode: "cmyk" });
```

`getQRAsEPS` escribe un archivo EPSF-3.0 con un `%%BoundingBox` en puntos y cada módulo, ojo y marco como una ruta PostScript. Igual que el PDF de impresión, conserva los degradados lineales y radiales (como sombreados de PostScript Level 3) y no tiene transparencia. Los logos PNG y JPEG se incrustan como imágenes; otros formatos de logo se convierten en el navegador y se omiten en el servidor. El texto del marco usa Helvetica, así que los caracteres fuera de Latin-1 se imprimen como `?`. `svgToEPS(svg, { width })` convierte cualquier SVG que renderice esta biblioteca. La CLI también escribe EPS: `qrdx generate "https://example.com" -o qr.eps`.

<IfAvailable feature="aiArt" id="ai-art" title="Arte con IA">

[El arte QR con IA](/ai/art) convierte tu código en una escena con {facts.artModel}, a través de Vercel AI Gateway. Obtienes {facts.aiArtStyles} estilos predefinidos para explorar por categoría o buscar, cada uno con una vista previa que pasó la verificación de escaneo, cosas que evitar, un control deslizante de **visibilidad del QR** (cuánto favorece el modelo al código), un control deslizante de **creatividad** (con qué libertad interpreta tu prompt), de 1 a 4 variaciones por ejecución y una imagen de referencia opcional, como un logo o una paleta, cuyos colores y formas se trasladan.

Cada imagen se comprueba en el servidor antes de que la veas. QRdx envía al modelo un código simple en blanco y negro (corrección de errores H, módulos cuadrados, una zona de silencio amplia) y le pide que conserve la cuadrícula de módulos, los ojos de búsqueda y la zona de silencio. Luego decodifica la imagen del modelo con jsQR, tal cual y a través de un modelo de cámara de teléfono. Si falla, localiza la cuadrícula de módulos donde el modelo la dibujó y refuerza el código sobre la propia imagen del modelo lo menos posible: primero los ojos de búsqueda y la zona de silencio, después los módulos, aumentando la intensidad paso a paso hasta que la imagen se escanee, también cuando el código se ve más pequeño en la cámara. La visibilidad del QR fija hasta dónde puede llegar. Solo si eso no basta, redibuja la imagen como un código Image QR. Una imagen que aun así no se decodifica con tu contenido exacto no se entrega. Después tu navegador puntúa las variaciones y elige la mejor; descárgala a 1024 px o como copia de impresión de 2048 px (remuestreada y verificada de nuevo).

Cada imagen entregada usa una de las imágenes de arte con IA mensuales del plan: las cuentas Gratis reciben 3 al mes, Pro 30 y Business 150 compartidas por todos en el espacio de trabajo. Las imágenes que fallan o no pasan la verificación de escaneo no consumen ninguna, y la copia de impresión es gratuita. El arte con IA es una imagen rasterizada y su contenido es fijo, así que, para tener un enlace editable, coloca en ella el enlace corto de un [código dinámico](/docs/dynamic-qr-codes). Los desarrolladores pueden generarla desde la [API de arte con IA](/docs/developers/ai-art-api).
