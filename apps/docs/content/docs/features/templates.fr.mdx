Un modèle est un cadre qui place le code à l'intérieur d'un visuel de taille fixe. Passez son identifiant dans `templateId` et le composant dessine tout le visuel à `size`, avec le code plus petit à l'intérieur. Cette page liste les modèles intégrés, les options de Dot Ring et la façon de dessiner un modèle en code.

Vous concevez plutôt dans le Playground ou le tableau de bord ? Les modèles sont des vignettes du groupe **Classique** du sélecteur de cadres ; voir [Ajouter un cadre et un appel à l'action](/docs/help/designing/frames) dans l'aide.

Les modèles se distinguent des autres [cadres](/docs/features/frames) sur un point : la taille. Un cadre ajoute de l'espace autour du code, donc `size` correspond à la largeur du code et l'image s'agrandit. Un modèle dessine tout son visuel à `size`, avec le code plus petit à l'intérieur.

## Modèles intégrés [#built-in-templates]

| `templateId` | Nom | Couleur |
| --- | --- | --- |
| `Arrow` | Arrow | La couleur sombre du code (`fgColor`) |
| `StandardBox` | Standard Box | `fgColor` |
| `SquareBorder` | Square Border | `fgColor` |
| `StrikedBox` | Striked Box | Sa propre couleur sombre |
| `Halloween` | Halloween | Son propre orange, vert et noir |
| `DotRing` | Dot Ring | Anneau en `fgColor`, texte en blanc ; les deux peuvent changer (ci-dessous) |

`default` ne dessine aucun visuel. Il se contente de réduire un peu le code, à 95 % de `size`. Sans `templateId`, le code occupe tout `size`.

```tsx title="components/arrow-code.tsx"
import { QRCode } from "qrdx";

export function ArrowCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      templateId="Arrow"
      fgColor="#1a56db"
    />
  );
}
```

<Shot id="lib-templates" />

Les couleurs, les motifs et le logo restent dans les propriétés du code, donc un modèle fonctionne avec n'importe quel style :

```tsx title="components/boxed-logo-code.tsx"
import { QRCode } from "qrdx";

export function BoxedLogoCode() {
  return (
    <QRCode
      value="https://example.com"
      size={512}
      templateId="StandardBox"
      fgColor="#1a56db"
      level="H"
      logo="/logo.png"
    />
  );
}
```

L'Image API accepte un modèle via `template` et la CLI via `--template`.

## Dot Ring [#dot-ring]

Un code rond. Le code est placé dans un disque de points à l'intérieur d'un anneau sombre, avec une ligne de texte courant le long de l'anneau. Les points affichés dépendent d'un hash du contenu du code : chaque lien obtient donc son propre anneau, et un même lien obtient toujours le même.

```tsx title="components/dot-ring-code.tsx"
import { QRCode } from "qrdx";

export function DotRingCode() {
  return (
    <QRCode
      value="https://example.com"
      size={512}
      templateId="DotRing"
      bodyPattern="circle-large"
      customProps={{
        customText: "Scan for the menu",
        textPosition: "bottom",
        textColor: "#fde047",
        outerCircleColor: "#1e3a8a",
      }}
    />
  );
}
```

Ses réglages vont dans `customProps`, typé `DotRingProps` :

| Propriété | Valeur par défaut | Notes |
| --- | --- | --- |
| `customText` | « Scan the QR code * » quatre fois autour | Texte le long de l'anneau ; `""` laisse l'anneau vide. Un texte trop long pour l'anneau est ajusté (ci-dessous) |
| `textFill` | `"none"` | `"repeat"` répète le texte sur tout l'anneau (ci-dessous) |
| `textPosition` | `"top"` | `"top"` : centré en haut, lu dans le sens horaire. `"bottom"` : centré en bas, lu de gauche à droite |
| `textRotation` | `0` | Fait tourner le texte autour du centre, en degrés dans le sens horaire |
| `textColor` | `#ffffff` | Couleur du texte |
| `fontFamily` | pile de polices système | Famille de police CSS du texte |
| `fontWeight` | `900` | Graisse de la police |
| `fontSize` | `32` | Dans le dessin du modèle de 593 unités, où le code mesure 300 de large. Un texte long peut être dessiné plus petit |
| `fontLetterSpacing` | `3.5` | Espace supplémentaire entre les lettres, dans les mêmes unités. Un texte long et `textFill` l'ajustent |
| `outerCircleColor` | `fgColor` | Couleur de l'anneau |
| `strokeWidth`, `strokeColor` | `0`, `#000000` | Un contour le long des deux bords de l'anneau |
| `outerStrokeWidth`, `outerStrokeColor` | `strokeWidth`, `strokeColor` | Bord extérieur de l'anneau uniquement |
| `innerStrokeWidth`, `innerStrokeColor` | `strokeWidth`, `strokeColor` | Bord intérieur de l'anneau uniquement |

Un texte qui tient dans l'anneau est posé tel quel, centré en haut ou en bas. Un texte trop long ne déborde jamais sur son propre début : les lettres se rapprochent d'abord, puis la police diminue, jusqu'à la moitié de la taille par défaut. Le texte referme alors l'anneau avec une espace entre mots là où il rejoint son début. S'il ne tient toujours pas, un texte qui répète une phrase garde autant de copies entières que possible, et tout autre texte est coupé après le dernier mot entier qui tient et se termine par des points de suspension.

Un logo se place au centre, comme sur n'importe quel code. Les longs liens (codes de plus de 49 modules de large) gardent une bande claire entre le code et les points, pour rester scannables une fois imprimés en petit.

Le texte est du texte SVG dans la police que vous choisissez ; par défaut, c'est la pile de polices système, donc rien n'est téléchargé. Les téléchargements SVG et PNG dans le navigateur utilisent les polices du visiteur. PDF et EPS l'impriment en Helvetica Bold, utilisez donc du texte Latin-1 dans ce cas. `getQRAsPNG` de `qrdx/node` nécessite une police installée sur le serveur, comme les libellés de cadre.

### Remplir l'anneau [#fill-the-ring]

Une phrase courte laisse une partie de l'anneau vide. Définissez `textFill: "repeat"` pour la répéter autant de fois qu'elle tient, avec un espacement uniformisé pour que l'anneau se referme avec le même écart qu'entre les copies :

```tsx title="components/docs-ring-code.tsx"
import { QRCode } from "qrdx";

export function DocsRingCode() {
  return (
    <QRCode
      value="https://example.com/docs"
      size={512}
      templateId="DotRing"
      customProps={{ customText: "Read the docs *", textFill: "repeat" }}
    />
  );
}
```

Donnez la phrase une seule fois. Un texte qui répète déjà une phrase, comme `"Make your own * Make your own *"`, est interprété comme cette phrase et remplit donc l'anneau de la même manière.

## Les modèles sont des spécifications de cadre [#templates-are-frame-specs]

Le visuel de Arrow, Standard Box, Square Border, Striked Box et Halloween est une [spécification de cadre](/docs/features/frames#frame-specs), au même format JSON que tous les autres cadres, dessinée par le même moteur. `getTemplate(id).spec` la renvoie. Utilisez-la comme cadre quand vous voulez le dimensionnement des cadres (le code garde sa taille et le visuel grandit autour) et l'option de couleur du cadre :

```tsx title="components/arrow-frame-code.tsx"
import { getTemplate, QRCode } from "qrdx";

const spec = getTemplate("Arrow")?.spec;

export function ArrowFrameCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      frame={spec && { style: "custom", spec, color: "#1a56db" }}
    />
  );
}
```

Dot Ring n'a pas de spécification : ses points dépendent du contenu du code, il les dessine donc en code (voir [Dessiner un modèle en code](#draw-a-template-in-code)).

`templateId` dessine le même visuel qu'avant. Les designs enregistrés, les URL d'image, les commandes CLI et le code qui utilisent un identifiant de modèle donnent le même rendu qu'auparavant.

## Registre des modèles [#template-registry]

```ts title="lib/templates.ts"
import { getAllTemplates, getTemplate, getTemplateIds } from "qrdx";

getTemplateIds(); // ["default", "Arrow", "StandardBox", "SquareBorder", "StrikedBox", "Halloween", "DotRing"]
getAllTemplates(); // every TemplateDefinition, with its id and name
getTemplate("Halloween"); // one by id, or undefined
```

## Dessiner un modèle en code [#draw-a-template-in-code]

Une spécification de cadre décrit un visuel fixe. Quand le visuel doit être calculé, écrivez une `TemplateDefinition` et passez-la dans `customTemplate`. Son `wrapper` reçoit le code en `children` et renvoie le SVG à dessiner. Il dessine sur un canevas de 300 sur 300, et le code arrive lui aussi à cette taille : réduisez-le pour laisser de la place à votre visuel. `props` contient les `fgColor` et `bgColor` du code, et le troisième argument contient l'`url` et la `pixelSize` du code.

Cet exemple dessine un anneau autour du code :

```tsx title="components/ring-template-code.tsx"
import { QRCode, type TemplateDefinition } from "qrdx";

const ringTemplate: TemplateDefinition = {
  id: "ring",
  name: "Ring",
  wrapper: (children, props) => (
    <svg
      viewBox="0 0 300 300"
      width="300"
      height="300"
      xmlns="http://www.w3.org/2000/svg"
    >
      <circle
        cx="150"
        cy="150"
        r="140"
        fill="none"
        stroke={props?.fgColor ?? "#000000"}
        strokeWidth="8"
      />
      {/* The code at half size, centered */}
      <g transform="translate(75, 75) scale(0.5)">{children}</g>
    </svg>
  ),
};

export function RingTemplateCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      customTemplate={ringTemplate}
      fgColor="#1a56db"
    />
  );
}
```

`customTemplate` l'emporte sur `templateId` quand les deux sont définis. Gardez le code assez grand pour être scanné à la distance où les gens tiendront leur téléphone, et laissez un espace clair entre lui et votre visuel. Vérifiez le résultat avec le [score de scan](/docs/features/frames#will-it-scan). Sans JSX, écrivez le wrapper avec `h` de `qrdx/core` ; voir [JavaScript natif](/docs/vanilla-js#custom-templates-without-jsx).
