La prop `art` intègre un logo ou une photo dans les modules d'un code, sous forme de formes vectorielles et sans IA : Logo QR recolore les modules situés dans la forme de votre logo, et Image QR laisse apparaître votre photo à travers chaque module. Les deux sont dessinés par la bibliothèque elle-même : ils fonctionnent donc hors ligne, côté serveur et dans Node, et le résultat reste toujours un vrai QR code. Cette page présente la prop, la façon dont l'image est échantillonnée et la manière dont la lisibilité au scan est préservée.

Vous concevez dans le Playground ou dans le tableau de bord ? Consultez [Intégrer un logo ou une photo dans le code](/docs/help/designing/art) dans l'aide.

QRdx propose trois façons de transformer un code en œuvre graphique :

| | Fonctionnement | Sortie | Coût |
| --- | --- | --- | --- |
| **Logo QR** (`mode: "logo"`) | Les modules situés dans la forme de votre logo prennent ses couleurs ; les autres s'estompent vers un ton plus clair | Vectoriel (SVG, PDF, EPS, PNG) | Gratuit |
| **Image QR** (`mode: "halftone"`) | Chaque module montre votre photo autour d'un carré central qui conserve la vraie valeur | Vectoriel (SVG, PDF, EPS, PNG) | Gratuit |
| **Art IA** | Un modèle d'image IA redessine le code sous forme de scène, et chaque image est vérifiée pour être lisible au scan | Image de 1024 px, copie d'impression de 2048 px | Images d'art IA selon le forfait |

## Dessiner un code artistique [#draw-an-art-code]

Passez une prop `art` avec un mode, une image échantillonnée et une intensité facultative :

```tsx title="components/logo-art-code.tsx"
import { loadQRArtImage, type QRArtImage, QRCode } from "qrdx";

// Browser: sample an uploaded file, a data URL or an <img>
export async function sampleLogo(file: File): Promise<QRArtImage> {
  return await loadQRArtImage(file, { mode: "logo" });
}

export function LogoArtCode({ image }: { image: QRArtImage }) {
  return (
    <QRCode
      value="https://example.com"
      size={512}
      level="H"
      art={{ mode: "logo", image, intensity: 0.7 }}
    />
  );
}
```

Côté serveur ou dans Node, décodez l'image vous-même et passez les pixels RGBA à `createQRArtImage` :

```ts title="lib/sample-photo.ts"
import { createQRArtImage } from "qrdx";
import sharp from "sharp";

const { data, info } = await sharp("photo.jpg")
  .ensureAlpha()
  .raw()
  .toBuffer({ resolveWithObject: true });

export const image = createQRArtImage(
  { data, width: info.width, height: info.height },
  { maxSize: 96, square: true }
);
// art={{ mode: "halftone", image, intensity: 0.8 }}
```

`art.image` est du JSON simple (`{ width, height, data }` avec RGBA en base64) : vous pouvez donc le stocker avec un design enregistré et afficher le même code n'importe où, de façon synchrone, sans récupérer à nouveau l'image.

| Option | Valeurs | Notes |
| --- | --- | --- |
| `mode` | `logo`, `halftone` | `halftone` correspond à Image QR dans l'éditeur |
| `image` | issue de `loadQRArtImage` ou `createQRArtImage` | 192 par 192 échantillons au maximum. `loadQRArtImage` échantillonne par défaut sur 160 de large |
| `intensity` | `0` à `1` | `0.6` par défaut ; `0` donne l'aspect d'un code ordinaire |
| `variant` | `blend`, `badge` (logo) ; `color`, `mono` (halftone) | L'aspect au sein du mode. `badge` place le logo vectorisé sur une plaque arrondie au centre d'un code teinté ; `mono` est une trame noir et blanc. La première valeur est celle par défaut de chaque mode |
| `matchEyes` | `true`, `false` | Mode logo uniquement : colore les yeux d'angle à partir du logo (`true` par défaut). Les `eyeColors` propres à chaque œil restent prioritaires |

L'art remplace le motif du corps ; les yeux d'angle conservent leur `cornerEyePattern`, leur `cornerEyeDotPattern` et leurs couleurs. L'art utilise la première couleur d'un dégradé `fgColor` ou `bgColor`, et exige un premier plan sombre sur un fond clair ; avec des couleurs inversées, il revient à un aspect ordinaire. Utilisez `level="H"`, qui laisse le plus de place à l'art.

## Comment la lisibilité au scan est préservée [#how-scannability-is-kept]

- **Logo QR** : les modules sombres situés dans le logo sont recolorés, mais uniquement assombris jusqu'à une luminance qu'un lecteur interprète encore comme sombre ; les modules clairs situés dans le logo reçoivent une teinte pâle qui reste au-dessus du seuil de clarté. Les modules sombres hors du logo s'estompent en gris, sans jamais être plus clairs que le seuil de sombre.
- **Badge Logo QR** : chaque module sous la plaque peut compromettre un mot de code. La plaque est dimensionnée de sorte qu'aucun bloc de correction d'erreurs ne perde plus de 60 % des mots de code qu'il peut réparer, ce qui laisse le reste à la caméra. L'intensité agrandit la plaque jusqu'à cette taille. Les petits codes reçoivent un logo plus petit, et les plus petits (version 1, version 2 en L ou M, version 3 en L) ne dessinent aucune plaque.
- **Image QR** : chaque module est découpé en grille de 3 par 3. Les cellules extérieures montrent la photo, assombrie ou éclaircie pour correspondre à la valeur du module, et le centre conserve exactement la couleur de premier plan ou de fond, c'est-à-dire là où les lecteurs échantillonnent.
- Les modules de repérage, de synchronisation, d'alignement, de format et de version sont toujours dessinés en aplat.

Vérifiez chaque design avec `getScanScore(props)` avant l'impression, et testez-le avec l'appareil photo d'un vrai téléphone.

## Exporter les codes artistiques [#export-art-codes]

Les codes artistiques sont des formes vectorielles : chaque export les garde nets :

```ts title="lib/export-art.ts"
import { downloadQRCode, getQRAsEPS, getQRAsPrintPDF } from "qrdx";

await downloadQRCode(props, { format: "svg", size: { width: 1024, height: 1024 } });
const pdf = await getQRAsPrintPDF(props, { size: 40, unit: "mm", colorMode: "cmyk" });
const eps = await getQRAsEPS(props, { sizeMm: 40, bleedMm: 3, colorMode: "cmyk" });
```

`getQRAsEPS` écrit un fichier EPSF-3.0 avec un `%%BoundingBox` en points, où chaque module, œil et cadre est un tracé PostScript. Comme le PDF d'impression, il conserve les dégradés linéaires et radiaux (sous forme de dégradés PostScript Level 3) et n'a aucune transparence. Les logos PNG et JPEG sont intégrés comme images ; les autres formats de logo sont convertis dans le navigateur et omis côté serveur. Le texte du cadre utilise Helvetica : les caractères hors Latin-1 s'impriment donc sous forme de `?`. `svgToEPS(svg, { width })` convertit n'importe quel SVG rendu par cette bibliothèque. La CLI écrit aussi de l'EPS : `qrdx generate "https://example.com" -o qr.eps`.

<IfAvailable feature="aiArt" id="ai-art" title="Art IA">

[L'art QR par IA](/ai/art) transforme votre code en scène avec {facts.artModel}, via Vercel AI Gateway. Vous disposez de {facts.aiArtStyles} styles prédéfinis à parcourir par catégorie ou à rechercher, chacun avec un aperçu ayant passé la vérification du scan, des éléments à éviter, un curseur **Visibilité du QR** (à quel point le modèle favorise le code), un curseur **créativité** (avec quelle liberté il interprète votre prompt), 1 à 4 variations par génération et une image de référence facultative, comme un logo ou une palette, dont les couleurs et les formes sont reprises.

Chaque image est vérifiée sur le serveur avant que vous la voyiez. QRdx envoie au modèle un code noir et blanc simple (correction d'erreurs H, modules carrés, large zone de silence) et lui demande de conserver la grille de modules, les yeux de repérage et la zone de silence. Il décode ensuite l'image du modèle avec jsQR, telle quelle puis à travers un modèle de caméra de téléphone. En cas d'échec, il retrouve la grille de modules là où le modèle l'a dessinée et renforce le code sur l'image même du modèle aussi peu que possible : d'abord les yeux de repérage et la zone de silence, puis les modules, en augmentant la force par paliers jusqu'à ce que l'image soit lisible, y compris quand le code est plus petit dans le champ de la caméra. La visibilité du QR fixe jusqu'où il peut aller. Ce n'est que si cela ne suffit pas qu'il redessine l'image sous forme de QR code Image QR. Une image qui ne se décode toujours pas en votre contenu exact n'est pas livrée. Votre navigateur note ensuite les variations et choisit la meilleure ; téléchargez-la en 1024 px ou en copie d'impression de 2048 px (rééchantillonnée et revérifiée).

Chaque image livrée consomme l'une des images d'art IA mensuelles du forfait : les comptes Gratuit en ont 3 par mois, Pro 30, et Business 150 partagées par tous les membres de l'espace de travail. Les images en échec ou qui ne passent pas la vérification du scan n'en consomment aucune, et la copie d'impression est gratuite. L'art IA est une image matricielle dont le contenu est figé : pour un lien modifiable, placez-y le lien court d'un [QR code dynamique](/docs/dynamic-qr-codes). Les développeurs peuvent le générer depuis l'[API d'art IA](/docs/developers/ai-art-api).
