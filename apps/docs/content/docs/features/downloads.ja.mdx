`downloadQRCode(props, options)` は、`props` で記述したコードをブラウザー上で6種類の形式のいずれかのファイルとして保存します。関連する関数は、同じファイルをデータURL、Blob、マークアップとして返します。また、`qrdx/node` はサーバー上で PNG を生成します。どの関数も `QRCode` と同じ `props` を受け取るため、ファイルは画面上のコードと一致します。

Playground やダッシュボードからダウンロードする場合は、ヘルプの [QRコードのダウンロードと印刷](/docs/help/getting-started/download-and-print)をご覧ください。

## ファイルをダウンロードする [#download-a-file]

```ts title="lib/download.ts"
import { downloadQRCode } from "qrdx";

await downloadQRCode(
  {
    value: "https://example.com",
    fgColor: "#1d4ed8",
    bodyPattern: "rounded",
    frame: { style: "banner-bottom", text: "Scan me" },
  },
  {
    format: "png",
    size: { width: 1024, height: 1024 },
    filename: "menu.png",
  }
);
```

<Shot id="lib-download-result" />

ブラウザーが `menu.png` を保存します。`size` はコード本体の縦横のピクセル数で、50から5000までの正方形です。フレームを付けると、ファイルはそれより大きくなります。`filename` は省略できます。省略した場合、ファイル名は `qr-code.<ext>` になり、ラスター形式ではピクセルサイズが正確に付加されます（`qr-code-1024x1024.png`、下部にバナーがある場合は `qr-code-1270x1454.png`）。`quality`（0から1）は WebP にのみ適用されます。

props は `QRCode` と同じですが、ロゴは `imageSettings` に指定します。`QRCode` が描画するコード（`logo` と `logoOptions` を含む）をエクスポートするには、元の props の代わりに `getQRData(props)` または `resolveQRCodeProps(props)` を渡します。

## 形式 [#formats]

| `format` | ファイル | 備考 |
| --- | --- | --- |
| `png` | 画像 | 透明な背景を保持します。ほとんどの用途でのデフォルトです |
| `jpg` | 画像 | 背景は単色のみで、ファイルは小さくなります |
| `webp` | 画像 | PNG と同じピクセルをより小さなファイルにします。`quality` を指定しない限りロスレスです |
| `svg` | ベクター | どんなサイズでも鮮明です。印刷所やデザインツール向けのファイルです |
| `pdf` | ドキュメント | コードを PNG として載せた1ページです。オプションの `jspdf` パッケージが必要です |
| `eps` | ベクター | Illustrator、CorelDRAW、InDesign 向けの PostScript です。`size.width` はポイント（1インチあたり72）として扱われます |

### WebP [#webp]

WebP はデフォルトでロスレスなので、モジュールの端は正確なままで、透明な背景も透明のままです。ブラウザーの canvas がロスレス WebP を書き出せる場合（Chrome と Edge は対応しています）は、ブラウザーがファイルを作成します。書き出せない場合は、ライブラリーがバイト列を確認し、小さな組み込みのロスレスエンコーダーでピクセルを自らエンコードします。Safari は WebP を要求されると PNG を返します。いずれの場合も、`.webp` ファイルは必ず WebP です。

`quality`（0から1）を指定すると、ブラウザーが対応していれば、代わりにより小さな非可逆ファイルを要求します。非可逆 WebP はモジュールの端や色をぼかすため、遠くからスキャンするコードにはデフォルトのままにしてください。`getQRAsWebP` はファイルを `Blob` として返します。

```ts title="lib/webp.ts"
import { getQRAsWebP } from "qrdx";

const lossless = await getQRAsWebP({ value: "https://example.com", size: 1024 });
const lossy = await getQRAsWebP({ value: "https://example.com", size: 1024 }, { quality: 0.9 });
```

`canvasToWebP(canvas, options)` は任意の canvas に対して同じ処理を行い、`encodeWebPLossless(rgba, width, height)` は DOM を使わずに RGBA ピクセルをエンコードします。

### PDF [#pdf]

PDF のダウンロードでは、同じサイズのページにコードを PNG として載せます。オプションの `jspdf` パッケージ（`npm install jspdf`）が必要です。インストールされていない場合、PDF のダウンロードは `PDF export needs the optional "jspdf" package` をスローします。実寸のベクター PDF、塗り足し、トンボ、CMYK が必要な場合は `downloadPrintPDF` を使用してください。詳しくは[印刷用エクスポート](/docs/features/frames#print-ready-export)をご覧ください。

### EPS [#eps]

EPS に追加のパッケージは不要です。`downloadQRCode` は `size.width` をポイントとして扱うため、512 px を指定すると 512 pt（18 cm）のファイルが書き出されます。正確な実寸が必要な場合は、EPS を文字列として返す `getQRAsEPS` を使用してください。コードの幅は `sizeMm`（デフォルトは 50 mm）で、フレームを付けるとその分が加わります。

```ts title="lib/eps.ts"
import { downloadPrintEPS, getQRAsEPS } from "qrdx";

const eps = await getQRAsEPS(
  { value: "https://example.com" },
  { sizeMm: 40, bleedMm: 3, colorMode: "cmyk" }
);

await downloadPrintEPS({ value: "https://example.com" }, { sizeMm: 40, filename: "menu.eps" });
```

EPS には透明度もトンボもありません。線形グラデーションと放射状グラデーションは、滑らかな PostScript Level 3 のシェーディングとして出力され、角度グラデーションは細い楔形を扇状に並べて出力されます。透過する色は背景と混合され、背景は白い用紙と混合されます。PNG と JPEG のロゴは埋め込まれます。EPS は[画像フィル](/docs/features/colors-gradients#image-fills)を扱えません。`getQRAsEPS` は `EPS_IMAGE_FILL_REASON` をスローし、ダッシュボードのダウンロードダイアログでは代わりに PDF、SVG、PNG が提示されます。

## データURL、Blob、マークアップ [#data-urls-blobs-and-markup]

```ts title="lib/export.ts"
import { copyQRCodeToClipboard, getQRCodeDataUrl, getSVGString } from "qrdx";

const props = { value: "https://example.com", size: 512 };

// The same file as a data URL, for an <img> or a form field
const png = await getQRCodeDataUrl(props, "png", { width: 512, height: 512 });

// A PNG on the clipboard, for pasting into a document
await copyQRCodeToClipboard(props, { width: 512, height: 512 });

// The SVG markup, for inlining in a page or an email template
const svg = await getSVGString(props);
```

- `getQRCodeDataUrl(props, format, size, { quality })` は、`downloadQRCode` が扱うすべての形式を受け付けます。
- `copyQRCodeToClipboard` は PNG を書き込みます。クリックハンドラーから呼び出してください。ブラウザーは、ユーザー操作の外でのクリップボードへの書き込みを拒否します。
- `getSVGString` はロゴをデータURLとして埋め込むため、マークアップは単体で完結します。`qrdx/core` の `toSVGString` は、この処理を省いた同期版です。

## プリセットサイズ [#preset-sizes]

```ts title="lib/sizes.ts"
import { PRESET_SIZES, validateSize } from "qrdx";

PRESET_SIZES.small; // { width: 200, height: 200 }
PRESET_SIZES.medium; // 400
PRESET_SIZES.large; // 800
PRESET_SIZES.xlarge; // 1200
PRESET_SIZES["2xl"]; // 1600
PRESET_SIZES["3xl"]; // 2000

validateSize(4000, 4000); // { isValid: true }
validateSize(6000, 6000); // { isValid: false, error: "Size must not exceed 5000x5000 pixels" }
```

ファイルの用途に合わせてサイズを選んでください。Webページなら 256 から 512 px、300 ppi での印刷なら 1024 px 以上です（1024 px は幅約 8.7 cm までシャープに印刷できます）。正確な印刷サイズには、ミリメートルとインチで指定する印刷用の関数を使用してください。

## Node での PNG [#png-in-node]

`qrdx/node` の `getQRAsPNG` は、ブラウザーなしで PNG のバイト列を返します。`qrdx` と並べて、オプションのラスタライザーを1つインストールする必要があります。`@resvg/resvg-js` はロゴを含めてブラウザーと同じように SVG を描画し、`sharp` も使用できます。

```ts title="scripts/make-png.ts"
import { writeFile } from "node:fs/promises";
import { getQRAsPNG } from "qrdx/node";

const png = await getQRAsPNG(
  { value: "https://example.com", bodyPattern: "rounded", margin: 4 },
  { size: 1024 }
);
await writeFile("qr-code.png", png);
```

`qrdx` からではなく、必ず `qrdx/node` からインポートしてください。これにより、ブラウザー向けバンドルにネイティブモジュールが含まれません。データURLのロゴはそのまま埋め込まれます。`http(s)` のURLやローカルパスは `loadExternalLogos: true` を指定した場合にのみ読み込まれるため、呼び出し元の設定をそのまま渡すサーバーが、内部URLの取得やディスクの読み取りを強いられることはありません。SVGマークアップにラスタライザーは不要で、`qrdx/core` の `toSVGString` はどこでも実行できます。

## うまくいかない場合 [#if-something-goes-wrong]

- **`Size must be at least 50x50 pixels`、`Size must not exceed 5000x5000 pixels`、または `Width and height must be equal for QR codes`。** `validateSize` がサイズを拒否しました。範囲内の正方形のサイズを渡してください。
- **`PDF export needs the optional "jspdf" package`。** `qrdx` と同じパッケージに `jspdf` をインストールしてください。
- **ファイルにロゴが含まれていない。** 画像が CORS ヘッダーのない別のオリジンから提供されているため、ブラウザーがコピーできませんでした。自分のオリジンから配信するか、データURLを渡してください。
- **`copyQRCodeToClipboard` が拒否される。** クリックまたはキー操作のハンドラーの外で実行されたか、ページが HTTPS で配信されていません。ハンドラー内から直接呼び出してください。
- **`getQRAsPNG` がラスタライザーの不足に関するエラーをスローする。** `qrdx` と並べて `@resvg/resvg-js` または `sharp` をインストールしてください。
