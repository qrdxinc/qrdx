टेम्पलेट एक फ़्रेम होता है, जो कोड को तय साइज़ की आर्टवर्क के अंदर फ़िट करता है। इसकी id को `templateId` के रूप में दें, तो कॉम्पोनेंट पूरी आर्टवर्क `size` पर बनाता है और कोड उसके अंदर छोटा रहता है। इस पेज पर बिल्ट-इन टेम्पलेट, Dot Ring के विकल्प और कोड में टेम्पलेट बनाने का तरीका दिया गया है।

Playground या डैशबोर्ड में डिज़ाइन कर रहे हैं? टेम्पलेट फ़्रेम पिकर के **Classic** ग्रुप में टाइल के रूप में दिखते हैं; Help में [फ़्रेम और कॉल टू एक्शन जोड़ें](/docs/help/designing/frames) देखें।

टेम्पलेट दूसरे [फ़्रेम](/docs/features/frames) से एक बात में अलग हैं: साइज़। फ़्रेम कोड के चारों ओर जगह जोड़ता है, इसलिए `size` कोड की चौड़ाई होती है और इमेज बड़ी हो जाती है। टेम्पलेट पूरी आर्टवर्क `size` पर बनाता है, और कोड उसके अंदर छोटा रहता है।

## बिल्ट-इन टेम्पलेट [#built-in-templates]

| `templateId` | नाम | रंग |
| --- | --- | --- |
| `Arrow` | Arrow | कोड का गहरा रंग (`fgColor`) |
| `StandardBox` | Standard Box | `fgColor` |
| `SquareBorder` | Square Border | `fgColor` |
| `StrikedBox` | Striked Box | अपना गहरा रंग |
| `Halloween` | Halloween | अपना नारंगी, हरा और काला रंग |
| `DotRing` | Dot Ring | रिंग `fgColor` में, टेक्स्ट सफ़ेद में; दोनों बदले जा सकते हैं (नीचे देखें) |

`default` कोई आर्टवर्क नहीं बनाता। यह बस कोड को थोड़ा अंदर करता है, `size` के 95% तक। `templateId` के बिना कोड पूरे `size` में आता है।

```tsx title="components/arrow-code.tsx"
import { QRCode } from "qrdx";

export function ArrowCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      templateId="Arrow"
      fgColor="#1a56db"
    />
  );
}
```

<Shot id="lib-templates" />

रंग, पैटर्न और लोगो कोड के अपने props में ही रहते हैं, इसलिए टेम्पलेट किसी भी स्टाइल के साथ चलता है:

```tsx title="components/boxed-logo-code.tsx"
import { QRCode } from "qrdx";

export function BoxedLogoCode() {
  return (
    <QRCode
      value="https://example.com"
      size={512}
      templateId="StandardBox"
      fgColor="#1a56db"
      level="H"
      logo="/logo.png"
    />
  );
}
```

image API में टेम्पलेट `template` के रूप में और CLI में `--template` के रूप में दिया जाता है।

## Dot Ring [#dot-ring]

एक गोल कोड। कोड डॉट्स की एक डिस्क में बैठता है, जो गहरी रिंग के अंदर होती है, और रिंग के साथ-साथ टेक्स्ट की एक लाइन लिखी जाती है। कौन-से डॉट्स दिखें, यह कोड के कंटेंट के हैश से तय होता है, इसलिए हर link की अपनी अलग रिंग बनती है और एक ही link को हमेशा वही रिंग मिलती है।

```tsx title="components/dot-ring-code.tsx"
import { QRCode } from "qrdx";

export function DotRingCode() {
  return (
    <QRCode
      value="https://example.com"
      size={512}
      templateId="DotRing"
      bodyPattern="circle-large"
      customProps={{
        customText: "Scan for the menu",
        textPosition: "bottom",
        textColor: "#fde047",
        outerCircleColor: "#1e3a8a",
      }}
    />
  );
}
```

इसकी सेटिंग `customProps` में जाती हैं, जिसका टाइप `DotRingProps` है:

| Prop | डिफ़ॉल्ट | नोट्स |
| --- | --- | --- |
| `customText` | "Scan the QR code *" रिंग में चार बार | रिंग के साथ चलने वाला टेक्स्ट; `""` देने पर रिंग खाली रहती है। रिंग के लिए बहुत लंबा टेक्स्ट फ़िट कर दिया जाता है (नीचे देखें) |
| `textFill` | `"none"` | `"repeat"` टेक्स्ट को पूरी रिंग में दोहराता है (नीचे देखें) |
| `textPosition` | `"top"` | `"top"`: ऊपर बीच में, घड़ी की दिशा में पढ़ा जाता है। `"bottom"`: नीचे बीच में, बाएँ से दाएँ पढ़ा जाता है |
| `textRotation` | `0` | टेक्स्ट को केंद्र के चारों ओर, घड़ी की दिशा में डिग्री में घुमाता है |
| `textColor` | `#ffffff` | टेक्स्ट का रंग |
| `fontFamily` | सिस्टम फ़ॉन्ट स्टैक | टेक्स्ट का CSS फ़ॉन्ट फ़ैमिली |
| `fontWeight` | `900` | फ़ॉन्ट वेट |
| `fontSize` | `32` | टेम्पलेट की 593-यूनिट ड्रॉइंग में, जहाँ कोड 300 चौड़ा है। लंबा टेक्स्ट छोटा बनाया जा सकता है |
| `fontLetterSpacing` | `3.5` | अक्षरों के बीच अतिरिक्त जगह, उन्हीं यूनिट में। लंबा टेक्स्ट और `textFill` इसे एडजस्ट करते हैं |
| `outerCircleColor` | `fgColor` | रिंग का रंग |
| `strokeWidth`, `strokeColor` | `0`, `#000000` | रिंग के दोनों किनारों पर स्ट्रोक |
| `outerStrokeWidth`, `outerStrokeColor` | `strokeWidth`, `strokeColor` | सिर्फ़ रिंग का बाहरी किनारा |
| `innerStrokeWidth`, `innerStrokeColor` | `strokeWidth`, `strokeColor` | सिर्फ़ रिंग का भीतरी किनारा |

जो टेक्स्ट रिंग में समा जाता है, वह जैसा दिया गया हो वैसा ही ऊपर बीच में या नीचे के साथ लिखा जाता है। जो टेक्स्ट बहुत लंबा हो, वह कभी अपनी ही शुरुआत से नहीं टकराता: पहले अक्षर पास किए जाते हैं, फिर फ़ॉन्ट छोटा किया जाता है, डिफ़ॉल्ट साइज़ के आधे तक। इसके बाद टेक्स्ट जहाँ अपनी शुरुआत से मिलता है, वहाँ एक शब्द-जितनी जगह छोड़कर रिंग को बंद करता है। फिर भी न समाए, तो जो टेक्स्ट कोई वाक्यांश दोहराता है उसकी जितनी पूरी कॉपियाँ समा सकें उतनी रखी जाती हैं, और दूसरा टेक्स्ट आख़िरी पूरे शब्द के बाद काट दिया जाता है, जो समा सके, और अंत में ellipsis लगता है।

लोगो किसी भी कोड की तरह बीच में जाता है। लंबे link (49 मॉड्यूल से ज़्यादा चौड़े कोड) में कोड और डॉट्स के बीच हल्की पट्टी रहती है, ताकि छोटा प्रिंट होने पर भी वे स्कैन हो सकें।

टेक्स्ट आपके चुने फ़ॉन्ट में SVG टेक्स्ट होता है; डिफ़ॉल्ट सिस्टम फ़ॉन्ट स्टैक है, इसलिए कुछ डाउनलोड नहीं होता। ब्राउज़र में SVG और PNG डाउनलोड देखने वाले के फ़ॉन्ट इस्तेमाल करते हैं। PDF और EPS इसे Helvetica Bold में प्रिंट करते हैं, इसलिए वहाँ Latin-1 टेक्स्ट इस्तेमाल करें। `qrdx/node` के `getQRAsPNG` को सर्वर पर इंस्टॉल किया हुआ फ़ॉन्ट चाहिए, जैसा फ़्रेम लेबल को चाहिए।

### रिंग भरें [#fill-the-ring]

छोटा वाक्यांश रिंग का कुछ हिस्सा खाली छोड़ देता है। `textFill: "repeat"` सेट करें, तो वह जितनी बार समा सके उतनी बार दोहराया जाता है, और जगह इस तरह बराबर की जाती है कि रिंग उतने ही अंतर से बंद हो जितना कॉपियों के बीच है:

```tsx title="components/docs-ring-code.tsx"
import { QRCode } from "qrdx";

export function DocsRingCode() {
  return (
    <QRCode
      value="https://example.com/docs"
      size={512}
      templateId="DotRing"
      customProps={{ customText: "Read the docs *", textFill: "repeat" }}
    />
  );
}
```

वाक्यांश एक ही बार दें। जो टेक्स्ट पहले से कोई वाक्यांश दोहराता है, जैसे `"Make your own * Make your own *"`, उसे वही एक वाक्यांश माना जाता है, इसलिए वह रिंग को उसी तरह भरता है।

## टेम्पलेट फ़्रेम स्पेक होते हैं [#templates-are-frame-specs]

Arrow, Standard Box, Square Border, Striked Box और Halloween की आर्टवर्क एक [फ़्रेम स्पेक](/docs/features/frames#frame-specs) है, यानी हर दूसरे फ़्रेम जैसा ही JSON फ़ॉर्मैट, जिसे वही इंजन बनाता है। `getTemplate(id).spec` इसे लौटाता है। जब आपको फ़्रेम वाला साइज़ चाहिए (कोड अपने साइज़ पर रहे और आर्टवर्क उसके चारों ओर बढ़े) और फ़्रेम का रंग विकल्प चाहिए, तब इसे फ़्रेम की तरह इस्तेमाल करें:

```tsx title="components/arrow-frame-code.tsx"
import { getTemplate, QRCode } from "qrdx";

const spec = getTemplate("Arrow")?.spec;

export function ArrowFrameCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      frame={spec && { style: "custom", spec, color: "#1a56db" }}
    />
  );
}
```

Dot Ring का कोई स्पेक नहीं है: इसके डॉट्स कोड के कंटेंट से आते हैं, इसलिए यह उन्हें कोड में बनाता है ([कोड में टेम्पलेट बनाएँ](#draw-a-template-in-code) देखें)।

`templateId` वही आर्टवर्क बनाता है जो पहले बनती थी। टेम्पलेट id इस्तेमाल करने वाले सेव किए डिज़ाइन, इमेज URL, CLI कमांड और कोड पहले जैसे ही दिखते हैं।

## टेम्पलेट रजिस्ट्री [#template-registry]

```ts title="lib/templates.ts"
import { getAllTemplates, getTemplate, getTemplateIds } from "qrdx";

getTemplateIds(); // ["default", "Arrow", "StandardBox", "SquareBorder", "StrikedBox", "Halloween", "DotRing"]
getAllTemplates(); // every TemplateDefinition, with its id and name
getTemplate("Halloween"); // one by id, or undefined
```

## कोड में टेम्पलेट बनाएँ [#draw-a-template-in-code]

फ़्रेम स्पेक तय आर्टवर्क बताता है। जब आर्टवर्क की गणना करनी हो, तो `TemplateDefinition` लिखें और उसे `customTemplate` के रूप में दें। इसका `wrapper` कोड को `children` के रूप में पाता है और बनाने के लिए SVG लौटाता है। यह 300 गुणा 300 के कैनवास पर बनाता है, और कोड भी उसी साइज़ में आता है, इसलिए अपनी आर्टवर्क के लिए जगह छोड़ने को उसे छोटा करें। `props` में कोड के `fgColor` और `bgColor` होते हैं, और तीसरे आर्ग्युमेंट में कोड का `url` और `pixelSize` होता है।

यह कोड के चारों ओर एक रिंग बनाता है:

```tsx title="components/ring-template-code.tsx"
import { QRCode, type TemplateDefinition } from "qrdx";

const ringTemplate: TemplateDefinition = {
  id: "ring",
  name: "Ring",
  wrapper: (children, props) => (
    <svg
      viewBox="0 0 300 300"
      width="300"
      height="300"
      xmlns="http://www.w3.org/2000/svg"
    >
      <circle
        cx="150"
        cy="150"
        r="140"
        fill="none"
        stroke={props?.fgColor ?? "#000000"}
        strokeWidth="8"
      />
      {/* The code at half size, centered */}
      <g transform="translate(75, 75) scale(0.5)">{children}</g>
    </svg>
  ),
};

export function RingTemplateCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      customTemplate={ringTemplate}
      fgColor="#1a56db"
    />
  );
}
```

दोनों सेट हों तो `customTemplate` को `templateId` से ऊपर माना जाता है। कोड को इतना बड़ा रखें कि लोग जहाँ से फ़ोन पकड़ेंगे वहाँ से स्कैन हो सके, और उसके व आपकी आर्टवर्क के बीच हल्की जगह छोड़ें। नतीजे को [स्कैन स्कोर](/docs/features/frames#will-it-scan) से जाँचें। JSX के बिना, wrapper को `qrdx/core` के `h` से लिखें; [Vanilla JavaScript](/docs/vanilla-js#custom-templates-without-jsx) देखें।
