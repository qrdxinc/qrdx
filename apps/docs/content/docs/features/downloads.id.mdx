`downloadQRCode(props, options)` menyimpan kode yang dijelaskan oleh `props` sebagai file di browser, dalam enam format. Fungsi-fungsi pendampingnya mengembalikan file yang sama sebagai data URL, Blob, atau markup, dan `qrdx/node` membuat PNG di server. Setiap fungsi menerima `props` yang sama dengan `QRCode`, sehingga file yang dihasilkan sama dengan kode di layar.

Mengunduh dari Playground atau dasbor? Lihat [Unduh dan cetak kode QR](/docs/help/getting-started/download-and-print) di Bantuan.

## Mengunduh file [#download-a-file]

```ts title="lib/download.ts"
import { downloadQRCode } from "qrdx";

await downloadQRCode(
  {
    value: "https://example.com",
    fgColor: "#1d4ed8",
    bodyPattern: "rounded",
    frame: { style: "banner-bottom", text: "Scan me" },
  },
  {
    format: "png",
    size: { width: 1024, height: 1024 },
    filename: "menu.png",
  }
);
```

<Shot id="lib-download-result" />

Browser menyimpan `menu.png`. `size` adalah lebar dan tinggi kode itu sendiri dalam piksel, dari 50 hingga 5000 dan berbentuk persegi; bingkai membuat file lebih besar dari ukuran tersebut. `filename` bersifat opsional: tanpanya, file diberi nama `qr-code.<ext>`, dengan ukuran piksel persis ditambahkan untuk format raster (`qr-code-1024x1024.png`, atau `qr-code-1270x1454.png` dengan banner bawah). `quality` (0 sampai 1) hanya berlaku untuk WebP.

Props-nya sama seperti pada `QRCode`, kecuali logo dimasukkan lewat `imageSettings`. Untuk mengekspor kode yang digambar oleh `QRCode`, termasuk `logo` dan `logoOptions`-nya, berikan `getQRData(props)` atau `resolveQRCodeProps(props)` sebagai ganti props mentah.

## Format [#formats]

| `format` | File | Catatan |
| --- | --- | --- |
| `png` | Gambar | Mempertahankan latar belakang transparan. Default untuk sebagian besar kebutuhan |
| `jpg` | Gambar | Hanya latar belakang solid, file lebih kecil |
| `webp` | Gambar | Piksel PNG dalam file yang lebih kecil; lossless kecuali `quality` diatur |
| `svg` | Vektor | Tajam di ukuran berapa pun; file untuk percetakan dan alat desain |
| `pdf` | Dokumen | Satu halaman berisi kode sebagai PNG. Memerlukan paket opsional `jspdf` |
| `eps` | Vektor | PostScript untuk Illustrator, CorelDRAW, dan InDesign. `size.width` dibaca sebagai poin (72 per inci) |

### WebP [#webp]

WebP bersifat lossless secara default, sehingga tepi modul tetap presisi dan latar belakang transparan tetap transparan. Jika kanvas browser dapat menulis WebP lossless (Chrome dan Edge bisa), browser yang membuat file. Jika tidak bisa, pustaka memeriksa byte-nya dan mengenkode piksel sendiri dengan encoder lossless bawaan yang kecil: Safari, saat diminta WebP, mengembalikan PNG. Bagaimanapun, file `.webp` selalu berformat WebP.

`quality` (0 sampai 1) meminta file lossy yang lebih kecil, jika didukung browser. WebP lossy melunakkan tepi modul dan warna, jadi pertahankan default untuk kode yang harus bisa dipindai dari jauh. `getQRAsWebP` mengembalikan file sebagai `Blob`:

```ts title="lib/webp.ts"
import { getQRAsWebP } from "qrdx";

const lossless = await getQRAsWebP({ value: "https://example.com", size: 1024 });
const lossy = await getQRAsWebP({ value: "https://example.com", size: 1024 }, { quality: 0.9 });
```

`canvasToWebP(canvas, options)` melakukan hal yang sama untuk kanvas apa pun, dan `encodeWebPLossless(rgba, width, height)` mengenkode piksel RGBA tanpa DOM.

### PDF [#pdf]

Unduhan PDF berisi kode sebagai PNG pada halaman berukuran sama. Ini memerlukan paket opsional `jspdf` (`npm install jspdf`); tanpanya, unduhan PDF melempar `PDF export needs the optional "jspdf" package`. Untuk PDF vektor dengan ukuran fisik, dengan bleed, tanda potong, dan CMYK, gunakan `downloadPrintPDF`; lihat [Ekspor siap cetak](/docs/features/frames#print-ready-export).

### EPS [#eps]

EPS tidak memerlukan paket tambahan. `downloadQRCode` membaca `size.width` sebagai poin, jadi permintaan 512 px menulis file 512 pt (18 cm). Untuk ukuran fisik yang tepat, gunakan `getQRAsEPS`, yang mengembalikan EPS sebagai string: kode selebar `sizeMm` (default 50 mm), dan bingkai menambah ukuran tersebut.

```ts title="lib/eps.ts"
import { downloadPrintEPS, getQRAsEPS } from "qrdx";

const eps = await getQRAsEPS(
  { value: "https://example.com" },
  { sizeMm: 40, bleedMm: 3, colorMode: "cmyk" }
);

await downloadPrintEPS({ value: "https://example.com" }, { sizeMm: 40, filename: "menu.eps" });
```

EPS tidak mendukung transparansi dan tanda potong. Gradien linear dan radial dicetak sebagai shading PostScript Level 3 yang halus; gradien sudut dicetak sebagai kipas irisan tipis. Warna tembus pandang dicampur dengan latar belakang, dan latar belakang dengan kertas putih. Logo PNG dan JPEG disematkan. EPS tidak dapat membawa [isian gambar](/docs/features/colors-gradients#image-fills): `getQRAsEPS` melempar `EPS_IMAGE_FILL_REASON`, dan dialog unduh di dasbor menawarkan PDF, SVG, dan PNG sebagai gantinya.

## Data URL, Blob, dan markup [#data-urls-blobs-and-markup]

```ts title="lib/export.ts"
import { copyQRCodeToClipboard, getQRCodeDataUrl, getSVGString } from "qrdx";

const props = { value: "https://example.com", size: 512 };

// The same file as a data URL, for an <img> or a form field
const png = await getQRCodeDataUrl(props, "png", { width: 512, height: 512 });

// A PNG on the clipboard, for pasting into a document
await copyQRCodeToClipboard(props, { width: 512, height: 512 });

// The SVG markup, for inlining in a page or an email template
const svg = await getSVGString(props);
```

- `getQRCodeDataUrl(props, format, size, { quality })` menerima setiap format yang diterima `downloadQRCode`.
- `copyQRCodeToClipboard` menulis PNG. Panggil dari handler klik: browser menolak penulisan papan klip di luar gestur pengguna.
- `getSVGString` menyematkan logo sebagai data URL, sehingga markup berdiri sendiri. `toSVGString` dari `qrdx/core` adalah versi sinkron tanpa langkah tersebut.

## Ukuran preset [#preset-sizes]

```ts title="lib/sizes.ts"
import { PRESET_SIZES, validateSize } from "qrdx";

PRESET_SIZES.small; // { width: 200, height: 200 }
PRESET_SIZES.medium; // 400
PRESET_SIZES.large; // 800
PRESET_SIZES.xlarge; // 1200
PRESET_SIZES["2xl"]; // 1600
PRESET_SIZES["3xl"]; // 2000

validateSize(4000, 4000); // { isValid: true }
validateSize(6000, 6000); // { isValid: false, error: "Size must not exceed 5000x5000 pixels" }
```

Pilih ukuran sesuai tujuan file: 256 hingga 512 px untuk halaman web, 1024 px atau lebih untuk cetak pada 300 piksel per inci (1024 px tercetak tajam hingga lebar sekitar 8,7 cm). Untuk ukuran cetak yang tepat, gunakan fungsi cetak, yang bekerja dalam milimeter dan inci.

## PNG di Node [#png-in-node]

`getQRAsPNG` dari `qrdx/node` mengembalikan byte PNG tanpa browser. Fungsi ini memerlukan satu rasterizer opsional yang dipasang di samping `qrdx`: `@resvg/resvg-js` menggambar SVG, termasuk logo, seperti yang dilakukan browser; `sharp` juga bisa digunakan.

```ts title="scripts/make-png.ts"
import { writeFile } from "node:fs/promises";
import { getQRAsPNG } from "qrdx/node";

const png = await getQRAsPNG(
  { value: "https://example.com", bodyPattern: "rounded", margin: 4 },
  { size: 1024 }
);
await writeFile("qr-code.png", png);
```

Impor dari `qrdx/node`, jangan pernah dari `qrdx`, agar bundle browser tidak pernah memuat modul native. Logo berupa data URL disematkan apa adanya; URL `http(s)` atau path lokal hanya dimuat dengan `loadExternalLogos: true`, sehingga server yang meneruskan pengaturan dari pemanggil tidak bisa dipaksa mengambil URL internal atau membaca disknya sendiri. Markup SVG tidak memerlukan rasterizer: `toSVGString` dari `qrdx/core` berjalan di mana saja.

## Jika terjadi masalah [#if-something-goes-wrong]

- **`Size must be at least 50x50 pixels`, `Size must not exceed 5000x5000 pixels`, atau `Width and height must be equal for QR codes`.** `validateSize` menolak ukuran tersebut. Berikan ukuran persegi dalam rentang yang valid.
- **`PDF export needs the optional "jspdf" package`.** Pasang `jspdf` di paket yang sama dengan `qrdx`.
- **Logo tidak ada di file.** Gambar berasal dari origin lain tanpa header CORS, sehingga browser tidak dapat menyalinnya. Sajikan dari origin Anda sendiri atau berikan data URL.
- **`copyQRCodeToClipboard` ditolak.** Fungsi dijalankan di luar handler klik atau tombol, atau halaman tidak disajikan melalui HTTPS. Panggil dari handler itu sendiri.
- **`getQRAsPNG` melempar error tentang rasterizer yang hilang.** Pasang `@resvg/resvg-js` atau `sharp` di samping `qrdx`.
