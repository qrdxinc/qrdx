`downloadQRCode(props, options)` salva nel browser, come file, il codice descritto da `props`, in uno dei sei formati disponibili. Le funzioni sorelle restituiscono invece lo stesso file come data URL, Blob o markup, e `qrdx/node` crea un PNG su un server. Ogni funzione accetta le stesse `props` di `QRCode`, quindi il file corrisponde al codice che vedi a schermo.

Vuoi scaricare dal Playground o dalla dashboard? Consulta [Scarica e stampa un QR code](/docs/help/getting-started/download-and-print) nella Guida.

## Scaricare un file [#download-a-file]

```ts title="lib/download.ts"
import { downloadQRCode } from "qrdx";

await downloadQRCode(
  {
    value: "https://example.com",
    fgColor: "#1d4ed8",
    bodyPattern: "rounded",
    frame: { style: "banner-bottom", text: "Scan me" },
  },
  {
    format: "png",
    size: { width: 1024, height: 1024 },
    filename: "menu.png",
  }
);
```

<Shot id="lib-download-result" />

Il browser salva `menu.png`. `size` è la larghezza e l'altezza in pixel del codice stesso, da 50 a 5000, e il codice è quadrato; una cornice rende il file più grande. `filename` è facoltativo: se lo ometti, il file si chiama `qr-code.<ext>`, con la dimensione esatta in pixel aggiunta per i formati raster (`qr-code-1024x1024.png`, oppure `qr-code-1270x1454.png` con un banner in basso). `quality` (da 0 a 1) vale solo per WebP.

Le props sono le stesse di `QRCode`, tranne per il logo, che va in `imageSettings`. Per esportare il codice disegnato da un `QRCode`, inclusi `logo` e `logoOptions`, passa `getQRData(props)` o `resolveQRCodeProps(props)` al posto delle props originali.

## Formati [#formats]

| `format` | File | Note |
| --- | --- | --- |
| `png` | Immagine | Mantiene lo sfondo trasparente. È il formato predefinito per la maggior parte degli usi |
| `jpg` | Immagine | Solo sfondo pieno, file più leggero |
| `webp` | Immagine | I pixel del PNG in un file più leggero; senza perdita, a meno che non imposti `quality` |
| `svg` | Vettoriale | Nitido a qualsiasi dimensione; il file per tipografie e strumenti di design |
| `pdf` | Documento | Una pagina con il codice come PNG. Richiede il pacchetto opzionale `jspdf` |
| `eps` | Vettoriale | PostScript per Illustrator, CorelDRAW e InDesign. `size.width` viene letto in punti (72 per pollice) |

### WebP [#webp]

WebP è senza perdita per impostazione predefinita, quindi i bordi dei moduli restano precisi e lo sfondo trasparente resta trasparente. Dove il canvas del browser sa scrivere WebP senza perdita (Chrome ed Edge lo fanno), il file lo crea il browser. Dove non ci riesce, la libreria controlla i byte e codifica i pixel da sé con un piccolo encoder lossless integrato: Safari, se gli chiedi WebP, restituisce un PNG. In ogni caso un file `.webp` è sempre WebP.

`quality` (da 0 a 1) richiede invece un file più piccolo con perdita, dove il browser lo supporta. Il WebP con perdita ammorbidisce i bordi dei moduli e i colori, quindi mantieni il valore predefinito per i codici che devono essere letti da lontano. `getQRAsWebP` restituisce il file come `Blob`:

```ts title="lib/webp.ts"
import { getQRAsWebP } from "qrdx";

const lossless = await getQRAsWebP({ value: "https://example.com", size: 1024 });
const lossy = await getQRAsWebP({ value: "https://example.com", size: 1024 }, { quality: 0.9 });
```

`canvasToWebP(canvas, options)` fa lo stesso per qualsiasi canvas, e `encodeWebPLossless(rgba, width, height)` codifica pixel RGBA senza DOM.

### PDF [#pdf]

Il download PDF contiene il codice come PNG su una pagina della stessa dimensione. Richiede il pacchetto opzionale `jspdf` (`npm install jspdf`); senza di esso, i download PDF generano l'errore `PDF export needs the optional "jspdf" package`. Per un PDF vettoriale a dimensione fisica, con abbondanza, crocini di taglio e CMYK, usa `downloadPrintPDF`; vedi [Esportazione pronta per la stampa](/docs/features/frames#print-ready-export).

### EPS [#eps]

EPS non richiede pacchetti aggiuntivi. `downloadQRCode` legge `size.width` in punti, quindi una richiesta da 512 px scrive un file da 512 pt (18 cm). Per una dimensione fisica esatta usa `getQRAsEPS`, che restituisce l'EPS come stringa: il codice è largo `sizeMm` (50 mm per impostazione predefinita) e una cornice si aggiunge a questa misura.

```ts title="lib/eps.ts"
import { downloadPrintEPS, getQRAsEPS } from "qrdx";

const eps = await getQRAsEPS(
  { value: "https://example.com" },
  { sizeMm: 40, bleedMm: 3, colorMode: "cmyk" }
);

await downloadPrintEPS({ value: "https://example.com" }, { sizeMm: 40, filename: "menu.eps" });
```

EPS non supporta la trasparenza né i crocini di taglio. I gradienti lineari e radiali vengono stampati come sfumature PostScript Level 3 morbide; i gradienti angolari vengono stampati come un ventaglio di sottili spicchi. I colori semitrasparenti vengono mescolati con lo sfondo, e lo sfondo con la carta bianca. I logo PNG e JPEG sono incorporati. EPS non può contenere un [riempimento con immagine](/docs/features/colors-gradients#image-fills): `getQRAsEPS` genera `EPS_IMAGE_FILL_REASON`, e la finestra di download della dashboard offre invece PDF, SVG e PNG.

## Data URL, Blob e markup [#data-urls-blobs-and-markup]

```ts title="lib/export.ts"
import { copyQRCodeToClipboard, getQRCodeDataUrl, getSVGString } from "qrdx";

const props = { value: "https://example.com", size: 512 };

// The same file as a data URL, for an <img> or a form field
const png = await getQRCodeDataUrl(props, "png", { width: 512, height: 512 });

// A PNG on the clipboard, for pasting into a document
await copyQRCodeToClipboard(props, { width: 512, height: 512 });

// The SVG markup, for inlining in a page or an email template
const svg = await getSVGString(props);
```

- `getQRCodeDataUrl(props, format, size, { quality })` accetta tutti i formati accettati da `downloadQRCode`.
- `copyQRCodeToClipboard` scrive un PNG. Chiamala da un gestore di clic: i browser rifiutano le scritture negli appunti fuori da un gesto dell'utente.
- `getSVGString` incorpora il logo come data URL, così il markup è autosufficiente. `toSVGString` di `qrdx/core` è la versione sincrona senza questo passaggio.

## Dimensioni predefinite [#preset-sizes]

```ts title="lib/sizes.ts"
import { PRESET_SIZES, validateSize } from "qrdx";

PRESET_SIZES.small; // { width: 200, height: 200 }
PRESET_SIZES.medium; // 400
PRESET_SIZES.large; // 800
PRESET_SIZES.xlarge; // 1200
PRESET_SIZES["2xl"]; // 1600
PRESET_SIZES["3xl"]; // 2000

validateSize(4000, 4000); // { isValid: true }
validateSize(6000, 6000); // { isValid: false, error: "Size must not exceed 5000x5000 pixels" }
```

Scegli la dimensione in base alla destinazione del file: da 256 a 512 px per una pagina web, 1024 px o più per la stampa a 300 pixel per pollice (1024 px stampa nitidamente fino a circa 8,7 cm di larghezza). Per dimensioni di stampa esatte usa le funzioni di stampa, che lavorano in millimetri e pollici.

## PNG in Node [#png-in-node]

`getQRAsPNG` di `qrdx/node` restituisce byte PNG senza un browser. Richiede un rasterizzatore opzionale installato accanto a `qrdx`: `@resvg/resvg-js` disegna l'SVG, loghi inclusi, come fanno i browser; funziona anche `sharp`.

```ts title="scripts/make-png.ts"
import { writeFile } from "node:fs/promises";
import { getQRAsPNG } from "qrdx/node";

const png = await getQRAsPNG(
  { value: "https://example.com", bodyPattern: "rounded", margin: 4 },
  { size: 1024 }
);
await writeFile("qr-code.png", png);
```

Importala da `qrdx/node`, mai da `qrdx`, così i bundle per il browser non vedono mai i moduli nativi. Un logo che è un data URL viene incorporato così com'è; un URL `http(s)` o un percorso locale viene caricato solo con `loadExternalLogos: true`, così un server che inoltra le impostazioni di un chiamante non può essere indotto a recuperare URL interni o a leggere il proprio disco. Il markup SVG non richiede un rasterizzatore: `toSVGString` di `qrdx/core` funziona ovunque.

## Se qualcosa va storto [#if-something-goes-wrong]

- **`Size must be at least 50x50 pixels`, `Size must not exceed 5000x5000 pixels` o `Width and height must be equal for QR codes`.** `validateSize` ha rifiutato la dimensione. Passa una dimensione quadrata nell'intervallo consentito.
- **`PDF export needs the optional "jspdf" package`.** Installa `jspdf` nello stesso pacchetto di `qrdx`.
- **Il logo manca nel file.** L'immagine proviene da un'altra origine senza header CORS, quindi il browser non ha potuto copiarla. Servila dalla tua origine o passa un data URL.
- **`copyQRCodeToClipboard` viene rifiutata.** È stata eseguita fuori da un gestore di clic o di tasti, oppure la pagina non è servita tramite HTTPS. Chiamala dal gestore stesso.
- **`getQRAsPNG` genera un errore per un rasterizzatore mancante.** Installa `@resvg/resvg-js` o `sharp` accanto a `qrdx`.
