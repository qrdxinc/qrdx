テンプレートは、決まったサイズのアートワークの中にコードをはめ込むフレームです。テンプレートの ID を `templateId` として渡すと、コンポーネントはアートワーク全体を `size` で描画し、その内側にそれより小さくコードを配置します。このページでは、組み込みテンプレートの一覧、Dot Ring のオプション、コードでテンプレートを描画する方法を説明します。

Playground やダッシュボードでデザインする場合は、ヘルプの[フレームとコール・トゥ・アクションを追加する](/docs/help/designing/frames)をご覧ください。テンプレートは、フレームピッカーの **Classic** グループにタイルとして表示されます。

テンプレートは、サイズの扱いが他の[フレーム](/docs/features/frames)と異なります。フレームはコードの周囲に余白を追加するため、`size` はコードの幅になり、画像全体は大きくなります。テンプレートはアートワーク全体を `size` で描画し、コードはその内側で小さくなります。

## 組み込みテンプレート [#built-in-templates]

| `templateId` | 名前 | 色 |
| --- | --- | --- |
| `Arrow` | Arrow | コードの暗色（`fgColor`） |
| `StandardBox` | Standard Box | `fgColor` |
| `SquareBorder` | Square Border | `fgColor` |
| `StrikedBox` | Striked Box | 専用の暗色 |
| `Halloween` | Halloween | 専用のオレンジ、緑、黒 |
| `DotRing` | Dot Ring | リングは `fgColor`、テキストは白。どちらも変更できます（後述） |

`default` はアートワークを描画しません。コードを `size` の 95% にわずかに縮めるだけです。`templateId` を指定しない場合、コードは `size` いっぱいに表示されます。

```tsx title="components/arrow-code.tsx"
import { QRCode } from "qrdx";

export function ArrowCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      templateId="Arrow"
      fgColor="#1a56db"
    />
  );
}
```

<Shot id="lib-templates" />

色、パターン、ロゴはコード自身のプロパティで指定するため、テンプレートはどのスタイルとも組み合わせられます。

```tsx title="components/boxed-logo-code.tsx"
import { QRCode } from "qrdx";

export function BoxedLogoCode() {
  return (
    <QRCode
      value="https://example.com"
      size={512}
      templateId="StandardBox"
      fgColor="#1a56db"
      level="H"
      logo="/logo.png"
    />
  );
}
```

Image API ではテンプレートを `template` で、CLI では `--template` で指定します。

## Dot Ring [#dot-ring]

円形のコードです。コードは暗色のリングの内側にあるドットの円盤に収まり、リングに沿ってテキストが1行配置されます。表示されるドットはコードの内容のハッシュから決まるため、リンクごとに固有のリングになり、同じリンクには常に同じリングが描かれます。

```tsx title="components/dot-ring-code.tsx"
import { QRCode } from "qrdx";

export function DotRingCode() {
  return (
    <QRCode
      value="https://example.com"
      size={512}
      templateId="DotRing"
      bodyPattern="circle-large"
      customProps={{
        customText: "Scan for the menu",
        textPosition: "bottom",
        textColor: "#fde047",
        outerCircleColor: "#1e3a8a",
      }}
    />
  );
}
```

設定は `customProps` に指定します。型は `DotRingProps` です。

| プロパティ | デフォルト | 備考 |
| --- | --- | --- |
| `customText` | "Scan the QR code *" を4回繰り返したもの | リングに沿うテキスト。`""` を指定するとリングは空になります。リングに収まらない長いテキストは調整されます（後述） |
| `textFill` | `"none"` | `"repeat"` を指定すると、テキストをリング全体に繰り返します（後述） |
| `textPosition` | `"top"` | `"top"`：上部の中央に、時計回りに読む向きで配置します。`"bottom"`：下部の中央に、左から右へ読む向きで配置します |
| `textRotation` | `0` | テキストを中心まわりに時計回りに回転させます（単位は度） |
| `textColor` | `#ffffff` | テキストの色 |
| `fontFamily` | システムフォントスタック | テキストの CSS フォントファミリー |
| `fontWeight` | `900` | フォントの太さ |
| `fontSize` | `32` | テンプレートの 593 単位の描画領域での値で、コードの幅は 300 です。長いテキストは小さく描画されることがあります |
| `fontLetterSpacing` | `3.5` | 文字間の追加スペース（同じ単位）。長いテキストや `textFill` では調整されます |
| `outerCircleColor` | `fgColor` | リングの色 |
| `strokeWidth`, `strokeColor` | `0`, `#000000` | リングの両端に沿う縁取り線 |
| `outerStrokeWidth`, `outerStrokeColor` | `strokeWidth`, `strokeColor` | リングの外側の縁のみ |
| `innerStrokeWidth`, `innerStrokeColor` | `strokeWidth`, `strokeColor` | リングの内側の縁のみ |

リングに収まるテキストは、指定どおりに上部の中央または下部に沿って配置されます。収まらないテキストは、自身の先頭にぶつからないように調整されます。まず文字の間隔を詰め、それでも収まらなければフォントを小さくします。縮小はデフォルトサイズの半分までです。その後、テキストは先頭と接する位置で単語間のスペースを空けてリングを閉じます。それでも収まらない場合、フレーズを繰り返したテキストは収まる範囲で完全なコピーだけを残し、それ以外のテキストは収まる最後の単語の後で切り詰められ、末尾に省略記号が付きます。

ロゴは、他のコードと同様に中央に配置できます。長いリンク（幅が49モジュールを超えるコード）では、コードとドットの間に明るい帯を残すため、小さく印刷してもスキャンできます。

テキストは、選択したフォントの SVG テキストです。デフォルトはシステムフォントスタックなので、フォントはダウンロードされません。ブラウザでの SVG と PNG のダウンロードでは、閲覧者の環境のフォントが使われます。PDF と EPS では Helvetica Bold で印刷されるため、Latin-1 のテキストを使用してください。`qrdx/node` の `getQRAsPNG` では、フレームのラベルと同様に、サーバーにフォントをインストールしておく必要があります。

### リングを埋める [#fill-the-ring]

短いフレーズではリングの一部が空いたままになります。`textFill: "repeat"` を設定すると、フレーズが収まる回数だけ繰り返されます。間隔は均等に調整され、コピー同士の間隔と同じ隙間でリングが閉じます。

```tsx title="components/docs-ring-code.tsx"
import { QRCode } from "qrdx";

export function DocsRingCode() {
  return (
    <QRCode
      value="https://example.com/docs"
      size={512}
      templateId="DotRing"
      customProps={{ customText: "Read the docs *", textFill: "repeat" }}
    />
  );
}
```

フレーズは1回だけ指定してください。`"Make your own * Make your own *"` のように、すでにフレーズを繰り返しているテキストは、そのフレーズとして扱われるため、同じようにリングが埋まります。

## テンプレートはフレーム仕様です [#templates-are-frame-specs]

Arrow、Standard Box、Square Border、Striked Box、Halloween のアートワークは、他のすべてのフレームと同じ JSON 形式の[フレーム仕様](/docs/features/frames#frame-specs)で、同じエンジンによって描画されます。`getTemplate(id).spec` でその仕様を取得できます。フレームのサイズ指定（コードのサイズは変わらず、アートワークがその周囲で大きくなる）とフレームの色オプションを使いたい場合は、これをフレームとして使用します。

```tsx title="components/arrow-frame-code.tsx"
import { getTemplate, QRCode } from "qrdx";

const spec = getTemplate("Arrow")?.spec;

export function ArrowFrameCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      frame={spec && { style: "custom", spec, color: "#1a56db" }}
    />
  );
}
```

Dot Ring には仕様がありません。ドットはコードの内容から決まるため、コード内で描画されます（[コードでテンプレートを描画する](#draw-a-template-in-code)を参照）。

`templateId` はこれまでと同じアートワークを描画します。テンプレート ID を使用している保存済みのデザイン、画像 URL、CLI コマンド、コードは、これまでと同じ見た目になります。

## テンプレートレジストリ [#template-registry]

```ts title="lib/templates.ts"
import { getAllTemplates, getTemplate, getTemplateIds } from "qrdx";

getTemplateIds(); // ["default", "Arrow", "StandardBox", "SquareBorder", "StrikedBox", "Halloween", "DotRing"]
getAllTemplates(); // every TemplateDefinition, with its id and name
getTemplate("Halloween"); // one by id, or undefined
```

## コードでテンプレートを描画する [#draw-a-template-in-code]

フレーム仕様は固定のアートワークを記述するものです。アートワークを計算で作る必要がある場合は、`TemplateDefinition` を作成し、`customTemplate` として渡します。その `wrapper` はコードを `children` として受け取り、描画する SVG を返します。描画は 300 × 300 のキャンバス上で行われ、コードも同じサイズで渡されるため、アートワークの余地を残すようにコードを縮小してください。`props` にはコードの `fgColor` と `bgColor` が含まれ、第3引数にはコードの `url` と `pixelSize` が含まれます。

次の例は、コードの周りにリングを描画します。

```tsx title="components/ring-template-code.tsx"
import { QRCode, type TemplateDefinition } from "qrdx";

const ringTemplate: TemplateDefinition = {
  id: "ring",
  name: "Ring",
  wrapper: (children, props) => (
    <svg
      viewBox="0 0 300 300"
      width="300"
      height="300"
      xmlns="http://www.w3.org/2000/svg"
    >
      <circle
        cx="150"
        cy="150"
        r="140"
        fill="none"
        stroke={props?.fgColor ?? "#000000"}
        strokeWidth="8"
      />
      {/* The code at half size, centered */}
      <g transform="translate(75, 75) scale(0.5)">{children}</g>
    </svg>
  ),
};

export function RingTemplateCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      customTemplate={ringTemplate}
      fgColor="#1a56db"
    />
  );
}
```

`templateId` と `customTemplate` の両方を指定した場合は、`customTemplate` が優先されます。コードは、ユーザーがスマートフォンをかざす距離からスキャンできる大きさを保ち、コードとアートワークの間に明るい隙間を残してください。結果は[スキャンスコア](/docs/features/frames#will-it-scan)で確認できます。JSX を使わない場合は、`qrdx/core` の `h` を使ってラッパーを記述します。詳しくは [Vanilla JavaScript](/docs/vanilla-js#custom-templates-without-jsx) をご覧ください。
