`art` プロパティを使うと、ロゴや写真をコードのモジュールにベクター図形として溶け込ませられます。AI は使いません。Logo QR はロゴの形の内側にあるモジュールの色を変え、Image QR はすべてのモジュールに写真を透かして表示します。どちらもライブラリ自身が描画するため、オフラインでも、サーバーでも、Node でも動作し、結果は常に本物のQRコードです。このページでは、このプロパティ、画像のサンプリング方法、スキャンできる状態の保ち方を説明します。

Playground やダッシュボードでデザインする場合は、ヘルプの[ロゴや写真をコードに溶け込ませる](/docs/help/designing/art)をご覧ください。

QRdx には、コードをアートに変える方法が3つあります。

| | 仕組み | 出力 | コスト |
| --- | --- | --- | --- |
| **Logo QR** (`mode: "logo"`) | ロゴの形の内側にあるモジュールがロゴの色になり、それ以外は明るい色調に薄くなります | ベクター (SVG、PDF、EPS、PNG) | 無料 |
| **Image QR** (`mode: "halftone"`) | 本来の値を保つ中央の正方形を残して、すべてのモジュールに写真が表示されます | ベクター (SVG、PDF、EPS、PNG) | 無料 |
| **AI アート** | AI 画像モデルがコードをシーンとして描き直し、すべての画像でスキャンできることを検証します | 1024 px の画像、2048 px の印刷用コピー | プランに含まれる AI アート画像 |

## アートコードを描画する [#draw-an-art-code]

モード、サンプリング済みの画像、必要に応じて強度を指定した `art` プロパティを渡します。

```tsx title="components/logo-art-code.tsx"
import { loadQRArtImage, type QRArtImage, QRCode } from "qrdx";

// Browser: sample an uploaded file, a data URL or an <img>
export async function sampleLogo(file: File): Promise<QRArtImage> {
  return await loadQRArtImage(file, { mode: "logo" });
}

export function LogoArtCode({ image }: { image: QRArtImage }) {
  return (
    <QRCode
      value="https://example.com"
      size={512}
      level="H"
      art={{ mode: "logo", image, intensity: 0.7 }}
    />
  );
}
```

<Shot id="lib-art-codes" />

サーバーや Node では、自分で画像をデコードし、RGBA ピクセルを `createQRArtImage` に渡します。

```ts title="lib/sample-photo.ts"
import { createQRArtImage } from "qrdx";
import sharp from "sharp";

const { data, info } = await sharp("photo.jpg")
  .ensureAlpha()
  .raw()
  .toBuffer({ resolveWithObject: true });

export const image = createQRArtImage(
  { data, width: info.width, height: info.height },
  { maxSize: 96, square: true }
);
// art={{ mode: "halftone", image, intensity: 0.8 }}
```

`art.image` は単純な JSON (`{ width, height, data }`、data は base64 の RGBA) です。そのため、保存したデザインと一緒に保管でき、画像を再取得せずに、どこでも同期的に同じコードを描画できます。

| オプション | 値 | 備考 |
| --- | --- | --- |
| `mode` | `logo`、`halftone` | `halftone` はエディターでは Image QR にあたります |
| `image` | `loadQRArtImage` または `createQRArtImage` の戻り値 | 最大 192 × 192 サンプルです。`loadQRArtImage` は既定で横 160 サンプルを取得します |
| `intensity` | `0` から `1` | 既定値は `0.6` です。`0` では通常のコードに見えます |
| `variant` | `blend`、`badge` (logo)、`color`、`mono` (halftone) | モード内の見た目です。`badge` はトレースしたロゴを、色味を付けたコードの中央にある角丸のプレートに載せます。`mono` は白黒のハーフトーンです。各モードの最初の値が既定値です |
| `matchEyes` | `true`、`false` | Logo モードのみ。ロゴの色で角のアイを着色します (既定値は `true`)。アイごとの `eyeColors` が指定されている場合はそちらが優先されます |

アートはボディパターンを置き換えます。角のアイは `cornerEyePattern`、`cornerEyeDotPattern`、色をそのまま使います。アートはグラデーションの `fgColor` や `bgColor` の最初の色を使い、明るい背景に暗い前景が必要です。色を反転させると、通常の見た目に戻ります。アートに最も余裕を与える `level="H"` を使ってください。

## スキャンできる状態の保ち方 [#how-scannability-is-kept]

- **Logo QR**: ロゴ内の暗いモジュールは色が変わりますが、スキャナーが暗いと読み取れる輝度までしか暗くしません。ロゴ内の明るいモジュールには、明るさのしきい値を下回らない淡い色味が付きます。ロゴ外の暗いモジュールはグレーに薄くなりますが、暗さのしきい値より明るくなることはありません。
- **Logo QR のバッジ**: プレートの下にあるモジュールは、それぞれ1つのコードワードを損なう可能性があります。プレートのサイズは、どの誤り訂正ブロックでも、修復可能なコードワードの 60% を超えて失われないように決められ、残りはカメラのために確保されます。強度を上げると、プレートはそのサイズまで大きくなります。小さいコードではロゴも小さくなり、最小のもの (バージョン 1、L または M のバージョン 2、L のバージョン 3) ではプレートを描画しません。
- **Image QR**: 各モジュールを 3 × 3 のグリッドに分割します。外側のセルには写真が表示され、モジュールの値に合わせて暗くまたは明るくされます。中央のセルは前景色または背景色そのままで、スキャナーはここをサンプリングします。
- ファインダー、タイミング、アライメント、フォーマット、バージョンの各モジュールは、常にベタ塗りで描画されます。

印刷する前に `getScanScore(props)` でデザインを確認し、実際のスマートフォンのカメラでもテストしてください。

## アートコードを書き出す [#export-art-codes]

アートコードはベクター図形なので、どの形式で書き出しても鮮明なままです。

```ts title="lib/export-art.ts"
import { downloadQRCode, getQRAsEPS, getQRAsPrintPDF } from "qrdx";

await downloadQRCode(props, { format: "svg", size: { width: 1024, height: 1024 } });
const pdf = await getQRAsPrintPDF(props, { size: 40, unit: "mm", colorMode: "cmyk" });
const eps = await getQRAsEPS(props, { sizeMm: 40, bleedMm: 3, colorMode: "cmyk" });
```

`getQRAsEPS` は、ポイント単位の `%%BoundingBox` を持つ EPSF-3.0 ファイルを書き出し、すべてのモジュール、アイ、フレームを PostScript のパスとして出力します。印刷用 PDF と同様に、線形グラデーションと放射状グラデーションを (PostScript Level 3 のシェーディングとして) 保持し、透明度は使いません。PNG と JPEG のロゴは画像として埋め込まれます。それ以外の形式のロゴはブラウザーでは変換されますが、サーバーでは含まれません。フレームのテキストには Helvetica を使うため、Latin-1 以外の文字は `?` として出力されます。`svgToEPS(svg, { width })` は、このライブラリが出力する任意の SVG を変換します。CLI でも EPS を書き出せます: `qrdx generate "https://example.com" -o qr.eps`。

<IfAvailable feature="aiArt" id="ai-art" title="AI アート">

[AI QR アート](/ai/art)は、Vercel AI Gateway 経由で {facts.artModel} を使い、コードをシーンに変えます。{facts.aiArtStyles} 種類のスタイルプリセットをカテゴリーで見たり検索したりでき、それぞれにスキャン確認に合格したプレビュー、避けたい要素、**QR の視認性**スライダー (モデルがコードをどれだけ重視するか)、**創造性**スライダー (モデルがプロンプトをどれだけ自由に解釈するか)、1回の実行あたり 1〜4 個のバリエーション、そしてロゴやカラーパレットなどの参照画像 (任意) が用意されています。参照画像の色や形は結果に引き継がれます。

すべての画像は、表示される前にサーバーで確認されます。QRdx はモデルに、シンプルな白黒のコード (誤り訂正 H、正方形のモジュール、広いクワイエットゾーン) を送り、モジュールのグリッド、ファインダーアイ、クワイエットゾーンを保つように指示します。続いて、モデルが返した画像を jsQR でそのまま、およびスマートフォンカメラのモデルを通してデコードします。失敗した場合は、モデルが描いたモジュールのグリッドの位置を見つけ、モデル自身の画像の上でコードを必要最小限だけ強化します。まずファインダーアイとクワイエットゾーン、次にモジュールの順で、画像がスキャンできるようになるまで強度を段階的に上げます。これは、カメラから見てコードが小さい場合にも対応します。QR の視認性は、どこまで強化してよいかを決めます。それでも足りない場合にのみ、画像を Image QR コードとして描き直します。それでもあなたの指定した内容と完全に一致するようにデコードできない画像は、納品されません。その後、ブラウザーがバリエーションを採点して最良のものを選びます。1024 px で、または 2048 px の印刷用コピー (リサンプリングして再度確認したもの) としてダウンロードできます。

納品された画像1枚ごとに、プランの月間 AI アート画像を1枚消費します。フリーアカウントは月 3 枚、Pro は 30 枚、Business は 150 枚で、ワークスペースの全員で共有します。失敗した画像やスキャン確認に合格しなかった画像は消費せず、印刷用コピーは無料です。AI アートはラスター画像で、内容が固定されています。編集可能なリンクにしたい場合は、[動的QRコード](/docs/dynamic-qr-codes)の短縮リンクを埋め込んでください。開発者は [AI アート API](/docs/developers/ai-art-api) から生成できます。
