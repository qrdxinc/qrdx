चार props किसी कोड को रंग देते हैं: डेटा मॉड्यूल के लिए `fgColor`, बैकग्राउंड के लिए `bgColor`, तीनों कोनों की आइज़ के लिए `eyeColor` और हर आइ के अंदर के डॉट के लिए `dotColor`। हर एक में सॉलिड कलर या ग्रेडिएंट ऑब्जेक्ट दिया जा सकता है, और आइज़ के कलर डिफ़ॉल्ट रूप से `fgColor` ही होते हैं। इस पेज में हर तरह के फ़िल और कोड को पढ़ने लायक रखने के तरीके बताए गए हैं।

इसके बजाय Playground या डैशबोर्ड में डिज़ाइन कर रहे हैं? Help में [ऐसे कलर चुनें जो स्कैन हों](/docs/help/designing/colors-and-contrast) देखें।

## सॉलिड कलर [#solid-colors]

```tsx title="components/brand-code.tsx"
import { QRCode } from "qrdx";

export function BrandCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      fgColor="#1a56db"
      bgColor="#f9fafb"
      eyeColor="#0d47a1"
      dotColor="#3b82f6"
    />
  );
}
```

सॉलिड कलर कोई भी CSS कलर हो सकता है जिसे इंजन पार्स कर सके: 3, 4, 6 या 8 अंकों वाला hex, `rgb()` और `rgba()`, कोई नामित कलर, या `transparent`। `hsl()` जैसे दूसरे CSS सिंटैक्स SVG में रेंडर हो जाते हैं, लेकिन कंट्रास्ट चेक, PDF और EPS उन्हें पढ़ नहीं सकते, इसलिए ऊपर दिए रूपों का ही इस्तेमाल करें। `{ type: "solid", color: "#1a56db" }` स्ट्रिंग के बराबर ही है।

`eyeColors` हर आइ को अलग से सेट करता है (`topLeft`, `topRight`, `bottomLeft`, हर एक में `outer` और `inner` कलर या ग्रेडिएंट); देखें [हर आइ का अलग कलर](/docs/features/patterns#per-eye-colors)।

### पारदर्शी बैकग्राउंड [#transparent-background]

`bgColor="transparent"` कोई बैकग्राउंड नहीं बनाता, इसलिए PNG और SVG डाउनलोड पारदर्शी होते हैं और PDF व EPS फ़ाइलों में बैकग्राउंड फ़िल नहीं होता। कोड को हल्की, सादी सतह पर रखें: डिकोडर को मॉड्यूल के बीच के हल्के गैप चाहिए होते हैं।

## लीनियर ग्रेडिएंट [#linear-gradients]

```tsx title="components/gradient-code.tsx"
import { QRCode } from "qrdx";

export function GradientCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      fgColor={{
        type: "linear",
        angle: 45,
        stops: [
          { color: "#4f46e5", offset: 0 },
          { color: "#db2777", offset: 100 },
        ],
      }}
    />
  );
}
```

- `angle` डिग्री में है: 0 बाएँ से दाएँ चलता है, 90 ऊपर से नीचे, 45 ऊपर के बाएँ कोने से नीचे के दाएँ कोने की ओर।
- `stops` में कम से कम दो एंट्री चाहिए। `offset` 0 से 100 तक का प्रतिशत है, और स्टॉप के कलर में alpha हो सकता है।
- कोई भी कलर prop ग्रेडिएंट ले सकता है, `bgColor` और आइज़ भी। `QRCodeCanvas` ग्रेडिएंट नहीं बना सकता और पहला स्टॉप इस्तेमाल करता है; `QRCode` या `QRCodeSVG` इस्तेमाल करें।

ग्रेडिएंट SVG, PNG, JPG, WebP और PDF डाउनलोड में जाते हैं। प्रिंट PDF और EPS उन्हें स्मूद शेडिंग के रूप में बनाते हैं।

## रेडियल ग्रेडिएंट [#radial-gradients]

```tsx title="components/radial-code.tsx"
import { QRCode } from "qrdx";

export function RadialCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      fgColor={{
        type: "radial",
        stops: [
          { color: "#0f766e", offset: 0 },
          { color: "#0c4a6e", offset: 100 },
        ],
      }}
    />
  );
}
```

रेडियल ग्रेडिएंट कोड के केंद्र से बाहर की ओर चलता है। इसका केंद्र और त्रिज्या कोड के साइज़ के हिसाब से तय होते हैं, इसलिए इसमें सिर्फ़ `stops` दिए जाते हैं।

## एंगुलर ग्रेडिएंट [#angular-gradients]

एंगुलर ग्रेडिएंट, CSS `conic-gradient` की तरह, जिस हिस्से को भर रहा है उसके केंद्र के चारों ओर घड़ी की दिशा में घूमता है। `angle` वह जगह है जहाँ से घुमाव शुरू होता है, ऊपर से घड़ी की दिशा में डिग्री में। ऑफ़सेट पूरे चक्कर में 0 से 100 तक चलते हैं।

```tsx title="components/angular-code.tsx"
import { QRCode } from "qrdx";

export function AngularCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      fgColor={{
        type: "angular",
        angle: 30,
        stops: [
          { color: "#1d4ed8", offset: 0 },
          { color: "#7c3aed", offset: 50 },
          { color: "#1d4ed8", offset: 100 },
        ],
      }}
    />
  );
}
```

SVG में conic ग्रेडिएंट नहीं होता, इसलिए कोड पतले वेज का एक पंखा बनाता है, जिनके बीच लगभग दो कलर लेवल का अंतर होता है। PDF और EPS भी यही वेज बनाते हैं।

## पारदर्शी कलर [#see-through-colors]

कलर और ग्रेडिएंट स्टॉप में alpha हो सकता है, जैसे `#1d4ed8cc` या `rgba(29, 78, 216, 0.8)`। SVG इसे `fill-opacity` और `stop-opacity` के रूप में लिखता है, और PDF इसे बनाए रखता है। EPS में पारदर्शिता नहीं होती, इसलिए पारदर्शी कलर को बैकग्राउंड के साथ मिला दिया जाता है। स्कैन चेक पारदर्शी कलर को वैसे आँकता है जैसा वह बैकग्राउंड पर दिखता है।

## इमेज फ़िल [#image-fills]

इमेज फ़िल बैकग्राउंड, मॉड्यूल या आइज़ में एक तस्वीर भरता है। तस्वीर पूरे कोड पर बिछाई जाती है, इसलिए जो मॉड्यूल और आइज़ एक ही तस्वीर साझा करते हैं उनमें एक ही तस्वीर दिखती है।

```tsx title="components/photo-code.tsx"
import { QRCode } from "qrdx";

export function PhotoCode({ photo }: { photo: string }) {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      fgColor={{
        type: "image",
        src: photo, // a data:image/jpeg;base64,… URL
        fit: "cover", // or "contain", "tile"
        position: "center",
        scale: 1,
        opacity: 0.45,
        underlay: "#000000",
      }}
    />
  );
}
```

- `src` तस्वीर ही है, जैसे लोगो में। QRdx इमेज फ़िल (कोड, थीम और REST API में) सिर्फ़ base64 `data:image` URL (PNG, JPEG, WebP या GIF) के रूप में सेव करता है, जो अधिकतम 1.5 MB का हो; लिंक से दी गई तस्वीर मंज़ूर नहीं की जाती। PNG और JPEG हर एक्सपोर्ट में एम्बेड होते हैं, और सर्वर कभी कोई लिंक फ़ेच नहीं करते।
- `underlay` तस्वीर के नीचे का सॉलिड कलर है। `opacity` उसे दिखने देती है: काले के ऊपर यह मॉड्यूल के लिए फ़ोटो को गहरा करती है, और सफ़ेद के ऊपर बैकग्राउंड के लिए उसे हल्का करती है।
- तस्वीर की बारीकियाँ कैमरे को शोर जैसी लगती हैं, इसलिए स्कैन चेक ज़्यादा कंट्रास्ट माँगता है: मॉड्यूल या आइज़ में 7:1, उनके पीछे 12:1 (`SCAN_IMAGE_CONTRAST_MIN`)। यह तस्वीर को उसके सबसे हल्के और सबसे गहरे दसवें हिस्से से मापता है (`getImageTones`)। एडिटर में **Make it scannable** underlay के ऊपर वह opacity ढूँढ देता है जो चेक पास करती है।
- SVG, PNG और PDF इमेज फ़िल रखते हैं। EPS नहीं रख सकता; देखें [EPS](/docs/features/downloads#eps)।

इमेज फ़िल लोगो की तरह ही चलते हैं। वे एडिटर में, सेव किए कोड में और सेव की गई थीम में डिज़ाइन के साथ रहते हैं। वे `?style=` लिंक, प्रकाशित कम्युनिटी स्टाइल, Get code स्निपेट या चैट के संदर्भ में नहीं जाते: वहाँ हर इमेज फ़िल की जगह उसका underlay कलर आ जाता है। Image API (`GET /v1/qr`) और MCP सर्वर इन्हें नहीं लेते। `POST /v1/codes` और `PATCH /v1/codes/{id}` इन्हें सिर्फ़ `data:image` URL के रूप में लेते हैं, और बाकी हर चीज़ पर 400 लौटाते हैं।

## कंट्रास्ट जाँचें [#check-the-contrast]

स्कैनर को हल्के बैकग्राउंड पर गहरे मॉड्यूल चाहिए। स्कैन स्कोर हर कलर को, हर ग्रेडिएंट स्टॉप समेत, बैकग्राउंड के मुकाबले जाँचता है; वही हेल्पर एक्सपोर्ट किए गए हैं:

```ts title="lib/check-contrast.ts"
import { getContrastLevel, getContrastRatio } from "qrdx";

const ratio = getContrastRatio("#1a56db", "#f9fafb");
// 5.9

getContrastLevel(ratio);
// { level: "AA", warning: false, message: "Good contrast" }
```

स्कैन स्कोर 4.5 या उससे ज़्यादा के अनुपात को पास करता है (`SCAN_CONTRAST_MIN`), उससे नीचे अंक काटता है, और 1.5 से नीचे डिज़ाइन को फ़ेल कर देता है। `getContrastLevel` 7 से `AAA`, 4.5 से `AA`, 3 से चेतावनी के साथ `AA Large`, और उससे नीचे `Fail` लौटाता है। गहरे बैकग्राउंड पर हल्का कोड अनुपात में पास हो जाता है लेकिन पोलैरिटी चेक में अंक खो देता है: ज़्यादातर फ़ोन कैमरे उसे पढ़ लेते हैं, कुछ स्कैनर ऐप नहीं पढ़ते।
