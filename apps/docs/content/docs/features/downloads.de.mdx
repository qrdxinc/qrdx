`downloadQRCode(props, options)` speichert den durch `props` beschriebenen Code im Browser als Datei, und zwar in einem von sechs Formaten. Die Schwesterfunktionen liefern dieselbe Datei stattdessen als Data-URL, Blob oder Markup, und `qrdx/node` erzeugt auf einem Server ein PNG. Jede Funktion nimmt dieselben `props` wie `QRCode`, sodass die Datei zum Code auf dem Bildschirm passt.

Du lädst stattdessen aus dem Playground oder dem Dashboard herunter? Dann lies [QR-Code herunterladen und drucken](/docs/help/getting-started/download-and-print) in der Hilfe.

## Eine Datei herunterladen [#download-a-file]

```ts title="lib/download.ts"
import { downloadQRCode } from "qrdx";

await downloadQRCode(
  {
    value: "https://example.com",
    fgColor: "#1d4ed8",
    bodyPattern: "rounded",
    frame: { style: "banner-bottom", text: "Scan me" },
  },
  {
    format: "png",
    size: { width: 1024, height: 1024 },
    filename: "menu.png",
  }
);
```

<Shot id="lib-download-result" />

Der Browser speichert `menu.png`. `size` ist die Breite und Höhe des Codes selbst in Pixeln, von 50 bis 5000 und quadratisch; ein Rahmen macht die Datei größer. `filename` ist optional: Ohne Angabe heißt die Datei `qr-code.<ext>`, bei Rasterformaten mit der genauen Pixelgröße dahinter (`qr-code-1024x1024.png`, oder `qr-code-1270x1454.png` mit einem Banner unten). `quality` (0 bis 1) gilt nur für WebP.

Die Props sind dieselben wie bei `QRCode`, nur dass ein Logo in `imageSettings` steht. Um den Code zu exportieren, den ein `QRCode` zeichnet, einschließlich `logo` und `logoOptions`, übergib statt der rohen Props `getQRData(props)` oder `resolveQRCodeProps(props)`.

## Formate [#formats]

| `format` | Datei | Hinweise |
| --- | --- | --- |
| `png` | Bild | Behält einen transparenten Hintergrund. Die Standardwahl für die meisten Fälle |
| `jpg` | Bild | Nur einfarbiger Hintergrund, kleinere Datei |
| `webp` | Bild | Die Pixel des PNG in einer kleineren Datei; verlustfrei, solange `quality` nicht gesetzt ist |
| `svg` | Vektor | Bei jeder Größe scharf; die Datei für Druckereien und Design-Tools |
| `pdf` | Dokument | Eine Seite mit dem Code als PNG. Benötigt das optionale Paket `jspdf` |
| `eps` | Vektor | PostScript für Illustrator, CorelDRAW und InDesign. `size.width` wird als Punkt gelesen (72 pro Zoll) |

### WebP [#webp]

WebP ist standardmäßig verlustfrei, daher bleiben die Modulkanten exakt und ein transparenter Hintergrund bleibt transparent. Wo das Canvas des Browsers verlustfreies WebP schreibt (Chrome und Edge tun das), erzeugt der Browser die Datei. Wo er das nicht kann, prüft die Bibliothek die Bytes und kodiert die Pixel selbst mit einem kleinen eingebauten verlustfreien Encoder: Safari liefert auf die Anfrage nach WebP ein PNG. In beiden Fällen ist eine `.webp`-Datei immer WebP.

Mit `quality` (0 bis 1) forderst du stattdessen eine kleinere verlustbehaftete Datei an, sofern der Browser das unterstützt. Verlustbehaftetes WebP macht Modulkanten und Farben weicher, behalte also für Codes, die aus großer Entfernung scannen müssen, den Standard bei. `getQRAsWebP` gibt die Datei als `Blob` zurück:

```ts title="lib/webp.ts"
import { getQRAsWebP } from "qrdx";

const lossless = await getQRAsWebP({ value: "https://example.com", size: 1024 });
const lossy = await getQRAsWebP({ value: "https://example.com", size: 1024 }, { quality: 0.9 });
```

`canvasToWebP(canvas, options)` macht dasselbe für ein beliebiges Canvas, und `encodeWebPLossless(rgba, width, height)` kodiert RGBA-Pixel ohne DOM.

### PDF [#pdf]

Der PDF-Download enthält den Code als PNG auf einer Seite derselben Größe. Er benötigt das optionale Paket `jspdf` (`npm install jspdf`); ohne es lösen PDF-Downloads den Fehler `PDF export needs the optional "jspdf" package` aus. Für ein Vektor-PDF in physischer Größe, mit Beschnitt, Schnittmarken und CMYK nutzt du `downloadPrintPDF`; siehe [Druckfertiger Export](/docs/features/frames#print-ready-export).

### EPS [#eps]

EPS braucht kein zusätzliches Paket. `downloadQRCode` liest `size.width` als Punkt, eine Anfrage mit 512 px schreibt also eine Datei mit 512 pt (18 cm). Für eine exakte physische Größe nutzt du `getQRAsEPS`, das das EPS als String zurückgibt: Der Code ist `sizeMm` breit (Standard 50 mm), ein Rahmen kommt dazu.

```ts title="lib/eps.ts"
import { downloadPrintEPS, getQRAsEPS } from "qrdx";

const eps = await getQRAsEPS(
  { value: "https://example.com" },
  { sizeMm: 40, bleedMm: 3, colorMode: "cmyk" }
);

await downloadPrintEPS({ value: "https://example.com" }, { sizeMm: 40, filename: "menu.eps" });
```

EPS kennt keine Transparenz und keine Schnittmarken. Lineare und radiale Verläufe werden als weiche PostScript-Level-3-Schattierungen gedruckt; Winkelverläufe als Fächer aus dünnen Keilen. Durchscheinende Farben werden mit dem Hintergrund gemischt, der Hintergrund mit weißem Papier. PNG- und JPEG-Logos werden eingebettet. EPS kann keine [Bildfüllung](/docs/features/colors-gradients#image-fills) enthalten: `getQRAsEPS` löst `EPS_IMAGE_FILL_REASON` aus, und der Download-Dialog im Dashboard bietet stattdessen PDF, SVG und PNG an.

## Data-URLs, Blobs und Markup [#data-urls-blobs-and-markup]

```ts title="lib/export.ts"
import { copyQRCodeToClipboard, getQRCodeDataUrl, getSVGString } from "qrdx";

const props = { value: "https://example.com", size: 512 };

// The same file as a data URL, for an <img> or a form field
const png = await getQRCodeDataUrl(props, "png", { width: 512, height: 512 });

// A PNG on the clipboard, for pasting into a document
await copyQRCodeToClipboard(props, { width: 512, height: 512 });

// The SVG markup, for inlining in a page or an email template
const svg = await getSVGString(props);
```

- `getQRCodeDataUrl(props, format, size, { quality })` akzeptiert jedes Format, das `downloadQRCode` akzeptiert.
- `copyQRCodeToClipboard` schreibt ein PNG. Rufe die Funktion aus einem Klick-Handler auf: Browser verweigern Schreibzugriffe auf die Zwischenablage außerhalb einer Nutzeraktion.
- `getSVGString` bettet das Logo als Data-URL ein, sodass das Markup für sich allein funktioniert. `toSVGString` aus `qrdx/core` ist die synchrone Version ohne diesen Schritt.

## Voreingestellte Größen [#preset-sizes]

```ts title="lib/sizes.ts"
import { PRESET_SIZES, validateSize } from "qrdx";

PRESET_SIZES.small; // { width: 200, height: 200 }
PRESET_SIZES.medium; // 400
PRESET_SIZES.large; // 800
PRESET_SIZES.xlarge; // 1200
PRESET_SIZES["2xl"]; // 1600
PRESET_SIZES["3xl"]; // 2000

validateSize(4000, 4000); // { isValid: true }
validateSize(6000, 6000); // { isValid: false, error: "Size must not exceed 5000x5000 pixels" }
```

Wähle die Größe danach, wohin die Datei geht: 256 bis 512 px für eine Webseite, 1024 px oder mehr für den Druck mit 300 Pixeln pro Zoll (1024 px druckt bis etwa 8,7 cm Breite scharf). Für exakte Druckgrößen nutze die Druckfunktionen, die in Millimetern und Zoll arbeiten.

## PNG in Node [#png-in-node]

`getQRAsPNG` aus `qrdx/node` gibt PNG-Bytes ohne Browser zurück. Es braucht einen optionalen Rasterizer, der neben `qrdx` installiert ist: `@resvg/resvg-js` zeichnet das SVG samt Logos so wie Browser; `sharp` funktioniert ebenfalls.

```ts title="scripts/make-png.ts"
import { writeFile } from "node:fs/promises";
import { getQRAsPNG } from "qrdx/node";

const png = await getQRAsPNG(
  { value: "https://example.com", bodyPattern: "rounded", margin: 4 },
  { size: 1024 }
);
await writeFile("qr-code.png", png);
```

Importiere es aus `qrdx/node`, nie aus `qrdx`, damit Browser-Bundles die nativen Module nie zu sehen bekommen. Ein Logo als Data-URL wird unverändert eingebettet; eine `http(s)`-URL oder ein lokaler Pfad wird nur mit `loadExternalLogos: true` geladen, damit ein Server, der Einstellungen eines Aufrufers durchreicht, nicht dazu gebracht werden kann, interne URLs abzurufen oder die eigene Festplatte zu lesen. SVG-Markup braucht keinen Rasterizer: `toSVGString` aus `qrdx/core` läuft überall.

## Wenn etwas schiefgeht [#if-something-goes-wrong]

- **`Size must be at least 50x50 pixels`, `Size must not exceed 5000x5000 pixels` oder `Width and height must be equal for QR codes`.** `validateSize` hat die Größe abgelehnt. Übergib eine quadratische Größe im gültigen Bereich.
- **`PDF export needs the optional "jspdf" package`.** Installiere `jspdf` im selben Paket wie `qrdx`.
- **Das Logo fehlt in der Datei.** Das Bild stammt von einem anderen Ursprung ohne CORS-Header, daher konnte der Browser es nicht kopieren. Liefere es von deinem eigenen Ursprung aus oder übergib eine Data-URL.
- **`copyQRCodeToClipboard` wird abgelehnt.** Die Funktion lief außerhalb eines Klick- oder Tasten-Handlers, oder die Seite wird nicht über HTTPS ausgeliefert. Rufe sie direkt aus dem Handler auf.
- **`getQRAsPNG` meldet einen fehlenden Rasterizer.** Installiere `@resvg/resvg-js` oder `sharp` neben `qrdx`.
