Trois props donnent sa forme à un code : `bodyPattern` pour les modules de données, `cornerEyePattern` pour les trois yeux d'angle et `cornerEyeDotPattern` pour le point à l'intérieur de chaque œil. Cette page les présente, ainsi que l'échelle des modules, les codes à forme et les couleurs par œil. Chaque valeur est dessinée en direct dans [Formes, yeux et cadres](/docs/styles).

Vous concevez plutôt dans le Playground ou le tableau de bord ? Commencez par [Créer votre premier QR code](/docs/help/getting-started/first-qr-code) dans l'aide.

```tsx title="components/shaped-code.tsx"
import { QRCode } from "qrdx";

export function ShapedCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      bodyPattern="liquid"
      cornerEyePattern="leaf"
      cornerEyeDotPattern="leaf"
    />
  );
}
```

## Motifs du corps [#body-patterns]

`bodyPattern` donne sa forme aux modules de données. Il existe {facts.bodyPatterns} valeurs ; la valeur par défaut est `circle`.

- Classiques : `square`, `small-square`, `horizontal-line`, `vertical-line`, `octagon`
- Arrondis : `circle`, `circle-large`, `rounded`, `liquid`, `liquid-horizontal`, `liquid-vertical`, `random-dots`
- Décoratifs : `classy`, `classy-rounded`, `leaf`, `diamond`, `hexagon`
- Ludiques : `mosaic`, `plus`, `star`, `heart`, `pacman`, `circle-mixed`

`liquid`, `classy` et `classy-rounded` relient les modules voisins en un seul contour lisse ; `liquid-horizontal` et `liquid-vertical` ne les relient qu'en lignes ou en colonnes. `random-dots` et `mosaic` varient d'un module à l'autre, mais dessinent toujours le même code pour une même valeur. Les motifs d'alignement sont toujours dessinés en carrés pleins, quel que soit le motif, afin que les décodeurs les repèrent.

### Échelle des modules [#module-scale]

`moduleScale` (de 0.5 à 1, 1 par défaut) réduit chaque module de données autour de son centre pour un rendu plus léger et plus aéré. Les motifs connectés ont alors des lignes plus fines. Chaque motif cesse de rétrécir à la plus petite taille qui se décode encore dans les tests du package (par exemple 0.95 pour `circle`, 0.7 pour `classy` ; les seuils sont exportés sous le nom `MODULE_SCALE_FLOOR`), et les motifs d'alignement gardent leur taille complète.

```tsx title="components/light-code.tsx"
import { QRCode } from "qrdx";

export function LightCode() {
  return (
    <QRCode
      value="https://example.com"
      bodyPattern="liquid"
      moduleScale={0.8}
    />
  );
}
```

## Cadres des yeux [#eye-frames]

`cornerEyePattern` donne sa forme aux yeux d'angle. Il existe {facts.eyeShapes} valeurs ; la valeur par défaut est `gear` : `square`, `rounded`, `extra-rounded`, `squircle`, `cushion`, `bevel`, `octagon`, `leaf`, `leaf-reverse`, `drop`, `petal`, `shield`, `gear`, `circle`, `diya`, `message` et `pointy`.

`leaf`, `leaf-reverse`, `drop` et `petal` orientent chacun des trois yeux vers son angle du code. Les yeux `circle` peuvent échapper à certaines applications de scan ; le [score de scan](/docs/features/frames#will-it-scan) vous en avertit.

## Centres des yeux [#eye-centers]

`cornerEyeDotPattern` donne sa forme au point à l'intérieur de chaque œil. Il existe {facts.eyeCentres} valeurs ; la valeur par défaut est `circle` : `square`, `rounded`, `extra-rounded`, `circle`, `squircle`, `octagon`, `hexagon`, `dots`, `leaf`, `leaf-reverse`, `drop`, `drop-reverse`, `plus`, `cross-rounded`, `flower`, `heart`, `message`, `message-reverse`, `diya`, `diya-reverse` et `rounded-triangle`.

## Associations à éviter et formes retirées [#pairs-to-avoid-and-retired-shapes]

Les corps `diamond` avec des yeux `square`, `pacman` avec `rounded`, et `small-square` avec des yeux `square` ou `rounded` sont mal lus de près. Le Playground ne les combine pas, ils sont exportés sous le nom `WEAK_BODY_EYES`, et `getStylePairRisk(props)` renvoie l'avertissement affiché par le score de scan.

Un centre `circle` dans des yeux aux angles carrés (`square`, `rounded`, `extra-rounded` et la plupart des autres) peut échapper aux décodeurs stricts dans les rendus nets : à l'écran, dans les exports PNG et dans les grands tirages. Les corps pleins (`square`, `liquid`, `classy`, `classy-rounded`) restent en général lisibles, et les yeux `gear`, `circle` et `octagon` ne sont pas concernés. Le score de scan vous en avertit (`style-pair`) et vous pouvez tout de même faire ce choix. Ces associations sont exportées sous le nom `WEAK_SHARP_DOT_EYES` (avec `SHARP_DOT_EYE_SAFE_BODIES`), et un centre `rounded` évite le problème.

Les yeux `curly` et les centres `diamond`, `star` et `banner` ont été retirés, car leur scan n'est pas fiable. Les designs enregistrés avec ces formes s'affichent toujours, mais elles ne sont plus proposées ni listées ; voir [Formes retirées](/docs/styles#retired-shapes).

## Codes ronds [#circle-codes]

`shape="circle"` place le code dans un disque et remplit le reste avec des modules décoratifs de la même forme de point. Le vrai code conserve autour de lui un anneau clair de `margin` modules (au moins 3), et les scanners ne lisent que le code au centre. Le disque est plus grand que le code : imprimez-le donc un peu plus grand pour la même distance de scan ; le [calculateur de taille d'impression](/tools/print-size) compte le disque entier.

```tsx title="components/circle-code.tsx"
import { QRCode } from "qrdx";

export function CircleCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      shape="circle"
      bodyPattern="rounded"
    />
  );
}
```

Dans les tests de décodage du package, les codes ronds se lisent comme les codes carrés avec des formes de point pleines (`square`, `rounded`, `classy`, `liquid`).

## Codes en cœur [#heart-codes]

`shape="heart"` fonctionne comme un code rond, mais en forme de cœur. Le vrai code se trouve au milieu du cœur avec son anneau clair d'au moins 3 modules, et le reste du cœur se remplit de modules décoratifs. Le code occupe une part plus petite d'un cœur que d'un cercle : imprimez donc un code en cœur plus grand qu'un code carré pour la même distance de scan. Le score de scan en tient compte : à taille égale, un code en cœur obtient un score plus bas qu'un code rond.

```tsx title="components/heart-code.tsx"
import { QRCode } from "qrdx";

export function HeartCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      shape="heart"
      bodyPattern="rounded"
    />
  );
}
```

Dans le Playground, un code à forme remplace le cadre : en choisir un supprime le cadre, et choisir un cadre supprime la forme. Chaque cadre peint une plaque claire sous le code, ce qui masquerait le contour. Le moteur dessine tout de même `shape` avec un `frame` si vous passez les deux. Dans les tests de décodage du package, les codes en cœur se lisent avec toutes les formes de point pleines et avec des yeux `square`, `rounded` et `gear`.

## Formes personnalisées [#custom-shapes]

`shape` accepte aussi une silhouette : une petite grille tracée à partir de votre propre image (64 cellules de côté au maximum). Le code occupe la partie centrale la plus spacieuse de la forme, et le reste de la forme se remplit de modules décoratifs. Seule la grille est conservée, jamais l'image.

```tsx title="components/silhouette-code.tsx"
import { getQRSilhouetteFit, loadQRSilhouette, QRCode } from "qrdx";

export async function silhouetteFrom(file: File) {
  const shape = await loadQRSilhouette(file); // a PNG, JPEG or SVG, in the browser
  const fit = getQRSilhouetteFit(shape);
  if (!fit.ok) throw new Error(fit.message);
  return shape;
}

export function SilhouetteCode({ shape }: { shape: Awaited<ReturnType<typeof silhouetteFrom>> }) {
  return <QRCode value="https://example.com" size={256} shape={shape} />;
}
```

`loadQRSilhouette` dessine l'image sur un canvas et utilise sa transparence, ou son niveau de sombre lorsqu'elle est opaque, de sorte qu'une forme claire sur fond sombre fonctionne aussi. Sur un serveur, passez des pixels RGBA décodés à `createQRSilhouette`. `getQRSilhouetteFit` refuse une forme trop fine pour contenir le code avec sa zone de silence, comme une étoile fine, une barre ou un anneau. Une forme refusée est dessinée comme un code carré.

Dans le tableau de bord, une silhouette reste attachée au design, comme un logo importé : les liens partagés, les éléments de la communauté, les extraits de code et le chat IA utilisent un code carré à la place.

## Couleurs par œil [#per-eye-colors]

`eyeColor` et `dotColor` colorent les trois yeux. `eyeColors` les remplace œil par œil (`topLeft`, `topRight`, `bottomLeft`), chacun avec une couleur ou un dégradé `outer` (cadre) et `inner` (point) :

```tsx title="components/eye-colors-code.tsx"
import { QRCode } from "qrdx";

export function EyeColorsCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      eyeColor="#111827"
      eyeColors={{
        topLeft: { outer: "#dc2626", inner: "#1d4ed8" },
        topRight: { outer: "#16a34a" },
      }}
    />
  );
}
```

Gardez chaque œil foncé par rapport au fond : les décodeurs repèrent le code grâce à ses trois yeux. Le score de scan vérifie le contraste des couleurs propres à chaque œil.
