Um template é uma moldura que encaixa o código dentro de uma arte de tamanho definido. Passe o id dele como `templateId` e o componente desenha a arte inteira em `size`, com o código menor dentro dela. Esta página lista os templates incluídos, as opções do Dot Ring e como desenhar um template em código.

Está criando o design no Playground ou no painel? Os templates aparecem como blocos no grupo **Classic** do seletor de molduras; veja [Adicione uma moldura e uma chamada para ação](/docs/help/designing/frames) na Ajuda.

Os templates diferem das outras [molduras](/docs/features/frames) em um ponto: o tamanho. Uma moldura adiciona espaço ao redor do código, então `size` é a largura do código e a imagem cresce. Um template desenha a arte inteira em `size`, com o código menor dentro dela.

## Templates incluídos [#built-in-templates]

| `templateId` | Nome | Cor |
| --- | --- | --- |
| `Arrow` | Arrow | A cor escura do código (`fgColor`) |
| `StandardBox` | Standard Box | `fgColor` |
| `SquareBorder` | Square Border | `fgColor` |
| `StrikedBox` | Striked Box | Cor escura própria |
| `Halloween` | Halloween | Laranja, verde e preto próprios |
| `DotRing` | Dot Ring | Anel em `fgColor`, texto em branco; os dois podem mudar (abaixo) |

`default` não desenha arte. Ele só recua um pouco o código, para 95% de `size`. Sem `templateId`, o código ocupa todo o `size`.

```tsx title="components/arrow-code.tsx"
import { QRCode } from "qrdx";

export function ArrowCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      templateId="Arrow"
      fgColor="#1a56db"
    />
  );
}
```

<Shot id="lib-templates" />

Cores, padrões e logo continuam nas props do próprio código, então um template funciona com qualquer estilo:

```tsx title="components/boxed-logo-code.tsx"
import { QRCode } from "qrdx";

export function BoxedLogoCode() {
  return (
    <QRCode
      value="https://example.com"
      size={512}
      templateId="StandardBox"
      fgColor="#1a56db"
      level="H"
      logo="/logo.png"
    />
  );
}
```

A Image API recebe um template como `template` e a CLI como `--template`.

## Dot Ring [#dot-ring]

Um código redondo. O código fica em um disco de pontos dentro de um anel escuro, com uma linha de texto ao longo do anel. Os pontos exibidos vêm de um hash do conteúdo do código, então cada link ganha um anel só dele e o mesmo link sempre recebe o mesmo anel.

```tsx title="components/dot-ring-code.tsx"
import { QRCode } from "qrdx";

export function DotRingCode() {
  return (
    <QRCode
      value="https://example.com"
      size={512}
      templateId="DotRing"
      bodyPattern="circle-large"
      customProps={{
        customText: "Scan for the menu",
        textPosition: "bottom",
        textColor: "#fde047",
        outerCircleColor: "#1e3a8a",
      }}
    />
  );
}
```

As configurações ficam em `customProps`, com o tipo `DotRingProps`:

| Prop | Padrão | Observações |
| --- | --- | --- |
| `customText` | "Scan the QR code *" quatro vezes ao redor | Texto ao longo do anel; `""` deixa o anel vazio. Texto longo demais para o anel é ajustado (abaixo) |
| `textFill` | `"none"` | `"repeat"` repete o texto em todo o anel (abaixo) |
| `textPosition` | `"top"` | `"top"`: centralizado no topo, lido no sentido horário. `"bottom"`: centralizado na parte de baixo, lido da esquerda para a direita |
| `textRotation` | `0` | Gira o texto em torno do centro, em graus no sentido horário |
| `textColor` | `#ffffff` | Cor do texto |
| `fontFamily` | pilha de fontes do sistema | Família de fonte CSS do texto |
| `fontWeight` | `900` | Peso da fonte |
| `fontSize` | `32` | No desenho de 593 unidades do template, em que o código tem 300 de largura. Texto longo pode ser desenhado menor |
| `fontLetterSpacing` | `3.5` | Espaço extra entre as letras, nas mesmas unidades. Texto longo e `textFill` o ajustam |
| `outerCircleColor` | `fgColor` | Cor do anel |
| `strokeWidth`, `strokeColor` | `0`, `#000000` | Um contorno nas duas bordas do anel |
| `outerStrokeWidth`, `outerStrokeColor` | `strokeWidth`, `strokeColor` | Só a borda externa do anel |
| `innerStrokeWidth`, `innerStrokeColor` | `strokeWidth`, `strokeColor` | Só a borda interna do anel |

O texto que cabe no anel é desenhado como foi informado, centralizado no topo ou na parte de baixo. O texto longo demais nunca avança sobre o próprio início: primeiro as letras se aproximam, depois a fonte diminui, até a metade do tamanho padrão. Depois disso, o texto fecha o anel com um espaço de palavra no ponto em que encontra o início. Se ainda assim não couber, o texto que repete uma frase mantém o máximo de cópias inteiras que couberem, e os demais textos são cortados depois da última palavra inteira que couber e terminam com reticências.

Um logo vai no meio, como em qualquer código. Links longos (códigos com mais de 49 módulos de largura) mantêm uma faixa clara entre o código e os pontos, para que ainda tenham leitura mesmo impressos pequenos.

O texto é texto SVG na fonte que você escolher; o padrão é a pilha de fontes do sistema, então nada é baixado. Os downloads de SVG e PNG no navegador usam as fontes de quem está vendo. PDF e EPS imprimem o texto em Helvetica Bold, então use texto Latin-1 nesses formatos. `getQRAsPNG` de `qrdx/node` precisa de uma fonte instalada no servidor, assim como os rótulos das molduras.

### Preencha o anel [#fill-the-ring]

Uma frase curta deixa parte do anel vazia. Defina `textFill: "repeat"` para repeti-la quantas vezes couber, com o espaçamento uniformizado para que o anel feche com o mesmo intervalo que há entre as cópias:

```tsx title="components/docs-ring-code.tsx"
import { QRCode } from "qrdx";

export function DocsRingCode() {
  return (
    <QRCode
      value="https://example.com/docs"
      size={512}
      templateId="DotRing"
      customProps={{ customText: "Read the docs *", textFill: "repeat" }}
    />
  );
}
```

Informe a frase uma vez só. Um texto que já repete uma frase, como `"Make your own * Make your own *"`, é lido como essa frase e por isso preenche o anel do mesmo jeito.

## Templates são especificações de moldura [#templates-are-frame-specs]

A arte de Arrow, Standard Box, Square Border, Striked Box e Halloween é uma [especificação de moldura](/docs/features/frames#frame-specs), o mesmo formato JSON de todas as outras molduras, desenhado pelo mesmo mecanismo. `getTemplate(id).spec` a retorna. Use-a como moldura quando quiser o dimensionamento de moldura (o código mantém o tamanho e a arte cresce ao redor) e a opção de cor da moldura:

```tsx title="components/arrow-frame-code.tsx"
import { getTemplate, QRCode } from "qrdx";

const spec = getTemplate("Arrow")?.spec;

export function ArrowFrameCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      frame={spec && { style: "custom", spec, color: "#1a56db" }}
    />
  );
}
```

O Dot Ring não tem especificação: os pontos vêm do conteúdo do código, então ele os desenha em código (veja [Desenhe um template em código](#draw-a-template-in-code)).

`templateId` desenha a mesma arte de antes. Designs salvos, URLs de imagem, comandos da CLI e códigos que usam um id de template continuam com a mesma aparência de sempre.

## Registro de templates [#template-registry]

```ts title="lib/templates.ts"
import { getAllTemplates, getTemplate, getTemplateIds } from "qrdx";

getTemplateIds(); // ["default", "Arrow", "StandardBox", "SquareBorder", "StrikedBox", "Halloween", "DotRing"]
getAllTemplates(); // every TemplateDefinition, with its id and name
getTemplate("Halloween"); // one by id, or undefined
```

## Desenhe um template em código [#draw-a-template-in-code]

Uma especificação de moldura descreve uma arte fixa. Quando a arte precisa ser calculada, escreva um `TemplateDefinition` e passe-o como `customTemplate`. O `wrapper` recebe o código como `children` e retorna o SVG a ser desenhado. Ele desenha em um canvas de 300 por 300, e o código chega nesse mesmo tamanho, então reduza-o para deixar espaço para a sua arte. `props` traz o `fgColor` e o `bgColor` do código, e o terceiro argumento traz o `url` e o `pixelSize` do código.

Este desenha um anel ao redor do código:

```tsx title="components/ring-template-code.tsx"
import { QRCode, type TemplateDefinition } from "qrdx";

const ringTemplate: TemplateDefinition = {
  id: "ring",
  name: "Ring",
  wrapper: (children, props) => (
    <svg
      viewBox="0 0 300 300"
      width="300"
      height="300"
      xmlns="http://www.w3.org/2000/svg"
    >
      <circle
        cx="150"
        cy="150"
        r="140"
        fill="none"
        stroke={props?.fgColor ?? "#000000"}
        strokeWidth="8"
      />
      {/* The code at half size, centered */}
      <g transform="translate(75, 75) scale(0.5)">{children}</g>
    </svg>
  ),
};

export function RingTemplateCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      customTemplate={ringTemplate}
      fgColor="#1a56db"
    />
  );
}
```

`customTemplate` tem prioridade sobre `templateId` quando os dois são definidos. Mantenha o código grande o bastante para ter leitura de onde as pessoas vão segurar o celular e deixe um espaço claro entre ele e a sua arte. Confira o resultado com a [nota de leitura](/docs/features/frames#will-it-scan). Sem JSX, escreva o wrapper com `h` de `qrdx/core`; veja [JavaScript puro](/docs/vanilla-js#custom-templates-without-jsx).
