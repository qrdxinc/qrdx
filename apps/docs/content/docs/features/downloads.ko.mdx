`downloadQRCode(props, options)`는 `props`로 설명한 코드를 브라우저에서 파일로 저장하며, 여섯 가지 형식을 지원합니다. 같은 계열의 다른 함수는 같은 파일을 데이터 URL, Blob 또는 마크업으로 반환하고, `qrdx/node`는 서버에서 PNG를 만듭니다. 모든 함수는 `QRCode`와 같은 `props`를 받으므로 파일이 화면의 코드와 일치합니다.

Playground나 대시보드에서 다운로드하려면 도움말의 [QR 코드 다운로드 및 인쇄](/docs/help/getting-started/download-and-print)를 참고하세요.

## 파일 다운로드 [#download-a-file]

```ts title="lib/download.ts"
import { downloadQRCode } from "qrdx";

await downloadQRCode(
  {
    value: "https://example.com",
    fgColor: "#1d4ed8",
    bodyPattern: "rounded",
    frame: { style: "banner-bottom", text: "Scan me" },
  },
  {
    format: "png",
    size: { width: 1024, height: 1024 },
    filename: "menu.png",
  }
);
```

<Shot id="lib-download-result" />

브라우저가 `menu.png`를 저장합니다. `size`는 코드 자체의 가로·세로 픽셀 크기로, 50에서 5000까지의 정사각형입니다. 프레임을 쓰면 파일이 그보다 커집니다. `filename`은 선택 사항입니다. 생략하면 파일 이름은 `qr-code.<ext>`가 되고, 래스터 형식에는 정확한 픽셀 크기가 붙습니다(`qr-code-1024x1024.png`, 하단 배너가 있으면 `qr-code-1270x1454.png`). `quality`(0에서 1)는 WebP에만 적용됩니다.

props는 `QRCode`와 같지만, 로고는 `imageSettings`에 넣습니다. `QRCode`가 그리는 코드를 `logo`와 `logoOptions`까지 포함해 내보내려면 원본 props 대신 `getQRData(props)` 또는 `resolveQRCodeProps(props)`를 전달하세요.

## 형식 [#formats]

| `format` | 파일 | 참고 |
| --- | --- | --- |
| `png` | 이미지 | 투명 배경을 유지합니다. 대부분의 용도에 맞는 기본값입니다 |
| `jpg` | 이미지 | 단색 배경만 지원하며 파일이 더 작습니다 |
| `webp` | 이미지 | PNG와 같은 픽셀을 더 작은 파일에 담습니다. `quality`를 지정하지 않으면 무손실입니다 |
| `svg` | 벡터 | 어떤 크기에서도 선명합니다. 인쇄소와 디자인 도구에 적합한 파일입니다 |
| `pdf` | 문서 | 코드를 PNG로 담은 한 페이지입니다. 선택 패키지인 `jspdf`가 필요합니다 |
| `eps` | 벡터 | Illustrator, CorelDRAW, InDesign용 PostScript입니다. `size.width`는 포인트(인치당 72) 단위로 해석됩니다 |

### WebP [#webp]

WebP는 기본적으로 무손실이므로 모듈 가장자리가 정확하게 유지되고 투명 배경도 그대로 투명합니다. 브라우저의 캔버스가 무손실 WebP를 쓸 수 있는 환경(Chrome과 Edge)에서는 브라우저가 파일을 만듭니다. 그렇지 않은 환경에서는 라이브러리가 바이트를 확인하고, 내장된 작은 무손실 인코더로 픽셀을 직접 인코딩합니다. Safari는 WebP를 요청하면 PNG를 반환하기 때문입니다. 어느 쪽이든 `.webp` 파일은 항상 WebP입니다.

`quality`(0에서 1)를 지정하면 브라우저가 지원하는 경우 더 작은 손실 압축 파일을 요청합니다. 손실 WebP는 모듈 가장자리와 색상을 흐리게 하므로, 멀리서 스캔해야 하는 코드에는 기본값을 유지하세요. `getQRAsWebP`는 파일을 `Blob`으로 반환합니다.

```ts title="lib/webp.ts"
import { getQRAsWebP } from "qrdx";

const lossless = await getQRAsWebP({ value: "https://example.com", size: 1024 });
const lossy = await getQRAsWebP({ value: "https://example.com", size: 1024 }, { quality: 0.9 });
```

`canvasToWebP(canvas, options)`는 모든 캔버스에 같은 작업을 하고, `encodeWebPLossless(rgba, width, height)`는 DOM 없이 RGBA 픽셀을 인코딩합니다.

### PDF [#pdf]

PDF 다운로드는 코드를 PNG로 만들어 같은 크기의 페이지에 담습니다. 선택 패키지인 `jspdf`(`npm install jspdf`)가 필요하며, 없으면 PDF 다운로드에서 `PDF export needs the optional "jspdf" package` 오류가 발생합니다. 실제 물리 크기의 벡터 PDF를 도련, 재단선, CMYK와 함께 만들려면 `downloadPrintPDF`를 사용하세요. [인쇄용 내보내기](/docs/features/frames#print-ready-export)를 참고하세요.

### EPS [#eps]

EPS에는 추가 패키지가 필요 없습니다. `downloadQRCode`는 `size.width`를 포인트로 해석하므로, 512 px을 요청하면 512 pt(18 cm) 파일이 만들어집니다. 정확한 물리 크기가 필요하면 EPS를 문자열로 반환하는 `getQRAsEPS`를 사용하세요. 코드의 너비는 `sizeMm`(기본값 50 mm)이며, 프레임을 쓰면 그만큼 더해집니다.

```ts title="lib/eps.ts"
import { downloadPrintEPS, getQRAsEPS } from "qrdx";

const eps = await getQRAsEPS(
  { value: "https://example.com" },
  { sizeMm: 40, bleedMm: 3, colorMode: "cmyk" }
);

await downloadPrintEPS({ value: "https://example.com" }, { sizeMm: 40, filename: "menu.eps" });
```

EPS는 투명도와 재단선을 지원하지 않습니다. 선형 및 방사형 그라데이션은 매끄러운 PostScript Level 3 셰이딩으로 출력되고, 각도형 그라데이션은 가느다란 쐐기 모양을 부채꼴로 이어 붙여 출력됩니다. 투명한 색상은 배경과 혼합되고, 배경은 흰 종이와 혼합됩니다. PNG와 JPEG 로고는 포함됩니다. EPS에서는 [이미지 채우기](/docs/features/colors-gradients#image-fills)를 사용할 수 없습니다. `getQRAsEPS`는 `EPS_IMAGE_FILL_REASON` 오류를 발생시키며, 대시보드의 다운로드 대화상자에서는 대신 PDF, SVG, PNG를 제공합니다.

## 데이터 URL, Blob, 마크업 [#data-urls-blobs-and-markup]

```ts title="lib/export.ts"
import { copyQRCodeToClipboard, getQRCodeDataUrl, getSVGString } from "qrdx";

const props = { value: "https://example.com", size: 512 };

// The same file as a data URL, for an <img> or a form field
const png = await getQRCodeDataUrl(props, "png", { width: 512, height: 512 });

// A PNG on the clipboard, for pasting into a document
await copyQRCodeToClipboard(props, { width: 512, height: 512 });

// The SVG markup, for inlining in a page or an email template
const svg = await getSVGString(props);
```

- `getQRCodeDataUrl(props, format, size, { quality })`는 `downloadQRCode`가 받는 모든 형식을 지원합니다.
- `copyQRCodeToClipboard`는 PNG를 씁니다. 클릭 핸들러에서 호출하세요. 브라우저는 사용자 동작 밖에서의 클립보드 쓰기를 거부합니다.
- `getSVGString`은 로고를 데이터 URL로 포함하므로 마크업만으로 완결됩니다. `qrdx/core`의 `toSVGString`은 이 단계가 없는 동기 버전입니다.

## 크기 프리셋 [#preset-sizes]

```ts title="lib/sizes.ts"
import { PRESET_SIZES, validateSize } from "qrdx";

PRESET_SIZES.small; // { width: 200, height: 200 }
PRESET_SIZES.medium; // 400
PRESET_SIZES.large; // 800
PRESET_SIZES.xlarge; // 1200
PRESET_SIZES["2xl"]; // 1600
PRESET_SIZES["3xl"]; // 2000

validateSize(4000, 4000); // { isValid: true }
validateSize(6000, 6000); // { isValid: false, error: "Size must not exceed 5000x5000 pixels" }
```

파일을 쓸 곳에 맞춰 크기를 고르세요. 웹 페이지에는 256~512 px, 인치당 300픽셀로 인쇄할 때는 1024 px 이상이 좋습니다(1024 px은 너비 약 8.7 cm까지 선명하게 인쇄됩니다). 정확한 인쇄 크기가 필요하면 밀리미터와 인치 단위로 작동하는 인쇄 함수를 사용하세요.

## Node에서 PNG 만들기 [#png-in-node]

`qrdx/node`의 `getQRAsPNG`는 브라우저 없이 PNG 바이트를 반환합니다. `qrdx` 옆에 선택 래스터라이저를 하나 설치해야 합니다. `@resvg/resvg-js`는 브라우저와 같은 방식으로 로고를 포함해 SVG를 그리며, `sharp`도 사용할 수 있습니다.

```ts title="scripts/make-png.ts"
import { writeFile } from "node:fs/promises";
import { getQRAsPNG } from "qrdx/node";

const png = await getQRAsPNG(
  { value: "https://example.com", bodyPattern: "rounded", margin: 4 },
  { size: 1024 }
);
await writeFile("qr-code.png", png);
```

브라우저 번들에 네이티브 모듈이 포함되지 않도록 `qrdx`가 아니라 `qrdx/node`에서 가져오세요. 데이터 URL인 로고는 그대로 포함됩니다. `http(s)` URL이나 로컬 경로는 `loadExternalLogos: true`일 때만 불러오므로, 호출자의 설정을 그대로 전달하는 서버가 내부 URL을 가져오거나 자체 디스크를 읽도록 악용될 수 없습니다. SVG 마크업에는 래스터라이저가 필요 없습니다. `qrdx/core`의 `toSVGString`은 어디서나 실행됩니다.

## 문제가 생겼다면 [#if-something-goes-wrong]

- **`Size must be at least 50x50 pixels`, `Size must not exceed 5000x5000 pixels` 또는 `Width and height must be equal for QR codes`.** `validateSize`가 크기를 거부했습니다. 범위 안의 정사각형 크기를 전달하세요.
- **`PDF export needs the optional "jspdf" package`.** `qrdx`와 같은 패키지에 `jspdf`를 설치하세요.
- **파일에 로고가 없습니다.** 이미지가 CORS 헤더 없이 다른 출처에서 와서 브라우저가 복사할 수 없었습니다. 자체 출처에서 제공하거나 데이터 URL을 전달하세요.
- **`copyQRCodeToClipboard`가 거부됩니다.** 클릭이나 키 핸들러 밖에서 실행되었거나, 페이지가 HTTPS로 제공되지 않습니다. 핸들러 안에서 직접 호출하세요.
- **`getQRAsPNG`가 래스터라이저가 없다는 오류를 냅니다.** `qrdx` 옆에 `@resvg/resvg-js` 또는 `sharp`를 설치하세요.
