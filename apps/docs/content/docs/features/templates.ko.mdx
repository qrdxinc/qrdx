템플릿은 정해진 크기의 아트워크 안에 코드를 맞춰 넣는 프레임입니다. 템플릿 id를 `templateId`로 전달하면 컴포넌트가 전체 아트워크를 `size`로 그리고, 코드는 그 안에서 더 작게 그려집니다. 이 페이지에서는 기본 제공 템플릿, Dot Ring 옵션, 코드로 템플릿을 그리는 방법을 안내합니다.

Playground나 대시보드에서 디자인하시나요? 템플릿은 프레임 선택기의 **클래식** 그룹에 타일로 표시됩니다. 도움말의 [프레임과 행동 유도 문구 추가하기](/docs/help/designing/frames)를 참고하세요.

템플릿은 크기 면에서 다른 [프레임](/docs/features/frames)과 다릅니다. 프레임은 코드 주위에 여백을 추가하므로 `size`가 코드의 너비가 되고 이미지가 커집니다. 템플릿은 전체 아트워크를 `size`로 그리고, 코드는 그 안에서 더 작게 그려집니다.

## 기본 제공 템플릿 [#built-in-templates]

| `templateId` | 이름 | 색상 |
| --- | --- | --- |
| `Arrow` | Arrow | 코드의 어두운 색(`fgColor`) |
| `StandardBox` | Standard Box | `fgColor` |
| `SquareBorder` | Square Border | `fgColor` |
| `StrikedBox` | Striked Box | 자체 어두운 색 |
| `Halloween` | Halloween | 자체 주황색, 녹색, 검은색 |
| `DotRing` | Dot Ring | 링은 `fgColor`, 텍스트는 흰색이며 둘 다 변경할 수 있습니다(아래 참고) |

`default`는 아트워크를 그리지 않습니다. 코드를 `size`의 95%로 조금 안쪽에 배치할 뿐입니다. `templateId`가 없으면 코드가 `size`를 가득 채웁니다.

```tsx title="components/arrow-code.tsx"
import { QRCode } from "qrdx";

export function ArrowCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      templateId="Arrow"
      fgColor="#1a56db"
    />
  );
}
```

<Shot id="lib-templates" />

색상, 패턴, 로고는 코드 자체의 props로 유지되므로 어떤 스타일에서도 템플릿을 사용할 수 있습니다.

```tsx title="components/boxed-logo-code.tsx"
import { QRCode } from "qrdx";

export function BoxedLogoCode() {
  return (
    <QRCode
      value="https://example.com"
      size={512}
      templateId="StandardBox"
      fgColor="#1a56db"
      level="H"
      logo="/logo.png"
    />
  );
}
```

이미지 API에서는 템플릿을 `template`으로, CLI에서는 `--template`으로 전달합니다.

## Dot Ring [#dot-ring]

둥근 형태의 코드입니다. 코드는 어두운 링 안쪽의 점으로 이루어진 원판 위에 놓이고, 링을 따라 한 줄의 텍스트가 배치됩니다. 어떤 점이 표시될지는 코드 내용의 해시로 정해지므로 링크마다 고유한 링이 만들어지고, 같은 링크는 항상 같은 링을 얻습니다.

```tsx title="components/dot-ring-code.tsx"
import { QRCode } from "qrdx";

export function DotRingCode() {
  return (
    <QRCode
      value="https://example.com"
      size={512}
      templateId="DotRing"
      bodyPattern="circle-large"
      customProps={{
        customText: "Scan for the menu",
        textPosition: "bottom",
        textColor: "#fde047",
        outerCircleColor: "#1e3a8a",
      }}
    />
  );
}
```

설정은 `customProps`에 넣으며 타입은 `DotRingProps`입니다.

| Prop | 기본값 | 설명 |
| --- | --- | --- |
| `customText` | "Scan the QR code *"를 링을 따라 네 번 반복 | 링을 따라 배치되는 텍스트입니다. `""`로 설정하면 링이 비어 있습니다. 링에 비해 너무 긴 텍스트는 맞춰 조정됩니다(아래 참고) |
| `textFill` | `"none"` | `"repeat"`는 텍스트를 링 전체에 반복합니다(아래 참고) |
| `textPosition` | `"top"` | `"top"`: 위쪽 중앙에 시계 방향으로 읽히도록 배치합니다. `"bottom"`: 아래쪽 중앙에 왼쪽에서 오른쪽으로 읽히도록 배치합니다 |
| `textRotation` | `0` | 텍스트를 중심을 기준으로 시계 방향으로 회전합니다(단위: 도) |
| `textColor` | `#ffffff` | 텍스트 색상 |
| `fontFamily` | 시스템 글꼴 스택 | 텍스트의 CSS 글꼴 패밀리 |
| `fontWeight` | `900` | 글꼴 두께 |
| `fontSize` | `32` | 코드의 너비가 300인 템플릿의 593단위 도면 기준입니다. 긴 텍스트는 더 작게 그려질 수 있습니다 |
| `fontLetterSpacing` | `3.5` | 글자 사이의 추가 간격이며 같은 단위를 사용합니다. 긴 텍스트와 `textFill`이 이 값을 조정합니다 |
| `outerCircleColor` | `fgColor` | 링 색상 |
| `strokeWidth`, `strokeColor` | `0`, `#000000` | 링의 양쪽 가장자리를 따라 그리는 선 |
| `outerStrokeWidth`, `outerStrokeColor` | `strokeWidth`, `strokeColor` | 링의 바깥쪽 가장자리에만 적용 |
| `innerStrokeWidth`, `innerStrokeColor` | `strokeWidth`, `strokeColor` | 링의 안쪽 가장자리에만 적용 |

링에 들어가는 텍스트는 지정한 그대로 위쪽 중앙이나 아래쪽을 따라 배치됩니다. 너무 긴 텍스트는 자기 시작 부분과 겹치지 않습니다. 먼저 글자 간격이 좁아지고, 그다음 글꼴이 기본 크기의 절반까지 작아집니다. 그런 다음 텍스트가 시작 부분과 만나는 곳에 단어 간격을 두어 링을 닫습니다. 그래도 맞지 않으면, 문구를 반복하는 텍스트는 들어가는 만큼의 전체 반복만 남기고, 다른 텍스트는 들어가는 마지막 온전한 단어 뒤에서 잘라 말줄임표로 끝냅니다.

로고는 다른 코드와 마찬가지로 가운데에 들어갑니다. 긴 링크(가로 49모듈을 넘는 코드)는 코드와 점 사이에 밝은 띠를 유지하므로 작게 인쇄해도 스캔됩니다.

텍스트는 선택한 글꼴의 SVG 텍스트입니다. 기본값은 시스템 글꼴 스택이므로 다운로드되는 것이 없습니다. 브라우저에서 SVG와 PNG를 다운로드하면 보는 사람의 글꼴이 사용됩니다. PDF와 EPS는 Helvetica Bold로 인쇄하므로 여기에서는 Latin-1 텍스트를 사용하세요. `qrdx/node`의 `getQRAsPNG`는 프레임 라벨과 마찬가지로 서버에 설치된 글꼴이 필요합니다.

### 링 채우기 [#fill-the-ring]

짧은 문구는 링의 일부를 비워 둡니다. `textFill: "repeat"`를 설정하면 들어가는 만큼 문구를 반복하고, 링이 복사본 사이의 간격과 같은 간격으로 닫히도록 간격을 고르게 맞춥니다.

```tsx title="components/docs-ring-code.tsx"
import { QRCode } from "qrdx";

export function DocsRingCode() {
  return (
    <QRCode
      value="https://example.com/docs"
      size={512}
      templateId="DotRing"
      customProps={{ customText: "Read the docs *", textFill: "repeat" }}
    />
  );
}
```

문구는 한 번만 입력하세요. `"Make your own * Make your own *"`처럼 이미 문구를 반복하는 텍스트는 해당 문구로 인식되므로 같은 방식으로 링을 채웁니다.

## 템플릿은 프레임 스펙입니다 [#templates-are-frame-specs]

Arrow, Standard Box, Square Border, Striked Box, Halloween의 아트워크는 다른 모든 프레임과 같은 JSON 형식이며 같은 엔진으로 그려지는 [프레임 스펙](/docs/features/frames#frame-specs)입니다. `getTemplate(id).spec`이 이를 반환합니다. 프레임 크기 방식(코드는 크기를 유지하고 아트워크가 주위로 커집니다)과 프레임의 색상 옵션을 원할 때 프레임으로 사용하세요.

```tsx title="components/arrow-frame-code.tsx"
import { getTemplate, QRCode } from "qrdx";

const spec = getTemplate("Arrow")?.spec;

export function ArrowFrameCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      frame={spec && { style: "custom", spec, color: "#1a56db" }}
    />
  );
}
```

Dot Ring에는 스펙이 없습니다. 점이 코드 내용에서 만들어지므로 코드로 그립니다([코드로 템플릿 그리기](#draw-a-template-in-code) 참고).

`templateId`는 이전과 같은 아트워크를 그립니다. 템플릿 id를 사용하는 저장된 디자인, 이미지 URL, CLI 명령, 코드는 예전과 똑같이 보입니다.

## 템플릿 레지스트리 [#template-registry]

```ts title="lib/templates.ts"
import { getAllTemplates, getTemplate, getTemplateIds } from "qrdx";

getTemplateIds(); // ["default", "Arrow", "StandardBox", "SquareBorder", "StrikedBox", "Halloween", "DotRing"]
getAllTemplates(); // every TemplateDefinition, with its id and name
getTemplate("Halloween"); // one by id, or undefined
```

## 코드로 템플릿 그리기 [#draw-a-template-in-code]

프레임 스펙은 고정된 아트워크를 설명합니다. 아트워크를 계산해야 할 때는 `TemplateDefinition`을 작성해 `customTemplate`으로 전달하세요. `wrapper`는 코드를 `children`으로 받아 그릴 SVG를 반환합니다. 300×300 캔버스에 그리며 코드도 같은 크기로 전달되므로, 아트워크가 들어갈 공간을 남기도록 코드를 축소하세요. `props`에는 코드의 `fgColor`와 `bgColor`가 들어 있고, 세 번째 인자에는 코드의 `url`과 `pixelSize`가 있습니다.

다음은 코드 주위에 링을 그리는 예시입니다.

```tsx title="components/ring-template-code.tsx"
import { QRCode, type TemplateDefinition } from "qrdx";

const ringTemplate: TemplateDefinition = {
  id: "ring",
  name: "Ring",
  wrapper: (children, props) => (
    <svg
      viewBox="0 0 300 300"
      width="300"
      height="300"
      xmlns="http://www.w3.org/2000/svg"
    >
      <circle
        cx="150"
        cy="150"
        r="140"
        fill="none"
        stroke={props?.fgColor ?? "#000000"}
        strokeWidth="8"
      />
      {/* The code at half size, centered */}
      <g transform="translate(75, 75) scale(0.5)">{children}</g>
    </svg>
  ),
};

export function RingTemplateCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      customTemplate={ringTemplate}
      fgColor="#1a56db"
    />
  );
}
```

둘 다 설정하면 `customTemplate`이 `templateId`보다 우선합니다. 사람들이 휴대폰을 들고 스캔할 거리에서 읽힐 만큼 코드를 크게 유지하고, 코드와 아트워크 사이에 밝은 여백을 남기세요. 결과는 [스캔 점수](/docs/features/frames#will-it-scan)로 확인하세요. JSX를 쓰지 않는 경우 `qrdx/core`의 `h`로 wrapper를 작성하세요. [Vanilla JavaScript](/docs/vanilla-js#custom-templates-without-jsx)를 참고하세요.
