Una plantilla es un marco que encaja el código dentro de una ilustración de tamaño fijo. Pasa su id como `templateId` y el componente dibuja toda la ilustración con el tamaño `size`, con el código más pequeño en su interior. Esta página enumera las plantillas integradas, las opciones de Dot Ring y cómo dibujar una plantilla en código.

¿Diseñas en el Playground o en el panel? Las plantillas son mosaicos del grupo **Clásico** del selector de marcos; consulta [Añade un marco y una llamada a la acción](/docs/help/designing/frames) en la Ayuda.

Las plantillas se diferencian de los demás [marcos](/docs/features/frames) en una cosa: el tamaño. Un marco añade espacio alrededor del código, así que `size` es el ancho del código y la imagen crece. Una plantilla dibuja toda su ilustración con el tamaño `size`, con el código más pequeño en su interior.

## Plantillas integradas [#built-in-templates]

| `templateId` | Nombre | Color |
| --- | --- | --- |
| `Arrow` | Arrow | El color oscuro del código (`fgColor`) |
| `StandardBox` | Standard Box | `fgColor` |
| `SquareBorder` | Square Border | `fgColor` |
| `StrikedBox` | Striked Box | Su propio color oscuro |
| `Halloween` | Halloween | Su propio naranja, verde y negro |
| `DotRing` | Dot Ring | Su anillo en `fgColor`, su texto en blanco; ambos se pueden cambiar (abajo) |

`default` no dibuja ninguna ilustración. Solo reduce un poco el código, al 95 % de `size`. Sin `templateId`, el código ocupa todo `size`.

```tsx title="components/arrow-code.tsx"
import { QRCode } from "qrdx";

export function ArrowCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      templateId="Arrow"
      fgColor="#1a56db"
    />
  );
}
```

<Shot id="lib-templates" />

Los colores, los patrones y el logo siguen en las propiedades del propio código, así que una plantilla funciona con cualquier estilo:

```tsx title="components/boxed-logo-code.tsx"
import { QRCode } from "qrdx";

export function BoxedLogoCode() {
  return (
    <QRCode
      value="https://example.com"
      size={512}
      templateId="StandardBox"
      fgColor="#1a56db"
      level="H"
      logo="/logo.png"
    />
  );
}
```

La Image API recibe una plantilla como `template` y la CLI como `--template`.

## Dot Ring [#dot-ring]

Un código redondo. El código está en un disco de puntos dentro de un anillo oscuro, con una línea de texto colocada a lo largo del anillo. Los puntos que se muestran salen de un hash del contenido del código, así que cada enlace tiene su propio anillo y el mismo enlace siempre obtiene el mismo.

```tsx title="components/dot-ring-code.tsx"
import { QRCode } from "qrdx";

export function DotRingCode() {
  return (
    <QRCode
      value="https://example.com"
      size={512}
      templateId="DotRing"
      bodyPattern="circle-large"
      customProps={{
        customText: "Scan for the menu",
        textPosition: "bottom",
        textColor: "#fde047",
        outerCircleColor: "#1e3a8a",
      }}
    />
  );
}
```

Sus ajustes van en `customProps`, con el tipo `DotRingProps`:

| Propiedad | Valor por defecto | Notas |
| --- | --- | --- |
| `customText` | "Scan the QR code *" cuatro veces alrededor | Texto a lo largo del anillo; `""` deja el anillo vacío. El texto demasiado largo para el anillo se ajusta (abajo) |
| `textFill` | `"none"` | `"repeat"` repite el texto por todo el anillo (abajo) |
| `textPosition` | `"top"` | `"top"`: centrado en la parte superior, se lee en sentido horario. `"bottom"`: centrado a lo largo de la parte inferior, se lee de izquierda a derecha |
| `textRotation` | `0` | Gira el texto alrededor del centro, en grados en sentido horario |
| `textColor` | `#ffffff` | Color del texto |
| `fontFamily` | pila de fuentes del sistema | Familia de fuentes CSS del texto |
| `fontWeight` | `900` | Grosor de la fuente |
| `fontSize` | `32` | En el dibujo de 593 unidades de la plantilla, donde el código mide 300 de ancho. El texto largo puede dibujarse más pequeño |
| `fontLetterSpacing` | `3.5` | Espacio extra entre letras, en las mismas unidades. El texto largo y `textFill` lo ajustan |
| `outerCircleColor` | `fgColor` | Color del anillo |
| `strokeWidth`, `strokeColor` | `0`, `#000000` | Un trazo a lo largo de ambos bordes del anillo |
| `outerStrokeWidth`, `outerStrokeColor` | `strokeWidth`, `strokeColor` | Solo el borde exterior del anillo |
| `innerStrokeWidth`, `innerStrokeColor` | `strokeWidth`, `strokeColor` | Solo el borde interior del anillo |

El texto que cabe en el anillo se coloca tal cual, centrado en la parte superior o a lo largo de la inferior. El texto demasiado largo nunca choca con su propio comienzo: primero las letras se acercan, y después la fuente se hace más pequeña, hasta la mitad del tamaño por defecto. Entonces el texto cierra el anillo con un espacio de palabra donde se une con su inicio. Si aun así no cabe, el texto que repite una frase conserva tantas copias completas como quepan, y el resto del texto se corta después de la última palabra completa que quepa y termina con puntos suspensivos.

Un logo va en el centro, como en cualquier código. Los enlaces largos (códigos de más de 49 módulos de ancho) conservan una banda clara entre el código y los puntos, para que se sigan escaneando al imprimirlos pequeños.

El texto es texto SVG con la fuente que elijas; por defecto se usa la pila de fuentes del sistema, así que no se descarga nada. Las descargas de SVG y PNG en el navegador usan las fuentes del visitante. PDF y EPS lo imprimen en Helvetica Bold, así que usa texto Latin-1 ahí. `getQRAsPNG` de `qrdx/node` necesita una fuente instalada en el servidor, igual que las etiquetas de los marcos.

### Rellenar el anillo [#fill-the-ring]

Una frase corta deja parte del anillo vacía. Define `textFill: "repeat"` para repetirla tantas veces como quepa, con el espaciado repartido de forma uniforme para que el anillo se cierre con el mismo hueco que hay entre las copias:

```tsx title="components/docs-ring-code.tsx"
import { QRCode } from "qrdx";

export function DocsRingCode() {
  return (
    <QRCode
      value="https://example.com/docs"
      size={512}
      templateId="DotRing"
      customProps={{ customText: "Read the docs *", textFill: "repeat" }}
    />
  );
}
```

Escribe la frase una sola vez. El texto que ya repite una frase, como `"Make your own * Make your own *"`, se interpreta como esa frase, así que rellena el anillo de la misma manera.

## Las plantillas son especificaciones de marco [#templates-are-frame-specs]

La ilustración de Arrow, Standard Box, Square Border, Striked Box y Halloween es una [especificación de marco](/docs/features/frames#frame-specs), con el mismo formato JSON que cualquier otro marco, dibujada por el mismo motor. `getTemplate(id).spec` la devuelve. Úsala como marco cuando quieras el dimensionado de un marco (el código conserva su tamaño y la ilustración crece a su alrededor) y la opción de color del marco:

```tsx title="components/arrow-frame-code.tsx"
import { getTemplate, QRCode } from "qrdx";

const spec = getTemplate("Arrow")?.spec;

export function ArrowFrameCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      frame={spec && { style: "custom", spec, color: "#1a56db" }}
    />
  );
}
```

Dot Ring no tiene especificación: sus puntos salen del contenido del código, así que los dibuja en código (consulta [Dibuja una plantilla en código](#draw-a-template-in-code)).

`templateId` dibuja la misma ilustración de antes. Los diseños guardados, las URL de imagen, los comandos de la CLI y el código que usan un id de plantilla se ven igual que siempre.

## Registro de plantillas [#template-registry]

```ts title="lib/templates.ts"
import { getAllTemplates, getTemplate, getTemplateIds } from "qrdx";

getTemplateIds(); // ["default", "Arrow", "StandardBox", "SquareBorder", "StrikedBox", "Halloween", "DotRing"]
getAllTemplates(); // every TemplateDefinition, with its id and name
getTemplate("Halloween"); // one by id, or undefined
```

## Dibuja una plantilla en código [#draw-a-template-in-code]

Una especificación de marco describe una ilustración fija. Cuando la ilustración hay que calcularla, escribe un `TemplateDefinition` y pásalo como `customTemplate`. Su `wrapper` recibe el código como `children` y devuelve el SVG que se dibujará. Dibuja sobre un lienzo de 300 por 300, y el código llega también con ese tamaño, así que redúcelo para dejar espacio a tu ilustración. `props` lleva el `fgColor` y el `bgColor` del código, y el tercer argumento tiene la `url` y el `pixelSize` del código.

Este dibuja un anillo alrededor del código:

```tsx title="components/ring-template-code.tsx"
import { QRCode, type TemplateDefinition } from "qrdx";

const ringTemplate: TemplateDefinition = {
  id: "ring",
  name: "Ring",
  wrapper: (children, props) => (
    <svg
      viewBox="0 0 300 300"
      width="300"
      height="300"
      xmlns="http://www.w3.org/2000/svg"
    >
      <circle
        cx="150"
        cy="150"
        r="140"
        fill="none"
        stroke={props?.fgColor ?? "#000000"}
        strokeWidth="8"
      />
      {/* The code at half size, centered */}
      <g transform="translate(75, 75) scale(0.5)">{children}</g>
    </svg>
  ),
};

export function RingTemplateCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      customTemplate={ringTemplate}
      fgColor="#1a56db"
    />
  );
}
```

`customTemplate` tiene prioridad sobre `templateId` cuando se definen ambos. Mantén el código lo bastante grande para escanearlo desde donde la gente sostendrá el teléfono, y deja un hueco claro entre él y tu ilustración. Comprueba el resultado con la [puntuación de escaneo](/docs/features/frames#will-it-scan). Sin JSX, escribe el wrapper con `h` de `qrdx/core`; consulta [JavaScript puro](/docs/vanilla-js#custom-templates-without-jsx).
