Três props definem a forma de um código: `bodyPattern` para os módulos de dados, `cornerEyePattern` para os três olhos dos cantos e `cornerEyeDotPattern` para o ponto dentro de cada olho. Esta página cobre as três, além de escala dos módulos, códigos com formato e cores por olho. Todos os valores aparecem ao vivo em [Formas, olhos e molduras](/docs/styles).

Prefere criar no Playground ou no painel? Comece por [Crie seu primeiro QR code](/docs/help/getting-started/first-qr-code) na Ajuda.

```tsx title="components/shaped-code.tsx"
import { QRCode } from "qrdx";

export function ShapedCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      bodyPattern="liquid"
      cornerEyePattern="leaf"
      cornerEyeDotPattern="leaf"
    />
  );
}
```

## Padrões do corpo [#body-patterns]

`bodyPattern` define a forma dos módulos de dados. Há {facts.bodyPatterns} valores; o padrão é `circle`.

- Clássicos: `square`, `small-square`, `horizontal-line`, `vertical-line`, `octagon`
- Arredondados: `circle`, `circle-large`, `rounded`, `liquid`, `liquid-horizontal`, `liquid-vertical`, `random-dots`
- Decorativos: `classy`, `classy-rounded`, `leaf`, `diamond`, `hexagon`
- Divertidos: `mosaic`, `plus`, `star`, `heart`, `pacman`, `circle-mixed`

`liquid`, `classy` e `classy-rounded` unem módulos vizinhos em um único contorno suave; `liquid-horizontal` e `liquid-vertical` os unem apenas em linhas ou colunas. `random-dots` e `mosaic` variam de módulo para módulo, mas sempre desenham o mesmo código para o mesmo valor. Os padrões de alinhamento são sempre desenhados como quadrados sólidos, qualquer que seja o padrão, para que os decodificadores os encontrem.

### Escala dos módulos [#module-scale]

`moduleScale` (de 0.5 a 1, padrão 1) reduz cada módulo de dados em torno do seu centro, para um visual mais leve e espaçado. Padrões conectados ficam com linhas mais finas. Cada padrão para de encolher no menor tamanho que ainda é decodificado nos testes do pacote (por exemplo 0.95 para `circle`, 0.7 para `classy`; os limites são exportados como `MODULE_SCALE_FLOOR`), e os padrões de alinhamento mantêm o tamanho total.

```tsx title="components/light-code.tsx"
import { QRCode } from "qrdx";

export function LightCode() {
  return (
    <QRCode
      value="https://example.com"
      bodyPattern="liquid"
      moduleScale={0.8}
    />
  );
}
```

## Molduras dos olhos [#eye-frames]

`cornerEyePattern` define a forma dos olhos dos cantos. Há {facts.eyeShapes} valores; o padrão é `gear`: `square`, `rounded`, `extra-rounded`, `squircle`, `cushion`, `bevel`, `octagon`, `leaf`, `leaf-reverse`, `drop`, `petal`, `shield`, `gear`, `circle`, `diya`, `message` e `pointy`.

`leaf`, `leaf-reverse`, `drop` e `petal` viram cada um dos três olhos para o seu canto do código. Olhos `circle` podem não ser reconhecidos por alguns apps leitores; a [nota de leitura](/docs/features/frames#will-it-scan) avisa sobre isso.

## Centros dos olhos [#eye-centers]

`cornerEyeDotPattern` define a forma do ponto dentro de cada olho. Há {facts.eyeCentres} valores; o padrão é `circle`: `square`, `rounded`, `extra-rounded`, `circle`, `squircle`, `octagon`, `hexagon`, `dots`, `leaf`, `leaf-reverse`, `drop`, `drop-reverse`, `plus`, `cross-rounded`, `flower`, `heart`, `message`, `message-reverse`, `diya`, `diya-reverse` e `rounded-triangle`.

## Combinações a evitar e formas aposentadas [#pairs-to-avoid-and-retired-shapes]

Corpos `diamond` ao lado de olhos `square`, `pacman` ao lado de `rounded` e `small-square` ao lado de olhos `square` ou `rounded` não são reconhecidos de perto. O Playground não combina esses pares, eles são exportados como `WEAK_BODY_EYES` e `getStylePairRisk(props)` retorna o aviso que a nota de leitura mostra.

Um centro `circle` dentro de olhos com cantos retos (`square`, `rounded`, `extra-rounded` e a maioria dos outros) pode não ser reconhecido por decodificadores rigorosos em renderizações nítidas: em telas, em exportações PNG e em impressões grandes. Corpos sólidos (`square`, `liquid`, `classy`, `classy-rounded`) geralmente ainda são lidos, e olhos `gear`, `circle` e `octagon` não são afetados. A nota de leitura avisa sobre isso (`style-pair`) e você ainda pode escolher o par. Os pares são exportados como `WEAK_SHARP_DOT_EYES` (com `SHARP_DOT_EYE_SAFE_BODIES`), e um centro `rounded` evita o problema.

Olhos `curly` e centros `diamond`, `star` e `banner` foram aposentados porque não são lidos de forma confiável. Designs salvos com eles ainda são renderizados, mas não são mais oferecidos nem listados; veja [Formas aposentadas](/docs/styles#retired-shapes).

## Códigos circulares [#circle-codes]

`shape="circle"` coloca o código em um disco e preenche o restante com módulos decorativos no mesmo formato de ponto. O código real mantém um anel claro de `margin` módulos ao redor (no mínimo 3), e os leitores leem apenas o código do meio. O disco é maior que o código, então imprima um pouco maior para a mesma distância de leitura; a [calculadora de tamanho de impressão](/tools/print-size) considera o disco inteiro.

```tsx title="components/circle-code.tsx"
import { QRCode } from "qrdx";

export function CircleCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      shape="circle"
      bodyPattern="rounded"
    />
  );
}
```

Nos testes de decodificação do pacote, códigos circulares são lidos como os quadrados com formas de ponto sólidas (`square`, `rounded`, `classy`, `liquid`).

## Códigos em coração [#heart-codes]

`shape="heart"` funciona como um código circular, só que em formato de coração. O código real fica no meio do coração, com seu anel claro de pelo menos 3 módulos, e o restante do coração é preenchido com módulos decorativos. O código ocupa uma parte menor de um coração do que de um círculo, então imprima um código em coração maior que um quadrado para a mesma distância de leitura. A nota de leitura leva isso em conta: no mesmo tamanho, um código em coração tem nota menor que um circular.

```tsx title="components/heart-code.tsx"
import { QRCode } from "qrdx";

export function HeartCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      shape="heart"
      bodyPattern="rounded"
    />
  );
}
```

No Playground, um código com formato ocupa o lugar de uma moldura: escolher um remove a moldura, e escolher uma moldura remove o formato. Toda moldura pinta uma placa clara sob o código, o que esconderia o contorno. O motor ainda desenha `shape` com `frame` se você passar os dois. Nos testes de decodificação do pacote, códigos em coração são lidos com todas as formas de ponto sólidas e com olhos `square`, `rounded` e `gear`.

## Formas personalizadas [#custom-shapes]

`shape` também aceita uma silhueta: uma pequena grade traçada a partir de uma imagem sua (no máximo 64 células por lado). O código fica na parte central mais ampla da forma, e o restante é preenchido com módulos decorativos. Só a grade é guardada, nunca a imagem.

```tsx title="components/silhouette-code.tsx"
import { getQRSilhouetteFit, loadQRSilhouette, QRCode } from "qrdx";

export async function silhouetteFrom(file: File) {
  const shape = await loadQRSilhouette(file); // a PNG, JPEG or SVG, in the browser
  const fit = getQRSilhouetteFit(shape);
  if (!fit.ok) throw new Error(fit.message);
  return shape;
}

export function SilhouetteCode({ shape }: { shape: Awaited<ReturnType<typeof silhouetteFrom>> }) {
  return <QRCode value="https://example.com" size={256} shape={shape} />;
}
```

`loadQRSilhouette` desenha a imagem em um canvas e usa sua transparência, ou o escuro dela quando é opaca, então uma forma clara sobre fundo escuro também funciona. Em um servidor, passe pixels RGBA decodificados para `createQRSilhouette`. `getQRSilhouetteFit` recusa uma forma fina demais para conter o código com sua zona de silêncio, como uma estrela fina, uma barra ou um anel. Uma forma recusada é desenhada como um código quadrado.

No painel, a silhueta fica com o design, como um logo enviado: links compartilhados, itens da comunidade, trechos de código e o chat de IA usam um código quadrado.

## Cores por olho [#per-eye-colors]

`eyeColor` e `dotColor` colorem os três olhos. `eyeColors` substitui essas cores por olho (`topLeft`, `topRight`, `bottomLeft`), cada um com uma cor ou gradiente `outer` (moldura) e `inner` (ponto):

```tsx title="components/eye-colors-code.tsx"
import { QRCode } from "qrdx";

export function EyeColorsCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      eyeColor="#111827"
      eyeColors={{
        topLeft: { outer: "#dc2626", inner: "#1d4ed8" },
        topRight: { outer: "#16a34a" },
      }}
    />
  );
}
```

Mantenha todos os olhos escuros em contraste com o fundo: os decodificadores encontram o código pelos três olhos. A nota de leitura verifica o contraste das cores de cada olho.
