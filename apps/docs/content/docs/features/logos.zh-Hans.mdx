`QRCode` 提供 `logo` 属性，并自动为你排布图片：它会清除徽标后方的模块，而且绘制的徽标不会超过二维码的纠错能力所能修复的范围。本页介绍排布选项、各项限制，以及底层的原始 `imageSettings` API。

如果你是在 Playground 或控制台中设计？请参阅帮助中的[添加徽标](/docs/help/designing/logos)。

## 三行代码添加徽标 [#a-logo-in-three-lines]

```tsx title="components/logo-code.tsx"
import { QRCode } from "qrdx";

export function LogoCode() {
  return (
    <QRCode value="https://example.com" size={256} level="H" logo="/logo.png" />
  );
}
```

`logo` 可以是应用内的路径、URL 或 data URL。徽标按二维码宽度的四分之一绘制，其后方的模块会被清除，二维码依靠纠错来完成扫描。请使用 `level="H"`（二维码最多可有 30% 受损），或至少使用默认的 `Q`（25%）。

## 大小、留白和位置 [#size-clear-space-and-position]

`logoOptions` 使用与渲染尺寸无关的单位来排布徽标：

| 选项 | 范围 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `size` | 0.1 到 0.3 | 0.25 | 徽标宽度占二维码宽度的比例。超过 25% 时，即使是 H 级，在该包的解码测试中也无法读取 |
| `padding` | 0 到 2 | 0 | 徽标周围的留白，以模块为单位 |
| `x`, `y` | 0 到 1 | 0.5 | 徽标中心在二维码上的位置。徽标始终保持在二维码范围内 |
| `shape` | `square`、`rounded`、`circle` | `square` | 裁剪徽标 |
| `plate` | 一种颜色 | 无 | 徽标后方形状相同的纯色底板 |

```tsx title="components/placed-logo-code.tsx"
import { QRCode } from "qrdx";

export function PlacedLogoCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      level="H"
      logo="/logo.png"
      logoOptions={{ size: 0.2, padding: 1, x: 0.6, y: 0.55 }}
    />
  );
}
```

移动徽标时，请避开三个角上的定位图案，也要避开右下角附近的小方块（解码器用来校正透视的对齐图案）。如果徽标遮住了其中任何一个，扫描评分会判定为不通过。

## 徽标最大能有多大 [#how-big-a-logo-can-be]

徽标（连同其留白）会破坏它所触及的每个码字，而每个纠错块能修复的数量有限。`QRCode` 和 `getQRData` 会逐块统计被破坏的码字，并缩小徽标，直到最差的那个块最多只用掉其修复能力的 60%（`LOGO_EC_SAFETY`）。较小的二维码容量更小：在 Q 级下，一条短链接可容纳宽度约 13% 到 17% 的徽标，而使用 H 级或更短的内容可以容纳更大的徽标。

- `getLogoSizeLimit(props)` 返回适合该二维码的最大 `size`，这样滑块可以在该值处停止。
- `QRCodeSVG`、`QRCodeCanvas` 和 `getQRAsSVG` 上的原始 `imageSettings` 也适用同样的上限：能放下的徽标按原样绘制，过大的徽标会围绕其自身中心缩小。
- 当被清除的区域超过二维码的 7%（`AUTO_LEVEL_LOGO_COVERAGE`）时，`autoLevel` 会把纠错级别提高到 `H`。它默认关闭，因此现有二维码会保持原有级别。
- 扫描评分统计的是同样的码字，并会在上限缩小你的徽标之前发出警告。

## 形状、底板和背景 [#shape-plate-and-background]

```tsx title="components/round-logo-code.tsx"
import { QRCode } from "qrdx";

export function RoundLogoCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      level="H"
      logo="/logo.png"
      logoOptions={{ size: 0.22, shape: "circle", plate: "#ffffff" }}
    />
  );
}
```

裁剪使用的是 SVG 剪切路径。打印用的 PDF 和 EPS 会按相同的轮廓裁剪，因此每种下载文件看起来都一样。EPS 不支持透明，因此徽标的透明部分在其中会打印为白色。

如果徽标带有纯色底框（JPEG 中很常见），请将其移除：`removeLogoBackground(src)` 在浏览器中以 data URL 形式返回清理后的 PNG，`removeLogoBackdrop(pixels)` 则可在任何环境中对 RGBA 像素做同样的处理。当四个角颜色相同时，它们会从边缘向内清除该颜色，因此图案内部的同色部分（例如白色字母）会保留。当图片没有纯色背景时，两者都返回 `null`。

## 原始图片设置 [#raw-image-settings]

`QRCodeSVG` 和 `QRCodeCanvas` 通过 `imageSettings` 接收徽标，单位与 `size` 相同，均为像素。当你要自己排布徽标，或从其他渲染器移植代码时，可以使用它。

```tsx title="components/image-settings-code.tsx"
import { QRCodeSVG } from "qrdx";

export function ImageSettingsCode() {
  return (
    <QRCodeSVG
      value="https://example.com"
      size={512}
      level="H"
      autoLevel
      imageSettings={{
        src: "/logo.png",
        width: 110,
        height: 110,
        excavate: true,
        padding: 8,
      }}
    />
  );
}
```

- `width` 和 `height` 以像素为单位。省略 `x` 和 `y` 可使徽标居中。
- `excavate` 会清除徽标后方的模块。请保持开启，除非徽标是透明的，而你希望模块透过它显示出来。
- `padding` 会清除徽标周围额外的模块，单位与 `width` 和 `height` 相同，均为像素。
- `shape` 和 `plate` 的作用与 `logoOptions` 中相同。
- 无论 `margin` 为多少，徽标都保持其像素尺寸。

`getQRData(props)` 会将 `logo` 和 `logoOptions` 转换为适用于 1024 px 二维码的这些 `imageSettings`，`QRCode` 与各下载辅助函数正是借此共用同一套排布。

## 下载和格式 [#downloads-and-formats]

- PNG 和 JPEG 徽标会嵌入每种导出文件。SVG 和 WebP 徽标会在浏览器的导出中绘制，而在服务器上生成的 PNG 中则会被省略。
- 下载时，使用 data URL 最稳妥。远程图片需要带有 CORS 标头，浏览器才能将其复制到文件中；否则文件中不会有徽标。
- 在有颜色的二维码上，带透明背景的 PNG 效果最干净。对于 JPEG，请添加与背景同色的 `plate`，或先移除其底框。
- 打印前，请在两三部手机上测试带徽标的二维码，或使用[扫描评分](/docs/features/frames#will-it-scan)进行检查。
