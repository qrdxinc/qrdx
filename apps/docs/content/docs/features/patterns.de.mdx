Drei Props formen einen Code: `bodyPattern` für die Datenmodule, `cornerEyePattern` für die drei Eck-Eyes und `cornerEyeDotPattern` für den Punkt in jedem Eye. Diese Seite behandelt sie sowie Modulskalierung, geformte Codes und Farben pro Eye. Jeder Wert wird live unter [Formen, Eyes und Rahmen](/docs/styles) dargestellt.

Du gestaltest lieber im Playground oder im Dashboard? Dann starte in der Hilfe mit [Deinen ersten QR-Code erstellen](/docs/help/getting-started/first-qr-code).

```tsx title="components/shaped-code.tsx"
import { QRCode } from "qrdx";

export function ShapedCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      bodyPattern="liquid"
      cornerEyePattern="leaf"
      cornerEyeDotPattern="leaf"
    />
  );
}
```

## Body-Muster [#body-patterns]

`bodyPattern` bestimmt die Form der Datenmodule. Es gibt {facts.bodyPatterns} Werte; der Standard ist `circle`.

- Klassisch: `square`, `small-square`, `horizontal-line`, `vertical-line`, `octagon`
- Abgerundet: `circle`, `circle-large`, `rounded`, `liquid`, `liquid-horizontal`, `liquid-vertical`, `random-dots`
- Dekorativ: `classy`, `classy-rounded`, `leaf`, `diamond`, `hexagon`
- Verspielt: `mosaic`, `plus`, `star`, `heart`, `pacman`, `circle-mixed`

`liquid`, `classy` und `classy-rounded` verbinden benachbarte Module zu einer glatten Kontur; `liquid-horizontal` und `liquid-vertical` verbinden sie nur in Zeilen bzw. Spalten. `random-dots` und `mosaic` variieren von Modul zu Modul, zeichnen aber bei gleichem Wert immer denselben Code. Alignment-Muster werden unabhängig vom Muster immer als gefüllte Quadrate gezeichnet, damit Decoder sie finden.

### Modulskalierung [#module-scale]

`moduleScale` (0,5 bis 1, Standard 1) verkleinert jedes Datenmodul um seinen Mittelpunkt für einen leichteren, luftigeren Look. Bei verbundenen Mustern werden stattdessen die Linien dünner. Jedes Muster hört bei der kleinsten Größe auf zu schrumpfen, die in den Tests des Pakets noch dekodiert wird (zum Beispiel 0.95 für `circle`, 0.7 für `classy`; die Untergrenzen werden als `MODULE_SCALE_FLOOR` exportiert), und Alignment-Muster behalten ihre volle Größe.

```tsx title="components/light-code.tsx"
import { QRCode } from "qrdx";

export function LightCode() {
  return (
    <QRCode
      value="https://example.com"
      bodyPattern="liquid"
      moduleScale={0.8}
    />
  );
}
```

## Eye-Rahmen [#eye-frames]

`cornerEyePattern` bestimmt die Form der Eck-Eyes. Es gibt {facts.eyeShapes} Werte; der Standard ist `gear`: `square`, `rounded`, `extra-rounded`, `squircle`, `cushion`, `bevel`, `octagon`, `leaf`, `leaf-reverse`, `drop`, `petal`, `shield`, `gear`, `circle`, `diya`, `message` und `pointy`.

`leaf`, `leaf-reverse`, `drop` und `petal` drehen jedes der drei Eyes so, dass es zu seiner Ecke des Codes zeigt. `circle`-Eyes werden von manchen Scanner-Apps übersehen; der [Scan-Score](/docs/features/frames#will-it-scan) warnt davor.

## Eye-Zentren [#eye-centers]

`cornerEyeDotPattern` bestimmt die Form des Punkts in jedem Eye. Es gibt {facts.eyeCentres} Werte; der Standard ist `circle`: `square`, `rounded`, `extra-rounded`, `circle`, `squircle`, `octagon`, `hexagon`, `dots`, `leaf`, `leaf-reverse`, `drop`, `drop-reverse`, `plus`, `cross-rounded`, `flower`, `heart`, `message`, `message-reverse`, `diya`, `diya-reverse` und `rounded-triangle`.

## Zu vermeidende Kombinationen und eingestellte Formen [#pairs-to-avoid-and-retired-shapes]

`diamond`-Bodys neben `square`-Eyes, `pacman` neben `rounded` und `small-square` neben `square`- oder `rounded`-Eyes werden aus der Nähe übersehen. Der Playground kombiniert sie nicht, sie werden als `WEAK_BODY_EYES` ausgeliefert, und `getStylePairRisk(props)` gibt die Warnung zurück, die der Scan-Score anzeigt.

Ein `circle`-Zentrum in Eyes mit eckigen Ecken (`square`, `rounded`, `extra-rounded` und die meisten anderen) kann bei scharfen Renderings von strengen Decodern übersehen werden: auf Bildschirmen, in PNG-Exporten und in großen Drucken. Gefüllte Bodys (`square`, `liquid`, `classy`, `classy-rounded`) lassen sich meist trotzdem lesen, und `gear`-, `circle`- und `octagon`-Eyes sind nicht betroffen. Der Scan-Score warnt davor (`style-pair`), und du kannst die Kombination trotzdem wählen. Die Paare werden als `WEAK_SHARP_DOT_EYES` (mit `SHARP_DOT_EYE_SAFE_BODIES`) ausgeliefert, und ein `rounded`-Zentrum vermeidet das Problem.

`curly`-Eyes sowie `diamond`-, `star`- und `banner`-Zentren wurden eingestellt, weil sie nicht zuverlässig scannen. Damit gespeicherte Designs werden weiterhin gerendert, aber nicht mehr angeboten oder aufgelistet; siehe [Eingestellte Formen](/docs/styles#retired-shapes).

## Kreis-Codes [#circle-codes]

`shape="circle"` setzt den Code in eine Scheibe und füllt den Rest davon mit dekorativen Modulen in derselben Punktform. Der eigentliche Code behält einen hellen Ring aus `margin` Modulen um sich herum (mindestens 3), und Scanner lesen nur den Code in der Mitte. Die Scheibe ist größer als der Code, drucke sie also für dieselbe Scan-Distanz etwas größer; der [Druckgrößen-Rechner](/tools/print-size) berücksichtigt die ganze Scheibe.

```tsx title="components/circle-code.tsx"
import { QRCode } from "qrdx";

export function CircleCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      shape="circle"
      bodyPattern="rounded"
    />
  );
}
```

In den Dekodiertests des Pakets lassen sich Kreis-Codes mit gefüllten Punktformen (`square`, `rounded`, `classy`, `liquid`) genauso gut lesen wie quadratische.

## Herz-Codes [#heart-codes]

`shape="heart"` funktioniert wie ein Kreis-Code, nur in einem Herz. Der eigentliche Code sitzt mit seinem hellen Ring von mindestens 3 Modulen in der Mitte des Herzens, und der Rest des Herzens füllt sich mit dekorativen Modulen. Der Code nimmt einen kleineren Teil eines Herzens ein als eines Kreises, drucke einen Herz-Code also für dieselbe Scan-Distanz größer als einen quadratischen. Der Scan-Score berücksichtigt das: Bei gleicher Größe erzielt ein Herz-Code einen niedrigeren Wert als ein Kreis-Code.

```tsx title="components/heart-code.tsx"
import { QRCode } from "qrdx";

export function HeartCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      shape="heart"
      bodyPattern="rounded"
    />
  );
}
```

Ein geformter Code ersetzt im Playground einen Rahmen: Wählst du einen, wird der Rahmen entfernt, und wählst du einen Rahmen, wird die Form entfernt. Jeder Rahmen legt eine helle Platte unter den Code, die die Kontur verdecken würde. Die Engine zeichnet `shape` trotzdem mit einem `frame`, wenn du beides übergibst. In den Dekodiertests des Pakets lassen sich Herz-Codes mit allen gefüllten Punktformen und mit `square`-, `rounded`- und `gear`-Eyes lesen.

## Eigene Formen [#custom-shapes]

`shape` akzeptiert auch eine Silhouette: ein kleines Raster, das aus einem eigenen Bild nachgezeichnet wird (höchstens 64 Zellen pro Seite). Der Code sitzt im geräumigsten mittleren Teil der Form, und der Rest der Form füllt sich mit dekorativen Modulen. Gespeichert wird nur das Raster, nie das Bild.

```tsx title="components/silhouette-code.tsx"
import { getQRSilhouetteFit, loadQRSilhouette, QRCode } from "qrdx";

export async function silhouetteFrom(file: File) {
  const shape = await loadQRSilhouette(file); // a PNG, JPEG or SVG, in the browser
  const fit = getQRSilhouetteFit(shape);
  if (!fit.ok) throw new Error(fit.message);
  return shape;
}

export function SilhouetteCode({ shape }: { shape: Awaited<ReturnType<typeof silhouetteFrom>> }) {
  return <QRCode value="https://example.com" size={256} shape={shape} />;
}
```

`loadQRSilhouette` zeichnet das Bild auf ein Canvas und nutzt dessen Transparenz oder, wenn es deckend ist, seine Dunkelheit, sodass auch eine helle Form auf dunklem Hintergrund funktioniert. Auf einem Server übergibst du dekodierte RGBA-Pixel an `createQRSilhouette`. `getQRSilhouetteFit` lehnt eine Form ab, die zu dünn ist, um den Code mit seiner Ruhezone aufzunehmen, etwa einen dünnen Stern, einen Balken oder einen Ring. Eine abgelehnte Form wird als quadratischer Code gezeichnet.

Im Dashboard bleibt eine Silhouette beim Design, wie ein hochgeladenes Logo: Geteilte Links, Community-Einträge, Code-Snippets und der KI-Chat verwenden stattdessen einen quadratischen Code.

## Farben pro Eye [#per-eye-colors]

`eyeColor` und `dotColor` färben alle drei Eyes. `eyeColors` überschreibt sie pro Eye (`topLeft`, `topRight`, `bottomLeft`), jeweils mit einer Farbe oder einem Verlauf für `outer` (Rahmen) und `inner` (Punkt):

```tsx title="components/eye-colors-code.tsx"
import { QRCode } from "qrdx";

export function EyeColorsCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      eyeColor="#111827"
      eyeColors={{
        topLeft: { outer: "#dc2626", inner: "#1d4ed8" },
        topRight: { outer: "#16a34a" },
      }}
    />
  );
}
```

Halte jedes Eye dunkel gegenüber dem Hintergrund: Decoder finden den Code anhand seiner drei Eyes. Der Scan-Score prüft die Farben jedes Eyes einzeln auf Kontrast.
