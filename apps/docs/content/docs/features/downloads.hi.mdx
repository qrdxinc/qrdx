`downloadQRCode(props, options)` ब्राउज़र में `props` से बताए गए कोड को छह फ़ॉर्मैट में से किसी एक में फ़ाइल के रूप में सेव करता है। इसके साथी फ़ंक्शन वही फ़ाइल data URL, Blob या markup के रूप में लौटाते हैं, और `qrdx/node` सर्वर पर PNG बनाता है। हर फ़ंक्शन वही `props` लेता है जो `QRCode` लेता है, इसलिए फ़ाइल स्क्रीन पर दिख रहे कोड से मेल खाती है।

Playground या डैशबोर्ड से डाउनलोड करना चाहते हैं? Help में [QR कोड डाउनलोड और प्रिंट करें](/docs/help/getting-started/download-and-print) देखें।

## फ़ाइल डाउनलोड करें [#download-a-file]

```ts title="lib/download.ts"
import { downloadQRCode } from "qrdx";

await downloadQRCode(
  {
    value: "https://example.com",
    fgColor: "#1d4ed8",
    bodyPattern: "rounded",
    frame: { style: "banner-bottom", text: "Scan me" },
  },
  {
    format: "png",
    size: { width: 1024, height: 1024 },
    filename: "menu.png",
  }
);
```

<Shot id="lib-download-result" />

ब्राउज़र `menu.png` सेव करता है। `size` कोड की अपनी चौड़ाई और ऊँचाई पिक्सल में है, 50 से 5000 तक और वर्गाकार; फ़्रेम होने पर फ़ाइल इससे बड़ी बनती है। `filename` वैकल्पिक है: न देने पर फ़ाइल का नाम `qr-code.<ext>` होता है, और raster फ़ॉर्मैट में सही पिक्सल साइज़ जुड़ जाता है (`qr-code-1024x1024.png`, या नीचे बैनर होने पर `qr-code-1270x1454.png`)। `quality` (0 से 1) केवल WebP पर लागू होती है।

Props वही हैं जो `QRCode` पर हैं, बस लोगो `imageSettings` में जाता है। `QRCode` जो कोड बनाता है, उसे `logo` और `logoOptions` समेत एक्सपोर्ट करने के लिए, कच्चे props की जगह `getQRData(props)` या `resolveQRCodeProps(props)` दें।

## फ़ॉर्मैट [#formats]

| `format` | फ़ाइल | नोट्स |
| --- | --- | --- |
| `png` | इमेज | पारदर्शी बैकग्राउंड बनाए रखता है। ज़्यादातर उपयोग के लिए डिफ़ॉल्ट |
| `jpg` | इमेज | सिर्फ़ ठोस बैकग्राउंड, छोटी फ़ाइल |
| `webp` | इमेज | PNG के ही पिक्सल, छोटी फ़ाइल में; `quality` सेट न हो तो lossless |
| `svg` | वेक्टर | किसी भी साइज़ पर तेज़; प्रिंट शॉप और डिज़ाइन टूल के लिए सही फ़ाइल |
| `pdf` | डॉक्यूमेंट | एक पेज, जिस पर कोड PNG के रूप में है। वैकल्पिक `jspdf` पैकेज चाहिए |
| `eps` | वेक्टर | Illustrator, CorelDRAW और InDesign के लिए PostScript। `size.width` को points (72 प्रति इंच) माना जाता है |

### WebP [#webp]

WebP डिफ़ॉल्ट रूप से lossless है, इसलिए मॉड्यूल के किनारे सटीक रहते हैं और पारदर्शी बैकग्राउंड पारदर्शी रहता है। जहाँ ब्राउज़र का canvas lossless WebP लिखता है (Chrome और Edge लिखते हैं), वहाँ फ़ाइल ब्राउज़र बनाता है। जहाँ ऐसा नहीं होता, वहाँ लाइब्रेरी बाइट्स जाँचती है और एक छोटे बिल्ट-इन lossless एन्कोडर से पिक्सल खुद एन्कोड करती है: Safari से WebP माँगने पर PNG मिलता है। दोनों तरह से `.webp` फ़ाइल हमेशा WebP ही होती है।

`quality` (0 से 1) जहाँ ब्राउज़र सपोर्ट करता है वहाँ इसके बजाय छोटी lossy फ़ाइल माँगती है। Lossy WebP मॉड्यूल के किनारों और रंगों को नरम कर देता है, इसलिए जिन कोड को दूर से स्कैन होना है उनके लिए डिफ़ॉल्ट रखें। `getQRAsWebP` फ़ाइल को `Blob` के रूप में लौटाता है:

```ts title="lib/webp.ts"
import { getQRAsWebP } from "qrdx";

const lossless = await getQRAsWebP({ value: "https://example.com", size: 1024 });
const lossy = await getQRAsWebP({ value: "https://example.com", size: 1024 }, { quality: 0.9 });
```

`canvasToWebP(canvas, options)` किसी भी canvas के लिए यही काम करता है, और `encodeWebPLossless(rgba, width, height)` बिना DOM के RGBA पिक्सल एन्कोड करता है।

### PDF [#pdf]

PDF डाउनलोड में कोड उसी साइज़ के पेज पर PNG के रूप में होता है। इसके लिए वैकल्पिक `jspdf` पैकेज चाहिए (`npm install jspdf`); इसके बिना PDF डाउनलोड `PDF export needs the optional "jspdf" package` एरर देते हैं। भौतिक साइज़ में वेक्टर PDF के लिए, bleed, crop marks और CMYK के साथ, `downloadPrintPDF` इस्तेमाल करें; देखें [प्रिंट के लिए तैयार एक्सपोर्ट](/docs/features/frames#print-ready-export)।

### EPS [#eps]

EPS को किसी अतिरिक्त पैकेज की ज़रूरत नहीं है। `downloadQRCode` `size.width` को points मानता है, इसलिए 512 px माँगने पर 512 pt (18 cm) की फ़ाइल बनती है। सटीक भौतिक साइज़ के लिए `getQRAsEPS` इस्तेमाल करें, जो EPS को string के रूप में लौटाता है: कोड `sizeMm` चौड़ा होता है (डिफ़ॉल्ट 50 mm), और फ़्रेम उसमें जुड़ता है।

```ts title="lib/eps.ts"
import { downloadPrintEPS, getQRAsEPS } from "qrdx";

const eps = await getQRAsEPS(
  { value: "https://example.com" },
  { sizeMm: 40, bleedMm: 3, colorMode: "cmyk" }
);

await downloadPrintEPS({ value: "https://example.com" }, { sizeMm: 40, filename: "menu.eps" });
```

EPS में पारदर्शिता नहीं होती और crop marks भी नहीं होते। Linear और radial ग्रेडिएंट PostScript Level 3 shadings के रूप में smooth प्रिंट होते हैं; angular ग्रेडिएंट पतली wedges के पंखे के रूप में प्रिंट होते हैं। पारदर्शी रंग बैकग्राउंड के साथ मिला दिए जाते हैं, और बैकग्राउंड सफ़ेद काग़ज़ के साथ। PNG और JPEG लोगो एम्बेड होते हैं। EPS [इमेज फ़िल](/docs/features/colors-gradients#image-fills) नहीं रख सकता: `getQRAsEPS` `EPS_IMAGE_FILL_REASON` एरर देता है, और डैशबोर्ड का डाउनलोड डायलॉग इसकी जगह PDF, SVG और PNG देता है।

## Data URL, Blob और markup [#data-urls-blobs-and-markup]

```ts title="lib/export.ts"
import { copyQRCodeToClipboard, getQRCodeDataUrl, getSVGString } from "qrdx";

const props = { value: "https://example.com", size: 512 };

// The same file as a data URL, for an <img> or a form field
const png = await getQRCodeDataUrl(props, "png", { width: 512, height: 512 });

// A PNG on the clipboard, for pasting into a document
await copyQRCodeToClipboard(props, { width: 512, height: 512 });

// The SVG markup, for inlining in a page or an email template
const svg = await getSVGString(props);
```

- `getQRCodeDataUrl(props, format, size, { quality })` वे सभी फ़ॉर्मैट लेता है जो `downloadQRCode` लेता है।
- `copyQRCodeToClipboard` PNG लिखता है। इसे click handler से कॉल करें: ब्राउज़र user gesture के बाहर clipboard में लिखने से मना कर देते हैं।
- `getSVGString` लोगो को data URL के रूप में एम्बेड करता है, इसलिए markup अपने आप में पूरा होता है। `qrdx/core` का `toSVGString` बिना उस चरण वाला synchronous संस्करण है।

## प्रीसेट साइज़ [#preset-sizes]

```ts title="lib/sizes.ts"
import { PRESET_SIZES, validateSize } from "qrdx";

PRESET_SIZES.small; // { width: 200, height: 200 }
PRESET_SIZES.medium; // 400
PRESET_SIZES.large; // 800
PRESET_SIZES.xlarge; // 1200
PRESET_SIZES["2xl"]; // 1600
PRESET_SIZES["3xl"]; // 2000

validateSize(4000, 4000); // { isValid: true }
validateSize(6000, 6000); // { isValid: false, error: "Size must not exceed 5000x5000 pixels" }
```

साइज़ इस आधार पर चुनें कि फ़ाइल कहाँ जाएगी: वेब पेज के लिए 256 से 512 px, 300 पिक्सल प्रति इंच पर प्रिंट के लिए 1024 px या ज़्यादा (1024 px लगभग 8.7 cm चौड़ाई तक साफ़ प्रिंट होता है)। सटीक प्रिंट साइज़ के लिए प्रिंट फ़ंक्शन इस्तेमाल करें, जो मिलीमीटर और इंच में काम करते हैं।

## Node में PNG [#png-in-node]

`qrdx/node` का `getQRAsPNG` बिना ब्राउज़र के PNG बाइट्स लौटाता है। इसके लिए `qrdx` के साथ एक वैकल्पिक rasterizer इंस्टॉल होना चाहिए: `@resvg/resvg-js` SVG को, लोगो समेत, ब्राउज़र की तरह बनाता है; `sharp` भी चलता है।

```ts title="scripts/make-png.ts"
import { writeFile } from "node:fs/promises";
import { getQRAsPNG } from "qrdx/node";

const png = await getQRAsPNG(
  { value: "https://example.com", bodyPattern: "rounded", margin: 4 },
  { size: 1024 }
);
await writeFile("qr-code.png", png);
```

इसे `qrdx/node` से इम्पोर्ट करें, `qrdx` से कभी नहीं, ताकि ब्राउज़र bundles को native modules न दिखें। जो लोगो data URL है वह जैसा है वैसा एम्बेड होता है; `http(s)` URL या लोकल पाथ केवल `loadExternalLogos: true` के साथ लोड होता है, ताकि कॉलर की सेटिंग आगे भेजने वाला सर्वर इंटरनल URL fetch करने या अपनी डिस्क पढ़ने के लिए मजबूर न किया जा सके। SVG markup को rasterizer नहीं चाहिए: `qrdx/core` का `toSVGString` कहीं भी चलता है।

## अगर कुछ गड़बड़ हो [#if-something-goes-wrong]

- **`Size must be at least 50x50 pixels`, `Size must not exceed 5000x5000 pixels` या `Width and height must be equal for QR codes`.** `validateSize` ने साइज़ ठुकरा दिया। सीमा के भीतर का वर्गाकार साइज़ दें।
- **`PDF export needs the optional "jspdf" package`.** `jspdf` को उसी पैकेज में इंस्टॉल करें जिसमें `qrdx` है।
- **फ़ाइल में लोगो नहीं है।** इमेज किसी दूसरे origin से आती है जिसमें CORS headers नहीं हैं, इसलिए ब्राउज़र उसे कॉपी नहीं कर सका। उसे अपने origin से सर्व करें या data URL दें।
- **`copyQRCodeToClipboard` reject होता है।** यह click या key handler के बाहर चला, या पेज HTTPS पर सर्व नहीं हो रहा। इसे सीधे handler से कॉल करें।
- **`getQRAsPNG` rasterizer न होने की एरर देता है।** `qrdx` के साथ `@resvg/resvg-js` या `sharp` इंस्टॉल करें।
