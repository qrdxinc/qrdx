`downloadQRCode(props, options)` enregistre dans le navigateur, sous forme de fichier, le code décrit par `props`, dans l'un des six formats disponibles. Les fonctions voisines renvoient le même fichier sous forme d'URL de données, de Blob ou de balisage, et `qrdx/node` génère un PNG côté serveur. Chaque fonction prend les mêmes `props` que `QRCode`, de sorte que le fichier correspond au code affiché à l'écran.

Vous téléchargez plutôt depuis le Playground ou le tableau de bord ? Consultez [Télécharger et imprimer un QR code](/docs/help/getting-started/download-and-print) dans l'aide.

## Télécharger un fichier [#download-a-file]

```ts title="lib/download.ts"
import { downloadQRCode } from "qrdx";

await downloadQRCode(
  {
    value: "https://example.com",
    fgColor: "#1d4ed8",
    bodyPattern: "rounded",
    frame: { style: "banner-bottom", text: "Scan me" },
  },
  {
    format: "png",
    size: { width: 1024, height: 1024 },
    filename: "menu.png",
  }
);
```

<Shot id="lib-download-result" />

Le navigateur enregistre `menu.png`. `size` correspond à la largeur et à la hauteur en pixels du code lui-même, de 50 à 5000, et le code est carré ; un cadre rend le fichier plus grand. `filename` est facultatif : sans lui, le fichier s'appelle `qr-code.<ext>`, avec la taille exacte en pixels ajoutée pour les formats matriciels (`qr-code-1024x1024.png`, ou `qr-code-1270x1454.png` avec une bannière en bas). `quality` (de 0 à 1) ne s'applique qu'au WebP.

Les props sont les mêmes que pour `QRCode`, sauf qu'un logo se place dans `imageSettings`. Pour exporter le code dessiné par un `QRCode`, y compris ses `logo` et `logoOptions`, passez `getQRData(props)` ou `resolveQRCodeProps(props)` à la place des props brutes.

## Formats [#formats]

| `format` | Fichier | Remarques |
| --- | --- | --- |
| `png` | Image | Conserve un arrière-plan transparent. Le choix par défaut pour la plupart des usages |
| `jpg` | Image | Arrière-plan uni uniquement, fichier plus léger |
| `webp` | Image | Les pixels du PNG dans un fichier plus léger ; sans perte sauf si `quality` est définie |
| `svg` | Vectoriel | Net à toutes les tailles ; le fichier adapté aux imprimeurs et aux outils de conception |
| `pdf` | Document | Une page contenant le code sous forme de PNG. Nécessite le paquet facultatif `jspdf` |
| `eps` | Vectoriel | PostScript pour Illustrator, CorelDRAW et InDesign. `size.width` est interprétée en points (72 par pouce) |

### WebP [#webp]

Le WebP est sans perte par défaut : les bords des modules restent exacts et un arrière-plan transparent le reste. Lorsque le canvas du navigateur sait écrire du WebP sans perte (c'est le cas de Chrome et d'Edge), c'est le navigateur qui produit le fichier. Lorsqu'il ne le peut pas, la bibliothèque vérifie les octets et encode elle-même les pixels avec un petit encodeur sans perte intégré : Safari, à qui l'on demande du WebP, renvoie un PNG. Dans tous les cas, un fichier `.webp` est toujours du WebP.

`quality` (de 0 à 1) demande à la place un fichier plus léger avec perte, lorsque le navigateur le permet. Le WebP avec perte adoucit les bords des modules et les couleurs ; conservez donc la valeur par défaut pour les codes qui doivent se scanner de loin. `getQRAsWebP` renvoie le fichier sous forme de `Blob` :

```ts title="lib/webp.ts"
import { getQRAsWebP } from "qrdx";

const lossless = await getQRAsWebP({ value: "https://example.com", size: 1024 });
const lossy = await getQRAsWebP({ value: "https://example.com", size: 1024 }, { quality: 0.9 });
```

`canvasToWebP(canvas, options)` fait de même pour n'importe quel canvas, et `encodeWebPLossless(rgba, width, height)` encode des pixels RGBA sans DOM.

### PDF [#pdf]

Le téléchargement PDF contient le code sous forme de PNG, sur une page de même taille. Il nécessite le paquet facultatif `jspdf` (`npm install jspdf`) ; sans lui, les téléchargements PDF lèvent l'erreur `PDF export needs the optional "jspdf" package`. Pour un PDF vectoriel à une taille physique donnée, avec fond perdu, traits de coupe et CMJN, utilisez `downloadPrintPDF` ; voir [Export prêt à imprimer](/docs/features/frames#print-ready-export).

### EPS [#eps]

L'EPS ne nécessite aucun paquet supplémentaire. `downloadQRCode` interprète `size.width` en points : une demande de 512 px écrit donc un fichier de 512 pt (18 cm). Pour une taille physique exacte, utilisez `getQRAsEPS`, qui renvoie l'EPS sous forme de chaîne : le code mesure `sizeMm` de large (50 mm par défaut), et un cadre s'y ajoute.

```ts title="lib/eps.ts"
import { downloadPrintEPS, getQRAsEPS } from "qrdx";

const eps = await getQRAsEPS(
  { value: "https://example.com" },
  { sizeMm: 40, bleedMm: 3, colorMode: "cmyk" }
);

await downloadPrintEPS({ value: "https://example.com" }, { sizeMm: 40, filename: "menu.eps" });
```

L'EPS ne gère ni la transparence ni les traits de coupe. Les dégradés linéaires et radiaux sont imprimés sous forme de dégradés PostScript Level 3 lisses ; les dégradés angulaires sont imprimés sous forme d'un éventail de fines parts. Les couleurs semi-transparentes sont mélangées avec l'arrière-plan, et l'arrière-plan avec le blanc du papier. Les logos PNG et JPEG sont intégrés. L'EPS ne peut pas contenir de [remplissage par image](/docs/features/colors-gradients#image-fills) : `getQRAsEPS` lève `EPS_IMAGE_FILL_REASON`, et la boîte de dialogue de téléchargement du tableau de bord propose à la place PDF, SVG et PNG.

## URL de données, Blobs et balisage [#data-urls-blobs-and-markup]

```ts title="lib/export.ts"
import { copyQRCodeToClipboard, getQRCodeDataUrl, getSVGString } from "qrdx";

const props = { value: "https://example.com", size: 512 };

// The same file as a data URL, for an <img> or a form field
const png = await getQRCodeDataUrl(props, "png", { width: 512, height: 512 });

// A PNG on the clipboard, for pasting into a document
await copyQRCodeToClipboard(props, { width: 512, height: 512 });

// The SVG markup, for inlining in a page or an email template
const svg = await getSVGString(props);
```

- `getQRCodeDataUrl(props, format, size, { quality })` accepte tous les formats que `downloadQRCode` accepte.
- `copyQRCodeToClipboard` écrit un PNG. Appelez-la depuis un gestionnaire de clic : les navigateurs refusent les écritures dans le presse-papiers en dehors d'une action de l'utilisateur.
- `getSVGString` intègre le logo sous forme d'URL de données, de sorte que le balisage est autonome. `toSVGString` de `qrdx/core` en est la version synchrone, sans cette étape.

## Tailles prédéfinies [#preset-sizes]

```ts title="lib/sizes.ts"
import { PRESET_SIZES, validateSize } from "qrdx";

PRESET_SIZES.small; // { width: 200, height: 200 }
PRESET_SIZES.medium; // 400
PRESET_SIZES.large; // 800
PRESET_SIZES.xlarge; // 1200
PRESET_SIZES["2xl"]; // 1600
PRESET_SIZES["3xl"]; // 2000

validateSize(4000, 4000); // { isValid: true }
validateSize(6000, 6000); // { isValid: false, error: "Size must not exceed 5000x5000 pixels" }
```

Choisissez la taille selon la destination du fichier : de 256 à 512 px pour une page web, 1024 px ou plus pour une impression à 300 pixels par pouce (1024 px s'impriment nettement jusqu'à environ 8,7 cm de large). Pour des tailles d'impression exactes, utilisez les fonctions d'impression, qui travaillent en millimètres et en pouces.

## PNG dans Node [#png-in-node]

`getQRAsPNG` de `qrdx/node` renvoie des octets PNG sans navigateur. Elle nécessite un moteur de rastérisation facultatif installé à côté de `qrdx` : `@resvg/resvg-js` dessine le SVG, logos compris, comme le font les navigateurs ; `sharp` fonctionne aussi.

```ts title="scripts/make-png.ts"
import { writeFile } from "node:fs/promises";
import { getQRAsPNG } from "qrdx/node";

const png = await getQRAsPNG(
  { value: "https://example.com", bodyPattern: "rounded", margin: 4 },
  { size: 1024 }
);
await writeFile("qr-code.png", png);
```

Importez-la depuis `qrdx/node`, jamais depuis `qrdx`, afin que les bundles pour navigateur ne voient jamais les modules natifs. Un logo fourni sous forme d'URL de données est intégré tel quel ; une URL `http(s)` ou un chemin local n'est chargé qu'avec `loadExternalLogos: true`, afin qu'un serveur qui transmet les paramètres d'un appelant ne puisse pas être amené à récupérer des URL internes ni à lire son propre disque. Le balisage SVG ne nécessite aucun moteur de rastérisation : `toSVGString` de `qrdx/core` fonctionne partout.

## En cas de problème [#if-something-goes-wrong]

- **`Size must be at least 50x50 pixels`, `Size must not exceed 5000x5000 pixels` ou `Width and height must be equal for QR codes`.** `validateSize` a rejeté la taille. Passez une taille carrée comprise dans la plage autorisée.
- **`PDF export needs the optional "jspdf" package`.** Installez `jspdf` dans le même paquet que `qrdx`.
- **Le logo est absent du fichier.** L'image provient d'une autre origine sans en-têtes CORS, et le navigateur n'a donc pas pu la copier. Servez-la depuis votre propre origine ou passez une URL de données.
- **`copyQRCodeToClipboard` est rejetée.** Elle a été exécutée en dehors d'un gestionnaire de clic ou de touche, ou la page n'est pas servie en HTTPS. Appelez-la depuis le gestionnaire lui-même.
- **`getQRAsPNG` lève une erreur indiquant l'absence de moteur de rastérisation.** Installez `@resvg/resvg-js` ou `sharp` à côté de `qrdx`.
