O `QRCode` aceita uma prop `logo` e organiza a imagem para você: ele limpa os módulos atrás do logo e nunca desenha um logo maior do que o código consegue reparar. Esta página cobre as opções de layout, os limites e a API bruta `imageSettings` por baixo dos panos.

Está desenhando no Playground ou no painel? Veja [Adicionar um logo](/docs/help/designing/logos) na Ajuda.

## Um logo em três linhas [#a-logo-in-three-lines]

```tsx title="components/logo-code.tsx"
import { QRCode } from "qrdx";

export function LogoCode() {
  return (
    <QRCode value="https://example.com" size={256} level="H" logo="/logo.png" />
  );
}
```

`logo` aceita um caminho no seu app, uma URL ou uma data URL. O logo é desenhado com um quarto da largura do código, os módulos atrás dele são limpos e o código depende da correção de erros para ser lido. Use `level="H"` (até 30% do código pode estar danificado) ou, no mínimo, o padrão `Q` (25%).

## Tamanho, espaço livre e posição [#size-clear-space-and-position]

`logoOptions` organiza o logo em unidades que não dependem do tamanho de renderização:

| Opção | Faixa | Padrão | O que faz |
| --- | --- | --- | --- |
| `size` | 0.1 a 0.3 | 0.25 | A largura do logo como proporção da largura do código. Acima de 25%, nem o nível H consegue ser lido nos testes de decodificação do pacote |
| `padding` | 0 a 2 | 0 | Espaço livre ao redor do logo, em módulos |
| `x`, `y` | 0 a 1 | 0.5 | Onde fica o centro do logo ao longo do código. O logo sempre permanece dentro do código |
| `shape` | `square`, `rounded`, `circle` | `square` | Recorta o logo |
| `plate` | uma cor | nenhuma | Uma placa sólida atrás do logo, no mesmo formato |

```tsx title="components/placed-logo-code.tsx"
import { QRCode } from "qrdx";

export function PlacedLogoCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      level="H"
      logo="/logo.png"
      logoOptions={{ size: 0.2, padding: 1, x: 0.6, y: 0.55 }}
    />
  );
}
```

Mantenha um logo deslocado longe dos três olhos dos cantos e do quadradinho perto do canto inferior direito (o padrão de alinhamento que os decodificadores usam para corrigir a perspectiva). A pontuação de leitura reprova um logo que cubra algum deles.

## Qual o tamanho máximo de um logo [#how-big-a-logo-can-be]

Um logo (com seu espaço livre) estraga todas as palavras-código que ele toca, e cada bloco de correção de erros consegue reparar só um certo número delas. `QRCode` e `getQRData` contam as palavras-código estragadas bloco a bloco e reduzem o logo até que o pior bloco use no máximo 60% da sua capacidade de reparo (`LOGO_EC_SAFETY`). Códigos pequenos comportam menos: no nível Q, um link curto comporta um logo de cerca de 13% a 17% da largura, e o nível H ou um valor mais curto abre espaço para mais.

- `getLogoSizeLimit(props)` retorna o maior `size` que cabe em um código, para que um controle deslizante possa parar nele.
- O `imageSettings` bruto em `QRCodeSVG`, `QRCodeCanvas` e `getQRAsSVG` recebe o mesmo limite: um logo que cabe é desenhado como foi definido, e um maior é reduzido em torno do próprio centro.
- `autoLevel` aumenta a correção de erros para `H` sempre que a área limpa cobrir mais de 7% do código (`AUTO_LEVEL_LOGO_COVERAGE`). Ele vem desativado por padrão, então os códigos existentes mantêm o nível.
- A pontuação de leitura conta as mesmas palavras-código e avisa antes que o limite reduza o seu logo.

## Formato, placa e fundo [#shape-plate-and-background]

```tsx title="components/round-logo-code.tsx"
import { QRCode } from "qrdx";

export function RoundLogoCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      level="H"
      logo="/logo.png"
      logoOptions={{ size: 0.22, shape: "circle", plate: "#ffffff" }}
    />
  );
}
```

O recorte é um clip path de SVG. O PDF de impressão e o EPS recortam seguindo o mesmo contorno, então todos os downloads ficam iguais. O EPS não tem transparência, então as partes transparentes de um logo saem brancas nele.

Se um logo estiver sobre uma caixa sólida (comum em JPEGs), remova-a: `removeLogoBackground(src)` retorna o PNG limpo como data URL no navegador, e `removeLogoBackdrop(pixels)` faz o mesmo em pixels RGBA em qualquer lugar. Quando os quatro cantos têm a mesma cor, ela é removida das bordas para dentro, então a mesma cor dentro da marca (letras brancas, por exemplo) permanece. Ambas retornam `null` quando a imagem não tem fundo sólido.

## Configurações brutas da imagem [#raw-image-settings]

`QRCodeSVG` e `QRCodeCanvas` recebem o logo como `imageSettings`, nos mesmos pixels de `size`. Use quando você mesmo organiza o logo ou está portando código de outro renderizador.

```tsx title="components/image-settings-code.tsx"
import { QRCodeSVG } from "qrdx";

export function ImageSettingsCode() {
  return (
    <QRCodeSVG
      value="https://example.com"
      size={512}
      level="H"
      autoLevel
      imageSettings={{
        src: "/logo.png",
        width: 110,
        height: 110,
        excavate: true,
        padding: 8,
      }}
    />
  );
}
```

- `width` e `height` são em pixels. Omita `x` e `y` para centralizar o logo.
- `excavate` limpa os módulos atrás do logo. Deixe ativado, a menos que o logo seja translúcido e você queira que os módulos apareçam através dele.
- `padding` limpa módulos extras ao redor do logo, nos mesmos pixels de `width` e `height`.
- `shape` e `plate` funcionam como em `logoOptions`.
- O logo mantém o tamanho em pixels, independentemente de `margin`.

`getQRData(props)` converte `logo` e `logoOptions` nesses `imageSettings` para um código de 1024 px, e é assim que o `QRCode` e os helpers de download compartilham o mesmo layout.

## Downloads e formatos [#downloads-and-formats]

- Logos em PNG e JPEG são incorporados em todas as exportações. Logos em SVG e WebP são desenhados nas exportações feitas no navegador e ficam de fora de um PNG gerado em um servidor.
- Para downloads, uma data URL é a opção mais segura. Uma imagem remota precisa de cabeçalhos CORS para que o navegador possa copiá-la para o arquivo; sem eles, o arquivo fica sem logo.
- Um PNG com transparência dá o resultado mais limpo em um código colorido. Para um JPEG, adicione uma `plate` na cor do fundo ou remova a caixa antes.
- Teste um código com logo em dois ou três celulares antes de imprimir, ou verifique com a [pontuação de leitura](/docs/features/frames#will-it-scan).
