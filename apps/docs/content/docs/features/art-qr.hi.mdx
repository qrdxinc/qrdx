`art` prop किसी कोड के मॉड्यूल में लोगो या फ़ोटो को वेक्टर शेप के रूप में और बिना AI के मिला देता है: Logo QR आपके लोगो के आकार के अंदर आने वाले मॉड्यूल को नए रंग देता है, और Image QR हर मॉड्यूल में आपकी फ़ोटो दिखाता है। दोनों को लाइब्रेरी खुद ड्रॉ करती है, इसलिए ये ऑफ़लाइन, सर्वर पर और Node में चलते हैं, और नतीजा हमेशा एक असली QR कोड होता है। इस पेज में prop, तस्वीर के सैंपल होने का तरीका और स्कैन होने की क्षमता बनाए रखने का तरीका बताया गया है।

अगर आप playground या डैशबोर्ड में डिज़ाइन कर रहे हैं, तो Help में [कोड में लोगो या फ़ोटो मिलाएँ](/docs/help/designing/art) देखें।

QRdx में कोड को आर्टवर्क बनाने के तीन तरीके हैं:

| | यह कैसे काम करता है | आउटपुट | कीमत |
| --- | --- | --- | --- |
| **Logo QR** (`mode: "logo"`) | आपके लोगो के आकार के अंदर के मॉड्यूल उसके रंग लेते हैं; बाकी हल्के रंग में बदल जाते हैं | वेक्टर (SVG, PDF, EPS, PNG) | फ़्री |
| **Image QR** (`mode: "halftone"`) | हर मॉड्यूल एक बीच वाले वर्ग के आसपास आपकी फ़ोटो दिखाता है, जो असली वैल्यू बनाए रखता है | वेक्टर (SVG, PDF, EPS, PNG) | फ़्री |
| **AI art** | एक AI इमेज मॉडल कोड को एक दृश्य के रूप में दोबारा पेंट करता है, और हर इमेज का स्कैन होना जाँचा जाता है | 1024 px इमेज, 2048 px प्रिंट कॉपी | AI art इमेज प्लान से |

## आर्ट कोड बनाएँ [#draw-an-art-code]

मोड, सैंपल की गई इमेज और वैकल्पिक intensity के साथ `art` prop दें:

```tsx title="components/logo-art-code.tsx"
import { loadQRArtImage, type QRArtImage, QRCode } from "qrdx";

// Browser: sample an uploaded file, a data URL or an <img>
export async function sampleLogo(file: File): Promise<QRArtImage> {
  return await loadQRArtImage(file, { mode: "logo" });
}

export function LogoArtCode({ image }: { image: QRArtImage }) {
  return (
    <QRCode
      value="https://example.com"
      size={512}
      level="H"
      art={{ mode: "logo", image, intensity: 0.7 }}
    />
  );
}
```

<Shot id="lib-art-codes" />

सर्वर पर या Node में इमेज को खुद डिकोड करें और RGBA पिक्सल `createQRArtImage` को दें:

```ts title="lib/sample-photo.ts"
import { createQRArtImage } from "qrdx";
import sharp from "sharp";

const { data, info } = await sharp("photo.jpg")
  .ensureAlpha()
  .raw()
  .toBuffer({ resolveWithObject: true });

export const image = createQRArtImage(
  { data, width: info.width, height: info.height },
  { maxSize: 96, square: true }
);
// art={{ mode: "halftone", image, intensity: 0.8 }}
```

`art.image` सादा JSON है (`{ width, height, data }`, जिसमें data base64 RGBA है), इसलिए आप इसे सेव किए गए डिज़ाइन के साथ रख सकते हैं और तस्वीर दोबारा लाए बिना वही कोड कहीं भी, सिंक्रोनस तरीके से रेंडर कर सकते हैं।

| विकल्प | वैल्यू | नोट्स |
| --- | --- | --- |
| `mode` | `logo`, `halftone` | `halftone` एडिटर में Image QR है |
| `image` | `loadQRArtImage` या `createQRArtImage` से | ज़्यादा से ज़्यादा 192 गुणा 192 सैंपल। `loadQRArtImage` डिफ़ॉल्ट रूप से चौड़ाई में 160 सैंपल लेता है |
| `intensity` | `0` से `1` | डिफ़ॉल्ट `0.6`; `0` सादे कोड जैसा दिखता है |
| `variant` | `blend`, `badge` (logo); `color`, `mono` (halftone) | मोड के अंदर का लुक। `badge` ट्रेस किए गए लोगो को रंगीन कोड के बीच एक गोल प्लेट पर रखता है; `mono` ब्लैक-एंड-व्हाइट हाफ़टोन है। पहली वैल्यू हर मोड का डिफ़ॉल्ट है |
| `matchEyes` | `true`, `false` | सिर्फ़ logo मोड: कोने की आँखों को लोगो से रंगें (डिफ़ॉल्ट `true`)। हर आँख के लिए `eyeColors` फिर भी प्राथमिकता पाते हैं |

आर्ट बॉडी पैटर्न की जगह लेता है; कोने की आँखें अपने `cornerEyePattern`, `cornerEyeDotPattern` और रंग बनाए रखती हैं। आर्ट ग्रेडिएंट `fgColor` या `bgColor` का पहला रंग इस्तेमाल करता है, और उसे हल्की बैकग्राउंड पर गहरा फ़ोरग्राउंड चाहिए; उलटे रंगों में वह सादे लुक पर लौट जाता है। `level="H"` इस्तेमाल करें, इससे आर्ट को सबसे ज़्यादा जगह मिलती है।

## स्कैन होने की क्षमता कैसे बनी रहती है [#how-scannability-is-kept]

- **Logo QR**: लोगो के अंदर के गहरे मॉड्यूल का रंग बदला जाता है, लेकिन उन्हें सिर्फ़ उतना ही गहरा रखा जाता है जितनी luminance को स्कैनर अब भी गहरा पढ़ता है; लोगो के अंदर के हल्के मॉड्यूल को हल्की टिंट मिलती है जो light threshold से ऊपर रहती है। लोगो के बाहर के गहरे मॉड्यूल ग्रे में बदल जाते हैं, कभी dark threshold से ज़्यादा हल्के नहीं होते।
- **Logo QR badge**: प्लेट के नीचे का हर मॉड्यूल एक codeword बिगाड़ सकता है। प्लेट का आकार इस तरह रखा जाता है कि कोई भी error correction ब्लॉक अपने ठीक किए जा सकने वाले codewords के 60% से ज़्यादा न खोए, जिससे बाकी कैमरे के लिए बचे रहते हैं। Intensity प्लेट को उस आकार तक बढ़ाती है। छोटे कोड में छोटा लोगो आता है, और सबसे छोटे कोड (version 1, L या M पर version 2, L पर version 3) में कोई प्लेट नहीं बनती।
- **Image QR**: हर मॉड्यूल को 3 गुणा 3 ग्रिड में बाँटा जाता है। बाहरी सेल फ़ोटो दिखाते हैं, जिन्हें मॉड्यूल की वैल्यू के अनुसार गहरा या हल्का किया जाता है, और बीच वाला सेल सटीक फ़ोरग्राउंड या बैकग्राउंड रंग रखता है, जहाँ से स्कैनर सैंपल लेते हैं।
- Finder, timing, alignment, format और version मॉड्यूल हमेशा ठोस रंग में बनाए जाते हैं।

प्रिंट करने से पहले किसी भी डिज़ाइन को `getScanScore(props)` से जाँचें, और असली फ़ोन कैमरे से टेस्ट करें।

## आर्ट कोड एक्सपोर्ट करें [#export-art-codes]

आर्ट कोड वेक्टर शेप होते हैं, इसलिए हर एक्सपोर्ट में वे साफ़ बने रहते हैं:

```ts title="lib/export-art.ts"
import { downloadQRCode, getQRAsEPS, getQRAsPrintPDF } from "qrdx";

await downloadQRCode(props, { format: "svg", size: { width: 1024, height: 1024 } });
const pdf = await getQRAsPrintPDF(props, { size: 40, unit: "mm", colorMode: "cmyk" });
const eps = await getQRAsEPS(props, { sizeMm: 40, bleedMm: 3, colorMode: "cmyk" });
```

`getQRAsEPS` पॉइंट में `%%BoundingBox` वाली EPSF-3.0 फ़ाइल लिखता है, जिसमें हर मॉड्यूल, आँख और फ़्रेम एक PostScript पाथ होता है। प्रिंट PDF की तरह यह linear और radial ग्रेडिएंट रखता है (PostScript Level 3 shadings के रूप में) और इसमें ट्रांसपेरेंसी नहीं होती। PNG और JPEG लोगो इमेज के रूप में एम्बेड होते हैं; दूसरे लोगो फ़ॉर्मैट ब्राउज़र में बदले जाते हैं और सर्वर पर छोड़ दिए जाते हैं। फ़्रेम टेक्स्ट Helvetica इस्तेमाल करता है, इसलिए Latin-1 से बाहर के अक्षर `?` के रूप में प्रिंट होते हैं। `svgToEPS(svg, { width })` इस लाइब्रेरी से रेंडर किए गए किसी भी SVG को बदल देता है। CLI भी EPS लिखता है: `qrdx generate "https://example.com" -o qr.eps`।

[AI QR art](/ai/art) Vercel AI Gateway के ज़रिए {facts.artModel} से आपके कोड को एक दृश्य में बदल देता है। आपको {facts.aiArtStyles} स्टाइल प्रीसेट मिलते हैं जिन्हें आप कैटेगरी से ब्राउज़ या सर्च कर सकते हैं, हर एक का प्रीव्यू स्कैन जाँच पास कर चुका है, साथ में बचने वाली चीज़ें, एक **QR visibility** स्लाइडर (मॉडल कोड को कितना ज़्यादा तरजीह दे), एक **creativity** स्लाइडर (मॉडल आपके प्रॉम्प्ट को कितनी आज़ादी से पढ़े), हर रन में 1 से 4 variations और एक वैकल्पिक रेफ़रेंस इमेज, जैसे लोगो या पैलेट, जिसके रंग और आकार आगे आ जाते हैं।

हर इमेज आपको दिखाने से पहले सर्वर पर जाँची जाती है। QRdx मॉडल को एक सादा ब्लैक-एंड-व्हाइट कोड भेजता है (error correction H, चौकोर मॉड्यूल, चौड़ा quiet zone) और उससे मॉड्यूल ग्रिड, finder आँखें और quiet zone बनाए रखने को कहता है। फिर वह मॉडल की इमेज को जैसी है वैसी और फ़ोन-कैमरा मॉडल के ज़रिए jsQR से डिकोड करता है। अगर यह विफल होता है, तो वह मॉडल की बनाई जगह पर मॉड्यूल ग्रिड ढूँढता है और मॉडल की अपनी इमेज पर कोड को जितना कम हो सके उतना मज़बूत करता है: पहले finder आँखें और quiet zone, फिर मॉड्यूल, और मज़बूती को कदम-दर-कदम बढ़ाता है जब तक इमेज स्कैन न हो जाए, तब भी जब कैमरे के व्यू में कोड छोटा हो। QR visibility तय करती है कि वह कितनी दूर तक जा सकता है। अगर यह काफ़ी नहीं होता, तभी वह इमेज को Image QR कोड के रूप में दोबारा बनाता है। जो इमेज फिर भी आपकी सटीक सामग्री में डिकोड नहीं होती, वह दी नहीं जाती। फिर आपका ब्राउज़र variations को स्कोर करके सबसे अच्छी चुनता है; उसे 1024 px पर या 2048 px प्रिंट कॉपी (दोबारा रीसैंपल और फिर से जाँची हुई) के रूप में डाउनलोड करें।

हर दी गई इमेज प्लान की मासिक AI art इमेज में से एक इस्तेमाल करती है: फ़्री अकाउंट को महीने में 3 मिलती हैं, Pro को 30, और Business को 150 जो वर्कस्पेस में सभी के बीच साझा होती हैं। जो इमेज विफल होती हैं या स्कैन जाँच पास नहीं करतीं, वे कोई इस्तेमाल नहीं करतीं, और प्रिंट कॉपी मुफ़्त है। AI art एक रास्टर इमेज है और उसकी सामग्री तय रहती है, इसलिए बदले जा सकने वाले लिंक के लिए उसमें [डायनेमिक कोड](/docs/dynamic-qr-codes) का शॉर्ट लिंक रखें। डेवलपर इसे [AI art API](/docs/developers/ai-art-api) से जनरेट कर सकते हैं।
