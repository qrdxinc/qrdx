`QRCode`는 `logo` prop을 받아 이미지 배치를 대신 처리합니다. 로고 뒤의 모듈을 비우고, 코드가 복구할 수 있는 크기보다 큰 로고는 그리지 않습니다. 이 페이지에서는 배치 옵션, 한계, 그 아래에 있는 원시 `imageSettings` API를 다룹니다.

Playground나 대시보드에서 디자인하려면 도움말의 [로고 추가하기](/docs/help/designing/logos)를 참고하세요.

## 세 줄로 로고 넣기 [#a-logo-in-three-lines]

```tsx title="components/logo-code.tsx"
import { QRCode } from "qrdx";

export function LogoCode() {
  return (
    <QRCode value="https://example.com" size={256} level="H" logo="/logo.png" />
  );
}
```

`logo`에는 앱 안의 경로, URL 또는 데이터 URL을 넣을 수 있습니다. 로고는 코드 너비의 4분의 1 크기로 그려지고, 뒤쪽 모듈은 비워지며, 코드는 오류 정정에 의존해 스캔됩니다. `level="H"`(코드의 30%까지 손상 가능)를 사용하거나, 적어도 기본값인 `Q`(25%)를 사용하세요.

## 크기, 여백, 위치 [#size-clear-space-and-position]

`logoOptions`는 렌더링 크기와 무관한 단위로 로고를 배치합니다.

| 옵션 | 범위 | 기본값 | 역할 |
| --- | --- | --- | --- |
| `size` | 0.1 ~ 0.3 | 0.25 | 코드 너비에 대한 로고 너비의 비율입니다. 25%를 넘으면 H 레벨에서도 패키지의 디코드 테스트에서 읽히지 않습니다 |
| `padding` | 0 ~ 2 | 0 | 로고 주위의 여백이며 모듈 단위입니다 |
| `x`, `y` | 0 ~ 1 | 0.5 | 코드 위에서 로고 중심이 놓이는 위치입니다. 로고는 항상 코드 안에 머뭅니다 |
| `shape` | `square`, `rounded`, `circle` | `square` | 로고를 자릅니다 |
| `plate` | 색상 | 없음 | 로고 뒤에 같은 모양으로 깔리는 단색 받침입니다 |

```tsx title="components/placed-logo-code.tsx"
import { QRCode } from "qrdx";

export function PlacedLogoCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      level="H"
      logo="/logo.png"
      logoOptions={{ size: 0.2, padding: 1, x: 0.6, y: 0.55 }}
    />
  );
}
```

로고를 옮길 때는 세 개의 모서리 눈 모양과 오른쪽 아래 모서리 근처의 작은 사각형(디코더가 원근을 보정할 때 쓰는 정렬 패턴)을 피하세요. 이 중 하나라도 가리는 로고는 스캔 점수에서 실패로 처리됩니다.

## 로고의 최대 크기 [#how-big-a-logo-can-be]

로고(여백 포함)는 닿는 모든 코드워드를 손상시키고, 오류 정정 블록마다 복구할 수 있는 양은 한정되어 있습니다. `QRCode`와 `getQRData`는 손상된 코드워드를 블록별로 세고, 가장 나쁜 블록이 복구 용량의 60% 이하만 쓰도록 로고를 줄입니다(`LOGO_EC_SAFETY`). 작은 코드는 담을 수 있는 양이 더 적습니다. Q 레벨에서 짧은 링크는 너비의 약 13%~17% 크기의 로고까지 들어가며, H 레벨이거나 값이 더 짧으면 더 큰 로고도 들어갑니다.

- `getLogoSizeLimit(props)`는 코드에 들어갈 수 있는 가장 큰 `size`를 반환하므로, 슬라이더를 그 값에서 멈추게 할 수 있습니다.
- `QRCodeSVG`, `QRCodeCanvas`, `getQRAsSVG`의 원시 `imageSettings`에도 같은 상한이 적용됩니다. 들어가는 로고는 지정한 그대로 그려지고, 더 큰 로고는 자체 중심을 기준으로 줄어듭니다.
- `autoLevel`은 비워진 영역이 코드의 7%를 넘으면 오류 정정을 `H`로 올립니다(`AUTO_LEVEL_LOGO_COVERAGE`). 기본값은 꺼짐이므로 기존 코드는 레벨이 그대로 유지됩니다.
- 스캔 점수는 같은 코드워드를 세어, 상한 때문에 로고가 줄어들기 전에 경고합니다.

## 모양, 받침, 배경 [#shape-plate-and-background]

```tsx title="components/round-logo-code.tsx"
import { QRCode } from "qrdx";

export function RoundLogoCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      level="H"
      logo="/logo.png"
      logoOptions={{ size: 0.22, shape: "circle", plate: "#ffffff" }}
    />
  );
}
```

자르기는 SVG 클립 경로로 처리됩니다. 인쇄용 PDF와 EPS도 같은 윤곽으로 잘라내므로 모든 다운로드가 똑같이 보입니다. EPS는 투명도를 지원하지 않아 로고의 투명한 부분이 흰색으로 인쇄됩니다.

로고가 단색 상자 위에 놓여 있다면(JPEG에서 흔합니다) 그 상자를 제거하세요. `removeLogoBackground(src)`는 브라우저에서 정리된 PNG를 데이터 URL로 반환하고, `removeLogoBackdrop(pixels)`는 어디서든 RGBA 픽셀에 같은 작업을 합니다. 네 모서리가 같은 색이면 그 색을 가장자리부터 안쪽으로 지우므로, 마크 안쪽의 같은 색(예: 흰 글자)은 남습니다. 이미지에 단색 배경이 없으면 둘 다 `null`을 반환합니다.

## 원시 이미지 설정 [#raw-image-settings]

`QRCodeSVG`와 `QRCodeCanvas`는 `size`와 같은 픽셀 단위의 `imageSettings`로 로고를 받습니다. 로고를 직접 배치하거나 다른 렌더러의 코드를 옮길 때 사용하세요.

```tsx title="components/image-settings-code.tsx"
import { QRCodeSVG } from "qrdx";

export function ImageSettingsCode() {
  return (
    <QRCodeSVG
      value="https://example.com"
      size={512}
      level="H"
      autoLevel
      imageSettings={{
        src: "/logo.png",
        width: 110,
        height: 110,
        excavate: true,
        padding: 8,
      }}
    />
  );
}
```

- `width`와 `height`는 픽셀 단위입니다. `x`와 `y`를 생략하면 로고가 가운데에 놓입니다.
- `excavate`는 로고 뒤의 모듈을 비웁니다. 로고가 투명해서 모듈이 비쳐 보이길 원하는 경우가 아니라면 켜 두세요.
- `padding`은 로고 주위의 모듈을 추가로 비우며, `width`, `height`와 같은 픽셀 단위입니다.
- `shape`와 `plate`는 `logoOptions`와 같게 동작합니다.
- `margin`과 관계없이 로고는 픽셀 크기를 유지합니다.

`getQRData(props)`는 `logo`와 `logoOptions`를 1024 px 코드용 `imageSettings`로 변환합니다. `QRCode`와 다운로드 도우미가 하나의 배치를 공유하는 방식이 바로 이것입니다.

## 다운로드와 형식 [#downloads-and-formats]

- PNG와 JPEG 로고는 모든 내보내기에 포함됩니다. SVG와 WebP 로고는 브라우저에서 내보낼 때는 그려지지만, 서버에서 만든 PNG에는 빠집니다.
- 다운로드에는 데이터 URL이 가장 안전합니다. 원격 이미지는 브라우저가 파일로 복사하려면 CORS 헤더가 필요하며, 헤더가 없으면 파일에 로고가 들어가지 않습니다.
- 색이 있는 코드에서는 투명 PNG가 가장 깔끔하게 나옵니다. JPEG는 배경색의 `plate`를 추가하거나 먼저 상자를 제거하세요.
- 인쇄하기 전에 로고가 들어간 코드를 휴대폰 두세 대로 테스트하거나 [스캔 점수](/docs/features/frames#will-it-scan)로 확인하세요.
