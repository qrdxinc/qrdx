कोड का आकार तीन props से तय होता है: डेटा मॉड्यूल के लिए `bodyPattern`, तीनों कोने की आँखों (eyes) के लिए `cornerEyePattern`, और हर आई के अंदर के डॉट के लिए `cornerEyeDotPattern`। इस पेज में इन तीनों के साथ मॉड्यूल स्केल, शेप वाले कोड और हर आई के अलग रंग की जानकारी है। हर वैल्यू [शेप, आँखें और फ़्रेम](/docs/styles) में लाइव बनी दिखती है।

Playground या डैशबोर्ड में डिज़ाइन कर रहे हैं? Help में [अपना पहला QR कोड बनाएँ](/docs/help/getting-started/first-qr-code) से शुरू करें।

```tsx title="components/shaped-code.tsx"
import { QRCode } from "qrdx";

export function ShapedCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      bodyPattern="liquid"
      cornerEyePattern="leaf"
      cornerEyeDotPattern="leaf"
    />
  );
}
```

## बॉडी पैटर्न [#body-patterns]

`bodyPattern` डेटा मॉड्यूल का शेप तय करता है। इसकी {facts.bodyPatterns} वैल्यू हैं; डिफ़ॉल्ट `circle` है।

- क्लासिक: `square`, `small-square`, `horizontal-line`, `vertical-line`, `octagon`
- गोल: `circle`, `circle-large`, `rounded`, `liquid`, `liquid-horizontal`, `liquid-vertical`, `random-dots`
- सजावटी: `classy`, `classy-rounded`, `leaf`, `diamond`, `hexagon`
- मज़ेदार: `mosaic`, `plus`, `star`, `heart`, `pacman`, `circle-mixed`

`liquid`, `classy` और `classy-rounded` पास-पास के मॉड्यूल को जोड़कर एक चिकनी आउटलाइन बनाते हैं; `liquid-horizontal` और `liquid-vertical` उन्हें सिर्फ़ पंक्तियों या कॉलम में जोड़ते हैं। `random-dots` और `mosaic` हर मॉड्यूल पर अलग दिखते हैं, लेकिन एक ही वैल्यू पर हमेशा वही कोड बनाते हैं। अलाइनमेंट पैटर्न पैटर्न कोई भी हो, हमेशा ठोस वर्ग के रूप में बनते हैं, ताकि डिकोडर उन्हें ढूँढ सकें।

### मॉड्यूल स्केल [#module-scale]

`moduleScale` (0.5 से 1, डिफ़ॉल्ट 1) हर डेटा मॉड्यूल को उसके केंद्र के चारों ओर छोटा करता है, जिससे कोड हल्का और खुला-खुला दिखता है। जुड़े हुए पैटर्न में इसके बजाय रेखाएँ पतली होती हैं। हर पैटर्न उस सबसे छोटे साइज़ पर रुक जाता है जो पैकेज के टेस्ट में अब भी डिकोड होता है (जैसे `circle` के लिए 0.95, `classy` के लिए 0.7; ये न्यूनतम सीमाएँ `MODULE_SCALE_FLOOR` के नाम से एक्सपोर्ट होती हैं), और अलाइनमेंट पैटर्न पूरे साइज़ में रहते हैं।

```tsx title="components/light-code.tsx"
import { QRCode } from "qrdx";

export function LightCode() {
  return (
    <QRCode
      value="https://example.com"
      bodyPattern="liquid"
      moduleScale={0.8}
    />
  );
}
```

## आई फ़्रेम [#eye-frames]

`cornerEyePattern` कोने की आँखों का शेप तय करता है। इसकी {facts.eyeShapes} वैल्यू हैं; डिफ़ॉल्ट `gear` है: `square`, `rounded`, `extra-rounded`, `squircle`, `cushion`, `bevel`, `octagon`, `leaf`, `leaf-reverse`, `drop`, `petal`, `shield`, `gear`, `circle`, `diya`, `message` और `pointy`।

`leaf`, `leaf-reverse`, `drop` और `petal` तीनों आँखों को इस तरह घुमाते हैं कि हर आई कोड के अपने कोने की ओर रहे। `circle` आँखें कुछ स्कैनर ऐप्स से छूट सकती हैं; [स्कैन स्कोर](/docs/features/frames#will-it-scan) इनके बारे में चेतावनी देता है।

## आई सेंटर [#eye-centers]

`cornerEyeDotPattern` हर आई के अंदर के डॉट का शेप तय करता है। इसकी {facts.eyeCentres} वैल्यू हैं; डिफ़ॉल्ट `circle` है: `square`, `rounded`, `extra-rounded`, `circle`, `squircle`, `octagon`, `hexagon`, `dots`, `leaf`, `leaf-reverse`, `drop`, `drop-reverse`, `plus`, `cross-rounded`, `flower`, `heart`, `message`, `message-reverse`, `diya`, `diya-reverse` और `rounded-triangle`।

## बचने वाले जोड़े और हटाए गए शेप [#pairs-to-avoid-and-retired-shapes]

`square` आँखों के साथ `diamond` बॉडी, `rounded` आँखों के साथ `pacman`, और `square` या `rounded` आँखों के साथ `small-square` पास से स्कैन करने पर छूट जाते हैं। Playground इन्हें एक साथ नहीं रखता, ये `WEAK_BODY_EYES` के नाम से शिप होते हैं, और `getStylePairRisk(props)` वही चेतावनी लौटाता है जो स्कैन स्कोर में दिखती है।

चौकोर कोनों वाली आँखों (`square`, `rounded`, `extra-rounded` और ज़्यादातर अन्य) के अंदर `circle` सेंटर को सख़्त डिकोडर तीखे रेंडर में नहीं पढ़ पाते: स्क्रीन पर, PNG एक्सपोर्ट में और बड़े प्रिंट में। ठोस बॉडी (`square`, `liquid`, `classy`, `classy-rounded`) आमतौर पर फिर भी पढ़ी जाती हैं, और `gear`, `circle` और `octagon` आँखों पर इसका असर नहीं पड़ता। स्कैन स्कोर इसकी चेतावनी देता है (`style-pair`) और आप फिर भी इसे चुन सकते हैं। ये जोड़े `WEAK_SHARP_DOT_EYES` (और `SHARP_DOT_EYE_SAFE_BODIES`) के साथ शिप होते हैं, और `rounded` सेंटर चुनने से यह समस्या नहीं आती।

`curly` आँखें और `diamond`, `star` व `banner` सेंटर हटा दिए गए, क्योंकि वे भरोसेमंद ढंग से स्कैन नहीं होते। इनके साथ सेव किए गए डिज़ाइन अब भी रेंडर होते हैं, लेकिन ये अब ऑफ़र या लिस्ट नहीं किए जाते; [हटाए गए शेप](/docs/styles#retired-shapes) देखें।

## सर्कल कोड [#circle-codes]

`shape="circle"` कोड को एक गोले में रखता है और उसका बाकी हिस्सा उसी डॉट शेप के सजावटी मॉड्यूल से भर देता है। असली कोड के चारों ओर `margin` मॉड्यूल (कम से कम 3) का हल्का घेरा रहता है, और स्कैनर सिर्फ़ बीच का कोड पढ़ते हैं। गोला कोड से बड़ा होता है, इसलिए उतनी ही स्कैन दूरी के लिए इसे थोड़ा बड़ा प्रिंट करें; [प्रिंट साइज़ कैलकुलेटर](/tools/print-size) पूरे गोले को गिनता है।

```tsx title="components/circle-code.tsx"
import { QRCode } from "qrdx";

export function CircleCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      shape="circle"
      bodyPattern="rounded"
    />
  );
}
```

पैकेज के डिकोड टेस्ट में ठोस डॉट शेप (`square`, `rounded`, `classy`, `liquid`) के साथ सर्कल कोड चौकोर कोड की तरह ही पढ़े जाते हैं।

## हार्ट कोड [#heart-codes]

`shape="heart"` सर्कल कोड की तरह ही काम करता है, बस दिल के आकार में। असली कोड दिल के बीच में कम से कम 3 मॉड्यूल के हल्के घेरे के साथ रहता है, और दिल का बाकी हिस्सा सजावटी मॉड्यूल से भर जाता है। कोड दिल के उतने हिस्से में नहीं आता जितना गोले में आता है, इसलिए उतनी ही स्कैन दूरी के लिए हार्ट कोड को चौकोर कोड से बड़ा प्रिंट करें। स्कैन स्कोर इसे गिनता है: एक ही साइज़ पर हार्ट कोड का स्कोर सर्कल कोड से कम आता है।

```tsx title="components/heart-code.tsx"
import { QRCode } from "qrdx";

export function HeartCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      shape="heart"
      bodyPattern="rounded"
    />
  );
}
```

Playground में शेप वाला कोड फ़्रेम की जगह लेता है: शेप चुनने पर फ़्रेम हट जाता है, और फ़्रेम चुनने पर शेप हट जाता है। हर फ़्रेम कोड के नीचे एक हल्की प्लेट बनाता है, जो आउटलाइन को छिपा देती। दोनों देने पर भी इंजन `shape` को `frame` के साथ बनाता है। पैकेज के डिकोड टेस्ट में हार्ट कोड हर ठोस डॉट शेप के साथ और `square`, `rounded` व `gear` आँखों के साथ पढ़े गए।

## कस्टम शेप [#custom-shapes]

`shape` एक सिल्हूट भी लेता है: आपकी अपनी तस्वीर से बनाया गया छोटा ग्रिड (हर तरफ़ अधिकतम 64 सेल)। कोड शेप के सबसे खुले बीच वाले हिस्से में रहता है, और शेप का बाकी हिस्सा सजावटी मॉड्यूल से भर जाता है। सिर्फ़ ग्रिड रखा जाता है, तस्वीर कभी नहीं।

```tsx title="components/silhouette-code.tsx"
import { getQRSilhouetteFit, loadQRSilhouette, QRCode } from "qrdx";

export async function silhouetteFrom(file: File) {
  const shape = await loadQRSilhouette(file); // a PNG, JPEG or SVG, in the browser
  const fit = getQRSilhouetteFit(shape);
  if (!fit.ok) throw new Error(fit.message);
  return shape;
}

export function SilhouetteCode({ shape }: { shape: Awaited<ReturnType<typeof silhouetteFrom>> }) {
  return <QRCode value="https://example.com" size={256} shape={shape} />;
}
```

`loadQRSilhouette` तस्वीर को canvas पर बनाता है और उसकी ट्रांसपेरेंसी का इस्तेमाल करता है, या तस्वीर ठोस हो तो उसके गहरेपन का, इसलिए गहरे बैकग्राउंड पर हल्का शेप भी चलता है। सर्वर पर डिकोड किए गए RGBA पिक्सल `createQRSilhouette` को दें। `getQRSilhouetteFit` ऐसे शेप को मना कर देता है जो क्वाइट ज़ोन के साथ कोड रखने के लिए बहुत पतला हो, जैसे पतला तारा, पट्टी या छल्ला। मना किया गया शेप चौकोर कोड के रूप में बनता है।

डैशबोर्ड में सिल्हूट डिज़ाइन के साथ रहता है, अपलोड किए गए लोगो की तरह: शेयर किए गए लिंक, कम्युनिटी आइटम, कोड स्निपेट और AI चैट इसकी जगह चौकोर कोड इस्तेमाल करते हैं।

## हर आई का अलग रंग [#per-eye-colors]

`eyeColor` और `dotColor` तीनों आँखों को रंगते हैं। `eyeColors` इन्हें हर आई के लिए बदल देता है (`topLeft`, `topRight`, `bottomLeft`), और हर एक में `outer` (फ़्रेम) और `inner` (डॉट) का रंग या ग्रेडिएंट होता है:

```tsx title="components/eye-colors-code.tsx"
import { QRCode } from "qrdx";

export function EyeColorsCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      eyeColor="#111827"
      eyeColors={{
        topLeft: { outer: "#dc2626", inner: "#1d4ed8" },
        topRight: { outer: "#16a34a" },
      }}
    />
  );
}
```

हर आई को बैकग्राउंड के मुक़ाबले गहरा रखें: डिकोडर कोड को उसकी तीन आँखों से ढूँढते हैं। स्कैन स्कोर हर आई के अपने रंगों का कॉन्ट्रास्ट जाँचता है।
