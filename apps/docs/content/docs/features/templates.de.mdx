Eine Vorlage ist ein Rahmen, der den Code in ein Artwork mit fester Größe einpasst. Du übergibst ihre ID als `templateId`, und die Komponente zeichnet das gesamte Artwork in `size`, wobei der Code darin kleiner ist. Diese Seite listet die integrierten Vorlagen, die Optionen von Dot Ring und das Zeichnen einer Vorlage im Code auf.

Gestaltest du stattdessen im Playground oder im Dashboard? Vorlagen sind Kacheln in der Gruppe **Classic** der Rahmenauswahl; siehe [Rahmen und Call-to-Action hinzufügen](/docs/help/designing/frames) in der Hilfe.

Vorlagen unterscheiden sich in einem Punkt von den anderen [Rahmen](/docs/features/frames): der Größe. Ein Rahmen fügt Platz um den Code hinzu, also ist `size` die Breite des Codes und das Bild wächst. Eine Vorlage zeichnet ihr gesamtes Artwork in `size`, wobei der Code darin kleiner ist.

## Integrierte Vorlagen [#built-in-templates]

| `templateId` | Name | Farbe |
| --- | --- | --- |
| `Arrow` | Arrow | Die dunkle Farbe des Codes (`fgColor`) |
| `StandardBox` | Standard Box | `fgColor` |
| `SquareBorder` | Square Border | `fgColor` |
| `StrikedBox` | Striked Box | Eigene dunkle Farbe |
| `Halloween` | Halloween | Eigenes Orange, Grün und Schwarz |
| `DotRing` | Dot Ring | Ring in `fgColor`, Text in Weiß; beides lässt sich ändern (siehe unten) |

`default` zeichnet kein Artwork. Es rückt den Code nur ein wenig ein, auf 95 % von `size`. Ohne `templateId` füllt der Code `size` aus.

```tsx title="components/arrow-code.tsx"
import { QRCode } from "qrdx";

export function ArrowCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      templateId="Arrow"
      fgColor="#1a56db"
    />
  );
}
```

<Shot id="lib-templates" />

Farben, Muster und ein Logo bleiben bei den eigenen Props des Codes, daher funktioniert eine Vorlage mit jedem Stil:

```tsx title="components/boxed-logo-code.tsx"
import { QRCode } from "qrdx";

export function BoxedLogoCode() {
  return (
    <QRCode
      value="https://example.com"
      size={512}
      templateId="StandardBox"
      fgColor="#1a56db"
      level="H"
      logo="/logo.png"
    />
  );
}
```

Die Image API nimmt eine Vorlage als `template` entgegen, die CLI als `--template`.

## Dot Ring [#dot-ring]

Ein runder Code. Der Code sitzt in einer Scheibe aus Punkten innerhalb eines dunklen Rings, mit einer Textzeile entlang des Rings. Welche Punkte sichtbar sind, ergibt sich aus einem Hash des Code-Inhalts. So bekommt jeder Link seinen eigenen Ring, und derselbe Link bekommt immer denselben.

```tsx title="components/dot-ring-code.tsx"
import { QRCode } from "qrdx";

export function DotRingCode() {
  return (
    <QRCode
      value="https://example.com"
      size={512}
      templateId="DotRing"
      bodyPattern="circle-large"
      customProps={{
        customText: "Scan for the menu",
        textPosition: "bottom",
        textColor: "#fde047",
        outerCircleColor: "#1e3a8a",
      }}
    />
  );
}
```

Die Einstellungen kommen in `customProps`, typisiert als `DotRingProps`:

| Prop | Standard | Hinweise |
| --- | --- | --- |
| `customText` | „Scan the QR code *“ viermal rund um den Ring | Text entlang des Rings; `""` lässt den Ring leer. Zu langer Text wird angepasst (siehe unten) |
| `textFill` | `"none"` | `"repeat"` wiederholt den Text rund um den ganzen Ring (siehe unten) |
| `textPosition` | `"top"` | `"top"`: oben zentriert, im Uhrzeigersinn gelesen. `"bottom"`: unten zentriert entlang des Rings, von links nach rechts gelesen |
| `textRotation` | `0` | Dreht den Text um die Mitte, in Grad im Uhrzeigersinn |
| `textColor` | `#ffffff` | Textfarbe |
| `fontFamily` | System-Schriftstapel | CSS-Schriftfamilie des Textes |
| `fontWeight` | `900` | Schriftstärke |
| `fontSize` | `32` | In der 593 Einheiten großen Zeichnung der Vorlage, in der der Code 300 breit ist. Langer Text kann kleiner gezeichnet werden |
| `fontLetterSpacing` | `3.5` | Zusätzlicher Abstand zwischen den Buchstaben, in denselben Einheiten. Langer Text und `textFill` passen ihn an |
| `outerCircleColor` | `fgColor` | Ringfarbe |
| `strokeWidth`, `strokeColor` | `0`, `#000000` | Eine Kontur an beiden Rändern des Rings |
| `outerStrokeWidth`, `outerStrokeColor` | `strokeWidth`, `strokeColor` | Nur der äußere Rand des Rings |
| `innerStrokeWidth`, `innerStrokeColor` | `strokeWidth`, `strokeColor` | Nur der innere Rand des Rings |

Text, der auf den Ring passt, wird wie angegeben gesetzt, oben zentriert oder unten entlang des Rings. Zu langer Text läuft nie in seinen eigenen Anfang: Zuerst rücken die Buchstaben näher zusammen, dann wird die Schrift kleiner, bis auf die halbe Standardgröße. Der Text schließt den Ring dann mit einem Wortabstand, wo er auf seinen Anfang trifft. Passt er immer noch nicht, behält Text, der eine Phrase wiederholt, so viele ganze Kopien, wie passen, und anderer Text wird nach dem letzten ganzen Wort, das passt, abgeschnitten und endet mit einem Auslassungszeichen.

Ein Logo kommt wie bei jedem Code in die Mitte. Lange Links (Codes mit mehr als 49 Modulen Breite) behalten ein helles Band zwischen dem Code und den Punkten, damit sie auch klein gedruckt noch scannen.

Der Text ist SVG-Text in der Schrift, die du wählst; der Standard ist der System-Schriftstapel, also wird nichts heruntergeladen. SVG- und PNG-Downloads im Browser verwenden die Schriften des Betrachters. PDF und EPS drucken ihn in Helvetica Bold, verwende dort also Latin-1-Text. `getQRAsPNG` aus `qrdx/node` braucht eine auf dem Server installierte Schrift, genau wie Rahmenbeschriftungen.

### Den Ring füllen [#fill-the-ring]

Eine kurze Phrase lässt einen Teil des Rings leer. Setze `textFill: "repeat"`, um sie so oft zu wiederholen, wie sie passt, wobei der Abstand ausgeglichen wird, damit der Ring mit derselben Lücke schließt wie zwischen den Kopien:

```tsx title="components/docs-ring-code.tsx"
import { QRCode } from "qrdx";

export function DocsRingCode() {
  return (
    <QRCode
      value="https://example.com/docs"
      size={512}
      templateId="DotRing"
      customProps={{ customText: "Read the docs *", textFill: "repeat" }}
    />
  );
}
```

Gib die Phrase nur einmal an. Text, der bereits eine Phrase wiederholt, etwa `"Make your own * Make your own *"`, wird als diese Phrase gelesen und füllt den Ring daher genauso.

## Vorlagen sind Rahmen-Spezifikationen [#templates-are-frame-specs]

Das Artwork von Arrow, Standard Box, Square Border, Striked Box und Halloween ist eine [Rahmen-Spezifikation](/docs/features/frames#frame-specs), im selben JSON-Format wie jeder andere Rahmen und von derselben Engine gezeichnet. `getTemplate(id).spec` gibt sie zurück. Verwende sie als Rahmen, wenn du die Größenlogik eines Rahmens willst (der Code behält seine Größe und das Artwork wächst um ihn herum) und die Farboption des Rahmens:

```tsx title="components/arrow-frame-code.tsx"
import { getTemplate, QRCode } from "qrdx";

const spec = getTemplate("Arrow")?.spec;

export function ArrowFrameCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      frame={spec && { style: "custom", spec, color: "#1a56db" }}
    />
  );
}
```

Dot Ring hat keine Spezifikation: Seine Punkte ergeben sich aus dem Inhalt des Codes, deshalb zeichnet er sie im Code (siehe [Eine Vorlage im Code zeichnen](#draw-a-template-in-code)).

`templateId` zeichnet dasselbe Artwork wie zuvor. Gespeicherte Designs, Bild-URLs, CLI-Befehle und Code, die eine Vorlagen-ID verwenden, sehen aus wie immer.

## Vorlagen-Registry [#template-registry]

```ts title="lib/templates.ts"
import { getAllTemplates, getTemplate, getTemplateIds } from "qrdx";

getTemplateIds(); // ["default", "Arrow", "StandardBox", "SquareBorder", "StrikedBox", "Halloween", "DotRing"]
getAllTemplates(); // every TemplateDefinition, with its id and name
getTemplate("Halloween"); // one by id, or undefined
```

## Eine Vorlage im Code zeichnen [#draw-a-template-in-code]

Eine Rahmen-Spezifikation beschreibt festes Artwork. Muss das Artwork berechnet werden, schreibe eine `TemplateDefinition` und übergib sie als `customTemplate`. Ihr `wrapper` erhält den Code als `children` und gibt das zu zeichnende SVG zurück. Er zeichnet auf einer Fläche von 300 mal 300, und der Code kommt ebenfalls in dieser Größe an, verkleinere ihn also, um Platz für dein Artwork zu lassen. `props` enthält `fgColor` und `bgColor` des Codes, und das dritte Argument enthält `url` und `pixelSize` des Codes.

Dieses Beispiel zeichnet einen Ring um den Code:

```tsx title="components/ring-template-code.tsx"
import { QRCode, type TemplateDefinition } from "qrdx";

const ringTemplate: TemplateDefinition = {
  id: "ring",
  name: "Ring",
  wrapper: (children, props) => (
    <svg
      viewBox="0 0 300 300"
      width="300"
      height="300"
      xmlns="http://www.w3.org/2000/svg"
    >
      <circle
        cx="150"
        cy="150"
        r="140"
        fill="none"
        stroke={props?.fgColor ?? "#000000"}
        strokeWidth="8"
      />
      {/* The code at half size, centered */}
      <g transform="translate(75, 75) scale(0.5)">{children}</g>
    </svg>
  ),
};

export function RingTemplateCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      customTemplate={ringTemplate}
      fgColor="#1a56db"
    />
  );
}
```

`customTemplate` hat Vorrang vor `templateId`, wenn beide gesetzt sind. Halte den Code groß genug, damit er von dort scannt, wo Leute ihre Handys halten, und lasse zwischen ihm und deinem Artwork eine helle Lücke. Prüfe das Ergebnis mit dem [Scan-Score](/docs/features/frames#will-it-scan). Ohne JSX schreibst du den Wrapper mit `h` aus `qrdx/core`; siehe [Vanilla JavaScript](/docs/vanilla-js#custom-templates-without-jsx).
