Tres props dan forma a un código: `bodyPattern` para los módulos de datos, `cornerEyePattern` para los tres ojos de las esquinas y `cornerEyeDotPattern` para el punto dentro de cada ojo. Esta página los cubre, además de la escala de los módulos, los códigos con forma y los colores por ojo. Cada valor se muestra en vivo en [Formas, ojos y marcos](/docs/styles).

¿Prefieres diseñar en el Playground o en el panel? Empieza con [Crea tu primer código QR](/docs/help/getting-started/first-qr-code) en la Ayuda.

```tsx title="components/shaped-code.tsx"
import { QRCode } from "qrdx";

export function ShapedCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      bodyPattern="liquid"
      cornerEyePattern="leaf"
      cornerEyeDotPattern="leaf"
    />
  );
}
```

## Patrones del cuerpo [#body-patterns]

`bodyPattern` da forma a los módulos de datos. Hay {facts.bodyPatterns} valores; el predeterminado es `circle`.

- Clásicos: `square`, `small-square`, `horizontal-line`, `vertical-line`, `octagon`
- Redondeados: `circle`, `circle-large`, `rounded`, `liquid`, `liquid-horizontal`, `liquid-vertical`, `random-dots`
- Decorativos: `classy`, `classy-rounded`, `leaf`, `diamond`, `hexagon`
- Divertidos: `mosaic`, `plus`, `star`, `heart`, `pacman`, `circle-mixed`

`liquid`, `classy` y `classy-rounded` unen los módulos vecinos en un contorno suave; `liquid-horizontal` y `liquid-vertical` los unen solo en filas o en columnas. `random-dots` y `mosaic` varían según el módulo, pero siempre dibujan el mismo código para el mismo valor. Los patrones de alineación siempre se dibujan como cuadrados sólidos, sea cual sea el patrón, para que los decodificadores los encuentren.

### Escala de los módulos [#module-scale]

`moduleScale` (de 0.5 a 1, por defecto 1) reduce cada módulo de datos alrededor de su centro para lograr un aspecto más ligero y espaciado. Los patrones conectados obtienen líneas más finas en su lugar. Cada patrón deja de reducirse en el tamaño mínimo que aún se decodifica en las pruebas del paquete (por ejemplo 0.95 para `circle`, 0.7 para `classy`; los mínimos se exportan como `MODULE_SCALE_FLOOR`), y los patrones de alineación mantienen su tamaño completo.

```tsx title="components/light-code.tsx"
import { QRCode } from "qrdx";

export function LightCode() {
  return (
    <QRCode
      value="https://example.com"
      bodyPattern="liquid"
      moduleScale={0.8}
    />
  );
}
```

## Marcos de los ojos [#eye-frames]

`cornerEyePattern` da forma a los ojos de las esquinas. Hay {facts.eyeShapes} valores; el predeterminado es `gear`: `square`, `rounded`, `extra-rounded`, `squircle`, `cushion`, `bevel`, `octagon`, `leaf`, `leaf-reverse`, `drop`, `petal`, `shield`, `gear`, `circle`, `diya`, `message` y `pointy`.

`leaf`, `leaf-reverse`, `drop` y `petal` giran cada uno de los tres ojos para que mire hacia su esquina del código. Algunas apps de escaneo pueden no detectar los ojos `circle`; la [puntuación de escaneo](/docs/features/frames#will-it-scan) avisa de ello.

## Centros de los ojos [#eye-centers]

`cornerEyeDotPattern` da forma al punto dentro de cada ojo. Hay {facts.eyeCentres} valores; el predeterminado es `circle`: `square`, `rounded`, `extra-rounded`, `circle`, `squircle`, `octagon`, `hexagon`, `dots`, `leaf`, `leaf-reverse`, `drop`, `drop-reverse`, `plus`, `cross-rounded`, `flower`, `heart`, `message`, `message-reverse`, `diya`, `diya-reverse` y `rounded-triangle`.

## Combinaciones que conviene evitar y formas retiradas [#pairs-to-avoid-and-retired-shapes]

Los cuerpos `diamond` junto a ojos `square`, `pacman` junto a `rounded`, y `small-square` junto a ojos `square` o `rounded` no se detectan de cerca. El Playground no los combina, se incluyen como `WEAK_BODY_EYES`, y `getStylePairRisk(props)` devuelve la advertencia que muestra la puntuación de escaneo.

Un centro `circle` dentro de ojos con esquinas rectas (`square`, `rounded`, `extra-rounded` y la mayoría de los demás) puede no ser detectado por decodificadores estrictos en renders nítidos: en pantallas, en exportaciones PNG y en impresiones grandes. Los cuerpos sólidos (`square`, `liquid`, `classy`, `classy-rounded`) suelen leerse igualmente, y los ojos `gear`, `circle` y `octagon` no se ven afectados. La puntuación de escaneo lo advierte (`style-pair`) y aun así puedes elegirlo. Las combinaciones se incluyen como `WEAK_SHARP_DOT_EYES` (con `SHARP_DOT_EYE_SAFE_BODIES`), y un centro `rounded` evita el problema.

Los ojos `curly` y los centros `diamond`, `star` y `banner` se retiraron porque no se escanean de forma fiable. Los diseños guardados con ellos se siguen mostrando, pero ya no se ofrecen ni aparecen en las listas; consulta [Formas retiradas](/docs/styles#retired-shapes).

## Códigos circulares [#circle-codes]

`shape="circle"` coloca el código en un disco y rellena el resto con módulos decorativos con la misma forma de punto. El código real conserva un anillo claro de `margin` módulos a su alrededor (al menos 3), y los escáneres leen solo el código del centro. El disco es más grande que el código, así que imprímelo algo más grande para la misma distancia de escaneo; la [calculadora de tamaño de impresión](/tools/print-size) cuenta el disco entero.

```tsx title="components/circle-code.tsx"
import { QRCode } from "qrdx";

export function CircleCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      shape="circle"
      bodyPattern="rounded"
    />
  );
}
```

En las pruebas de decodificación del paquete, los códigos circulares se leen igual que los cuadrados con formas de punto sólidas (`square`, `rounded`, `classy`, `liquid`).

## Códigos con forma de corazón [#heart-codes]

`shape="heart"` funciona como un código circular, pero con forma de corazón. El código real queda en el centro del corazón con su anillo claro de al menos 3 módulos, y el resto del corazón se rellena con módulos decorativos. El código ocupa una parte menor de un corazón que de un círculo, así que imprime un código con forma de corazón más grande que uno cuadrado para la misma distancia de escaneo. La puntuación de escaneo lo tiene en cuenta: al mismo tamaño, un código con forma de corazón puntúa menos que uno circular.

```tsx title="components/heart-code.tsx"
import { QRCode } from "qrdx";

export function HeartCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      shape="heart"
      bodyPattern="rounded"
    />
  );
}
```

En el Playground, un código con forma ocupa el lugar de un marco: al elegir uno se quita el marco, y al elegir un marco se quita la forma. Todos los marcos pintan una placa clara bajo el código, que ocultaría el contorno. El motor sigue dibujando `shape` con un `frame` si pasas ambos. En las pruebas de decodificación del paquete, los códigos con forma de corazón se leen con todas las formas de punto sólidas y con ojos `square`, `rounded` y `gear`.

## Formas personalizadas [#custom-shapes]

`shape` también acepta una silueta: una cuadrícula pequeña trazada a partir de una imagen tuya (de como máximo 64 celdas por lado). El código se coloca en la parte central más amplia de la forma, y el resto de la forma se rellena con módulos decorativos. Solo se conserva la cuadrícula, nunca la imagen.

```tsx title="components/silhouette-code.tsx"
import { getQRSilhouetteFit, loadQRSilhouette, QRCode } from "qrdx";

export async function silhouetteFrom(file: File) {
  const shape = await loadQRSilhouette(file); // a PNG, JPEG or SVG, in the browser
  const fit = getQRSilhouetteFit(shape);
  if (!fit.ok) throw new Error(fit.message);
  return shape;
}

export function SilhouetteCode({ shape }: { shape: Awaited<ReturnType<typeof silhouetteFrom>> }) {
  return <QRCode value="https://example.com" size={256} shape={shape} />;
}
```

`loadQRSilhouette` dibuja la imagen en un canvas y usa su transparencia, o su oscuridad cuando es opaca, de modo que también funciona una forma clara sobre fondo oscuro. En un servidor, pasa píxeles RGBA decodificados a `createQRSilhouette`. `getQRSilhouetteFit` rechaza una forma demasiado delgada para contener el código con su zona de silencio, como una estrella fina, una barra o un anillo. Una forma rechazada se dibuja como un código cuadrado.

En el panel, una silueta permanece con el diseño, igual que un logo subido: los enlaces compartidos, los elementos de la comunidad, los fragmentos de código y el chat de IA usan un código cuadrado en su lugar.

## Colores por ojo [#per-eye-colors]

`eyeColor` y `dotColor` dan color a los tres ojos. `eyeColors` los reemplaza ojo por ojo (`topLeft`, `topRight`, `bottomLeft`), cada uno con un color o degradado `outer` (marco) e `inner` (punto):

```tsx title="components/eye-colors-code.tsx"
import { QRCode } from "qrdx";

export function EyeColorsCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      eyeColor="#111827"
      eyeColors={{
        topLeft: { outer: "#dc2626", inner: "#1d4ed8" },
        topRight: { outer: "#16a34a" },
      }}
    />
  );
}
```

Mantén cada ojo oscuro frente al fondo: los decodificadores encuentran el código por sus tres ojos. La puntuación de escaneo comprueba el contraste de los colores de cada ojo.
