`QRCode` accetta una prop `logo` e dispone l'immagine al posto tuo: libera i moduli dietro il logo e non ne disegna mai uno più grande di quanto il codice possa riparare. Questa pagina descrive le opzioni di layout, i limiti e l'API grezza `imageSettings` che sta sotto.

Stai progettando nel Playground o nella dashboard? Vedi [Aggiungere un logo](/docs/help/designing/logos) nella Guida.

## Un logo in tre righe [#a-logo-in-three-lines]

```tsx title="components/logo-code.tsx"
import { QRCode } from "qrdx";

export function LogoCode() {
  return (
    <QRCode value="https://example.com" size={256} level="H" logo="/logo.png" />
  );
}
```

`logo` accetta un percorso nella tua app, un URL o un data URL. Il logo viene disegnato a un quarto della larghezza del codice, i moduli dietro di esso vengono liberati e il codice si affida alla correzione degli errori per essere letto. Usa `level="H"` (fino al 30% del codice può essere danneggiato) oppure almeno il valore predefinito `Q` (25%).

## Dimensione, spazio libero e posizione [#size-clear-space-and-position]

`logoOptions` dispone il logo in unità che non dipendono dalla dimensione di rendering:

| Opzione | Intervallo | Predefinito | Cosa fa |
| --- | --- | --- | --- |
| `size` | da 0.1 a 0.3 | 0.25 | La larghezza del logo come quota della larghezza del codice. Oltre il 25% perfino il livello H smette di essere letto nei test di decodifica del pacchetto |
| `padding` | da 0 a 2 | 0 | Spazio libero attorno al logo, in moduli |
| `x`, `y` | da 0 a 1 | 0.5 | Dove si trova il centro del logo sul codice. Il logo resta sempre dentro il codice |
| `shape` | `square`, `rounded`, `circle` | `square` | Ritaglia il logo |
| `plate` | un colore | nessuno | Una base piena dietro il logo, della stessa forma |

```tsx title="components/placed-logo-code.tsx"
import { QRCode } from "qrdx";

export function PlacedLogoCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      level="H"
      logo="/logo.png"
      logoOptions={{ size: 0.2, padding: 1, x: 0.6, y: 0.55 }}
    />
  );
}
```

Se sposti il logo, tienilo lontano dai tre occhi agli angoli e dal piccolo quadrato vicino all'angolo in basso a destra (il pattern di allineamento che i decodificatori usano per correggere la prospettiva). Il punteggio di scansione boccia un logo che ne copre uno.

## Quanto può essere grande un logo [#how-big-a-logo-can-be]

Un logo (con il suo spazio libero) rovina ogni codeword che tocca, e ogni blocco di correzione degli errori ne ripara solo un certo numero. `QRCode` e `getQRData` contano le codeword rovinate blocco per blocco e riducono il logo finché il blocco peggiore usa al massimo il 60% della sua capacità di riparazione (`LOGO_EC_SAFETY`). I codici piccoli ne contengono meno: al livello Q un link breve ospita un logo di circa il 13%-17% della larghezza, mentre il livello H o un valore più corto lasciano più spazio.

- `getLogoSizeLimit(props)` restituisce il `size` più grande che entra in un codice, così uno slider può fermarsi lì.
- Le `imageSettings` grezze su `QRCodeSVG`, `QRCodeCanvas` e `getQRAsSVG` hanno lo stesso limite: un logo che ci sta viene disegnato com'è, uno più grande viene ridotto attorno al proprio centro.
- `autoLevel` porta la correzione degli errori a `H` ogni volta che l'area liberata copre più del 7% del codice (`AUTO_LEVEL_LOGO_COVERAGE`). È disattivato per impostazione predefinita, quindi i codici esistenti mantengono il loro livello.
- Il punteggio di scansione conta le stesse codeword e avvisa prima che il limite riduca il tuo logo.

## Forma, base e sfondo [#shape-plate-and-background]

```tsx title="components/round-logo-code.tsx"
import { QRCode } from "qrdx";

export function RoundLogoCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      level="H"
      logo="/logo.png"
      logoOptions={{ size: 0.22, shape: "circle", plate: "#ffffff" }}
    />
  );
}
```

Il ritaglio è un clip path SVG. Il PDF di stampa e l'EPS usano lo stesso contorno, quindi ogni download ha lo stesso aspetto. L'EPS non supporta la trasparenza, quindi le parti trasparenti di un logo vengono stampate in bianco.

Se un logo poggia su un riquadro pieno (comune con i JPEG), rimuovilo: `removeLogoBackground(src)` restituisce nel browser il PNG pulito come data URL, e `removeLogoBackdrop(pixels)` fa lo stesso su pixel RGBA in qualsiasi ambiente. Quando i quattro angoli hanno lo stesso colore, quel colore viene eliminato dai bordi verso l'interno, quindi lo stesso colore all'interno del marchio (per esempio lettere bianche) resta. Entrambe restituiscono `null` quando l'immagine non ha uno sfondo pieno.

## Impostazioni immagine grezze [#raw-image-settings]

`QRCodeSVG` e `QRCodeCanvas` accettano il logo come `imageSettings`, negli stessi pixel di `size`. Usalo quando disponi il logo da solo o porti codice da un altro renderer.

```tsx title="components/image-settings-code.tsx"
import { QRCodeSVG } from "qrdx";

export function ImageSettingsCode() {
  return (
    <QRCodeSVG
      value="https://example.com"
      size={512}
      level="H"
      autoLevel
      imageSettings={{
        src: "/logo.png",
        width: 110,
        height: 110,
        excavate: true,
        padding: 8,
      }}
    />
  );
}
```

- `width` e `height` sono in pixel. Ometti `x` e `y` per centrare il logo.
- `excavate` libera i moduli dietro il logo. Lascialo attivo, a meno che il logo sia trasparente e tu voglia che i moduli si vedano attraverso.
- `padding` libera moduli extra attorno al logo, negli stessi pixel di `width` e `height`.
- `shape` e `plate` funzionano come in `logoOptions`.
- Il logo mantiene la sua dimensione in pixel qualunque sia il `margin`.

`getQRData(props)` trasforma `logo` e `logoOptions` in queste `imageSettings` per un codice di 1024 px, ed è così che `QRCode` e gli helper di download condividono un unico layout.

## Download e formati [#downloads-and-formats]

- I loghi PNG e JPEG vengono incorporati in ogni esportazione. I loghi SVG e WebP vengono disegnati nelle esportazioni del browser e omessi da un PNG generato su un server.
- Per i download, un data URL è la scelta più sicura. Un'immagine remota richiede header CORS prima che il browser possa copiarla nel file; senza, il file non avrà il logo.
- Un PNG con trasparenza dà il risultato più pulito su un codice colorato. Per un JPEG, aggiungi una `plate` del colore dello sfondo oppure rimuovi prima il suo riquadro.
- Prova un codice con logo su due o tre telefoni prima di stamparlo, oppure controllalo con il [punteggio di scansione](/docs/features/frames#will-it-scan).
