`art` prop은 AI 없이 벡터 도형으로 로고나 사진을 코드의 모듈에 녹여 넣습니다. Logo QR은 로고 모양 안쪽의 모듈 색을 바꾸고, Image QR은 모든 모듈에 사진이 비치도록 표현합니다. 두 방식 모두 라이브러리가 직접 그리므로 오프라인, 서버, Node에서 동작하며 결과물은 항상 실제 QR 코드입니다. 이 페이지에서는 이 prop, 그림을 샘플링하는 방식, 스캔 가능한 상태를 유지하는 방법을 다룹니다.

Playground나 대시보드에서 디자인하시나요? 도움말의 [로고나 사진을 코드에 녹여 넣기](/docs/help/designing/art)를 참고하세요.

QRdx에서 코드를 아트워크로 만드는 방법은 세 가지입니다.

| | 작동 방식 | 출력 | 비용 |
| --- | --- | --- | --- |
| **Logo QR** (`mode: "logo"`) | 로고 모양 안쪽의 모듈은 로고의 색을 가져오고, 나머지는 더 밝은 톤으로 옅어집니다 | 벡터 (SVG, PDF, EPS, PNG) | 무료 |
| **Image QR** (`mode: "halftone"`) | 모든 모듈에 사진이 비치며, 가운데 사각형은 실제 값을 유지합니다 | 벡터 (SVG, PDF, EPS, PNG) | 무료 |
| **AI art** | AI 이미지 모델이 코드를 하나의 장면으로 다시 그리며, 모든 이미지는 스캔되는지 검증됩니다 | 1024 px 이미지, 2048 px 인쇄용 사본 | 요금제에 포함된 AI art 이미지 |

## 아트 코드 그리기 [#draw-an-art-code]

모드, 샘플링한 이미지, 선택 사항인 강도를 담아 `art` prop을 전달하세요.

```tsx title="components/logo-art-code.tsx"
import { loadQRArtImage, type QRArtImage, QRCode } from "qrdx";

// Browser: sample an uploaded file, a data URL or an <img>
export async function sampleLogo(file: File): Promise<QRArtImage> {
  return await loadQRArtImage(file, { mode: "logo" });
}

export function LogoArtCode({ image }: { image: QRArtImage }) {
  return (
    <QRCode
      value="https://example.com"
      size={512}
      level="H"
      art={{ mode: "logo", image, intensity: 0.7 }}
    />
  );
}
```

서버나 Node에서는 이미지를 직접 디코딩한 뒤 RGBA 픽셀을 `createQRArtImage`에 전달하세요.

```ts title="lib/sample-photo.ts"
import { createQRArtImage } from "qrdx";
import sharp from "sharp";

const { data, info } = await sharp("photo.jpg")
  .ensureAlpha()
  .raw()
  .toBuffer({ resolveWithObject: true });

export const image = createQRArtImage(
  { data, width: info.width, height: info.height },
  { maxSize: 96, square: true }
);
// art={{ mode: "halftone", image, intensity: 0.8 }}
```

`art.image`는 일반 JSON(base64 RGBA를 담은 `{ width, height, data }`)이므로 저장된 디자인과 함께 보관해 두었다가, 그림을 다시 가져오지 않고도 어디서나 동기적으로 같은 코드를 렌더링할 수 있습니다.

| 옵션 | 값 | 참고 |
| --- | --- | --- |
| `mode` | `logo`, `halftone` | `halftone`은 에디터의 Image QR입니다 |
| `image` | `loadQRArtImage` 또는 `createQRArtImage`의 결과 | 최대 192 x 192 샘플입니다. `loadQRArtImage`는 기본적으로 가로 160개를 샘플링합니다 |
| `intensity` | `0`~`1` | 기본값은 `0.6`이며, `0`이면 일반 코드처럼 보입니다 |
| `variant` | `blend`, `badge` (logo), `color`, `mono` (halftone) | 모드 안에서의 모양입니다. `badge`는 색조를 입힌 코드의 가운데에 둥근 판을 놓고 그 위에 따라 그린 로고를 얹으며, `mono`는 흑백 하프톤입니다. 첫 번째 값이 각 모드의 기본값입니다 |
| `matchEyes` | `true`, `false` | Logo 모드 전용: 로고에서 가져온 색으로 모서리 눈을 칠합니다(기본값 `true`). 눈별 `eyeColors`가 있으면 그 값이 우선합니다 |

아트는 본문 패턴을 대체하며, 모서리 눈은 `cornerEyePattern`, `cornerEyeDotPattern`과 색을 그대로 유지합니다. 아트는 그라디언트 `fgColor` 또는 `bgColor`의 첫 번째 색을 사용하고, 밝은 배경에 어두운 전경이 필요합니다. 색을 반전하면 일반 모양으로 돌아갑니다. 아트에 가장 많은 여유를 주는 `level="H"`를 사용하세요.

## 스캔 가능한 상태를 유지하는 방법 [#how-scannability-is-kept]

- **Logo QR**: 로고 안쪽의 어두운 모듈은 색이 바뀌지만, 스캐너가 여전히 어둡다고 읽는 밝기까지만 어두워집니다. 로고 안쪽의 밝은 모듈은 밝음 기준보다 높게 유지되는 옅은 색조를 입습니다. 로고 바깥의 어두운 모듈은 회색으로 옅어지며, 어두움 기준보다 밝아지지는 않습니다.
- **Logo QR badge**: 판 아래에 있는 모듈 하나하나가 코드워드 하나를 손상시킬 수 있습니다. 판의 크기는 어떤 오류 정정 블록도 복구 가능한 코드워드의 60%보다 많이 잃지 않도록 정해지며, 나머지는 카메라가 읽을 수 있도록 남겨 둡니다. 강도가 높을수록 판이 그 크기까지 커집니다. 작은 코드는 로고도 더 작아지며, 가장 작은 코드(버전 1, L 또는 M의 버전 2, L의 버전 3)에는 판을 그리지 않습니다.
- **Image QR**: 각 모듈을 3 x 3 격자로 나눕니다. 바깥쪽 칸에는 모듈의 값에 맞춰 더 어둡게 또는 더 밝게 조정한 사진이 비치고, 가운데 칸은 스캐너가 샘플링하는 위치이므로 전경색 또는 배경색을 그대로 유지합니다.
- 파인더, 타이밍, 정렬, 형식, 버전 모듈은 항상 단색으로 그립니다.

인쇄하기 전에 `getScanScore(props)`로 디자인을 확인하고, 실제 휴대폰 카메라로도 테스트하세요.

## 아트 코드 내보내기 [#export-art-codes]

아트 코드는 벡터 도형이므로 어떤 형식으로 내보내도 선명하게 유지됩니다.

```ts title="lib/export-art.ts"
import { downloadQRCode, getQRAsEPS, getQRAsPrintPDF } from "qrdx";

await downloadQRCode(props, { format: "svg", size: { width: 1024, height: 1024 } });
const pdf = await getQRAsPrintPDF(props, { size: 40, unit: "mm", colorMode: "cmyk" });
const eps = await getQRAsEPS(props, { sizeMm: 40, bleedMm: 3, colorMode: "cmyk" });
```

`getQRAsEPS`는 포인트 단위의 `%%BoundingBox`가 있는 EPSF-3.0 파일을 쓰며, 모든 모듈, 눈, 프레임이 PostScript 경로로 들어갑니다. 인쇄용 PDF처럼 선형 및 방사형 그라디언트를 (PostScript Level 3 셰이딩으로) 유지하고 투명도는 없습니다. PNG와 JPEG 로고는 이미지로 포함되고, 다른 형식의 로고는 브라우저에서는 변환되며 서버에서는 제외됩니다. 프레임 텍스트는 Helvetica를 사용하므로 Latin-1 밖의 문자는 `?`로 인쇄됩니다. `svgToEPS(svg, { width })`는 이 라이브러리가 렌더링한 모든 SVG를 변환합니다. CLI도 EPS를 쓸 수 있습니다: `qrdx generate "https://example.com" -o qr.eps`.

<IfAvailable feature="aiArt" title="AI art">

[AI QR art](/ai/art)는 Vercel AI Gateway를 통해 {facts.artModel}로 코드를 하나의 장면으로 만들어 줍니다. 카테고리별로 둘러보거나 검색할 수 있는 {facts.aiArtStyles}개의 스타일 프리셋이 있으며, 각 프리셋에는 스캔 검사를 통과한 미리보기, 피해야 할 것, **QR 가시성** 슬라이더(모델이 코드를 얼마나 강하게 우선하는지), **창의성** 슬라이더(프롬프트를 얼마나 자유롭게 해석하는지), 실행당 1~4개의 변형, 그리고 색과 모양을 가져올 로고나 팔레트 같은 선택 사항인 참조 이미지가 있습니다.

모든 이미지는 보여 드리기 전에 서버에서 검사됩니다. QRdx는 모델에 단순한 흑백 코드(오류 정정 H, 정사각형 모듈, 넓은 여백)를 보내고, 모듈 격자, 파인더 눈, 여백을 유지해 달라고 요청합니다. 그런 다음 모델이 만든 이미지를 jsQR로 있는 그대로, 그리고 휴대폰 카메라 모델을 거쳐 디코딩합니다. 실패하면 모델이 그린 모듈 격자를 찾아, 모델 자체의 이미지 위에서 코드를 가능한 한 적게 보강합니다. 먼저 파인더 눈과 여백을, 그다음 모듈을 보강하며, 이미지가 스캔될 때까지 강도를 단계적으로 높이고, 카메라 시야에서 코드가 더 작을 때도 스캔되도록 합니다. QR 가시성은 어디까지 보강할 수 있는지를 정합니다. 그래도 부족할 때만 이미지를 Image QR 코드로 다시 그립니다. 그래도 정확한 콘텐츠로 디코딩되지 않는 이미지는 제공하지 않습니다. 이후 브라우저가 변형의 점수를 매겨 가장 좋은 것을 고르며, 1024 px 또는 2048 px 인쇄용 사본(다시 샘플링한 뒤 한 번 더 검사)으로 다운로드할 수 있습니다.

제공된 이미지 하나마다 요금제의 월간 AI art 이미지 하나가 사용됩니다. 무료 계정은 월 3개, Pro는 30개, Business는 워크스페이스 전체가 함께 쓰는 150개입니다. 실패했거나 스캔 검사를 통과하지 못한 이미지는 차감되지 않으며, 인쇄용 사본은 무료입니다. AI art는 래스터 이미지이고 내용이 고정되므로, 수정 가능한 링크가 필요하면 [동적 QR 코드](/docs/dynamic-qr-codes)의 짧은 링크를 넣으세요. 개발자는 [AI art API](/docs/developers/ai-art-api)로 생성할 수 있습니다.
