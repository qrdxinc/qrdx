`QRCode` acepta una prop `logo` y distribuye la imagen por ti: despeja los módulos que quedan detrás del logo y nunca dibuja uno más grande de lo que el código puede reparar. Esta página cubre las opciones de diseño, los límites y la API `imageSettings` en bruto que hay debajo.

¿Prefieres diseñar en el Playground o en el panel? Consulta [Añade un logo](/docs/help/designing/logos) en la Ayuda.

## Un logo en tres líneas [#a-logo-in-three-lines]

```tsx title="components/logo-code.tsx"
import { QRCode } from "qrdx";

export function LogoCode() {
  return (
    <QRCode value="https://example.com" size={256} level="H" logo="/logo.png" />
  );
}
```

`logo` acepta una ruta de tu app, una URL o una URL de datos. El logo se dibuja a un cuarto del ancho del código, se despejan los módulos que quedan detrás y el código depende de la corrección de errores para poder escanearse. Usa `level="H"` (hasta el 30 % del código puede estar dañado) o, como mínimo, el valor por defecto `Q` (25 %).

## Tamaño, espacio libre y posición [#size-clear-space-and-position]

`logoOptions` distribuye el logo en unidades que no dependen del tamaño de renderizado:

| Opción | Rango | Valor por defecto | Qué hace |
| --- | --- | --- | --- |
| `size` | 0.1 a 0.3 | 0.25 | El ancho del logo como proporción del ancho del código. Por encima del 25 %, incluso el nivel H deja de leerse en las pruebas de decodificación del paquete |
| `padding` | 0 a 2 | 0 | Espacio libre alrededor del logo, en módulos |
| `x`, `y` | 0 a 1 | 0.5 | Dónde queda el centro del logo en el código. El logo siempre permanece dentro del código |
| `shape` | `square`, `rounded`, `circle` | `square` | Recorta el logo |
| `plate` | un color | ninguna | Una placa sólida detrás del logo, con la misma forma |

```tsx title="components/placed-logo-code.tsx"
import { QRCode } from "qrdx";

export function PlacedLogoCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      level="H"
      logo="/logo.png"
      logoOptions={{ size: 0.2, padding: 1, x: 0.6, y: 0.55 }}
    />
  );
}
```

Si mueves el logo, mantenlo alejado de los tres ojos de las esquinas y del cuadrado pequeño cercano a la esquina inferior derecha (el patrón de alineación que los decodificadores usan para corregir la perspectiva). La puntuación de escaneo marca como fallido un logo que cubra alguno de ellos.

## Qué tamaño puede tener un logo [#how-big-a-logo-can-be]

Un logo (con su espacio libre) estropea todas las palabras de código que toca, y cada bloque de corrección de errores solo puede reparar un número limitado. `QRCode` y `getQRData` cuentan las palabras de código estropeadas bloque por bloque y reducen el logo hasta que el peor bloque use como máximo el 60 % de su capacidad de reparación (`LOGO_EC_SAFETY`). Los códigos pequeños admiten menos: en el nivel Q, un enlace corto admite un logo de entre el 13 % y el 17 % del ancho, y el nivel H o un valor más corto dejan sitio para más.

- `getLogoSizeLimit(props)` devuelve el mayor `size` que cabe en un código, para que un control deslizante pueda detenerse ahí.
- Los `imageSettings` en bruto de `QRCodeSVG`, `QRCodeCanvas` y `getQRAsSVG` tienen el mismo límite: un logo que cabe se dibuja tal cual, y uno más grande se reduce alrededor de su propio centro.
- `autoLevel` sube la corrección de errores a `H` siempre que el área despejada cubra más del 7 % del código (`AUTO_LEVEL_LOGO_COVERAGE`). Está desactivado por defecto, así que los códigos existentes conservan su nivel.
- La puntuación de escaneo cuenta las mismas palabras de código y avisa antes de que el límite reduzca tu logo.

## Forma, placa y fondo [#shape-plate-and-background]

```tsx title="components/round-logo-code.tsx"
import { QRCode } from "qrdx";

export function RoundLogoCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      level="H"
      logo="/logo.png"
      logoOptions={{ size: 0.22, shape: "circle", plate: "#ffffff" }}
    />
  );
}
```

El recorte es una ruta de recorte SVG. El PDF de impresión y el EPS se recortan con el mismo contorno, de modo que todas las descargas se ven igual. EPS no admite transparencia, así que las partes transparentes de un logo se imprimen en blanco ahí.

Si un logo está sobre un recuadro de color sólido (habitual en los JPEG), quítalo: `removeLogoBackground(src)` devuelve el PNG limpio como URL de datos en el navegador, y `removeLogoBackdrop(pixels)` hace lo mismo con píxeles RGBA en cualquier entorno. Cuando las cuatro esquinas comparten un mismo color, se elimina ese color desde los bordes hacia dentro, de modo que el mismo color dentro de la marca (por ejemplo, letras blancas) se conserva. Ambas devuelven `null` cuando la imagen no tiene un fondo sólido.

## Ajustes de imagen en bruto [#raw-image-settings]

`QRCodeSVG` y `QRCodeCanvas` reciben el logo como `imageSettings`, en los mismos píxeles que `size`. Úsalo cuando distribuyas el logo tú mismo o migres código de otro renderizador.

```tsx title="components/image-settings-code.tsx"
import { QRCodeSVG } from "qrdx";

export function ImageSettingsCode() {
  return (
    <QRCodeSVG
      value="https://example.com"
      size={512}
      level="H"
      autoLevel
      imageSettings={{
        src: "/logo.png",
        width: 110,
        height: 110,
        excavate: true,
        padding: 8,
      }}
    />
  );
}
```

- `width` y `height` están en píxeles. Omite `x` y `y` para centrar el logo.
- `excavate` despeja los módulos que quedan detrás del logo. Déjalo activado, salvo que el logo sea translúcido y quieras que los módulos se vean a través de él.
- `padding` despeja módulos adicionales alrededor del logo, en los mismos píxeles que `width` y `height`.
- `shape` y `plate` funcionan igual que en `logoOptions`.
- El logo conserva su tamaño en píxeles sea cual sea el `margin`.

`getQRData(props)` convierte `logo` y `logoOptions` en estos `imageSettings` para un código de 1024 px, y así es como `QRCode` y las funciones de descarga comparten un mismo diseño.

## Descargas y formatos [#downloads-and-formats]

- Los logos PNG y JPEG se incrustan en todas las exportaciones. Los logos SVG y WebP se dibujan en las exportaciones del navegador y se omiten en un PNG generado en un servidor.
- Para las descargas, lo más seguro es una URL de datos. Una imagen remota necesita encabezados CORS para que el navegador pueda copiarla al archivo; sin ellos, el archivo no tendrá logo.
- Un PNG con transparencia da el resultado más limpio en un código de color. Si usas un JPEG, añade una `plate` del color del fondo o quita antes su recuadro.
- Prueba un código con logo en dos o tres teléfonos antes de imprimirlo, o compruébalo con la [puntuación de escaneo](/docs/features/frames#will-it-scan).
