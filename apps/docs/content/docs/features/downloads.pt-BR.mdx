`downloadQRCode(props, options)` salva o código descrito por `props` como um arquivo no navegador, em qualquer um de seis formatos. As funções irmãs devolvem o mesmo arquivo como data URL, Blob ou marcação, e `qrdx/node` gera um PNG em um servidor. Todas as funções recebem as mesmas `props` do `QRCode`, então o arquivo é igual ao código mostrado na tela.

Quer baixar pelo Playground ou pelo painel? Veja [Baixar e imprimir um QR code](/docs/help/getting-started/download-and-print) na Ajuda.

## Baixar um arquivo [#download-a-file]

```ts title="lib/download.ts"
import { downloadQRCode } from "qrdx";

await downloadQRCode(
  {
    value: "https://example.com",
    fgColor: "#1d4ed8",
    bodyPattern: "rounded",
    frame: { style: "banner-bottom", text: "Scan me" },
  },
  {
    format: "png",
    size: { width: 1024, height: 1024 },
    filename: "menu.png",
  }
);
```

<Shot id="lib-download-result" />

O navegador salva `menu.png`. `size` é a largura e a altura em pixels do código em si, de 50 a 5000, e é quadrado; uma moldura deixa o arquivo maior que isso. `filename` é opcional: sem ele, o arquivo se chama `qr-code.<ext>`, com o tamanho exato em pixels acrescentado nos formatos raster (`qr-code-1024x1024.png`, ou `qr-code-1270x1454.png` com um banner na parte inferior). `quality` (0 a 1) vale apenas para WebP.

As props são as mesmas do `QRCode`, exceto que o logo vai em `imageSettings`. Para exportar o código que um `QRCode` desenha, incluindo `logo` e `logoOptions`, passe `getQRData(props)` ou `resolveQRCodeProps(props)` em vez das props brutas.

## Formatos [#formats]

| `format` | Arquivo | Observações |
| --- | --- | --- |
| `png` | Imagem | Mantém o fundo transparente. O padrão para a maioria dos usos |
| `jpg` | Imagem | Apenas fundo sólido, arquivo menor |
| `webp` | Imagem | Os pixels do PNG em um arquivo menor; sem perdas, a menos que `quality` seja definido |
| `svg` | Vetorial | Nítido em qualquer tamanho; o arquivo para gráficas e ferramentas de design |
| `pdf` | Documento | Uma página com o código como PNG. Precisa do pacote opcional `jspdf` |
| `eps` | Vetorial | PostScript para Illustrator, CorelDRAW e InDesign. `size.width` é lido como pontos (72 por polegada) |

### WebP [#webp]

O WebP é sem perdas por padrão, então as bordas dos módulos ficam exatas e um fundo transparente continua transparente. Onde o canvas do navegador grava WebP sem perdas (Chrome e Edge fazem isso), o navegador gera o arquivo. Onde ele não consegue, a biblioteca verifica os bytes e codifica os pixels por conta própria com um pequeno codificador sem perdas embutido: o Safari, ao receber um pedido de WebP, devolve um PNG. De qualquer forma, um arquivo `.webp` é sempre WebP.

`quality` (0 a 1) pede um arquivo menor, com perdas, quando o navegador oferece suporte. O WebP com perdas suaviza as bordas dos módulos e as cores, então mantenha o padrão para códigos que precisam ser lidos de longe. `getQRAsWebP` devolve o arquivo como um `Blob`:

```ts title="lib/webp.ts"
import { getQRAsWebP } from "qrdx";

const lossless = await getQRAsWebP({ value: "https://example.com", size: 1024 });
const lossy = await getQRAsWebP({ value: "https://example.com", size: 1024 }, { quality: 0.9 });
```

`canvasToWebP(canvas, options)` faz o mesmo para qualquer canvas, e `encodeWebPLossless(rgba, width, height)` codifica pixels RGBA sem DOM.

### PDF [#pdf]

O download em PDF traz o código como PNG em uma página do mesmo tamanho. Ele precisa do pacote opcional `jspdf` (`npm install jspdf`); sem ele, os downloads em PDF lançam `PDF export needs the optional "jspdf" package`. Para um PDF vetorial em tamanho físico, com sangria, marcas de corte e CMYK, use `downloadPrintPDF`; veja [Exportação pronta para impressão](/docs/features/frames#print-ready-export).

### EPS [#eps]

O EPS não precisa de nenhum pacote extra. `downloadQRCode` lê `size.width` como pontos, então um pedido de 512 px grava um arquivo de 512 pt (18 cm). Para um tamanho físico exato, use `getQRAsEPS`, que devolve o EPS como string: o código tem `sizeMm` de largura (padrão 50 mm), e uma moldura acrescenta a esse valor.

```ts title="lib/eps.ts"
import { downloadPrintEPS, getQRAsEPS } from "qrdx";

const eps = await getQRAsEPS(
  { value: "https://example.com" },
  { sizeMm: 40, bleedMm: 3, colorMode: "cmyk" }
);

await downloadPrintEPS({ value: "https://example.com" }, { sizeMm: 40, filename: "menu.eps" });
```

O EPS não tem transparência nem marcas de corte. Gradientes lineares e radiais são impressos como degradês suaves do PostScript Level 3; gradientes angulares são impressos como um leque de cunhas finas. Cores translúcidas são misturadas com o fundo, e o fundo com o papel branco. Logos em PNG e JPEG são incorporados. O EPS não aceita [preenchimento com imagem](/docs/features/colors-gradients#image-fills): `getQRAsEPS` lança `EPS_IMAGE_FILL_REASON`, e a janela de download do painel oferece PDF, SVG e PNG no lugar.

## Data URLs, Blobs e marcação [#data-urls-blobs-and-markup]

```ts title="lib/export.ts"
import { copyQRCodeToClipboard, getQRCodeDataUrl, getSVGString } from "qrdx";

const props = { value: "https://example.com", size: 512 };

// The same file as a data URL, for an <img> or a form field
const png = await getQRCodeDataUrl(props, "png", { width: 512, height: 512 });

// A PNG on the clipboard, for pasting into a document
await copyQRCodeToClipboard(props, { width: 512, height: 512 });

// The SVG markup, for inlining in a page or an email template
const svg = await getSVGString(props);
```

- `getQRCodeDataUrl(props, format, size, { quality })` aceita todos os formatos que `downloadQRCode` aceita.
- `copyQRCodeToClipboard` grava um PNG. Chame-a em um handler de clique: os navegadores recusam gravações na área de transferência fora de um gesto do usuário.
- `getSVGString` incorpora o logo como data URL, então a marcação funciona sozinha. `toSVGString`, de `qrdx/core`, é a versão síncrona sem essa etapa.

## Tamanhos predefinidos [#preset-sizes]

```ts title="lib/sizes.ts"
import { PRESET_SIZES, validateSize } from "qrdx";

PRESET_SIZES.small; // { width: 200, height: 200 }
PRESET_SIZES.medium; // 400
PRESET_SIZES.large; // 800
PRESET_SIZES.xlarge; // 1200
PRESET_SIZES["2xl"]; // 1600
PRESET_SIZES["3xl"]; // 2000

validateSize(4000, 4000); // { isValid: true }
validateSize(6000, 6000); // { isValid: false, error: "Size must not exceed 5000x5000 pixels" }
```

Escolha o tamanho conforme o destino do arquivo: de 256 a 512 px para uma página web, 1024 px ou mais para impressão a 300 pixels por polegada (1024 px imprime com nitidez até cerca de 8,7 cm de largura). Para tamanhos de impressão exatos, use as funções de impressão, que trabalham em milímetros e polegadas.

## PNG no Node [#png-in-node]

`getQRAsPNG`, de `qrdx/node`, devolve bytes de PNG sem um navegador. Ele precisa de um rasterizador opcional instalado junto do `qrdx`: o `@resvg/resvg-js` desenha o SVG, logos incluídos, como os navegadores fazem; o `sharp` também funciona.

```ts title="scripts/make-png.ts"
import { writeFile } from "node:fs/promises";
import { getQRAsPNG } from "qrdx/node";

const png = await getQRAsPNG(
  { value: "https://example.com", bodyPattern: "rounded", margin: 4 },
  { size: 1024 }
);
await writeFile("qr-code.png", png);
```

Importe de `qrdx/node`, nunca de `qrdx`, para que os bundles do navegador nunca vejam os módulos nativos. Um logo que seja data URL é incorporado como está; uma URL `http(s)` ou um caminho local só é carregado com `loadExternalLogos: true`, para que um servidor que repasse as configurações de quem chama não possa ser levado a buscar URLs internas nem a ler o próprio disco. A marcação SVG não precisa de rasterizador: `toSVGString`, de `qrdx/core`, roda em qualquer lugar.

## Se algo der errado [#if-something-goes-wrong]

- **`Size must be at least 50x50 pixels`, `Size must not exceed 5000x5000 pixels` ou `Width and height must be equal for QR codes`.** `validateSize` rejeitou o tamanho. Passe um tamanho quadrado dentro do intervalo.
- **`PDF export needs the optional "jspdf" package`.** Instale o `jspdf` no mesmo pacote que o `qrdx`.
- **O logo não aparece no arquivo.** A imagem vem de outra origem sem cabeçalhos CORS, então o navegador não conseguiu copiá-la. Sirva-a a partir da sua própria origem ou passe uma data URL.
- **`copyQRCodeToClipboard` é rejeitada.** Ela rodou fora de um handler de clique ou de tecla, ou a página não é servida por HTTPS. Chame-a dentro do próprio handler.
- **`getQRAsPNG` lança um erro sobre rasterizador ausente.** Instale `@resvg/resvg-js` ou `sharp` junto do `qrdx`.
