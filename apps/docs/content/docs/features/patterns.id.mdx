Tiga prop membentuk sebuah kode: `bodyPattern` untuk modul data, `cornerEyePattern` untuk tiga mata di sudut, dan `cornerEyeDotPattern` untuk titik di dalam setiap mata. Halaman ini membahas ketiganya, ditambah skala modul, kode berbentuk, dan warna per mata. Setiap nilai digambar langsung di [Bentuk, mata, dan bingkai](/docs/styles).

Mendesain di Playground atau dasbor? Mulai dengan [Buat kode QR pertama Anda](/docs/help/getting-started/first-qr-code) di Bantuan.

```tsx title="components/shaped-code.tsx"
import { QRCode } from "qrdx";

export function ShapedCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      bodyPattern="liquid"
      cornerEyePattern="leaf"
      cornerEyeDotPattern="leaf"
    />
  );
}
```

## Pola badan [#body-patterns]

`bodyPattern` membentuk modul data. Ada {facts.bodyPatterns} nilai; nilai bawaannya adalah `circle`.

- Klasik: `square`, `small-square`, `horizontal-line`, `vertical-line`, `octagon`
- Membulat: `circle`, `circle-large`, `rounded`, `liquid`, `liquid-horizontal`, `liquid-vertical`, `random-dots`
- Dekoratif: `classy`, `classy-rounded`, `leaf`, `diamond`, `hexagon`
- Ceria: `mosaic`, `plus`, `star`, `heart`, `pacman`, `circle-mixed`

`liquid`, `classy`, dan `classy-rounded` menyatukan modul bertetangga menjadi satu garis tepi yang mulus; `liquid-horizontal` dan `liquid-vertical` menyatukannya hanya per baris atau per kolom. `random-dots` dan `mosaic` bervariasi di setiap modul, tetapi selalu menggambar kode yang sama untuk nilai yang sama. Pola penyelarasan selalu digambar sebagai persegi penuh, apa pun polanya, agar dekoder dapat menemukannya.

### Skala modul [#module-scale]

`moduleScale` (0,5 sampai 1, bawaan 1) mengecilkan setiap modul data di sekitar pusatnya agar tampilan lebih ringan dan lebih renggang. Pola yang saling terhubung justru mendapat garis yang lebih tipis. Setiap pola berhenti mengecil pada ukuran terkecil yang masih terbaca dalam pengujian paket (misalnya 0,95 untuk `circle`, 0,7 untuk `classy`; batas bawahnya diekspor sebagai `MODULE_SCALE_FLOOR`), dan pola penyelarasan tetap berukuran penuh.

```tsx title="components/light-code.tsx"
import { QRCode } from "qrdx";

export function LightCode() {
  return (
    <QRCode
      value="https://example.com"
      bodyPattern="liquid"
      moduleScale={0.8}
    />
  );
}
```

## Bingkai mata [#eye-frames]

`cornerEyePattern` membentuk mata sudut. Ada {facts.eyeShapes} nilai; nilai bawaannya adalah `gear`: `square`, `rounded`, `extra-rounded`, `squircle`, `cushion`, `bevel`, `octagon`, `leaf`, `leaf-reverse`, `drop`, `petal`, `shield`, `gear`, `circle`, `diya`, `message`, dan `pointy`.

`leaf`, `leaf-reverse`, `drop`, dan `petal` memutar masing-masing dari tiga mata agar menghadap sudutnya di dalam kode. Mata `circle` mungkin tidak terbaca oleh beberapa aplikasi pemindai; [skor pemindaian](/docs/features/frames#will-it-scan) memberi peringatan tentangnya.

## Pusat mata [#eye-centers]

`cornerEyeDotPattern` membentuk titik di dalam setiap mata. Ada {facts.eyeCentres} nilai; nilai bawaannya adalah `circle`: `square`, `rounded`, `extra-rounded`, `circle`, `squircle`, `octagon`, `hexagon`, `dots`, `leaf`, `leaf-reverse`, `drop`, `drop-reverse`, `plus`, `cross-rounded`, `flower`, `heart`, `message`, `message-reverse`, `diya`, `diya-reverse`, dan `rounded-triangle`.

## Pasangan yang harus dihindari dan bentuk yang dihentikan [#pairs-to-avoid-and-retired-shapes]

Badan `diamond` di samping mata `square`, `pacman` di samping `rounded`, dan `small-square` di samping mata `square` atau `rounded` tidak terbaca dari jarak dekat. Playground tidak menggabungkannya, pasangan itu dikirim sebagai `WEAK_BODY_EYES`, dan `getStylePairRisk(props)` mengembalikan peringatan yang ditampilkan skor pemindaian.

Pusat `circle` di dalam mata bersudut persegi (`square`, `rounded`, `extra-rounded`, dan sebagian besar lainnya) dapat tidak terbaca oleh dekoder yang ketat pada hasil render yang tajam: di layar, di ekspor PNG, dan di cetakan besar. Badan padat (`square`, `liquid`, `classy`, `classy-rounded`) biasanya masih terbaca, dan mata `gear`, `circle`, dan `octagon` tidak terpengaruh. Skor pemindaian memberi peringatan tentangnya (`style-pair`) dan Anda tetap dapat memilihnya. Pasangan ini dikirim sebagai `WEAK_SHARP_DOT_EYES` (bersama `SHARP_DOT_EYE_SAFE_BODIES`), dan pusat `rounded` menghindari masalah ini.

Mata `curly` serta pusat `diamond`, `star`, dan `banner` dihentikan karena tidak terbaca dengan andal. Desain yang disimpan dengan bentuk itu tetap dirender, tetapi tidak lagi ditawarkan atau didaftarkan; lihat [Bentuk yang dihentikan](/docs/styles#retired-shapes).

## Kode lingkaran [#circle-codes]

`shape="circle"` menempatkan kode di dalam cakram dan mengisi sisanya dengan modul dekoratif dalam bentuk titik yang sama. Kode yang sebenarnya mempertahankan cincin terang selebar `margin` modul di sekelilingnya (minimal 3), dan pemindai hanya membaca kode di bagian tengah. Cakram lebih besar daripada kodenya, jadi cetak sedikit lebih besar untuk jarak pemindaian yang sama; [kalkulator ukuran cetak](/tools/print-size) menghitung seluruh cakram.

```tsx title="components/circle-code.tsx"
import { QRCode } from "qrdx";

export function CircleCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      shape="circle"
      bodyPattern="rounded"
    />
  );
}
```

Dalam pengujian dekode paket, kode lingkaran terbaca seperti kode persegi dengan bentuk titik padat (`square`, `rounded`, `classy`, `liquid`).

## Kode hati [#heart-codes]

`shape="heart"` bekerja seperti kode lingkaran, tetapi dalam bentuk hati. Kode yang sebenarnya berada di tengah hati dengan cincin terangnya yang berisi minimal 3 modul, dan sisa hati diisi dengan modul dekoratif. Kode mengambil bagian yang lebih kecil dari hati dibandingkan dari lingkaran, jadi cetak kode hati lebih besar daripada kode persegi untuk jarak pemindaian yang sama. Skor pemindaian memperhitungkan hal ini: pada ukuran yang sama, kode hati mendapat skor lebih rendah daripada kode lingkaran.

```tsx title="components/heart-code.tsx"
import { QRCode } from "qrdx";

export function HeartCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      shape="heart"
      bodyPattern="rounded"
    />
  );
}
```

Kode berbentuk menggantikan bingkai di Playground: memilih satu akan menghapus bingkai, dan memilih bingkai akan menghapus bentuk. Setiap bingkai melukis pelat terang di bawah kode, yang akan menutupi garis tepinya. Mesin tetap menggambar `shape` bersama `frame` jika Anda memberikan keduanya. Dalam pengujian dekode paket, kode hati terbaca dengan setiap bentuk titik padat dan dengan mata `square`, `rounded`, dan `gear`.

## Bentuk kustom [#custom-shapes]

`shape` juga menerima siluet: grid kecil yang dilacak dari gambar milik Anda sendiri (paling banyak 64 sel per sisi). Kode berada di bagian tengah bentuk yang paling lapang, dan sisa bentuk diisi dengan modul dekoratif. Hanya grid yang disimpan, tidak pernah gambarnya.

```tsx title="components/silhouette-code.tsx"
import { getQRSilhouetteFit, loadQRSilhouette, QRCode } from "qrdx";

export async function silhouetteFrom(file: File) {
  const shape = await loadQRSilhouette(file); // a PNG, JPEG or SVG, in the browser
  const fit = getQRSilhouetteFit(shape);
  if (!fit.ok) throw new Error(fit.message);
  return shape;
}

export function SilhouetteCode({ shape }: { shape: Awaited<ReturnType<typeof silhouetteFrom>> }) {
  return <QRCode value="https://example.com" size={256} shape={shape} />;
}
```

`loadQRSilhouette` menggambar gambar pada kanvas dan menggunakan transparansinya, atau tingkat kegelapannya jika gambar buram, sehingga bentuk terang di atas latar gelap juga dapat digunakan. Di server, berikan piksel RGBA yang sudah didekode ke `createQRSilhouette`. `getQRSilhouetteFit` menolak bentuk yang terlalu tipis untuk memuat kode beserta zona tenangnya, seperti bintang tipis, batang, atau cincin. Bentuk yang ditolak digambar sebagai kode persegi.

Di dasbor, siluet tetap menyatu dengan desain, seperti logo yang diunggah: tautan yang dibagikan, item komunitas, cuplikan kode, dan obrolan AI menggunakan kode persegi.

## Warna per mata [#per-eye-colors]

`eyeColor` dan `dotColor` mewarnai ketiga mata. `eyeColors` menimpanya per mata (`topLeft`, `topRight`, `bottomLeft`), masing-masing dengan warna atau gradien `outer` (bingkai) dan `inner` (titik):

```tsx title="components/eye-colors-code.tsx"
import { QRCode } from "qrdx";

export function EyeColorsCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      eyeColor="#111827"
      eyeColors={{
        topLeft: { outer: "#dc2626", inner: "#1d4ed8" },
        topRight: { outer: "#16a34a" },
      }}
    />
  );
}
```

Jaga agar setiap mata tetap gelap terhadap latar belakang: dekoder menemukan kode lewat tiga matanya. Skor pemindaian memeriksa kontras warna setiap mata secara terpisah.
