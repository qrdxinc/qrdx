`QRCode` は `logo` propを受け取り、ロゴのレイアウトを自動で行います。ロゴの背後にあるモジュールを消去し、コードが復元できる範囲を超える大きさでは描画しません。このページでは、レイアウトオプション、上限、その土台にある生の `imageSettings` APIについて説明します。

コードではなく、Playgroundやダッシュボードでデザインする場合は、ヘルプの[ロゴを追加する](/docs/help/designing/logos)をご覧ください。

## 3行でロゴを追加する [#a-logo-in-three-lines]

```tsx title="components/logo-code.tsx"
import { QRCode } from "qrdx";

export function LogoCode() {
  return (
    <QRCode value="https://example.com" size={256} level="H" logo="/logo.png" />
  );
}
```

`logo` には、アプリ内のパス、URL、またはdata URLを指定できます。ロゴはコード幅の4分の1の大きさで描画され、背後のモジュールは消去されます。コードは誤り訂正によってスキャンされます。`level="H"`（コードの30%まで破損可能）か、少なくともデフォルトの `Q`（25%）を使用してください。

## サイズ、余白、位置 [#size-clear-space-and-position]

`logoOptions` では、描画サイズに依存しない単位でロゴのレイアウトを指定します。

| オプション | 範囲 | デフォルト | 内容 |
| --- | --- | --- | --- |
| `size` | 0.1〜0.3 | 0.25 | コードの幅に対するロゴの幅の割合です。25%を超えると、レベルHでもパッケージのデコードテストで読み取れなくなります |
| `padding` | 0〜2 | 0 | ロゴの周囲の余白です。単位はモジュールです |
| `x`, `y` | 0〜1 | 0.5 | コード上でのロゴの中心位置です。ロゴは常にコードの内側に収まります |
| `shape` | `square`, `rounded`, `circle` | `square` | ロゴを切り抜く形状です |
| `plate` | 色 | なし | ロゴの背後に敷く単色のプレートです。形状はロゴと同じです |

```tsx title="components/placed-logo-code.tsx"
import { QRCode } from "qrdx";

export function PlacedLogoCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      level="H"
      logo="/logo.png"
      logoOptions={{ size: 0.2, padding: 1, x: 0.6, y: 0.55 }}
    />
  );
}
```

ロゴを移動する場合は、3つの角のファインダーパターンと、右下付近の小さな四角（デコーダーが遠近の補正に使うアライメントパターン）に重ならないようにしてください。これらのいずれかを覆うロゴは、スキャンスコアで不合格になります。

## ロゴの最大サイズ [#how-big-a-logo-can-be]

ロゴ（余白を含む）が触れたコードワードはすべて失われ、誤り訂正ブロックごとに復元できる数には限りがあります。`QRCode` と `getQRData` は、失われたコードワードをブロックごとに数え、最も負荷の高いブロックでも復元能力の60%以内（`LOGO_EC_SAFETY`）に収まるまでロゴを縮小します。小さいコードは収容量が少なくなります。レベルQで短いリンクの場合、ロゴは幅の約13%〜17%が目安です。レベルHにするか値を短くすると、より大きなロゴを置けます。

- `getLogoSizeLimit(props)` は、コードに収まる最大の `size` を返します。スライダーの上限として使えます。
- `QRCodeSVG`、`QRCodeCanvas`、`getQRAsSVG` の生の `imageSettings` にも同じ上限が適用されます。収まるロゴはそのまま描画され、大きすぎるロゴはロゴ自身の中心を基準に縮小されます。
- `autoLevel` は、消去される領域がコードの7%を超えると、誤り訂正を `H` に引き上げます（`AUTO_LEVEL_LOGO_COVERAGE`）。デフォルトではオフなので、既存のコードのレベルは変わりません。
- スキャンスコアも同じコードワードを数え、上限によってロゴが縮小される前に警告します。

## 形状、プレート、背景 [#shape-plate-and-background]

```tsx title="components/round-logo-code.tsx"
import { QRCode } from "qrdx";

export function RoundLogoCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      level="H"
      logo="/logo.png"
      logoOptions={{ size: 0.22, shape: "circle", plate: "#ffffff" }}
    />
  );
}
```

切り抜きにはSVGのクリップパスを使います。印刷用のPDFとEPSも同じ輪郭で切り抜くため、どのダウンロードでも見た目が揃います。EPSは透過に対応していないため、ロゴの透明部分は白で出力されます。

ロゴが単色の四角い背景に載っている場合（JPEGによくあります）は、背景を取り除いてください。`removeLogoBackground(src)` はブラウザ上で、背景を取り除いたPNGをdata URLとして返します。`removeLogoBackdrop(pixels)` は、RGBAピクセルに対して場所を問わず同じ処理を行います。四隅が同じ色の場合は、その色を端から内側へ向かって消去するため、マーク内部の同じ色（たとえば白い文字）は残ります。どちらも、単色の背景がない画像では `null` を返します。

## 生の画像設定 [#raw-image-settings]

`QRCodeSVG` と `QRCodeCanvas` は、`size` と同じピクセル単位の `imageSettings` でロゴを受け取ります。ロゴのレイアウトを自分で行う場合や、他のレンダラーからコードを移植する場合に使用してください。

```tsx title="components/image-settings-code.tsx"
import { QRCodeSVG } from "qrdx";

export function ImageSettingsCode() {
  return (
    <QRCodeSVG
      value="https://example.com"
      size={512}
      level="H"
      autoLevel
      imageSettings={{
        src: "/logo.png",
        width: 110,
        height: 110,
        excavate: true,
        padding: 8,
      }}
    />
  );
}
```

- `width` と `height` の単位はピクセルです。`x` と `y` を省略すると、ロゴは中央に配置されます。
- `excavate` は、ロゴの背後のモジュールを消去します。ロゴが半透明で、モジュールを透かして見せたい場合を除き、オンのままにしてください。
- `padding` は、ロゴの周囲の余分なモジュールを消去します。単位は `width` と `height` と同じピクセルです。
- `shape` と `plate` は、`logoOptions` と同じように動作します。
- `margin` の値にかかわらず、ロゴのピクセルサイズは変わりません。

`getQRData(props)` は、`logo` と `logoOptions` を1024 pxのコード用のこれらの `imageSettings` に変換します。これにより、`QRCode` とダウンロード用ヘルパーが同じレイアウトを共有します。

## ダウンロードと形式 [#downloads-and-formats]

- PNGとJPEGのロゴは、すべてのエクスポートに埋め込まれます。SVGとWebPのロゴは、ブラウザ上のエクスポートでは描画されますが、サーバー上で作成するPNGには含まれません。
- ダウンロード用には、data URLが最も確実です。リモート画像は、ブラウザがファイルにコピーするためにCORSヘッダーが必要です。ヘッダーがない場合、ファイルにロゴは含まれません。
- 色付きのコードでは、透過PNGが最もきれいに仕上がります。JPEGの場合は、背景色の `plate` を追加するか、先に背景の四角を取り除いてください。
- ロゴ入りのコードは、印刷する前に2〜3台のスマートフォンでテストするか、[スキャンスコア](/docs/features/frames#will-it-scan)で確認してください。
