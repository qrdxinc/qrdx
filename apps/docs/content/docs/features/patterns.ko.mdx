코드의 모양은 세 가지 prop으로 정해요. 데이터 모듈은 `bodyPattern`, 모서리의 눈 세 개는 `cornerEyePattern`, 각 눈 안쪽의 점은 `cornerEyeDotPattern`이 담당해요. 이 페이지에서는 이 세 가지와 함께 모듈 크기, 모양이 있는 코드, 눈별 색상을 다룹니다. 모든 값은 [모양, 눈, 프레임](/docs/styles)에서 실시간으로 확인할 수 있습니다.

Playground나 대시보드에서 디자인하려고 하시나요? 도움말의 [첫 QR 코드 만들기](/docs/help/getting-started/first-qr-code)부터 시작하세요.

```tsx title="components/shaped-code.tsx"
import { QRCode } from "qrdx";

export function ShapedCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      bodyPattern="liquid"
      cornerEyePattern="leaf"
      cornerEyeDotPattern="leaf"
    />
  );
}
```

## 본문 패턴 [#body-patterns]

`bodyPattern`은 데이터 모듈의 모양을 정합니다. 값은 {facts.bodyPatterns}개이며 기본값은 `circle`입니다.

- 클래식: `square`, `small-square`, `horizontal-line`, `vertical-line`, `octagon`
- 둥근 모양: `circle`, `circle-large`, `rounded`, `liquid`, `liquid-horizontal`, `liquid-vertical`, `random-dots`
- 장식 모양: `classy`, `classy-rounded`, `leaf`, `diamond`, `hexagon`
- 재미있는 모양: `mosaic`, `plus`, `star`, `heart`, `pacman`, `circle-mixed`

`liquid`, `classy`, `classy-rounded`는 이웃한 모듈을 하나의 매끄러운 윤곽으로 이어 줍니다. `liquid-horizontal`과 `liquid-vertical`은 가로줄이나 세로줄 안에서만 이어 줍니다. `random-dots`와 `mosaic`은 모듈마다 모양이 다르지만, 같은 값이면 항상 같은 코드를 그립니다. 정렬 패턴은 어떤 패턴을 쓰든 항상 꽉 찬 정사각형으로 그려져서 디코더가 쉽게 찾을 수 있습니다.

### 모듈 크기 [#module-scale]

`moduleScale`(0.5~1, 기본값 1)은 각 데이터 모듈을 중심을 기준으로 줄여서 더 가볍고 간격이 넓은 느낌을 줍니다. 연결형 패턴은 대신 선이 얇아집니다. 각 패턴은 패키지 테스트에서 디코딩되는 가장 작은 크기까지만 줄어듭니다(예: `circle`은 0.95, `classy`는 0.7이며, 이 하한값은 `MODULE_SCALE_FLOOR`로 내보내집니다). 정렬 패턴은 원래 크기를 유지합니다.

```tsx title="components/light-code.tsx"
import { QRCode } from "qrdx";

export function LightCode() {
  return (
    <QRCode
      value="https://example.com"
      bodyPattern="liquid"
      moduleScale={0.8}
    />
  );
}
```

## 눈 프레임 [#eye-frames]

`cornerEyePattern`은 모서리 눈의 모양을 정합니다. 값은 {facts.eyeShapes}개이며 기본값은 `gear`입니다: `square`, `rounded`, `extra-rounded`, `squircle`, `cushion`, `bevel`, `octagon`, `leaf`, `leaf-reverse`, `drop`, `petal`, `shield`, `gear`, `circle`, `diya`, `message`, `pointy`.

`leaf`, `leaf-reverse`, `drop`, `petal`은 세 눈이 각각 코드의 해당 모서리를 향하도록 회전합니다. `circle` 눈은 일부 스캔 앱에서 인식되지 않을 수 있으며, [스캔 점수](/docs/features/frames#will-it-scan)가 이를 경고합니다.

## 눈 중심 [#eye-centers]

`cornerEyeDotPattern`은 각 눈 안쪽 점의 모양을 정합니다. 값은 {facts.eyeCentres}개이며 기본값은 `circle`입니다: `square`, `rounded`, `extra-rounded`, `circle`, `squircle`, `octagon`, `hexagon`, `dots`, `leaf`, `leaf-reverse`, `drop`, `drop-reverse`, `plus`, `cross-rounded`, `flower`, `heart`, `message`, `message-reverse`, `diya`, `diya-reverse`, `rounded-triangle`.

## 피해야 할 조합과 폐기된 모양 [#pairs-to-avoid-and-retired-shapes]

`square` 눈 옆의 `diamond` 본문, `rounded` 옆의 `pacman`, `square` 또는 `rounded` 눈 옆의 `small-square`는 가까이서 스캔하면 인식되지 않습니다. Playground는 이 조합을 허용하지 않으며, 이 조합은 `WEAK_BODY_EYES`로 제공됩니다. `getStylePairRisk(props)`는 스캔 점수에 표시되는 경고를 반환합니다.

모서리가 각진 눈(`square`, `rounded`, `extra-rounded` 등 대부분) 안의 `circle` 중심은 선명한 렌더링에서 엄격한 디코더가 인식하지 못할 수 있습니다. 화면, PNG 내보내기, 대형 인쇄물이 이에 해당합니다. 꽉 찬 본문(`square`, `liquid`, `classy`, `classy-rounded`)은 대체로 여전히 인식되며, `gear`, `circle`, `octagon` 눈은 영향을 받지 않습니다. 스캔 점수가 이를 경고하지만(`style-pair`) 선택은 그대로 할 수 있습니다. 이 조합은 `WEAK_SHARP_DOT_EYES`(및 `SHARP_DOT_EYE_SAFE_BODIES`)로 제공되며, `rounded` 중심을 쓰면 이 문제를 피할 수 있습니다.

`curly` 눈과 `diamond`, `star`, `banner` 중심은 안정적으로 스캔되지 않아 폐기되었습니다. 이 모양으로 저장한 디자인은 계속 렌더링되지만, 더 이상 제공되거나 목록에 표시되지 않습니다. [폐기된 모양](/docs/styles#retired-shapes)을 참고하세요.

## 원형 코드 [#circle-codes]

`shape="circle"`은 코드를 원판 안에 넣고, 나머지 부분을 같은 점 모양의 장식 모듈로 채웁니다. 실제 코드 주위에는 `margin` 모듈(최소 3)만큼의 밝은 링이 유지되며, 스캐너는 가운데의 코드만 읽습니다. 원판이 코드보다 크므로 같은 스캔 거리를 유지하려면 조금 더 크게 인쇄하세요. [인쇄 크기 계산기](/tools/print-size)는 원판 전체를 기준으로 계산합니다.

```tsx title="components/circle-code.tsx"
import { QRCode } from "qrdx";

export function CircleCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      shape="circle"
      bodyPattern="rounded"
    />
  );
}
```

패키지의 디코딩 테스트에서 원형 코드는 꽉 찬 점 모양(`square`, `rounded`, `classy`, `liquid`)일 때 정사각형 코드와 똑같이 읽혔습니다.

## 하트 코드 [#heart-codes]

`shape="heart"`는 원형 코드와 같은 방식으로 동작하며, 모양만 하트입니다. 실제 코드는 최소 3모듈의 밝은 링과 함께 하트 가운데에 놓이고, 하트의 나머지 부분은 장식 모듈로 채워집니다. 코드가 하트에서 차지하는 부분은 원에서보다 작으므로, 같은 스캔 거리를 유지하려면 하트 코드를 정사각형 코드보다 크게 인쇄하세요. 스캔 점수도 이를 반영해서, 같은 크기라면 하트 코드가 원형 코드보다 낮은 점수를 받습니다.

```tsx title="components/heart-code.tsx"
import { QRCode } from "qrdx";

export function HeartCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      shape="heart"
      bodyPattern="rounded"
    />
  );
}
```

Playground에서는 모양이 있는 코드가 프레임을 대신합니다. 모양을 고르면 프레임이 해제되고, 프레임을 고르면 모양이 해제됩니다. 모든 프레임은 코드 아래에 밝은 판을 깔기 때문에 윤곽이 가려지기 때문입니다. 두 값을 함께 전달하면 엔진은 `frame`과 함께 `shape`도 그립니다. 패키지의 디코딩 테스트에서 하트 코드는 모든 꽉 찬 점 모양과 `square`, `rounded`, `gear` 눈에서 읽혔습니다.

## 사용자 지정 모양 [#custom-shapes]

`shape`에는 실루엣도 쓸 수 있습니다. 실루엣은 직접 가진 그림을 따라 만든 작은 격자입니다(한 변 최대 64칸). 코드는 모양에서 가장 넓은 가운데 부분에 놓이고, 나머지 부분은 장식 모듈로 채워집니다. 격자만 저장되며 그림은 저장되지 않습니다.

```tsx title="components/silhouette-code.tsx"
import { getQRSilhouetteFit, loadQRSilhouette, QRCode } from "qrdx";

export async function silhouetteFrom(file: File) {
  const shape = await loadQRSilhouette(file); // a PNG, JPEG or SVG, in the browser
  const fit = getQRSilhouetteFit(shape);
  if (!fit.ok) throw new Error(fit.message);
  return shape;
}

export function SilhouetteCode({ shape }: { shape: Awaited<ReturnType<typeof silhouetteFrom>> }) {
  return <QRCode value="https://example.com" size={256} shape={shape} />;
}
```

`loadQRSilhouette`는 그림을 캔버스에 그린 뒤 투명도를 사용하며, 그림이 불투명하면 어두운 정도를 사용합니다. 그래서 어두운 배경 위의 밝은 모양도 쓸 수 있습니다. 서버에서는 디코딩된 RGBA 픽셀을 `createQRSilhouette`에 전달하세요. `getQRSilhouetteFit`은 얇은 별, 막대, 링처럼 여백을 포함한 코드를 담기에는 너무 얇은 모양을 거부합니다. 거부된 모양은 정사각형 코드로 그려집니다.

대시보드에서는 실루엣이 업로드한 로고처럼 디자인에 함께 저장됩니다. 공유 링크, 커뮤니티 항목, 코드 스니펫, AI 채팅에서는 정사각형 코드가 대신 사용됩니다.

## 눈별 색상 [#per-eye-colors]

`eyeColor`와 `dotColor`는 세 눈 모두에 색을 지정합니다. `eyeColors`는 이를 눈마다 덮어씁니다(`topLeft`, `topRight`, `bottomLeft`). 각 눈에는 `outer`(프레임)와 `inner`(점) 색상 또는 그라디언트를 지정할 수 있습니다.

```tsx title="components/eye-colors-code.tsx"
import { QRCode } from "qrdx";

export function EyeColorsCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      eyeColor="#111827"
      eyeColors={{
        topLeft: { outer: "#dc2626", inner: "#1d4ed8" },
        topRight: { outer: "#16a34a" },
      }}
    />
  );
}
```

모든 눈이 배경과 대비되도록 어둡게 유지하세요. 디코더는 세 눈으로 코드를 찾습니다. 스캔 점수는 각 눈의 색상별 대비를 확인합니다.
