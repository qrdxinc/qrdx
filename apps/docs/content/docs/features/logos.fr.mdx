`QRCode` accepte une prop `logo` et se charge de la mise en page de l'image : il dégage les modules derrière le logo et n'en dessine jamais un plus grand que ce que le code peut réparer. Cette page présente les options de mise en page, les limites et l'API brute `imageSettings` sur laquelle tout repose.

Vous créez votre code dans le Playground ou le tableau de bord ? Consultez plutôt [Ajouter un logo](/docs/help/designing/logos) dans l'aide.

## Un logo en trois lignes [#a-logo-in-three-lines]

```tsx title="components/logo-code.tsx"
import { QRCode } from "qrdx";

export function LogoCode() {
  return (
    <QRCode value="https://example.com" size={256} level="H" logo="/logo.png" />
  );
}
```

`logo` accepte un chemin dans votre application, une URL ou une URL de données (data URL). Le logo est dessiné à un quart de la largeur du code, les modules derrière lui sont dégagés, et le code s'appuie sur la correction d'erreur pour être lu au scan. Utilisez `level="H"` (30 % du code peut être endommagé) ou, au minimum, le niveau par défaut `Q` (25 %).

## Taille, espace libre et position [#size-clear-space-and-position]

`logoOptions` dispose le logo avec des unités qui ne dépendent pas de la taille du rendu :

| Option | Plage | Par défaut | Rôle |
| --- | --- | --- | --- |
| `size` | 0,1 à 0,3 | 0,25 | La largeur du logo en proportion de la largeur du code. Au-delà de 25 %, même le niveau H cesse d'être lu dans les tests de décodage du package |
| `padding` | 0 à 2 | 0 | Espace libre autour du logo, en modules |
| `x`, `y` | 0 à 1 | 0,5 | Position du centre du logo dans le code. Le logo reste toujours à l'intérieur du code |
| `shape` | `square`, `rounded`, `circle` | `square` | Rogne le logo |
| `plate` | une couleur | aucune | Une pastille pleine derrière le logo, de la même forme |

```tsx title="components/placed-logo-code.tsx"
import { QRCode } from "qrdx";

export function PlacedLogoCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      level="H"
      logo="/logo.png"
      logoOptions={{ size: 0.2, padding: 1, x: 0.6, y: 0.55 }}
    />
  );
}
```

Si vous déplacez le logo, tenez-le à l'écart des trois yeux d'angle et du petit carré près du coin inférieur droit (le motif d'alignement que les décodeurs utilisent pour corriger la perspective). Le score de scan signale un échec si un logo en recouvre un.

## Quelle taille pour un logo [#how-big-a-logo-can-be]

Un logo (avec son espace libre) détériore chaque mot de code qu'il touche, et chaque bloc de correction d'erreur n'en répare qu'un certain nombre. `QRCode` et `getQRData` comptent les mots de code détériorés bloc par bloc et réduisent le logo jusqu'à ce que le pire bloc utilise au plus 60 % de sa capacité de réparation (`LOGO_EC_SAFETY`). Les petits codes en contiennent moins : au niveau Q, un lien court accepte un logo d'environ 13 % à 17 % de la largeur, et le niveau H ou une valeur plus courte laisse plus de place.

- `getLogoSizeLimit(props)` renvoie la plus grande valeur de `size` compatible avec un code, pour qu'un curseur puisse s'arrêter là.
- Les `imageSettings` brutes sur `QRCodeSVG`, `QRCodeCanvas` et `getQRAsSVG` reçoivent le même plafond : un logo qui tient est dessiné tel quel, un logo plus grand est réduit autour de son propre centre.
- `autoLevel` passe la correction d'erreur à `H` dès que la zone dégagée couvre plus de 7 % du code (`AUTO_LEVEL_LOGO_COVERAGE`). Cette option est désactivée par défaut, donc les codes existants conservent leur niveau.
- Le score de scan compte les mêmes mots de code et avertit avant que le plafond ne réduise votre logo.

## Forme, pastille et arrière-plan [#shape-plate-and-background]

```tsx title="components/round-logo-code.tsx"
import { QRCode } from "qrdx";

export function RoundLogoCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      level="H"
      logo="/logo.png"
      logoOptions={{ size: 0.22, shape: "circle", plate: "#ffffff" }}
    />
  );
}
```

Le rognage est un tracé de détourage SVG. Le PDF et l'EPS d'impression sont détourés selon le même contour, si bien que tous les téléchargements ont le même rendu. L'EPS ne gère pas la transparence : les zones transparentes d'un logo y sont imprimées en blanc.

Si un logo est posé sur un cadre uni (fréquent avec les JPEG), supprimez-le : `removeLogoBackground(src)` renvoie le PNG nettoyé sous forme de data URL dans le navigateur, et `removeLogoBackdrop(pixels)` fait de même sur des pixels RGBA, où que vous soyez. Lorsque les quatre coins ont la même couleur, cette couleur est effacée des bords vers l'intérieur, de sorte que la même couleur à l'intérieur du motif (des lettres blanches, par exemple) est conservée. Les deux fonctions renvoient `null` lorsque l'image n'a pas d'arrière-plan uni.

## Paramètres d'image bruts [#raw-image-settings]

`QRCodeSVG` et `QRCodeCanvas` reçoivent le logo via `imageSettings`, avec les mêmes pixels que `size`. Utilisez-les si vous disposez le logo vous-même ou si vous portez du code depuis un autre moteur de rendu.

```tsx title="components/image-settings-code.tsx"
import { QRCodeSVG } from "qrdx";

export function ImageSettingsCode() {
  return (
    <QRCodeSVG
      value="https://example.com"
      size={512}
      level="H"
      autoLevel
      imageSettings={{
        src: "/logo.png",
        width: 110,
        height: 110,
        excavate: true,
        padding: 8,
      }}
    />
  );
}
```

- `width` et `height` sont en pixels. Omettez `x` et `y` pour centrer le logo.
- `excavate` dégage les modules derrière le logo. Laissez-le activé, sauf si le logo est translucide et que vous voulez que les modules transparaissent.
- `padding` dégage des modules supplémentaires autour du logo, dans les mêmes pixels que `width` et `height`.
- `shape` et `plate` fonctionnent comme dans `logoOptions`.
- Le logo garde sa taille en pixels, quelle que soit la valeur de `margin`.

`getQRData(props)` convertit `logo` et `logoOptions` en ces `imageSettings` pour un code de 1024 px, ce qui permet à `QRCode` et aux utilitaires de téléchargement de partager une même mise en page.

## Téléchargements et formats [#downloads-and-formats]

- Les logos PNG et JPEG sont intégrés dans tous les exports. Les logos SVG et WebP sont dessinés dans les exports du navigateur et omis d'un PNG généré sur un serveur.
- Pour les téléchargements, une data URL est le choix le plus sûr. Une image distante nécessite des en-têtes CORS pour que le navigateur puisse la copier dans le fichier ; sans eux, le fichier n'a pas de logo.
- Un PNG avec transparence donne le résultat le plus net sur un code coloré. Pour un JPEG, ajoutez une `plate` de la couleur de l'arrière-plan ou supprimez d'abord son cadre.
- Testez un code avec logo sur deux ou trois téléphones avant de l'imprimer, ou vérifiez-le avec le [score de scan](/docs/features/frames#will-it-scan).
