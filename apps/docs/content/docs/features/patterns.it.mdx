Tre prop danno forma a un codice: `bodyPattern` per i moduli dati, `cornerEyePattern` per i tre occhi agli angoli e `cornerEyeDotPattern` per il punto dentro ogni occhio. Questa pagina le descrive, insieme a scala dei moduli, codici sagomati e colori per singolo occhio. Ogni valore è disegnato dal vivo in [Forme, occhi e cornici](/docs/styles).

Preferisci progettare nel Playground o nella dashboard? Parti da [Crea il tuo primo QR code](/docs/help/getting-started/first-qr-code) nella Guida.

```tsx title="components/shaped-code.tsx"
import { QRCode } from "qrdx";

export function ShapedCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      bodyPattern="liquid"
      cornerEyePattern="leaf"
      cornerEyeDotPattern="leaf"
    />
  );
}
```

## Pattern del corpo [#body-patterns]

`bodyPattern` dà forma ai moduli dati. I valori sono {facts.bodyPatterns}; quello predefinito è `circle`.

- Classici: `square`, `small-square`, `horizontal-line`, `vertical-line`, `octagon`
- Arrotondati: `circle`, `circle-large`, `rounded`, `liquid`, `liquid-horizontal`, `liquid-vertical`, `random-dots`
- Decorativi: `classy`, `classy-rounded`, `leaf`, `diamond`, `hexagon`
- Giocosi: `mosaic`, `plus`, `star`, `heart`, `pacman`, `circle-mixed`

`liquid`, `classy` e `classy-rounded` uniscono i moduli vicini in un unico contorno morbido; `liquid-horizontal` e `liquid-vertical` li uniscono solo in righe o colonne. `random-dots` e `mosaic` variano da modulo a modulo, ma per lo stesso valore disegnano sempre lo stesso codice. I pattern di allineamento sono sempre disegnati come quadrati pieni, qualunque sia il pattern, così i decodificatori li trovano.

### Scala dei moduli [#module-scale]

`moduleScale` (da 0.5 a 1, predefinito 1) riduce ogni modulo dati attorno al suo centro per un aspetto più leggero e spaziato. I pattern connessi, invece, ottengono linee più sottili. Ogni pattern smette di ridursi alla dimensione minima che si decodifica ancora nei test del pacchetto (per esempio 0.95 per `circle`, 0.7 per `classy`; i limiti sono esportati come `MODULE_SCALE_FLOOR`), e i pattern di allineamento mantengono la dimensione piena.

```tsx title="components/light-code.tsx"
import { QRCode } from "qrdx";

export function LightCode() {
  return (
    <QRCode
      value="https://example.com"
      bodyPattern="liquid"
      moduleScale={0.8}
    />
  );
}
```

## Cornici degli occhi [#eye-frames]

`cornerEyePattern` dà forma agli occhi agli angoli. I valori sono {facts.eyeShapes}; quello predefinito è `gear`: `square`, `rounded`, `extra-rounded`, `squircle`, `cushion`, `bevel`, `octagon`, `leaf`, `leaf-reverse`, `drop`, `petal`, `shield`, `gear`, `circle`, `diya`, `message` e `pointy`.

`leaf`, `leaf-reverse`, `drop` e `petal` orientano ciascuno dei tre occhi verso il proprio angolo del codice. Gli occhi `circle` possono non essere riconosciuti da alcune app di scansione; il [punteggio di scansione](/docs/features/frames#will-it-scan) li segnala.

## Centri degli occhi [#eye-centers]

`cornerEyeDotPattern` dà forma al punto dentro ogni occhio. I valori sono {facts.eyeCentres}; quello predefinito è `circle`: `square`, `rounded`, `extra-rounded`, `circle`, `squircle`, `octagon`, `hexagon`, `dots`, `leaf`, `leaf-reverse`, `drop`, `drop-reverse`, `plus`, `cross-rounded`, `flower`, `heart`, `message`, `message-reverse`, `diya`, `diya-reverse` e `rounded-triangle`.

## Abbinamenti da evitare e forme ritirate [#pairs-to-avoid-and-retired-shapes]

I corpi `diamond` accanto a occhi `square`, `pacman` accanto a `rounded` e `small-square` accanto a occhi `square` o `rounded` non vengono riconosciuti da vicino. Il Playground non li combina, sono inclusi come `WEAK_BODY_EYES` e `getStylePairRisk(props)` restituisce l'avviso mostrato dal punteggio di scansione.

Un centro `circle` dentro occhi con angoli netti (`square`, `rounded`, `extra-rounded` e la maggior parte degli altri) può non essere riconosciuto da decodificatori rigorosi in render nitidi: sugli schermi, nelle esportazioni PNG e nelle stampe grandi. I corpi pieni (`square`, `liquid`, `classy`, `classy-rounded`) di solito si leggono comunque, e gli occhi `gear`, `circle` e `octagon` non sono interessati. Il punteggio di scansione lo segnala (`style-pair`) e puoi comunque sceglierlo. Gli abbinamenti sono inclusi come `WEAK_SHARP_DOT_EYES` (con `SHARP_DOT_EYE_SAFE_BODIES`), e un centro `rounded` evita il problema.

Gli occhi `curly` e i centri `diamond`, `star` e `banner` sono stati ritirati perché non si scansionano in modo affidabile. I design salvati con queste forme vengono ancora disegnati, ma non sono più proposti né elencati; vedi [Forme ritirate](/docs/styles#retired-shapes).

## Codici circolari [#circle-codes]

`shape="circle"` inserisce il codice in un disco e riempie il resto con moduli decorativi della stessa forma a punto. Il codice vero mantiene attorno a sé un anello chiaro di `margin` moduli (almeno 3), e gli scanner leggono solo il codice al centro. Il disco è più grande del codice, quindi stampalo un po' più grande per la stessa distanza di scansione; il [calcolatore della dimensione di stampa](/tools/print-size) considera l'intero disco.

```tsx title="components/circle-code.tsx"
import { QRCode } from "qrdx";

export function CircleCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      shape="circle"
      bodyPattern="rounded"
    />
  );
}
```

Nei test di decodifica del pacchetto i codici circolari si leggono come quelli quadrati con forme a punto piene (`square`, `rounded`, `classy`, `liquid`).

## Codici a cuore [#heart-codes]

`shape="heart"` funziona come un codice circolare, ma a forma di cuore. Il codice vero si trova al centro del cuore con il suo anello chiaro di almeno 3 moduli, e il resto del cuore si riempie di moduli decorativi. Il codice occupa una parte più piccola di un cuore che di un cerchio, quindi stampa un codice a cuore più grande di uno quadrato per la stessa distanza di scansione. Il punteggio di scansione ne tiene conto: a parità di dimensione, un codice a cuore ottiene un punteggio più basso di uno circolare.

```tsx title="components/heart-code.tsx"
import { QRCode } from "qrdx";

export function HeartCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      shape="heart"
      bodyPattern="rounded"
    />
  );
}
```

Un codice sagomato prende il posto di una cornice nel Playground: sceglierne uno rimuove la cornice, e scegliere una cornice rimuove la sagoma. Ogni cornice disegna una base chiara sotto il codice, che nasconderebbe il contorno. Il motore disegna comunque `shape` insieme a `frame` se passi entrambi. Nei test di decodifica del pacchetto i codici a cuore si leggono con ogni forma a punto piena e con occhi `square`, `rounded` e `gear`.

## Sagome personalizzate [#custom-shapes]

`shape` accetta anche una silhouette: una piccola griglia tracciata da un'immagine tua (al massimo 64 celle per lato). Il codice occupa la parte centrale più spaziosa della sagoma, e il resto della sagoma si riempie di moduli decorativi. Viene conservata solo la griglia, mai l'immagine.

```tsx title="components/silhouette-code.tsx"
import { getQRSilhouetteFit, loadQRSilhouette, QRCode } from "qrdx";

export async function silhouetteFrom(file: File) {
  const shape = await loadQRSilhouette(file); // a PNG, JPEG or SVG, in the browser
  const fit = getQRSilhouetteFit(shape);
  if (!fit.ok) throw new Error(fit.message);
  return shape;
}

export function SilhouetteCode({ shape }: { shape: Awaited<ReturnType<typeof silhouetteFrom>> }) {
  return <QRCode value="https://example.com" size={256} shape={shape} />;
}
```

`loadQRSilhouette` disegna l'immagine su un canvas e usa la sua trasparenza, oppure la sua scurezza se è opaca, quindi funziona anche una forma chiara su sfondo scuro. Su un server, passa pixel RGBA decodificati a `createQRSilhouette`. `getQRSilhouetteFit` rifiuta una sagoma troppo sottile per contenere il codice con la sua zona di rispetto, come una stella sottile, una barra o un anello. Una sagoma rifiutata viene disegnata come codice quadrato.

Nella dashboard una silhouette resta legata al design, come un logo caricato: link condivisi, elementi della community, snippet di codice e chat AI usano invece un codice quadrato.

## Colori per singolo occhio [#per-eye-colors]

`eyeColor` e `dotColor` colorano tutti e tre gli occhi. `eyeColors` li sovrascrive per singolo occhio (`topLeft`, `topRight`, `bottomLeft`), ciascuno con un colore o gradiente `outer` (cornice) e `inner` (punto):

```tsx title="components/eye-colors-code.tsx"
import { QRCode } from "qrdx";

export function EyeColorsCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      eyeColor="#111827"
      eyeColors={{
        topLeft: { outer: "#dc2626", inner: "#1d4ed8" },
        topRight: { outer: "#16a34a" },
      }}
    />
  );
}
```

Mantieni ogni occhio scuro rispetto allo sfondo: i decodificatori trovano il codice grazie ai suoi tre occhi. Il punteggio di scansione verifica il contrasto dei colori di ciascun occhio.
