`QRCode` menerima prop `logo` dan menata gambarnya untuk Anda: modul di belakang logo dikosongkan, dan logo tidak pernah digambar lebih besar daripada yang bisa dipulihkan oleh kode. Halaman ini membahas opsi tata letak, batasan, dan API `imageSettings` mentah yang ada di baliknya.

Mendesain di playground atau dasbor? Lihat [Tambahkan logo](/docs/help/designing/logos) di Bantuan.

## Logo dalam tiga baris [#a-logo-in-three-lines]

```tsx title="components/logo-code.tsx"
import { QRCode } from "qrdx";

export function LogoCode() {
  return (
    <QRCode value="https://example.com" size={256} level="H" logo="/logo.png" />
  );
}
```

`logo` menerima path di aplikasi Anda, URL, atau data URL. Logo digambar dengan lebar seperempat dari lebar kode, modul di belakangnya dikosongkan, dan kode mengandalkan koreksi kesalahan agar bisa dipindai. Gunakan `level="H"` (30% kode boleh rusak) atau minimal `Q` bawaan (25%).

## Ukuran, ruang kosong, dan posisi [#size-clear-space-and-position]

`logoOptions` menata logo dengan satuan yang tidak bergantung pada ukuran render:

| Opsi | Rentang | Bawaan | Fungsi |
| --- | --- | --- | --- |
| `size` | 0.1 sampai 0.3 | 0.25 | Lebar logo sebagai bagian dari lebar kode. Di atas 25%, bahkan level H tidak lagi terbaca dalam uji dekode paket |
| `padding` | 0 sampai 2 | 0 | Ruang kosong di sekeliling logo, dalam modul |
| `x`, `y` | 0 sampai 1 | 0.5 | Posisi titik tengah logo pada kode. Logo selalu tetap berada di dalam kode |
| `shape` | `square`, `rounded`, `circle` | `square` | Memotong bentuk logo |
| `plate` | sebuah warna | tidak ada | Alas warna solid di belakang logo, dengan bentuk yang sama |

```tsx title="components/placed-logo-code.tsx"
import { QRCode } from "qrdx";

export function PlacedLogoCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      level="H"
      logo="/logo.png"
      logoOptions={{ size: 0.2, padding: 1, x: 0.6, y: 0.55 }}
    />
  );
}
```

Jauhkan logo yang dipindahkan dari ketiga mata sudut dan dari kotak kecil di dekat sudut kanan bawah (pola penyelarasan yang dipakai dekoder untuk mengoreksi perspektif). Skor pemindaian akan menggagalkan logo yang menutupi salah satunya.

## Seberapa besar logo boleh dibuat [#how-big-a-logo-can-be]

Logo (beserta ruang kosongnya) merusak setiap codeword yang disentuhnya, dan setiap blok koreksi kesalahan hanya bisa memulihkan sejumlah tertentu. `QRCode` dan `getQRData` menghitung codeword yang rusak blok demi blok, lalu mengecilkan logo sampai blok terburuk memakai paling banyak 60% kapasitas pemulihannya (`LOGO_EC_SAFETY`). Kode kecil menampung lebih sedikit: pada level Q, tautan pendek muat logo sekitar 13% sampai 17% dari lebar, dan level H atau nilai yang lebih pendek memberi ruang lebih banyak.

- `getLogoSizeLimit(props)` mengembalikan `size` terbesar yang muat pada sebuah kode, sehingga slider bisa berhenti di situ.
- `imageSettings` mentah pada `QRCodeSVG`, `QRCodeCanvas`, dan `getQRAsSVG` mendapat batas yang sama: logo yang muat digambar apa adanya, sedangkan yang lebih besar dikecilkan di sekitar titik tengahnya sendiri.
- `autoLevel` menaikkan koreksi kesalahan ke `H` setiap kali area yang dikosongkan menutupi lebih dari 7% kode (`AUTO_LEVEL_LOGO_COVERAGE`). Opsi ini nonaktif secara bawaan, sehingga kode yang sudah ada tetap pada levelnya.
- Skor pemindaian menghitung codeword yang sama dan memberi peringatan sebelum batas membuat logo Anda dikecilkan.

## Bentuk, alas, dan latar belakang [#shape-plate-and-background]

```tsx title="components/round-logo-code.tsx"
import { QRCode } from "qrdx";

export function RoundLogoCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      level="H"
      logo="/logo.png"
      logoOptions={{ size: 0.22, shape: "circle", plate: "#ffffff" }}
    />
  );
}
```

Pemotongan bentuk memakai clip path SVG. PDF cetak dan EPS dipotong dengan kontur yang sama, sehingga semua unduhan tampak sama. EPS tidak mendukung transparansi, jadi bagian logo yang transparan dicetak putih di sana.

Jika logo berada di dalam kotak solid (umum pada JPEG), hapuslah kotak itu: `removeLogoBackground(src)` mengembalikan PNG yang sudah dibersihkan sebagai data URL di browser, dan `removeLogoBackdrop(pixels)` melakukan hal yang sama pada piksel RGBA di mana saja. Bila keempat sudut memiliki satu warna yang sama, warna itu dihapus dari tepi ke dalam, sehingga warna yang sama di dalam logo (misalnya huruf putih) tetap ada. Keduanya mengembalikan `null` jika gambar tidak memiliki latar belakang solid.

## Pengaturan gambar mentah [#raw-image-settings]

`QRCodeSVG` dan `QRCodeCanvas` menerima logo sebagai `imageSettings`, dalam piksel yang sama dengan `size`. Gunakan ini bila Anda menata logo sendiri atau memindahkan kode dari renderer lain.

```tsx title="components/image-settings-code.tsx"
import { QRCodeSVG } from "qrdx";

export function ImageSettingsCode() {
  return (
    <QRCodeSVG
      value="https://example.com"
      size={512}
      level="H"
      autoLevel
      imageSettings={{
        src: "/logo.png",
        width: 110,
        height: 110,
        excavate: true,
        padding: 8,
      }}
    />
  );
}
```

- `width` dan `height` dalam piksel. Hilangkan `x` dan `y` agar logo berada di tengah.
- `excavate` mengosongkan modul di belakang logo. Biarkan aktif kecuali logo bersifat tembus pandang dan Anda ingin modul terlihat menembusnya.
- `padding` mengosongkan modul tambahan di sekeliling logo, dalam piksel yang sama dengan `width` dan `height`.
- `shape` dan `plate` bekerja seperti pada `logoOptions`.
- Logo mempertahankan ukuran pikselnya berapa pun `margin`.

`getQRData(props)` mengubah `logo` dan `logoOptions` menjadi `imageSettings` ini untuk kode berukuran 1024 px, dan begitulah cara `QRCode` serta helper unduhan berbagi satu tata letak.

## Unduhan dan format [#downloads-and-formats]

- Logo PNG dan JPEG tertanam di setiap ekspor. Logo SVG dan WebP digambar dalam ekspor di browser dan tidak disertakan pada PNG yang dibuat di server.
- Untuk unduhan, data URL adalah yang paling aman. Gambar jarak jauh memerlukan header CORS sebelum browser boleh menyalinnya ke dalam file; tanpa header itu, file tidak akan memiliki logo.
- PNG dengan transparansi memberi hasil paling bersih pada kode berwarna. Untuk JPEG, tambahkan `plate` dengan warna latar belakang atau hapus kotaknya terlebih dahulu.
- Uji kode berlogo di dua atau tiga ponsel sebelum mencetaknya, atau periksa dengan [skor pemindaian](/docs/features/frames#will-it-scan).
