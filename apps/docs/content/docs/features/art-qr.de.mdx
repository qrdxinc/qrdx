Die Prop `art` blendet ein Logo oder Foto in die Module eines Codes ein, als Vektorformen und ohne KI: Logo QR färbt die Module innerhalb der Form deines Logos um, und Image QR zeigt dein Foto durch jedes Modul. Beides zeichnet die Bibliothek selbst, daher funktioniert es offline, auf dem Server und in Node, und das Ergebnis ist immer ein echter QR-Code. Diese Seite behandelt die Prop, wie das Bild abgetastet wird und wie die Scanbarkeit erhalten bleibt.

Du gestaltest lieber im Playground oder im Dashboard? Dann lies [Logo oder Foto in den Code einblenden](/docs/help/designing/art) in der Hilfe.

QRdx bietet drei Wege, einen Code in ein Kunstwerk zu verwandeln:

| | So funktioniert es | Ausgabe | Kosten |
| --- | --- | --- | --- |
| **Logo QR** (`mode: "logo"`) | Module innerhalb der Form deines Logos übernehmen dessen Farben; der Rest verblasst zu einem helleren Ton | Vektor (SVG, PDF, EPS, PNG) | Kostenlos |
| **Image QR** (`mode: "halftone"`) | Jedes Modul zeigt dein Foto rund um ein mittleres Quadrat, das den echten Wert behält | Vektor (SVG, PDF, EPS, PNG) | Kostenlos |
| **KI-Art** | Ein KI-Bildmodell zeichnet den Code als Szene neu, und jedes Bild wird auf Scanbarkeit geprüft | Bild mit 1024 px, Druckkopie mit 2048 px | KI-Art-Bilder aus dem Tarif |

## Einen Art-Code zeichnen [#draw-an-art-code]

Übergib die Prop `art` mit einem Modus, einem abgetasteten Bild und einer optionalen Intensität:

```tsx title="components/logo-art-code.tsx"
import { loadQRArtImage, type QRArtImage, QRCode } from "qrdx";

// Browser: sample an uploaded file, a data URL or an <img>
export async function sampleLogo(file: File): Promise<QRArtImage> {
  return await loadQRArtImage(file, { mode: "logo" });
}

export function LogoArtCode({ image }: { image: QRArtImage }) {
  return (
    <QRCode
      value="https://example.com"
      size={512}
      level="H"
      art={{ mode: "logo", image, intensity: 0.7 }}
    />
  );
}
```

Auf dem Server oder in Node dekodierst du das Bild selbst und übergibst die RGBA-Pixel an `createQRArtImage`:

```ts title="lib/sample-photo.ts"
import { createQRArtImage } from "qrdx";
import sharp from "sharp";

const { data, info } = await sharp("photo.jpg")
  .ensureAlpha()
  .raw()
  .toBuffer({ resolveWithObject: true });

export const image = createQRArtImage(
  { data, width: info.width, height: info.height },
  { maxSize: 96, square: true }
);
// art={{ mode: "halftone", image, intensity: 0.8 }}
```

`art.image` ist reines JSON (`{ width, height, data }` mit Base64-RGBA). So kannst du es mit einem gespeicherten Design ablegen und denselben Code überall synchron rendern, ohne das Bild erneut abzurufen.

| Option | Werte | Hinweise |
| --- | --- | --- |
| `mode` | `logo`, `halftone` | `halftone` heißt im Editor Image QR |
| `image` | von `loadQRArtImage` oder `createQRArtImage` | Höchstens 192 mal 192 Samples. `loadQRArtImage` tastet standardmäßig 160 in der Breite ab |
| `intensity` | `0` bis `1` | Standard `0.6`; bei `0` sieht der Code wie ein einfacher Code aus |
| `variant` | `blend`, `badge` (logo); `color`, `mono` (halftone) | Der Look innerhalb des Modus. `badge` setzt das nachgezeichnete Logo auf eine abgerundete Platte in der Mitte eines getönten Codes; `mono` ist ein Schwarz-Weiß-Halbton. Der erste Wert ist jeweils der Standard des Modus |
| `matchEyes` | `true`, `false` | Nur im Logo-Modus: färbt die Eckaugen nach dem Logo (Standard `true`). Einzelne `eyeColors` haben weiterhin Vorrang |

Art ersetzt das Modulmuster; die Eckaugen behalten ihr `cornerEyePattern`, `cornerEyeDotPattern` und ihre Farben. Art verwendet die erste Farbe eines Verlaufs bei `fgColor` oder `bgColor` und braucht einen dunklen Vordergrund auf hellem Hintergrund; bei invertierten Farben fällt sie auf einen einfachen Look zurück. Nutze `level="H"`, das der Art den meisten Spielraum gibt.

## So bleibt der Code scanbar [#how-scannability-is-kept]

- **Logo QR**: Dunkle Module innerhalb des Logos werden umgefärbt, aber nur so weit abgedunkelt, dass ein Scanner sie noch als dunkel liest; helle Module innerhalb des Logos erhalten einen blassen Farbton, der über der Hellschwelle bleibt. Dunkle Module außerhalb des Logos verblassen zu Grau, nie heller als die Dunkelschwelle.
- **Logo-QR-Badge**: Jedes Modul unter der Platte kann ein Codewort verderben. Die Platte ist so bemessen, dass kein Fehlerkorrekturblock mehr als 60 % der Codewörter verliert, die er reparieren kann. Der Rest bleibt für die Kamera. Die Intensität vergrößert die Platte bis zu dieser Größe. Kleine Codes bekommen ein kleineres Logo, und die kleinsten (Version 1, Version 2 bei L oder M, Version 3 bei L) zeichnen keine Platte.
- **Image QR**: Jedes Modul wird in ein 3-mal-3-Raster geteilt. Die äußeren Zellen zeigen das Foto, dunkler oder heller gedrückt passend zum Wert des Moduls, und die Mitte behält exakt die Vorder- oder Hintergrundfarbe, denn dort tasten Scanner ab.
- Finder-, Timing-, Alignment-, Format- und Versionsmodule werden immer vollflächig gezeichnet.

Prüfe jedes Design vor dem Druck mit `getScanScore(props)` und teste es mit einer echten Handykamera.

## Art-Codes exportieren [#export-art-codes]

Art-Codes sind Vektorformen, daher bleiben sie bei jedem Export scharf:

```ts title="lib/export-art.ts"
import { downloadQRCode, getQRAsEPS, getQRAsPrintPDF } from "qrdx";

await downloadQRCode(props, { format: "svg", size: { width: 1024, height: 1024 } });
const pdf = await getQRAsPrintPDF(props, { size: 40, unit: "mm", colorMode: "cmyk" });
const eps = await getQRAsEPS(props, { sizeMm: 40, bleedMm: 3, colorMode: "cmyk" });
```

`getQRAsEPS` schreibt eine EPSF-3.0-Datei mit einer `%%BoundingBox` in Punkten, und jedes Modul, Auge und jeder Rahmen wird als PostScript-Pfad ausgegeben. Wie das Druck-PDF behält sie lineare und radiale Verläufe (als PostScript-Level-3-Shadings) und hat keine Transparenz. PNG- und JPEG-Logos werden als Bilder eingebettet; andere Logoformate werden im Browser konvertiert und auf dem Server weggelassen. Rahmentext verwendet Helvetica, daher werden Zeichen außerhalb von Latin-1 als `?` gedruckt. `svgToEPS(svg, { width })` konvertiert jedes SVG, das diese Bibliothek rendert. Auch die CLI schreibt EPS: `qrdx generate "https://example.com" -o qr.eps`.

<IfAvailable feature="aiArt" id="ai-art" title="KI-Art">

[KI-QR-Art](/ai/art) verwandelt deinen Code mit {facts.artModel} über das Vercel AI Gateway in eine Szene. Du erhältst {facts.aiArtStyles} Stilvorlagen, die du nach Kategorie durchsuchen oder per Suche finden kannst, jeweils mit einer Vorschau, die die Scanprüfung bestanden hat, Dingen, die du vermeiden solltest, einem Regler **QR-Sichtbarkeit** (wie stark das Modell den Code bevorzugt), einem Regler **Kreativität** (wie frei es deinen Prompt auslegt), 1 bis 4 Variationen pro Durchlauf und einem optionalen Referenzbild, etwa einem Logo oder einer Palette, dessen Farben und Formen übernommen werden.

Jedes Bild wird auf dem Server geprüft, bevor du es siehst. QRdx sendet dem Modell einen schlichten Schwarz-Weiß-Code (Fehlerkorrektur H, quadratische Module, eine breite Ruhezone) und bittet es, das Modulraster, die Finder-Augen und die Ruhezone beizubehalten. Danach dekodiert es das Bild des Modells mit jsQR, unverändert und durch ein Handykamera-Modell. Schlägt das fehl, findet es das Modulraster dort, wo das Modell es gezeichnet hat, und verstärkt den Code im Bild des Modells so wenig wie möglich: zuerst die Finder-Augen und die Ruhezone, dann die Module, wobei die Stärke Schritt für Schritt erhöht wird, bis das Bild scannt, auch wenn der Code in der Kameraansicht kleiner ist. Die QR-Sichtbarkeit legt fest, wie weit es gehen darf. Nur wenn das nicht reicht, zeichnet es das Bild als Image-QR-Code neu. Ein Bild, das trotzdem nicht zu deinem exakten Inhalt dekodiert, wird nicht ausgeliefert. Dein Browser bewertet dann die Variationen und wählt die beste aus; lade sie mit 1024 px oder als Druckkopie mit 2048 px herunter (neu berechnet und erneut geprüft).

Jedes gelieferte Bild verbraucht eines der monatlichen KI-Art-Bilder des Tarifs: Konten im Tarif Kostenlos erhalten 3 im Monat, Pro 30 und Business 150, geteilt von allen im Workspace. Bilder, die fehlschlagen oder die Scanprüfung nicht bestehen, verbrauchen keins, und die Druckkopie ist kostenlos. KI-Art ist ein Rasterbild und sein Inhalt steht fest. Für einen bearbeitbaren Link setzt du daher den Kurzlink eines [dynamischen QR-Codes](/docs/dynamic-qr-codes) hinein. Entwickler können es über die [AI-Art-API](/docs/developers/ai-art-api) erzeugen.
