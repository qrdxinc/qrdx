Prop `art` memadukan logo atau foto ke dalam modul kode, sebagai bentuk vektor dan tanpa AI: Logo QR mewarnai ulang modul di dalam bentuk logo Anda, dan Image QR menampilkan foto Anda melalui setiap modul. Keduanya digambar oleh pustaka itu sendiri, sehingga berfungsi secara offline, di server, dan di Node, dan hasilnya selalu berupa kode QR yang sebenarnya. Halaman ini membahas prop tersebut, cara gambar diambil sampelnya, dan cara menjaga agar kode tetap dapat dipindai.

Mendesain di Playground atau dasbor? Lihat [Padukan logo atau foto ke dalam kode](/docs/help/designing/art) di Bantuan.

QRdx memiliki tiga cara untuk mengubah kode menjadi karya seni:

| | Cara kerja | Keluaran | Biaya |
| --- | --- | --- | --- |
| **Logo QR** (`mode: "logo"`) | Modul di dalam bentuk logo Anda mengambil warnanya; sisanya memudar ke warna yang lebih terang | Vektor (SVG, PDF, EPS, PNG) | Gratis |
| **Image QR** (`mode: "halftone"`) | Setiap modul menampilkan foto Anda di sekitar kotak tengah yang menyimpan nilai sebenarnya | Vektor (SVG, PDF, EPS, PNG) | Gratis |
| **Seni AI** | Model gambar AI melukis ulang kode sebagai sebuah adegan, dan setiap gambar diverifikasi agar dapat dipindai | Gambar 1024 px, salinan cetak 2048 px | Gambar seni AI sesuai paket |

## Gambar kode seni [#draw-an-art-code]

Berikan prop `art` dengan mode, gambar yang sudah diambil sampelnya, dan intensitas opsional:

```tsx title="components/logo-art-code.tsx"
import { loadQRArtImage, type QRArtImage, QRCode } from "qrdx";

// Browser: sample an uploaded file, a data URL or an <img>
export async function sampleLogo(file: File): Promise<QRArtImage> {
  return await loadQRArtImage(file, { mode: "logo" });
}

export function LogoArtCode({ image }: { image: QRArtImage }) {
  return (
    <QRCode
      value="https://example.com"
      size={512}
      level="H"
      art={{ mode: "logo", image, intensity: 0.7 }}
    />
  );
}
```

Di server atau di Node, dekode gambar sendiri lalu berikan piksel RGBA ke `createQRArtImage`:

```ts title="lib/sample-photo.ts"
import { createQRArtImage } from "qrdx";
import sharp from "sharp";

const { data, info } = await sharp("photo.jpg")
  .ensureAlpha()
  .raw()
  .toBuffer({ resolveWithObject: true });

export const image = createQRArtImage(
  { data, width: info.width, height: info.height },
  { maxSize: 96, square: true }
);
// art={{ mode: "halftone", image, intensity: 0.8 }}
```

`art.image` adalah JSON biasa (`{ width, height, data }` dengan RGBA base64), sehingga Anda dapat menyimpannya bersama desain yang tersimpan dan merender kode yang sama di mana saja, secara sinkron, tanpa mengambil gambar lagi.

| Opsi | Nilai | Catatan |
| --- | --- | --- |
| `mode` | `logo`, `halftone` | `halftone` adalah Image QR di editor |
| `image` | dari `loadQRArtImage` atau `createQRArtImage` | Maksimal 192 kali 192 sampel. `loadQRArtImage` mengambil 160 sampel secara melebar secara default |
| `intensity` | `0` sampai `1` | Default `0.6`; `0` terlihat seperti kode biasa |
| `variant` | `blend`, `badge` (logo); `color`, `mono` (halftone) | Tampilan dalam mode tersebut. `badge` menempatkan logo hasil jejak pada pelat membulat di tengah kode yang diberi rona; `mono` adalah halftone hitam putih. Nilai pertama adalah default setiap mode |
| `matchEyes` | `true`, `false` | Hanya mode logo: warnai mata sudut dari logo (default `true`). `eyeColors` per mata tetap diutamakan |

Seni menggantikan pola badan; mata sudut tetap memakai `cornerEyePattern`, `cornerEyeDotPattern`, dan warnanya. Seni memakai warna pertama dari gradien `fgColor` atau `bgColor`, dan memerlukan latar depan gelap pada latar belakang terang; dengan warna terbalik, tampilannya kembali ke gaya biasa. Gunakan `level="H"`, yang memberi ruang paling besar bagi seni.

## Cara menjaga agar tetap dapat dipindai [#how-scannability-is-kept]

- **Logo QR**: modul gelap di dalam logo diwarnai ulang, tetapi hanya digelapkan hingga luminans yang masih dibaca pemindai sebagai gelap; modul terang di dalam logo mendapat rona pucat yang tetap di atas ambang terang. Modul gelap di luar logo memudar menjadi abu-abu, tidak pernah lebih terang dari ambang gelap.
- **Badge Logo QR**: setiap modul di bawah pelat dapat merusak satu codeword. Ukuran pelat ditentukan agar tidak ada blok koreksi kesalahan yang kehilangan lebih dari 60% codeword yang dapat diperbaikinya, sehingga sisanya tersedia untuk kamera. Intensitas memperbesar pelat hingga ukuran tersebut. Kode kecil mendapat logo yang lebih kecil, dan yang terkecil (versi 1, versi 2 pada L atau M, versi 3 pada L) tidak menggambar pelat.
- **Image QR**: setiap modul dibagi menjadi kisi 3 kali 3. Sel luar menampilkan foto, didorong lebih gelap atau lebih terang agar sesuai dengan nilai modul, dan bagian tengah mempertahankan warna latar depan atau latar belakang yang tepat, yaitu tempat pemindai mengambil sampel.
- Modul pencari, pewaktuan, penyelarasan, format, dan versi selalu digambar solid.

Periksa desain apa pun dengan `getScanScore(props)` sebelum mencetak, dan uji dengan kamera ponsel sungguhan.

## Ekspor kode seni [#export-art-codes]

Kode seni berupa bentuk vektor, jadi setiap ekspor tetap tajam:

```ts title="lib/export-art.ts"
import { downloadQRCode, getQRAsEPS, getQRAsPrintPDF } from "qrdx";

await downloadQRCode(props, { format: "svg", size: { width: 1024, height: 1024 } });
const pdf = await getQRAsPrintPDF(props, { size: 40, unit: "mm", colorMode: "cmyk" });
const eps = await getQRAsEPS(props, { sizeMm: 40, bleedMm: 3, colorMode: "cmyk" });
```

`getQRAsEPS` menulis file EPSF-3.0 dengan `%%BoundingBox` dalam poin dan setiap modul, mata, dan bingkai sebagai jalur PostScript. Seperti PDF cetak, file ini mempertahankan gradien linear dan radial (sebagai shading PostScript Level 3) dan tidak memiliki transparansi. Logo PNG dan JPEG disematkan sebagai gambar; format logo lain dikonversi di browser dan dihilangkan di server. Teks bingkai memakai Helvetica, sehingga karakter di luar Latin-1 tercetak sebagai `?`. `svgToEPS(svg, { width })` mengonversi SVG apa pun yang dirender pustaka ini. CLI juga menulis EPS: `qrdx generate "https://example.com" -o qr.eps`.

<IfAvailable feature="aiArt" id="ai-art" title="Seni AI">

[Seni QR AI](/ai/art) mengubah kode Anda menjadi sebuah adegan dengan {facts.artModel}, melalui Vercel AI Gateway. Anda mendapatkan {facts.aiArtStyles} preset gaya untuk dijelajahi per kategori atau dicari, masing-masing dengan pratinjau yang lolos pemeriksaan pemindaian, hal yang dihindari, penggeser **Visibilitas QR** (seberapa kuat model mengutamakan kode), penggeser **kreativitas** (seberapa bebas model membaca prompt Anda), 1 sampai 4 variasi per proses, dan gambar referensi opsional, seperti logo atau palet, yang warna dan bentuknya terbawa.

Setiap gambar diperiksa di server sebelum Anda melihatnya. QRdx mengirim kode hitam putih polos ke model (koreksi kesalahan H, modul persegi, zona tenang yang lebar) dan memintanya mempertahankan kisi modul, mata pencari, dan zona tenang. Kemudian QRdx mendekode gambar model dengan jsQR, apa adanya dan melalui model kamera ponsel. Jika gagal, QRdx menemukan kisi modul di tempat model menggambarnya dan memperkuat kode pada gambar milik model itu sendiri seminimal mungkin: pertama mata pencari dan zona tenang, lalu modul, menaikkan kekuatan langkah demi langkah hingga gambar dapat dipindai, juga saat kode tampak lebih kecil dalam pandangan kamera. Visibilitas QR menentukan seberapa jauh hal itu boleh dilakukan. Hanya jika itu tidak cukup, QRdx menggambar ulang gambar sebagai kode Image QR. Gambar yang tetap tidak terdekode menjadi konten Anda yang tepat tidak akan dikirim. Browser Anda kemudian menilai variasi dan memilih yang terbaik; unduh pada 1024 px atau sebagai salinan cetak 2048 px (diambil sampel ulang dan diperiksa lagi).

Setiap gambar yang dikirim memakai satu dari gambar seni AI bulanan paket: akun Gratis mendapat 3 per bulan, Pro 30, dan Business 150 yang dibagi oleh semua orang di ruang kerja. Gambar yang gagal atau tidak lolos pemeriksaan pemindaian tidak memakai kuota, dan salinan cetak gratis. Seni AI adalah gambar raster dan kontennya tetap, jadi untuk tautan yang dapat diedit, letakkan tautan pendek [kode dinamis](/docs/dynamic-qr-codes) di dalamnya. Pengembang dapat membuatnya dari [AI art API](/docs/developers/ai-art-api).
