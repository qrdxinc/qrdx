`QRCode` hat eine `logo`-Prop und legt das Bild für dich aus: Es räumt die Module hinter dem Logo frei und zeichnet nie ein Logo, das größer ist, als der Code reparieren kann. Diese Seite behandelt die Layout-Optionen, die Grenzen und die rohe `imageSettings`-API darunter.

Du gestaltest lieber im Playground oder im Dashboard? Dann lies [Logo hinzufügen](/docs/help/designing/logos) in der Hilfe.

## Ein Logo in drei Zeilen [#a-logo-in-three-lines]

```tsx title="components/logo-code.tsx"
import { QRCode } from "qrdx";

export function LogoCode() {
  return (
    <QRCode value="https://example.com" size={256} level="H" logo="/logo.png" />
  );
}
```

`logo` akzeptiert einen Pfad in deiner App, eine URL oder eine Data-URL. Das Logo wird mit einem Viertel der Breite des Codes gezeichnet, die Module dahinter werden freigeräumt, und der Code verlässt sich beim Scannen auf die Fehlerkorrektur. Nutze `level="H"` (30 % des Codes dürfen beschädigt sein) oder mindestens den Standardwert `Q` (25 %).

## Größe, Freiraum und Position [#size-clear-space-and-position]

`logoOptions` legt das Logo in Einheiten aus, die nicht von der Render-Größe abhängen:

| Option | Bereich | Standard | Was sie bewirkt |
| --- | --- | --- | --- |
| `size` | 0.1 bis 0.3 | 0.25 | Die Breite des Logos als Anteil an der Breite des Codes. Über 25 % wird selbst Level H in den Decode-Tests des Pakets nicht mehr gelesen |
| `padding` | 0 bis 2 | 0 | Freiraum um das Logo, in Modulen |
| `x`, `y` | 0 bis 1 | 0.5 | Wo die Mitte des Logos im Code liegt. Das Logo bleibt immer innerhalb des Codes |
| `shape` | `square`, `rounded`, `circle` | `square` | Schneidet das Logo zu |
| `plate` | eine Farbe | keine | Eine einfarbige Unterlage hinter dem Logo, in derselben Form |

```tsx title="components/placed-logo-code.tsx"
import { QRCode } from "qrdx";

export function PlacedLogoCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      level="H"
      logo="/logo.png"
      logoOptions={{ size: 0.2, padding: 1, x: 0.6, y: 0.55 }}
    />
  );
}
```

Halte ein verschobenes Logo von den drei Eckaugen fern und von dem kleinen Quadrat nahe der unteren rechten Ecke (dem Alignment-Muster, mit dem Decoder perspektivische Verzerrung korrigieren). Der Scan-Score lässt ein Logo durchfallen, das eines davon verdeckt.

## Wie groß ein Logo sein darf [#how-big-a-logo-can-be]

Ein Logo (mit seinem Freiraum) zerstört jedes Codewort, das es berührt, und jeder Fehlerkorrektur-Block kann nur eine bestimmte Anzahl reparieren. `QRCode` und `getQRData` zählen die zerstörten Codewörter Block für Block und verkleinern das Logo, bis der schlechteste Block höchstens 60 % seiner Reparaturkapazität nutzt (`LOGO_EC_SAFETY`). Kleine Codes fassen weniger: Bei Level Q passt zu einem kurzen Link ein Logo von etwa 13 % bis 17 % der Breite, und Level H oder ein kürzerer Wert schafft mehr Platz.

- `getLogoSizeLimit(props)` liefert die größte `size`, die in einen Code passt, damit ein Slider dort anhalten kann.
- Rohe `imageSettings` bei `QRCodeSVG`, `QRCodeCanvas` und `getQRAsSVG` bekommen dieselbe Obergrenze: Ein Logo, das passt, wird wie angegeben gezeichnet, ein größeres wird um seine eigene Mitte herum verkleinert.
- `autoLevel` hebt die Fehlerkorrektur auf `H` an, sobald die freigeräumte Fläche mehr als 7 % des Codes bedeckt (`AUTO_LEVEL_LOGO_COVERAGE`). Standardmäßig ist es aus, damit bestehende Codes ihr Level behalten.
- Der Scan-Score zählt dieselben Codewörter und warnt, bevor die Obergrenze dein Logo verkleinern würde.

## Form, Unterlage und Hintergrund [#shape-plate-and-background]

```tsx title="components/round-logo-code.tsx"
import { QRCode } from "qrdx";

export function RoundLogoCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      level="H"
      logo="/logo.png"
      logoOptions={{ size: 0.22, shape: "circle", plate: "#ffffff" }}
    />
  );
}
```

Der Zuschnitt ist ein SVG-Clip-Path. Das Druck-PDF und EPS beschneiden an derselben Kontur, damit jeder Download gleich aussieht. EPS kennt keine Transparenz, deshalb werden transparente Bereiche eines Logos dort weiß gedruckt.

Wenn ein Logo auf einem einfarbigen Kasten sitzt (häufig bei JPEGs), entferne ihn: `removeLogoBackground(src)` gibt im Browser das bereinigte PNG als Data-URL zurück, und `removeLogoBackdrop(pixels)` macht dasselbe überall mit RGBA-Pixeln. Wenn die vier Ecken dieselbe Farbe haben, wird diese Farbe von den Rändern nach innen entfernt, sodass dieselbe Farbe im Inneren des Motivs (zum Beispiel weiße Buchstaben) erhalten bleibt. Beide geben `null` zurück, wenn das Bild keinen einfarbigen Hintergrund hat.

## Rohe Bildeinstellungen [#raw-image-settings]

`QRCodeSVG` und `QRCodeCanvas` nehmen das Logo als `imageSettings` entgegen, in denselben Pixeln wie `size`. Nutze das, wenn du das Logo selbst auslegst oder Code aus einem anderen Renderer übernimmst.

```tsx title="components/image-settings-code.tsx"
import { QRCodeSVG } from "qrdx";

export function ImageSettingsCode() {
  return (
    <QRCodeSVG
      value="https://example.com"
      size={512}
      level="H"
      autoLevel
      imageSettings={{
        src: "/logo.png",
        width: 110,
        height: 110,
        excavate: true,
        padding: 8,
      }}
    />
  );
}
```

- `width` und `height` sind in Pixeln angegeben. Lass `x` und `y` weg, um das Logo zu zentrieren.
- `excavate` räumt die Module hinter dem Logo frei. Lass es eingeschaltet, außer das Logo ist durchsichtig und die Module sollen hindurchscheinen.
- `padding` räumt zusätzliche Module um das Logo frei, in denselben Pixeln wie `width` und `height`.
- `shape` und `plate` funktionieren wie in `logoOptions`.
- Das Logo behält seine Pixelgröße, egal welchen `margin` du setzt.

`getQRData(props)` wandelt `logo` und `logoOptions` in diese `imageSettings` für einen Code mit 1024 px um. So teilen sich `QRCode` und die Download-Helfer ein Layout.

## Downloads und Formate [#downloads-and-formats]

- PNG- und JPEG-Logos werden in jeden Export eingebettet. SVG- und WebP-Logos werden in den Exporten des Browsers gezeichnet und in einem auf einem Server erzeugten PNG weggelassen.
- Für Downloads ist eine Data-URL am sichersten. Ein entferntes Bild braucht CORS-Header, bevor der Browser es in die Datei kopieren darf; ohne sie hat die Datei kein Logo.
- Ein PNG mit Transparenz liefert auf einem farbigen Code das sauberste Ergebnis. Füge bei einem JPEG eine `plate` in der Hintergrundfarbe hinzu oder entferne zuerst den Kasten.
- Teste einen Code mit Logo auf zwei oder drei Handys, bevor du ihn druckst, oder prüfe ihn mit dem [Scan-Score](/docs/features/frames#will-it-scan).
