Prop `frame` menggambar bingkai "Scan me" di sekitar kode, `getScanScore` memberi tahu Anda apakah sebuah desain dapat dipindai, dan fungsi cetak menulis file vektor dengan ukuran fisik lengkap dengan bleed dan crop mark. Halaman ini membahas ketiganya, dengan urutan tersebut.

Mendesain di Playground atau dasbor? Lihat [Tambahkan bingkai dan ajakan bertindak](/docs/help/designing/frames), [Periksa desain dengan skor pemindaian](/docs/help/designing/scan-score), dan [Unduh dan cetak kode QR](/docs/help/getting-started/download-and-print) di Bantuan.

## Bingkai ajakan bertindak [#call-to-action-frames]

Setiap bingkai yang digambar QRdx adalah spesifikasi bingkai: deskripsi JSON singkat tentang bentuk, label, dan warna. Satu mesin menggambar setiap spesifikasi, sehingga bingkai tampil sama dalam SVG, PNG, PDF, dan EPS. Ada {facts.frames} bingkai: {facts.frameStyles} bingkai bawaan dan {facts.officialFrames} [bingkai resmi](#official-frames). Anda juga dapat menulis sendiri atau memilih salah satu dari [komunitas](/community/frames).

`frame` berfungsi pada `QRCode`, `QRCodeSVG`, `QRCodeCanvas`, `getQRAsSVG`, `getQRData`, dan semua helper unduhan.

```tsx title="components/menu-frame-code.tsx"
import { QRCode } from "qrdx";

export function MenuFrameCode() {
  return (
    <QRCode
      value="https://example.com/menu"
      size={256}
      frame={{
        style: "banner-bottom",
        text: "Scan for the menu",
        color: "#1e3a8a",
      }}
    />
  );
}
```

Bingkai ditambahkan di sekeliling kode: hasil keluaran menjadi lebih besar, dan modul serta quiet zone tidak pernah tertutup, sehingga kemudahan pemindaian tidak berubah. Celah terang dengan warna latar kode memisahkan kode dari bingkai.

### Bingkai bawaan [#built-in-frames]

Bingkai bawaan dinamai berdasarkan `style`-nya. Opsi-opsi tersebut mengisi label dan warna pada spesifikasinya:

| Opsi | Default | Catatan |
| --- | --- | --- |
| `style` | tidak ada | Salah satu dari {facts.frameStyles} gaya bawaan di bawah, `none`, atau `custom` dengan `spec` |
| `text` | `"Scan me"` | Hingga 24 karakter. Berikan `""` untuk menyembunyikan label |
| `color` | warna milik spesifikasinya: hitam untuk semua bingkai bawaan kecuali `gradient-border`, yang dimulai dengan warna ungu | Warna bingkai |
| `textColor` | putih pada bingkai, `color` pada area terang | Warna label |
| `secondaryText` | tidak ada | Label kedua, hingga 24 karakter: pita bawah `banner-top-bottom`, busur bawah `circle`, footer `menu-card` |
| `secondaryColor` | warna aksen spesifikasi, merah muda | Warna akhir `gradient-border` |
| `fontScale` | `1` | Ukuran label dari 0,5 hingga 1,5; label tetap mengecil agar muat |

Bingkai bawaan, berdasarkan `style`:

- Banner dan border: `banner-bottom`, `banner-top`, `banner-top-bottom`, `border`, `rounded-border`, `gradient-border`, `focus` (siku di sudut)
- Gelembung: `speech-bubble`, `speech-bubble-top`, `chat-bubble`
- Lencana: `circle` (teks melingkar di sekitar cincin), `badge` (pita), `sticker` (die-cut dengan bayangan)
- Objek: `polaroid`, `phone`, `ticket`, `tag` (tag gantung dengan lubang), `envelope`, `menu-card`

Setiap nama ini mewakili sebuah spesifikasi di mesin, dan namanya tetap berlaku selamanya. Desain tersimpan, tautan Image API, flag CLI, dan kode yang menggunakannya akan terus menggambar bingkai yang sama. Bingkai yang menghilangkan baris labelnya saat tidak ada label, seperti border, tetap melakukannya. Lihat semuanya, didekode di browser Anda, di [Bentuk, mata, dan bingkai](/docs/styles#frames).

`BUILT_IN_FRAMES` mencantumkannya beserta nama dan spesifikasinya (`BUILT_IN_FRAME_SPECS` memuat spesifikasi berdasarkan gaya). `frameSpecOf` mengembalikan spesifikasi yang digambar oleh bingkai apa pun, dan `getFrameColors` mengembalikan warna yang dipakainya:

```ts title="lib/frames.ts"
import { BUILT_IN_FRAMES, frameSpecOf, getFrameColors, getFrameDimensions } from "qrdx";

BUILT_IN_FRAMES.map((frame) => frame.name); // ["Banner", "Top banner", "Two banners", …]

// A built-in style's spec, or a custom frame's own
const ticket = frameSpecOf({ style: "ticket" });

// The frame's options, else its spec's defaults
getFrameColors({ style: "border", color: "#1e3a8a" });
// { frame: "#1e3a8a", text: "#1e3a8a", accent: "#1e3a8a" }

// The output size: a 400 px code in a bottom banner
getFrameDimensions(400, { style: "banner-bottom" }); // { width: 496, height: 568 }
```

Untuk mengubah lebih dari sekadar label dan warna, mulailah bingkai kustom dari spesifikasi bawaan: `{ style: "custom", spec: frameSpecOf({ style: "ticket" }) }` menggambar tiket yang sama, dan Anda dapat mengedit bentuknya.

Setiap bingkai terdiri dari bentuk dan teks biasa dengan warna opak, sehingga ekspor SVG, PNG, PDF, dan EPS sama persis. Border gradien digambar sebagai langkah warna solid yang halus, dan huruf melengkung pada bingkai circle adalah teks yang diputar di semua format. Label menggunakan system font stack, jadi tidak ada yang diunduh.

`FRAME_STYLES`, `frameSchema` (zod), dan tipe `QRFrame` serta `FrameStyle` juga diekspor dari `qrdx/types` untuk validasi sisi server. CLI menggambar bingkai yang sama dengan `--frame`, `--frame-text`, `--frame-color`, dan `--frame-text-color`; lihat [CLI](/docs/developers/cli).

### Spesifikasi bingkai [#frame-specs]

Spesifikasi bingkai adalah JSON dengan `kind: "qrdx.frame"`, `version: 1`, ukuran `artboard`, kotak `qr` tempat kode berada, `colors` default, `shapes` yang dilukis di belakang kode, dan `labels`. Bentuknya berupa rect (dengan lubang opsional), lingkaran dan cincin, elips, poligon, path, garis, dan ikon bawaan. Bentuk diisi dengan token tema (`frame`, `text`, `accent`, `background`), warna hex, campuran dua warna, atau gradien. Spesifikasi tidak memuat markup, tautan, atau gambar. Periksa spesifikasi yang tidak Anda tulis sendiri dengan `frameSpecSchema` atau `getFrameSpecIssues` dari `qrdx/types` sebelum menyimpannya. Mesin memeriksanya lagi sebelum menggambar.

```tsx title="components/custom-frame-code.tsx"
import { QRCode } from "qrdx";
import spec from "./my-frame.json";

export function CustomFrameCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      frame={{ style: "custom", spec, text: "Scan me", color: "#1e3a8a" }}
    />
  );
}
```

Field opsional yang dipakai bingkai bawaan dan templat (spesifikasi tanpa field ini digambar seperti sebelumnya):

| Field | Fungsi |
| --- | --- |
| `labels[].collapse` | `{ y, height }`. Saat label tidak menampilkan teks, pita dari `y` sampai `y + height` dipotong: baris di bawahnya naik dan gambar menjadi lebih pendek. Bentuk yang seluruhnya berada di dalam pita dihilangkan, dan bentuk yang melintasinya menjadi lebih pendek. Pita tidak boleh melintasi kode, padding-nya, atau pita lain |
| `qr.plate` | `"opaque"` (default), `"background"`, atau `"none"`. Mesin melukis plat berwarna latar kode di bawah kode. Saat latar itu tembus pandang, `"opaque"` melukis plat dan isian `background` menjadi putih, sehingga gambar tidak pernah terlihat melalui quiet zone. `"background"` membuatnya tetap tembus pandang dan tidak melukis plat; ini hanya diizinkan bila di bawah plat hanya ada isian `background`, atau cincin yang lubangnya menampung plat. `"none"` tidak melukis plat sama sekali, sehingga latar dan margin kode itu sendiri menjadi satu-satunya ruang terang, dan `qr.padding` boleh di bawah 4%. Templat menggunakannya |
| `stroke` | `{ color, width }` pada rect, lingkaran, elips, poligon, atau path: garis tepi yang berpusat pada tepi bentuk, digambar setelah isiannya, paling besar 10% dari sisi terpendek artboard |
| `colors.text` | Warna hex, atau campuran `frame`, `accent`, `background`, dan warna hex, seperti `{ "mix": ["frame", "accent"], "amount": 0.5 }` untuk label border gradien. Ini adalah default; `textColor` tetap diutamakan |

Baris label teks juga boleh masuk ke padding plat, selama tetap berada di luar kode dan huruf kapitalnya tetap di luar padding pada ukuran teks terbesar (`fontScale` 1.5). Bingkai border menempatkan labelnya tepat di bawah kode dengan cara ini.

## Bingkai resmi [#official-frames]

Selain bingkai bawaan, QRdx memiliki {facts.officialFrames} bingkai resmi: desain siap pakai untuk ajakan bertindak, restoran dan kafe, toko dan kemasan, kecantikan dan kebugaran, acara dan pernikahan, hotel dan perjalanan, properti, mobil dan parkir, kesehatan dan pendidikan, olahraga dan kebugaran, bisnis dan sosial, serta nirlaba dan kelompok komunitas. {facts.seasonalFrames} di antaranya untuk hari raya dan musim, dari Tahun Baru Imlek, Holi, Idul Fitri, dan Diwali hingga Hanukkah, Paskah, Thanksgiving, dan Natal. Masing-masing adalah spesifikasi bingkai dengan label dan warna yang dapat Anda ubah, dirilis di bawah CC0, dan diuji agar dapat dipindai pada jarak ponsel. Di [komunitas](/community/frames), bingkai ini diterbitkan oleh @qrdx.

```tsx title="components/official-frame-code.tsx"
import { getOfficialFrame, QRCode } from "qrdx";

const diwali = getOfficialFrame("diwali-diya"); // undefined for an unknown id

export function OfficialFrameCode() {
  return diwali ? (
    <QRCode
      value="https://example.com/offers"
      size={256}
      frame={{ style: "custom", spec: diwali.spec, text: "Scan for offers" }}
    />
  ) : null;
}
```

`OFFICIAL_FRAMES` adalah seluruh pustaka, dan `OFFICIAL_FRAME_INDEX` mencantumkan setiap bingkai tanpa spesifikasinya, sehingga pemilih dapat menampilkan pustaka dan memuat spesifikasi hanya saat dibutuhkan. Pustaka ini dibangun sebagai modul tersendiri, sehingga aplikasi yang tidak pernah mengimpornya tidak ikut mengirimkannya. Di [Image API](/docs/developers/image-api#community-items) dan [server MCP](/docs/developers/mcp), gunakan bingkai resmi sebagai item komunitas, seperti `item=frame:diwali-diya`.

## Apakah akan terpindai? [#will-it-scan]

`getScanScore` memperkirakan seberapa andal sebuah desain dapat dipindai. Fungsi ini berjalan di browser dan memuat jsQR sesuai kebutuhan.

```ts title="lib/scan-score.ts"
import { getScanScore } from "qrdx";

const { score, grade, checks } = await getScanScore({
  value: "https://example.com",
  bodyPattern: "circle",
  cornerEyePattern: "gear",
});
// score: 0 to 100, grade: "great" | "ok" | "risky" | "fails"
// checks: [{ id, passed, message, fix? }]
```

Hal yang diperiksa:

- **Decoding pada 96, 160, dan 320 px.** Desain dirender pada setiap lebar, diberi keburaman dan penurunan kontras seperti kamera, lalu didekode beberapa kali pada skala yang sedikit berbeda.
- **Kontras** antara setiap warna kode (termasuk titik gradien, warna mata, dan warna titik) dan latar belakang, serta apakah kodenya gelap di atas latar terang.
- **Cakupan logo** dibandingkan dengan yang dapat dipulihkan oleh tingkat koreksi kesalahan.
- **Zona tenang**: margin, ditambah celah yang ditambahkan oleh bingkai.
- **Risiko bentuk mata**: mata `circle` mungkin tidak terdeteksi oleh sebagian aplikasi pemindai, dan mata `curly` yang sudah dihentikan gagal pada dekoder yang ketat.
- **Pasangan gaya** (`style-pair`): bentuk yang gagal bersamaan dalam uji dekode paket, seperti modul `small-square` di samping mata persegi (lihat `getStylePairRisk`).

`getImageScanScore(fileOrImage)` melakukan hal yang sama untuk gambar yang sudah ada: fungsi ini mengembalikan konten hasil dekode beserta pemeriksaan dekode, kontras, polaritas, zona tenang, dan resolusi yang diukur dari piksel. [Pemeriksa pemindaian](/tools/scan-checker) dibangun di atasnya. Di Node, `scanQRPixels(pixels, expected)` memeriksa apakah piksel RGBA mentah dapat didekode menjadi sebuah nilai, baik apa adanya maupun melalui model kamera.

<Callout type="info">
  Skor ini adalah heuristik yang dibangun di atas satu dekoder open source. Aplikasi kamera ponsel sering kali lebih toleran, jadi anggap skor ini sebagai panduan dan uji pemindaian hasil cetak yang penting.
</Callout>

## Ekspor siap cetak [#print-ready-export]

`downloadPrintPDF` menulis PDF vektor dengan ukuran fisik yang tepat. Modul, mata, dan bingkai berupa jalur vektor; logo tetap berupa gambar raster.

```ts title="lib/print.ts"
import { downloadPrintPDF, downloadPrintSVG, getPrintLayout } from "qrdx";

const props = { value: "https://example.com", frame: { style: "banner-bottom" } } as const;

await downloadPrintPDF(props, {
  size: 40, // width of the code itself
  unit: "mm", // or "in"
  bleed: 3, // millimeters on every side
  cropMarks: true,
  colorMode: "cmyk",
});

await downloadPrintSVG(props, { size: 1.5, unit: "in" }); // width="…in" height="…in"

const layout = getPrintLayout(props, { size: 40 });
layout.trimWidth; // finished width in mm, frame included
layout.maxScanDistance; // 400 (mm)
```

- `size` adalah lebar kode, dari 5 mm hingga 2 m; bingkai menambah ukuran akhir.
- Dengan `bleed` (hingga 20 mm), warna latar belakang atau warna bingkai persegi diperluas melewati tepi potong sehingga pemotongan tidak menyisakan garis putih tipis. Tanda potong berada di luar area bleed.
- `colorMode: "cmyk"` menggunakan konversi sederhana (`rgbToCmyk`: K adalah 1 dikurangi nilai terbesar dari R, G, dan B, tanpa profil ICC; hitam murni dicetak hanya dengan K). Minta konversi dengan manajemen warna kepada percetakan Anda bila warna merek yang tepat itu penting.
- Gradien linear dan radial dicetak sebagai shading yang halus di PDF, dalam CMYK bila PDF-nya CMYK; SVG cetak tetap mempertahankannya tetapi tetap RGB.
- Teks bingkai di PDF menggunakan Helvetica Bold, sehingga karakter di luar Latin-1 mungkin tidak dirender. Gunakan SVG untuk aksara lain.
- `getQRAsPrintPDF` dan `getQRAsPrintPDFBuffer` mengembalikan file tanpa mengunduhnya, dan juga berfungsi di Node. `getQRAsEPS` menulis kode yang sama sebagai EPS; lihat [EPS](/docs/features/downloads#eps).

Seberapa besar mencetaknya: sebuah kode dapat dipindai dari jarak sekitar sepuluh kali lebarnya, jadi lebar kira-kira sama dengan jarak pemindaian dibagi 10 (lebar 2 cm untuk 20 cm). Kode yang lebih padat memerlukan ukuran lebih besar; [kalkulator ukuran cetak](/tools/print-size) memperhitungkan hal itu.
