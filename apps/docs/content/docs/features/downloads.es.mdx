`downloadQRCode(props, options)` guarda en el navegador, como archivo, el código descrito por `props`, en cualquiera de seis formatos. Las funciones hermanas devuelven ese mismo archivo como data URL, como Blob o como marcado, y `qrdx/node` genera un PNG en un servidor. Todas las funciones reciben los mismos `props` que `QRCode`, así que el archivo coincide con el código que ves en pantalla.

¿Descargas desde el Playground o el panel? Consulta [Descargar e imprimir un código QR](/docs/help/getting-started/download-and-print) en la Ayuda.

## Descargar un archivo [#download-a-file]

```ts title="lib/download.ts"
import { downloadQRCode } from "qrdx";

await downloadQRCode(
  {
    value: "https://example.com",
    fgColor: "#1d4ed8",
    bodyPattern: "rounded",
    frame: { style: "banner-bottom", text: "Scan me" },
  },
  {
    format: "png",
    size: { width: 1024, height: 1024 },
    filename: "menu.png",
  }
);
```

El navegador guarda `menu.png`. `size` es el ancho y el alto en píxeles del código en sí, de 50 a 5000 y siempre cuadrado; un marco hace que el archivo sea más grande. `filename` es opcional: sin él, el archivo se llama `qr-code.<ext>`, con el tamaño exacto en píxeles añadido en los formatos raster (`qr-code-1024x1024.png`, o `qr-code-1270x1454.png` con un banner inferior). `quality` (de 0 a 1) se aplica solo a WebP.

Los props son los mismos que en `QRCode`, salvo que el logo va en `imageSettings`. Para exportar el código que dibuja un `QRCode`, con su `logo` y `logoOptions`, pasa `getQRData(props)` o `resolveQRCodeProps(props)` en lugar de los props sin procesar.

## Formatos [#formats]

| `format` | Archivo | Notas |
| --- | --- | --- |
| `png` | Imagen | Conserva el fondo transparente. El predeterminado para la mayoría de los usos |
| `jpg` | Imagen | Solo fondo sólido, archivo más pequeño |
| `webp` | Imagen | Los píxeles del PNG en un archivo más pequeño; sin pérdida salvo que definas `quality` |
| `svg` | Vectorial | Nítido a cualquier tamaño; el archivo para imprentas y herramientas de diseño |
| `pdf` | Documento | Una página con el código como PNG. Requiere el paquete opcional `jspdf` |
| `eps` | Vectorial | PostScript para Illustrator, CorelDRAW e InDesign. `size.width` se interpreta como puntos (72 por pulgada) |

### WebP [#webp]

WebP es sin pérdida de forma predeterminada, así que los bordes de los módulos se mantienen exactos y un fondo transparente sigue siendo transparente. Cuando el canvas del navegador escribe WebP sin pérdida (Chrome y Edge lo hacen), el navegador genera el archivo. Cuando no puede, la biblioteca revisa los bytes y codifica ella misma los píxeles con un pequeño codificador sin pérdida integrado: Safari, al pedirle WebP, devuelve un PNG. En cualquier caso, un archivo `.webp` siempre es WebP.

`quality` (de 0 a 1) pide en su lugar un archivo con pérdida más pequeño, cuando el navegador lo admite. El WebP con pérdida suaviza los bordes de los módulos y los colores, así que mantén el valor predeterminado para los códigos que deban escanearse desde lejos. `getQRAsWebP` devuelve el archivo como un `Blob`:

```ts title="lib/webp.ts"
import { getQRAsWebP } from "qrdx";

const lossless = await getQRAsWebP({ value: "https://example.com", size: 1024 });
const lossy = await getQRAsWebP({ value: "https://example.com", size: 1024 }, { quality: 0.9 });
```

`canvasToWebP(canvas, options)` hace lo mismo con cualquier canvas, y `encodeWebPLossless(rgba, width, height)` codifica píxeles RGBA sin DOM.

### PDF [#pdf]

La descarga en PDF contiene el código como PNG en una página del mismo tamaño. Requiere el paquete opcional `jspdf` (`npm install jspdf`); sin él, las descargas en PDF lanzan `PDF export needs the optional "jspdf" package`. Para un PDF vectorial a un tamaño físico, con sangrado, marcas de corte y CMYK, usa `downloadPrintPDF`; consulta [Exportación lista para imprimir](/docs/features/frames#print-ready-export).

### EPS [#eps]

EPS no necesita ningún paquete adicional. `downloadQRCode` interpreta `size.width` como puntos, así que una solicitud de 512 px escribe un archivo de 512 pt (18 cm). Para un tamaño físico exacto, usa `getQRAsEPS`, que devuelve el EPS como cadena: el código mide `sizeMm` de ancho (50 mm de forma predeterminada), y un marco se suma a esa medida.

```ts title="lib/eps.ts"
import { downloadPrintEPS, getQRAsEPS } from "qrdx";

const eps = await getQRAsEPS(
  { value: "https://example.com" },
  { sizeMm: 40, bleedMm: 3, colorMode: "cmyk" }
);

await downloadPrintEPS({ value: "https://example.com" }, { sizeMm: 40, filename: "menu.eps" });
```

EPS no tiene transparencia ni marcas de corte. Los degradados lineales y radiales se imprimen como sombreados suaves de PostScript Nivel 3; los degradados angulares se imprimen como un abanico de cuñas finas. Los colores translúcidos se mezclan con el fondo, y el fondo con el papel blanco. Los logos PNG y JPEG se incrustan. EPS no puede incluir un [relleno de imagen](/docs/features/colors-gradients#image-fills): `getQRAsEPS` lanza `EPS_IMAGE_FILL_REASON`, y el diálogo de descarga del panel ofrece PDF, SVG y PNG en su lugar.

## Data URLs, Blobs y marcado [#data-urls-blobs-and-markup]

```ts title="lib/export.ts"
import { copyQRCodeToClipboard, getQRCodeDataUrl, getSVGString } from "qrdx";

const props = { value: "https://example.com", size: 512 };

// The same file as a data URL, for an <img> or a form field
const png = await getQRCodeDataUrl(props, "png", { width: 512, height: 512 });

// A PNG on the clipboard, for pasting into a document
await copyQRCodeToClipboard(props, { width: 512, height: 512 });

// The SVG markup, for inlining in a page or an email template
const svg = await getSVGString(props);
```

- `getQRCodeDataUrl(props, format, size, { quality })` acepta todos los formatos que acepta `downloadQRCode`.
- `copyQRCodeToClipboard` escribe un PNG. Llámala desde un controlador de clic: los navegadores rechazan las escrituras en el portapapeles fuera de un gesto del usuario.
- `getSVGString` incrusta el logo como data URL, de modo que el marcado es autosuficiente. `toSVGString` de `qrdx/core` es la versión síncrona sin ese paso.

## Tamaños predefinidos [#preset-sizes]

```ts title="lib/sizes.ts"
import { PRESET_SIZES, validateSize } from "qrdx";

PRESET_SIZES.small; // { width: 200, height: 200 }
PRESET_SIZES.medium; // 400
PRESET_SIZES.large; // 800
PRESET_SIZES.xlarge; // 1200
PRESET_SIZES["2xl"]; // 1600
PRESET_SIZES["3xl"]; // 2000

validateSize(4000, 4000); // { isValid: true }
validateSize(6000, 6000); // { isValid: false, error: "Size must not exceed 5000x5000 pixels" }
```

Elige el tamaño según el destino del archivo: de 256 a 512 px para una página web, 1024 px o más para imprimir a 300 píxeles por pulgada (1024 px se imprime nítido hasta unos 8,7 cm de ancho). Para tamaños de impresión exactos, usa las funciones de impresión, que trabajan en milímetros y pulgadas.

## PNG en Node [#png-in-node]

`getQRAsPNG` de `qrdx/node` devuelve bytes PNG sin navegador. Necesita un rasterizador opcional instalado junto a `qrdx`: `@resvg/resvg-js` dibuja el SVG, logos incluidos, como lo hacen los navegadores; `sharp` también funciona.

```ts title="scripts/make-png.ts"
import { writeFile } from "node:fs/promises";
import { getQRAsPNG } from "qrdx/node";

const png = await getQRAsPNG(
  { value: "https://example.com", bodyPattern: "rounded", margin: 4 },
  { size: 1024 }
);
await writeFile("qr-code.png", png);
```

Impórtala desde `qrdx/node`, nunca desde `qrdx`, para que los paquetes del navegador nunca vean los módulos nativos. Un logo que sea una data URL se incrusta tal cual; una URL `http(s)` o una ruta local se carga solo con `loadExternalLogos: true`, de modo que un servidor que reenvía los ajustes de quien llama no pueda ser obligado a pedir URL internas ni a leer su propio disco. El marcado SVG no necesita rasterizador: `toSVGString` de `qrdx/core` se ejecuta en cualquier parte.

## Si algo sale mal [#if-something-goes-wrong]

- **`Size must be at least 50x50 pixels`, `Size must not exceed 5000x5000 pixels` o `Width and height must be equal for QR codes`.** `validateSize` rechazó el tamaño. Pasa un tamaño cuadrado dentro del rango.
- **`PDF export needs the optional "jspdf" package`.** Instala `jspdf` en el mismo paquete que `qrdx`.
- **Falta el logo en el archivo.** La imagen viene de otro origen sin encabezados CORS, así que el navegador no pudo copiarla. Sírvela desde tu propio origen o pasa una data URL.
- **`copyQRCodeToClipboard` se rechaza.** Se ejecutó fuera de un controlador de clic o de teclado, o la página no se sirve por HTTPS. Llámala desde el propio controlador.
- **`getQRAsPNG` lanza un error por falta de rasterizador.** Instala `@resvg/resvg-js` o `sharp` junto a `qrdx`.
