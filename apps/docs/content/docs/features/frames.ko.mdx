`frame` prop은 코드 주위에 "Scan me" 프레임을 그리고, `getScanScore`는 디자인이 스캔되는지 알려 주며, 인쇄 함수는 도련(bleed)과 재단선을 포함해 실제 크기의 벡터 파일을 만듭니다. 이 페이지에서는 이 세 가지를 순서대로 다룹니다.

플레이그라운드나 대시보드에서 디자인하고 계신가요? 도움말의 [프레임과 행동 유도 문구 추가](/docs/help/designing/frames), [스캔 점수로 디자인 확인하기](/docs/help/designing/scan-score), [QR 코드 다운로드 및 인쇄](/docs/help/getting-started/download-and-print)를 참고하세요.

## 행동 유도 프레임 [#call-to-action-frames]

QRdx가 그리는 모든 프레임은 프레임 스펙입니다. 도형, 레이블, 색상을 설명하는 작은 JSON입니다. 하나의 엔진이 모든 스펙을 그리므로 프레임은 SVG, PNG, PDF, EPS에서 똑같이 보입니다. 프레임은 총 {facts.frames}개이며, 기본 제공 프레임 {facts.frameStyles}개와 [공식 프레임](#official-frames) {facts.officialFrames}개로 이루어져 있습니다. 직접 만들거나 [커뮤니티](/community/frames)에서 골라 쓸 수도 있습니다.

`frame`은 `QRCode`, `QRCodeSVG`, `QRCodeCanvas`, `getQRAsSVG`, `getQRData`, 그리고 모든 다운로드 헬퍼에서 동작합니다.

```tsx title="components/menu-frame-code.tsx"
import { QRCode } from "qrdx";

export function MenuFrameCode() {
  return (
    <QRCode
      value="https://example.com/menu"
      size={256}
      frame={{
        style: "banner-bottom",
        text: "Scan for the menu",
        color: "#1e3a8a",
      }}
    />
  );
}
```

프레임은 코드 바깥쪽에 추가됩니다. 그래서 출력 크기는 커지지만 모듈과 여백(quiet zone)은 가려지지 않으므로 스캔 성능은 그대로입니다. 코드 배경색의 밝은 간격이 코드와 프레임을 구분합니다.

### 기본 제공 프레임 [#built-in-frames]

기본 제공 프레임은 `style`로 이름을 지정합니다. 옵션은 스펙의 레이블과 색상을 채웁니다.

| 옵션 | 기본값 | 참고 |
| --- | --- | --- |
| `style` | 없음 | 아래의 기본 제공 스타일 {facts.frameStyles}개 중 하나, `none`, 또는 `spec`과 함께 쓰는 `custom` |
| `text` | `"Scan me"` | 최대 24자. 레이블을 숨기려면 `""`를 전달하세요 |
| `color` | 스펙 자체의 색상: 보라색으로 시작하는 `gradient-border`를 제외한 모든 기본 제공 프레임은 검은색 | 프레임 색상 |
| `textColor` | 프레임 위에서는 흰색, 밝은 영역에서는 `color` | 레이블 색상 |
| `secondaryText` | 없음 | 두 번째 레이블, 최대 24자: `banner-top-bottom`의 아래쪽 띠, `circle`의 아래쪽 호, `menu-card`의 푸터 |
| `secondaryColor` | 스펙의 강조색인 분홍색 | `gradient-border`의 끝 색상 |
| `fontScale` | `1` | 0.5에서 1.5까지의 레이블 크기이며, 레이블은 여전히 맞게 줄어듭니다 |

`style`별 기본 제공 프레임은 다음과 같습니다.

- 배너와 테두리: `banner-bottom`, `banner-top`, `banner-top-bottom`, `border`, `rounded-border`, `gradient-border`, `focus` (모서리 괄호)
- 말풍선: `speech-bubble`, `speech-bubble-top`, `chat-bubble`
- 배지: `circle` (링을 따라 배치한 텍스트), `badge` (리본), `sticker` (그림자가 있는 다이컷)
- 오브젝트: `polaroid`, `phone`, `ticket`, `tag` (구멍이 있는 행택), `envelope`, `menu-card`

이 이름은 각각 엔진의 스펙을 가리키며, 앞으로도 계속 유효합니다. 이 이름을 사용하는 저장된 디자인, 이미지 API 링크, CLI 플래그, 코드는 계속 같은 프레임을 그립니다. 테두리처럼 레이블이 없을 때 레이블 행을 없애는 프레임은 지금도 그렇게 동작합니다. 브라우저에서 디코딩한 모든 프레임은 [도형, 눈, 프레임](/docs/styles#frames)에서 볼 수 있습니다.

`BUILT_IN_FRAMES`는 이름과 스펙을 함께 나열합니다(`BUILT_IN_FRAME_SPECS`는 스타일별 스펙을 담고 있습니다). `frameSpecOf`는 프레임이 그리는 스펙을 반환하고, `getFrameColors`는 프레임이 칠하는 색상을 반환합니다.

```ts title="lib/frames.ts"
import { BUILT_IN_FRAMES, frameSpecOf, getFrameColors, getFrameDimensions } from "qrdx";

BUILT_IN_FRAMES.map((frame) => frame.name); // ["Banner", "Top banner", "Two banners", …]

// A built-in style's spec, or a custom frame's own
const ticket = frameSpecOf({ style: "ticket" });

// The frame's options, else its spec's defaults
getFrameColors({ style: "border", color: "#1e3a8a" });
// { frame: "#1e3a8a", text: "#1e3a8a", accent: "#1e3a8a" }

// The output size: a 400 px code in a bottom banner
getFrameDimensions(400, { style: "banner-bottom" }); // { width: 496, height: 568 }
```

레이블과 색상 외에 더 많은 것을 바꾸려면 기본 제공 스펙에서 커스텀 프레임을 시작하세요. `{ style: "custom", spec: frameSpecOf({ style: "ticket" }) }`는 같은 티켓을 그리며, 그 도형을 직접 편집할 수 있습니다.

모든 프레임은 불투명한 색상의 단순한 도형과 텍스트로 이루어져 있으므로 SVG, PNG, PDF, EPS 내보내기 결과가 일치합니다. 그라디언트 테두리는 고운 단색 단계로 그려지고, 원형 프레임의 곡선 글자는 모든 형식에서 회전된 텍스트입니다. 레이블은 시스템 글꼴 스택을 사용하므로 내려받는 것이 없습니다.

`FRAME_STYLES`, `frameSchema`(zod), `QRFrame` 및 `FrameStyle` 타입도 서버 측 검증을 위해 `qrdx/types`에서 내보내집니다. CLI는 `--frame`, `--frame-text`, `--frame-color`, `--frame-text-color`로 같은 프레임을 그립니다. [CLI](/docs/developers/cli)를 참고하세요.

### 프레임 스펙 [#frame-specs]

프레임 스펙은 `kind: "qrdx.frame"`, `version: 1`, `artboard` 크기, 코드가 들어갈 `qr` 상자, 기본 `colors`, 코드 뒤에 칠해지는 `shapes`, 그리고 `labels`로 이루어진 JSON입니다. 도형에는 사각형(선택적으로 구멍 포함), 원과 링, 타원, 다각형, 패스, 선, 기본 제공 아이콘이 있습니다. 도형은 테마 토큰(`frame`, `text`, `accent`, `background`), 16진수 색상, 두 색의 혼합, 또는 그라디언트로 채워집니다. 스펙에는 마크업, 링크, 이미지가 들어 있지 않습니다. 직접 작성하지 않은 스펙은 저장하기 전에 `qrdx/types`의 `frameSpecSchema` 또는 `getFrameSpecIssues`로 확인하세요. 엔진은 그리기 전에 한 번 더 확인합니다.

```tsx title="components/custom-frame-code.tsx"
import { QRCode } from "qrdx";
import spec from "./my-frame.json";

export function CustomFrameCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      frame={{ style: "custom", spec, text: "Scan me", color: "#1e3a8a" }}
    />
  );
}
```

기본 제공 프레임과 템플릿이 사용하는 선택 필드입니다(이 필드가 없는 스펙은 이전과 같이 그려집니다).

| 필드 | 기능 |
| --- | --- |
| `labels[].collapse` | `{ y, height }`. 레이블에 텍스트가 없으면 `y`부터 `y + height`까지의 띠가 잘려 나갑니다. 그 아래 행은 위로 올라오고 아트워크는 짧아집니다. 띠 안에 완전히 들어가는 도형은 제외되고, 띠를 가로지르는 도형은 짧아집니다. 띠는 코드, 코드의 패딩, 다른 띠와 겹칠 수 없습니다 |
| `qr.plate` | `"opaque"`(기본값), `"background"`, `"none"`. 엔진은 코드 아래에 코드 배경색으로 플레이트를 칠합니다. 배경이 투명할 때 `"opaque"`는 플레이트를 칠하고 `background` 채움은 흰색이 되므로, 아트워크가 여백(quiet zone)에 비치지 않습니다. `"background"`는 이들을 투명하게 유지하고 플레이트를 생략합니다. 플레이트 아래에 `background` 채움만 있거나, 구멍에 플레이트가 들어가는 링만 있을 때에 한해 허용됩니다. `"none"`은 플레이트를 전혀 칠하지 않으므로 코드 자체의 배경과 여백만 밝은 공간이 되며, `qr.padding`은 4% 미만일 수 있습니다. 템플릿이 이를 사용합니다 |
| `stroke` | 사각형, 원, 타원, 다각형, 패스에 쓰는 `{ color, width }`. 도형 가장자리를 중심으로 채움 뒤에 그려지는 윤곽선이며, 아트보드의 짧은 변의 최대 10%입니다 |
| `colors.text` | 16진수 색상, 또는 `frame`, `accent`, `background`와 16진수 색상의 혼합. 예를 들어 그라디언트 테두리의 레이블에는 `{ "mix": ["frame", "accent"], "amount": 0.5 }`를 씁니다. 이는 기본값이며 `textColor`가 여전히 우선합니다 |

텍스트 레이블의 행은 코드에서 떨어져 있고 가장 큰 텍스트 크기(`fontScale` 1.5)에서도 대문자가 패딩 밖에 머문다면 플레이트의 패딩 안까지 들어갈 수도 있습니다. 테두리 프레임은 이 방식으로 레이블을 코드 바로 아래에 배치합니다.

## 공식 프레임 [#official-frames]

기본 제공 프레임 외에도 QRdx에는 공식 프레임 {facts.officialFrames}개가 있습니다. 행동 유도, 식당과 카페, 상점과 포장, 뷰티와 웰니스, 이벤트와 웨딩, 호텔과 여행, 부동산, 자동차와 주차, 건강과 교육, 스포츠와 피트니스, 비즈니스와 소셜, 비영리 단체와 커뮤니티 그룹용으로 만든 디자인입니다. 이 중 {facts.seasonalFrames}개는 설날, 홀리, 이드, 디왈리부터 하누카, 부활절, 추수감사절, 크리스마스까지 명절과 계절용입니다. 각 프레임은 레이블과 색상을 바꿀 수 있는 프레임 스펙이며 CC0로 공개되어 있고, 휴대폰으로 스캔하는 거리에서 스캔되는지 테스트를 거쳤습니다. [커뮤니티](/community/frames)에는 @qrdx가 게시합니다.

```tsx title="components/official-frame-code.tsx"
import { getOfficialFrame, QRCode } from "qrdx";

const diwali = getOfficialFrame("diwali-diya"); // undefined for an unknown id

export function OfficialFrameCode() {
  return diwali ? (
    <QRCode
      value="https://example.com/offers"
      size={256}
      frame={{ style: "custom", spec: diwali.spec, text: "Scan for offers" }}
    />
  ) : null;
}
```

`OFFICIAL_FRAMES`는 전체 라이브러리이고, `OFFICIAL_FRAME_INDEX`는 스펙 없이 모든 프레임을 나열하므로, 선택기는 라이브러리를 보여 주고 필요할 때만 스펙을 불러올 수 있습니다. 라이브러리는 별도의 모듈로 빌드되므로 이를 import하지 않는 앱에는 포함되지 않습니다. [이미지 API](/docs/developers/image-api#community-items)와 [MCP 서버](/docs/developers/mcp)에서는 공식 프레임을 `item=frame:diwali-diya`처럼 커뮤니티 항목으로 사용하세요.

## 스캔이 될까요? [#will-it-scan]

`getScanScore`는 디자인이 얼마나 안정적으로 스캔되는지 추정합니다. 브라우저에서 실행되며 jsQR을 필요할 때 불러옵니다.

```ts title="lib/scan-score.ts"
import { getScanScore } from "qrdx";

const { score, grade, checks } = await getScanScore({
  value: "https://example.com",
  bodyPattern: "circle",
  cornerEyePattern: "gear",
});
// score: 0 to 100, grade: "great" | "ok" | "risky" | "fails"
// checks: [{ id, passed, message, fix? }]
```

확인하는 항목은 다음과 같습니다.

- **96, 160, 320 px에서의 디코딩.** 디자인을 각 너비로 렌더링하고 카메라처럼 흐림과 대비 저하를 적용한 뒤, 조금씩 다른 배율로 여러 번 디코딩합니다.
- 모든 코드 색상(그라디언트 정지점, 눈 색상, 점 색상 포함)과 배경 사이의 **대비**, 그리고 코드가 밝은 배경 위의 어두운 색인지 여부.
- 오류 정정 수준으로 복구할 수 있는 범위와 비교한 **로고 점유율**.
- **여백(Quiet zone)**: 설정한 마진과 프레임이 추가하는 간격.
- **눈 모양 위험**: `circle` 눈은 일부 스캐너 앱에서 인식되지 않을 수 있고, 더 이상 사용되지 않는 `curly` 눈은 엄격한 디코더에서 실패합니다.
- **스타일 조합** (`style-pair`): 패키지의 디코딩 테스트에서 함께 쓰면 실패하는 모양 조합입니다. 예를 들어 `small-square` 모듈과 사각형 눈의 조합이 있습니다(`getStylePairRisk` 참고).

`getImageScanScore(fileOrImage)`는 기존 이미지에 대해 같은 검사를 합니다. 디코딩된 내용과 함께 픽셀에서 측정한 디코딩, 대비, 극성, 여백, 해상도 검사 결과를 반환합니다. [스캔 검사기](/tools/scan-checker)가 이 함수를 기반으로 만들어졌습니다. Node에서는 `scanQRPixels(pixels, expected)`로 원본 RGBA 픽셀이 그대로, 그리고 카메라 모델을 거친 뒤에도 해당 값으로 디코딩되는지 확인할 수 있습니다.

<Callout type="info">
  이 점수는 오픈소스 디코더 하나를 기반으로 한 휴리스틱입니다. 휴대폰 카메라 앱은 대개 더 너그럽게 인식하므로, 참고용으로 활용하고 중요한 인쇄물은 직접 스캔해서 테스트하세요.
</Callout>

## 인쇄용 내보내기 [#print-ready-export]

`downloadPrintPDF`는 정확한 실제 크기의 벡터 PDF를 만듭니다. 모듈, 눈, 프레임은 벡터 경로이고 로고는 래스터 이미지로 유지됩니다.

```ts title="lib/print.ts"
import { downloadPrintPDF, downloadPrintSVG, getPrintLayout } from "qrdx";

const props = { value: "https://example.com", frame: { style: "banner-bottom" } } as const;

await downloadPrintPDF(props, {
  size: 40, // width of the code itself
  unit: "mm", // or "in"
  bleed: 3, // millimeters on every side
  cropMarks: true,
  colorMode: "cmyk",
});

await downloadPrintSVG(props, { size: 1.5, unit: "in" }); // width="…in" height="…in"

const layout = getPrintLayout(props, { size: 40 });
layout.trimWidth; // finished width in mm, frame included
layout.maxScanDistance; // 400 (mm)
```

- `size`는 코드의 너비이며 5 mm에서 2 m까지 지정할 수 있습니다. 프레임이 있으면 완성된 크기가 그만큼 커집니다.
- `bleed`(최대 20 mm)를 지정하면 배경이나 사각형 프레임의 색상이 재단선 바깥까지 확장되어, 재단 후에도 흰 틈이 남지 않습니다. 재단 표시는 블리드 바깥에 놓입니다.
- `colorMode: "cmyk"`는 간단한 변환을 사용합니다(`rgbToCmyk`: K는 1에서 R, G, B 중 가장 큰 값을 뺀 값이며 ICC 프로필은 사용하지 않습니다. 순수한 검은색은 K만으로 인쇄됩니다). 정확한 브랜드 색상이 중요하다면 인쇄소에 색상 관리 변환을 요청하세요.
- 선형 및 방사형 그라디언트는 PDF에서 부드러운 셰이딩으로 인쇄되며, PDF가 CMYK이면 CMYK로 출력됩니다. 인쇄용 SVG는 그라디언트를 유지하지만 RGB로 남습니다.
- PDF의 프레임 텍스트는 Helvetica Bold를 사용하므로 Latin-1 범위 밖의 문자는 표시되지 않을 수 있습니다. 다른 문자 체계에는 SVG를 사용하세요.
- `getQRAsPrintPDF`와 `getQRAsPrintPDFBuffer`는 파일을 다운로드하지 않고 반환하며 Node에서도 동작합니다. `getQRAsEPS`는 같은 코드를 EPS로 만듭니다. [EPS](/docs/features/downloads#eps)를 참고하세요.

인쇄 크기 기준: 코드는 자신의 너비의 약 열 배 거리에서 스캔되므로, 너비는 스캔 거리를 10으로 나눈 값 정도입니다(20 cm 거리면 너비 2 cm). 밀도가 높은 코드는 더 커야 하며, [인쇄 크기 계산기](/tools/print-size)는 이를 반영합니다.
