`frame` プロパティはコードの周りに「Scan me」フレームを描画し、`getScanScore` はデザインがスキャンできるかどうかを判定します。印刷用の関数は、塗り足しとトンボ付きで、実寸のベクターファイルを書き出します。このページでは、この3つをこの順に説明します。

Playgroundやダッシュボードでデザインする場合は、ヘルプの[フレームと行動喚起を追加する](/docs/help/designing/frames)、[スキャンスコアでデザインを確認する](/docs/help/designing/scan-score)、[QRコードをダウンロードして印刷する](/docs/help/getting-started/download-and-print)をご覧ください。

## 行動喚起フレーム [#call-to-action-frames]

QRdxが描画するフレームはすべてフレーム仕様です。図形、ラベル、色を記述した小さなJSONです。すべての仕様を1つのエンジンが描画するため、フレームはSVG、PNG、PDF、EPSのどれでも同じ見た目になります。フレームは全部で {facts.frames} 種類あります。内訳は、{facts.frameStyles} 種類の組み込みフレームと {facts.officialFrames} 種類の[公式フレーム](#official-frames)です。独自のフレームを書くことも、[コミュニティ](/community/frames)から選ぶこともできます。

`frame` は `QRCode`、`QRCodeSVG`、`QRCodeCanvas`、`getQRAsSVG`、`getQRData`、およびすべてのダウンロード用ヘルパーで使えます。

```tsx title="components/menu-frame-code.tsx"
import { QRCode } from "qrdx";

export function MenuFrameCode() {
  return (
    <QRCode
      value="https://example.com/menu"
      size={256}
      frame={{
        style: "banner-bottom",
        text: "Scan for the menu",
        color: "#1e3a8a",
      }}
    />
  );
}
```

フレームはコードの外側に追加されます。そのため出力サイズは大きくなりますが、モジュールとクワイエットゾーンが覆われることはなく、スキャンのしやすさは変わりません。コードの背景色と同じ明るい余白が、コードとフレームを区切ります。

### 組み込みフレーム [#built-in-frames]

組み込みフレームは `style` で指定します。オプションで、その仕様のラベルと色を設定します。

| オプション | デフォルト | 備考 |
| --- | --- | --- |
| `style` | なし | 下記の {facts.frameStyles} 種類の組み込みスタイルのいずれか、`none`、または `spec` を伴う `custom` |
| `text` | `"Scan me"` | 24文字まで。ラベルを非表示にするには `""` を渡します |
| `color` | 仕様自体の色。`gradient-border` 以外の組み込みフレームはすべて黒で、`gradient-border` は紫から始まります | フレームの色 |
| `textColor` | フレーム上では白、明るい領域では `color` | ラベルの色 |
| `secondaryText` | なし | 2つ目のラベル（24文字まで）。`banner-top-bottom` の下部の帯、`circle` の下側の円弧、`menu-card` のフッターに入ります |
| `secondaryColor` | 仕様のアクセントカラー（ピンク） | `gradient-border` の終了色 |
| `fontScale` | `1` | ラベルのサイズ。0.5から1.5まで。ラベルは収まるように縮小されます |

`style` で指定できる組み込みフレームは次のとおりです。

- バナーと枠線: `banner-bottom`、`banner-top`、`banner-top-bottom`、`border`、`rounded-border`、`gradient-border`、`focus`（四隅のブラケット）
- 吹き出し: `speech-bubble`、`speech-bubble-top`、`chat-bubble`
- バッジ: `circle`（リング状に配置したテキスト）、`badge`（リボン）、`sticker`（影付きのダイカット）
- オブジェクト: `polaroid`、`phone`、`ticket`、`tag`（穴の開いた下げ札）、`envelope`、`menu-card`

これらの名前はそれぞれエンジン内の仕様に対応しており、今後も変わらず有効です。これらを使っている保存済みのデザイン、Image APIのリンク、CLIのフラグ、コードは、これまでと同じフレームを描画し続けます。枠線のように、ラベルがないときにラベル行を省くフレームも、そのまま省きます。すべてのフレームをブラウザー上でデコードして確認するには、[図形、アイ、フレーム](/docs/styles#frames)をご覧ください。

`BUILT_IN_FRAMES` は名前と仕様の一覧です（スタイル別の仕様は `BUILT_IN_FRAME_SPECS` にあります）。`frameSpecOf` は任意のフレームが描画する仕様を返し、`getFrameColors` はそのフレームが使う色を返します。

```ts title="lib/frames.ts"
import { BUILT_IN_FRAMES, frameSpecOf, getFrameColors, getFrameDimensions } from "qrdx";

BUILT_IN_FRAMES.map((frame) => frame.name); // ["Banner", "Top banner", "Two banners", …]

// A built-in style's spec, or a custom frame's own
const ticket = frameSpecOf({ style: "ticket" });

// The frame's options, else its spec's defaults
getFrameColors({ style: "border", color: "#1e3a8a" });
// { frame: "#1e3a8a", text: "#1e3a8a", accent: "#1e3a8a" }

// The output size: a 400 px code in a bottom banner
getFrameDimensions(400, { style: "banner-bottom" }); // { width: 496, height: 568 }
```

ラベルと色以外も変更したい場合は、組み込みの仕様からカスタムフレームを作り始めてください。`{ style: "custom", spec: frameSpecOf({ style: "ticket" }) }` は同じチケットを描画し、その図形を編集できます。

すべてのフレームは、不透明な色の単純な図形とテキストでできているため、SVG、PNG、PDF、EPSの出力が一致します。グラデーション枠線は細かい単色のステップで描画され、circleフレームの曲線状の文字はどの形式でも回転したテキストです。ラベルにはシステムフォントスタックを使うので、フォントのダウンロードは発生しません。

`FRAME_STYLES`、`frameSchema`（zod）、`QRFrame` 型と `FrameStyle` 型は、サーバー側での検証用に `qrdx/types` からもエクスポートされています。CLIでは `--frame`、`--frame-text`、`--frame-color`、`--frame-text-color` で同じフレームを描画できます。詳しくは[CLI](/docs/developers/cli)をご覧ください。

### フレーム仕様 [#frame-specs]

フレーム仕様は、`kind: "qrdx.frame"`、`version: 1`、`artboard` のサイズ、コードを配置する `qr` ボックス、デフォルトの `colors`、コードの背後に描画される `shapes`、そして `labels` を持つJSONです。図形には、矩形（穴を開けることも可能）、円とリング、楕円、多角形、パス、線、組み込みアイコンがあります。塗りには、テーマトークン（`frame`、`text`、`accent`、`background`）、16進数カラー、2色の混合、またはグラデーションを指定できます。仕様にはマークアップ、リンク、画像を含められません。自分で書いていない仕様は、保存する前に `qrdx/types` の `frameSpecSchema` または `getFrameSpecIssues` で検証してください。エンジンも描画の前に再度検証します。

```tsx title="components/custom-frame-code.tsx"
import { QRCode } from "qrdx";
import spec from "./my-frame.json";

export function CustomFrameCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      frame={{ style: "custom", spec, text: "Scan me", color: "#1e3a8a" }}
    />
  );
}
```

組み込みフレームとテンプレートが使うオプションのフィールドです（これらのフィールドがない仕様は、従来どおり描画されます）。

| フィールド | 機能 |
| --- | --- |
| `labels[].collapse` | `{ y, height }`。ラベルにテキストがないとき、`y` から `y + height` までの帯が切り取られます。その下の行は上に詰められ、アートワークは短くなります。帯の内側に完全に収まる図形は除かれ、帯をまたぐ図形は短くなります。帯がコード、そのパディング、または別の帯をまたぐことはできません |
| `qr.plate` | `"opaque"`（デフォルト）、`"background"`、`"none"`。エンジンは、コードの背景色のプレートをコードの下に描画します。その背景が透過のとき、`"opaque"` はプレートを描画し、`background` は白で塗りつぶすので、アートワークがクワイエットゾーンから透けて見えることはありません。`"background"` は透過のままプレートを描画しません。プレートの下に `background` の塗りだけがあるか、穴にプレートが収まるリングがあるだけの場合にのみ使えます。`"none"` はプレートをまったく描画しないため、コード自身の背景とマージンだけが明るい余白になり、`qr.padding` は4%未満にできます。テンプレートはこれを使います |
| `stroke` | 矩形、円、楕円、多角形、パスに指定する `{ color, width }`。図形の縁を中心とした輪郭線で、塗りのあとに描画され、アートボードの短辺の10%までです |
| `colors.text` | 16進数カラー、または `frame`、`accent`、`background`、16進数カラーを混合したもの。グラデーション枠線のラベルでは `{ "mix": ["frame", "accent"], "amount": 0.5 }` のように指定します。これはデフォルト値で、`textColor` が指定されていればそちらが優先されます |

テキストラベルの行は、コードにかからず、最大のテキストサイズ（`fontScale` 1.5）でも大文字がパディングの外に収まる限り、プレートのパディングの中に入り込むこともできます。枠線フレームは、この方法でラベルをコードのすぐ下に配置しています。

## 公式フレーム [#official-frames]

組み込みフレームに加えて、QRdxには {facts.officialFrames} 種類の公式フレームがあります。行動喚起、レストランとカフェ、店舗とパッケージ、美容とウェルネス、イベントと結婚式、ホテルと旅行、不動産、車と駐車場、健康と教育、スポーツとフィットネス、ビジネスとソーシャル、非営利団体と地域コミュニティ向けに作られた、すぐに使えるデザインです。そのうち {facts.seasonalFrames} 種類は、旧正月、ホーリー、イード、ディワリからハヌカ、イースター、感謝祭、クリスマスまで、祝日や季節向けです。いずれも、変更できるラベルと色を持つフレーム仕様で、CC0で公開されており、スマートフォンで読み取る距離でスキャンできることがテスト済みです。[コミュニティ](/community/frames)では、@qrdx が公開しています。

```tsx title="components/official-frame-code.tsx"
import { getOfficialFrame, QRCode } from "qrdx";

const diwali = getOfficialFrame("diwali-diya"); // undefined for an unknown id

export function OfficialFrameCode() {
  return diwali ? (
    <QRCode
      value="https://example.com/offers"
      size={256}
      frame={{ style: "custom", spec: diwali.spec, text: "Scan for offers" }}
    />
  ) : null;
}
```

`OFFICIAL_FRAMES` はライブラリ全体で、`OFFICIAL_FRAME_INDEX` は仕様を含まない全フレームの一覧です。これを使えば、ピッカーでライブラリを表示し、必要になったときにだけ仕様を読み込めます。ライブラリは独立したモジュールとしてビルドされるため、これをインポートしないアプリには含まれません。[Image API](/docs/developers/image-api#community-items)と[MCPサーバー](/docs/developers/mcp)では、`item=frame:diwali-diya` のように、公式フレームをコミュニティアイテムとして使えます。

## スキャンできるか [#will-it-scan]

`getScanScore` は、デザインがどのくらい確実にスキャンできるかを推定します。ブラウザー上で動作し、必要に応じて jsQR を読み込みます。

```ts title="lib/scan-score.ts"
import { getScanScore } from "qrdx";

const { score, grade, checks } = await getScanScore({
  value: "https://example.com",
  bodyPattern: "circle",
  cornerEyePattern: "gear",
});
// score: 0 to 100, grade: "great" | "ok" | "risky" | "fails"
// checks: [{ id, passed, message, fix? }]
```

チェックする項目は次のとおりです。

- **96px、160px、320px でのデコード。** それぞれの幅でデザインを描画し、カメラで撮影したようなぼかしとコントラストの低下を加えたうえで、少しずつ異なる倍率で数回デコードします。
- **コントラスト**。コードのすべての色（グラデーションの色停止点、アイの色、ドットの色を含む）と背景とのコントラスト、およびコードが明るい背景に暗い色で描かれているかどうか。
- **ロゴの占有率**。エラー訂正レベルで復元できる範囲と比較します。
- **クワイエットゾーン**。マージンに、フレームによって加わる余白を足したもの。
- **アイの形状によるリスク**: `circle` のアイは一部のスキャナーアプリで読み取れない場合があり、廃止された `curly` のアイは厳密なデコーダーでは読み取れません。
- **スタイルの組み合わせ**（`style-pair`）: パッケージのデコードテストで、組み合わせると読み取れなくなる形状です。たとえば、`small-square` のモジュールと四角いアイの組み合わせがあります（`getStylePairRisk` を参照）。

`getImageScanScore(fileOrImage)` は、既存の画像に対して同じ処理を行います。デコードされた内容に加え、ピクセルから測定したデコード、コントラスト、極性、クワイエットゾーン、解像度のチェック結果を返します。[スキャンチェッカー](/tools/scan-checker)はこの関数を基に作られています。Node では、`scanQRPixels(pixels, expected)` を使うと、生の RGBA ピクセルが、そのままの状態とカメラモデルを通した状態の両方で、指定した値にデコードされるかを確認できます。

<Callout type="info">
  このスコアは、1つのオープンソースのデコーダーに基づくヒューリスティックです。スマートフォンのカメラアプリのほうが寛容な場合も多いため、目安として使い、重要な印刷物は実際にスキャンして確認してください。
</Callout>

## 印刷用エクスポート [#print-ready-export]

`downloadPrintPDF` は、正確な物理サイズのベクター PDF を書き出します。モジュール、アイ、フレームはベクターパスで、ロゴはラスター画像のままです。

```ts title="lib/print.ts"
import { downloadPrintPDF, downloadPrintSVG, getPrintLayout } from "qrdx";

const props = { value: "https://example.com", frame: { style: "banner-bottom" } } as const;

await downloadPrintPDF(props, {
  size: 40, // width of the code itself
  unit: "mm", // or "in"
  bleed: 3, // millimeters on every side
  cropMarks: true,
  colorMode: "cmyk",
});

await downloadPrintSVG(props, { size: 1.5, unit: "in" }); // width="…in" height="…in"

const layout = getPrintLayout(props, { size: 40 });
layout.trimWidth; // finished width in mm, frame included
layout.maxScanDistance; // 400 (mm)
```

- `size` はコードの幅で、5 mm から 2 m まで指定できます。フレームを付けると、仕上がりサイズはその分大きくなります。
- `bleed`（最大 20 mm）を指定すると、背景または四角いフレームの色が裁ち落とし線の外側まで広がり、トリミングしても白い隙間が残りません。トンボは塗り足しの外側に付きます。
- `colorMode: "cmyk"` は簡易的な変換を使います（`rgbToCmyk`: K は 1 から R、G、B の最大値を引いた値で、ICC プロファイルは使いません。純粋な黒は K のみで印刷されます）。ブランドカラーを正確に再現したい場合は、印刷会社にカラーマネジメント済みの変換を依頼してください。
- 線形グラデーションと放射状グラデーションは、PDF 内で滑らかなシェーディングとして印刷されます。PDF が CMYK の場合は CMYK になります。印刷用 SVG ではグラデーションは保持されますが、RGB のままです。
- PDF 内のフレームのテキストには Helvetica Bold を使うため、Latin-1 以外の文字は表示されない場合があります。その他の文字体系には SVG を使用してください。
- `getQRAsPrintPDF` と `getQRAsPrintPDFBuffer` は、ダウンロードせずにファイルを返し、Node でも動作します。`getQRAsEPS` は同じコードを EPS として書き出します。[EPS](/docs/features/downloads#eps)を参照してください。

印刷するサイズの目安: コードは、自身の幅の約10倍の距離からスキャンできます。つまり、幅はスキャンする距離を10で割った値が目安です（20 cm の距離なら幅 2 cm）。密度の高いコードにはさらに大きなサイズが必要です。[印刷サイズ計算ツール](/tools/print-size)ではその点も考慮されます。
