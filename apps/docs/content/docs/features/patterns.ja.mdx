コードの形は3つのプロパティで決まります。データモジュールには `bodyPattern`、3つのコーナーのアイには `cornerEyePattern`、各アイの内側のドットには `cornerEyeDotPattern` を使います。このページでは、これらに加えて、モジュールの縮小、形のあるコード、アイごとの色を説明します。すべての値は [形、アイ、フレーム](/docs/styles) でリアルタイムに確認できます。

Playground やダッシュボードでデザインする場合は、ヘルプの [最初のQRコードを作る](/docs/help/getting-started/first-qr-code) から始めてください。

```tsx title="components/shaped-code.tsx"
import { QRCode } from "qrdx";

export function ShapedCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      bodyPattern="liquid"
      cornerEyePattern="leaf"
      cornerEyeDotPattern="leaf"
    />
  );
}
```

## ボディパターン [#body-patterns]

`bodyPattern` はデータモジュールの形を指定します。値は {facts.bodyPatterns} 種類あり、デフォルトは `circle` です。

- クラシック: `square`、`small-square`、`horizontal-line`、`vertical-line`、`octagon`
- 丸み系: `circle`、`circle-large`、`rounded`、`liquid`、`liquid-horizontal`、`liquid-vertical`、`random-dots`
- 装飾系: `classy`、`classy-rounded`、`leaf`、`diamond`、`hexagon`
- 遊び心のある形: `mosaic`、`plus`、`star`、`heart`、`pacman`、`circle-mixed`

`liquid`、`classy`、`classy-rounded` は、隣り合うモジュールをつなげて1つのなめらかな輪郭にします。`liquid-horizontal` と `liquid-vertical` は、行または列の方向だけでつなげます。`random-dots` と `mosaic` はモジュールごとに形が変わりますが、同じ値であれば常に同じコードが描画されます。アラインメントパターンは、どのパターンを選んでも常にベタの正方形で描画されるので、デコーダーが見つけられます。

### モジュールのスケール [#module-scale]

`moduleScale`(0.5〜1、デフォルトは 1)は、各データモジュールを中心に向かって縮小し、軽くゆとりのある見た目にします。つながるパターンでは、代わりに線が細くなります。各パターンは、パッケージのテストでデコードできる最小のサイズで縮小が止まります(たとえば `circle` は 0.95、`classy` は 0.7 です。下限値は `MODULE_SCALE_FLOOR` としてエクスポートされています)。アラインメントパターンは元のサイズのままです。

```tsx title="components/light-code.tsx"
import { QRCode } from "qrdx";

export function LightCode() {
  return (
    <QRCode
      value="https://example.com"
      bodyPattern="liquid"
      moduleScale={0.8}
    />
  );
}
```

## アイのフレーム [#eye-frames]

`cornerEyePattern` はコーナーのアイの形を指定します。値は {facts.eyeShapes} 種類あり、デフォルトは `gear` です。`square`、`rounded`、`extra-rounded`、`squircle`、`cushion`、`bevel`、`octagon`、`leaf`、`leaf-reverse`、`drop`、`petal`、`shield`、`gear`、`circle`、`diya`、`message`、`pointy` が使えます。

`leaf`、`leaf-reverse`、`drop`、`petal` は、3つのアイがそれぞれコードの角の方を向くように回転します。`circle` のアイは、一部のスキャナーアプリで読み取れないことがあります。[スキャンスコア](/docs/features/frames#will-it-scan) がこれについて警告します。

## アイの中心 [#eye-centers]

`cornerEyeDotPattern` は各アイの内側のドットの形を指定します。値は {facts.eyeCentres} 種類あり、デフォルトは `circle` です。`square`、`rounded`、`extra-rounded`、`circle`、`squircle`、`octagon`、`hexagon`、`dots`、`leaf`、`leaf-reverse`、`drop`、`drop-reverse`、`plus`、`cross-rounded`、`flower`、`heart`、`message`、`message-reverse`、`diya`、`diya-reverse`、`rounded-triangle` が使えます。

## 避けたい組み合わせと廃止された形 [#pairs-to-avoid-and-retired-shapes]

`diamond` のボディと `square` のアイ、`pacman` と `rounded`、`small-square` と `square` または `rounded` のアイの組み合わせは、近くからでも読み取れないことがあります。Playground ではこれらを組み合わせません。これらは `WEAK_BODY_EYES` として公開されており、`getStylePairRisk(props)` はスキャンスコアに表示される警告を返します。

角が四角いアイ(`square`、`rounded`、`extra-rounded` など大半)の中に `circle` の中心を置くと、画面、PNG エクスポート、大きな印刷物のようにくっきり描画される場合に、厳密なデコーダーでは読み取れないことがあります。ベタのボディ(`square`、`liquid`、`classy`、`classy-rounded`)なら、たいていは読み取れます。`gear`、`circle`、`octagon` のアイには影響がありません。スキャンスコアはこれについて警告し(`style-pair`)、選択自体はできます。この組み合わせは `WEAK_SHARP_DOT_EYES`(および `SHARP_DOT_EYE_SAFE_BODIES`)として公開されています。中心を `rounded` にすれば、この問題は避けられます。

`curly` のアイと、`diamond`、`star`、`banner` の中心は、確実にスキャンできないため廃止されました。これらを使って保存したデザインは引き続き表示されますが、新たに選ぶことも一覧に表示されることもありません。[廃止された形](/docs/styles#retired-shapes) をご覧ください。

## 円形のコード [#circle-codes]

`shape="circle"` は、コードを円盤の中に配置し、残りの部分を同じドット形の装飾モジュールで埋めます。実際のコードの周囲には、`margin` モジュール分(最低 3)の明るい余白が残り、スキャナーは中央のコードだけを読み取ります。円盤はコードより大きいので、同じスキャン距離にするには少し大きめに印刷してください。[印刷サイズ計算ツール](/tools/print-size) は円盤全体を考慮して計算します。

```tsx title="components/circle-code.tsx"
import { QRCode } from "qrdx";

export function CircleCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      shape="circle"
      bodyPattern="rounded"
    />
  );
}
```

パッケージのデコードテストでは、ベタのドット形(`square`、`rounded`、`classy`、`liquid`)の円形コードは、四角いコードと同じように読み取れました。

## ハート型のコード [#heart-codes]

`shape="heart"` は円形のコードと同じように動作し、形がハートになります。実際のコードは、3モジュール以上の明るい余白とともにハートの中央に配置され、ハートの残りは装飾モジュールで埋められます。ハートの中でコードが占める割合は円より小さいため、同じスキャン距離にするには、四角いコードよりも大きくハート型のコードを印刷してください。スキャンスコアもこれを考慮し、同じサイズならハート型のコードは円形のコードよりスコアが低くなります。

```tsx title="components/heart-code.tsx"
import { QRCode } from "qrdx";

export function HeartCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      shape="heart"
      bodyPattern="rounded"
    />
  );
}
```

Playground では、形のあるコードはフレームの代わりになります。形を選ぶとフレームが解除され、フレームを選ぶと形が解除されます。どのフレームもコードの下に明るいプレートを描くため、輪郭が隠れてしまうからです。`shape` と `frame` の両方を渡した場合、エンジンはそのまま `shape` を描画します。パッケージのデコードテストでは、ハート型のコードは、すべてのベタのドット形と、`square`、`rounded`、`gear` のアイで読み取れました。

## カスタムシェイプ [#custom-shapes]

`shape` にはシルエットも指定できます。シルエットは、手持ちの画像からなぞって作る小さなグリッド(1辺が最大 64 セル)です。コードはシェイプの中で最も広い中央部分に配置され、残りは装飾モジュールで埋められます。保存されるのはグリッドだけで、画像は保存されません。

```tsx title="components/silhouette-code.tsx"
import { getQRSilhouetteFit, loadQRSilhouette, QRCode } from "qrdx";

export async function silhouetteFrom(file: File) {
  const shape = await loadQRSilhouette(file); // a PNG, JPEG or SVG, in the browser
  const fit = getQRSilhouetteFit(shape);
  if (!fit.ok) throw new Error(fit.message);
  return shape;
}

export function SilhouetteCode({ shape }: { shape: Awaited<ReturnType<typeof silhouetteFrom>> }) {
  return <QRCode value="https://example.com" size={256} shape={shape} />;
}
```

`loadQRSilhouette` は画像をキャンバスに描画し、その透明度を使います。不透明な画像の場合は暗さを使うので、暗い背景の上の明るい形も使えます。サーバー上では、デコード済みの RGBA ピクセルを `createQRSilhouette` に渡してください。`getQRSilhouetteFit` は、細い星、バー、リングのように、クワイエットゾーンを含めてコードを収めるには細すぎる形を受け付けません。受け付けられなかった形は、四角いコードとして描画されます。

ダッシュボードでは、シルエットはアップロードしたロゴと同様にデザインに紐づいて保存されます。共有リンク、コミュニティのアイテム、コードスニペット、AI チャットでは、代わりに四角いコードが使われます。

## アイごとの色 [#per-eye-colors]

`eyeColor` と `dotColor` は、3つのアイすべてに色を付けます。`eyeColors` を使うと、アイごとに(`topLeft`、`topRight`、`bottomLeft`)上書きできます。それぞれに、`outer`(フレーム)と `inner`(ドット)の色またはグラデーションを指定します。

```tsx title="components/eye-colors-code.tsx"
import { QRCode } from "qrdx";

export function EyeColorsCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      eyeColor="#111827"
      eyeColors={{
        topLeft: { outer: "#dc2626", inner: "#1d4ed8" },
        topRight: { outer: "#16a34a" },
      }}
    />
  );
}
```

すべてのアイは、背景に対して暗い色にしてください。デコーダーは3つのアイを手がかりにコードを見つけます。スキャンスコアは、各アイ自身の色についてコントラストをチェックします。
