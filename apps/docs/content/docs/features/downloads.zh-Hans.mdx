`downloadQRCode(props, options)` 会在浏览器中把 `props` 描述的二维码保存为文件，支持六种格式。与它同系列的函数则返回同一文件的 data URL、Blob 或标记，而 `qrdx/node` 可在服务器上生成 PNG。每个函数接收的 `props` 都与 `QRCode` 相同，因此导出的文件与屏幕上的二维码一致。

想从 Playground 或控制台下载？请参阅帮助中的[下载并打印二维码](/docs/help/getting-started/download-and-print)。

## 下载文件 [#download-a-file]

```ts title="lib/download.ts"
import { downloadQRCode } from "qrdx";

await downloadQRCode(
  {
    value: "https://example.com",
    fgColor: "#1d4ed8",
    bodyPattern: "rounded",
    frame: { style: "banner-bottom", text: "Scan me" },
  },
  {
    format: "png",
    size: { width: 1024, height: 1024 },
    filename: "menu.png",
  }
);
```

<Shot id="lib-download-result" />

浏览器会保存 `menu.png`。`size` 是二维码本身的像素宽度和高度，范围为 50 到 5000，且必须为正方形；如果添加了边框，文件会比这个尺寸更大。`filename` 为可选项：不填时文件名为 `qr-code.<ext>`，光栅格式还会加上确切的像素尺寸（`qr-code-1024x1024.png`，带底部横幅时为 `qr-code-1270x1454.png`）。`quality`（0 到 1）仅适用于 WebP。

props 与 `QRCode` 上的相同，只是 Logo 要放在 `imageSettings` 中。若要导出 `QRCode` 绘制出的二维码（包括它的 `logo` 和 `logoOptions`），请传入 `getQRData(props)` 或 `resolveQRCodeProps(props)`，而不是原始 props。

## 格式 [#formats]

| `format` | 文件 | 说明 |
| --- | --- | --- |
| `png` | 图片 | 保留透明背景。多数场景的默认选择 |
| `jpg` | 图片 | 仅支持纯色背景，文件更小 |
| `webp` | 图片 | 像素与 PNG 相同但文件更小；除非设置了 `quality`，否则为无损 |
| `svg` | 矢量 | 任意尺寸都清晰；适合印刷厂和设计工具 |
| `pdf` | 文档 | 单页，二维码以 PNG 形式嵌入。需要可选的 `jspdf` 包 |
| `eps` | 矢量 | 适用于 Illustrator、CorelDRAW 和 InDesign 的 PostScript。`size.width` 按点（每英寸 72 点）读取 |

### WebP [#webp]

WebP 默认为无损，因此模块边缘保持精确，透明背景也保持透明。如果浏览器的 canvas 能写出无损 WebP（Chrome 和 Edge 可以），则由浏览器生成文件。如果不能，库会检查字节，并用内置的小型无损编码器自行编码像素：Safari 在请求 WebP 时会返回 PNG。无论哪种方式，`.webp` 文件始终是 WebP。

`quality`（0 到 1）会在浏览器支持时改为请求体积更小的有损文件。有损 WebP 会使模块边缘和颜色变得柔和，因此对于需要远距离扫描的二维码，请保留默认设置。`getQRAsWebP` 以 `Blob` 形式返回文件：

```ts title="lib/webp.ts"
import { getQRAsWebP } from "qrdx";

const lossless = await getQRAsWebP({ value: "https://example.com", size: 1024 });
const lossy = await getQRAsWebP({ value: "https://example.com", size: 1024 }, { quality: 0.9 });
```

`canvasToWebP(canvas, options)` 对任意 canvas 执行同样的操作，而 `encodeWebPLossless(rgba, width, height)` 可在没有 DOM 的情况下编码 RGBA 像素。

### PDF [#pdf]

PDF 下载会把二维码作为 PNG 放在同样大小的页面上。它需要可选的 `jspdf` 包（`npm install jspdf`）；没有安装时，PDF 下载会抛出 `PDF export needs the optional "jspdf" package`。如需按物理尺寸生成带出血、裁切标记和 CMYK 的矢量 PDF，请使用 `downloadPrintPDF`；参见[可直接印刷的导出](/docs/features/frames#print-ready-export)。

### EPS [#eps]

EPS 不需要额外的包。`downloadQRCode` 将 `size.width` 按点读取，因此请求 512 px 会写出 512 pt（18 厘米）的文件。若需要精确的物理尺寸，请使用 `getQRAsEPS`，它以字符串形式返回 EPS：二维码宽度为 `sizeMm`（默认 50 毫米），边框会在此基础上增加尺寸。

```ts title="lib/eps.ts"
import { downloadPrintEPS, getQRAsEPS } from "qrdx";

const eps = await getQRAsEPS(
  { value: "https://example.com" },
  { sizeMm: 40, bleedMm: 3, colorMode: "cmyk" }
);

await downloadPrintEPS({ value: "https://example.com" }, { sizeMm: 40, filename: "menu.eps" });
```

EPS 不支持透明度，也没有裁切标记。线性和径向渐变会以平滑的 PostScript Level 3 渐变输出；角向渐变则以一组细楔形输出。半透明颜色会与背景混合，背景再与白纸混合。PNG 和 JPEG 的 Logo 会被嵌入。EPS 无法承载[图片填充](/docs/features/colors-gradients#image-fills)：`getQRAsEPS` 会抛出 `EPS_IMAGE_FILL_REASON`，控制台的下载对话框则改为提供 PDF、SVG 和 PNG。

## Data URL、Blob 与标记 [#data-urls-blobs-and-markup]

```ts title="lib/export.ts"
import { copyQRCodeToClipboard, getQRCodeDataUrl, getSVGString } from "qrdx";

const props = { value: "https://example.com", size: 512 };

// The same file as a data URL, for an <img> or a form field
const png = await getQRCodeDataUrl(props, "png", { width: 512, height: 512 });

// A PNG on the clipboard, for pasting into a document
await copyQRCodeToClipboard(props, { width: 512, height: 512 });

// The SVG markup, for inlining in a page or an email template
const svg = await getSVGString(props);
```

- `getQRCodeDataUrl(props, format, size, { quality })` 支持 `downloadQRCode` 支持的所有格式。
- `copyQRCodeToClipboard` 写入的是 PNG。请在点击处理函数中调用它：浏览器会拒绝在用户操作之外写入剪贴板。
- `getSVGString` 会把 Logo 以 data URL 的形式嵌入，因此标记可独立使用。`qrdx/core` 中的 `toSVGString` 是不含这一步的同步版本。

## 预设尺寸 [#preset-sizes]

```ts title="lib/sizes.ts"
import { PRESET_SIZES, validateSize } from "qrdx";

PRESET_SIZES.small; // { width: 200, height: 200 }
PRESET_SIZES.medium; // 400
PRESET_SIZES.large; // 800
PRESET_SIZES.xlarge; // 1200
PRESET_SIZES["2xl"]; // 1600
PRESET_SIZES["3xl"]; // 2000

validateSize(4000, 4000); // { isValid: true }
validateSize(6000, 6000); // { isValid: false, error: "Size must not exceed 5000x5000 pixels" }
```

请根据文件的用途选择尺寸：网页用 256 到 512 px；按每英寸 300 像素印刷则用 1024 px 或更大（1024 px 在宽约 8.7 厘米以内都能清晰印刷）。若需要精确的印刷尺寸，请使用以毫米和英寸为单位的打印函数。

## 在 Node 中生成 PNG [#png-in-node]

`qrdx/node` 中的 `getQRAsPNG` 无需浏览器即可返回 PNG 字节。它需要在 `qrdx` 旁边安装一个可选的光栅化工具：`@resvg/resvg-js` 会像浏览器一样绘制 SVG（包括 Logo）；`sharp` 也可使用。

```ts title="scripts/make-png.ts"
import { writeFile } from "node:fs/promises";
import { getQRAsPNG } from "qrdx/node";

const png = await getQRAsPNG(
  { value: "https://example.com", bodyPattern: "rounded", margin: 4 },
  { size: 1024 }
);
await writeFile("qr-code.png", png);
```

请从 `qrdx/node` 导入，切勿从 `qrdx` 导入，这样浏览器打包产物就不会引入原生模块。作为 data URL 的 Logo 会原样嵌入；`http(s)` URL 或本地路径只有在设置 `loadExternalLogos: true` 时才会加载，因此转发调用方设置的服务器不会被诱导去请求内部 URL 或读取自己的磁盘。SVG 标记不需要光栅化工具：`qrdx/core` 中的 `toSVGString` 可在任何环境运行。

## 出现问题时 [#if-something-goes-wrong]

- **`Size must be at least 50x50 pixels`、`Size must not exceed 5000x5000 pixels` 或 `Width and height must be equal for QR codes`。** `validateSize` 拒绝了该尺寸。请传入范围内的正方形尺寸。
- **`PDF export needs the optional "jspdf" package`。** 请在与 `qrdx` 相同的包中安装 `jspdf`。
- **文件中缺少 Logo。** 图片来自另一个没有 CORS 头的源，因此浏览器无法复制它。请从你自己的源提供图片，或传入 data URL。
- **`copyQRCodeToClipboard` 被拒绝。** 它在点击或按键处理函数之外运行，或者页面不是通过 HTTPS 提供的。请在处理函数内部调用它。
- **`getQRAsPNG` 抛出缺少光栅化工具的错误。** 请在 `qrdx` 旁边安装 `@resvg/resvg-js` 或 `sharp`。
