La prop `frame` disegna un frame "Scan me" attorno a un codice, `getScanScore` ti dice se un design verrà letto correttamente, e le funzioni di stampa scrivono file vettoriali a una dimensione fisica, con abbondanza e crocini di taglio. Questa pagina tratta i tre argomenti, in questo ordine.

Stai progettando nel Playground o nella dashboard? Vedi [Aggiungere un frame e un invito all'azione](/docs/help/designing/frames), [Controllare un design con lo scan score](/docs/help/designing/scan-score) e [Scaricare e stampare un QR code](/docs/help/getting-started/download-and-print) nella guida.

## Frame con invito all'azione [#call-to-action-frames]

Ogni frame che QRdx disegna è una specifica di frame: una piccola descrizione JSON di forme, etichette e colori. Un unico motore disegna ogni specifica, quindi un frame ha lo stesso aspetto in SVG, PNG, PDF e EPS. Ci sono {facts.frames} frame: {facts.frameStyles} frame integrati e {facts.officialFrames} [frame ufficiali](#official-frames). Puoi anche scriverne uno tuo o sceglierne uno dalla [community](/community/frames).

`frame` funziona su `QRCode`, `QRCodeSVG`, `QRCodeCanvas`, `getQRAsSVG`, `getQRData` e su tutti gli helper di download.

```tsx title="components/menu-frame-code.tsx"
import { QRCode } from "qrdx";

export function MenuFrameCode() {
  return (
    <QRCode
      value="https://example.com/menu"
      size={256}
      frame={{
        style: "banner-bottom",
        text: "Scan for the menu",
        color: "#1e3a8a",
      }}
    />
  );
}
```

Il frame viene aggiunto attorno al codice: l'output diventa più grande, e i moduli e la zona di rispetto non vengono mai coperti, quindi la leggibilità non cambia. Uno spazio chiaro del colore di sfondo del codice separa il codice dal frame.

### Frame integrati [#built-in-frames]

Un frame integrato si identifica con il suo `style`. Le opzioni riempiono le etichette e i colori della sua specifica:

| Opzione | Predefinito | Note |
| --- | --- | --- |
| `style` | nessuno | Uno dei {facts.frameStyles} stili integrati qui sotto, `none`, oppure `custom` con una `spec` |
| `text` | `"Scan me"` | Fino a 24 caratteri. Passa `""` per nascondere l'etichetta |
| `color` | il colore della specifica: nero per ogni frame integrato tranne `gradient-border`, che parte dal viola | Colore del frame |
| `textColor` | bianco sul frame, `color` sulle aree chiare | Colore dell'etichetta |
| `secondaryText` | nessuno | Seconda etichetta, fino a 24 caratteri: la fascia inferiore di `banner-top-bottom`, l'arco inferiore di `circle`, il piè di pagina di `menu-card` |
| `secondaryColor` | l'accento della specifica, rosa | Colore finale di `gradient-border` |
| `fontScale` | `1` | Dimensione dell'etichetta da 0.5 a 1.5; le etichette si riducono comunque per starci |

I frame integrati, per `style`:

- Banner e bordi: `banner-bottom`, `banner-top`, `banner-top-bottom`, `border`, `rounded-border`, `gradient-border`, `focus` (angoli a staffa)
- Fumetti: `speech-bubble`, `speech-bubble-top`, `chat-bubble`
- Badge: `circle` (testo disposto attorno a un anello), `badge` (nastro), `sticker` (fustellato con ombra)
- Oggetti: `polaroid`, `phone`, `ticket`, `tag` (cartellino con foro), `envelope`, `menu-card`

Ognuno di questi nomi corrisponde a una specifica nel motore, e i nomi restano validi per sempre. I design salvati, i link dell'Image API, i flag della CLI e il codice che li usano continuano a disegnare lo stesso frame. I frame che eliminano la riga dell'etichetta quando non c'è etichetta, come i bordi, continuano a farlo. Vedili tutti, decodificati nel tuo browser, in [Forme, occhi e frame](/docs/styles#frames).

`BUILT_IN_FRAMES` li elenca con nomi e specifiche (`BUILT_IN_FRAME_SPECS` contiene le specifiche per stile). `frameSpecOf` restituisce la specifica disegnata da qualsiasi frame, e `getFrameColors` i colori con cui dipinge:

```ts title="lib/frames.ts"
import { BUILT_IN_FRAMES, frameSpecOf, getFrameColors, getFrameDimensions } from "qrdx";

BUILT_IN_FRAMES.map((frame) => frame.name); // ["Banner", "Top banner", "Two banners", …]

// A built-in style's spec, or a custom frame's own
const ticket = frameSpecOf({ style: "ticket" });

// The frame's options, else its spec's defaults
getFrameColors({ style: "border", color: "#1e3a8a" });
// { frame: "#1e3a8a", text: "#1e3a8a", accent: "#1e3a8a" }

// The output size: a 400 px code in a bottom banner
getFrameDimensions(400, { style: "banner-bottom" }); // { width: 496, height: 568 }
```

Per cambiare più delle etichette e dei colori, parti da una specifica integrata per creare un frame personalizzato: `{ style: "custom", spec: frameSpecOf({ style: "ticket" }) }` disegna lo stesso ticket, e puoi modificarne le forme.

Ogni frame è fatto di semplici forme e testo con colori opachi, quindi le esportazioni SVG, PNG, PDF e EPS coincidono. Il bordo sfumato è disegnato con sottili gradini di colore pieno, e le lettere curve del frame circle sono testo ruotato in ogni formato. L'etichetta usa lo stack di font di sistema, quindi non viene scaricato nulla.

`FRAME_STYLES`, `frameSchema` (zod) e i tipi `QRFrame` e `FrameStyle` sono esportati anche da `qrdx/types` per la validazione lato server. La CLI disegna gli stessi frame con `--frame`, `--frame-text`, `--frame-color` e `--frame-text-color`; vedi [CLI](/docs/developers/cli).

### Specifiche di frame [#frame-specs]

Una specifica di frame è un JSON con `kind: "qrdx.frame"`, `version: 1`, una dimensione `artboard`, un riquadro `qr` dove va il codice, `colors` predefiniti, le `shapes` dipinte dietro il codice e le `labels`. Le forme sono rettangoli (con un foro facoltativo), cerchi e anelli, ellissi, poligoni, tracciati, linee e icone integrate. Sono riempite con un token del tema (`frame`, `text`, `accent`, `background`), un colore esadecimale, un mix di due colori o un gradiente. Una specifica non contiene markup, link o immagini. Controlla una specifica che non hai scritto tu con `frameSpecSchema` o `getFrameSpecIssues` da `qrdx/types` prima di salvarla. Il motore la ricontrolla prima di disegnare.

```tsx title="components/custom-frame-code.tsx"
import { QRCode } from "qrdx";
import spec from "./my-frame.json";

export function CustomFrameCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      frame={{ style: "custom", spec, text: "Scan me", color: "#1e3a8a" }}
    />
  );
}
```

Campi facoltativi usati dai frame integrati e dai modelli (le specifiche che non li hanno si disegnano come prima):

| Campo | Cosa fa |
| --- | --- |
| `labels[].collapse` | `{ y, height }`. Quando l'etichetta non mostra testo, la fascia da `y` a `y + height` viene rimossa: le righe sotto salgono e la grafica diventa più corta. Le forme interamente dentro la fascia vengono omesse, e quelle che la attraversano si accorciano. Una fascia non può attraversare il codice, il suo padding o un'altra fascia |
| `qr.plate` | `"opaque"` (predefinito), `"background"` o `"none"`. Il motore dipinge sotto il codice una base del colore di sfondo del codice. Quando quello sfondo è trasparente, `"opaque"` dipinge la base e `background` riempie di bianco, così la grafica non si vede mai attraverso la zona di rispetto. `"background"` li mantiene trasparenti e omette la base; è consentito solo quando sotto la base ci sono soltanto riempimenti `background`, o un anello il cui foro contiene la base. `"none"` non dipinge alcuna base, quindi lo sfondo e il margine del codice sono il suo unico spazio chiaro, e `qr.padding` può essere inferiore al 4%. I modelli lo usano |
| `stroke` | `{ color, width }` su un rettangolo, cerchio, ellisse, poligono o tracciato: un contorno centrato sul bordo della forma, disegnato dopo il riempimento, al massimo il 10% del lato corto dell'artboard |
| `colors.text` | Un colore esadecimale, o un mix di `frame`, `accent`, `background` e colori esadecimali, come `{ "mix": ["frame", "accent"], "amount": 0.5 }` per l'etichetta del bordo sfumato. È il valore predefinito; `textColor` ha comunque la precedenza |

La riga di un'etichetta di testo può anche entrare nel padding della base, purché resti fuori dal codice e le sue maiuscole restino fuori dal padding alla dimensione massima del testo (`fontScale` 1.5). I frame con bordo collocano così la loro etichetta subito sotto il codice.

## Frame ufficiali [#official-frames]

Oltre ai frame integrati, QRdx ha {facts.officialFrames} frame ufficiali: design già pronti per inviti all'azione, ristoranti e caffè, negozi e confezioni, bellezza e benessere, eventi e matrimoni, hotel e viaggi, immobiliare, auto e parcheggi, salute e istruzione, sport e fitness, aziende e social, organizzazioni non profit e gruppi di comunità. {facts.seasonalFrames} sono dedicati a feste e stagioni, dal Capodanno lunare, Holi, Eid e Diwali a Hanukkah, Pasqua, Thanksgiving e Natale. Ognuno è una specifica di frame con etichette e colori che puoi cambiare, rilasciata con licenza CC0, e ognuno è testato per essere letto alle distanze tipiche dello smartphone. Nella [community](/community/frames) sono pubblicati da @qrdx.

```tsx title="components/official-frame-code.tsx"
import { getOfficialFrame, QRCode } from "qrdx";

const diwali = getOfficialFrame("diwali-diya"); // undefined for an unknown id

export function OfficialFrameCode() {
  return diwali ? (
    <QRCode
      value="https://example.com/offers"
      size={256}
      frame={{ style: "custom", spec: diwali.spec, text: "Scan for offers" }}
    />
  ) : null;
}
```

`OFFICIAL_FRAMES` è l'intera libreria, e `OFFICIAL_FRAME_INDEX` elenca ogni frame senza la sua specifica, così un selettore può mostrare la libreria e caricare le specifiche solo quando servono. La libreria è compilata come modulo a sé, quindi un'app che non la importa mai non la include. Nell'[Image API](/docs/developers/image-api#community-items) e nel [server MCP](/docs/developers/mcp), usa un frame ufficiale come elemento della community, ad esempio `item=frame:diwali-diya`.

## Si scansionerà? [#will-it-scan]

`getScanScore` stima quanto una grafica si scansioni in modo affidabile. Gira nel browser e carica jsQR on demand.

```ts title="lib/scan-score.ts"
import { getScanScore } from "qrdx";

const { score, grade, checks } = await getScanScore({
  value: "https://example.com",
  bodyPattern: "circle",
  cornerEyePattern: "gear",
});
// score: 0 to 100, grade: "great" | "ok" | "risky" | "fails"
// checks: [{ id, passed, message, fix? }]
```

Cosa controlla:

- **Decodifica a 96, 160 e 320 px.** La grafica viene renderizzata a ciascuna larghezza, con sfocatura e perdita di contrasto simili a quelle di una fotocamera, e decodificata alcune volte a scale leggermente diverse.
- **Contrasto** tra ogni colore del codice (inclusi i punti del gradiente e i colori di occhi e punti) e lo sfondo, e se il codice è scuro su chiaro.
- **Copertura del logo** rispetto a ciò che il livello di correzione degli errori è in grado di recuperare.
- **Zona di rispetto**: il margine, più lo spazio che aggiunge una cornice.
- **Rischio della forma degli occhi**: gli occhi `circle` possono non essere riconosciuti da alcune app di scansione, e gli occhi `curly`, ormai ritirati, non vengono letti dai decodificatori più rigorosi.
- **Coppie di stili** (`style-pair`): forme che falliscono insieme nei test di decodifica del pacchetto, come i moduli `small-square` accanto a occhi quadrati (vedi `getStylePairRisk`).

`getImageScanScore(fileOrImage)` fa lo stesso per un'immagine esistente: restituisce il contenuto decodificato più i controlli di decodifica, contrasto, polarità, zona di rispetto e risoluzione, misurati dai pixel. Lo [strumento di verifica della scansione](/tools/scan-checker) si basa su di essa. In Node, `scanQRPixels(pixels, expected)` verifica che i pixel RGBA grezzi vengano decodificati in un valore, così come sono e attraverso il modello della fotocamera.

<Callout type="info">
  Il punteggio è un'euristica basata su un solo decodificatore open source. Le app della fotocamera dei telefoni sono spesso più tolleranti, quindi usalo come guida e prova a scansionare le stampe importanti.
</Callout>

## Esportazione pronta per la stampa [#print-ready-export]

`downloadPrintPDF` scrive un PDF vettoriale a una dimensione fisica esatta. Moduli, occhi e cornici sono tracciati vettoriali; un logo resta un'immagine raster.

```ts title="lib/print.ts"
import { downloadPrintPDF, downloadPrintSVG, getPrintLayout } from "qrdx";

const props = { value: "https://example.com", frame: { style: "banner-bottom" } } as const;

await downloadPrintPDF(props, {
  size: 40, // width of the code itself
  unit: "mm", // or "in"
  bleed: 3, // millimeters on every side
  cropMarks: true,
  colorMode: "cmyk",
});

await downloadPrintSVG(props, { size: 1.5, unit: "in" }); // width="…in" height="…in"

const layout = getPrintLayout(props, { size: 40 });
layout.trimWidth; // finished width in mm, frame included
layout.maxScanDistance; // 400 (mm)
```

- `size` è la larghezza del codice, da 5 mm a 2 m; una cornice si aggiunge alla dimensione finale.
- Con `bleed` (fino a 20 mm), lo sfondo o il colore di una cornice quadrata si estende oltre il bordo di taglio, così il taglio non lascia strisce bianche. I segni di taglio si trovano fuori dall'abbondanza.
- `colorMode: "cmyk"` usa una conversione semplice (`rgbToCmyk`: K è 1 meno il valore più alto tra R, G e B, senza profilo ICC; il nero puro viene stampato solo con K). Chiedi al tuo stampatore una conversione con gestione del colore quando i colori esatti del brand sono importanti.
- I gradienti lineari e radiali vengono stampati come sfumature morbide nel PDF, in CMYK quando il PDF è CMYK; l'SVG di stampa li mantiene ma resta in RGB.
- Il testo della cornice nel PDF usa Helvetica Bold, quindi i caratteri fuori da Latin-1 potrebbero non essere visualizzati. Usa l'SVG per altri alfabeti.
- `getQRAsPrintPDF` e `getQRAsPrintPDFBuffer` restituiscono il file invece di scaricarlo e funzionano anche in Node. `getQRAsEPS` scrive lo stesso codice in EPS; vedi [EPS](/docs/features/downloads#eps).

Quanto stampare in grande: un codice si scansiona da una distanza di circa dieci volte la sua larghezza, quindi la larghezza è circa la distanza di scansione divisa per 10 (2 cm di larghezza per 20 cm). I codici più densi richiedono più spazio; il [calcolatore della dimensione di stampa](/tools/print-size) ne tiene conto.
