Di akhir halaman ini, Anda akan memiliki kode QR bergaya di komponen Angular, terikat ke sebuah signal, beserta tombol yang menyimpannya sebagai SVG. `qrdx/angular` adalah komponen standalone, `<qrdx-qr-code>`, yang dibangun di atas engine yang sama dengan komponen React. Komponen ini menerima props dari `<QRCode>` milik React sebagai signal input dan menggambar SVG yang sama. Komponen ini dirender di server dengan `@angular/ssr` dan di-hydrate tanpa error.

## Sebelum memulai [#before-you-start]

- Proyek Angular 20 atau lebih baru, yang dibuat dengan Angular CLI. Build produksi dan `ng serve` sama-sama berfungsi.
- Node.js 18 atau lebih baru.

## Membangunnya [#build-it]

### 1. Instal qrdx [#1-install-qrdx]

```package-install
qrdx
```

`@angular/core` adalah peer dependency opsional dari `qrdx`, sehingga menginstalnya tidak akan menambahkan Angular ke aplikasi yang tidak menggunakannya, dan tidak pernah menambahkan React ke aplikasi Anda.

### 2. Gambar sebuah kode [#2-draw-a-code]

Impor `QRCode` dan tambahkan ke `imports` komponen Anda. NgModule tidak diperlukan.

```ts title="src/app/app.ts"
import { Component, signal } from "@angular/core";
import { QRCode, type QRCodeProps } from "qrdx/angular";

@Component({
  selector: "app-root",
  imports: [QRCode],
  template: `
    <qrdx-qr-code
      [value]="url()"
      [size]="240"
      [margin]="4"
      level="Q"
      bodyPattern="rounded"
      [fgColor]="fgColor"
      [frame]="{ style: 'banner-bottom', text: 'Scan me' }"
      aria-label="QR code for example.com"
    />
  `,
})
export class App {
  protected readonly url = signal("https://example.com");
  protected readonly fgColor: QRCodeProps["fgColor"] = {
    type: "linear",
    angle: 45,
    stops: [
      { color: "#1d4ed8", offset: 0 },
      { color: "#0f172a", offset: 100 },
    ],
  };
}
```

`ng serve` menampilkan kode 240 px dengan modul membulat, gradasi biru ke biru tua, dan banner "Scan me". Atur `url` ke tautan lain dan kode akan digambar ulang. Bila sebuah perubahan menghasilkan markup yang sama, halaman tidak disentuh.

### 3. Simpan sebagai file [#3-save-it-as-a-file]

Komponen ini dapat mengunduh dan mengekspor kode yang digambarnya, seperti `qrdx/vanilla`. Aksesnya melalui template reference variable atau `viewChild(QRCode)`:

```html title="src/app/app.html"
<qrdx-qr-code #qr value="https://example.com" [size]="256" [margin]="4" />
<button type="button" (click)="qr.download({ format: 'svg', filename: 'qr-code.svg' })">
  Download SVG
</button>
```

Mengeklik tombol akan menyimpan `qr-code.svg`.

- `download({ format, size, filename, quality })` menyimpan file: PNG secara default, atau `"jpg"`, `"webp"`, `"svg"`, `"pdf"`, atau `"eps"`. PDF memerlukan paket opsional `jspdf`.
- `toDataURL(format, { size, quality })` mengembalikan kode sebagai data URL.
- `markup()` adalah markup SVG, `options()` adalah props yang digunakan untuk menggambar kode, dan `svg` adalah elemen `<svg>`.

Semua yang ada di `qrdx/core` juga diekspor dari `qrdx/angular`, sehingga `toSVGString`, `downloadQRCode`, `getScanScore`, dan lainnya berasal dari impor yang sama.

## Input [#inputs]

Setiap prop dari `<QRCode>` milik React adalah input dengan nama dan tipe yang sama, dan Angular memeriksa binding Anda terhadapnya saat mengompilasi template. `value` wajib diisi.

| Input | Fungsinya |
| --- | --- |
| `value`, `size`, `level`, `margin`, `autoLevel` | Konten, ukuran piksel, koreksi kesalahan, zona tenang, dan menaikkan level untuk logo besar |
| `fgColor`, `bgColor`, `eyeColor`, `dotColor`, `eyeColors` | Warna, gradasi, dan isian gambar |
| `bodyPattern`, `cornerEyePattern`, `cornerEyeDotPattern`, `moduleScale` | Bentuk titik dan mata |
| `logo`, `logoOptions`, `hideLogo`, `scale` | Logo di tengah, tata letaknya sama seperti pada `<QRCode>` |
| `frame`, `shape`, `art` | Bingkai dengan ajakan bertindak, bentuk lingkaran dan hati, Logo QR, dan Image QR |
| `templateId`, `customTemplate`, `customProps` | Templat |
| `frameLabelMarkers`, `partMarkers` | Penanda untuk pratinjau langsung editor |
| `svgStyle` | Gaya inline untuk `<svg>` (`style` milik `QRCode`) |

`style` dinamai `svgStyle` karena input bernama `style` akan mengambil alih atribut `style` milik elemen itu sendiri. Atribut yang Anda pasang pada `<qrdx-qr-code>`, seperti `class`, `style`, atau `aria-label`, tetap berada pada elemen tersebut; `<svg>` berada di dalamnya.

Gaya milik komponen Anda tidak menjangkau `<svg>`, karena Angular membatasi cakupannya pada elemen di template Anda. Agar kode memenuhi kontainernya, gunakan `svgStyle`:

```html title="src/app/app.html"
<qrdx-qr-code value="https://example.com" [svgStyle]="{ width: '100%', height: 'auto' }" />
```

## Server rendering dan hydration [#server-rendering-and-hydration]

Dengan `@angular/ssr`, HTML dari server sudah memuat kode, sehingga kode tampil sebelum aplikasi dimuat. Di browser, Angular melakukan hydrate pada halaman dan mempertahankan elemen `<qrdx-qr-code>`; komponen kemudian menggambar ulang kodenya, identik dengan yang dari server. Anda tidak memerlukan `ngSkipHydration`.

Output tidak memiliki id acak, sehingga server dan browser menggambar markup yang sama.

## Jika terjadi masalah [#if-something-goes-wrong]

- **`NG8001: 'qrdx-qr-code' is not a known element`.** `QRCode` tidak ada di array `imports` komponen. Tambahkan, seperti pada langkah 2.
- **Aturan CSS untuk `svg` di komponen Anda tidak berpengaruh.** Angular membatasi gaya Anda pada template Anda sendiri. Gunakan input `svgStyle`, atau letakkan aturan itu di stylesheet global.
- **`PDF export needs the optional "jspdf" package`.** Jalankan `npm install jspdf` di aplikasi.
