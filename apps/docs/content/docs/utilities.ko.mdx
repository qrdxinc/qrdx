이 헬퍼들은 렌더러와 스캔 점수가 사용하는 작은 함수로, 직접 만든 UI에서도 쓸 수 있도록 내보내져 있습니다. 대표 색상 고르기, 대비 확인, 다운로드 크기 검증, 캔버스 기능 감지를 할 수 있습니다. 별도로 표시한 경우를 제외하면 어디서나 실행됩니다.

| 함수 | 반환값 | 참고 |
| --- | --- | --- |
| `getSolidColor(color, fallback?)` | `string` | `ColorConfig`를 대표하는 색상 하나입니다. 문자열이면 그 값, 단색이면 `color`, 그라디언트면 첫 번째 색 정지점, 이미지 채우기면 `underlay`, 그 외에는 `fallback`(`"#000000"`)을 반환합니다 |
| `getContrastRatio(a, b)` | `number` | 두 CSS 색상 사이의 WCAG 대비율이며 1에서 21 사이입니다. 투명한 색상은 먼저 흰색 위에 합성합니다. 색상을 파싱할 수 없으면 1을 반환합니다 |
| `getContrastLevel(ratio)` | `{ level, warning, message }` | 7 이상이면 `AAA`, 4.5 이상이면 `AA`, 3 이상이면 `AA Large`(`warning: true` 포함), 3 미만이면 `Fail`입니다 |
| `getLuminance(r, g, b)` | `number` | sRGB 색상의 상대 휘도이며 0에서 1 사이입니다 |
| `hexToRgb(hex)` | `{ r, g, b } \| null` | 3, 4, 6, 8자리 16진수를 읽고 알파는 버립니다. 그 밖의 값은 `null`입니다 |
| `validateSize(width, height)` | `{ isValid, error? }` | 모든 다운로드에 적용되는 규칙으로, 50에서 5000 px 사이의 정사각형이어야 합니다 |
| `SUPPORTS_PATH2D` | `boolean` | 현재 환경의 캔버스가 `addPath`가 있는 `Path2D`를 지원하는지 나타냅니다 |

## 색상 [#colors]

```ts title="lib/colors.ts"
import { getSolidColor, hexToRgb } from "qrdx";

getSolidColor({
  type: "linear",
  angle: 45,
  stops: [
    { color: "#ff6b6b", offset: 0 },
    { color: "#4ecdc4", offset: 100 },
  ],
});
// "#ff6b6b": the first stop

getSolidColor({ type: "image", src: photo, underlay: "#111111" }); // "#111111"
getSolidColor(undefined, "#ffffff"); // "#ffffff"

hexToRgb("#ff6b6b"); // { r: 255, g: 107, b: 107 }
hexToRgb("#f00"); // { r: 255, g: 0, b: 0 }
hexToRgb("red"); // null
```

견본, CSS 배경, 대체 색상처럼 색상 하나가 필요한 곳에는 `getSolidColor`를 사용하세요. 렌더러도 `QRCodeCanvas`나 Canvas 프레임 그리기처럼 형식이 그라디언트를 그릴 수 없는 곳에서 이 함수를 사용합니다.

## 대비 [#contrast]

```ts title="lib/contrast.ts"
import { getContrastLevel, getContrastRatio, getLuminance } from "qrdx";

getContrastRatio("#000000", "#ffffff"); // 21
getContrastRatio("#1d4ed8", "#f8fafc"); // 6.4
getContrastRatio("rgba(29, 78, 216, 0.5)", "#ffffff"); // the blue over white, so lower

getContrastLevel(4.5);
// { level: "AA", warning: false, message: "Good contrast" }

getContrastLevel(2);
// { level: "Fail", warning: true, message: "Poor contrast - QR code may not scan properly" }

getLuminance(255, 255, 255); // 1
```

스캔 점수는 대비율이 4.5 이상(`SCAN_CONTRAST_MIN`)이면 코드를 통과시키고, 그보다 낮으면 점수를 깎으며, 1.5 미만이면 실패로 처리합니다. 이미지는 더 높은 대비가 필요합니다. `SCAN_IMAGE_CONTRAST_MIN`은 모듈 안의 이미지 채우기에는 7, 모듈 뒤의 이미지에는 12입니다. `getScanContrast(props)`는 모든 그라디언트 정지점과 눈 색상을 포함해 디자인 전체에 스캔 점수와 같은 검사를 실행합니다. [프레임, 스캔 점수, 인쇄 파일](/docs/features/frames#will-it-scan)을 참고하세요.

실시간 대비 검사기는 열두 줄 정도면 만들 수 있습니다.

```tsx title="components/contrast-checker.tsx"
"use client";

import { getContrastLevel, getContrastRatio } from "qrdx";
import { useState } from "react";

export function ContrastChecker() {
  const [fgColor, setFgColor] = useState("#000000");
  const [bgColor, setBgColor] = useState("#ffffff");
  const ratio = getContrastRatio(fgColor, bgColor);
  const level = getContrastLevel(ratio);

  return (
    <div>
      <input
        aria-label="Module color"
        type="color"
        value={fgColor}
        onChange={(event) => setFgColor(event.target.value)}
      />
      <input
        aria-label="Background color"
        type="color"
        value={bgColor}
        onChange={(event) => setBgColor(event.target.value)}
      />
      <p>
        {ratio.toFixed(2)}:1, {level.level}. {level.message}
      </p>
    </div>
  );
}
```

## 검증 [#validation]

```ts title="lib/sizes.ts"
import { validateSize } from "qrdx";

validateSize(1024, 1024); // { isValid: true }
validateSize(40, 40); // { isValid: false, error: "Size must be at least 50x50 pixels" }
validateSize(6000, 6000); // { isValid: false, error: "Size must not exceed 5000x5000 pixels" }
validateSize(400, 300); // { isValid: false, error: "Width and height must be equal for QR codes" }
```

`downloadQRCode`, `getQRCodeDataUrl`, `copyQRCodeToClipboard`는 크기 검증에 실패하면 같은 `error` 텍스트를 던지므로, 폼에서 먼저 확인할 수 있습니다.

## 기능 감지 [#feature-detection]

```ts title="lib/features.ts"
import { SUPPORTS_PATH2D } from "qrdx";

if (SUPPORTS_PATH2D) {
  // draw module paths with Path2D
}
```

`SUPPORTS_PATH2D`는 모듈이 로드될 때 한 번 계산되므로 서버에서는 `false`입니다.

## 기타 헬퍼 [#other-helpers]

- `getColorString(color)`와 `normalizeColorConfig(color)`는 `ColorConfig`의 여러 형태를 서로 변환합니다. `isGradient(color)`와 `isImagePaint(color)`는 형태를 구분합니다.
- `sanitizeFrameText(text)`와 `isLatin1Text(text)`는 프레임 라벨 규칙(24자, PDF와 EPS는 Latin-1)을 적용합니다.
- `decodePNGPixels(bytes)`는 DOM 없이 8비트 PNG를 RGBA 픽셀로 읽으며, Node에서 `createQRArtImage`, `createQRSilhouette`, `scanQRPixels`와 함께 사용합니다.
- `rgbToCmyk(color)`는 CMYK 인쇄 파일에 사용되는 변환입니다.
