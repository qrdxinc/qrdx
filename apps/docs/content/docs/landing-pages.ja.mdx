ホスト型ランディングページは、QRdx が `https://qrdx.dev/p/<slug>`（または[カスタムドメイン](/docs/custom-domains)）で配信するモバイルページです。すべてのページに[動的QRコード](/docs/dynamic-qr-codes)が付属するため、コードを印刷した後でもページを編集でき、すべてのスキャンを確認できます。コードのリンク先がまだない場合や、Webサイトよりもスマートフォン向けのページのほうが適している場合に使います。たとえば、メニュー、連絡先カード、リンク集、イベント、商品の詳細などです。

<Callout type="info" title="プラン">
  フリーでは、「Made with QRdx」フッター付きのホスト型ページを3件まで作成できます。Pro ではフッターと件数の上限がなくなり、Business ではホワイトラベルページとカスタム CSS が使えます。各ページは、プランに含まれる動的QRコードを1つ消費します。詳しくは[プランと上限](/docs/plans-and-limits)をご覧ください。
</Callout>

お急ぎの場合は、手順をまとめたページをご覧ください。[モバイルページを作成する](/docs/help/pages-and-forms/create-a-page)、[印刷済みコードの開き先を変更する](/docs/help/dynamic-codes/change-the-type)

## 仕組み [#how-it-works]

<Diagram id="hosted-page-anatomy" />

ページはブロックを積み重ねたものです。ヘッダー、リンク、連絡先カード、メニュー、フォームなどがブロックになります。エディターでブロックを並べて公開すると、QRdx がサーバー上でページを生成します。そのため、スマートフォンでも高速に表示され、自分のサイトは必要ありません。コードの短縮リンクからページが開き、[コードのコントロール](/docs/code-controls)の機能（パスワード、スケジュール、スキャン回数の上限）もすべて使えます。

## ページを作成する [#create-a-page]

1. サイドバーの **Pages & forms** を開いて **New page** をクリックするか、コード一覧の **New code** をクリックして、**Website link** の代わりにページタイプを選びます。
2. {facts.hostedPageTypes} 種類の[ページタイプ](#page-types)から1つ選び、ギャラリーからテンプレートを選びます。
3. **Create page** をクリックします。テンプレートのブロックが入った状態でエディターが開き、ページの QRコードもダウンロードできる状態になります。

<Shot id="page-templates" />

すでにWebサイトを開くコードを印刷している場合は、そのコードを開いて **Change type** をクリックすると、同じ短縮リンクのままページに切り替えられます。

テンプレートには、ページの全体像をつかめるように、サンプルの名前、価格、数値、写真が最初から入っています。初めて公開するまでは、これらを自分の内容に置き換えるようエディターが案内します。

## ページタイプ [#page-types]

どのページタイプも出発点にすぎません。どのブロックもどのページにも追加でき、あるタイプで作ったページを別のタイプのような見た目にすることもできます。

| ページタイプ | 用途 | 最初の構成 |
| --- | --- | --- |
| **Link list** | プロフィール用リンク、クリエイター、ポッドキャスト | プロフィールヘッダー、リンク、SNSアイコン |
| **Social media** | すべてのプロフィールを1つのコードにまとめる | プロフィールヘッダー、ハンドル名を入れたネットワークごとの行 |
| **Business** | 店舗、サロン、オフィス | 営業時間、住所と地図、連絡先、行動を促すボタン |
| **vCard Plus** | デジタル名刺 | **Save contact** 付きの連絡先カード |
| **Menu** | カフェ、レストラン、バー | 食事制限タグとアレルゲン付きのメニュー（[詳細](/docs/forms-and-pages#menu)） |
| **Coupon** | 割引や無料特典 | コード、バーコード、または利用ボタン付きのクーポン（[詳細](/docs/forms-and-pages#coupon)） |
| **Event** | パーティー、カンファレンス、ウェビナー、結婚式 | カレンダーに追加できるイベント（[詳細](/docs/forms-and-pages#event)） |
| **App download** | 1つのコードですべてのアプリストアに対応 | アプリのダウンロード（[詳細](/docs/forms-and-pages#app-download)） |
| **Feedback & forms** | レビュー、NPS調査、登録 | フォーム。フィードバックのテンプレートにはレビューリンクも含まれます（[詳細](/docs/forms-and-pages#forms)） |
| **Product** | パッケージ、ラベル、下げ札 | 原材料、アレルゲン、栄養成分、認証、お手入れ方法、GS1 Digital Link（[詳細](/docs/product-pages)） |
| **Appointments** | サロン、クリニック、家庭教師 | サービスと料金、予約リクエストフォーム、営業時間 |
| **Payments & tips** | チップ、寄付、請求書 | 支払いリンクと、コピーできる銀行口座情報 |
| **Property listing** | 売買・賃貸物件、オープンハウス | 価格と物件情報、写真、担当者、内覧リクエストまたは受付フォーム |
| **Pet ID tag** | 首輪のタグ、迷子ペットのポスター | 電話ボタン、ペットの情報、「見つけました」フォーム |
| **Medical ID** | タグ、リストバンド、アレルギーカード | 緊急連絡先、持病、アレルギー、服用中の薬 |
| **PDF** | パンフレット、マニュアル、資料集 | 閲覧またはダウンロードできる PDF、または複数のファイル |
| **Images** | ギャラリー、ポートフォリオ | フォトギャラリー |
| **MP3 / Audio** | 音楽、ポッドキャスト、ボイスメッセージ | オーディオプレーヤー |
| **Video** | 商品動画、クリップ | 動画 |
| **Playlist** | ミックス、音声ガイド、オーディオブック | 続けて再生される複数のトラック |
| **Custom page** | その他すべて | 空白のページまたはお知らせ |

このデプロイメントではファイルのアップロードが設定されていないため、アップロードを前提とする5つのタイプ（PDF、Images、MP3 / Audio、Video、Playlist）は選択画面に表示されません。ブロックから、他の場所にあるファイルへリンクすることは引き続き可能です。

**Appointments** は、予約リクエストをページの[回答](/docs/forms-and-pages#responses)と通知に送信し、予約ツールへのリンクも設定できます。空き時間をリアルタイムで表示するカレンダーはありません。各リクエストはご自身で確定します。

**Payments & tips** では決済は行いません。各ボタンは、決済アプリ（PayPal、Venmo、Cash App、Revolut、Wise）自身のページを開きます。銀行口座情報、UPI ID、ウォレットアドレスにはコピーボタンがあります。

**Pet ID tag** と **Medical ID** のページは、コードをスキャンした人なら誰でも閲覧できます。ペットを見つけた人や、緊急時にあなたを助ける人の役に立つ情報だけを追加してください。

## 編集と公開 [#edit-and-publish]

エディターには3つのタブとスマートフォンのライブプレビューがあります。プレビュー上のブロックをタップすると、そのブロックの設定に移動します。

- **Blocks**: **Add block** でブロックを追加し、ドラッグ（または矢印ボタン）で並べ替えます。ブロックは削除せずに非表示にしたり、複製や削除をしたりできます。ブロックごとに専用のフォームがあり、問題（たとえば `https://` のないリンク）はブロック上に表示されます。公開する前に修正が必要です。
- **Design**: [保存済みの QRテーマ](/dashboard?to=themes)のいずれかの色を使うと、印刷したコードとページの見た目をそろえられます。プリセットのパレットを選ぶことも、各色を個別に設定することもできます。フォント、角の丸み、単色・グラデーション・画像の背景、任意のロゴを選べます。**Match colors** は、背景色とアクセントカラーから読みやすいテキストとカードの色を自動で決めます。テキストのコントラストが低い場合は警告が表示されます。
- **Settings**: 共有プレビューの説明と画像、**Show in search engines**（初期設定ではオフ）、Business では **Custom CSS** を設定できます。

<Shot id="page-editor" />

**Publish** をクリックする（または <kbd>⌘</kbd>/<kbd>Ctrl</kbd> + <kbd>S</kbd> を押す）と、変更が公開されます。公開するまで、訪問者に表示される内容は変わりません。未公開の編集内容はブラウザーに保存されるので、タブを閉じた後でも復元できます。公開のたびにバージョンとして保存されます。編集中にチームメンバーが同じページを公開した場合、QRdx はその変更を上書きせず、再読み込みを求めます。

## ブロック [#blocks]

| ブロック | 表示内容 |
| --- | --- |
| プロフィールヘッダー | 写真またはロゴ、名前、自己紹介、任意のカバー画像 |
| テキスト | 見出しと段落（改行は保持されます） |
| ボタン | 1つの行動喚起：Webリンク、メールアドレス、電話番号 |
| リンクリスト | リンクボタンを縦に並べたもの。Instagram、YouTube、WhatsAppなどにはサイトのアイコンが付きます |
| ソーシャルアイコン | プロフィールを丸いアイコン、ボタン、またはハンドル名付きのリストで表示 |
| アプリダウンロード | App Store、Google Play、Webサイト。訪問者が使っているストアを先頭に表示します（[詳細](/docs/forms-and-pages#app-download)） |
| 画像 | 写真またはバナー。リンクを設定することもできます |
| 動画 | YouTube、Vimeo、Loomの動画。訪問者が再生をタップして初めて動画サイトから読み込まれます |
| PDF、ギャラリー、音声、動画ファイル、ダウンロード | アップロードまたはリンクしたファイル（[詳細](/docs/files)） |
| 連絡先カード | 名前、役職、電話番号、メールアドレス、Webサイト、住所、クイックアクション（電話、WhatsApp、メール、Webサイト、道順）、**連絡先を保存**、**共有** |
| 住所と地図 | 住所と、Google MapsおよびApple Mapsの道順。埋め込み地図も任意で追加できます |
| 営業時間 | 曜日ごとの時間（分割営業や深夜0時をまたぐ時間を含む）。ブロックに設定したタイムゾーンに従って**営業中**バッジが表示されます |
| Wi-Fi | ネットワーク名とパスワード（コピーボタン付き）（[詳細](/docs/forms-and-pages#menu)） |
| 詳細 | ラベルと値を、リストまたはタイルのグリッドで表示（寝室数、犬種、血液型、内容量など） |
| イベント | 日付、会場、主催者、カレンダーへの追加（[詳細](/docs/forms-and-pages#event)） |
| フォーム、レビューリンク | 回答の受信トレイ付きの質問と、レビューボタン（[詳細](/docs/forms-and-pages#forms)） |
| メニュー、クーポン | 価格付きのセクションと項目、バーコード付きのクーポン（[詳細](/docs/forms-and-pages)） |
| 商品詳細 | 認証、原材料、アレルゲン、栄養成分表、タップで開くセクション、GTIN（[詳細](/docs/product-pages)） |
| 支払いリンク | PayPal、Venmo、Cash App、Revolut、Wise、UPI、銀行振込、暗号資産ウォレット。ボタンで各アプリが開き、詳細情報にはコピーボタンがあります。ページ自体が支払いを受け付けることはありません |
| 区切り線、スペーサー | レイアウト用の補助ブロック |

### vCard Plusと連絡先の保存 [#vcard-plus-and-save-contact]

**連絡先を保存**は、スマートフォンの連絡先アプリで開けるvCard 3.0ファイル（`.vcf`）をダウンロードします。ファイルには、名前、会社名、役職、電話番号、メールアドレス、Webサイト、住所、自己紹介、ページのソーシャルプロフィール、写真が含まれます。QRdxのストレージにアップロードした写真は、1 MB以下であればファイルに埋め込まれます。それより大きい写真や、他のサイトからリンクした写真はリンクとして含まれます。QRdxが他のサイトの画像をダウンロードすることはないためです。**共有**はスマートフォンの共有シートを開き、パソコンではページのリンクをコピーします。このカードをNFCカードにも書き込む場合は、[NFC名刺](/docs/nfc#nfc-business-cards)をご覧ください。

## 訪問者が得られるもの [#what-visitors-get]

- スマートフォン向けに作られた、高速なサーバーレンダリングのページ。ページ上のQRdxのスクリプトは、**ページアクティビティ**カード用に表示数とタップ数を数えるものだけです。プロダクト分析やサポートウィジェットはありません。独自の[トラッキングピクセル](/docs/tracking-and-conversions#tracking-pixels-on-hosted-pages-pro)は、コードに追加した場合にのみ読み込まれます。
- **検索エンジンに表示**をオンにしない限り、検索エンジンには表示されません。
- チャットアプリやソーシャルネットワーク向けの共有プレビュー（タイトル、説明、画像）。パスワードで保護されたコードは、プレビューにページの詳細を表示しません。
- すべてのページに、小さな**不正を報告**リンクが表示されます。ホワイトラベルのページも同様です。

[コードコントロール](/docs/code-controls)のパスワード保護、開始日と終了日、スキャン数の上限、一時停止は、ページとその**連絡先を保存**ファイルにも適用されます。ページのリンクが直接開かれた場合も同様です。

## 制限とプラン [#limits-and-plans]

| | フリー | Pro | Business |
| --- | --- | --- | --- |
| ホスト型ページ | 3 | 無制限 | 無制限 |
| 「Made with QRdx」フッター | 表示 | 非表示 | 非表示 |
| ホワイトラベル（ブラウザアイコンに自分のロゴを使用、QRdxのブランド表示なし） | なし | なし | あり |
| カスタムCSS | なし | なし | あり |

制限が適用されるのは新しいページの作成のみです。すでにあるページは、ダウングレード後を含め、どのプランでも引き続き動作します。Businessからダウングレードした場合、ページのカスタムCSSは適用されなくなり、エディターはそのページの**設定**でCSSを削除するまで再公開を受け付けません。

### カスタムCSS [#custom-css]

Businessでは、**設定** → **カスタムCSS**に通常のCSSを記述できます。ルールはページ内にのみ適用されます。すべてのセレクターはページコンテンツにスコープされ、各ブロックは `.lp-block-<type>` で指定できます（例：`.lp-block-links a`、`.lp-block-contact h1`）。安全のため、CSSからファイルを読み込むこと（`url()`、`@import`、`@font-face`）やバックスラッシュによるエスケープは使えず、使用できるat-ruleは `@media`、`@supports`、`@container`、`@keyframes` のみです。

## 開発者向け [#for-developers]

[REST API](/docs/developers/api/update-code)におけるコードの `kind` は `redirect` または `page` で、`PATCH /v1/codes/{id}` は**タイプを変更**と同じように両者を切り替えます。ページ自体はエディターで作成します。APIでブロックを編集することはできません。
