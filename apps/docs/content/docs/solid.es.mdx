Al final de esta página tendrás un código QR con estilo en un componente de Solid que sigue a un signal, y un botón que lo guarda como PNG. `qrdx/solid` incluye los dos componentes SVG de la biblioteca de React, `QRCodeSVG` y `QRCode`, creados para SolidJS. Dibujan el mismo SVG que los componentes de React, siguen tus signals y se renderizan en un servidor.

<NpmStatus package="qrdx" />

## Antes de empezar [#before-you-start]

- Un proyecto con Solid 1.8 o posterior (de la línea 1.x), con Vite o SolidStart.
- Node.js 18 o posterior.

## Constrúyelo [#build-it]

### 1. Instala qrdx [#1-install-qrdx]

```package-install
qrdx
```

`solid-js` es una dependencia peer opcional de `qrdx`. Tu aplicación ya la tiene, y no necesitas `react`.

### 2. Dibuja un código que siga a un signal [#2-draw-a-code-that-follows-a-signal]

```tsx title="src/components/menu-code.tsx"
import { createSignal } from "solid-js";
import { QRCodeSVG } from "qrdx/solid";

export function MenuCode() {
  const [color, setColor] = createSignal("#0f172a");
  return (
    <>
      <QRCodeSVG
        value="https://example.com/menu"
        size={256}
        margin={4}
        fgColor={color()}
        frame={{ style: "banner-bottom", text: "Scan me" }}
        aria-label="QR code for the menu"
      />
      <button type="button" onClick={() => setColor("#1d4ed8")}>
        Blue
      </button>
    </>
  );
}
```

La página muestra un código oscuro con un banner "Scan me". Haz clic en **Blue** y el código se vuelve a dibujar en azul.

<Shot id="lib-solid-signal-code" />

`QRCodeSVG` acepta todas las opciones que acepta `QRCodeSVG` de React: patrones, colores y degradados, logotipos (`imageSettings`), marcos, formas, plantillas y arte. Los atributos como `class`, `style` o `aria-label` van en el `<svg>`, o en el `<svg>` exterior del marco cuando hay un marco.

`QRCode` añade el atajo de logotipo del `QRCode` de React: `logo`, `logoOptions`, `hideLogo` y `scale`. Solo acepta las props del código y `style`; pon `class` o `aria-label` en un elemento que lo envuelva, o usa `QRCodeSVG`.

```tsx title="src/components/logo-code.tsx"
import { QRCode } from "qrdx/solid";

export function LogoCode() {
  return <QRCode value="https://example.com" size={256} logo="/logo.png" level="H" />;
}
```

Las props son reactivas, como en cualquier componente de Solid. Cuando `color()` cambia, el código se vuelve a dibujar. Los controladores de eventos en las props no se colocan en el `<svg>`, así que ponlos en un elemento que envuelva el código.

### 3. Guárdalo como archivo [#3-save-it-as-a-file]

Los componentes solo dibujan el código. Las descargas, `toSVGString`, la puntuación de escaneo y las demás funciones vienen de `qrdx/core`. Ese es el motor que los componentes ya usan, así que no se incluye dos veces en el paquete.

```tsx title="src/components/downloadable-code.tsx"
import { downloadQRCode } from "qrdx/core";
import { QRCodeSVG } from "qrdx/solid";

const options = { value: "https://example.com", size: 256, margin: 4 };

export function DownloadableCode() {
  return (
    <>
      <QRCodeSVG {...options} />
      <button
        type="button"
        onClick={() =>
          downloadQRCode(options, {
            format: "png",
            size: { width: 1024, height: 1024 },
            filename: "qr-code.png",
          })
        }
      >
        Download PNG
      </button>
    </>
  );
}
```

Al hacer clic en el botón se guarda `qr-code.png` a 1024 px. [JavaScript puro](/docs/vanilla-js) explica `qrdx/core` por completo.

## Cómo dibuja [#how-it-draws]

El paquete no contiene JSX de Solid, por lo que no necesita el compilador de Solid y funciona con cualquier configuración de compilación.

- En el navegador, un componente devuelve el propio elemento `<svg>`, construido con `createElementNS` (no se analiza HTML). Solid lo coloca en la página, lo sustituye por uno nuevo cuando un cambio de prop altera el marcado y lo elimina cuando el componente se desmonta.
- Un cambio de prop que dibuja el mismo marcado no toca la página.

## Renderizado en servidor e hidratación [#server-rendering-and-hydration]

Con `renderToString` de `solid-js/web`, un componente escribe el mismo marcado que `toSVGString` de `qrdx/core`, más la clave de hidratación `data-hk` de Solid en el elemento raíz. `hydrate` usa esa clave para conservar el `<svg>` del servidor en lugar de dibujarlo de nuevo. Dentro de `<NoHydration>`, la clave se omite.

El marcado no tiene ids aleatorios, así que el servidor y el navegador siempre coinciden.

## Si algo sale mal [#if-something-goes-wrong]

- **`Failed to resolve import "react"`.** Importaste desde `qrdx` en lugar de `qrdx/solid`. La entrada principal contiene los componentes de React; cambia la importación.
- **Un controlador de clic en el componente no hace nada.** Los controladores se descartan del `<svg>`. Envuelve el código en un elemento y pon ahí el controlador.
- **`PDF export needs the optional "jspdf" package`.** Ejecuta `npm install jspdf` en la aplicación.
