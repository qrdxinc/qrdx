Qualquer [QR code dinâmico](/docs/dynamic-qr-codes) também pode ir em uma tag NFC. Você grava o link NFC do código em uma tag, adesivo ou cartão, e o celular que encostar nele abre o mesmo destino do QR code. Os toques aparecem na análise do código ao lado das leituras de QR, contados separadamente. Use onde tocar é mais fácil do que fazer a leitura: adesivos de mesa, cartões de visita, prateleiras de produtos. Funciona em todos os planos.

A QRdx não vende, imprime nem envia tags ou cartões. Compre tags em branco de qualquer fornecedor de NFC e grave você mesmo a partir da página do código.

## Como funciona [#how-it-works]

<Diagram id="nfc-link" />

O link NFC de um código é o link curto dele com `?nfc` no final, como `https://qrdx.dev/q/aB3dE5f?nfc`, ou `https://go.example.com/menu?nfc` em um [domínio personalizado](/docs/custom-domains). Ele passa pelo mesmo redirecionamento do link curto, então roteamento inteligente, senhas, agendamentos e limites de leituras valem para os toques também. O final `?nfc` só avisa a análise de que a visita foi um toque. O QR code mantém o próprio link, e os códigos que você já imprimiu funcionam exatamente como antes.

Para encontrar o link, abra o código em [Códigos](/dashboard?to=codes) e escolha **Use with NFC** na aba **Overview** dele.

## Gravar uma tag no Android [#write-a-tag-on-android]

O Chrome no Android consegue gravar tags direto da página NFC do código:

1. Ative o NFC nas configurações do celular.
2. Abra o código no Chrome, escolha **Use with NFC** e toque em **Write to NFC tag**.
3. Segure a tag rente à parte de trás do celular até a página mostrar **Written**.
4. Encoste a tag no celular para testar. Ela abre o link.

Gravar a partir de uma página web exige Web NFC, que só o Chrome no Android tem. No computador, a página NFC mostra um QR code: faça a leitura com o celular Android, entre na conta e grave a tag por lá.

### Bloquear uma tag [#locking-a-tag]

Depois que a tag é gravada, a página oferece bloqueá-la quando o navegador permite. Uma tag bloqueada nunca mais pode ser alterada nem apagada, por ninguém, inclusive você. Por isso, bloqueie só tags que ficam onde estranhos poderiam regravá-las, como um adesivo na mesa de uma cafeteria. A tag guarda o link do código, e não o destino dele, então você ainda pode mudar na QRdx para onde uma tag bloqueada leva.

## Gravar uma tag no iPhone [#write-a-tag-on-iphone]

O Safari não grava tags NFC, então use qualquer app gravador de NFC da App Store:

1. Copie o link NFC da página NFC do código.
2. No app, adicione um registro de URL (alguns apps chamam de Link ou URI) e cole o link.
3. Escolha Write e segure a parte de cima do iPhone contra a tag até o app avisar que terminou.

Para gravar, é preciso um iPhone 7 ou mais recente com iOS 13 ou superior.

## Quais tags comprar [#which-tags-to-buy]

Procure um chip NTAG213, NTAG215 ou NTAG216. Eles vêm como adesivos, cartões, chaveiros e pulseiras.

| Chip | Memória |
| --- | --- |
| NTAG213 | 144 bytes |
| NTAG215 | 504 bytes |
| NTAG216 | 888 bytes |

Um link NFC em qrdx.dev ocupa cerca de 30 bytes, então os três comportam. Links em domínios personalizados longos ou com finais longos ocupam mais; a página NFC mostra quantos bytes o seu precisa e em quais chips ele cabe.

Celulares Android com NFC ativado e iPhone XS ou mais recente abrem o link de uma tag assim que ela encosta no celular, sem precisar de app.

## Cartões de visita NFC [#nfc-business-cards]

Uma [página vCard Plus](/docs/landing-pages#vcard-plus-and-save-contact) é uma página de contato com um botão **Save contact**, e funciona bem como cartão de visita NFC. Para um código que abre uma delas, a aba **Overview** mostra **Put this card on NFC**, e o editor de páginas tem um botão **Put on NFC**. Os dois abrem a mesma página NFC com um guia para cartões.

1. Compre cartões de visita NFC em branco, ou adesivos NFC para cartões que você já tem.
2. Imprima também o QR code do código no cartão. Celulares sem NFC, ou com NFC desativado, fazem a leitura dele.
3. Grave o link NFC em cada cartão a partir da página NFC do código.

Como cada cartão guarda o link do código, editar a página vCard Plus na QRdx atualiza todos os cartões que você já entregou.

## Toques na análise [#taps-in-analytics]

A aba **Analytics** de um código mostra **QR scans and NFC taps** das datas que você escolheu, e os totais acima contam os dois. A página Analytics do workspace e as páginas de análise compartilhadas mostram a mesma divisão. Leituras de antes da existência dos links NFC contam como leituras de QR. Os toques seguem as mesmas regras das leituras: bots e pré-visualizações de links não são contados.

## Limites e planos [#limits-and-plans]

Os links NFC funcionam em todos os planos, para todo código dinâmico. O código em si conta para os códigos ativos do seu plano como qualquer outro.

## Para desenvolvedores [#for-developers]

A REST API retorna o link como `nfcLink` em cada código. A [análise de leituras](/docs/developers/api/get-code-scans) inclui `sources` com as duas contagens e um `source` (`qr` ou `nfc`) em cada leitura listada, a exportação CSV tem uma coluna `source`, e os [webhooks](/docs/webhooks) de `scan.created` também trazem `source`.
