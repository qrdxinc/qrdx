이 페이지를 끝까지 따라 하면 일반 HTML 페이지에 스타일이 적용된 QR 코드를 그리고, 코드에서 업데이트하고, PNG로 저장할 수 있습니다. 번들러를 쓰든 script 태그 하나만 쓰든 가능합니다. `qrdx/vanilla`는 React 컴포넌트가 그리는 것과 같은 엔진이라서 모든 패턴, 색상, 로고, 프레임, 내보내기를 지원하는 동일한 SVG를 그리며, `react`와 `react-dom`을 import하지 않습니다.

<NpmStatus package="qrdx" />

## 시작하기 전에 [#before-you-start]

- 1~3단계에는 번들러(Vite, webpack, Parcel 등)를 쓰는 페이지가 필요합니다. 번들러를 쓰지 않는다면 [4단계](#4-use-it-without-a-bundler)로 건너뛰세요.
- 번들러에는 Node.js 18 이상이 필요합니다.

## 만들어 보기 [#build-it]

### 1. qrdx 설치 [#1-install-qrdx]

```package-install
qrdx
```

`react`와 `react-dom`은 선택적 peer dependency입니다. `qrdx/vanilla`나 `qrdx/core`에는 필요하지 않습니다.

### 2. 요소에 코드 그리기 [#2-draw-a-code-into-an-element]

```html title="index.html"
<div id="qr"></div>
<script type="module" src="/main.js"></script>
```

```js title="main.js"
import { createQRCode } from "qrdx/vanilla";

const qr = createQRCode("#qr", {
  value: "https://example.com/menu",
  size: 256,
  margin: 4,
  bodyPattern: "rounded",
  frame: { style: "banner-bottom", text: "Scan for the menu" },
  "aria-label": "QR code for the menu",
});
```

`#qr` 안에 `<svg>`가 나타납니다. 둥근 모듈로 이루어진 256 px 코드이고, 그 아래에 배너가 있습니다. `createQRCode(element, options)`는 요소 또는 CSS 선택자를 받으며, React `QRCodeSVG`가 받는 모든 옵션(패턴, 색상과 그라데이션, 로고(`imageSettings`), 프레임, 셰이프, 템플릿, 아트)을 지원합니다. `className`, `style`, `aria-label` 같은 속성은 `<svg>`에 적용됩니다. 요소는 `createElementNS`로 만들기 때문에 HTML을 파싱하지 않습니다.

### 3. 업데이트, 내보내기, 제거 [#3-update-export-and-remove-it]

```js title="main.js"
qr.update({ fgColor: "#1d4ed8" }); // redraws the code in place, now blue

qr.toSVGString(); // '<svg xmlns="http://www.w3.org/2000/svg" …'
await qr.toDataURL("png", { size: 1024 }); // "data:image/png;base64,…"
await qr.download({ format: "png", size: 1024, filename: "menu.png" });

qr.destroy(); // removes the <svg>
```

- `update`는 새 옵션을 현재 옵션에 병합하고 다시 그립니다. 옵션을 제거하려면 `undefined`를 전달하세요. 마크업이 바뀌지 않으면 페이지는 건드리지 않습니다.
- `toDataURL`과 `download`는 기본적으로 코드 자체의 `size`로 PNG를 만듭니다. 지원하는 형식은 `png`, `jpg`, `webp`, `svg`, `pdf`, `eps`입니다. 프레임을 쓰면 이미지가 코드보다 커집니다. PDF에는 선택 패키지인 `jspdf`가 필요합니다.
- `qr.svg`는 `<svg>` 요소이고, `qr.options`는 현재 옵션입니다.
- `destroy`는 `<svg>`를 제거합니다. 그 이후에 `update`를 호출하면 오류가 발생합니다.

### 4. 번들러 없이 사용하기 [#4-use-it-without-a-bundler]

```html title="index.html"
<div id="qr"></div>
<script type="module">
  import { createQRCode } from "https://cdn.jsdelivr.net/npm/qrdx/dist/vanilla.browser.mjs";

  createQRCode("#qr", { value: "https://example.com", size: 256, margin: 4 });
</script>
```

`dist/vanilla.browser.mjs`는 같은 API를 ES 모듈 하나로 제공하는 파일입니다. 버전을 고정하려면 URL의 `qrdx` 뒤에 `@`와 버전을 추가하세요. 같은 경로가 unpkg에서도 동작합니다.

이 파일에는 공식 프레임 라이브러리의 데이터가 들어 있지 않아서, 이를 쓰지 않는 페이지는 해당 데이터를 내려받지 않습니다. 공식 프레임을 사용하려면 옆에 있는 파일에서 import하세요.

```js title="index.html"
import { getOfficialFrame } from "https://cdn.jsdelivr.net/npm/qrdx/dist/frames-official.mjs";

const wifi = getOfficialFrame("wifi-card");
qr.update({ frame: { style: "custom", spec: wifi.spec } });
```

PDF 내보내기와 스캔 점수는 실행될 때 `jspdf`와 `jsqr`를 불러옵니다. 이 기능을 쓰는 페이지에서는 모듈 스크립트보다 앞에 둔 import map으로 둘을 매핑하세요.

```html title="index.html"
<script type="importmap">
  {
    "imports": {
      "jspdf": "https://cdn.jsdelivr.net/npm/jspdf@4/+esm",
      "jsqr": "https://cdn.jsdelivr.net/npm/jsqr@1/+esm"
    }
  }
</script>
```

## qrdx/core로 마크업과 DOM 노드 다루기 [#markup-and-dom-nodes-with-qrdxcore]

`qrdx/core`에는 React 컴포넌트를 제외하고 메인 `qrdx` 진입점에 있는 모든 기능이 들어 있습니다. Node와 브라우저 모두에서 동작합니다.

```ts title="code.ts"
import {
  createQRCodeTree,
  renderToDOM,
  renderToString,
  resolveQRCodeProps,
  toSVGElement,
  toSVGString,
} from "qrdx/core";

// What <QRCodeSVG> renders, as a string (no DOM needed)
const svg = toSVGString({ value: "https://example.com", size: 256 });

// The same code as an <svg> element
document.body.append(toSVGElement({ value: "https://example.com" }));

// The code as plain { type, props, key } nodes, then markup or DOM nodes
const tree = createQRCodeTree({ value: "https://example.com" });
renderToString(tree);
renderToDOM(tree);

// <QRCode>'s logo API (logo, logoOptions, hideLogo, scale)
toSVGString(resolveQRCodeProps({ value: "https://example.com", logo: "/logo.png" }));
```

출력에 무작위 id가 없으므로 서버에서 렌더링한 마크업이 브라우저의 마크업과 일치합니다. 다운로드, 스캔 점수, 인쇄용 PDF와 EPS는 React 라이브러리와 같은 함수(`downloadQRCode`, `getQRCodeDataUrl`, `getScanScore`, `downloadPrintPDF` 등)에서 제공됩니다. 서버에서 PNG가 필요하면 `qrdx/node`의 `getQRAsPNG`를 사용하세요.

## JSX 없이 사용자 지정 템플릿 만들기 [#custom-templates-without-jsx]

템플릿의 `wrapper`는 그려진 코드를 받아서 감싼 결과를 반환합니다. `h(type, props, ...children)`를 쓰면 JSX 없이 wrapper를 작성할 수 있습니다.

```js title="labelled-template.js"
import { h, toSVGString } from "qrdx/core";

const Labelled = {
  id: "Labelled",
  name: "Labelled",
  wrapper: (children, props) =>
    h(
      "svg",
      { viewBox: "0 0 300 340", xmlns: "http://www.w3.org/2000/svg" },
      h("g", { transform: "translate(20, 20) scale(0.87)" }, children),
      h("text", { x: "150", y: "325", textAnchor: "middle" }, props?.label)
    ),
};

toSVGString({
  value: "https://example.com",
  customTemplate: Labelled,
  customProps: { label: "Scan me" },
});
```

`h`를 `qrdx`에서 import하면 같은 wrapper를 React 컴포넌트에서도 쓸 수 있습니다.

## 문제가 생겼을 때 [#if-something-goes-wrong]

- **`qrdx: no element matches #qr`.** 요소가 만들어지기 전에 스크립트가 실행되었습니다. `<script type="module">`을 요소 뒤에 두거나 `DOMContentLoaded`를 기다리세요.
- **`qrdx: this QR code was destroyed`.** `destroy` 이후에 `update`를 호출했습니다. `createQRCode`로 새 코드를 만드세요.
- **`PDF export needs the optional "jspdf" package`.** `qrdx`와 함께 `jspdf`를 설치하거나, 번들러가 없는 페이지라면 import map에 추가하세요.
- **코드는 그려졌는데 휴대폰이 읽지 못해요.** `margin: 4`를 추가하고, 밝은 배경 위에 어두운 모듈을 유지하세요. 그리고 `getScanScore`로 디자인을 확인하세요. [QR 코드가 스캔되지 않아요](/docs/help/troubleshooting/wont-scan)를 참고하세요.
