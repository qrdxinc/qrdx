读完本页，你将得到一个 Preact 组件中带样式的二维码，以及一个把它保存为 PNG 的按钮。`qrdx/preact` 提供了 React 库中的两个 SVG 组件 `QRCodeSVG` 和 `QRCode`，并针对 Preact 构建。它们使用 Preact 自带的 `h` 绘制，因此你既不需要 `preact/compat`，也不需要 `react`，而且绘制出的 SVG 与 React 组件完全相同。

<NpmStatus package="qrdx" />

## 开始之前 [#before-you-start]

- 一个 Preact 10 或更高版本的项目，使用 Vite 或任何其他打包工具。
- Node.js 18 或更高版本。

## 动手构建 [#build-it]

### 1. 安装 qrdx [#1-install-qrdx]

```package-install
qrdx
```

`preact` 是 `qrdx` 的可选对等依赖。你的应用中已经有它了。

### 2. 绘制二维码 [#2-draw-a-code]

```tsx title="src/components/menu-code.tsx"
import { QRCodeSVG } from "qrdx/preact";

export function MenuCode() {
  return (
    <QRCodeSVG
      value="https://example.com/menu"
      size={256}
      margin={4}
      bodyPattern="rounded"
      frame={{ style: "banner-bottom", text: "Scan me" }}
      aria-label="QR code for the menu"
    />
  );
}
```

页面会显示一个 256 px 的二维码，模块为圆角，下方有“Scan me”横幅。

<Shot id="lib-preact-code" />

`QRCodeSVG` 支持 React 版 `QRCodeSVG` 的所有选项：图案、颜色与渐变、徽标（`imageSettings`）、边框、形状、模板和艺术样式。`class`、`style` 或 `aria-label` 等属性会加在 `<svg>` 上；如果有边框，则加在边框最外层的 `<svg>` 上。

`QRCode` 增加了 React 版 `QRCode` 的徽标快捷方式：`logo`、`logoOptions`、`hideLogo` 和 `scale`。它只接受二维码的属性和 `style`；请把 `class` 或 `aria-label` 放在它外层的元素上，或者改用 `QRCodeSVG`。

```tsx title="src/components/logo-code.tsx"
import { QRCode } from "qrdx/preact";

export function LogoCode() {
  return <QRCode value="https://example.com" size={256} logo="/logo.png" level="H" />;
}
```

两个组件都会在属性变化时重绘，没有变化时则跳过绘制。与 React 中一样，属性里的事件处理函数不会加到 `<svg>` 上。请把它们放在二维码外层的元素上。

### 3. 保存为文件 [#3-save-it-as-a-file]

这两个组件只负责绘制二维码。下载、`toSVGString`、扫描评分和其他函数来自 `qrdx/core`。组件本来就使用这个引擎，所以不会被重复打包。

```tsx title="src/components/downloadable-code.tsx"
import { downloadQRCode } from "qrdx/core";
import { QRCodeSVG } from "qrdx/preact";

const options = { value: "https://example.com", size: 256, margin: 4 };

export function DownloadableCode() {
  return (
    <>
      <QRCodeSVG {...options} />
      <button
        type="button"
        onClick={() =>
          downloadQRCode(options, {
            format: "png",
            size: { width: 1024, height: 1024 },
            filename: "qr-code.png",
          })
        }
      >
        Download PNG
      </button>
    </>
  );
}
```

点击按钮会以 1024 px 保存 `qr-code.png`。请像上面那样把选项放在同一个对象里，这样文件就会与屏幕上的二维码一致。[原生 JavaScript](/docs/vanilla-js) 完整介绍了 `qrdx/core`。

## 服务器端渲染 [#server-rendering]

`preact-render-to-string` 的 `renderToString` 写出的 SVG 与 `qrdx/core` 的 `toSVGString` 相同。唯一的区别在于转义：Preact 在文本中保留 `>` 和 `'` 的原样，而 core 会写成 `&gt;` 和 `&#x27;`。浏览器对两者的解析结果一致。

`hydrate` 会保留服务器输出的 `<svg>`，不会再次绘制。标记中没有随机 id，因此服务器和浏览器始终保持一致。

## 搭配 preact/compat 使用 [#with-preactcompat]

如果你的应用已经把 `react` 别名指向 `preact/compat`，那么 `qrdx` 中的 React 组件也可以使用：`import { QRCodeSVG } from "qrdx"`。`qrdx/preact` 无需别名即可绘制相同的二维码，因此在 Preact 应用中添加 `qrdx` 时建议优先使用它。

## 如果出现问题 [#if-something-goes-wrong]

- **`Failed to resolve import "react"`。** 在没有 `preact/compat` 的应用中，你从 `qrdx` 而不是 `qrdx/preact` 导入了组件。请修改导入。
- **组件上的点击处理函数不起作用。** 处理函数会从 `<svg>` 上被丢弃。请用 `<button>` 或 `<div>` 包裹二维码，并把处理函数放在那里。
- **`PDF export needs the optional "jspdf" package`。** 请在应用中运行 `npm install jspdf`。
