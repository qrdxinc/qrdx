托管页面可以展示你上传到 QRdx 的文件:PDF 格式的菜单或宣传册、照片图库、音乐或播客,或者视频。上传的文件保存在侧边栏的 **Files**(文件)中,归属于你上传时所在的工作区,每个文件都有一个固定链接,替换文件后该链接依然有效。当文件没有其他存放位置,或者你想在不改动页面的情况下更换下一季的菜单时,可以使用它们。

<Callout type="info" title="套餐">
  免费版每个工作区包含 50 MB 存储空间,单个文件最大 10 MB;Pro 为 5 GB 和 100 MB;Business 为 50 GB 和 250 MB。参见[套餐与限制](/docs/plans-and-limits)。
</Callout>

## 工作原理 [#how-it-works]

<Diagram id="file-delivery" />

你的浏览器会将文件直接上传到存储桶。随后 QRdx 会对文件进行检查(检查大小,以及文件开头的字节是否确实属于该类型的文件),把检查通过的版本复制到该文件专属的位置,并为其生成链接 `https://qrdx.dev/api/files/<id>`。页面和二维码都使用这个链接,因此替换文件不会对它们产生任何影响。

## 可上传的文件 [#what-you-can-upload]

| 类型 | 格式 |
| --- | --- |
| PDF | PDF |
| 图片 | JPEG、PNG、WebP、GIF、AVIF |
| 音频 | MP3、M4A、AAC、Ogg、WAV |
| 视频 | MP4、WebM、MOV |

采用 H.264 视频编码的 MP4 可在所有浏览器中播放。手机拍摄的 MOV 文件通常也能播放,但如果某个浏览器无法播放,请将其转换为 MP4。SVG、HTML、压缩包和办公文档无法上传,这样存储中提供的任何内容都不可能在访客的浏览器中运行代码。

每个上传的文件在使用前都会经过检查:其大小必须与声明的一致,开头的字节必须确实属于该类型的文件(重命名为 `.pdf` 的 HTML 页面会被拒绝)。被拒绝的上传会从存储中删除,并显示为 **Blocked**(已屏蔽)。

## 在页面上使用文件 [#use-files-on-a-page]

有五种区块可以展示文件。每种区块既可以使用上传的文件,也可以使用指向其他位置所托管文件的链接:

- **PDF** 在平板和电脑上以内嵌方式显示上传的文档,并提供 **Open PDF**(在手机上为全屏查看器)和可选的下载按钮。从其他网站链接的 PDF 会显示 **Open PDF** 按钮。
- **Gallery**(图库)以 1 到 3 列的网格展示照片。点按照片可全屏打开;滑动或使用方向键即可浏览。
- **Audio**(音频)播放带封面和播放列表的曲目;一首结束后自动播放下一首。下载按钮为可选项。
- **Video file**(视频文件)播放你上传的 MP4 或 WebM,可选择像 GIF 一样静音循环播放。对于 YouTube、Vimeo 或 Loom,请改用 **Video**(视频)区块:在有人点按播放之前,它不会从视频网站加载任何内容。
- **Downloads**(下载)列出可供人们保存的文件,每个文件都有各自的标签。

**New code**(新建二维码)中的 **PDF**、**Images**、**MP3 / Audio**、**Video** 和 **Playlist** 页面类型会直接为你放好这些区块。

在区块中,选择 **Upload**(上传)可从你的设备添加文件,选择 **From your files**(从我的文件)可重复使用之前上传的文件,也可以粘贴链接。

## 替换或删除文件 [#replace-or-delete-a-file]

在侧边栏打开 **Files**,使用文件旁边的菜单:

- **Copy link**(复制链接)会复制该文件自己的链接(`https://qrdx.dev/api/files/<id>`)。你也可以把它用作动态二维码的目标地址。
- **Replace file…**(替换文件…)会在同一个链接下上传新内容,例如下一季的菜单。使用该文件的页面和二维码会在一分钟内显示新版本。文件只能用同一类型的文件替换(PDF 只能用 PDF 替换)。
- **Delete**(删除)会永久删除该文件。如果仍有页面或二维码在使用它,QRdx 会先列出这些页面或二维码;删除后,这些页面在原来放置文件的位置会显示“File unavailable”。

<Shot id="files-page" />

成员可以替换和删除自己上传的文件;所有者和管理员可以管理工作区中的所有文件。

## 被举报的文件 [#reported-files]

每个托管页面都有一个 **Report abuse**(举报滥用)链接。如果某个文件违反规定,或者版权所有者要求将其移除,QRdx 可以将其屏蔽。被屏蔽的文件会在一分钟内停止在所有页面上以及通过其 QRdx 链接提供服务(页面会显示“File unavailable”),并且它的相同副本(最大 25 MB)无法再次上传。

## 限制与套餐 [#limits-and-plans]

| 套餐 | 每个工作区的存储空间 | 单个文件上限 |
| --- | --- | --- |
| 免费版 | 50 MB | 10 MB |
| Pro | 5 GB | 100 MB |
| Business | 50 GB | 250 MB |

工作区采用其所有者和账单成员中最高的套餐。限制只会阻止新的上传:降级后,或工作区超出存储空间时,你已上传的所有文件仍会继续在使用它们的每个页面上提供服务。删除不再需要的文件(或升级套餐)即可上传新文件。一个始终没有完成的上传会在两小时后不再计入存储空间。

## 面向开发者 [#for-developers]

文件在控制台中上传和管理。在 API 方面,二维码的设计可以通过文件 id 使用已上传的 logo:参见[二维码样式中的 logo](/docs/developers/rest-api#code-logos)。

## 设置存储(自托管) [#set-up-storage-self-hosting]

文件上传使用 [Cloudflare R2](https://developers.cloudflare.com/r2/)。没有它时,文件页面会提示无法上传,上传 API 会返回 `503` 和“Storage not configured on this server.”,选择器中会隐藏这五种上传页面类型,但区块仍然可以使用指向其他位置所托管文件的链接。

1. 在 Cloudflare 控制台中打开 **R2**,创建一个存储桶,例如 `qrdx-files`。
2. 在 **R2** → **Manage API tokens** 下,创建一个对该存储桶拥有 **Object Read & Write** 权限的令牌。
3. 设置以下环境变量并重启:

   ```bash title="apps/app/.env.local"
   R2_ACCOUNT_ID=your-cloudflare-account-id
   R2_ACCESS_KEY_ID=token-access-key-id
   R2_SECRET_ACCESS_KEY=token-secret-access-key
   R2_BUCKET=qrdx-files
   # Optional: serve files from a public bucket URL or custom domain
   R2_PUBLIC_BASE_URL=https://files.example.com
   ```

4. 为存储桶添加 CORS 策略(**Settings** → **CORS policy**)。浏览器会直接上传到 R2,因此存储桶必须接受来自你应用源的、带有 `Content-Type` 标头的 `PUT` 请求:

   ```json title="R2 bucket CORS policy"
   [
     {
       "AllowedOrigins": ["https://qrdx.example.com", "http://localhost:3000"],
       "AllowedMethods": ["PUT", "GET", "HEAD"],
       "AllowedHeaders": ["Content-Type"],
       "ExposeHeaders": ["ETag"],
       "MaxAgeSeconds": 3600
     }
   ]
   ```

   将 `https://qrdx.example.com` 替换为人们打开你的控制台时使用的源(协议和主机,末尾不带斜杠)。只有在你从本地开发服务器上传时,才保留 `http://localhost:3000`。

### 公开文件或预签名链接 [#public-files-or-presigned-links]

访客始终通过 `/api/files/<id>` 打开文件,该地址会重定向到已存储的对象:

- 如果设置了 `R2_PUBLIC_BASE_URL`(连接到存储桶的自定义域名,或其 `r2.dev` URL,Cloudflare 会对后者限速,并建议仅用于测试),就会重定向到该公开 URL。对象键包含随机 id,因此文件无法被列出或猜到。
- 如果没有设置,存储桶保持私有,每次重定向都使用一小时后过期的预签名链接。

无论哪种方式,被替换、删除或屏蔽的文件都会在一分钟内停止通过其 QRdx 链接提供服务。被屏蔽的文件还会立即从其公开 URL 消失:其对象会移动到带有随机部分的 `quarantine/` 键下(保留下来是为了让管理员可以恢复),其 QRdx 链接会返回 `410 Gone`。

浏览器会上传到 `staging/` 键下。上传通过检查后,QRdx 会把检查通过的版本原样复制到该文件自己的键下,因此仍然有效的上传链接无法替换已通过检查的文件。

<Callout type="info" title="清理被放弃的上传">
  一个始终没有完成的上传会在两小时后不再计入存储空间,并在下次有人向该工作区上传时被清理。请为存储桶添加对象生命周期规则(**Settings** → **Object lifecycle rules**),在一天后删除前缀为 `staging/` 的对象,这样被放弃的上传所遗留的内容也会被清除。
</Callout>
