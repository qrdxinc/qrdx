Al terminar esta página tendrás un código QR con estilo dibujado por el elemento `<qrdx-code>` en una página HTML simple, con opciones de objeto definidas desde un script y una exportación a PNG. `qrdx/element` está construido sobre `qrdx/core`, así que dibuja el mismo SVG que el `QRCodeSVG` de React, con todos los estilos, marcos, logos y exportaciones. No necesita ningún framework y funciona en frameworks que renderizan elementos del DOM. Está probado en React 19 y Vue 3.

<NpmStatus package="qrdx" />

## Antes de empezar [#before-you-start]

- Una página a la que puedas añadir un `<script type="module">`. No hace falta un bundler, aunque también puedes usar uno.
- Para la ruta con bundler, Node.js 18 o superior.

## Constrúyelo [#build-it]

### 1. Carga el elemento [#1-load-the-element]

<Tabs items={["From a CDN", "With a bundler"]}>
<Tab value="From a CDN">

```html title="index.html"
<script
  type="module"
  src="https://cdn.jsdelivr.net/npm/qrdx/dist/element-define.browser.mjs"
></script>
```

`dist/element-define.browser.mjs` registra `<qrdx-code>`. Carga `dist/element.browser.mjs`, un módulo ES con el motor incluido. Añade `@` y una versión después de `qrdx` en la URL para fijar una. Las mismas rutas funcionan en unpkg.

</Tab>
<Tab value="With a bundler">

```package-install
qrdx
```

```js title="main.js"
import "qrdx/element/define"; // registers <qrdx-code>
```

Importar `qrdx/element` por sí solo no registra nada. Llama tú mismo a `defineQRdxCode` para elegir el nombre de la etiqueta:

```js title="main.js"
import { defineQRdxCode } from "qrdx/element";

defineQRdxCode(); // <qrdx-code>
defineQRdxCode("brand-qr"); // <brand-qr> as well
```

Es seguro llamarla de nuevo, y en un servidor no hace nada. Lanza un error si otro elemento ya tiene ese nombre.

</Tab>
</Tabs>

### 2. Pon un código en la página [#2-put-a-code-in-the-page]

```html title="index.html"
<qrdx-code
  value="https://example.com/menu"
  size="256"
  margin="4"
  body-pattern="rounded"
  label="QR code for the menu"
></qrdx-code>
```

La página muestra un código de 256 px con módulos redondeados. Edita un atributo en el inspector del navegador y el código se vuelve a dibujar.

<Shot id="lib-element-code" />

### 3. Define opciones de objeto desde un script [#3-set-object-options-from-a-script]

Los degradados, marcos, logos y demás opciones de objeto son propiedades. Defínelas desde un script:

```js title="main.js"
const qr = document.querySelector("qrdx-code");

qr.fgColor = {
  type: "linear",
  angle: 45,
  stops: [
    { color: "#1d4ed8", offset: 0 },
    { color: "#0f172a", offset: 100 },
  ],
};
qr.frame = { style: "banner-bottom", text: "Scan for the menu" };
qr.imageSettings = { src: "/logo.png", width: 40, height: 40, excavate: true };
qr.props = { eyeColor: "#be123c" };
```

El código se vuelve a dibujar una sola vez, con el degradado, el banner, el logo y los ojos rojos. Sin un script, pon las opciones de objeto en el atributo `props` como JSON:

```html title="index.html"
<qrdx-code
  value="https://example.com"
  props='{"frame": {"style": "banner-bottom", "text": "Scan me"}}'
></qrdx-code>
```

### 4. Expórtalo [#4-export-it]

```js title="main.js"
qr.toSVGString(); // '<svg xmlns="http://www.w3.org/2000/svg" …'
await qr.toDataURL("png", { size: 1024 }); // "data:image/png;base64,…"
await qr.download({ format: "png", size: 1024, filename: "menu.png" });
```

`download` guarda `menu.png` a 1024 px. Las exportaciones dibujan el código a partir de `qr.options`, igual que `toSVGString` y `downloadQRCode` de `qrdx/core`, sin el `part`, `role` ni `aria-label` del elemento. `toDataURL` y `download` usan por defecto PNG con el `size` del código. Los formatos son `png`, `jpg`, `webp`, `svg`, `pdf` y `eps`. Sin un valor, lanzan un error (`toSVGString`) o se rechazan.

PDF necesita el paquete opcional `jspdf`. Desde un CDN, asígnalo con un import map colocado antes del script del módulo:

```html title="index.html"
<script type="importmap">
  { "imports": { "jspdf": "https://cdn.jsdelivr.net/npm/jspdf@4/+esm" } }
</script>
```

## Atributos [#attributes]

| Atributo | Qué define |
| --- | --- |
| `value` | El texto o la URL que se codifica. Sin él no se dibuja nada |
| `size` | Ancho y alto en píxeles (un marco se suma a esto) |
| `level` | Corrección de errores: `L`, `M`, `Q` o `H` |
| `fg-color`, `bg-color`, `eye-color`, `dot-color` | Colores sólidos |
| `body-pattern`, `corner-eye-pattern`, `corner-eye-dot-pattern` | Formas de los módulos, los ojos y los puntos de los ojos |
| `margin` | Zona de silencio, en módulos |
| `template-id` | Una plantilla integrada |
| `module-scale` | Tamaño de cada módulo, de 0.5 a 1 |
| `auto-level` | Sube la corrección de errores a `H` cuando un logo lo necesita |
| `shape` | `square`, `circle` o `heart` |
| `label` | Lo que anuncian los lectores de pantalla (por defecto "QR code") |
| `props` | Cualquier otra opción, como JSON |

Los números y niveles que no se pueden leer se ignoran. [Formas, ojos y marcos](/docs/styles) muestra todos los patrones.

## Propiedades [#properties]

Cada atributo es también una propiedad, con el nombre de la opción: `qr.fgColor`, `qr.bodyPattern`, `qr.templateId`. Las opciones que son objetos son solo propiedades: degradados y rellenos de imagen, `frame`, `imageSettings`, `eyeColors`, `art`, `customTemplate` y `customProps`. `props` acepta todas las opciones a la vez.

- Un atributo o una propiedad con nombre tiene prioridad sobre la misma opción en `props`. Entre un atributo y su propiedad, gana el que se haya definido último. Define una propiedad como `undefined` para descartarla.
- Las propiedades no escriben atributos de vuelta.
- Los cambios se agrupan. Por muchos que hagas seguidos, el código se vuelve a dibujar una sola vez, en una microtarea, y solo si su marcado cambió.
- `qr.options` es con lo que se dibuja el código, y `qr.svg` es el `<svg>` dibujado.
- Las propiedades definidas antes de que el elemento esté registrado se recogen cuando se registra.

Un marco oficial viene del archivo que está junto al elemento:

```js title="main.js"
import { getOfficialFrame } from "https://cdn.jsdelivr.net/npm/qrdx/dist/frames-official.mjs";

qr.frame = { style: "custom", spec: getOfficialFrame("wifi-card").spec };
```

## Estilos y accesibilidad [#styling-and-accessibility]

El código se dibuja en un shadow root abierto. El CSS de la página no puede alcanzar sus trazados, así que una regla como `svg path { fill: red }` o `svg { width: 100% }` no puede romper el código. Aplica estilos al `<svg>` desde fuera con `::part(svg)`:

```css title="styles.css"
qrdx-code::part(svg) {
  border-radius: 12px;
}
```

El elemento es `inline-block`. Su `<svg>` mantiene su `size`, pero se reduce para caber en un contenedor más estrecho.

El `<svg>` tiene `role="img"` y un `aria-label` tomado del atributo `label`, o "QR code" si no lo hay. La etiqueta nunca recurre al valor, que puede contener una contraseña de Wi-Fi o datos de contacto.

## Renderizado en servidor [#server-rendering]

`toQRdxCodeHTML(options)` devuelve el marcado del elemento con el código ya dibujado en un shadow root declarativo. Los navegadores muestran el código antes de que se ejecute cualquier script, y el elemento toma el control cuando se registra. Funciona en Node y no necesita DOM.

```js title="server.js"
import { toQRdxCodeHTML } from "qrdx/element";

const html = toQRdxCodeHTML(
  {
    value: "https://example.com",
    size: 256,
    frame: { style: "banner-bottom", text: "Scan me" },
  },
  { label: "Link to example.com" }
);
// <qrdx-code value="https://example.com" size="256" label="Link to example.com"
//   props="{…}"><template shadowrootmode="open">…</template></qrdx-code>
```

Las opciones simples se convierten en atributos y el resto va en `props` como JSON, de modo que el elemento lee las mismas opciones. `customTemplate` no se puede escribir como marcado: defínela como propiedad en el navegador. Pasa `tagName` si registraste otro nombre.

## React 19 [#react-19]

React 19 define un prop como propiedad cuando el elemento la tiene, así que los objetos funcionan como props. Registra el elemento una vez, antes de renderizar:

```tsx title="components/menu-code.tsx"
import "qrdx/element/define";

export function MenuCode({ url }: { url: string }) {
  return (
    <qrdx-code
      value={url}
      size={256}
      body-pattern="rounded"
      frame={{ style: "banner-bottom", text: "Scan me" }}
      label="Menu"
    />
  );
}
```

Para TypeScript, añade el elemento a JSX en un archivo `.d.ts`:

```ts title="qrdx-code.d.ts"
import type { QRdxCodeElement, QRdxCodeJSXProps } from "qrdx/element";

declare module "react" {
  namespace JSX {
    interface IntrinsicElements {
      "qrdx-code": React.DetailedHTMLProps<
        React.HTMLAttributes<QRdxCodeElement>,
        QRdxCodeElement
      > &
        QRdxCodeJSXProps;
    }
  }
}
```

Un `ref` te da el elemento, para `toDataURL` y `download`.

## Vue [#vue]

Indica al compilador de Vue que `qrdx-code` es un elemento personalizado:

```js title="vite.config.js"
import vue from "@vitejs/plugin-vue";
import { defineConfig } from "vite";

export default defineConfig({
  plugins: [
    vue({
      template: {
        compilerOptions: { isCustomElement: (tag) => tag === "qrdx-code" },
      },
    }),
  ],
});
```

Después importa `qrdx/element/define` una vez, en `main.js`, y enlaza opciones en las plantillas. Vue define un enlace como propiedad cuando el elemento la tiene:

```vue title="src/App.vue"
<qrdx-code
  :value="url"
  :size="256"
  body-pattern="rounded"
  :frame="{ style: 'banner-bottom', text: 'Scan me' }"
  label="Menu"
/>
```

## Si algo sale mal [#if-something-goes-wrong]

- **No se dibuja nada.** El elemento no tiene `value`, o el script que lo registra no se ha ejecutado. Revisa el atributo y comprueba que `element-define` se cargue como módulo.
- **Se dispara un evento `qrdx-error`.** No se puede dibujar el código, por ejemplo porque el valor es demasiado largo para un código QR, o porque el atributo `props` no es un objeto JSON. El error está en `event.detail.error`. El elemento elimina el código anterior y registra el error, salvo que un listener llame a `event.preventDefault()`:

  ```js title="main.js"
  qr.addEventListener("qrdx-error", (event) => {
    event.preventDefault();
    showMessage("That text is too long for a QR code.");
  });
  ```

- **`qrdx: <qrdx-code> is already defined by another element`.** Otro script registró el mismo nombre de etiqueta. Pasa otro nombre a `defineQRdxCode`.
- **TypeScript: `Property 'qrdx-code' does not exist on type 'JSX.IntrinsicElements'`.** Añade la declaración de la sección de React 19.
