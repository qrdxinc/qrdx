이 페이지를 끝까지 따라 하면 시그널을 따라 바뀌는 스타일 QR 코드를 Solid 컴포넌트로 만들고, 이를 PNG로 저장하는 버튼까지 갖추게 됩니다. `qrdx/solid`는 React 라이브러리의 SVG 컴포넌트 두 가지인 `QRCodeSVG`와 `QRCode`를 SolidJS용으로 만든 것입니다. React 컴포넌트와 같은 SVG를 그리고, 시그널을 따라가며, 서버에서도 렌더링됩니다.

<NpmStatus package="qrdx" />

## 시작하기 전에 [#before-you-start]

- Solid 1.8 이상(1.x 버전대) 프로젝트와 Vite 또는 SolidStart
- Node.js 18 이상

## 만들어 보기 [#build-it]

### 1. qrdx 설치 [#1-install-qrdx]

```package-install
qrdx
```

`solid-js`는 `qrdx`의 선택적 peer dependency입니다. 앱에 이미 설치되어 있을 것이고, `react`는 필요하지 않습니다.

### 2. 시그널을 따라가는 코드 그리기 [#2-draw-a-code-that-follows-a-signal]

```tsx title="src/components/menu-code.tsx"
import { createSignal } from "solid-js";
import { QRCodeSVG } from "qrdx/solid";

export function MenuCode() {
  const [color, setColor] = createSignal("#0f172a");
  return (
    <>
      <QRCodeSVG
        value="https://example.com/menu"
        size={256}
        margin={4}
        fgColor={color()}
        frame={{ style: "banner-bottom", text: "Scan me" }}
        aria-label="QR code for the menu"
      />
      <button type="button" onClick={() => setColor("#1d4ed8")}>
        Blue
      </button>
    </>
  );
}
```

페이지에 "Scan me" 배너가 달린 어두운 코드가 나타납니다. **Blue**를 클릭하면 코드가 파란색으로 다시 그려집니다.

<Shot id="lib-solid-signal-code" />

`QRCodeSVG`는 React `QRCodeSVG`가 받는 모든 옵션을 받습니다. 패턴, 색상과 그라데이션, 로고(`imageSettings`), 프레임, 모양, 템플릿, 아트가 해당합니다. `class`, `style`, `aria-label` 같은 속성은 `<svg>`에 적용되고, 프레임이 있을 때는 프레임의 바깥쪽 `<svg>`에 적용됩니다.

`QRCode`는 React `QRCode`의 로고 단축 옵션인 `logo`, `logoOptions`, `hideLogo`, `scale`을 추가로 제공합니다. 코드의 props와 `style`만 받으므로, `class`나 `aria-label`은 코드를 감싸는 요소에 지정하거나 `QRCodeSVG`를 사용하세요.

```tsx title="src/components/logo-code.tsx"
import { QRCode } from "qrdx/solid";

export function LogoCode() {
  return <QRCode value="https://example.com" size={256} logo="/logo.png" level="H" />;
}
```

props는 다른 Solid 컴포넌트와 마찬가지로 반응형입니다. `color()`가 바뀌면 코드가 다시 그려집니다. props에 넣은 이벤트 핸들러는 `<svg>`에 연결되지 않으므로, 코드를 감싸는 요소에 지정하세요.

### 3. 파일로 저장하기 [#3-save-it-as-a-file]

컴포넌트는 코드를 그리기만 합니다. 다운로드, `toSVGString`, 스캔 점수 등의 함수는 `qrdx/core`에서 가져옵니다. 컴포넌트가 이미 사용하는 엔진이므로 번들에 두 번 포함되지 않습니다.

```tsx title="src/components/downloadable-code.tsx"
import { downloadQRCode } from "qrdx/core";
import { QRCodeSVG } from "qrdx/solid";

const options = { value: "https://example.com", size: 256, margin: 4 };

export function DownloadableCode() {
  return (
    <>
      <QRCodeSVG {...options} />
      <button
        type="button"
        onClick={() =>
          downloadQRCode(options, {
            format: "png",
            size: { width: 1024, height: 1024 },
            filename: "qr-code.png",
          })
        }
      >
        Download PNG
      </button>
    </>
  );
}
```

버튼을 클릭하면 `qr-code.png`가 1024 px 크기로 저장됩니다. `qrdx/core`는 [Vanilla JavaScript](/docs/vanilla-js)에서 자세히 다룹니다.

## 그리는 방식 [#how-it-draws]

패키지에 Solid JSX가 들어 있지 않아서 Solid 컴파일러가 필요 없고, 어떤 빌드 설정에서도 동작합니다.

- 브라우저에서 컴포넌트는 `createElementNS`로 만든 `<svg>` 요소를 그대로 반환합니다(HTML을 파싱하지 않습니다). Solid가 이를 페이지에 넣고, prop이 바뀌어 마크업이 달라지면 새 요소로 교체하며, 컴포넌트가 언마운트되면 제거합니다.
- prop이 바뀌어도 같은 마크업이 나오면 페이지는 그대로 유지됩니다.

## 서버 렌더링과 하이드레이션 [#server-rendering-and-hydration]

`solid-js/web`의 `renderToString`을 사용하면 컴포넌트는 `qrdx/core`의 `toSVGString`과 같은 마크업을 출력하며, 루트 요소에 Solid의 하이드레이션 키인 `data-hk`가 추가됩니다. `hydrate`는 이 키를 이용해 `<svg>`를 다시 그리지 않고 서버의 것을 그대로 유지합니다. `<NoHydration>` 안에서는 이 키가 빠집니다.

마크업에 임의의 id가 없으므로 서버와 브라우저의 결과가 항상 일치합니다.

## 문제가 생겼을 때 [#if-something-goes-wrong]

- **`Failed to resolve import "react"`.** `qrdx/solid`가 아닌 `qrdx`에서 가져왔습니다. 메인 엔트리에는 React 컴포넌트가 들어 있으니 import를 바꾸세요.
- **컴포넌트에 단 클릭 핸들러가 동작하지 않습니다.** 핸들러는 `<svg>`에서 제외됩니다. 코드를 요소로 감싸고 핸들러는 그 요소에 지정하세요.
- **`PDF export needs the optional "jspdf" package`.** 앱에서 `npm install jspdf`를 실행하세요.
