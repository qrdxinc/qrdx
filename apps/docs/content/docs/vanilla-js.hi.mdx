इस पेज के अंत तक आपके पास एक सादे HTML पेज में बना हुआ स्टाइल्ड QR कोड होगा, जिसे आप अपने कोड से अपडेट करेंगे और PNG के रूप में सेव करेंगे, चाहे bundler के साथ या सिर्फ़ एक script टैग के साथ। `qrdx/vanilla` वही इंजन है जिससे React कंपोनेंट बनाते हैं, इसलिए यह वही SVG बनाता है, हर पैटर्न, रंग, लोगो, फ़्रेम और एक्सपोर्ट के साथ, और यह `react` या `react-dom` को import नहीं करता।

## शुरू करने से पहले [#before-you-start]

- स्टेप 1 से 3 के लिए bundler वाला एक पेज (Vite, webpack, Parcel या कोई भी और)। अगर bundler नहीं है, तो सीधे [स्टेप 4](#4-use-it-without-a-bundler) पर जाएँ।
- bundler के लिए Node.js 18 या उससे नया।

## इसे बनाएँ [#build-it]

### 1. qrdx इंस्टॉल करें [#1-install-qrdx]

```package-install
qrdx
```

`react` और `react-dom` वैकल्पिक peer dependencies हैं। `qrdx/vanilla` या `qrdx/core` के लिए इनकी ज़रूरत नहीं है।

### 2. किसी element में कोड बनाएँ [#2-draw-a-code-into-an-element]

```html title="index.html"
<div id="qr"></div>
<script type="module" src="/main.js"></script>
```

```js title="main.js"
import { createQRCode } from "qrdx/vanilla";

const qr = createQRCode("#qr", {
  value: "https://example.com/menu",
  size: 256,
  margin: 4,
  bodyPattern: "rounded",
  frame: { style: "banner-bottom", text: "Scan for the menu" },
  "aria-label": "QR code for the menu",
});
```

`#qr` के अंदर एक `<svg>` दिखाई देता है: गोल modules वाला 256 px का कोड और उसके नीचे एक बैनर। `createQRCode(element, options)` एक element या CSS selector लेता है, और वे सभी विकल्प लेता है जो React का `QRCodeSVG` लेता है: पैटर्न, रंग और ग्रेडिएंट, लोगो (`imageSettings`), फ़्रेम, आकार, टेम्पलेट और आर्ट। `className`, `style` या `aria-label` जैसे एट्रिब्यूट `<svg>` पर लगते हैं। element `createElementNS` से बनता है, इसलिए कोई HTML पार्स नहीं होता।

### 3. अपडेट करें, एक्सपोर्ट करें और हटाएँ [#3-update-export-and-remove-it]

```js title="main.js"
qr.update({ fgColor: "#1d4ed8" }); // redraws the code in place, now blue

qr.toSVGString(); // '<svg xmlns="http://www.w3.org/2000/svg" …'
await qr.toDataURL("png", { size: 1024 }); // "data:image/png;base64,…"
await qr.download({ format: "png", size: 1024, filename: "menu.png" });

qr.destroy(); // removes the <svg>
```

- `update` नए विकल्पों को मौजूदा विकल्पों में मिलाता है और दोबारा बनाता है। किसी विकल्प को हटाने के लिए `undefined` दें। अगर markup नहीं बदलता, तो पेज को छुआ नहीं जाता।
- `toDataURL` और `download` डिफ़ॉल्ट रूप से कोड के अपने `size` पर PNG देते हैं। फ़ॉर्मैट `png`, `jpg`, `webp`, `svg`, `pdf` और `eps` हैं। फ़्रेम लगाने पर इमेज कोड से बड़ी हो जाती है। PDF के लिए वैकल्पिक `jspdf` पैकेज चाहिए।
- `qr.svg` यही `<svg>` element है और `qr.options` मौजूदा विकल्प हैं।
- `destroy` `<svg>` को हटा देता है। इसके बाद `update` error देता है।

### 4. bundler के बिना इस्तेमाल करें [#4-use-it-without-a-bundler]

```html title="index.html"
<div id="qr"></div>
<script type="module">
  import { createQRCode } from "https://cdn.jsdelivr.net/npm/qrdx/dist/vanilla.browser.mjs";

  createQRCode("#qr", { value: "https://example.com", size: 256, margin: 4 });
</script>
```

`dist/vanilla.browser.mjs` वही API है, एक ES module के रूप में। कोई वर्शन पिन करने के लिए URL में `qrdx` के बाद `@` और वर्शन जोड़ें। यही पाथ unpkg पर भी चलता है।

यह फ़ाइल आधिकारिक फ़्रेम लाइब्रेरी का डेटा शामिल नहीं करती, ताकि जो पेज उसे इस्तेमाल नहीं करते वे उसे डाउनलोड न करें। कोई आधिकारिक फ़्रेम इस्तेमाल करने के लिए, उसे इसके बगल वाली फ़ाइल से import करें:

```js title="index.html"
import { getOfficialFrame } from "https://cdn.jsdelivr.net/npm/qrdx/dist/frames-official.mjs";

const wifi = getOfficialFrame("wifi-card");
qr.update({ frame: { style: "custom", spec: wifi.spec } });
```

PDF एक्सपोर्ट और स्कैन स्कोर चलते समय `jspdf` और `jsqr` लोड करते हैं। जो पेज इन्हें इस्तेमाल करता है, वह दोनों को import map से मैप करता है, जो module script से पहले रखा जाता है:

```html title="index.html"
<script type="importmap">
  {
    "imports": {
      "jspdf": "https://cdn.jsdelivr.net/npm/jspdf@4/+esm",
      "jsqr": "https://cdn.jsdelivr.net/npm/jsqr@1/+esm"
    }
  }
</script>
```

## qrdx/core के साथ markup और DOM नोड [#markup-and-dom-nodes-with-qrdxcore]

`qrdx/core` में वह सब कुछ है जो मुख्य `qrdx` entry में है, सिवाय React कंपोनेंट के। यह Node और ब्राउज़र दोनों में चलता है।

```ts title="code.ts"
import {
  createQRCodeTree,
  renderToDOM,
  renderToString,
  resolveQRCodeProps,
  toSVGElement,
  toSVGString,
} from "qrdx/core";

// What <QRCodeSVG> renders, as a string (no DOM needed)
const svg = toSVGString({ value: "https://example.com", size: 256 });

// The same code as an <svg> element
document.body.append(toSVGElement({ value: "https://example.com" }));

// The code as plain { type, props, key } nodes, then markup or DOM nodes
const tree = createQRCodeTree({ value: "https://example.com" });
renderToString(tree);
renderToDOM(tree);

// <QRCode>'s logo API (logo, logoOptions, hideLogo, scale)
toSVGString(resolveQRCodeProps({ value: "https://example.com", logo: "/logo.png" }));
```

आउटपुट में कोई random id नहीं होता, इसलिए सर्वर पर बना markup ब्राउज़र के markup से मेल खाता है। डाउनलोड, स्कैन स्कोर और प्रिंट-रेडी PDF और EPS उन्हीं फ़ंक्शन से आते हैं जो React लाइब्रेरी में हैं: `downloadQRCode`, `getQRCodeDataUrl`, `getScanScore`, `downloadPrintPDF` और बाकी। सर्वर पर PNG के लिए `qrdx/node` से `getQRAsPNG` इस्तेमाल करें।

## JSX के बिना कस्टम टेम्पलेट [#custom-templates-without-jsx]

टेम्पलेट का `wrapper` बना हुआ कोड लेता है और उसे लपेटकर लौटाता है। `h(type, props, ...children)` JSX के बिना wrapper लिखने देता है:

```js title="labelled-template.js"
import { h, toSVGString } from "qrdx/core";

const Labelled = {
  id: "Labelled",
  name: "Labelled",
  wrapper: (children, props) =>
    h(
      "svg",
      { viewBox: "0 0 300 340", xmlns: "http://www.w3.org/2000/svg" },
      h("g", { transform: "translate(20, 20) scale(0.87)" }, children),
      h("text", { x: "150", y: "325", textAnchor: "middle" }, props?.label)
    ),
};

toSVGString({
  value: "https://example.com",
  customTemplate: Labelled,
  customProps: { label: "Scan me" },
});
```

यही wrapper React कंपोनेंट में भी चलता है, बस `h` को `qrdx` से import करें।

## अगर कुछ गड़बड़ हो जाए [#if-something-goes-wrong]

- **`qrdx: no element matches #qr`.** स्क्रिप्ट element बनने से पहले चल गई। `<script type="module">` को element के बाद रखें, या `DOMContentLoaded` का इंतज़ार करें।
- **`qrdx: this QR code was destroyed`.** आपने `destroy` के बाद `update` कॉल किया। `createQRCode` से नया कोड बनाएँ।
- **`PDF export needs the optional "jspdf" package`.** `qrdx` के साथ `jspdf` इंस्टॉल करें, या bundler के बिना वाले पेज पर इसे import map में जोड़ें।
- **कोड बन गया है लेकिन फ़ोन उसे नहीं पढ़ता।** `margin: 4` जोड़ें, हल्की पृष्ठभूमि पर गहरे modules रखें, और `getScanScore` से डिज़ाइन जाँचें। देखें [कोड स्कैन नहीं हो रहा](/docs/help/troubleshooting/wont-scan)।
