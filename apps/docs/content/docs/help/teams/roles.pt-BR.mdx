title: "Funções da equipe"
description: "O que proprietários, administradores, membros, membros de cobrança e leitores podem fazer em um workspace."
---

Cada membro de um workspace tem uma função: **Proprietário**, **Administrador**, **Membro**, **Cobrança** ou **Leitor**. No seu próprio workspace, você é o proprietário. A função define o que a pessoa pode alterar; todos podem ver os QR codes, as páginas e as análises do workspace.

## O que cada função pode fazer [#what-each-role-can-do]

| | Proprietário | Administrador | Membro | Cobrança | Leitor |
| --- | --- | --- | --- | --- | --- |
| Ver QR codes, páginas, arquivos e análises | Sim | Sim | Sim | Sim | Sim |
| Criar QR codes, páginas, arquivos, pastas, tags e temas; editar os QR codes do workspace; excluir os que a própria pessoa criou | Sim | Sim | Sim | | |
| Criar chaves de API | Sim | Sim | Sim | | |
| Excluir ou alterar o que outros membros criaram | Sim | Sim | | | |
| Convidar e remover pessoas e alterar funções | Sim | Sim | | | |
| Renomear o workspace, alterar sua URL e logo e gerenciar o link de entrada | Sim | Sim | | | |
| Adicionar, verificar e remover domínios personalizados | Sim | Sim | | | |
| Gerenciar webhooks, temas compartilhados e o tema padrão | Sim | Sim | | | |
| Ver e revogar as chaves de API de todos | Sim | Sim | | | |
| [Exigir verificação em duas etapas](/docs/help/teams/require-two-step-verification) e configurar login único (Business) | Sim | Sim | | | |
| Ler o registro de auditoria (Business) | Sim | Sim | | | |
| Fazer upgrade, alterar ou cancelar o plano em que o workspace funciona | Sim | | | Sim | |
| Tornar outros membros proprietários ou membros de cobrança | Sim | | | | |
| Criar e alterar apps OAuth | Sim | | | | |
| Excluir o workspace | Sim | | | | |

Um membro de **Cobrança** gerencia o plano e tem acesso somente leitura em todo o resto. Um **Leitor** vê tudo e não altera nada.

## Quem paga pelo workspace [#who-pays-for-the-workspace]

Um workspace funciona com o melhor plano entre seus proprietários e membros de cobrança. Dar a função de Cobrança a alguém permite que a pessoa pague pelo workspace sem poder alterar os QR codes dele.

## Alterar a função de alguém [#change-someones-role]

Na página **Configurações** → **Equipe**, altere a **Função** ao lado do nome da pessoa. Administradores podem definir as funções de administrador, membro e leitor; só proprietários podem dar ou tirar as funções de proprietário e de cobrança.

Alterar a função de alguém, remover alguém, convidar um administrador e excluir o workspace pedem que você [confirme que é você](/docs/help/privacy-and-security/two-step-verification#confirm-its-you) antes, a menos que você já tenha feito isso nesse navegador nos últimos 10 minutos.

## Transferir um workspace [#hand-over-a-workspace]

Não existe um botão de transferência separado. Torne a nova pessoa um **Proprietário**. Quando houver outro proprietário, você poderá sair do workspace. Seu próprio workspace não pode ser transferido dessa forma: você não pode sair dele.

## Se algo der errado [#if-something-goes-wrong]

### Você não consegue escolher Proprietário ou Cobrança para alguém [#you-cant-pick-owner-or-billing-for-someone]

Só um proprietário pode dar essas funções. Peça a um dos proprietários do workspace.

### Um membro não consegue excluir um QR code [#a-member-cant-delete-a-code]

Membros excluem apenas o que criaram. Um QR code criado por outra pessoa precisa de um administrador ou proprietário.
