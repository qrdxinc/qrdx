워크스페이스의 좌석 수는 소유자와 결제 멤버의 요금제에 따라 정해집니다. 이 페이지에서는 몇 명까지 참여할 수 있는지, 그리고 멤버가 나가거나 제거되는 방법과 워크스페이스를 삭제하는 방법을 설명합니다.

## 제공되는 좌석 수 [#how-many-seats-you-get]

| 요금제 | 좌석 |
| --- | --- |
| 무료 | 1개 (본인) |
| Pro | 소유자 포함 3개 |
| Business | 무제한 |

워크스페이스는 소유자와 결제 멤버 중 가장 높은 요금제를 사용합니다. 멤버가 각자 구독할 필요는 없습니다.

## 대기 중인 초대도 좌석을 사용합니다 [#pending-invitations-use-a-seat]

초대는 수락되거나 취소될 때까지 좌석 하나를 차지합니다. 좌석을 비우려면 **설정** → **팀** 페이지의 **대기 중인 초대**에서 해당 초대를 찾아 **취소**를 클릭하세요.

## 소유자의 요금제가 바뀌면 [#if-the-owners-plan-changes]

이미 워크스페이스에 있는 멤버는 그대로 유지됩니다. 빈 좌석이 생길 때까지 새 초대만 막힙니다.

## 멤버 제거하기 [#remove-someone]

**설정** → **팀** 페이지에서 제거할 멤버 이름 옆의 **제거**를 클릭하고 **멤버 제거**를 클릭한 다음, 요청이 있으면 [본인 확인](/docs/help/privacy-and-security/two-step-verification#confirm-its-you)을 진행하세요. 멤버는 관리자와 소유자만 제거할 수 있으며, 본인의 워크스페이스에서는 누구도 제거할 수 없습니다.

멤버가 만든 코드와 페이지는 워크스페이스에 그대로 남습니다. 멤버가 워크스페이스용으로 만든 API 키는 더 이상 작동하지 않습니다.

## 워크스페이스에서 나가기 [#leave-a-workspace]

워크스페이스의 **설정** → **일반**에서 **워크스페이스 나가기**를 클릭하세요. 해당 워크스페이스의 코드, 페이지, 테마에 더 이상 접근할 수 없게 됩니다. 직접 만든 항목은 워크스페이스에 남으며, 다시 참여하려면 새 초대가 필요합니다.

소유자가 본인뿐이라면 먼저 다른 사람을 소유자로 지정하세요. [팀 역할](/docs/help/teams/roles)을 참고하세요. 본인의 워크스페이스에서는 나갈 수 없습니다.

## 워크스페이스 삭제하기 [#delete-a-workspace]

소유자는 **설정** → **일반**에서 **워크스페이스 삭제**를 클릭할 수 있습니다. 확인하려면 워크스페이스의 URL을 입력하세요. 본인의 워크스페이스는 삭제할 수 없으며, [계정을 삭제](/docs/help/account-and-billing/delete-your-account)할 때 함께 삭제됩니다.

<Shot id="workspace-danger-zone" />

작동이 멈추는 것은 없습니다. 코드, 페이지, 테마, 파일, 도메인은 각각 해당 항목을 만든 멤버의 본인 워크스페이스로 이동하며, 인쇄된 코드도 계속 리디렉션됩니다. 워크스페이스의 멤버와 대기 중인 초대는 제거되고, API 키는 삭제됩니다.

## 문제가 생겼다면 [#if-something-goes-wrong]

### 초대 링크 만들기가 비활성화되어 있어요 [#create-invite-link-is-disabled]

대기 중인 초대를 포함해 모든 좌석이 사용 중입니다. 초대를 취소하거나 멤버를 제거하거나, 소유자 또는 결제 멤버에게 업그레이드를 요청하세요.

### 워크스페이스 나가기가 거부돼요 [#leave-workspace-is-refused]

본인이 유일한 소유자이거나 본인의 워크스페이스입니다. 먼저 다른 멤버를 소유자로 지정하세요. 본인의 워크스페이스에서는 나갈 수 없습니다.
