워크스페이스의 모든 멤버에게는 **Owner**, **Admin**, **Member**, **Billing**, **Viewer** 중 하나의 역할이 있습니다. 내 워크스페이스에서는 내가 소유자입니다. 역할에 따라 변경할 수 있는 범위가 달라지며, 워크스페이스의 코드, 페이지, 분석은 모든 멤버가 볼 수 있습니다.

## 역할별 권한 [#what-each-role-can-do]

| | Owner | Admin | Member | Billing | Viewer |
| --- | --- | --- | --- | --- | --- |
| 코드, 페이지, 파일, 분석 보기 | 예 | 예 | 예 | 예 | 예 |
| 코드, 페이지, 파일, 폴더, 태그, 테마 만들기, 워크스페이스의 코드 편집, 본인이 만든 항목 삭제 | 예 | 예 | 예 | | |
| API 키 만들기 | 예 | 예 | 예 | | |
| 다른 멤버가 만든 항목 삭제 또는 변경 | 예 | 예 | | | |
| 멤버 초대 및 제거, 역할 변경 | 예 | 예 | | | |
| 워크스페이스 이름 변경, URL 및 로고 변경, 참여 링크 관리 | 예 | 예 | | | |
| 사용자 지정 도메인 추가, 인증, 제거 | 예 | 예 | | | |
| 웹훅, 공유 테마, 기본 테마 관리 | 예 | 예 | | | |
| 모든 멤버의 API 키 확인 및 폐기 | 예 | 예 | | | |
| [2단계 인증 필수 설정](/docs/help/teams/require-two-step-verification) 및 싱글 사인온 설정(Business) | 예 | 예 | | | |
| 감사 로그 보기(Business) | 예 | 예 | | | |
| 워크스페이스가 사용하는 요금제 업그레이드, 변경, 취소 | 예 | | | 예 | |
| 다른 멤버를 소유자 또는 결제 담당자로 지정 | 예 | | | | |

| 워크스페이스 삭제 | 예 | | | | |

**Billing** 멤버는 요금제를 관리하며, 그 외의 모든 부분에서는 읽기 전용입니다. **Viewer**는 모든 것을 볼 수 있지만 아무것도 변경할 수 없습니다.

## 워크스페이스 요금은 누가 내나요 [#who-pays-for-the-workspace]

워크스페이스는 소유자와 결제 담당자 중 가장 높은 요금제로 운영됩니다. 누군가에게 Billing 역할을 주면 코드를 변경할 권한 없이 워크스페이스 요금을 결제하게 할 수 있습니다.

## 역할 변경하기 [#change-someones-role]

**Settings** → **Team** 페이지에서 해당 멤버 이름 옆의 **Role**을 변경하세요. 관리자는 Admin, Member, Viewer 역할을 지정할 수 있고, Owner와 Billing 역할은 소유자만 지정하거나 해제할 수 있습니다.

역할 변경, 멤버 제거, 관리자 초대, 워크스페이스 삭제를 하려면 먼저 [본인 확인](/docs/help/privacy-and-security/two-step-verification#confirm-its-you)이 필요합니다. 단, 해당 브라우저에서 최근 10분 이내에 확인했다면 다시 하지 않아도 됩니다.

## 워크스페이스 넘겨주기 [#hand-over-a-workspace]

별도의 이전 버튼은 없습니다. 새 담당자를 **Owner**로 지정하세요. 다른 소유자가 있으면 워크스페이스를 나갈 수 있습니다. 내 개인 워크스페이스는 이 방법으로 넘길 수 없습니다. 개인 워크스페이스는 나갈 수 없기 때문입니다.

## 문제가 생겼을 때 [#if-something-goes-wrong]

### 다른 멤버에게 Owner 또는 Billing 역할을 지정할 수 없어요 [#you-cant-pick-owner-or-billing-for-someone]

이 역할은 소유자만 줄 수 있습니다. 워크스페이스의 소유자에게 요청하세요.

### 멤버가 코드를 삭제할 수 없어요 [#a-member-cant-delete-a-code]

멤버는 본인이 만든 항목만 삭제할 수 있습니다. 다른 사람이 만든 코드는 관리자나 소유자가 삭제해야 합니다.
