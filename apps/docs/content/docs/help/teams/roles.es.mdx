Cada miembro de un espacio de trabajo tiene un rol: **Propietario**, **Administrador**, **Miembro**, **Facturación** o **Lector**. En tu propio espacio de trabajo, eres el propietario. El rol decide qué puede cambiar cada persona; todos pueden ver los códigos, las páginas y las analíticas del espacio de trabajo.

## Qué puede hacer cada rol [#what-each-role-can-do]

| | Propietario | Administrador | Miembro | Facturación | Lector |
| --- | --- | --- | --- | --- | --- |
| Ver códigos, páginas, archivos y analíticas | Sí | Sí | Sí | Sí | Sí |
| Crear códigos, páginas, archivos, carpetas, etiquetas y temas; editar los códigos del espacio de trabajo; eliminar los propios | Sí | Sí | Sí | | |
| Crear claves de API | Sí | Sí | Sí | | |
| Eliminar o cambiar lo que crearon otros miembros | Sí | Sí | | | |
| Invitar y quitar personas, y cambiar roles | Sí | Sí | | | |
| Cambiar el nombre del espacio de trabajo, su URL y su logotipo, y gestionar el enlace para unirse | Sí | Sí | | | |
| Añadir, verificar y quitar dominios personalizados | Sí | Sí | | | |
| Gestionar webhooks, temas compartidos y el tema predeterminado | Sí | Sí | | | |
| Ver y revocar las claves de API de todos | Sí | Sí | | | |
| [Exigir la verificación en dos pasos](/docs/help/teams/require-two-step-verification) y configurar el inicio de sesión único (Business) | Sí | Sí | | | |
| Leer el registro de auditoría (Business) | Sí | Sí | | | |
| Mejorar, cambiar o cancelar el plan en el que funciona el espacio de trabajo | Sí | | | Sí | |
| Convertir a otros miembros en propietarios o miembros de facturación | Sí | | | | |
| Crear y modificar aplicaciones OAuth | Sí | | | | |
| Eliminar el espacio de trabajo | Sí | | | | |

Un miembro de **Facturación** gestiona el plan y es de solo lectura en todo lo demás. Un **Lector** lo ve todo y no cambia nada.

## Quién paga el espacio de trabajo [#who-pays-for-the-workspace]

Un espacio de trabajo funciona con el mejor plan entre sus propietarios y miembros de facturación. Dar a alguien el rol de Facturación le permite pagar el espacio de trabajo sin poder cambiar sus códigos.

## Cambiar el rol de alguien [#change-someones-role]

En la página **Ajustes** → **Equipo**, cambia el **Rol** junto a su nombre. Los administradores pueden asignar los roles de administrador, miembro y lector; solo los propietarios pueden dar o quitar los roles de propietario y de facturación.

Cambiar el rol de alguien, quitar a alguien, invitar a un administrador y eliminar el espacio de trabajo te piden [confirmar que eres tú](/docs/help/privacy-and-security/two-step-verification#confirm-its-you) antes, salvo que ya lo hayas hecho en ese navegador en los últimos 10 minutos.

## Traspasar un espacio de trabajo [#hand-over-a-workspace]

No hay un botón de traspaso aparte. Convierte a la nueva persona en **Propietario**. Cuando haya otro propietario, podrás abandonar el espacio de trabajo. Tu propio espacio de trabajo no se puede traspasar de esta forma: no puedes abandonarlo.

## Si algo sale mal [#if-something-goes-wrong]

### No puedes elegir Propietario o Facturación para alguien [#you-cant-pick-owner-or-billing-for-someone]

Solo un propietario puede dar esos roles. Pídeselo a uno de los propietarios del espacio de trabajo.

### Un miembro no puede eliminar un código [#a-member-cant-delete-a-code]

Los miembros solo eliminan lo que crearon. Un código creado por otra persona requiere un administrador o propietario.
