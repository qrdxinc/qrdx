Setiap anggota ruang kerja memiliki satu peran: **Owner**, **Admin**, **Member**, **Billing**, atau **Viewer**. Di ruang kerja milik Anda sendiri, Anda adalah pemiliknya. Peran menentukan apa yang dapat diubah seseorang; semua orang dapat melihat kode, halaman, dan analitik ruang kerja.

## Apa yang dapat dilakukan setiap peran [#what-each-role-can-do]

| | Owner | Admin | Member | Billing | Viewer |
| --- | --- | --- | --- | --- | --- |
| Melihat kode, halaman, file, dan analitik | Ya | Ya | Ya | Ya | Ya |
| Membuat kode, halaman, file, folder, tag, dan tema; mengedit kode ruang kerja; menghapus milik sendiri | Ya | Ya | Ya | | |
| Membuat kunci API | Ya | Ya | Ya | | |
| Menghapus atau mengubah apa yang dibuat anggota lain | Ya | Ya | | | |
| Mengundang dan menghapus orang, serta mengubah peran | Ya | Ya | | | |
| Mengganti nama ruang kerja, mengubah URL dan logonya, serta mengelola tautan bergabung | Ya | Ya | | | |
| Menambah, memverifikasi, dan menghapus domain kustom | Ya | Ya | | | |
| Mengelola webhook, tema bersama, dan tema default | Ya | Ya | | | |
| Melihat dan mencabut kunci API semua orang | Ya | Ya | | | |
| [Mewajibkan verifikasi dua langkah](/docs/help/teams/require-two-step-verification) dan menyiapkan single sign-on (Business) | Ya | Ya | | | |
| Membaca log audit (Business) | Ya | Ya | | | |
| Upgrade, mengubah, atau membatalkan paket yang digunakan ruang kerja | Ya | | | Ya | |
| Menjadikan anggota lain sebagai pemilik atau anggota penagihan | Ya | | | | |
| Membuat dan mengubah aplikasi OAuth | Ya | | | | |
| Menghapus ruang kerja | Ya | | | | |

Anggota **Billing** mengelola paket dan hanya dapat melihat di semua bagian lainnya. **Viewer** dapat melihat semuanya dan tidak mengubah apa pun.

## Siapa yang membayar ruang kerja [#who-pays-for-the-workspace]

Ruang kerja berjalan dengan paket terbaik di antara para pemilik dan anggota penagihannya. Memberi seseorang peran Billing memungkinkan mereka membayar ruang kerja tanpa dapat mengubah kodenya.

## Mengubah peran seseorang [#change-someones-role]

Di halaman **Settings** → **Team**, ubah **Role** di sebelah nama mereka. Admin dapat menetapkan peran admin, anggota, dan penampil; hanya pemilik yang dapat memberikan atau mencabut peran pemilik dan penagihan.

Mengubah peran seseorang, menghapus seseorang, mengundang admin, dan menghapus ruang kerja meminta Anda untuk [mengonfirmasi bahwa ini Anda](/docs/help/privacy-and-security/two-step-verification#confirm-its-you) terlebih dahulu, kecuali Anda sudah melakukannya di browser tersebut dalam 10 menit terakhir.

## Menyerahkan ruang kerja [#hand-over-a-workspace]

Tidak ada tombol transfer tersendiri. Jadikan orang baru tersebut **Owner**. Setelah ada pemilik lain, Anda dapat keluar dari ruang kerja. Ruang kerja pribadi Anda tidak dapat diserahkan dengan cara ini: Anda tidak dapat keluar darinya.

## Jika terjadi masalah [#if-something-goes-wrong]

### Anda tidak dapat memilih Owner atau Billing untuk seseorang [#you-cant-pick-owner-or-billing-for-someone]

Hanya pemilik yang dapat memberikan peran tersebut. Mintalah bantuan salah satu pemilik ruang kerja.

### Anggota tidak dapat menghapus kode [#a-member-cant-delete-a-code]

Anggota hanya dapat menghapus apa yang mereka buat. Kode buatan orang lain memerlukan admin atau pemilik.
