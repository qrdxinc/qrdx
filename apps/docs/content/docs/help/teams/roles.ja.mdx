ワークスペースの各メンバーには、**オーナー**、**管理者**、**メンバー**、**請求担当**、**閲覧者**のいずれか1つの役割があります。自分のワークスペースでは、あなたがオーナーです。役割によって変更できる内容が決まりますが、ワークスペースのコード、ページ、分析は全員が閲覧できます。

## 役割ごとにできること [#what-each-role-can-do]

| | オーナー | 管理者 | メンバー | 請求担当 | 閲覧者 |
| --- | --- | --- | --- | --- | --- |
| コード、ページ、ファイル、分析を見る | はい | はい | はい | はい | はい |
| コード、ページ、ファイル、フォルダ、タグ、テーマを作成する。ワークスペースのコードを編集する。自分が作成したものを削除する | はい | はい | はい | | |
| API キーを作成する | はい | はい | はい | | |
| 他のメンバーが作成したものを削除または変更する | はい | はい | | | |
| メンバーの招待と削除、役割の変更 | はい | はい | | | |
| ワークスペース名の変更、URL とロゴの変更、参加リンクの管理 | はい | はい | | | |
| カスタムドメインの追加、確認、削除 | はい | はい | | | |
| Webhook、共有テーマ、デフォルトテーマを管理する | はい | はい | | | |
| 全員の API キーを確認して無効にする | はい | はい | | | |
| [2段階認証を必須にする](/docs/help/teams/require-two-step-verification)、シングルサインオンを設定する(Business) | はい | はい | | | |
| 監査ログを読む(Business) | はい | はい | | | |
| ワークスペースのプランをアップグレード、変更、解約する | はい | | | はい | |
| 他のメンバーをオーナーまたは請求担当にする | はい | | | | |
| OAuth アプリを作成、変更する | はい | | | | |
| ワークスペースを削除する | はい | | | | |

**請求担当**のメンバーはプランを管理でき、それ以外はすべて閲覧のみです。**閲覧者**はすべてを見られますが、何も変更できません。

## ワークスペースの料金を支払う人 [#who-pays-for-the-workspace]

ワークスペースは、オーナーと請求担当のうち最も上位のプランで動作します。請求担当の役割を付与すると、コードを変更できないまま、ワークスペースの料金を支払ってもらえます。

## 役割を変更する [#change-someones-role]

**設定** → **チーム**ページで、名前の横にある**役割**を変更します。管理者は管理者、メンバー、閲覧者を設定できます。オーナーと請求担当の役割を付与したり外したりできるのは、オーナーだけです。

役割の変更、メンバーの削除、管理者の招待、ワークスペースの削除を行うときは、先に[本人確認](/docs/help/privacy-and-security/two-step-verification#confirm-its-you)が求められます。ただし、そのブラウザーで過去10分以内に確認済みの場合は求められません。

## ワークスペースを引き継ぐ [#hand-over-a-workspace]

専用の移管ボタンはありません。新しい担当者を**オーナー**にしてください。別のオーナーがいれば、ワークスペースから退出できます。自分のワークスペースはこの方法では引き継げません。退出できないためです。

## うまくいかない場合 [#if-something-goes-wrong]

### 他のユーザーにオーナーや請求担当を選べない [#you-cant-pick-owner-or-billing-for-someone]

これらの役割を付与できるのはオーナーだけです。ワークスペースのオーナーに依頼してください。

### メンバーがコードを削除できない [#a-member-cant-delete-a-code]

メンバーが削除できるのは、自分が作成したものだけです。他のユーザーが作成したコードの削除には、管理者またはオーナーが必要です。
