---

소유자와 관리자는 워크스페이스의 모든 구성원이 [2단계 인증](/docs/help/privacy-and-security/two-step-verification)을 사용하도록 요구할 수 있습니다. 2단계 인증을 켜지 않은 구성원은 켤 때까지 워크스페이스를 열 수 없으므로, 누군가의 이메일에 접근하는 것만으로는 워크스페이스에 들어갈 수 없습니다.

<Callout type="info">
  2단계 인증 필수 설정은 **Business** 플랜에 포함된 기능입니다. 워크스페이스의 소유자 또는 결제 구성원 중 한 명이 Business를 사용 중이면 해당 워크스페이스에서 이 기능을 쓸 수 있습니다. [좌석 및 워크스페이스 한도](/docs/help/teams/seats)를 참고하세요.
</Callout>

## 켜기 [#turn-it-on]

### 1. 먼저 내 계정에서 켜기 [#1-turn-it-on-for-yourself-first]

**설정** → **프로필 및 보안**에서 내 계정의 2단계 인증을 켜세요. 내 계정에 2단계 인증이 없으면 필수로 설정할 수 없습니다.

### 2. 팀 페이지 열기 [#2-open-the-team-page]

워크스페이스에서 **설정** → **팀**으로 이동하세요.

### 3. 필수로 설정하기 [#3-require-it]

**2단계 인증** 아래에서 **2단계 인증 필수**를 켜세요. 아직 2단계 인증을 켜지 않은 구성원이 있으면 QRdx가 몇 명인지 알려 주고, 진행하기 전에 확인을 요청해요.

<Shot id="require-two-step" />

### 4. 본인 확인하기 [#4-confirm-its-you]

[본인 확인](/docs/help/privacy-and-security/two-step-verification#confirm-its-you)을 진행하세요. 그러면 카드에 "2단계 인증이 필수로 설정되었어요"라고 표시돼요.

소유자와 관리자만 변경할 수 있으며, 켜거나 끌 때는 본인 확인을 해야 합니다. 이메일은 발송되지 않습니다. 2단계 인증을 켜지 않은 구성원은 다음에 워크스페이스를 열 때 알게 됩니다.

## 누가 켰는지 확인하기 [#see-who-has-it-on]

**설정** → **팀** 페이지에서 소유자와 관리자는 각 구성원의 2단계 인증이 **켜짐**인지 **꺼짐**인지 볼 수 있어요. 휴대폰에서는 각 사람의 이메일 주소 아래에 표시됩니다.

## 2단계 인증을 켜지 않은 구성원에게 보이는 화면 [#what-members-without-it-see]

워크스페이스를 열면 2단계 인증이 필요하다는 안내와 함께 **2단계 인증 켜기** 버튼이 보여요. 이 버튼을 누르면 **설정** → **프로필 및 보안**으로 이동하고, 2단계 인증을 켠 뒤 **돌아가기**를 누르면 원래 보던 페이지로 돌아갑니다.

그때까지는 해당 워크스페이스의 내용을 보거나 변경할 수 없습니다. 다른 워크스페이스는 평소처럼 사용할 수 있어요.

워크스페이스에서 해당 구성원에게 보내는 알림도 마찬가지입니다. 이 워크스페이스의 이메일 알림, 주간 요약, Slack 또는 Discord 알림이 중단되고 새로 추가할 수도 없습니다. 워크스페이스 데이터를 다른 도구로 보내도록 설정한 동기화도 일시 중지됩니다. 알림은 2단계 인증을 켜면 다시 시작되지만, 일시 중지된 동기화는 직접 다시 켜야 합니다.

나중에 누군가 2단계 인증을 끄면, 다시 켤 때까지 워크스페이스가 다시 닫힙니다. 소유자와 관리자도 마찬가지입니다.

## API 키 [#api-keys]

워크스페이스에서 만든 API 키는 2단계 인증 여부와 관계없이 만든 사람에게 계속 작동합니다. 2단계 인증은 로그인을 보호하고, 키는 그 자체로 별도의 자격 증명이기 때문입니다. 워크스페이스를 열 수 없는 사람은 새 키를 만들 수 없으며, 소유자와 관리자는 워크스페이스의 **설정** → **API 키 및 앱**에서 모든 구성원의 키를 보고 폐기할 수 있습니다.

OAuth로 누군가의 계정에 연결된 앱은 그 사람의 개인 워크스페이스에서만 작동하므로, 팀 워크스페이스에는 접근하지 못합니다.

## 워크스페이스가 Business에서 벗어나는 경우 [#if-the-workspace-leaves-business]

필수 설정이 적용되지 않으며, 설정은 꺼짐으로 표시됩니다. 워크스페이스가 다시 Business로 돌아오면 다시 적용돼요.

## 끄기 [#turn-it-off]

**설정** → **팀** 페이지에서 **2단계 인증 필수**를 끄고 본인 확인을 하세요. 2단계 인증이 없는 구성원도 바로 워크스페이스를 다시 열 수 있습니다.

## 문제가 생겼을 때 [#if-something-goes-wrong]

### 스위치가 비활성화되어 있어요 [#the-switch-is-disabled]

내 계정에 아직 2단계 인증이 켜져 있지 않거나, 워크스페이스가 Business가 아닌 경우입니다. 어느 쪽인지 카드에 표시돼요.

### 구성원이 접속하지 못하고 2단계 인증도 켤 수 없어요 [#a-member-is-locked-out-and-cant-turn-it-on]

구성원은 워크스페이스가 필요 없는 본인의 **설정** → **프로필 및 보안**에서 켤 수 있습니다. 휴대폰과 백업 코드를 모두 잃어버렸다면 [휴대폰과 백업 코드를 모두 잃어버린 경우](/docs/help/privacy-and-security/two-step-verification#lost-your-phone-and-your-backup-codes)를 참고하세요.
