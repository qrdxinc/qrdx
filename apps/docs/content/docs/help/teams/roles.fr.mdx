description: "Ce que les propriétaires, administrateurs, membres, membres facturation et lecteurs peuvent faire dans un espace de travail."

Chaque membre d'un espace de travail a un seul rôle : **Propriétaire**, **Administrateur**, **Membre**, **Facturation** ou **Lecteur**. Dans votre propre espace de travail, vous êtes le propriétaire. Le rôle détermine ce que chacun peut modifier ; tout le monde peut voir les codes, les pages et les statistiques de l'espace de travail.

## Ce que chaque rôle peut faire [#what-each-role-can-do]

| | Propriétaire | Administrateur | Membre | Facturation | Lecteur |
| --- | --- | --- | --- | --- | --- |
| Voir les codes, les pages, les fichiers et les statistiques | Oui | Oui | Oui | Oui | Oui |
| Créer des codes, des pages, des fichiers, des dossiers, des tags et des thèmes ; modifier les codes de l'espace de travail ; supprimer les siens | Oui | Oui | Oui | | |
| Créer des clés API | Oui | Oui | Oui | | |
| Supprimer ou modifier ce que d'autres membres ont créé | Oui | Oui | | | |
| Inviter et retirer des personnes, et changer les rôles | Oui | Oui | | | |
| Renommer l'espace de travail, changer son URL et son logo, et gérer le lien d'invitation | Oui | Oui | | | |
| Ajouter, vérifier et supprimer des domaines personnalisés | Oui | Oui | | | |
| Gérer les webhooks, les thèmes partagés et le thème par défaut | Oui | Oui | | | |
| Voir et révoquer les clés API de tous les membres | Oui | Oui | | | |
| [Exiger la vérification en deux étapes](/docs/help/teams/require-two-step-verification) et configurer l'authentification unique (Business) | Oui | Oui | | | |
| Consulter le journal d'audit (Business) | Oui | Oui | | | |
| Passer à une offre supérieure, modifier ou résilier l'offre sur laquelle fonctionne l'espace de travail | Oui | | | Oui | |
| Nommer d'autres membres propriétaires ou membres facturation | Oui | | | | |
| Créer et modifier des applications OAuth | Oui | | | | |
| Supprimer l'espace de travail | Oui | | | | |

Un membre **Facturation** gère l'offre et dispose d'un accès en lecture seule partout ailleurs. Un **Lecteur** voit tout et ne modifie rien.

## Qui paie pour l'espace de travail [#who-pays-for-the-workspace]

Un espace de travail fonctionne avec la meilleure offre parmi celles de ses propriétaires et de ses membres facturation. Attribuer le rôle Facturation à quelqu'un lui permet de payer pour l'espace de travail sans pouvoir modifier ses codes.

## Changer le rôle d'un membre [#change-someones-role]

Sur la page **Paramètres** → **Équipe**, modifiez le **Rôle** à côté de son nom. Les administrateurs peuvent attribuer les rôles administrateur, membre et lecteur ; seuls les propriétaires peuvent donner ou retirer les rôles de propriétaire et de facturation.

Pour changer le rôle d'un membre, retirer quelqu'un, inviter un administrateur ou supprimer l'espace de travail, vous devez d'abord [confirmer que c'est bien vous](/docs/help/privacy-and-security/two-step-verification#confirm-its-you), sauf si vous l'avez déjà fait dans ce navigateur au cours des 10 dernières minutes.

## Transférer un espace de travail [#hand-over-a-workspace]

Il n'existe pas de bouton de transfert distinct. Nommez la nouvelle personne **Propriétaire**. Dès qu'il y a un autre propriétaire, vous pouvez quitter l'espace de travail. Votre propre espace de travail ne peut pas être transféré de cette façon : vous ne pouvez pas le quitter.

## En cas de problème [#if-something-goes-wrong]

### Vous ne pouvez pas choisir Propriétaire ou Facturation pour un membre [#you-cant-pick-owner-or-billing-for-someone]

Seul un propriétaire peut attribuer ces rôles. Demandez à l'un des propriétaires de l'espace de travail.

### Un membre ne peut pas supprimer un code [#a-member-cant-delete-a-code]

Les membres ne suppriment que ce qu'ils ont créé. Pour un code créé par quelqu'un d'autre, il faut un administrateur ou un propriétaire.
