Ogni membro di un workspace ha un solo ruolo: **Proprietario**, **Amministratore**, **Membro**, **Fatturazione** oppure **Osservatore**. Nel tuo workspace personale sei il proprietario. Il ruolo decide cosa una persona può modificare; tutti possono vedere i codici, le pagine e le statistiche del workspace.

## Cosa può fare ogni ruolo [#what-each-role-can-do]

| | Proprietario | Amministratore | Membro | Fatturazione | Osservatore |
| --- | --- | --- | --- | --- | --- |
| Vedere codici, pagine, file e statistiche | Sì | Sì | Sì | Sì | Sì |
| Creare codici, pagine, file, cartelle, tag e temi; modificare i codici del workspace; eliminare i propri | Sì | Sì | Sì | | |
| Creare chiavi API | Sì | Sì | Sì | | |
| Eliminare o modificare ciò che hanno creato altri membri | Sì | Sì | | | |
| Invitare e rimuovere persone e cambiare i ruoli | Sì | Sì | | | |
| Rinominare il workspace, cambiarne l'URL e il logo e gestire il link di invito | Sì | Sì | | | |
| Aggiungere, verificare e rimuovere domini personalizzati | Sì | Sì | | | |
| Gestire webhook, temi condivisi e il tema predefinito | Sì | Sì | | | |
| Vedere e revocare le chiavi API di tutti | Sì | Sì | | | |
| [Richiedere la verifica in due passaggi](/docs/help/teams/require-two-step-verification) e configurare il single sign-on (Business) | Sì | Sì | | | |
| Leggere il registro di audit (Business) | Sì | Sì | | | |
| Passare a un piano superiore, cambiare o annullare il piano su cui funziona il workspace | Sì | | | Sì | |
| Rendere altri membri proprietari o membri con ruolo Fatturazione | Sì | | | | |
| Creare e modificare app OAuth | Sì | | | | |
| Eliminare il workspace | Sì | | | | |

Un membro con ruolo **Fatturazione** gestisce il piano ed è in sola lettura per tutto il resto. Un **Osservatore** vede tutto e non modifica nulla.

## Chi paga per il workspace [#who-pays-for-the-workspace]

Un workspace usa il piano migliore tra quelli dei suoi proprietari e dei membri con ruolo Fatturazione. Dare a qualcuno il ruolo Fatturazione gli permette di pagare per il workspace senza poterne modificare i codici.

## Cambiare il ruolo di una persona [#change-someones-role]

Nella pagina **Impostazioni** → **Team**, cambia il **Ruolo** accanto al nome della persona. Gli amministratori possono assegnare i ruoli amministratore, membro e osservatore; solo i proprietari possono assegnare o togliere i ruoli proprietario e fatturazione.

Cambiare il ruolo di una persona, rimuovere qualcuno, invitare un amministratore ed eliminare il workspace richiedono prima di [confermare la tua identità](/docs/help/privacy-and-security/two-step-verification#confirm-its-you), a meno che tu non l'abbia già fatto in quel browser negli ultimi 10 minuti.

## Passare un workspace a un'altra persona [#hand-over-a-workspace]

Non esiste un pulsante di trasferimento separato. Rendi la nuova persona **Proprietario**. Quando c'è un altro proprietario, puoi lasciare il workspace. Il tuo workspace personale non può essere ceduto in questo modo: non puoi lasciarlo.

## Se qualcosa non funziona [#if-something-goes-wrong]

### Non puoi scegliere Proprietario o Fatturazione per una persona [#you-cant-pick-owner-or-billing-for-someone]

Solo un proprietario può assegnare questi ruoli. Chiedi a uno dei proprietari del workspace.

### Un membro non riesce a eliminare un codice [#a-member-cant-delete-a-code]

I membri eliminano solo ciò che hanno creato. Per un codice creato da qualcun altro serve un amministratore o un proprietario.
