---
title: "团队角色"
description: "所有者、管理员、成员、账单成员和查看者在工作区中各自可以执行的操作。"
---

工作区中的每位成员都有一个角色：**所有者**、**管理员**、**成员**、**账单**或**查看者**。在你自己的工作区中，你就是所有者。角色决定一个人可以更改哪些内容；所有人都可以查看工作区的二维码、页面和分析数据。

## 各角色可执行的操作 [#what-each-role-can-do]

| | 所有者 | 管理员 | 成员 | 账单 | 查看者 |
| --- | --- | --- | --- | --- | --- |
| 查看二维码、页面、文件和分析数据 | 是 | 是 | 是 | 是 | 是 |
| 创建二维码、页面、文件、文件夹、标签和主题；编辑工作区的二维码；删除自己创建的内容 | 是 | 是 | 是 | | |
| 创建 API 密钥 | 是 | 是 | 是 | | |
| 删除或修改其他成员创建的内容 | 是 | 是 | | | |
| 邀请和移除成员，以及更改角色 | 是 | 是 | | | |
| 重命名工作区、更改其 URL 和徽标，以及管理加入链接 | 是 | 是 | | | |
| 添加、验证和移除自定义域名 | 是 | 是 | | | |
| 管理 webhook、共享主题和默认主题 | 是 | 是 | | | |
| 查看并撤销所有人的 API 密钥 | 是 | 是 | | | |
| [要求两步验证](/docs/help/teams/require-two-step-verification)并设置单点登录（Business） | 是 | 是 | | | |
| 查看审计日志（Business） | 是 | 是 | | | |
| 升级、更改或取消工作区所使用的套餐 | 是 | | | 是 | |
| 将其他成员设为所有者或账单成员 | 是 | | | | |
| 创建和修改 OAuth 应用 | 是 | | | | |
| 删除工作区 | 是 | | | | |

**账单**成员负责管理套餐，在其他方面均为只读。**查看者**可以查看所有内容，但不能更改任何内容。

## 谁为工作区付费 [#who-pays-for-the-workspace]

工作区使用其所有者和账单成员中最高级的套餐。给某人分配账单角色，就能让他为工作区付费，而无法更改其中的二维码。

## 更改成员角色 [#change-someones-role]

在**设置** → **团队**页面中，更改对应成员姓名旁边的**角色**。管理员可以设置管理员、成员和查看者；只有所有者可以授予或收回所有者和账单角色。

更改成员角色、移除成员、邀请管理员和删除工作区时，会先要求你[确认是你本人操作](/docs/help/privacy-and-security/two-step-verification#confirm-its-you)；如果你在该浏览器中 10 分钟内已确认过，则无需再次确认。

## 移交工作区 [#hand-over-a-workspace]

没有单独的转移按钮。将新成员设为**所有者**即可。有了另一位所有者之后，你就可以退出该工作区。你自己的工作区无法通过这种方式移交：你不能退出它。

## 如果出了问题 [#if-something-goes-wrong]

### 无法为某人选择所有者或账单角色 [#you-cant-pick-owner-or-billing-for-someone]

只有所有者可以授予这些角色。请联系该工作区的某位所有者。

### 成员无法删除二维码 [#a-member-cant-delete-a-code]

成员只能删除自己创建的内容。其他人创建的二维码需要由管理员或所有者来删除。
