---
title: "要求启用两步验证"
description: "要求工作区中的所有人先启用两步验证，才能打开该工作区。属于 Business 套餐的功能。"
---

所有者和管理员可以要求工作区中的所有人使用[两步验证](/docs/help/privacy-and-security/two-step-verification)。尚未启用两步验证的成员在启用之前无法打开该工作区，因此仅仅入侵了某人的邮箱，也无法进入你的工作区。

<Callout type="info">
  要求启用两步验证属于 **Business** 套餐的功能。只要工作区的某位所有者或账单成员使用 Business，该工作区就可以使用此功能。请参阅[席位与工作区限制](/docs/help/teams/seats)。
</Callout>

## 开启要求 [#turn-it-on]

### 1. 先为自己启用两步验证 [#1-turn-it-on-for-yourself-first]

在 **设置** → **个人资料与安全** 中为你自己的账号启用两步验证。如果你自己没有启用，就无法对工作区提出此要求。

### 2. 打开团队页面 [#2-open-the-team-page]

在工作区中，前往 **设置** → **团队**。

### 3. 开启要求 [#3-require-it]

在 **两步验证** 下，打开 **要求启用两步验证**。如果有成员尚未启用，QRdx 会告诉你有多少人，并在继续之前征求你的确认。

<Shot id="require-two-step" />

### 4. 确认是你本人操作 [#4-confirm-its-you]

[确认是你本人操作](/docs/help/privacy-and-security/two-step-verification#confirm-its-you)。完成后，卡片上会显示“已要求启用两步验证”。

只有所有者和管理员可以更改此设置，开启或关闭时都需要确认是你本人操作。系统不会向任何人发送邮件：未启用两步验证的成员会在下次打开工作区时得知。

## 查看谁已启用 [#see-who-has-it-on]

在 **设置** → **团队** 页面，所有者和管理员可以看到每位成员的两步验证状态为 **已开启** 还是 **未开启**。在手机上，该状态显示在每个人的邮箱地址下方。

## 未启用的成员会看到什么 [#what-members-without-it-see]

他们打开工作区时，会看到该工作区要求启用两步验证，并有一个 **启用两步验证** 按钮。点击后会进入 **设置** → **个人资料与安全**，启用完成后，点击 **返回** 工作区即可回到之前所在的页面。

在此之前，他们无法查看或更改该工作区中的任何内容。他们的其他工作区不受影响，照常使用。

这也包括该工作区发给他们的内容。他们在此工作区的邮件提醒、每周摘要以及 Slack 或 Discord 提醒都会停止，也无法新增提醒。他们设置的用于把该工作区数据发送到其他工具的同步会暂停。启用两步验证后，提醒会恢复；已暂停的同步则需要手动重新开启。

如果有人之后关闭了两步验证，该工作区会再次对其关闭，直到他们重新开启。所有者和管理员也不例外。

## API 密钥 [#api-keys]

在工作区中创建的 API 密钥，无论创建者是否启用了两步验证，都会继续对创建者本人有效。两步验证保护的是登录，而密钥本身就是一种独立的凭证。任何人如果无法打开工作区，就无法在其中创建新密钥；所有者和管理员可以在工作区的 **设置** → **API 密钥与应用** 中查看并撤销所有人的密钥。

通过 OAuth 连接到某人账号的应用只能在该用户自己的工作区中使用，因此永远无法访问团队工作区。

## 如果工作区不再使用 Business [#if-the-workspace-leaves-business]

此要求将不再生效，设置会显示为关闭。如果工作区重新使用 Business，此要求会再次生效。

## 关闭要求 [#turn-it-off]

在 **设置** → **团队** 页面，关闭 **要求启用两步验证**，并确认是你本人操作。未启用两步验证的成员可以立即重新打开工作区。

## 遇到问题时 [#if-something-goes-wrong]

### 开关无法使用 [#the-switch-is-disabled]

可能是你自己的账号尚未启用两步验证，也可能是工作区没有使用 Business。卡片上会说明是哪种情况。

### 成员被锁定，无法启用 [#a-member-is-locked-out-and-cant-turn-it-on]

他们可以在自己的 **设置** → **个人资料与安全** 中启用，这不需要进入该工作区。如果他们丢失了手机和备份码，请参阅[手机和备份码都丢失了](/docs/help/privacy-and-security/two-step-verification#lost-your-phone-and-your-backup-codes)。
