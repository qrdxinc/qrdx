वर्कस्पेस के हर सदस्य का एक रोल होता है: **Owner**, **Admin**, **Member**, **Billing** या **Viewer**। आपके अपने वर्कस्पेस में आप owner होते हैं। रोल तय करता है कि कोई क्या बदल सकता है; वर्कस्पेस के कोड, पेज और analytics सभी देख सकते हैं।

## हर रोल क्या कर सकता है [#what-each-role-can-do]

| | Owner | Admin | Member | Billing | Viewer |
| --- | --- | --- | --- | --- | --- |
| कोड, पेज, फ़ाइलें और analytics देखना | हाँ | हाँ | हाँ | हाँ | हाँ |
| कोड, पेज, फ़ाइलें, फ़ोल्डर, टैग और थीम बनाना; वर्कस्पेस के कोड एडिट करना; अपने बनाए हुए डिलीट करना | हाँ | हाँ | हाँ | | |
| API key बनाना | हाँ | हाँ | हाँ | | |
| दूसरे सदस्यों के बनाए हुए को डिलीट करना या बदलना | हाँ | हाँ | | | |
| लोगों को इन्वाइट करना और हटाना, और रोल बदलना | हाँ | हाँ | | | |
| वर्कस्पेस का नाम बदलना, उसका URL और लोगो बदलना, और जॉइन लिंक मैनेज करना | हाँ | हाँ | | | |
| कस्टम डोमेन जोड़ना, वेरिफ़ाई करना और हटाना | हाँ | हाँ | | | |
| webhook, शेयर्ड थीम और डिफ़ॉल्ट थीम मैनेज करना | हाँ | हाँ | | | |
| सभी की API key देखना और रद्द करना | हाँ | हाँ | | | |
| [टू-स्टेप वेरिफ़िकेशन अनिवार्य करना](/docs/help/teams/require-two-step-verification) और सिंगल साइन-ऑन सेट अप करना (Business) | हाँ | हाँ | | | |
| ऑडिट लॉग पढ़ना (Business) | हाँ | हाँ | | | |
| वर्कस्पेस जिस प्लान पर चलता है उसे अपग्रेड, बदलना या कैंसल करना | हाँ | | | हाँ | |
| दूसरे सदस्यों को owner या billing member बनाना | हाँ | | | | |
| OAuth app बनाना और बदलना | हाँ | | | | |
| वर्कस्पेस डिलीट करना | हाँ | | | | |

**Billing** सदस्य प्लान मैनेज करता है और बाकी सब जगह सिर्फ़ देख सकता है। **Viewer** सब कुछ देखता है, पर कुछ बदल नहीं सकता।

## वर्कस्पेस का भुगतान कौन करता है [#who-pays-for-the-workspace]

वर्कस्पेस अपने owners और billing members के बीच सबसे अच्छे प्लान पर चलता है। किसी को Billing रोल देने से वह वर्कस्पेस का भुगतान कर सकता है, बिना उसके कोड बदल पाए।

## किसी का रोल बदलें [#change-someones-role]

**Settings** → **Team** पेज पर, उनके नाम के बगल में **Role** बदलें। Admin, admin, member और viewer सेट कर सकते हैं; owner और billing रोल सिर्फ़ owners दे या हटा सकते हैं।

किसी का रोल बदलने, किसी को हटाने, किसी admin को इन्वाइट करने और वर्कस्पेस डिलीट करने से पहले [पुष्टि करनी होती है कि यह आप ही हैं](/docs/help/privacy-and-security/two-step-verification#confirm-its-you), जब तक कि आपने उसी ब्राउज़र में पिछले 10 मिनट में ऐसा न किया हो।

## वर्कस्पेस सौंपें [#hand-over-a-workspace]

अलग से ट्रांसफ़र बटन नहीं है। नए व्यक्ति को **Owner** बनाएँ। जब कोई दूसरा owner हो जाए, तो आप वर्कस्पेस छोड़ सकते हैं। आपका अपना वर्कस्पेस इस तरह नहीं सौंपा जा सकता: आप उसे छोड़ नहीं सकते।

## अगर कुछ गड़बड़ हो [#if-something-goes-wrong]

### आप किसी के लिए Owner या Billing नहीं चुन पा रहे [#you-cant-pick-owner-or-billing-for-someone]

ये रोल सिर्फ़ owner दे सकता है। वर्कस्पेस के किसी owner से कहें।

### कोई member कोड डिलीट नहीं कर पा रहा [#a-member-cant-delete-a-code]

Members सिर्फ़ वही डिलीट कर सकते हैं जो उन्होंने बनाया हो। किसी और के बनाए कोड के लिए admin या owner चाहिए।
