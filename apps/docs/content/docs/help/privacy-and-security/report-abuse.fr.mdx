title: "Signaler un QR code malveillant"
description: "Signalez un code QRdx, un lien court ou une page qui mène à du phishing, à un logiciel malveillant, à une arnaque ou à d'autres contenus dangereux."
---

Si un code QRdx, un lien court ou une page mène à du phishing, à un logiciel malveillant, à une arnaque ou à un autre contenu dangereux, signalez-le : une personne l'examinera. Vous n'avez pas besoin de compte.

## Le signaler [#report-it]

1. Ouvrez le [formulaire de signalement](/report-abuse). Chaque page qu'ouvre un QR code dynamique QRdx, y compris les pages de mot de passe et de « campagne terminée », y renvoie également.
2. Collez le lien court du code, le lien de la page ou le code court de 7 caractères.
3. Choisissez un motif et ajoutez des précisions si vous le souhaitez.
4. Indiquez votre adresse e-mail si vous voulez savoir ce que nous avons fait. C'est facultatif.
5. Envoyez le signalement.

<Shot id="report-abuse-form" />

## Que se passe-t-il ensuite [#what-happens-next]

Une personne examine chaque signalement dans un délai de 24 à 48 heures. Les codes qui enfreignent nos règles sont désactivés pour tout le monde : les personnes qui les scannent voient « Ce QR code n'est plus actif », et le propriétaire ne peut pas les réactiver.

## Restez prudent [#stay-safe]

Ne saisissez ni mots de passe, ni numéros de carte, ni codes à usage unique sur une page atteinte depuis un QR code auquel vous ne faites pas confiance.

## QR codes statiques [#static-codes]

Un QR code statique contient directement son contenu et ne passe jamais par QRdx : nous ne pouvons donc pas le désactiver. Signalez le site dangereux à son hébergeur ou à [Google Safe Browsing](https://safebrowsing.google.com/safebrowsing/report_phish/).

## Si votre code a été désactivé [#if-your-code-was-switched-off]

Si vous pensez que nous avons commis une erreur, écrivez à [support@qrdx.dev](mailto:support@qrdx.dev) avec « [appeal] » dans l'objet et le lien court du code. Lisez la [politique en matière d'abus](/legal/report-abuse) complète.
