你的 QRdx 账户没有密码，因此保护账户，就是保护你的登录方式，并了解在出现异常时 QRdx 会怎么做。本页涵盖全部相关内容：两步验证、通行密钥、敏感变更前的检查、你会收到的邮件，以及如何退出其他设备。

## 没有可泄露的密码 [#no-password-to-leak]

QRdx 没有密码。你可以使用 Google、GitHub 或发送到邮箱的一次性验证码登录<IfAvailable feature="passkeys">，也可以使用通行密钥登录</IfAvailable>。<IfAvailable feature="sso"> 如果你的工作区使用 Business 方案，还可以允许你通过公司的[单点登录](/docs/help/teams/single-sign-on)登录，或者强制要求使用单点登录。</IfAvailable>

这意味着你的邮箱账户，以及你的 Google 或 GitHub 账户，都是进入 QRdx 的钥匙。请同样为它们开启两步验证。

<IfAvailable feature="sso" id="if-your-company-requires-single-sign-on" title="如果你的公司要求使用单点登录">

Business 工作区可以对公司的邮箱域名[要求使用单点登录](/docs/help/teams/single-sign-on#require-single-sign-on)。如果你的邮箱地址属于该域名：

- 你只能通过单点登录登录：邮箱验证码、Google 或 GitHub<IfAvailable feature="passkeys">，或者 **Continue with passkey**，</IfAvailable>都无法让你登录；
- 在公司的登录页面之后，仍然需要两步验证<IfAvailable feature="passkeys">，通行密钥也仍可作为你的第二步</IfAvailable>；
- 每次登录最多持续 24 小时，之后需要再次通过单点登录登录；
- 你的 QRdx 邮箱不能更改为该域名之外的地址。

工作区开启该要求时，不是通过单点登录开始的会话会被退出。工作区的所有者仍保留其他登录方式，这样公司登录页面出现问题时，不会把所有人都锁在门外。

</IfAvailable>

## 开启两步验证 [#turn-on-two-step-verification]

[两步验证](/docs/help/privacy-and-security/two-step-verification)会让 QRdx 在你登录之后要求完成第二步，无论你用哪种方式登录：<IfAvailable feature="passkeys">你的通行密钥或</IfAvailable>验证器应用中的验证码。这样，即使有人进入了你的邮箱或 Google 账户，没有这一步也无法进入 QRdx。你会获得 10 个备份码，用于无法完成第二步的情况。开启两步验证会退出你账户上所有其他已登录的浏览器或设备，因此每一个都需要通过第二步重新登录。

<IfAvailable feature="passkeys" id="add-a-passkey" title="添加通行密钥">

[通行密钥](/docs/help/privacy-and-security/passkeys)通过你的指纹、面容或屏幕锁来确认是你本人。它只能在 QRdx 自己的网站上使用，因此仿冒网站无法获取它。它可以通过 **Continue with passkey** 单独让你登录，也可以作为你的第二步。在两步验证关闭时添加通行密钥会将其开启，并退出你的其他设备。

</IfAvailable>

## 变更时需要确认是你本人 [#changes-ask-you-to-confirm-its-you]

在更改账户安全相关设置之前，即使你已登录，QRdx 也会要求你[确认是你本人](/docs/help/privacy-and-security/two-step-verification#confirm-its-you)。涉及以下操作：

- 账户：更改邮箱地址、删除账户、开启或关闭两步验证、生成新的备份码、更改第二步方式，以及关联或取消关联 Google 或 GitHub；
- 开发者工具：创建 API 密钥或 OAuth 应用的 client secret、批准请求使用你账户的应用、添加 webhook 或更改其 URL，以及显示或轮换 webhook 的签名密钥；
- 连接：添加 Slack 或 Discord 通知 webhook，以及连接会把你的扫描数据或表单回答发送到其他工具的集成；
- 工作区：删除工作区、更改某人的角色、移除某人，以及邀请管理员。<IfAvailable feature="sso"> 更改工作区的单点登录连接和要求使用单点登录也同样需要确认。</IfAvailable>

开启两步验证后，你需要使用<IfAvailable feature="passkeys">通行密钥、</IfAvailable>验证器验证码或备份码来确认，而不能使用邮件验证码。未开启时，你可以使用 QRdx 发送到邮箱的 6 位验证码<IfAvailable feature="passkeys">、你的通行密钥（如果有）</IfAvailable>，或者重新通过你已关联的 Google 或 GitHub 账户登录<IfAvailable feature="sso">（或者使用工作区的单点登录，前提是它采用 OIDC）</IfAvailable>。一次确认在该浏览器中有效 10 分钟。

更改邮箱地址还需要输入发送到新地址的验证码。完成后，你会在其他所有地方被退出，旧地址也会收到一封说明邮箱已更改的邮件。无法访问你的邮箱？请参阅[处理方法](/docs/help/account-and-billing/sign-in#lost-access-to-your-email)。

## 在新环境中使用的登录状态 [#a-sign-in-used-somewhere-new]

你登录时，QRdx 会记录你登录所在的国家或地区以及你的浏览器，例如“Chrome on macOS”。如果之后该登录状态在不同的国家或地区、使用不同的浏览器被使用，QRdx 会要求你先[确认是你本人](/docs/help/privacy-and-security/two-step-verification#confirm-its-you)，才能在账户中进行其他操作。在你确认之前，该浏览器在 QRdx 的其他所有地方都会被视为已退出。因此，即使有人从你的浏览器中复制了登录状态，除非也能确认是你本人，否则无法在远处使用。

只有两者都发生变化时才会询问。使用同一个浏览器出行，或更新浏览器或系统，都不算变化。你确认之后，QRdx 会为该登录状态记录新的国家或地区和浏览器。你也可以选择退出后重新登录。

这只是一道额外的检查，并不是保证：被复制的登录状态如果在你所在的国家或地区使用，或在同类浏览器中使用，则不会被询问。QRdx 只有在其托管服务提供商提供国家或地区信息时才能获知，没有提供时，这项检查不会运行。若要结束你不认识的登录，请[退出其他设备](#sign-out-other-devices)。

## 账户安全相关邮件 [#emails-about-your-accounts-security]

在以下情况下，我们会向你账户的邮箱地址发送邮件：

- 某个浏览器或设备首次登录你的账户；
- 两步验证被开启或关闭、添加或移除了验证器应用<IfAvailable feature="passkeys">或通行密钥</IfAvailable>，或生成了新的备份码；
- 使用了备份码（用于登录或确认是你本人），并告知你还剩多少个备份码；
- 支持团队被要求关闭你的两步验证，邮件会说明发生的日期和如何阻止，以及该请求被取消时的通知；
- 你的邮箱地址被更改（发送到旧地址）。

每封邮件都会说明发生了什么、在哪台设备和浏览器上（例如“Chrome on macOS”）、大致位置、来自哪个 IP 地址以及发生时间。**Review security** 会打开你的安全设置。如果不是你本人操作，请按邮件中的步骤操作并联系支持团队。

包含验证码的邮件，例如登录验证码和用于确认是你本人的验证码，会说明验证码是在大致什么位置请求的。QRdx 绝不会通过电话、聊天或邮件向你索要验证码：请不要把验证码告诉任何人。

### 新的登录 [#new-sign-ins]

QRdx 通过你完成登录时设置的 cookie 来识别浏览器。当没有该 cookie 的浏览器或设备登录你的账户时，你会收到一封邮件。开启两步验证后，会在完成第二步之后发送。

在 QRdx 已识别的浏览器中再次登录不会发送邮件，创建账户时也不会发送。如果你清除了 cookie 或使用隐私窗口，下一次在那里登录会被视为新的登录。

每个新浏览器都会各收到一封邮件，每天最多 10 封，这样密集的登录不会塞满你的收件箱。每次登录仍会显示在 **Sessions** 下。QRdx 会记住你最近使用过的 50 个浏览器，并会忘记已有 400 天没有登录的浏览器。

<IfAvailable feature="sso">

有一个例外：当你通过工作区的 SAML 身份提供商登录且两步验证处于关闭状态时，QRdx 在你返回时无法识别该浏览器，因此不会发送这封邮件。

</IfAvailable>

## 登录状态保持多久 [#how-long-you-stay-signed-in]

一次登录最长持续 30 天。之后，无论你使用得多么频繁，QRdx 都会要求你在该浏览器中重新登录。如果你在某个浏览器中大约一周没有使用 QRdx，则会更早在那里被退出。

## 退出其他设备 [#sign-out-other-devices]

前往 **Settings** → **Profile & security**。在 **Sessions** 下，可以退出某一台设备，也可以点击 **Sign out everywhere else**。此操作从不要求你确认是你本人，因此可以立即执行。

<Shot id="sessions-card" />

开启两步验证也会退出其他所有设备。如果支持团队为你关闭了两步验证（需要[等待 7 天](/docs/help/privacy-and-security/two-step-verification#lost-your-phone-and-your-backup-codes)），所有设备会在当天被退出，包括你正在使用的这台。<IfAvailable feature="sso"> 如果你的公司开始要求使用单点登录，不是通过单点登录开始的会话会被退出，而单点登录会话最长持续 24 小时。</IfAvailable>

## 移除你已连接的应用 [#remove-apps-you-connected]

如果你允许其他应用使用你的 QRdx 账户，这些应用会列在 **Settings** → **Authorized apps** 下。请移除你不再使用的应用。应用在你退出登录后仍会继续工作，因此批准某个应用时，系统会要求你确认是本人操作。

## 报告安全问题 [#report-a-security-problem]

请发送邮件至 [support@qrdx.dev](mailto:support@qrdx.dev)，主题以 `[security]` 开头。请不要在公开的 GitHub issue 中发布。参见[安全政策](/legal/security)。

有害二维码不属于安全漏洞：请改为[举报它](/docs/help/privacy-and-security/report-abuse)。
