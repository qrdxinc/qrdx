---
title: "Denunciar um QR code prejudicial"
description: "Denuncie um código QRdx, link curto ou página que leve a phishing, malware, golpes ou outros conteúdos prejudiciais."
---

Se um código QRdx, link curto ou página levar a phishing, malware, golpe ou outro conteúdo prejudicial, denuncie e uma pessoa vai analisar. Você não precisa ter uma conta.

## Faça a denúncia [#report-it]

1. Abra o [formulário de denúncia](/report-abuse). Toda página aberta por um QR code dinâmico do QRdx, incluindo as páginas de senha e de "campanha encerrada", também tem um link para ele.
2. Cole o link curto do código, o link da página ou o código curto de 7 caracteres.
3. Escolha um motivo e adicione os detalhes que quiser.
4. Deixe seu e-mail se quiser saber o que fizemos. É opcional.
5. Envie a denúncia.

<Shot id="report-abuse-form" />

## O que acontece depois [#what-happens-next]

Uma pessoa analisa cada denúncia em 24 a 48 horas. Os códigos que violam nossas regras são desativados para todos: quem fizer a leitura vê "Este QR code não está mais ativo", e o dono não consegue reativá-los.

## Fique seguro [#stay-safe]

Não digite senhas, números de cartão nem códigos de uso único em uma página que você abriu por um QR code em que não confia.

## QR codes estáticos [#static-codes]

Um QR code estático guarda o conteúdo diretamente e nunca passa pelo QRdx, então não conseguimos desativá-lo. Denuncie o site prejudicial à empresa que o hospeda ou ao [Google Safe Browsing](https://safebrowsing.google.com/safebrowsing/report_phish/).

## Se o seu código foi desativado [#if-your-code-was-switched-off]

Se você acha que erramos, envie um e-mail para [support@qrdx.dev](mailto:support@qrdx.dev) com "[appeal]" no assunto e o link curto do código. Leia a [política de abuso](/legal/report-abuse) completa.
