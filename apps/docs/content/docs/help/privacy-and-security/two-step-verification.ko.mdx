2단계 인증(2FA라고도 해요)은 로그인에 두 번째 단계를 더해 줍니다. 이메일 코드, Google 또는 GitHub<IfAvailable feature="sso">(또는 워크스페이스의 싱글 사인온)</IfAvailable>로 로그인하고 나면 QRdx가 <IfAvailable feature="passkeys">패스키 또는 </IfAvailable>인증 앱의 6자리 코드를 요청합니다. 누군가 내 이메일이나 Google 계정에 들어오더라도 이 단계가 없으면 QRdx에는 들어올 수 없습니다.

<IfAvailable feature="passkeys">

[패스키](/docs/help/privacy-and-security/passkeys)는 지문, 얼굴, 화면 잠금 또는 보안 키로 본인인지 확인합니다. QRdx 공식 사이트에서만 작동하므로 비슷하게 만든 가짜 사이트는 패스키를 가로챌 수 없습니다.

</IfAvailable>

인증 앱도 사용할 수 있습니다. 30초마다 바뀌는 6자리 코드를 보여 주는 앱이면 모두 가능하며, 대부분의 비밀번호 관리자에 있는 일회용 코드 기능도 포함됩니다. QRdx는 두 번째 단계 코드를 이메일이나 문자 메시지로 보내지 않습니다.

두 가지를 모두 설정해 두고, 로그인할 때 편한 쪽을 사용할 수도 있어요.

## 2단계 인증 켜기 [#turn-it-on]

1. **설정** → **프로필 및 보안**으로 이동하세요.
2. **2단계 인증**에서 **켜기**를 클릭하고 [본인 확인](#confirm-its-you)을 진행하세요.
3. 아래 설명대로 두 번째 단계를 설정하세요<IfAvailable feature="passkeys">. **패스키** 또는 **인증 앱**을 선택하면 됩니다</IfAvailable>.
4. 백업 코드 10개를 저장하세요. 복사하거나 텍스트 파일로 다운로드해서 비밀번호 관리자 같은 안전한 곳에 보관하세요. QRdx는 백업 코드를 한 번만 보여 줍니다. **백업 코드를 저장했어요**를 체크하고 **완료**를 클릭하세요.

<Shot id="two-step-card" />

<IfAvailable feature="passkeys">

패스키를 사용하려면 추천 이름(예: "Chrome on macOS"처럼 브라우저와 시스템 이름)을 그대로 쓰거나 원하는 이름을 입력한 뒤 **계속**을 클릭하고, 브라우저에서 패스키를 저장하세요.

</IfAvailable>

인증 앱을 사용하려면 앱으로 QR 코드를 스캔하거나 그 아래에 표시된 키를 입력하세요. 앱에 표시된 6자리 코드를 입력하고 **확인**을 클릭하세요.

이제 2단계 인증이 켜졌으며, 내 계정에 로그인되어 있던 다른 모든 브라우저와 기기는 로그아웃됩니다. 각 기기에서 두 번째 단계와 함께 다시 로그인해야 해요. 2단계 인증을 켠 브라우저는 로그인 상태가 유지됩니다.<IfAvailable feature="passkeys"> 나중에 다른 방법을 추가하려면 같은 섹션을 사용하세요. 이미 가지고 있는 백업 코드는 그대로 유지되고, 로그아웃되는 사람도 없습니다.</IfAvailable>

<IfAvailable feature="passkeys">

2단계 인증에서 패스키를 쓸 수 있게 되기 전에 패스키를 추가했다면, 설정에 **패스키를 두 번째 단계로 사용할 수 있어요**라고 표시됩니다. **켜기**를 클릭하고 본인 확인을 한 다음, 그 패스키로 본인임을 확인하고 백업 코드를 저장하세요. 이때 다른 기기도 로그아웃됩니다.

</IfAvailable>

2단계 인증을 켜거나 끌 때, 방법을 추가하거나 삭제할 때, 새 백업 코드를 만들 때, 백업 코드를 사용할 때마다 계정 이메일 주소로 메일을 보냅니다. 지원팀에 2단계 인증 해제를 요청했을 때도 메일을 보냅니다.

## 2단계 인증으로 로그인하기 [#sign-in-with-it]

평소처럼 로그인하세요. 그러면 QRdx가 두 번째 단계를 요청합니다.

<IfAvailable feature="passkeys">

패스키가 있으면 브라우저의 패스키 창이 자동으로 열립니다. 일부 브라우저는 클릭해야 열리는데, 이때는 **패스키로 계속**을 클릭하세요. 창을 닫았거나 시간이 초과되었다면 다시 시도하거나 다른 방법을 선택하세요.

</IfAvailable>

단계 아래의 **인증 코드 사용**과 **백업 코드 사용**을 누르면 가지고 있는 다른 방법으로 전환할 수 있습니다. QRdx는 이 브라우저에서 마지막으로 사용한 방법을 기억했다가 다음번에 먼저 보여 줍니다.

인증 코드는 30초마다 바뀌므로, 코드가 거부되면 다음 코드가 나올 때까지 기다리세요.

각 로그인 단계에서는 잘못된 코드를 5번까지 입력할 수 있습니다<IfAvailable feature="passkeys">. 확인에 실패한 패스키도 1번으로 계산됩니다</IfAvailable>. 그 후에는 로그인을 처음부터 다시 시작해야 합니다. 연속으로 10번 잘못 입력하면 QRdx는 15분 동안 내 계정의 코드를 받지 않습니다.

이 단계는 10분 후에 만료됩니다. 만료되면 다시 로그인하세요.

## 백업 코드 [#backup-codes]

백업 코드는 휴대폰<IfAvailable feature="passkeys">이나 패스키</IfAvailable>가 없을 때 두 번째 단계 대신 사용할 수 있습니다. 두 번째 단계에서 **백업 코드 사용**을 클릭하고 코드를 하나 입력하세요. 코드는 `ABCDE-FGH23`처럼 대문자와 2~9 숫자로 이루어져 있으며, 헷갈리기 쉬운 0, O, 1, I는 들어 있지 않습니다. 소문자로 입력해도 되고, 대시는 있어도 없어도 됩니다. 각 코드는 한 번만 사용할 수 있어요.

로그인하거나 본인 확인을 하기 위해 백업 코드를 사용할 때마다 남은 코드 수를 담아 계정 이메일 주소로 메일을 보냅니다. 본인이 사용한 것이 아니라면 누군가 내 백업 코드를 가지고 있다는 뜻이니 즉시 지원팀에 문의하세요.

설정에서 남은 코드 수를 확인할 수 있습니다. 2개 이하로 남았다면 새 코드를 만드세요. **새 코드**를 클릭하고 본인 확인을 하면 됩니다. 기존 코드는 더 이상 사용할 수 없습니다.

## 신뢰하는 기기 [#trusted-devices]

두 번째 단계에서 **이 기기에서 30일 동안 다시 묻지 않기**를 체크하면 해당 브라우저에서는 30일 동안 이 단계를 건너뜁니다. 본인 소유의 기기에서만 사용하세요. 2단계 인증을 끄면 신뢰하는 기기가 모두 초기화됩니다.

## 2단계 인증을 요청하는 로그인 [#which-sign-ins-ask-for-it]

모든 로그인에서 요청합니다. 이메일 코드, Google, GitHub<IfAvailable feature="sso">, 워크스페이스 싱글 사인온이 모두 해당됩니다</IfAvailable>. 이미 로그인된 브라우저에서 다시 로그인하는 경우도 포함됩니다.

<IfAvailable feature="passkeys">

**패스키로 계속**으로 로그인하는 경우는 예외입니다. 패스키 로그인은 이미 기기와 지문, 얼굴 또는 화면 잠금이라는 두 가지 요소를 사용하므로 QRdx는 두 번째 단계를 요청하지 않습니다. QRdx는 이런 방식으로 본인을 확인하는 패스키만 허용합니다.

</IfAvailable>

## 방법 변경하기 [#change-your-methods]

**설정** → **프로필 및 보안**의 **2단계 인증**에서 인증 앱을 설정하거나 삭제할 수 있습니다<IfAvailable feature="passkeys">. 패스키는 추가하거나 이름을 바꾸거나 삭제할 수 있습니다</IfAvailable>. 변경할 때마다 본인 확인이 필요해요.

마지막 방법을 삭제하면 2단계 인증이 꺼지고 백업 코드도 더 이상 작동하지 않습니다. QRdx가 확인 전에 미리 알려 드립니다.

## 본인 확인 [#confirm-its-you]

계정 보안과 관련된 변경을 하기 전에는 로그인되어 있더라도 QRdx가 본인 확인을 요청합니다. 해당하는 작업은 다음과 같습니다.

- 이메일 주소 변경
- 계정 삭제
- 2단계 인증 켜기 또는 끄기, 새 백업 코드 만들기
- 인증 앱 추가 또는 삭제<IfAvailable feature="passkeys">, 패스키 추가, 이름 변경 또는 삭제</IfAvailable>
- Google 또는 GitHub 계정 연결 또는 연결 해제
- API 키 만들기, OAuth 앱 만들기 또는 OAuth 앱의 새 클라이언트 시크릿 만들기
- **승인** 화면에서 내 QRdx 계정을 사용하려는 앱 승인
- 웹훅 엔드포인트 추가, 엔드포인트 URL 변경, 서명 시크릿 표시 또는 교체
- Slack 또는 Discord 알림 웹훅 추가, 또는 스캔이나 폼 응답을 다른 도구로 보내는 연동 연결
- 워크스페이스에서: 워크스페이스 삭제, 멤버 역할 변경, 멤버 제거, 이메일이나 참여 링크로 관리자 초대, [2단계 인증 필수](/docs/help/teams/require-two-step-verification) 설정 또는 해제

<IfAvailable feature="sso">

워크스페이스의 싱글 사인온 연결을 만들거나 수정하거나 확인하거나 삭제할 때, 그리고 싱글 사인온을 필수로 설정할 때도 마찬가지입니다.

</IfAvailable>

본인 확인 방법은 2단계 인증이 켜져 있는지에 따라 달라집니다.

| 2단계 인증 | 본인 확인 방법 |
| --- | --- |
| **켜짐** | <IfAvailable feature="passkeys">패스키, </IfAvailable>인증 앱의 코드 또는 백업 코드(사용하면 소진됩니다). QRdx는 여기서 이메일 코드를 제공하지 않으므로, 이메일에 접근할 수 있다는 것만으로는 보안 설정을 바꿀 수 없습니다. |
| **꺼짐** | QRdx가 이메일로 보내 주는 6자리 코드, 또는 연결해 둔 Google 또는 GitHub 계정으로 다시 로그인<IfAvailable feature="sso">하거나 OIDC를 사용하는 워크스페이스 싱글 사인온으로 로그인</IfAvailable>. <IfAvailable feature="passkeys">패스키가 있다면 패스키도 사용할 수 있습니다.</IfAvailable> |

다시 로그인을 선택하면 해당 로그인 화면으로 이동해 계정을 선택하거나 로그인하게 되며, 이후 같은 페이지로 돌아옵니다. 자리를 비운 동안에는 변경 내용이 저장되지 않으므로 돌아온 뒤 다시 변경하세요. 연결해 둔 계정을 사용하세요. QRdx는 다른 계정으로 바꾸거나 새 계정을 만들지 않습니다.

그래서 이메일에 접근할 수 없더라도 다른 방법으로 본인 확인을 할 수 있어요. 어느 방법도 쓸 수 없다면 [이메일 접근 권한을 잃어버린 경우](/docs/help/account-and-billing/sign-in#lost-access-to-your-email)를 참고하세요.

본인 확인은 해당 브라우저에서 10분 동안 유효하므로, 여러 변경을 연달아 하면 한 번만 확인합니다.

로그인도 해당 브라우저에서 10분 동안 본인 확인으로 인정됩니다. 2단계 인증이 켜져 있다면 두 번째 단계에 답한 로그인<IfAvailable feature="passkeys">이나 **패스키로 계속**으로 한 로그인</IfAvailable>만 해당하며, 신뢰하는 기기라서 두 번째 단계를 건너뛴 로그인은 해당하지 않습니다.<IfAvailable feature="sso"> ID 공급자의 앱 대시보드에서 QRdx를 여는 것도 두 번째 단계에 답하지 않았다면 인정되지 않습니다.</IfAvailable>

다른 기기 로그아웃은 본인 확인을 요청하지 않으므로, 다른 사람이 내 계정에 들어왔다면 바로 로그아웃시킬 수 있습니다.

## 끄기 [#turn-it-off]

**설정** → **프로필 및 보안**으로 이동해 **2단계 인증**에서 **끄기**를 클릭하고 본인 확인을 진행하세요. 백업 코드와 인증 앱 설정이 있다면 함께 삭제돼요.

참여 중인 워크스페이스가 [2단계 인증을 요구](/docs/help/teams/require-two-step-verification)하는 경우, 2단계 인증을 다시 켤 때까지 해당 워크스페이스를 열 수 없어요.

## 휴대폰과 백업 코드를 모두 잃어버렸을 때 [#lost-your-phone-and-your-backup-codes]

<IfAvailable feature="passkeys">패스키, </IfAvailable>인증 앱 또는 백업 코드가 아직 있다면 그 방법으로 로그인한 다음 설정에서 인증 방법을 변경하세요.

두 번째 단계를 거칠 수 있는 방법을 모두 잃어버렸다면 계정의 이메일 주소로 [support@qrdx.dev](mailto:support@qrdx.dev)에 어떤 일이 있었는지 알려 주세요. 저희에게 메일을 보낸 사람이 본인이 아닐 수도 있으므로, 해당 주소에서 온 요청임을 확인한 후에도 지원팀의 해제 처리는 7일간 대기합니다.

1. **해당 일이 시작되는 날 그 주소로 이메일을 보내 드려요.** 그때까지는 아무것도 바뀌지 않으며, 지금 로그인된 기기는 로그인 상태가 유지돼요.
2. **요청하지 않았다면 중단하세요.** 인증 앱이나 백업 코드로 로그인하면 해제가 취소돼요.<IfAvailable feature="passkeys"> 패스키로 로그인해도 취소되지 않아요. 이 초기화는 기기를 분실한 경우를 위한 것이고, 패스키가 그 기기에 있을 수 있기 때문이에요.</IfAvailable> **설정** → **프로필 및 보안**의 **2단계 인증**에서 **취소**를 클릭하고 [본인 확인](#confirm-its-you)을 하거나, 받은 이메일에 답장해도 돼요. 취소되면 이메일로 알려 드려요.
3. **7일이 지난 날 2단계 인증이 꺼져요.** 인증 앱 설정, 백업 코드, 신뢰하는 기기가 삭제되고,<IfAvailable feature="passkeys"> 패스키는 그대로 유지되며,</IfAvailable> 모든 기기에서 계정이 로그아웃돼요. 이 내용도 이메일로 알려 드려요. 그다음 평소처럼 로그인해서 2단계 인증을 다시 켜세요.
