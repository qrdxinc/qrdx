Tus códigos impresos están a salvo. Esa es la [Garantía Never-Hostage](/guarantee), y se aplica en todos los planes, incluido el plan Gratis. Esta página explica exactamente qué sigue funcionando y qué cambia cuando bajas de plan, cancelas o falla un pago.

## Lo que prometemos [#what-we-promise]

- **Los códigos estáticos son gratis para siempre.** Contienen tu contenido directamente y nunca caducan.
- **Los códigos dinámicos siguen redirigiendo** después de un cambio a un plan inferior, un pago fallido o una cancelación.
- **Sin pausas y sin anuncios.** Nunca pausamos tus códigos por motivos de facturación y nunca enviamos a quienes los escanean a través de una página de QRdx.
- **Los límites solo impiden crear cosas nuevas.** Los códigos y las páginas existentes siguen funcionando, y puedes seguir cambiando el destino de tus códigos.
- **Exporta todo.** Descarga tus códigos, escaneos y respuestas en cualquier plan.
- **12 meses de preaviso** si QRdx llegara a cerrar, con tiempo para exportarlo todo y una vía documentada para ejecutar tú mismo la aplicación de código abierto.

## Qué sigue funcionando después de bajar de plan [#what-keeps-working-after-a-downgrade]

- Todos los códigos dinámicos y todas las páginas.
- Las reglas de enrutamiento, las contraseñas, los horarios y los píxeles que ya guardaste.
- Los dominios personalizados que ya verificaste.

## Qué cambia [#what-changes]

- No puedes crear códigos ni páginas nuevos más allá de los límites del nuevo plan.
- El historial de escaneos muestra solo lo que incluye tu nuevo plan. No se elimina nada, y vuelve a mostrarse si mejoras de plan.
- Las páginas del plan Gratis vuelven a mostrar el pie "Made with QRdx".
- Los formularios dejan de recibir respuestas cuando se alcanza el límite mensual.
- Se bloquean las subidas que superen tu límite de almacenamiento.

## Qué sí detiene un código [#what-does-stop-a-code]

Solo lo que tú decides: pausarlo, una fecha de finalización, un límite de escaneos, archivarlo o eliminarlo. QRdx también puede desactivar un código que se use para abusos.
