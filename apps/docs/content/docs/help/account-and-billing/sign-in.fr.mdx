QRdx n'utilise pas de mots de passe. Vous vous connectez avec Google, GitHub ou un code envoyé par e-mail, et votre compte est lié à cette adresse e-mail. Cette page présente les méthodes de connexion, la façon de les associer, le changement d'adresse et la marche à suivre si vous avez perdu l'accès à votre boîte mail.

## Méthodes de connexion [#ways-to-sign-in]

- **Google** ou **GitHub**.
- **Code par e-mail** : saisissez votre adresse e-mail et cliquez sur **Email me a code**, puis entrez le code à 6 chiffres que nous vous envoyons. Un code est valable 5 minutes.

<IfAvailable feature="passkeys">
Une fois que vous avez [ajouté une clé d'accès](/docs/help/privacy-and-security/passkeys), vous pouvez aussi cliquer sur **Continue with passkey** et vous connecter avec votre empreinte digitale, votre visage ou le verrouillage de votre écran.
</IfAvailable>

Lors de votre première connexion, QRdx crée votre compte.

Avec Google ou GitHub, QRdx ne crée le compte que si votre adresse e-mail y a été vérifiée. Si la vôtre ne l'est pas, vérifiez-la d'abord (GitHub liste vos adresses sous **Settings** → **Emails**), ou connectez-vous plutôt avec un code par e-mail.

## Un compte pour votre adresse que vous n'avez pas créé [#an-account-for-your-address-you-didnt-make]

Si QRdx possède déjà un compte pour votre adresse et que vous ne l'avez pas créé, connectez-vous avec un code par e-mail. Dès que cela prouve que l'adresse est la vôtre, QRdx supprime ce que l'inscription précédente pourrait utiliser pour revenir dans le compte ou pour continuer à récupérer ses données :

- ses liens Google et GitHub, et toutes ses sessions ;
- sa vérification en deux étapes et ses appareils de confiance<IfAvailable feature="passkeys">, ainsi que ses clés d'accès</IfAvailable> ;
- ses clés API, et les applications qu'il avait autorisées à utiliser le compte ;
- les webhooks et les alertes Slack et Discord qu'il avait configurés, ainsi que les synchronisations qu'il avait mises en place pour envoyer des scans ou des réponses de formulaire vers un autre outil.

Tout le reste du compte est conservé : vérifiez donc ensuite ses espaces de travail et leurs membres.

## Associer Google ou GitHub [#link-google-or-github]

Allez dans **Settings** → **Profile & security** → **Sign-in methods**.

- **Email code** est toujours activé.
- Associez Google ou GitHub pour vous connecter en un clic. Le compte doit utiliser la même adresse e-mail que votre compte QRdx.
- Cliquez sur **Unlink** pour en supprimer une.

## Changer votre adresse e-mail [#change-your-email-address]

1. Allez dans **Settings** → **Profile & security**.
2. À côté de **Email**, cliquez sur **Change**, puis [confirmez votre identité](/docs/help/privacy-and-security/two-step-verification#confirm-its-you).
3. Saisissez la nouvelle adresse et entrez le code que nous y envoyons.

QRdx vous déconnecte ensuite de tous les autres appareils et navigateurs, et votre ancienne adresse reçoit un e-mail indiquant que le compte a été déplacé, avec un moyen de contacter le support si ce n'était pas vous.

## Perte d'accès à votre e-mail [#lost-access-to-your-email]

Si vous pouvez encore accéder à QRdx, changez vous-même votre adresse e-mail, comme indiqué ci-dessus. Pour confirmer votre identité sans votre boîte mail, utilisez <IfAvailable feature="passkeys">votre clé d'accès, </IfAvailable>un compte Google ou GitHub que vous avez associé, ou votre méthode de vérification en deux étapes si elle est activée. Vous êtes déconnecté ? Connectez-vous d'abord avec <IfAvailable feature="passkeys">votre clé d'accès ou </IfAvailable>un compte Google ou GitHub associé.

Si aucune de ces méthodes ne fonctionne, écrivez à [support@qrdx.dev](mailto:support@qrdx.dev) depuis l'adresse que vous souhaitez utiliser. Déplacer un compte vers une nouvelle adresse est l'opération la plus sensible du support, c'est pourquoi elle suit trois étapes :

1. **Nous avons besoin d'une preuve que le compte est le vôtre.** Nous vous demandons l'adresse e-mail du compte, ainsi que l'un des éléments suivants : si vous avez payé pour QRdx, le numéro de l'une de vos [factures](/docs/help/account-and-billing/invoices) et la date approximative du paiement ; si un espace de travail de votre compte utilise son propre [domaine](/docs/help/domains/custom-domains), un enregistrement DNS que nous vous envoyons, à ajouter à ce domaine.
2. **Nous prévenons l'ancienne adresse et attendons 7 jours.** Si quelqu'un y répond pendant ce délai pour refuser, nous arrêtons la procédure.
3. **Ensuite, nous déplaçons le compte.** Nous remplaçons son adresse e-mail par la nouvelle, le déconnectons partout et envoyons un e-mail à l'ancienne adresse. Connectez-vous avec un code envoyé à la nouvelle adresse. Votre vérification en deux étapes, si elle est activée, reste inchangée.

Si nous ne pouvons pas confirmer que le compte est le vôtre, nous ne le déplacerons pas, même si cela le rend inaccessible. Le confier à la mauvaise personne serait pire.

Avant que votre ancienne adresse ne cesse de fonctionner, ajoutez une clé d'accès ou associez Google ou GitHub, afin de toujours pouvoir confirmer votre identité.

## Se déconnecter des autres appareils [#sign-out-of-other-devices]

Sous **Sessions** dans **Settings** → **Profile & security**, déconnectez un appareil, ou cliquez sur **Sign out everywhere else**.

## En cas de problème [#if-something-goes-wrong]

### Le code de connexion n'arrive pas [#the-sign-in-code-doesnt-arrive]

Consultez [Les codes ou e-mails de connexion n'arrivent pas](/docs/help/troubleshooting/emails).

### Google ou GitHub indique que votre adresse e-mail n'est pas vérifiée [#google-or-github-says-your-email-isnt-verified]

Vérifiez d'abord l'adresse sur ce service, ou connectez-vous avec un code par e-mail envoyé à la même adresse.

### L'association de Google ou GitHub est refusée [#linking-google-or-github-is-refused]

Ce compte utilise une autre adresse e-mail que votre compte QRdx. Associez un compte ayant la même adresse, ou [changez d'abord votre adresse e-mail](#change-your-email-address).
