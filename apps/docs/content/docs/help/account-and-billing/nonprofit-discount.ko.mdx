등록된 비영리 단체와 자선 단체는 월간 또는 연간으로 결제하는 Pro나 Business를 {facts.nonprofitDiscountPercent}% 할인받을 수 있습니다. 할인은 코드로 제공되며, QRdx 팀이 단체 등록 정보를 확인한 후 결제할 때 입력하면 됩니다. 이 할인은 QRdx가 직접 제공하는 혜택이므로 qrdx.dev에서만 신청할 수 있습니다. 자체 호스팅 QRdx 서버는 결제를 별도로 운영합니다.

## 코드 요청하기 [#ask-for-a-code]

1. 로그인한 후 [요금제 페이지](/pricing)를 엽니다.
2. 요금제 아래 **Non-profit or charity?** 옆에 있는 **Ask for a code**를 클릭해요.
3. 단체 이름과 국가, 자선 단체 또는 비영리 단체 등록부에 기재된 번호(또는 공개 등록부에 있는 단체 정보 링크), 답변을 받을 이메일 주소, 원하는 요금제를 입력합니다.
4. **Send request**를 클릭해요.

요청은 이메일로 QRdx 팀에 전달되며, 저희가 등록 정보를 확인합니다. 보통 며칠 안에 답변을 드립니다. 단체가 자격 요건을 충족하면 답변에 할인 코드가 들어 있습니다. 결제를 완료하기 전에는 요금이 청구되지 않습니다.

## 코드 사용하기 [#use-the-code]

1. [요금제 페이지](/pricing)에서 **Monthly** 또는 **Yearly**를 선택하고 해당 요금제의 업그레이드 버튼을 클릭해요.
2. 결제 화면의 할인 입력란에 코드를 입력합니다. 결제하기 전에 가격이 내려가요.

할인은 갱신을 포함해 해당 구독의 모든 결제에 적용됩니다. 유료 요금제의 첫 결제와 마찬가지로 {facts.moneyBackDays}일 환불 보장이 적용돼요. [환불 정책](/legal/refunds)을 참고하세요.

## 문제가 생겼을 때 [#if-something-goes-wrong]

### 양식으로 요청을 보낼 수 없어요 [#the-form-cant-send-your-request]

같은 내용을 담아 [support@qrdx.dev](mailto:support@qrdx.dev)로 이메일을 보내 주세요.

### 결제할 때 코드가 거부돼요 [#the-code-is-refused-at-checkout]

코드가 발급된 요금제를 선택했는지, 요청서에 적은 계정으로 로그인했는지 확인하세요. 그래도 해결되지 않으면 코드를 보내 드린 이메일에 답장해 주세요.
