인쇄한 코드는 안전합니다. 이것이 [Never-Hostage 보장](/guarantee)이며, 무료를 포함한 모든 요금제에 적용됩니다. 이 페이지에서는 요금제를 낮추거나 구독을 취소하거나 결제에 실패했을 때 무엇이 계속 작동하고 무엇이 달라지는지 정확히 안내합니다.

## 저희가 약속하는 것 [#what-we-promise]

- **정적 QR 코드는 영원히 무료입니다.** 콘텐츠를 코드에 직접 담고 있으며 만료되지 않습니다.
- **동적 QR 코드는 계속 리디렉션됩니다.** 요금제를 낮추거나 결제에 실패하거나 구독을 취소한 뒤에도 마찬가지입니다.
- **일시 중지도 광고도 없습니다.** 결제 문제로 코드를 일시 중지하지 않으며, 스캔하는 사람을 QRdx 페이지로 보내지도 않습니다.
- **한도는 새로 만드는 것만 막습니다.** 기존 코드와 페이지는 계속 작동하며, 코드가 연결된 대상도 계속 변경할 수 있습니다.
- **모든 것을 내보낼 수 있습니다.** 모든 요금제에서 코드, 스캔 기록, 응답을 다운로드할 수 있습니다.
- **QRdx가 서비스를 종료하게 되면 12개월 전에 알려 드립니다.** 모든 데이터를 내보낼 시간을 드리고, 오픈 소스 앱을 직접 운영하는 방법도 문서로 안내합니다.

## 요금제를 낮춘 뒤에도 계속 작동하는 것 [#what-keeps-working-after-a-downgrade]

- 모든 동적 QR 코드와 모든 페이지.
- 이미 저장한 라우팅 규칙, 비밀번호, 일정, 픽셀.
- 이미 인증한 사용자 지정 도메인.

## 달라지는 것 [#what-changes]

- 새 요금제의 한도를 넘어서 새 코드나 페이지를 만들 수 없습니다.
- 스캔 기록에는 새 요금제에 포함된 범위만 표시됩니다. 삭제되는 것은 없으며, 다시 업그레이드하면 전부 표시됩니다.
- 무료 요금제의 페이지에는 "Made with QRdx" 푸터가 다시 표시됩니다.
- 월 한도에 도달하면 양식이 더 이상 응답을 받지 않습니다.
- 저장 용량 한도를 넘는 업로드는 차단됩니다.

## 코드가 중단되는 경우 [#what-does-stop-a-code]

직접 선택한 경우에만 중단됩니다. 일시 중지, 종료일, 스캔 횟수 제한, 보관, 삭제가 해당합니다. 또한 악용에 사용되는 코드는 QRdx가 비활성화할 수 있습니다.
