QRdx 没有密码。你可以使用 Google、GitHub 或发送到邮箱的验证码登录,你的账户与该邮箱地址绑定。本页介绍各种登录方式、如何关联它们、如何更改邮箱地址,以及无法访问邮箱时如何重新登录。

## 登录方式 [#ways-to-sign-in]

- **Google** 或 **GitHub**。
- **邮箱验证码**:输入你的邮箱并点击 **Email me a code**,然后输入我们发送的 6 位验证码。验证码有效期为 5 分钟。

<IfAvailable feature="passkeys">
[添加通行密钥](/docs/help/privacy-and-security/passkeys)后,你还可以点击 **Continue with passkey**,使用指纹、面容或屏幕锁登录。
</IfAvailable>

首次登录时,QRdx 会为你创建账户。

使用 Google 或 GitHub 登录时,只有在它们已验证你的邮箱地址的情况下,QRdx 才会创建账户。如果你的邮箱在那边尚未验证,请先完成验证(GitHub 会在 **Settings** → **Emails** 下列出你的邮箱地址),或者改用邮箱验证码登录。

## 你并未创建的、使用你邮箱地址的账户 [#an-account-for-your-address-you-didnt-make]

如果 QRdx 中已经存在一个使用你的邮箱地址、但并非由你创建的账户,请使用邮箱验证码登录。验证码证明该地址属于你之后,QRdx 会移除先前注册者可能用来重新登录或持续获取该账户数据的内容:

- 该账户的 Google 和 GitHub 关联,以及所有会话;
- 该账户的两步验证和受信任设备<IfAvailable feature="passkeys">,以及它的通行密钥</IfAvailable>;
- 该账户的 API 密钥,以及它授权使用该账户的应用;
- 它设置的 webhook 以及 Slack 和 Discord 提醒,还有它设置的、将扫描记录或表单回答发送到其他工具的同步。

账户中的其他内容都会保留,因此事后请检查其中的工作区及其成员。

## 关联 Google 或 GitHub [#link-google-or-github]

前往 **Settings** → **Profile & security** → **Sign-in methods**。

- **邮箱验证码**始终处于开启状态。
- 关联 Google 或 GitHub 后即可一键登录。该账户使用的邮箱地址必须与你的 QRdx 账户相同。
- 点击 **Unlink** 可移除某个关联。

## 更改邮箱地址 [#change-your-email-address]

1. 前往 **Settings** → **Profile & security**。
2. 在 **Email** 旁点击 **Change**,并[确认是你本人操作](/docs/help/privacy-and-security/two-step-verification#confirm-its-you)。
3. 输入新地址,并输入我们发送到该地址的验证码。

之后,QRdx 会让你在其他所有设备和浏览器上退出登录,并向你的旧地址发送一封邮件,说明账户已迁移,同时提供联系支持团队的方式,以防这并非你本人操作。

## 无法访问邮箱 [#lost-access-to-your-email]

如果你仍能进入 QRdx,请按上述步骤自行更改邮箱。若要在无法使用邮箱的情况下确认是你本人,可以使用<IfAvailable feature="passkeys">你的通行密钥、</IfAvailable>你已关联的 Google 或 GitHub 账户,或已开启的两步验证方式。已退出登录?请先用<IfAvailable feature="passkeys">你的通行密钥或</IfAvailable>已关联的 Google 或 GitHub 账户登录。

如果以上方式都不可行,请使用你想要启用的邮箱地址发送邮件至 [support@qrdx.dev](mailto:support@qrdx.dev)。将账户迁移到新地址是支持团队处理的最敏感的事务,因此要经过三个步骤:

1. **我们需要证明该账户属于你。** 我们会询问账户的邮箱地址,以及以下其中一项:如果你为 QRdx 付过费,请提供某张[发票](/docs/help/account-and-billing/invoices)上的编号及大致付款时间;如果你账户下的某个工作区使用了自己的[域名](/docs/help/domains/custom-domains),则需要在该域名下添加我们发给你的 DNS 记录。
2. **我们通知旧地址并等待 7 天。** 在此期间,如果有人从旧地址回复并表示反对,我们将停止处理。
3. **然后我们迁移账户。** 我们会把账户邮箱改为新地址,让账户在所有地方退出登录,并向旧地址发送邮件。请使用发送到新地址的验证码登录。如果你开启了两步验证,它将保持不变。

如果我们无法确认该账户属于你,就不会迁移它,即使这会让你无法再访问该账户。把账户交给错误的人后果更严重。

在旧地址停用之前,请先添加通行密钥或关联 Google 或 GitHub,这样你始终可以确认是你本人。

## 退出其他设备的登录 [#sign-out-of-other-devices]

在 **Settings** → **Profile & security** 的 **Sessions** 下,可以退出某一台设备,也可以点击 **Sign out everywhere else**。

## 出现问题时 [#if-something-goes-wrong]

### 收不到登录验证码 [#the-sign-in-code-doesnt-arrive]

请参阅[收不到登录验证码或邮件](/docs/help/troubleshooting/emails)。

### Google 或 GitHub 提示你的邮箱未验证 [#google-or-github-says-your-email-isnt-verified]

请先在那边验证该地址,或使用邮箱验证码登录同一个地址。

### 关联 Google 或 GitHub 被拒绝 [#linking-google-or-github-is-refused]

该账户使用的邮箱地址与你的 QRdx 账户不同。请关联一个地址相同的账户,或者先[更改你的邮箱](#change-your-email-address)。
