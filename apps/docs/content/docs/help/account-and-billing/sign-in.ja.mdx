QRdx にパスワードはありません。Google、GitHub、またはメールに届くコードでログインし、アカウントはそのメールアドレスに紐づきます。このページでは、ログイン方法、その連携、メールアドレスの変更、メールボックスにアクセスできなくなったときに再びログインする方法を説明します。

## ログイン方法 [#ways-to-sign-in]

- **Google** または **GitHub**。
- **メールコード**：メールアドレスを入力して **Email me a code** をクリックし、届いた6桁のコードを入力します。コードの有効時間は5分です。

<IfAvailable feature="passkeys">
[パスキーを追加](/docs/help/privacy-and-security/passkeys)すると、**Continue with passkey** をクリックして、指紋、顔、または画面ロックでログインすることもできます。
</IfAvailable>

初めてログインすると、QRdx がアカウントを作成します。

Google または GitHub の場合、QRdx はメールアドレスが認証済みのときだけアカウントを作成します。認証されていない場合は、先に認証するか（GitHub では **Settings** → **Emails** にアドレスの一覧があります）、代わりにメールコードでログインしてください。

## 自分で作成していない、あなたのアドレスのアカウント [#an-account-for-your-address-you-didnt-make]

あなたのアドレスのアカウントがすでに QRdx にあり、自分で作成したものでない場合は、メールコードでログインしてください。それによってアドレスがあなたのものだと確認されると、QRdx は、以前の登録者が再びログインしたりアカウントのデータを取得し続けたりするのに使える次の情報を削除します。

- Google と GitHub の連携、およびすべてのセッション
- 2段階認証と信頼済みデバイス<IfAvailable feature="passkeys">、およびパスキー</IfAvailable>
- API キー、およびアカウントの利用を許可したアプリ
- 設定されていた Webhook、Slack と Discord のアラート、スキャンやフォームの回答を他のツールに送る連携

それ以外のアカウントの内容は残るため、あとでワークスペースとそのメンバーを確認してください。

## Google または GitHub を連携する [#link-google-or-github]

**Settings** → **Profile & security** → **Sign-in methods** に移動します。

- **メールコード** は常に有効です。
- Google または GitHub を連携すると、ワンクリックでログインできます。アカウントのメールアドレスは QRdx アカウントと同じである必要があります。
- 連携を解除するには **Unlink** をクリックします。

## メールアドレスを変更する [#change-your-email-address]

1. **Settings** → **Profile & security** に移動します。
2. **Email** の横にある **Change** をクリックし、[本人確認](/docs/help/privacy-and-security/two-step-verification#confirm-its-you)を行います。
3. 新しいアドレスを入力し、そのアドレスに届くコードを入力します。

その後、QRdx は他のすべてのデバイスとブラウザからログアウトします。古いアドレスには、アカウントが移動したことを知らせるメールが届きます。このメールには、本人の操作でない場合にサポートへ連絡する方法も記載されています。

## メールにアクセスできなくなった場合 [#lost-access-to-your-email]

QRdx にまだログインできる場合は、上記のとおり自分でメールアドレスを変更してください。メールボックスなしで本人確認を行うには、<IfAvailable feature="passkeys">パスキー、</IfAvailable>連携済みの Google または GitHub アカウント、または有効にしている場合は2段階認証の方法を使います。ログアウトしている場合は、まず<IfAvailable feature="passkeys">パスキーまたは</IfAvailable>連携済みの Google または GitHub アカウントでログインしてください。

どれも使えない場合は、使いたいアドレスから [support@qrdx.dev](mailto:support@qrdx.dev) にメールを送ってください。アカウントを新しいアドレスに移すことはサポートが行う作業の中で最も慎重を要するため、次の3つの手順で進めます。

1. **アカウントがあなたのものである証明が必要です。** アカウントのメールアドレスと、次のいずれかをお尋ねします。QRdx に支払いをしている場合は、[請求書](/docs/help/account-and-billing/invoices)のいずれかの番号とおおよその支払い時期。アカウント内のワークスペースが独自の[ドメイン](/docs/help/domains/custom-domains)を使っている場合は、こちらからお送りする DNS レコードをそのドメインに追加してください。
2. **古いアドレスに通知し、7日間待ちます。** その間に古いアドレスから返信があり、拒否された場合は、手続きを中止します。
3. **その後、アカウントを移します。** アカウントのメールアドレスを新しいアドレスに変更し、すべての場所からログアウトして、古いアドレスにメールを送ります。新しいアドレスに届くコードでログインしてください。2段階認証は、有効にしていれば、そのまま維持されます。

アカウントがあなたのものであると確認できない場合は、たとえアクセスできないままになったとしても、アカウントは移しません。誤った相手に渡してしまうほうが問題が大きいためです。

古いアドレスが使えなくなる前に、パスキーを追加するか Google または GitHub を連携しておくと、いつでも本人確認ができます。

## 他のデバイスからログアウトする [#sign-out-of-other-devices]

**Settings** → **Profile & security** の **Sessions** で、1台のデバイスからログアウトするか、**Sign out everywhere else** をクリックします。

## 問題が起きた場合 [#if-something-goes-wrong]

### ログインコードが届かない [#the-sign-in-code-doesnt-arrive]

[ログインコードやメールが届かない](/docs/help/troubleshooting/emails)をご覧ください。

### Google または GitHub でメールが未認証と表示される [#google-or-github-says-your-email-isnt-verified]

先にそちらでアドレスを認証するか、同じアドレス宛てのメールコードでログインしてください。

### Google または GitHub の連携が拒否される [#linking-google-or-github-is-refused]

そのアカウントは QRdx アカウントとは異なるメールアドレスを使っています。同じアドレスのアカウントを連携するか、先に[メールアドレスを変更](#change-your-email-address)してください。
