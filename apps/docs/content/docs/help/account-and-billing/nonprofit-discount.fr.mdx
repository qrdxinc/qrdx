Les associations et organismes caritatifs enregistrés bénéficient de {facts.nonprofitDiscountPercent} % de réduction sur Pro ou Business, en facturation mensuelle ou annuelle. La réduction prend la forme d'un code que vous saisissez au moment du paiement, une fois que l'équipe QRdx a vérifié votre enregistrement. Il s'agit d'une offre propre à QRdx : elle est proposée sur qrdx.dev, et un serveur QRdx auto-hébergé a sa propre facturation.

<IfAvailable feature="nonprofitDiscounts">

## Demander un code [#ask-for-a-code]

1. Connectez-vous et ouvrez la [page des tarifs](/pricing).
2. Sous les offres, à côté de **Association ou organisme caritatif ?**, cliquez sur **Demander un code**.
3. Saisissez le nom et le pays de votre organisation, votre numéro dans un registre des associations ou des organismes caritatifs (ou un lien vers votre fiche dans un registre public), l'adresse e-mail à laquelle nous devons répondre, et l'offre souhaitée.
4. Cliquez sur **Envoyer la demande**.

La demande parvient par e-mail à l'équipe QRdx, qui vérifie l'enregistrement. Nous répondons généralement sous quelques jours. Si votre organisation est éligible, la réponse contient un code de réduction. Rien n'est facturé avant le paiement.

## Utiliser le code [#use-the-code]

1. Sur la [page des tarifs](/pricing), choisissez **Mensuel** ou **Annuel** et cliquez sur le bouton de mise à niveau de l'offre.
2. Au moment du paiement, saisissez le code dans le champ de réduction. Le prix baisse avant que vous ne payiez.

La réduction s'applique à chaque paiement de cet abonnement, renouvellements compris. Comme tout premier paiement d'une offre payante, il est couvert par une garantie de remboursement de {facts.moneyBackDays} jours. Consultez la [politique de remboursement](/legal/refunds).

## En cas de problème [#if-something-goes-wrong]

### Le formulaire ne parvient pas à envoyer votre demande [#the-form-cant-send-your-request]

Écrivez à [support@qrdx.dev](mailto:support@qrdx.dev) en indiquant les mêmes informations.

### Le code est refusé au moment du paiement [#the-code-is-refused-at-checkout]

Vérifiez que vous avez choisi l'offre pour laquelle le code a été émis et que vous êtes connecté au compte indiqué dans la demande. Si le problème persiste, répondez à l'e-mail qui vous a envoyé le code.
