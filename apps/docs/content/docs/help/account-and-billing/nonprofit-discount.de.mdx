Eingetragene gemeinnützige Organisationen und Wohltätigkeitsorganisationen erhalten {facts.nonprofitDiscountPercent}% Rabatt auf Pro oder Business, bei monatlicher oder jährlicher Abrechnung. Der Rabatt kommt als Code, den du beim Checkout eingibst, nachdem das QRdx-Team deine Registrierung geprüft hat. Es ist ein eigenes Angebot von QRdx und gilt daher auf qrdx.dev; ein selbst gehosteter QRdx-Server hat eine eigene Abrechnung.

## Code anfragen [#ask-for-a-code]

1. Melde dich an und öffne die [Preisseite](/pricing).
2. Klicke unter den Tarifen neben **Gemeinnützig oder Wohltätigkeitsorganisation?** auf **Code anfragen**.
3. Gib den Namen und das Land deiner Organisation ein, deine Nummer in einem Register für Wohltätigkeitsorganisationen oder gemeinnützige Organisationen (oder einen Link zu deinem Eintrag in einem öffentlichen Register), die E-Mail-Adresse, an die wir antworten sollen, und den gewünschten Tarif.
4. Klicke auf **Anfrage senden**.

Die Anfrage erreicht das QRdx-Team per E-Mail, und wir prüfen die Registrierung. Meist antworten wir innerhalb weniger Tage. Wenn deine Organisation berechtigt ist, enthält die Antwort einen Rabattcode. Es wird nichts abgebucht, bevor du zur Kasse gehst.

## Code verwenden [#use-the-code]

1. Wähle auf der [Preisseite](/pricing) **Monatlich** oder **Jährlich** und klicke auf die Upgrade-Schaltfläche für den Tarif.
2. Gib beim Checkout den Code im Rabattfeld ein. Der Preis sinkt, bevor du zahlst.

Der Rabatt gilt für jede Zahlung dieses Abonnements, auch für Verlängerungen. Wie jede erste Zahlung für einen kostenpflichtigen Tarif ist sie durch eine {facts.moneyBackDays}-Tage-Geld-zurück-Garantie abgesichert. Siehe die [Erstattungsrichtlinie](/legal/refunds).

## Wenn etwas schiefgeht [#if-something-goes-wrong]

### Das Formular kann deine Anfrage nicht senden [#the-form-cant-send-your-request]

Schreib mit denselben Angaben eine E-Mail an [support@qrdx.dev](mailto:support@qrdx.dev).

### Der Code wird beim Checkout abgelehnt [#the-code-is-refused-at-checkout]

Prüfe, ob du den Tarif gewählt hast, für den der Code ausgestellt wurde, und ob du in dem Konto angemeldet bist, das du in der Anfrage angegeben hast. Wenn es trotzdem nicht klappt, antworte auf die E-Mail, mit der du den Code erhalten hast.
