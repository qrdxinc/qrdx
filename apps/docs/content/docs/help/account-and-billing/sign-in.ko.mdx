QRdx에는 비밀번호가 없습니다. Google, GitHub 또는 이메일로 받은 코드로 로그인하며, 계정은 해당 이메일 주소에 연결됩니다. 이 페이지에서는 로그인 방법, 로그인 방법 연결, 이메일 주소 변경, 메일함에 접근할 수 없을 때 다시 로그인하는 방법을 설명합니다.

## 로그인 방법 [#ways-to-sign-in]

- **Google** 또는 **GitHub**
- **이메일 코드**: 이메일 주소를 입력하고 **Email me a code**를 클릭한 다음, 전송된 6자리 코드를 입력해요. 코드는 5분 동안 유효합니다.

<IfAvailable feature="passkeys">
[패스키를 추가](/docs/help/privacy-and-security/passkeys)했다면 **Continue with passkey**를 클릭해 지문, 얼굴 또는 화면 잠금으로 로그인할 수도 있습니다.
</IfAvailable>

처음 로그인하면 QRdx가 계정을 만듭니다.

Google 또는 GitHub로 로그인하는 경우, 해당 서비스에서 이메일 주소를 인증한 경우에만 QRdx가 계정을 만듭니다. 이메일이 인증되지 않았다면 먼저 인증하거나(GitHub에서는 **Settings** → **Emails**에서 주소 목록을 확인할 수 있습니다) 이메일 코드로 로그인하세요.

## 본인이 만들지 않은 내 주소의 계정 [#an-account-for-your-address-you-didnt-make]

QRdx에 내 이메일 주소로 만들어진 계정이 이미 있는데 본인이 만든 것이 아니라면, 이메일 코드로 로그인하세요. 코드로 해당 주소가 본인 것임이 확인되면, QRdx는 이전 가입자가 다시 접근하거나 계정 데이터를 계속 받는 데 사용할 수 있는 항목을 제거합니다.

- Google 및 GitHub 연결과 모든 세션
- 2단계 인증과 신뢰할 수 있는 기기<IfAvailable feature="passkeys">, 그리고 패스키</IfAvailable>
- API 키와 계정 사용을 허용한 앱
- 설정해 둔 웹훅, Slack 및 Discord 알림, 그리고 스캔이나 양식 응답을 다른 도구로 보내도록 설정한 모든 동기화

그 외의 모든 항목은 계정에 그대로 남으므로, 이후에 워크스페이스와 멤버를 확인하세요.

## Google 또는 GitHub 연결 [#link-google-or-github]

**Settings** → **Profile & security** → **Sign-in methods**로 이동하세요.

- **Email code**는 항상 켜져 있어요.
- Google 또는 GitHub를 연결하면 한 번의 클릭으로 로그인할 수 있습니다. 해당 계정은 QRdx 계정과 같은 이메일 주소를 사용해야 합니다.
- 연결을 해제하려면 **Unlink**를 클릭하세요.

## 이메일 주소 변경 [#change-your-email-address]

1. **Settings** → **Profile & security**로 이동하세요.
2. **Email** 옆의 **Change**를 클릭하고 [본인 확인](/docs/help/privacy-and-security/two-step-verification#confirm-its-you)을 진행하세요.
3. 새 주소를 입력하고 해당 주소로 전송된 코드를 입력하세요.

그러면 QRdx는 다른 모든 기기와 브라우저에서 로그아웃시키고, 이전 주소로 계정이 이전되었다는 이메일을 보냅니다. 본인이 아닌 경우 지원팀에 연락할 수 있는 방법도 함께 안내합니다.

## 이메일에 접근할 수 없을 때 [#lost-access-to-your-email]

아직 QRdx에 접근할 수 있다면 위의 방법대로 직접 이메일을 변경하세요. 메일함 없이 본인임을 확인하려면 <IfAvailable feature="passkeys">패스키, </IfAvailable>연결해 둔 Google 또는 GitHub 계정, 또는 켜 두었다면 2단계 인증 방법을 사용하세요. 로그아웃된 상태라면 먼저 <IfAvailable feature="passkeys">패스키 또는 </IfAvailable>연결된 Google 또는 GitHub 계정으로 로그인하세요.

이 방법으로 해결되지 않으면 사용하려는 주소에서 [support@qrdx.dev](mailto:support@qrdx.dev)로 이메일을 보내 주세요. 계정을 새 주소로 옮기는 일은 지원팀이 처리하는 작업 중 가장 민감하기 때문에 세 단계로 진행합니다.

1. **계정이 본인 것이라는 증거가 필요합니다.** 계정의 이메일 주소와 다음 중 하나를 요청합니다. QRdx를 결제한 적이 있다면 [인보이스](/docs/help/account-and-billing/invoices) 중 하나의 번호와 대략적인 결제 시기, 계정의 워크스페이스가 자체 [도메인](/docs/help/domains/custom-domains)을 사용한다면 저희가 보내 드리는 DNS 레코드를 해당 도메인에 추가한 것입니다.
2. **이전 주소로 알리고 7일 동안 기다립니다.** 그 기간에 이전 주소에서 누군가 응답해 거절하면 절차를 중단합니다.
3. **그다음 계정을 이전합니다.** 계정의 이메일을 새 주소로 변경하고, 모든 곳에서 로그아웃시키며, 이전 주소로 이메일을 보냅니다. 새 주소로 전송된 코드로 로그인하세요. 2단계 인증을 켜 두었다면 그대로 유지됩니다.

계정이 본인 것임을 확인할 수 없다면, 계정에 접근할 수 없게 되더라도 이전하지 않습니다. 엉뚱한 사람에게 계정을 넘기는 것이 더 큰 문제이기 때문입니다.

이전 주소를 사용할 수 없게 되기 전에 패스키를 추가하거나 Google 또는 GitHub를 연결해 두세요. 그러면 언제든 본인임을 확인할 수 있습니다.

## 다른 기기에서 로그아웃 [#sign-out-of-other-devices]

**Settings** → **Profile & security**의 **Sessions**에서 기기 하나를 로그아웃하거나 **Sign out everywhere else**를 클릭하세요.

## 문제가 생겼을 때 [#if-something-goes-wrong]

### 로그인 코드가 도착하지 않아요 [#the-sign-in-code-doesnt-arrive]

[로그인 코드나 이메일이 도착하지 않을 때](/docs/help/troubleshooting/emails)를 참고하세요.

### Google 또는 GitHub에서 이메일이 인증되지 않았다고 해요 [#google-or-github-says-your-email-isnt-verified]

해당 서비스에서 먼저 주소를 인증하거나, 같은 주소로 이메일 코드를 받아 로그인하세요.

### Google 또는 GitHub 연결이 거부돼요 [#linking-google-or-github-is-refused]

해당 계정이 QRdx 계정과 다른 이메일 주소를 사용하고 있습니다. 같은 주소를 사용하는 계정을 연결하거나, 먼저 [이메일을 변경](#change-your-email-address)하세요.
