사용자 지정 도메인을 사용하면 코드에 `qrdx.dev` 링크 대신 `go.yourbrand.com/…`가 담기므로, 사람들이 스캔하기 전에 여러분의 브랜드를 먼저 보게 됩니다. 이 페이지에서는 도메인을 연결해 코드에 적용하는 방법을 안내합니다. 자세한 내용은 [사용자 지정 도메인 가이드](/docs/custom-domains)를 참고하세요.

<Callout type="info">
  Pro는 도메인 5개, Business는 25개를 포함합니다. 도메인은 워크스페이스 소유자와 관리자가 추가하고 확인하며, 확인된 도메인은 모든 멤버가 사용할 수 있습니다. [플랜과 포함 내용](/docs/help/account-and-billing/plans)을 참고하세요.
</Callout>

## 도메인 연결하기 [#connect-a-domain]

### 1. 도메인 추가하기 [#1-add-the-domain]

대시보드에서 **설정** → **도메인**으로 이동한 뒤 **도메인 추가**를 클릭하세요. 도메인을 입력합니다. 예: `go.yourbrand.com`. `go.`나 `qr.` 같은 서브도메인을 사용하는 것이 가장 좋습니다. 메인 웹사이트는 그대로 유지됩니다.

### 2. DNS 레코드 추가하기 [#2-add-the-dns-records]

QRdx가 추가할 레코드를 **유형**, **이름**, **값**과 함께 보여 줍니다. 도메인을 구입했거나 DNS를 관리하는 DNS 제공업체에서 값을 그대로 복사해 추가하세요.<IfAvailable feature="domainConnect"> QRdx가 사용 중인 제공업체를 인식하면 **설정하기**를 클릭해 제공업체 이름으로 대신 설정할 수 있습니다. 해당 사이트에서 변경을 승인하고 돌아오면 됩니다.</IfAvailable>

<Shot id="dns-records" />

### 3. 확인하기 [#3-verify]

**확인**을 클릭하세요. 레코드가 발견될 때까지 상태는 **DNS 대기 중**으로 표시되고, 발견되면 **확인됨**으로 바뀌며 QRdx가 이제 동적 QR 코드에 이 도메인을 선택할 수 있다고 알려 줍니다. DNS 변경은 보통 몇 분 안에 반영되지만 최대 48시간이 걸릴 수 있습니다.

## 코드에 사용하기 [#use-it-for-a-code]

- **새 코드:** **코드 만들기**를 클릭하기 전에 **짧은 링크 도메인**에서 도메인을 선택하세요.
- **기존 코드:** **링크 편집**을 열고 도메인을 선택한 뒤 **변경 사항 저장**을 클릭하세요. 코드에 새 링크가 담기므로 다시 다운로드하세요. `qrdx.dev` 링크로 이미 인쇄한 코드는 계속 작동합니다.

## 인쇄한 코드는 계속 작동합니다 [#printed-codes-keep-working]

모든 코드는 `qrdx.dev` 링크에서도 계속 작동하므로, 도메인을 옮기기 전에 인쇄한 코드가 깨지지 않습니다.

코드를 한 사용자 지정 도메인에서 다른 사용자 지정 도메인으로 옮기면 이전 도메인으로 인쇄한 코드는 작동하지 않게 됩니다. 저장하기 전에 QRdx가 경고해 드려요.

## 문제가 생겼다면 [#if-something-goes-wrong]

### 상태가 DNS 대기 중에서 바뀌지 않아요 [#the-status-stays-on-waiting-for-dns]

각 레코드의 이름과 값이 QRdx에 표시된 내용과 일치하는지, 불필요한 문자가 없는지 확인한 뒤 **DNS 확인**을 클릭하세요. 일부 제공업체는 변경 사항을 게시하는 데 몇 시간이 걸리고, 일부는 최대 48시간이 걸립니다.

### DNS 제공업체가 레코드를 추가하지 않았어요 [#your-dns-provider-didnt-add-the-records]

자동 설정이 완료되지 않았습니다. 도메인 아래의 표를 보고 직접 레코드를 추가한 뒤 **확인**을 클릭하세요.

### 스캔하면 "이 도메인은 아직 연결되지 않았습니다"라고 나와요 [#scanners-see-this-domain-isnt-connected-yet]

코드에는 이미 도메인이 담겨 있지만 DNS 설정이 끝나지 않은 상태입니다. 위의 단계를 마무리하세요. 도메인이 **확인됨**이 되는 즉시 코드가 작동합니다.
