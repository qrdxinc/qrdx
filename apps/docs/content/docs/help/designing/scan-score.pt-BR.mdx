title: "Verifique um design com a pontuação de leitura"

---

Todo design no [Playground](/playground) recebe uma **Pontuação de leitura** de 0 a 100, exibida abaixo da prévia, por exemplo "Pontuação de leitura 92 · Ótimo". Ela testa o código como a câmera de um celular faria, para você corrigir problemas antes de imprimir.

<Shot id="playground-content" />

## O que a pontuação significa [#what-the-score-means]

| Nível | Pontuação | O que fazer |
| --- | --- | --- |
| **Ótimo** | 85 ou mais | Pronto para imprimir. |
| **OK** | 65 a 84 | Deve ser lido. Veja os avisos. |
| **Arriscado** | Abaixo de 65 | Corrija as verificações marcadas com um X. |
| **Falha** | | O código não foi decodificado no maior tamanho de teste, ou o contraste está baixo demais. Não imprima. |

## Veja o que corrigir [#see-what-to-fix]

Clique na pontuação. O painel **Vai ser lido?** lista todas as verificações, com as que falharam primeiro.

<Shot id="scan-score-panel" />

As verificações são:

- **Decodificação**: o código é lido em três tamanhos, com um desfoque parecido com o de uma câmera.
- **Contraste**: o código e o fundo devem ter uma diferença de 4,5:1 ou mais.
- **Escuro sobre claro**: códigos escuros sobre fundos claros são lidos em mais apps.
- **Logo**: um logo não pode cobrir mais do que a correção de erros consegue reconstruir, nem tocar em um olho de canto.
- **Formato dos olhos**: olhos circulares e ondulados falham em alguns apps leitores.
- **Zona de silêncio**: a borda vazia ao redor do código. Quatro módulos é o ideal.

## Correções rápidas [#quick-fixes]

| A verificação | A correção |
| --- | --- |
| Contraste baixo | Deixe o código mais escuro ou o fundo mais claro. Veja [Escolha cores que funcionam na leitura](/docs/help/designing/colors-and-contrast). |
| Logo cobre demais | Defina **Correção de erros** como **Alta** ou diminua o logo. Veja [Adicione um logo](/docs/help/designing/logos). |
| Formato dos olhos | Mude para olhos quadrados, arredondados ou de engrenagem. |
| Zona de silêncio | Defina **Margem** como **Padrão** ou **Grande**. |

## Verifique um código impresso [#check-a-printed-code]

A pontuação testa o design na tela. Para testar um código que você já imprimiu, tire uma foto e solte-a no [verificador de leitura](/tools/scan-checker). A imagem nunca sai do seu dispositivo.
