[Playground](/playground) 中的每个设计都会获得一个 0 到 100 的**扫描评分**，显示在预览下方，例如“扫描评分 92 · 优秀”。它会模拟手机摄像头来测试二维码，让你在打印之前就能修复问题。

<Shot id="playground-content" />

## 评分的含义 [#what-the-score-means]

| 等级 | 分数 | 该怎么做 |
| --- | --- | --- |
| **优秀** | 85 或更高 | 可以打印。 |
| **一般** | 65 至 84 | 应该可以扫描。请查看警告。 |
| **有风险** | 低于 65 | 修复标有叉号的检查项。 |
| **失败** | | 二维码在最大测试尺寸下无法解码，或者对比度过低。请勿打印。 |

## 查看需要修复的内容 [#see-what-to-fix]

点击评分，**能否扫描？**面板会列出所有检查项，未通过的排在最前面。

<Shot id="scan-score-panel" />

检查项包括：

- **解码**：在三种尺寸下，用类似摄像头的模糊效果读取二维码。
- **对比度**：二维码与背景的对比度应不低于 4.5:1。
- **深色on浅色**：深色二维码搭配浅色背景，能被更多应用扫描。
- **Logo**：Logo 覆盖的面积不能超过纠错能力可以还原的范围，也不能触碰定位角的眼部。
- **定位眼形状**：圆形和卷曲形的定位眼在某些扫描应用中会失败。
- **静区**：二维码周围的空白边框。理想宽度为四个模块。

## 快速修复 [#quick-fixes]

| 检查项 | 修复方法 |
| --- | --- |
| 对比度低 | 让二维码颜色更深，或让背景更浅。参见[选择易于扫描的颜色](/docs/help/designing/colors-and-contrast)。 |
| Logo 遮挡过多 | 将**纠错等级**设为**高**，或缩小 Logo。参见[添加 Logo](/docs/help/designing/logos)。 |
| 定位眼形状 | 改用方形、圆角或齿轮形定位眼。 |
| 静区 | 将**边距**设为**标准**或**大**。 |

## 检查已打印的二维码 [#check-a-printed-code]

评分测试的是屏幕上的设计。若要测试已经打印出来的二维码，请拍一张照片，然后拖入[扫描检测工具](/tools/scan-checker)。图片不会离开你的设备。
