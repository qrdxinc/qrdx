Jedes Design im [Playground](/playground) bekommt einen **Scan-Score** von 0 bis 100. Er steht unter der Vorschau, zum Beispiel „Scan-Score 92 · Great". Der Score testet den Code so, wie es eine Handykamera tun würde. So kannst du Probleme beheben, bevor du druckst.

<Shot id="playground-content" />

## Was der Score bedeutet [#what-the-score-means]

| Bewertung | Score | Was zu tun ist |
| --- | --- | --- |
| **Great** | 85 oder mehr | Bereit zum Drucken. |
| **OK** | 65 bis 84 | Er sollte sich scannen lassen. Lies die Warnungen. |
| **Risky** | Unter 65 | Behebe die Prüfungen, die mit einem Kreuz markiert sind. |
| **Fails** | | Der Code wurde bei der größten Testgröße nicht dekodiert, oder der Kontrast ist viel zu niedrig. Drucke ihn nicht. |

## Sieh, was du beheben musst [#see-what-to-fix]

Klicke auf den Score. Das Panel **Will it scan?** listet alle Prüfungen auf, die fehlgeschlagenen zuerst.

<Shot id="scan-score-panel" />

Das sind die Prüfungen:

- **Decoding**: Der Code wird in drei Größen mit einer kameraähnlichen Unschärfe gelesen.
- **Contrast**: Code und Hintergrund sollten sich um mindestens 4,5:1 unterscheiden.
- **Dark on light**: Dunkle Codes auf hellem Hintergrund lassen sich in mehr Apps scannen.
- **Logo**: Ein Logo darf nicht mehr abdecken, als die Fehlerkorrektur wiederherstellen kann, und darf keine Eckaugen berühren.
- **Eye shape**: Kreisförmige und geschwungene Augen scheitern in manchen Scanner-Apps.
- **Quiet zone**: der leere Rand um den Code. Ideal sind vier Module.

## Schnelle Lösungen [#quick-fixes]

| Die Prüfung | Die Lösung |
| --- | --- |
| Niedriger Kontrast | Mache den Code dunkler oder den Hintergrund heller. Siehe [Farben wählen, die sich scannen lassen](/docs/help/designing/colors-and-contrast). |
| Logo deckt zu viel ab | Stelle **Error correction** auf **High** oder mache das Logo kleiner. Siehe [Logo hinzufügen](/docs/help/designing/logos). |
| Eye shape | Wechsle zu quadratischen, abgerundeten oder zahnradförmigen Augen. |
| Quiet zone | Stelle **Padding** auf **Standard** oder **Large**. |

## Gedruckten Code prüfen [#check-a-printed-code]

Der Score testet das Design am Bildschirm. Um einen Code zu testen, den du schon gedruckt hast, mache ein Foto und lade es in den [Scan-Checker](/tools/scan-checker) hoch. Das Bild verlässt dein Gerät nie.
