title: "Choisir des couleurs qui se scannent"
description: "Gardez un code foncé sur un fond clair, conservez un fort contraste et utilisez les dégradés avec précaution."
---

Les lecteurs de QR code recherchent des carrés foncés sur un fond clair. La plupart des problèmes de couleur viennent du non-respect de cette règle. Cette page indique où se trouvent les couleurs dans le Playground et comment garder un code scannable lorsque vous les modifiez.

## Modifier les couleurs [#change-the-colors]

1. Dans le [Playground](/playground?tab=design&section=colors), ouvrez l'onglet **Design**, puis **Couleurs**.
2. Choisissez la couleur à modifier. **Arrière-plan** correspond à la zone derrière le code. **Premier plan** colore les petits carrés qui contiennent vos données. **Yeux** colore les trois grands carrés des coins. **Points** colore le centre de chaque carré de coin.
3. Choisissez un remplissage : **Uni**, **Linéaire**, **Radial**, **Angulaire** ou **Image**.

L'aperçu et le **Score de scan** situé en dessous se mettent à jour au fur et à mesure. **Palettes de couleurs**, sous les quatre couleurs, permet de toutes les définir en une fois.

## Règles pour garder un code scannable [#rules-that-keep-a-code-scannable]

- **Code foncé, fond clair.** Les codes clairs sur fond foncé échouent dans certaines applications d'appareil photo.
- **Fort contraste.** Visez un rapport de contraste d'au moins 4,5:1 entre le code et le fond.
- **Des dégradés restant foncés.** Un dégradé convient lorsque chacune de ses couleurs est assez foncée par rapport au fond.
- **Fond uni.** Une photo chargée derrière le code le rend plus difficile à lire. Si vous voulez une image dans le code, utilisez plutôt [Image QR](/docs/help/designing/art), qui teste le résultat pour vous.

## Vérifier le contraste [#check-the-contrast]

**Vérificateur de contraste**, dans la barre d'outils au-dessus de l'aperçu, affiche le rapport pour vos couleurs et signale les paires inférieures à 4,5:1.

Le **Score de scan** sous l'aperçu vérifie aussi le contraste, ainsi que la taille, la zone de silence et le logo. Voir [Vérifier un design avec le score de scan](/docs/help/designing/scan-score).

## En cas de problème [#if-something-goes-wrong]

### Le score indique Échec après un changement de couleur [#the-score-says-fails-after-a-color-change]

Le contraste est beaucoup trop faible pour qu'un appareil photo distingue le code du fond. Assombrissez le premier plan ou éclaircissez le fond jusqu'à ce que le score remonte.

### Le code se scanne sur votre téléphone, mais pas sur d'autres [#it-scans-on-your-phone-but-not-on-other-phones]

Les codes clair sur foncé et les paires à faible contraste sont lus par certains appareils photo et pas par d'autres. Inversez les couleurs pour que le code soit la partie foncée, et amenez le rapport à 4,5:1 ou plus.

### Un dégradé fait passer le score à Risqué [#a-gradient-makes-the-score-risky]

Une extrémité du dégradé est trop claire. Rapprochez les deux couleurs de l'extrémité foncée, ou utilisez un premier plan uni et réservez le dégradé aux yeux.
