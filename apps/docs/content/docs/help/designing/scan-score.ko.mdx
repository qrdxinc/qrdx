[Playground](/playground)의 모든 디자인에는 미리보기 아래에 0부터 100까지의 **스캔 점수**가 표시됩니다. 예: "스캔 점수 92 · 훌륭함". 휴대폰 카메라처럼 코드를 테스트하므로, 인쇄하기 전에 문제를 고칠 수 있습니다.

<Shot id="playground-content" />

## 점수의 의미 [#what-the-score-means]

| 등급 | 점수 | 해야 할 일 |
| --- | --- | --- |
| **훌륭함** | 85 이상 | 바로 인쇄해도 됩니다. |
| **보통** | 65~84 | 스캔은 될 것입니다. 경고를 읽어 보세요. |
| **위험** | 65 미만 | X 표시가 있는 검사 항목을 고치세요. |
| **실패** | | 가장 큰 테스트 크기에서 코드가 해독되지 않았거나, 대비가 너무 낮습니다. 인쇄하지 마세요. |

## 고칠 부분 확인하기 [#see-what-to-fix]

점수를 클릭하세요. **스캔될까요?** 패널에 모든 검사 항목이 나열되며, 실패한 항목이 맨 위에 표시됩니다.

<Shot id="scan-score-panel" />

검사 항목은 다음과 같습니다.

- **해독**: 카메라와 비슷한 흐림 효과를 적용해 세 가지 크기로 코드를 읽습니다.
- **대비**: 코드와 배경의 대비는 4.5:1 이상이어야 합니다.
- **밝은 배경에 어두운 코드**: 밝은 배경에 어두운 코드가 더 많은 앱에서 스캔됩니다.
- **로고**: 로고는 오류 정정으로 복원할 수 있는 범위를 넘어 코드를 가려서는 안 되며, 모서리 눈에 닿아서도 안 됩니다.
- **눈 모양**: 원형과 곡선형 눈은 일부 스캐너 앱에서 인식되지 않습니다.
- **여백**: 코드 주위의 빈 테두리입니다. 4모듈이 가장 좋습니다.

## 빠른 해결 방법 [#quick-fixes]

| 검사 항목 | 해결 방법 |
| --- | --- |
| 낮은 대비 | 코드를 더 어둡게 하거나 배경을 더 밝게 하세요. [스캔되는 색상 고르기](/docs/help/designing/colors-and-contrast)를 참고하세요. |
| 로고가 너무 많이 가림 | **오류 정정**을 **높음**으로 설정하거나 로고를 더 작게 만드세요. [로고 추가하기](/docs/help/designing/logos)를 참고하세요. |
| 눈 모양 | 사각형, 둥근 사각형 또는 톱니 눈으로 바꾸세요. |
| 여백 | **패딩**을 **표준** 또는 **크게**로 설정하세요. |

## 인쇄된 코드 확인하기 [#check-a-printed-code]

이 점수는 화면에서 디자인을 테스트합니다. 이미 인쇄한 코드를 테스트하려면 사진을 찍어 [스캔 검사기](/tools/scan-checker)에 올리세요. 이미지는 기기 밖으로 나가지 않습니다.
