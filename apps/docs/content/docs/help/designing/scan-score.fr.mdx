---
title: "Vérifier un design avec le score de scan"
description: "Le score de scan teste votre design comme le voit l'appareil photo d'un téléphone et vous indique quoi corriger."
---

Chaque design du [Playground](/playground) reçoit un **Score de scan** de 0 à 100, affiché sous l'aperçu, par exemple « Score de scan 92 · Excellent ». Il teste le code comme le ferait l'appareil photo d'un téléphone, pour que vous puissiez corriger les problèmes avant d'imprimer.

<Shot id="playground-content" />

## Ce que signifie le score [#what-the-score-means]

| Niveau | Score | Que faire |
| --- | --- | --- |
| **Excellent** | 85 ou plus | Prêt à imprimer. |
| **Correct** | 65 à 84 | Il devrait se scanner. Lisez les avertissements. |
| **Risqué** | Moins de 65 | Corrigez les vérifications marquées d'une croix. |
| **Échec** | | Le code n'a pas été décodé à la plus grande taille de test, ou le contraste est beaucoup trop faible. Ne l'imprimez pas. |

## Voir ce qu'il faut corriger [#see-what-to-fix]

Cliquez sur le score. Le panneau **Va-t-il se scanner ?** liste toutes les vérifications, celles qui ont échoué en premier.

<Shot id="scan-score-panel" />

Les vérifications sont les suivantes :

- **Décodage** : le code est lu à trois tailles avec un flou semblable à celui d'un appareil photo.
- **Contraste** : le code et l'arrière-plan doivent présenter un écart de 4,5:1 ou plus.
- **Foncé sur clair** : les codes foncés sur fond clair sont lus par un plus grand nombre d'applications.
- **Logo** : un logo ne doit pas couvrir plus que ce que la correction d'erreur peut reconstituer, et ne doit pas toucher l'œil d'un coin.
- **Forme des yeux** : les yeux en cercle et en forme de boucle échouent dans certaines applications de scan.
- **Zone de silence** : la bordure vide autour du code. Quatre modules, c'est idéal.

## Corrections rapides [#quick-fixes]

| La vérification | La correction |
| --- | --- |
| Contraste faible | Assombrissez le code ou éclaircissez l'arrière-plan. Voir [Choisir des couleurs qui se scannent](/docs/help/designing/colors-and-contrast). |
| Le logo couvre trop | Réglez **Correction d'erreur** sur **Élevée**, ou réduisez le logo. Voir [Ajouter un logo](/docs/help/designing/logos). |
| Forme des yeux | Passez à des yeux carrés, arrondis ou en engrenage. |
| Zone de silence | Réglez **Marge** sur **Standard** ou **Grande**. |

## Vérifier un code imprimé [#check-a-printed-code]

Le score teste le design à l'écran. Pour tester un code déjà imprimé, prenez-le en photo et déposez l'image dans le [vérificateur de scan](/tools/scan-checker). L'image ne quitte jamais votre appareil.
