스캐너는 밝은 배경 위의 어두운 사각형을 찾습니다. 색상 문제는 대부분 이 규칙을 어길 때 생깁니다. 이 페이지에서는 Playground에서 색상을 바꾸는 위치와, 색상을 바꾸면서도 코드를 스캔 가능한 상태로 유지하는 방법을 안내합니다.

## 색상 변경하기 [#change-the-colors]

1. [Playground](/playground?tab=design&section=colors)에서 **Design** 탭을 열고 **Colors**를 선택해요.
2. 변경할 색상을 선택해요. **Background**는 코드 뒤의 영역입니다. **Foreground**는 데이터를 담은 작은 사각형의 색입니다. **Eyes**는 모서리에 있는 큰 사각형 세 개의 색입니다. **Dots**는 각 모서리 사각형의 중앙 색입니다.
3. 채우기 방식을 선택해요: **Solid**, **Linear**, **Radial**, **Angular** 또는 **Image**.

미리보기와 그 아래의 **Scan score**는 변경하는 대로 업데이트됩니다. 네 가지 색상 아래의 **Color palettes**에서는 색상을 한 번에 모두 설정할 수 있습니다.

## 코드를 스캔 가능하게 유지하는 규칙 [#rules-that-keep-a-code-scannable]

- **어두운 코드, 밝은 배경.** 어두운 배경 위의 밝은 코드는 일부 카메라 앱에서 인식되지 않습니다.
- **강한 대비.** 코드와 배경 사이의 대비율을 4.5:1 이상으로 맞추세요.
- **그라디언트는 어둡게 유지.** 그라디언트에 쓰인 모든 색이 배경과 비교해 충분히 어둡다면 사용해도 좋습니다.
- **단순한 배경.** 코드 뒤에 복잡한 사진이 있으면 읽기 어려워집니다. 코드에 그림을 넣고 싶다면 결과를 대신 테스트해 주는 [Image QR](/docs/help/designing/art)을 사용하세요.

## 대비 확인하기 [#check-the-contrast]

미리보기 위 도구 모음의 **Contrast Checker**는 선택한 색상의 대비율을 보여 주고, 4.5:1 미만인 조합을 표시합니다.

미리보기 아래의 **Scan score**도 대비를 확인하며, 크기, 여백, 로고도 함께 확인합니다. [스캔 점수로 디자인 확인하기](/docs/help/designing/scan-score)를 참고하세요.

## 문제가 생겼을 때 [#if-something-goes-wrong]

### 색상을 바꾼 뒤 점수가 Fails로 나와요 [#the-score-says-fails-after-a-color-change]

대비가 너무 낮아서 카메라가 코드와 배경을 구분하지 못합니다. 점수가 다시 올라올 때까지 전경색을 더 어둡게 하거나 배경색을 더 밝게 하세요.

### 내 휴대폰에서는 스캔되는데 다른 휴대폰에서는 안 돼요 [#it-scans-on-your-phone-but-not-on-other-phones]

밝은 코드에 어두운 배경인 조합이나 대비가 낮은 조합은 일부 카메라에서만 읽힙니다. 코드가 어두운 부분이 되도록 색을 바꾸고, 대비율을 4.5:1 이상으로 맞추세요.

### 그라디언트 때문에 점수가 Risky로 나와요 [#a-gradient-makes-the-score-risky]

그라디언트의 한쪽 끝이 너무 밝습니다. 두 색을 모두 어두운 쪽으로 옮기거나, 전경은 단색으로 하고 그라디언트는 Eyes에만 사용하세요.
