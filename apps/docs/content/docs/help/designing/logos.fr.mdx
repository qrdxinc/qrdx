title: "Ajouter un logo"
description: "Placez votre logo au centre d'un QR code sans nuire au scan."
---

Un logo au centre d'un code l'identifie à votre marque et indique à l'utilisateur ce qui l'attend. QRdx masque certains carrés du code sous le logo, et la correction d'erreur les reconstitue lors du scan. Cette page explique comment ajouter un logo tout en gardant le code lisible.

## Ajouter votre logo [#add-your-logo]

1. Dans le [Playground](/playground?tab=design&section=logo), ouvrez l'onglet **Design**, puis **Logo**.
2. Activez **Logo au centre**.
3. Choisissez l'une des **Icônes rapides**, choisissez une marque sous **Logos de marques**, ou cliquez sur **Importer votre logo**. Les fichiers importés peuvent être au format PNG, JPG, WebP ou SVG, jusqu'à 1 Mo. Un PNG transparent ou un SVG donne le meilleur rendu.
4. Réglez la taille, la forme et la plaque sous **Options du logo**, qui apparaît dès qu'un logo est activé.

Pour modifier le logo plus tard, cliquez sur **Remplacer** ou **Supprimer**.

## Utiliser le logo d'une marque [#use-a-brands-logo]

**Logos de marques** ouvre une galerie de {facts.brandLogos} marques issues de [Simple Icons](https://simpleicons.org) : Instagram, WhatsApp, PayPal, Spotify, Google Maps, les boutiques d'applications et des milliers d'autres. Les plus populaires apparaissent en premier, et vous pouvez rechercher par nom.

- Choisissez **Couleur de la marque**, **Noir** ou **Blanc** pour le logo.
- **Plaque** place une forme pleine derrière le logo. Un logo blanc en a toujours besoin, dans la couleur de la marque, tout comme une couleur de marque très claire.

Le logo est enregistré dans votre design, comme un fichier importé, si bien que le code ne le charge jamais depuis une source externe.

La marque de chaque entreprise appartient à son propriétaire. Utilisez-la pour diriger les gens vers cette marque, par exemple votre profil Instagram. Quelques marques ont demandé à Simple Icons de retirer leurs logos, ils ne figurent donc pas dans la galerie.

## Régler la correction d'erreur sur Élevée [#set-error-correction-to-high]

Ouvrez **Correction d'erreur** dans l'onglet **Design** et choisissez **Élevée** dès qu'un logo est activé. Les niveaux sont **Faible** (7 %), **Moyenne** (15 %), **Quartile** (25 %) et **Élevée** (30 %) : la part du code qui peut être masquée ou abîmée sans empêcher le scan.

## En cas de problème [#if-something-goes-wrong]

### Le score de scan baisse après l'ajout du logo [#the-scan-score-drops-after-you-add-the-logo]

Vérifiez que **Correction d'erreur** est réglée sur **Élevée**. QRdx dimensionne le logo pour vous : avec ce niveau, le score remonte généralement.

### Le score indique que le logo recouvre un œil de coin [#the-score-says-the-logo-covers-a-corner-eye]

Le logo atteint l'un des trois grands carrés d'angle, dont les lecteurs ont besoin pour repérer le code. Réduisez la taille du logo sous **Options du logo**.

### Le logo paraît flou dans le code [#the-logo-looks-fuzzy-in-the-code]

Un petit PNG ou JPG a été agrandi. Importez un SVG ou un PNG plus grand avec un fond transparent.

### L'importation est refusée [#the-upload-is-refused]

Le fichier dépasse 1 Mo ou n'est pas au format PNG, JPG, WebP ou SVG. Exportez un fichier plus léger et réessayez.

## Vous voulez le logo dans les points ? [#want-the-logo-in-the-dots-instead]

**Logo QR** dans l'onglet **Art** peint les points à l'intérieur de la forme de votre logo, au lieu de placer le logo par-dessus. Consultez [Fondre un logo ou une photo dans le code](/docs/help/designing/art).
