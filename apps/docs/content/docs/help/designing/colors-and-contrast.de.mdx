title: "Wähle Farben, die sich scannen lassen"
description: "Halte den Code dunkel und den Hintergrund hell, sorge für starken Kontrast und setze Farbverläufe mit Bedacht ein."

Scanner suchen nach dunklen Quadraten auf hellem Hintergrund. Die meisten Farbprobleme entstehen, weil diese Regel gebrochen wird. Diese Seite zeigt dir, wo du im Playground die Farben findest und wie der Code beim Ändern scanbar bleibt.

## Farben ändern [#change-the-colors]

1. Öffne im [Playground](/playground?tab=design&section=colors) den Tab **Design** und dann **Farben**.
2. Wähle die Farbe, die du ändern möchtest. **Hintergrund** ist die Fläche hinter dem Code. **Vordergrund** färbt die kleinen Quadrate, die deine Daten enthalten. **Augen** färbt die drei großen Quadrate in den Ecken. **Punkte** färbt die Mitte jedes Eckquadrats.
3. Wähle eine Füllung: **Einfarbig**, **Linear**, **Radial**, **Kegelförmig** oder **Bild**.

Die Vorschau und der **Scan-Score** darunter aktualisieren sich dabei laufend. Mit den **Farbpaletten** unter den vier Farben legst du alle auf einmal fest.

## Regeln für einen scanbaren Code [#rules-that-keep-a-code-scannable]

- **Dunkler Code, heller Hintergrund.** Helle Codes auf dunklem Hintergrund schlagen in manchen Kamera-Apps fehl.
- **Starker Kontrast.** Strebe ein Kontrastverhältnis von mindestens 4.5:1 zwischen Code und Hintergrund an.
- **Farbverläufe bleiben dunkel.** Ein Farbverlauf ist in Ordnung, wenn jede Farbe darin dunkel genug gegenüber dem Hintergrund ist.
- **Schlichter Hintergrund.** Ein unruhiges Foto hinter dem Code erschwert das Lesen. Wenn du ein Bild im Code haben möchtest, nutze stattdessen [Image QR](/docs/help/designing/art), das das Ergebnis für dich testet.

## Kontrast prüfen [#check-the-contrast]

Der **Kontrastprüfer** in der Symbolleiste über der Vorschau zeigt das Verhältnis für deine Farben an und markiert Paare unter 4.5:1.

Der **Scan-Score** unter der Vorschau prüft ebenfalls den Kontrast, außerdem Größe, Ruhezone und Logo. Siehe [Ein Design mit dem Scan-Score prüfen](/docs/help/designing/scan-score).

## Wenn etwas schiefgeht [#if-something-goes-wrong]

### Der Score zeigt nach einer Farbänderung „Fehlgeschlagen“ [#the-score-says-fails-after-a-color-change]

Der Kontrast ist viel zu niedrig, als dass eine Kamera den Code vom Hintergrund unterscheiden könnte. Mach den Vordergrund dunkler oder den Hintergrund heller, bis der Score wieder erscheint.

### Auf deinem Handy klappt der Scan, auf anderen nicht [#it-scans-on-your-phone-but-not-on-other-phones]

Hell-auf-Dunkel-Codes und Farbpaare mit niedrigem Kontrast werden von manchen Kameras gelesen und von anderen nicht. Tausche die Farben, damit der Code der dunkle Teil ist, und bring das Verhältnis auf mindestens 4.5:1.

### Ein Farbverlauf setzt den Score auf „Riskant“ [#a-gradient-makes-the-score-risky]

Ein Ende des Farbverlaufs ist zu hell. Verschiebe beide Farben Richtung dunkel oder nutze einen einfarbigen Vordergrund und spare dir den Farbverlauf für die Augen.
