title: "スキャンスコアでデザインを確認する"
description: "スキャンスコアは、スマートフォンのカメラが見るのと同じ条件でデザインをテストし、修正すべき点を教えてくれます。"
---

[Playground](/playground)のすべてのデザインには、プレビューの下に0〜100の**スキャンスコア**が表示されます(例:「スキャンスコア 92 · Great」)。スマートフォンのカメラと同じ条件でコードをテストするため、印刷前に問題を修正できます。

<Shot id="playground-content" />

## スコアの意味 [#what-the-score-means]

| 評価 | スコア | 対処 |
| --- | --- | --- |
| **Great** | 85以上 | そのまま印刷できます。 |
| **OK** | 65〜84 | スキャンできるはずです。警告を確認してください。 |
| **Risky** | 65未満 | バツ印が付いたチェックを修正してください。 |
| **Fails** | | 最大のテストサイズでコードをデコードできなかったか、コントラストが低すぎます。印刷しないでください。 |

## 修正点を確認する [#see-what-to-fix]

スコアをクリックします。**Will it scan?** パネルに、すべてのチェックが失敗したものから順に表示されます。

<Shot id="scan-score-panel" />

チェック項目は次のとおりです。

- **デコード**:カメラのようなぼかしを加えた状態で、3つのサイズでコードを読み取ります。
- **コントラスト**:コードと背景の比率は4.5:1以上にしてください。
- **明るい背景に暗いコード**:明るい背景に暗いコードの組み合わせは、より多くのアプリでスキャンできます。
- **ロゴ**:ロゴは、誤り訂正で復元できる範囲を超えて覆ってはならず、コーナーのアイにも触れてはいけません。
- **アイの形**:円形や波形のアイは、一部のスキャナーアプリでスキャンに失敗します。
- **クワイエットゾーン**:コードの周囲の空白の余白です。4モジュールが理想的です。

## 簡単な修正方法 [#quick-fixes]

| チェック | 修正方法 |
| --- | --- |
| コントラストが低い | コードを暗くするか、背景を明るくします。[スキャンできる色を選ぶ](/docs/help/designing/colors-and-contrast)を参照してください。 |
| ロゴが大きすぎる | **誤り訂正**を**高**に設定するか、ロゴを小さくします。[ロゴを追加する](/docs/help/designing/logos)を参照してください。 |
| アイの形 | 四角、角丸、歯車のアイに切り替えます。 |
| クワイエットゾーン | **余白**を**標準**または**大**に設定します。 |

## 印刷したコードを確認する [#check-a-printed-code]

スコアは画面上のデザインをテストします。すでに印刷したコードをテストするには、写真を撮って[スキャンチェッカー](/tools/scan-checker)にドロップしてください。画像がお使いのデバイスの外に出ることはありません。
