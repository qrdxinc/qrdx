Un **thème** est un design enregistré : couleurs, points, yeux, logo et cadre. Il n'inclut ni votre lien ni aucun autre contenu, ce qui vous permet de le réutiliser sur chaque code que vous créez.

<Callout type="info">
  Le plan Gratuit permet d'enregistrer jusqu'à 10 thèmes. Pro et Business n'ont aucune limite. Consultez [Les plans et ce qu'ils incluent](/docs/help/account-and-billing/plans).
</Callout>

## Enregistrer un design comme thème [#save-a-design-as-a-theme]

1. Dans le [Playground](/playground), cliquez sur l'icône en forme de cœur (**Enregistrer le design**) au-dessus de l'aperçu, ou appuyez sur <kbd>S</kbd>.
2. Connectez-vous si on vous le demande.
3. Dans la boîte de dialogue **Save QR Code Theme**, donnez un nom au thème et cliquez sur **Save Theme**.

Lorsque vous modifiez un thème déjà enregistré, la boîte de dialogue vous propose de le **Mettre à jour** ou de l'**Enregistrer comme nouveau**.

Vos thèmes se trouvent sur la page **Thèmes** de votre tableau de bord.

## Réutiliser un thème [#reuse-a-theme]

Sur la page **Thèmes**, ouvrez le menu d'un thème :

- **Modifier dans le Playground** l'ouvre dans l'éditeur.
- **Renommer** modifie son nom.
- **Définir par défaut** l'utilise pour vos nouveaux codes. Pour un thème d'équipe, l'option devient **Définir par défaut de l'espace de travail**, et **Retirer par défaut** l'annule.
- **Copier dans cet espace de travail** partage une copie avec tous les membres de l'espace de travail que vous avez ouvert.
- **Copier le lien** copie un lien qui ouvre le style dans le Playground.
- **Publier dans la communauté** le partage avec tout le monde (voir ci-dessous). **Publier son cadre** publie le cadre seul.
- **Supprimer** le supprime.

**Nouveau thème**, en haut de la page, permet d'en créer un nouveau.

## Partager un style [#share-a-style]

Cliquez sur l'icône de partage (**Partager le design**) au-dessus de l'aperçu, ou appuyez sur <kbd>X</kbd>. QRdx vous demande d'abord d'enregistrer le design, puis vous donne un lien.

Le lien partage le style, pas votre contenu. Toute personne qui l'ouvre obtient vos couleurs, vos points et vos yeux dans le Playground, et y ajoute son propre lien.

## Publier dans la communauté [#publish-to-the-community]

Une fois un design enregistré, **Publier dans la communauté** sur la page **Thèmes** le partage dans la [communauté](/community) pour que d'autres puissent le réutiliser.

- Il doit obtenir un scan Excellent (85 ou plus) avec un lien et avec des informations Wi-Fi. QRdx le vérifie au moment de la publication.
- Les logos importés et les images ne sont jamais publiés.
- Tout le contenu de la communauté est libre de droits sous [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) : chacun peut l'utiliser pour n'importe quel usage, sans mention de crédit.
- La publication crée un instantané : les modifications ultérieures de votre design enregistré ne changent pas ce que vous avez publié. Pour le mettre à jour, publiez-le de nouveau.

## En cas de problème [#if-something-goes-wrong]

### L'icône en forme de cœur est devenue Publier [#the-heart-icon-has-turned-into-publish]

Le thème que vous modifiez est enregistré et n'a aucune modification non enregistrée. Modifiez quelque chose pour enregistrer une nouvelle version, ou gérez-le depuis la page **Thèmes**.

### Vous ne pouvez plus enregistrer de thème [#you-cant-save-another-theme]

Vous avez atteint les 10 thèmes du plan Gratuit. Supprimez-en un que vous n'utilisez pas, ou [passez à un plan supérieur](/pricing).

### La publication est refusée [#publishing-is-refused]

Le design n'obtient pas un scan Excellent à la fois avec un lien et avec des informations Wi-Fi. Ouvrez-le dans le Playground, corrigez les vérifications dans [le score de scan](/docs/help/designing/scan-score), enregistrez, puis publiez de nouveau.
