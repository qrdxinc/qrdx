---
title: "Comprueba un diseño con la puntuación de escaneo"
description: "La puntuación de escaneo prueba tu diseño como lo ve la cámara de un teléfono y te dice qué corregir."
---

Cada diseño del [playground](/playground) recibe una **Puntuación de escaneo** de 0 a 100, que aparece debajo de la vista previa, por ejemplo "Puntuación de escaneo 92 · Excelente". Prueba el código como lo haría la cámara de un teléfono, para que puedas corregir los problemas antes de imprimir.

<Shot id="playground-content" />

## Qué significa la puntuación [#what-the-score-means]

| Nivel | Puntuación | Qué hacer |
| --- | --- | --- |
| **Excelente** | 85 o más | Listo para imprimir. |
| **Aceptable** | 65 a 84 | Debería escanearse. Lee las advertencias. |
| **Arriesgado** | Menos de 65 | Corrige las comprobaciones marcadas con una cruz. |
| **Falla** | | El código no se decodificó en el tamaño de prueba más grande, o el contraste es demasiado bajo. No lo imprimas. |

## Descubre qué corregir [#see-what-to-fix]

Haz clic en la puntuación. El panel **¿Se escaneará?** enumera todas las comprobaciones, con las fallidas primero.

<Shot id="scan-score-panel" />

Las comprobaciones son:

- **Decodificación**: el código se lee en tres tamaños con un desenfoque similar al de una cámara.
- **Contraste**: el código y el fondo deben diferir en una proporción de 4.5:1 o más.
- **Oscuro sobre claro**: los códigos oscuros sobre fondos claros se escanean en más aplicaciones.
- **Logo**: un logo no debe cubrir más de lo que la corrección de errores puede reconstruir, ni tocar el ojo de una esquina.
- **Forma de los ojos**: los ojos circulares y ondulados fallan en algunas aplicaciones de escaneo.
- **Zona de silencio**: el borde vacío alrededor del código. Lo ideal son cuatro módulos.

## Soluciones rápidas [#quick-fixes]

| La comprobación | La solución |
| --- | --- |
| Contraste bajo | Oscurece el código o aclara el fondo. Consulta [Elige colores que se escaneen](/docs/help/designing/colors-and-contrast). |
| El logo cubre demasiado | Establece **Corrección de errores** en **Alta**, o reduce el logo. Consulta [Añade un logo](/docs/help/designing/logos). |
| Forma de los ojos | Cambia a ojos cuadrados, redondeados o de engranaje. |
| Zona de silencio | Establece **Margen** en **Estándar** o **Grande**. |

## Comprueba un código impreso [#check-a-printed-code]

La puntuación prueba el diseño en pantalla. Para probar un código que ya imprimiste, haz una foto y suéltala en el [verificador de escaneo](/tools/scan-checker). La imagen nunca sale de tu dispositivo.
