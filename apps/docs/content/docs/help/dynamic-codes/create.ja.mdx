---
title: "動的QRコードを作成する"
description: "印刷後も変更できるコードを、Playgroundまたはダッシュボードから作成します。"
---

動的QRコードには、`qrdx.dev/q/aB3xY7k` のような短いリンクが含まれており、スキャンのたびにリンク先（コードで開きたいページ）へ転送されます。印刷後でもリンク先を変更でき、すべてのスキャンを確認できます。デザインしながらPlaygroundで作成することも、ダッシュボードから作成することもできます。

<Callout type="info">
  動的コードを使うには、無料のQRdxアカウントが必要です。フリープランでは有効なコードを10個まで作成できます。Pro と Business では上限はありません。[プランと含まれる内容](/docs/help/account-and-billing/plans)をご覧ください。
</Callout>

## Playgroundから作成する [#from-the-playground]

### 1. リンクを入力する [#1-type-your-link]

[Playground](/playground?type=url)を開き、**Website address** にアドレスを入力します。

### 2. 動的を選ぶ [#2-pick-dynamic]

アドレスの下にある **Static or dynamic QR code** のスイッチには、**Static**（「Fixed once printed」）と **Dynamic**（「Edit later, count scans」）の選択肢があります。**Dynamic** を選びます。

サインインしていない場合は、サインインのダイアログが開きます。入力したリンクはそのまま残り、サインインするとすぐにコードが作成されます。

### 3. コードをダウンロードする [#3-download-the-code]

QRdx から「Your QR code is now dynamic」と表示されます。スイッチには、コピーボタン付きの短いリンクのほか、ドメイン、バックハーフ、フォルダー、タグを設定する **Link options…** と、ダッシュボードでコードを開く **Scans & settings** が表示されます。いつもどおりコードをダウンロードしてください。このコードには短いリンクがエンコードされています。

<Shot id="playground-dynamic-on" />

このスイッチは URL タイプ専用です。連絡先カードやメニューなど、あとから変更したいほかのコンテンツには、専用の動的コードが付く[モバイルページ](/docs/help/pages-and-forms/create-a-page)を作成してください。

## ダッシュボードから作成する [#from-your-dashboard]

### 1. 新しいコードを開始する [#1-start-a-new-code]

**Codes** に移動し、**New code** をクリックします。**New dynamic QR code** ダイアログが開きます。

### 2. 開く内容を選ぶ [#2-say-what-it-opens]

**What does it open?** で **Website link** を選びます。

### 3. 詳細を入力する [#3-fill-in-the-details]

**Destination URL** を入力します。必要に応じて、**Short link domain** を選び、**Custom back-half (optional)** を入力し、コードに **Title (optional)** を付けます。

<Shot id="new-code-dialog" />

### 4. 作成する [#4-create-it]

**Create code** をクリックします。ダイアログに「Your dynamic QR code is ready」と表示され、**View analytics**、**Open the code**、**Create another**、**Done** が表示されます。コードはそのページからダウンロードしてください。

## 短いリンクの末尾を自分で決める [#choose-your-own-short-link-ending]

Pro と Business では、**Custom back-half (optional)** で短いリンクの末尾を自由に決められます（例：`qrdx.dev/q/spring-menu`）。3〜64文字の英字、数字、ハイフン、アンダースコアが使えます。ハイフンで始めたり終わったりすることはできません。また、一部の予約語は使えません。

フリープランでは、QRdx が7文字のランダムな末尾を自動で割り当てます。短いリンクは大文字と小文字が区別されます。

## 上限に達したとき [#when-you-reach-the-limit]

フリープランで10個に数えられるのは、有効なコードのみです。アーカイブしたコードやゴミ箱のコードは数えられませんが、一時停止中のコードは数えられます。上限に達すると、Playgroundに **Upgrade to Pro** と **Manage codes** が表示されます。使わなくなったコードは[アーカイブ](/docs/help/dynamic-codes/archive-and-delete)するか、[アップグレード](/pricing)してください。

## うまくいかないとき [#if-something-goes-wrong]

### スイッチに Dynamic が表示されない [#the-switch-doesnt-show-dynamic]

コードのタイプが URL ではありません。**QR code type** カードの **Change** をクリックして **URL** を選ぶか、ほかのコンテンツにはモバイルページを作成してください。

### サインインしたのにコードが作成されなかった [#you-signed-in-but-the-code-wasnt-made]

もう一度 **Dynamic** を選んでください。入力したリンクは残っています。

### バックハーフが受け付けられない [#the-back-half-is-refused]

すでに使われているか、使用できない文字や予約語が含まれています。別の末尾をお試しください。
