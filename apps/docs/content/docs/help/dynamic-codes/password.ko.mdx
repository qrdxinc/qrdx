동적 QR 코드에 비밀번호를 설정하면 스캔한 사람이 비밀번호를 입력해야 목적지에 접속할 수 있습니다. 직원용 페이지나 행사 프로그램처럼 비공개 콘텐츠로 연결되는 코드에 사용하세요.

<Callout type="info">
  비밀번호 기능은 Pro와 Business에서 제공합니다. 비밀번호 제거는 모든 요금제에서 가능합니다. [요금제와 포함 기능](/docs/help/account-and-billing/plans)을 참고하세요.
</Callout>

## 비밀번호 추가하기 [#add-a-password]

1. **Codes**에서 코드를 열고 **Settings** 탭으로 이동해요.
2. **Access & schedule**을 열어요.
3. 4자에서 64자 사이로 **Password**를 입력해요.
4. **Save changes**를 클릭해요. 코드 상태가 "Live and password protected"로 표시됩니다.

## 스캔한 사람에게 보이는 화면 [#what-scanners-see]

스캔한 사람에게는 "This QR code is password protected"라는 제목의 단순한 페이지가 표시되며, **Password** 입력란과 **Continue** 버튼이 있습니다. 올바른 비밀번호를 입력하면 해당 브라우저는 6시간 동안 잠금이 해제된 상태로 유지되므로, 스캔할 때마다 다시 입력하지 않아도 됩니다.

<Shot id="scan-password" />

## 비밀번호는 따로 공유하세요 [#share-the-password-separately]

비밀번호를 아는 사람은 누구나 코드를 열 수 있습니다. 다른 비밀번호와 마찬가지로 별도로 전달하고, 코드 옆에 함께 인쇄하지 마세요.

## 비밀번호 변경 또는 제거하기 [#change-or-remove-the-password]

QRdx는 현재 비밀번호를 표시하지 않습니다. 변경하려면 **Password** 입력란에 새 비밀번호를 입력하고 저장하세요. 제거하려면 **Remove password**를 클릭하거나 입력란을 비우고 저장하세요. 이때 패널에 "The password will be removed when you save"라는 안내가 표시됩니다.

## 문제가 생겼을 때 [#if-something-goes-wrong]

### 비밀번호가 작동하지 않는다는 사람이 있어요 [#people-say-the-password-doesnt-work]

**Save changes**를 클릭했는지, 그리고 대문자를 포함해 정확한 문자로 비밀번호를 공유했는지 확인하세요.

### 비밀번호를 잊어버렸어요 [#youve-forgotten-the-password]

새 비밀번호를 설정하세요. 저장하는 즉시 이전 비밀번호는 사용할 수 없습니다.

### 비밀번호를 다시 요구받은 사람이 있어요 [#someone-was-asked-again]

비밀번호는 한 브라우저에서 6시간 동안만 기억됩니다. 다른 브라우저나 기기를 사용하거나 브라우저 데이터를 지운 경우에는 다시 입력해야 합니다.
