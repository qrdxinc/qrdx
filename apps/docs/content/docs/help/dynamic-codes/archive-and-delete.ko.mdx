동적 QR 코드를 더 이상 쓰지 않을 때는 보관하거나 휴지통으로 옮기거나 영구 삭제할 수 있습니다. 어느 방법이든 코드는 작동을 멈추지만, 멈추는 방식은 서로 다릅니다.

<Callout type="warn">
  코드를 보관하거나 휴지통으로 옮기거나 삭제하면 코드가 작동하지 않습니다. 인쇄된 코드를 부드럽게 종료하려면 대신 [일시 중지](/docs/help/dynamic-codes/pause-schedule-limit)하고 대체 URL을 추가하세요.
</Callout>

## 선택 방법 [#which-to-choose]

| | 스캔한 사용자에게 표시되는 내용 | 한도에 포함 여부 | 되돌리는 방법 |
| --- | --- | --- | --- |
| **일시 중지** | 대체 URL 또는 "This campaign is paused" | 포함 | **Resume** |
| **보관** | "This QR code is no longer active" | 미포함 | **Unarchive** |
| **휴지통으로 이동** | "This QR code is no longer active" | 미포함 | **Restore** |
| **영구 삭제** | "QR code not found" | 미포함 | 없음. 완전히 사라집니다. |

## 코드 보관하기 [#archive-a-code]

**Codes**에서 코드의 메뉴(**⋯**)를 열고 **Archive**를 선택하세요. 보관한 코드는 요금제의 코드 한도에 포함되지 않습니다. 코드를 다시 켜려면 **Unarchive**를 선택하세요. 무료 요금제에서는 비어 있는 코드 슬롯이 필요합니다.

## 코드를 휴지통으로 옮기기 [#move-a-code-to-the-trash]

코드의 메뉴를 열고 **Move to trash**를 선택하세요. 휴지통에 있는 코드를 보려면 도구 모음에서 **Filter**를 열고 **Status**를 **Trash**로 설정하세요. 여기서 각 코드의 메뉴에 **Restore**와 **Delete forever**가 표시됩니다. QRdx는 휴지통을 자동으로 비우지 않습니다.

## 코드 영구 삭제하기 [#delete-a-code-forever]

휴지통에서 코드 하나에 **Delete forever**를 선택하거나, **Empty trash**를 선택해 휴지통의 모든 코드를 삭제하세요. 코드의 스캔 기록과 버전 기록도 함께 삭제되며, 어떤 방법으로도 되돌릴 수 없습니다. 스캔한 사용자에게는 "QR code not found"가 표시됩니다.

## 문제가 생겼을 때 [#if-something-goes-wrong]

### Unarchive 또는 Restore가 거부됩니다 [#unarchive-or-restore-is-refused]

무료 요금제를 사용 중이고 이미 활성 코드가 10개 있는 경우입니다. 먼저 다른 코드를 보관하거나 [업그레이드](/pricing)하세요.

### 코드를 삭제했는데 스캔 데이터를 되찾고 싶어요 [#you-deleted-a-code-and-want-its-scans-back]

스캔 데이터는 코드와 함께 사라집니다. 필요할 수도 있는 코드를 삭제하기 전에 [스캔 데이터를 내보내세요](/docs/help/dynamic-codes/scans#download-your-scans).
