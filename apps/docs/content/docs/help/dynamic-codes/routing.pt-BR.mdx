title: "Envie leituras para links diferentes"
description: "Direcione cada leitura por dispositivo, país, área, idioma ou horário e faça testes A/B com o roteamento inteligente."
---

O roteamento inteligente envia cada leitura de um QR code dinâmico para um link diferente, com base nas regras que você define: iPhones para a App Store, visitantes na França para a página em francês, leituras após o horário de fechamento para um formulário de pedido. Esta página leva você até uma regra funcionando; o [guia de roteamento inteligente](/docs/smart-routing) explica cada condição em detalhe.

<Callout type="info">
  O roteamento inteligente faz parte dos planos Pro e Business e funciona em códigos que abrem um link de site. Veja [Planos e o que cada um inclui](/docs/help/account-and-billing/plans).
</Callout>

## Adicione uma regra [#add-a-rule]

### 1. Abra o Roteamento inteligente [#1-open-smart-routing]

Abra o código em **Códigos**, vá até a aba **Configurações** e abra **Roteamento inteligente**.

### 2. Comece uma regra [#2-start-a-rule]

Clique em **Adicionar regra**. Em **Começar por**, escolha um modelo ou **Regra vazia**.

### 3. Defina as condições e o link [#3-set-the-conditions-and-the-link]

Escolha as condições que uma leitura precisa atender e o link que as leituras correspondentes vão abrir.

### 4. Salve [#4-save]

Clique em **Salvar regras**. As leituras que não correspondem a nenhuma regra abrem o destino normal do código.

## Condições que você pode usar [#conditions-you-can-use]

**Dispositivo**, **Sistema operacional**, **País**, **Região**, **Área**, **Idioma**, **Horário do dia**, **Período** e **Número de leituras**. Marque **não é** para inverter uma condição.

Uma **Área** é um ponto com um raio. Ela usa a localização que quem faz a leitura compartilha quando a [localização precisa](/docs/precise-location) está ativada e, caso contrário, a localização aproximada da rede da pessoa.

Uma regra pode ter até 8 condições. Um código pode ter até 20 regras.

## Modelos [#templates]

- **Link inteligente de app (App Store / Google Play)**: iPhones para a App Store, celulares Android para o Google Play.
- **País** e **Idioma do visitante**.
- **Horário comercial**.
- **Período (campanha)**: um link para um intervalo de datas.
- **Primeiras leituras**: um link diferente para as primeiras leituras.
- **Dentro de uma área (geofence)**: um link diferente para leituras perto de um local.
- **Divisão A/B**: distribui as leituras entre 2 a 5 versões.

## A primeira regra que corresponder vence [#the-first-matching-rule-wins]

As regras são verificadas de cima para baixo. Coloque as regras mais específicas primeiro.

Abra **Teste suas regras (usa alterações não salvas)** e clique em **Executar teste** para ver para onde uma leitura iria antes de salvar.

## Testes A/B [#ab-tests]

Uma divisão A/B envia cada visitante para uma versão. Cada visitante mantém a mesma versão durante o dia. A aba **Análises** do código mostra como as leituras se dividem entre as versões.

## Após um downgrade [#after-a-downgrade]

As regras salvas continuam funcionando. Para alterá-las de novo, é preciso ter Pro ou Business.

## Se algo der errado [#if-something-goes-wrong]

### O Roteamento inteligente não aparece em Configurações [#smart-routing-isnt-in-settings]

O código abre uma página hospedada. O roteamento é para códigos que abrem um link de site; troque o tipo primeiro. Veja [Mude o que um código impresso abre](/docs/help/dynamic-codes/change-the-type).

### Uma leitura foi para o link errado [#a-scan-went-to-the-wrong-link]

Uma regra anterior correspondeu primeiro. Reordene as regras e confirme com **Executar teste**. Veja [Um código abre a página errada](/docs/help/troubleshooting/wrong-destination).

### Uma regra de área não alcança quem está no local [#an-area-rule-misses-people-who-are-there]

Sem localização precisa, o QRdx só sabe a localização aproximada da rede de quem faz a leitura, que pode ficar a uma cidade de distância. Ative **Pedir localização precisa a quem faz a leitura** no código ou aumente o raio.
