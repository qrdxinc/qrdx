Anda dapat membuat banyak kode QR dinamis sekaligus dari file CSV, atau memindahkan kode yang Anda miliki di layanan lain ke QRdx. Halaman ini membahas proses impornya; [Pindah dari Bitly, Rebrandly, dan lainnya](/docs/migrate) menjelaskan cara menjaga kode yang sudah Anda cetak tetap berfungsi.

<Callout type="info">
  Di paket Gratis, Anda dapat mengimpor satu kode dalam satu waktu. Pro dan Business dapat mengimpor banyak kode sekaligus. Lihat [Paket dan isinya](/docs/help/account-and-billing/plans).
</Callout>

## Dari file CSV [#from-a-csv-file]

### 1. Buka fitur impor [#1-open-the-import]

Buka **Codes** lalu klik **Import** di sidebar Codes. Anda juga dapat membuka menu **More code actions** (**⋯**) dan memilih **Import codes**, lalu **From a CSV file**. Halaman **Import codes from CSV** akan terbuka.

### 2. Unggah file Anda [#2-upload-your-file]

Unggah file CSV dengan satu kode per baris. Satu-satunya kolom yang wajib adalah tujuan. Anda juga dapat menyertakan judul, folder, tag, dan slug (back-half kustom). Satu file dapat berisi hingga {facts.importRows} baris dan berukuran hingga 10 MB.

Anda juga dapat memilih folder dan tag untuk setiap kode dalam file. Baris yang memiliki folder sendiri tetap memakainya, dan tag dari file ditambahkan ke tag yang Anda pilih.

<Shot id="import-csv" />

### 3. Biarkan proses berjalan [#3-let-it-run]

Setiap baris diperiksa sebelum ada yang dibuat; baris yang bermasalah dilewati dan didaftarkan. File besar dikirim secara bertahap sementara bilah kemajuan terisi, dan Anda dapat menjeda lalu melanjutkan.

### 4. Unduh hasilnya [#4-download-the-results]

Setelah selesai, unduh **Results CSV** berisi tautan pendek setiap baris, atau ZIP berisi kode baru dalam file **PNG (1024 px)** atau **SVG (vector)** beserta indeks `codes.csv`.

## Dari layanan lain [#from-another-service]

Buka menu **More code actions** (**⋯**), pilih **Import codes**, lalu **From Bitly and other apps**, dan pilih tempat kode Anda berada sekarang.

- **Bitly**: masuk ke Bitly dan pilih tautannya.
- **Rebrandly** dan **Short.io**: tempelkan kunci API dari layanan tersebut.
- **QR Code Generator PRO**, **Uniqode**, **Flowcode**, **QR TIGER**, **ME-QR**, **TinyURL**, **Hovercode**, **Scanova**, dan **Another provider (CSV)**: unggah file ekspor dari layanan tersebut, hingga 2 MB.

## Jaga kode cetak tetap berfungsi [#keep-printed-codes-working]

Kode yang sudah dicetak masih mengarah ke layanan lama. Panduan migrasi menjelaskan cara menjaganya tetap berfungsi, dan cara mempertahankan back-half asli Anda. Lihat [Pindah dari Bitly, Rebrandly, dan lainnya](/docs/migrate).

## Jika terjadi masalah [#if-something-goes-wrong]

### Beberapa baris dilewati [#some-rows-were-skipped]

Hasil mencantumkan setiap baris yang dilewati beserta alasannya, misalnya alamat yang bukan tautan atau back-half yang sudah dipakai. Perbaiki baris tersebut di file Anda lalu impor lagi. Tidak ada yang dibuat dua kali.

### Impor berhenti [#the-import-stopped]

Jika halaman dimuat ulang atau koneksi terputus, halaman akan menawarkan untuk melanjutkan atau mencoba lagi saat Anda kembali. Kode yang sudah dibuat tidak dibuat ulang.

### Hanya satu baris yang diimpor [#only-one-row-was-imported]

Anda memakai paket Gratis, yang mengimpor satu kode dalam satu waktu. Impor baris berikutnya, atau [upgrade](/pricing) untuk mengimpor seluruh file.
