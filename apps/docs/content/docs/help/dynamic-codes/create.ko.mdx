동적 코드에는 `qrdx.dev/q/aB3xY7k` 같은 짧은 링크가 들어 있어요. 이 링크가 스캔할 때마다 목적지(코드가 열었으면 하는 페이지)로 연결해 줍니다. 인쇄한 뒤에도 목적지를 바꿀 수 있고, 모든 스캔을 확인할 수 있습니다. 디자인하면서 Playground에서 만들 수도 있고, 대시보드에서 만들 수도 있습니다.

<Callout type="info">
  동적 코드를 사용하려면 무료 QRdx 계정이 필요합니다. 무료 플랜에서는 활성 코드를 10개까지 사용할 수 있고, Pro와 Business에는 제한이 없습니다. [플랜과 포함 기능](/docs/help/account-and-billing/plans)을 참고하세요.
</Callout>

## Playground에서 만들기 [#from-the-playground]

### 1. 링크 입력하기 [#1-type-your-link]

[Playground](/playground?type=url)를 열고 **웹사이트 주소**에 주소를 입력합니다.

### 2. 동적 선택하기 [#2-pick-dynamic]

주소 아래의 **정적 또는 동적 QR 코드** 스위치에는 **정적**("인쇄하면 고정")과 **동적**("나중에 수정, 스캔 집계")이 있습니다. **동적**을 선택하세요.

로그인하지 않은 상태라면 로그인 창이 열립니다. 입력한 링크는 그대로 유지되고, 로그인하는 즉시 코드가 만들어집니다.

### 3. 코드 다운로드하기 [#3-download-the-code]

QRdx가 "QR 코드가 동적으로 바뀌었어요"라고 알려 줍니다. 이제 스위치에 짧은 링크와 복사 버튼이 표시되고, 도메인, 뒷부분, 폴더, 태그를 설정하는 **링크 옵션…**과 대시보드에서 코드를 여는 **스캔 및 설정**도 나타납니다. 코드는 평소처럼 다운로드하면 되며, 이제 짧은 링크가 담겨 있습니다.

<Shot id="playground-dynamic-on" />

이 스위치는 URL 유형에서만 쓸 수 있습니다. 연락처 카드, 메뉴 등 나중에 바꾸고 싶은 다른 콘텐츠는 [모바일 페이지](/docs/help/pages-and-forms/create-a-page)를 만들어 주세요. 모바일 페이지에는 전용 동적 코드가 함께 만들어집니다.

## 대시보드에서 만들기 [#from-your-dashboard]

### 1. 새 코드 시작하기 [#1-start-a-new-code]

**코드**로 이동해 **새 코드**를 클릭합니다. **새 동적 QR 코드** 대화상자가 열립니다.

### 2. 무엇을 열지 선택하기 [#2-say-what-it-opens]

**무엇을 여나요?**에서 **웹사이트 링크**를 선택합니다.

### 3. 세부 정보 입력하기 [#3-fill-in-the-details]

**목적지 URL**을 입력합니다. 원하면 **짧은 링크 도메인**을 고르고, **사용자 지정 뒷부분(선택)**을 입력하고, 코드에 **제목(선택)**을 붙일 수 있습니다.

<Shot id="new-code-dialog" />

### 4. 만들기 [#4-create-it]

**코드 만들기**를 클릭합니다. 대화상자에 "동적 QR 코드가 준비됐어요"라는 메시지와 함께 **분석 보기**, **코드 열기**, **하나 더 만들기**, **완료**가 표시됩니다. 코드는 해당 코드 페이지에서 다운로드하세요.

## 짧은 링크 끝부분 직접 정하기 [#choose-your-own-short-link-ending]

Pro와 Business에서는 **사용자 지정 뒷부분(선택)**으로 짧은 링크의 끝부분을 직접 정할 수 있습니다. 예를 들면 `qrdx.dev/q/spring-menu`처럼요. 영문자, 숫자, 대시, 밑줄로 3~64자까지 쓸 수 있고, 대시로 시작하거나 끝날 수 없으며, 일부 예약어는 사용할 수 없습니다.

무료에서는 QRdx가 무작위 7자리 끝부분을 정해 줍니다. 짧은 링크는 대소문자를 구분합니다.

## 한도에 도달했을 때 [#when-you-reach-the-limit]

무료에서는 활성 코드만 10개 한도에 포함됩니다. 보관한 코드와 휴지통에 있는 코드는 포함되지 않지만, 일시중지한 코드는 포함됩니다. 한도에 도달하면 Playground에 **Pro로 업그레이드**와 **코드 관리**가 표시됩니다. 더 이상 쓰지 않는 코드는 [보관](/docs/help/dynamic-codes/archive-and-delete)하거나 [업그레이드](/pricing)하세요.

## 문제가 생겼을 때 [#if-something-goes-wrong]

### 스위치에 동적이 표시되지 않아요 [#the-switch-doesnt-show-dynamic]

코드 유형이 URL이 아닌 경우입니다. **QR 코드 유형** 카드에서 **변경**을 클릭해 **URL**을 선택하거나, 다른 콘텐츠라면 모바일 페이지를 만드세요.

### 로그인했는데 코드가 만들어지지 않았어요 [#you-signed-in-but-the-code-wasnt-made]

**동적**을 다시 선택하세요. 입력한 링크는 그대로 남아 있습니다.

### 뒷부분이 거부돼요 [#the-back-half-is-refused]

이미 사용 중이거나, 허용되지 않는 문자나 예약어를 사용한 경우입니다. 다른 끝부분을 시도해 보세요.
