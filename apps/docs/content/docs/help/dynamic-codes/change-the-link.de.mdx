---
title: "Ändern, wohin ein Code führt"
description: "Bearbeite das Ziel eines dynamischen QR-Codes. Gedruckte Exemplare öffnen beim nächsten Scan den neuen Link."
---

Du kannst das Ziel eines dynamischen Codes jederzeit ändern: die Seite, die ein Scan öffnet. Jedes gedruckte Exemplar öffnet beim nächsten Scan den neuen Link, weil der Code selbst nur den Kurzlink enthält.

## Im Dashboard [#from-your-dashboard]

### 1. Link bearbeiten öffnen [#1-open-edit-link]

Gehe zu **Codes**. Öffne das Menü des Codes (die Schaltfläche **Code-Aktionen**, dargestellt als **⋯**) und wähle **Link bearbeiten**. Du kannst den Code auch öffnen und im Tab **Übersicht** auf **Link bearbeiten** klicken.

### 2. Ziel ändern [#2-change-the-destination]

Ändere im Dialog **Dynamischen QR-Code bearbeiten** die **Ziel-URL**.

### 3. Speichern [#3-save]

Klicke auf **Änderungen speichern**. QRdx bestätigt mit „Änderungen gespeichert“ und „Scans öffnen jetzt das aktualisierte Ziel.“

## Im Playground [#from-the-playground]

Wenn der dynamische Code im Playground geöffnet ist, gib die neue Adresse unter **Website-Adresse** ein. Der Schalter darunter zeigt „Gedruckte Codes öffnen weiterhin“ deinen alten Link an, bis du auf **Auf die neue Adresse umstellen** klickst. QRdx bestätigt dann mit „Ziel aktualisiert“.

## Änderungen gelten sofort [#changes-take-effect-right-away]

QRdx speichert Weiterleitungen nicht im Cache. Der nächste Scan öffnet das neue Ziel, auf jedem Smartphone.

## Den Kurzlink selbst nicht ändern [#dont-change-the-short-link-itself]

Das Ziel zu ändern ist immer unbedenklich. Den hinteren Teil des Kurzlinks zu ändern oder den Code von einer eigenen Domain zu entfernen, ist es nicht: QRdx warnt, dass Codes, die mit dem alten Link gedruckt wurden, nicht mehr funktionieren. Eine Ausnahme ist der Umzug eines Codes von seinem `qrdx.dev`-Link auf eine eigene Domain: Der `qrdx.dev`-Link funktioniert weiter.

## Eine Änderung rückgängig machen [#undo-a-change]

1. Öffne den Code unter **Codes** und wechsle zum Tab **Einstellungen**.
2. Öffne **Versionsverlauf**.
3. Klicke neben der gewünschten Version auf **Wiederherstellen** und dann auf **Version wiederherstellen**.

QRdx speichert bis zu 100 Versionen pro Code, in jedem Tarif.

## Stattdessen eine Seite öffnen [#open-a-page-instead]

Damit der Code statt eines Links eine gehostete Seite öffnet, klicke im Tab **Übersicht** des Codes auf **Typ ändern**. Siehe [Ändern, was ein gedruckter Code öffnet](/docs/help/dynamic-codes/change-the-type).

## Wenn etwas nicht klappt [#if-something-goes-wrong]

### Der gedruckte Code öffnet noch die alte Seite [#the-printed-code-still-opens-the-old-page]

Im Playground reicht es nicht, die Adresse zu ändern: Klicke auf **Auf die neue Adresse umstellen**. Prüfe im Dashboard, ob du auf **Änderungen speichern** geklickt hast. Wenn das Ziel stimmt und ein Scan trotzdem woanders landet, siehe [Ein Code öffnet die falsche Seite](/docs/help/troubleshooting/wrong-destination).

### Link bearbeiten fehlt [#edit-link-isnt-there]

Der Code ist ein statischer QR-Code: Der Link ist darin gespeichert und lässt sich nicht ändern. Drucke stattdessen einen dynamischen QR-Code. Siehe [Statisch oder dynamisch: Was brauchst du?](/docs/help/getting-started/static-vs-dynamic).
