---
title: "Modifier la destination d'un code"
description: "Modifiez la destination d'un QR code dynamique. Les exemplaires imprimés ouvrent le nouveau lien dès le scan suivant."
---

Vous pouvez modifier à tout moment la destination d'un code dynamique, c'est-à-dire la page qu'ouvre un scan. Chaque exemplaire imprimé ouvre le nouveau lien dès son prochain scan, car le code ne contient que le lien court.

## Depuis votre tableau de bord [#from-your-dashboard]

### 1. Ouvrir Modifier le lien [#1-open-edit-link]

Allez dans **Codes**. Ouvrez le menu du code (le bouton **Actions du code**, représenté par **⋯**) et choisissez **Modifier le lien**. Vous pouvez aussi ouvrir le code et cliquer sur **Modifier le lien** dans son onglet **Vue d'ensemble**.

### 2. Changer la destination [#2-change-the-destination]

Dans la boîte de dialogue **Modifier le QR code dynamique**, changez l'**URL de destination**.

### 3. Enregistrer [#3-save]

Cliquez sur **Enregistrer les modifications**. QRdx confirme avec « Modifications enregistrées » et « Les scans ouvrent désormais la destination mise à jour. »

## Depuis le Playground [#from-the-playground]

Si le code dynamique est ouvert dans le Playground, saisissez la nouvelle adresse dans **Adresse du site web**. Le commutateur situé en dessous indique « Les codes imprimés ouvrent toujours » votre ancien lien tant que vous n'avez pas cliqué sur **Rediriger vers la nouvelle adresse**. QRdx confirme alors avec « Destination mise à jour ».

## Les modifications sont immédiates [#changes-take-effect-right-away]

QRdx ne met pas les redirections en cache. Le scan suivant ouvre la nouvelle destination, sur tous les téléphones.

## Ne modifiez pas le lien court lui-même [#dont-change-the-short-link-itself]

Changer la destination est toujours sans risque. Ce n'est pas le cas de la modification de la fin du lien du code (back-half) ni de son retrait d'un domaine personnalisé : QRdx vous avertit que les codes imprimés avec l'ancien lien cesseront de fonctionner. Le passage d'un code de son lien `qrdx.dev` à un domaine personnalisé fait exception : le lien `qrdx.dev` continue de fonctionner.

## Annuler une modification [#undo-a-change]

1. Ouvrez le code depuis **Codes** et allez dans son onglet **Paramètres**.
2. Ouvrez **Historique des versions**.
3. Cliquez sur **Restaurer** à côté de la version souhaitée, puis sur **Restaurer la version**.

QRdx conserve jusqu'à 100 versions de chaque code, avec tous les forfaits.

## Ouvrir une page à la place [#open-a-page-instead]

Pour que le code ouvre une page hébergée plutôt qu'un lien, cliquez sur **Changer le type** dans l'onglet **Vue d'ensemble** du code. Consultez [Changer ce qu'ouvre un code imprimé](/docs/help/dynamic-codes/change-the-type).

## En cas de problème [#if-something-goes-wrong]

### Le code imprimé ouvre toujours l'ancienne page [#the-printed-code-still-opens-the-old-page]

Dans le Playground, changer l'adresse ne suffit pas : cliquez sur **Rediriger vers la nouvelle adresse**. Dans le tableau de bord, vérifiez que vous avez cliqué sur **Enregistrer les modifications**. Si la destination est correcte et qu'un scan mène pourtant ailleurs, consultez [Un code ouvre la mauvaise page](/docs/help/troubleshooting/wrong-destination).

### L'option Modifier le lien n'apparaît pas [#edit-link-isnt-there]

Le code est statique : le lien est stocké dans le code et ne peut pas changer. Imprimez plutôt un code dynamique. Consultez [QR code statique ou dynamique : lequel choisir ?](/docs/help/getting-started/static-vs-dynamic).
