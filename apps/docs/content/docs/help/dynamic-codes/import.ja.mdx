title: "他のサービスからコードを移行する"
description: "CSVファイルからリンクをインポートしたり、BitlyなどのQRコードサービスからコードを移行したりできます。"
---

CSVファイルから多数の動的QRコードを一括で作成できます。他のサービスで使っているコードをQRdxに移行することもできます。このページではインポートの手順を説明します。すでに印刷したコードを引き続き使えるようにする方法は、[Bitly、Rebrandlyなどから移行する](/docs/migrate)をご覧ください。

<Callout type="info">
  フリーでは一度に1つのコードしかインポートできません。Proと Businessでは複数のコードを一括でインポートできます。詳しくは[プランと含まれる機能](/docs/help/account-and-billing/plans)をご覧ください。
</Callout>

## CSVファイルから [#from-a-csv-file]

### 1. インポートを開く [#1-open-the-import]

**コード**に移動し、コードのサイドバーにある**インポート**をクリックします。**その他のコード操作**メニュー（**⋯**）から**コードをインポート**、**CSVファイルから**の順に選ぶこともできます。**CSVからコードをインポート**ページが開きます。

### 2. ファイルをアップロードする [#2-upload-your-file]

1行に1つのコードを記載したCSVファイルをアップロードします。必須の列は宛先のみです。タイトル、フォルダ、タグ、スラッグ（カスタムのバックハーフ）も含められます。ファイルは最大{facts.importRows}行、10 MBまで対応しています。

ファイル内のすべてのコードに対して、フォルダとタグを選ぶこともできます。行に独自のフォルダが指定されている場合はそれが優先され、ファイルのタグは、選択したタグに追加されます。

<Shot id="import-csv" />

### 3. 処理を実行する [#3-let-it-run]

作成前にすべての行が検証されます。問題のある行はスキップされ、一覧に表示されます。大きなファイルは分割して送信され、その間は進行状況バーが進みます。一時停止と再開も可能です。

### 4. 結果をダウンロードする [#4-download-the-results]

完了したら、各行の短縮リンクを含む**結果CSV**をダウンロードできます。新しいコードを**PNG（1024 px）**または**SVG（ベクター）**ファイルにまとめたZIPと、インデックスの `codes.csv` もダウンロードできます。

## 他のサービスから [#from-another-service]

**その他のコード操作**メニュー（**⋯**）を開き、**コードをインポート**、**BitlyなどのアプリからQ**ではなく**Bitlyなどのアプリから**の順に選び、現在コードがあるサービスを選びます。

- **Bitly**：Bitlyにサインインし、リンクを選びます。
- **Rebrandly**と**Short.io**：そのサービスのAPIキーを貼り付けます。
- **QR Code Generator PRO**、**Uniqode**、**Flowcode**、**QR TIGER**、**ME-QR**、**TinyURL**、**Hovercode**、**Scanova**、**別のプロバイダー（CSV）**：そのサービスからエクスポートしたファイルをアップロードします（2 MBまで）。

## 印刷済みのコードを使い続ける [#keep-printed-codes-working]

印刷済みのコードは、まだ古いサービスを指しています。使い続けられるようにする方法と、元のバックハーフを維持する方法は、移行ガイドで説明しています。[Bitly、Rebrandlyなどから移行する](/docs/migrate)をご覧ください。

## うまくいかない場合 [#if-something-goes-wrong]

### 一部の行がスキップされた [#some-rows-were-skipped]

結果には、スキップされた各行とその理由が表示されます。たとえば、リンクではないアドレスや、すでに使われているバックハーフなどです。ファイル内の該当行を修正して、もう一度インポートしてください。コードが重複して作成されることはありません。

### インポートが止まった [#the-import-stopped]

ページが再読み込みされたり接続が切れたりした場合は、戻ったときに再開または再試行を選べます。すでに作成されたコードが再度作成されることはありません。

### 1行しかインポートされなかった [#only-one-row-was-imported]

フリーをご利用の場合、一度にインポートできるコードは1つだけです。次の行をインポートするか、[アップグレード](/pricing)してファイル全体をインポートしてください。
