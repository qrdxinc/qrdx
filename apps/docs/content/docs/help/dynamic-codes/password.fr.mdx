---
title: "Protéger un code par mot de passe"
description: "Demandez un mot de passe avant qu'un QR code dynamique n'ouvre sa destination."
---

Avec un mot de passe sur un code dynamique, les personnes qui le scannent doivent le saisir avant d'accéder à votre destination. Utilisez-le pour un code qui ouvre un contenu privé, comme une page réservée au personnel ou le programme d'un événement.

<Callout type="info">
  Les mots de passe sont inclus dans Pro et Business. Vous pouvez supprimer un mot de passe quel que soit votre forfait. Voir [Les forfaits et ce qu'ils incluent](/docs/help/account-and-billing/plans).
</Callout>

## Ajouter un mot de passe [#add-a-password]

1. Ouvrez le code depuis **Codes**, puis allez dans son onglet **Paramètres**.
2. Ouvrez **Accès et planification**.
3. Saisissez un **Mot de passe** de 4 à 64 caractères.
4. Cliquez sur **Enregistrer les modifications**. Le statut du code indique « En ligne et protégé par mot de passe ».

<Shot id="code-password" />

## Ce que voient les personnes qui scannent [#what-scanners-see]

Elles voient une page simple intitulée « Ce QR code est protégé par mot de passe », avec un champ **Mot de passe** et un bouton **Continuer**. Une fois le bon mot de passe saisi, ce navigateur reste déverrouillé pendant 6 heures, ce qui évite de le redemander à chaque scan.

<Shot id="scan-password" />

## Partager le mot de passe séparément [#share-the-password-separately]

Toute personne qui connaît le mot de passe peut ouvrir le code. Transmettez-le comme n'importe quel mot de passe, et non imprimé à côté du code.

## Modifier ou supprimer le mot de passe [#change-or-remove-the-password]

QRdx n'affiche jamais le mot de passe actuel. Pour le modifier, saisissez-en un nouveau dans le champ **Mot de passe** et enregistrez. Pour le supprimer, cliquez sur **Supprimer le mot de passe** (ou videz le champ) et enregistrez ; le panneau indique « Le mot de passe sera supprimé à l'enregistrement ».

## En cas de problème [#if-something-goes-wrong]

### Des personnes disent que le mot de passe ne fonctionne pas [#people-say-the-password-doesnt-work]

Vérifiez que vous avez cliqué sur **Enregistrer les modifications** et que vous avez communiqué le mot de passe avec les caractères exacts, majuscules comprises.

### Vous avez oublié le mot de passe [#youve-forgotten-the-password]

Définissez-en un nouveau. L'ancien mot de passe cesse de fonctionner dès que vous enregistrez.

### Le mot de passe a été redemandé à quelqu'un [#someone-was-asked-again]

Le mot de passe est mémorisé pendant 6 heures dans un même navigateur. Dans un autre navigateur ou sur un autre appareil, ou après avoir vidé les données du navigateur, il est redemandé.
