---
title: "印刷済みQRコードの開き先を変更する"
description: "ウェブサイトリンクのQRコードをホスト型ページに切り替えたり、ページをリンクに戻したりできます。印刷済みのQRコードはそのまま使えます。"
---

動的QRコードの開き先は、ウェブサイトリンクかホスト型ページのどちらかです。印刷後でも、この2つを切り替えられます。短縮リンクは変わらないため、印刷済みのすべてのQRコードは、次回のスキャン時から新しいページまたはリンクを開きます。スキャン数も同じQRコードで引き続きカウントされます。

## ウェブサイトリンクをページに切り替える [#turn-a-website-link-into-a-page]

### 1. 「タイプを変更」を開く [#1-open-change-type]

**Codes** からQRコードを開き、**Overview** タブで **Change type** をクリックします。**Change what this code opens** ダイアログが開きます。

<Shot id="change-type-dialog" />

### 2. ページを選ぶ [#2-pick-a-page]

**Hosted page** で、ページタイプを選び、続けてテンプレートを選びます。

### 3. ページを作成する [#3-build-the-page]

**Continue to editor** をクリックして、ページを作成します。

### 4. 公開する [#4-publish]

ページエディタで **Publish** をクリックします。公開するまで、スキャンは引き続き元のリンクに移動します。公開せずにエディタを離れた場合は何も変わらず、未公開の編集内容はこのブラウザに残ります。

## ページをリンクに戻す [#turn-a-page-back-into-a-link]

1. QRコードを開き、**Change type** をクリックします。
2. **Website link** を選び、アドレスを入力して **Switch to website link** をクリックします。

ページは **Pages** に残ります。ページを元に戻すには、もう一度 **Change type** を開き、**Switch back** から選びます。**Switch back** は、そのQRコードに以前のページがある場合に表示されます。

## 別のページタイプに切り替える [#switch-to-another-page-type]

すでにページを開くQRコードでは、ダイアログに **Another page type** セクションが表示されます。新しいページは選択したテンプレートから始まり、古いページから引き継げるものが引き継がれます。引き継がれるのは、ページ名、設定、ロゴと、テンプレートにも存在するブロック（ヘッダー、リンク、連絡先など）です。引き継げないものはダイアログに一覧表示されます。それらは古いページに残り、古いページは **Pages** に保存されます。

## 変わらないもの [#what-stays-the-same]

短縮リンク、スキャン履歴、フォルダ、タグ、メモ、QRデザイン、パスワード、スケジュール、スキャン上限は変わりません。

設定の中には、片方のタイプでのみ機能するものがあります。

- スマートルーティング、A/Bテスト、UTMパラメータ、コンバージョントラッキングは、ウェブサイトリンクにのみ適用されます。
- トラッキングピクセルは、ホスト型ページでのみ読み込まれます。

これらは切り替えても保持され、元のタイプに戻すとふたたび機能します。保存されているのに使われていない設定は、QRコードの **Settings** タブに表示されます。

## プラン [#plans]

新しいページは、ほかの作成したページと同様に、プランのホスト型ページの数に含まれます。QRコードが開かなくなったページも、**Pages** から削除するまでカウントされます。すでにあるページに戻す場合は、カウントは増えません。詳しくは[プランと制限](/docs/plans-and-limits)をご覧ください。

## 切り替えを元に戻す [#undo-a-switch]

切り替えるたびに、QRコードの以前の設定が **Settings** タブの **Version history** に保存されます。以前のバージョンを復元すると、そのバージョンが開いていたページがまだ存在する限り、タイプも元に戻ります。

## うまくいかない場合 [#if-something-goes-wrong]

### スキャンすると古いリンクが開く [#scans-still-open-the-old-link]

ページをまだ公開していません。**Pages** からページを開き、**Publish** をクリックしてください。

### ダイアログに「Switch back」がない [#switch-back-isnt-in-the-dialog]

**Switch back** は、そのQRコードが以前にページを開いていた場合にのみ表示されます。新しいページの場合は、**Hosted page** でタイプを選んでください。
