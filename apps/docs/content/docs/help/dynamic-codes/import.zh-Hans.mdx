您可以通过 CSV 文件一次性创建多个动态二维码，也可以把您在其他服务中的二维码迁移到 QRdx。本页介绍导入操作本身；如何让已经印刷的二维码继续有效，请参阅[从 Bitly、Rebrandly 等服务迁移](/docs/migrate)。

<Callout type="info">
  免费版一次只能导入一个二维码。Pro 和 Business 可以一次导入多个。请参阅[套餐及包含的功能](/docs/help/account-and-billing/plans)。
</Callout>

## 从 CSV 文件导入 [#from-a-csv-file]

### 1. 打开导入功能 [#1-open-the-import]

进入**二维码**页面，点击二维码侧边栏中的**导入**。您也可以打开**更多二维码操作**菜单（**⋯**），选择**导入二维码**，再选择**从 CSV 文件**。随后会打开**从 CSV 导入二维码**页面。

### 2. 上传文件 [#2-upload-your-file]

上传一个 CSV 文件，每行对应一个二维码。唯一必填的列是目标地址。您还可以包含标题、文件夹、标签和 slug（自定义后缀）。一个文件最多可包含 {facts.importRows} 行，大小不超过 10 MB。

您还可以为文件中的所有二维码统一选择文件夹和标签。已指定自己文件夹的行会保留原有文件夹，文件级标签会添加到您所选的标签之上。

<Shot id="import-csv" />

### 3. 等待导入完成 [#3-let-it-run]

在创建任何二维码之前，会先检查每一行；有问题的行会被跳过并列出。大文件会分批发送，同时进度条逐步填满，您可以暂停和继续。

### 4. 下载结果 [#4-download-the-results]

完成后，您可以下载包含每行短链接的**结果 CSV**，也可以下载包含新二维码的 ZIP 文件，格式为 **PNG (1024 px)** 或 **SVG (vector)**，并附带 `codes.csv` 索引。

## 从其他服务导入 [#from-another-service]

打开**更多二维码操作**菜单（**⋯**），选择**导入二维码**，再选择**从 Bitly 和其他应用**，然后选择您的二维码当前所在的服务。

- **Bitly**：登录 Bitly 并选择链接。
- **Rebrandly** 和 **Short.io**：粘贴该服务的 API 密钥。
- **QR Code Generator PRO**、**Uniqode**、**Flowcode**、**QR TIGER**、**ME-QR**、**TinyURL**、**Hovercode**、**Scanova** 和**其他服务商 (CSV)**：上传从该服务导出的文件，大小不超过 2 MB。

## 让已印刷的二维码继续有效 [#keep-printed-codes-working]

已印刷的二维码仍然指向旧服务。迁移指南介绍了如何让它们继续有效，以及如何保留原有的后缀。请参阅[从 Bitly、Rebrandly 等服务迁移](/docs/migrate)。

## 如果出现问题 [#if-something-goes-wrong]

### 部分行被跳过 [#some-rows-were-skipped]

结果中会列出每个被跳过的行及原因，例如地址不是链接，或后缀已被占用。请在文件中修正这些行后重新导入。不会重复创建二维码。

### 导入中断 [#the-import-stopped]

如果页面刷新或连接中断，您再次回到页面时，页面会提供继续或重试的选项。已创建的二维码不会重复创建。

### 只导入了一行 [#only-one-row-was-imported]

您使用的是免费版，一次只能导入一个二维码。请导入下一行，或[升级](/pricing)以导入整个文件。
