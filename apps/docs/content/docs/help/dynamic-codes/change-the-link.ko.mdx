---

동적 코드의 이동 주소, 즉 스캔했을 때 열리는 페이지는 언제든 바꿀 수 있습니다. 코드 자체에는 짧은 링크만 들어 있기 때문에, 인쇄된 모든 코드가 다음 스캔부터 새 링크를 엽니다.

## 대시보드에서 [#from-your-dashboard]

### 1. 링크 수정 열기 [#1-open-edit-link]

**Codes**로 이동하세요. 코드의 메뉴(**Code actions** 버튼, **⋯**로 표시)를 열고 **Edit link**를 선택해요. 코드를 열어 **Overview** 탭에서 **Edit link**를 클릭해도 됩니다.

### 2. 이동 주소 변경하기 [#2-change-the-destination]

**Edit dynamic QR code** 대화상자에서 **Destination URL**을 변경하세요.

### 3. 저장 [#3-save]

**Save changes**를 클릭하세요. QRdx가 "Changes saved"와 "Scans now open the updated destination."이라는 메시지로 확인해 줍니다.

## Playground에서 [#from-the-playground]

동적 코드가 Playground에 열려 있다면 **Website address**에 새 주소를 입력하세요. 그 아래의 스위치에는 **Point it to the new address**를 클릭하기 전까지 인쇄된 코드가 이전 링크를 계속 연다는 "Printed codes still open" 문구가 표시됩니다. 클릭하면 QRdx가 "Destination updated"로 확인해 줍니다.

## 변경은 바로 적용됩니다 [#changes-take-effect-right-away]

QRdx는 리디렉션을 캐시하지 않습니다. 다음 스캔부터 모든 휴대폰에서 새 이동 주소가 열립니다.

## 짧은 링크 자체는 바꾸지 마세요 [#dont-change-the-short-link-itself]

이동 주소를 바꾸는 것은 언제나 안전합니다. 하지만 코드의 back-half를 바꾸거나 사용자 지정 도메인에서 다른 곳으로 옮기면 안전하지 않습니다. 이 경우 QRdx는 이전 링크로 인쇄된 코드가 작동하지 않게 된다고 경고합니다. 단, 코드를 `qrdx.dev` 링크에서 사용자 지정 도메인으로 옮기는 경우는 예외이며, `qrdx.dev` 링크는 계속 작동합니다.

## 변경 취소하기 [#undo-a-change]

1. **Codes**에서 코드를 열고 **Settings** 탭으로 이동하세요.
2. **Version history**를 여세요.
3. 원하는 버전 옆의 **Restore**를 클릭한 다음 **Restore version**을 클릭하세요.

QRdx는 모든 요금제에서 코드당 최대 100개의 버전을 보관해요.

## 링크 대신 페이지 열기 [#open-a-page-instead]

코드가 링크 대신 호스팅 페이지를 열도록 하려면 코드의 **Overview** 탭에서 **Change type**을 클릭하세요. [인쇄된 코드가 여는 대상 변경하기](/docs/help/dynamic-codes/change-the-type)를 참고하세요.

## 문제가 생겼다면 [#if-something-goes-wrong]

### 인쇄된 코드가 여전히 이전 페이지를 열어요 [#the-printed-code-still-opens-the-old-page]

Playground에서는 주소를 바꾸는 것만으로는 충분하지 않습니다. **Point it to the new address**를 클릭하세요. 대시보드에서는 **Save changes**를 클릭했는지 확인하세요. 이동 주소가 맞는데도 스캔하면 다른 곳으로 이동한다면 [코드가 엉뚱한 페이지를 열어요](/docs/help/troubleshooting/wrong-destination)를 참고하세요.

### Edit link가 보이지 않아요 [#edit-link-isnt-there]

정적 코드이기 때문입니다. 링크가 코드 안에 저장되어 있어 바꿀 수 없어요. 대신 동적 코드를 인쇄하세요. [정적 코드와 동적 코드, 어떤 것이 필요할까요?](/docs/help/getting-started/static-vs-dynamic)를 참고하세요.
