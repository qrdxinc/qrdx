Du kannst viele dynamische QR-Codes auf einmal aus einer CSV-Datei erstellen oder die Codes, die du bei einem anderen Dienst hast, zu QRdx übertragen. Diese Seite behandelt den Import selbst. In [Von Bitly, Rebrandly und anderen umziehen](/docs/migrate) erfährst du, wie bereits gedruckte Codes weiter funktionieren.

<Callout type="info">
  Mit Kostenlos kannst du jeweils einen Code importieren. Pro und Business importieren viele auf einmal. Siehe [Tarife und ihre Leistungen](/docs/help/account-and-billing/plans).
</Callout>

## Aus einer CSV-Datei [#from-a-csv-file]

### 1. Import öffnen [#1-open-the-import]

Gehe zu **Codes** und klicke in der Seitenleiste „Codes" auf **Import**. Du kannst auch das Menü **Weitere Code-Aktionen** (**⋯**) öffnen und **Codes importieren** wählen, dann **Aus einer CSV-Datei**. Die Seite **Codes aus CSV importieren** öffnet sich.

### 2. Datei hochladen [#2-upload-your-file]

Lade eine CSV-Datei mit einem Code pro Zeile hoch. Die einzige Pflichtspalte ist das Ziel. Du kannst außerdem einen Titel, einen Ordner, Tags und einen Slug (den individuellen hinteren Teil des Links) angeben. Eine Datei kann bis zu {facts.importRows} Zeilen enthalten und bis zu 10 MB groß sein.

Du kannst auch einen Ordner und Tags für alle Codes der Datei auswählen. Eine Zeile mit eigenem Ordner behält ihn, und die Tags der Datei werden zu den ausgewählten hinzugefügt.

<Shot id="import-csv" />

### 3. Import laufen lassen [#3-let-it-run]

Jede Zeile wird geprüft, bevor etwas erstellt wird. Zeilen mit Problemen werden übersprungen und aufgelistet. Große Dateien werden in Teilen gesendet, während sich ein Fortschrittsbalken füllt, und du kannst pausieren und fortsetzen.

### 4. Ergebnisse herunterladen [#4-download-the-results]

Wenn der Import fertig ist, lade die **Ergebnis-CSV** mit dem Kurzlink jeder Zeile herunter, oder eine ZIP-Datei mit den neuen Codes als **PNG (1024 px)** oder **SVG (Vektor)** samt einem Index `codes.csv`.

## Von einem anderen Dienst [#from-another-service]

Öffne das Menü **Weitere Code-Aktionen** (**⋯**), wähle **Codes importieren**, dann **Von Bitly und anderen Apps**, und wähle aus, wo sich deine Codes jetzt befinden.

- **Bitly**: Melde dich bei Bitly an und wähle die Links aus.
- **Rebrandly** und **Short.io**: Füge einen API-Schlüssel dieses Dienstes ein.
- **QR Code Generator PRO**, **Uniqode**, **Flowcode**, **QR TIGER**, **ME-QR**, **TinyURL**, **Hovercode**, **Scanova** und **Anderer Anbieter (CSV)**: Lade die Exportdatei dieses Dienstes hoch, bis zu 2 MB.

## Gedruckte Codes weiter nutzbar halten [#keep-printed-codes-working]

Gedruckte Codes verweisen weiterhin auf den alten Dienst. Die Umzugsanleitung erklärt, wie sie weiter funktionieren und wie du deine ursprünglichen Slugs behältst. Siehe [Von Bitly, Rebrandly und anderen umziehen](/docs/migrate).

## Wenn etwas schiefgeht [#if-something-goes-wrong]

### Einige Zeilen wurden übersprungen [#some-rows-were-skipped]

Die Ergebnisse listen jede übersprungene Zeile mit dem Grund auf, zum Beispiel eine Adresse, die kein Link ist, oder ein bereits vergebener Slug. Korrigiere diese Zeilen in deiner Datei und importiere sie erneut. Nichts wird doppelt erstellt.

### Der Import wurde unterbrochen [#the-import-stopped]

Wenn die Seite neu geladen wurde oder die Verbindung abgebrochen ist, bietet die Seite beim Zurückkommen an, fortzusetzen oder es erneut zu versuchen. Bereits erstellte Codes werden nicht noch einmal angelegt.

### Nur eine Zeile wurde importiert [#only-one-row-was-imported]

Du nutzt Kostenlos, das jeweils einen Code importiert. Importiere die nächste Zeile oder [wechsle zu einem höheren Tarif](/pricing), um die ganze Datei zu importieren.
