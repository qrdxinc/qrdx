---
title: "Mude o que um código impresso abre"
description: "Transforme um código de link de site em uma página hospedada, ou uma página de volta em um link. O código impresso continua funcionando."
---

Um QR code dinâmico abre um link de site ou uma página hospedada, e você pode alternar entre os dois depois de imprimir. O link curto não muda, então cada cópia impressa abre a nova página ou o novo link na próxima leitura, e as leituras continuam sendo contadas no mesmo código.

## Transformar um link de site em uma página [#turn-a-website-link-into-a-page]

### 1. Abra Mudar tipo [#1-open-change-type]

Abra o código em **Códigos** e clique em **Mudar tipo** na aba **Visão geral**. A janela **Mude o que este código abre** será aberta.

<Shot id="change-type-dialog" />

### 2. Escolha uma página [#2-pick-a-page]

Em **Página hospedada**, escolha um tipo de página e depois um modelo.

### 3. Monte a página [#3-build-the-page]

Clique em **Continuar para o editor** e monte a página.

### 4. Publique [#4-publish]

Clique em **Publicar** no editor de páginas. As leituras continuam indo para o link antigo até você publicar. Se você sair do editor sem publicar, nada muda, e suas edições não publicadas ficam neste navegador.

## Transformar uma página de volta em um link [#turn-a-page-back-into-a-link]

1. Abra o código e clique em **Mudar tipo**.
2. Escolha **Link de site**, digite o endereço e clique em **Mudar para link de site**.

A página continua em **Páginas**. Para recuperá-la, abra **Mudar tipo** de novo e escolha a página em **Voltar para**, que aparece quando o código já teve páginas antes.

## Mudar para outro tipo de página [#switch-to-another-page-type]

Em um código que já abre uma página, a janela tem uma seção **Outro tipo de página**. A nova página começa do modelo que você escolher e aproveita da antiga o que for compatível: o nome da página, as configurações e o logo, além dos blocos que o modelo também tiver, como o cabeçalho, os links ou os dados de contato. A janela lista o que não for compatível. Isso fica na página antiga, que é mantida em **Páginas**.

## O que permanece igual [#what-stays-the-same]

O link curto, o histórico de leituras, a pasta, as tags, as notas, o design do QR, a senha, o agendamento e o limite de leituras não mudam.

Algumas configurações só funcionam com um dos tipos:

- Roteamento inteligente, testes A/B, parâmetros UTM e rastreamento de conversões valem apenas para links de site.
- Pixels de rastreamento são carregados apenas em páginas hospedadas.

Elas são mantidas quando você muda de tipo e voltam a funcionar se você voltar. A aba **Configurações** do código indica quais estão salvas, mas não estão em uso.

## Planos [#plans]

Uma nova página conta para o limite de páginas hospedadas do seu plano, como qualquer página que você cria. Uma página que o código deixa de abrir continua contando até você excluí-la em **Páginas**. Voltar para uma página que você já tem não aumenta a contagem. Veja [Planos e limites](/docs/plans-and-limits).

## Desfazer uma mudança [#undo-a-switch]

Cada mudança salva as configurações anteriores do código no **Histórico de versões**, na aba **Configurações**. Restaurar uma versão anterior volta o tipo, desde que a página que ele abria ainda exista.

## Se algo der errado [#if-something-goes-wrong]

### As leituras ainda abrem o link antigo [#scans-still-open-the-old-link]

Você ainda não publicou a página. Abra-a em **Páginas** e clique em **Publicar**.

### A opção de voltar não aparece na janela [#switch-back-isnt-in-the-dialog]

Ela só aparece quando o código já abriu uma página antes. Para uma página nova, escolha um tipo em **Página hospedada**.
