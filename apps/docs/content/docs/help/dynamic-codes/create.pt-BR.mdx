---
title: "Criar um QR code dinâmico"
description: "Crie um código que você pode alterar depois de impresso, pelo Playground ou pelo seu painel."
---

Um código dinâmico guarda um link curto, como `qrdx.dev/q/aB3xY7k`, que encaminha cada leitura para o seu destino: a página que você quer que o código abra. Você pode mudar o destino depois de imprimir e ver cada leitura. Dá para criar um pelo Playground enquanto faz o design, ou pelo seu painel.

<Callout type="info">
  Códigos dinâmicos exigem uma conta QRdx grátis. O plano Grátis inclui 10 códigos ativos; Pro e Business não têm limite. Veja [Planos e o que eles incluem](/docs/help/account-and-billing/plans).
</Callout>

## Pelo Playground [#from-the-playground]

### 1. Digite seu link [#1-type-your-link]

Abra o [Playground](/playground?type=url) e digite o endereço em **Endereço do site**.

### 2. Escolha Dinâmico [#2-pick-dynamic]

Abaixo do endereço, o seletor **QR code estático ou dinâmico** oferece **Estático** ("Fixo depois de impresso") e **Dinâmico** ("Edite depois, conte as leituras"). Escolha **Dinâmico**.

Se você não estiver conectado, a janela de login abre. Seu link continua onde está, e o código é criado assim que você entrar.

### 3. Baixe o código [#3-download-the-code]

O QRdx confirma com "Seu QR code agora é dinâmico". O seletor passa a mostrar o link curto com um botão de copiar, além de **Opções do link…** para o domínio, o final personalizado, a pasta e as tags, e **Leituras e configurações** para abrir o código no seu painel. Baixe o código como de costume: agora ele codifica o link curto.

<Shot id="playground-dynamic-on" />

O seletor vale para o tipo URL. Para um cartão de contato, um cardápio ou qualquer outro conteúdo que você queira alterar depois, crie uma [página mobile](/docs/help/pages-and-forms/create-a-page), que ganha um código dinâmico próprio.

## Pelo seu painel [#from-your-dashboard]

### 1. Comece um novo código [#1-start-a-new-code]

Vá em **Códigos** e clique em **Novo código**. A janela **Novo QR code dinâmico** abre.

### 2. Diga o que ele abre [#2-say-what-it-opens]

Em **O que ele abre?**, escolha **Link de site**.

### 3. Preencha os detalhes [#3-fill-in-the-details]

Preencha **URL de destino**. Se quiser, escolha um **Domínio do link curto**, digite um **Final personalizado (opcional)** e dê um **Título (opcional)** ao código.

<Shot id="new-code-dialog" />

### 4. Crie o código [#4-create-it]

Clique em **Criar código**. A janela mostra "Seu QR code dinâmico está pronto" com **Ver análises**, **Abrir o código**, **Criar outro** e **Concluir**. Baixe o código na página dele.

## Escolha o final do seu link curto [#choose-your-own-short-link-ending]

No Pro e no Business, **Final personalizado (opcional)** permite escolher o final do link curto, por exemplo `qrdx.dev/q/spring-menu`. Ele pode ter de 3 a 64 letras, números, hifens ou sublinhados, não pode começar nem terminar com hífen, e algumas palavras reservadas não são permitidas.

No Grátis, o QRdx escolhe para você um final aleatório de 7 caracteres. Links curtos diferenciam maiúsculas de minúsculas.

## Quando você atinge o limite [#when-you-reach-the-limit]

No Grátis, só os códigos ativos contam para os 10. Códigos arquivados e códigos na lixeira não contam; códigos pausados contam. Quando você está no limite, o Playground mostra **Fazer upgrade para o Pro** e **Gerenciar códigos**. [Arquive](/docs/help/dynamic-codes/archive-and-delete) um código que você não usa mais, ou [faça upgrade](/pricing).

## Se algo der errado [#if-something-goes-wrong]

### O seletor não mostra Dinâmico [#the-switch-doesnt-show-dynamic]

O tipo do código não é URL. Clique em **Alterar** no cartão **Tipo de QR code** e escolha **URL**, ou crie uma página mobile para outros conteúdos.

### Você entrou, mas o código não foi criado [#you-signed-in-but-the-code-wasnt-made]

Escolha **Dinâmico** de novo. O link que você digitou continua lá.

### O final personalizado foi recusado [#the-back-half-is-refused]

Ele já está em uso, ou tem um caractere ou uma palavra reservada não permitidos. Tente outro final.
