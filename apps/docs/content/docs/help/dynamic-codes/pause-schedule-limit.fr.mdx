Un code dynamique peut être mis en pause, recevoir des dates de début et de fin, ou être plafonné à un nombre de scans. Tout se trouve au même endroit : ouvrez le code depuis **Codes**, allez dans l'onglet **Paramètres**, puis ouvrez **Accès et planification**. Cliquez sur **Enregistrer les modifications** quand vous avez terminé.

<Callout type="info">
  La mise en pause fonctionne avec tous les forfaits. Les dates de début et de fin, les limites de scans et les URL de secours font partie de Pro et Business. Consultez [Les forfaits et ce qu'ils incluent](/docs/help/account-and-billing/plans).
</Callout>

## Mettre un code en pause [#pause-a-code]

Activez **Mettre le code en pause** et cliquez sur **Enregistrer les modifications**. Le statut du code indique « Code en pause ». Vous pouvez aussi choisir **Mettre en pause** dans le menu du code, dans la liste **Codes**, puis **Reprendre** pour le réactiver.

## Définir des dates de début et de fin [#set-start-and-end-dates]

Renseignez **Début**, **Fin**, ou les deux. Les heures sont exprimées dans votre fuseau horaire. Les scans effectués avant le début ou après la fin n'atteignent pas votre destination. Utilisez cette option pour une campagne à dates fixes.

## Plafonner les scans [#cap-the-scans]

Définissez une **Limite de scans**. Les scans sont comptés de la même façon que dans vos statistiques, robots exclus. Une fois ce nombre de scans atteint, le code se termine.

## Ce que voient les utilisateurs [#what-people-see]

Lorsqu'un code n'est pas actif, les personnes qui le scannent voient une page simple, sans marque QRdx, avec un lien pour signaler un abus :

- En pause : « Cette campagne est en pause ».
- Avant la date de début : « Cette campagne n'a pas encore commencé ».
- Après la date de fin ou la limite de scans : « Cette campagne est terminée ».

## Rediriger vers une page utile [#send-people-somewhere-useful-instead]

Renseignez **URL de secours** pour envoyer les scans d'un code en pause ou terminé vers une page de votre choix, par exemple votre page d'accueil. Elle s'applique aux codes en pause, aux codes dont la date de fin est dépassée et à ceux dont la limite de scans est atteinte. Avant la date de début, les personnes qui scannent voient toujours la page « n'a pas encore commencé ».

## Après un passage à un forfait inférieur [#after-a-downgrade]

Les paramètres déjà enregistrés continuent de fonctionner et vous pouvez les supprimer à tout moment. Pour en modifier un ou en ajouter un nouveau, il faut Pro ou Business.

## En cas de problème [#if-something-goes-wrong]

### La page de secours ne s'affiche pas avant la date de début [#the-fallback-page-doesnt-show-before-the-start-date]

C'est normal. L'URL de secours ne concerne que les codes en pause ou terminés.

### Le code est marqué « En attente de vérification » [#the-code-is-marked-held-for-review]

QRdx vérifie les URL de secours comme il vérifie les destinations. Une URL de secours qui semble dangereuse place le code en attente de vérification, et le code ne redirige plus tant qu'une personne ne l'a pas examiné. [Contactez le support](/docs/help/contact) si vous pensez qu'il s'agit d'une erreur.

### Des scans passent encore après la date de fin [#scans-still-get-through-after-the-end-date]

Vérifiez que vous avez cliqué sur **Enregistrer les modifications** et que l'heure de fin est bien exprimée dans votre fuseau horaire, indiqué dans le panneau à côté des champs.
