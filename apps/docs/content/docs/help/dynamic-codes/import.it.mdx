Puoi creare molti QR code dinamici in una volta sola da un file CSV, oppure spostare in QRdx i codici che hai su un altro servizio. Questa pagina riguarda l'importazione vera e propria; [Passa da Bitly, Rebrandly e altri](/docs/migrate) spiega come far continuare a funzionare i codici che hai già stampato.

<Callout type="info">
  Con il piano Gratuito puoi importare un codice alla volta. Pro e Business ne importano molti insieme. Vedi [Piani e cosa includono](/docs/help/account-and-billing/plans).
</Callout>

## Da un file CSV [#from-a-csv-file]

### 1. Apri l'importazione [#1-open-the-import]

Vai su **Codes** e fai clic su **Import** nella barra laterale dei codici. Puoi anche aprire il menu **More code actions** (**⋯**) e scegliere **Import codes**, poi **From a CSV file**. Si apre la pagina **Import codes from CSV**.

### 2. Carica il file [#2-upload-your-file]

Carica un file CSV con un codice per riga. L'unica colonna obbligatoria è la destinazione. Puoi includere anche un titolo, una cartella, dei tag e uno slug (la parte finale personalizzata). Un file può avere fino a {facts.importRows} righe e pesare fino a 10 MB.

Puoi anche scegliere una cartella e dei tag per tutti i codici del file. Una riga con una propria cartella la mantiene, e i tag del file vengono aggiunti a quelli che scegli.

<Shot id="import-csv" />

### 3. Lascia che proceda [#3-let-it-run]

Ogni riga viene controllata prima che venga creato qualcosa; le righe con problemi vengono saltate e riportate in un elenco. I file grandi vengono inviati a blocchi mentre una barra di avanzamento si riempie, e puoi mettere in pausa e riprendere.

### 4. Scarica i risultati [#4-download-the-results]

Al termine, scarica il **Results CSV** con il link breve di ogni riga, oppure uno ZIP con i nuovi codici come file **PNG (1024 px)** o **SVG (vector)** con un indice `codes.csv`.

## Da un altro servizio [#from-another-service]

Apri il menu **More code actions** (**⋯**), scegli **Import codes**, poi **From Bitly and other apps** e seleziona dove si trovano ora i tuoi codici.

- **Bitly**: accedi a Bitly e scegli i link.
- **Rebrandly** e **Short.io**: incolla una chiave API di quel servizio.
- **QR Code Generator PRO**, **Uniqode**, **Flowcode**, **QR TIGER**, **ME-QR**, **TinyURL**, **Hovercode**, **Scanova** e **Another provider (CSV)**: carica il file di esportazione di quel servizio, fino a 2 MB.

## Far funzionare i codici stampati [#keep-printed-codes-working]

I codici stampati puntano ancora al vecchio servizio. La guida alla migrazione spiega come farli continuare a funzionare e come mantenere le parti finali originali. Vedi [Passa da Bitly, Rebrandly e altri](/docs/migrate).

## Se qualcosa va storto [#if-something-goes-wrong]

### Alcune righe sono state saltate [#some-rows-were-skipped]

I risultati elencano ogni riga saltata con il motivo, ad esempio un indirizzo che non è un link o una parte finale già in uso. Correggi quelle righe nel file e importale di nuovo. Nulla viene creato due volte.

### L'importazione si è interrotta [#the-import-stopped]

Se la pagina si è ricaricata o la connessione è caduta, al tuo ritorno la pagina ti propone di riprendere o riprovare. I codici già creati non vengono creati di nuovo.

### È stata importata solo una riga [#only-one-row-was-imported]

Hai il piano Gratuito, che importa un codice alla volta. Importa la riga successiva, oppure [passa a un piano superiore](/pricing) per importare l'intero file.
