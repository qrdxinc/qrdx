---
title: "Créer un QR code dynamique"
description: "Créez un code que vous pouvez modifier après l'impression, depuis le Playground ou depuis votre tableau de bord."
---

Un code dynamique contient un lien court, comme `qrdx.dev/q/aB3xY7k`, qui redirige chaque scan vers votre destination : la page que vous voulez que le code ouvre. Vous pouvez modifier la destination après l'impression et consulter chaque scan. Vous pouvez en créer un depuis le Playground pendant que vous concevez votre code, ou depuis votre tableau de bord.

<Callout type="info">
  Les codes dynamiques nécessitent un compte QRdx gratuit. Le forfait Gratuit inclut 10 codes actifs ; Pro et Business n'ont aucune limite. Voir [Les forfaits et ce qu'ils incluent](/docs/help/account-and-billing/plans).
</Callout>

## Depuis le Playground [#from-the-playground]

### 1. Saisissez votre lien [#1-type-your-link]

Ouvrez le [Playground](/playground?type=url) et saisissez l'adresse dans **Adresse du site web**.

### 2. Choisissez Dynamique [#2-pick-dynamic]

Sous l'adresse, le sélecteur **QR code statique ou dynamique** propose **Statique** (« Figé une fois imprimé ») et **Dynamique** (« Modifiable plus tard, avec comptage des scans »). Choisissez **Dynamique**.

Si vous n'êtes pas connecté, la fenêtre de connexion s'ouvre. Votre lien reste en place, et le code est créé dès que vous êtes connecté.

### 3. Téléchargez le code [#3-download-the-code]

QRdx confirme avec « Votre QR code est maintenant dynamique ». Le sélecteur affiche alors le lien court avec un bouton de copie, ainsi que **Options du lien…** pour le domaine, la fin du lien, le dossier et les tags, et **Scans et paramètres** pour ouvrir le code dans votre tableau de bord. Téléchargez le code comme d'habitude : il encode désormais le lien court.

<Shot id="playground-dynamic-on" />

Le sélecteur concerne le type URL. Pour une carte de contact, un menu ou tout autre contenu que vous voulez pouvoir modifier plus tard, créez une [page mobile](/docs/help/pages-and-forms/create-a-page), qui dispose de son propre code dynamique.

## Depuis votre tableau de bord [#from-your-dashboard]

### 1. Démarrez un nouveau code [#1-start-a-new-code]

Allez dans **Codes** et cliquez sur **Nouveau code**. La fenêtre **Nouveau QR code dynamique** s'ouvre.

### 2. Indiquez ce qu'il ouvre [#2-say-what-it-opens]

Sous **Que doit-il ouvrir ?**, choisissez **Lien vers un site web**.

### 3. Renseignez les détails [#3-fill-in-the-details]

Renseignez **URL de destination**. Si vous le souhaitez, choisissez un **Domaine du lien court**, saisissez une **Fin de lien personnalisée (facultatif)** et donnez un **Titre (facultatif)** au code.

<Shot id="new-code-dialog" />

### 4. Créez-le [#4-create-it]

Cliquez sur **Créer le code**. La fenêtre affiche « Votre QR code dynamique est prêt » avec **Voir les statistiques**, **Ouvrir le code**, **En créer un autre** et **Terminé**. Téléchargez le code depuis sa page.

## Choisir la fin de votre lien court [#choose-your-own-short-link-ending]

Avec Pro et Business, **Fin de lien personnalisée (facultatif)** vous permet de choisir la fin du lien court, par exemple `qrdx.dev/q/spring-menu`. Elle peut contenir de 3 à 64 lettres, chiffres, tirets ou tirets bas, ne peut pas commencer ni se terminer par un tiret, et quelques mots réservés ne sont pas autorisés.

Avec Gratuit, QRdx choisit pour vous une fin aléatoire de 7 caractères. Les liens courts sont sensibles à la casse.

## Lorsque vous atteignez la limite [#when-you-reach-the-limit]

Avec Gratuit, seuls les codes actifs comptent dans la limite de 10. Les codes archivés et ceux de la corbeille ne comptent pas ; les codes en pause, si. Lorsque vous êtes à la limite, le Playground affiche **Passer à Pro** et **Gérer les codes**. [Archivez](/docs/help/dynamic-codes/archive-and-delete) un code que vous n'utilisez plus, ou [passez à un forfait supérieur](/pricing).

## En cas de problème [#if-something-goes-wrong]

### Le sélecteur n'affiche pas Dynamique [#the-switch-doesnt-show-dynamic]

Le type du code n'est pas URL. Cliquez sur **Modifier** dans la carte **Type de QR code** et choisissez **URL**, ou créez une page mobile pour un autre contenu.

### Vous vous êtes connecté, mais le code n'a pas été créé [#you-signed-in-but-the-code-wasnt-made]

Choisissez à nouveau **Dynamique**. Le lien que vous avez saisi est toujours là.

### La fin de lien est refusée [#the-back-half-is-refused]

Elle est déjà prise, ou elle utilise un caractère ou un mot réservé non autorisé. Essayez une autre fin.
