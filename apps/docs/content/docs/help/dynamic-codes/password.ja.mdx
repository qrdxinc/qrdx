---
title: "コードをパスワードで保護する"
description: "動的QRコードが宛先を開く前に、パスワードの入力を求めます。"
---

動的QRコードにパスワードを設定すると、スキャンした人は宛先に到達する前にパスワードを入力する必要があります。スタッフ用ページやイベントのプログラムなど、非公開の内容を開くコードに使用してください。

<Callout type="info">
  パスワードは Pro と Business の機能です。パスワードの解除はどのプランでも行えます。[プランと含まれる機能](/docs/help/account-and-billing/plans)をご覧ください。
</Callout>

## パスワードを追加する [#add-a-password]

1. **Codes** からコードを開き、**Settings** タブに移動します。
2. **Access & schedule** を開きます。
3. 4～64文字の **Password** を入力します。
4. **Save changes** をクリックします。コードのステータスが「Live and password protected」と表示されます。

<Shot id="code-password" />

## スキャンした人に表示される内容 [#what-scanners-see]

スキャンした人には、「This QR code is password protected」というタイトルのシンプルなページが表示され、**Password** フィールドと **Continue** ボタンがあります。正しいパスワードを入力すると、そのブラウザーでは6時間ロックが解除された状態になるため、スキャンのたびに再入力を求められることはありません。

<Shot id="scan-password" />

## パスワードは別の方法で共有する [#share-the-password-separately]

パスワードを知っている人は誰でもコードを開けます。パスワードはコードの隣に印刷せず、通常のパスワードと同じように別の方法で共有してください。

## パスワードを変更または解除する [#change-or-remove-the-password]

QRdx は現在のパスワードを表示しません。変更するには、**Password** フィールドに新しいパスワードを入力して保存します。解除するには、**Remove password** をクリックするか（またはフィールドを空にして）保存します。このとき、パネルには「The password will be removed when you save」と表示されます。

## 問題が発生した場合 [#if-something-goes-wrong]

### パスワードが使えないと言われた [#people-say-the-password-doesnt-work]

**Save changes** をクリックしたかどうか、また大文字を含め、正確な文字でパスワードを共有したかどうかを確認してください。

### パスワードを忘れた [#youve-forgotten-the-password]

新しいパスワードを設定してください。保存した時点で、古いパスワードは使えなくなります。

### もう一度パスワードを求められた人がいる [#someone-was-asked-again]

パスワードは1つのブラウザーで6時間記憶されます。別のブラウザーやデバイスの場合、またはブラウザーのデータを消去した場合は、再度入力を求められます。
