---
title: "Archiver, supprimer et restaurer des codes"
description: "Ce qui arrive à un code imprimé lorsque vous l'archivez, le placez dans la corbeille ou le supprimez définitivement."
---

Lorsque vous n'avez plus besoin d'un QR code dynamique, vous pouvez l'archiver, le placer dans la corbeille ou le supprimer définitivement. Chaque option empêche le code de fonctionner, mais de manière différente.

<Callout type="warn">
  Archiver, placer dans la corbeille ou supprimer un code l'empêche de fonctionner. Pour retirer en douceur un code imprimé, [mettez-le en pause](/docs/help/dynamic-codes/pause-schedule-limit) et ajoutez plutôt une URL de secours.
</Callout>

## Quelle option choisir [#which-to-choose]

| | Ce que voient les scanners | Compte dans votre limite | Retour avec |
| --- | --- | --- | --- |
| **Mettre en pause** | L'URL de secours, ou « Cette campagne est en pause » | Oui | **Reprendre** |
| **Archiver** | « Ce QR code n'est plus actif » | Non | **Désarchiver** |
| **Placer dans la corbeille** | « Ce QR code n'est plus actif » | Non | **Restaurer** |
| **Supprimer définitivement** | « QR code introuvable » | Non | Rien. Il est perdu. |

## Archiver un code [#archive-a-code]

Dans **Codes**, ouvrez le menu du code (**⋯**) et choisissez **Archiver**. Les codes archivés ne comptent pas dans la limite de codes de votre offre. Choisissez **Désarchiver** pour réactiver le code. Avec l'offre Gratuit, vous avez besoin d'un emplacement de code libre.

## Placer un code dans la corbeille [#move-a-code-to-the-trash]

Ouvrez le menu du code et choisissez **Placer dans la corbeille**. Pour afficher les codes placés dans la corbeille, ouvrez **Filtrer** dans la barre d'outils et réglez **Statut** sur **Corbeille**. Là, le menu de chaque code propose **Restaurer** et **Supprimer définitivement**. QRdx ne vide jamais la corbeille de lui-même.

## Supprimer un code définitivement [#delete-a-code-forever]

Dans la corbeille, choisissez **Supprimer définitivement** sur un code, ou **Vider la corbeille** pour supprimer tout son contenu. L'historique des scans et l'historique des versions du code sont supprimés avec lui, et rien ne permet de le récupérer. Les scanners voient « QR code introuvable ».

## En cas de problème [#if-something-goes-wrong]

### Désarchiver ou Restaurer est refusé [#unarchive-or-restore-is-refused]

Vous êtes sur l'offre Gratuit et vous avez déjà 10 codes actifs. Archivez d'abord un autre code, ou [passez à une offre supérieure](/pricing).

### Vous avez supprimé un code et voulez récupérer ses scans [#you-deleted-a-code-and-want-its-scans-back]

Ils ont disparu avec le code. Avant de supprimer un code dont vous pourriez avoir besoin, [exportez ses scans](/docs/help/dynamic-codes/scans#download-your-scans).
