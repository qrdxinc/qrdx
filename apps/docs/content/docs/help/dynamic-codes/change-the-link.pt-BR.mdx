---
title: "Mude para onde um código aponta"
description: "Edite o destino de um QR code dinâmico. As cópias impressas abrem o novo link na próxima leitura."
---

Você pode mudar o destino de um código dinâmico a qualquer momento: a página que uma leitura abre. Todas as cópias impressas abrem o novo link na próxima leitura, porque o código em si guarda apenas o link curto.

## Pelo seu painel [#from-your-dashboard]

### 1. Abra Editar link [#1-open-edit-link]

Vá em **Códigos**. Abra o menu do código (o botão **Ações do código**, exibido como **⋯**) e escolha **Editar link**. Você também pode abrir o código e clicar em **Editar link** na aba **Visão geral**.

### 2. Mude o destino [#2-change-the-destination]

Na caixa de diálogo **Editar QR code dinâmico**, altere a **URL de destino**.

### 3. Salve [#3-save]

Clique em **Salvar alterações**. O QRdx confirma com "Alterações salvas" e "As leituras agora abrem o destino atualizado."

## Pelo Playground [#from-the-playground]

Se o código dinâmico estiver aberto no Playground, digite o novo endereço em **Endereço do site**. O interruptor logo abaixo diz "Os códigos impressos ainda abrem" o link antigo até você clicar em **Apontar para o novo endereço**. Em seguida, o QRdx confirma com "Destino atualizado".

## As mudanças valem na hora [#changes-take-effect-right-away]

O QRdx não faz cache de redirecionamentos. A próxima leitura abre o novo destino, em qualquer celular.

## Não mude o link curto em si [#dont-change-the-short-link-itself]

Mudar o destino é sempre seguro. Mudar o final do link do código (back-half) ou tirá-lo de um domínio próprio não é: o QRdx avisa que os códigos impressos com o link antigo deixam de funcionar. Mover um código do link `qrdx.dev` para um domínio próprio é a exceção: o link `qrdx.dev` continua funcionando.

## Desfaça uma mudança [#undo-a-change]

1. Abra o código em **Códigos** e vá para a aba **Configurações**.
2. Abra o **Histórico de versões**.
3. Clique em **Restaurar** ao lado da versão que você quer e depois em **Restaurar versão**.

O QRdx guarda até 100 versões de cada código, em todos os planos.

## Abra uma página em vez disso [#open-a-page-instead]

Para fazer o código abrir uma página hospedada em vez de um link, clique em **Alterar tipo** na aba **Visão geral** do código. Veja [Mude o que um código impresso abre](/docs/help/dynamic-codes/change-the-type).

## Se algo der errado [#if-something-goes-wrong]

### O código impresso ainda abre a página antiga [#the-printed-code-still-opens-the-old-page]

No Playground, mudar o endereço não basta: clique em **Apontar para o novo endereço**. No painel, confira se você clicou em **Salvar alterações**. Se o destino está certo e uma leitura ainda cai em outro lugar, veja [Um código abre a página errada](/docs/help/troubleshooting/wrong-destination).

### Não aparece Editar link [#edit-link-isnt-there]

O código é estático: o link fica guardado dentro dele e não pode mudar. Imprima um código dinâmico no lugar. Veja [Estático ou dinâmico: qual você precisa?](/docs/help/getting-started/static-vs-dynamic).
