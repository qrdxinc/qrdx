---
title: "Einen Code mit einem Passwort schützen"
description: "Verlange ein Passwort, bevor ein dynamischer QR-Code sein Ziel öffnet."
---

Mit einem Passwort auf einem dynamischen Code müssen Scannende es eingeben, bevor sie dein Ziel erreichen. Nutze es für einen Code, der etwas Privates öffnet, zum Beispiel eine Seite für Mitarbeitende oder ein Veranstaltungsprogramm.

<Callout type="info">
  Passwörter gehören zu Pro und Business. Ein Passwort zu entfernen funktioniert in jedem Tarif. Siehe [Tarife und was sie enthalten](/docs/help/account-and-billing/plans).
</Callout>

## Passwort hinzufügen [#add-a-password]

1. Öffne den Code unter **Codes** und gehe zum Tab **Einstellungen**.
2. Öffne **Zugriff & Zeitplan**.
3. Gib ein **Passwort** mit 4 bis 64 Zeichen ein.
4. Klicke auf **Änderungen speichern**. Der Status des Codes lautet „Live und passwortgeschützt“.

<Shot id="code-password" />

## Was Scannende sehen [#what-scanners-see]

Scannende sehen eine schlichte Seite mit dem Titel „Dieser QR-Code ist passwortgeschützt“, mit einem Feld **Passwort** und einer Schaltfläche **Weiter**. Nach Eingabe des richtigen Passworts bleibt dieser Browser 6 Stunden lang freigeschaltet, damit nicht bei jedem Scan erneut danach gefragt wird.

<Shot id="scan-password" />

## Das Passwort getrennt weitergeben [#share-the-password-separately]

Jeder, der das Passwort kennt, kann den Code öffnen. Gib es so weiter, wie du jedes andere Passwort weitergeben würdest, nicht neben dem Code aufgedruckt.

## Passwort ändern oder entfernen [#change-or-remove-the-password]

QRdx zeigt das aktuelle Passwort nie an. Um es zu ändern, gib im Feld **Passwort** ein neues ein und speichere. Um es zu entfernen, klicke auf **Passwort entfernen** (oder leere das Feld) und speichere; das Panel zeigt dann „Das Passwort wird beim Speichern entfernt“.

## Wenn etwas schiefgeht [#if-something-goes-wrong]

### Leute sagen, das Passwort funktioniert nicht [#people-say-the-password-doesnt-work]

Prüfe, ob du auf **Änderungen speichern** geklickt hast und ob du das Passwort mit genau denselben Zeichen weitergegeben hast, einschließlich Großbuchstaben.

### Du hast das Passwort vergessen [#youve-forgotten-the-password]

Lege ein neues fest. Das alte Passwort funktioniert nicht mehr, sobald du speicherst.

### Jemand wurde erneut gefragt [#someone-was-asked-again]

Das Passwort wird 6 Stunden lang in einem Browser gespeichert. Bei einem anderen Browser oder Gerät oder nach dem Leeren des Browsers wird erneut danach gefragt.
