title: "Einen Code pausieren, planen oder begrenzen"

---

Ein dynamischer Code lässt sich pausieren, mit Start- und Enddatum versehen oder auf eine bestimmte Anzahl Scans begrenzen. All das findest du an einer Stelle: Öffne den Code unter **Codes**, wechsle zum Tab **Settings** und öffne **Access & schedule**. Klicke zum Abschluss auf **Save changes**.

<Callout type="info">
  Das Pausieren funktioniert in jedem Tarif. Start- und Enddatum, Scan-Limits und Fallback-URLs gehören zu Pro und Business. Siehe [Tarife und was sie enthalten](/docs/help/account-and-billing/plans).
</Callout>

<Shot id="code-settings" />

## Einen Code pausieren [#pause-a-code]

Aktiviere **Pause code** und klicke auf **Save changes**. Der Status des Codes lautet dann „Code paused“. Du kannst auch in der Liste **Codes** im Menü des Codes **Pause** wählen und mit **Resume** den Code wieder einschalten.

## Start- und Enddatum festlegen [#set-start-and-end-dates]

Fülle **Starts**, **Ends** oder beide Felder aus. Die Zeiten gelten in deiner Zeitzone. Scans vor dem Start oder nach dem Ende erreichen dein Ziel nicht. Nutze das für eine Kampagne mit festen Terminen.

## Die Scans begrenzen [#cap-the-scans]

Lege ein **Scan limit** fest. Scans werden so gezählt wie in deinen Analytics, Bots bleiben dabei außen vor. Nach dieser Anzahl an Scans endet der Code.

## Was Besucher sehen [#what-people-see]

Ist ein Code nicht aktiv, sehen Scanner eine schlichte Seite ohne QRdx-Branding, mit einem Link zum Melden von Missbrauch:

- Pausiert: „This campaign is paused“.
- Vor dem Startdatum: „This campaign hasn't started yet“.
- Nach dem Enddatum oder dem Scan-Limit: „This campaign has ended“.

## Besucher stattdessen sinnvoll weiterleiten [#send-people-somewhere-useful-instead]

Trage eine **Fallback URL** ein, um Scans eines pausierten oder beendeten Codes auf eine Seite deiner Wahl zu schicken, zum Beispiel auf deine Startseite. Sie gilt für pausierte Codes, Codes nach dem Enddatum und Codes nach dem Scan-Limit. Vor dem Startdatum sehen Scanner immer die Seite „hasn't started yet“.

## Nach einem Downgrade [#after-a-downgrade]

Bereits gespeicherte Einstellungen funktionieren weiter, und du kannst sie jederzeit entfernen. Um eine Einstellung zu ändern oder neu hinzuzufügen, brauchst du Pro oder Business.

## Wenn etwas nicht klappt [#if-something-goes-wrong]

### Die Fallback-Seite erscheint vor dem Startdatum nicht [#the-fallback-page-doesnt-show-before-the-start-date]

Das ist so gewollt. Die Fallback-URL gilt nur für pausierte und beendete Codes.

### Der Code ist als „Held for review“ markiert [#the-code-is-marked-held-for-review]

QRdx prüft Fallback-URLs genauso wie Ziele. Eine Fallback-URL, die unsicher aussieht, hält den Code zur Prüfung zurück, und er leitet erst weiter, wenn ein Mensch ihn angesehen hat. [Kontaktiere den Support](/docs/help/contact), wenn du glaubst, dass es ein Irrtum ist.

### Nach dem Enddatum kommen noch Scans durch [#scans-still-get-through-after-the-end-date]

Prüfe, ob du auf **Save changes** geklickt hast und ob die Endzeit in deiner Zeitzone angegeben ist. Diese steht im Bereich neben den Feldern.
