---
title: "Codes archivieren, löschen und wiederherstellen"
description: "Was mit einem gedruckten Code passiert, wenn du ihn archivierst, in den Papierkorb verschiebst oder endgültig löschst."
---

Wenn du einen dynamischen QR-Code nicht mehr brauchst, kannst du ihn archivieren, in den Papierkorb verschieben oder endgültig löschen. Jede Option sorgt dafür, dass der Code nicht mehr funktioniert, aber jeweils auf andere Weise.

<Callout type="warn">
  Wenn du einen Code archivierst, in den Papierkorb verschiebst oder löschst, funktioniert er nicht mehr. Wenn du einen gedruckten Code schonend außer Betrieb nehmen willst, [pausiere ihn](/docs/help/dynamic-codes/pause-schedule-limit) stattdessen und lege eine Fallback-URL fest.
</Callout>

## Was du wählen solltest [#which-to-choose]

| | Das sehen Scanner | Zählt zu deinem Limit | Zurück mit |
| --- | --- | --- | --- |
| **Pausieren** | Die Fallback-URL oder „Diese Kampagne ist pausiert“ | Ja | **Fortsetzen** |
| **Archivieren** | „Dieser QR-Code ist nicht mehr aktiv“ | Nein | **Archivierung aufheben** |
| **In den Papierkorb verschieben** | „Dieser QR-Code ist nicht mehr aktiv“ | Nein | **Wiederherstellen** |
| **Endgültig löschen** | „QR-Code nicht gefunden“ | Nein | Nichts. Er ist weg. |

## Einen Code archivieren [#archive-a-code]

Öffne unter **Codes** das Menü des Codes (**⋯**) und wähle **Archivieren**. Archivierte Codes zählen nicht zum Code-Limit deines Tarifs. Wähle **Archivierung aufheben**, um den Code wieder zu aktivieren. Im Tarif Kostenlos brauchst du dafür einen freien Code-Platz.

## Einen Code in den Papierkorb verschieben [#move-a-code-to-the-trash]

Öffne das Menü des Codes und wähle **In den Papierkorb verschieben**. Um Codes im Papierkorb zu sehen, öffne in der Symbolleiste **Filter** und setze **Status** auf **Papierkorb**. Dort bietet das Menü jedes Codes die Optionen **Wiederherstellen** und **Endgültig löschen**. QRdx leert den Papierkorb nie von selbst.

## Einen Code endgültig löschen [#delete-a-code-forever]

Wähle im Papierkorb bei einem Code **Endgültig löschen** oder wähle **Papierkorb leeren**, um alles darin zu löschen. Der Scan-Verlauf und der Versionsverlauf des Codes werden mitgelöscht, und nichts kann ihn zurückholen. Scanner sehen „QR-Code nicht gefunden“.

## Wenn etwas schiefgeht [#if-something-goes-wrong]

### Archivierung aufheben oder Wiederherstellen wird abgelehnt [#unarchive-or-restore-is-refused]

Du hast den Tarif Kostenlos und bereits 10 aktive Codes. Archiviere zuerst einen anderen Code oder [wechsle auf einen höheren Tarif](/pricing).

### Du hast einen Code gelöscht und willst seine Scans zurück [#you-deleted-a-code-and-want-its-scans-back]

Sie sind mit dem Code verschwunden. Bevor du einen Code löschst, den du vielleicht noch brauchst, [exportiere seine Scans](/docs/help/dynamic-codes/scans#download-your-scans).
