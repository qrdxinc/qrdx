---
title: "Arquivar, excluir e restaurar códigos"
description: "O que acontece com um código impresso quando você o arquiva, o move para a lixeira ou o exclui para sempre."
---

Quando você não precisar mais de um QR code dinâmico, pode arquivá-lo, movê-lo para a lixeira ou excluí-lo para sempre. Cada opção faz o código parar de funcionar, mas de um jeito diferente.

<Callout type="warn">
  Arquivar, mover para a lixeira ou excluir um código faz com que ele pare de funcionar. Para desativar um código impresso de forma mais suave, [pause-o](/docs/help/dynamic-codes/pause-schedule-limit) e adicione uma URL de fallback.
</Callout>

## Qual escolher [#which-to-choose]

| | Quem lê vê | Conta no seu limite | Volta com |
| --- | --- | --- | --- |
| **Pausar** | A URL de fallback, ou "Esta campanha está pausada" | Sim | **Retomar** |
| **Arquivar** | "Este QR code não está mais ativo" | Não | **Desarquivar** |
| **Mover para a lixeira** | "Este QR code não está mais ativo" | Não | **Restaurar** |
| **Excluir para sempre** | "QR code não encontrado" | Não | Nada. Ele se foi. |

## Arquivar um código [#archive-a-code]

Em **Códigos**, abra o menu do código (**⋯**) e escolha **Arquivar**. Códigos arquivados não contam no limite de códigos do seu plano. Escolha **Desarquivar** para reativar o código. No plano Grátis, você precisa ter uma vaga livre para códigos.

## Mover um código para a lixeira [#move-a-code-to-the-trash]

Abra o menu do código e escolha **Mover para a lixeira**. Para ver os códigos na lixeira, abra **Filtro** na barra de ferramentas e defina **Status** como **Lixeira**. Lá, o menu de cada código oferece **Restaurar** e **Excluir para sempre**. O QRdx nunca esvazia a lixeira sozinho.

## Excluir um código para sempre [#delete-a-code-forever]

Na lixeira, escolha **Excluir para sempre** em um código, ou **Esvaziar lixeira** para excluir tudo o que está nela. O histórico de leituras e o histórico de versões do código são excluídos junto com ele, e nada pode recuperá-lo. Quem lê o código vê "QR code não encontrado".

## Se algo der errado [#if-something-goes-wrong]

### Desarquivar ou Restaurar é recusado [#unarchive-or-restore-is-refused]

Você está no plano Grátis e já tem 10 códigos ativos. Arquive outro código primeiro ou [faça upgrade](/pricing).

### Você excluiu um código e quer as leituras de volta [#you-deleted-a-code-and-want-its-scans-back]

Elas se foram junto com o código. Antes de excluir um código que talvez você precise, [exporte as leituras dele](/docs/help/dynamic-codes/scans#download-your-scans).
