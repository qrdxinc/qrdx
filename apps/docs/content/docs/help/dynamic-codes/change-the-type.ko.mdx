---
title: "인쇄된 코드가 여는 대상 변경하기"
description: "웹사이트 링크 코드를 호스팅 페이지로 바꾸거나, 페이지를 다시 링크로 되돌릴 수 있어요. 인쇄된 코드는 계속 작동합니다."
---

동적 QR 코드는 웹사이트 링크 또는 호스팅 페이지 중 하나를 열며, 인쇄한 뒤에도 둘 사이를 전환할 수 있습니다. 짧은 링크는 바뀌지 않으므로 인쇄된 모든 코드는 다음 스캔부터 새 페이지나 링크를 열고, 스캔 수도 같은 코드에서 계속 집계됩니다.

## 웹사이트 링크를 페이지로 바꾸기 [#turn-a-website-link-into-a-page]

### 1. 유형 변경 열기 [#1-open-change-type]

**코드**에서 코드를 열고 **개요** 탭의 **유형 변경**을 클릭하세요. **이 코드가 여는 대상 변경** 대화상자가 열립니다.

<Shot id="change-type-dialog" />

### 2. 페이지 선택 [#2-pick-a-page]

**호스팅 페이지**에서 페이지 유형을 고른 다음 템플릿을 선택하세요.

### 3. 페이지 만들기 [#3-build-the-page]

**편집기로 계속**을 클릭하고 페이지를 만드세요.

### 4. 게시 [#4-publish]

페이지 편집기에서 **게시**를 클릭하세요. 게시하기 전까지 스캔은 계속 이전 링크로 이동합니다. 게시하지 않고 편집기를 나가면 아무것도 바뀌지 않으며, 게시하지 않은 수정 내용은 이 브라우저에 남아 있습니다.

## 페이지를 다시 링크로 되돌리기 [#turn-a-page-back-into-a-link]

1. 코드를 열고 **유형 변경**을 클릭하세요.
2. **웹사이트 링크**를 선택하고 주소를 입력한 다음 **웹사이트 링크로 전환**을 클릭하세요.

페이지는 **페이지**에 그대로 남습니다. 다시 사용하려면 **유형 변경**을 다시 열고 **다시 전환**에서 선택하세요. 이 항목은 코드에 이전 페이지가 있을 때 나타납니다.

## 다른 페이지 유형으로 전환하기 [#switch-to-another-page-type]

이미 페이지를 여는 코드에는 대화상자에 **다른 페이지 유형** 섹션이 있습니다. 새 페이지는 선택한 템플릿에서 시작하며, 이전 페이지에서 맞는 내용을 가져옵니다. 페이지 이름, 설정, 로고와 함께 템플릿에도 있는 블록(헤더, 링크, 연락처 등)이 해당됩니다. 맞지 않는 항목은 대화상자에 표시됩니다. 그런 내용은 이전 페이지에 남으며, 이전 페이지는 **페이지**에 보관됩니다.

## 그대로 유지되는 항목 [#what-stays-the-same]

짧은 링크, 스캔 기록, 폴더, 태그, 메모, QR 디자인, 비밀번호, 일정, 스캔 한도는 바뀌지 않습니다.

일부 설정은 한 가지 유형에서만 작동합니다.

- 스마트 라우팅, A/B 테스트, UTM 파라미터, 전환 추적은 웹사이트 링크에만 적용됩니다.
- 추적 픽셀은 호스팅 페이지에서만 로드됩니다.

이 설정들은 전환해도 유지되며, 다시 되돌리면 다시 작동합니다. 저장되어 있지만 사용되지 않는 설정은 코드의 **설정** 탭에 표시됩니다.

## 요금제 [#plans]

새 페이지는 직접 만든 다른 페이지와 마찬가지로 요금제의 호스팅 페이지 수에 포함됩니다. 코드가 더 이상 열지 않는 페이지도 **페이지**에서 삭제하기 전까지는 계속 포함됩니다. 이미 있는 페이지로 되돌릴 때는 개수가 늘어나지 않습니다. [요금제와 한도](/docs/plans-and-limits)를 참고하세요.

## 전환 취소하기 [#undo-a-switch]

전환할 때마다 코드의 이전 설정이 **설정** 탭의 **버전 기록**에 저장됩니다. 이전 버전을 복원하면 그 버전이 열던 페이지가 아직 있는 경우 유형도 함께 되돌아갑니다.

## 문제가 생겼을 때 [#if-something-goes-wrong]

### 스캔하면 여전히 이전 링크가 열려요 [#scans-still-open-the-old-link]

아직 페이지를 게시하지 않았습니다. **페이지**에서 페이지를 열고 **게시**를 클릭하세요.

### 대화상자에 다시 전환 항목이 없어요 [#switch-back-isnt-in-the-dialog]

코드가 이전에 페이지를 연 적이 있을 때만 나타납니다. 새 페이지라면 **호스팅 페이지**에서 유형을 선택하세요.
