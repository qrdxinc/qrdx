CSV 파일로 동적 QR 코드를 한 번에 여러 개 만들 수 있고, 다른 서비스에서 사용하던 코드를 QRdx로 옮길 수도 있습니다. 이 페이지는 가져오기 자체를 다룹니다. 이미 인쇄한 코드를 계속 사용할 수 있게 하는 방법은 [Bitly, Rebrandly 등에서 옮기기](/docs/migrate)에서 설명합니다.

<Callout type="info">
  무료에서는 코드를 한 번에 하나씩 가져올 수 있습니다. Pro와 Business는 여러 개를 한 번에 가져옵니다. [요금제와 포함 기능](/docs/help/account-and-billing/plans)을 참고하세요.
</Callout>

## CSV 파일에서 가져오기 [#from-a-csv-file]

### 1. 가져오기 열기 [#1-open-the-import]

**코드**로 이동한 다음 코드 사이드바에서 **가져오기**를 클릭하세요. **코드 더보기 작업** 메뉴(**⋯**)를 열고 **코드 가져오기**, **CSV 파일에서**를 선택해도 됩니다. **CSV에서 코드 가져오기** 페이지가 열립니다.

### 2. 파일 업로드 [#2-upload-your-file]

한 행에 코드 하나씩 담은 CSV 파일을 업로드하세요. 필수 열은 연결 대상(목적지)뿐입니다. 제목, 폴더, 태그, 슬러그(사용자 지정 백하프)도 넣을 수 있습니다. 파일은 최대 {facts.importRows}행, 최대 10MB까지 가능합니다.

파일에 있는 모든 코드에 적용할 폴더와 태그를 고를 수도 있습니다. 자체 폴더가 있는 행은 그 폴더를 유지하고, 파일에 지정한 태그는 선택한 태그에 추가됩니다.

<Shot id="import-csv" />

### 3. 진행 지켜보기 [#3-let-it-run]

코드를 만들기 전에 모든 행을 먼저 검사하며, 문제가 있는 행은 건너뛰고 목록으로 보여 드립니다. 큰 파일은 진행률 표시줄이 차는 동안 나누어 전송되며, 일시 중지했다가 다시 시작할 수 있습니다.

### 4. 결과 다운로드 [#4-download-the-results]

완료되면 각 행의 짧은 링크가 담긴 **결과 CSV**를 다운로드하거나, 새 코드를 **PNG(1024 px)** 또는 **SVG(벡터)** 파일로 묶고 `codes.csv` 색인을 포함한 ZIP을 다운로드하세요.

## 다른 서비스에서 가져오기 [#from-another-service]

**코드 더보기 작업** 메뉴(**⋯**)를 열고 **코드 가져오기**, **Bitly 및 기타 앱에서**를 선택한 다음, 지금 코드가 있는 곳을 고르세요.

- **Bitly**: Bitly에 로그인한 뒤 링크를 선택하세요.
- **Rebrandly**와 **Short.io**: 해당 서비스의 API 키를 붙여 넣으세요.
- **QR Code Generator PRO**, **Uniqode**, **Flowcode**, **QR TIGER**, **ME-QR**, **TinyURL**, **Hovercode**, **Scanova**, **다른 제공업체(CSV)**: 해당 서비스에서 내보낸 파일을 업로드하세요. 최대 2MB까지 가능합니다.

## 인쇄한 코드 계속 사용하기 [#keep-printed-codes-working]

인쇄한 코드는 여전히 이전 서비스를 가리킵니다. 계속 사용할 수 있게 하는 방법과 기존 백하프를 유지하는 방법은 이전 가이드에서 설명합니다. [Bitly, Rebrandly 등에서 옮기기](/docs/migrate)를 참고하세요.

## 문제가 생겼을 때 [#if-something-goes-wrong]

### 일부 행을 건너뛰었어요 [#some-rows-were-skipped]

결과에는 건너뛴 각 행과 그 이유가 표시됩니다. 예를 들어 링크가 아닌 주소이거나 이미 사용 중인 백하프인 경우입니다. 파일에서 해당 행을 고친 뒤 다시 가져오세요. 코드가 중복 생성되지는 않습니다.

### 가져오기가 중단됐어요 [#the-import-stopped]

페이지가 새로고침되었거나 연결이 끊긴 경우, 다시 돌아오면 페이지에서 이어서 하거나 다시 시도할 수 있습니다. 이미 만든 코드는 다시 만들어지지 않습니다.

### 한 행만 가져와졌어요 [#only-one-row-was-imported]

무료를 사용 중이라 코드를 한 번에 하나씩만 가져올 수 있습니다. 다음 행을 가져오거나 [업그레이드](/pricing)해서 파일 전체를 가져오세요.
