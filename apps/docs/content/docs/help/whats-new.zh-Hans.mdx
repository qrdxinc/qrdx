QRdx 更新频繁,每次更新都有记录。本页说明在哪里查看这些记录、新工作如何确定,以及用户常提到但 QRdx 目前尚未支持的功能。

## 新功能 [#whats-new]

每个版本都收录在[更新日志](/changelogs)中,按时间从新到旧排列,并标明版本号和日期。每条记录都会说明改动了什么,以及在应用中的哪个位置可以找到。更新日志还提供订阅源,你可以关注。

## 后续计划 [#whats-next]

我们不会发布带日期的路线图,也不会在功能完成之前就做出承诺。功能上线后,会记录在更新日志中。

用户的需求决定我们要做什么。如需提出需求:

- 使用 qrdx.dev 上的支持组件,或发邮件至 [support@qrdx.dev](mailto:support@qrdx.dev);
- 或在 [GitHub Discussions](https://github.com/qrdxinc/qrdx/discussions) 中发起一个想法。

## QRdx 目前不支持的功能 [#what-qrdx-doesnt-do-today]

用户常问到、但 QRdx 目前还没有的功能:

- **直接在 Playground 中为链接以外的内容创建动态码。** **Dynamic** 开关仅适用于 URL 类型。如果你想为通讯录名片、菜单、PDF 或其他之后还要修改的内容生成二维码,请使用[移动页面](/docs/help/pages-and-forms/create-a-page)。
- **所有插件都上架应用商店。** [插件页面](/plugins)说明了目前每个插件的安装方式,包括从应用商店安装或从源码安装。

<IfAvailable feature="sso">

- **自动开通与停用账号(SCIM)。** Business 工作区可以启用[单点登录](/docs/help/teams/single-sign-on),并要求其域名下的成员必须使用单点登录,但在你的身份提供商中移除某人,并不会将其从工作区中移除。在要求使用单点登录的情况下,该成员会在一天内被登出。
