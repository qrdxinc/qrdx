---
title: "Uma leitura mostra uma página de erro"
description: "O que significa cada página de erro de QR code, de \"QR code not found\" a \"This campaign has ended\", e como resolver."
---

Quando um QR code dinâmico não consegue abrir o destino, quem faz a leitura vê uma página curta no lugar. Cada página abaixo é uma delas, com a causa, a solução e como conferir se funcionou. A maioria vem das configurações do próprio código.

## "This campaign is paused", "This campaign hasn't started yet" ou "This campaign has ended" [#this-campaign-is-paused-this-campaign-hasnt-started-yet-or-this-campaign-has-ended]

O código está pausado, ainda não chegou à data de início, passou da data de término ou atingiu o limite de leituras.

1. Abra o código em **Codes** e vá para a aba **Settings**, depois **Access & schedule**.
2. Desative **Pause code**, altere **Starts** ou **Ends**, ou aumente o **Scan limit**.
3. Clique em **Save changes**.

Faça a leitura de novo: o destino abre. Para enviar as pessoas a um lugar útil enquanto um código está pausado ou encerrado, preencha **Fallback URL**. Veja [Pause, schedule or limit a code](/docs/help/dynamic-codes/pause-schedule-limit).

## "This QR code is password protected" [#this-qr-code-is-password-protected]

O código tem uma senha, e esta é a página que a solicita. Digite-a em **Password** e clique em **Continue**; o navegador fica desbloqueado por 6 horas. Para remover a senha, abra **Access & schedule** e clique em **Remove password**. Veja [Protect a code with a password](/docs/help/dynamic-codes/password).

## "This QR code is no longer active" [#this-qr-code-is-no-longer-active]

O código está arquivado ou na lixeira. Em **Codes**, abra o menu do código e escolha **Unarchive**, ou filtre a lista por **Trash** e escolha **Restore**. No plano Grátis, você precisa de uma vaga livre para códigos. Faça a leitura de novo para confirmar. Veja [Archive, delete and restore codes](/docs/help/dynamic-codes/archive-and-delete).

O QRdx também mostra esta página para um código que ele desativou após uma denúncia de abuso.

## "QR code not found" [#qr-code-not-found]

O link curto não pertence a nenhum código. Uma destas situações aconteceu:

- O código foi excluído definitivamente, ou a conta dona dele foi excluída. Um código excluído não pode voltar.
- O back-half do código foi alterado depois da impressão. Abra **Edit link** e volte ao valor anterior.
- O link foi digitado à mão com algum erro. Links curtos diferenciam maiúsculas de minúsculas.

## "This domain isn't connected yet" [#this-domain-isnt-connected-yet]

O código usa um domínio personalizado cuja configuração de DNS não foi concluída. Vá em **Settings** → **Domains**, adicione os registros exibidos e clique em **Verify**. A página deixa de aparecer quando o domínio estiver como **Verified**. Veja [Use your own domain](/docs/help/domains/custom-domains).

## "Too many requests" [#too-many-requests]

Uma mesma rede abriu muitos QR codes em poucos segundos. Espere um momento e faça a leitura de novo. Não há nada de errado com o código.

## "Page not found" em uma página mobile [#page-not-found-on-a-mobile-page]

A página hospedada em `/p/…` foi excluída ou o endereço foi digitado errado. Procure a página em **Pages & forms** e confira se o código aponta para ela. Veja [Change what a printed code opens](/docs/help/dynamic-codes/change-the-type).

## "This form isn't accepting responses right now." [#this-form-isnt-accepting-responses-right-now]

O workspace atingiu o limite mensal de respostas de formulário. Ele reabre no mês seguinte, ou na hora, após um upgrade. Veja [Collect answers with a form](/docs/help/pages-and-forms/forms#monthly-limits).

## Ainda com problemas [#still-stuck]

[Fale com o suporte](/docs/help/contact) informando o link curto do código e o texto exato que aparece na página.
