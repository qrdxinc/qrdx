---
title: "Ein Scan zeigt eine Fehlerseite"
description: "Was die einzelnen QR-Code-Fehlerseiten bedeuten, von „QR-Code nicht gefunden“ bis „Diese Kampagne ist beendet“, und wie du sie behebst."
---

Wenn ein dynamischer QR-Code sein Ziel nicht öffnen kann, sehen Scannende stattdessen eine kurze Seite. Jede Seite unten ist eine davon, mit Ursache, Lösung und der Prüfung, ob es geklappt hat. Die meisten stammen aus den eigenen Einstellungen des Codes.

## „Diese Kampagne ist pausiert“, „Diese Kampagne hat noch nicht begonnen“ oder „Diese Kampagne ist beendet“ [#this-campaign-is-paused-this-campaign-hasnt-started-yet-or-this-campaign-has-ended]

Der Code ist pausiert, hat sein Startdatum noch nicht erreicht, ist über das Enddatum hinaus oder hat sein Scan-Limit erreicht.

1. Öffne den Code unter **Codes** und gehe zum Tab **Einstellungen**, dann zu **Zugriff & Zeitplan**.
2. Deaktiviere **Code pausieren**, ändere **Beginn** oder **Ende** oder erhöhe das **Scan-Limit**.
3. Klicke auf **Änderungen speichern**.

Scanne erneut: Das Ziel öffnet sich. Damit Leute während einer Pause oder nach dem Ende trotzdem etwas Nützliches sehen, trage eine **Fallback-URL** ein. Siehe [Einen Code pausieren, planen oder begrenzen](/docs/help/dynamic-codes/pause-schedule-limit).

## „Dieser QR-Code ist passwortgeschützt“ [#this-qr-code-is-password-protected]

Der Code hat ein Passwort, und diese Seite fragt danach. Gib es unter **Passwort** ein und klicke auf **Weiter**; der Browser bleibt 6 Stunden lang entsperrt. Um das Passwort zu entfernen, öffne **Zugriff & Zeitplan** und klicke auf **Passwort entfernen**. Siehe [Einen Code mit einem Passwort schützen](/docs/help/dynamic-codes/password).

## „Dieser QR-Code ist nicht mehr aktiv“ [#this-qr-code-is-no-longer-active]

Der Code ist archiviert oder im Papierkorb. Öffne unter **Codes** das Menü des Codes und wähle **Aus Archiv holen**, oder filtere die Liste nach **Papierkorb** und wähle **Wiederherstellen**. Im Plan Kostenlos brauchst du dafür einen freien Code-Platz. Scanne erneut, um es zu bestätigen. Siehe [Codes archivieren, löschen und wiederherstellen](/docs/help/dynamic-codes/archive-and-delete).

QRdx zeigt diese Seite auch für einen Code an, der nach einer Missbrauchsmeldung deaktiviert wurde.

## „QR-Code nicht gefunden“ [#qr-code-not-found]

Der Kurzlink gehört zu keinem Code. Einer dieser Fälle ist eingetreten:

- Der Code wurde endgültig gelöscht, oder das Konto, dem er gehörte, wurde gelöscht. Ein gelöschter Code lässt sich nicht zurückholen.
- Der hintere Teil des Links wurde nach dem Druck geändert. Öffne **Link bearbeiten** und ändere ihn zurück.
- Der Link wurde von Hand mit einem Fehler eingetippt. Bei Kurzlinks kommt es auf Groß- und Kleinschreibung an.

## „Diese Domain ist noch nicht verbunden“ [#this-domain-isnt-connected-yet]

Der Code nutzt eine eigene Domain, deren DNS-Einrichtung noch nicht abgeschlossen ist. Gehe zu **Einstellungen** → **Domains**, füge die angezeigten Einträge hinzu und klicke auf **Verifizieren**. Die Seite verschwindet, sobald die Domain **Verifiziert** ist. Siehe [Eigene Domain verwenden](/docs/help/domains/custom-domains).

## „Zu viele Anfragen“ [#too-many-requests]

Ein Netzwerk hat innerhalb weniger Sekunden sehr viele QR-Codes geöffnet. Warte einen Moment und scanne erneut. Mit dem Code stimmt alles.

## „Seite nicht gefunden“ bei einer mobilen Seite [#page-not-found-on-a-mobile-page]

Die gehostete Seite unter `/p/…` wurde gelöscht, oder ihre Adresse wurde falsch eingetippt. Prüfe unter **Seiten & Formulare**, ob die Seite existiert und ob der Code auf sie zeigt. Siehe [Ändern, was ein gedruckter Code öffnet](/docs/help/dynamic-codes/change-the-type).

## „Dieses Formular nimmt derzeit keine Antworten an.“ [#this-form-isnt-accepting-responses-right-now]

Der Workspace hat sein monatliches Limit für Formularantworten erreicht. Es öffnet sich nächsten Monat wieder, oder sofort nach einem Upgrade. Siehe [Antworten mit einem Formular sammeln](/docs/help/pages-and-forms/forms#monthly-limits).

## Du kommst nicht weiter [#still-stuck]

[Kontaktiere den Support](/docs/help/contact) mit dem Kurzlink des Codes und dem genauen Text auf der Seite.
