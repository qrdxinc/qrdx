---
title: "Un code ne se scanne pas"
description: "Pourquoi un QR code ne se scanne pas, et comment corriger chaque cause."
---

Si l'appareil photo d'un téléphone ne réagit pas à votre code, ou ne le lit que de temps en temps, la cause se trouve presque toujours parmi celles ci-dessous. Commencez par identifier laquelle.

- Pour un design dans le [Playground](/playground), cliquez sur le **score de scan** sous l'aperçu. Le panneau **Va-t-il se scanner ?** affiche en premier les vérifications échouées. Voir [Vérifier un design avec le score de scan](/docs/help/designing/scan-score).
- Pour un code déjà imprimé, prenez-le en photo et déposez la photo dans le [vérificateur de scan](/tools/scan-checker). Il indique ce que dit le code et la qualité de sa lecture.

## L'appareil photo ne réagit pas du tout [#the-camera-doesnt-react-at-all]

### Contraste faible, ou code clair sur fond sombre [#low-contrast-or-a-light-code-on-a-dark-background]

Les scanners cherchent des carrés sombres sur un fond clair, et abandonnent quand les deux sont trop proches. Assombrissez le code ou éclaircissez le fond, et inversez les couleurs si le code est la partie claire. Pour vérifier : la vérification **Contraste** du score de scan est réussie à partir de 4,5:1. Voir [Choisir des couleurs qui se scannent](/docs/help/designing/colors-and-contrast).

### Pas de bordure dégagée autour du code [#no-clear-border-around-the-code]

Les scanners ont besoin d'un espace vide autour du code pour en repérer les bords. Réglez **Marge** sur **Standard** ou **Grande** dans l'onglet **Design**, et évitez que du texte ou un visuel touche le code. Pour vérifier : la vérification **Zone de silence** est réussie.

<Diagram id="wont-scan-quiet-zone" />

### Imprimé trop petit [#printed-too-small]

Un code se scanne à une distance d'environ dix fois sa largeur : un code de 2 cm lu à l'autre bout d'une pièce échoue. Imprimez-le à environ un dixième de la distance de scan : 2 cm pour une carte lue à 20 cm, 10 cm pour une affiche lue à 1 m. Le [calculateur de taille d'impression](/tools/print-size) fait le calcul pour votre code. Pour vérifier : scannez une impression de test depuis la distance réelle.

## Il ne se scanne que de temps en temps [#it-scans-only-sometimes]

### Un logo en couvre trop [#a-logo-covers-too-much]

La correction d'erreur ne peut reconstituer qu'une partie limitée d'un code. Réglez **Correction d'erreur** sur **Élevée** dans l'onglet **Design**, ou réduisez le logo. Pour vérifier : la vérification **Logo** est réussie. Voir [Ajouter un logo](/docs/help/designing/logos).

### Yeux ronds ou ondulés [#circle-or-curly-eyes]

Certaines applications de scan ne reconnaissent pas les yeux de coin ronds ou ondulés. Passez à des yeux carrés, arrondis ou en engrenage. Pour vérifier : la vérification **Forme des yeux** est réussie.

<Diagram id="wont-scan-eyes" />

### Trop de contenu [#too-much-content]

Un QR code statique qui contient un long texte ou une longue adresse devient dense, et les codes denses échouent quand ils sont petits. Faites plutôt un QR code dynamique : il ne contient qu'un lien court. Voir [Statique ou dynamique : lequel vous faut-il ?](/docs/help/getting-started/static-vs-dynamic).

## Il se scanne à l'écran mais pas à l'impression [#it-scans-on-screen-but-not-in-print]

### Impression floue, surface brillante ou courbe [#blurry-print-or-a-glossy-or-curved-surface]

Les images en pixels imprimées en grand deviennent floues, et les surfaces brillantes ou courbes renvoient la lumière vers l'appareil photo. Téléchargez un SVG, un EPS ou un PDF depuis l'onglet **Prêt à imprimer**, imprimez sur une surface mate et gardez le code à plat. Pour vérifier : imprimez un exemplaire et scannez-le avec deux téléphones différents avant d'en imprimer davantage. Voir [Télécharger et imprimer un QR code](/docs/help/getting-started/download-and-print).

## Il se scanne, mais affiche une erreur [#it-scans-but-shows-an-error]

L'appareil photo lit le code et ouvre une page du type « QR code introuvable ». Ce n'est pas un problème de scan : voir [Un scan affiche une page d'erreur](/docs/help/troubleshooting/error-pages).

## Toujours bloqué [#still-stuck]

[Contactez le support](/docs/help/contact) avec une photo du code imprimé et le modèle de téléphone que vous avez essayé.
