---
title: "Um código abre a página errada"
description: "Por que um QR code abre um link antigo ou inesperado e como descobrir o que ele realmente guarda."
---

Um código que abre uma página antiga ou inesperada é um QR code estático que ainda guarda o link antigo, ou um QR code dinâmico com alguma configuração que envia a leitura para outro lugar. Descubra primeiro qual é o caso e depois siga a lista.

## Primeiro, veja o que o código guarda [#first-see-what-the-code-holds]

Tire uma foto do código impresso e coloque no [verificador de leitura](/tools/scan-checker). Ele mostra exatamente o que o código contém.

- Se mostrar o endereço do seu site, o código é **estático**.
- Se mostrar um link curto como `qrdx.dev/q/…` ou um link no seu próprio domínio, o código é **dinâmico**.

## Um código estático abre o link antigo [#a-static-code-opens-the-old-link]

O código foi baixado antes de se tornar dinâmico, então ele guarda o link antigo e não pode ser alterado. Transforme o código em dinâmico e imprima a nova versão. Confirme: o verificador de leitura mostra um link curto. Veja [Crie um QR code dinâmico](/docs/help/dynamic-codes/create).

## Um código dinâmico ainda abre o destino antigo [#a-dynamic-code-still-opens-the-old-destination]

O novo destino não foi salvo. No Playground, alterar o endereço não basta: clique em **Point it to the new address**. No painel, abra **Edit link**, altere a **Destination URL** e clique em **Save changes**. Confirme: faça a leitura de novo. O QRdx não faz cache dos redirecionamentos, então a próxima leitura usa o novo destino. Veja [Mude para onde um código aponta](/docs/help/dynamic-codes/change-the-link).

## Algumas pessoas chegam a outra página [#some-people-land-on-a-different-page]

Uma regra de roteamento inteligente ou um teste A/B envia parte das leituras para outro lugar. Abra a aba **Settings** do código e depois **Smart routing**. A primeira regra que corresponder vence, então confira a ordem. Abra **Test your rules (uses unsaved changes)** e clique em **Run test** para ver para onde uma leitura iria. Em um teste A/B, cada visitante mantém a mesma versão durante o dia, então duas pessoas podem ver páginas diferentes. Veja [Envie leituras para links diferentes](/docs/help/dynamic-codes/routing).

## O código abre a sua página de fallback [#the-code-opens-your-fallback-page]

O código está pausado, passou da data de término ou do limite de leituras, então as leituras vão para a **Fallback URL**. Abra **Access & schedule** na aba **Settings** e retome o código, ou altere as datas ou o limite. Veja [Pause, agende ou limite um código](/docs/help/dynamic-codes/pause-schedule-limit).

## O link tem texto extra depois de um ponto de interrogação [#the-link-has-extra-text-after-a-question-mark]

Você configurou parâmetros UTM, então as leituras abrem o seu link com tags `utm_` adicionadas. Isso é esperado, e a página é a mesma.

## A página certa abre, mas parece antiga [#the-right-page-opens-but-it-looks-old]

O celular está mostrando uma cópia em cache do seu site, não do redirecionamento. Recarregue a página no navegador.

## Continua errado [#still-wrong]
