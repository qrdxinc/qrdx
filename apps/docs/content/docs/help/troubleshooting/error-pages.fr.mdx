---
title: "Un scan affiche une page d'erreur"
description: "Ce que signifie chaque page d'erreur de QR code, de « QR code introuvable » à « Cette campagne est terminée », et comment la corriger."
---

Lorsqu'un QR code dynamique ne peut pas ouvrir sa destination, les personnes qui le scannent voient une courte page à la place. Chaque page ci-dessous correspond à l'une d'elles, avec la cause, la solution et la manière de vérifier que cela a fonctionné. La plupart proviennent des paramètres du code lui-même.

## « Cette campagne est en pause », « Cette campagne n'a pas encore commencé » ou « Cette campagne est terminée » [#this-campaign-is-paused-this-campaign-hasnt-started-yet-or-this-campaign-has-ended]

Le code est en pause, n'a pas atteint sa date de début, a dépassé sa date de fin ou a atteint sa limite de scans.

1. Ouvrez le code depuis **Codes** et allez dans son onglet **Paramètres**, puis **Accès et planification**.
2. Désactivez **Mettre le code en pause**, modifiez **Début** ou **Fin**, ou augmentez la **Limite de scans**.
3. Cliquez sur **Enregistrer les modifications**.

Scannez à nouveau : la destination s'ouvre. Pour envoyer les gens vers une page utile pendant qu'un code est en pause ou terminé, renseignez **URL de secours**. Consultez [Mettre en pause, planifier ou limiter un code](/docs/help/dynamic-codes/pause-schedule-limit).

## « Ce QR code est protégé par mot de passe » [#this-qr-code-is-password-protected]

Le code est protégé par un mot de passe, et cette page sert à le demander. Saisissez-le dans **Mot de passe** et cliquez sur **Continuer** ; le navigateur reste déverrouillé pendant 6 heures. Pour supprimer le mot de passe, ouvrez **Accès et planification** et cliquez sur **Supprimer le mot de passe**. Consultez [Protéger un code par mot de passe](/docs/help/dynamic-codes/password).

## « Ce QR code n'est plus actif » [#this-qr-code-is-no-longer-active]

Le code est archivé ou dans la corbeille. Dans **Codes**, ouvrez le menu du code et choisissez **Désarchiver**, ou filtrez la liste sur **Corbeille** et choisissez **Restaurer**. Avec Gratuit, vous avez besoin d'un emplacement de code gratuit disponible. Scannez à nouveau pour confirmer. Consultez [Archiver, supprimer et restaurer des codes](/docs/help/dynamic-codes/archive-and-delete).

QRdx affiche aussi cette page pour un code qu'il a désactivé après un signalement d'abus.

## « QR code introuvable » [#qr-code-not-found]

Le lien court n'appartient à aucun code. L'un des cas suivants s'est produit :

- Le code a été supprimé définitivement, ou le compte qui le possédait a été supprimé. Un code supprimé ne peut pas être récupéré.
- La fin du lien (back-half) du code a été modifiée après l'impression. Ouvrez **Modifier le lien** et rétablissez-la.
- Le lien a été saisi à la main avec une erreur. Les liens courts sont sensibles à la casse.

## « Ce domaine n'est pas encore connecté » [#this-domain-isnt-connected-yet]

Le code utilise un domaine personnalisé dont la configuration DNS n'est pas terminée. Allez dans **Paramètres** → **Domaines**, ajoutez les enregistrements indiqués et cliquez sur **Vérifier**. La page disparaît une fois le domaine **Vérifié**. Consultez [Utiliser votre propre domaine](/docs/help/domains/custom-domains).

## « Trop de requêtes » [#too-many-requests]

Un même réseau a ouvert de nombreux QR codes en quelques secondes. Patientez un instant et scannez à nouveau. Le code n'a aucun problème.

## « Page introuvable » sur une page mobile [#page-not-found-on-a-mobile-page]

La page hébergée située à `/p/…` a été supprimée, ou son adresse a été mal saisie. Vérifiez la page dans **Pages et formulaires**, ainsi que le fait que le code pointe bien vers elle. Consultez [Modifier ce qu'ouvre un code imprimé](/docs/help/dynamic-codes/change-the-type).

## « Ce formulaire n'accepte pas de réponses pour le moment. » [#this-form-isnt-accepting-responses-right-now]

L'espace de travail a atteint sa limite mensuelle de réponses aux formulaires. Il rouvre le mois prochain, ou immédiatement après une mise à niveau. Consultez [Recueillir des réponses avec un formulaire](/docs/help/pages-and-forms/forms#monthly-limits).

## Toujours bloqué [#still-stuck]

[Contactez le support](/docs/help/contact) en indiquant le lien court du code et le texte exact affiché sur la page.
