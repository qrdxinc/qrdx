QRdxは頻繁に更新されており、すべての変更が記録されています。このページでは、変更内容を読める場所、新しい開発をどのように決めているか、そしてよく要望をいただくもののうちQRdxにまだないものをご案内します。

## 新機能 [#whats-new]

すべてのリリースは[変更履歴](/changelogs)に新しい順で掲載されており、バージョン番号と日付が付いています。各項目には、何が変わったか、アプリのどこで確認できるかが書かれています。変更履歴にはフィードもあり、購読できます。

## 今後の予定 [#whats-next]

日付入りのロードマップは公開しておらず、完成前に機能をお約束することもありません。何かがリリースされたときは、変更履歴に掲載します。

開発内容は、皆さまからの要望を参考に決めています。要望を送るには次の方法があります。

- qrdx.dev のサポートウィジェットを使うか、[support@qrdx.dev](mailto:support@qrdx.dev) にメールを送る
- または [GitHub Discussions](https://github.com/qrdxinc/qrdx/discussions) でアイデアを投稿する

## 現在QRdxでできないこと [#what-qrdx-doesnt-do-today]

現時点でQRdxにない機能として、よくお問い合わせいただくものは次のとおりです。

- **Playgroundから直接作る、リンク以外の内容の動的QRコード。** **動的**のスイッチはURLタイプ用です。連絡先カード、メニュー、PDFなど、後から内容を変更したいものには、[モバイルページ](/docs/help/pages-and-forms/create-a-page)を使ってください。
- **すべてのプラグインのアプリストア掲載。** 現在の各プラグインのインストール方法（ストアから、またはソースから）は、[プラグインのページ](/plugins)をご覧ください。

<IfAvailable feature="sso">

- **自動プロビジョニング（SCIM）。** Businessのワークスペースでは[シングルサインオン](/docs/help/teams/single-sign-on)を有効にでき、ドメインに対して必須にすることもできます。ただし、IDプロバイダーからメンバーを削除しても、ワークスペースからは削除されません。シングルサインオンを必須にしている場合は、1日以内にそのメンバーがサインアウトされます。

</IfAvailable>
