QRdx는 QR 코드용 모바일 페이지를 호스팅합니다. 링크 목록, 메뉴, 연락처 카드, 쿠폰은 물론 {facts.hostedPageTypes}가지의 다른 유형도 만들 수 있습니다. 블록으로 페이지를 구성하며, 코드를 다시 인쇄하지 않고도 언제든 수정할 수 있습니다.

<Callout type="info">
  무료 플랜에는 페이지 3개가 포함되며, 작은 "Made with QRdx" 푸터가 표시됩니다. Pro는 페이지 수에 제한이 없고 푸터도 없습니다. Business는 화이트 라벨 페이지와 사용자 지정 CSS를 추가로 제공합니다. [플랜과 포함 기능](/docs/help/account-and-billing/plans)을 참고하세요.
</Callout>

## 페이지 만들기 [#create-a-page]

### 1. 새 페이지 시작하기 [#1-start-a-new-page]

대시보드에서 **Pages & forms**로 이동한 다음 **New page**를 클릭하세요.

### 2. 유형 선택하기 [#2-pick-a-type]

페이지의 용도를 선택하세요. 링크 목록, Business, vCard Plus, 메뉴, 쿠폰, 이벤트, 앱 다운로드, 피드백 및 양식, PDF, 이미지, MP3 / 오디오, 동영상, 소셜 미디어, 제품, 예약, 결제 및 팁, 부동산 매물, 반려동물 ID 태그, 의료 ID, 플레이리스트, 사용자 지정 페이지 중에서 고를 수 있습니다.

### 3. 템플릿 선택하기 [#3-pick-a-template]

시작점으로 사용할 템플릿을 선택하세요. 모든 블록, 색상, 텍스트는 나중에 바꿀 수 있어요.

### 4. 만들기 [#4-create-it]

원하면 페이지 이름을 정한 다음 **Create page**를 클릭하세요. 편집기가 열리고, 동시에 QRdx가 페이지용 동적 QR 코드를 만듭니다.

[Playground](/playground)에서 시작할 수도 있습니다. **QR code type** 카드에서 **Change**를 클릭하고 **Hosted pages** 그룹에서 유형을 선택하세요.

## 편집하고 게시하기 [#edit-and-publish]

페이지 편집기에는 탭이 세 개 있어요. 콘텐츠는 **Blocks**, 색상과 글꼴은 **Design**, 이름과 기타 옵션은 **Settings**에서 설정합니다.

<Shot id="page-editor" />

**Publish**를 클릭하거나 <kbd>⌘</kbd>/<kbd>Ctrl</kbd> + <kbd>S</kbd>를 누르기 전까지는 방문자에게 아무것도 바뀌지 않습니다. 헤더에는 새 페이지일 때 "Not published yet", 게시된 페이지를 수정한 후에는 "Unpublished changes"라고 표시됩니다.

게시하지 않은 수정 내용은 브라우저에 저장되므로 탭을 닫았다가 다시 돌아와도 됩니다. 다시 돌아오면 해당 날짜의 게시되지 않은 변경 사항이 있다는 배너가 표시되고, **Restore**와 **Discard** 버튼이 나타나요.

## QR 코드 받기 [#get-the-qr-code]

페이지 편집기 헤더에서 **QR code**를 클릭하면 페이지의 코드를 열고 다운로드할 수 있습니다. **View live**를 클릭하면 게시된 페이지가 열려요.

페이지에 코드가 없다면 **Pages & forms**에서 해당 페이지의 메뉴(**⋯**)를 열고 **Create a QR code**를 선택하세요.

## 문제가 생겼을 때 [#if-something-goes-wrong]

### 방문자에게 이전 페이지가 계속 보여요 [#visitors-still-see-the-old-page]

변경 사항을 게시하지 않은 경우입니다. 페이지를 열고 **Publish**를 클릭하세요.

### 수정한 내용이 사라졌어요 [#your-edits-disappeared]

수정 내용은 편집한 브라우저에 저장됩니다. 해당 브라우저에서 페이지를 열고 배너의 **Restore**를 클릭하세요. 다른 브라우저나 기기에서 수정한 내용은 여기에 없습니다.

### 페이지를 더 만들 수 없어요 [#you-cant-create-another-page]

무료 플랜을 사용 중이고 이미 페이지가 3개 있는 경우입니다. **Pages & forms**에서 사용하지 않는 페이지를 삭제하거나 [업그레이드](/pricing)하세요.
