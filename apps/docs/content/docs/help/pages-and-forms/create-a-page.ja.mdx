QRdxは、QRコード用のモバイルページをホストします。リンク集、メニュー、連絡先カード、クーポン、そのほか{facts.hostedPageTypes}種類のページを作成できます。ブロックを組み合わせてページを作り、コードを再印刷しなくても、いつでも編集できます。

<Callout type="info">
  フリーでは3ページまで作成でき、小さな「Made with QRdx」フッターが表示されます。Proではページ数が無制限で、フッターも表示されません。Businessではホワイトラベルページとカスタム CSS も使えます。詳しくは[プランと含まれる機能](/docs/help/account-and-billing/plans)をご覧ください。
</Callout>

## ページを作成する [#create-a-page]

### 1. 新しいページを始める [#1-start-a-new-page]

ダッシュボードで **Pages & forms** を開き、**New page** をクリックします。

### 2. タイプを選ぶ [#2-pick-a-type]

ページの用途を選びます。Link list、Business、vCard Plus、Menu、Coupon、Event、App download、Feedback & forms、PDF、Images、MP3 / Audio、Video、Social media、Product、Appointments、Payments & tips、Property listing、Pet ID tag、Medical ID、Playlist、Custom page から選べます。

<Shot id="page-templates" />

<Clip id="create-page" />

### 3. テンプレートを選ぶ [#3-pick-a-template]

出発点となるテンプレートを選びます。ブロック、色、テキストはあとからすべて変更できます。

### 4. 作成する [#4-create-it]

必要に応じてページに名前を付け、**Create page** をクリックします。エディターが開き、同時にQRdxがそのページ用の動的QRコードを作成します。

[Playground](/playground)から始めることもできます。**QR code type** カードの **Change** をクリックし、**Hosted pages** グループからタイプを選びます。

## 編集と公開 [#edit-and-publish]

ページエディターには3つのタブがあります。コンテンツを編集する **Blocks**、色や書体を設定する **Design**、名前やその他のオプションを設定する **Settings** です。

<Shot id="page-editor" />

**Publish** をクリックするか、<kbd>⌘</kbd>/<kbd>Ctrl</kbd> + <kbd>S</kbd> を押すまで、訪問者に表示される内容は変わりません。ヘッダーには、新しいページでは「Not published yet」、公開済みのページを編集したあとは「Unpublished changes」と表示されます。

未公開の編集内容はブラウザーに保存されるため、タブを閉じても戻ってこられます。戻ると、その日付の未公開の変更があることを知らせるバナーが表示され、**Restore** と **Discard** を選べます。

## QRコードを取得する [#get-the-qr-code]

ページエディターのヘッダーにある **QR code** をクリックすると、そのページのコードを表示してダウンロードできます。**View live** をクリックすると、公開済みのページが開きます。

ページにコードがない場合は、**Pages & forms** でそのページのメニュー（**⋯**）を開き、**Create a QR code** を選びます。

## うまくいかないとき [#if-something-goes-wrong]

### 訪問者に古いページが表示される [#visitors-still-see-the-old-page]

変更を公開していません。ページを開いて **Publish** をクリックしてください。

### 編集内容が消えた [#your-edits-disappeared]

編集内容は、編集したブラウザーに保存されています。そのブラウザーでページを開き、バナーの **Restore** をクリックしてください。別のブラウザーやデバイスで行った編集は、ここには保存されていません。

### これ以上ページを作成できない [#you-cant-create-another-page]

フリーのプランで、すでに3ページある状態です。**Pages & forms** で使っていないページを削除するか、[アップグレード](/pricing)してください。
