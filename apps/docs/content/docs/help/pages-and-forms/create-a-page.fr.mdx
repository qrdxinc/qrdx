QRdx héberge une page mobile pour votre QR code : une liste de liens, un menu, une carte de contact, un coupon ou l'un des {facts.hostedPageTypes} autres types. Vous la construisez avec des blocs et vous pouvez la modifier à tout moment sans réimprimer le code.

<Callout type="info">
  Gratuit inclut 3 pages, avec un petit pied de page « Made with QRdx ». Pro offre des pages illimitées et aucun pied de page. Business ajoute les pages en marque blanche et le CSS personnalisé. Voir [Les offres et ce qu'elles incluent](/docs/help/account-and-billing/plans).
</Callout>

## Créer une page [#create-a-page]

### 1. Démarrer une nouvelle page [#1-start-a-new-page]

Dans votre tableau de bord, allez dans **Pages & forms** et cliquez sur **New page**.

### 2. Choisir un type [#2-pick-a-type]

Choisissez à quoi sert la page : Link list, Business, vCard Plus, Menu, Coupon, Event, App download, Feedback & forms, PDF, Images, MP3 / Audio, Video, Social media, Product, Appointments, Payments & tips, Property listing, Pet ID tag, Medical ID, Playlist ou Custom page.

### 3. Choisir un modèle [#3-pick-a-template]

Choisissez un point de départ. Vous pourrez modifier ensuite chaque bloc, couleur et texte.

### 4. La créer [#4-create-it]

Donnez un nom à la page si vous le souhaitez, puis cliquez sur **Create page**. L'éditeur s'ouvre, et QRdx crée en même temps un QR code dynamique pour la page.

Vous pouvez aussi partir du [Playground](/playground) : cliquez sur **Change** sur la carte **QR code type** et choisissez un type dans le groupe **Hosted pages**.

## Modifier et publier [#edit-and-publish]

L'éditeur de page comporte trois onglets : **Blocks** pour le contenu, **Design** pour les couleurs et la typographie, et **Settings** pour le nom et les autres options.

<Shot id="page-editor" />

Rien ne change pour les visiteurs tant que vous n'avez pas cliqué sur **Publish** ou appuyé sur <kbd>⌘</kbd>/<kbd>Ctrl</kbd> + <kbd>S</kbd>. L'en-tête affiche « Not published yet » pour une nouvelle page et « Unpublished changes » dès que vous modifiez une page publiée.

Les modifications non publiées sont conservées dans votre navigateur : vous pouvez fermer l'onglet et revenir plus tard. À votre retour, une bannière indique que vous avez des modifications non publiées datant de ce moment, avec les boutons **Restore** et **Discard**.

## Obtenir le QR code [#get-the-qr-code]

Cliquez sur **QR code** dans l'en-tête de l'éditeur de page pour ouvrir le code de la page et le télécharger. **View live** ouvre la page publiée.

Si une page n'a pas de code, ouvrez son menu (**⋯**) dans **Pages & forms** et choisissez **Create a QR code**.

## En cas de problème [#if-something-goes-wrong]

### Les visiteurs voient toujours l'ancienne page [#visitors-still-see-the-old-page]

Vous n'avez pas publié la modification. Ouvrez la page et cliquez sur **Publish**.

### Vos modifications ont disparu [#your-edits-disappeared]

Elles sont conservées dans le navigateur où vous les avez faites. Ouvrez la page dans ce navigateur et cliquez sur **Restore** dans la bannière. Les modifications faites dans un autre navigateur ou sur un autre appareil n'y figurent pas.

### Vous ne pouvez pas créer une autre page [#you-cant-create-another-page]

Vous êtes sur l'offre Gratuit et vous avez déjà 3 pages. Supprimez une page inutilisée depuis **Pages & forms**, ou [passez à une offre supérieure](/pricing).
