Ogni QR code che crei con QRdx è di uno di due tipi. Un QR code statico memorizza il contenuto nel codice stesso. Un QR code dinamico memorizza un link breve che inoltra ogni scansione alla tua destinazione, cioè la pagina che il codice deve aprire. Scegli prima di stampare, perché un QR code statico già stampato non può diventare dinamico.

<Diagram id="static-vs-dynamic" />

## QR code statici [#static-qr-codes]

Un QR code statico contiene direttamente il link, la password del Wi-Fi o il biglietto da visita.

- Funziona per sempre, senza account e senza server.
- È gratuito e illimitato.
- Non si può modificare dopo la stampa. Per cambiare il contenuto devi stampare un nuovo codice.
- Le scansioni non vengono conteggiate.

Ogni codice che scarichi dal [Playground](/playground) senza selezionare **Dinamico** è statico.

## QR code dinamici [#dynamic-qr-codes]

Un QR code dinamico contiene un link breve, come `qrdx.dev/q/aB3xY7k`. Quando qualcuno lo scansiona, QRdx lo inoltra alla tua destinazione.

- Puoi cambiare la destinazione in qualsiasi momento, anche dopo la stampa.
- Ogni scansione viene conteggiata, con data e ora, luogo e dispositivo.
- Puoi metterlo in pausa, impostare date di inizio e fine, aggiungere una password o indirizzare le scansioni a link diversi.
- Serve un account QRdx gratuito. Il piano Gratuito include 10 QR code dinamici; Pro e Business non hanno limiti.

Consulta [Creare un QR code dinamico](/docs/help/dynamic-codes/create).

## Come scegliere [#which-to-choose]

| Scegli il dinamico quando | Scegli lo statico quando |
| --- | --- |
| Il codice finisce su qualcosa che non puoi sostituire senza ristampare, come confezioni, insegne o menu. | Il contenuto non cambia mai, come i dati del Wi-Fi o un biglietto da visita. |
| Il link potrebbe cambiare, come un'offerta stagionale o un menu. | Non vuoi creare un account. |
| Vuoi sapere quante persone lo scansionano. | Non vuoi nulla tra la scansione e il tuo contenuto. |

## Anche le pagine sono dinamiche [#pages-are-dynamic-too]

Una [pagina mobile](/docs/help/pages-and-forms/create-a-page) ospitata da QRdx ha sempre un QR code dinamico. Puoi modificare la pagina quando vuoi e il codice stampato continua a funzionare.

## I QR code dinamici continuano a funzionare [#dynamic-codes-keep-working]

Un QR code dinamico continua a inoltrare le scansioni se passi a un piano inferiore, annulli l'abbonamento o un pagamento non va a buon fine. Consulta [Cosa succede ai tuoi codici se smetti di pagare](/docs/help/account-and-billing/never-hostage).
