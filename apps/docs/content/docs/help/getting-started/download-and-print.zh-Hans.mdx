[Playground](/playground) 中的 **下载** 按钮可为你提供两种文件：适用于屏幕和文档的图片，或交给印刷厂的可印刷文件。本页帮助你选择格式和尺寸，并在批量印刷前检查效果。

## 下载图片文件 [#download-an-image-file]

适用于屏幕、电子邮件、幻灯片和大多数日常打印。

### 1. 打开下载对话框 [#1-open-the-download-dialog]

点击预览上方的 **下载**，或按 <kbd>D</kbd>。**下载二维码** 对话框会打开，其中有两个标签页：**图片文件** 和 **可印刷**。

<Shot id="playground-download" />

### 2. 选择格式 [#2-choose-a-format]

选择 **PNG**、**JPG**、**WebP**、**SVG**、**PDF** 或 **EPS**。使用哪种格式，请参考下面的表格。

### 3. 选择尺寸 [#3-choose-a-size]

选择 **邮件**（200 px）、**网页**（400 px）、**社交**（800 px）、**打印**（1200 px）或 **海报**（2000 px），也可以选择 **自定义**，输入 50 到 5000 px 之间的任意宽度。

### 4. 设置背景 [#4-set-the-background]

如果二维码放在彩色页面或图片上，请开启 **透明背景**。JPG 不支持透明，因此选择该格式时此开关为关闭状态。

### 5. 下载 [#5-download]

点击底部的下载按钮。文件会保存到你的下载文件夹，任何格式都包含边框。

## 下载可印刷文件 [#download-a-print-ready-file]

当印刷厂向你索取文件，或需要按精确尺寸打印时使用。

### 1. 打开可印刷标签页 [#1-open-the-print-ready-tab]

在 **下载二维码** 对话框中，点击 **可印刷**。

<Shot id="playground-download-print" />

### 2. 设置尺寸 [#2-set-the-size]

在 **扫描距离约为** 下，选择人们扫描二维码时与它的距离。然后以毫米或英寸为单位设置 **二维码宽度**。对话框会根据该距离给出建议的最小宽度。

### 3. 选择颜色模式 [#3-choose-the-color-mode]

在 **颜色模式** 下选择 **RGB** 或 **CMYK**。印刷厂通常要求使用 CMYK。

### 4. 添加出血和裁切标记 [#4-add-bleed-and-crop-marks]

如果背景延伸到页面边缘，请将 **出血** 设为 **3 mm**，这样裁切后不会留下白边。开启 **裁切标记（PDF）** 可显示裁切位置。裁切标记仅会添加到 PDF 中。

### 5. 下载 [#5-download-1]

点击 PDF 下载按钮，或选择 **SVG** 或 **EPS** 获取不含页面设置的矢量文件。

## 如何选择格式 [#which-format-to-choose]

| 格式 | 适用场景 |
| --- | --- |
| PNG、WebP | 屏幕、电子邮件、文档和网页。WebP 与 PNG 像素相同，但文件更小。 |
| JPG | 照片，以及只接受 JPG 的应用。不支持透明背景。 |
| SVG、EPS | 印刷厂和设计工具。矢量文件在任何尺寸下都保持清晰。 |
| 来自 **可印刷** 的 PDF | 任何要打印的内容。它包含尺寸、颜色模式、出血和裁切标记。来自 **图片文件** 标签页的 PDF 则只包含二维码的一张图片。 |

## 打印多大 [#how-big-to-print]

二维码可以在大约为其宽度十倍的距离外被扫描。请让二维码的宽度约为扫描距离的十分之一：

- 在 20 cm 处读取的名片，需要约 2 cm 宽的二维码。
- 在 1 m 处读取的海报，需要约 10 cm 宽的二维码。

内容越多的二维码，方块越小，需要的空间也越大。[打印尺寸计算器](/tools/print-size)可以根据你的二维码和距离算出最小尺寸。

## 留出清晰的边距 [#leave-a-clear-border]

扫描器需要二维码周围的空白区域来定位它。**设计** 标签页中的 **内边距** 可以自动添加空白；**标准**（4 个模块）是稳妥的选择。不要让其他图案碰到二维码。

## 打印前先测试 [#test-before-you-print]

先打印一份，用两部不同的手机在人们实际扫描的距离上进行扫描。你也可以拍下打印出来的二维码，把照片放入[扫描检测器](/tools/scan-checker)。

## 出现问题时 [#if-something-goes-wrong]

### EPS 显示为灰色 [#eps-is-grayed-out]

EPS 不支持图片填充。请改为下载 SVG 或可印刷 PDF，或在 **设计** 标签页中将填充改为纯色或渐变。

### 透明背景显示为灰色 [#transparent-background-is-grayed-out]

你选择了 JPG。请改选 PNG、WebP 或 SVG。

### 打印出的二维码模糊 [#the-printed-code-looks-blurry]

像素图片被打印得超出了其尺寸所能承受的大小。请从 **可印刷** 标签页下载 SVG、EPS 或 PDF，它们在任何尺寸下都保持清晰。
