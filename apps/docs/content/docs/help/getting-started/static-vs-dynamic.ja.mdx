title: "静的と動的、どちらが必要ですか？"
description: "静的QRコードは内容をコード自体に保存し、変更できません。動的QRコードは短いリンクを保存し、印刷後に変更できます。"
---

QRdxで作成するQRコードは、2種類のいずれかです。静的QRコードは、内容をコード自体に保存します。動的QRコードは、短いリンクを保存し、スキャンのたびに遷移先（コードで開くページ）へ転送します。印刷済みの静的QRコードを動的QRコードに変えることはできないため、印刷前に選んでください。

## 静的QRコード [#static-qr-codes]

静的QRコードには、リンク、Wi-Fiのパスワード、連絡先カードそのものが保存されます。

- アカウントもサーバーも不要で、ずっと使えます。
- 無料で、作成数に制限はありません。
- 印刷後に変更することはできません。内容を変えるには、新しいコードを印刷します。
- スキャンは集計されません。

[Playground](/playground)で**動的**を選ばずにダウンロードしたコードは、すべて静的QRコードです。

## 動的QRコード [#dynamic-qr-codes]

動的QRコードには、`qrdx.dev/q/aB3xY7k`のような短いリンクが保存されます。誰かがスキャンすると、QRdxがその人を遷移先へ転送します。

- 印刷後でも、いつでも遷移先を変更できます。
- すべてのスキャンが集計され、日時、場所、使用デバイスがわかります。
- 一時停止、開始日と終了日の設定、パスワードの追加、スキャンの振り分けができます。
- 無料のQRdxアカウントが必要です。フリープランには動的QRコードが10個含まれ、ProとBusinessでは制限がありません。

[動的QRコードを作成する](/docs/help/dynamic-codes/create)をご覧ください。

## どちらを選ぶか [#which-to-choose]

| 動的QRコードを選ぶ場合 | 静的QRコードを選ぶ場合 |
| --- | --- |
| パッケージ、看板、メニューなど、再印刷しないと差し替えられないものにコードを載せる。 | Wi-Fiの情報や連絡先カードなど、内容が変わらない。 |
| 季節限定のオファーやメニューなど、リンクが変わる可能性がある。 | アカウントを作りたくない。 |
| スキャンした人数を知りたい。 | スキャンから内容までの間に何も介在させたくない。 |

## ページも動的です [#pages-are-dynamic-too]

QRdxがホストする[モバイルページ](/docs/help/pages-and-forms/create-a-page)には、必ず動的QRコードが割り当てられます。ページはいつでも編集でき、印刷したコードもそのまま使えます。

## 動的QRコードは使い続けられます [#dynamic-codes-keep-working]

ダウングレード、解約、支払いの失敗があっても、動的QRコードはスキャンの転送を続けます。[支払いを停止した場合のコードの扱い](/docs/help/account-and-billing/never-hostage)をご覧ください。
