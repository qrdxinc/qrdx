[Playground](/playground)の**ダウンロード**ボタンでは、画面や文書向けの画像、または印刷会社に渡す印刷用ファイルを入手できます。このページでは、形式とサイズの選び方と、多数のコピーを印刷する前の確認方法を説明します。

## 画像ファイルをダウンロードする [#download-an-image-file]

画面、メール、スライド、そして日常的なほとんどの印刷に使えます。

### 1. ダウンロードダイアログを開く [#1-open-the-download-dialog]

プレビューの上にある**ダウンロード**をクリックするか、<kbd>D</kbd>を押します。**QRコードをダウンロード**ダイアログが開き、**画像ファイル**と**印刷用**の2つのタブが表示されます。

<Shot id="playground-download" />

### 2. 形式を選ぶ [#2-choose-a-format]

**PNG**、**JPG**、**WebP**、**SVG**、**PDF**、**EPS**から選びます。どれを使うかは下の表を参考にしてください。

### 3. サイズを選ぶ [#3-choose-a-size]

**メール**（200 px）、**Web**（400 px）、**SNS**（800 px）、**印刷**（1200 px）、**ポスター**（2000 px）から選びます。**カスタム**では50〜5000 pxの任意の幅を指定できます。

### 4. 背景を設定する [#4-set-the-background]

コードを色付きのページや写真の上に置く場合は、**透過背景**をオンにします。JPGは透過できないため、この形式ではスイッチがオフになります。

### 5. ダウンロードする [#5-download]

下部にあるダウンロードボタンをクリックします。ファイルはダウンロードフォルダに保存され、どの形式でもフレームが含まれます。

## 印刷用ファイルをダウンロードする [#download-a-print-ready-file]

印刷会社からファイルを求められた場合や、正確なサイズで印刷する場合に使います。

### 1. 印刷用タブを開く [#1-open-the-print-ready-tab]

**QRコードをダウンロード**ダイアログで**印刷用**をクリックします。

<Shot id="playground-download-print" />

### 2. サイズを設定する [#2-set-the-size]

**スキャンする距離の目安**で、コードをどのくらい離れた位置からスキャンするかを選びます。次に、**コードの幅**をmmまたはインチで設定します。ダイアログには、その距離に対する最小幅が提案されます。

### 3. カラーモードを選ぶ [#3-choose-the-color-mode]

**カラーモード**で**RGB**または**CMYK**を選びます。印刷会社ではCMYKが求められるのが一般的です。

### 4. 塗り足しとトンボを追加する [#4-add-bleed-and-crop-marks]

背景がページの端まで届く場合は、**塗り足し**を**3 mm**に設定すると、断裁しても白い線が残りません。**トンボ（PDF）**をオンにすると、裁断位置が表示されます。トンボが追加されるのはPDFのみです。

### 5. ダウンロードする [#5-download-1]

PDFのダウンロードボタンをクリックします。ページ設定のないベクターファイルが必要な場合は、**SVG**または**EPS**をクリックします。

## 形式の選び方 [#which-format-to-choose]

| 形式 | 用途 |
| --- | --- |
| PNG、WebP | 画面、メール、文書、Webページ。WebPはPNGと同じピクセルを、より小さいファイルで保持します。 |
| JPG | 写真や、JPGしか受け付けないアプリ。透過背景は使えません。 |
| SVG、EPS | 印刷会社やデザインツール。ベクターファイルはどのサイズでも鮮明なままです。 |
| **印刷用**タブのPDF | 印刷するものすべて。サイズ、カラーモード、塗り足し、トンボが含まれます。**画像ファイル**タブのPDFには、コードの画像が入ります。 |

## 印刷サイズの目安 [#how-big-to-print]

QRコードは、幅のおよそ10倍の距離からスキャンできます。コードの幅は、スキャン距離の約10分の1にしてください。

- 20 cmの距離から読み取る名刺には、幅約2 cmのコードが必要です。
- 1 mの距離から読み取るポスターには、幅約10 cmのコードが必要です。

内容が多いコードほどセルが小さくなり、より広いスペースが必要です。[印刷サイズ計算ツール](/tools/print-size)で、お使いのコードと距離に応じた最小サイズを計算できます。

## 余白を確保する [#leave-a-clear-border]

スキャナーがコードを見つけるには、周囲に空白が必要です。**デザイン**タブの**余白**を使うと自動で追加されます。**標準**（4モジュール）が安心です。ほかの図柄がコードに触れないようにしてください。

## 印刷前にテストする [#test-before-you-print]

1部印刷し、実際にスキャンする距離から、2台の異なるスマートフォンでスキャンします。印刷したコードを撮影し、その写真を[スキャンチェッカー](/tools/scan-checker)に入れて確認することもできます。

## うまくいかない場合 [#if-something-goes-wrong]

### EPSがグレーアウトしている [#eps-is-grayed-out]

EPSは画像による塗りつぶしを保持できません。代わりにSVGまたは印刷用PDFをダウンロードするか、**デザイン**タブで塗りつぶしを単色またはグラデーションに変更してください。

### 透過背景がグレーアウトしている [#transparent-background-is-grayed-out]

JPGを選択しています。代わりにPNG、WebP、SVGを選んでください。

### 印刷したコードがぼやける [#the-printed-code-looks-blurry]

ピクセル画像が、本来対応できるサイズより大きく印刷されています。**印刷用**タブからSVG、EPS、PDFをダウンロードしてください。これらはどのサイズでも鮮明なままです。
