Tombol **Download** di [Playground](/playground) memberi Anda gambar untuk layar dan dokumen, atau file siap cetak untuk percetakan. Halaman ini membantu Anda memilih format dan ukuran, serta memeriksa hasilnya sebelum mencetak banyak salinan.

## Unduh file gambar [#download-an-image-file]

Gunakan ini untuk layar, email, slide, dan sebagian besar pencetakan sehari-hari.

### 1. Buka dialog unduhan [#1-open-the-download-dialog]

Klik **Download** di atas pratinjau, atau tekan <kbd>D</kbd>. Dialog **Download QR code** terbuka dengan dua tab, **Image file** dan **Print-ready**.

<Shot id="playground-download" />

### 2. Pilih format [#2-choose-a-format]

Pilih **PNG**, **JPG**, **WebP**, **SVG**, **PDF**, atau **EPS**. Tabel di bawah menjelaskan format mana yang sebaiknya digunakan.

### 3. Pilih ukuran [#3-choose-a-size]

Pilih **Email** (200 px), **Web** (400 px), **Social** (800 px), **Print** (1200 px), atau **Poster** (2000 px), atau **Custom** untuk lebar apa pun dari 50 hingga 5000 px.

### 4. Atur latar belakang [#4-set-the-background]

Aktifkan **Transparent background** jika kode diletakkan di halaman atau gambar berwarna. JPG tidak bisa transparan, sehingga sakelar ini nonaktif untuk format tersebut.

### 5. Unduh [#5-download]

Klik tombol unduh di bagian bawah. File disimpan ke folder unduhan Anda dengan bingkai disertakan, di semua format.

## Unduh file siap cetak [#download-a-print-ready-file]

Gunakan ini saat percetakan meminta file, atau saat Anda mencetak dengan ukuran yang tepat.

### 1. Buka tab Print-ready [#1-open-the-print-ready-tab]

Di dialog **Download QR code**, klik **Print-ready**.

<Shot id="playground-download-print" />

### 2. Atur ukuran [#2-set-the-size]

Di bawah **Scanned from about**, pilih seberapa jauh orang akan memindai kode. Lalu atur **Code width** dalam mm atau inci. Dialog menyarankan lebar minimum untuk jarak tersebut.

### 3. Pilih mode warna [#3-choose-the-color-mode]

Pilih **RGB** atau **CMYK** di bawah **Color mode**. Percetakan biasanya meminta CMYK.

### 4. Tambahkan bleed dan tanda potong [#4-add-bleed-and-crop-marks]

Atur **Bleed** ke **3 mm** jika latar belakang memanjang hingga tepi halaman, sehingga pemotongan tidak meninggalkan garis putih. Aktifkan **Crop marks (PDF)** untuk menunjukkan tempat memotong. Tanda potong hanya ditambahkan ke PDF.

### 5. Unduh [#5-download-1]

Klik tombol unduh PDF, atau **SVG** atau **EPS** untuk file vektor tanpa pengaturan halaman.

## Format mana yang dipilih [#which-format-to-choose]

| Format | Gunakan untuk |
| --- | --- |
| PNG, WebP | Layar, email, dokumen, dan halaman web. WebP menyimpan piksel yang sama dengan PNG dalam file yang lebih kecil. |
| JPG | Foto dan aplikasi yang hanya menerima JPG. Tidak mendukung latar belakang transparan. |
| SVG, EPS | Percetakan dan alat desain. File vektor tetap tajam di ukuran berapa pun. |
| PDF dari **Print-ready** | Apa pun yang Anda cetak. File ini membawa ukuran, mode warna, bleed, dan tanda potong. PDF dari tab **Image file** berisi gambar kode saja. |

## Seberapa besar mencetaknya [#how-big-to-print]

Kode QR dapat dipindai dari jarak sekitar sepuluh kali lebarnya. Buat kode selebar sekitar sepersepuluh jarak pemindaian:

- Kartu nama yang dibaca dari jarak 20 cm membutuhkan kode selebar sekitar 2 cm.
- Poster yang dibaca dari jarak 1 m membutuhkan kode selebar sekitar 10 cm.

Kode dengan isi lebih banyak memiliki kotak yang lebih kecil dan membutuhkan ruang lebih besar. [Kalkulator ukuran cetak](/tools/print-size) menghitung ukuran minimum untuk kode dan jarak Anda.

## Sisakan batas yang kosong [#leave-a-clear-border]

Pemindai membutuhkan ruang kosong di sekeliling kode untuk menemukannya. **Padding** di tab **Design** menambahkannya untuk Anda; **Standard** (4 modul) adalah pilihan yang aman. Jangan biarkan karya seni lain menyentuh kode.

## Uji sebelum mencetak [#test-before-you-print]

Cetak satu salinan dan pindai dengan dua ponsel berbeda, dari jarak tempat orang akan memindainya. Anda juga dapat memotret kode yang sudah dicetak dan memasukkan fotonya ke [pemeriksa pemindaian](/tools/scan-checker).

## Jika terjadi masalah [#if-something-goes-wrong]

### EPS berwarna abu-abu [#eps-is-grayed-out]

EPS tidak dapat memuat isian gambar. Unduh SVG atau PDF siap cetak sebagai gantinya, atau ubah isian menjadi warna solid atau gradien di tab **Design**.

### Transparent background berwarna abu-abu [#transparent-background-is-grayed-out]

Anda memilih JPG. Pilih PNG, WebP, atau SVG sebagai gantinya.

### Kode yang dicetak tampak buram [#the-printed-code-looks-blurry]

Gambar piksel dicetak lebih besar daripada ukuran yang diizinkannya. Unduh SVG, EPS, atau PDF dari tab **Print-ready**, yang tetap tajam di ukuran berapa pun.
