title: "Crie seu primeiro QR code"
description: "Crie um QR code no Playground e baixe. Grátis, sem conta e sem marca d'água."
---

O [Playground](/playground) é o editor do QRdx. Nele você cria um QR code em cerca de um minuto, sem precisar de conta. O código que você baixa é estático: o link fica guardado dentro do código, funciona para sempre e não pode ser alterado depois de impresso.

## Crie o código [#make-the-code]

### 1. Escolha o que o código abre [#1-pick-what-the-code-opens]

Abra o [Playground](/playground). A aba **Conteúdo** já está aberta e **URL** é o tipo selecionado, o certo para qualquer endereço da web.

Para Wi-Fi, cartão de contato, WhatsApp ou qualquer outra coisa, clique em **Alterar** no card **Tipo de QR code** e escolha um tipo.

<Shot id="playground-type-picker" />

### 2. Digite seu link [#2-type-your-link]

Cole ou digite o endereço em **Endereço do site**. Quando o endereço for um link válido, a prévia deixa de mostrar o exemplo desfocado e passa a mostrar o seu código. A linha abaixo do campo diz onde as leituras abrem, por exemplo "As leituras abrem example.com". Confira antes de imprimir.

<Shot id="playground-content" />

### 3. Escolha um visual [#3-pick-a-look]

Este passo é opcional. Em **Comece com um estilo**, escolha um dos estilos prontos. Para personalizar mais, abra a aba **Design**, que reúne cores, pontos, olhos, logo e moldura.

### 4. Baixe [#4-download]

Clique em **Baixar** acima da prévia ou pressione <kbd>D</kbd>. Escolha um formato e um tamanho e clique no botão de download na parte de baixo da janela. O arquivo vai para a sua pasta de downloads.

<Clip id="first-code" />

## Confira se o código é lido [#check-that-it-scans]

Veja a **Pontuação de leitura** abaixo da prévia. Com 85 ou mais, a nota é Ótima e o código está pronto para imprimir. Abaixo de 65, clique na pontuação e corrija as verificações marcadas com um X. Veja [Verifique um design com a pontuação de leitura](/docs/help/designing/scan-score).

Depois, leia o código com o seu próprio celular.

## Se você puder mudar o link depois [#if-you-might-change-the-link-later]

Um código do Playground guarda o próprio link, então uma cópia impressa não pode ser alterada. Se o link puder mudar, ou se você quiser contar as leituras, escolha **Dinâmico** no seletor **QR code estático ou dinâmico** abaixo do endereço antes de baixar. É preciso ter uma conta grátis. Veja [Crie um QR code dinâmico](/docs/help/dynamic-codes/create) e [Estático ou dinâmico: qual você precisa?](/docs/help/getting-started/static-vs-dynamic).

## Se algo der errado [#if-something-goes-wrong]

### A prévia ainda mostra o exemplo desfocado [#the-preview-still-shows-the-blurred-sample]

O endereço ainda não é um link válido. Veja se falta um ponto ou se há um espaço sobrando, e digite o endereço completo.

### O botão Baixar está desativado [#the-download-button-is-grayed-out]

Ele fica desativado até o código ter conteúdo. Digite o endereço primeiro.

### Seu celular não lê o código [#your-phone-doesnt-read-the-code]

Confira a pontuação de leitura e depois veja [Um código não é lido](/docs/help/troubleshooting/wont-scan).
