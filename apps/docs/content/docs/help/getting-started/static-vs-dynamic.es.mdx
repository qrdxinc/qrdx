---
title: "Estático o dinámico, ¿cuál necesitas?"
description: "Los códigos estáticos guardan tu contenido dentro del código y nunca cambian. Los códigos dinámicos guardan un enlace corto que puedes cambiar después de imprimir."
---

Todos los códigos QR que creas con QRdx son de uno de dos tipos. Un código estático guarda tu contenido dentro del propio código. Un código dinámico guarda un enlace corto que redirige cada escaneo a tu destino, la página que el código debe abrir. Elige antes de imprimir, porque un código estático impreso no puede pasar a ser dinámico.

<Diagram id="static-vs-dynamic" />

## Códigos QR estáticos [#static-qr-codes]

Un código estático contiene directamente el enlace, la contraseña del Wi-Fi o la tarjeta de contacto.

- Funciona para siempre, sin cuenta y sin servidor.
- Es gratis e ilimitado.
- No se puede cambiar después de imprimirlo. Para cambiar el contenido, tienes que imprimir un código nuevo.
- Los escaneos no se cuentan.

Todo código que descargas desde el [Playground](/playground) sin elegir **Dinámico** es estático.

## Códigos QR dinámicos [#dynamic-qr-codes]

Un código dinámico contiene un enlace corto, como `qrdx.dev/q/aB3xY7k`. Cuando alguien lo escanea, QRdx lo redirige a tu destino.

- Puedes cambiar el destino en cualquier momento, incluso después de imprimir.
- Cada escaneo se cuenta, con cuándo, dónde y en qué dispositivo.
- Puedes pausarlo, asignarle fechas de inicio y fin, añadir una contraseña o enviar los escaneos a enlaces distintos.
- Necesita una cuenta gratuita de QRdx. El plan Gratis incluye 10 códigos dinámicos; Pro y Business no tienen límite.

Consulta [Crear un código QR dinámico](/docs/help/dynamic-codes/create).

## Cuál elegir [#which-to-choose]

| Elige dinámico cuando | Elige estático cuando |
| --- | --- |
| El código va en algo que no puedes reemplazar sin volver a imprimir, como envases, carteles o menús. | El contenido nunca cambia, como los datos del Wi-Fi o una tarjeta de contacto. |
| El enlace puede cambiar, como una oferta de temporada o un menú. | No quieres una cuenta. |
| Quieres saber cuántas personas lo escanean. | No quieres nada entre el escaneo y tu contenido. |

## Las páginas también son dinámicas [#pages-are-dynamic-too]

Una [página móvil](/docs/help/pages-and-forms/create-a-page) alojada por QRdx siempre recibe un código dinámico. Puedes editar la página en cualquier momento y el código impreso seguirá funcionando.

## Los códigos dinámicos siguen funcionando [#dynamic-codes-keep-working]

Un código dinámico sigue redirigiendo los escaneos si cambias a un plan inferior, cancelas o falla un pago. Consulta [Qué pasa con tus códigos si dejas de pagar](/docs/help/account-and-billing/never-hostage).
