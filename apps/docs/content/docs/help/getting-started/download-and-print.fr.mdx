Le bouton **Télécharger** du [Playground](/playground) vous donne soit une image pour les écrans et les documents, soit un fichier prêt à imprimer pour un imprimeur. Cette page vous aide à choisir le format et la taille, et à vérifier le résultat avant d'imprimer de nombreux exemplaires.

## Télécharger un fichier image [#download-an-image-file]

À utiliser pour les écrans, les e-mails, les présentations et la plupart des impressions courantes.

### 1. Ouvrir la boîte de dialogue de téléchargement [#1-open-the-download-dialog]

Cliquez sur **Télécharger** au-dessus de l'aperçu, ou appuyez sur <kbd>D</kbd>. La boîte de dialogue **Télécharger le QR code** s'ouvre avec deux onglets, **Fichier image** et **Prêt à imprimer**.

<Shot id="playground-download" />

### 2. Choisir un format [#2-choose-a-format]

Choisissez **PNG**, **JPG**, **WebP**, **SVG**, **PDF** ou **EPS**. Le tableau ci-dessous indique lequel utiliser.

### 3. Choisir une taille [#3-choose-a-size]

Choisissez **E-mail** (200 px), **Web** (400 px), **Réseaux sociaux** (800 px), **Impression** (1200 px) ou **Affiche** (2000 px), ou **Personnalisée** pour toute largeur de 50 à 5000 px.

### 4. Définir l'arrière-plan [#4-set-the-background]

Activez **Arrière-plan transparent** si le code se trouve sur une page ou une image colorée. Le JPG ne peut pas être transparent : l'option est donc désactivée pour ce format.

### 5. Télécharger [#5-download]

Cliquez sur le bouton de téléchargement en bas. Le fichier est enregistré dans votre dossier de téléchargements, avec le cadre inclus, quel que soit le format.

## Télécharger un fichier prêt à imprimer [#download-a-print-ready-file]

À utiliser lorsqu'un imprimeur vous demande un fichier, ou lorsque vous imprimez à une taille précise.

### 1. Ouvrir l'onglet Prêt à imprimer [#1-open-the-print-ready-tab]

Dans la boîte de dialogue **Télécharger le QR code**, cliquez sur **Prêt à imprimer**.

<Shot id="playground-download-print" />

### 2. Définir la taille [#2-set-the-size]

Sous **Scanné d'environ**, choisissez la distance à laquelle les gens scanneront le code. Définissez ensuite la **Largeur du code** en mm ou en pouces. La boîte de dialogue suggère une largeur minimale pour cette distance.

### 3. Choisir le mode colorimétrique [#3-choose-the-color-mode]

Choisissez **RVB** ou **CMJN** sous **Mode colorimétrique**. Les imprimeurs demandent généralement du CMJN.

### 4. Ajouter un fond perdu et des traits de coupe [#4-add-bleed-and-crop-marks]

Réglez **Fond perdu** sur **3 mm** si l'arrière-plan va jusqu'au bord de la page, afin que le massicotage ne laisse jamais de ligne blanche. Activez **Traits de coupe (PDF)** pour indiquer où couper. Les traits de coupe sont ajoutés uniquement au PDF.

### 5. Télécharger [#5-download-1]

Cliquez sur le bouton de téléchargement PDF, ou sur **SVG** ou **EPS** pour obtenir un fichier vectoriel sans mise en page.

## Quel format choisir [#which-format-to-choose]

| Format | Usage |
| --- | --- |
| PNG, WebP | Écrans, e-mails, documents et pages web. Le WebP contient les mêmes pixels que le PNG dans un fichier plus léger. |
| JPG | Photos et applications qui n'acceptent que le JPG. Pas d'arrière-plan transparent. |
| SVG, EPS | Imprimeurs et outils de design. Les fichiers vectoriels restent nets à toutes les tailles. |
| PDF depuis **Prêt à imprimer** | Tout ce que vous imprimez. Il contient la taille, le mode colorimétrique, le fond perdu et les traits de coupe. Un PDF issu de l'onglet **Fichier image** contient à la place une image du code. |

## Quelle taille imprimer [#how-big-to-print]

Un QR code se scanne à environ dix fois sa largeur. Donnez au code environ un dixième de la distance de scan :

- Une carte de visite lue à 20 cm nécessite un code d'environ 2 cm de large.
- Une affiche lue à 1 m nécessite un code d'environ 10 cm de large.

Les codes qui contiennent plus de contenu ont des carrés plus petits et ont besoin de plus de place. Le [calculateur de taille d'impression](/tools/print-size) détermine la taille minimale pour votre code et votre distance.

## Laisser une marge dégagée [#leave-a-clear-border]

Les lecteurs ont besoin d'espace vide autour du code pour le repérer. **Marge intérieure** dans l'onglet **Design** l'ajoute pour vous ; **Standard** (4 modules) est le choix le plus sûr. Ne laissez aucun autre visuel toucher le code.

## Tester avant d'imprimer [#test-before-you-print]

Imprimez un exemplaire et scannez-le avec deux téléphones différents, à la distance à laquelle les gens le scanneront. Vous pouvez aussi photographier le code imprimé et déposer la photo dans le [vérificateur de scan](/tools/scan-checker).

## En cas de problème [#if-something-goes-wrong]

### L'EPS est grisé [#eps-is-grayed-out]

L'EPS ne peut pas contenir un remplissage par image. Téléchargez plutôt un SVG ou un PDF prêt à imprimer, ou remplacez le remplissage par une couleur unie ou un dégradé dans l'onglet **Design**.

### L'arrière-plan transparent est grisé [#transparent-background-is-grayed-out]

Vous avez choisi le JPG. Choisissez plutôt PNG, WebP ou SVG.

### Le code imprimé semble flou [#the-printed-code-looks-blurry]

Une image en pixels a été imprimée plus grande que sa taille ne le permet. Téléchargez un SVG, un EPS ou un PDF depuis l'onglet **Prêt à imprimer** : ils restent nets à toutes les tailles.
