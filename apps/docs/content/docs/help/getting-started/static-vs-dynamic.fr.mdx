---
title: "QR code statique ou dynamique : lequel choisir ?"
description: "Les codes statiques stockent votre contenu dans le code et ne changent jamais. Les codes dynamiques stockent un lien court que vous pouvez modifier après l'impression."
---

Chaque QR code que vous créez avec QRdx est de l'un de ces deux types. Un code statique stocke votre contenu dans le code lui-même. Un code dynamique stocke un lien court qui redirige chaque scan vers votre destination, c'est-à-dire la page que le code doit ouvrir. Choisissez avant d'imprimer, car un code statique imprimé ne peut pas devenir dynamique.

<Diagram id="static-vs-dynamic" />

## QR codes statiques [#static-qr-codes]

Un code statique contient directement le lien, le mot de passe Wi-Fi ou la fiche de contact.

- Il fonctionne indéfiniment, sans compte ni serveur.
- Il est gratuit et illimité.
- Il ne peut pas être modifié après l'impression. Pour changer le contenu, vous imprimez un nouveau code.
- Les scans ne sont pas comptabilisés.

Tout code que vous téléchargez depuis le [Playground](/playground) sans avoir choisi **Dynamique** est statique.

## QR codes dynamiques [#dynamic-qr-codes]

Un code dynamique contient un lien court, par exemple `qrdx.dev/q/aB3xY7k`. Quand quelqu'un le scanne, QRdx le redirige vers votre destination.

- Vous pouvez modifier la destination à tout moment, même après l'impression.
- Chaque scan est comptabilisé, avec le moment, le lieu et l'appareil utilisé.
- Vous pouvez le mettre en pause, lui donner des dates de début et de fin, ajouter un mot de passe ou envoyer les scans vers différents liens.
- Il nécessite un compte QRdx gratuit. Le plan Gratuit inclut 10 codes dynamiques ; Pro et Business n'ont aucune limite.

Consultez [Créer un QR code dynamique](/docs/help/dynamic-codes/create).

## Comment choisir [#which-to-choose]

| Choisissez le dynamique quand | Choisissez le statique quand |
| --- | --- |
| Le code est placé sur un support que vous ne pouvez pas remplacer sans le réimprimer, comme un emballage, une enseigne ou un menu. | Le contenu ne change jamais, comme des identifiants Wi-Fi ou une fiche de contact. |
| Le lien pourrait changer, comme une offre saisonnière ou un menu. | Vous ne voulez pas de compte. |
| Vous voulez savoir combien de personnes le scannent. | Vous ne voulez aucun intermédiaire entre le scan et votre contenu. |

## Les pages sont aussi dynamiques [#pages-are-dynamic-too]

Une [page mobile](/docs/help/pages-and-forms/create-a-page) hébergée par QRdx reçoit toujours un code dynamique. Vous pouvez modifier la page à tout moment et le code imprimé continue de fonctionner.

## Les codes dynamiques continuent de fonctionner [#dynamic-codes-keep-working]

Un code dynamique continue de rediriger les scans si vous passez à un plan inférieur, si vous résiliez ou si un paiement échoue. Consultez [Ce qui arrive à vos codes si vous cessez de payer](/docs/help/account-and-billing/never-hostage).
