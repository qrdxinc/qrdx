---
title: "Estático ou dinâmico: qual você precisa?"
description: "Os QR codes estáticos guardam seu conteúdo no próprio código e nunca mudam. Os QR codes dinâmicos guardam um link curto que você pode alterar depois de imprimir."
---

Todo QR code que você cria com o QRdx é de um destes dois tipos. Um QR code estático guarda seu conteúdo dentro do próprio código. Um QR code dinâmico guarda um link curto que encaminha cada leitura para o seu destino, a página que o código deve abrir. Escolha antes de imprimir, porque um QR code estático impresso não pode virar dinâmico.

<Diagram id="static-vs-dynamic" />

## QR codes estáticos [#static-qr-codes]

Um QR code estático guarda o próprio link, a senha do Wi-Fi ou o cartão de contato.

- Funciona para sempre, sem conta e sem servidor.
- É grátis e ilimitado.
- Não pode ser alterado depois de impresso. Para mudar o conteúdo, você imprime um novo código.
- As leituras não são contadas.

Todo código que você baixa no [Playground](/playground) sem escolher **Dinâmico** é estático.

## QR codes dinâmicos [#dynamic-qr-codes]

Um QR code dinâmico guarda um link curto, como `qrdx.dev/q/aB3xY7k`. Quando alguém faz a leitura, o QRdx encaminha a pessoa para o seu destino.

- Você pode mudar o destino a qualquer momento, até depois de imprimir.
- Cada leitura é contada, com data e hora, local e dispositivo.
- Você pode pausar o código, definir datas de início e fim, adicionar uma senha ou enviar as leituras para links diferentes.
- Exige uma conta QRdx grátis. O plano Grátis inclui 10 QR codes dinâmicos; Pro e Business não têm limite.

Veja [Criar um QR code dinâmico](/docs/help/dynamic-codes/create).

## Qual escolher [#which-to-choose]

| Escolha dinâmico quando | Escolha estático quando |
| --- | --- |
| O código vai em algo que você não consegue substituir sem reimprimir, como embalagens, placas ou cardápios. | O conteúdo nunca muda, como os dados de um Wi-Fi ou um cartão de contato. |
| O link pode mudar, como uma oferta sazonal ou um cardápio. | Você não quer criar uma conta. |
| Você quer saber quantas pessoas fazem a leitura. | Você não quer nada entre a leitura e o seu conteúdo. |

## As páginas também são dinâmicas [#pages-are-dynamic-too]

Uma [página para celular](/docs/help/pages-and-forms/create-a-page) hospedada pelo QRdx sempre recebe um QR code dinâmico. Você pode editar a página a qualquer momento e o código impresso continua funcionando.

## Os QR codes dinâmicos continuam funcionando [#dynamic-codes-keep-working]

Um QR code dinâmico continua encaminhando as leituras se você fizer downgrade, cancelar ou se um pagamento falhar. Veja [O que acontece com seus códigos se você parar de pagar](/docs/help/account-and-billing/never-hostage).
