---
title: "Statisch oder dynamisch: Was brauchst du?"
description: "Statische Codes speichern deinen Inhalt im Code selbst und ändern sich nie. Dynamische Codes speichern einen Kurzlink, den du auch nach dem Druck ändern kannst."
---

Jeder QR-Code, den du mit QRdx erstellst, gehört zu einer von zwei Arten. Ein statischer QR-Code speichert deinen Inhalt direkt im Code. Ein dynamischer QR-Code speichert einen Kurzlink, der jeden Scan an dein Ziel weiterleitet, also an die Seite, die der Code öffnen soll. Entscheide dich vor dem Druck, denn ein gedruckter statischer Code kann nicht dynamisch werden.

## Statische QR-Codes [#static-qr-codes]

Ein statischer Code enthält den Link, das Wi-Fi-Passwort oder die Kontaktkarte selbst.

- Er funktioniert für immer, ohne Konto und ohne Server.
- Er ist kostenlos und unbegrenzt.
- Er lässt sich nach dem Druck nicht ändern. Willst du den Inhalt ändern, druckst du einen neuen Code.
- Scans werden nicht gezählt.

Jeder Code, den du aus dem [Playground](/playground) herunterlädst, ohne **Dynamisch** zu wählen, ist statisch.

## Dynamische QR-Codes [#dynamic-qr-codes]

Ein dynamischer Code enthält einen Kurzlink, zum Beispiel `qrdx.dev/q/aB3xY7k`. Wenn jemand ihn scannt, leitet QRdx die Person zu deinem Ziel weiter.

- Du kannst das Ziel jederzeit ändern, auch nach dem Druck.
- Jeder Scan wird gezählt, mit Zeitpunkt, Ort und Gerät.
- Du kannst ihn pausieren, mit Start- und Enddatum versehen, ein Passwort hinzufügen oder Scans an verschiedene Links senden.
- Du brauchst dafür ein kostenloses QRdx-Konto. Der Plan Kostenlos enthält 10 dynamische Codes; Pro und Business haben kein Limit.

Siehe [Einen dynamischen QR-Code erstellen](/docs/help/dynamic-codes/create).

## Was du wählen solltest [#which-to-choose]

| Wähle dynamisch, wenn … | Wähle statisch, wenn … |
| --- | --- |
| der Code auf etwas kommt, das du nur mit neuem Druck ersetzen kannst, etwa Verpackungen, Schilder oder Speisekarten. | sich der Inhalt nie ändert, etwa Wi-Fi-Daten oder eine Kontaktkarte. |
| sich der Link ändern könnte, etwa bei einem Saisonangebot oder einer Speisekarte. | du kein Konto möchtest. |
| du wissen willst, wie viele Leute ihn scannen. | du nichts zwischen dem Scan und deinem Inhalt haben willst. |

## Auch Seiten sind dynamisch [#pages-are-dynamic-too]

Eine [mobile Seite](/docs/help/pages-and-forms/create-a-page), die QRdx hostet, bekommt immer einen dynamischen QR-Code. Du kannst die Seite jederzeit bearbeiten, und der gedruckte Code funktioniert weiter.

## Dynamische Codes funktionieren weiter [#dynamic-codes-keep-working]

Ein dynamischer Code leitet Scans auch dann weiter, wenn du herabstufst, kündigst oder eine Zahlung fehlschlägt. Siehe [Was mit deinen Codes passiert, wenn du nicht mehr zahlst](/docs/help/account-and-billing/never-hostage).
