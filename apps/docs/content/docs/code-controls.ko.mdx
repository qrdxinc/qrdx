코드 제어는 [동적 QR 코드](/docs/dynamic-qr-codes)를 스캔했을 때 연결이 이루어질지 여부를 결정합니다. 코드를 일정 기간(이벤트, 프로모션)에만, 특정 사람(비밀번호)에게만, 또는 정해진 횟수만큼만 작동하게 하고 싶을 때, 그리고 인쇄된 코드를 다시 인쇄하지 않고 끄고 싶을 때 사용하세요.

<Callout type="info" title="일시 중지는 무료, 나머지는 Pro">
  일시 중지는 모든 요금제에서 사용할 수 있습니다. 비밀번호, 시작일과 종료일, 스캔 제한, 대체 URL은 Pro와 Business에 포함됩니다. [요금제와 한도](/docs/plans-and-limits)를 참고하세요.
</Callout>

바쁘신가요? 간단한 작업 안내 페이지가 있습니다: [코드 일시 중지, 예약, 제한하기](/docs/help/dynamic-codes/pause-schedule-limit)와 [비밀번호로 코드 보호하기](/docs/help/dynamic-codes/password).

## 작동 방식 [#how-it-works]

모든 제어는 코드의 **설정** 탭에 있는 **접근 및 일정** 패널에서 설정합니다. 코드는 [코드](/dashboard?to=codes)에서 열 수 있습니다. QRdx는 스캔할 때마다 리디렉션하기 전에 다음 순서로 제어를 확인합니다. 코드가 일시 중지되었는지, 시작되었는지, 종료되었는지, 스캔 제한을 넘었는지, 비밀번호가 필요한지 확인합니다. 처음으로 실패한 확인이 스캔한 사람에게 보여 줄 내용을 결정합니다. 변경 사항은 다음 스캔부터 적용되며, 코드를 다시 인쇄할 필요는 없습니다.

<Shot id="code-settings" />

| 제어 | 스캔한 사람에게 보이는 화면 | 요금제 |
| --- | --- | --- |
| 일시 중지 | 대체 URL 또는 중립적인 "이 캠페인은 일시 중지되었습니다" 페이지 | 모든 요금제 |
| 비밀번호 | 비밀번호 화면. 올바른 비밀번호를 입력하면 코드가 열립니다 | Pro와 Business |
| 시작 | 시작 전: "이 캠페인은 아직 시작되지 않았습니다" | Pro와 Business |
| 종료 | 종료 후: 대체 URL 또는 "이 캠페인은 종료되었습니다" | Pro와 Business |
| 스캔 제한 | 제한에 도달한 후: 대체 URL 또는 "종료" 페이지 | Pro와 Business |
| 대체 URL | 일시 중지, 종료, 제한 초과된 코드가 사람들을 보내는 곳 | Pro와 Business |

## 일시 중지 [#pause]

**코드 일시 중지**를 켜면 이벤트 사이처럼 한동안 코드를 멈출 수 있고, 끄면 다시 시작됩니다. 코드의 **⋯** 메뉴에도 **일시 중지**와 **재개**가 있으며, 코드 목록의 일괄 작업으로 여러 코드를 한 번에 일시 중지할 수도 있습니다. 코드가 일시 중지된 동안의 스캔은 대체 URL을 설정했다면 그곳으로 연결되고, 설정하지 않았다면 캠페인이 일시 중지되었다고 알리는 단순한 페이지로 연결됩니다.

## 비밀번호 [#password]

4자에서 64자 사이의 비밀번호를 설정하면 코드를 스캔하는 사람은 누구나 먼저 비밀번호 화면을 보게 됩니다. 올바른 비밀번호를 입력하면 해당 브라우저는 단축 링크와 그 링크가 여는 호스팅 페이지에서 6시간 동안 잠금이 해제된 상태로 유지됩니다. 비밀번호를 바꾸면 이전 비밀번호로 잠금을 해제한 모든 브라우저가 다시 잠기고, 비밀번호를 제거하면 코드가 다시 모두에게 열립니다.

<Shot id="scan-password" />

비밀번호는 bcrypt 해시로 저장되므로 QRdx는 나중에 비밀번호를 보여 드릴 수 없고 새로 교체만 할 수 있습니다. 한 방문자가 비밀번호를 반복해서 틀리면 시도 속도가 느려집니다. 비밀번호는 코드와 따로 공유하세요. 둘 다 가진 사람은 누구나 들어올 수 있습니다.

## 시작일과 종료일 [#start-and-end-dates]

- **시작:** 그때까지는 스캔하면 "이 캠페인은 아직 시작되지 않았습니다. 나중에 이 코드를 다시 스캔해 주세요."라고 표시됩니다. 시작 전에는 대체 URL이 사용되지 않습니다.
- **종료:** 그 시점부터 스캔하면 대체 URL로 연결되거나 "이 캠페인은 종료되었습니다"라고 표시됩니다.

날짜는 사용자의 시간대로 입력하고 정확한 시각으로 저장되므로, 코드는 어디에서나 같은 순간에 종료됩니다. 종료일은 시작일보다 뒤여야 합니다.

## 스캔 제한 [#scan-limit]

제한은 분석과 같은 방식으로 스캔을 집계합니다. 봇과 링크 미리보기는 집계되지 않고, 한 주소에서 1분 안에 반복된 스캔은 한 번으로 집계됩니다. 코드가 제한에 도달하면 이후 스캔은 대체 URL 또는 "종료" 페이지로 연결됩니다. 제한을 높이거나 지우면 코드가 다시 열립니다.

## 대체 URL [#fallback-url]

일시 중지, 종료, 제한 초과된 코드가 사람들을 보내는 주소입니다. 홈페이지나 다음 캠페인 같은 곳을 지정할 수 있습니다. 설정하지 않으면 스캔한 사람에게 작은 중립 페이지가 표시됩니다. 이 페이지에는 광고, QRdx 홍보, 가입 유도가 절대 표시되지 않으며, 캠페인 상태와 **악용 신고** 링크만 나타납니다. 대체 URL도 대상 주소와 같은 안전 검사를 거칩니다.

## 한도와 요금제 [#limits-and-plans]

- 일시 중지는 모든 요금제에서 사용할 수 있습니다.
- 비밀번호, 날짜, 스캔 제한, 대체 URL을 설정하거나 변경하려면 Pro 또는 Business가 필요합니다.
- 요금제를 낮춰도 코드가 종료되거나 잠기지는 않습니다. Pro에서 설정한 제어는 설정한 대로 계속 작동하며, 어떤 요금제에서든 제거할 수 있습니다.

## 링크 안전 검사 [#safety-checks-on-links]

QRdx는 대상 주소와 대체 URL을 저장할 때마다 검사합니다.

- [Google Web Risk](https://cloud.google.com/web-risk)가 악성코드, 피싱, 원치 않는 소프트웨어로 등록한 링크는 거부됩니다(서버에 Web Risk 키가 있는 경우). 대량 처리 중에 생길 수 있듯 Web Risk가 제때 응답하지 못하면 코드는 생성되고 잠시 후 링크를 다시 조회합니다. 그때 Web Risk가 해당 링크를 등록해 두었다면 코드는 꺼지고 검토자가 확인합니다.
- `javascript:`, `data:` 등 웹이 아닌 링크는 거부됩니다.
- 계정을 만든 후 처음 7일 동안 URL 단축 서비스, IP 주소 그대로인 주소, 비슷하게 보이는(동형 문자) 도메인을 가리키는 코드는 꺼진 상태로 저장되고 **검토 대기** 상태가 됩니다. 패널에 그렇게 표시되며 사용자가 따로 할 일은 없고, 문제가 없으면 검토자가 코드를 켭니다.
- 새 계정은 한 시간에 동적 코드를 최대 30개까지 만들 수 있으며, 유료 요금제의 워크스페이스에서는 {facts.newPaidAccountHourlyCodes}개까지 만들 수 있습니다. 이를 넘으면 오류 메시지에 몇 분을 기다려야 하는지 표시되고, 대시보드 가져오기는 그때까지 일시 중지됩니다.

누구나 [qrdx.dev/report-abuse](/report-abuse)에서 코드를 신고할 수 있습니다. 검토 후 꺼진 코드는 모두에게 작동하지 않으며 소유자가 다시 켤 수 없습니다. [유해한 QR 코드 신고하기](/docs/help/privacy-and-security/report-abuse)를 참고하세요.

## 개발자용 [#for-developers]

REST API로 코드를 만들고, 수정하고, 삭제할 수 있지만 제어는 설정할 수 없습니다. 제어는 대시보드에서 설정합니다. API 응답의 코드 `status`는 코드가 활성 상태인지 보관 상태인지 알려 줍니다. 제어에 의해 차단된 스캔은 스캔으로 기록되지 않으므로 `scan.created` [웹훅](/docs/webhooks) 이벤트로 전달되지 않습니다.

## 셀프 호스팅 [#self-hosting]

- `WEB_RISK_API_KEY`: Web Risk API를 사용 설정한 Google Cloud API 키입니다. 없으면 링크는 위의 오프라인 규칙으로만 검사됩니다.
- `SAFETY_YOUNG_ACCOUNT_DAYS`, `SAFETY_YOUNG_ACCOUNT_DYNAMIC_PER_HOUR`, `SAFETY_RECHECK_BATCH`는 7일, 시간당 30개 코드, Web Risk 재검사 크기를 변경합니다.
- `NEXT_PUBLIC_TURNSTILE_SITE_KEY`와 `TURNSTILE_SECRET_KEY`: 공개 신고 양식에 적용하는 Cloudflare Turnstile입니다(선택 사항).
- 잠금 해제 쿠키는 `BETTER_AUTH_SECRET`으로 서명됩니다.

[셀프 호스팅](/docs/self-hosting#optional-services)을 참고하세요.
