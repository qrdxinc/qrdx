Al terminar esta página tendrás un código QR con estilo en un componente de Vue 3, renderizado en el servidor e hidratado sin discrepancias, y un botón que lo guarda como PNG. `qrdx/vue` incluye versiones para Vue de los componentes de React, `QRCode` y `QRCodeSVG`, además de un composable `useQRCode`. Aceptan las mismas props que los componentes de React y dibujan el mismo SVG. La entrada se basa en `qrdx/core` y no importa `react`.

<NpmStatus package="qrdx" />

## Antes de empezar [#before-you-start]

- Un proyecto con Vue 3.3 o superior, con Vite o Nuxt. TypeScript comprueba las props de los componentes a partir de Vue 3.4.20.
- Node.js 18 o superior.

## Constrúyelo [#build-it]

### 1. Instala qrdx [#1-install-qrdx]

```package-install
qrdx
```

`vue` es una dependencia peer opcional, así que se usa el Vue de tu propia aplicación.

### 2. Dibuja un código [#2-draw-a-code]

```vue title="src/App.vue"
<script setup lang="ts">
import { QRCode } from "qrdx/vue";
import { ref } from "vue";

const url = ref("https://example.com/menu");
</script>

<template>
  <QRCode
    :value="url"
    :size="256"
    :margin="4"
    body-pattern="rounded"
    :frame="{ style: 'banner-bottom', text: 'Scan for the menu' }"
    aria-label="QR code for the menu"
  />
</template>
```

La página muestra un código de 256 px con módulos redondeados y un banner debajo. Cambia `url` y el código se vuelve a dibujar, con Vue actualizando el `<svg>` en el sitio.

<Shot id="lib-framed-menu-code" />

`QRCode` acepta las props del `QRCode` de React: todas las opciones de `QRProps`, más `logo`, `logoOptions`, `hideLogo` y `scale` para un logo. En una plantilla, escríbelas en kebab-case (`body-pattern`) o en camelCase. Un indicador como `auto-level` o `hide-logo` no necesita valor. `class`, `style`, `aria-label` y otros atributos van en el `<svg>`, o en el `<svg>` exterior del marco cuando hay marco, y lo mismo ocurre con los listeners como `@click`.

### 3. Guárdalo como archivo con useQRCode [#3-save-it-as-a-file-with-useqrcode]

```vue title="src/components/DownloadCode.vue"
<script setup lang="ts">
import { useQRCode } from "qrdx/vue";
import { ref } from "vue";

const url = ref("https://example.com/menu");
const { svg, download } = useQRCode(() => ({
  value: url.value,
  size: 256,
  margin: 4,
  bodyPattern: "rounded",
}));
</script>

<template>
  <div v-html="svg" />
  <button type="button" @click="download({ format: 'png', size: 1024, filename: 'menu.png' })">
    Download PNG
  </button>
</template>
```

El código se muestra a partir de su marcado, y el botón guarda `menu.png` a 1024 px. `useQRCode(props)` recibe las props de `QRCode` como objeto, ref, objeto reactivo o getter, y devuelve:

- `svg`: el marcado SVG como ref computada. Sigue las props y funciona durante el renderizado en el servidor.
- `toDataURL(format, { size, quality })`: el código como data URL.
- `download({ format, filename, size, quality })`: guarda el código como archivo.
- `options`: las opciones con las que se dibuja el código, como ref computada.

`toDataURL` y `download` usan por defecto PNG con el `size` propio del código. Los formatos son `png`, `jpg`, `webp`, `svg`, `pdf` y `eps`. PNG, JPG y WebP necesitan un navegador, y PDF necesita el paquete opcional `jspdf`.

## QRCodeSVG y ajustes de imagen sin procesar [#qrcodesvg-and-raw-image-settings]

`QRCodeSVG` acepta `QRProps`, como el `QRCodeSVG` de React. Un logo va en `imageSettings`, en píxeles:

```vue title="src/components/LogoCode.vue"
<script setup lang="ts">
import { QRCodeSVG } from "qrdx/vue";
</script>

<template>
  <QRCodeSVG
    value="https://example.com"
    :size="256"
    level="H"
    :image-settings="{ src: '/logo.png', width: 48, height: 48, excavate: true }"
  />
</template>
```

Prefiere `QRCode` con `logo` y `logoOptions`, salvo que coloques el logo tú mismo.

## Renderizado en el servidor y Nuxt [#server-rendering-and-nuxt]

Ambos componentes se renderizan con el renderizador de servidor de Vue (`vue/server-renderer`), de modo que el código forma parte del HTML del servidor. El marcado no tiene ids aleatorios, así que el navegador lo hidrata sin discrepancias.

En Nuxt, úsalos en cualquier página o componente. Se renderizan en el servidor y se hidratan en el navegador. Dentro de `<ClientOnly>` se renderizan solo en el navegador.

## Más de qrdx/core [#more-from-qrdxcore]

`qrdx/vue` reexporta todo lo de `qrdx/core`: `toSVGString`, `downloadQRCode`, `getQRCodeDataUrl`, `getScanScore`, la biblioteca oficial de marcos (`getOfficialFrame`) y el resto. [JavaScript puro](/docs/vanilla-js) los explica. Para PNG en un servidor, usa `getQRAsPNG` de `qrdx/node`.

El `wrapper` de una plantilla personalizada se escribe con la `h` que exporta `qrdx/vue`. Es la `h` del core, no la de Vue, así que importa una de las dos con otro nombre cuando un archivo necesite ambas:

```ts title="src/labelled-template.ts"
import { h } from "qrdx/vue";

export const Labelled = {
  id: "Labelled",
  name: "Labelled",
  wrapper: (children, props) =>
    h(
      "svg",
      { viewBox: "0 0 300 340", xmlns: "http://www.w3.org/2000/svg" },
      h("g", { transform: "translate(20, 20) scale(0.87)" }, children),
      h("text", { x: "150", y: "325", textAnchor: "middle" }, props?.label)
    ),
};
```

Pásala como `customTemplate`, con sus props en `customProps`: `<QRCode value="https://example.com" :custom-template="Labelled" :custom-props="{ label: 'Scan me' }" />`.

## Si algo sale mal [#if-something-goes-wrong]

- **`Failed to resolve component: QRCode`.** El componente no está importado en ese archivo. Añade `import { QRCode } from "qrdx/vue"` a su `<script setup>`.
- **Una prop no tiene efecto.** La escribiste como cadena de atributo donde hace falta un valor: `size="256"` pasa una cadena, `:size="256"` un número. Las props de tipo objeto, como `frame` e `image-settings`, siempre necesitan los dos puntos.
- **`PDF export needs the optional "jspdf" package`.** Ejecuta `npm install jspdf` en la aplicación.
