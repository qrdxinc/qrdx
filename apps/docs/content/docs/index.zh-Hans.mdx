QRdx 是一个开源的二维码平台：静态二维码免费使用，无需注册账号；动态二维码可在印刷后修改，并提供托管页面和扫描分析。动态二维码在所有套餐中都能持续使用，即使你取消订阅也一样（[Never-Hostage 保障](/guarantee)）。
